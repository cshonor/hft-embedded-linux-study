# 18.2 数据链路套接字地址结构

> [Ch 29 数据链路访问](../../3_DeepMaster/Chapter29_DatalinkAccess/study.md) · [18.3 rt_msghdr](../18.3_Socket_Read_Write.md)

---

## 核心结构：`sockaddr_dl`

定义于 `<net/if_dl.h>`，处理 **MAC / 链路层** 地址：

```c
struct sockaddr_dl {
    uint8_t      sdl_len;    /* 结构体总长度 */
    sa_family_t  sdl_family; /* AF_LINK */
    uint16_t     sdl_index;  /* 接口索引，如 1=lo0，2=eth0 */
    uint8_t      sdl_type;   /* IFT_ETHER 等 */
    uint8_t      sdl_nlen;   /* 接口名长度 */
    uint8_t      sdl_alen;   /* MAC 地址长度 */
    uint8_t      sdl_slen;   /* 链路层选择子长度 */
    char         sdl_data[]; /* 接口名 + MAC 连续存放 */
};
```

---

## 易错：内存布局

`sdl_data` **不是**普通 C 字符串：

```text
[ 接口名如 "eth0" ][ MAC 如 00:11:22:33:44:55 ]
```

| 错误 | 正确 |
|------|------|
| `printf("%s", sdl_data)` | 用 **`sdl_nlen`** 跳过接口名，再按 **`sdl_alen`** 取 MAC |

路由消息里常夹杂 `sockaddr_dl` — 解析 `rtm_addrs` 时必须识别 **AF_LINK**。
