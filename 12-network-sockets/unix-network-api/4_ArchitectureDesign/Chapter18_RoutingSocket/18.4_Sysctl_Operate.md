## 核心主旨：取代有缺陷的 ioctl

`ioctl(SIOCGIFCONF)` 等存在缓冲区**静默截断** — `sysctl` 为 POSIX 推荐的现代方案。

```c
int sysctl(int *name, u_int namelen,
           void *oldp, size_t *oldlenp,
           void *newp, size_t newlen);
```

---

## MIB 层次化 `name[]`

访问路由 / 接口时常用层级：

| 层 | 典型值 | 含义 |
|----|--------|------|
| 1 | `CTL_NET` | 网络子系统 |
| 2 | `AF_ROUTE` | 路由 |
| 3 | `0` | 协议号 |
| 4 | `AF_INET` / `0` | 地址族或全部 |
| 5 | `NET_RT_DUMP` / `NET_RT_IFLIST` | 倾印路由表 / 接口列表 |

---

## Two-Pass：规避截断

```text
① sysctl(name, oldp=NULL)     → oldlenp 得到所需精确字节数
② malloc(oldlen)
③ sysctl(name, oldp=buf)      → 完整、无截断取回数据
```

| 对比 | ioctl | sysctl |
|------|-------|--------|
| 长度 | 猜缓冲区，可能截断 | 先问长度再分配 |
| 路由表 | 不便完整导出 | `NET_RT_DUMP` |
