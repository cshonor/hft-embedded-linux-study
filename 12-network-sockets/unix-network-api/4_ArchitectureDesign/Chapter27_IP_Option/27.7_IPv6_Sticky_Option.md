# 27.7 IPv6 粘附选项（Sticky Options）

> [Ch 14.5 sendmsg 辅助数据](../../2_AdvancedSkill/Chapter14_AdvancedIO_Func/14.5_Recvmsg_Sendmsg_Func.md) · [Ch 15.7 SCM_RIGHTS](../Chapter15_UnixDomainProtocol/15.7_File_Descriptor_Transfer.md)

---

## 两种传递途径

| 方式 | API | 作用域 |
|------|-----|--------|
| **辅助数据** | **`sendmsg`** 的 `msg_control` | **仅当前一个**数据报（UDP 常用） |
| **粘附选项** | **`setsockopt`**（如 `IPPROTO_IPV6`, **`IPV6_DSTOPTS`**） | **套接字级**：此后所有报文（含 TCP 各分节、`write`）自动附带 |

---

## 选型

```text
单包实验 / UDP 每包不同扩展首部  → sendmsg 辅助数据
TCP 客户端全程相同扩展首部       → setsockopt 粘附
```

理解**单次生效** vs **全局生效**的控制面差异。
