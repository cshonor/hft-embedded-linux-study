# 27.3 IPv4 源路径选项

> [27.2 IPv4 选项](../27.2_IPv4_Packet_Option.md) · [27.6 IPv6 路由首部](../27.6_IPv6_Route_Header.md)

---

## 核心主旨

**源路由**：由**发送端**（非路由器）指定数据报必经的中间节点。

| 类型 | 行为 |
|------|------|
| **严格源路由（SSRR）** | 必须**严格**按列表逐跳；非直连下一跳 → 丢弃 |
| **宽松源路由（LSRR）** | 必须经过列表节点，节点间可经未列出路由器 |

---

## 编程要点

| 方向 | 机制 |
|------|------|
| 发送 | 构造 IP 列表 → **`setsockopt(IP_OPTIONS)`** |
| 接收（TCP） | SYN 带源路由 → 内核**反转**路径，应答**原路返回** |

---

## 现实：全网封杀

| 风险 | 后果 |
|------|------|
| IP 欺骗、绕过防火墙拓扑 | 核心路由器/防火墙见源路由选项 → **静默丢弃** |

现代网络编程：**仅作理论了解**，勿依赖生产路径。
