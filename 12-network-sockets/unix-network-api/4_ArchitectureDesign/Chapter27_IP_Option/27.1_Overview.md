## 核心主旨

多数应用无需操作 **IP 层**首部；诊断工具、测量、特殊路由策略则需控制或观察 IP 报文路径。

---

## IPv4 vs IPv6 架构

| | IPv4 | IPv6 |
|---|------|------|
| 机制 | 首部最多 **40 字节**固定“选项”区 | **扩展首部**菊花链，长度灵活 |
| 现状 | 极少使用、多被过滤 | 工程化 API（RFC 3542） |
| 编程 | 手工 **TLV** 裸字节 | `inet6_opt_*` / `inet6_rth_*` |
