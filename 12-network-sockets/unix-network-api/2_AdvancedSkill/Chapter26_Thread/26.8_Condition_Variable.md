## 核心主旨

活跃连接已满时，主线程应**休眠等待**槽位，而非 Mutex 自旋轮询。

**条件变量（`pthread_cond_t`）必须与 Mutex 配合。**

---

## pthread_cond_wait

```c
int pthread_cond_wait(pthread_cond_t *cond, pthread_mutex_t *mutex);
```

**原子逻辑**（调用前已持有 `mutex`）：

1. 线程睡眠  
2. **自动解锁** `mutex`  
3. 被唤醒后返回前 **自动重新加锁** `mutex`

---

## 虚假唤醒：必须用 while

```c
pthread_mutex_lock(&mutex);
while (active_threads >= MAX_THREADS) {
    pthread_cond_wait(&cond, &mutex);
}
active_threads++;
pthread_mutex_unlock(&mutex);
```

**禁止用 `if`** 只等一次。

---

## 唤醒

| API | 作用 |
|-----|------|
| **`pthread_cond_signal`** | 唤醒**一个**等待线程 |
| **`pthread_cond_broadcast`** | 唤醒**全部**等待线程 |
