## 辅助封装

书中 **`host_serv`**：封装 `getaddrinfo` 的 **`hints` 初始化**。

| 输入 | 输出 |
|------|------|
| 主机名、服务名、地址族 | 就绪的 **`addrinfo` 链表首指针** |

减少每次手写 `memset` + `ai_family` + `ai_socktype` 的重复。
