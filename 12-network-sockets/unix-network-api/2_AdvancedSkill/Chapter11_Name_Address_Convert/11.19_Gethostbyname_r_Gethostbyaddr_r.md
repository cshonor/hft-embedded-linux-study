# 11.19 gethostbyname_r 和 gethostbyaddr_r 函数

---

## 历史补救

带 **`_r`（Reentrant）** 后缀：调用者提供 **缓冲区** 与长度，结果写入调用方内存，避免静态区竞争。

---

## 现状

| 问题 | 说明 |
|------|------|
| **参数不一致** | Linux 与 Solaris 等 `_r` 原型不同 |
| **可移植性差** | 难以写跨平台代码 |
| **最佳实践** | **弃用**，改用 **`getaddrinfo`** |
