# 13.6 daemon_inetd 函数

> [13.4 daemon_init](../13.4_Daemon_Init_Func.md) · [13.5 inetd](../13.5_inetd_Daemon.md) · [13.3 syslog](../13.3_Syslog_Func.md)

---

## 适用场景

专为 **inetd 拉起** 的程序编写初始化 — **不要** 再调 `daemon_init`（inetd 已脱离终端）。

书中封装：**`daemon_inetd`**（或等价逻辑）。

---

## 获取客户身份

无 `accept` 环节，仅有 **0/1/2 = 网络套接字**：

```c
getpeername(0, ...);   /* 对 fd 0 查远程 IP/端口 */
```

---

## 日志输出陷阱

| 禁止 | 原因 |
|------|------|
| `printf` / `fprintf(stderr, ...)` | **1、2 已是网络套接字** → 文本发往客户，**破坏协议** |

| 合法 | 说明 |
|------|------|
| **`syslog`** | 唯一安全的错误/调试出口 |

---

## 与 13.4 对比

| | 自启动守护进程 | inetd 子服务 |
|--|----------------|--------------|
| 初始化 | `daemon_init` | **仅** openlog + getpeername 等 |
| 套接字 API | 自备 listen/accept | **无**；stdio = 网络 |
| 日志 | syslog | **必须** syslog |
