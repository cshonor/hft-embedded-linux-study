# 5.9 处理 SIGCHLD 信号

> [5.10 waitpid](../5.10_Wait_Waitpid_Func.md) · [5.7 僵尸](../5.7_Normal_Exit.md)

---

## 核心主旨与关键论据

**任何子进程终止**时，内核向父进程发 **`SIGCHLD`**。若父进程不处理（默认在某些系统上可能表现为忽略或需显式设置），子进程退出状态无人取走 → **僵死进程**。并发服务器的 `main` 在 **`Listen` 之后**必须注册 SIGCHLD 处理。

---

## 逻辑脉络

```text
子进程 exit → 内核发 SIGCHLD 给父
→ 父的信号处理函数运行（异步，打断 accept）
→ 处理函数内 waitpid 回收（见 5.10 必须 while+WNOHANG）
→ 父返回 accept 循环
```

### 典型注册位置（与 5.2 结合）

```c
Listen(listenfd, LISTENQ);
Signal(SIGCHLD, sig_chld);   /* 或 sigaction 等价 */
for (;;) {
    connfd = Accept(...);
    if (fork() == 0) { ... }
    Close(connfd);
}
```

---

## 易错细节与重点结论

| 规则 | 说明 |
|------|------|
| **handler 里禁止 printf** | 只用异步信号安全函数（`write` 到 fd 1、`waitpid` 等） |
| **handler 里不能只 wait 一次** | 信号不排队，并发断开可能丢信号（5.10） |
| **与 SA_RESTART 配合** | accept 被中断后应能继续接客 |
| **不要 SIG_IGN SIGCHLD 若还要并发** | 忽略则子变僵尸（除非用 SIGCHLD+SA_NOCLDWAIT 等特例，本书不主打） |
