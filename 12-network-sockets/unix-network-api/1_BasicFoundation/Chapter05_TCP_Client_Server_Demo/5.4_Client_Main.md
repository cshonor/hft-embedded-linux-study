# 5.4 TCP 回射客户程序：main 函数

> [5.3 str_echo](../5.3_Server_Str_Echo.md) · [5.5 str_cli](../5.5_Client_Str_Cli.md) · `connect`：[Ch 4.3](../../Chapter04_BasicTCPSocket/4.3_Connect_Function.md)

---

## 核心主旨与关键论据

客户 `main` 负责：**校验参数 → 构造服务器地址 → 建立 TCP 连接 → 把已连接套接字交给 `str_cli`**。与 Ch 1.2 时间客户端同源，但目标端口与业务函数不同。

---

## 核心知识点与代码拆解

### 命令行参数

- 典型：`client <服务器IP>`  
- **必须校验** `argc`：缺 IP 则用法提示并退出  
- IP 为 **ASCII 点分十进制**（或后续扩展域名，Ch 11）

### 地址结构装填

```c
bzero(&servaddr, sizeof(servaddr));
servaddr.sin_family = AF_INET;
servaddr.sin_port = htons(SERV_PORT);
if (inet_pton(AF_INET, argv[1], &servaddr.sin_addr) <= 0)
    err_quit("inet_pton error for %s", argv[1]);
```

| 步骤 | 要点 |
|------|------|
| `bzero` | 清零整个 `sockaddr_in`（本书偏好，见 Ch 3.5） |
| `htons` | 端口转**网络字节序** |
| `inet_pton` | 比 `inet_addr` 安全，支持错误区分；返回 ≤0 则参数非法 |

### 连接与交接

```c
sockfd = Socket(AF_INET, SOCK_STREAM, 0);
Connect(sockfd, (SA *)&servaddr, sizeof(servaddr));
str_cli(sockfd);   /* 阻塞在这里直到用户 EOF */
exit(0);           /* 触发四次挥手 */
```

- **`Connect` 包裹函数**：失败则 `err_sys` 退出  
- **connect 失败后不能对同一 sockfd 再 connect**（Ch 4.3）：须 close 后重新 socket  

---

## 逻辑脉络与因果关系

```text
解析 IP → socket → connect（三次握手，阻塞）→ str_cli（交互循环）
→ main exit → close 套接字 → 客户发 FIN
```

---

## 易错细节与重点结论

| 易错 | 纠正 |
|------|------|
| 忘记 `htons` 端口 | 连到错误端口或连接失败 |
| `inet_pton` 返回值未检查 | 非法 IP 仍去 connect |
| connect 失败后重试同一 fd | **必须** close + 新 socket |
| 在 main 里写读写循环 | 应分离到 `str_cli` 便于 Ch 6 改造 |
