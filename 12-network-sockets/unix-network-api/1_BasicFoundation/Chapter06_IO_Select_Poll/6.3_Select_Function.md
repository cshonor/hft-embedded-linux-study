# 6.3 select 函数

> [6.4 str_cli 修订](../6.4_Str_Cli_Revised.md) · poll：[6.10](../6.10_Poll_Function.md)

---

## 核心主旨与关键定义

**`select`**：进程指示内核等待**多个事件**之一发生，在事件发生或超时后唤醒。

```c
int select(int maxfdp1, fd_set *readset, fd_set *writeset,
           fd_set *exceptset, const struct timeval *timeout);
```

| 返回值 | 含义 |
|--------|------|
| > 0 | 就绪描述符**数目** |
| 0 | 超时 |
| -1 | 出错 |

---

## 参数解析

### 1. `timeout`

| 取值 | 行为 |
|------|------|
| **`NULL`** | 永远等，直到有就绪 |
| **正时间** | 最多等该时长 |
| **`{0,0}`** | **轮询**，立即返回 |

### 2. `fd_set` 与四个宏

| 宏 | 作用 |
|----|------|
| **`FD_ZERO(&fdset)`** | 清空位图 |
| **`FD_SET(fd, &fdset)`** | 加入待测 fd |
| **`FD_CLR(fd, &fdset)`** | 移出 |
| **`FD_ISSET(fd, &fdset)`** | **测试是否就绪**（返回后由内核置位） |

`readset` / `writeset` / `exceptset`：测读、写、异常。

### 3. `maxfdp1`

- **最大 fd 编号 + 1**  
- 内核只扫描 `[0, maxfdp1)`，降低开销  

---

## 6.3.1 描述符就绪条件（排查 Bug 核心）

### 读就绪（满足其一）

1. 接收缓冲字节 ≥ **`SO_RCVLOWAT`**（TCP/UDP 默认 1）→ `read` 不阻塞  
2. **读半关闭**（收到 **FIN**）→ `read` 不阻塞，**立即返回 0（EOF）**  
3. **监听套接字**且已完成连接队列非空 → `accept` 不阻塞  
4. **套接字错误待处理** → `read` 返回 -1 + errno  

### 写就绪（满足其一）

1. 发送缓冲可用空间 ≥ **`SO_SNDLOWAT`**（TCP 常 2048）且已连接（UDP 可无连接）  
2. **写半关闭** → 再写可能 **`SIGPIPE`**  
3. 非阻塞 **`connect` 成功或已失败**  
4. 套接字错误待处理 → `write` -1  

### 异常就绪

- **带外数据 OOB** 或带外标记  

---

## 6.3.2 select 的最大描述符数

- 受 **`FD_SETSIZE`** 限制（常 **1024**，编译期静态位图）  
- 超 1024 并发 → 需 **poll / epoll**  

---

## 易错细节与重点结论

| 陷阱 | 说明 |
|------|------|
| 每次循环忘记 `FD_ZERO` + 重新 `FD_SET` | `select` **覆盖** fd_set，必须重建 |
| FIN 到达即读就绪 | 不 read 会反复唤醒 select |
| maxfdp1 传错 | 漏测高编号 fd |
