# 2.3 用户数据报协议（UDP）

> 对比 TCP 字节流：[2.4](../2.4_TCP_Protocol.md) · 服务器示例：Ch 8

## 核心知识点

**无连接**、**不可靠**的数据报服务：加端口号交给 IP，**不保证**到达。

## 关键特性

| 特性 | 说明 |
|------|------|
| **保留记录边界** | 发 2000 字节数据报 → 一次 `recvfrom` 收 2000 字节（若未丢）；**无 TCP 粘包** |
| **无可靠性** | 不保证到达、顺序、唯一（可丢、乱序、重复） |
| **应用层补偿** | 需可靠时须在应用层自实现 **ACK、超时、重传** |

## 易错点与坑点

**UDP 无内置流量控制**：发送远快于接收 → 接收缓冲区溢出 → 数据报**静默丢弃**。

## 个人学习总结

> 💡 WebRTC、高频交易/游戏中 UDP 的现代用法。
