# 2.11 缓冲区大小及限制

> MSS 选项：[2.6](../2.6_TCP_Connect_Terminate.md) · 套接字缓冲选项：Ch 7

## 核心知识点

数据经应用 → 传输层缓冲 → 网络层 → 链路层，各层有大小限制。

## 关键定义

| 术语 | 说明 |
|------|------|
| **MTU** | 链路层单帧载荷上限；以太网常 **1500 字节** |
| **路径 MTU** | 路径上最小 MTU（可不对称） |
| **IP 分片** | 报文超 MTU 时 IP 切片 |
| **DF 位** | 禁止分片；超 MTU 则丢弃并 ICMP「fragmentation needed」→ **路径 MTU 发现** |
| **MSS** | TCP 通告单分节最大数据量 |

**常见 MSS（IPv4/以太网）**

```text
MSS = 1500 - 20(IP) - 20(TCP) = 1460 字节
```

## 输出路径差异

| 协议 | `write` 行为 |
|------|----------------|
| **TCP** | 拷贝到 **SO_SNDBUF**；满则阻塞；按 MSS 切块发送；**收到 ACK 才释放**已发数据 |
| **UDP** | 无真发送缓冲，仅上限；加 UDP 头交 IP；IP 接受则 `write` **立即返回**（后续可能丢） |
