# 8.2 recvfrom 和 sendto 函数

> [8.4 dg_echo](../8.4_UDP_Server_Dg_Echo.md) · 值—结果：Ch 3.3

---

## 核心主旨

UDP **无连接状态**，`read`/`write` **不能**在 I/O 时指定对端地址，须用 **`recvfrom` / `sendto`**。

---

## 函数原型

```c
ssize_t recvfrom(int sockfd, void *buff, size_t nbytes, int flags,
                 struct sockaddr *from, socklen_t *addrlen);

ssize_t sendto(int sockfd, const void *buff, size_t nbytes, int flags,
               const struct sockaddr *to, socklen_t addrlen);
```

### recvfrom

| 参数 | 说明 |
|------|------|
| `from`, `addrlen` | **值—结果**；内核填入**发送方** IP+端口 |
| 不关心来源 | `from` / `addrlen` 可为 **`NULL`** |

### sendto

- `to` + `addrlen`：目的地，须 **网络字节序** 装填好的 `sockaddr`

---

## 易错细节与重点结论

| 现象 | 与 TCP 区别 |
|------|-------------|
| **0 字节 UDP 报文** | `recvfrom` 返回 **0** = 空数据报，**不是 EOF** |
| TCP `read` 返回 0 | **对端关闭连接（FIN）** |
| **地址结构太小** | 内核可能**截断** `from` 中地址（旧系统或不警告） |
