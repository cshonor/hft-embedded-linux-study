# 24.4 TCP 带外数据小结

---

## RFC 冲突（历史大坑）

| RFC | 紧急指针含义 |
|-----|----------------|
| **793** | 指向紧急数据**最后一字节的后一字节** |
| **1122** | 指向**最后一字节本身** |

当今多数 Berkeley 系与 Windows 按 **1122**，并兼容老行为。

---

## 覆盖陷阱（Overwrite）

TCP **只有一个**带外标记。

连续两次 `MSG_OOB`，接收端未读第一次 → **后一次覆盖前一次** → 第一个 OOB 字节沦为**普通数据**。

---

## 易错汇总

| 点 | 说明 |
|----|------|
| 非独立通道 | 仅 URG 补丁，不可靠、易覆盖 |
| 多字节 OOB send | 通常仅**最后一字节**有效 |
| 双读模式 | 分离 vs inline 不可混用 `MSG_OOB` |
