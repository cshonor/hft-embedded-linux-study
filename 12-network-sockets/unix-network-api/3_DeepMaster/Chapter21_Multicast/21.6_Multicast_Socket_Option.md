# 21.6 多播套接字选项

> [Ch 7.2 setsockopt](../../1_BasicFoundation/Chapter07_SocketOption/7.2_Getsockopt_Setsockopt.md) · [21.7 mcast_*](../21.7_Mcast_Join_Related_Func.md)

---

## 级别

`IPPROTO_IP` / `IPPROTO_IPV6` + `setsockopt`。

---

## 1. 加入/离开组（接收必备）

| 族 | 加入 | 离开 | 结构 |
|----|------|------|------|
| IPv4 | `IP_ADD_MEMBERSHIP` | `IP_DROP_MEMBERSHIP` | `ip_mreq`（组 IP + 接口 IP） |
| IPv6 | `IPV6_JOIN_GROUP` | `IPV6_LEAVE_GROUP` | `ipv6_mreq`（组 + **接口 index**） |
| SSM | `IP_ADD_SOURCE_MEMBERSHIP` 等 | | 含源 IP |

---

## 2. 外出接口（发送）

**`IP_MULTICAST_IF` / `IPV6_MULTICAST_IF`** — 强制从指定网卡发多播。

---

## 3. TTL / 跳数

**`IP_MULTICAST_TTL` / `IPV6_MULTICAST_HOPS`**

- 默认常 **1**（仅本地子网）  
- 跨路由器须显式增大  

---

## 4. 回环 Loopback

**`IP_MULTICAST_LOOP` / `IPV6_MULTICAST_LOOP`**

- 默认 **1**：本机也 Join 时，**收到自己发的**多播  
- 设 **0** 可省本机处理
