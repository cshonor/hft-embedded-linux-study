## 开启 SIGIO 三步骤（必须全部完成）

```text
1. sigaction(SIGIO, handler, ...)     /* 建立 SIGIO 处理函数 */
2. fcntl(fd, F_SETOWN, pid/pgrp)      /* 套接字属主：信号发给谁 */
3. fcntl(fd, F_SETFL, O_ASYNC)        /* 或 ioctl FIOASYNC：开启异步 I/O */
```

缺任一步 → **无 SIGIO**。

---

## UDP：理想用武之地

仅两种情形触发 `SIGIO`：

| 事件 | 处理 |
|------|------|
| **数据报到达** | 可安全 `recvfrom` |
| **异步错误** | 可读错误状态 |

收到 SIGIO → 明确可读或出错。

---

## TCP：几乎无用

触发 `SIGIO` 的事件**过多**且语义含混：

- listen 上新连接就绪  
- 各种断开/半关闭状态变化  
- 数据到达  
- **发送缓冲区有空**（可写）  
- 异步错误  

收到 SIGIO 时**不知**是哪一种 → 盲目 read/write 易 **EWOULDBLOCK**。

---

## 特例（偏门）

**仅对 listenfd** 开信号驱动时，SIGIO 常表示 **accept 就绪** — 少数高并发优化曾探索。
