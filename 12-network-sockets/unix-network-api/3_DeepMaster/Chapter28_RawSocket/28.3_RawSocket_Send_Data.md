## 未开启 IP_HDRINCL（默认）

| 应用提供 | 内核行为 |
|----------|----------|
| 数据 = **IP 载荷** | 填 IP ID、长度、分片、**校验和**、TTL、选路发送 |

应用**不能**改源 IP 等 IP 层字段。

---

## 已开启 IP_HDRINCL

`sendto` 数据须含**完整 IPv4 首部**。

内核干预（**跨平台不一致**）：

| 字段 | 常见行为 |
|------|----------|
| **ip_id** | 应用填 0 → 内核生成唯一值 |
| **ip_sum** | 内核**重算**校验和 |
| **源 IP** | 0 → 路由选外出接口 IP；显式指定 → 可能 **IP 伪造**（仅限授权测试） |
| **ip_len / ip_off** | Berkeley：曾要求**主机序**；Linux 等多要求**网络序** — 移植雷区 |
