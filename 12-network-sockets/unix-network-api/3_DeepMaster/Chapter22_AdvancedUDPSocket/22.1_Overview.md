## 黄金法则预览

- **必须 UDP**：广播/多播  
- **可用 UDP**：简单请求-应答（DNS）、可丢包低延迟（实时媒体）  
- **避免 UDP**：大块可靠传输（须在应用层重做 TCP+拥塞控制）
