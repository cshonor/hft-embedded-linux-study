## 核心主旨

默认套接字为**阻塞**：操作不能立即完成时进程**睡眠**。

**非阻塞 I/O**：内核**不睡眠**，立即返回，通常 **`errno = EWOULDBLOCK`**（或 `EAGAIN`）。

设置：**`fcntl` → `O_NONBLOCK`**（见 Ch 7.11）。

---

## 四类可能阻塞的操作

### 1. 输入（read/recv/recvfrom/recvmsg…）

| 模式 | 行为 |
|------|------|
| 阻塞 | 接收缓冲区空 → 睡眠 |
| 非阻塞 | 无数据 → **-1, EWOULDBLOCK** |

### 2. 输出（write/send…）

| 协议 | 非阻塞行为 |
|------|------------|
| **TCP** | 发送缓冲区满 → EWOULDBLOCK；有部分空间 → **短写**（返回实际写入字节） |
| **UDP** | 通常**无**真正发送缓冲区阻塞 → 少见 EWOULDBLOCK |

### 3. accept

| 模式 | 行为 |
|------|------|
| 阻塞 | 已完成连接队列空 → 睡眠 |
| 非阻塞 | 队列空 → **EWOULDBLOCK** |

### 4. connect

| 模式 | 行为 |
|------|------|
| 阻塞 | 等待三路握手完成 → 睡眠 |
| 非阻塞 | 不能立刻建立 → **-1, errno = EINPROGRESS**（**不是** EWOULDBLOCK），握手在后台继续 |
