## 核心主旨

如何让网络服务器在后台**安静、稳定**运行。

---

## 守护进程（Daemon）

| 属性 | 说明 |
|------|------|
| 定义 | 后台运行、**无控制终端**的进程 |
| 生命周期 | 常于系统引导启动，直至关机 |
| 无终端的意义 | 不收键盘信号（`SIGINT`、`SIGTSTP`）；错误不会打到用户屏幕 |

---

## 启动方式分类

| 方式 | 示例 |
|------|------|
| **引导脚本** | `/etc/rc` 等；`inetd`、Web 服、`syslogd`（常 root） |
| **inetd 超级服务器** | 按需派生具体服务 |
| **cron** | 定期执行 → 子进程亦为守护进程 |
| **at** | 指定时刻执行一次 |
| **用户后台** | `nohup` 或命令末尾 **`&`** |
