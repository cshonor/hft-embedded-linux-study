# 11.5 getservbyname 和 getservbyport 函数

> [11.6 getaddrinfo](../11.6_Getaddrinfo_Func.md)（服务名一并解析）

---

## 核心主旨

用 **服务名**（"ftp"、"http"）代替硬编码端口；双向映射。

| 函数 | 方向 |
|------|------|
| **`getservbyname`** | 服务名 + 协议（如 `"udp"`）→ `servent`（含端口） |
| **`getservbyport`** | **网络字节序**端口 + 协议 → 服务名 |

---

## 底层机制

通常读本地 **`/etc/services`**。

---

## 易错细节

- **`getservbyport` 的端口必须是网络字节序**  
- 现代代码：在 **`getaddrinfo` 的 `service` 参数** 直接传 `"http"` 或 `"80"`
