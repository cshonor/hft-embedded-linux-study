## 核心主旨

协议无关的 **TCP 监听套接字**封装。

```text
getaddrinfo（AI_PASSIVE）→ for:
    socket → setsockopt(SO_REUSEADDR) → bind → listen
    任一成功 → 返回 listenfd
    bind 失败 → close(fd)，下一节点
```

---

## 易错细节

| 点 | 说明 |
|----|------|
| **bind 失败** | 必须先 **close** 再试下一地址 |
| **多地址** | 可能只需一个 listenfd 绑定通配或某一接口 |
| **v6-only 栈** | 链表内容与系统策略有关 |
