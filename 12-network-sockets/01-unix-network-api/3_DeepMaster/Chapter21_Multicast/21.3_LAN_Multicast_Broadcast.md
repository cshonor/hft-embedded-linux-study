# 21.3 局域网上多播和广播的比较

> [Ch 20.3](../Chapter20_Broadcast/20.3_Unicast_Broadcast_Compare.md)

---

## 广播（回顾）

全子网网卡收帧 → 中断 → IP → UDP → 无监听端口才丢 → **无辜主机 CPU 浪费**。

---

## 多播过滤

| 情况 | 行为 |
|------|------|
| **未 Join** 该组 | 网卡未配置该多播 MAC → **硬件丢弃**，CPU 无感 |
| **已 Join** | 网卡放行 → 因 **32:1 MAC 碰撞**，IP 层再比对**完整**多播 IP → UDP |

---

## 重点结论

过滤从**软件协议栈下推到网卡硬件** — 多播相对广播的核心优势（LAN 上）。
