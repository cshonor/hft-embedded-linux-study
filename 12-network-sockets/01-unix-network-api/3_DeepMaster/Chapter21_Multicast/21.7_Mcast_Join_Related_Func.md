## 协议无关封装

屏蔽 `ip_mreq` / `ipv6_mreq` 与选项宏差异：

| 函数 | 作用 |
|------|------|
| **`mcast_join(sockfd, grp, grplen, ifname, ifindex)`** | 按 `sockaddr` 族自动 `setsockopt` 加入 |
| **`mcast_leave`** | 离开组 |
| **`mcast_set_loop`** | 回环 |
| **`mcast_set_ttl`** | TTL/hops |
