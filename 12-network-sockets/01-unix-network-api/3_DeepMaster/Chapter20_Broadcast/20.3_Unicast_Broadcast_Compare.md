# 20.3 单播和广播的比较

---

## 单播接收流程

```text
网卡收帧 → 硬件比对目的 MAC
  不匹配（且非组播/广播 MAC）→ 硬件丢弃，不占 CPU
  匹配 → 中断 → IP 查目的 IP → UDP 查端口 → 入套接字队列
```

---

## 广播的代价

```text
目的 IP/MAC 为广播 → 子网每台主机网卡都必须收帧 → 中断上送
→ IP 交 UDP → 无进程监听该端口 → 丢弃（可能 ICMP 端口不可达）
```

---

## 核心论据

**未参与协议的主机仍承担 CPU/中断开销** — 高频广播须迁向**多播**（Ch 21）；亦是 **IPv6 废除广播** 的理由之一。
