## 核心主旨

**`ioctl`（I/O Control）**：无法归入 `read/write` 或 `getsockopt/setsockopt` 的底层操作，历史上常经此完成。

本章四大应用领域：

| 领域 | 节 |
|------|-----|
| 套接字操作 | 17.3 |
| 文件描述符操作 | 17.4 |
| **网络接口配置** | 17.5–17.7 |
| ARP / 路由表 | 17.8–17.9 |

---

## 历史演进与 POSIX 替代

| 功能 | 现代替代 |
|------|----------|
| 非阻塞、信号驱动 I/O | **`fcntl`** |
| 带外标记 | **`sockatmark`** |
| 路由表、ARP 遍历 | **路由套接字**（Ch 18）、Netlink |
| **本机网卡拓扑** | **`SIOCGIFCONF`** 长期仍不可替代 |

---

## 易错细节

`ioctl` **可移植性差**，参数类型无编译期检查 — 新代码优先 POSIX 专用 API。
