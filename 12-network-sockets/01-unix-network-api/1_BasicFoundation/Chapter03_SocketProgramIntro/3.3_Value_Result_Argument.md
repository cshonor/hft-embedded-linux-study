# 3.3 值—结果参数

> [3.2 地址结构](../3.2_SocketAddressStructure.md) · `socklen_t`：[Ch 1.11](../../Chapter01_Introduction/1.11_64BitArchitecture.md)

---

## 核心主旨与关键论据

套接字地址结构在**用户进程与内核**间传递时，**长度参数**随方向变化 — **值—结果参数（Value-Result Argument）**。

---

## 进程 → 内核（纯 Value）

| 函数 | 传递 |
|------|------|
| `bind`, `connect`, `sendto` | 结构体指针 + **整数长度**（如 `sizeof(servaddr)`） |

内核已知拷贝字节数 → **防越界读**用户空间。

---

## 内核 → 进程（Value-Result）

| 函数 | 传递 |
|------|------|
| `accept`, `recvfrom`, `getsockname`, `getpeername` | 结构体指针 + **`socklen_t *` 长度指针** |

| 时机 | 长度含义 |
|------|----------|
| **调用时（Value）** | 缓冲区**最大**容量 |
| **返回时（Result）** | 内核**实际写入**字节数 |

POSIX 规定长度类型为 **`socklen_t`**（64 位兼容，Ch 1.11）。

---

## 逻辑脉络

```text
bind/connect：我告诉内核「结构体有多大」
accept/recvfrom：我告诉内核「你最多写多少」；返回后告诉我「你写了多少」
```
