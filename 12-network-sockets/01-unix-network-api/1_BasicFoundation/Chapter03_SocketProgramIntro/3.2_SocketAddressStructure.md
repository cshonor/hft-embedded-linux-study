# 3.2 套接字地址结构

> [3.3 值—结果](../3.3_Value_Result_Argument.md) · [3.4 字节序](../3.4_ByteOrderFunction.md)

---

## 核心主旨与关键论据

套接字函数需要指向**套接字地址结构**的指针；**不同协议族**有不同定义。所有通信端点 = **IP + 端口**，必须按协议族正确装填，且**端口/IP 用网络字节序**。

---

## 1. IPv4：`sockaddr_in`（`<netinet/in.h>`）

| 成员 | 说明 |
|------|------|
| **`sin_len`** | 可选，8 位；4.3BSD-Reno 加；**POSIX 不强制** |
| **`sin_family`** | 必须 **`AF_INET`** |
| **`sin_port`** | 16 位端口，**网络字节序**（`htons`） |
| **`sin_addr`** | 32 位 IPv4（`struct in_addr`），**网络字节序** |
| **`sin_zero`** | 填充 0，与通用结构对齐（常 16 字节） |

---

## 2. 通用：`sockaddr`

- ANSI C 前无 `void *`，故定义**通用**结构让 `bind`/`connect` 接受任意协议族地址  
- 调用时**必须强转**：

```c
bind(sockfd, (struct sockaddr *)&servaddr, sizeof(servaddr));
```

---

## 3. IPv6：`sockaddr_in6`

- `sin6_family` = **`AF_INET6`**  
- `sin6_port`、`sin6_addr`（**128 位**）  
- `sin6_flowinfo`、`sin6_scope_id`  
- 可能有 **64 位对齐** 要求

---

## 4. `sockaddr_storage`（新通用）

- 空间容纳**任意**套接字地址结构  
- 满足最苛刻**内存对齐**  
- 协议无关代码常用作「足够大的缓冲区」

---

## 易错细节与重点结论

| 陷阱 | 后果 |
|------|------|
| 忘记 `htons`/`htonl` | 连错端口/IP |
| 用 `sockaddr_in` 大小传给 IPv6 API | 溢出/错误 |
| 未 `bzero` 结构体 | 随机垃圾字段 |
