# 2.10 TCP 端口号与并发服务器

> 端口分类：[2.9](../2.9_PortNumber.md) · 监听/已连接套接字：Ch 1.5 / Ch 4

## 核心知识点

并发服务器如何把到达的分节分到正确的进程/套接字？

## 执行流程原理

```text
1. 服务器在知名端口（如 21）创建监听套接字
2. 客户1 (IP1:1500) 连接 → 三次握手 → fork → 已连接套接字绑定客户1 四元组
3. 客户2 (IP2:1501) 同样连到 :21
4. 分路：TCP 查 源IP、源端口、目的IP、目的端口
   - 精确匹配某已连接套接字 → 送入该套接字
   - 否则若目的端口为 21 且 LISTEN → 送入监听套接字排队
```

## 易错点与坑点

**不能仅凭目的端口（如 21）分路** — 必须依赖完整 **四元组** 做上下文路由。
