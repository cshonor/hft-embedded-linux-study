## 核心主旨

结合 **`select` + `shutdown`**，适应交互输入、批量重定向、服务器早/正常关闭。

---

## 核心逻辑

### 标志位 `stdineof`

- 初值 **0**  
- stdin 真正 EOF（`read` 返回 0）→ `stdineof = 1`，**不再监听 stdin**

### 处理 stdin EOF（批量关键）

```text
select 显示 stdin 可读 → read(stdin) 得 0
→ stdineof = 1
→ FD_CLR(stdin, &rset)      /* 不再 select stdin */
→ Shutdown(sockfd, SHUT_WR) /* 发 FIN，半关闭写 */
→ 继续循环，只读 sockfd
```

### 处理网络 EOF

```text
select 显示 sockfd 可读 → read 得 0
→ 若 stdineof == 1：正常结束，return
→ 若 stdineof == 0：err_quit("server terminated prematurely")
```

### 废弃 stdio

- **不用 `fgets`/`readline`** — stdio 缓冲与 `select` 冲突（缓冲里已有数据但 select 不知）  
- 改用 **`read`/`write`** 原始 I/O  

---

## 逻辑脉络（三种场景）

| 场景 | 行为 |
|------|------|
| 交互 Ctrl+D | shutdown 写 + 收完回射 → 正常退出 |
| ` < file` | 发完文件 → shutdown → **收齐**回射 |
| 服务器先死 | select 唤醒 → read=0 且 stdineof=0 → 报错退出 |

---

## 易错细节与重点结论

| 陷阱 | 说明 |
|------|------|
| fgets + select | **禁止**混用（6.7 明确） |
| stdin EOF 直接 exit | 6.5 的错 |
| 忘记 FD_CLR(stdin) | shutdown 后仍 select stdin 可能忙等 |
