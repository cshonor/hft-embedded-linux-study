## 一、本章整体定位

第 1 章是**全书总纲**：用最简 **Daytime TCP C/S** 搭好套接字编程**最小闭环**，定下全书编码范式；后续各章在此骨架上**迭代扩充**。

<a id="ch1-12-hft-checklist"></a>

## 六、HFT 自建 TCP 程序自检清单

```text
【TCP 程序初始化自检】
1. 头文件：unp.h + 包裹函数（或自研等价封装）
2. 协议族：AF_UNSPEC(无关) vs AF_INET / AF_INET6(单栈)
3. 地址结构：sockaddr_in / in6；bzero 或 memset 清零
4. 端口：必须 htons(端口)，禁止裸写 sin_port
5. IP：inet_pton；不用 inet_addr / gethostbyname
6. 错误处理：调试用大写包裹；生产用回调/回收，慎 exit
7. 强转：统一 (SA *) 传参
8. 服务端：分清 listenfd(只 accept) 与 connfd(只 I/O)
```

## 八、精简总结

第 1 章**舍弃复杂业务**，只保留**最小 TCP 通信**，是 UNIX 网络编程的**最小原型**。  
看懂本章代码 = 掌握套接字**骨架**；高级 I/O、并发、多协议都是在骨架上**加功能**。

**链路**：1.2/1.5 原型 → 1.4 规范 → 1.3/11 双栈 → 6/14 多路复用 → 5/26 并发 → 8/21 UDP/组播。
