## 核心主旨与关键论据

TCP 客户通过 **`connect`** 主动发起连接，触发**三次握手**；调用可能**长时间阻塞**。

```c
int connect(int sockfd, const struct sockaddr *servaddr, socklen_t addrlen);
```

- `servaddr` 含服务器 **IP + 端口**  
- 状态：`CLOSED` → `SYN_SENT` → 成功则 **`ESTABLISHED`**

---

## 错误处理（三类典型）

| errno | 类型 | 含义 |
|-------|------|------|
| **ETIMEDOUT** | — | 发 SYN 无响应；内核多次重传（如 ~75s）后失败；主机宕机/防火墙 |
| **ECONNREFUSED** | **硬错误** | 收到 **RST**；主机可达但**端口无 listen** |
| **EHOSTUNREACH / ENETUNREACH** | **软错误** | 中途 ICMP 不可达；内核暂存并继续重传，最终失败才返回 |

---

## 易错细节与重点结论

**connect 失败后禁止对同一 sockfd 再次 connect** — 套接字已损坏；必须 **`close` + 新 `socket`** 再试。
