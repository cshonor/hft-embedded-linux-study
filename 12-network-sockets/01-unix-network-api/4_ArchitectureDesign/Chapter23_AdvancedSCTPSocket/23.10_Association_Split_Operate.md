## 杀手级 API：`sctp_peeloff`

一到多下解决“轻量请求海量、个别长连接需独占线程”的架构问题。

```c
int newfd = sctp_peeloff(sockfd, assoc_id);
```

---

## 场景

```text
主线程：SOCK_SEQPACKET 快速处理大量短请求
某关联：大文件传输等长事务
  → peeloff(assoc_id) → newfd
  → 交给工作线程；主线程继续服务其他关联
```

---

## 结果

| 项 | 说明 |
|----|------|
| `newfd` | **独立一到一**（`SOCK_STREAM`）描述符 |
| 原 fd | 该关联从群集套接字**剥离** |

类 UDP 并发 + 可对单连接做阻塞长 I/O。
