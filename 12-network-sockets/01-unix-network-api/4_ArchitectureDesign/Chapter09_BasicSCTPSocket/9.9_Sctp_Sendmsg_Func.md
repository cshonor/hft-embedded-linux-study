## 核心主旨

SCTP **核心发送 API**；一到多模型取代 `sendto`/`write`。

---

## 关键 `sctp_sndrcvinfo` 字段

| 字段 | 作用 |
|------|------|
| **`sinfo_stream`** | 指定**流号**（缓解队头阻塞） |
| **`sinfo_flags`** | 如 **`SCTP_UNORDERED`** 无序交付；**`SCTP_EOF`** 终止关联 |
| **`sinfo_ppid`** | 净荷协议标识（业务类型标记） |
| **`sinfo_timetolive`** | 消息生存期，过期未发则丢弃 |
