# 9.3 sctp_bindx 函数

> [Ch 4.4 bind](../../1_BasicFoundation/Chapter04_BasicTCPSocket/4.4_Bind_Function.md)

---

## 核心机制

标准 **`bind`** 只能绑**一个** IP（或通配）。

**多宿**端点需同时绑定多个本地 IP → **`sctp_bindx`** 动态增删地址。

---

## 操作标志

| 标志 | 作用 |
|------|------|
| **`SCTP_BINDX_ADD_ADDR`** | 追加绑定地址 |
| **`SCTP_BINDX_REM_ADDR`** | 移除绑定地址 |
