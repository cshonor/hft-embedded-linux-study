## 核心主旨

**Unix 域协议**不是广域网协议，而是**同一主机上进程间通信（IPC）**，复用套接字 API（`socket`、`bind`、`connect`、`read`、`write` 等）。

协议族：**`AF_LOCAL`**（历史上 **`AF_UNIX`**，等价）。

---

## 为何优先于 TCP 环回？

| 优势 | 说明 |
|------|------|
| **性能** | 同机常约为 TCP localhost 的 **约 2 倍** — 少校验和、序列号、IP 封装等协议栈开销 |
| **描述符传递** | 无亲缘关系进程间传递**已打开 fd**（15.7） |
| **凭证传递** | 内核附带真实 **UID/GID**（15.8），应用层不可伪造 |

---

## 典型场景

本机微服务、Sidecar、Master/Worker（Nginx/Gunicorn）、需把 `accept` 到的连接交给工作进程。
