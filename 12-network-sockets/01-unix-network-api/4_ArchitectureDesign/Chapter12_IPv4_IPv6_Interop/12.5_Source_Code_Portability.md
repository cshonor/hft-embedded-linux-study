## 核心原则

编写在 **纯 IPv4 / 纯 IPv6 / 双栈** 上均可编译运行的代码。

---

## 黄金法则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **勿硬编码 `AF_INET` / `AF_INET6`** | 由解析结果决定 |
| 2 | **`getaddrinfo`** | 主机名 + 服务名 → 遍历 `addrinfo`，`ai_family`/`ai_socktype`/`ai_addr` 直接传给 `socket`、`connect`、`bind` |
| 3 | **`sockaddr_storage`** | `accept`、保存对端地址时用；勿仅用 `sockaddr_in` |
| 4 | **`getnameinfo`** | 二进制地址 → 可读字符串；替代 `inet_ntoa`/`inet_ntop`（后者需预知协议族） |

---

## 与互操作的关系

应用层遵循上述范式 → 双栈内核自动完成 **IPv4-mapped** 等转换 → 协议升级对业务 **近乎零感知**。
