## ⚠️ 已知状态：里面有 233 条坏链，是**故意不修**的

这些 `notes.md` 模板里大量链接指向**重构前的路径**（`../OUTLINE.md`、`../chapter-XX/1.x-*.md`、
`../../../09-device-drivers-dt/` 等），在归档位置下必然失效。

**不修的理由**：它们是**空壳模板**（绝大多数只有「本章要点 · 待填」几行），没有阅读价值，
修 233 条链接只为让检查器变绿，收益为零。

**判据**：如果你发现归档里某篇 `notes.md` **有实质内容**（>2KB 且不是模板），
那它应该在重构时被迁出而漏掉了 —— 请迁到对应的任务节点下，而不是去修它的链接。
