## 章节核心提炼

### 优劣势

| 优势 | 代价 |
|------|------|
| 创建/切换快，共享 fd 与内存 | **无进程级内存隔离**，竞态风险高 |

### 安全防范底线

1. 传子线程：**malloc** 独立参数，或 **(void*)connfd 值强转** — **禁止**传栈上 `&connfd`  
2. 线程模型：主线程 **勿 close** 子线程正在用的 connfd  
3. 不需要 join 时：**`pthread_detach`**，防僵死线程耗尽资源  
4. 子线程慎用 **`exit()`** — 会杀掉全进程  

### 同步三位一体

| 问题 | 手段 |
|------|------|
| 不可重入遗留 API | **TSD** |
| 共享计数器/全局状态 | **Mutex** |
| 等待「有空槽」 | **条件变量** + **while** |

## 与 fork / select / 非阻塞对照

| 模型 | 典型场景 |
|------|----------|
| fork | 简单并发服，隔离强 |
| select | 单线程多路复用 |
| 非阻塞 + epoll | 高并发 C10K |
| **pthread** | 每连接一线程；须严格同步 |
