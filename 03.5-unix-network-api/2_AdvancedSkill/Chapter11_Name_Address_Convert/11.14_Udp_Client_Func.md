## UDP 客户端封装

```text
getaddrinfo → for:
    socket（不 connect）
    成功 → 返回 sockfd + 目标 sockaddr*（供 sendto）
```

与 TCP 版区别：**不调用 `connect`**，保留无连接 `sendto` 模型。

---

## 个人学习总结

`udp_client(host, service, &sa, &salen)` — 封装：getaddrinfo → 返回 sockfd + 对端地址。

**一句话**：udp_client = 协议无关的 UDP 客户端准备——返回 fd 和对端地址供 sendto 用。

> UDP 无连接，不需要 connect，但需要知道对端地址。
