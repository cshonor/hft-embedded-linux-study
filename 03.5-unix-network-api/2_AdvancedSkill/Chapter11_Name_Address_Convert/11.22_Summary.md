## 章节核心提炼

### 范式转移

从 **IPv4 + 硬编码端口** → **主机名 + 服务名 + 协议无关**。

### 黄金准则

| 场景 | API |
|------|-----|
| 客户端解析、连接 | **`getaddrinfo`** + 遍历 + `freeaddrinfo` |
| 服务端展示对端 | **`getnameinfo`** |
| **严禁** | `gethostbyname` / `gethostbyaddr` |

### 封装函数（书中）

`host_serv`、`tcp_connect`、`tcp_listen`、`udp_client`、`udp_connect`、`udp_server` — 统一隐藏 hints 与链表遍历。

### 可重入性

新 API **无静态缓冲区** → 多线程安全；旧 API 与 `_r` 变体仅作历史背景。

---

## 个人学习总结

本章核心：getaddrinfo（名字→地址）+ getnameinfo（地址→名字），取代所有旧 API。

**封装五件套**：tcp_connect / tcp_listen / udp_client / udp_connect / udp_server。

**禁用清单**：gethostbyname/addr、inet_ntoa、getservbyname——全部不可重入或仅 IPv4。

> 协议无关编程 = getaddrinfo + AF_UNSPEC + 遍历 res 链表。
