# 11.15 udp_connect 函数

> [Ch 8.11 UDP connect](../../1_BasicFoundation/Chapter08_BasicUDPSocket/8.11_UDP_Connect_Usage.md) · [11.14](11.14_Udp_Client_Func.md)

## 核心主旨

在 11.14 逻辑上增加 **`connect`** → **已连接 UDP 套接字**。

| 收益 | 说明 |
|------|------|
| API | 后续 **`write`/`read`** |
| 安全 | 内核过滤非绑定源 |
| 错误 | **ICMP 异步错误**可上报（如 `ECONNREFUSED`） |

---

## 个人学习总结

`udp_connect(host, service)` — 封装：getaddrinfo + connect（UDP connect 不发握手，只绑定对端）。

**一句话**：udp_connect = UDP connect 版客户端——之后用 read/write 替代 sendto/recvfrom。

> UDP connect 的好处：收 ICMP 异步错误 + 内核做源地址过滤。
