# 14.6 辅助数据

> [14.5 recvmsg](../14.5_Recvmsg_Sendmsg_Func.md) · [Ch 15.7 传递 fd](../../4_ArchitectureDesign/Chapter15_UnixDomainProtocol/15.7_File_Descriptor_Transfer.md)（待学）

---

## 核心概念

**辅助数据（Ancillary Data）**：负载之外的元信息，经 **`msg_control`** 传递。

格式：一个或多个 **`cmsghdr`** + 数据，**严格对齐**。

---

## 五个宏（必须用，禁止手算偏移）

| 宏 | 作用 |
|----|------|
| **`CMSG_FIRSTHDR(&mhdr)`** | 第一个 cmsghdr |
| **`CMSG_NXTHDR(&mhdr, cmsg)`** | 下一个 |
| **`CMSG_DATA(cmsg)`** | 数据区起始指针 |
| **`CMSG_LEN(length)`** | 本条长度（含头+数据，不含尾部填充） |
| **`CMSG_SPACE(length)`** | 分配本条所需**总空间**（含对齐填充） |

---

## 典型应用

| 场景 | 选项/协议 |
|------|-----------|
| UDP 目的地址 | IPv4 `IP_RECVDSTADDR`；IPv6 `IPV6_PKTINFO` |
| 接收接口索引 | 随 pktinfo |
| **传递打开的文件描述符** | **Unix 域**套接字（Ch 15） |
| 进程凭证 | Unix 域 credentials |

---

## 易错细节

- 32/64 位对齐不同 → **手工指针加减必错**  
- `msg_controllen` 不足 → **`MSG_CTRUNC`**
