# 14.5 recvmsg 和 sendmsg 函数

> [14.6 辅助数据](../14.6_Auxiliary_Data.md) · [Ch 8 recvfrom](../../1_BasicFoundation/Chapter08_BasicUDPSocket/8.2_Recvfrom_Sendto_Func.md)

## 核心主旨

Unix 网络 API 中**最通用**的 I/O：涵盖 read/write、recv/send、recvfrom/sendto、readv/writev，并支持**辅助数据**。

---

## msghdr 结构

```c
struct msghdr {
  void         *msg_name;       /* 地址（无连接套接字，同 recvfrom 的 from） */
  socklen_t     msg_namelen;
  struct iovec *msg_iov;        /* iovec 数组 */
  int           msg_iovlen;
  void         *msg_control;    /* 辅助数据缓冲区 */
  socklen_t     msg_controllen;
  int           msg_flags;      /* recvmsg：由内核填写 */
};
```

---

## msg_flags 机制（易错）

| API | flags 传递 |
|-----|------------|
| `recv` | 参数**按值传入**内核 |
| **`recvmsg`** | 调用参数指定控制标志；**`msg_flags` 由内核返回** |

内核可设 **`msg_flags`** 示例：

| 标志 | 含义 |
|------|------|
| **`MSG_TRUNC`** | UDP 报文被截断 |
| **`MSG_CTRUNC`** | 辅助数据被截断 |
| **`MSG_BCAST` / `MSG_MCAST`** | 链路层广播/多播收到 |
