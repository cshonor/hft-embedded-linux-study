# 14.7 排队的数据量

> [Ch 16 非阻塞](../Chapter16_NonBlockingIO/) · [14.3 MSG_PEEK](../14.3_Recv_Send_Func.md)

---

## 实用痛点

想知道接收缓冲区**有多少字节可读**，且**不被阻塞**。

---

## 三种技术

| # | 方法 | 说明 |
|---|------|------|
| 1 | **非阻塞 I/O** | `fcntl` 设非阻塞 → `read`；无数据则 **EWOULDBLOCK** |
| 2 | **`MSG_PEEK`** | 有数据则复制返回但不消费；**两次**系统调用（peek + read），慢 |
| 3 | **`ioctl(FIONREAD)`** | 立即返回，第三参数填入**排队字节数** |

---

## 重点结论

高性能路径优先 **FIONREAD** 或 **非阻塞试探**；避免依赖 MSG_PEEK 双调用。
