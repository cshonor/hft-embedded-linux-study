## 一、和 C 的对应关系

| C（1.2） | Rust |
|----------|------|
| `argc` / `argv[1]` | `env::args()`，`len() == 2` |
| `socket` + `connect` | `TcpStream::connect("IP:13")` |
| `sin_addr` + `sin_port` | `format!("{host}:13")`，库内解析+网络序 |
| `while (read > 0)` | `loop { read; break if n==0 }` |
| `recvline[n]=0` + `fputs` | `from_utf8_lossy(&buf[..n])` |
| `exit` 关 fd | `stream` **Drop** |

## 二、核心逻辑（摘录，完整见 `.rs` 文件）

```rust
let addr = format!("{host}:13");
let mut stream = TcpStream::connect(&addr)?;
let mut buf = [0u8; MAXLINE];
loop {
    let n = stream.read(&mut buf)?;
    if n == 0 { break; }
    print!("{}", String::from_utf8_lossy(&buf[..n]));
}
```

- **TCP 仍须循环 read**；`n == 0` 同 C 的 `read == 0`。
- **connect 失败**须重新 `TcpStream::connect`，不能复用失败的流。
