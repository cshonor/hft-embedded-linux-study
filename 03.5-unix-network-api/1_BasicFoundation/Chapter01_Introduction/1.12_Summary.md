## 一、本章整体定位

第 1 章是**全书总纲**：用最简 **Daytime TCP C/S** 搭好套接字编程**最小闭环**，定下全书编码范式；后续各章在此骨架上**迭代扩充**。

## 六、HFT 自建 TCP 程序自检清单

```text
【TCP 程序初始化自检】
1. 头文件：unp.h + 包裹函数（或自研等价封装）
2. 协议族：AF_UNSPEC(无关) vs AF_INET / AF_INET6(单栈)
3. 地址结构：sockaddr_in / in6；bzero 或 memset 清零
4. 端口：必须 htons(端口)，禁止裸写 sin_port
5. IP：inet_pton；不用 inet_addr / gethostbyname
6. 错误处理：调试用大写包裹；生产用回调/回收，慎 exit
7. 强转：统一 (SA *) 传参
8. 服务端：分清 listenfd(只 accept) 与 connfd(只 I/O)
```

## 八、精简总结

第 1 章**舍弃复杂业务**，只保留**最小 TCP 通信**，是 UNIX 网络编程的**最小原型**。
看懂本章代码 = 掌握套接字**骨架**；高级 I/O、并发、多协议都是在骨架上**加功能**。

**链路**：1.2/1.5 原型 → 1.4 规范 → 1.3/11 双栈 → 6/14 多路复用 → 5/26 并发 → 8/21 UDP/组播。

### 定位

**图 1-5（TCP 时间获取客户程序）** 与 **图 1-9（TCP 时间获取服务器程序）** 构成最基础、完整的 **Daytime TCP C/S 模型**：展示 **建立连接 → 数据交互 → 断开连接** 的全生命周期（IPv4 硬编码版）。

```text
        【服务端先启动，长期运行】
              listenfd  bind :13  listen
                    │
    客户端 connect ─┼─► 三次握手 ──► accept → connfd
                    │                    │
                    │              write 时间串
                    │                    │
    客户端 read ◄───┴──────────────── FIN
    read==0 退出
```

<a id="ch1-cs-server-init"></a>

### 一、服务器初始化与等待（图 1-9）

服务器**先于客户端**启动，并一直运行。

| 步骤 | API / 行为 |
|------|------------|
| **创建套接字** | `Socket` → 得到 **`listenfd`**（监听套接字） |
| **填地址** | **`INADDR_ANY`（0.0.0.0）** + **`htons(13)`** → 接受本机**任意网卡**上发往 13 端口的连接 |
| **绑定** | `Bind(listenfd, …)` |
| **监听** | `Listen(listenfd, LISTENQ)` → 普通套接字变为**监听套接字**，内核可为外来连接排队 |
| **等待** | `for (;;)` 中 **`Accept` 阻塞睡眠**，直到有客户完成握手 |

> `listenfd` **只**用于 `accept`，**不**在此 fd 上 `read`/`write`。

<a id="ch1-cs-client-connect"></a>

### 二、客户端连接发起（图 1-5）

用户在命令行传入**服务器 IP** 后运行客户端。

| 步骤 | API / 行为 |
|------|------------|
| **创建套接字** | `socket` / `Socket` → **`sockfd`** |
| **构造地址** | `argv[1]` 经 **`inet_pton`** → `sin_addr`；端口 **`htons(13)`** |
| **主动打开** | **`connect`** → 内核发起 TCP **三次握手** |

<a id="ch1-cs-data-close"></a>

### 三、数据交互与连接终止

**服务器侧（accept 返回之后）**

| 顺序 | 动作 |
|------|------|
| 1 | 三次握手完成，阻塞的 **`Accept` 返回** → 新 fd **`connfd`**（**已连接套接字**，专用于该客户） |
| 2 | `time` 取秒数 → `snprintf` + `ctime` 格式化为可读字符串（含 `\r\n`） |
| 3 | **`Write(connfd, …)`** 经 TCP 发出 |
| 4 | **`Close(connfd)`** → 发 **FIN**，正常终止本会话 |
| 5 | 回到 **`Accept` 阻塞**，等下一客户 → **迭代服务器**（串行，同时只服务一路） |

**客户端侧**

| 顺序 | 动作 |
|------|------|
| 1 | **`while (read > 0)`** 循环读应答（TCP **无记录边界**，可能多次 `read` 才读全） |
| 2 | 收到服务器 **FIN** 后 **`read` 返回 0**（EOF）→ 循环结束 |
| 3 | `fputs` 打印 → **`exit(0)`** → 进程结束，套接字被回收 |

<a id="ch1-cs-fd"></a>

### 四、两套 fd 对照（背）

| | 客户端 | 服务端 |
|---|--------|--------|
| **主 fd** | `sockfd`（connect 后读写） | `listenfd`（只 accept，终身不关） |
| **会话 fd** | 同上 | **`connfd`**（每客户一个，写完即 `close`） |
| **端口** | 连 **对方 IP:13** | **bind 0.0.0.0:13** |

<a id="ch1-cs-timeline"></a>

### 五、时间线（与 TCP 报文对应）

```text
时刻 T0  服务端：socket → bind → listen → accept() 睡眠
时刻 T1  客户端：socket → connect → SYN…
时刻 T2  内核：三次握手完成
时刻 T3  服务端：accept 醒 → connfd；write 时间串 → close(connfd) [FIN]
时刻 T4  客户端：read 循环 → read=0 → 打印 → exit [FIN/关 fd]
时刻 T5  服务端：再次 accept 睡眠（若仍有 listenfd）
```

> 封装分层：[1.7 §四](./1.7_OSIModel.md#ch1-7-encap) · listen 队列：[1.5 附录](./1.5_SimpleTimeServer.md#listen-queue)

**一句话**：**服：先 bind:13 再 listen，accept 睡；客：connect 握手；服：write 时间后 close(connfd)；客：while read 到 0 再退出。**
