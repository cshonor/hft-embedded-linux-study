# 8.5 UDP 回射客户程序：main 函数

> [8.6 dg_cli](8.6_UDP_Client_Dg_Cli.md)

---

## 核心主旨

- 校验命令行：**服务器 IP**  
- **`inet_pton`** → 填入 `sockaddr_in`（网络字节序）  
- **`socket`** → 将 `sockfd` 与地址交给 **`dg_cli`**

与 TCP 客户 main 类似，但**无 `Connect`**（初版）。

---

## 个人学习总结

UDP 客户 main：socket→dg_cli→close。无 connect——sendto 时内核临时绑源地址。

**一句话**：UDP 客户连 connect 都不需要——sendto 直接带目标地址。

> 与 TCP 客户对比：TCP 必须 connect 建连，UDP 直接发。
