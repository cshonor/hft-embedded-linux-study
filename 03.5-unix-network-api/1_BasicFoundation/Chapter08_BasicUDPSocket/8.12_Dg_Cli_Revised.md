# 8.12 dg_cli 函数（修订版）

> [8.11 connect](8.11_UDP_Connect_Usage.md)

---

## 代码重构

| 改动 | 效果 |
|------|------|
| **`main` 里 `Connect(servaddr)`** | 绑定对端 |
| **`dg_cli` 用 `write`/`read`** | 替代 sendto/recvfrom |
| 服务器未启动 | ICMP → **`read` 报错**，**不死锁** |

---

## 逻辑脉络

```text
Ch8.6 初版 → 丢包/假源/无 ICMP
→ connect + read/write → 代码短 + 错误可达
```

---

## 个人学习总结

connect 版 dg_cli：先 connect(serveraddr) → 用 read/write 替代 sendto/recvfrom → 能收 ECONNREFUSED。

**一句话**：加了 connect 后 dg_cli 的三个问题（丢包除外）都解决了——异步错误可见了。

> 丢包仍需应用层超时——connect 不改变 UDP 不可靠本质。
