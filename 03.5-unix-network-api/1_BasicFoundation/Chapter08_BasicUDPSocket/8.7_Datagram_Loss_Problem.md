# 8.7 数据报的丢失

> [8.12 connect 修订](../8.12_Dg_Cli_Revised.md) · Ch 6 超时：[6.5](../../Chapter06_IO_Select_Poll/6.5_Batch_Input_Process.md) · SO_RCVTIMEO：Ch 7.5

---

## 核心主旨

初版 UDP 回射在广域网上**极度脆弱**：UDP **无可靠性**。

---

## 通信陷阱

| 情况 | 客户行为 |
|------|----------|
| 请求丢包 | **`recvfrom` 永久阻塞** |
| 应答丢包 | 同上 |
| 无 TCP 定时器 | **无从得知**是否丢失 |

**单边盲区** — 不像 TCP 有重传。

---

## 重点结论

**绝不能无限期阻塞在 `recvfrom` 上。**

须加应用层超时：

| 手段 | 章节 |
|------|------|
| **`alarm` + 信号** | 经典 |
| **`select`/`poll` 超时** | Ch 6 |
| **`SO_RCVTIMEO`** | Ch 7.5 |

高可靠 UDP 还须自建 **ACK + 重传** 状态机（TFTP 等）。
