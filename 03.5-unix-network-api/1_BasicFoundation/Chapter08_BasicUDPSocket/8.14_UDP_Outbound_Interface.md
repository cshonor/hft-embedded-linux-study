# 8.14 UDP 中的外出接口的确定

---

## 核心主旨

多网卡/多 IP 主机：UDP **源 IP** 如何选定？

---

## 机制对比

| 类型 | 源 IP 决定时机 |
|------|----------------|
| **未 connect + sendto** | 每次 **sendto** 时查路由表 → 选外出接口主 IP |
| **已 connect + write** | **`connect` 时**查路由并固定，后续 write 不再选路 |
| **bind 指定本地 IP** | 强制以该 IP 为源（路由不符可能不通） |

---

## 易错细节

多宿环境下 **bind/connect 顺序** 与策略路由影响连通性。

---

## 个人学习总结

UDP sendto 时源 IP 由内核路由表决定——多网卡机器可能走"错误"接口。

**控制方式**：bind 指定源 IP，或用 IP_PKTINFO 辅助数据（Ch22）。

**一句话**：UDP 无连接→内核选路由→源 IP 随路由走；要固定源 IP 就 bind。
