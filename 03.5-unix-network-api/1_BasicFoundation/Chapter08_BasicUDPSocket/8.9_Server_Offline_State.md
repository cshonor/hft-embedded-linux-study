# 8.9 服务器进程未运行

> [8.11 UDP connect](8.11_UDP_Connect_Usage.md) · ICMP：Ch 5.5

---

## 核心异常

客户向**开机但无 UDP 服务进程**的主机发报文：

| 步 | 行为 |
|----|------|
| 1 | 目标内核收 UDP，**无进程 bind 该端口** |
| 2 | 生成 **ICMP 端口不可达** 回客户机 |
| 3 | 这是 **异步错误** — **`sendto` 已成功返回**（数据已交 IP 层） |

---

## 关键结论（反直觉）

**未连接的 UDP 套接字**在多数实现上**收不到**该 ICMP 映射的错误。

→ 客户仍**阻塞在 `recvfrom`**，对失败**一无所知**。

---

## 逻辑对比

| 套接字状态 | ICMP 端口不可达 |
|------------|-----------------|
| **未 connect UDP** | 常**不**传递给应用 |
| **已 connect UDP**（8.11） | 后续 **read/write** 可得 **ECONNREFUSED** 等 |

---

## 个人学习总结

UDP 服务器端口无进程 → 内核回 ICMP "port unreachable" → 但 ICMP 是**异步错误**——sendto 已返回成功。

**问题**：未 connect 的 UDP socket 收不到 ICMP 错误 → recvfrom 永远阻塞。

**解法**：UDP connect 后，ICMP 错误延迟到 read/write 时返回 ECONNREFUSED。
