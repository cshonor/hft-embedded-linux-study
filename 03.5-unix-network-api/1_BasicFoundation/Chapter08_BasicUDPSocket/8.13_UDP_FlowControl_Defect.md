# 8.13 UDP 缺乏流量控制

> SO_RCVBUF：Ch 7.5 · TCP 对比：Ch 2.4

---

## 案例：发送端狂发

客户 `for` 循环 **2000 次 sendto**，服务器处理慢或 **`SO_RCVBUF` 很小**：

| 层 | 行为 |
|----|------|
| 网卡 → UDP 接收队列满 | **悄悄丢弃**新报文 |
| 无窗口通告 | **不告诉**发送方「慢点」 |
| sendto | **不阻塞**（除非本地队列满） |

---

## 重点结论

UDP **无流量控制** → 高吞吐须应用层 **ACK + 滑动窗口/限流**。
