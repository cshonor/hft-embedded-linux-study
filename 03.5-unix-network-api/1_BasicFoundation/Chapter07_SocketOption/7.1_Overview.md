## 核心主旨与关键机制

套接字 API 提供机制，动态**获取和修改**套接字底层默认行为 — 统称 **套接字选项（Socket Options）**。

### 三大控制入口

| 入口 | 作用域 |
|------|--------|
| **`getsockopt` / `setsockopt`** | **套接字层级**（本章主体） |
| **`fcntl`** | 套接字作为 **fd** 的通用文件控制（非阻塞、信号驱动） |
| **`ioctl`** | 更底层设备/网口控制（**Ch 17**） |

---
