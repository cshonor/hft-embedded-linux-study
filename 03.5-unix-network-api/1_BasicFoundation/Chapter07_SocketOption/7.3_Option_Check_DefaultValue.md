# 7.3 检查选项是否受支持并获取默认值

---

## 核心主旨

不同 OS/内核版本对选项支持不一致；可用工具程序**遍历选项** + `getsockopt` 输出**系统默认值**。

---

## 实用要点与代码逻辑

| 设计 | 说明 |
|------|------|
| **不遇错即 exit** | 某选项 `getsockopt` 失败 → 判定**本系统不支持**，非致命 |
| 典型 errno | **`EOPNOTSUPP`**、**`ENOPROTOOPT`** |
| **`#ifdef`** | SCTP、多播等选项仅在协议栈编译进内核时存在 |

---

## 逻辑脉络

```text
开发前/移植时运行 checkopts 类程序
→ 确认 SO_REUSEPORT、SCTP_* 等是否可用
→ 再写生产 setsockopt
```
