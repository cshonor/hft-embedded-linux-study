# 2.5 流控制传输协议（SCTP）

> 关联建立/终止：[2.8](../2.8_SCTP_Connect_Terminate.md) · 套接字 API：Ch 9

## 核心知识点

较新的传输协议，弥补 TCP 在信令等场景的不足：**面向消息的可靠传输**。

## 关键特性

| 特性 | 说明 |
|------|------|
| **面向消息** | TCP 可靠性 + UDP 式**消息边界** |
| **关联（Association）** | 不叫「连接」而叫**关联** |
| **多宿（Multihoming）** | 两端可各有多 IP；主路径故障时**透明切换**备用路径 |
| **多流（Multi-streaming）** | 一关联内多逻辑流；**流内有序、流间不互相头端阻塞** |

## 个人学习总结

> 💡 独立网页资源、信令传输中多流的优势。
