## 核心知识点

本章是网络编程的**传输层基石**：**TCP**、**UDP**、**SCTP**。须理解连接建立/终止、状态转换、缓冲机制，才能写出健壮的客户/服务器程序。

| 协议 | 定位 |
|------|------|
| **UDP** | 简单、**不可靠**的数据报 |
| **TCP** | 复杂、**可靠**的字节流 |
| **SCTP** | 消息边界 + **多宿** + **多流**（减轻头端阻塞） |

三者均建立在网络层 **IPv4 / IPv6** 之上。
