# 2.4 传输控制协议（TCP）

> 握手/挥手：[2.6](../2.6_TCP_Connect_Terminate.md) · 对比 UDP：[2.3](../2.3_UDP_Protocol.md)

## 核心知识点

**面向连接**、**可靠**、**全双工字节流** — 互联网最核心的传输协议。

## 关键机制

| 机制 | 要点 |
|------|------|
| **面向连接** | 传数据前须建立 TCP 连接 |
| **确认与重传** | 发数据启定时器等 ACK；超时未 ACK 则重传 |
| **RTT 估算** | 动态估算往返时间，自适应重传超时 |
| **排序 / 去重** | 每字节有序列号；乱序重排、重复丢弃 |
| **流量控制** | **通告窗口** = 接收缓冲剩余；窗口 0 时发送端阻塞 |
| **无记录边界** | 应用写入块大小 ≠ 网络分节大小 → **拆包/粘包** |

## 易错点与坑点

**「可靠」≠ 对端一定收到**：TCP 尽最大努力递送；实在无法递送则放弃重传并**可靠地通知**应用（返回错误）。
