# 2.8 SCTP 关联的建立和终止

> 协议特性：[2.5](../2.5_SCTP_Protocol.md) · 对比 TCP 握手：[2.6](../2.6_TCP_Connect_Terminate.md)

## 核心知识点

SCTP 面向连接，但握手/终止在抗攻击与状态管理上与 TCP 不同。

## 执行流程原理

### 2.8.1 四路握手（Four-Way Handshake）

| 步 | 消息 |
|----|------|
| 1 | 客户 **INIT** |
| 2 | 服务器 **INIT ACK**（含 **状态 cookie**，**不分配内存**） |
| 3 | 客户 **COOKIE ECHO**（回射 cookie） |
| 4 | 服务器验证后 **COOKIE ACK**，关联建立 |

**防 SYN 泛洪**：第 2 步服务器**不建内部状态**；状态加密签名在 cookie 中；第 3 步合法回传后才分配资源。

### 2.8.2 关联终止

- 三消息：`SHUTDOWN` → `SHUTDOWN ACK` → `SHUTDOWN COMPLETE`  
- **不支持半关闭**；一端关闭则关联整体消亡  
- **无 TIME_WAIT**；用**验证标签**区分旧分节

## 个人学习总结

> 💡 与 TCP 半关闭、TIME_WAIT 的对比表。
