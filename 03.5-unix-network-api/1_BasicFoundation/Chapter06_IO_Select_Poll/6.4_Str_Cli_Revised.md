# 6.4 str_cli 函数（修订版）

> Ch 5 缺陷：[5.5](../Chapter05_TCP_Client_Server_Demo/5.5_Client_Str_Cli.md) · 批量输入：[6.5](../6.5_Batch_Input_Process.md)

## 核心主旨与逻辑重构

用 **`select`** 重写客户主循环，**同时监听 stdin 与 sockfd**，解决 Ch 5「阻塞 fgets 不知网络断」问题。

---

## 执行流程原理

```text
FD_ZERO(&rset)
FD_SET(sockfd, &rset)
FD_SET(fileno(stdin), &rset)    /* 通常 0 */

for (;;) {
    rset_save = rset
    nready = select(maxfd+1, &rset_save, NULL, NULL, NULL)

    if (FD_ISSET(sockfd, &rset_save)) {
        /* 网络可读：回射或 FIN */
        if (readline(...) == 0) exit;  /* 服务器 FIN */
        fputs(...)
    }

    if (FD_ISSET(fileno(stdin), &rset_save)) {
        if (fgets(...) == NULL) break; /* 键盘 EOF — 6.5 会暴露问题 */
        writen(sockfd, ...)
    }
}
```

---

## 重点结论

| Ch 5 | Ch 6.4 |
|------|--------|
| 只阻塞 `fgets` | **`select` 任一就绪即处理** |
| 服务器 FIN 时可能仍在等键盘 | **FIN 使 sockfd 读就绪 → 立刻 readline=0 退出** |

**已解决**：远端进程异常 / 正常 FIN 的**及时感知**（在交互式键盘场景下）。

---

## 易错细节

- 仍用 `fgets`/`readline` + `select`：stdio **缓冲**与 select 混用有风险（6.7 改 `read`/`write`）  
- `rset` 必须用 **`rset_save`** 副本 — `select` 修改传入集合
