# 6.9 pselect 函数

> [6.3 select](../6.3_Select_Function.md)

---

## 核心主旨

POSIX 在 `select` 上演进为 **`pselect`**，解决超时精度与**信号竞争**。

```c
int pselect(int maxfdp1, fd_set *readset, fd_set *writeset, fd_set *exceptset,
            const struct timespec *timeout, const sigset_t *sigmask);
```

---

## 核心差别

| # | 改进 |
|---|------|
| **1** | 超时用 **`timespec`** — **纳秒**精度（`select` 用 `timeval` 微秒） |
| **2** | **`sigmask` 参数** — 阻塞期间**原子地**替换信号掩码，返回后恢复 |

### sigmask 解决什么问题

在「检查条件」与「调用 select 阻塞」之间的缝隙，若信号到达且处理函数也改 fd 状态 → **竞态**。`pselect` 可在等待时屏蔽指定信号，避免丢失/重复逻辑。

---

## 易错细节

- 与 `select` 一样仍受 **FD_SETSIZE** 限制（位图模型未变）  
- `sigmask == NULL` 时行为类似普通 select
