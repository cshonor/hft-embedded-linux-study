## 核心主旨与关键论据

套接字编程起步：**套接字地址结构**是用户进程与内核传递「通信端点」的媒介。本章覆盖：结构体类型、**值—结果参数**、**网络字节序**、地址转换 API、**readn/writen**。

---

## 逻辑脉络

1. **结构体** — 明确 IP + 端口如何存放  
2. **长度传递** — 进程↔内核双向规则不同  
3. **协议演进** — `inet_addr` → **`inet_pton`**；`sock_ntop` 协议无关  

---

> 💡 **后续拓展留白**  
> - 内核如何按 `sa_family` 分发到协议栈

## 个人学习总结

本章是套接字编程的地基：地址结构体 → 字节序 → 地址转换 → 循环读写。

**一句话**：所有 socket API 的地址参数都是 `sockaddr*` 强转，端口/IP 必须网络字节序。

> 学习路线：3.2 结构体 → 3.3 值-结果 → 3.4 字节序 → 3.7 pton/ntop → 3.9 readn/writen，按此顺序过关即可。
