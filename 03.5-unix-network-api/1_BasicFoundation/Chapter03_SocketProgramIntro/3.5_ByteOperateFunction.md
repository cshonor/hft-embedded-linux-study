# 3.5 字节操纵函数

---

## 核心主旨

地址结构含 **0 字节**，不能用 `strcpy`。初始化用 **`bzero`**（本书偏好）而非易写反参数的 **`memset`**。

| 函数族 | 说明 |
|--------|------|
| Berkeley | **`bzero(dest, nbytes)`** — 2 参数 |
| ANSI | `memset(dest, c, len)` — **值与长度易写反** |

---

## 重点结论

`memset(&addr, sizeof(addr), 0)` 类错误**编译器不报错**，运行时行为诡异。

---

## 个人学习总结

地址结构含 0 字节，不能用 `strcpy`。用 `bzero` 或 `memset` 初始化。

**一句话**：`memset(&addr, sizeof(addr), 0)` 参数写反编译器不报错——值和长度搞反是经典 bug。

> 现代 C 推荐 `memset`，C23 有 `memset_explicit`（清敏感数据防编译器优化删除）。
