# 4.9 close 函数

> 引用计数：[4.8](4.8_ConcurrentServer.md)

---

## 核心主旨与关键论据

**`close(sockfd)`** 释放描述符；对 TCP 还触发**正常终止**（四次挥手）。

```c
int close(int sockfd);
```

---

## 底层机制

- 套接字描述符**引用计数 −1**  
- 计数 **> 0**（如子进程仍持有）→ **直接返回**，内核**不**终止 TCP  
- 计数 **= 0** → 内核认为无进程使用 → 尽量发完发送缓冲 → 发 **FIN**

---

## 与 shutdown 区别（预告 Ch 6）

| | close | shutdown |
|--|-------|----------|
| 粒度 | 整个 fd | 可半关闭读/写 |
| 引用计数 | 减 1 | 不关闭 fd |

---

## 个人学习总结

`close` 减引用计数，计数为 0 时内核发 FIN 终止 TCP。与 `shutdown` 区别：close 减计数+关 fd，shutdown 不关 fd 但可半关闭。

**一句话**：fork 后 connfd 引用计数=2，父 close 只减到 1，子 exit 才真正断开。

> shutdown(SHUT_WR) 可触发半关闭而不关 fd——Ch6 str_cli 终结版的关键。
