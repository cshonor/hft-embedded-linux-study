## 核心主旨

Ch 28 **原始套接字** → **网络层（IP）**。

**数据链路层访问** → **OSI 第 2 层**，无统一 Unix 系统调用，各 OS 实现不同。

---

## 应用场景

| # | 场景 |
|---|------|
| 1 | **混杂嗅探** — `tcpdump`、`Wireshark`（非仅本机帧） |
| 2 | **非 IP 协议** — ARP、RARP 等不经 IP 栈的帧 |
| 3 | **自构以太网帧** — 完全控制 MAC/类型字段 |

## 个人学习总结

数据链路层访问 = 绕过 IP 层，直接收发以太网帧。用于抓包（tcpdump/libpcap）、自定义链路层协议、ARP 实现。

**三平台方案**：BSD BPF、Solaris DLPI、Linux PF_PACKET。

**一句话**：数据链路访问 = "看到完整以太网帧（含 MAC 头）"——比 raw socket 更底层。

> HFT 关联：DPDK 也工作在链路层，但通过 PMD 直接操作网卡 DMA，比 PF_PACKET 更高效。
