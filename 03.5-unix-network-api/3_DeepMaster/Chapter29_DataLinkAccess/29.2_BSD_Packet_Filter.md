# 29.2 BPF：BSD 分组过滤器

---

## 核心机制

**BPF（BSD Packet Filter）** — Berkeley 数据链路访问架构；思想也被 **Linux** 采纳。

---

## 接口

- 打开 **`/dev/bpf`** 设备文件访问链路层  

---

## 内核级过滤（核心优势）

| 无过滤 | 每帧拷到用户态 → CPU 瘫痪 |
|--------|-------------------------|
| **BPF** | 应用提交 **BPF 字节码**（伪机器码）到**内核虚拟机** |

```text
网卡收帧 → 内核 BPF 评估 → 仅匹配帧入缓冲 → 用户 read
```

例：规则「TCP 且 port 80」— 在用户态前丢弃无关帧。

---

## 个人学习总结

BPF（BSD Packet Filter）= BSD 的数据链路层抓包接口。设备文件 /dev/bpf0~N。

**BPF 过滤器**：内核中运行的字码过滤器——只有匹配的数据帧才从内核拷贝到用户空间，减少不必要拷贝。

**一句话**：BPF = 内核级过滤器 + 字节码虚拟机——tcpdump 的过滤表达式编译成 BPF 字节码。

> BPF 后来演化为 eBPF——Linux 的 eBPF 是其精神继承者，用于 XDP 等高速包处理。
