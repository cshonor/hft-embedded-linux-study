# 29.6 libnet：分组构造与输出函数库

> [29.5 libpcap](29.5_Libpcap_Capture_Lib.md) · [Ch 28 发包](../Chapter28_RawSocket/28.3_RawSocket_Send_Data.md)

---

## 核心主旨

**libpcap** = **读**；**libnet** = 跨平台**写（注入帧）**。

---

## 痛点

原生 raw 发 SYN 等须手算校验和、对齐；**无法直接改以太网 MAC 头**。

---

## libnet 接口（分层构造）

| 函数 | 层 |
|------|-----|
| `libnet_build_ethernet` | 以太网 |
| `libnet_build_ipv4` | IP |
| `libnet_build_tcp` | TCP（含校验和） |
| `libnet_write` | 注入驱动栈 |

---

## 黄金法则

链路层**发包** → 优先 **libnet**（与 libpcap 配对）。

---

## 个人学习总结

libnet = 跨平台构造+发送数据包库。提供逐层填包 API（以太网→IP→TCP/UDP）。

**一句话**：libpcap 抓包，libnet 发包——两者配合可做协议测试/网络仿真。

> 现代 C 工程中用得少——scapy（Python）更常用做快速构造和发送自定义包。
