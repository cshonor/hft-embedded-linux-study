# 29.7 检查 UDP 的校验和字段

> [29.5 libpcap](29.5_Libpcap_Capture_Lib.md) · [Ch 8 UDP](../../1_BasicFoundation/Chapter08_BasicUDPSocket/study.md)

---

## 实战目标

用 **libpcap** 抓 **DNS（UDP）** 请求，在应用层**重算 UDP 校验和**以验证完整性。

---

## 解析步骤（手动偏移）

`libpcap` 返回**完整以太网帧**：

```text
跳过以太网头（常 14 字节，注意 VLAN tag）
→ 解析 IPv4 头，按 IHL 跳过
→ 定位 UDP 头与载荷
```

---

## UDP 校验和与伪首部

校验和计算须包含 **UDP 伪首部**：

- 源 IP、目的 IP  
- 协议号 **17**  
- UDP 长度  
- UDP 头 + 数据  

---

## IP 分片陷阱

链路层抓到的是**未重组分片**：

- 仅**首片**含 UDP 头  
- 后续分片无 UDP 头 → 底层抓包**分片重组**极繁琐  

---

## 个人学习总结

UDP 校验和含**伪首部**（源 IP + 目的 IP + 协议 + UDP 长度）——校验范围覆盖 IP 头部分字段。

**关键**：IPv4 UDP 校验和可选（=0 表示不校验）；IPv6 UDP 校验和必填。

**一句话**：UDP 校验和 = 伪首部 + UDP 头 + 数据——校验 IP 地址正确性，防止错投。

> 用 PF_PACKET 抓包时需自己计算伪首部验证校验和——内核已验证的不重复检查。
