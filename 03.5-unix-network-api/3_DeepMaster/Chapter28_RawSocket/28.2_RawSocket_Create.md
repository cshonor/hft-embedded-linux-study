# 28.2 原始套接字创建

> [Ch 7.2 setsockopt](../../1_BasicFoundation/Chapter07_SocketOption/7.2_Getsockopt_Setsockopt.md)

---

## 创建 API

```c
int sockfd = socket(AF_INET, SOCK_RAW, protocol);
/* 或 AF_INET6 */
```

| 参数 | 说明 |
|------|------|
| **`protocol`** | `IPPROTO_ICMP`、`IPPROTO_IGMP` 或自定义协议号 |

---

## 特权限制（极重要）

**仅 root（超级用户）** 可创建 `SOCK_RAW` — 防伪造源 IP 等危险报文注入。

---

## IP_HDRINCL

| 默认 | 内核自动拼接 **IP 首部** |
|------|-------------------------|
| **`IP_HDRINCL=1`** | 应用自供完整 IP 首部（`sendto` 数据含 IP 头） |

```c
setsockopt(sockfd, IPPROTO_IP, IP_HDRINCL, &on, sizeof(on));
```

---

## 个人学习总结

`socket(AF_INET, SOCK_RAW, protocol)` — 创建原始套接字。protocol 指定接收哪种协议（IPPROTO_ICMP、IPPROTO_TCP 等）。

**IP_HDRINCL**：setsockopt 设此选项 → 发送时包含自己构造的 IP 头；不设 → 内核填 IP 头。

**一句话**：IP_HDRINCL=1 时发送数据从 IP 头开始；=0 时从传输层开始，内核补 IP 头。

> 需 CAP_NET_RAW 或 root 权限才能创建 raw socket。
