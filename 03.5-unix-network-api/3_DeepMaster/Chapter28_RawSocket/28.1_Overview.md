## 核心主旨

此前应用多在**传输层**（TCP/UDP/SCTP）。

**原始套接字（Raw Socket）**：越过传输层，直接与**网络层（IPv4/IPv6）**及 **ICMP、IGMP** 等交互。

---

## 应用场景

| # | 场景 |
|---|------|
| 1 | **ICMP/IGMP** — `ping`、`traceroute` |
| 2 | **自定义传输层协议**（非 TCP/UDP 的 IP 协议号） |
| 3 | **自构 IP 首部** — `IP_HDRINCL`（扫描、测试等，须合法授权） |

---

## 局限预告

**无法**用普通 `SOCK_RAW` 截获本机 **TCP/UDP** 流量 → 须 **Ch 29 数据链路层**（BPF/libpcap）。

## 个人学习总结

原始套接字 SOCK_RAW — 绕过传输层，直接读写 IP 层数据包。需 root 权限。

**用途**：ping（ICMP）、traceroute（TTL 递增）、自定义协议、抓包。

**一句话**：raw socket = "自己构造 IP 头和传输层"——完全控制报文内容。

> HFT 关联：HFT 不用 raw socket——DPDK 比 raw socket 更底层（链路层），且无需 root syscall 开销。
