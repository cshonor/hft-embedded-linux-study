# 21.5 源特定多播

---

## ASM（任意源多播）

传统模型：Join 组 **G** 后，接收**任意源**发往 G 的数据 → 易被伪造源/垃圾流量攻击。

---

## SSM（源特定多播）

| 项 | 说明 |
|----|------|
| 绑定 | 组 **G** + 合法源 **S** |
| 要求 | **IGMPv3**（IPv4）或 **MLDv2**（IPv6） |
| 优势 | 抗欺骗、简化路由（以 S 为根的源树） |

套接字：`IP_ADD_SOURCE_MEMBERSHIP` 等（21.6）。

---

## 个人学习总结

SSM（Source-Specific Multicast）= (S, G) 模式——接收者指定"只收来自源 S 的组 G 的数据"。

**优势**：避免任意源注入伪造数据；无需全网组员发现协议；路由器只需维护 (S, G) 状态。

**一句话**：SSM = "只收指定源的组播"——更安全、更可扩展。

> HFT 关联：交易所行情用 SSM——确保只收交易所网关的数据，防伪造。
