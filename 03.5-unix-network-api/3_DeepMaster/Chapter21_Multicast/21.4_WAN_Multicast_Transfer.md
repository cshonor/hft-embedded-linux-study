# 21.4 广域网上的多播

---

## 两层协议

### 1. 主机 ↔ 本地路由器（组管理）

| 协议 | 用途 |
|------|------|
| **IGMP**（IPv4） | 主机 Join 后向路由器**报告** |
| **MLD**（IPv6，ICMPv6） | 同上 |

机制：宣告「本子网有接收者，请转发该组」。

### 2. 多播路由器之间

PIM、DVMRP、MOSPF 等 → 构建 **多播分发树**，避免环路，在分支复制报文。

---

## 与套接字 TTL

默认 **TTL/hops=1** 时多播**不出子网**；跨 WAN 须调大 TTL **且** 路径上路由器支持多播路由。
