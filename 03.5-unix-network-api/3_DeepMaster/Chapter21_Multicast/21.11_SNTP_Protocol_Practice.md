# 21.11 SNTP：简单网络时间协议

---

## 场景

| 模式 | 压力 |
|------|------|
| 单播 NTP | 每台客户端请求 → 服务器并发巨大 |
| **多播 NTP/SNTP** | 服务器周期广播时间 → 客户端被动收 |

---

## 多播地址

- IPv4：**`224.0.1.1`**  
- IPv6：**`ff02::101`**（链路本地等，以部署为准）

---

## 客户端设计

```text
bind(NTP 端口 123) + mcast_join(上述组)
→ recvfrom 阻塞
→ 收到一包 → 校时 → 可退出
```

**性能**：服务器负载近似**恒定低频多播**，客户端规模理论上可极大扩展。

---

## 个人学习总结

SNTP（Simple NTP）= 简化版 NTP，常用组播模式：服务器周期性组播时间戳，客户端接收校准。

**一句话**：SNTP 组播 = 服务器 224.0.1.1:123 定期发时间戳 → 客户端被动接收校准。

> HFT 关联：时间同步是 HFT 基础设施——组播 SNTP 比 PTP 简单但精度低（毫秒级 vs 微秒级）。
