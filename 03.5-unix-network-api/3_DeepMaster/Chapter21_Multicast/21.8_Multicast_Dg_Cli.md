# 21.8 使用多播的 dg_cli 函数

---

## 发送端

与单播 UDP 客户几乎相同 — 目的地址改为 **D 类 / ff00::** 多播地址即可 `sendto`。

---

## 易错细节

| 点 | 说明 |
|----|------|
| **发送方通常不必 Join** | 合法多播目的即可发出 |
| **跨子网** | 可能需 **`mcast_set_ttl`** 增大跳数 |
| 勿与广播混淆 | 不需要 **SO_BROADCAST** |

---

## 个人学习总结

组播版 dg_cli：发送方 sendto 组地址（无需 join）；接收方 bind 组端口 + join 组 + recvfrom。

**一句话**：组播发送 = 普通 UDP sendto 组地址；组播接收 = bind + join + recvfrom。

> bind 端口而非组地址——组地址通过 IP_ADD_MEMBERSHIP 加入。
