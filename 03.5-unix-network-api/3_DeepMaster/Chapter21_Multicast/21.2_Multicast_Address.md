# 21.2 多播地址

---

## 逻辑组

多播地址标识**组（Group）**，非单台主机。

---

## IPv4（D 类）

| 项 | 内容 |
|----|------|
| 范围 | **`224.0.0.0` – `239.255.255.255`** |
| 全节点 | **`224.0.0.1`** |
| 全路由器 | **`224.0.0.2`** |

### MAC 映射（IANA）

- 以太网多播 MAC：**`01:00:5E:00:00:00` – `01:00:5E:7F:FF:FF`**
- **低 23 位** 来自 IPv4 多播地址低 23 位  

### 32:1 碰撞

组 ID 有 **28 位**，MAC 只用 **23 位** → **每 32 个** IPv4 多播 IP 映射到**同一** MAC → IP 层须**软件核对**完整组地址。

---

## IPv6

| 项 | 内容 |
|----|------|
| 前缀 | **`ff00::/8`** |
| 结构 | Flags(4) + **Scope(4)** + Group ID(112) |
| Scope | 节点/链路/站点/组织/全球等边界 |
| MAC | 低 32 位 → 前缀 **`33:33`** 后 |
