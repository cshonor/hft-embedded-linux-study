## 核心主旨

Ch 6 五种 I/O 模型之一：**信号驱动式 I/O（Signal-Driven I/O）**。

| 对比 | 行为 |
|------|------|
| 阻塞 I/O | 进程阻塞在 read/write |
| 非阻塞 | 轮询 + EWOULDBLOCK |
| **信号驱动** | 内核在 fd **就绪**时发 **`SIGIO`**，进程继续做别的事 |

---

## 核心理念

告诉内核：“描述符可 I/O 时，用 **SIGIO** 通知我。”

等待阶段进程**不阻塞**在读写上。

## 个人学习总结

信号驱动 I/O = SIGIO 通知——fd 可读时内核发 SIGIO 信号，应用在信号处理器中 read。

**三步启用**：①fcntl F_SETOWN 设接收进程 ②fcntl O_ASYNC（或 FIOASYNC）开异步通知 ③非阻塞 I/O。

**一句话**：SIGIO = "内核主动告诉你有数据了"——类似硬件中断，不用轮询。

> 历史定位：SIGIO 被 epoll 的边缘触发取代——现代几乎不用。
