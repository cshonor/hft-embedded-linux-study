## 核心主旨

**带外数据（OOB, Out-of-Band）**：独立于普通流、用于优先/快速传递控制信息的逻辑通道。

| 协议 | 实现 |
|------|------|
| 概念 | 优先通道 |
| **TCP** | **无独立通道** → **紧急模式（Urgent Mode）**：头部 URG + 紧急指针 |

设计初衷：普通数据因流控阻塞时，仍能传递重要控制信息。

## 个人学习总结

TCP 带外数据（OOB）= 紧急数据——通过 URG 标志 + 紧急指针在 TCP 头中标记，不占用数据流位置。

**一句话**：OOB 是 TCP 的"加急通道"——1 字节紧急数据可"跳过"普通数据被优先接收。

> 现代趋势：OOB 基本被废弃——应用层用独立连接或带内标记替代。
