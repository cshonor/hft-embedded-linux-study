# 24.2 TCP 带外数据

> [Ch 7.9 TCP 选项](../../1_BasicFoundation/Chapter07_SocketOption/7.9_TCP_Socket_Option.md)

---

## 底层机制

TCP 头部：

| 字段 | 作用 |
|------|------|
| **URG** | 本段含紧急数据 |
| **紧急指针** | 16 位偏移 + 序号 → **紧急数据结束位置**（带外字节序号） |

---

## 发送

```c
send(fd, "a", 1, MSG_OOB);
```

**陷阱**：`send(..., "abc", 3, MSG_OOB)` 时，标准上**通常只有最后一字节**（`'c'`）为带外字节，紧急指针指向它。

---

## 接收端通知

| 机制 | 说明 |
|------|------|
| **`SIGURG`** | 须 `fcntl(F_SETOWN)` 设套接字属主 |
| **`select` 异常** | 套接字进入 **`exceptset`** |

可在 OOB 数据体到达前**提前**通知（仅 URG 头到达时）。

---

## 读取：SO_OOBINLINE

| 模式 | `SO_OOBINLINE` | 读法 |
|------|----------------|------|
| **分离（默认 0）** | 带外字节进**单字节**独立缓冲 | **`recv(..., MSG_OOB)`** |
| **线内（1）** | 带外字节留在**普通流**顺序中 | 普通 `read`/`recv`；用 **`sockatmark`**（24.3） |

---

## 个人学习总结

TCP 紧急模式：send 带 MSG_OOB → 设 URG 标志 + 紧急指针指向下一字节。接收方收到 URG → 发 SIGURG（信号驱动）或可用 recv MSG_OOB 读取。

**两种读取模式**：①MSG_OOB 单独读 1 字节 ②SO_OOBINLINE 嵌入普通数据流。

**一句话**：OOB 只有 1 字节，多次 send MSG_OOB 只保留最后一个——前一个被覆盖。

> TCP 紧急指针的语义在 RFC 793 和 1122 之间有历史差异。
