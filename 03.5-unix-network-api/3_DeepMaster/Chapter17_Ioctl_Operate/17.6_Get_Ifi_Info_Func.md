# 17.6 get_ifi_info 函数

> [17.5 SIOCGIFCONF](17.5_Network_Interface_Config.md) · [Ch 18.5](../../4_ArchitectureDesign/Chapter18_RoutingSocket/18.5_Get_Ifi_Info_Func.md)（路由套接字版）

---

## 核心封装

直接处理 `SIOCGIFCONF` 的缓冲区伸缩、解析、IPv4/IPv6 步长对齐**极其繁琐** — 书中 **`get_ifi_info`** 封装。

---

## 功能

- 透明调用底层 `ioctl`  
- 处理缓冲区加倍重试、对齐  
- 返回 **`ifi_info` 链表**

---

## ifi_info 典型字段

| 字段 | 内容 |
|------|------|
| 接口名 | `eth0`、`lo0` |
| 索引 | 接口 index |
| 单播 IP | `sockaddr` |
| 掩码、广播地址 | |
| 标志 | 广播/多播/P2P/UP 等 |

---

## 地位

编写多播、底层协议、代理时的**基石**工具函数。

---

## 个人学习总结

Stevens 封装 `get_ifi_info(family, doaliases)` — 基于 SIOCGIFCONF 返回 ifi_info 结构链表（接口名、IP、掩码、广播地址）。

**一句话**：get_ifi_info = 统一的接口信息获取封装——屏蔽不同 OS 的 ioctl 差异。

> 现代替代：getifaddrs() 更简洁；DPDK 用 rte_eth_dev_info 获取网卡信息。
