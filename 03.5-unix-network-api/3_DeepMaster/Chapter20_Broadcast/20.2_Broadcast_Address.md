# 20.2 广播地址

---

## 地址分类（IPv4）

将 IPv4 分为 **netid + hostid**（子网划分后实际四类）：

| 类型 | 形式 | 路由行为 |
|------|------|----------|
| **受限广播** | **`255.255.255.255`** | 路由器**绝不转发**；仅限本链路 |
| **指向网络** | netid 固定，hostid 全 1（如 `10.255.255.255`） | 理论上可转发到该网络；现代路由器多**默认禁用** |
| **子网定向广播** | 子网 hostid 全 1（如 `192.168.42.0/24` → **`192.168.42.255`**） | **最常用**；接口发链路层广播帧 |
| **全子网定向** | 子网位+主机位全 1 | 已过时，易混淆 |

---

## 链路层

目的 IP 为广播 → 常映射以太网 **`FF:FF:FF:FF:FF:FF`**。

---

## 个人学习总结

IPv4 广播地址：受限广播 255.255.255.255（不路由）和定向广播（子网全 1，如 192.168.1.255）。

**一句话**：255.255.255.255 只在本网传播；192.168.1.255 可跨路由器到达目标子网（但默认被路由器丢弃）。

> 子网广播地址 = 网络号 | ~掩码。如 192.168.1.0/24 → 192.168.1.255。
