## 章节核心提炼

### 1. 范围与协议

- 广播 = **LAN 内**高侵入通信  
- **`255.255.255.255`**、**子网定向广播**最常见  
- **仅 UDP**；IPv6 用多播

### 2. 安全锁

必须 **`SO_BROADCAST`**，否则 **EACCES**。

### 3. 代价

穿透单播 MAC 硬件过滤，**全子网主机**协议栈处理 — 理解后更易接受 IPv6/多播设计。

### 4. 一发多收防死锁

- 初级：`alarm` + `recvfrom`（有竞态）  
- 生产：**`pselect`** 或 **select 超时**  

---

## 广播 vs 多播（预告 Ch 21）

| | 广播 | 多播 |
|--|------|------|
| 接收方 | 子网**全部**主机 | **加入组**的主机 |
| IPv6 | 无 | 标准方案 |

---

## 个人学习总结

广播 = UDP 子网内一对全。需要 SO_BROADCAST 权限。255.255.255.255 不路由，定向广播默认被路由器丢弃。

**竞态**：alarm+recvfrom 有信号竞态 → 用 pselect 或 SO_RCVTIMEO 替代。

> 广播已被组播取代——组播可控接收者列表、可跨子网、更高效。
