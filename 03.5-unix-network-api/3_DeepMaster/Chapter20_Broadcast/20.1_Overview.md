## 核心主旨

| 模式 | 说明 |
|------|------|
| **单播** | 一点对一点 |
| **广播** | 向 LAN 内**所有**节点发（本章） |
| **多播** | 向**订阅组**发（Ch 21） |

广播**限制在局域网**：路由器通常**不转发**，防广播风暴。

---

## 重点结论

| 点 | 说明 |
|----|------|
| **仅 UDP** | TCP **不支持**广播（面向连接、点对点） |
| **IPv4** | 支持；ARP、DHCP 等常用 |
| **IPv6** | **废除广播**，由**多播**取代 |

---

> 💡 **后续拓展留白**  
> - 云 VPC / SDN 下二层广播常被限制或模拟单播
