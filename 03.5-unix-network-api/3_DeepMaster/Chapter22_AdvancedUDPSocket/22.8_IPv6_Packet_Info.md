# 22.8 IPv6 分组信息

> [22.2](22.2_Flag_DestIP_InterfaceIndex.md) · [14.6 cmsghdr](../../2_AdvancedSkill/Chapter14_AdvancedIO_Func/14.6_Auxiliary_Data.md)

---

## IPV6_PKTINFO / RECVPKTINFO

通过 **`recvmsg` / `sendmsg`** 与 **`in6_pktinfo`** 辅助数据。

---

## 接收（recvmsg）

- 目的 IPv6 地址  
- 到达**接口索引**

---

## 发送（sendmsg 控制信息）

可**覆盖**（在属于本机的前提下）：

- **源 IPv6 地址**  
- **外出接口索引**（覆盖默认路由选路）

---

## 个人学习总结

IPv6 IPV6_PKTINFO — 类似 IPv4 IP_PKTINFO，通过 recvmsg 辅助数据获取目的地址和接口索引。

**差异**：IPv6 结构体是 in6_pktinfo（含 pi6_addr + pi6_ifindex），IPv4 是 in_pktinfo。

**一句话**：IPv6 pktinfo 与 IPv4 等价——协议无关代码需处理两种结构。

> IPV6_RECVPKTINFO 需先 setsockopt 开启才能在 recvmsg 中收到。
