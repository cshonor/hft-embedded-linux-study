## IPV6_PKTINFO / RECVPKTINFO

通过 **`recvmsg` / `sendmsg`** 与 **`in6_pktinfo`** 辅助数据。

---

## 接收（recvmsg）

- 目的 IPv6 地址  
- 到达**接口索引**

---

## 发送（sendmsg 控制信息）

可**覆盖**（在属于本机的前提下）：

- **源 IPv6 地址**  
- **外出接口索引**（覆盖默认路由选路）
