# 27.2 IPv4 选项

> [27.3 源路由](27.3_IPv4_Source_Route_Option.md) · [Ch 7 getsockopt](../../1_BasicFoundation/Chapter07_SocketOption/study.md)

---

## API

```c
getsockopt / setsockopt(sockfd, IPPROTO_IP, IP_OPTIONS, ...);
```

| 项 | 说明 |
|----|------|
| 级别 | **`IPPROTO_IP`** |
| 选项名 | **`IP_OPTIONS`** |
| 格式 | 无内核辅助结构 — 须按 **RFC 791 TLV** 手工拼接裸字节 |

---

## 常见选项（理论）

| 选项 | 作用 | 局限 |
|------|------|------|
| **记录路由（RR）** | 沿途路由器填入出口 IP | 40 字节上限 → **最多约 9 个** IP，公网几乎无用 |
| **时间戳（Timestamp）** | 记录到达时间与 IP | 同上，现代极少启用 |

---

## 个人学习总结

IPv4 包选项：`setsockopt(IP_OPTIONS)` 设置 IPv4 头部选项。选项格式：code(1B)+len(1B)+ptr(1B)+data。常用选项：LSRR/SSRR（源路由）、RR（记录路由）、TS（时间戳）。

**一句话**：IP_OPTIONS=往 IP 头部塞 TLV 选项，ping -R 用 RR 记录路径，traceroute 用 LSRR。

> 易考点：IP 头部+选项总长最多 60 字节（IHL 4 bit，最大 15×4=60），选项最多 40 字节。
