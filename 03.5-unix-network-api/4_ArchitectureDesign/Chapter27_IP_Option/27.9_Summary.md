## 章节核心提炼

### 1. IPv4 选项的黄昏

40 字节上限 + 防火墙封杀 → **RR/源路由** 现代**无实用价值**，理论了解即可。

### 2. IPv6 工程化

**扩展首部**菊花链 → 可扩展；用 **`inet6_opt_*` / `inet6_rth_*`** 构建解析。

### 3. Type 0 路由已废

**RFC 5095** — 勿依赖 IPv6 Type 0 路由首部。

### 4. 双轨控制面

| | 辅助数据 `sendmsg` | 粘附 `setsockopt` |
|---|-------------------|-------------------|
| 生效 | 单包 | 整套接字 |

## 个人学习总结

IP 选项总结：IPv4 用 IP_OPTIONS 设置头部 TLV（40B 上限），IPv6 用扩展头链（无上限）。IPv6 选项可通过粘性（setsockopt 一次）或辅助数据（每包）设置。源路由选项因安全风险基本废弃。

**一句话**：IPv4 选项=40B TLV 头部，IPv6 选项=扩展头链+粘性/辅助两种设置方式，源路由已废弃。

> HFT 关联：IP 选项基本不用在 HFT 中（增加路由器处理延迟），但理解 IPv6 扩展头有助于排查组播/移动 IP 问题。
