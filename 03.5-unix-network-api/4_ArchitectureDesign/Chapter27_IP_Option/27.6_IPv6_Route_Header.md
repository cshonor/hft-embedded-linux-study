# 27.6 IPv6 路由首部

> [27.3 IPv4 源路由](27.3_IPv4_Source_Route_Option.md) · [27.8 历史 API](27.8_Historical_IPv6_API.md)

---

## 机制（Type 0，已废弃）

类似 IPv4 **宽松源路由**；构建 API：

```text
inet6_rth_init()
inet6_rth_add()      /* 逐个添加必经 IPv6 节点 */
inet6_rth_reverse()  /* 反转收到的路由首部 */
```

---

## 安全：RFC 5095

**Type 0 路由首部**可被用于 **DoS 放大**（两节点间无限弹射）→ **RFC 5095 正式废弃**。

现代内核多**默认拒绝** Type 0 — 学习 API 时须知历史背景，**勿在生产依赖**。

---

## 个人学习总结

IPv6 路由头（Routing Header）：类似 IPv4 源路由，指定数据包途经的节点。Type 2 用于移动 IPv6（单地址），Type 0 已废弃（安全风险）。

**一句话**：IPv6 Routing Header=IPv4 源路由的继任者，Type 0 废弃（安全），Type 2 仅供移动 IP。

> 易考点：RH Type 0 可指定任意路径绕过防火墙，RFC 5095 废弃。现代实现默认丢弃 Type 0。
