## 核心主旨与时代背景

IPv4 → IPv6 过渡漫长，长期并存：

| 主机类型 | 说明 |
|----------|------|
| 纯 IPv4 | 仅 `AF_INET` |
| 纯 IPv6 | 仅 `AF_INET6` |
| **双栈（Dual-stack）** | 同时支持两者 |

本章问题：**双栈主机上，IPv4 应用与 IPv6 应用如何互通？** 内核扮演 **“隐形翻译官”**。

## 个人学习总结

IPv4/IPv6 互操作概述：双栈（dual-stack）主机同时运行 IPv4 和 IPv6 协议栈。IPv6 socket 可通过 IPV6_V6ONLY 选项控制是否接受 IPv4 映射地址。

**一句话**：双栈=一台机器同时跑 v4/v6，一个 v6 socket 默认可收 v4 连接（映射地址 ::ffff:a.b.c.d）。

> 易考点：IPV6_V6ONLY=1 时 v6 socket 只收 v6，=0（默认）时 v4 映射地址也接受。
