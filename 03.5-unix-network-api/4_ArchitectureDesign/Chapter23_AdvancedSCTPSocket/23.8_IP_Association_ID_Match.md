# 23.8 找出关联 ID

> [Ch 9.11 sctp_opt_info](../Chapter09_BasicSCTPSocket/9.11_Sctp_Opt_Info_Func.md) · [23.7 地址查询](23.7_Local_Remote_Addr_Query.md) · [23.10 peeloff](23.10_Association_Split_Operate.md)

---

## 核心主旨

连接池中只知对端某个 **IP** → 需反查其 **assoc_id**，才能对该关联设选项或 `sctp_peeloff`。

---

## API

**`sctp_opt_info`** + **`SCTP_GET_PEER_ADDR_INFO`**（及对端地址参数）→ 得到 **Association ID** 等。

---

## 与一到多管理

```text
sctp_recvmsg → sndrcvinfo.sinfo_assoc_id
或 sctp_opt_info(对端 IP) → assoc_id
  → setsockopt / sctp_peeloff / 统计
```

---

## 个人学习总结

IP 地址与关联 ID 匹配：一到多模型中多个关联共享一个 socket，`sctp_opt_info(SCTP_SOCKOPT_PEELOFF)` 或 `sctp_getpaddrs` 按 assoc_id 区分。通过对端 IP+port 反查 assoc_id 需遍历。

**一句话**：一到多 socket 中 assoc_id 是关联的唯一标识，IP:port 可能重复（不同关联同 IP），必须用 assoc_id。

> 易考点：收到数据时 sctp_recvmsg 填充 rcvinfo.rcv_assoc_id，后续操作用这个 ID 定位关联。
