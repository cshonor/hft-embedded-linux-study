## `AF_LOCAL` 下的特殊行为

### 1. `bind` 占坑陷阱

| 情况 | 结果 |
|------|------|
| `sun_path` 已存在 | **`EADDRINUSE`** |

**最佳实践**：`bind` 前 **`unlink(path)`** 删除旧 socket 文件残留。

---

### 2. 权限

客户端连接需：

- 套接字所在**目录**有 **x（进入）** 权限  
- 套接字文件本身有 **w（写）** 权限  

---

### 3. `close` 不删文件

关闭套接字**不会**自动 `unlink` 路径 — 退出前未清理会留下**无法使用的垃圾 socket 文件**。

守护进程：启动时 `unlink` + 正常退出时再次清理。

---

## 个人学习总结

Unix 域 socket 的基本函数与 inet 完全相同——socket/bind/listen/accept/connect/read/write。区别仅在于地址结构用 `sockaddr_un`，path 替代 IP:port。

**一句话**：API 和 TCP 一模一样，只是 AF_INET→AF_UNIX、sockaddr_in→sockaddr_un、IP:port→path。

> 易考点：connect 一个不存在的 path 返回 ENOENT，bind 到已存在 path 返回 EADDRINUSE（需先 unlink）。
