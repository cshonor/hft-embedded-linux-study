## 与 TCP 的差异

| TCP | SCTP |
|-----|------|
| **`shutdown`** 可**半关闭**（SHUT_WR：不发仍可收） | **不支持半关闭** |
| | `shutdown` → 启动**关联终止序列** |

---

## 调用表现

发起后双方**不应再发新业务数据**；用于排空缓冲区、可靠传完排队数据后关闭关联。

---

## 个人学习总结

SCTP 的 `shutdown` 是优雅关闭（graceful shutdown），三步握手（SHUTDOWN/SHUTDOWN-ACK/SHUTDOWN-COMPLETE），不同于 TCP 的四步 FIN。`close` 则是立即关闭。

**一句话**：TCP close=FIN 四步挥手，SCTP shutdown=三步挥手且不允许半关闭（无 SHUT_WR 状态）。

> 易考点：SCTP 不支持 TCP 那样的半关闭（half-close），shutdown 后双向都不传数据。
