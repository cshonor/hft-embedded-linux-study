# 9.7 sctp_getladdrs 函数

> [9.8 sctp_freeladdrs](9.8_Sctp_Freeladdrs_Func.md) · [9.5 对端地址](9.5_Sctp_Getpaddrs_Func.md)

---

## 核心主旨

获取指定关联中**本地（Local）**正在使用的全部绑定 IP 地址。

---

## 个人学习总结

`sctp_getladdrs` 获取本端（local）所有绑定地址列表，配合 `sctp_freeladdrs` 释放。

**一句话**：local 地址=bindx 绑定的那些，peer 地址=connectx/connect 对端报告的那些。

> 易考点：关联建立后两端地址列表都可能变化（动态增删），不应缓存。
