# 30.11 预先创建线程：每个线程各自 accept

> [30.10 每连接线程](30.10_TCP_Thread_Concurrent_Server.md) · [30.12 主 accept](30.12_PreThread_Server_MainAccept.md)

---

## Prethread（线程池）

启动时预建 **N 个工作线程**，避免每连接 `pthread_create`。

---

## 运作机制

所有工作线程在**互斥锁**保护下，对**同一监听套接字**轮流 **`accept`**。

---

## 性能

共享内存廉价 → 锁开销极低 → 书中压测**吞吐量顶尖**范式之一。

前提：业务与第三方库**线程安全**。

---

## 个人学习总结

Pre-thread 单 accept 服务器：创建 N 个线程，所有线程共享 listenfd 各自 accept。惊群问题同 pre-fork，但线程创建开销已消除。

**一句话**：pre-thread 单 accept=N 线程争 accept，比 pre-fork 轻（无 fork 开销），但仍有惊群。

> 易考点：线程版惊群比进程版更轻——线程唤醒开销小，且共享地址空间无 IPC 需求。
