## 典型模式

| 要素 | 说明 |
|------|------|
| 连接数 | 同时发起**数千** TCP 连接 |
| 协议 | 发固定长度请求 → 收等量回射 → 关闭 |
| 指标 | 首连建立到末连断开的**总耗时** → 吞吐 |
