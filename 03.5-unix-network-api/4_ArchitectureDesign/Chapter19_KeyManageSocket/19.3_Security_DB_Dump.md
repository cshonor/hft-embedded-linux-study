## 核心主旨

内核维护 **SADB（Security Association Database）** — 当前有效 SA 集合。调试或状态同步时可请求**完整快照**。

---

## `SADB_DUMP` 流程

```text
① 构造 sadb_msg：type = SADB_DUMP，指定 satype（如 SADB_SATYPE_ESP）
② write 到 PF_KEY 套接字
③ while read：
     每条消息 = 一条 SA 记录
     末包 sadb_msg_seq 特殊标记（常为 0，依实现）→ 倾泻结束
```

| 点 | 说明 |
|----|------|
| 多部分流 | SADB 可能很大，内核**无法单包**返回全部 |
| 循环 read | 应用须持续读至结束标记 |
