## 通信模型

与路由套接字类似：经 **`read` / `write`** 交换**结构化二进制消息**，非流式文本。

---

## 统一首部：`sadb_msg`（`<net/pfkeyv2.h>`）

| 字段 | 含义 |
|------|------|
| **`sadb_msg_version`** | 常为 **`PF_KEY_V2`** |
| **`sadb_msg_type`** | `SADB_ADD`、`SADB_DUMP`、`SADB_ACQUIRE` 等 |
| **`sadb_msg_len`** | 整条消息长度，单位 **8 字节（64 位）** |
| **`sadb_msg_seq`** | 请求/应答匹配 |
| **`sadb_msg_pid`** | 进程标识，匹配用 |

---

## 扩展（Extensions）

```text
sadb_msg
  + sadb_sa      （SPI、生存期等）
  + sadb_address （源/目的 IP）
  + sadb_key     （认证/加密密钥）
  + …
```

| 陷阱 | 说明 |
|------|------|
| **8 字节对齐** | 各扩展须 64 位对齐；解析时按长度**指针步进** |
| 长度单位 | `sadb_msg_len` 等为 **8 字节块数**，非字节数 |

任一 `sadb_ext` 长度算错 → 内核拒收消息。
