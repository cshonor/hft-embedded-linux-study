## 核心主旨

---

## 架构选择

刻意采用 **一到多（One-to-Many，`SOCK_SEQPACKET`）**：

| 优势 | 说明 |
|------|------|
| 单 fd | 同时处理**成百上千关联** |
| 展示 SCTP 特性 | **多流**、消除 **队头阻塞** |
| 状态机 | 比 per-连接 accept 更轻（类 UDP 服） |

## 个人学习总结

SCTP C/S demo 概览：使用一到多模型构建回射服务器，客户端用 sctp_sendmsg/sctp_recvmsg 交互。重点关注 stream 分配和通知处理。

**一句话**：一到多 SCTP 服务器=一个 socket 服务所有客户端，比 TCP 的 fork/thread 模型简洁。

> 易考点：一到多模型中服务器无需 accept/fork，直接 recvmsg 即可收新关联数据。
