## 核心主旨

一到多客户 **不必 `connect`**。

```text
socket(SOCK_SEQPACKET, IPPROTO_SCTP)
→ setsockopt SCTP_EVENTS（sctp_data_io_event）
→ sctpstr_cli(sockfd, 服务器地址)
```

---

## 与服务器对称

同样依赖 **`sctp_sndrcvinfo`** 查验回射来自哪条**流**、哪个**关联**。

---

## 个人学习总结

一到多 SCTP 客户端：`socket(SOCK_STREAM)` → `connect` → `sctp_sendmsg`/`sctp_recvmsg`。客户端用一到一模型，指定目标 stream 发送。

**一句话**：客户端侧 SCTP 和 TCP 几乎一样——connect 后 send/recv，只是多了 stream 参数。

> 易考点：客户端 sendmsg 时 stream 号自由选择，服务器看到的 stream 号=客户端指定的。
