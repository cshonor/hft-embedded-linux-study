## 章节核心提炼

### 1. 多流实战价值

差网络下 **SCTP 多流** 消除 TCP **队头阻塞** 长尾 — 信令、多媒体调度。

### 2. 事件订阅必修课

一到多下消息带 **assoc_id、stream** 元数据 → 必须 **`SCTP_EVENTS` + sctp_data_io_event**。

### 3. 精细化状态控制

| 需求 | 手段 |
|------|------|
| 流数量 | 关联前 **`SCTP_INITMSG`** |
| 关单关联 | **`sctp_sendmsg` + SCTP_EOF** |
| 勿误用 | 一到多上 **`close` 关全部** |

## 个人学习总结

SCTP C/S demo 总结：一到多模型简化服务器代码，多流解决 HoL 阻塞，notification 提供关联生命周期事件。相比 TCP C/S 模型，SCTP 在消息边界和多流方面有天然优势。

**一句话**：SCTP C/S demo 三大要点——一到多免 fork、多流避 HoL、notification 事件驱动。

> HFT 关联：如果交易平台选 SCTP，多流可分离行情/委托/回报，天然解耦，但 SCTP 穿 NAT/防火墙困难，实际部署受限。
