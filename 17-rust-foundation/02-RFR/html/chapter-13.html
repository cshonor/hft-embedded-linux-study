The Standard Library（标准库拾遗）

所属：What's Out There? · ← 章索引

易被忽略但常用的 std 设施：

API 用途
Cow<'a, str> 多数只读、偶尔拥有的字符串 API
write! + fmt::Write 向 String 等追加格式化，少 format!
VecDeque 双端 O(1)；队列 / 滑动窗口
Arc::make_mut 唯一引用原地变；否则 clone 内部（写时复制）

2.1

Index Pointers（索引指针）

所属：Patterns in the Wild · ← 章索引

节点放进 Vec<T>，用 NodeId（usize/u32） 代替大量 Rc/引用 织网。

优点 代价
生命周期可控、缓存局部性好 索引失效；需 Generational Index 等约定

生态参考：petgraph、有序 indexmap。

ER → Item 15 借用检查器 · 图

2.2

Drop Guards（Drop 卫士）

所属：Patterns in the Wild · ← 章索引

在 unsafe、持锁区段或「必须配对释放」的资源上，构造局部 Guard，在 Drop 中清理。

  • panic 路径仍会 drop — 恢复不变式、释放句柄
  • Tokio 等库中常见

→ 第 1 章 · Drop · ER Item 11 RAII

2.3

Extension Traits（扩展 Trait）

所属：Patterns in the Wild · ← 章索引

绕过孤儿限制的安全做法：定义 MyExt，对 T: Iterator 等做 blanket impl。

trait MyExt: Iterator { ... }
impl<I: Iterator> MyExt for I { ... }

示例：itertools、tower::ServiceExt。

→ 第 3 章 · 人体工程学 impl · 第 2 章 · 孤儿规则

2.4

Crate Preludes（Crate 预导入）

所属：Patterns in the Wild · ← 章索引

把常用类型与扩展 trait pub use 到 my_crate::prelude::*，降低入门摩擦。

注意

扩展 trait 的方法仍须 trait 在作用域 — Rust 方法解析规则不变。

use my_crate::prelude::*;

→ 第 5 章 · 避免通配符 import（ER 对 * 的谨慎与此不同层）
