统一 IO 示例

use std::io::{self, Read, Write};
use std::net::TcpStream;

fn copy_stream<R: Read, W: Write>(mut r: R, mut w: W) -> io::Result<()> {
    let mut buf = [0u8; 1024];
    loop {
        let n = r.read(&mut buf)?;
        if n == 0 { break; }
        w.write_all(&buf[..n])?;
    }
    w.flush()?;
    Ok(())
}

fn main() -> io::Result<()> {
    copy_stream(io::stdin().lock(), io::stdout().lock())?;
    let mut tcp = TcpStream::connect("example.com:80")?;
    tcp.write_all(b"GET / HTTP/1.1\r\nHost: example.com\r\n\r\n")?;
    copy_stream(tcp, io::stdout())?;
    Ok(())
}

13.4

向量 I/O 与 stdio 锁精简走读

章索引：第 13 章 · 相关：13.1.2 · 13.1.3 · 13.2

一句话

对照 library/std 的 readv/writev 与 stdio 全局锁 概念骨架 — 非 rustc 逐字拷贝。

A. writev（Unix）

// sys 层 — 概念
pub fn write_vectored(fd: RawFd, bufs: &[IoSlice]) -> io::Result<usize> {
    let mut iovec: Vec<libc::iovec> = bufs.iter().map(|s| libc::iovec {
        iov_base: s.as_ptr() as *mut _,
        iov_len: s.len(),
    }).collect();

    let ret = unsafe {
        cvt(libc::writev(fd, iovec.as_mut_ptr(), iovec.len() as _))?
    };
    Ok(ret as usize)
}

TcpStream / File 在 Write::write_vectored 中 override · 否则默认 循环 write。

B. readv（Unix）

// 对称：readv 填充多个 IoSliceMut
unsafe {
    cvt(libc::readv(fd, iovec.as_mut_ptr(), count))?
}

C. stdio 全局锁（概念）

// io/stdio.rs — 逻辑骨架
pub fn stdin() -> &'static Stdin {
    STDIN.get_or_init(|| Stdin { inner: sys_stdio::stdin() })
}

impl Stdin {
    pub fn lock(&self) -> StdinLock<'_> {
        StdinLock {
            inner: self.inner.lock(), // 全局 Mutex/ReentrantMutex
        }
    }
}

impl Read for StdinLock<'_> {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        self.inner.read(buf) // 底层 fd 0 read
    }
}
点 说明
lock() 持锁期间 独占 stdin
println! stdout().lock() 同理

D. 缓冲与 flush

Stdout（TTY）:     行缓冲 → '\n' 或 flush() → write(fd 1)
Stdout（重定向）:  块缓冲 → 满块或 flush
Stderr:            无缓冲 → 每次 write 尽快到达 fd 2

实现分散在 sys::stdio · LineWriter 等 wrapper。

13.5

Socket 网络 IO 精简走读

章索引：第 13 章 · 前：13.3 · 网络 I/O

一句话

Unix Berkeley Socket 与 Winsock 在 sys::net 收敛 — 对上 TcpStream: Read + Write · Drop → close。

A. TcpStream connect（Unix 概念）

// sys/unix/net.rs — 骨架
pub fn connect(addr: &SocketAddr) -> io::Result<TcpStream> {
    let socket = Socket::new(addr.domain(), Type::STREAM)?;
    socket.connect(addr)?;
    Ok(TcpStream { inner: socket })
}

impl Read for TcpStream {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        self.inner.read(buf) // recv(2) 或 read on socket fd
    }
}
impl Write for TcpStream {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        self.inner.write(buf) // send(2)
    }
}

B. TcpListener accept

pub fn accept(&self) -> io::Result<(TcpStream, SocketAddr)> {
    let (stream, addr) = self.inner.accept()?;
    Ok((TcpStream { inner: stream }, addr))
}

accept 阻塞 直到有连接 · async 版在 tokio/mio + epoll。

C. UdpSocket

// 不 impl Read/Write 整体流 — 使用 datagram API
socket.send_to(buf, target_addr)?;
socket.recv_from(&mut buf)?; // 返回 (len, src_addr)

D. Drop 关闭

impl Drop for TcpStream {
    fn drop(&mut self) {
        let _ = self.inner.close(); // close(fd) / closesocket
    }
}

↔ 9.5.1 · FD · 12.4 · File Drop

E. Windows Winsock 差异

进程启动: WSAStartup（std 运行时/首次 socket 时）
API:      WSASocket · connect · recv/send
句柄:     SOCKET → 内部适配 Read/Write
关闭:     closesocket

上层 TcpStream::connect("host:port") 无 cfg 分支。

F. 与 Ch14 分界

本章 std::net Ch14 async
阻塞 read/write poll + Waker + epoll
线程 1:1 阻塞 单线程多连接
