固有函数库

章索引：第 4 章 · 后：4.1.1 · 原子操作

一句话

固有函数（intrinsics） 由 编译器内置实现（常对应 CPU 指令/汇编），是 core::intrinsics 的根基 — 不是 普通 Rust 函数；原子、数学/位运算、分支提示等 高性能底层能力 由此接入标准库。

原书要点

概念

项 说明
定义 编译器 直接 codegen 的特殊函数，与 目标架构 紧密相关
位置 core::intrinsics（用户代码 几乎不应 直接调用 — 由 Atomic*、Wrapping 等安全封装调用）
与 std 关系 属于 core 层，内核与用户态均可链接

.1 原子操作函数

章索引：第 4 章 · 前：4.1 · 后：4.1.2 · 数学/位操作

一句话

atomic_* intrinsic 是多核并发下 load/store/CAS/fence 的硬件基石 — AtomicUsize 等类型与 Mutex/RwLock 临界区保护 最终都依赖 这些原子原语。

原书要点

能力 说明
原子读写 单变量上的不可分割读/写，配合 Ordering（Relaxed/Acquire/Release/SeqCst…）
CAS compare_exchange — 无锁队列、自旋锁、版本计数
fence 跨核内存序屏障
与并发原语 std::sync::Mutex 等 用户态 API 内部仍可能落到 OS + 原子；无锁路径 直接 用 Atomic* 
// 用户态典型用法（非直接 intrinsic）
use std::sync::atomic::{AtomicU64, Ordering};
let seq = AtomicU64::new(0);
seq.fetch_add(1, Ordering::Relaxed);

HFT 关联

场景 用法
订单序号 AtomicU64 Relaxed 递增
行情版本 CAS 更新快照指针
无锁队列 compare_exchange 入队/出队

项 说明

断言类

类型 说明

栈获取

用途 说明

4.2

.4 引用类型 match 语法研究

章索引：第 4 章 · 前：4.2.3 · 后：4.2.5 · Result

一句话

对 &T / &mut T 做 模式匹配 时，编译器在 自动解引用（Deref）、绑定模式 与 生命周期推断 之间做协调 — 表面语法是「match 引用」，底层仍是 按值/按引用解构 + 借用规则。

原书要点

常见形态

写法 效果
match &opt { Some(x) => … } x: &T — 不移动内部值
match &mut v { … } 可变借用绑定
match *r { … } 显式解引用（须 Copy 或移动）
ref / ref mut 绑定 模式内 强制 以引用绑定

底层逻辑

match expr
  ├─ expr 若为引用 ──► 模式默认匹配「被指向的值」（Deref 模式匹配）
  ├─ 绑定变量 ──► 推断 &T 或 T（是否 move）
  └─ 生命周期 ──► 绑定引用不得长于被 match 的借用

易错点

陷阱 说明
move vs borrow Some(x) 在 match &opt 中 x 是引用
ref 关键字 Some(ref x) 在 match 值 时仍绑定为引用
mut 模式 &mut 匹配要求表达式为可变借用

4.3

.1 编译器内置 Marker Trait

章索引：第 4 章 · 前：4.3 · 后：4.3.2 · 算术 Trait

一句话

Marker Trait（Send、Sync、Copy、Sized 等）无方法体 — 仅标记类型的 特殊属性；Auto Trait 由编译器按成员 自动推导，是 跨线程安全 与 泛型约束 的隐形基石。

原书要点

核心 Marker

Trait 含义
Send 所有权可 转移到 其他线程
Sync &T 可安全共享 于多线程（T: Sync ⇔ &T: Send）
Copy 按位复制，不 move（与 Drop 互斥于常见类型）
Sized 编译期已知大小；默认泛型 T: Sized
Unpin 移动后不 invalidate 自引用（async 相关）

Auto Trait 规则（直觉）

若 T 的所有字段都 Send  ──►  T 自动 Send（除非手动 unsafe impl 或 !Send 字段）
若 T 的所有字段都 Sync  ──►  T 自动 Sync
反例 说明
Rc<T> !Send — 非原子引用计数
Cell<T> !Sync — 内部可变性非线程安全
*const T !Send / !Sync（裸指针）

一句话

? 不是魔法 — 它是 Try Trait 的语法糖：把 Result/Option/ControlFlow 等的 Break 变体 早退为函数返回值，Continue 则解包继续执行。

原书要点

展开直觉

// expr?  大致等价于：
match Try::branch(expr) {
    ControlFlow::Continue(v) => v,
    ControlFlow::Break(e)    => return From::from(e),
}
组件 作用
Try 定义 from_output / branch — 哪些类型可用 ?
ControlFlow<B, C> Continue(C) 继续 · Break(B) 早退
From 错误类型转换（? 在 Err 侧）

适用类型

类型 ? 行为
Result<T,E> Err → return Err（可 From 转换）
Option<T> None → return None
ControlFlow<E,T> 自定义控制流

一句话

a..b / a..=b / .. / ..=n 等范围语法 desugar 为 Range / RangeInclusive / RangeFrom / … 结构体 — 它们实现 RangeBounds，供 slice::get、迭代器、BTreeMap 区间查询 等统一描述 左闭右开 / 闭区间。

原书要点

语法 → 类型

语法 标准库类型 区间语义
a..b Range<T> [a, b) 左闭右开
a..=b RangeInclusive<T> [a, b] 两端闭
a.. RangeFrom<T> [a, ∞)
..b RangeTo<T> (-∞, b)
..=b RangeToInclusive<T> (-∞, b]
.. RangeFull 全范围

作用 说明

4.3

.5 索引运算符 Trait

章索引：第 4 章 · 前：4.3.4 · 后：第 5 章 · 迭代器

一句话

arr[i] / s[i] 语法糖来自 Index / IndexMut Trait — 数组、切片、Vec、字符串、HashMap 等 各自 impl，统一「下标访问」表象，底层可以是 边界检查、O(1) 偏移或 hash 查找。

原书要点

Trait 签名（简化）

pub trait Index<Idx: ?Sized> {
    type Output: ?Sized;
    fn index(&self, index: Idx) -> &Self::Output;
}

pub trait IndexMut<Idx: ?Sized>: Index<Idx> {
    fn index_mut(&mut self, index: Idx) -> &mut Self::Output;
}
类型 Idx 常见形式
[T] / Vec<T> usize · Range<usize> 等
str Range<usize>（字节区间，非 char）
[T; N] usize
HashMap<K,V> &K

与 panic

API 行为
arr[i] 越界 → panic（debug 友好）
arr.get(i) 返回 Option<&T> — 安全

组合 Range

let mid = &v[1..4];  // Index<Range<usize>> → 切片引用
