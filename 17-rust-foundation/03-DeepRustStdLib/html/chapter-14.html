14.1

.1 协程概述

章索引：第 14 章 · 前：14.1 · 后：14.1.2 · 多路复用

一句话

Rust 无内置协程调度器 — 仅 async fn / async {} 语法 · 编译器 desugar 为 Future 状态机 · 惰性（不 poll 不执行）· 无运行时绑定。

原书要点

1. async/await 编译变换

async fn demo() -> u32 {
    let a = read_io().await;
    a + 1
}
// 编译器 ≈ 匿名 enum DemoFuture { State0, State1, … }
// 每个 .await → 一个变体 · 保存跨 await 的局部变量/引用
点 说明
协程 ≈ Future 语言 coroutine 落地为 trait Future
.await poll 子 Future · 未完成 → yield Pending
惰性 调用 demo() 不跑 IO · 须 executor poll
Send 跨线程 spawn 须状态机 Send

→ 脱糖示例：14.4 · 状态机走读

2. 协程 vs OS 线程

线程（Ch11） async 协程（Ch14）

栈 固定 MB 级 状态机 按需 · 可大量并发
阻塞 IO 占满线程 Pending · 线程服务其他 Future
典型规模 数百～数千线程 成千上万 Future · 少量工作线程

Rust 协程支持类型简析

章索引：第 14 章 · 前：14.1.2 · 后：14.2.1 · 协程管理

一句话

前言点名的 async 基石 — Poll · Context · Waker · Future 在 core::future / core::task；Executor 用它们 驱动 poll（14.2.1）· trait 定义见 14.2.2。

原书要点

核心三要素

1. Poll<T>

pub enum Poll<T> {
    Ready(T),   // 完成 · 返回 Output
    Pending,    // 未就绪 · 须挂起
}

poll 是唯一推进接口 — 运行时反复 future.poll(&mut cx)。

2. Waker

  • 保存 唤醒任务 的句柄；
  • IO 就绪 / 定时器到期 → waker.wake()（或 wake_by_ref）；
  • Executor 将 Task 重新入队 · 下次 poll。

3. Context<'_>

  • 仅包装 &Waker；
  • 传入 poll · Future 在 Pending 前向 reactor 注册 Waker。
Executor                         Future (async 状态机)
  loop {                           poll(Pin<&mut Self>, &mut Context)
    ready = task.poll(cx)              ├─ Ready(T)  → 完成
    if Pending → 运行其他任务          └─ Pending   → 已注册 Waker
  }
reactor: epoll 就绪 → Waker::wake(task)
类型 位置
Poll core::task
Context · Waker core::task::wake
Future core::future

14.2

.2 Future Trait 分析

章索引：第 14 章 · 前：14.2.1 · 后：14.3 · std 工具

一句话

整个 async 体系的根 — poll(self: Pin<&mut Self>, cx: &mut Context) -> Poll<Output> · 惰性 · 非阻塞 Pending · Waker 唤醒再 poll；Pin 联动 Ch7 · 阻塞 IO 联动 Ch13。

原书要点

标准库定义（core）

pub trait Future {
    type Output;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output>;
}

pub enum Poll<T> {
    Ready(T),
    Pending,
}

两个关键约束

约束 联动 含义
Pin<&mut Self> Ch7 · Pin 自引用状态机 不可 move
仅 poll 无默认实现 编译器/手写 IO 所有 async 任务 必须实现 poll

Pin 闭环（全书最重要串联之一）

async 状态机 enum 内字段 A 的引用指向同 struct 内字段 B
  → move 整个 enum → 内部指针悬垂
  → 编译器生成 !Unpin
  → poll 签名强制 Pin
  → Box::pin / pin_mut! 固定地址

↔ Ch8 · Box::pin · 14.4 · 走读

与阻塞 I/O（Ch13）

阻塞: thread 在 read() 内核 sleep（占线程）
async:  poll → Pending → epoll 等 fd → Waker::wake → 再 poll（不占线程空等）

HFT

少 poll、少 wake — 批处理就绪事件 · 避免 executor 抖动；超低延时可能 不用 async。

14.4

async 脱糖状态机与 Pin 走读

章索引：第 14 章 · 相关：14.1.1 · 7.4 Pin

一句话

教学用脱糖骨架 — 展示 async fn → enum 状态机 → 自引用 → 必须 Pin；非编译器真实输出，便于理解 14.2.2。

A. 源码级 async 示例

async fn demo() -> u32 {
    let a = read_io().await;
    a + 1
}

B. 概念脱糖（三状态）

enum DemoFuture {
    // 初始：开始 poll read_io
    Start,
    // 等待 read_io 完成 · 保存 ReadIoFuture 子状态机
    WaitingRead { read_fut: ReadIoFuture },
    // 已完成（或内嵌结果）
    Done,
}

impl Future for DemoFuture {
    type Output = u32;

    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<u32> {
        let this = self.get_mut(); // 需 unsafe 或 pin-project — 示意
        match this {
            DemoFuture::Start => {
                *this = DemoFuture::WaitingRead { read_fut: read_io() };
                // 递归/循环 poll 子 Future…
                Poll::Pending
            }
            DemoFuture::WaitingRead { read_fut } => {
                match Pin::new(read_fut).poll(cx) {
                    Poll::Ready(a) => Poll::Ready(a + 1),
                    Poll::Pending => Poll::Pending,
                }
            }
            DemoFuture::Done => unreachable!(),
        }
    }
}

真实编译器输出更复杂 · 常用 pin-project / async-trait 等 crate 辅助手写 Future。

C. 自引用为何发生

状态 WaitingRead 内可能同时存：
  · read_fut 子 Future
  · 指向 read_fut 内部 buffer 的指针（编译器优化布局）
整体 enum 若被 move（栈搬家、放入 Vec  realloc）→ 内部指针悬垂

D. Pin 与 Unpin

类型 Unpin? 要求
i32、普通 struct 是 可 &mut T poll
async 状态机 否（默认） 必须 Pin<&mut Self>
堆上固定 — Box::pin(async { ... })
栈上固定 — pin_mut!(x) 宏 
let fut = Box::pin(async {
    let x = read_io().await;
    x + 1
});
// spawn 时传入 Pin<Box<impl Future>>

↔ Ch8 · Box · Pin<&mut RefCell<...>> 等内部可变组合（高级）

E. 常见误区

误区 正解
手动 move async 块 !Unpin · 用 Pin
Pin = 永远堆分配 pin_mut! 栈 Pin
Pin 阻止所有移动 只约束 被 pin 的值 · Pin<Box<T>> 仍可 move Box 本身

14.5

Waker 与 poll 机制走读

章索引：第 14 章 · 相关：14.2 · 14.1.2

一句话

Waker = 可克隆的唤醒句柄 — IO 就绪时 原子标记 + 通知 executor 再 poll；概念骨架对照 core::task::Wake trait。

A. poll 注册 Waker（概念）

impl Future for SocketReadFuture {
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<usize> {
        if self.socket.is_readable() {
            return Poll::Ready(self.socket.read_inner());
        }
        // 未就绪：向 reactor 注册 cx.waker()
        self.socket.register_readable(cx.waker());
        Poll::Pending
    }
}
