6.1

整数类型

章索引：第 6 章 · 后：6.2 · 布尔

一句话

第 6 章在 4.2.1 · 溢出策略 之上，重点展开 NonZero* 非零整数 — 语义保证 ≠0，驱动 Option<NonZeroU32> niche 优化（与原生 u32 同尺寸）；并延续解析/格式化等 std API。

原书要点

非零整数（NonZero）— 本章核心

类型 语义
NonZeroU8 … NonZeroU128 构造时 禁止 0 · 内部保证 get() != 0
NonZeroUsize / NonZeroIsize 指针长度、索引等常见

内存优化（零成本抽象）：

Option<u32>        →  通常 8 字节（tag + padding）
Option<NonZeroU32> →  4 字节 — 用 0 表示 None，非零值表示 Some
机制 说明
Niche optimization 0 在 NonZero* 中 非法 → 编译器 复用 0 作 None
与枚举 标准库大量 Option<NonZero*> 压缩智能指针/计数器布局

↔ 3.4 · NonNull niche（指针非空同理）

let n = NonZeroU32::new(42).unwrap();
let opt: Option<NonZeroU32> = None; // 内存布局 ≡ 单个 u32

其他续篇 API

主题 说明
Display / parse 格式化 · from_str
as_* 变宽/截断须自觉
位操作 4.1.2 · intrinsic

HFT

实践 说明
订单 ID / 序号 NonZeroU64 0 非法 · Option 字段更紧凑
tick 用 i64 + checked 与 NonZero 正交 · 禁止 silent wrap

6.2

布尔类型

章索引：第 6 章 · 前：6.1 · 后：6.3 · 字符

一句话

bool 除 1 字节两值 与 Option<bool> niche 外，标准库提供 then / then_some — 把条件判断 嵌入迭代器/闭包链，是函数式编程拼图，替代部分 if…else 分支。

原书要点

基础

项 说明
大小 size_of::<bool>() == 1
无 truthy if n { … } 非法 · 须显式比较
niche Option<bool> 等布局优化

函数式转换（原书重点）

方法 签名直觉 作用
then_some true → Some(v) · false → None 条件 Optional 化
then true → f() · false → None 惰性 构造 · 闭包链 
// 链式：条件成立才产生下一步
let opt = flag.then_some(42);
let mapped = flag.then(|| expensive());

// 融入 Iterator
items.into_iter()
    .filter(|x| x.valid)
    .flat_map(|x| x.is_top.then_some(x.price))
    .collect::<Vec<_>>();

if flag { Some(x) } else { None }  ──►  flag.then_some(x)

一句话

char = 4 字节 Unicode 标量 — 原书系统梳理 与 u32、UTF-8 字节、&str 的互转，以及 分类判断、escape_unicode 等字符级 API；是理解 6.4 · UTF-8 字符串 的前置。

原书要点

类型关系

方向 API / 规则
char ↔ u32 as u32 / char::from_u32（Option — 非法标量拒绝）
→ UTF-8 字节 encode_utf8(&mut [u8; 4]) → &str 片段
← &str .chars().next() 或解析单个字符 
let c = '中';
let mut buf = [0u8; 4];
let s: &str = c.encode_utf8(&mut buf);

分类与转义

API 作用
is_alphabetic / is_numeric / is_whitespace Unicode 分类
is_ascii() ASCII 子集
escape_unicode() Iterator<Item=char> — \u{4e2d} 形式转义
escape_debug / escape_default 调试/默认转义

char str

6.4

字符串类型

章索引：第 6 章 · 前：6.3 · 后：6.5 · 切片

一句话

str = 变长 UTF-8 [u8] — 须 is_char_boundary 防切片 panic；find 不写死一种算法，而经 Pattern / Searcher Trait 统一多种 needle；子串对子串则 TwoWay 双向匹配 + 周期性跳跃，极低额外内存。

原书要点

UTF-8 与边界安全

陷阱 标准库对策
&s[i..j] 按字节切 切在码元中间 → panic
is_char_boundary(n) 判断索引 n 是否为 合法字符起始字节
安全 API split_at · floor_char_boundary · chars() 按字符迭代 
assert!(s.is_char_boundary(0));
// s[k..] 前须保证 k 为 char boundary

↔ 6.3 · char 与 UTF-8

Pattern 与 Searcher Trait（高度抽象）

str.find(needle) 的 needle 不必是 &str：

实现 Pattern 的 needle 示例
&str / &[char] 子串 · 字符集
闭包 |c: char| c.is_numeric()
外部 crate 可扩展（原书提及正则等） 
find / match_indices / split
  └── Pattern::into_searcher(haystack) → Searcher
        └── next_match() 驱动查找
Trait 职责
Pattern 将「模式」转为 Searcher
Searcher 在 haystack 上 逐步 报告匹配区间
DoubleEndedSearcher 反向搜索支持

TwoWay 算法（字符串找字符串 · 极致性能）

最复杂场景：&str needle in &str haystack → TwoWaySearcher。

要点 说明
周期性（Period） 模式自重复时 大步跳过 · 非逐字节 +1
双向 前后缀信息压缩比较
空间 O(1) 额外堆 — 常数级预处理 
非编译器魔术 ──► Pattern/Searcher 抽象 + TwoWay 实现

HFT

symbol 前缀/后缀查找 — &str 零拷贝 + find；避免未校验字节索引切片。

6.5

切片类型

章索引：第 6 章 · 前：6.4 · 后：第 7 章

一句话

[T] 胖指针视图 — 原书以 swap 与 插入排序 为例：安全层对外，内部在证明 不越界、不重叠 后大量使用 unsafe + ptr::copy_nonoverlapping 直拷内存，支撑与 C 级相当的吞吐。

原书要点

切片本质

项 说明
DST ptr + len · 3.1.1 · 胖指针
&[T] / &mut [T] 连续元素视图
与 Vec &v[..] 借用底层缓冲

↔ 5.5 · 双指针迭代

示例一：swap 与底层指针

slice.swap(i, j) 交换两元素 — 内部可在 unsafe 下 指针读写的 避免多余 temp move（尤其大 T 或优化路径）。

示例二：插入排序 + copy_nonoverlapping

向前挪动元素时，若逐步 安全 move：

每步 → 可能 drop + 所有权转移  →  指令膨胀

标准库在 unsafe 块 内：

ptr::copy_nonoverlapping(src, dst, count);  // 等同 C memcpy
范式 说明
对外 safe sort / sort_by / swap — 用户 &mut [T]
对内 unsafe std 作者承担 边界/别名 证明
哲学 高级安全封装 ← 高水平 unsafe 底座

↔ 3.1 · 裸指针 · Nomicon
