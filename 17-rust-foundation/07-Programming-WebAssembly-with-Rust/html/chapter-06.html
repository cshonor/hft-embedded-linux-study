6.1

How to Be a Good Host

第 6 章索引：README · 后：6.2-interpreting-wasm-rust

一句话

Wasm 可移植靠 模块↔宿主契约；任何宿主必须履行 加载验证、暴露 export、满足 import、解释执行、模块隔离 五项职责 — 浏览器只是宿主之一。

原书要点

Part III 开篇：打破「Wasm = 浏览器」

印象 本章
Wasm 只在 Web 跑 Rust 控制台程序 也可当宿主
需要 JS / 网络 无浏览器、无前端 即可 load + execute

↔ 1.1 · Wasm 不限于 Web

好宿主的 5 项核心职责

# 职责 说明
1 Load and Validate 加载与验证 读 .wasm 二进制 · 验证格式合法 — 防恶意模块的第一道防线
2 Expose Exports 暴露导出 宿主侧 glue，安全调用模块 export 函数（如 $move、add）
3 Satisfy Imports 满足导入 模块 import 的外部函数必须由宿主提供；缺实现则 实例化失败
4 Interpret / Execute 解释执行 维护运行时状态 · 处理 trap/错误 · 执行 Wasm 指令
5 Module Isolation 模块隔离 沙盒：一模块崩溃不拖垮其它模块 · 不能越权读宿主/他模块私有内存 
┌──────────── Host (Rust 控制台) ────────────┐
│ ① load/validate  ② call exports            │
│ ③ provide imports  ④ VM/runtime  ⑤ sandbox│
│         ▲ import          export ▼           │
│    ┌────┴──── .wasm 模块 ────┐              │
│    │  linear memory (隔离)    │              │
│    └─────────────────────────┘              │
└─────────────────────────────────────────────┘

与 Layer 3 / HFT

场景 宿主职责映射
Layer 3 · wasmtime 嵌入均线策略 喂 tick import · 读 signal export · 策略 wasm 隔离崩溃
实盘 宿主持有订单/风控状态 — 防止策略 wasm 篡改全局账本（见 6.3 防作弊）

→ layer03 · host_wasmtime

6.2

Interpreting WebAssembly Modules with Rust

第 6 章索引：README · 前：6.1-good-host · 后：6.3-console-checkers

一句话

不必手写 Wasm VM — 用 Rust 的 wasmi 库加载 Ch1 · add 模块到 ModuleInstance，传参调用 export，在控制台看到结果。

原书要点

为何用现成解释器

选项 说明
手写 VM 教学价值高（CI / Ch1），工程成本极大
wasmi Parity 团队为以太坊客户端等场景开发的 Wasm 解释器（Rust）
现代替代 wasmtime / wasmer 更常用于生产 — Layer 3 宿主可优先 wasmtime → layer03

原书 2019 用 wasmi；概念（Module → Instance → call export）与 wasmtime 一致。

wasmi 基本流程

读取 add.wasm 字节流
  → Module::from_buffer / 解析
  → 链接 imports（本例 add 模块可能无 import）
  → ModuleInstance::new
  → instance.call("add", &[RuntimeValue::I32(1), I32(2)])
  → 控制台打印 3

概念代码（API 随 wasmi 版本略有差异）：

// 伪代码 — 表达流程
let wasm_bytes = std::fs::read("add.wasm")?;
let module = wasmi::Module::from_buffer(&wasm_bytes)?;
let instance = wasmi::ModuleInstance::new(&module, &imports_ref)?;
let result = instance.invoke_export("add", &[I32(1), I32(2)])?;

与 6.1 五项职责的对应

职责 wasmi 中的体现
Load/Validate Module::from_buffer 解析 + 验证
Expose Exports invoke_export("add", ...)
Satisfy Imports 构造 imports 表（add 模块可为空）
Execute 解释器逐条执行
Isolation 模块独立 linear memory + trap 边界

与 Layer 1 衔接

同一 add 函数：

Ch1 WAT 手写  →  Ch3 Rust cdylib  →  Ch6 wasmi 控制台调用
Layer 1 还可并排 .ll 对照

→ layer01

WAT / 工具 / 代码锚点

项 说明
依赖 wasmi = "0.4" 量级（原书；新项目查 crates.io）
输入 1.3 或 3.3 的 add.wasm
demo 规划 layer03/host_wasmtime/ 用 wasmtime 复现同流程

6.3

Building a Console Host Checkers Player

第 6 章索引：README · 前：6.2-interpreting-wasm-rust · 后：6.4-wrap-up

一句话

把 Ch2/Ch3 跳棋 .wasm 原封不动搬进 Rust 控制台宿主：实现 ModuleImportResolver + Externals 满足 notify_* import，再封装 Game API，并直接读模块 linear memory 在终端画 ASCII 棋盘。

原书要点

实战目标

点 说明
同一份 .wasm 浏览器 JS 宿主 ↔ 本章 Rust 控制台 — 零修改
可移植性 证明 Wasm 二进制跨宿主切换

来源模块 → Ch2 wast 或 Ch3 Rusty Checkers

宿主三层结构

┌─────────────────────────────────────┐
│  Game API（Rust 惯用封装）            │  ← move_piece(), render_board()
├─────────────────────────────────────┤
│  Externals（中央调度）                │  ← 拦截 import 调用
├─────────────────────────────────────┤
│  ModuleImportResolver（解析导入）     │  ← 链接 notify_* 签名与索引
├─────────────────────────────────────┤
│  wasmi ModuleInstance + linear mem   │
└─────────────────────────────────────┘

1. 解析导入 — ModuleImportResolver

任务 说明
Wasm 跳棋 import $notify_piecemoved · $notify_piececrowned（Ch2/Ch3）
Resolver 提供函数 签名 · 分配 调用索引 · 实例化时满足 import 表
失败 缺 import → 模块 无法 ModuleInstance::new

2. 满足外部调用 — Externals trait

角色 说明
中央调度器 Wasm 执行 call import 时，runtime 转到宿主 Rust 函数
宿主侧状态 可单独记录胜负、生命值等 — 防止 Wasm 模块作弊改全局结果
通知回调 在 Externals 里 println! 或更新 Game 状态，再触发重绘

↔ Layer 3：宿主持有实盘风控计数，策略 wasm 只能 export 信号 → layer03

3. 封装 Game API + 读 linear memory

技巧 说明
Rust API 包装 避免每次 invoke_export 手写参数
直接读 linear memory 宿主控制内存视图 · 按 Ch2 公式 offset=(x+y*8)*4 读每格 i32
ASCII 渲染 终端打印棋盘 — 不依赖 JS/DOM 
宿主 read memory[offset] → 0/1/2/4/5/6 位标志
  → 映射为 '.', 'b', 'B', 'w', 'W' 等字符
  → println! 网格

这与 Layer 2「宿主 fetch JSON、Wasm 解析」相反：宿主直接窥视 Wasm 内存（仅当布局契约稳定且受控时安全）。

与浏览器宿主对比

JS 宿主 (Ch3) Rust 控制台 (Ch6)
import 实现 env.notify_* 回调 Externals
棋盘 UI DOM / canvas ASCII + memory 读取
网络 可选 fetch 无

WAT / 工具 / 代码锚点

项 说明
wasmi traits ModuleImportResolver · Externals
内存 书中棋盘 ~256B；wasmi 可访问 memory 导出
demo layer03/host_wasmtime/ — 用 wasmtime 加载 checkers 或 ma_core
