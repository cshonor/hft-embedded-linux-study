安装

安装 Rust

通过 rustup 下载 Rust，这是一个管理 Rust 版本和相关工具的命令行工具。需要互联网连接。

如果不想用 rustup，可参阅 Rust 其他安装方法。

命令行符号说明

  • $ — 命令行的开始，不需输入
  • 不以 $ 开头的行 — 表示命令的输出
  • PowerShell 专用示例使用 > 而非 $

Linux / macOS 安装

$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

安装成功会显示：Rust is installed now. Great!

链接器

Rust 需要链接器。若遇链接器错误，可安装 C 编译器：

  • macOS：$ xcode-select --install
  • Linux（如 Ubuntu）：安装 build-essential 包

Windows 安装

访问：https://www.rust-lang.org/zh-CN/tools/install

  • 可能需安装 Visual Studio C++ build tools
  • 推荐安装 VS 2019 构建工具
  • 勾选：C++ build tools、Windows 10 SDK、英文语言包

更新与卸载

# 更新到最新版本
$ rustup update

# 卸载 Rust 和 rustup
$ rustup self uninstall

验证安装

$ rustc --version

输出示例：rustc x.y.z (abcabcabc yyyy-mm-dd)

Windows 若无法识别命令，检查 Rust 是否已加入 %PATH%

本地文档

$ rustup doc

在浏览器中打开本地文档，便于离线查阅 API。

发布渠道（Stable / Nightly）

rustup 默认装 Stable。三渠道与 #![feature(...)] 见 附录 G；Edition 见 附录 E；与 Channel 的完整对比见根目录 README § 工具链。

获取帮助

  • Rust 官方 Discord #beginners 频道
  • Rust 用户论坛
  • Stack Overflow
1.2

Hello, World!

按照传统，学习新语言时先编写一个输出 "Hello, world!" 的简单程序。

注意：本书假定你熟悉基本命令行。Rust 对编辑器、工具、代码位置无特殊要求，可自由选用 IDE。很多 IDE 已提供 Rust 支持。

创建项目目录

建议在主目录下创建 projects 目录存放项目。

Linux / macOS / PowerShell

$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world

Windows CMD

> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

编写和运行 Rust 程序

  1. 创建源文件 main.rs（Rust 文件以 .rs 结尾）
  2. 多词文件名用下划线：hello_world.rs ✓ helloworld.rs ✗

main.rs

fn main() {
    println!("Hello, world!");
}

编译与运行

Linux / macOS：

$ rustc main.rs
$ ./main
Hello, world!

Windows：

> rustc main.rs
> .\main.exe
Hello, world!

Rust 程序剖析

main 函数

fn main() {

}
  • main 是主函数，可执行程序的入口，第一个运行的代码
  • 无参数、无返回值
  • 函数体用大括号 {} 括起
  • 风格建议：左大括号与函数声明同一行，中间留空格

可用 rustfmt 工具自动格式化代码（已随 Rust 安装）

println! 宏

    println!("Hello, world!");
要点 说明
缩进 使用 4 个空格，不用 Tab
! 表示宏，不是普通函数（宏详见第 19 章）
字符串 "Hello, world!" 作为参数传给 println!
分号 ; 表示表达式结束

编译和运行是独立的步骤

编译

$ rustc main.rs
  • 类似 gcc / clang
  • 生成二进制可执行文件

编译后的文件

平台 文件
Linux / macOS main、main.rs
Windows (PowerShell) main.exe、main.pdb、main.rs
Windows (CMD) main.exe、main.pdb、main.rs
  • main.exe（或 main）— 可执行文件
  • main.pdb — 调试信息（仅 Windows）

运行

$ ./main          # Linux / macOS
$ .\main.exe      # Windows

Rust 是预编译语言

  • 预编译 (AOT)：先编译成可执行文件，分发后他人无需安装 Rust 即可运行
  • 与 Ruby、Python、JavaScript 不同：分发 .rb/.py/.js 需要对方安装对应运行环境
  • 代价：需单独执行编译步骤，不能“一条命令”直接运行源码

下一步

rustc 适合简单程序。项目变大后，需要更好的项目管理工具 → Cargo（见 1.3 Hello, Cargo!）

1.3

Hello, Cargo!

Cargo 是 Rust 的构建系统和包管理器，负责： - 构建代码 - 下载依赖库（dependency） - 编译依赖

官方安装包自带 Cargo。检查安装：$ cargo --version

使用 Cargo 创建项目

$ cargo new hello_cargo
$ cd hello_cargo

生成的项目结构

hello_cargo/
├── Cargo.toml    # 配置文件
├── src/
│   └── main.rs   # 源码
└── .gitignore    # Git 忽略文件（自动初始化 Git 仓库）

在已有 Git 仓库中运行 cargo new 不会生成 Git 相关文件。可加 --vcs=git 强制生成。

Cargo.toml

[package]
name = "hello_cargo"
version = "0.1.0"
edition = "2021"

[dependencies]
部分 说明
[package] 包配置
name 项目名称
version 版本号
edition Rust Edition（2015/2018/2021/2024）— 语法迁移，不是 Stable/Nightly；见 附录 E
[dependencies] 依赖的 crate 列表
  • 使用 TOML 格式
  • 代码包在 Rust 中称为 crate

项目结构约定

位置 用途
src/ 源代码
根目录 README、配置、许可协议等

Cargo 要求源码放在 src/ 中。

Cargo 命令

cargo build — 构建

$ cargo build
  • 生成可执行文件：target/debug/hello_cargo（Windows: hello_cargo.exe）
  • 首次运行会生成 Cargo.lock 记录依赖版本

cargo run — 构建并运行

$ cargo run
  • 一步完成编译和运行
  • 若源码未改动，直接运行已编译的可执行文件

cargo check — 快速检查

$ cargo check
  • 只检查能否编译，不生成可执行文件
  • 比 cargo build 更快
  • 适合开发时频繁检查

命令对比

命令 作用
cargo build 构建项目
cargo run 构建并运行
cargo check 只检查编译，不生成二进制

发布构建

$ cargo build --release
  • 输出目录：target/release/（而非 target/debug/）
  • 启用优化，运行更快
  • 编译时间更长
  • 基准测试时请使用 release 版本
配置 用途
target/debug/ 开发，快速编译
target/release/ 发布，优化性能

现有项目转 Cargo

  1. 将源码移到 src/ 目录
  2. 在根目录创建 Cargo.toml

克隆并构建已有项目

$ git clone example.org/someproject
$ cd someproject
$ cargo build

小结

  • rustup 安装 Rust
  • rustc 直接编译简单程序
  • Cargo 管理项目、依赖、构建
  • 跨平台命令统一，无需区分系统
