所有可能会用到模式的位置

模式 = 匹配 + 变量绑定 · 六处场景 · 哪些可反驳 → 18.2 §二

cd 00-Book/18-patterns/18.1-pattern-locations-demo
cargo run

核心结论（先背）

Rust 里凡能写变量、解构的地方都是模式，共 6 类场景：

# 场景 典型写法
1 match 分支 match v { P => … }
2 if let / else if let if let Some(x) = opt { … }
3 while let while let Some(x) = iter.next()
4 for 迭代头 for (i, x) in v.iter().enumerate()
5 let 声明 let (a, b) = (1, 2)
6 函数/闭包参数 fn f(&(x, y): &(i32, i32))

→ 可反驳 vs 不可反驳：18.2

一、match 分支

match VALUE {
    PATTERN => EXPRESSION,
    ...
}
  • 必须穷尽所有可能值；_ 匹配剩余且不绑定
  • 各分支可用可反驳模式；整体须覆盖全部情况

→ 6.2 match

二、if let / else if let

链式条件，不必写完整 match：

if let Some(color) = favorite_color {
    // ...
} else if let Ok(age) = age {
    if age > 30 { /* ... */ }
} else {
    // ...
}
要点 说明
可反驳 匹配失败走 else / 跳过
不穷尽 漏分支编译器不强制报错
作用域 if let 绑定变量仅块内有效

❌ if let Ok(age) = res && age > 18 —— 不能合并外部条件
✅ 拆成 if let Ok(age) = res { if age > 18 { … } }

三、while let 条件循环

while let Some(top) = stack.pop() {
    println!("{top}");
}

匹配成功 → 执行循环体；失败 → 退出循环。→ 13.2.2 §四

四、for 循环

for (index, value) in v.iter().enumerate() {
    println!("{index}: {value}");
}

注意：for 的模式必须是不可反驳的 —— 每一轮迭代都必须能绑定（for Some(x) in … 若迭代器可能产出 None 会编译失败）。
(i, x) 来自 enumerate 时总是 (usize, &T)，故不可反驳。

五、let 语句

let PATTERN = EXPRESSION;
let (x, y, z) = (1, 2, 3);
let (_, y) = (3, 4);

仅允许不可反驳模式（见 18.2 §三.1）。

六、函数参数 / 闭包参数

fn print_coordinates(&(x, y): &(i32, i32)) {
    println!("({x}, {y})");
}

参数位置 = 模式，规则同 let（不可反驳）。

18.2

可反驳性（Refutability）：模式是否会匹配失效

← 18.1 模式位置 · 18.3 模式语法 · demo：18.2-refutability-demo/

六处场景速查 → 18.1 · match 穷尽 → 6.2

cd 00-Book/18-patterns/18.2-refutability-demo
cargo run              # 完整整合 demo（六场景）
cargo run -- errors    # 可反驳/不可反驳对照说明
cargo test

核心结论（先背）

  1. 不可反驳（Irrefutable）：对所有可能值都能匹配 → 只能用于 let、函数/闭包参数、for。
  2. 可反驳（Refutable）：对某些值会匹配失败 → 用于 match 臂、if let、while let。
  3. let Some(x) = opt 编译失败；改用 if let / match。
  4. if let 绑定变量仅块内有效；不检查穷尽（与 match 不同）。

一、定义

类型 含义 例子
不可反驳 一定匹配成功 x、(a,b)、_、..
可反驳 可能失败 Some(x)（遇 None）、Ok(x)（遇 Err）、字面量 1

二、强制规则（编译器硬性要求）

使用位置 允许的模式 原因
let、函数/闭包参数、for 仅不可反驳 必须保证每轮/每次一定能绑定
match 臂 可反驳（整体须穷尽） 为「匹配/不匹配」设计
if let / while let 可反驳 失败走 else / 退出循环

易错：for 不是可反驳上下文 —— for Some(x) in iter 若 iter 含 None → refutable pattern in for loop binding。

三、分场景演示 + 易错点

1. let（仅不可反驳）

✅ 合法：

let x = 10;
let (a, b) = (1, 2);
let (_, y) = (3, 4);

❌ 编译失败：

// let Some(x) = Some(5);  // E0005: refutable pattern in local binding

✅ 替代：

let opt = Some(5);
if let Some(x) = opt {
    println!("{x}");
}

2. 函数参数（仅不可反驳）

✅ 合法：

fn print_pos(&(x, y): &(i32, i32)) {
    println!("x={x}, y={y}");
}

❌ 非法：

// fn bad(Some(val): Option<i32>) {}

3. match（可反驳 + 穷尽）

match num {
    Some(n) => println!("值：{n}"),
    None => println!("空值"),
}

必须写全分支或用 _ 兜底。

4. if let / else if let

let v: Option<i32> = None;
if let Some(1) = v {
    println!("1");
} else if let Some(2) = v {
    println!("2");
} else {
    println!("其他");
}

作用域陷阱：

let res: Result<i32, &str> = Ok(20);
// if let Ok(age) = res && age > 18 { }  // ❌ age 不能这样用

if let Ok(age) = res {
    if age > 18 {
        println!("成年");
    }
}

无意义警告：if let x = 5 → irrefutable_let_patterns（应直接用 let）。

5. while let（可反驳）

let mut stack = vec![1, 2, 3];
while let Some(val) = stack.pop() {
    println!("出栈：{val}");
}
// 3 → 2 → 1，None 时退出

6. for（不可反驳，但可解构）

for (idx, item) in v.iter().enumerate() {
    println!("{idx}: {item}");
}

解构 (usize, &T) 总是成功；不能写 for Some(x) in options（除非类型保证永无 None）。

四、忽略语法（_ / ..）

语法 作用
_ 忽略单个值，不绑定
.. 忽略连续多个字段/元组元素 
let (x, _) = (10, 20);
let (a, ..) = (1, 2, 3, 4);
let (.., d) = (1, 2, 3, 4);

→ 更多语法：18.3

五、速记（背诵版）

  1. 六处都是模式：match / if let / while let / for / let / 参数。
  2. 不可反驳 → let、参数、for。
  3. 可反驳 → match 臂、if let、while let。
  4. if let 变量块内有效；不与 && 混写外部条件。
  5. match 穷尽；if let 链不穷尽。

六、整体脉络

绑定一定成功？  →  let / fn 参数 / for  →  不可反驳
允许匹配失败？  →  if let / while let / match  →  可反驳（match 还须穷尽）
枚举部分分支？  →  禁止 let Some(x) = opt  →  if let / match

18.3

模式语法

核心结论（先背）

模式可用于 match、if let、while let、for、let、函数参数等（→ 18.1）。

语法 作用
字面量 匹配固定常量
A \| B 多模式，满足其一
a..=b 闭区间（仅整数/字符）
解构 拆分结构体/枚举/元组/嵌套
_ 忽略、不绑定、不转移所有权
_var 绑定、转移所有权、消警告
.. 忽略剩余（元组只能一个 ..）
if 条件 匹配守卫
var @ 模式 校验 + 绑定二合一

一、字面量模式

直接匹配固定常量：整数、字符、字符串、布尔值等。

match num {
    1 => println!("1"),
    2 => println!("2"),
    _ => println!("其他"),
}

match c {
    'a' => println!("a"),
    'b' => println!("b"),
    _ => (),
}

二、match 中的变量与遮蔽

match 每个分支是独立作用域；模式中绑定的变量会遮蔽外层同名变量。

let y = 10;
let opt = Some(10);

match opt {
    Some(y) => println!("内部 y: {y}"),  // 新绑定，遮蔽外层 y
    None => (),
}
println!("外层 y: {y}");  // 仍是 10

想引用外层变量 → 不能写同名绑定，须用匹配守卫（§七）或换名（如 Some(n)）。

三、多模式 |

模式1 | 模式2 | 模式3 — 满足任意一个即可匹配。

match n {
    1 | 2 | 3 => println!("1/2/3"),
    4 | 5 => println!("4/5"),
    _ => println!("其他"),
}

四、范围模式 ..=（闭区间）

起始..=结束 — 闭区间，包含两端。

支持 不支持
整数、char 浮点数、字符串 
match age {
    0..=18 => println!("未成年"),
    19..=60 => println!("成年"),
    _ => println!("长者"),
}

match ch {
    'a'..='z' => println!("小写"),
    'A'..='Z' => println!("大写"),
    _ => (),
}

五、解构模式

5.1 元组

let (a, b) = (10, 20);

match t {
    (0, y) => println!("第一为 0，第二 {y}"),
    (x, 20) => println!("第二为 20，第一 {x}"),
    _ => (),
}

5.2 结构体

  • 简写：let Point { x, y } = p;
  • 重命名：let Point { x: a, y: b } = p;
  • 字面量约束字段：Point { x: 0, y }
match p {
    Point { x: 0, y } => println!("x=0, y={y}"),
    Point { x, y: 0 } => println!("y=0, x={x}"),
    _ => (),
}

5.3 枚举

变体形状须与定义完全一致（单元 / 元组 / 结构体变体）。

match c {
    Color::Rgb(r, g, b) => println!("{r} {g} {b}"),
    Color::Hsv(h, s, v) => println!("{h} {s} {v}"),
    Color::Black => println!("黑"),
}

5.4 嵌套解构

match msg {
    Msg::ChangeColor(Color::Hsv(h, s, v)) => println!("{h} {s} {v}"),
    _ => (),
}

5.5 混合解构

let ((feet, inches), Point { x, y }) = ((3, 10), Point { x: 3, y: -10 });

六、忽略值：_ / _var / ..

6.1 _ — 不绑定、不转移所有权

let s = Some(String::from("hello"));
if let Some(_) = s {
    println!("匹配");
}
println!("{s:?}");  // s 仍可用

fn calc(_: i32, b: i32) -> i32 { b * 2 }

6.2 _x — 绑定、转移所有权

let s = Some(String::from("hello"));
if let Some(_s) = s {  // String 被移入 _s
    println!("匹配");
}
// println!("{s:?}");  // E0382: borrow of moved value
_ _var
绑定 否 是
所有权 不转移 转移
用途 通配/忽略 消未使用警告

6.3 .. — 忽略剩余

let Person { name, .. } = p;       // 结构体：忽略其余字段
let (first, .., last) = t;         // 元组：忽略中间
// let (.., mid, ..) = t;           // E0425: 只能一个 ..

七、匹配守卫 if

写在模式后：模式 if 条件 =>

用途：

  1. 同一种模式下追加布尔判断
  2. 引用外层变量（避免遮蔽）
  3. 与 \| 组合 — 守卫对整个多模式组生效
let y = 5;
match opt {
    Some(n) if n == y => println!("等于外层 y"),  // 用守卫，不用 Some(y)
    Some(n) => println!("{n}"),
    None => (),
}

match num {
    1 | 2 | 3 if flag => println!("1/2/3 且 flag"),  // 守卫作用于整组
    _ => (),
}

八、@ 绑定

变量 @ 模式 — 先校验模式，同时绑定值。

match n {
    id @ 3..=7 => println!("{id} 在 3~7"),
    _ => (),
}

match s {
    Status::Code(val @ 200..=299) => println!("正常: {val}"),
    _ => (),
}

九、高频易错点 & 编译报错

# 易错 说明 / 报错
1 变量遮蔽 Some(y) 内 y 是新变量；引用外层用守卫 if n == y
2 _ vs _x _ 不转移所有权；_x 会 move → E0382
3 两个 .. 元组模式只能一个 .. → E0425
4 浮点范围 1.0..=5.0 非法；仅整数/char
5 守卫 + \| 1 \| 2 \| 3 if flag 守卫作用于整组
6 解构形状 枚举变体须与定义一致，否则 E0023
7 match 穷尽 未覆盖所有情况 → E0004（用 _ 兜底）
