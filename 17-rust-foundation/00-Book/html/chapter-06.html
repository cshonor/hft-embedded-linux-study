一、枚举核心概念

enum：一个变量同一时刻只能是枚举中某一个成员（变体 variant） — 用来归类有限的可选种类（IP 只有 V4/V6、消息只有退出/移动/写入/改色）。

1. 最简无数据枚举（单元变体）

enum IpAddrKind {
    V4,
    V6,
}

let four = IpAddrKind::V4;
let six = IpAddrKind::V6;

成员在枚举命名空间内，用 :: 构造/访问。

2. 老式写法：枚举 + 结构体拆分（不推荐）

enum IpAddrKind { V4, V6 }

struct IpAddr {
    kind: IpAddrKind,
    address: String,
}

let ip = IpAddr {
    kind: IpAddrKind::V4,
    address: String::from("127.0.0.1"),
};

缺点：类型与数据拆开，啰嗦 → Rust 推荐把数据直接绑在变体上。

二、四种变体格式（Rust 枚举灵魂）

单个 enum 内，每个变体可以是不同形态 — 与 C/C++ 枚举最大区别：

enum Message {
    Quit,                        // ① 单元变体：无数据
    Move { x: i32, y: i32 },     // ② 结构体变体：命名字段
    Write(String),               // ③ 单元素元组变体
    ChangeColor(u8, u8, u8),     // ④ 多元素元组变体
}

let m1 = Message::Quit;
let m2 = Message::Move { x: 10, y: 20 };
let m3 = Message::Write(String::from("hello"));
let m4 = Message::ChangeColor(255, 0, 0);

Message 四种变体完整详解（4 种形态全覆盖）

Quit / Move / Write / ChangeColor = 变体标签（区分种类）；括号/大括号里 = 该分支实际携带的值。

# 变体 形态 构造示例
① Quit 单元变体：无括号、无数据 Message::Quit
② Move { x, y } 结构体变体：大括号、命名字段 Message::Move { x: 10, y: 20 }
③ Write(String) 单元素元组变体：小括号、1 个类型 Message::Write(String::from("你好"))
④ ChangeColor(u8,u8,u8) 多元素元组变体：小括号、按顺序 Message::ChangeColor(255, 0, 0)

① Quit — 只是分类标记，不捆绑数据；适用：退出指令等无需附带信息的场景。

② Move { x, y } — 大括号 = 命名字段，和 struct 一样，靠字段名不靠顺序；可读性强，适合多参数。

③ Write(String) — Write 是标签，括号里字符串是正文数据。

④ ChangeColor(r,g,b) — 3 个 u8 按顺序对应 RGB，无字段名。

IpAddr 同理：V4 / V6 是标签；(127,0,0,1) / String 是具体值。

配套 match 取标签内的值 → 6.2 match：

match msg {
    Message::Quit => println!("退出"),
    Message::Move { x, y } => println!("移动坐标：{} {}", x, y),
    Message::Write(s) => println!("消息内容：{}", s),
    Message::ChangeColor(r, g, b) => println!("颜色：{} {} {}", r, g, b),
}

IP 进阶：变体绑定不同类型

enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}

let localhost = IpAddr::V4(127, 0, 0, 1);

元组变体 () 详解：括号里每一项都是独立类型

变体后面小括号 = 元组结构；括号里 N 个类型 = 这个变体必须携带 N 个对应类型的数据。

V4(u8, u8, u8, u8) — 四个独立 u8

  1. 四个 u8 对应 IPv4 四段：192.168.1.1
  2. 实例化：IpAddr::V4(192, 168, 1, 1) — 四个数按顺序填入四个位置
  3. 本质：元组式绑定，一个 V4 变体身上捆 4 个值

V6(String) — 单个 String

只存一串文本 IP：IpAddr::V6(String::from("::1"))

括号里多种、多个不同类型

struct User { name: String }
struct Point { x: i32, y: i32 }

enum Test {
    Item1(u8, i32, String),  // 3 个不同类型，按顺序传
    Item2(User, Point),      // 2 个完整结构体
}

Test::Item1(1, 42, String::from("hi"));
Test::Item2(
    User { name: String::from("张三") },
    Point { x: 10, y: 20 },
);
变体 含义
Item1(a, b, c) 固定绑定 3 个数据：u8 + i32 + String
Item2(user, point) 捆绑 两个完整 struct

括号里可以是 u8、String、自定义 struct 等任意类型。

() 元组 vs {} 结构体变体

小括号 () 大括号 {}
字段 无名，靠顺序取值 有名，靠字段名取值
例子 V4(u8, u8, u8, u8) Move { x: i32, y: i32 }
构造 V4(192, 168, 1, 1) Move { x: 10, y: 20 }

标准库 std::net::IpAddr（工业级写法）

变体直接嵌套现成结构体：

enum IpAddr {
    V4(Ipv4Addr),
    V6(Ipv6Addr),
}

use std::net::{IpAddr, Ipv4Addr};

let ip: IpAddr = IpAddr::V4(Ipv4Addr::new(127, 0, 0, 1));
// Ipv4Addr 自带 is_loopback()、parse() 等

三、枚举可以 impl 写方法（和 struct 一样）

impl Message {
    fn call(&self) {
        println!("执行消息逻辑");
    }
}

let msg = Message::Quit;
msg.call();

四、标准库 Option<T>（Rust 无 null）

源码（内置泛型枚举）

enum Option<T> {
    Some(T),
    None,
}

使用规则

  1. Option<T> 与 T 是两种完全不同类型，不能混用；
  2. Rust 强制处理 None，杜绝空指针式崩溃。
let num: Option<i32> = Some(5);
let empty: Option<i32> = None; // None 须能推断 T

常用方法（提前记）

方法 作用
is_some() / is_none() 判断 Some / None
unwrap() 取内部值；None 则 panic（生产慎用）
unwrap_or(default) None 返回默认值，Some 返回原值

五、下一节：match 匹配

枚举取值常用 match，按变体分支并解构内部数据：

match msg {
    Message::Quit => println!("退出"),
    Message::Move { x, y } => println!("坐标 {} {}", x, y),
    Message::Write(s) => println!("{}", s),
    Message::ChangeColor(r, g, b) => println!("rgb {} {} {}", r, g, b),
}

→ 6.2 match

精简口诀

  1. 裸枚举：enum 名 { A, B }，:: 取成员
  2. 带数据：无数据 / 结构体 {} / 单值 () / 多值 () 四类变体
  3. 枚举能 impl 方法
  4. Option = Some(T) / None，替代 null

cargo run

6.1

.2 枚举类型 vs 变体标签

← 主笔记：6.1 定义枚举 · 四种变体 → Message 详解 · match → 6.2

对应 demo：6.1-enums-demo/ · 预期编译失败：compile_fail/variant_not_a_type.rs

一句话

变量的类型永远是外层枚举名（如 IpAddr）；V4/V6 只是变体标签，不能用来标注变量类型。

let ip: IpAddr = IpAddr::V4(192, 168, 1, 1); // ✅

// let ip: V4 = IpAddr::V4(192, 168, 1, 1);  // ❌ E0412：V4 不是类型

一、三点拆分（对标 Option）

1. 变量类型永远 = 枚举本名

enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
    Unknown,
}

let a: IpAddr = IpAddr::V4(127, 0, 0, 1);
let b: IpAddr = IpAddr::V6("::1".into());
let c: IpAddr = IpAddr::Unknown;
// 左边统一是 IpAddr，不管右边哪个变体

对标 Option<T>

let x: Option<i32> = Some(5);  // 类型 Option<i32>，不是 Some
let y: Option<i32> = None;       // 类型 Option<i32>，不是 None

V4/V6 ≈ Some；Unknown ≈ None — 全是变体构造器/标签，不是类型。

2. IpAddr::V4(数值) 是什么？

IpAddr::V4 = 构造器：用 V4 标签 + 括号数据，生成一个 IpAddr 实例。

角色
IpAddr 大类型（整体箱子）
V4 分类标签 + 携带括号内数据

类比：Option::Some(5) → 产出 Option<i32> 的值。

3. 不能把 V4 单独当类型

Rust 没有「把枚举变体拆成独立类型」的语法。要取 V4 里的数据，只能 match 解构：

match a {
    IpAddr::V4(n1, n2, n3, n4) => println!("{}", n1),
    IpAddr::V6(s) => println!("{}", s),
    IpAddr::Unknown => {}
}

二、为什么 Some 可省略 Option::，V4 必须写 IpAddr::？

原因
Some / None 标准库 prelude 预导入 use Option::{Some, None}，全局可用
V4 / V6 自定义 enum，无自动导入，须全称 IpAddr::V4

手动导入后可省略前缀：

use IpAddr::{V4, V6, Unknown};

let ip: IpAddr = V4(192, 168, 1, 1); // 等价 IpAddr::V4(...)

三、总结

# 规则
1 标注变量类型：永远写外层枚举（Option<i32> / IpAddr）
2 Some、None、V4、V6：变体标签，不能当类型写在冒号后
3 Some(5) / V4(1,2,3,4)：构造实例；产物类型是外层 enum

6.1

.3 取出枚举内部数据（四种方式）

← 6.1.2 类型 vs 标签 · match → 6.2 · if let → 6.3

对应 demo：6.1-enums-demo/（§7 取值 + MyOption 自实现 unwrap）

先敲定：标签 vs 内部数据

# 规则
1 变量类型 = 外层枚举：Option<i32> / IpAddr
2 Some、None、V4、V6 = 分类标签，本身不是业务数据
3 Some(内部值)：标签 + 一份数据；None：只有标签、无数据
4 业务最终用的是括号/大括号里的内部数据；标签只用来区分「有没有 / 是哪种」 
let num: Option<i32> = Some(99);
// Some 是标签，99 才是要用的数字

四种取出方式（Option · IpAddr 通用）

对照例子：

  • 例 1：Option<i32> = Some(10)
  • 例 2：IpAddr = IpAddr::V4(192, 168, 1, 2)

方式 1：match — 最标准、最安全（首选）

靠标签分支，解构掏出内部数据：

let opt = Some(10);
match opt {
    Some(x) => println!("取出：{}", x),
    None => println!("没有数据"),
}

let ip = IpAddr::V4(192, 168, 1, 2);
match ip {
    IpAddr::V4(a, b, c, d) => println!("{}.{}.{}.{}", a, b, c, d),
    IpAddr::V6(s) => println!("ipv6: {}", s),
    IpAddr::Unknown => println!("无 ip"),
}

匹配到标签时，自动把变体绑定的数据绑定到新变量。

→ 详解 6.2 match

方式 2：if let — 只关心一个变体

if let Some(val) = Some(10) {
    println!("{}", val);
}

if let IpAddr::V4(w, x, y, z) = ip {
    println!("{}", w);
}

→ 详解 6.3 if let

方式 3：Option 专属 — unwrap / unwrap_or

仅标准库 Option 内置；自定义 enum 需自己 impl（见 demo MyOption）。

Some(5).unwrap();              // 取出 5；None 则 panic
None::<i32>.unwrap_or(0);      // None → 0，安全

⚠️ unwrap 底层本质就是 match。

方式 4：let else（Rust 1.65+）

let Some(data) = Some(88) else { return; };
println!("{}", data);

等价于：

let data = match Some(88) {
    Some(v) => v,
    None => return,
};

关键总结

  1. 标签作用：分类判断 — Some/V4 有内嵌数据可提取；None/Unknown 无数据可取
  2. 取值本质：解构 — 匹配标签，剥离枚举外壳，拿到内部原始数据
  3. Option 只是标准库预装 enum，与手写 IpAddr 机制完全一致

自定义 enum 仿 unwrap（IpAddr 示例）

标准库不给 IpAddr 配 unwrap，只能自己封装：

fn get_v4(ip: IpAddr) -> (u8, u8, u8, u8) {
    match ip {
        IpAddr::V4(a, b, c, d) => (a, b, c, d),
        _ => panic!("不是 ipv4"),
    }
}

与 Option::unwrap() 思路一模一样。

6.2

match 控制流运算符

对应 demo 项目：00-Book/06-enums-pattern-matching/6.2-match-demo/

match 会把一个值与一系列模式（pattern）比较，执行第一个匹配成功的分支。Rust 会在编译期检查 match 必须穷尽（exhaustive）：所有可能情况都要处理。

基本结构

match value {
    pattern1 => expr1,
    pattern2 => expr2,
    // ...
}
  • match 后面是一个表达式（不要求是 bool，和 if 不同）
  • 每个分支用 => 连接「模式」与「要执行的表达式」
  • 分支之间用逗号分隔
  • 分支代码多行时可用 { ... }

枚举 + match：硬币示例

enum Coin { Penny, Nickel, Dime, Quarter }

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
    }
}

分支里执行多行代码

Coin::Penny => {
    println!("Lucky penny!");
    1
}

绑定值的模式（从成员里取数据）

enum Coin {
    Quarter(UsState),
    // ...
}

match coin {
    Coin::Quarter(state) => {
        println!("State quarter from {:?}!", state);
        25
    }
    // ...
}

state 会绑定到 Quarter(...) 内部的值。

匹配 Option

fn plus_one(x: Option<i32>) -> Option<i32> {
    match x {
        None => None,
        Some(i) => Some(i + 1),
    }
}

match 必须穷尽

match x {
    Some(i) => Some(i + 1),
    // ❌ 少了 None 分支会报错：non-exhaustive patterns
}

通配模式与 _

使用变量接住“其他情况”

match dice_roll {
    3 => add_fancy_hat(),
    7 => remove_fancy_hat(),
    other => move_player(other),
}

不需要值时用 _

match dice_roll {
    3 => add_fancy_hat(),
    7 => remove_fancy_hat(),
    _ => reroll(),
}

也可以什么都不做：_ => ()

6.3

if let 简单控制流

对应 demo 项目：00-Book/06-enums-pattern-matching/6.3-if-let-demo/

if let 是 match 的语法糖：当你只关心匹配某一个模式时，用更少的样板代码完成同样的事。

用 match 只关心一个分支（会显得啰嗦）

let some_u8_value = Some(0u8);
match some_u8_value {
    Some(3) => println!("three"),
    _ => (),
}

为了满足 match 的穷尽性，必须写 _ => ()。

用 if let（更简洁）

let some_u8_value = Some(0u8);
if let Some(3) = some_u8_value {
    println!("three");
}

语法：if let PATTERN = EXPR { ... }

权衡： - 优点：更短、更少缩进、更少样板代码 - 缺点：不像 match 那样强制穷尽性检查

if let + else

else 相当于 match 的 _ 分支。

以硬币为例：对 Quarter 打印州名，否则计数：

let mut count = 0;
if let Coin::Quarter(state) = coin {
    println!("State quarter from {:?}!", state);
} else {
    count += 1;
}

小结

  • match：强制穷尽，适合要处理多种情况
  • if let：只处理一种情况时更简洁
