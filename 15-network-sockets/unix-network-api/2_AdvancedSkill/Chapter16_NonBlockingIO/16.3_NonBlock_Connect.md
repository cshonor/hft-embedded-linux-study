# 16.3 非阻塞 connect

> [Ch 4.3 connect](../../1_BasicFoundation/Chapter04_BasicTCPSocket/4.3_Connect_Function.md) · [14.2 select 超时](../Chapter14_AdvancedIO_Func/14.2_Socket_Timeout_Set.md)

---

## 核心主旨

非阻塞 `connect` → 立即 **EINPROGRESS**，握手在**内核后台**进行。

---

## 三大优势

| # | 能力 |
|---|------|
| 1 | **重叠处理**：RTT 等待期间可做其他计算 |
| 2 | **并发连接**：单线程同时发起大量 connect（浏览器、爬虫） |
| 3 | **精准超时**：用 `select` 等待，短于默认 ~75s |

---

## 完成后 select 行为

| 结果 | 套接字在 select 中 |
|------|-------------------|
| **成功** | **可写** |
| **失败**（拒绝、超时等） | **可读且可写**，并有 **pending error** |

---

## 易错细节

**不能**仅凭「可写」断定成功 — 失败时也可能唤醒写集（见 16.4 **`getsockopt(SO_ERROR)`**）。
