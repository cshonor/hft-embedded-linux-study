# 5.16 服务器主机关机

> 等同进程终止表现：[5.12](../5.12_Server_Process_Abort.md)

---

## 核心主旨与关键论据

Unix **正常关机**时，`init` 会清理用户进程：先 **`SIGTERM`** 给进程机会优雅退出，超时则 **`SIGKILL`**。服务器进程被终止 → 内核关闭其套接字 → 向仍连接的客户发 **FIN** —— 对客户侧表现与 **5.12 服务器进程终止** 同类。

---

## 核心机制

| 阶段 | 信号/行为 |
|------|-----------|
| 1 | 向用户进程发 **`SIGTERM`**（可捕获，做清理） |
| 2 | 未退出则 **`SIGKILL`**（不可忽略，强杀） |
| 3 | 进程消失 → 所有 fd 关闭 → TCP **FIN** |

---

## 逻辑脉络

```text
关机 → 服务器进程死 → FIN 到客户
→ 若客户阻塞 fgets：仍可能延迟感知（同 5.12）
→ 用户输入后 writen/readline 才退出
```

---

## 易错细节与重点结论

| 对比 | 关机 | 崩溃（5.14） |
|------|------|----------------|
| 发 FIN？ | **有**（正常终止路径） | 通常无 |
| 客户感知 | 类似 5.12 | 超时为主 |
