# 5.14 服务器主机崩溃

> [5.15 重启](../5.15_Server_Host_Restart.md) · keepalive：Ch 7

---

## 核心主旨与关键论据

与 **5.12 进程崩溃**（内核还能发 FIN）不同：**整机断电、拔网线** 时，连接变成**黑洞** —— 无 FIN、无 RST，客户可能**长时间无感知**。

---

## 故障演进

| 阶段 | 行为 |
|------|------|
| 1 | 客户 **`write`** 发出数据 |
| 2 | 无 ACK → TCP **指数退避重传** SYN 段上的数据或后续段 |
| 3 | 重传多次后放弃（如总计约 **9 分钟** 量级，依实现） |
| 4 | 应用层 `write`/`read` 最终失败 |

### 应用层错误码

| 情况 | 典型 errno |
|------|------------|
| 一直重传无 ICMP | **`ETIMEDOUT`** |
| 中间路由器 ICMP 目的不可达 | **`EHOSTUNREACH`** / **`ENETUNREACH`** |

---

## 盲区陷阱

- 客户**一直不发数据**（一直阻塞 `fgets`）→ 可能**永远不知道**主机已死  
- 对策：**`SO_KEEPALIVE`**（Ch 7）或应用层 **心跳（Heartbeat）** 定时写/读探测

---

## 易错细节与重点结论

| 对比 | 5.12 进程死 | 5.14 主机死 |
|------|-------------|-------------|
| 内核发 FIN？ | 通常 **有** | **无** |
| 感知速度 | 下次 I/O 可能较快 | 可能 **分钟级** 超时 |
| 客户阻塞 fgets | 仍不知 | 仍不知 |
