# 1.8 BSD 网络支持历史

## 核心知识点

加州大学伯克利 **BSD** 推动 TCP/IP 协议栈与 **Sockets API** 的普及与演进。

## 关键时间线（图 1-15）

| 年份 | 版本 | 里程碑 |
|------|------|--------|
| **1983** | 4.2BSD | 首个广泛可用的 TCP/IP + 套接字 API |
| **1988** | 4.3BSD Tahoe | TCP 慢启动、拥塞避免、快速重传 |
| **1990** | 4.3BSD Reno | TCP 快速恢复、首部预测；`sockaddr` 增加**长度字段** |
| **1994** | 4.4BSD-Lite | 本书常引用的底座；衍生 FreeBSD / NetBSD / OpenBSD |

**Unix 分支**：Solaris、HP-UX 等商用 Unix 的网络实现多可追溯到伯克利代码库。

## 个人学习总结

> 💡 可拓展：Linux 网络栈与早期 BSD 栈的架构差异。
