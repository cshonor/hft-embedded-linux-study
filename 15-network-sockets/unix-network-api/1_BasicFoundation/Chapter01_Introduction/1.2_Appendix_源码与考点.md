## 一、完整源码（书中逻辑）

```c
#include    "unp.h"

int main(int argc, char **argv)
{
    int                 sockfd, n;
    char                recvline[MAXLINE + 1];
    struct sockaddr_in  servaddr;

    if (argc != 2)
        err_quit("usage: a.out <IPaddress>");

    if ((sockfd = socket(AF_INET, SOCK_STREAM, 0)) < 0)
        err_sys("socket error");

    bzero(&servaddr, sizeof(servaddr));
    servaddr.sin_family = AF_INET;
    servaddr.sin_port   = htons(13);
    if (inet_pton(AF_INET, argv[1], &servaddr.sin_addr) <= 0)
        err_quit("inet_pton error for %s", argv[1]);

    if (connect(sockfd, (SA *) &servaddr, sizeof(servaddr)) < 0)
        err_sys("connect error");

    while ((n = read(sockfd, recvline, MAXLINE)) > 0) {
        recvline[n] = 0;
        if (fputs(recvline, stdout) == EOF)
            err_sys("fputs error");
    }
    if (n < 0)
        err_sys("read error");

    exit(0);
}
```

## 二、逐行 ↔ 五步法

| 行 | 代码 | 五步法 / 要点 |
|----|------|----------------|
| 入参 | `argc != 2` | 必须 **argv[1]=IP** → [附录·argc](./1.2_Appendix_C新手与字节序.md#ch1-2-faq) |
| ① | `socket(AF_INET, SOCK_STREAM, 0)` | 创建 IPv4 TCP → [socket 三参数](./1.2_SimpleTimeClient.md#ch1-2-socket) |
| ② | `bzero` + `sin_*` + `htons(13)` + `inet_pton` | **sin_addr=IP，sin_port=端口** → [主笔记表](./1.2_SimpleTimeClient.md#ch1-2-flow) |
| ③ | `connect(..., (SA*)...)` | 三次握手 → [API 精读·connect](./1.2_Appendix_API精读.md#ch1-2-connect) |
| ④ | `while (read > 0)` + `recvline[n]=0` | 流式循环读 → [API 精读·read](./1.2_Appendix_API精读.md#ch1-2-read) |
| ⑤ | `exit(0)` | 进程结束关 fd；生产建议显式 `close(sockfd)` |

## 三、运行时序（一条线）

```text
argv[1] IP → socket → 填 servaddr(IP+13) → connect → while read 打印 → read=0 → exit
```

## 四、编译运行

```bash
gcc daytimetcpcli.c -o daytimetcpcli unp.a   # 需 unp.h / libunp
./daytimetcpcli 127.0.0.1
```

Linux：`systemctl start daytime.socket`。Windows：WSL 或 [1.5 服务端](./1.5_SimpleTimeServer.md)。
