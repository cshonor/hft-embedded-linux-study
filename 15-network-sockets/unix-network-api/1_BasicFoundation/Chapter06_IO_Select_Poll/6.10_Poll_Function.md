# 6.10 poll 函数

---

## 核心主旨

System V **`poll`**：功能类似 `select`，接口更现代，规避位图与 **1024** 硬上限。

```c
int poll(struct pollfd *fdarray, unsigned long nfds, int timeout);
```

```c
struct pollfd {
    int   fd;       /* 待检查描述符 */
    short events;   /* 关心的事件（输入） */
    short revents;  /* 实际发生（内核填） */
};
```

| 返回值 | 含义 |
|--------|------|
| > 0 | 就绪数 |
| 0 | 超时 |
| -1 | 错误 |

---

## 核心事件宏

| 宏 | 用途 |
|----|------|
| **POLLIN** | 普通/优先级数据可读 |
| **POLLRDNORM** | 普通数据可读 |
| **POLLOUT** / **POLLWRNORM** | 可写 |
| **POLLERR** | 错误 |
| **POLLHUP** | 挂起 / 半关闭 |
| **POLLNVAL** | fd 无效 |

---

## 与 select 的三大优势

| # | poll | select |
|---|------|--------|
| **1** | **无 FD_SETSIZE 天花板**（数组大小由 `nfds` 决定） | 常限 1024 |
| **2** | **`events` / `revents` 分离** — 不必每轮重建整个位图 | 返回覆盖 fd_set |
| **3** | **`fd == -1` 自动忽略** — 踢掉连接只需置 -1 | 须 FD_CLR + 维护 maxfd |

---

## 易错细节与重点结论

- `timeout`：**毫秒**；**-1** 永久等  
- `revents` 须与 **POLLERR | POLLHUP** 等一起处理错误断开  
- 仍可能 **O(nfds)** 扫描 — 高并发用 epoll
