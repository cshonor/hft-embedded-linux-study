# 6.11 TCP 回射服务器程序（再修订版）

> [6.8 select 服务器](../6.8_TCP_Server_Revised.md) · [6.10 poll](../6.10_Poll_Function.md)

---

## 核心主旨

将 6.8 的 **select 单进程服务器** 改写为 **`poll`**，体验更清晰的数组管理与无 1024 限制。

---

## 架构要点

| 项 | 做法 |
|----|------|
| **数组** | `struct pollfd client[OPEN_MAX]` 替代 `client[]` + `fd_set` |
| **监听槽** | `client[0].fd = listenfd`，`events = POLLRDNORM` |
| **空闲槽** | `fd = -1`（poll 自动忽略） |

---

## 工作流

```text
1. poll(client, nfds, -1) 阻塞
2. client[0].revents & POLLRDNORM → accept → 填入第一个 fd==-1 的槽
3. 遍历 i>=1：
     revents & (POLLRDNORM | POLLERR) → read
       n>0  → writen
       n==0 → close；client[i].fd = -1
```

### 与 select 版对比

| 操作 | select 版 | poll 版 |
|------|-----------|---------|
| 踢连接 | close + client[i]=-1 + 下次 FD_ZERO/SET | **fd=-1** 即可 |
| 监听 listen | 每次 FD_SET(listenfd) | client[0] 固定 |

---

## 易错细节

- 与 6.8 相同：**阻塞 read** → DoS 挂死全进程 → 须 **非阻塞**（Ch 16）  
- `nfds` 应覆盖**实际使用的最大下标+1**
