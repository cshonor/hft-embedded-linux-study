# 2.13 常见因特网应用的协议使用

## 核心知识点

应用层按业务需求选择传输层协议。

## 对照表

| 传输层 | 典型应用 |
|--------|----------|
| **ICMP** | `ping`、`traceroute`（部分实现也用 UDP） |
| **UDP** | **DNS**（常 UDP，长报文 TCP）、**DHCP/BOOTP**（须广播）、**NTP**、**TFTP**（应用层重传）、**SNMP** |
| **TCP** | **HTTP**、**SMTP**、**SSH/Telnet**、**FTP** |

## 选型逻辑

| 需求 | 倾向 |
|------|------|
| 低延迟、广播、简单请求 | UDP |
| 可靠字节流、不容丢字节 | TCP |
