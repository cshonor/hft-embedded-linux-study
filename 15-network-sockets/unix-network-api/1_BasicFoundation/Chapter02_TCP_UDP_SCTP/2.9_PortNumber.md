# 2.9 端口号

> 并发分路：[2.10](../2.10_TCP_Port_ConcurrentServer.md)

## 核心知识点

传输层用 **16 位端口号**区分同机不同应用进程。

## IANA 三段划分

| 范围 | 名称 | 说明 |
|------|------|------|
| **0～1023** | 众所周知端口 | HTTP 80、FTP 21 等；Unix 绑定常需 **root**（**保留端口**） |
| **1024～49151** | 已登记端口 | 非系统级应用 |
| **49152～65535** | 动态/私用端口 | **临时端口（ephemeral）**；客户端常由内核随机分配 |

## 套接字对（Socket Pair）

- TCP 连接由 **4 元组**唯一确定：`{本地 IP, 本地端口, 远端 IP, 远端端口}`  
- 每端 **(IP, 端口)** 称为一个 **套接字（socket）**
