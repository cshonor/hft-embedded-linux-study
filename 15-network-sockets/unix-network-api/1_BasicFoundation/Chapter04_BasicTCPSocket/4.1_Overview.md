## 核心主旨与关键论据

本章系统讲解编写**完整 TCP 客户/服务器**所需的基础套接字 API：从 **`socket`** 开始，沿时间线覆盖客户 **`connect`**、服务器 **`bind` → `listen` → `accept`**，并引入 **`fork` 并发**模型。

---

## 逻辑脉络与时间线

### 客户程序生命周期

```text
socket → connect（三次握手）→ 数据读写 → close（四次挥手）
```

### 服务器程序生命周期

```text
socket → bind（绑定知名端口）→ listen（被动监听）
→ accept（取已连接套接字）→ 读写 → close
```

### 与 Ch 5 的关系

- Ch 4：**API 语义与机制**（本 chapter）  
- Ch 5：用 Echo **组合 API** + **健壮性/信号/异常**  

---

## 核心知识点

| API | 角色 |
|-----|------|
| `socket` | 创建端点 |
| `connect` | 客户主动建连 |
| `bind` | 服务器注册本地地址 |
| `listen` | 转监听套接字 + backlog |
| `accept` | 取已完成连接 |
| `fork` | 并发派生子进程 |
| `close` | 减引用计数，可能触发 FIN |
