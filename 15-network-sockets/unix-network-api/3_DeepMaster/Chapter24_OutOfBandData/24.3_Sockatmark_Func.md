# 24.3 sockatmark 函数

> [17.3 SIOCATMARK](../Chapter17_Ioctl_Operate/17.3_Socket_Ioctl_Operate.md) · [24.2](../24.2_TCP_OutOfBand_Data.md)

---

## 核心主旨

`SO_OOBINLINE=1` 时，须判断读指针是否到达**带外标记**处。

```c
int sockatmark(int sockfd);
```

| 返回值 | 含义 |
|--------|------|
| **1** | 下一字节为带外数据 / 正处于标记 |
| **0** | 否 |
| **-1** | 错误 |

POSIX 替代 **`ioctl(SIOCATMARK)`**。

---

## 字节流与标记

- URG 头先到即可触发 **SIGURG** / **select 异常**（数据体未到）  
- 读到标记前：**`read` 不跨越标记** — 即使请求 1024 字节，标记在第 5 字节则**短读 5**  
- 越过标记后才能读后续普通数据
