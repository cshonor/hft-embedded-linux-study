## 命令（套接字与普通 fd 均可）

| 命令 | 作用 |
|------|------|
| **`FIONBIO`** | arg 指向 int：0 清除 / 非 0 设置 **非阻塞** |
| **`FIOASYNC`** | 设置/清除 **信号驱动 I/O**（`O_ASYNC`） |
| **`FIONREAD`** | arg 指向 int：返回接收缓冲区**排队未读字节数** |

---

## 对比结论

| | `ioctl(FIONBIO)` | `fcntl(O_NONBLOCK)` |
|--|------------------|---------------------|
| 调用次数 | **一次** | 常需 GET 再 SET |
| POSIX | 不推荐 | **规范要求** |

`FIONREAD` 与 14.7 探测排队数据一致，**不阻塞**。
