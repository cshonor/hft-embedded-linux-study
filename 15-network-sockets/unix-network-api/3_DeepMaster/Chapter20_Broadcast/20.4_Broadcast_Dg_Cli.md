# 20.4 使用广播的 dg_cli 函数

---

## 改造要点

UDP 单播客户 → 广播客户，改动很小。

---

## SO_BROADCAST（强制）

向广播地址 `sendto` 前必须：

```c
int on = 1;
setsockopt(sockfd, SOL_SOCKET, SO_BROADCAST, &on, sizeof(on));
```

未设置 → 内核拒绝发送，**`errno = EACCES`**。

---

## 实现步骤

```text
socket(UDP) → setsockopt(SO_BROADCAST)
→ 目的地址：子网广播（192.168.x.255）或 255.255.255.255
→ 循环 sendto 请求 + recvfrom 收多台服务器应答
```

勿硬编码广播地址 — 可用 **`ioctl` `SIOCGIFBRDADDR`** 取本网卡子网广播地址。

---

## 易错：IP 分片

**广播数据报通常不允许分片** → 载荷须 **< 接口 MTU**（以太网约 1500 − IP/UDP 头）。
