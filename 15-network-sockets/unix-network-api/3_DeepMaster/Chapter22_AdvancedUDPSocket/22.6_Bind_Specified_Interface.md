## 核心场景

`bind` **通配** `0.0.0.0` 还是**具体网卡 IP**？

---

## UDP 端点匹配规则

内核选套接字时：**越具体 bind 优先级越高**。

---

## 并发绑定示例

```text
套接字 A：bind(192.168.1.100)
套接字 B：SO_REUSEADDR + bind(0.0.0.0)

→ 发往 192.168.1.100 的报文 → A
→ 发往其他本地 IP 的报文   → B
```
