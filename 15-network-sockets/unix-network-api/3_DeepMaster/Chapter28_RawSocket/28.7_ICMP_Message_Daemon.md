## 痛点

**未 connect 的 UDP** 套接字：异步 ICMP 错误（端口不可达等）**常不**传递给应用（Ch 8.9）→ 客户端盲目 `recvfrom` 超时。

---

## icmpd 架构

```text
1. 后台守护进程 icmpd
2. 原始 ICMP 套接字 — 捕获本机相关 ICMP 错误
3. ICMP 载荷含原 IP 头 + 原 UDP 头前 8 字节（含端口）
4. 解析本地源端口 → 经 Unix 域套接字等 IPC 推送给对应 UDP 应用
```

---

## 地位

在 **UDP connect** / 现代 API 普及前，将网络层错误**桥接**到应用层的经典模式。
