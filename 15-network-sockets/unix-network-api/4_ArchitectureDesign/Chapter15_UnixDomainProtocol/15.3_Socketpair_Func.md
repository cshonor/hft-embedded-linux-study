## 核心机制：全双工“管道”

`pipe` 通常**半双工**；`socketpair` 创建两个**已互连、全双工**的 Unix 域套接字。

```c
int socketpair(int family, int type, int protocol, int sockfd[2]);
```

| 参数 | 典型值 |
|------|--------|
| `family` | **`AF_LOCAL`** |
| `type` | `SOCK_STREAM` 或 `SOCK_DGRAM` |
| `protocol` | 0 |

写入 `sockfd[0]` 的数据可从 `sockfd[1]` 读，反之亦然。

---

## 典型用法

```text
socketpair → fork
  父：close(sockfd[1])，用 sockfd[0]
  子：close(sockfd[0])，用 sockfd[1]
→ 父子极速双向通道
```
