# 5.7 与 IP 相关的攻击

## 一、IP 欺骗（IP Spoofing）

### 原理

IP 头部 **源地址字段可随意伪造** — 协议本身**无身份校验**机制（设计于互信环境）。

```text
攻击者 1.1.1.1 --(源 IP 伪造为 2.2.2.2)--> 服务器/防火墙 --> 受害者
接收方误以为来自 2.2.2.2，可能开放基于 IP 的信任
```

### 危害

| # | 危害 |
|---|------|
| 1 | 绕过基于 **IP 白名单 / IP 信任** 的访问控制 |
| 2 | 构造 **反射式 DDoS**：伪造**受害者 IP** 向服务器发包 → 应答流量**全部涌向受害者** |

→ 反射/放大 DDoS 与 UDP/DNS/NTP 等：[ch10 §安全](../chapter10-udp-ip-fragment/10.14-udp-security.md)

### 主流防护

| 方案 | 说明 |
|------|------|
| **BCP 38** | 运营商/边界执行**入站路由过滤** — 丢弃源地址**不属于该入接口合法网段**的报文 |
| **uRPF**（单播反向路径转发） | 校验源 IP **反向路由**是否存在且与入接口一致；不存在则丢弃 |

**uRPF 模式**

| 模式 | 行为 |
|------|------|
| **严格（Strict）** | 源 IP 必须**精确匹配**入接口所在子网 |
| **松散（Loose）** | 只要路由表中**存在**到源 IP 的路由即可 |

→ 详读：[ch02 §2.8 防护](../chapter02-ip-address-architecture/2.8-address-security-threat.md#ch02-8-defense) · [ch01 架构威胁](../chapter01-overview/1.8-architecture-threat.md#ch1-8-attacks)

## 二、IP 分片攻击

### 原理

利用 **畸形分片、分片重叠、超长分片**，使目标主机重组时出现解析异常 → **内存溢出、系统崩溃**。

| 类型 | 说明 |
|------|------|
| **重叠分片** | 经典 **Teardrop 攻击** — 片偏移重叠，旧栈重组崩溃 |
| **永不完成的片** | 占满重装缓冲，耗尽内存 / `nf_conntrack` |
| **过小/异常片** | 边界过滤对象 |

→ [ch10 Teardrop 变体](../chapter10-udp-ip-fragment/study.md) · IPv6 仅源分片：[5.3](5.3-ipv6-extension-headers.md#ch05-3-types)

### 现状与防护

| 层 | 措施 |
|----|------|
| **协议栈** | 现代 OS 已**加固**重组逻辑，原生 Teardrop 类风险**大幅降低** |
| **边界运维** | **限制异常分片** — 拦截过小/畸形/重叠分片 |
| **减少分片** | 启用 **PMTUD（路径 MTU 发现）** — DF=1 + ICMP PTB → 源端控制包长 → [ch03 §PMTUD](../chapter03-link-layer/3.8-mtu.md#ch03-8-pmtud) |

<a id="ch05-7-principle"></a>

## 三、核心安全原则

IP 协议设计之初**不具备身份认证、加密能力**，仅负责**寻址与转发**。

| 层次 | 手段 |
|------|------|
| **上层协议** | **TLS**（传输/应用）、**IPsec**（网络层 ESP/AH → [ch18](../chapter18-network-security/study.md)） |
| **网络运维** | BCP 38、uRPF、分片管控、ICMP 策略（勿拦 PTB） |
| **应用设计** | **不依赖源 IP 作为身份**；令牌 / 证书认证 |

<a id="ch05-7-arp-link"></a>

## 四、与链路层 ARP 欺骗的联动

| 层 | 攻击 | 组合效果 |
|----|------|----------|
| **L2 ARP 欺骗** | 伪造 MAC ↔ IP 映射 | 同广播域 **MITM** → [ch04 §4.11](../chapter04-arp-protocol/4.11-arp-spoof-defense.md) |
| **L3 IP 欺骗** | 伪造源 IP | 越权、反射 DDoS |
| **L2 + L3** | ARP 劫持 + IP 伪造 | **更强**的窃听/篡改/放大攻击面 |

**一句**：防火墙（L3）**拦不住 ARP**（L2）；IP 层也不验源 — 需**分层防御**。

<a id="ch05-7-cheat"></a>

## 五、考点速记

| # | 要点 |
|---|------|
| 1 | **IP 欺骗**：伪造**源 IP** → 越权访问、**反射 DDoS**；防护：**BCP 38**、**uRPF** |
| 2 | **分片攻击**：**畸形/重叠分片** → 重组漏洞；代表 **Teardrop**；防护：边界控分片、**PMTUD** |
| 3 | **本质**：IP 层**无安全校验** → 靠 **TLS/IPsec** + 网络策略 |
| 4 | **联动**：常与 **ARP 欺骗**（ch04）组合，二层+三层伪造 |

| 易错 | 正确 |
|------|------|
| 防火墙能防 IP 欺骗 | 需**边界入站过滤**（BCP38/uRPF）；内网仍可能伪造 |
| Teardrop 现代仍高危 | 栈已加固；边界仍应**滤异常分片** |
| 拦 ICMP 更安全 | 误拦 **PTB** → **PMTUD 黑洞**、大包卡死 |

---

## 疑问与总结

**背：源 IP 可伪造（BCP38/uRPF）；分片畸形（Teardrop/滤片/PMTUD）；IP 无身份 → TLS + 不信 IP。**
