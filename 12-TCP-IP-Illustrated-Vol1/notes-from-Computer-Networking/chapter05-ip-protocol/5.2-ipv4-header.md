# 5.2 IPv4 头部和 IPv6 头部

> 章级精读：[study.md#ch05-2](./study.md#ch05-2) · 分用：[ch01 §分用](../chapter01-overview/study.md#ch01-layering) · 扩展头：[5.3](5.3-ipv6-extension-headers.md) · 分片：[ch10](../chapter10-udp-ip-fragment/study.md)

## 本节核心目标

对比 **IPv4 可变头** 与 **IPv6 固定 40 字节头** 的设计差异与核心字段。

---

<a id="ch05-2-overview"></a>

## 一、整体核心差异

| 维度 | IPv4 | IPv6 |
|------|------|------|
| **头部长度** | **可变**：最小 20 B，带选项最大 **60 B** | **固定 40 B**，无内嵌选项 |
| **设计思路** | 功能内嵌主头；分片复杂；**每跳校验和**开销大 | 基础头只留转发必需字段；**额外功能 → 扩展头**按需挂载 |
| **转发效率** | 变长解析 + 校验和更新 | 固定头 → **ASIC/NP 流水线**友好 |

---

<a id="ch05-2-protocol"></a>

## Protocol 字段（三层 → IP 载荷分用）

| 项 | 说明 |
|----|------|
| **位置** | IPv4 首部 **第 9 字节**（TTL 与首部校验和之间） |
| **作用** | 标明 **IP 载荷**是 ICMP、TCP 还是 UDP |
| **口诀** | **二层定三层，三层定内层** |

| 值 | 载荷 | 层次 |
|----|------|------|
| **1** | **ICMP** | 网络层（封装在 IP 内） |
| **6** | **TCP** | 传输层 |
| **17** | **UDP** | 传输层 |

IPv6 用 **Next Header**（含扩展头链 → [5.3 §链式规则](5.3-ipv6-extension-headers.md#ch05-3-chain)）。

<a id="ch05-2-ipv4"></a>

## 二、IPv4 核心字段（必记）

| 字段 | 核心作用 | 补充说明 |
|------|----------|----------|
| **TTL** | 每经过一跳路由器 **−1**，**防报文环路** | IPv6 对应 **Hop Limit**，逻辑一致 |
| **TOS / DS+ECN** | 早期服务类型；现为 **DSCP**（差分服务）+ **ECN**（显式拥塞通知） | QoS 优先级、拥塞标记 |
| **头部校验和** | 仅对 **IP 首部**完整性校验 | **逐跳**路由器须重算、更新 → 转发开销大 |
| **标识 / 标志(DF/MF) / 片偏移** | 控制 **IP 分片与重组** | 路由器可中途分片；**DF=1** = 禁止分片 |

> **IPv4 分片 = 网络层分片**，**中间路由器可介入**。

## 三、IPv6 头部：删减、新增、改造

### 1）直接移除

| 移除项 | 原因 |
|--------|------|
| **头部校验和** | L2 **FCS** + L4（TCP/UDP）校验已覆盖；减少路由器运算 |
| **路由器级分片** | **中间路由器不分片**；过大 → 丢弃 + **ICMPv6 Packet Too Big** → **源主机**分片 |
| **标识 / DF/MF / 片偏移** | 不再出现在 **基础头**（极端场景见扩展头 → [5.3](5.3-ipv6-extension-headers.md)） |

### 2）新增

- **流标签（Flow Label）**：标识同一类数据流 → **QoS、流量调度、快速转发**  
  场景：视频/语音等长流，设备可基于流标签处理，无需反复解析五元组。

### 3）功能迁移

- IPv4 **选项** → IPv6 **扩展头链表**（[5.3](5.3-ipv6-extension-headers.md)）  
- 优势：基础头固定；常规转发**不必**解析扩展头；仅安全/分片/路由等场景才遍历。

### 4）同源字段更名

- IPv4 **TTL** → IPv6 **Hop Limit**（每跳递减，防环路）

### 字段对照速查

| 字段 | IPv4 | IPv6 |
|------|------|------|
| 头长 | **IHL**，20–60 B | **固定 40 B** |
| QoS | **ToS** → DSCP/ECN | **Traffic Class** |
| 流标签 | 无 | **20 bit Flow Label** |
| 长度 | **Total Length**（含头） | **Payload Length**（不含头） |
| 寿命 | **TTL** | **Hop Limit** |
| 上层 | **Protocol** | **Next Header** |
| 校验和 | **有，每跳更新** | **无** |
| 分片 | 主头字段 + 路由器可分片 | **仅源分片** + 扩展头 |

<a id="ch05-2-fragment-vs-segment"></a>

## 四、易混：IP 分片 vs TCP 分段（必考）

| | **IPv4 分片**（网络层） | **TCP 分段**（传输层） |
|--|-------------------------|-------------------------|
| **触发方** | **中间路由器**（或源主机） | **端系统（源主机）** |
| **依据** | 链路 **MTU** | **MSS**（两端协商） |
| **对象** | 整个 **IP 报文** | **TCP 数据载荷** |
| **层级** | 三层 | 四层 |

**总结**：三层管「**链路能否承载**」；四层管「**应用数据如何拆**」— 层级、触发主体、依据**完全不同**。

<a id="ch05-2-cheat"></a>

## 五、极简背诵清单

1. **IPv4**：头长可变（20–60 B）；有头校验和；**路由器可分片**；选项内嵌主头。  
2. **IPv6**：头长固定 **40 B**；**无头校验和**；**路由器不分片**；新增**流标签**；选项 → **扩展头**。  
3. **分片** = 网络层（MTU / 路由器）；**分段** = 传输层（MSS / 端主机）。
