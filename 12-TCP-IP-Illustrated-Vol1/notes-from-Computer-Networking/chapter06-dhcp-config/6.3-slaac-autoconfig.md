# 6.3 无状态地址自动配置 (SLAAC)

> 章级精读：[study.md#ch06-3](./study.md#ch06-3) · DHCPv6 对照：[6.2 §IPv6](6.2-dhcp-protocol.md) · ND/RA：[ch08 §8.5](../chapter08-icmpv4-icmpv6/8.5-ipv6-ndp.md) · 免费 ARP/ACD：[ch04 §4.8](../chapter04-arp-protocol/4.8-gratuitous-arp.md)

## 本节核心目标

掌握 **APIPA（IPv4 链路本地）** 与 **IPv6 SLAAC** — 无 DHCP 服务器场景下的零配置配址，以及 **M/O 标志** 与 DHCPv6 的分工。

<a id="ch06-3-apipa"></a>

## 一、IPv4 APIPA（链路本地地址）

| 项 | 说明 |
|----|------|
| **触发条件** | **DHCP 服务器不可达**（超时/无响应） |
| **地址段** | 自动分配 **`169.254.0.0/16`**（RFC 3927） |
| **冲突检测** | 依靠 **免费 ARP / ACD**（Address Conflict Detection）校验地址唯一性 |
| **范围** | **仅本地链路**有效，**不能跨路由** |

```text
DHCP 失败 → 随机选 169.254.x.x → 免费 ARP 探测冲突 → 可用则启用
```

→ 地址分类：[ch02 §2.5](../chapter02-ip-address-architecture/2.5-special-address.md) · ACD 细节：[ch04 §4.8](../chapter04-arp-protocol/4.8-gratuitous-arp.md)

## 二、IPv6 SLAAC 流程（无状态自动配址）

**SLAAC**（Stateless Address Autoconfiguration）：主机根据路由器通告**自行合成**全球单播地址，**无需**中心化地址分配服务器记录租约。

### 流程

| 步骤 | 报文 | 说明 |
|------|------|------|
| **1** | **RS**（Router Solicitation，路由器请求） | 主机主动发报文，**询问**网络前缀（也可被动等 RA） |
| **2** | **RA**（Router Advertisement，路由器通告） | 路由器回复，下发**网段前缀**、**M/O 控制标志位**、跳数等 |
| **3** | **地址合成** | **`RA 前缀` + `接口标识 IID`** → 完整 IPv6 全球单播地址 |

```text
主机 --[ RS 组播 ]--> 路由器
主机 <--[ RA 带 Prefix + M/O ]-- 路由器
地址 = Prefix + IID（默认 EUI-64）
```

### IID 生成（默认 EUI-64）

| 项 | 说明 |
|----|------|
| **规则** | 48 bit MAC 中间插入 **`0xFFFE`**，翻转 **U/L 位**（第 7 位） |
| **隐私扩展** | RFC 4941：随机 IID、定期更换，防 MAC 追踪 → [study §6.3.2](./study.md#ch06-3) |

→ ICMPv6 NDP：[ch08 §8.5](../chapter08-icmpv4-icmpv6/8.5-ipv6-ndp.md)

<a id="ch06-3-mo"></a>

## 三、M/O 标志位（核心区分）

RA 报文中 **ICMPv6 Router Advertisement** 的标志位决定是否与 **DHCPv6** 配合：

| 标志 | 名称 | 置 1 含义 |
|------|------|-----------|
| **M** | **Managed** | 启用 **有状态 DHCPv6** — 地址由 DHCPv6 **分配**（非 SLAAC） |
| **O** | **OtherConfig** | **仅**向 DHCPv6 获取 **DNS、域名** 等附加参数；**地址仍由 SLAAC 生成** |

| M | O | 行为 |
|---|---|------|
| 0 | 0 | **纯 SLAAC** — 仅 RA 前缀拼地址 |
| 0 | 1 | SLAAC 地址 + **DHCPv6 无状态**（Information-Request 要 DNS 等） |
| 1 | * | **有状态 DHCPv6** 分配地址（SLAAC 不用于地址） |

**结论**：**SLAAC 不强制搭配 DHCPv6** — 是否使用、用于地址还是仅 DNS，由 **RA 的 M/O 标志**决定。

→ DHCPv6 模式对照：[6.2 §IPv6](6.2-dhcp-protocol.md)

## 四、易混考点

| # | 要点 |
|---|------|
| 1 | **APIPA** 是 **IPv4** 零配置方案；**SLAAC** 是 **IPv6** 主流零配置方案 |
| 2 | **SLAAC** 靠 **RA** 完成地址生成；是否用 **DHCPv6** 取决于 **M/O 标志** |
| 3 | **IID** 默认采用 **EUI-64** 规则生成（可换隐私扩展随机 IID） |

| 易错 | 正确 |
|------|------|
| SLAAC 一定配 DHCPv6 | **看 M/O**；可纯 SLAAC（M=0,O=0） |
| O=1 时地址也靠 DHCPv6 | O=1 仅要 **DNS 等**；地址仍 **SLAAC** |
| APIPA 可跨网段路由 | **169.254/16** 仅链路本地 |
| M 与 O 同义 | **M=有状态地址**；**O=仅其他配置** |

---

## 考点速记

1. **APIPA**：DHCP 不可达 → **`169.254/16`** + **免费 ARP/ACD**
2. **SLAAC**：**RS → RA → 前缀+IID**；IID 默认 **EUI-64**
3. **M/O**：M=有状态 DHCPv6 地址；O=SLAAC 地址 + DHCPv6 要 DNS
4. **SLAAC ≠ 必须 DHCPv6**

---

## 疑问与总结

**背：APIPA 169.254+ACD；SLAAC=RS/RA+前缀拼IID；M 管地址、O 管 DNS；二者都是零配置，族别不同。**
