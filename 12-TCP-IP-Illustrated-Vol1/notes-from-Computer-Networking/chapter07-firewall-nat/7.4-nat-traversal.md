## 一、UDP 打洞（Hole Punching）

### 1. 流程

| 步骤 | 说明 |
|------|------|
| **① 主动外联** | 内网主机向公网对端/信令服务器**主动发 UDP** |
| **② 建立映射** | NAT 生成**外向端口映射**（reflexive 公网 IP:Port） |
| **③ 反向打入** | 对端向该 **(公网 IP, 端口)** 发包 → 利用 NAT **会话表**允许回连 |

```text
内网 A → 主动发包 → NAT 建映射 → 对端 B 向 (公网IP:Port) 回包 → 穿入内网 A
```

常经**信令服务器**协调 A、B **同时**向对方发探测包，NAT 视为由内向外合法流 → 开**针孔**。

### 2. 原理

利用 NAT **连接跟踪 / 会话表**：内网先发起的外向流会在表项中记录映射；对端若命中同一五元组（或宽松过滤策略允许），反向报文可通过。

### 3. 成败关键：NAT 类型

| NAT 类型 | 打洞难度 |
|----------|----------|
| **全锥 Full Cone** | **最易** — 固定映射，任意外网可回连 |
| **限制 / 端口限制** | 中等 — 过滤策略更严 |
| **对称 Symmetric** | **最难** — 不同目的 → **不同映射**，打洞常失败 → 需 **TURN** |

→ 四类详解：[7.3 §映射类型](7.3-nat-napt.md#ch07-3-mapping-types) · **口诀：全锥易，对称靠中继**

## 二、NAT 穿越三剑客（STUN / TURN / ICE）

| 协议 | 核心作用 | 备注 |
|------|----------|------|
| **STUN** | 查询自身 NAT 映射后的**公网 IP + 端口** | **纯查询**，不转发业务流量 |
| **TURN** | 打洞失败时做**流量中继转发** | **兜底**；消耗服务器带宽/成本高 |
| **ICE** | 自动收集各类**候选地址**、连通性探测，**择优选择传输路径** | 组合 STUN/TURN；WebRTC 标配 |

```text
ICE 收集候选 → STUN 获 reflexive 地址 → 直连/打洞探测 → 失败则 TURN relay
```

| 协议 | 机制 | 限制 |
|------|------|------|
| **STUN** | 反射寻址 | 轻量；难穿**对称 NAT** |
| **TURN** | 中继 | 成功率高；带宽成本高 |
| **ICE** | 交互式连接建立 | 自动选最优路径 |

### 退化场景排查

连接**降级走 TURN** 时，优先排查：

| 原因 | 说明 |
|------|------|
| **对称 NAT** | 打洞失败最常见根因 |
| **UDP 防火墙拦截** | 边界/本机阻 UDP |
| **会话超时** | 映射被清，探测时已失效 |

## 四、映射保活

| 项 | 说明 |
|----|------|
| **问题** | NAT 表项存在**空闲超时** — 长时间无流量映射被清除 |
| **后果** | 对端无法再通过原公网端口回连 → **断连** |
| **解决** | 定时 **STUN Binding 刷新** 或应用层**心跳包** |

→ TCP 侧保活：[ch17 Keepalive](../chapter17-tcp-keepalive/study.md)

<a id="ch07-4-cheat"></a>

## 考点速记

| # | 要点 |
|---|------|
| 1 | **打洞**依赖主动建流产生的 NAT **外向映射** |
| 2 | **STUN** 查地址 · **TURN** 做中继 · **ICE** 路径优选 |
| 3 | 降级至 **TURN** → 大概率 **对称 NAT** 打洞失败 |
| 4 | 必须 **心跳/刷新绑定**，防 NAT 超时断连 |

| 易错 | 正确 |
|------|------|
| STUN 转发业务流量 | STUN **仅查询** reflexive 地址 |
| TURN 是首选 | TURN 是**兜底**；直连/打洞优先 |
| 打洞与 NAT 类型无关 | **全锥易、对称最难** |
| 映射永久有效 | 有空闲超时 → 需 **保活** |

---

## 疑问与总结

**背：主动发包建映射 → 对端反向打入；STUN/TURN/ICE 分工；对称 NAT → TURN；心跳防超时。**
