# 7.7 与防火墙和 NAT 相关的攻击

> 章级精读：[study.md#ch07-7](./study.md#ch07-7) · conntrack 运维：[7.5 §运维](7.5-acl-port-control.md#ch07-5-ops) · 源 IP 不可信：[ch05 §5.7](../chapter05-ip-protocol/5.7-ip-attacks.md)

## 本节核心目标

认识 **应用层隧道绕过防火墙** 与 **NAT/防火墙状态耗尽** — 状态化中间件引入的**可用性**与**隐蔽通道**风险。

<a id="ch07-7-tunnel"></a>

## 一、防火墙攻击：应用层隧道绕过

### 原理

| 项 | 说明 |
|----|------|
| **手法** | 恶意流量封装在 **80/443** 等**必放行端口**内传输 |
| **典型** | HTTPS 隧道内嵌 **C2（远控）** 流量 — 端口过滤视为「正常 Web」 |
| **本质** | 绕过**端口级/包过滤** ACL，利用「业务端口开放」策略 |

```text
防火墙：443 放行 → 攻击者 HTTPS 隧道 → 内网 C2 / 数据渗出
```

### 防护

| 手段 | 说明 |
|------|------|
| **TLS 检测/解密** | 检查加密载荷（企业代理、SSL 中间人 — 有隐私与合规成本） |
| **正向代理** | 强制流量经代理审查，非直连 |
| **流量行为分析** | 连接频率、字节模式、DNS/ SNI 异常等 — 不依赖明文 |

→ ACL 端口放行策略：[7.2 §三条规则](7.2-packet-filter-firewall.md#ch07-2-rules) · [7.5](7.5-acl-port-control.md#ch07-5-acl)

<a id="ch07-7-state-exhaustion"></a>

## 二、NAT 状态耗尽攻击 (State Exhaustion)

### 原理

| 项 | 说明 |
|----|------|
| **手法** | 向 NAT/防火墙发送**大量新建/半开连接**（如伪造 SYN  flood） |
| **结果** | **`conntrack` 连接跟踪表 / NAT 映射表占满** |
| **影响** | **新连接无法建立** → 内网用户**断网**（已有连接可能仍存活） |

### 特点

| 项 | 说明 |
|----|------|
| **NAT 定位** | 侧重**地址转换**，**并非专业安全设备** |
| **瓶颈** | 状态表容量有限 → 易成为**可用性单点** |
| **与 7.5 关联** | 表满现象同 [7.5 §conntrack](7.5-acl-port-control.md#ch07-5-ops) — 此处强调**主动攻击**触发 |

**一句**：打爆连接跟踪表，破坏的是**可用性**，不一定是机密性。

---

<a id="ch07-7-mitigation"></a>

## 三、缓解方案

| # | 手段 | 说明 |
|---|------|------|
| 1 | **限流** | 限制**单 IP / 单源**新建连接速率；每源映射数上限 |
| 2 | **调优** | **缩短**会话老化超时；**扩容** `conntrack` 表项（`/proc/sys/net/netfilter/nf_conntrack_max` — 仍有限） |
| 3 | **架构优化** | 核心业务部署 **DMZ**；或**原生 IPv6** 直连，规避 NAT 状态瓶颈 |

**过滤先于 NAT**：先 Drop 垃圾流，减少占表 — [7.5 架构](7.5-acl-port-control.md#ch07-5-acl)

### 补充：其他状态化攻击面

| 攻击 | 说明 |
|------|------|
| **分片绕过** | 操纵分片偏移，非法 L4 信息在首包审查后于内网**重组** — 严格碎片策略 |
| **状态注入** | 伪造 ACK/序列号误导状态表 |

→ 源 IP 伪造：[ch05 §5.7](../chapter05-ip-protocol/5.7-ip-attacks.md) · **uRPF**、**TCP MSS** 限制

<a id="ch07-7-cheat"></a>

## 考点速记

| # | 要点 |
|---|------|
| 1 | **隧道绕过**：利用**常用开放端口（80/443）** 隐藏恶意流量 |
| 2 | **状态耗尽**：打爆 **conntrack / NAT 映射表** → 新连接失败 → **可用性 DoS** |
| 3 | **防护**：**限流**、**调超时/扩表**、**架构拆分（DMZ/v6）**、TLS 检测/代理/行为分析 |

| 易错 | 正确 |
|------|------|
| NAT 能防 DDoS | NAT **非安全设备**；状态表满 → **断新连** |
| 只开 443 就安全 | **HTTPS 隧道**可藏 C2 — 需深度检测或行为分析 |
| 扩表一劳永逸 | 扩容有限；需 **限流 + 过滤先于 NAT** |
