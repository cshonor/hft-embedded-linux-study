# 1.8 与 Internet 体系结构相关的攻击

> 章级导读：[../study.md](../study.md) · [1.1 端到端/命运共享](./1.1-architecture-principles.md) · 全书安全：[第 18 章](../chapter18-network-security/study.md)  
> **厚版背诵**（分层总表+防御+链路对齐）：[自顶向下 §8 一页表](../../top_down/08_network_security/layer-attacks-cheatsheet.md)

## 本节核心目标

认识早期 Internet **默认信任、明文传输** 带来的基础威胁；理解攻击与 **分层架构** 的对应关系，以及 **TLS / IPsec / 防火墙** 等演进的动机（与 [1.1](./1.1-architecture-principles.md#ch1-e2e) **端到端** 论点一致：复杂安全语义应在端点闭合）。

---

## 设计背景

- 早期侧重**连通性与简单性**，缺乏原生**身份、完整性、机密性**机制。
- 中间网络被假定为「可能出错但非恶意」→ 与今日威胁模型差距大。
- **根因常是架构假设过时**，不是单一实现 bug；不能仅靠「信任运营商」。

## 典型攻击总表（本章级 · 补全）

| 攻击 | 原理（人话） | 关联层 | 防御要点（预告） |
|------|----------------|--------|------------------|
| **IP 欺骗 (Spoofing)** | 伪造**源 IP**，接收方以为是可信主机，难以溯源 | **网络层（IP）** | [BCP38/uRPF 详读](../../chapter02-ip-address-architecture/2.8-address-security-threat.md) |
| **DoS / 拒绝服务** | 海量无效流量 / 半开连接，耗尽**带宽、CPU、连接表** | **多层面** | 限速、CDN、SYN Cookie、清洗 |
| **窃听 (Eavesdropping)** | **明文**或无线链路上抓包，直接看账号密码等 | **链路嗅探 + 应用明文** | **TLS/HTTPS**、WPA3 |
| **ARP 欺骗** | 伪造 ARP 响应，改内网 **IP→MAC** 表，流量被劫持 | **链路层（ARP）** | DAI、802.1X；上层加密 |
| **MAC 欺骗 / MAC 泛洪** | 伪造源 MAC，或塞满交换机 **CAM 表** → 泛洪、易被监听 | **链路层（帧/交换机）** | 端口安全、MAC 绑定、VLAN |
| **TCP 劫持 / 会话劫持** | 猜到 **TCP 序号**，插入会话，篡改或冒充通信 | **传输层（TCP）** | 强随机 ISN、**TLS** |
| **SYN 洪泛 (SYN Flood)** | 大量 SYN 不回 ACK，占满**半开连接表** | **传输层（TCP）** | SYN Cookie、防火墙 |
| **UDP 洪水** | 海量 UDP 占满带宽或拖垮应用（含反射放大） | **传输层（UDP）** | 限速、关不必要 UDP 端口 |
| **DNS 欺骗 / 缓存投毒** | 伪造 DNS 应答，域名→**恶意 IP**（钓鱼） | **应用层（DNS）** | DNSSEC、DoH/DoT |
| **HTTP 劫持 / MITM** | 中间截获 **HTTP**，改页面、插广告、偷密码 | **链路→应用** | **HTTPS + HSTS**、证书校验 |

→ 与已学协议栈逐节对照：[top_down 分层表](../../top_down/08_network_security/layer-attacks-cheatsheet.md#ch8-layer-table)

## 每层一句话（串 HTTP / TCP / IP / 链路）

| 层 | 核心（你已学） | 典型攻击 | 本质 |
|----|----------------|----------|------|
| **链路** | 帧、MAC、ARP、交换机 | ARP 欺骗、MAC 欺骗/泛洪、无线窃听 | 内网**默认信任**，缺身份验证 |
| **网络** | IP、路由 | IP 欺骗、分片攻击、ICMP 洪水 | **不验源 IP**，只管转发 |
| **传输** | 端口、TCP 握手/SEQ | SYN 洪水、TCP 劫持、UDP 洪水 | 握手与序号可**伪造/预测** |
| **应用** | HTTP、DNS | HTTP 劫持、DNS 欺骗、SQL 注入、XSS | **明文**或**输入未校验** |

```text
安全上网栈（对照 1.1 B/S）：
浏览器 ── HTTPS/TLS（应用层机密+完整+鉴别）──► 服务器
         └── TCP ── IP ── 以太网 / Wi‑Fi（§6.1 三选一）
链路层仍可能 ARP/MITM，但 TLS 保护应用内容（证书须校验）
```

→ 链路：[§6.4 ARP](../../top_down/06_link_layer_and_lan/6.4_ethernet_arp_switch_vlan/study.md) · TCP：[§3.5](../../top_down/03_transport_layer/3.5_tcp_connection_and_transmission/study.md) · HTTP：[§2.2](../../top_down/02_application_layer/2.2_http_and_web/study.md)

## 寄快递类比（新手秒懂）

| 攻击 | 类比 |
|------|------|
| IP 欺骗 | 信封写**别人的寄件人** |
| ARP 欺骗 | 门卫（ARP 表）被骗，**A 的信全转给你** |
| DoS | 一天 **10 万空包裹**，快递站瘫痪 |
| 窃听 | 偷看**没封口的信**（明文 HTTP） |
| SYN 洪水 | 只填**寄件单不取件**，占满柜台 |
| DNS 欺骗 | 把「百度」地址**改成你家** |
| HTTP 劫持 | 中途**换页、插广告**（HTTPS = 密封 + 验章） |

## 考点 · 30 秒背诵

- **链路**：ARP 欺骗 · MAC 欺骗/泛洪 · 无线窃听  
- **网络**：IP 欺骗 · ICMP/分片类  
- **传输**：SYN 洪水 · TCP 劫持 · UDP 洪水  
- **应用**：HTTP 劫持 · DNS 欺骗 · SQL 注入 · XSS  

**口诀**：链偷 ARP MAC，网骗 IP，传 SYN 劫，应 HTTP DNS 注。

- 攻击根因 = **架构假设过时**；**端到端安全**要求在端点语义上闭合（[1.1](./1.1-architecture-principles.md#ch1-e2e)）。
- 加密 ≠ 鉴别；仅有 TLS 信道仍须**校验证书**，防 MITM。
