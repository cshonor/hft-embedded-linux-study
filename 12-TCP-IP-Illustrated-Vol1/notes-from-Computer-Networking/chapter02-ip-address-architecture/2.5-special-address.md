# 2.5 特殊用途地址

> 章级精读：[../study.md#ch02-5](../study.md#ch02-5) · 组播：[ch09](../chapter09-broadcast-multicast/study.md) · NAT/过渡：[ch07](../chapter07-firewall-nat/study.md) · [2.2 IPv6 映射](./2.2-ip-address-representation.md#ch02-2-ipv6-chunks)

## 本节核心目标

区分 **私有 / 环回 / 链路本地 / 组播 / 任播 / 文档 / 过渡地址**；掌握 IPv4、IPv6 对应块；辨析**组播 vs 广播**、**任播 vs 单播**。

> **口诀**：224 组播只喊小区 · 255 广播只喊本局域网 · 127 自己跟自己 · 169.254 DHCP 救急 · 192.0.2 课本假 IP

## 一、IPv4 五大特殊块（大白话 + 例子）

### 1）组播 `224.0.0.0/4`（D 类）

**范围**：`224.0.0.0` – `239.255.255.255`

| 地址 | 含义 | 例子 |
|------|------|------|
| **224.0.0.1** | **本网段所有主机** | 同一交换机/VLAN 下电脑都能收；**路由器不往外发** |
| **224.0.0.2** | **本网段所有路由器** | OSPF、RIP 等路由协议常用 |

**总结**：**224 开头 = 组播**，一般**只在当前局域网有效**，不会像公网单播那样跑遍整个互联网。→ 对比 [2.3 广播/组播](./2.3-basic-ip-structure.md#ch02-unicast-vs-broadcast)

### 2）受限广播 `255.255.255.255/32`

**是不是全网互联网都收到？→ 绝对不是！**

- 仅限**当前局域网**（本 VLAN、本交换机）
- **路由器默认丢弃**，不转发到外网、不跨 AS

**例子**：DHCP 发现时 `0.0.0.0` → `255.255.255.255`，只在你家/公司内网喊一声，**运营商和互联网收不到**。

> **255.255.255.255 = 只喊自己小区，不喊全世界。**

（子网定向广播如 `192.168.1.255/24` 也是主机位全 1，同样**不跨路由** → [2.3](./2.3-basic-ip-structure.md#ch02-broadcast-iid)）

### 3）环回 `127.0.0.0/8`

**范围**：`127.0.0.0` – `127.255.255.255`

**127 后面能随便变吗？→ 可以！**

- 常用 **`127.0.0.1`**（localhost）
- **`127.0.0.5`、`127.10.20.30`** 都行
- 只要以 **127** 开头 → **不经过物理网卡出站**，本机进程之间通信

**例子**：本机起 Web 服务，浏览器访问 `http://127.0.0.5:8080`，**不用联网**。

### 4）链路本地 APIPA `169.254.0.0/16`

**何时出现**：**DHCP 失败** / 没网线 / 没拿到地址 → 系统自动配 **169.254.x.x**

**例子**：电脑拿到 `169.254.88.99` → 只能和**同网段同样 169.254** 的设备互访，**不能上网**。

### 5）文档测试 `192.0.2.0/24`（TEST-NET）

专门给**教材、RFC 示例、实验**用；**公网永不分配、不可路由**。

**例子**：书上写「服务器 `192.0.2.10`」——现实中**不存在这台公网机**，不会和真 IP 冲突。

### 笔记可直接抄（五条）

1. **组播 224/4**：`224.0.0.1` = 本网段所有主机；`224.0.0.2` = 本网段所有路由器；**仅局域网内**。  
2. **受限广播 255.255.255.255/32**：**仅本局域网**；路由器不转发，**不会传遍互联网**。  
3. **环回 127/8**：开头 **127** 即可（如 `127.0.0.1`、`127.5.5.5`）；**本机内部，不走网卡**。  
4. **链路本地 169.254/16**：DHCP 失败自动分配；**只能内网互访，不能上网**。  
5. **文档 192.0.2.0/24**：**课本专用假 IP**，不上公网。

## 三、IPv6 特殊前缀（RFC 4193 / 3849 / 6890）

| 类型 | 前缀 | 说明 |
|------|------|------|
| **环回** | **`::1/128`** | 等价 `127.0.0.1` |
| **未指定** | **`::/128`** | 地址缺失 |
| **ULA 私有** | **`fc00::/7`** | 常用 **`fd00::/8`**（本地唯一，随机） |
| **链路本地** | **`fe80::/10`** | 每接口必有；**仅链路内** |
| **组播** | **`ff00::/8`** | **`ff02::1`** 链路所有节点；**`ff02::2`** 所有路由器 |
| **文档** | **`2001:db8::/32`** | 教材/示例，**勿上公网** |
| **IPv4 映射** | **`::ffff:0:0/96`** | 见 [2.2](./2.2-ip-address-representation.md) |

### 任播 Anycast

- **无单独前缀**；**与单播同格式**，多机共享同一地址，路由选**拓扑最近**应答（DNS 根、CDN）。

## 四、IPv4 ↔ IPv6 过渡地址（联动 ch07 NAT）

| 机制 | 前缀 / 格式 | 说明 |
|------|-------------|------|
| **IPv4-mapped** | **`::ffff:0:0/96`** | 例 `::ffff:192.168.1.1` |
| **NAT64** | **`64:ff9b::/96`** | 无状态翻译，嵌入 IPv4 |
| **6to4** | **`2002::/16`** | 由公网 IPv4 生成前缀 |
| **Teredo** | **`2001::/32`** | NAT 后 IPv6 穿透 |

→ 详读：[ch07 NAT](../chapter07-firewall-nat/study.md) · [自顶向下 §4.3 NAT](../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat/study.md)

## 五、分类速记表（直接背）

| 类型 | IPv4 | IPv6 | 用途 |
|------|------|------|------|
| 私有 | 10/8、172.16/12、192.168/16 | fc00::/7（fd00::/8） | 内网 + NAT |
| 环回 | 127.0.0.0/8 | ::1/128 | 本机自测 |
| 链路本地 | 169.254/16 | fe80::/10 | APIPA / 邻居发现 |
| 组播 | 224.0.0.0/4 | ff00::/8 | 一对多（IGMP/MLD） |
| 任播 | 无单独块 | 共享单播前缀 | 同址多机，就近 |
| 文档 | 192.0.2.0/24 | 2001:db8::/32 | 示例，不上公网 |
| 过渡 | — | ::ffff:/96、64:ff9b::/96、2002::/16 | v4↔v6 |

## 六、易混辨析（必考）

| 对比 | 要点 |
|------|------|
| **组播 vs 广播** | 广播（v4）= 本网**所有**主机；组播 = **加入组**才收（IGMP/MLD） |
| **任播 vs 单播** | 单播一对一；任播**同 IP 多机**，路由选**最近**一台应答 |
| **IPv6 无广播** | 用 **`ff02::1`** 等组播替代 |

---

## 七、30 秒写卷子

**IPv4 必背三块私有**：`10/8`、`172.16/12`、`192.168/16` · 环回 `127/8` · 组播 `224/4` · APIPA `169.254/16`  
**IPv6**：环回 `::1` · 链路本地 `fe80::/10` · 组播 `ff00::/8` · 文档 `2001:db8::/32` · 映射 `::ffff:x.x.x.x`  
**无广播**：v6 用 `ff02::1`

## 八、自测（4 题）

1. `ff02::1` 与 `224.0.0.1` 分别等价于什么场景？  
2. `2001:db8::1` 能当公网服务器地址吗？  
3. `255.255.255.255` 能让整个互联网所有设备都收到吗？  
4. `127.0.0.9` 和 `127.99.88.77` 能用吗？数据包会出网卡吗？

<details>
<summary>答案</summary>

1. **`ff02::1`**：IPv6 **链路本地所有节点**组播；**`224.0.0.1`**：IPv4 **本网段所有主机**组播（非广播）。  
2. **不能**。`2001:db8::/32` 为**文档专用**，公网不可路由。  
3. **不能**。仅限**本局域网**；路由器**不转发**到互联网。  
4. **能用**。凡 **127/8** 均属环回，**本机内部**，正常配置下**不经物理网卡访问外网**。

</details>
