# 2.7 单播地址分配

> 章级精读：[../study.md#ch02-7](../study.md#ch02-7) · [2.6 全球分配](./2.6-address-allocation.md) · DHCP：[ch06](../chapter06-dhcp-config/study.md) · NAT：[ch07](../chapter07-firewall-nat/study.md) · 私有地址：[2.5](./2.5-special-address.md) · 单播/广播/组播：[2.3 §二](./2.3-basic-ip-structure.md#ch02-unicast-vs-broadcast)

## 本节核心目标

搞懂：**正常 IP 怎么分**——内网用私有地址，外网用公网 PA/PI；需要时再记 PA/PI、多宿主等考试点。

> **一句话通透**  
> **单播地址 = 正常能用的 IP**。分配就是：**内网用私有 IP，外网用公网 PA/PI IP**。

---

<a id="ch02-7-plain"></a>

## 一、大白话核心

**单播地址 = 普通可用的 IP 地址**

给每台设备一个**唯一标识**，用来**一对一**上网、通信。

- **广播、组播**是特殊地址，**不能当普通 IP 用** → [2.3 对比](./2.3-basic-ip-structure.md#ch02-unicast-vs-broadcast)
- 电脑、手机、服务器日常用的，**全都是单播地址**
- **192.168、10 开头**这些私有 IP，**也是单播**（只是不能直接在公网上路由，常配合 NAT）

---

<a id="ch02-7-terms"></a>

## 二、关键名词（通俗版）

| 名词 | 大白话 |
|------|--------|
| **PA 地址** | **运营商给的公网 IP**。换运营商往往要换 IP；便宜，**小公司、只连一家 ISP** 够用 |
| **PI 地址** | **自己申请的永久公网 IP**（跟运营商无关）。换运营商可以**不换 IP**；适合**大公司、多家运营商备用** |
| **ISP** | **运营商**：拉网线、分公网 IP、帮你连上互联网 |
| **边界宣告** | 企业有了公网 IP 后，用 **BGP** 告诉其他运营商「**这个聚合后的大网段（如 /24）在我这里**」→ [2.4 CIDR+BGP](./2.4-cidr-aggregation.md#ch02-4-bgp) |
| **DHCP** | 内网**自动**给电脑分 IP、掩码、网关、DNS，不用手输 |

---

<a id="ch02-7-enterprise"></a>

## 三、企业怎么分配 IP（最简单逻辑）

### 1）内网（公司内部）

- 用**私有 IP**（`192.168.x.x`、`10.x.x.x`、`172.16–31.x.x`）
- 按部门/楼层划 **VLAN**，每段一个子网
- 用 **DHCP** 自动分配；服务器、网关可**固定 IP**

### 2）外网（上互联网）

- 用 **PA 或 PI 公网 IP**
  - 只连一家运营商 → 一般用 **PA**
  - 多家运营商备份（多宿主）→ 一般用 **PI**
- 在**出口路由器**做**边界宣告**，让外网能访问

### 典型场景（扫一眼）

| 场景 | 怎么做 |
|------|--------|
| 家里上网 | 私有 IP + 路由器 **NAT** + **DHCP** |
| 公司内网 | 私有 IP + **VLAN** + **DHCP** |
| 公司对外 | **PA/PI** 公网 IP + **边界宣告** |

## 四、IPv6 全球单播（通俗讲）

> **斜杠后面的数字 = 前面多少个二进制位，不是多少段！**  
> `/3` = 前 **3 个 bit**，不是 3 段；`/64` = 前 **64 个 bit**，不是 64 段。

### 先记地址长什么样

- IPv6 一共 **128 bit = 8 段 × 16 bit**（每段 4 个十六进制数）→ [2.2 写法](./2.2-ip-address-representation.md#ch02-2-ipv6-chunks)

### `2000::/3` 到底是啥？

- **`/3`**：只看地址**最开头 3 个二进制位**，固定为 **`001`**
- 第一段十六进制常以 **`2`** 开头（`2` = `0010`，最高 3 bit 是 `001`）
- 所以：**`2000::/3` = 所有以 2/3 开头的 IPv6 = 全球公网单播地址**

**和 8 段的关系**：`/3` 只划了**最左边 3 bit**，和后面 7 段、125 bit **无关**；别当成「前 3 段」。

<a id="ch02-7-ipv6-prefix"></a>

### 极简示意图（`/3` 在哪）

```text
128 bit（写成 8 段 × 16 bit，例如 2001:db8:…）

/3 只看最左边 3 个二进制位：
┌───┬───┬───┬──────────────── 后面 125 bit ────────────────┐
│ 0 │ 0 │ 1 │  … 随便变 …                                   │
└───┴───┴───┴──────────────────────────────────────────────┘
  ↑ 固定 001  →  落在 2000::/3（全球单播块）

/64 常考（网络 vs 主机）：
┌──────────── 前 64 bit ────────────┬──────── 后 64 bit ────────┐
│ 网络侧（常 ≈ 前 4 段）             │  IID / 设备 ID（常 ≈ 后 4 段）│
└───────────────────────────────────┴───────────────────────────┘
```

| 写法 | 含义（都是二进制位） |
|------|----------------------|
| IPv4 `/24` | 前 **24 bit** 是网络部分 |
| IPv6 `/3` | 前 **3 bit** 固定 → 全球单播块 |
| IPv6 `/64` | 前 **64 bit** 常作网络；后 **64 bit** 常作 **IID** |

### 笔记可直接抄的一段

> **IPv6 全球单播地址：`2000::/3`**  
> 含义：**前 3 个二进制位固定为 `001`**，代表全球唯一公网 IP。  
> 地址结构：**全球路由前缀 + 子网 ID + 接口标识 IID（64 bit）**

- 公司内网 IPv6「私有」：**`fd00::/8`（ULA）** —— 这里的 **`/8`** 同样是前 **8 个 bit**，不是 8 段
- IID 细节 → [2.3](./2.3-basic-ip-structure.md#ch02-broadcast-iid)

## 五、考试加厚（需要背时再展开）

<details>
<summary>点开：PA/PI 专业对照、多宿主、易混、自测</summary>

### PA / PI 专业名对照

| | **PA**（Provider-Aggregatable） | **PI**（Provider-Independent） |
|---|--------------------------------|--------------------------------|
| 谁分的 | **ISP** | **RIR**（见 [2.6](./2.6-address-allocation.md)） |
| 换 ISP | 常要**换 IP / 重宣告** | **可携带**，多 ISP 可宣告**同一前缀** |
| 路由表 | 易聚合 | 难聚合、全球表压力大 |
| 适用 | 中小企业、单 ISP | 大企业、云、**多宿主** |

### 多宿主 Multihoming

同时接**多个 ISP** → 要**冗余/高可用**，不是自动「带宽翻倍」（要 ECMP 等设计）。技术上常用 **PI + BGP**。

### IPv4 单播范围（历史分类，考试仍考）

| 类 | 范围（示意） |
|----|--------------|
| A | 1.0.0.0 – 126.255.255.255 |
| B | 128.0.0.0 – 191.255.255.255 |
| C | 192.0.0.0 – 223.255.255.255 |

排除：网络地址、广播、[特殊块](./2.5-special-address.md)。现网编址 → [2.4 CIDR](./2.4-cidr-aggregation.md)

### 易混

| 易混 | 纠正 |
|------|------|
| 单播 ≠ 公网 | 私有地址**也是单播** |
| PA/PI | 只谈**公网**；内网没有 PA/PI |
| 边界宣告 | 不是配个 IP 就行，要靠 **BGP** 让运营商接受你的前缀 |

### 自测

1. 小企业只连一家 ISP，一般用 PA 还是 PI？换 ISP 时地址通常怎样？  
2. 多宿主能否不跑 BGP 就让全球按你的策略选路？

**答案**：1）一般 **PA**；换 ISP 常要换地址或重新宣告。2）**不能**，要靠 BGP 与运营商接受前缀。

</details>

### 背诵四句

- **内网**：私有 + VLAN + DHCP  
- **外网**：PA/PI + 边界宣告  
- **IPv6 公网**：`2000::/3`，前缀 + 子网 + IID  
- **IPv6 内网**：`fd00::/8`
