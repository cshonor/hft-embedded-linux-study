# 2.3 基本的 IP 地址结构

> 章级精读：[../study.md#ch02-3](../study.md#ch02-3) · [2.4 CIDR](./2.4-cidr-aggregation.md) · [2.2 表示法](./2.2-ip-address-representation.md)

## 本节核心目标

串起 **分类寻址 → 子网/VLSM → CIDR → IPv6**，并掌握 **IPv4 广播** 与 **IPv6 IID（EUI-64）**。

---

<a id="ch02-evolution"></a>

## 一、演进脉络（IPv4 → IPv6）

```text
分类 A/B/C/D/E → 子网+掩码(FLSM) → VLSM → CIDR/聚合 → IPv6(128位,/64,IID,无广播)
```

### 1）分类寻址（Classful，RFC 791）

| 类 | 网络位 : 主机位 | 问题 |
|----|-----------------|------|
| **A** | 8 : 24 | 主机位太多 → **严重浪费** |
| **B** | 16 : 16 | B 类枯竭（ROAD 背景） |
| **C** | 24 : 8 | 小网够用，大网不够 |
| **D** | 组播 | — |
| **E** | 保留 | — |

**固定边界** → 路由表膨胀、分配不灵活。

### 2）子网 + 掩码（FLSM）

- 从**主机号借位**划**子网**；**掩码**定网络/子网/主机边界。
- **同一主网掩码固定**（定长子网）。
- 例：`192.168.1.0/24`，掩码 `255.255.255.0` → **隔离广播域**。

### 3）VLSM（可变长子网掩码）

- **同一主网内不同前缀长度**（CIDR 思想在子网内的应用）。
- 例：点对点 `/30`（2 个可用地址）；大部门 `/23`（约 510 主机）。
- **按需分配，减少浪费**；需 OSPF/IS-IS/BGP 等**无类**路由协议。

| | FLSM | VLSM |
|---|------|------|
| 掩码 | 全网相同 | 各子网可不同 |
| 浪费 | 点对点也占 /24 等 | 可按需 /30、/31 |

### 4）CIDR（无类域间路由）

- **抛弃 A/B/C 刚性类界**；只用 **前缀 + 主机位**（`a.b.c.d/x`）。
- **路由聚合（超网）**：多条短前缀合并为更短一条 → 减核心路由表项。
- 背景：**B 类枯竭 + ROAD** → 见 [2.4 CIDR+聚合](./2.4-cidr-aggregation.md#ch02-4-aggregate)（含 `192.1.12.0/22` 例题）

### 5）演进到 IPv6

| 项 | IPv6 |
|----|------|
| 长度 | **128 bit** |
| 编址 | **无分类**；常见单播 **/64 前缀 + 64 bit IID** |
| 广播 | **无**；用**组播**（如 `ff02::1` 所有节点） |
| 主机标识 | **IID**（≈ IPv4 主机号） |

## 二、单播 vs 广播 vs 组播（必考 · 新手易懂）

结合 IPv4/IPv6、路由规则与典型协议，一次性分清。

### 1）核心定义（通信方式）

| 类型 | 模式 | 说明 |
|------|------|------|
| **单播 Unicast** | **一对一** | 一个发送方 → **一个**接收方 |
| **广播 Broadcast** | **一对全体** | 一个发送方 → **本网段所有**设备（仅 IPv4） |
| **组播 Multicast** | **一对部分** | 一个发送方 → **加入该组**的设备 |

### 2）核心区别总表（直接背诵）

| 对比项 | 单播 | 广播 | 组播 |
|--------|------|------|------|
| 通信模式 | 一对一 | 一对全部（同子网） | 一对指定群组 |
| IPv4 是否存在 | ✅ 是 | ✅ 是 | ✅ 是 |
| IPv6 是否存在 | ✅ 是 | ❌ **彻底取消** | ✅ **完全替代广播** |
| 能否跨路由器 | ✅ 可路由转发 | ❌ 路由器默认阻断 | ✅ 可跨网段（IGMP/MLD） |
| 能否设为主机 IP | ✅ 正常主机地址 | ❌ 禁止分配 | ❌ 仅作目的地址 |
| IPv4 地址特征 | 主机位**非全 0/全 1** | 主机位**全 1** | D 类 **`224.0.0.0/4`** |

→ 与 MAC 单播/组播/广播对照及 **`01:00:5E` 映射**：[ch09.3](../../chapter09-broadcast-multicast/9.3-multicast-mac-mapping.md)
| IPv6 地址特征 | **`2000::/3`** 全球单播 | **无** | **`ff00::/8`**（`ff` 开头） |
| 典型协议/场景 | HTTP、TCP、上网、远程 | ARP、DHCP 发现 | 直播、IPTV、OSPF 等 |

→ 组播地址块详解：[2.5](./2.5-special-address.md) · 单播分配：[2.7](./2.7-unicast-allocation.md#ch02-7-unicast)

### 3）通俗举例

- **单播**：私聊，只发给**指定一个人**。
- **广播**：教室里大喊，**全班所有人**都听见。
- **组播**：兴趣小组通知，**只有进组的同学**能收到。

### 4）网段举例：`192.168.1.0/24`

| 地址 | 值 | 能否分配给主机 |
|------|-----|----------------|
| **网络地址** | 192.168.1.0（主机位全 0） | ❌ |
| **单播** | 192.168.1.1 – 192.168.1.254 | ✅ |
| **定向广播** | 192.168.1.255（主机位全 1） | ❌ 仅目的 |
| **受限广播** | 255.255.255.255 | ❌ 仅目的 |

### 5）考点补充（易混）

1. **IPv6 没有广播**  
   原广播功能用**组播**实现，如 **`ff02::1`** = 链路内所有节点（对照 v4 广播语义）。

2. **一对多时的流量效率**（同一份内容发给很多人）  
   **组播 > 单播 > 广播**  
   - 广播：子网内**每台**都要处理，浪费最大。  
   - 单播：N 个接收者往往要发 **N 份**拷贝。  
   - 组播：网络侧尽量**复制一份流**，只投递给订阅者（直播、流媒体）。

3. **使用限制**  
   - **网络地址**（主机位全 0）与**广播地址**（主机位全 1）**都不能**当主机 IP。  
   - 组播、广播**一般只做目的地址**，极少作源地址。

### 6）极简速记口诀

- **单播**：一对一，到处走，正常 IP 随便用  
- **广播**：一对全，不出网，主机位全 1，**IPv6 已淘汰**  
- **组播**：一对群，可路由，直播路由全靠它

## 三、广播计算与 IPv6 接口标识（IID）

### IPv4 广播（计算）

- **定义**：**主机位全 1**（在给定前缀下）。
- **计算**：`广播 = 网络地址 OR (NOT 掩码)`  
  例：`192.168.1.0/24` → **`192.168.1.255`**

| 类型 | 地址 | 行为 |
|------|------|------|
| **定向广播** | 主机位全 1 | 特定子网内所有主机 |
| **受限广播** | **`255.255.255.255`** | 仅本地链路，**路由器不转发** |

### IPv6 单播与 IID

```text
IPv6 单播（常见）= 网络前缀(常 64 bit) + 接口标识 IID(64 bit)
```

**IID 作用**：标识**接口**（≈ IPv4 主机号部分）。

| 生成方式 | 说明 |
|----------|------|
| **EUI-64** | 48 bit MAC → 中间插 **FF:FE** → 64 bit；第 1 字节 **U/L 位取反** |
| **隐私扩展** | 随机 IID，防 MAC 追踪 |

**EUI-64 例题**

```text
MAC：00-0C-29-0C-47-D5
→ 拆 24+24，中间 FF:FE → 000C:29FF:FE0C:47D5
→ U/L 取反 → IID：020C:29FF:FE0C:47D5
```

### 必背对比

| | IPv4 | IPv6 |
|---|------|------|
| **广播** | **有**（主机位全 1） | **无** |
| 同等功能 | 子网广播 / 255.255.255.255 | **组播**（如 **`ff02::1`**） |
| 接口标识 | 主机号（在前缀内） | **IID**（64 bit） |

## 四、30 秒写卷子（浓缩背诵）

**演进**  
1. 分类 A/B/C → 固定边界，浪费、表大  
2. 子网+掩码 → 划子网，FLSM，隔离广播域  
3. VLSM → 同网不同掩码，省地址  
4. CIDR → 无类前缀，路由聚合  
5. IPv6 → 128 位，/64+IID，无广播  

**单播 / 广播 / 组播**  
- 单播：一对一、`2000::/3`、正常 IP  
- 广播：一对全、不出网、主机位全 1；v6 **无**  
- 组播：`224/4`、`ff00::/8`；一对多效率 **组播 > 单播 > 广播**

**广播与 IID**  
- IPv4 广播 = **主机位全 1**；受限 = **255.255.255.255**  
- IPv6 **IID** = 接口 64 bit；**无广播**，用 **组播**

2. VLSM 和 FLSM 核心区别一词？  
3. IPv6 链路本地「所有节点」组播地址常记哪个？

<details>

2. **掩码是否可变长**（VLSM 同网可不同前缀；FLSM 固定）  
3. **`ff02::1`**
