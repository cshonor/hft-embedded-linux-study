## 一、二层交换机（只处理 MAC，数据链路层）

### 1. 核心硬件：交换芯片 / 交换矩阵

| 组件 | 说明 |
|------|------|
| **交换矩阵** | 交换机内部**高速数据通路** — 设备内「高速立交桥」，在各端口间**搬运帧** |
| **交换芯片** | 内嵌芯片，专做**二层转发** — **硬件转发**，不靠 CPU，极快 |

### 2. 核心数据表：MAC 地址表（二层表）

| 字段 | 说明 |
|------|------|
| **MAC 地址** | 主机/设备二层地址 |
| **端口** | 从哪个物理口学到 |
| **老化时间** | 超时删除，防表项陈旧 |

→ 学习机制：[3.4 §MAC 学习](3.4-bridge-switch-stp.md#ch03-4-switch) · 硬件总览：[3.12 §名词归类](3.12-switch-router-hardware.md#ch03-12-glossary)

### 3. 完整工作流程（极简）

| 步骤 | 动作 |
|------|------|
| ① | 端口收到帧，读**源 MAC** |
| ② | **学习**：「源 MAC → 入端口」写入 MAC 表 |
| ③ | 读**目的 MAC**，查 MAC 表 |
| ④a | **查到**（已知单播）→ 交换矩阵从**对应端口**发出（精准转发） |
| ④b | **查不到 / 广播 MAC `FF:FF…` / 组播 MAC** → **泛洪**到其他所有端口 |

```text
认 MAC → 查 MAC 表 → 交换矩阵硬件转发 → 只管本网段，不看 IP
```

**一句**：**认 MAC、查 MAC 表、靠交换芯片/矩阵硬件转发，管内网，不看 IP。**

## 二、路由器（处理 IP，网络层）

### 1. 核心数据表：路由表（三层表）

与 **MAC 表完全不是一回事**。

| 字段 | 说明 |
|------|------|
| **目标 IP 网段** | 前缀/掩码匹配 |
| **下一跳** | 下一台路由器或直连 |
| **出接口** | 从哪个口发出 |

### 2. 转发流程

| 步骤 | 动作 |
|------|------|
| ① | 收到帧，**拆掉二层头**，读**目的 IP** |
| ② | 查**路由表** → 得出**出端口 / 下一跳** |
| ③ | **重新封装**二层头（新目的 MAC 等），从对应口转发 |

### 3. 路由器硬件补充

| 项 | 说明 |
|----|------|
| **交换矩阵** | 高端路由器**也有** — 负责设备内部端口间高速传数据 |
| **区别** | **查什么表**：交换机矩阵 + **MAC 表**；路由器矩阵 + **路由表** |

**一句**：**认 IP、查路由表、跨网段/出网关，是不同网络之间的「大门」。**

<a id="ch03-12-glossary"></a>

## 三、名词归类（重点背诵）

| 名词 | 存在于 | 作用 |
|------|--------|------|
| **交换芯片 / 交换矩阵** | **交换机、高端路由器** | **硬件高速搬运数据** — 物理通道，不区分 L2/L3，只负责「传」 |
| **MAC 地址表** | **二层交换机** | 依据 **MAC**；**同 LAN 内**转发 |
| **路由表** | **路由器 / 三层交换机** | 依据 **IP 网段**；**跨网段、跨网关**转发 |

```text
矩阵/芯片 = 怎么搬（硬件通路）
MAC 表   = 交换机查什么（L2）
路由表   = 路由器查什么（L3）
```

## 四、场景串讲

### 场景 1：同网段两台电脑互传（只走交换机）

```text
电脑 A → 交换机端口 1
查 MAC 表 → 电脑 B 在端口 2
交换矩阵 → 端口 2
✅ 全程不看 IP、不走路由器、不用路由表
```

### 场景 2：电脑上网（交换机 + 路由器）

| 步骤 | 设备 | 动作 |
|------|------|------|
| 1 | 主机 | 目的 IP 不在本网段 → 发给**网关** |
| 2 | **交换机** | 查 MAC 表 → 转发到**路由器端口** |
| 3 | **路由器** | 拆 L2 头，查**路由表** → 外网出接口 |
| 4 | 路由器 | 内部交换矩阵 → 外网口 → 互联网 |

→ 网关/NAT：[ch07](../chapter07-firewall-nat/study.md)

## 五、三层交换机（企业常用）

**二层交换 + 三层路由 二合一**

| 项 | 说明 |
|----|------|
| **硬件** | 仍有**交换芯片 / 交换矩阵** |
| **表项** | 同时维护 **MAC 表 + 路由表** |
| **场景** | 内网不同 **VLAN / 网段** 互通，**不必外接路由器** |

→ VLAN：[3.2 §802.1Q](3.2-ethernet-ieee802-encapsulation.md#ch03-2-vlan-tci)

<a id="ch03-12-cheat"></a>

## 超精简口诀 / 考点

| 设备 | 口诀 |
|------|------|
| **交换机** | 认 **MAC**，查 **MAC 表**，交换矩阵搬数据，**管内网** |
| **路由器** | 认 **IP**，查 **路由表**，**管跨网段、出网关** |
| **交换芯片/矩阵** | **纯硬件通道**，交换机、路由器**都能用** |

| 易错 | 正确 |
|------|------|
| MAC 表 = 路由表 | **两张完全不同的表** |
| 路由器没有交换矩阵 | 高端路由器**常有**矩阵，差在**配哪张表** |
| 同网段也要过网关 | **同网段直连交换机**，**不经网关** |
| 交换芯片会查 IP | 交换芯片做 **L2 硬件转发**；**查 IP 是路由表+三层引擎** |

---

## 疑问与总结

**背：矩阵=搬数据；MAC表=交换机L2；路由表=路由器L3；同网段只交换机；上网交换机送网关+路由表查外网。**
