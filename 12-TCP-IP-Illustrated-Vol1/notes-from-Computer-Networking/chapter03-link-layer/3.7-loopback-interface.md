## 零、软件接口（API）— 别和环回口混名

> **软件接口** = 程序/模块之间按约定交换数据、调用功能的**交互点**（**代码层规范**，不是网线）。

| 类型 | 例子 |
|------|------|
| **API** | 支付接口、微信登录、系统函数调用 |
| **Web 接口** | REST（JSON/HTTP）、SOAP、gRPC |
| **模块间** | 函数、类方法、进程间调用 |

**作用**：解耦、复用、标准化，让不同语言/系统能互调。

**例**：Python 调 C++ 库 → 通过 **API** 传参拿结果。

> **易混**：这里的「接口」≠ 路由器上的 **Loopback 逻辑接口**（下文专讲）。

## 一、回环地址大白话（127.0.0.0/8 + 实操）

### 1）基础定义

**回环地址（Loopback）**：专门给**本机自己和自己通信**用的虚拟地址。

- **不经过真实网卡**，不走网线 / Wi‑Fi  
- 数据在**操作系统内部**直接折返  

| 项 | 说明 |
|----|------|
| **网段** | **127.0.0.0 ~ 127.255.255.255**（整个 **127.0.0.0/8**） |
| **最常用** | **127.0.0.1**（`localhost`） |
| **127.0.0.0** | 该网段的**网络号**，**不分配给主机**做通信 |

### 2）核心特点

| 特点 | 大白话 |
|------|--------|
| **与物理网卡无关** | 没插网线、没连 WiFi、禁用网卡，**127.0.0.1 仍能通** — 系统虚拟「内部通道」 |
| **本机都能访问** | 任意网卡、任意程序访问 `127.x.x.x`，都指向**本机自己** |
| **数据不出本机** | 发往 127 的包被 OS 拦截，**不进局域网、不上外网** |

### 3）例子

**例 1：本地 Web / 数据库**

- 服务监听 `127.0.0.1:8080`  
- **本机**浏览器打开 `http://127.0.0.1:8080` → ✅  
- **同 WiFi 另一台手机**访问 `127.0.0.1` → ❌（127 只认**当前这台**）

**例 2：自检协议栈**

```bash
ping 127.0.0.1
# Windows: ping 127.0.0.1 -n 4
```

| 结果 | 含义 |
|------|------|
| **能通** | 本机 **TCP/IP 协议栈正常**（与网线、路由器无关） |
| **不通** | 系统网络组件异常，先查驱动/协议栈 |

### 4）127.0.0.0 vs 127.0.0.1

| 地址 | 角色 |
|------|------|
| **127.0.0.0** | **网段标识**（网络号），代表整个 /8，**不用于主机通信** |
| **127.0.0.1** | 网段内**主机地址**，日常测试、本地服务**一律用它** |

### 5）路由表（对应「所有接口都能通」）

系统默认有一条规则：

```text
目标 127.0.0.0/8 → 全部走本地回环接口（lo / Loopback）
```

所以不管有多少物理网口，访问 127 网段最终都**导向本机内部**。

### 6）极简总结

1. **127.0.0.0/8** = 整段回环，**本机自访**。  
2. 日常用 **127.0.0.1**；**127.0.0.0** 只是网段名。  
3. **断网也能 ping 通**；数据**绝不离开本机**。  
4. 本机所有程序、所有接口都能访问它。

## 二、127.0.0.1 / ::1 与「不可路由」（规范补充）

### IPv4：127.0.0.0/8

| 项 | 内容 |
|----|------|
| **范围** | **127.0.0.0 – 127.255.255.255** |
| **常用** | **127.0.0.1**；主机名 **localhost** 常解析到此 |
| **行为** | 协议栈内折返，**不出物理网卡** |
| **路由** | **路由器不转发** → **不可路由** |

### IPv6：::1/128

与 **127.0.0.1** 同级：**IPv6 本机回环**，同样不可路由。

### 为何不可路由？

**RFC**：环回仅本机使用，不能跨路由器转发 → 防误进公网。

```text
应用 send → 目的 127.0.0.1 → 不进真实网卡 → 本机 recv
```

## 三、Loopback 环回接口（虚拟口）

| 点 | 大白话 |
|----|--------|
| **是什么** | **纯软件虚拟接口**，无物理网卡 |
| **状态** | **永远 Up** |
| **流量** | **不经过物理链路**，协议栈内折返 |

### 主机 vs 路由器（易混）

| | **PC / 服务器** | **路由器 / 三层交换机** |
|---|----------------|-------------------------|
| 127.0.0.1 | 系统自带**环回地址** | 也可用 |
| **Loopback 口** | 常指上述逻辑 | **独立虚拟接口** Lo0，可配**任意 IP**（如 **1.1.1.1/32**） |
| 要点 | 测本机服务 | **稳定标识**、Router-ID、管理 IP |

**掩码**：设备上环回口常 **/32**（255.255.255.255）作**设备标识**。

<a id="ch03-7-rid"></a>

## 四、Router-ID（路由协议「身份证号」）

| 项 | 说明 |
|----|------|
| **是什么** | OSPF/BGP 等里**唯一标识一台路由器**的 32 位 ID |
| **选举顺序（默认）** | ① **手动配置**（最高）→ ② **Loopback 口最大 IP**（推荐）→ ③ **物理口最大 IP** |
| **为何用 Loopback** | 物理口可能 Down、IP 会变 → ID 变 → **邻居震荡**；Loopback **永 Up、IP 固定** → **更稳** |

> **一句**：**Loopback = 路由器稳定虚拟身份证；Router-ID = 协议用这个身份证认设备。**

---

<a id="ch03-7-mgmt"></a>

## 五、远程管理（为何绑 Loopback）

| 项 | 说明 |
|----|------|
| **是什么** | 经 **SSH / Telnet / Web** 远程配设备，不用机房 **Console** |
| **为何用 Loopback IP** | **稳定**（物理口断管理不断）· **唯一好记** · 可 ACL **只放行环回 SSH** |
| **典型** | `Loopback0: 1.1.1.1/32` → 全网路由可达 → `ssh 1.1.1.1` |

> **一句**：**Loopback 当管理 IP = 远程管理更不怕物理口断线。**

<a id="ch03-7-traps"></a>

## 六、易混（避坑）

| ❌ 错 | ✅ 对 |
|------|------|
| IPv4 环回 **/24** | **127.0.0.0/8** |
| IPv6 环回 **FE80::1** | **::1/128**（FE80 = 链路本地） |
| Loopback **就是** 127.0.0.1 | 路由器上 **Loopback 口可配任意 IP**；127.0.0.1 是**环回地址** |
| **API** = Loopback 口 | **API** = 程序接口；**Loopback** = 网络虚拟接口 |

**localhost**：主机名，常解析到 **127.0.0.1**。

<a id="ch03-7-exam"></a>

## 七、考试速记表 + 五句背诵

| # | 考点 | 一句话 |
|---|------|--------|
| 1 | **软件接口/API** | 程序间通信约定，解耦与互调 |
| 2 | **127.0.0.0/8、::1** | 本机环回，**不可路由**，本地测试 |
| 3 | **Loopback 口** | 虚拟口 **永远 Up**；路由器上常 **/32** |
| 4 | **Router-ID** | 协议唯一 ID；优先**手动** → **Loopback 最大 IP** |
| 5 | **远程管理** | SSH 等；**Loopback IP** 保证管理稳定 |

### 五句专抄

1. **API**：程序间约定，≠ 环回网络接口。  
2. **127/8、::1**：本机专用，**路由器不转发**。  
3. **Loopback 口**：永 Up；路由器上可作 **RID / 管理 IP**。  
4. **Router-ID**：手动 > **Loopback 最大 IP** > 物理口最大 IP。  
5. **远程管理**：`ssh` 环回 IP，不怕物理口断。

## 八、自测

1. 127.0.0.2 算不算环回？为何不可路由？  
2. Loopback 口与 127.0.0.1 在路由器上有何区别？  
3. OSPF Router-ID 为何优先 Loopback？

<details>
<summary>参考答案</summary>

1. **算**（/8 整段）；RFC 规定**仅本机**，路由器**不转发**。  
2. **127.0.0.1** 是环回**地址**；**Loopback0** 是**接口**，可配如 **1.1.1.1/32**。  
3. Loopback **稳定不变**，避免物理口变化导致 **邻居关系震荡**。

</details>
