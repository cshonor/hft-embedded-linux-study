# 11.2 DNS 名称空间

> 章级精读：[../study.md#ch11-2](../study.md#ch11-2)

## 本节核心目标

掌握**倒置树**、TLD、FQDN 与命名规则。

---

## 层次（右→左读）

```text
www.example.com.
  │      │    └── 根（.）
  │      └── 二级域 / 注册域
  └── 主机名
```

| 层级 | 示例 |
|------|------|
| **TLD** | `.com` `.org` `.cn` |
| 二级域 | `example.com` |
| 主机 | `www.example.com` |

---

## 语法

- 标签长度、字符集限制（字母数字连字符等）；**FQDN** 常以根 `.` 结束。
