# 18.8 第 3 层 IP 安全 (IPsec)

> 章级精读：[../study.md#ch18-8](../study.md#ch18-8) · 自顶向下：[08 §8.4](../../../top_down/08_network_security/8.4_ipsec_vpn.md)

## 本节核心目标

掌握 **IKEv2、AH、ESP、NAT-T** 与 VPN 模式。

---

## 组件

- **IKEv2**：自动协商密钥与 SA
- **AH**：认证头部，**不加密**；校验含 IP 头 → **不过 NAT**
- **ESP**：封装安全负载，**可加密**；常配合 **NAT-T（UDP 4500）**

---

## 模式

| 模式 | 场景 |
|------|------|
| **传输** | 主机↔主机，保护载荷 |
| **隧道** | **Site-to-Site VPN**，封装整包 |

---

## NAT 穿越

- IPsec 与 NAT 天生冲突 → **NAT-T** 将 ESP 封在 UDP 中
