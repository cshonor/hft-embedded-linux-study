---

## 核心问题

---

## PKI 要素

| 概念 | 说明 |
|------|------|
| **CA** | 信任锚，签发证书 |
| **证书链** | 根 CA → 中间 CA → 站点证书 |
| **吊销** | **CRL** / **OCSP** 紧急作废泄露证书 |
