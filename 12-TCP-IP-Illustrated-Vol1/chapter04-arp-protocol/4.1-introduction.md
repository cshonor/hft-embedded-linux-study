# 4.1 引言

> 章级精读：[../study.md#ch04-1](../study.md#ch04-1) · 链路层：[ch03](../chapter03-link-layer/study.md) · ARP 安全：[3.10 §ARP](../chapter03-link-layer/3.10-link-layer-security.md#ch03-10-arp) · IPv6 ND：[ch08](../chapter08-icmpv4-icmpv6/study.md)

## 本节核心目标

理解 **ARP** 在 IPv4 中把 **IP 地址解析为 MAC 地址** 的使命。

---

<a id="ch04-1-why"></a>

## 一、ARP 是干嘛的？（大白话）

**一句话：ARP 是 IPv4 里专门负责「把 IP 翻译成 MAC」的协议。**

### 为什么需要 ARP？

| 层 | 用什么寻址 | 例子 |
|----|------------|------|
| **网络层（IP）** | **IP 地址** | 192.168.1.1 |
| **链路层（以太网）** | **MAC 地址**（48 位） | 00:11:22:33:44:55 |

要把 IP 包发到**局域网**里，网卡封装以太网帧时**必须知道下一跳的 MAC**；只有 IP、没有 MAC → **帧发不出去** → 需要 **ARP**。

### ARP 的定位

| 项 | 说明 |
|----|------|
| **工作范围** | **IPv4 + 同一广播域**（同一交换机 / 同一 Wi‑Fi，除非隔离） |
| **标准** | **RFC 826**（1982） |
| **IPv6** | **不用 ARP**，改用 **ND（Neighbor Discovery，邻居发现）**，走 **ICMPv6** → [§三](#ch04-1-nd) · [ch08](../chapter08-icmpv4-icmpv6/study.md) |

---

## 二、核心要点（逐条）

### 1）链路层看 MAC；发以太网前要有下一跳 MAC

```text
IP 包 → 交给网卡 → 封装以太网帧（源 MAC + 目的 MAC）
```

不知道**目的 MAC** → 发不出去 → 先 **ARP**。

### 2）ARP 在广播域内**动态**完成 IP→MAC

| 词 | 含义 |
|----|------|
| **动态** | 不用手配表，设备自己问、自己学 |
| **广播域** | 同交换机 / 同 Wi‑Fi；**跨路由器不行**（路由器不转发 ARP 广播）→ [4.2 广播域边界](./4.2-arp-basic-operation.md#ch04-2-broadcast-boundary) · [3.10](../chapter03-link-layer/3.10-link-layer-security.md#ch03-10-arp-lan) |

**极简流程**（细节见 [4.2](./4.2-arp-basic-operation.md)）

1. A 要发给 B，**ARP 缓存没有 B 的 MAC**  
2. A **广播 ARP 请求**：「谁是 192.168.1.2？请回复 MAC！」  
3. 全网收到，**只有 B** 认出来是问自己  
4. B **单播 ARP 应答**：「我是 192.168.1.2，MAC 是 xx:xx:xx:xx:xx:xx」  
5. A 写入 **ARP 缓存**（几分钟老化）→ [4.3](./4.3-arp-cache.md)

### 3）IPv6：ND 替代 ARP

<a id="ch04-1-nd"></a>

**ND** 不仅做 **IP→MAC**，还负责：

- 路由器发现、前缀发现  
- 邻居存活检测  
- 无状态地址自动配置（SLAAC）等  

报文多用 **组播/单播**，不像 ARP 那样**全广播**，效率与可控性更好。

## 三、何时触发 ARP？

### 1）本机发 IP 包，且目的 MAC 未知（缓存未命中）

- **第一次**访问该 IP  
- 缓存项**过期**（Linux/macOS 完整条目约 **20 分钟**；Windows 可更短）→ [4.6](./4.6-arp-cache-timeout.md#ch04-6-complete)  
- 对方**换网卡**（MAC 变了）

### 2）跨子网：ARP 的是**默认网关** MAC，不是远端主机

**例**：PC `192.168.1.10` 访问公网 `14.215.177.38`

| 错想 | 实际 |
|------|------|
| PC 去 ARP 百度的 IP | **不会**；百度不在本网段 |
| 正确 | PC **ARP 默认网关**（如 `192.168.1.1`）的 MAC → 帧发给网关 → 网关再路由到公网 |

→ 直接/间接交付：[4.2](./4.2-arp-basic-operation.md) · [路由表+ARP](./4.2-arp-basic-operation.md#ch04-2-route-arp) · 出网关后 [IGP/BGP](../chapter05-ip-protocol/5.4-ip-routing-basic.md#ch05-4-full-chain)

## 四、背诵

### 一句话

**ARP：IPv4 局域网里，用广播问出 IP 对应的 MAC，只在同广播域有效；跨网段只 ARP 网关；IPv6 用 ND 替代 ARP。**

### 三行笔记（可直接抄）

```text
1. ARP = IPv4 把 IP 翻成 MAC；发以太网帧前必须有目的 MAC。
2. 同广播域：广播问 → 单播答 → 写缓存；跨网段只 ARP 默认网关。
3. IPv6 不用 ARP，用 ND（ICMPv6），还能发现路由器/前缀。
```

## 自测

1. 为什么 IP 包下发以太网前还要 ARP？  
2. ARP 能否跨路由器找到外网主机 MAC？  
3. IPv6 用什么替代 ARP？

<details>
<summary>参考答案</summary>

1. 以太网帧头需要**目的 MAC**，IP 地址不能代替 MAC 交付。  
2. **不能**；跨网段只 ARP **下一跳/默认网关** 的 MAC。  
3. **ND（邻居发现）**，基于 **ICMPv6**。

</details>
