# 4.8 免费 ARP 和地址冲突检测 (ACD)

> 章级精读：[../study.md#ch04-8](../study.md#ch04-8) · DHCP 联动：[ch06](../../chapter06-dhcp-config/study.md)

## 本节核心目标

掌握 **Gratuitous ARP** 的**公告 MAC** 与 **ACD** 用途。

---

## 免费 ARP (Gratuitous ARP)

- 主机广播：目标 IP = **本机 IP** 的 ARP（常为请求形态）。
- **换网卡 / 故障转移**：通知邻居更新 **IP → 新 MAC**。

---

## 地址冲突检测 (ACD, RFC 5227)

- 配置新 IP 前先探测：若收到**应答** → 局域网内**已有设备占用**该 IP → 应放弃或重选。

---

## 易混（盲区）

- 免费 ARP **正常不期待回复**；**收到回复 = 冲突信号**，不是握手成功。
