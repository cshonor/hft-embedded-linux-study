## 本节核心目标

理解 ICMP 作为 IP **差错反馈与诊断** 辅助协议的定位。

---

## 核心要点

- IP **尽力而为** → 丢包、不可达、TTL 耗尽等需**标准方式**通知源端。
- ICMP **封装在 IP 数据报内**（IPv4 **Protocol = 1**；ICMPv6 **Next Header = 58**）。
- **不是**传输层协议；无端口，靠 **Type + Code** 区分语义。

## 分层识别：ICMP 不在以太网里标

**口诀**：**二层定三层，三层定内层（ICMP / TCP / UDP）**

| 层级 | 字段 | ICMP 举例 |
|------|------|-----------|
| **二层** | **EtherType = 0x0800** | 只知载荷是 **IPv4** |
| **三层** | **Protocol = 1** | 才知载荷是 **ICMP** |

**特例**：ICMP **本身就是网络层协议**，但标准规定**必须封装在 IP 里传输**，故标识只在 IP 头，**不会**出现在以太网头。

```text
以太网头 (EtherType=0x0800) + IP 头 (Protocol=1) + ICMP 数据
        ↓                           ↓
  二层判定：里面是 IPv4        三层判定：里面是 ICMP
```
