# 11.7 开放 DNS 服务器和 DynDNS

> 章级精读：[../study.md](../study.md)

## 本节核心目标

了解 **公共解析器** 与 **动态 DNS**。

---

## 开放解析器

- 如 `8.8.8.8`、`1.1.1.1` — 任何客户端可查询。
- 风险：被用于**放大攻击**若配置不当 → [11.12](11.12-dns-security-threat.md)

---

## DynDNS / DDNS

- 家庭宽带 **公网 IP 常变** → 客户端或路由器向服务商更新 **A 记录**。
- 与 [ch06 DDNS](../../chapter06-dhcp-config/6.4-dhcp-dns-ddns.md) 企业场景类似。
