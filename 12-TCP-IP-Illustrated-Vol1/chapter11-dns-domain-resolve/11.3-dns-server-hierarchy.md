# 11.3 名称服务器和区域

> 章级精读：[../study.md#ch11-3](../study.md#ch11-3) · 递归迭代：[11.4 缓存](11.4-dns-cache.md)

## 本节核心目标

理解 **Zone**、**权威服务器** 与分层委托。

---

## 角色

| 角色 | 职责 |
|------|------|
| **根服务器** | 指向 TLD 权威 |
| **TLD 服务器** | `.com` 等 |
| **权威 NS** | 持有本 **Zone** 的 RR |
| **解析器（递归）** | 代客户端迭代查询并缓存 |

---

## 区域 (Zone)

- 一段名称空间的管理边界；**区域文件** 含该 zone 的 RR。
- **区域传输** 在从服务器间同步 → 常用 **TCP** → [11.5](11.5-dns-packet-structure.md)

---

## 查询类型

- **递归**：解析器替你查到底（客户端→解析器）。
- **迭代**：服务器只给**下一跳**线索（解析器↔权威链）。
