# 5.8 总结

> 章级精读：[../study.md#ch05-exam](../study.md#ch05-exam)

## 本节核心目标

收束 IP 层“细腰”角色与 v4→v6 演进。

---

## 精髓

- **统一 IP 地址** 掩盖底层异构链路（以太网/Wi‑Fi/PPP…）。
- **无连接尽力而为** + **LPM 转发** = 全球可扩展路由基础。

---

## v4 → v6

| 方向 | 要点 |
|------|------|
| 地址 | 枯竭 → 海量空间 |
| 头部 | 可变+分片 → **固定 40B + 扩展头** |
| 主机 | 多地址选择、SLAAC 等 |
