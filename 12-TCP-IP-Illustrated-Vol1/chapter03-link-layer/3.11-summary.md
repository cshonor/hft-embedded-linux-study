# 3.11 总结

> 章级精读：[../study.md#ch03-exam](../study.md#ch03-exam)

## 本节核心目标

回顾链路层从**共享以太网 → 全双工交换 → 无线 Wi‑Fi** 的进化及对 IP 的支撑。

---

## 一页脉络

```text
多介质接入（以太网 / Wi-Fi / PPP）
  → 帧封装 + MAC 交付
  → MTU/PMTUD 约束 IP 包大小
  → 交换 + STP 扩展 LAN
  → 隧道跨异构网
```

---

## 介质对照（速记）

| 链路 | 典型 MTU | 备注 |
|------|----------|------|
| 以太网 | 1500 | 最常见 |
| 802.11 | ~2300+ | 仍受路径 PMTU 限制 |
| 环回 | 很大 | 本机测试 |
