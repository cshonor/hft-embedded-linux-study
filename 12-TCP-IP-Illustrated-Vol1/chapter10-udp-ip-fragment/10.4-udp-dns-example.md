# 10.4 例子

> 章级精读：[../study.md](../study.md) · DNS 章：[ch11](../../chapter11-dns-domain-resolve/study.md)

## 本节核心目标

用 **DNS 查询** 理解 UDP 请求-应答无握手。

---

## 典型流程

1. 客户端 `sendto` DNS 查询 → 目的 **UDP/53**
2. 服务器 `recvfrom` → 处理 → `sendto` 应答
3. **无** SYN/握手；丢包靠**应用超时重试**

---

## 抓包

- Wireshark：`udp.port == 53`
- 常与 **IP 分片** 无关（小包）；大包 DNS（EDNS0）需注意 MTU → [10.7](10.7-ip-fragment-mechanism.md)
