# 10.11 UDP 服务器的设计

> 章级精读：[../study.md#ch10-8](../study.md#ch10-8) · 自顶向下 Socket：[§2.7](../../../top_down/02_application_layer/2.7_socket_programming_udp.md)

## 本节核心目标

掌握 **bind、REUSE、无拥塞控制** 与多进程负载均衡。

---

## 绑定规则

| 绑定 | 含义 |
|------|------|
| `0.0.0.0` + 端口 | 所有接口上该端口 |
| 特定 IP + 端口 | 仅该接口 |

- 匹配：**目的 IP+端口** 落到最合适 socket。

---

## 端口复用

- **`SO_REUSEADDR`**：重启后快速绑定 TIME_WAIT 端口（TCP 更多；UDP 重启监听）。
- **`SO_REUSEPORT`**（Linux）：多进程**内核负载均衡**同一 UDP 端口。

---

## 无流量控制

- 发送过快 → 接收 socket 缓冲满 → **丢包**；还可恶化路由器队列。
- 需应用层**限速**、FEC、或改用 QUIC/TCP。
