# 10.14 与 UDP 和 IP 分片相关的攻击

> 章级精读：[../study.md#ch10-9](../study.md#ch10-9) · IP 分片攻击：[ch05 §5.7](../../chapter05-ip-protocol/5.7-ip-attacks.md)

## 本节核心目标

认识 **放大反射 DDoS** 与 **Teardrop 类分片攻击**。

---

## 放大反射 (Amplification)

- 伪造受害者源 IP → 向 **DNS/NTP** 等发**小查询**。
- 服务器向受害者回**大应答** → 流量放大。
- 缓解：源过滤 BCP38、响应速率限制、**DNSSEC 无关但 RRL**。

---

## 分片攻击

- 重叠/畸形片 → 重组 bug → 历史 **内核崩溃**。
- 缓解：现代内核加固、边界**丢弃可疑分片**。

---

## UDP 无连接

- 更易被用于**反射**；应用层需认证（QUIC/TLS）。
