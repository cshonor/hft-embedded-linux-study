# 10.7 IP 分片

> 章级精读：[../study.md#ch10-5](../study.md#ch10-5) · [§10.7 算例](../study.md#ch10-6) · MTU：[ch03 §3.8](../../chapter03-link-layer/3.8-mtu.md)

## 本节核心目标

掌握 v4 **Identification、MF、片偏移** 与**任一片丢失则整报文报废**。

---

## 为何危险（UDP 开发者必背）

- 应用一次发送 **> MTU−IP头−UDP头** → IPv4 **路由器可分片**。
- 接收端重组：**一片丢失 → 全部片超时丢弃** → 应用看到**整包丢失**。

---

## 关键字段

| 字段 | 作用 |
|------|------|
| Identification | 同属一片的 ID |
| MF | 还有更多片 |
| Fragment Offset | 片在原始报文中的位置（8 字节单位） |

---

## 现代实践

- **避免 IP 分片**：单 UDP ≤ **~1200–1400 B**（QUIC 常用 1200）。
- v6：**仅源节点分片**；路径用 PTB → [10.8](10.8-udp-pmtud.md)
