# 6.8 属性声明：format

## 本节讲什么

**`__attribute__((format(printf, fmt_idx, arg_start)))`** 让 GCC 对 **自定义 printf 风格函数** 做 **格式串与实参** 编译期检查，捕获 `%d` 配 `"string"` 类错误。内核 `printk`、DPDK `RTE_LOG`、自研日志层都依赖此属性。

## 要点

```c
void my_log(int level, const char *fmt, ...)
    __attribute__((format(printf, 2, 3)));
```

- 第 2 参为 format 串下标（从 1 计）
- 第 3 参为 **第一个可变参** 下标
- 配合 **6.12** 宏转发 `...`

## 代码自测

**题目 1：** 以下自定义日志函数加了 `format` 属性，它的作用是什么？不加会怎样？
```c
void my_log(const char *fmt, ...)
    __attribute__((format(printf, 1, 2)));

my_log("%d %s\n", "hello", 42);  // 这里会怎样？
```

<details>
<summary>参考答案</summary>

`format(printf, 1, 2)` 告诉编译器：第 1 个参数是格式串，第 2 个参数起是可变参数，按 `printf` 规则检查。调用 `my_log("%d %s\n", "hello", 42)` 时编译器报警告：`%d` 期望 int 但传了 char*，`%s` 期望 char* 但传了 int。不加 `format` 属性则编译器不检查格式串与参数的匹配，运行时才崩溃。内核的 `printk`、`pr_err` 等都有此属性。

</details>
