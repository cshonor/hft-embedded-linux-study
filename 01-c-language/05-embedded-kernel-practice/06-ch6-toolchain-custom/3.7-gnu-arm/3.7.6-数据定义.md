# 3.7.6 数据定义

## 本节讲什么

在汇编中 **静态分配** 数据：字符串、表、中断向量常数——与 C 全局对象一样进入 `.data`/`.rodata`。

## 要点

```arm
    .data
gpio_table:
    .word 0x1000, 0x1004, 0x1008
msg:
    .asciz "Hello\n"
    .align 2
count:
    .int 42
    .skip 16, 0xFF
```

| 伪操作 | 含义 |
|--------|------|
| `.int` / `.long` | 32 位字 |
| `.asciz` | 以 0 结尾字符串 |
| `.skip n, fill` | 预留 n 字节 |
| `.incbin "blob.bin"` | 嵌入二进制 |

- 向量表：`.word reset, undef, swi, prefetch, data, irq, fiq`
- 与 C `const uint32_t gpio_table[]` 可 `extern` 互引

## 代码自测

**题目 1：** 以下 GNU ARM 汇编数据定义各分配多少字节？初始值是什么？
```c
.byte 0x41        @ ?
.hword 0x1234      @ ?
.word 0xDEADBEEF   @ ?
.ascii "Hello"     @ ?
.space 16          @ ?
```
<details>
<summary>参考答案</summary>

- `.byte 0x41`：1 字节，值 0x41（字符 A）
- `.hword 0x1234`：2 字节（半字），值 0x1234
- `.word 0xDEADBEEF`：4 字节（字），值 0xDEADBEEF
- `.ascii "Hello"`：5 字节（不含 NUL），字符串 "Hello"
- `.space 16`：16 字节，全零（未初始化空间）

对应 C：`char`/`short`/`int`/`char[]`/`char buf[16]`。
`.ascii` 不加 NUL，`.asciz` 自动加 NUL（6 字节）。

</details>
