# 2.6 数组下标与结构体成员

## 本节讲什么

下标、成员访问的语法糖背后是指针运算；**优先级** 决定 `&st.member` 如何分组。可读性陷阱 `i[a]` 语法合法但应禁止。

## 要点

### 下标等价

```c
a[i]  等价  *(a + i)
i[a]  等价  *(i + a)  /* 语法合法：交换律，禁止在工程代码中使用 */
```

[Expert C ch04](../../03-Advanced-Expert-C-Programming/ch04-arrays-are-not-pointers/) 强调数组 ≠ 指针，但 **下标运算符** 仍是指针算术语法糖。

### 结构体成员优先级

| 写法 | 解析 |
|------|------|
| `st.member` | 成员访问 |
| `p->member` | `(*p).member` |
| `&st.member` | `&(st.member)` — **`.` 高于 `&`** |
| `&p->member` | 正确取成员地址 |

错误理解：`*p.member` 等价 `*(p.member)`（把 member 当指针）—— 实际是 `*(p->member)` 需看 p 类型。

## 代码自测

**题目 1：** 以下声明分别是什么？
```c
int a[10];           // ?
struct Point { int x, y; } p, *q;  // ?
int b[10], c[20];    // ?
```

<details>
<summary>参考答案</summary>

`int a[10]` — 10 个 int 的数组
`struct Point { ... } p, *q` — 定义结构体 Point 的同时声明变量 p 和指针 q
`int b[10], c[20]` — b 是 10 个 int 的数组，c 是 20 个 int 的数组（不是 2D 数组）
注意：`int a, b[10]` 中 a 是 int，b 是 int[10]——数组分量只作用于紧邻的标识符。

</details>
