# 7.5 指针宽度随架构变化

## 本节讲什么

32 位系统指针 **4 字节**，64 位 **8 字节**。用 `int` 保存指针在 32 位「碰巧能跑」，64 位 **截断高 32 位**，句柄/回调/内核 user pointer 全面失效。

## 要点

```c
void *buf = malloc(64);
int addr = (int)(uintptr_t)buf;   /* 64 位：截断，灾难 */
```

### 规范

```c
#include <stdint.h>
uintptr_t u = (uintptr_t)ptr;
void *p = (void *)u;
```

- 指针 ↔ 整数：**`uintptr_t` / `intptr_t`**
- 不要用 `unsigned long` 代替（LP64 下 long 8 字节但 Windows LLP64 下 4 字节）

## 代码自测

**题目 1：** 以下代码在 32 位和 64 位平台上有什么不同？
```c
int* p = malloc(100);
printf("%d\n", (int)p);  // 把指针转 int
```

<details>
<summary>参考答案</summary>

32 位平台：指针 4 字节，转 int 安全。64 位平台：指针 8 字节，int 4 字节——截断高位，指针值错误。应使用 `intptr_t`/`uintptr_t`（`<stdint.h>`）：
```c
printf("%" PRIdPTR "\n", (intptr_t)p);
```
`intptr_t` 保证能安全存放指针值的整数类型。

</details>
