# 1.5 GDB 源码级调试

## 本节讲什么

**gdb** 断点、单步、看内存、backtrace、**core** —— 定位空指针/栈溢出/段错误，Linux C 开发必备调试器。

## GDB 定位

**GDB**（GNU Debugger）是 GNU 项目下的命令行程序调试器，主要调试 C/C++、汇编等编译型程序，Linux/Unix 环境标准调试工具。

> **GDB vs GDP**：GDB 是 GNU 调试器（程序员工具）；GDP 是国内生产总值（经济指标）。完全无关。

## 能干什么

| 能力 | 说明 |
|------|------|
| 启动程序 | 可带参数运行待调试程序 |
| 设置断点 | 程序跑到断点就暂停 |
| 单步执行 | 一条语句 / 一条汇编指令 |
| 查看/修改内存 | 寄存器、变量、任意内存地址 |
| 崩溃分析 | 段错误 core dump，定位崩溃行号 |
| attach 进程 | 调试正在运行的进程（不停机排查） |

## 核心流程

```bash
gcc -g -O0 -Wall main.c -o app    # -g 打入 DWARF 调试信息
gdb ./app                         # 启动 GDB
```

```
(gdb) break main     → (gdb) run → (gdb) next/step → (gdb) print var → (gdb) bt → (gdb) quit
```
