# 1.3.3 Git 常用命令

## 本节讲什么

嵌入式工程 **Git 日常流程** 与 **.gitignore** 模板。

## 要点

```bash
git init
git add main.c Makefile
git commit -m "ch01: add gcc demo"
git branch feature-gdb
git checkout feature-gdb   # 或 git switch
git merge main
git log --oneline
git diff
```

### .gitignore（嵌入式）

```gitignore
*.o *.a *.so
*.i *.s
app app.arm
build/
core
*.swp
.vscode/
```

| 忽略 | 原因 |
|------|------|
| ***.o / build/** | 可再编译 |
| **core** | gdb 转储 |

### 冲突

```bash
git status
# 编辑冲突文件 → git add → git commit
```

## 代码自测

**题目 1：** 以下 Git 命令序列完成了什么操作？
```c
git init
git add .
git commit -m "init"
git remote add origin <url>
git push -u origin main
```
<details>
<summary>参考答案</summary>

1. `git init`：初始化本地仓库
2. `git add .`：将所有文件加入暂存区
3. `git commit -m "init"`：提交到本地仓库
4. `git remote add origin <url>`：关联远程仓库
5. `git push -u origin main`：推送到远程 main 分支，`-u` 设置上游跟踪

`git log --oneline` 查看提交历史，`git diff` 查看未暂存的改动。

</details>
