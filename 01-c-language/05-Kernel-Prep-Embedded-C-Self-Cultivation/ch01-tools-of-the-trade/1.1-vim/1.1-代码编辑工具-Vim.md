# 1.1 代码编辑工具：Vim

## 本节讲什么

**Linux Shell + Vim** —— 嵌入式标准开发方式：脱离 IDE，命令行可见、可追溯。

## 要点

### Shell 基础（WSL/Linux）

| 类别 | 命令 |
|------|------|
| 文件 | `cd` `ls` `mkdir` `cp` `rm` `find` `tree` |
| 文本 | `cat` `grep` `sed` `awk` |
| 进程 | `ps` `top` `kill` |
| 权限 | `chmod` `ln -s` |

```bash
grep -rn "main" *.c
find . -name "*.o" -delete
```

- **bash 脚本**为 **1.6 buildenv** 铺垫

### Vim 定位

- 服务器/板卡无 GUI IDE 时的默认编辑器
- 三种模式：**普通 / 插入 / 命令**

## 代码自测

**题目 1：** Vim 有哪几种主要模式？如何在这些模式之间切换？
<details>
<summary>参考答案</summary>

Vim 有四种主要模式：
- **普通模式**（默认）：按 `Esc` 进入，用于移动和命令
- **插入模式**：按 `i`/`a`/`o` 进入，用于输入文本
- **可视模式**：按 `v`（字符）/`V`（行）/`Ctrl+v`（块）进入，用于选中文本
- **命令行模式**：普通模式下按 `:` 进入，用于保存退出等

核心原则：用 `Esc` 回到普通模式，普通模式是"家"。

</details>
