# 1.4 ELF 二进制分析工具

## 本节讲什么

**nm / readelf / objdump / size / hexdump** —— 查看符号、段布局、反汇编；DPDK & Linux 内核二进制必备三件套。

## 三者分工

| 工具 | 核心用途 | 主要看什么 |
|------|----------|-----------|
| **nm** | 符号表 | 函数、全局变量，哪些导出、未定义 |
| **readelf** | ELF 元信息 | 程序头、节、符号表、重定位、dynamic 段 |
| **objdump** | 反汇编 | 机器码→汇编；段内容、重定位 |

> 关键：GDB 是运行时调试；nm/readelf/objdump 是**静态分析**，程序不用跑，直接分析磁盘上的二进制文件。

## 速查

```bash
# nm —— 查符号
nm -D libdpdk.so | grep rte_     # DPDK 导出 API
nm -u mod.ko                     # 内核模块依赖的外部符号

# readelf —— ELF 结构
readelf -h a.out                 # ELF 头（类型、架构、入口）
readelf -S a.out                 # 所有节 .text .data .bss
readelf -l a.out                 # 程序段（LOAD 视图）
readelf -r mod.ko                # 重定位信息（.ko 灵魂）
readelf -d libdpdk.so            # dynamic 段（依赖哪些 .so）

# objdump —— 反汇编
objdump -d a.out                 # 反汇编 .text
objdump -S a.out                 # 源码 + 汇编混排（需 -g）
objdump -d --disassemble=main a.out  # 只看指定函数

# 其他
size a.out                       # text data bss 十进制
hexdump -C a.out | head          # 原始字节
```

## nm 符号类型速记

| 标记 | 含义 |
|------|------|
| `T`/`t` | 代码段函数（大写=全局，小写=static） |
| `D`/`d` | 已初始化数据 |
| `B`/`b` | BSS 未初始化数据 |
| `U` | 未定义（需要外部链接提供） |
