# 6.10.1 属性声明：noinline

## 本节讲什么

**`noinline`** 禁止内联；**`always_inline`** 强制内联。用于 **调试栈回溯**、**控制代码体积** 或 **极热路径必 inline**。

## 要点

```c
__attribute__((noinline))
static int cold_path(int x) { return x * 2; }

static inline __attribute__((always_inline))
int hot_add(int a, int b) { return a + b; }
```

```bash
gcc -O2 -S inline_demo.c -o inline_demo.s
grep -E 'call|hot_add' inline_demo.s
```

## 代码自测

**题目 1：** 为什么有时要刻意阻止编译器内联？给出一个场景。
```c
__attribute__((noinline))
void slow_path(void) { /* heavy computation */ }

void hot_loop(void) {
    for (int i = 0; i < 1000000; i++) {
        if (rare_condition()) slow_path();
    }
}
```

<details>
<summary>参考答案</summary>

阻止内联的原因：(1) 避免 hot_loop 函数过大——内联展开会增加指令缓存压力，反而降低性能；(2) rare_condition 大部分为假，slow_path 展开是浪费 I-cache；(3) 调试时 noinline 函数有独立栈帧，GDB 可以断点；(4) 减少代码体积（嵌入式 Flash 有限）。内核 `noinline` 常用于错误处理路径、调试函数、不希望膨胀的热路径。

</details>
