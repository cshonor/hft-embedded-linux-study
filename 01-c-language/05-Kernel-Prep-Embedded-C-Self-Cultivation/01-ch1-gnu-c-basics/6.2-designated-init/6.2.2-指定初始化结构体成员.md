# 6.2.2 指定初始化结构体成员

## 本节讲什么

结构体用 **`.member = value`** 初始化，顺序任意、可只写部分成员。嵌套结构体、数组字段同样支持 designated。这是内核 **`file_operations`**、**`of_device_id`** 等结构最常用写法。

## 要点

```c
struct point {
    int x, y, z;
};

struct point p = { .y = 10, .x = 20 };  /* z 自动为 0 */

struct nested {
    struct point origin;
    const char *label;
};

struct nested n = {
    .label  = "sensor_a",
    .origin = { .x = 1, .y = 2 },
};
```

```c
/* 静态 const 配置 — DPDK 风格示意 */
struct port_conf {
    uint16_t rx_queues;
    uint16_t tx_queues;
    uint32_t promisc : 1;
};

static const struct port_conf eth0 = {
    .rx_queues = 4,
    .tx_queues = 4,
    .promisc   = 0,
};
```

| 写法 | 优点 |
|------|------|
| `.field = v` | 重构字段顺序时 diff 小 |
| 指定 + 省略 | 默认值 0，表项只写差异 |

```c
/* C99 compound literal + designated */
struct point tmp = (struct point){ .x = 1, .y = 2 };
```

## 代码自测

**题目 1：** 以下两种结构体初始化方式有什么区别？哪种更好？
```c
struct point { int x, y; };
// 方式A: C89 位置初始化
struct point p1 = { 10, 20 };
// 方式B: C99 指定初始化
struct point p2 = { .x = 10, .y = 20 };
```
<details>
<summary>参考答案</summary>

方式 A（位置初始化）：按成员声明顺序赋值，必须记住顺序。若结构体改了成员顺序，初始化值会错位。

方式 B（指定初始化）：按成员名赋值，不依赖顺序。即使结构体改了成员顺序或新增成员，初始化仍然正确。

方式 B 更好的原因：
1. **可读性**：`.x = 10` 明确知道在初始化哪个成员
2. **健壮性**：结构体新增成员时，旧代码不受影响（新成员自动 0）
3. **安全性**：不会因为顺序错误导致误赋值

Linux 内核统一使用指定初始化：
```c
struct file_operations fops = {
    .open = my_open,
    .read = my_read,
    .release = my_release,
};
```

</details>
