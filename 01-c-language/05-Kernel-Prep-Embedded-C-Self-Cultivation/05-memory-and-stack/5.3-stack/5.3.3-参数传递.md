# 5.3.3 参数传递

## 本节讲什么

**AAPCS** 规定：前 4 个整型/指针参数用 **r0–r3**，第 5 个起 **入栈**；浮点另有 VFP 规则。返回值 **r0**（64 位用 r0+r1）。结构体过大则传指针或按规则拆寄存器。

## 要点

### 寄存器 vs 栈

```c
void foo(int a, int b, int c, int d, int e) { /* e 在栈上 */ }
```

```bash
arm-linux-gnueabihf-gcc -S -O0 -o - foo.c   # 看 r0–r3 与 [sp, #offset]
# x86_64 不同：rdi, rsi, rdx, rcx, r8, r9 后入栈
```

| 类型 | ARM 32（AAPCS） |
|------|-----------------|
| int/pointer | r0–r3，余者栈 |
| 返回值 | r0 |
| 被调者保存 | r4–r11, fp |
| 调用者保存 | r0–r3, lr |

### 数组与指针

- 数组作实参 **退化为指针**，传地址（4 字节），不拷贝整数组
- **内核** 拷贝用户缓冲区：`copy_from_user()`，避免直接解引用用户指针

### GDB

```bash
(gdb) break foo
(gdb) run
(gdb) info args
(gdb) print/x $r0 $r1 $r2 $r3
(gdb) x/4wx $sp    # 栈上第 5 个参数
```

## 代码自测

**题目 1：** ARM ATPCS 下函数参数如何传递？超过 4 个参数时怎么办？
```c
int func(int a, int b, int c, int d, int e, int f) {
    return a + b + c + d + e + f;
}
```
<details>
<summary>参考答案</summary>

ATPCS 参数传递规则：
- 前 4 个参数通过 R0-R3 传递：a→R0, b→R1, c→R2, d→R3
- 第 5 个起压栈：e→[SP], f→[SP+4]
- 返回值在 R0（64 位用 R0+R1）

调用 `func(1,2,3,4,5,6)`：
```asm
MOV R0, #1
MOV R1, #2
MOV R2, #3
MOV R3, #4
PUSH {R0}      @ 临时用R0存5
MOV R0, #6     @ 不对，应该先压第6个
```

实际：参数 5,6 逆序压栈（右到左）：
```asm
MOV R0, #6
PUSH {R0}      @ f=6
MOV R0, #5
PUSH {R0}      @ e=5
MOV R0, #1; MOV R1, #2; MOV R2, #3; MOV R3, #4
BL func
ADD SP, SP, #8 @ 清理栈上参数
```

浮点参数用 VFP 寄存器 S0-S15。

</details>
