# 6.11.2 常用的内建函数

## 本节讲什么

嵌入式/内核/DPDK 常见 **`__builtin_*`**：位计数、字节序、prefetch、return address。

## 要点

```c
int lz  = __builtin_clz(1u);
int pop = __builtin_popcountll(mask);
uint32_t sw = __builtin_bswap32(0x01020304);
__builtin_prefetch(p + 64, 0, 3);
void *ra = __builtin_return_address(0);
```

| Builtin | 场景 |
|---------|------|
| `__builtin_prefetch` | 包处理 prefetch |
| `__builtin_bswap*` | 网络 endian |
| `__builtin_expect` | 分支布局 |

## 代码自测

**题目 1：** 以下内建函数分别做什么？在什么场景下使用？
```c
int c = __builtin_clz(0x10);      // (A)
int p = __builtin_popcount(0xF0); // (B)
void __builtin_prefetch(ptr);     // (C)
if (__builtin_expect(x, 0)) { }   // (D)
```

<details>
<summary>参考答案</summary>

(A) `clz` = count leading zeros，`0x10` = `0b10000`，前导零 27（32位），用于快速求 log2 或对齐计算；(B) `popcount` = 数 1 的个数，`0xF0` 有 4 个 1，用于位图统计；(C) `prefetch` = 预取数据到缓存，用于已知即将访问的地址提前加载（如遍历链表前预取下一个节点）；(D) `expect` = 分支预测提示，告诉编译器 `x` 大概率为 0，让编译器把 else 分支放在 if 后面（指令缓存友好）。内核 `likely()`/`unlikely()` 就是 `__builtin_expect`。

</details>
