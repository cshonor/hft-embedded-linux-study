题目 1： 芯片制造的基本流程是什么？从沙子到芯片经历哪些主要步骤？

参考答案

基本流程：硅提炼 → 单晶硅锭生长 → 切割晶圆 → 光刻（多次） → 刻蚀 → 离子注入 → 金属化 → 封装测试。光刻是核心步骤——用紫外光通过掩模在硅片上转印电路图案。芯片制造是现代工业皇冠上的明珠，涉及物理、化学、材料等多学科。

2.1

.1 从沙子到单晶硅

本节讲什么

石英砂 → 高纯单晶硅锭 → 晶圆 —— 芯片的物理起点。

要点

  1. 提纯：SiO₂ 还原得冶金硅，再化学提纯至 99.9999999%（9N）
  2. 拉晶（CZ）：熔融硅中旋转拉出单晶锭，控制晶向（如 ⟨100⟩）
  3. 切片与抛光：锭 → 薄圆片（Wafer），直径 200/300 mm
  4. 氧化/光刻起点：表面生长 SiO₂ 作绝缘与掩膜基底
  • 晶圆上划片后得 Die；良率影响成本
  • 嵌入式 MCU 常用 8"/12" 线；高端 x86/ARM 服务器芯片用更先进制程

与后续衔接

2.1.2 在硅上构造 PN 结；2.1.3 光刻成电路。

代码自测

题目 1： 为什么芯片制造使用硅而不是其他材料？单晶硅的制造方法是什么？

参考答案

硅的优势：(1)储量丰富（沙子主要成分是 SiO2）；(2)半导体特性适合制造晶体管；(3)能形成稳定的氧化层 SiO2 作为绝缘层。单晶硅制造用直拉法（CZ法）——将多晶硅在石英坩埚中熔化，用籽晶提拉生长出单晶硅锭。

2.1

.2 PN 结的工作原理

本节讲什么

P 型 / N 型掺杂 + PN 结 —— 晶体管与二极管的物理开关。

要点

概念 说明
掺杂 P：缺电子（空穴）；N：多余电子
耗尽层 结区无自由载流子，形成势垒
正向偏置 导通，电流通过
反向偏置 截止，仅极小漏电流
  • MOSFET：Gate 电压控制沟道，实现 0/1 开关 → 逻辑门 → CPU
  • 漏电流与 静态功耗 相关；低功耗 MCU / 移动端 SoC 重点优化

与后续衔接

2.1.3 数十亿晶体管组成运算器与存储单元；2.2.2 寄存器/ALU 的硬件根基。

代码自测

题目 1： PN 结的导电特性是什么？为什么二极管只允许单向导通？

参考答案

PN 结在正向偏置时导通（P接正极、N接负极），反向偏置时截止。原理：P 区空穴多、N 区电子多，交界处形成耗尽层和内建电场。正向偏置削弱内建电场，载流子穿过形成电流；反向偏置增强内建电场，阻止载流子通过。PN 结是晶体管和芯片的基础。

光刻 + 掺杂 + 多层互联 把 PN 结堆叠成完整数字电路。

设计(RTL) → 版图 → 光刻 → 刻蚀/沉积 → 重复多层 → 测试 → 划片

代码自测

题目 1： CMOS 电路由什么组成？为什么 CMOS 静态功耗低？

参考答案

CMOS 由 PMOS 和 NMOS 互补对组成。静态功耗低是因为在稳定状态下，PMOS 和 NMOS 只有一个导通，另一个截止——没有从 VDD 到 GND 的直流通路（理想情况下静态电流为零）。功耗主要来自开关切换时的动态功耗和漏电流。

题目 1： 芯片封装的作用是什么？BGA 和 QFP 封装有什么区别？

参考答案

封装作用：(1)保护芯片；(2)散热；(3)电气连接芯片引脚到 PCB。QFP（四侧引脚扁平封装）引脚从侧面伸出，间距较大，手工焊接较容易。BGA（球栅阵列）引脚是底部焊球，密度高、信号完整性好，但需要专用设备焊接。嵌入式产品常用 QFP/BGA。

.1 计算机理论基石：图灵机

本节讲什么

图灵机模型 —— 证明「什么可计算」，为 CPU「取指-执行」提供理论原型。

要点

无限纸带 + 读写头 + 有限状态 + 转移规则
要素 对应现代 CPU
纸带 内存
读写头 总线访问
状态 PC + 寄存器
规则表 指令译码
  • 丘奇-图灵论题：可计算函数 ≡ 图灵机可计算
  • 实际 CPU 是 有限内存 + 有限状态 的图灵机实现
  • HFT 策略再复杂，最终仍归结为 有限步骤的指令序列

题目 1： 图灵机由哪些部分组成？它和现代 CPU 有什么关系？

参考答案

图灵机组成：无限长纸带、读写头、状态寄存器、规则表。关系：图灵机是计算的理论模型，现代 CPU 是其物理实现——纸带对应内存，读写头对应 PC/MAR，规则表对应指令集。图灵机证明了"可计算性"的边界——有些问题图灵机也无法解决（停机问题）。

2.2

.2 CPU 内部结构及工作原理

本节讲什么

寄存器、PC、PSR/FLAGS、总线 —— C 语句在 CPU 内的执行载体。

要点

通用寄存器

  • CPU 唯一零延迟存储；运算前须 Load 进寄存器
  • 分类：数据、地址、SP/FP（栈帧，ch05）
  • 32/64 位宽决定一次运算与指针宽度

PC（Program Counter）

  • 存下一条指令地址；顺序执行 PC 自增
  • 函数调用/跳转 = 写 PC

PSR / FLAGS

标志 含义 C 对应
Z 结果为 0 if (a==0)
N 负数 有符号比较
C 进位 无符号溢出
V 溢出 有符号溢出
  • if/for 底层：cmp → 条件跳转读 FLAGS（Demo03 objdump）

一条赋值语句的硬件流

a = b + c;
  1. Load b,c → 寄存器
  2. ALU add
  3. Store → a 内存地址

实操

gdb 单步 + info registers；objdump -d 看 cmp/je。

与后续衔接

ch03 ARM 寄存器 R0–R15；2.8 总线。

代码自测

题目 1： 以下代码在 CPU 流水线上可能产生什么问题？如何解决？

int data = 0;
void f(void) {
    if (data) { /* A */ }
    data = 1;
}
参考答案

分支预测问题：CPU 在执行 if (data) 时，data 的值可能还未确定（如果前面有对 data 的 store 操作还在流水线中），导致流水线停顿或预测失败。

流水线冒险类型： - 数据冒险：后续指令依赖前序指令的结果 - 控制冒险：分支指令改变 PC，预取的指令作废 - 结构冒险：多条指令同时需要同一硬件资源

解决：数据前递（forwarding）、分支预测、流水线暂停（stall）。

题目 1： CPU 设计中 RTL 级设计是什么意思？为什么用硬件描述语言（HDL）？

参考答案

RTL（Register Transfer Level）寄存器传输级设计——描述数据在寄存器之间的传输和变换。用 HDL（如 Verilog/VHDL）因为：(1)可以精确描述时序逻辑和组合逻辑；(2)可仿真验证；(3)可综合为门级网表。CPU 设计流程：架构设计 → RTL 编码 → 仿真验证 → 综合 → 布局布线 → 流片。

题目 1： 冯诺依曼架构和哈佛架构的主要区别是什么？

// 冯诺依曼：指令和数据共用一条总线
// 哈佛：指令和数据各有独立总线
参考答案

冯诺依曼：指令和数据存储在同一内存，共用一条总线——取指和访存不能同时进行。哈佛：指令和数据分开存储，各有独立总线——取指和访存可同时进行，吞吐量更高。现代 CPU 多用改进哈佛架构（L1 Cache 分指令/数据，L2/L3 统一）。

2.3

.1 冯·诺依曼架构

本节讲什么

五大部件 + 统一存储 —— 现代通用计算机骨架；指令与数据同存于内存，总线分时复用。

要点

部件 作用
ALU 算术/逻辑运算
CU 取指、译码、控制时序
存储器 RAM 运行态 + ROM/Flash 固件
输入 按键、串口、传感器
输出 屏、PWM、电机

数据流

取指(PC) → 译码 → 读操作数(内存/寄存器) → ALU → 写回 → 更新 PC
  • C 赋值 a = b + c：Load 到寄存器 → Add → Store 回内存（2.2.2）

特性与代价

  • 指令/数据同一内存 → 结构简单
  • 指令与数据争用总线 → 带宽瓶颈

代码自测

题目 1： 冯·诺依曼架构和哈佛架构的核心区别是什么？对 C 编程有什么影响？

参考答案

冯·诺依曼架构：指令和数据共享同一存储器和总线。简化硬件设计，但取指和取数据不能同时进行（瓶颈）。

哈佛架构：指令和数据有独立的存储器和总线。可以同时取指和取数据，吞吐量更高。

对 C 编程的影响： - 哈佛架构（如 AVR 单片机）需要 pgm_read_byte() 等特殊宏读取 Flash 中的常量 - 冯·诺依曼架构（如 x86/ARM AArch64）中函数指针和数据指针大小相同 - 嵌入式 MCU 常用改进型哈佛架构（L1 缓存分 I-cache/D-cache）

代码自测

题目 1： 以下代码两种遍历方式的性能差异原因是什么？

#define N 1024
int matrix[N][N];
// 方式A
for (i = 0; i < N; i++)
    for (j = 0; j < N; j++)
        sum += matrix[i][j];
// 方式B
for (j = 0; j < N; j++)
    for (i = 0; i < N; i++)
        sum += matrix[i][j];
参考答案

方式 A 远快于方式 B。

C 语言二维数组按行存储（row-major），matrix[i][j] 和 matrix[i][j+1] 在内存中相邻。方式 A 顺序访问，利用空间局部性，一个 Cache Line（通常 64 字节 = 16 个 int）只需从内存加载一次。方式 B 跳跃访问（每次跨 N*4 字节），每次访问都 Cache Miss，性能差 10 倍以上。

Cache 工作原理：CPU 访问内存时先查 Cache，命中则直接使用，未命中则从内存加载一个 Cache Line。

题目 1： 经典五级流水线的每个阶段做什么？

IF → ID → EX → MEM → WB
参考答案

多核优势：功耗与频率超线性增长（频率翻倍功耗约 8 倍），而多核只线性增长。Amdahl 定律：加速比受限于串行部分——如果程序 50% 可并行，最多加速 2 倍。说明并行化程度决定了多核的实际收益。编程模型的串行部分是瓶颈。

题目 1： 内存映射 I/O 和端口映射 I/O 的区别是什么？C 代码如何访问？

// 内存映射 I/O (ARM)
#define GPIO_BASE  0x3F200000
volatile unsigned int *gpio = (volatile unsigned int *)GPIO_BASE;
*gpio = (1 << 5);  // 设置 GPIO5

参考答案

内存映射 I/O（ARM/MIPS）：外设寄存器映射到统一地址空间，用普通指针访问。需要 volatile 防止编译器优化掉重复读写。

区别：内存映射 I/O 可以用 memcpy/指针运算，端口映射不行。ARM 采用内存映射，所以嵌入式 C 编程中 volatile 指针操作是基本功。

题目 1： RISC 和 CISC 的主要区别是什么？ARM 和 x86 分别属于哪类？

题目 1： ISA（指令集架构）和微架构的关系是什么？同一 ISA 的不同 CPU 能运行同一二进制程序吗？

参考答案

ISA（Instruction Set Architecture）：软件和硬件之间的契约，定义指令格式、寄存器、寻址模式、中断模型等。如 ARMv8-A、x86-64、RISC-V。

微架构（Microarchitecture）：ISA 的具体硬件实现，如流水线深度、Cache 层级、分支预测器。同一 ISA 可以有多种微架构实现。

关系：ISA 是接口，微架构是实现。同一 ISA 的不同 CPU 能运行同一二进制程序（如 ARMv8-A 的 Cortex-A53 和 Cortex-A78 都能运行同一 ARM64 程序），但性能不同。
