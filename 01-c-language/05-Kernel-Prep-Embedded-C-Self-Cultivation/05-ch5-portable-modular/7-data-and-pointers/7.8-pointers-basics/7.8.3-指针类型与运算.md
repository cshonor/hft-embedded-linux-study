# 7.8.3 指针类型与运算

## 本节讲什么

指针支持**加减整数**、**相减**、**关系比较**（同数组内），步长由指向类型决定。`NULL`、野指针、悬垂指针解引用均为 UB。本节归纳合法运算与 GDB 调试命令，并强调对齐与越界风险。

## 要点

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
p++;           /* 指向下一个 int，地址 +sizeof(int) */
int d = p - a; /* ptrdiff_t，元素个数差 */

char *bp = (char *)a;
bp += 4;       /* 字节步长 1 */
```

| 运算 | 合法条件 |
|------|----------|
| `p + n` / `p - n` | 结果指向同数组或尾后 |
| `p - q` | 同数组内 |
| `p < q` | 同数组内 |
| `p == NULL` | 始终 |

```c
#define NULL ((void *)0)   /* 常见；亦可用 0 */

int *wild;           /* 未初始化 */
*wild = 1;           /* UB */

int *dangling = malloc(sizeof *dangling);
free(dangling);
/* *dangling = 1; */ /* 悬垂 → demo06 */
```

```gdb
(gdb) set $p = (int *)0x7fffffffe000
(gdb) x/5wx $p
(gdb) print $p[2]
(gdb) watch *p              # 写监视点
```

**类型与对齐**：

```c
void *vp = &x;
int *ip = vp;        /* void* 转具体类型 */
/* 须保证对齐；ARM 上 misalign fault */
```

- **指针算术单位是元素**，不是字节（`char *` 除外）
- **`intptr_t`**：指针与整数互转打印
- **内核** `ERR_PTR`/`PTR_ERR` 在指针低位编码错误（架构相关）

## 代码自测

**题目 1：** 指针支持哪些运算？以下操作的结果是什么？
```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;
int *q = &arr[4];
printf("%d %d\n", *(p+2), p[2]);  // ?
printf("%ld\n", q - p);             // ?
```
<details>
<summary>参考答案</summary>

输出 `30 30` 和 `4`。

指针运算：
1. **指针 + 整数**：`p + 2` 指向 `arr[2]`。地址增加 `2 * sizeof(int)` = 8 字节
2. **指针 - 整数**：类似，地址减少
3. **指针 - 指针**：`q - p` = 4。结果是两个指针之间的元素个数（不是字节数）
4. **指针比较**：`p < q` 比较地址大小
5. **下标访问**：`p[2]` 等价于 `*(p + 2)`

不支持：指针 + 指针、指针 * 整数（无意义）

`q - p = 4` 的原因：`q` 和 `p` 之间隔了 4 个 int 元素。地址差 / sizeof(int) = 4。只有指向同一数组的指针才能相减。

`p[2]` 和 `*(p+2)` 完全等价——C 的下标运算就是指针运算的语法糖。

</details>
