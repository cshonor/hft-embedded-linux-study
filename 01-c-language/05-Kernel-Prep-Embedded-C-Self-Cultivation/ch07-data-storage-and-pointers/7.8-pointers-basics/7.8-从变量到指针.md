# 7.8 从变量到指针

## 本节讲什么

**指针**是保存对象**地址**的变量；`&` 取址、`*` 解引用构成 C 间接访问的核心。从标量变量到指针，是从「直接操作值」到「通过地址操作内存」的跃迁，内核链表、`kmalloc` 返回值、硬件寄存器映射都建立在此。本节建立指针与变量的对应关系。

## 要点

```c
int x = 42;
int *p = &x;    /* p 保存 x 的地址 */

printf("x=%d  *p=%d  &x=%p  p=%p\n", x, *p, (void *)&x, (void *)p);
*p = 100;       /* 通过指针改 x */
```

| 运算符 | 含义 |
|--------|------|
| `&obj` | 取对象地址，类型 `T *` |
| `*ptr` | 解引用，得到 `T` 左值 |
| `ptr->mbr` | 等价 `(*ptr).mbr` |

```c
int *q = NULL;          /* 空指针，未指向有效对象 */
if (q != NULL)
    *q = 1;

void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;  /* 通过指针修改调用方变量 */
}
```

## 代码自测

**题目 1：** 指针的本质是什么？以下代码中各操作的含义是什么？
```c
int x = 42;
int *p = &x;    // p 存储什么?
*p = 100;       // 操作什么?
p++;            // p 变化多少?
```
<details>
<summary>参考答案</summary>

指针本质：存储内存地址的变量。指针类型决定解引用时读取多少字节和指针运算的步长。

- `int *p = &x`：p 存储 x 的地址（如 0x7fff1234）
- `*p = 100`：解引用，通过地址找到 x，修改 x 为 100
- `p++`：p 的地址值增加 `sizeof(int)` = 4 字节（指向下一个 int 位置）

指针 vs 变量：
- 变量：有名字的内存区域，通过名字访问
- 指针：存储地址的变量，通过地址间接访问

`int *p` 的含义：
- `p` 是变量名
- `*` 表示 p 是指针
- `int` 表示 p 指向的数据类型是 int
- `sizeof(p)` = 4（32位）或 8（64位），与指向类型无关

</details>
