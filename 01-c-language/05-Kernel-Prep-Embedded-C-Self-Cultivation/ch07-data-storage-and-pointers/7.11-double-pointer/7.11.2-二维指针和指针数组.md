# 7.11.2 二维指针和指针数组

## 本节讲什么

`char **` 常表示「元素为 `char *` 的指针数组」：每元素指向独立字符串，行不必连续，长度可不等。与 `char *matrix[]` 静态表、`main` 的 `argv` 同构。**demo02** 动态构建 `uart0/spi1/i2c2` 列表是典型应用。

## 要点

```
char **argv 布局:

 argv ──→ [ ptr0 ] ──→ "uart0\0"
          [ ptr1 ] ──→ "spi1\0"
          [ ptr2 ] ──→ "i2c2\0"

 顶层是指针数组；每条字符串单独分配。
```

```c
char *names[] = { "uart0", "spi1", "i2c2" };  /* 指针数组，静态 */
char **dyn = NULL;   /* 动态版 demo02 */

for (size_t i = 0; i < n; i++)
    printf("[%zu] %s\n", i, dyn[i]);
```

| 对比 | `char **` | `char (*)[N]` |
|------|-----------|----------------|
| 行连续 | 否 | 是（二维数组） |
| 行长度 | 可不等 | 固定 N |
| 传参 | `char **` | `char (*)[N]` 或 decay |

```c
/* 内核模块参数（示意） */
static char *board_parts[] = { "mmc", "spi", NULL };
```

- **释放顺序**：先 `free` 每行，再 `free` 指针数组
- **`const char **` vs `char * const *`**：常量性位置影响接口契约
- **NULL 结尾**：模仿 `argv` 便于遍历

## 代码自测

**题目 1：** 以下两种"二维数组"在内存布局上有什么区别？
```c
// 方式A: 指针数组
int *arr1[3];
arr1[0] = malloc(4 * sizeof(int));
arr1[1] = malloc(4 * sizeof(int));
arr1[2] = malloc(4 * sizeof(int));

// 方式B: 二维数组
int arr2[3][4];
```
<details>
<summary>参考答案</summary>

**方式 A（指针数组）**：
- arr1 是 3 个 `int *` 指针的数组
- 每行可以不同长度（锯齿数组）
- 每行的内存不连续（各自的 malloc）
- `arr1[i][j]` = `*(*(arr1 + i) + j)`：先取指针，再偏移
- 需要 3+1=4 次 malloc（指针数组 + 每行）

**方式 B（二维数组）**：
- arr2 是连续的 12 个 int
- 每行长度固定 4
- 内存连续：`arr2[0][0]` ~ `arr2[2][3]` 连续
- `arr2[i][j]` = `*(*(arr2 + i) + j)`：arr2 退化为 `int (*)[4]`
- 一次分配（栈上）

区别：
| | 指针数组 | 二维数组 |
|---|---|---|
| 内存 | 不连续 | 连续 |
| 行长 | 可变 | 固定 |
| 分配 | 多次 malloc | 栈/一次 |
| 传参 | `int **` | `int (*)[N]` |

`argv` 是指针数组（每个参数长度不同）。

</details>
