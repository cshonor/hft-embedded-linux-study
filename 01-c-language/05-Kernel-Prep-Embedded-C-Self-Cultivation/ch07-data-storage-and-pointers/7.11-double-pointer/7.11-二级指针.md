# 7.11 二级指针

## 本节讲什么

**二级指针** `T **` 保存「指针变量的地址」，用于在函数内**修改调用方的指针**、构建指针数组、表达「字符串列表」或「行指针表」。与「指向数组的指针」、二维数组名不同，类型系统上必须逐级匹配。

## 要点

```c
char *s = "uart";
char **pp = &s;       /* pp 指向 char * 变量 s */

void alloc_buf(char **out, size_t n) {
    *out = malloc(n);   /* 改调用方的指针 */
}
```

| 类型 | 含义 |
|------|------|
| `T *` | 指向 T |
| `T **` | 指向「T 的指针」 |
| `T *a[N]` | N 个 T*，数组对象 |

```c
/* demo02 模式 */
char **list = NULL;
size_t count = 0;
append_string(&list, &count, "uart0");  /* &list 是 char *** 语义上传递二级 */
```

```bash
gcc demo02_double_ptr.c -o demo02 && ./demo02
```

- **`int **` 不是二维数组** `int[m][n]` 的传参类型**
- **`realloc` 改指针**：须 `char **` 让调用方看到新地址
- **NULL**：空列表常 `char **p = NULL`

## 代码自测

**题目 1：** 二级指针 `int **pp` 的作用是什么？以下代码输出什么？
```c
int x = 42;
int *p = &x;
int **pp = &p;
printf("%d %d %d\n", x, *p, **pp);
*pp = NULL;
printf("%p\n", (void *)p);
```
<details>
<summary>参考答案</summary>

输出 `42 42 42` 和 `(nil)`。

二级指针：指向指针的指针。
- `pp` 存储 `p` 的地址（p 是 `int *`，pp 是 `int **`）
- `*pp` = p = &x（一级解引用得到 p 的值，即 x 的地址）
- `**pp` = *p = x = 42（二级解引用得到 x 的值）

`*pp = NULL` 修改了 p 的值（不是 x），p 变为 NULL。

用途：
1. **修改调用者的指针**：函数内修改外部指针变量
```c
void alloc(int **pp) { *pp = malloc(sizeof(int)); }
int *p = NULL; alloc(&p);  // p 被修改
```
2. **指针数组**：`char **argv`（命令行参数）
3. **二维动态数组**：`int **matrix = malloc(rows * sizeof(int*))`
