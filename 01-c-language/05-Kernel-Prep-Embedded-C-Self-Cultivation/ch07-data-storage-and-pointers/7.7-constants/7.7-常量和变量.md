# 7.7 常量和变量

## 本节讲什么

**变量**是可修改的存储对象；**常量**在编译期或运行期不可（或不应）修改。`const`、`volatile`、`restrict` 修饰符精确表达意图，是驱动、MMIO、并发代码的类型契约。本节总览常量与变量的分类，为 **7.7.1–7.7.3** 与指针 const 四形式铺路。

## 要点

```c
const int max_users = 32;      /* 只读变量，可能在 .rodata */
#define BUF_SIZE 256           /* 预处理替换，无类型 */
enum { TIMEOUT_MS = 1000 };

int counter;                   /* 可写变量 */
static const char msg[] = "ok"; /* 字符串字面量合并 */
```

| 修饰符 | 作用 |
|--------|------|
| `const` | 语义只读，可能放只读段 |
| `volatile` | 每次从内存读/写，禁止优化缓存 → **demo05** |
| `restrict` | 指针独占别名，C99 优化提示 → **7.13** |

**const 指针四形式**（本章必须掌握）：

```c
const int *p1;        /* 指向 const int：*p1 不可改 */
int *const p2 = &x;   /* const 指针：p2 不可改 */
const int *const p3;  /* 都不可改 */
int const *p4;        /* 同 p1 */
```

```c
/* MMIO：volatile + 指针 */
volatile uint32_t *reg = (volatile uint32_t *)0x40001000;
*reg = 1;   /* 每次真实写硬件 */
```

## 代码自测

**题目 1：** C 语言中常量有哪些种类？以下各是什么类型的常量？
```c
#define MAX 100           // ?
const int size = 10;       // ?
int arr[10];               // 10 是?
"hello"                    // ?
enum { BUF = 256 };        // ?
```
<details>
<summary>参考答案</summary>

C 语言常量种类：

1. **字面量常量**（Literal）：`10`（整数）、`3.14`（浮点）、`"hello"`（字符串字面量）、`'a'`（字符常量）
2. **宏常量**（#define）：`MAX` 是预处理符号，编译前替换为 100。无类型，不占内存
3. **const 修饰的变量**：`size` 是"只读变量"，C 中它不是真正的常量（不能用作数组大小，C99 VLA 除外）。存储在 .rodata 或 .data 段
4. **枚举常量**：`BUF` 是编译期 int 常量，类似 #define 但有类型
5. **数组大小**：`10` 是整数常量表达式

关键区别：
- `#define`/enum：编译期常量，可用作数组大小、case 标签
- `const`：C 中是只读变量，不是常量表达式（C++ 中是常量）
- `const int size = 10; int arr[size];` 在 C89 中不合法（C99 VLA 合法）

</details>
