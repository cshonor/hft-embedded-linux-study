# 7.7.2 常量存储

## 本节讲什么

常量数据可存放在**只读段（.rodata）**、与代码段相邻的 literal pool，或作为立即数编进指令。`const` 全局/静态常量在嵌入式中可链接到 Flash，节省 RAM。字符串字面量、查找表、设备 ID 表是典型常量对象。

## 要点

```c
const int table[] = { 1, 2, 3 };     /* .rodata */
static const char name[] = "uart0";

#define GPIO_BASE 0x40000000         /* 预处理，不占存储 */

const int *p = table;                /* p 可变，*p 不可通过 p 改 */
```

| 形式 | 存储行为 |
|------|----------|
| `const` 全局 | `.rodata`，写保护（MMU 可设只读） |
| 字符串字面量 | 通常 `.rodata`，合并相同串 |
| 局部 `const` | 可能在栈，仍不可写 |
| `enum` / `#define` | 常出现在指令立即数 |

```c
/* 错误：修改字面量（C 标准未定义，常见 SIGSEGV） */
char *s = "hello";
s[0] = 'H';

/* 正确 */
const char *s = "hello";
char buf[] = "hello";  /* 可写数组副本 */
```

```bash
readelf -S a.out | grep rodata
objdump -s -j .rodata a.out
```

- **嵌入式链接脚本**：`.rodata` 映射到 Flash
- **内核 `__initconst`**：初始化后只读数据可释放
- **const 指针四形式** 决定能否改指向与内容 → **7.7**

## 代码自测

**题目 1：** 以下常量分别存储在哪里？
```c
const int g = 10;            // ?
const char *s = "hello";     // "hello"在? s在?
int main(void) {
    const int l = 20;         // ?
    char *str = "world";      // "world"在?
}
```
<details>
<summary>参考答案</summary>

- `const int g = 10`：**.rodata** 段（全局 const，只读）
- `"hello"`：**.rodata** 段（字符串字面量，只读）
- `s`：**.data** 段（s 本身是 `const char *` 指针，指针变量可修改，存 .data）
- `const int l = 20`：**栈**（局部 const 仍在栈上，编译器可能优化为立即数）
- `"world"`：**.rodata** 段

关键理解：
1. 字符串字面量 `"hello"` 存在 .rodata，不可修改。`s[0] = 'H'` 是未定义行为
2. `const char *s` 中 const 修饰的是 `*s`（指向的内容只读），不是 `s`（指针本身可改）
3. `char *str = "world"` 危险：str 不是 const，但指向只读内存。`str[0] = 'W'` 编译通过但运行崩溃。应用 `const char *str`
4. 局部 const 可能被优化为立即数（不占内存），取决于编译器和优化等级

</details>
