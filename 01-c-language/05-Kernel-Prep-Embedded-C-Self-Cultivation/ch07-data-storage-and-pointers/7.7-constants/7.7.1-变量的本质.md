# 7.7.1 变量的本质

## 本节讲什么

变量是**具名存储对象**：编译器为其分配地址（栈、静态区或寄存器），生命周期由作用域与链接属性决定。理解「变量 = 名字 + 存储期 + 类型 + 地址」是读懂指针的基础——指针里保存的就是这类对象的地址。

## 要点

```c
void demo(void) {
    int a = 10;           /* 自动变量，栈，块作用域 */
    static int call_count; /* 静态存储，程序寿命 */
    register int hint;    /* 寄存器提示，现代编译器常忽略 */
}
int g;                    /* 全局，.bss 或 .data */
```

| 存储类 | 生命周期 | 默认初始化 |
|--------|----------|------------|
| 自动 | 进入/离开块 | 未定义 |
| 静态 | 整个程序 | 零 |
| 线程局部 `_Thread_local` | 线程 | 实现 |
| 堆 | `malloc` 到 `free` | 未定义 |

```bash
# 查看符号放在哪一段
gcc -c file.c -o file.o
nm file.o
readelf -s file.o | grep -E ' g | a '
```

```gdb
(gdb) break demo
(gdb) run
(gdb) print &a
(gdb) info locals
(gdb) x/wx &a          # 查看内存字
```

- **未初始化自动变量**：读值 UB，安全代码显式赋值
- **别名**：同一内存可有多个名字（union、指针）
- **优化**：寄存器变量无固定地址，`&a` 可能迫使 spill 到栈

## 代码自测

**题目 1：** 变量的本质是什么？以下变量分别存储在哪个段？
```c
int g_init = 42;        // ?
int g_uninit;            // ?
const int g_const = 10;  // ?
static int s_var = 5;   // ?
int main(void) {
    int local = 1;       // ?
    static int s_local;  // ?
}
```
<details>
<summary>参考答案</summary>

变量的本质：一块有名字、有类型、有地址的内存区域。

- `g_init = 42`：**.data** 段（已初始化全局变量）
- `g_uninit`：**.bss** 段（未初始化全局变量，加载时清零）
- `g_const = 10`：**.rodata** 段（只读，修改触发段错误）
- `s_var = 5`：**.data** 段（static 全局，限制作用域但不改存储位置）
- `local = 1`：**栈**（局部变量）
- `s_local`：**.bss** 段（static 局部，未初始化。存储位置与全局相同，但作用域是函数内）

static 的两个含义：
1. 修饰局部变量：改变存储位置（栈→.bss/.data），生命周期变为整个程序
2. 修饰全局变量/函数：改变链接性（external→internal），限制在文件内可见

`const` 全局变量放 .rodata（只读页），`const` 局部变量仍在栈上（只是编译器检查不修改）。

</details>
