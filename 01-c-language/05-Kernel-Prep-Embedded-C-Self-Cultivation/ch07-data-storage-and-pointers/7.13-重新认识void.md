# 7.13 重新认识void

## 本节讲什么

`void` 表示**无类型**：不能声明 `void` 变量；`void *` 是**通用指针**，可保存任意对象地址，解引用前须转为具体类型。`void` 函数无返回值。`restrict`（C99）修饰指针，承诺无别名以助优化。三者常与 `memcpy`、回调、MMIO 封装一起出现。

## 要点

```c
void noop(void) { }              /* 无返回值 */

void *p = malloc(64);            /* 任意类型地址 */
int *ip = p;                     /* 转回，须对齐且知对象类型 */
free(p);

/* 不声明 void x; — 非法 */
```

| 话题 | 规则 |
|------|------|
| `void *` 算术 | 非法，须先 cast |
| `void *` 比较 | 可与任意对象指针比较 |
| `memcpy` | `void *` 目的，`const void *` 源 |

**restrict**（优化契约）：

```c
void sum(size_t n, const int *restrict src, int *restrict dst) {
    for (size_t i = 0; i < n; i++)
        dst[i] += src[i];   /* 编译器假设 src/dst 不重叠 */
}
/* 内核热路径；重叠须用 memmove */
```

**volatile**（回顾 **demo05**）：

```c
volatile uint32_t *reg = (volatile uint32_t *)base;
*reg = val;   /* 每次真实访问设备 */
```

```c
/* MMIO 宏模式 demo07 */
#define REG32(addr)  (*(volatile uint32_t *)(addr))
#define BIT(n)       (1u << (n))
REG32(GPIO_BASE + 0x04) |= BIT(0);
```

- **`void **` 少见**：通用容器用 `void *` + 类型标签
- **函数指针与 `void *`**：POSIX `dlsym` 返回后 cast，C 标准严格说不保证
- **C++**：`void *` 不能隐式转 `T *`；C 可以

## 代码自测

**题目 1：** void 在 C 语言中有哪些用途？`void *` 指针的特点是什么？
```c
void func(void);          // 无参数无返回值
void *malloc(size_t size); // 返回无类型指针
void *vp = malloc(100);
int *ip = vp;              // 隐式转换，合法吗?
*vp;                        // 合法吗?
```
<details>
<summary>参考答案</summary>

void 的用途：
1. **函数返回类型**：`void func()` 表示无返回值
2. **函数参数**：`func(void)` 表示无参数（`func()` 在 C 中表示参数未指定）
3. **void 指针**：`void *` 无类型指针

`void *` 特点：
- **通用指针**：可以指向任何类型的数据
- **隐式转换**：`void *` 可与其他指针类型互相转换，无需强制 cast（C 语言）
  - `int *ip = vp` 合法（C 中 void* 隐式转换，C++ 需要 cast）
- **不能解引用**：`*vp` 不合法——不知道读取多少字节
- **不能做指针运算**：`vp + 1` 不合法——不知道步长
- `malloc` 返回 `void *`，调用者负责转换为正确类型

用途：
- 泛型接口：`qsort` 的比较器接收 `const void *`
- 内存操作：`memcpy`/`memset` 接收 `void *`
- 抽象句柄：`void *handle = lib_init();`

`void *` 是 C 语言实现泛型的核心工具。

</details>
