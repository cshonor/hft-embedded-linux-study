# 7.6.2 枚举的本质

## 本节讲什么

枚举常量在 C 中本质是**整数**，可与 `int` 互相赋值（隐式转换），比较、算术、用作数组下标均可。编译器可为枚举定义**不完全兼容**的其他整数类型检查，但不可依赖枚举阻止所有误用。理解「名义类型、实质整数」有助于设计状态机。

## 要点

```c
enum { A = 0, B = 1, C = 2 };
int x = B;
enum { A, B, C };
int arr[] = { [A] = 10, [B] = 20 };   /* 指定初始化 ch06 */

enum color { RED = 1, GREEN, BLUE };  /* GREEN=2, BLUE=3 */
```

| 特性 | 说明 |
|------|------|
| 默认值 | 首项 0，后续 +1（除非显式赋值） |
| 重复值 | 允许，用于别名 |
| 范围 | 须在 `int` 可表示范围（实现） |
| sizeof(enum) | 常为 `int` 大小 |

```c
/* 误用：超出枚举定义的值 */
enum state { ON, OFF };
enum state s = 99;   /* 往往仅警告，运行逻辑错误 */

if (s == 99) { }    /* 合法比较，说明 enum 非真正封闭 */
```

- **位标志**：大集合用 `#define` 或 `unsigned` + 宏，单选状态用 enum
- **序列化**：存盘/网络用定宽整数，不假设 enum 宽度
- **C++ enum class**：强类型；纯 C 工程用约定 + 审查

## 代码自测

**题目 1：** enum 的本质是什么？以下代码合法吗？
```c
enum color { RED = 0, GREEN = 1, BLUE = 2 };
int x = GREEN;
enum color c = 5;  // 合法吗？
```
<details>
<summary>参考答案</summary>

enum 的本质：**编译期常量的集合 + 一个 int 类型的别名**。

- `x = GREEN` 合法：enum 常量就是 int，可直接赋值给 int
- `enum color c = 5` 合法但危险：C 标准允许将任意 int 赋值给 enum 变量（不检查范围）。5 不是合法的 color 值，但编译器不报错。

本质理解：
1. enum 常量（RED/GREEN/BLUE）在编译后被替换为对应的 int 值
2. enum 变量（c）的底层类型是 int（C 标准），不是独立类型
3. C 不做 enum 范围检查（C++ 做有限检查）
4. `sizeof(enum color) == sizeof(int)`（通常 4 字节）

因此 enum 不是真正的类型安全。要实现类型安全可用 C11 的 `_Generic` 或手动检查。

GCC 扩展 `__attribute__((packed))` 可让 enum 用更小类型（`unsigned char`）。

</details>
