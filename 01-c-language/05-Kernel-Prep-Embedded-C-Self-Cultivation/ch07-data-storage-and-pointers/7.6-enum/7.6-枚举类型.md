# 7.6 枚举类型

## 本节讲什么

`enum` 为一组命名整数常量提供类型与作用域，比 `#define` 更利于调试器与编译器检查。驱动状态机、错误码、操作码（**demo04** `op_t`）广泛使用。本节概述枚举语法、底层表示及与内核 `enum` 宏扩展的关系。

## 要点

```c
enum color { RED, GREEN, BLUE };   /* RED=0 起递增 */
enum { MAX_BUF = 256 };            /* 匿名枚举当常量 */

enum gpio_dir {
    GPIO_IN  = 0,
    GPIO_OUT = 1,
};
```

| 对比 `#define` | enum 优势 |
|----------------|-----------|
| 调试显示符号名 | 符号表保留（未 strip） |
| 类型检查较弱 | 与 `int` 兼容但有 distinct 检查（编译器扩展） |
| 无作用域 | 遵循块/文件作用域 |

```c
/* 指定底层类型（C23 / GCC 扩展） */
enum op_t : uint8_t {
    OP_ADD, OP_SUB, OP_MUL, OP_DIV, OP_COUNT
};
```

- **底层类型**：标准 C 前为 `int`；嵌入式协议字段常显式 `uint8_t` 成员存枚举值
- **计数哨兵**：`OP_COUNT` 作数组大小 → **demo04** jump table
- **内核**：大量 `enum foo` + `FOO_MAX` 模式

## 代码自测

**题目 1：** enum 和 #define/const 定义常量有什么区别？以下枚举的值是什么？
```c
enum color {
    RED,    // ?
    GREEN,  // ?
    BLUE    // ?
};
enum day {
    MON = 1,
    TUE,    // ?
    WED     // ?
};
```
<details>
<summary>参考答案</summary>

enum color: RED=0, GREEN=1, BLUE=2（默认从 0 递增）
enum day: MON=1, TUE=2, WED=3（指定起始值后递增）

enum vs #define vs const：
| | enum | #define | const |
|---|---|---|---|
| 类型检查 | 有（enum 类型） | 无 | 有 |
| 调试 | 可见符号名 | 不可见（预处理消失）| 可见 |
| 作用域 | 遵循 C 作用域 | 全局（文件级） | 遵循 C 作用域 |
| 内存 | 不占内存（编译期常量）| 不占 | 可能占（C 中 const 不是常量） |
| 取地址 | 不能 | 不能 | 能 |

enum 实际类型是 int（C 标准），GCC 可配置为更小类型。内核中大量使用 enum（如 `enum irqreturn`）。

</details>
