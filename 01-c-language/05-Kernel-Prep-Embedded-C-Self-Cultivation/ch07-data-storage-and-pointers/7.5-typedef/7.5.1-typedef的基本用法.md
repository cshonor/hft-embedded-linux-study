# 7.5.1 typedef的基本用法

## 本节讲什么

`typedef old_type new_name;` 声明**类型别名**；`new_name` 之后可当类型使用。可与 `struct`、指针、数组、函数指针组合。读内核代码时，能快速展开 typedef 是理解 `DEFINE_SPINLOCK`、`list_for_each_entry` 的前提。

## 要点

```c
/* 基本类型 */
typedef unsigned char byte;

/* 结构体 */
typedef struct node {
    int data;
    struct node *next;
} node_t;

/* 指针 */
typedef int *intptr_alias;   /* intptr_alias 是指针类型，不是 int 的指针变量 */

/* 数组 */
typedef int row_t[4];
row_t matrix;   /* int matrix[4] */

/* 函数指针 — 读法：typedef 返回 (*NAME)(参数) */
typedef int (*signal_handler_t)(int signo);
```

**声明对比**：

```c
int *a, b;           /* a 是指针，b 是 int */
typedef int *ptr_t;
ptr_t c, d;          /* c、d 都是 int * */
```

```c
/* 内核链表 */
struct list_head {
    struct list_head *next, *prev;
};
```

- **多次 typedef**：链式别名 `typedef u8 byte; typedef byte octet;` 可读性下降
- **与 `static`/存储类**：`typedef` 只作用于类型，不含存储期
- **函数指针 typedef** 是 **7.12** / **demo04** 推荐写法

## 代码自测

**题目 1：** 以下 typedef 各定义了什么类型？
```c
typedef unsigned char  uint8;
typedef int (*FuncPtr)(int);
typedef struct node { int data; struct node *next; } Node;
typedef int Array5[5];
```
<details>
<summary>参考答案</summary>

- `uint8`：unsigned char 的别名
- `FuncPtr`：指向 `int(int)` 函数的指针类型
- `Node`：struct node 的别名（同时定义了 struct 和 typedef）
- `Array5`：含 5 个 int 的数组类型

用法：
```c
uint8 x = 255;
FuncPtr fp = &some_func;
Node *head = NULL;
Array5 arr = {1, 2, 3, 4, 5};
```

注意 `Array5` 的用法——`int Array5[5]` 是类型定义，`Array5 arr` 声明了一个 `int[5]` 数组。这种用法不常见但合法。

typedef 和 #define 的区别：typedef 是编译器处理的类型定义，#define 是预处理器文本替换。typedef 能正确处理指针连续声明（`int *a, b;` 中 b 是 int 不是 int*，但 `typedef int* IntPtr; IntPtr a, b;` 中 a/b 都是 int*）。

</details>
