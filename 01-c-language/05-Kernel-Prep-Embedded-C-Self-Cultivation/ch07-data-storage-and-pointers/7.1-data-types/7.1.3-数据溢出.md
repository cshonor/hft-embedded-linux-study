# 7.1.3 数据溢出

## 本节讲什么

运算结果超出类型可表示范围时发生**溢出**。有符号整数溢出在 C 中是**未定义行为（UB）**；无符号溢出按模 2^宽度回绕。内核计时、环形缓冲区索引、长度累加若忽视溢出，会导致安全漏洞与难以复现的故障。

## 要点

```c
uint8_t  u = 255; u++;           /* 0，定义明确 */
int8_t   s = 127; s++;           /* 有符号溢出 → UB */
unsigned a = 0, b = 1;
if (a - b < 10) { }              /* 真！无符号下溢为大数 */
```

| 类型 | 溢出 |
|------|------|
| `signed` | UB，编译器可假设不发生并优化掉「保护代码」 |
| `unsigned` | 模运算，常用于环形下标 |
| 浮点 | 无穷/NaN，一般不用于 IRQ 路径 |

```c
/* 安全累加长度（内核常见模式） */
if (len > SIZE_MAX - need)
    return -ENOMEM;
total += need;

/* 环形缓冲区 */
#define RING_SIZE 256
unsigned head, tail;
unsigned next = (head + 1) % RING_SIZE;  /* 或 & (RING_SIZE-1) 当 SIZE 为 2 幂 */
```

```bash
gcc -ftrapv -O0 overflow_test.c   # 部分平台运行时捕获有符号溢出（调试）
gcc -fsanitize=undefined ./a.out  # UBSan
```

- **宽度提升**：运算前先 cast 到更宽无符号再判断
- **常量折叠** 可在编译期发现部分溢出 → **7.7.3**
- **时间戳回绕**：`jiffies`、毫秒计数用无符号减法技巧 `(now - start) < timeout`

## 代码自测

**题目 1：** 以下代码的输出结果是什么？有符号溢出和无符号溢出有什么区别？
```c
int a = INT_MAX;    // 2147483647
unsigned int b = UINT_MAX;  // 4294967295
a = a + 1;
b = b + 1;
printf("a=%d b=%u\n", a, b);
```
<details>
<summary>参考答案</summary>

输出 `a=-2147483648 b=0`。

**有符号溢出**：未定义行为（UB）。实际通常回绕到最小值（补码），但编译器可能做其他优化。`INT_MAX + 1` → `INT_MIN`。

**无符号溢出**：明确定义为回绕（wrap around）。`UINT_MAX + 1` → 0。

区别：
- 无符号溢出是合法的（C 标准定义），常用于哈希/校验和
- 有符号溢出是 UB，编译器可能基于"不溢出"假设优化掉溢出检查

常见坑：
```c
int len = a + b;  // 若 a+b 溢出，len 可能为负
if (len < bufsize)  // 检查可能被优化掉
```

安全检查：用 `__builtin_add_overflow(a, b, &result)`。
