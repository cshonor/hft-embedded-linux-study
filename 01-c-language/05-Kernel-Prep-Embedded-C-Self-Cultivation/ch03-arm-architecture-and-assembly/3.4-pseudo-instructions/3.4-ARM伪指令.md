# 3.4 ARM伪指令

## 本节讲什么

伪指令由汇编器展开为一条或多条真实 ARM 指令，解决 **大立即数加载** 和 **小范围地址计算** 等编码限制，程序员仍写一条「看起来简单」的语句。

## 要点

| 伪指令 | 展开目的 | 小节 |
|--------|----------|------|
| `LDR Rd, =expr` | 任意 32 位常数/符号地址 | **3.4.1** |
| `ADR Rd, label` | PC 相对小偏移地址 | **3.4.2** |

```arm
ldr r0, =0x12345678       @ → literal pool + ldr [pc, #off]
adr r0, my_func           @ → add/sub 与 PC 相关
```

- GNU 汇编（`arm-linux-gnueabihf-as`）与 Keil 语法略有差异，本章以 **GNU** 为准（**3.7**）
- 内联汇编中尽量用 C 变量约束，少手写 `ldr =`

## 与后续衔接

- **3.7.2** `.ltorg` 控制 literal 池位置
- **ch04** 链接后 literal 仍在 `.rodata` 或 `.text` 尾部

## 代码自测

**题目 1：** 伪指令和真实指令有什么区别？LDR 伪指令如何工作？
```asm
LDR R0, =0x12345678  ; 伪指令
```

<details>
<summary>参考答案</summary>

伪指令不是真实的 CPU 指令——编译器将其翻译为一条或多条真实指令。LDR R0, =0x12345678 伪指令：如果值可以用 MOV 编码则生成 MOV，否则编译器在代码附近分配一个 literal pool 存放常量，生成 LDR R0, [PC, #offset] 从 literal pool 加载。伪指令提高了汇编编程的便利性。

</details>
