# 3.4.1 LDR伪指令

## 本节讲什么

`LDR Rd, =imm/label` 加载 **无法用 mov # 编码** 的 32 位立即数或符号地址；汇编器在附近插入 literal pool 并用 `ldr [pc, #off]` 取出。

## 要点

```arm
ldr r0, =0x12345678
ldr r1, =my_buffer
ldr r2, =main
```

- 展开示例：`ldr r0, [pc, #constant_offset]`
- 池太远时需 `.ltorg` 强制就近放置（**3.7.2**）
- 加载 **地址** 而非内容：`ldr r1, =buf`；取内容另需 `ldr r0, [r1]`

## 与后续衔接

- **3.3.7** PC 相对寻址；**ch04** 符号重定位填最终地址

## 代码自测

**题目 1：** 以下两个 LDR 的区别是什么？
```asm
LDR R0, [R1]       ; A
LDR R0, =0x4000    ; B
```

<details>
<summary>参考答案</summary>

A 是真实的 LDR 指令——从 R1 指向的地址加载数据。B 是 LDR 伪指令——加载立即数 0x4000 到 R0。区别：A 的第二个操作数是 [R1]（内存地址），B 是 =0x4000（等号后跟立即数）。编译器会将 B 翻译为 MOV 或从 literal pool 加载。

</details>
