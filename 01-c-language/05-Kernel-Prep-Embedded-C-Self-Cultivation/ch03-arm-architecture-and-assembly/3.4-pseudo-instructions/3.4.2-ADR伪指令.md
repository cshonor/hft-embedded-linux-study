# 3.4.2 ADR伪指令

## 本节讲什么

`ADR Rd, label` 把 **label 与当前指令的偏移地址** 写入 Rd，范围约 ±4KB（ARM），适合 PIC 中取函数/数据地址而不经 literal pool。

## 要点

```arm
adr r0, local_label     @ r0 = PC 相对地址
adr r1, my_func
blx r1                  @ 间接调用
```

- 与 `ldr rd, =label` 区别：`ADR` 算 **相对 PC**；`LDR =` 常经内存常数池
- 超出范围汇编器报错，需改用 `ldr =` 或链接重定位
- 内核 per-CPU 数据有时用 `adr` 取近端表项

## 与后续衔接

- **3.3.7**；AArch64 对应 `adr`/`adrp`（**3.8**）

## 代码自测

**题目 1：** ADR 伪指令的作用是什么？和 LDR 伪指令有什么区别？
```asm
ADR R0, label
LDR R0, =label
```

<details>
<summary>参考答案</summary>

ADR 伪指令加载 label 的地址（基于 PC 的相对地址），生成 ADD/SUB 指令。LDR =label 加载 label 的绝对地址，从 literal pool 读取。区别：ADR 只能加载 ±4KB 范围内的地址（PC 相对），LDR 可以加载任意地址。ADR 生成的代码位置无关，LDR 不是。

</details>
