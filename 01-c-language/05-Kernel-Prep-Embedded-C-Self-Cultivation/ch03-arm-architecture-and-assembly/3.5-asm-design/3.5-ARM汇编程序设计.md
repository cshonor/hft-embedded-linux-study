# 3.5 ARM汇编程序设计

## 本节讲什么

从单条指令上升到 **完整汇编源文件**：段布局、标号、伪操作、与 C 的符号衔接。掌握程序结构才能编写 `boot.S`、内核入口和 DPDK 平台相关启动片段。

## 要点

### 源文件三要素

1. **格式**：`.global`、`.type`、标号、指令（**3.5.1**）
2. **符号**：局部/全局标号、外部引用（**3.5.2**）
3. **伪操作**：`.text`、`.data`、`.word` 等（**3.5.3**）

```arm
    .text
    .global add_asm
    .type add_asm, %function
add_asm:
    add r0, r0, r1
    bx  lr
```

- 与 `demo/add_asm.S` 同构：导出符号供 C `extern` 链接
- 注释用 `@`（ARM）或 `/* */`；换行续行用 `\`

## 代码自测

**题目 1：** 一个完整的 ARM 汇编程序需要包含哪些部分？以下程序的功能是什么？
```c
.global _start
_start:
    MOV R0, #1
    MOV R1, #2
    ADD R2, R0, R1
    B _start
```
<details>
<summary>参考答案</summary>

ARM 汇编程序结构：
1. **伪操作段**：`.global`/`.text`/`.data`/`.bss` 声明段和符号
2. **指令段**：实际执行的指令
3. **数据段**：常量和变量定义

该程序功能：R0=1, R1=2, R2=R0+R1=3，然后 `B _start` 无限循环（死循环）。这是裸机程序的典型结构——没有 OS 时程序不能返回，通常用死循环保持运行。

`.global _start` 使 `_start` 对链接器可见，作为程序入口。

</details>
