# 3.5.3 伪操作

## 本节讲什么

以 `.` 开头的 **汇编器指令**（非 CPU 指令）：定义段、对齐、数据、宏，把源文件组织成链接器可消费的 `.o`。

## 要点

```arm
    .text
    .data
val:
    .word 0x12345678
    .byte 0x12
    .ascii "OK\0"
    .space 64, 0
    .end
```

| 伪操作 | 作用 |
|--------|------|
| `.text` / `.data` / `.bss` | 段切换 |
| `.align n` | 2^n 字节对齐 |
| `.word` / `.byte` | _emit 数据 |
| `.equ SYM, 0` | 符号等价常量 |

- **3.7** 展开 GNU 专用伪操作（`.section`、`.ltorg`）
- 设备树 blob、中断向量表在 `.rodata`/`.text` 用 `.word` 填入口地址

## 代码自测

**题目 1：** 以下 ARM 汇编伪操作各有什么作用？
```c
.text              @ ?
.data              @ ?
.bss               @ ?
.global main        @ ?
.word 0x12345678   @ ?
```
<details>
<summary>参考答案</summary>

- `.text`：声明代码段（只读、可执行）
- `.data`：声明数据段（已初始化全局变量，可读写）
- `.bss`：声明 BSS 段（未初始化全局变量，自动清零，不占文件空间）
- `.global main`：声明 main 为全局符号，链接器可见（程序入口或导出函数）
- `.word 0x12345678`：在当前位置存储一个 32 位字（4 字节）

伪操作不生成机器指令，而是指导汇编器/链接器如何组织代码和数据。对应 C 的段属性。

</details>
