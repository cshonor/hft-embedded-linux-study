# 3.2.6 条件执行指令

## 本节讲什么

ARM32 几乎所有指令可带 **条件码后缀**，仅在 CPSR 标志满足时执行——用 `cmp` + 条件 `mov` 代替分支，减少流水线冲刷（AArch64 已弱化此特性）。

## 要点

```arm
cmp r0, r1
movgt r2, #1          @ r0>r1（有符号）时 r2=1
moveq r2, #0          @ 相等时 r2=0
addeq r0, r0, #1      @ Z=1 时加 1
```

| 后缀 | 条件 |
|------|------|
| eq/ne | 相等/不等 |
| gt/lt/ge/le | 有符号比较 |
| hi/ls | 无符号高于/低于 |
| mi/pl | 负/正 |

- 默认后缀 **AL**（总是执行）可省略
- 内核早期手写汇编常用；现代 C 编译器仍对简单 `cmov` 模式生成条件指令

## 与后续衔接

- 与 **3.2.7** 分支互补；**3.9** 异常返回用条件 `subs pc`

## 代码自测

**题目 1：** ARM 的条件执行是 RISC 架构的独特特性。以下代码有什么优势？
```asm
CMP R0, #0
MOVGT R1, #1     ; R0 > 0 时执行
MOVLE R1, #0     ; R0 <= 0 时执行
```

<details>
<summary>参考答案</summary>

条件执行避免了分支指令——两条 MOV 根据 CMP 设置的标志位选择性执行。优势：(1)避免分支预测失败的开销；(2)代码更紧凑；(3)流水线不断流。几乎所有 ARM 指令都可以加条件后缀（EQ/NE/GT/LT/GE/LE 等），这是 ARM 区别于其他 RISC 的特色。

</details>
