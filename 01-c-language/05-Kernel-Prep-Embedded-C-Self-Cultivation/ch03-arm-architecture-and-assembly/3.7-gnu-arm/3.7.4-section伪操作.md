# 3.7.4 .section伪操作

## 本节讲什么

`.section` / `.text` / `.data` / `.bss` / `.rodata` 把代码与数据分入 ELF 段，链接脚本按段布置到 Flash/RAM。

## 要点

```arm
    .section .text.boot, "ax", %progbits
    .section .data.cacheline_aligned, "aw", %progbits
    .previous
    .pushsection .rodata
    .popsection
```

| 段 | 典型内容 |
|----|----------|
| `.text` | 代码 |
| `.rodata` | 常量、字符串 |
| `.data` | 已初始化全局变量 |
| `.bss` | 未初始化，占址不占 ROM |

- 内核 `__cacheline_aligned` 把 per-CPU 变量放入对齐段
- DPDK `__rte_cache_aligned` 同理，避免 false sharing

## 与后续衔接

- **ch04** 链接脚本 `SECTIONS`；**ch05** BSS 清零

---

## 代码自测

**题目 1：** 以下 GNU 汇编代码中 .section 的作用是什么？
```asm
.section .text
    // code
.section .data
    // data
```

<details>
<summary>参考答案</summary>

.section 指定后续代码/数据放入哪个段。.text 是代码段（只读），.data 是已初始化数据段（可读写），.bss 是未初始化数据段。段是链接器组织程序的基本单位——不同段有不同的属性（读/写/执行权限）。ELF 文件由多个段组成。

</details>
