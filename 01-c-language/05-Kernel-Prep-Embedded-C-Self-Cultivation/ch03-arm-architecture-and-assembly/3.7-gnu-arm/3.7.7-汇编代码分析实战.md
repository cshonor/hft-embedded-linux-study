# 3.7.7 汇编代码分析实战

## 本节讲什么

用 **`objdump -dS`**、**`gdb disassemble`** 对照 C 与 ARM 汇编，验证 AAPCS、寻址与优化——读内核/DPDK 热点的必备技能。

## 要点

```bash
cd demo
make clean && make
# 本地 x86 时 objdump 显示对应 ISA；ARM 交叉：
# arm-linux-gnueabihf-gcc -c -O0 -g add_asm.S demo03_main.c
# arm-linux-gnueabihf-objdump -dS demo03.elf

objdump -d add_asm.o
objdump -d -M reg-names-raw demo03   # 若已链接
gdb -batch -ex "disassemble add_asm" demo03
```

### 读 `add_asm` 清单

```arm
add_asm:
    add r0, r0, r1    @ r0 为返回值
    bx  lr
```

### 读 C `main` 调用链（`-O0 -g`）

- `mov` 装载参数到 **r0, r1**
- `bl add_asm` → **lr** 保存返回点
- `str` 保存返回值到局部变量

### 练习检查单

1. 指出 **栈指针** 在函数入口是否调整  
2. 标出 **callee-saved** 是否被修改  
3. `ldr [fp, #-N]` 对应哪个局部变量或参数  

- 内核 `ftrace`/`perf` 回溯依赖同一套帧分析

## 代码自测

**题目 1：** 分析以下 U-Boot 启动汇编代码的功能：它完成了什么操作？
```c
_start:
    LDR R0, =0x70000000
    ORR R0, R0, #0x13
    MCR p15, 0, R0, c1, c0, 0
```
<details>
<summary>参考答案</summary>

该代码配置 ARM 的协处理器 CP15 来设置系统控制：

1. `LDR R0, =0x70000000`：加载常量到 R0
2. `ORR R0, R0, #0x13`：R0 |= 0x13（设置位 0,1,4）
3. `MCR p15, 0, R0, c1, c0, 0`：写 R0 到 CP15 的系统控制寄存器（SCTLR）

位 0 = MMU 使能，位 1 = 对齐检查，位 4 = D-cache 使能。`0x13` = MMU on + 对齐检查 + D-cache on。`MCR` = Move to Coprocessor Register，从 ARM 寄存器写到协处理器。

这是典型的裸机/启动代码：直接操作 CP15 系统寄存器。

</details>
