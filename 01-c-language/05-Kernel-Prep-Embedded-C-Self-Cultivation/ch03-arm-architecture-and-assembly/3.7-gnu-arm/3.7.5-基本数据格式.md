# 3.7.5 基本数据格式

## 本节讲什么

GNU ARM 汇编中 **常数书写、字节序、对齐** 约定；与 C 类型宽度对应，避免 `ldrb`/`ldr` 误用。

## 要点

```arm
.word 0x12345678        @ 32 位，小端内存：78 56 34 12
.short 0xABCD
.byte 0xFF
.quad 0x1234            @ 64 位（AArch64/NEON 上下文）
```

- **@** 行注释；`#` 为立即数前缀（`mov r0, #1`）
- `.align 2` → 2^2 = 4 字节边界；结构体字段对齐影响加载指令选择
- 设备寄存器 32 位宽用 `ldr`；字节设备用 `ldrb` + `volatile` C 封装

## 代码自测

**题目 1：** GNU ARM 汇编中以下指令分别操作多少字节？
```asm
LDRB R0, [R1]  ; A
LDRH R0, [R1]  ; B
LDR  R0, [R1]  ; C
```

<details>
<summary>参考答案</summary>

A：加载 1 字节（Byte）到 R0，高位补零。B：加载 2 字节（Halfword）到 R0。C：加载 4 字节（Word）到 R0。还有 LDRSB/LDRSH（有符号扩展）。对应存储指令：STRB/STRH/STR。数据宽度匹配在内存映射 IO 中非常重要——读错误宽度可能产生错误结果。

</details>
