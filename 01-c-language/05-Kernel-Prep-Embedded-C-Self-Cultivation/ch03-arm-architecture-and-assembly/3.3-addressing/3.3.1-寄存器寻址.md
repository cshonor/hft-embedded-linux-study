# 3.3.1 寄存器寻址

## 本节讲什么

操作数直接来自寄存器，不访问内存——ARM 运算类指令的默认方式，速度最快。

## 要点

```arm
add r0, r1, r2        @ 三个寄存器
mov r3, r1            @ 寄存器复制
mul r0, r1, r2        @ r0 = r1 * r2
```

- R0–R12 通用；R13 SP、R14 LR、R15 PC 有特殊含义（**3.1**）
- 编译器尽量把局部变量保持在寄存器，减少 `ldr`/`str`

## 与后续衔接

- AAPCS 规定 R0–R3 传参（**3.6.1**）

## 代码自测

**题目 1：** 以下 ARM 寻址方式叫什么？
```asm
MOV R0, R1    ; 操作数是寄存器
ADD R0, R1, R2
```

<details>
<summary>参考答案</summary>

寄存器寻址——操作数直接在寄存器中。这是最快最常用的寻址方式，不需要访问内存。ARM 有 16 个通用寄存器（R0-R15），其中 R13=SP、R14=LR、R15=PC。寄存器寻址是 RISC 架构的基本特征。

</details>
