# 3.3.4 寄存器间接寻址

## 本节讲什么

地址 = 寄存器内容，零偏移——指针解引用 `*p` 的直接汇编对应。

## 要点

```arm
ldr r0, [r1]          @ r0 = *r1
str r0, [r2]          @ *r2 = r0
ldrb r3, [r4]         @ 字节读（char）
```

- 空 `[]` 表示偏移为 0
- 内核 `readl(addr)` 类宏最终落到 `ldr` + 设备寄存器基址

## 与后续衔接

- 加偏移变 **3.3.5**；多级指针多次 `ldr`

## 代码自测

**题目 1：** 寄存器间接寻址和 C 指针的关系是什么？以下汇编等价于哪行 C 代码？
```c
LDR R0, [R1]     @ R1 存储地址
LDR R2, [R0]      @ ?
```
<details>
<summary>参考答案</summary>

寄存器间接寻址 = C 语言的指针解引用。

`LDR R0, [R1]` 等价于 `int *p = addr;`（R1 是指针 p）
`LDR R2, [R0]` 等价于 `int x = *p;`（R0 现在是值，但作为指针再解引用）

更准确的对应：
```c
int *p = (int *)R1;  // R1 是地址
int x = *p;          // LDR R0, [R1]
int y = *(int *)x;   // LDR R2, [R0]（二级解引用）
```

RISC 的 Load-Store 架构意味着 C 指针操作在底层就是 LDR/STR。

</details>
