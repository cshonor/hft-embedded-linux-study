# 3.3.5 基址寻址

## 本节讲什么

`[Rn, #offset]` 等形式：基址 + 立即数或寄存器偏移；`!` 写回、`]` 后偏移等变体控制指针是否前进。

## 要点

```arm
ldr r0, [r1, #8]          @ 结构体字段偏移
ldr r0, [r1], #4          @ 读后 r1 += 4（后变址）
str r0, [r1, #4]!         @ 写前 r1 += 4（前变址）
ldr r0, [sp, #12]         @ 栈帧局部变量
```

| 形式 | 效果 |
|------|------|
| `[Rn, #imm]` | 地址不变 |
| `[Rn], #imm` | 访问后 Rn += imm |
| `[Rn, #imm]!` | 先 Rn += imm 再访问 |

- 函数栈帧中 `fp`/`sp` + 偏移访问参数与局部变量（**3.6.1**）

## 与后续衔接

- **ch05** 栈布局与 `[sp, #off]` 一一对应

## 代码自测

**题目 1：** 以下指令的寻址方式叫什么？前索引和后索引有什么区别？
```asm
LDR R0, [R1, #4]!   ; 前索引
LDR R0, [R1], #4     ; 后索引
```

<details>
<summary>参考答案</summary>

基址寻址——地址 = 基址寄存器 + 偏移量。前索引 [R1, #4]!：先计算 R1+4 作为地址，然后更新 R1=R1+4（! 表示回写）。后索引 [R1], #4：先用 R1 作为地址访问，然后更新 R1=R1+4。区别在于访问用的地址——前索引用新地址，后索引用旧地址。

</details>
