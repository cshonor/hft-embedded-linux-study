# 3.6 C语言和汇编语言混合编程

## 本节讲什么

同一工程内 **C 调汇编**、**汇编调 C**、**C 内嵌汇编** 三种路径；须共同遵守 **AAPCS/ATPCS** 调用约定，否则参数、返回值、栈帧错乱——内核 `asm/` 与驱动里极常见。

## 要点

| 方式 | 场景 | 小节 |
|------|------|------|
| C → 汇编函数 | 热点、平台原语 | **3.6.1** + demo |
| C 内嵌汇编 | 读协处理器、屏障 | **3.6.2** |
| 汇编 → C | 启动代码调 `main` | **3.6.3** |

```c
// demo03_main.c
extern int add_asm(int a, int b);
sum = add_asm(3, 5);
```

```arm
@ add_asm.S — AAPCS：r0,r1 入参，r0 返回
add r0, r0, r1
bx  lr
```

- DPDK `rte_pause()`、内核 `barrier()` 等为内联汇编封装

## 代码自测

**题目 1：** C 和汇编混合编程有哪几种方式？各适用什么场景？
<details>
<summary>参考答案</summary>

三种主要方式：

1. **内联汇编**（Inline Assembly）：C 函数中直接嵌入汇编，用 `asm`/`__asm__` 关键字。适用于少量特殊指令（如 MSR/CP15 操作寄存器、内存屏障）。

2. **C 调汇编**：C 中声明 `extern` 函数，汇编中用 `.global` 导出。适用于性能关键路径的手写优化。

3. **汇编调 C**：汇编中按 ATPCS 约定传参（R0-R3），`BL` 调用 C 函数。适用于启动代码（如 U-Boot 的 `_start` 调用 C 的 `board_init`）。

内核中常见内联汇编：读写系统寄存器、原子操作、内存屏障。

</details>
