# 5.5 mmap 映射区域探秘

## 本节讲什么

**mmap** 把 **文件或设备** 映射进进程虚拟地址，或 **匿名映射** 分配零页（heap 延伸、共享内存、栈）。是 Linux **VMA 扩展** 的主要手段，也是 **MMIO 访问硬件** 的用户态入口。

## 要点

```c
void *p = mmap(NULL, len, PROT_READ|PROT_WRITE,
               MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
munmap(p, len);
```

```bash
cat /proc/self/maps | grep mmap
strace -e mmap,munmap ./demo01_memory_zone 2>&1 | head
```

- 映射区在 maps 中常显示为 **匿名 `[anon]`** 或文件路径
- 大块 `malloc` 底层走 **mmap**（>128KB 量级，依 glibc 版本）

## 代码自测

**题目 1：** `mmap` 和 `malloc` 分配内存有什么本质区别？以下代码 `mmap` 返回的内存有什么特点？
```c
void *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE,
               MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
```

<details>
<summary>参考答案</summary>

`malloc` 从用户态堆（brk/mmap 混合）分配，由 libc 管理；`mmap` 直接向内核申请虚拟内存区域，按页对齐（通常 4KB）。这段代码映射了一页 4096 字节的匿名内存（无文件 backing），权限为可读写，私有映射（COW）。特点：(1) 已清零（内核保证匿名映射初值为零）；(2) 页对齐；(3) 必须用 `munmap` 释放，不能 `free`。

</details>
