# 1.2.3 使用 make 编译程序

## 本节讲什么

**Makefile** 语法：目标、依赖、自动变量 —— 多文件工程模板。

## 要点

```makefile
CC      ?= gcc
CFLAGS  ?= -Wall -Wextra -std=c11 -g
LDFLAGS ?=

app: main.o util.o
	$(CC) $(LDFLAGS) -o $@ $^

main.o: main.c util.h
	$(CC) $(CFLAGS) -c $< -o $@

util.o: util.c util.h
	$(CC) $(CFLAGS) -c $< -o $@

.PHONY: clean
clean:
	rm -f *.o app
```

| 自动变量 | 含义 |
|----------|------|
| **$@** | 目标 |
| **$<** | 首依赖 |
| **$^** | 全部依赖 |

```bash
make all
make clean
```

- **.PHONY`** 声明伪目标  
- 大型工程见 **1.2.4 CMake**

## 代码自测

**题目 1：** 以下 Makefile 的执行逻辑是什么？最终生成的可执行文件叫什么？
```c
main: main.o utils.o
	gcc main.o utils.o -o main

main.o: main.c utils.h
	gcc -c main.c

utils.o: utils.c utils.h
	gcc -c utils.c
```
<details>
<summary>参考答案</summary>

执行 `make` 时：
1. 默认目标 `main` 依赖 `main.o` 和 `utils.o`
2. 检查 `main.o`：若 `main.c` 或 `utils.h` 比 `main.o` 新，则执行 `gcc -c main.c`
3. 检查 `utils.o`：同理
4. 若任一 .o 被更新，重新链接生成 `main`

关键：Makefile 通过时间戳判断是否需要重新编译。`clean` 目标需 `make clean` 显式调用。

</details>
