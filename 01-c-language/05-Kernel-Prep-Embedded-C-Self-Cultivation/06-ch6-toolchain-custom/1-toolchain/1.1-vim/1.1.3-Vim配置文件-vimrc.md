# 1.1.3 Vim 配置文件：vimrc

## 本节讲什么

**`~/.vimrc`** 基础配置 —— C 语法高亮、缩进、行号。

## 要点

```vim
syntax on
filetype plugin indent on
set number
set tabstop=4 shiftwidth=4 expandtab
set autoindent
set hlsearch
set incsearch
colorscheme desert
```

| 选项 | 作用 |
|------|------|
| **expandtab** | Tab → 空格，内核风格 |
| **shiftwidth=4** | C 缩进 4 格 |
| **hlsearch** | 搜索高亮 |

```bash
vim ~/.vimrc
```

## 代码自测

**题目 1：** 以下 vimrc 配置各有什么作用？
```c
set nu          " 显示行号
set tabstop=4   " Tab 显示宽度
set expandtab   " Tab 转空格
set autoindent  " 自动缩进
syntax on       " 语法高亮
```
<details>
<summary>参考答案</summary>

- `set nu`：显示行号，方便定位
- `set tabstop=4`：Tab 字符显示为 4 个空格宽
- `set expandtab`：按 Tab 键插入空格而非制表符，避免不同编辑器缩进不一致
- `set autoindent`：新行继承上一行的缩进
- `syntax on`：启用语法高亮

vimrc 分为系统级（`/etc/vim/vimrc`）和用户级（`~/.vimrc`），用户级优先。

</details>
