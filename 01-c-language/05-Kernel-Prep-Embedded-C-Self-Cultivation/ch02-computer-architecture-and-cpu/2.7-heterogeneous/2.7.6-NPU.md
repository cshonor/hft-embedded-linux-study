# 2.7.6 NPU

## 本节讲什么

**神经网络处理单元** —— 手机/嵌入式 SoC 上的 AI 推理加速器（INT8/FP16）。

## 要点

| 特性 | 说明 |
|------|------|
| **算子** | Conv、Depthwise、激活融合 |
| **带宽** | 权重压缩、片上 SRAM |
| **接口** | IOCTL / 共享内存 / **MMIO** 启动 job |

- 代表：Apple ANE、高通 Hexagon、瑞芯微 NPU  
- CPU 跑 **驱动 + 预处理**；NPU 跑推理；实时性看 **job 排队延迟**  
- 与 DPDK 无直接交集；嵌入式视觉/语音常见

## 与后续衔接

**2.7.7** 网络向 DPU/IPU；**2.8.3** 设备寄存器启动加速器。

## 代码自测

**题目 1：** NPU 和 GPU 都能做 AI 计算，有什么区别？

<details>
<summary>参考答案</summary>

NPU 是专门为神经网络设计的 ASIC——卷积、池化、激活函数有专用硬件单元，效率远高于 GPU。GPU 是通用并行处理器，灵活但效率不如 NPU。手机 SoC 中的 NPU 功耗仅几瓦，专做人脸识别、拍照 AI 增强。GPU 适合训练，NPU 适合边缘推理。

</details>
