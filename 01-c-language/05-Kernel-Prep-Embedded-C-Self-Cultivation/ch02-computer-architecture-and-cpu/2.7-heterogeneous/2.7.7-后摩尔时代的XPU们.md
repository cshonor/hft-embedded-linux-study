# 2.7.7 后摩尔时代的 XPU 们

## 本节讲什么

**DPU / IPU / SmartNIC / CXL 设备** 等「XPU」—— 网络与数据中心的新兴专用芯片。

## 要点

| XPU | 角色 |
|-----|------|
| **DPU/IPU** | 虚拟化、存储、网络栈 offload |
| **SmartNIC** | RSS、TLS、RoCE、P4 可编程 |
| **CXL** | 内存扩展、池化，改变 NUMA 拓扑 |

- AWS Nitro、NVIDIA BlueField、Intel IPU — **释放 Host CPU** 给业务（含 DPDK app）  
- HFT：定制 **TOE/低延迟 NIC** + kernel bypass  
- 选型问：**哪些包处理在卡上、哪些仍回 CPU**

## 与后续衔接

**2.8 总线** PCIe/CXL 地址空间；**DPDK** PMD 驱动对接具体 NIC 硬件。

## 代码自测

**题目 1：** 为什么出现了这么多 XPU（CPU/GPU/NPU/TPU/DPU/BPU）？

<details>
<summary>参考答案</summary>

因为通用处理器（CPU）面临摩尔定律放缓和功耗墙，专用加速器（XPU）在特定领域能效更高。领域专用架构（DSA）通过牺牲通用性换取能效比——TPU 做 AI 比 CPU 快 30 倍能效。趋势是从"一个 CPU 做所有事"转向"多个 XPU 各做擅长的事"。

</details>
