# 2.7.4 FPGA

## 本节讲什么

**现场可编程门阵列** —— 硬件逻辑可重配，纳秒级固定延迟流水线。

## 要点

- **LUT + 布线** 实现任意组合/时序逻辑；开发：**Verilog/VHDL → 比特流**  
- 优势：**确定性延迟**、线速包处理、自定义协议  
- HFT：**tick-to-trade**、order gateway 硬件加速常见 FPGA  
- DPDK 侧：**AF_XDP + FPGA**、P4 SmartNIC（Netronome/Broadcom）

- 代价：开发周期长、功耗与面积高于 ASIC；量产量大后常转 **ASIC**

## 与后续衔接

**2.1.3** ASIC 流片；**2.8.3** PCIe BAR MMIO 访问 FPGA 寄存器。

## 代码自测

**题目 1：** FPGA 和 CPU/GPU 的本质区别是什么？什么场景用 FPGA？

<details>
<summary>参考答案</summary>

FPGA 是可编程硬件——通过配置逻辑门实现任意电路，本质上"用硬件实现软件"。区别：CPU/GPU 是固定硬件运行软件，FPGA 是重新配置硬件。优势：极致低延迟、可定制。场景：金融 HFT（纳秒级延迟）、5G 基带、原型验证。劣势：开发难度大、成本高。

</details>
