# 2.1.4 芯片的封装

## 本节讲什么

**Die 封装成可焊接/插接的芯片** —— 引脚、散热、电气保护与嵌入式 BOM 选型。

## 要点

| 封装 | 特点 |
|------|------|
| **DIP/QFP** | 引脚外露，手工焊接友好 |
| **BGA/LGA** | 球栅/触阵，高密度（x86、SoC） |
| **QFN** | 底部散热焊盘，MCU 常见 |

- **封装 ≠ 内核**：同 Die 可不同封装（引脚数、电压域）  
- **热设计**：DPDK 跑满核 + 网卡 DMA → 需关注 **TDP 与散热片**  
- 引脚定义见 **Datasheet**：电源、GND、复位、JTAG、外设总线

## 与后续衔接

**2.8** 引脚连到 PCB 总线，再映射为 **MMIO 地址**；**ch03** 开发板原理图读引脚。

## 代码自测

**题目 1：** 芯片封装的作用是什么？BGA 和 QFP 封装有什么区别？

<details>
<summary>参考答案</summary>

封装作用：(1)保护芯片；(2)散热；(3)电气连接芯片引脚到 PCB。QFP（四侧引脚扁平封装）引脚从侧面伸出，间距较大，手工焊接较容易。BGA（球栅阵列）引脚是底部焊球，密度高、信号完整性好，但需要专用设备焊接。嵌入式产品常用 QFP/BGA。

</details>
