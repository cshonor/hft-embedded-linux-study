## 代码自测

**题目 1：** 总线的作用是什么？地址总线和数据总线有什么区别？
```
// CPU 通过总线访问内存
CPU ---[地址总线]---> 内存
CPU <---[数据总线]---> 内存
```

<details>
<summary>参考答案</summary>

总线是 CPU 与外设之间的通信通道。地址总线：CPU 发出地址，决定寻址空间大小（32 位地址 = 4GB）。数据总线：传输数据，决定一次传输的数据量（32/64 位）。控制总线：传输读写控制信号。总线宽度直接影响 CPU 性能。

</details>
