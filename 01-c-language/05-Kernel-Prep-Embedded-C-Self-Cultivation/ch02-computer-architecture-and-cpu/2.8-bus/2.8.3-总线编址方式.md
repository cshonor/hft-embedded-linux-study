# 2.8.3 总线编址方式

## 本节讲什么

**统一编址（Memory-Mapped I/O）vs 独立编址（Port I/O）** —— 外设寄存器如何进入程序地址空间；**MMIO 重点**。

## 要点

| 方式 | 特点 | 平台 |
|------|------|------|
| **统一编址 MMIO** | 外设寄存器占内存地址段 | ARM、RISC-V、PCIe BAR |
| **独立编址 Port** | 专用 in/out 指令 | x86 传统 IO 空间 |

### MMIO 访问要点

```c
#define REG(base, off) (*(volatile uint32_t *)((base) + (off)))
REG(UART_BASE, 0x00) = 0x03;  /* 写控制寄存器 */
while (!(REG(UART_BASE, 0x04) & 0x01)) ;  /* 读状态位 */
```

- 必须 **`volatile`**：防止编译器优化掉对硬件的读写  
- **位域/掩码** 按 Datasheet，勿假设 RAM 语义  
- **对齐与宽度**：8/16/32 bit 访问；错误宽度 → fault 或读错  
- PCIe NIC：**BAR0** 映射 DMA 描述符环与控制寄存器 — DPDK PMD 初始化核心

### 与 DMA

- CPU 写 MMIO **启动 DMA**；数据在 **RAM**，不在寄存器地址  
- Cache 一致性：**2.4.3** flush/invalidate

## 与后续衔接

**2.8.4** 多字节 MMIO 与端序；**ch03** 具体外设基址表；内核 **readl/writel**。

## 代码自测

**题目 1：** 内存映射 I/O 和端口映射 I/O 的区别是什么？C 代码如何访问？
```c
// 内存映射 I/O (ARM)
#define GPIO_BASE  0x3F200000
volatile unsigned int *gpio = (volatile unsigned int *)GPIO_BASE;
*gpio = (1 << 5);  // 设置 GPIO5

// 端口映射 I/O (x86)
outb(0x80, 0x3F8);  // 向端口 0x3F8 写入 0x80
```
<details>
<summary>参考答案</summary>

**内存映射 I/O**（ARM/MIPS）：外设寄存器映射到统一地址空间，用普通指针访问。需要 `volatile` 防止编译器优化掉重复读写。

**端口映射 I/O**（x86）：外设使用独立的 I/O 地址空间，需要特殊指令（`in`/`out`），C 语言通过 `outb()`/`inb()` 等封装函数访问。

区别：内存映射 I/O 可以用 `memcpy`/指针运算，端口映射不行。ARM 采用内存映射，所以嵌入式 C 编程中 `volatile` 指针操作是基本功。

</details>
