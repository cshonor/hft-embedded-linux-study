# 2.8.1 地址的本质

## 本节讲什么

**地址是总线上的逻辑编号** —— 非「第几号抽屉」，而是 **CPU 发出、译码器路由** 的信号。

## 要点

- CPU 读/写时：**地址线** 选设备/单元，**数据线** 传内容，**控制线** 读/写使能  
- **物理地址** vs **虚拟地址**：OS/MMU 再映射一层（**ch05**）  
- 同一物理地址空间可挂：**RAM、Flash、GPIO、UART、NIC BAR**

```c
uint32_t *p = (uint32_t *)0x20000000;  /* 可能是 SRAM，也可能是外设 — 看 Memory Map */
```

- DPDK：`/proc/iomem` 查看设备占用的物理区间

## 代码自测

**题目 1：** CPU 地址的本质是什么？为什么 32 位 CPU 最大寻址 4GB？

<details>
<summary>参考答案</summary>

地址是内存中每个字节的编号。32 位 CPU 有 32 根地址线，可以产生 2^32 = 4294967296 个不同地址，即 4GB。64 位 CPU 理论上可寻址 16EB，但实际受限于物理引脚和内存控制器（通常 48 位 = 256TB）。虚拟地址空间和物理地址空间是两个不同的概念。

</details>
