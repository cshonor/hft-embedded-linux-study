## 代码自测

**题目 1：** 为什么需要 Cache？Cache 命中的基本原理是什么？

<details>
<summary>参考答案</summary>

CPU 速度远快于内存（100:1 以上），Cache 利用局部性原理缩小速度差距。局部性：(1)时间局部性——刚访问的数据可能再次访问；(2)空间局部性——访问的数据附近的数据可能被访问。Cache 命中时从快速 SRAM 读取，未命中时从慢速 DRAM 读取。

</details>
