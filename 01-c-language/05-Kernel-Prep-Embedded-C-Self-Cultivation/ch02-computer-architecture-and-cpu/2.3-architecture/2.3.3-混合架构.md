# 2.3.3 混合架构

## 本节讲什么

**现代 SoC 混合**：片内哈佛 + 片外统一总线；Cache 弥合速度差。

## 要点

- CPU 核内：I-Cache / D-Cache 分离（哈佛味道）  
- 片外 DDR：统一地址空间（冯·诺依曼对外）  
- **ARM Cortex-A**：多级 Cache + AXI 总线  

## 与后续衔接

**2.4** Cache；**2.6** 多核互连。

## 代码自测

**题目 1：** 现代 CPU 为什么要用混合架构（Modified Harvard）？

<details>
<summary>参考答案</summary>

纯哈佛架构的指令和数据空间完全分离，编程不灵活（不能把数据当代码执行，不能自修改代码）。混合架构在 L1 Cache 层面分离（指令/数据各自缓存），但在 L2/L3 和主存层面统一——既获得哈佛架构的并行优势，又保留冯诺依曼的灵活性。x86 和 ARM 都用混合架构。

</details>
