# 2.6.1 单核处理器的瓶颈

## 本节讲什么

**频率墙、功耗墙、ILP 墙** —— 为何不能无限提高单核 GHz。

## 要点

| 瓶颈 | 表现 |
|------|------|
| **频率** | 深流水线 + 线延迟限制 |
| **功耗** | P ∝ CV²f，散热成为硬约束 |
| **ILP** | 指令相关使 IPC 趋近上限 |

- 2005 前后业界转向 **多核** 而非单纯提频  
- 嵌入式：单核 MCU 仍大量存在（成本、实时）  
- 服务器 DPDK：**多核水平扩展** 替代超频

## 与后续衔接

**2.6.2** 多核互连；**2.5** 单核 ILP 优化已接近天花板。

## 代码自测

**题目 1：** 单核处理器提高频率遇到什么物理限制？

<details>
<summary>参考答案</summary>

(1)功耗墙：功耗与频率立方成正比（P ~ f^3），频率过高导致散热不可行；(2)内存墙：内存速度跟不上 CPU；(3)ILP 墙：指令级并行度有限，乱序执行收益递减；(4)延迟墙：光速限制下信号传播延迟。这些限制使得 2005 年后 CPU 发展从提频转向多核。

</details>
