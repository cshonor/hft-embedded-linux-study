## 代码自测

**题目 1：** 以下哪种情况会导致流水线停顿？
```
1. ADD R1, R2, R3
2. SUB R4, R1, R5  // 依赖 R1
3. MUL R6, R4, R7  // 依赖 R4
```

<details>
<summary>参考答案</summary>

指令 2 等待指令 1 的 R1 结果（数据冒险），指令 3 等待指令 2 的 R4 结果。流水线通过转发（forwarding）可以减少停顿——ALU 计算结果直接转发给下一条指令，不必等写回。但 load-use 冒险（LD 后紧跟使用）仍需停顿一拍。

</details>
