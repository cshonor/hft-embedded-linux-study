# 2.5.3 流水线冒险

## 本节讲什么

**结构 / 数据 / 控制冒险** —— 流水线停顿（stall/bubble）的三大来源。

## 要点

| 类型 | 原因 | 缓解 |
|------|------|------|
| **结构** | 硬件资源冲突（单端口内存） | 哈佛分离、双端口 |
| **数据** | 读后写、写后读相关 | 旁路（forwarding）、stall |
| **控制** | 分支/跳转改变 PC | 预测、延迟槽 |

```c
a = b + c;   /* 写 a */
d = a + 1;   /* 读 a — RAW 冒险，可能 stall 或 forwarding */
```

- 编译器 **调度指令** 可插入无关指令填 bubble  
- 内核 **内存屏障** 与流水线无关，约束的是 **可见性/顺序**（别混淆）

## 代码自测

**题目 1：** 流水线冒险有哪三种类型？分别如何解决？

<details>
<summary>参考答案</summary>

(1)结构冒险：资源冲突（如同时访存取指和访存取数据）——哈佛架构分离 I/D 总线解决。(2)数据冒险：数据依赖（RAW/WAR/WAW）——转发/旁路、流水线停顿解决。(3)控制冒险：分支指令改变 PC——分支预测、延迟分支解决。冒险是流水线性能损失的主要原因。

</details>
