# 6.2.1 指定初始化数组元素

## 本节讲什么

数组指定初始化用 **`[index] = value`** 语法，稀疏数组与查找表尤其清晰。ROM 中只占用实际元素，未写明的下标为 0（静态存储期）。

## 要点

```c
/* 稀疏 IRQ 映射表 */
static int irq_map[256] = {
    [0]  = -1,
    [32] = 1,
    [33] = 2,
    [255] = -1,
};

/* 字符串/枚举索引（C99 枚举即 int 常量） */
enum { OP_ADD, OP_SUB, OP_MUL, OP_MAX };
static const char *op_name[OP_MAX] = {
    [OP_ADD] = "add",
    [OP_SUB] = "sub",
    [OP_MUL] = "mul",
};
```

```c
/* 范围初始化：GNU 扩展 case ... 的「表驱动 cousin」 */
static int level[16] = {
    [0 ... 3] = 1,   /* GNU: 连续下标批量赋值 */
    [15] = 99,
};
```

> **注意**：`[0 ... 3]` 为 **GNU 扩展**，`-std=c99 -pedantic` 会警告；内核普遍可用。

```bash
gcc -std=gnu11 -c table.c
objdump -s -j .rodata table.o | less   # 观察稀疏表在 .rodata 的布局
```

- 与 **memset 全表** 相比：源码可读、编译期确定
- DPDK `rte_*` 静态 ops 表偶见 designated 初始化

## 代码自测

**题目 1：** C99 designated initializer 如何初始化数组的特定元素？以下代码输出什么？
```c
int arr[10] = { [3] = 100, [7] = 200 };
for (int i = 0; i < 10; i++)
    printf("%d ", arr[i]);
```
<details>
<summary>参考答案</summary>

输出 `0 0 0 100 0 0 0 200 0 0`。

C99 designated initializer（指定初始化器）：
- `[3] = 100`：将下标 3 的元素初始化为 100
- `[7] = 200`：将下标 7 的元素初始化为 200
- 其余元素自动初始化为 0

优点：
- 不需要按顺序初始化
- 未指定的元素自动清零
- 代码可读性好，明确指定哪个元素

对比 C89：`int arr[10] = {0,0,0,100,0,0,0,200,0,0};`（冗长且易错）

内核用法：`const int lookup[256] = { ['A'] = 1, ['B'] = 2, ['C'] = 3 };`

</details>
