# 6.2 指定初始化

## 本节讲什么

**指定初始化（designated initializer）** 允许按 **下标或成员名** 初始化聚合类型，不必按顺序填零。C99 纳入标准；GNU 更早支持。内核驱动表、DPDK 静态配置、协议常量表均大量使用。

## 要点

```c
int a[10] = { [3] = 1, [7] = 2 };
struct cfg { int port; const char *name; } c = { .port = 8080, .name = "dpdk0" };
```

- 未指定元素 **零初始化**
- 可与普通初始化混用（C99 起顺序规则需查标准）
- C++ 不支持相同语法（C++20 有不同 designated init）

## 代码自测

**题目 1：** 以下两种初始化方式有什么区别？指定初始化的优势是什么？
```c
struct conf c1 = {0, 0, 8080, 1, 0};   // 位置初始化
struct conf c2 = {.port = 8080, .enable = 1};  // 指定初始化
```

<details>
<summary>参考答案</summary>

位置初始化需要记住字段顺序，容易写错（如把 port 写成第 2 个），且未列出的字段自动清零。指定初始化通过 `.field = value` 按名赋值，不依赖字段顺序，未指定的字段自动清零。优势：(1) 可读性好；(2) 结构体增删字段不影响已有初始化代码；(3) 只初始化关心的字段。这是 C99 标准，GNU C 也支持 `[index] = value` 用于数组。

</details>
