# 6.4.1 typeof关键字

## 本节讲什么

**typeof**（GNU 扩展；C23 标准关键字同名）在编译期复制操作数的类型，用于宏中声明与参数同类型的临时变量，避免 `void*` 或多次求值。

## 要点

```c
int x = 42;
typeof(x) y = 0;        /* y 为 int */
typeof(&x) p = &x;      /* p 为 int * */

#define SWAP(a, b) do {                 \
    typeof(a) __t = (a);                \
    (a) = (b);                          \
    (b) = __t;                          \
} while (0)
```

| 对比 | 说明 |
|------|------|
| `typeof(a)` | 保留 const/volatile |
| `__typeof__` | 旧 GNU 拼写，等价 |
| C23 `_Generic` | 标准替代，宏写法更繁 |

```c
/* 内核常用 typeof(*ptr) */
#define assign_ptr(ptr, val) do {       \
    *(ptr) = (typeof(*(ptr)))(val);     \
} while (0)
```

- Clang/GCC 均支持；MSVC 无 typeof，需 typedef 或 C11 `_Generic`
- 与 **`__builtin_types_compatible_p`** 配合做类型断言

## 代码自测

**题目 1：** typeof 关键字的作用是什么？以下代码中 t 的类型是什么？
```c
int x = 42;
typeof(x) t;          // t 的类型?
typeof(x + 1) t2;     // t2 的类型?
typeof("hello") s;    // s 的类型?
```
<details>
<summary>参考答案</summary>

`typeof` 是 GCC 扩展，推导表达式的类型。

- `typeof(x) t;`：t 是 `int`（与 x 同类型）
- `typeof(x + 1) t2;`：t2 是 `int`（x+1 的结果类型是 int）
- `typeof("hello") s;`：s 是 `char[6]`（字符串字面量的类型）

用法：
- 声明与某变量同类型的变量：`typeof(a) b;`
- 在宏中自动适配类型：`#define SWAP(a, b) { typeof(a) t = a; a = b; b = t; }`
- container_of 宏的核心：`typeof(((type *)0)->member) *mptr = ptr;`

C23 引入了 `typeof` 作为标准特性（GCC 11+/Clang 15+ 支持）。

</details>
