# 6.3.1 表达式、语句和代码块

## 本节讲什么

C 语法区分 **表达式（有值）** 与 **语句（执行效果）**；**复合语句** `{ ... }` 即代码块。宏只能「文本替换」——若要在宏里写 `if`、临时变量又 **返回一个值**，需要语句表达式桥接二者。

## 要点

| 种类 | 示例 | 能否出现在右值位置 |
|------|------|-------------------|
| **表达式** | `a + b`、`func()` | 是 |
| **语句** | `if (x) y;`、`return 0;` | 否 |
| **代码块** | `{ int t=x; x=t; }` | 单独不行 |

```c
int x = 1 + 2;           /* 表达式语句 */
if (x > 0) { x++; }      /* 语句块 */

/* 错误：块不是表达式 */
/* int y = { int t=1; t; }; */
```

```c
/* GNU：块 + 末尾表达式 → 整体是表达式 */
int y = ({
    int t = x + 1;
    t * 2;
});
```

- 宏 `MAX(a,b)` 若写成三元运算符，**a/b 可能被求值两次**（见 **6.3.3**）
- 内核 `do { ... } while (0)` 是 **语句** 包装，无返回值

## 代码自测

**题目 1：** C 语言中表达式、语句和代码块的区别是什么？以下各是什么？
```c
x + 1              // ?
x = 1;              // ?
{ int t = x; x = y; y = t; }  // ?
```
<details>
<summary>参考答案</summary>

- **表达式**（Expression）：有值和类型。`x + 1` 是表达式，值为计算结果。单独的 `42`、`x++` 也是表达式。
- **语句**（Statement）：以分号结尾，不一定有值。`x = 1;` 是语句。`x + 1;` 也是合法语句（计算但丢弃结果）。
- **代码块**（Block/Compound Statement）：`{}` 包围的语句序列，形成新的作用域。块内变量在块外不可见。

C 的基本分类：
- 表达式语句：`x = 1;`
- 声明语句：`int x;`
- 复合语句（块）：`{ ... }`
- 选择语句：`if`/`switch`
- 循环语句：`while`/`for`/`do`
- 跳转语句：`goto`/`break`/`continue`/`return`

GNU C 扩展：语句表达式 `({ ... })` 让代码块变成有值的表达式。

</details>
