# 6.3.3 在宏定义中使用语句表达式

## 本节讲什么

编写「像函数一样返回值」的宏时，语句表达式 + **`typeof`** 是标准套路：临时变量保存参数、只求值一次、避免 side effect。本节给出 **`min`/`max`** 与带 `if` 的安全宏模板。

## 要点

### 错误示范

```c
#define BAD_MAX(a, b) ((a) > (b) ? (a) : (b))
/* BAD_MAX(x++, y++)  → x/y 可能 ++ 两次 */
```

### 推荐写法

```c
#define MAX(a, b) ({                        \
    typeof(a) __max_a = (a);                \
    typeof(b) __max_b = (b);                \
    __max_a > __max_b ? __max_a : __max_b;  \
})
```

```c
/* 带分支的宏 */
#define CLAMP(val, lo, hi) ({               \
    typeof(val) __v = (val);                \
    typeof(lo)  __lo = (lo);                \
    typeof(hi)  __hi = (hi);                \
    __v < __lo ? __lo : (__v > __hi ? __hi : __v); \
})
```

| 技巧 | 目的 |
|------|------|
| `typeof` 临时 | 类型安全、单求值 |
| 唯一变量名 `__max_a` | 避免嵌套宏名冲突（内核用更复杂 token paste） |
| 外层 `({})` | 可用于 `if (MAX(a,b) > 0)` |

```c
/* 语句表达式 + GNU 条件编译 */
#define IS_ERR_OR_NULL(ptr) ({              \
    const void *__p = (ptr);                \
    !__p || (unsigned long)__p >= (unsigned long)-4096UL; \
})
```

- 若宏展开为 **语句** 而非表达式，用 `do { ... } while (0)`（无返回值）

## 代码自测

**题目 1：** 以下 MAX 宏用语句表达式解决了什么问题？
```c
#define MAX(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    _a > _b ? _a : _b; \
})
```
<details>
<summary>参考答案</summary>

解决了传统宏的两个问题：

1. **副作用求值两次**：`MAX(i++, j++)` 传统宏会 i++/j++ 各执行两次。语句表达式版本只求值一次（存入 `_a`/`_b`）。

2. **类型安全**：`typeof(a)` 推导类型，`_a` 和 `a` 类型一致。传统宏用 `((a) > (b) ? (a) : (b))` 可能因隐式转换导致精度丢失。

3. **变量名冲突**：`_a`/`_b` 是块内局部变量，不污染外部作用域。

这是 Linux 内核 min/max 宏的标准实现（`include/linux/minmax.h`）。

注意：`_a`/`_b` 用下划线前缀避免与用户变量冲突。更安全用 `__UNIQUE_ID` 生成唯一名。

</details>
