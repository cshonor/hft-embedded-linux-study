# 6.3.4 内核中的语句表达式

## 本节讲什么

Linux 内核头文件大量宏基于语句表达式：`min`/`max`、`clamp`、`container_of`、位域操作、`READ_ONCE` 等。读内核或写 out-of-tree 模块必须能 **展开阅读** 这些宏。

## 要点

```c
/* include/linux/minmax.h 思路 */
#define min(x, y) ({                    \
    typeof(x) min1 = (x);               \
    typeof(y) min2 = (y);               \
    (void) (&min1 == &min2);            /* 类型不一致则编译报错 */ \
    min1 < min2 ? min1 : min2;          \
})
```

```c
/* container_of — 见 6.4.4 */
#define container_of(ptr, type, member) ({          \
    void *__mptr = (void *)(ptr);                   \
    ((type *)(__mptr - offsetof(type, member)));     \
})
```

```c
/* 位操作：设/清/测 */
#define BIT(nr) (1UL << (nr))
#define GENMASK(h, l) (/* ... */)
```

- **`(void) (&min1 == &min2)`**： ingenious 编译期类型检查 trick
- **`READ_ONCE`/`WRITE_ONCE`**：含 `volatile` 与 barrier，包装在宏内
- DPDK **`RTE_MIN`/`RTE_MAX`** 类似，定义在 `rte_common.h`

```bash
# 查看预处理展开
gcc -E -I/path/to/kernel/headers test.c | grep -A5 'min('
```

## 代码自测

**题目 1：** Linux 内核中语句表达式有哪些典型应用场景？
<details>
<summary>参考答案</summary>

内核中语句表达式的典型应用：

1. **min/max/clamp 宏**：类型安全 + 单次求值
```c
#define min(x, y) ({ typeof(x) _x = (x); typeof(y) _y = (y); (void)(&_x == &_y); _x < _y ? _x : _y; })
```
`(void)(&_x == &_y)` 是编译时类型检查：若 x/y 类型不同，指针比较警告。

2. **循环展开宏**：`for_each_*` 系列宏
3. **锁保护宏**：`lockdep_*` 宏中临时变量
4. **条件编译替代**：`IS_ENABLED()` 宏
5. **container_of**：结合 typeof + offsetof

核心价值：在宏中安全地使用临时变量，不污染调用者作用域，同时保持表达式语义。
