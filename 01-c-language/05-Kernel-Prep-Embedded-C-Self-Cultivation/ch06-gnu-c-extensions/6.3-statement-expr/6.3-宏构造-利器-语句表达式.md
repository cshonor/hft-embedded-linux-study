# 6.3 宏构造「利器」：语句表达式

## 本节讲什么

**语句表达式（statement expression）** 语法 `({ statements; expr; })` 把多条语句打包成一个 **有值的表达式**，是 GNU 扩展。内核 **`min`/`max`**、**`container_of`**、原子操作宏都依赖它；没有语句表达式，很多 C 宏无法既安全又返回结果。

## 要点

```c
#define min(a, b) ({                    \
    typeof(a) _a = (a);                 \
    typeof(b) _b = (b);                 \
    _a < _b ? _a : _b;                  \
})
```

- 最后一项 **分号前的表达式** 为整个 `({})` 的值
- 内部可声明临时变量，避免宏参数 **多次求值**
- `-std=gnu11` 默认可用；纯 `-std=c11` 非法

## 代码自测

**题目 1：** 语句表达式和普通逗号表达式有什么区别？以下宏为什么需要语句表达式？
```c
// 逗号表达式
#define MAX1(a, b) ((a) > (b) ? (a) : (b))
// 语句表达式
#define MAX2(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    _a > _b ? _a : _b; \
})
```

<details>
<summary>参考答案</summary>

`MAX1` 对 `MAX(i++, j++)` 会双重求值副作用；`MAX2` 用语句表达式 `({ ... })` 先求值一次存入临时变量，再比较。语句表达式允许在块内声明变量、多条语句，最后一个表达式的值作为整体返回值。逗号表达式不能声明变量也不能有多条语句。内核宏大量使用语句表达式（如 `min`、`max`、`container_of`）。这是 GNU 扩展，非标准 C。

</details>
