# 6.10.3 内联函数与宏

## 本节讲什么

**宏** 灵活但缺类型、双求值；**inline 函数** 更安全。内核仍大量宏因 **typeof/语句表达式**；新代码优先 **static inline**。

## 要点

```c
#define MACRO_SQ(x) ((x) * (x))
static inline int sq(int x) { return x * x; }
```

| 需求 | 选宏 | 选 inline |
|------|------|-----------|
| `#x` 字符串化 | 是 | 否 |
| 热点小函数 | 可 | **优先** |

## 代码自测

**题目 1：** 内联函数比宏安全在哪？以下宏有什么问题，用 inline 函数如何解决？
```c
#define SQUARE(x) ((x) * (x))
int r = SQUARE(i++);  // 问题？
```

<details>
<summary>参考答案</summary>

`SQUARE(i++)` 展开为 `((i++) * (i++))`，`i` 自增两次，行为未定义。用 inline 函数解决：`static inline int square(int x) { return x * x; }`，参数只求值一次。inline 函数优势：(1) 参数只求值一次，无副作用问题；(2) 有类型检查；(3) 调试时可设断点；(4) 不会意外的命名冲突（宏没有作用域）。宏的优势：(1) 可用于任意类型（泛型）；(2) 编译期字符串拼接。C11 的 `_Generic` 可让函数实现泛型。

</details>
