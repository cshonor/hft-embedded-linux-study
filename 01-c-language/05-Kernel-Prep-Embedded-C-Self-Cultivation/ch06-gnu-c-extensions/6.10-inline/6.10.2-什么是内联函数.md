# 6.10.2 什么是内联函数

## 本节讲什么

**内联** = 编译器把函数体 **插入调用点**，像宏但 **有类型检查** 与 **单求值**。C99 **`inline` 关键字** 与 **`static inline`** 头文件模式是内核/DPDK 默认写法。

## 要点

```c
static inline uint32_t rol32(uint32_t x, int n)
{
    return (x << n) | (x >> (32 - n));
}
```

```c
/* C99 extern inline 模型（少用，易 ODR 踩坑） */
inline int helper(int x) { return x + 1; }
```

| 形式 | ODR / 链接 |
|------|------------|
| `static inline` in .h | 每 TU 副本，无符号冲突 |
| 普通函数 | 单一定义，`call` 指令 |
| 宏 | 文本替换，无类型 |

- **代码膨胀**：大函数 inline 增大 I-cache 压力
- **函数指针** 取址时通常 **必须** 产生 out-of-line 副本
- DPDK **`static __rte_always_inline`** 强制热路径展开

```bash
gcc -O2 -S inline.c -o inline.s
grep -c 'call' inline.s
```

## 代码自测

**题目 1：** inline 函数和宏定义有什么区别？以下两种方式各有什么问题？
```c
// 宏
#define SQUARE(x) ((x)*(x))
// 内联函数
static inline int square(int x) { return x * x; }

// 调用
SQUARE(i++);     // 问题?
square(i++);     // 问题?
```
<details>
<summary>参考答案</summary>

宏 `SQUARE(i++)`：`i++` 被求值两次，i 自增两次。副作用问题。

内联函数 `square(i++)`：`i++` 只求值一次（作为参数传递），i 自增一次。安全。

区别：
| | 宏 | inline 函数 |
|---|---|---|
| 类型检查 | 无 | 有 |
| 副作用 | 可能多次求值 | 只一次 |
| 调试 | 无法单步 | 可调试（-O0） |
| 作用域 | 全局 | 文件级（static） |
| 类型通用 | 是 | 否（需 typeof/宏配合）|

内核中：简单操作用 inline 函数（如 `list_add`），类型泛型用宏（如 `container_of`/`min`）。

`static inline` 必须 static：避免链接器符号冲突。`inline` 关键字只是建议，编译器可能不内联。`__attribute__((always_inline))` 强制内联。

</details>
