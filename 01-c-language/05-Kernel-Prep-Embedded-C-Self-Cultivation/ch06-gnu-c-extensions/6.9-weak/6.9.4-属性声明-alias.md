# 6.9.4 属性声明：alias

## 本节讲什么

**`__attribute__((alias("sym")))`** 为现有符号创建 **别名**；常与 **weak** 结合导出兼容旧名。

## 要点

```c
void default_handler(int sig) { (void)sig; }

void legacy_handler(int sig)
    __attribute__((alias("default_handler")));
```

| 属性 | 作用 |
|------|------|
| `alias("target")` | 本符号为 target 别名 |
| `weak` | 可被强符号覆盖 |

```bash
nm demo.o | grep handler
```

- **限制**：alias 目标须在同翻译单元

## 代码自测

**题目 1：** `__attribute__((alias("target")))` 的作用是什么？以下代码中 `fast_memcpy` 和 `memcpy` 的关系？
```c
void my_memcpy(void *d, const void *s, size_t n) { /* ... */ }
void memcpy(void *d, const void *s, size_t n)
    __attribute__((alias("my_memcpy")));
```

<details>
<summary>参考答案</summary>

`alias("my_memcpy")` 让 `memcpy` 成为 `my_memcpy` 的别名——两个符号指向同一个函数地址，不产生额外代码。效果类似 `#define memcpy my_memcpy`，但在链接器层面实现，对动态链接也有效。用途：(1) 给函数起别名提供兼容接口；(2) 实现弱符号的默认实现（`__attribute__((weak, alias("default_impl")))`）。注意：`alias` 目标必须在同一翻译单元中定义。

</details>
