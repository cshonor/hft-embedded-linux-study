# 6.9 属性声明：weak

## 本节讲什么

**弱符号（weak symbol）** 链接时若存在 **强符号** 同名定义则 **被覆盖**；否则使用 weak 默认实现。`__attribute__((weak))` 用于 **可插拔 hook、BSP 默认 stub、单元测试替换**。

## 要点

```c
void board_init(void) __attribute__((weak));
void board_init(void) { /* default empty */ }
```

- 函数与全局变量均可 weak
- 链接阶段决议，非运行时
- **demo03** 演示 weak 覆盖

## 代码自测

**题目 1：** `weak` 属性的变量被强符号覆盖时，链接器如何处理？以下代码输出什么？
```c
// a.c
int debug_level __attribute__((weak)) = 0;
// b.c
int debug_level = 100;
// main.c
extern int debug_level;
int main(void) { printf("%d\n", debug_level); }
```
编译：`gcc a.c b.c main.c`

<details>
<summary>参考答案</summary>

输出 `100`。链接器规则：强符号优先于弱符号。`b.c` 中的 `debug_level = 100` 是强符号，覆盖 `a.c` 中的弱符号 `= 0`。如果没有 `b.c`，则使用弱符号默认值 0。用途：库提供默认配置（弱符号），应用层覆盖（强符号）实现定制，无需修改库代码。`__attribute__((weak))` 也可用于函数，效果相同。

</details>
