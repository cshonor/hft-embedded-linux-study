# 6.9.2 函数的强符号与弱符号

## 本节讲什么

**weak 函数** 提供默认空实现；板级提供 **强符号** 同签名函数即可 **无修改链接** 替换。与 **函数指针表** 相比：零 indirection，但 **仅一个** 最终实现。

## 要点

```c
void hook_on_boot(void) __attribute__((weak));
void hook_on_boot(void) { printf("default hook\n"); }

/* board.c 强符号 */
void hook_on_boot(void) { printf("board hook\n"); }
```

| weak 函数 | 函数指针 |
|-----------|----------|
| 零开销直接调用 | 需间接调用 |
| 仅一份实现 | 可运行时切换 |
| 链接期绑定 | 灵活 |

## 代码自测

**题目 1：** weak 函数和函数指针表都能实现"可替换实现"，各有什么优缺点？
```c
// 方案 A: weak 函数
void hook(void) __attribute__((weak));
void hook(void) { printf("default\n"); }  // 可被强符号覆盖

// 方案 B: 函数指针
void (*hook)(void) = default_hook;  // 运行时可换
```

<details>
<summary>参考答案</summary>

weak 函数优点：(1) 零间接调用开销（链接期绑定，直接跳转）；(2) 代码简洁。缺点：(1) 只能有一个最终实现；(2) 运行时不能切换。函数指针优点：(1) 运行时可动态切换；(2) 可有多套实现。缺点：(1) 每次调用间接寻址（多一次内存访问）；(2) 需要全局变量。嵌入式启动阶段用 weak（零开销、链接期决定），运行时需要多态用函数指针。

</details>
