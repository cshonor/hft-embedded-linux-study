# 6.6 属性声明：section

## 本节讲什么

**`__attribute__((section("name")))`** 把变量或函数放入 **自定义 ELF 段**，链接脚本 **`SECTIONS`** 再决定加载地址。用于 **init 段回收**、**U-Boot 自复制**、**模块参数表**、**tracepoint 段**。

## 要点

```c
static int cfg __attribute__((section(".my_cfg"))) = 42;
void boot_helper(void) __attribute__((section(".boot.text")));
```

```bash
objdump -h a.out          # 段列表
readelf -S a.out | grep boot
nm a.out | grep boot_helper
```

## 代码自测

**题目 1：** `__attribute__((section(".init")))` 放在函数声明上有什么效果？以下代码的函数会出现在 ELF 的哪个段？
```c
void early_init(void) __attribute__((section(".init.text")));
void early_init(void) { /* ... */ }
```
用 `readelf` 如何验证？

<details>
<summary>参考答案</summary>

该函数被放入名为 `.init.text` 的自定义段，而非默认的 `.text`。效果：(1) 链接脚本可把 `.init.text` 放到特定地址（如 U-Boot 的运行前复制区域）；(2) 内核用 `__init` 宏把初始化函数放入 `.init.text`，启动后回收该段内存。验证：`readelf -S a.out | grep init.text` 看段是否存在；`nm a.out | grep early_init` 看符号地址是否在该段范围内。

</details>
