# 6.8.2 变参函数的设计与实现

## 本节讲什么

C **变参函数** 用 **`...`** 与 **`stdarg.h`**（`va_list` / `va_start` / `va_arg` / `va_end`）实现。设计日志 API 时：固定前缀参数（level、tag）+ 可变 fmt/args；format 属性索引要 **跳过固定参**。

## 要点

```c
#include <stdarg.h>
#include <stdio.h>

void vlog(int level, const char *tag,
          const char *fmt, ...)
    __attribute__((format(printf, 3, 4)));

void vlog(int level, const char *tag,
          const char *fmt, ...)
{
    va_list ap;
    va_start(ap, fmt);
    fprintf(stderr, "[%d][%s] ", level, tag);
    vfprintf(stderr, fmt, ap);
    fputc('\n', stderr);
    va_end(ap);
}
```

| 规则 | 说明 |
|------|------|
| 至少一个 named 参数在 `...` 前 | C 要求 |
| default promotion | `char`→`int`，`float`→`double` |
| `va_end` 必须调用 | 栈清理 |

- 内核 **`printk`** 支持 `%pV` 等扩展格式
- DPDK **`RTE_LOG`** 多级 + 编译期 level

## 代码自测

**题目 1：** 以下自定义 printf 实现，va_list 的使用流程是什么？
```c
void my_printf(const char *fmt, ...) {
    va_list args;
    va_start(args, fmt);
    while (*fmt) {
        if (*fmt == '%') {
            fmt++;
            switch (*fmt) {
                case 'd': printf("%d", va_arg(args, int)); break;
                case 's': printf("%s", va_arg(args, char*)); break;
            }
        } else { putchar(*fmt); }
        fmt++;
    }
    va_end(args);
}
```
<details>
<summary>参考答案</summary>

va_list 使用流程：
1. `va_list args;`：声明参数列表变量
2. `va_start(args, fmt);`：初始化，从最后一个固定参数 fmt 之后开始读可变参数
3. `va_arg(args, int)`：取出下一个参数，指定类型为 int。每次调用后指针前移
4. `va_end(args);`：清理

关键点：
- `va_arg` 必须知道参数类型（通过格式字符串推断）
- 类型提升：`char`/`short` 自动提升为 `int`，`float` 提升为 `double`
- 无法反向遍历或随机访问（只能顺序取）
- 不同架构 va_list 实现不同（x86 栈上，ARM 寄存器+栈混合）

这就是为什么 printf 必须有格式字符串——编译器和运行时都依赖它来推断参数类型和数量。

</details>
