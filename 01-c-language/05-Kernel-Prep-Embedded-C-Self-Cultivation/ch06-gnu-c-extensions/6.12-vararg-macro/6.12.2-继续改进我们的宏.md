# 6.12.2 继续改进我们的宏

## 本节讲什么

逐步完善 **`LOG` 宏**：加入 **级别**、**`__FILE__`/`__LINE__`/`__FUNCTION__`**、**`##__VA_ARGS__` 空参**、**do-while(0)** 包装，并与 **6.8 format 属性** 底层函数配合。

## 要点

### 问题 1：空可变参

```c
#define LOG(fmt, ...) printf(fmt, ##__VA_ARGS__)
LOG("started\n");   /* GNU ## 去掉多余逗号 */
```

### 问题 2：宏作为单语句

```c
#define LOG(fmt, ...) do {                          \
    printf("[%s:%d] " fmt "\n",                     \
           __FILE__, __LINE__, ##__VA_ARGS__);       \
} while (0)
```

### 问题 3：级别 + 函数名

```c
#define LOG_LEVEL 2
#define LOG(lvl, fmt, ...) do {                     \
    if ((lvl) <= LOG_LEVEL)                          \
        fprintf(stderr, "%s: " fmt, __func__, ##__VA_ARGS__); \
} while (0)
```

| 改进 | 目的 |
|------|------|
| `do { } while (0)` | 安全用于 `if/else` 后 |
| `##__VA_ARGS__` | `LOG("ok")` 无参合法 |
| 底层 `format` 函数 | 编译期格式检查（**demo06**） |

```c
/* 语句表达式版：宏返回值（少用） */
#define max3(a,b,c) ({ int _m = max(a,b); max(_m, c); })
```

## 代码自测

**题目 1：** 以下调试宏如何用 do-while(0) 和 ##__VA_ARGS__ 实现？为什么用 do-while(0)？
```c
#define DEBUG_PRINT(fmt, ...) \
    do { \
        if (debug_enabled) \
            fprintf(stderr, "[%s:%d] " fmt, __FILE__, __LINE__, ##__VA_ARGS__); \
    } while (0)

// 调用
if (x > 0)
    DEBUG_PRINT("x=%d\n", x);
else
    DEBUG_PRINT("x<=0\n");
```
<details>
<summary>参考答案</summary>

`do { ... } while (0)` 的作用：让宏展开后成为一个完整的语句，可以安全地用在 if/else 等控制流中。

不用 do-while(0) 的问题：
```c
// 如果宏定义为：
#define DEBUG_PRINT(fmt, ...) if (debug_enabled) fprintf(stderr, ...)
// 调用
if (x > 0)
    DEBUG_PRINT("x=%d", x);
else
    do_something();
// 展开后：
if (x > 0)
    if (debug_enabled) fprintf(...);
else  // 这个 else 绑定到内层 if！
    do_something();
```

do-while(0) 解决：展开后是一个语句块，else 正确绑定到外层 if。

`##__VA_ARGS__`：GCC 扩展，当没有可变参数时去掉前面的逗号。`DEBUG_PRINT("error\n")` 不传额外参数时不会出现 `fmt, ` 后面多余逗号。

这是内核 `pr_debug`/`dev_dbg` 等宏的标准模式。

</details>
