# 6.12.4 内核中的可变参数宏

## 本节讲什么

内核 **`printk`**、**`pr_info`/`dev_err`** 等均 **可变参宏 + format 属性**。

## 要点

```c
#define pr_info(fmt, ...) \
    printk(KERN_INFO fmt, ##__VA_ARGS__)
```

| 宏族 | 用途 |
|------|------|
| `pr_*` | 内核通用 log |
| `dev_*` | 带 device 前缀 |

- DPDK **`RTE_LOG`** 编译期 level + **`##__VA_ARGS__`**

## 代码自测

**题目 1：** 内核 `pr_err` 宏最终如何把 `printk` 的级别和格式串拼接？以下展开结果是什么？
```c
#define pr_err(fmt, ...) \
    printk(KERN_ERR pr_fmt(fmt), ##__VA_ARGS__)
#define pr_fmt(fmt) KBUILD_MODNAME ": " fmt

pr_err("timeout: %d\n", rc);
// 展开为？
```

<details>
<summary>参考答案</summary>

展开过程：(1) `pr_err("timeout: %d\n", rc)` → `printk(KERN_ERR pr_fmt("timeout: %d\n"), rc)`；(2) `pr_fmt("timeout: %d\n")` → `KBUILD_MODNAME ": " "timeout: %d\n"`，C 字符串字面量相邻自动拼接；(3) 最终：`printk(KERN_ERR KBUILD_MODNAME ": " "timeout: %d\n", rc)`。`KERN_ERR` 是 `"<3>"`（日志级别字符串），也靠字符串拼接。`##__VA_ARGS__` 确保无额外参数时也能编译。模块名通过 `KBUILD_MODNAME` 宏自动注入。

</details>
