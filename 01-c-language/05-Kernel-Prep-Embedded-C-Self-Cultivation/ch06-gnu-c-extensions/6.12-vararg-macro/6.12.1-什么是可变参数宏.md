# 6.12.1 什么是可变参数宏

## 本节讲什么

**可变参数宏** 在预处理阶段 **文本替换** 为函数调用。C99 引入；GNU **`##__VA_ARGS__`** 改善空参。

## 要点

```c
#define debug(fmt, ...) printf("[dbg] " fmt "\n", __VA_ARGS__)
```

| 令牌 | 含义 |
|------|------|
| `__VA_ARGS__` | `...` 对应实参 |
| `__VA_OPT__(x)` | C20 可选片段 |

## 代码自测

**题目 1：** 以下可变参数宏在调用 `LOG("hello")`（无额外参数）时会发生什么？如何修复？
```c
#define LOG(fmt, ...) printf(fmt, __VA_ARGS__)
LOG("hello");          // (A) 编译错误？
LOG("val=%d\n", 42);  // (B) 正常？
```

<details>
<summary>参考答案</summary>

(A) 编译错误——`__VA_ARGS__` 为空时，展开为 `printf("hello", )`，末尾多一个逗号。修复：GNU 扩展用 `##__VA_ARGS__`：`#define LOG(fmt, ...) printf(fmt, ##__VA_ARGS__)`。`##` 在 `__VA_ARGS__` 为空时删除前面的逗号。C99 不支持这个语法，C20 才标准化 `__VA_OPT__`。(B) 正常——展开为 `printf("val=%d\n", 42)`。

</details>
