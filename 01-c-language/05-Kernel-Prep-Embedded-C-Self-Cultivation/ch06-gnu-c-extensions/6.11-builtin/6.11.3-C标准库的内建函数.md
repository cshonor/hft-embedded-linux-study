# 6.11.3 C标准库的内建函数

## 本节讲什么

许多 **libc 函数** 被 GCC **当作 builtin 优化**：`strlen`、`memcpy` 等可 **编译期折叠**。

## 要点

```c
size_t n = strlen("hello");  /* 编译期 → 5 */
```

```bash
gcc -O2 -S strlen_demo.c
```

- 内核 freestanding 不用 libc builtin

## 代码自测

**题目 1：** `memcpy` 既可以用库函数版本也可以用 `__builtin_memcpy`，编译器如何选择？以下代码在 `-O2` 下会怎样？
```c
char dst[8], src[8] = "hello";
__builtin_memcpy(dst, src, 5);
```

<details>
<summary>参考答案</summary>

编译器优先用内建版本。`-O2` 下，因为大小是编译期常量 5（小于阈值），编译器可能直接展开为几条 `mov` 指令，不调用 `memcpy` 函数。如果大小是运行时变量或很大，则回退为调用库函数 `memcpy`。`__builtin_memcpy` 和 `memcpy` 在语义上相同，但内建版本有编译期优化机会。内核中 `memcpy` 通常被 `#define` 为 `__builtin_memcpy` 以获得最佳代码。

</details>
