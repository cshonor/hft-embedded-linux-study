# 6.11.1 什么是内建函数

## 本节讲什么

Builtins 是 GCC/Clang **内建接口**：语法像函数调用，编译期特殊处理。

## 要点

```c
int x = __builtin_popcount(0xffu);
__builtin_trap();
```

```bash
gcc -E -dM - | grep __GNUC__
```

## 代码自测

**题目 1：** `__builtin_*` 函数是真正的函数吗？以下代码编译后 `__builtin_trap()` 会生成什么？
```c
void fatal(void) {
    __builtin_trap();  // 生成什么指令？
}
```

<details>
<summary>参考答案</summary>

不是真正的函数——是编译器内置的伪函数，直接映射到目标指令。`__builtin_trap()` 在 x86 生成 `ud2` 指令（未定义指令，触发非法指令异常），在 ARM 生成 `BKPT` 或 `UDF`。其他例子：`__builtin_memcpy` 可能直接展开为 `rep movsb` 或 `memcpy` 调用（取决于大小和优化级别）。内建函数在编译期处理，不产生符号表条目，无链接依赖。

</details>
