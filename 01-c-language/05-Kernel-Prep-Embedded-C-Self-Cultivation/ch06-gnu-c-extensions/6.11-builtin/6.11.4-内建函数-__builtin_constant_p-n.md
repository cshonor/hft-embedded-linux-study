# 6.11.4 内建函数：__builtin_constant_p(n)

## 本节讲什么

**`__builtin_constant_p(expr)`** 编译期判断 **expr 是否为常量**；为真时 **丢弃假分支**。

## 要点

```c
#define SET_BIT(x, n) do {                              \
    if (__builtin_constant_p(n))                        \
        (x) |= (1UL << (n));                            \
    else                                                \
        (x) |= ((typeof(x))1 << (n));                   \
} while (0)
```

| 返回值 | 含义 |
|--------|------|
| 1 | 编译期已知 |
| 0 | 运行时变量 |

## 代码自测

**题目 1：** `__builtin_constant_p(5)` 和 `__builtin_constant_p(n)`（n 是运行时变量）分别返回什么？以下宏如何利用这个特性？
```c
#define mymemset(s, c, n) do { \
    if (__builtin_constant_p(n) && n <= 16) { \
        /* 展开为赋值 */ \
    } else { \
        memset(s, c, n); \
    } \
} while (0)
```

<details>
<summary>参考答案</summary>

`__builtin_constant_p(5)` 返回 1（编译期已知），`__builtin_constant_p(n)` 返回 0（运行时变量）。宏的优化逻辑：如果 `n` 是编译期常量且 <= 16，展开为直接赋值（无函数调用开销）；否则调用 `memset`。这是内核 `memset`/`memcpy` 等函数的常见优化模式——常量小尺寸内联展开，大尺寸或运行时尺寸调库函数。`__builtin_constant_p` 只在优化级别 `-O1` 以上才可靠工作。

</details>
