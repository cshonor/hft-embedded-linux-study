# 8.6 实例：目录列表

## 本节讲什么

遍历目录、打印文件名，综合运用 **`open`/`read`/`stat`** 与第 6 章 **struct**。并覆盖 **stat 元数据**、**目录与权限** 等 UNIX 文件模型核心。

## 要点

### stat / fstat

```c
#include <sys/stat.h>
int stat(const char *path, struct stat *st);
int fstat(int fd, struct stat *st);
```

**`struct stat`** 常见字段：

| 字段 | 含义 |
|------|------|
| `st_size` | 字节大小 |
| `st_mode` | 类型 + 权限（`S_ISREG`/`S_ISDIR`/`S_ISCHR`…） |
| `st_mtime` | 修改时间 |
| `st_ino` | inode 号 |

- 配合第 6 章：**对齐、字段类型** 随 POSIX 平台

### 目录操作（用户 8.7）

| 调用 | 作用 |
|------|------|
| `mkdir(path, mode)` | 创建目录 |
| `rmdir(path)` | 删除空目录 |
| `chdir(path)` | 切换进程**当前工作目录** |
| `getcwd(buf, size)` | 读当前路径 |

- 配置加载、相对路径解析依赖 **cwd**

### 权限 chmod（用户 8.6）

```c
chmod(path, mode_t mode);
```

- 修改 permission bits；与 `open` 的 `mode` + **umask** 配合

### 目录读取

- 经典：读 **`read`** 目录 fd（老式）或 **`opendir`/`readdir`**（POSIX，K&R 后扩展）
- K&R **`fstat`** + 目录项结构解析 `ls` 简化版

## 示例逻辑（ls 思想）

```
对每个目录项：
  stat → 打印 mode、大小、名字
  目录则递归或标记
```

## 考点

- **硬链接** 同 inode 多名字（8.3 `link`）
- **设备文件** `S_ISCHR` / `S_ISBLK` —— 嵌入式访问驱动

## 与后续衔接

自制 OS 用户态 `ls`、`pwd`；Linux **`/proc`**、 **`/sys`** 遍历；UEFI 无 POSIX 目录 API，但「元数据 + 枚举」思维相同。

## 常见陷阱

1. **readdir 返回的指针在下次调用时被覆盖**：`struct dirent *d; d = readdir(dir); printf("%s", d->d_name); d = readdir(dir); printf("%s", d->d_name);` ——第二次 readdir 可能覆盖了第一次返回的 dirent 结构（静态/内部缓冲）。如果需要保存文件名，必须 `strdup(d->d_name)` 复制。glibc 的 readdir 用线程局部存储缓解了这个问题，但可移植代码仍应假设返回值在下一次调用后失效。

2. **遍历目录时修改目录内容**：在 `readdir` 循环中创建/删除文件，行为**未定义**——readdir 的内部状态可能被破坏，可能跳过文件、重复文件或崩溃。安全做法：先把文件名列表全部读入数组（strdup 保存），关闭目录后再操作文件。

3. **stat vs lstat 搞混——符号链接处理不同**：`stat(path, &st)` 跟随符号链接获取**目标文件**的元数据；`lstat(path, &st)` 不跟随，获取**符号链接本身**的元数据。`ls -l` 用 lstat 显示符号链接信息，`ls -L` 用 stat 跟随。目录遍历如果用 stat 遇到指向父目录的循环符号链接，会无限递归——必须用 lstat 检测 `S_ISLNK`。

## 自测题

**1. 选择**：`stat("link.txt", &st)` 中 `link.txt` 是一个指向 `real.txt` 的符号链接，`st.st_size` 返回的是谁的文件大小？
- A. 符号链接文件本身的大小
- B. real.txt 的大小
- C. 0
- D. 链接路径字符串的长度

<details><summary>答案</summary>
B。`stat` **跟随**符号链接获取目标文件的元数据，所以返回 real.txt 的大小。如果要获取符号链接本身的信息（如链接路径长度），用 `lstat`——它不跟随链接。`lstat` 返回的 `st_mode` 中 `S_ISLNK` 为真，`stat` 返回的不会。目录遍历防循环符号链接必须用 `lstat` 检查 `S_ISLNK`。
</details>

**2. 判断**：readdir 保证按文件名字母顺序返回目录项。

<details><summary>答案</summary>
错。readdir 返回顺序**未定义**——取决于文件系统内部结构（ext4 按哈希，FAT 按创建顺序，tmpfs 按插入顺序）。如果需要排序，必须先把所有文件名读入数组再 `qsort`。`ls` 默认排序就是在用户态做的。`scandir` 函数封装了"读取+排序"流程，但底层仍是 readdir。
</details>

**3. 踩坑**：以下递归遍历目录的代码在遇到符号链接时无限循环，为什么？
```c
void walk(const char *path) {
    DIR *d = opendir(path);
    while ((de = readdir(d))) {
        stat(de->d_name, &st);
        if (S_ISDIR(st.st_mode))
            walk(de->d_name);
    }
    closedir(d);
}
```

<details><summary>答案</summary>
三个问题：1) `stat` 跟随符号链接——如果目录中有一个符号链接指向上级目录，stat 返回目录类型，递归进入 → 无限循环。修复：用 `lstat` 并检查 `S_ISLNK` 跳过符号链接。2) 没有跳过 `.` 和 `..`——`readdir` 返回 `.`（当前目录）和 `..`（上级目录），递归进入 `..` 会无限循环。修复：`if (strcmp(de->d_name, ".") == 0 || strcmp(de->d_name, "..") == 0) continue;`。3) `de->d_name` 只是文件名，不是完整路径——递归时需拼接 `path + "/" + de->d_name`。
</details>

**4. 应用**：用 opendir/readdir/stat 写一个 `list_dir` 函数，打印目录下每个文件的名字和大小（字节），按大小降序排列。

<details><summary>答案</summary>
```c
#include <dirent.h>
#include <sys/stat.h>
#include <string.h>
#include <stdlib.h>
#include <stdio.h>

typedef struct { char name[256]; off_t size; } Entry;

int cmp_size(const void *a, const void *b) {
    return ((Entry*)b)->size - ((Entry*)a)->size;  /* 降序 */
}

void list_dir(const char *path) {
    DIR *d = opendir(path);
    if (!d) { perror("opendir"); return; }

    Entry entries[1024];
    int n = 0;
    struct dirent *de;
    while ((de = readdir(d)) && n < 1024) {
        if (de->d_name[0] == '.') continue;  /* 跳过隐藏文件 */
        char full[512];
        snprintf(full, sizeof full, "%s/%s", path, de->d_name);
        struct stat st;
        if (lstat(full, &st) == 0) {
            strncpy(entries[n].name, de->d_name, 255);
            entries[n].name[255] = '\0';
            entries[n].size = st.st_size;
            n++;
        }
    }
    closedir(d);

    qsort(entries, n, sizeof(Entry), cmp_size);
    for (int i = 0; i < n; i++)
        printf("%10ld  %s\n", entries[i].size, entries[i].name);
}
```
关键：路径拼接（path + "/" + name）、lstat 防符号链接、qsort 排序、opendir 失败检查。这是 `ls -lS` 的核心逻辑。
</details>
