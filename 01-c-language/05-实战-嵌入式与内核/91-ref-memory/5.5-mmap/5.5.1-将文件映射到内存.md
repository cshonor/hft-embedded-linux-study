# 5.5.1 将文件映射到内存

## 本节讲什么

**文件 mmap** 把磁盘内容映射为虚拟页：读时缺页从页缓存载入，写 `MAP_SHARED` 回刷文件。适合大文件随机访问、共享只读配置，避免 `read/write` 双拷贝。

## 要点

```c
int fd = open("data.bin", O_RDONLY);
void *p = mmap(NULL, st.st_size, PROT_READ, MAP_PRIVATE, fd, 0);
/* 访问 p[i] 等价读文件 offset i */
munmap(p, st.st_size);
close(fd);
```

```bash
gcc -o fmmap fmmap.c
strace -e mmap,openat ./fmmap 2>&1
cat /proc/self/maps | grep data.bin
```

| 标志 | 行为 |
|------|------|
| `MAP_PRIVATE` | CoW，不写回文件 |
| `MAP_SHARED` | 修改可见于其他映射/文件 |

- **内核** `filp->f_op->mmap` 驱动实现；如 **/dev/mem** 需 root
- **DPDK**：配置文件、 hugepage 文件在 `/dev/hugepages`

## 代码自测

**题目 1：** mmap 将文件映射到内存后，以下代码的行为是什么？和 read 有什么区别？
```c
int fd = open("data.txt", O_RDWR);
char *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
p[0] = 'H';  // 修改映射区
munmap(p, 4096);
close(fd);
```
<details>
<summary>参考答案</summary>

mmap 将文件 4096 字节映射到进程虚拟地址空间，`p[0] = 'H'` 直接修改内存即修改文件内容（MAP_SHARED 模式下写入同步到文件）。

与 read 的区别：
| | mmap | read |
|---|---|---|
| 拷贝 | 1次（内核页缓存→用户映射） | 2次（磁盘→内核→用户） |
| 访问方式 | 指针直接访问 | 需 buffer + read 调用 |
| 随机访问 | 高效（指针偏移） | 需 lseek + read |
| 适用场景 | 大文件随机访问 | 顺序读、小文件 |

MAP_SHARED：修改同步到文件；MAP_PRIVATE：写时复制，不影响原文件。

munmap 后修改被写回文件（若 MAP_SHARED）。

</details>
