# 8.1.11 字符数组的初始化

## 本节讲什么

**字符数组** vs **字符串指针数组**——报文缓冲与协议常量表的两种典型写法。这一节讲清"可写缓冲"和"只读常量表"的存储差异。

## 要点

### 可读写二维字符数组

```c
char pkt_buf[16][64];   /* 16×64 连续可写缓冲 */
strncpy(pkt_buf[0], data, 63);
pkt_buf[0][63] = '\0';
```

- 每行 64 字节连续可写，适合批量报文缓冲
- 二进制报文无 `\0` 时**勿用 strlen**——用显式长度
- 内存连续，cache 友好

### 字符串指针数组（只读表）

```c
const char *pkt_type_name[] = {
    "HEARTBEAT", "QUOTE", "ORDER", "CANCEL"
};
```

- 各字符串在 **`.rodata`**，修改 → 段错误
- 指针数组本身在栈/全局，存的是各字符串地址
- 适合错误码、opcode 名称表

### 字符数组 vs 字符指针（单串）

```c
char s1[] = "writable";    /* 栈数组，字面量拷贝进来，可改 */
char *s2 = "rodata";      /* 指向 .rodata，只读，改崩 */
const char *s3 = "rodata"; /* 同上，但 const 标记意图 */
```

| 形式 | 存储 | 可改 | 用途 |
|------|------|------|------|
| `char s[] = "abc"` | 栈/全局（拷贝） | 是 | 可改缓冲 |
| `char *s = "abc"` | 指向 `.rodata` | 否（改崩） | 只读（不推荐） |
| `const char *s = "abc"` | 指向 `.rodata` | 否（编译拦） | 只读（推荐） |

## 底层映射

### `.rodata` 字符串字面量

```c
const char *names[] = {"HEARTBEAT", "QUOTE"};
```

```
.rodata 段:
  "HEARTBEAT\0"   ← names[0] 指向这里
  "QUOTE\0"       ← names[1] 指向这里

names 数组（栈/全局）:
  [0] → 0x401234  (指向 .rodata)
  [1] → 0x40123e
```

`names` 是指针数组，存的是地址；字符串本身在只读段。改 `names[0][0] = 'h'` 会尝试写 `.rodata` → `SIGSEGV`。

### 二维字符数组的连续存储

```c
char buf[3][16] = {"abc", "defgh", "x"};
```

```
地址:     0    1    2 ... 15    16   17 ...
内容:    'a' 'b' 'c' \0 ...  'd'  'e'  'f' ...
         ↑ buf[0]            ↑ buf[1]
```

每行 16 字节连续，`buf[i]` 跳 `16*sizeof(char)`。整体在栈或全局，可改。

## HFT / DPDK

| 场景 | 写法 |
|------|------|
| 报文缓冲池 | `char buf[16][2048]` 二维数组 |
| opcode 名称表 | `const char *names[] = {...}` |
| 协议字面量 | `const char *proto = "FIX.4.2"` |
| 错误码 | `const char *err_str[] = {"OK", "TIMEOUT", "FULL"}` |

### 工程纪律

- 二进制报文用显式长度，不靠 `\0`（**ch09**）
- 只读常量表用 `const char *[]`，编译期拦误改
- 可写缓冲用 `char buf[]`，不用 `char *` 指向字面量
- `char *s = "abc"` 已 deprecated，用 `const char *`

## 常见误区

| 误区 | 事实 |
|------|------|
| "`char *s = "abc"; s[0]='X';` 没事" | 改 `.rodata`，`SIGSEGV` |
| "二进制报文能用 strlen" | 无 `\0` 时不行，用显式长度 |
| "指针数组里的串能改" | 在 `.rodata`，改崩 |
| "`char s[]="abc"` 和 `char *s="abc"` 一样" | 前者可改拷贝，后者只读指向 |

## 实操

```bash
# 看字符串字面量在 .rodata
cat > t.c << 'EOF'
const char *s = "FIX.4.2";
int main(void){return 0;}
EOF
gcc t.c -o t && objdump -s -j .rodata ./t
# 故意改只读字面量
cat > t.c << 'EOF'
int main(void){char *s="abc";s[0]='X';return 0;}
EOF
gcc t.c -o t && ./t; echo $?    # Segmentation fault (139)
# 指针数组 vs 二维数组的地址布局
cat > t.c << 'EOF'
#include <stdio.h>
int main(void){
  char buf[3][16]={"a","bb","ccc"};
  const char *p[]={"a","bb","ccc"};
  printf("buf[0]=%p buf[1]=%p (contiguous)\n",(void*)buf[0],(void*)buf[1]);
  printf("p[0]=%p p[1]=%p (rodata, may be far)\n",(void*)p[0],(void*)p[1]);
  return 0;
}
EOF
gcc t.c -o t && ./t
```

## 代码自测

**题目 1：** 以下两种初始化有什么区别？
```c
char a[] = "hello";
char b[] = {'h', 'e', 'l', 'l', 'o'};
```

<details>
<summary>参考答案</summary>

a 有 6 个元素（h, e, l, l, o, \0）——字符串字面量自动添加终止符。b 有 5 个元素（h, e, l, l, o）——没有终止符。sizeof(a) = 6, sizeof(b) = 5。用 b 作为字符串传递给 strlen/printf 会越界读取。

</details>
