# 8.1.15 数组类型表达式清单

## 本节讲什么

退化规则（C11 6.3.2.1p3）的主语是 **an expression that has type "array of type"**——**类型为数组类型的表达式**。本节把"哪些表达式是数组类型表达式"列成清单：

- **三类"原生"形态**：数组名、字符串字面量、复合字面量
- **三类容易漏掉的派生形态**：结构体数组成员 `s.arr`、二维数组的行 `m[0]`、解引用数组指针 `*p`
- **三类典型反例**：指针变量、函数形参、`malloc` 返回的指针

附带精确化一个流传很广的说法：**函数形参 `int a[]` 的调整，只发生在最外层**——`int a[][5]` 调整后是 `int (*)[5]`，**不是** `int *`。

配套：[8.1.1 数组名与退化](./8.1.1-数组名.md)（退化规则与 4 条例外的完整辨析）、[8.1.13 数组指针的步长](./8.1.13-数组指针的步长.md)、[8.1.14 `a[0]` 不是指针](./8.1.14-a0不是指针.md)。

## 要点

### ✅ 原生形态：写出来就自带数组类型（三类）

| # | 表达式 | 类型 | 退化后 | `sizeof`（不退化） |
|---|--------|------|--------|-------------------|
| 1 | 数组名 `a`（`int a[5]`） | `int[5]` | `int *` | 20 |
| 2 | 字符串字面量 `"abc"` | `char[4]` | `char *` | 4 |
| 3 | 复合字面量 `(int[]){1,2,3}` | `int[3]` | `int *` | 12 |

这三类是**语法层面直接产生数组类型**的写法，也是教材里最常列的三类。

### ⚠️ 但"只有这三类"是不准确的：派生形态同样是数组类型表达式

| # | 表达式 | 类型 | 实测 `sizeof` | 同样命中退化/例外 |
|---|--------|------|--------------|------------------|
| 4 | 结构体数组成员 `s.arr` | `int[5]` | **20** | ✅ |
| 5 | 二维数组的行 `m[0]`（`int m[3][5]`） | `int[5]` | **20** | ✅ |
| 6 | 解引用数组指针 `*p`（`int (*p)[5]`） | `int[5]` | **20** | ✅ |

实测（clang 23.1.0，`_Generic` 探针给出的都是**退化后**类型，`sizeof` 给出的是**不退化**的大小）：

```
[三类] 数组名 a          sizeof=20 type=int *
[三类] 字面量 "abc"      sizeof=4  type=char *
[三类] &"abc"            sizeof=8  type=char (*)[4]
[三类] (int[]){1,2,3}    sizeof=12 type=int *
[三类] &(int[]){1,2,3}   sizeof=8  type=int (*)[3]

[补] s.arr（数组成员）    sizeof=20 type=int *
[补] m[0]（二维的行）     sizeof=20 type=int *
[补] *p（解引用数组指针） sizeof=20 type=int *
```

后三行是关键反证：它们既不是数组名、也不是字面量、也不是复合字面量，但 `sizeof` 都是 20（说明**在 `sizeof` 上下文没退化**）、`_Generic` 都是 `int *`（说明**在一般上下文退化**）——完全符合 6.3.2.1p3 的行为，**它们就是数组类型表达式**。

> **准确表述**：数组名/字符串字面量/复合字面量是**语法上直接写出来的三类**；但标准的判定标准是"**表达式的类型是不是数组类型**"，`s.arr`、`m[0]`、`*p` 同样满足。所以清单该是"3 类原生 + 3 类派生"，或干脆说"**看类型，不看写法**"。

### ❌ 典型反例：看着像数组，其实是指针

| 表达式 | 真实类型 | 为什么不是 |
|--------|---------|-----------|
| `int *p;` 里的 `p` | `int *` | 声明就是指针，永远是指针 |
| `void f(int a[])` 里的 `a` | `int *`（**参数调整**） | §6.7.6.3p7：形参声明为数组类型被调整为指针 |
| `malloc(n)` 的返回值 | `void *` | 堆块不是数组对象，`sizeof(p)` 恒为 8 |

## 逐个拆解

### 1. 数组名表达式

```c
int a[5];
a;              /* 类型 int[5] —— 数组类型表达式 */
sizeof(a);      /* 20，例外 1：不退化 */
&a;             /* int (*)[5]，例外 3：不退化 */
a + 1;          /* 退化 → int *，步长 4 */
```

详见 [8.1.1](./8.1.1-数组名.md)。

### 2. 字符串字面量 `"abc"`

```c
"abc";              /* 类型 char[4]（末尾自带 '\0'） */
char *s = "abc";    /* 退化：char[4] → char *        */
sizeof("abc");      /* 4 —— 例外 1，不退化           */
&"abc";             /* char (*)[4] —— 例外 3，不退化 */
```

三个要点：

| 要点 | 说明 |
|------|------|
| 长度含 `\0` | `"abc"` 是 `char[4]` 不是 `char[3]`，`sizeof` = 4 |
| **类型是 `char[4]`，不是 `const char[4]`** | 这是 C 与 C++ 的关键差别——见下 |
| 修改是 UB | C11 6.4.5p7：修改字符串字面量的行为未定义（通常落在 `.rodata`，写则 SIGSEGV） |

> ⚠️ **C 里字符串字面量的类型是 `char[N]`（非 const），但修改是 UB。** 这两句不矛盾，也正因为不加 `const`，下面这行在 C 里**毫无警告**：
> ```c
> char *s = "abc";   /* C：合法，无警告；但 s[0] = 'x' 是 UB */
> ```
> 实测对比（同一行代码，两种语言）：
> ```
> $ clang  -std=c11  -Wall -c lit.c     # 无输出，零警告
> $ clang++ -std=c++17 -Wall -c lit.c
> warning: ISO C++11 does not allow conversion from string literal to 'char *' [-Wwritable-strings]
> ```
> 工程上仍应写 `const char *s = "abc";`——把 UB 挡在编译期。详见 [8.1.11 字符数组的初始化](./8.1.11-字符数组的初始化.md)。

### 3. 复合字面量（C99+）

```c
(int[]){1, 2, 3};            /* 类型 int[3] —— 匿名数组对象 */
sizeof((int[]){1, 2, 3});    /* 12 —— 例外 1 */
&((int[]){1, 2, 3});         /* int (*)[3] —— 例外 3 */
```

| 性质 | 说明 |
|------|------|
| 是**左值** | 可取地址：`&(int[]){1,2,3}` 合法 |
| 函数内 → **自动存储期** | 块结束时销毁（栈上） |
| 文件作用域 → **静态存储期** | 生命周期贯穿全程（C11 6.5.2.5p5）——常被漏掉 |
| 可加限定 | `(const int[]){1,2}` 落只读段 |

> ⚠️ 函数内**不要返回指向复合字面量的指针**——它随块销毁，返回即悬垂（同 `ch06 6.5` 野指针）。

### ★ 函数参数：调整只发生在最外层

C11 **6.7.6.3p7**（参数类型调整）：形参声明为"数组类型"时，被调整为"指向元素类型的指针"。这条只剥**最外层**那一维：

```c
void f1(int a[]);     /* → int *a        ，sizeof(a) = 8 */
void f2(int a[5]);    /* → int *a        ，5 被完全忽略 */
void f3(int a[][5]);  /* → int (*a)[5]   ，行长 5 保留！ */
void f4(int *a);      /* 本来就等价      */
```

实测：

```
[参数] int a[]    sizeof=8 type=int *
[参数] int a[5]   sizeof=8 type=int *
[参数] int a[][5] sizeof=8 type=int (*)[5]     ← 不是 int *，行长信息还在
[参数] int *a     sizeof=8 type=int *
```

而且 clang 会主动提示你踩了这个坑：

```
warning: sizeof on array function parameter will return size of 'int *'
         instead of 'int[]' [-Wsizeof-array-argument]
```

> **所以"形参写 `int a[]` 就是语法糖、本质 `int *a`"这个说法只对一维成立。** 二维参数是 `int (*)[N]`——它保留了行长，正是 HFT 里传定长二维表的正确写法（[8.1.7](./8.1.7-声明数组参数.md)、[8.2](./../8.2-multidimensional-arrays/8.2-多维数组.md)）。
>
> 顺带：C99 的 `void f(int a[static 5])` 调整后仍是 `int *`，但 `static` 向编译器保证"至少有 5 个元素且非空"，可做预取优化。

## 标准依据

| 条款 | 内容 | 对本节的意义 |
|------|------|-------------|
| C11 **6.3.2.1p3** | 数组类型表达式 → 首元素指针，非左值；`sizeof`/`_Alignof`/一元 `&`/字面量初始化数组除外 | 退化规则的**判定标准是类型，不是写法** |
| C11 **6.7.6.3p7** | 形参声明为数组类型 → 调整为指向元素类型的指针 | `int a[]` ≡ `int *a`；但 `int a[][5]` → `int (*)[5]` |
| C11 **6.4.5p5-7** | 字符串字面量的类型是 `char[N]`；修改它 → **UB** | 类型是 `char[]` 不是 `const char[]` |
| C11 **6.5.2.5** | 复合字面量：类型、存储期（p5）、左值性 | `(int[]){1,2,3}` 的规则 |
| C11 **6.5.6p2** | 指针算术要求完整对象类型 | 退化后才能做 `+1` |

## 底层映射

### 三类的段归属

| 表达式 | 典型落点 | 说明 |
|--------|---------|------|
| 全局数组名 | `.data` / `.bss` | 见 [8.1.8](./8.1.8-初始化.md) |
| 局部数组名 | 栈 | |
| 字符串字面量 | `.rodata`（Mach-O `__TEXT,__cstring`） | 写则 SIGSEGV |
| 复合字面量（函数内） | 栈 | 块结束销毁 |
| 复合字面量（文件作用域） | `.data` / `.rodata` | 静态存储期 |

### 汇编：复合字面量就是个匿名栈对象

```c
int *p = (int[]){1, 2, 3};
```

arm64 `-O2` 下通常是三条 `mov` 往栈上写立即数再取地址——和 `int tmp[3] = {1,2,3}; int *p = tmp;` 生成的代码**没有区别**。复合字面量只是"没有名字的数组变量"。

## 实测

**完整输出**（clang 23.1.0，`-std=c11 -Wno-sizeof-array-argument`，arm64 / LP64）：

```
[三类] 数组名 a          sizeof=20 type=int *
[三类] 字面量 "abc"      sizeof=4  type=char *
[三类] &"abc"            sizeof=8  type=char (*)[4]
[三类] (int[]){1,2,3}    sizeof=12 type=int *
[三类] &(int[]){1,2,3}   sizeof=8  type=int (*)[3]
[补] s.arr（数组成员）    sizeof=20 type=int *
[补] m[0]（二维的行）     sizeof=20 type=int *
[补] *p（解引用数组指针） sizeof=20 type=int *
[参数] int a[]    sizeof=8 type=int *
[参数] int a[5]   sizeof=8 type=int *
[参数] int a[][5] sizeof=8 type=int (*)[5]
[参数] int *a     sizeof=8 type=int *
```

**`-Wsizeof-array-argument` 原文**（一维参数的铁证）：

```
warning: sizeof on array function parameter will return size of 'int *'
         instead of 'int[]' [-Wsizeof-array-argument]
```

**C vs C++ 字符串字面量**（同一行 `char *s = "abc";`）：

```
$ clang   -std=c11   -Wall -c lit.c     # 零警告
$ clang++ -std=c++17 -Wall -c lit.c
warning: ISO C++11 does not allow conversion from string literal to 'char *' [-Wwritable-strings]
```

## HFT / DPDK

| 场景 | 写法 | 要点 |
|------|------|------|
| 只读查表 | `const char *s = "..."` / `static const int map[]` | 别写 `char *` 指向字面量，把 UB 挡在编译期 |
| 临时初始化 | `(struct cfg[]){...}` 传参 | 复合字面量省一个命名变量；注意块作用域生命周期 |
| 二维表传参 | `void f(int (*tbl)[COLS], size_t rows)` | 或 `int tbl[][COLS]`，**行长必须保留** |
| 堆"数组" | `malloc(n * sizeof(int))` | 不是数组对象；`sizeof(p)` 恒 8，长度必须自己存 |
| 报文模板 | `static const uint8_t tpl[] = {...}` | 落只读段，不占可写页 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "数组类型表达式只有三类" | 三类是**语法上直接写出的**；`s.arr`、`m[0]`、`*p` 同样是（实测 `sizeof` 均 20、均退化） |
| "字符串字面量类型是 `const char[4]`" | C 里是 `char[4]`；`const` 是 C++ 的规则。但**修改仍是 UB** |
| "`char *s = "abc"` 有警告，说明不安全" | C 里零警告——所以要自己写 `const char *` |
| "形参 `int a[]` 就是 `int *a`（通用）" | 只对一维；`int a[][5]` 调整后是 `int (*)[5]`，行长保留 |
| "复合字面量都在栈上" | 函数内是自动存储期；**文件作用域是静态存储期** |
| "`malloc` 出来的是数组" | 是指针，不是数组对象；没有 `sizeof` 长度信息 |
| "复合字面量不是左值" | 是左值，可以 `&(int[]){1,2}` |
| "返回复合字面量的地址没问题" | 函数内块作用域，返回即悬垂 |

## 实操

```bash
# 1. 三类原生 + 三类派生 + 参数调整，一次看清
cat > t.c << 'EOF'
#include <stdio.h>
#define TY(x) _Generic((x), int *: "int *", int (*)[5]: "int (*)[5]", \
                       char *: "char *", char (*)[4]: "char (*)[4]", default: "?")
struct S { int arr[5]; };
void f1(int a[])   { printf("int a[]    sizeof=%zu type=%s\n", sizeof a, TY(a)); }
void f3(int a[][5]){ printf("int a[][5] sizeof=%zu type=%s\n", sizeof a, TY(a)); }
int main(void) {
    int a[5] = {0}; int m[3][5] = {0}; struct S s = {0}; int (*p)[5] = &a;
    printf("a      sizeof=%zu type=%s\n", sizeof a, TY(a));
    printf("\"abc\"  sizeof=%zu type=%s\n", sizeof "abc", TY("abc"));
    printf("&\"abc\" sizeof=%zu type=%s\n", sizeof &"abc", TY(&"abc"));
    printf("s.arr  sizeof=%zu type=%s\n", sizeof s.arr, TY(s.arr));
    printf("m[0]   sizeof=%zu type=%s\n", sizeof m[0], TY(m[0]));
    printf("*p     sizeof=%zu type=%s\n", sizeof *p, TY(*p));
    f1(a); f3(m);
    return 0;
}
EOF
clang -std=c11 -Wno-sizeof-array-argument t.c -o t && ./t

# 2. 打开被关掉的告警看参数调整
clang -std=c11 -Wall -c t.c -o /dev/null      # -Wsizeof-array-argument

# 3. C vs C++ 字符串字面量类型
printf 'int main(void){char *s = "abc"; (void)s; return 0;}\n' > lit.c
clang   -std=c11   -Wall -c lit.c -o /dev/null   # 零警告
clang++ -std=c++17 -Wall -c lit.c -o /dev/null   # -Wwritable-strings
```

## 代码自测

**题目 1：** 函数参数 `void test(int arr[])` 中，表达式 `arr` 是什么类型？

A. `int[]` 数组类型　　B. `int *` 指针类型　　C. `int (*)[]` 数组指针

<details>
<summary>参考答案</summary>

**B（`int *`）。** C11 §6.7.6.3p7：形参声明为数组类型时**调整为指向元素类型的指针**，所以 `int arr[]` 从声明那一刻起就等于 `int *arr`，`[]` 里的数字（如果有）也被完全忽略。

实测：`sizeof(arr)` = 8、`_Generic(arr)` → `int *`；clang 还会给 `warning: sizeof on array function parameter will return size of 'int *' instead of 'int[]' [-Wsizeof-array-argument]`。

**注意只剥最外层**：`int arr[][5]` 调整后是 `int (*)[5]`，行长保留——传二维表必须靠这个。

</details>

**题目 2：** `struct S { int arr[5]; } s;` 中，`s.arr` 是数组类型表达式吗？怎么证明？

<details>
<summary>参考答案</summary>

**是。** 判定标准是"表达式的类型是不是数组类型"，不是"它是不是数组名/字面量"。

证明：看两个上下文的取值是否不同——

```c
printf("%zu\n", sizeof s.arr);   /* 20 —— sizeof 上下文不退化 */
_Generic(s.arr, int *: "int *")  /* int * —— 一般上下文退化 */
```

实测 `sizeof s.arr` = 20、`_Generic` = `int *`，与数组名 `a` 的行为完全一致（`m[0]`、`*p` 同理，都是 20 / `int *`）。

</details>

**题目 3：** 以下代码在 C 和 C++ 下分别是什么结果？

```c
char *s = "abc";
s[0] = 'x';
```

<details>
<summary>参考答案</summary>

- **C11**：编译**零警告**，运行 `s[0] = 'x'` 是 **UB**（C11 6.4.5p7），通常是 SIGSEGV（字面量在 `.rodata`）
- **C++17**：第一行的赋值就不被允许——`warning: ISO C++11 does not allow conversion from string literal to 'char *' [-Wwritable-strings]`

差异根源：C 里字符串字面量的类型是 `char[4]`，C++ 里是 `const char[4]`。**C 工程上应主动写 `const char *s`，把 UB 挡在编译期**；要可写就用 `char s[] = "abc";`（栈上拷贝，[8.1.11](./8.1.11-字符数组的初始化.md)）。

</details>

**题目 4：** 复合字面量在以下两种位置，生命周期有什么不同？

```c
/* 位置 A：函数内 */
int *f(void) { return (int[]){1, 2, 3}; }

/* 位置 B：文件作用域 */
int *g = (int[]){1, 2, 3};
```

<details>
<summary>参考答案</summary>

- **位置 A（函数内）**：**自动存储期**，块结束销毁。`f()` 返回的是**悬垂指针**，调用方访问是 UB。
- **位置 B（文件作用域）**：**静态存储期**（C11 6.5.2.5p5），生命周期贯穿全程，返回/保存其地址是安全的。

这也是"复合字面量都在栈上"这个印象不准确的地方。

</details>
