# 8.2.6 初始化

## 本节讲什么

二维数组 initializer 语法：嵌套花括号、行优先填、缺省补零。这一节讲清三种初始化写法和它们的可读性差异。

## 要点

```c
int tbl[2][3] = {{1,2,3}, {4,5,6}};   /* 嵌套：每行一组 */
int tbl[2][3] = {1,2,3,4,5,6};        /* 平铺：行优先填 */
int tbl[2][3] = {0};                   /* 全零 */
int tbl[2][3] = {{1,2}, {4}};          /* 部分初始化，其余补 0 */
```

### 三种写法

| 写法 | 含义 | 可读性 |
|------|------|--------|
| `{{1,2,3},{4,5,6}}` | 每行一组花括号 | 最清晰 |
| `{1,2,3,4,5,6}` | 行优先平铺 | 紧凑但易错 |
| `{0}` | 全零 | 常用 |

### 部分初始化补零

```c
int tbl[2][3] = {{1,2}, {4}};
/* tbl[0]={1,2,0}, tbl[1]={4,0,0} */
```

每行单独看：写了的元素填值，没写的补 0（**8.1.9** 规则的二维版）。

### C99 指定初始化

```c
int tbl[2][3] = { [1] = { [2] = 99 } };
/* tbl[1][2]=99，其余全 0 */

int tbl[2][3] = { [1][2] = 99 };
/* 等价：直接指定二维位置 */
```

指定初始化让"只填一个位置"很清晰，其余自动补 0。

## 底层映射

### 存储与初始化值

| 定义 | 存储 | 未列元素 |
|------|------|----------|
| 全局 `int g[2][3] = {{1}}` | `.data` | 补 0 |
| 全局 `int g[2][3]` | `.bss` | 全 0 |
| 栈 `int a[2][3]` | 栈 | 脏值 |
| 栈 `int a[2][3] = {0}` | 栈 | 全 0 |

二维的补零规则和一维一致——只要写了 `= {...}`，整个数组进入初始化状态，未列元素补 0。

### 嵌套 vs 平铺的等价性

```c
int a[2][3] = {{1,2,3},{4,5,6}};
int b[2][3] = {1,2,3,4,5,6};
/* a 和 b 完全相等 */
```

两者都按行优先填，结果相同。但嵌套写法可读性更好——一眼看出每行的边界。

## HFT / DPDK

| 场景 | 写法 |
|------|------|
| 静态配置表 | `static const int cfg[N][M] = {{...},{...}}` 在 `.rodata` |
| 单位矩阵 | `int I[3][3] = {{1,0,0},{0,1,0},{0,0,1}}` |
| 行情初值 | `int book[N_SYM][N_LEVEL] = {0}` 启动清零 |
| 状态转移表 | `int fsm[S][S] = {{...}}` |

### 工程纪律

- 配置表用嵌套花括号，可读性优先
- 栈数组 `= {0}` 清零
- 静态配置表放 `static const`，进 `.rodata` 省运行时初始化
- 大数组避免栈上定义，用静态/堆

## 常见误区

| 误区 | 事实 |
|------|------|
| "`{1,2,3,4,5,6}` 和 `{{1,2,3},{4,5,6}}` 不同" | 等价，都行优先填 |
| "`{{1,2},{4}}` 的空位是脏值" | 补 0（部分初始化规则） |
| "栈二维数组自动清零" | 不，栈数组未初始化是脏值 |
| "指定初始化 `[1][2]=99` 非法" | C99 合法 |

## 实操

```bash
# 验证三种写法等价
cat > t.c << 'EOF'
#include <stdio.h>
int main(void){
  int a[2][3]={{1,2,3},{4,5,6}};
  int b[2][3]={1,2,3,4,5,6};
  int c[2][3]={{1,2},{4}};
  for(int i=0;i<2;i++)for(int j=0;j<3;j++)
    printf("a[%d][%d]=%d b=%d c=%d\n",i,j,a[i][j],b[i][j],c[i][j]);
  return 0;
}
EOF
gcc t.c -o t && ./t
# c 的输出：c[0]={1,2,0}, c[1]={4,0,0}
```

## 代码自测

**题目 1：** 以下代码中 arr 的内存布局是怎样的？
```c
int arr[2][3] = {1, 2, 3, 4, 5, 6};
```

<details>
<summary>参考答案</summary>

与 {{1,2,3},{4,5,6}} 相同——按行优先填充。arr[0] = {1,2,3}, arr[1] = {4,5,6}。不使用内层花括号时，编译器按顺序填充。如果初始值不够：{1,2,3,4} 会让 arr[0]={1,2,3}, arr[1]={4,0,0}。

</details>
