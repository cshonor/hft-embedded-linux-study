# 10.6.2 联合的初始化

## 本节讲什么

union 初始化与 struct 类似但有**关键区别**：union 同一时刻仅一个成员有效，初始化时**必须明确指定哪个成员**。C89 规定不指定时初始化**第一个成员**；C99 起支持**指定成员初始化**（`.member =`），这是初始化 union 的**推荐方式**。本节剖析初始化规则、与 struct 的区别、切换成员时的清零需求、以及运行时构造。

## 要点

### C89：默认第一个成员

```c
union raw_data {
    uint32_t word;
    uint8_t  bytes[4];
};

union raw_data u = { 0x12345678 };   /* 初始化第一个成员 word */
```

- C89 只能用值列表初始化**第一个成员**
- 顺序对应第一个成员的结构
- 想初始化其他成员需先初始化第一个，再赋值

### C99：指定成员初始化（推荐）

```c
union raw_data u = { .word = 0x12345678 };
union raw_data u2 = { .bytes = { 0x78, 0x56, 0x34, 0x12 } };
```

- `.member = value` 明确指定初始化哪个成员
- 只能指定**一个**成员（union 同时只有一个有效）
- 未指定的成员共享存储，值未定义

**铁律**：C99 起，union 初始化**总是用指定成员**，避免歧义。

### 嵌套 union 在 struct 中

```c
struct msg {
    uint32_t magic;
    uint8_t  type;
    union {
        struct { uint64_t order_id; uint32_t qty; } order;
        struct { uint32_t seq; uint16_t price; } quote;
    } body;
};

struct msg m = {
    .magic = 0xDEADBEEF,
    .type = PKT_ORDER,
    .body.order = { .order_id = 1001, .qty = 100 },
};
```

- 外层 struct 用 `.field =`
- 内层 union 用 `.member =`，指定哪个变体
- 嵌套初始化可读性强

### 匿名 union 的初始化

```c
struct msg {
    uint32_t magic;
    uint8_t  type;
    union {                           /* 匿名 union */
        struct { uint64_t order_id; uint32_t qty; } order;
        struct { uint32_t seq; uint16_t price; } quote;
    };
};

struct msg m = {
    .magic = 0xDEADBEEF,
    .type = PKT_ORDER,
    .order = { .order_id = 1001, .qty = 100 },   /* 直接初始化匿名 union 成员 */
};
```

- 匿名 union 的成员直接在外层 struct 初始化列表中指定
- 语法更简洁

### 未初始化成员的值

```c
union raw_data u = { .word = 0x12345678 };
/* u.bytes 的值是 0x12345678 的字节解读（小端：78 56 34 12） */
/* 但"读 bytes"在 C99 前是 UB，C99 后允许（类型双关例外） */

union raw_data u2 = { .bytes = { 1, 2, 3, 4 } };
/* u2.word 的值未定义（除非通过 union 类型双关读取） */
```

- 初始化一个成员后，其他成员的值是**该字节的重新解读**
- C99 起允许通过 union 读取（类型双关）
- C89 严格 UB

### 切换成员时的清零

```c
union raw_data u;
u.word = 0x12345678;     /* 写入 word */
/* 现在想用 bytes */
memset(&u, 0, sizeof u); /* 清零，避免残留 */
u.bytes[0] = 0xFF;       /* 只设第一个字节，其余 0 */
```

- 切换 union 成员时，原成员的值**仍存在于共享存储**
- 若新成员比旧成员小，残留字节可能影响后续读取
- **谨慎做法**：切换前 `memset` 清零
- **实践做法**：知道自己在做什么，通常不需清零

### 运行时构造

```c
union raw_data u;
u.word = 0x12345678;   /* 运行时赋值 */

/* 或复合字面量 */
union raw_data u2 = (union raw_data){ .word = 0x12345678 };
```

- 运行时赋值与初始化语法一致
- 复合字面量可在任意位置构造 union 值

### union 数组的初始化

```c
union slot {
    uint64_t value;
    struct { uint32_t a, b; } pair;
};

union slot arr[3] = {
    { .value = 1 },
    { .pair = { .a = 2, .b = 3 } },
    { .value = 4 },
};
```

- 每个元素独立指定成员
- 可混合不同变体

### 静态 union 的初始化

```c
static union raw_data s_u = { .word = 0x12345678 };
/* 编译期初始化，进 .data 段 */

static union raw_data s_zero = { 0 };
/* C89：第一个成员 word = 0 */
/* C99：仍合法，等价 .word = 0 */
```

- 静态 union 的初始化值必须是编译期常量
- `{0}` 是通用零初始化惯用法，对 union 也有效

### const union

```c
const union raw_data c_u = { .word = 0x12345678 };
/* c_u.word = 0; */   /* 编译错误：const */
uint32_t w = c_u.word;   /* OK：只读 */
```

- const union 的所有成员都不可修改
- 用于只读配置、协议模板

## HFT 关联

- **协议模板**：`static const struct msg order_tmpl = { .magic = MAGIC, .type = PKT_ORDER, .body.order = { 0 } }`
- **报文构造**：构造订单报文时用指定成员初始化 union 载荷
- **DPDK mbuf**：mbuf 的 union 字段在 mempool 分配后清零，再按需写入
- **测试夹具**：单元测试中构造变体消息用复合字面量
- **共享内存**：跨进程 union 必须用 packed + 定长类型 + 显式初始化

### 实操：协议模板复用

```c
static const struct msg ORDER_TMPL = {
    .magic = 0x4F524431,   /* "ORD1" */
    .type = PKT_ORDER,
    .body.order = { .order_id = 0, .qty = 0 },
};

void send_order(uint64_t id, uint32_t qty) {
    struct msg pkt = ORDER_TMPL;   /* 复制模板 */
    pkt.body.order.order_id = id;  /* 填入动态字段 */
    pkt.body.order.qty = qty;
    /* 发送 */
}
```

模板复用避免重复构造，且保证字段一致。

### 实操：变体消息构造

```c
struct msg make_quote(uint32_t seq, uint16_t price) {
    struct msg m = {0};   /* 全零 */
    m.magic = MAGIC;
    m.type = PKT_QUOTE;
    m.body.quote.seq = seq;
    m.body.quote.price = price;
    return m;
}

struct msg make_order(uint64_t id, uint32_t qty) {
    struct msg m = {0};
    m.magic = MAGIC;
    m.type = PKT_ORDER;
    m.body.order.order_id = id;
    m.body.order.qty = qty;
    return m;
}
```

`{0}` 先清零所有字段（包括 union），再按需填入。

### 实操：切换成员的清零

```c
union payload {
    uint8_t  bytes[8];
    uint64_t word;
} u;

u.word = 0xFFFFFFFFFFFFFFFF;   /* 全 1 */
/* 现在只用 bytes[0] */
u.bytes[0] = 0x42;
/* bytes[1..7] 仍是 0xFF！ */

memset(&u, 0, sizeof u);       /* 清零 */
u.bytes[0] = 0x42;             /* 现在 bytes[1..7] 是 0 */
```

切换到较小成员时，残留字节可能干扰——清零是最安全的做法。
