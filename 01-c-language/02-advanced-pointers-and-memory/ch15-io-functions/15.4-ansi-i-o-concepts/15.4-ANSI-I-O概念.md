# 15.4 ANSI I/O 概念

## 本节讲什么

标准 I/O 建立在两大抽象之上：**流（stream）** 和 **文件（file）**。流是 `FILE *` 封装的「可读写的数据通道」，文件是「磁盘/管道/设备上的持久化对象」。`fopen` 把文件绑定到流，后续 I/O 通过流进行。这一节是后续 15.4.1（流）和 15.4.2（文件）的入口。

认知锚点：理解「流」与「文件」的分离，才能理解为什么 `freopen` 能把已打开的流重定向到新文件、为什么同一文件可被多个流打开、为什么管道和设备也能用 stdio 操作——**流是抽象，文件是实现**。

## 要点

### 两大抽象

| 抽象 | 本质 | 对应代码 |
|------|------|----------|
| **流 stream** | 可读写的数据通道 + 状态 | `FILE *` |
| **文件 file** | 持久化或虚拟的数据源 | 路径/fd |

```c
FILE *fp = fopen("quote.dat", "rb");
/*  fp  →  流（FILE *）
    "quote.dat"  →  文件（磁盘对象）
    fopen  →  把文件绑定到流 */
```

### 流与文件的分离

```c
/* 同一文件可被多个流打开 */
FILE *fp1 = fopen("data.txt", "r");
FILE *fp2 = fopen("data.txt", "r");
/* fp1 和 fp2 是独立的流，各自有缓冲和读写位置 */

/* 一个流可重定向到不同文件 */
freopen("new.txt", "r", fp1);
/* fp1 现在指向 new.txt，原 data.txt 的流关闭 */
```

**流与文件是多对多关系**：一个文件可被多个流打开（各自独立），一个流可通过 `freopen` 切换到不同文件。

### 流的来源

stdio 的流可以绑定到多种「文件」：

| 文件类型 | 打开方式 | 例子 |
|----------|----------|------|
| 磁盘文件 | `fopen("path", mode)` | `/data/quote.dat` |
| 标准流 | 预定义 | `stdin`/`stdout`/`stderr` |
| 管道 | `popen` 或 `fdopen(pipe_fd)` | 进程间通信 |
| 设备 | `fopen("/dev/xxx")` | `/dev/null`、`/dev/urandom` |
| 内存 | `fmemopen`（POSIX） | 内存缓冲区当流 |
| 套接字 | `fdopen(socket_fd)` | 网络通信 |

所有这些「文件」都能用 `fread`/`fwrite`/`fprintf` 操作——这是 stdio 抽象的威力。

### 文本流 vs 二进制流

```c
FILE *t1 = fopen("data.txt", "r");    /* 文本流 */
FILE *t2 = fopen("data.dat", "rb");   /* 二进制流 */
```

| 模式 | 换行处理 | 平台差异 |
|------|----------|----------|
| 文本 `r`/`w` | 平台默认换行转换 | Windows: `\n` ↔ `\r\n` |
| 二进制 `rb`/`wb` | 不转换，原样读写 | 跨平台一致 |

**Linux 下 `r` 和 `rb` 行为相同**（换行就是 `\n`）。**Windows 下 `r` 会把 `\r\n` 转成 `\n`，`rb` 不转换**。跨平台代码统一用 `b`，避免换行污染二进制数据。

## HFT 关联

### 行情数据文件

```c
FILE *fp = fopen("/data/market_20240101.dat", "rb");
/* 磁盘文件 → 流 → fread 读取 */
```

HFT 行情数据用二进制流读写，保证跨平台一致。

### 管道流

```c
FILE *pp = popen("gzip -dc quote.dat.gz", "r");
/* 管道：gzip 解压输出 → 流 → fread 读取 */
char buf[4096];
while (fgets(buf, sizeof(buf), pp)) {
    parse_line(buf);
}
pclose(pp);
```

`popen` 创建管道连接外部命令，用 stdio 接口读取命令输出。HFT 运维脚本常用。

### 内存流

```c
char membuf[4096];
FILE *mf = fmemopen(membuf, sizeof(membuf), "w+");
fprintf(mf, "seq=%u price=%u", seq, price);
fflush(mf);
/* membuf 内已有格式化结果，无需磁盘 I/O */
```

`fmemopen` 把内存缓冲区当流操作，适合内存内格式化。详见 15.15。

### 设备流

```c
FILE *null_fp = fopen("/dev/null", "w");
/* 丢弃输出，用于性能测试 */
fprintf(null_fp, "this goes nowhere\n");
```

`/dev/null` 是特殊设备文件，写入的数据被丢弃。性能测试时用 `/dev/null` 作为输出，避免磁盘 I/O 干扰。
