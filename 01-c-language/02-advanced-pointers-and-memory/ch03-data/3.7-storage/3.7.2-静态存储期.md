# 3.7.2 静态存储期

## 本节讲什么

**静态存储期(static storage duration)** 的对象存活于 `.data`/`.bss` 段,程序启动前初始化,程序结束时销毁。全局变量、文件级 static、块内 static 都属于此类。本节讲 `.data` 与 `.bss` 的区别、初始化时机、static 局部的"块作用域 + 静态存储期"特例。

## 要点

### .data vs .bss

```c
int g_init = 42;           /* .data, 外部链接 */
int g_zero;                /* .bss, 自动 0 */
static int s_init = 1;     /* .data, 内部链接 */
static int s_zero;         /* .bss, 自动 0 */
void f(void) {
    static int call = 0;   /* .data/.bss, 块作用域但静态存储期 */
    call++;
}
```

- 静态对象**程序全程存活**,作用域仍按声明位置(块/文件)
- `.data` 占文件体积(存初值);`.bss` 不占,加载时清零
- static 局部:作用域限块,存储期静态 —— 3.8 详

### 初始化时机

- 静态对象在**程序启动前**初始化,不是首次调用时(C11 6.2.4p3)
- 初始化器必须是**常量表达式**(C11 6.7.9p4),5 直接烧进 `.data` 段镜像
- 无显式初值时自动零初始化(`.bss` 段,加载器 mmap 时清零)
- "首次调用时初始化"是 C++ 的动态初始化语义,**C 没有这条**

## 与 HFT/DPDK

### 静态配置表用 .bss 清零

```c
/* 嵌入式/DPDK: 大配置数组放 bss 利用清零, 不占镜像 */
static struct device g_devs[MAX_DEV];   /* .bss, 启动时全 0 */
```

- 只读配置改 `static const` 进 `.rodata`,可被多核安全共享
- `.bss` 不占可执行文件体积,加载器分配内存并清零

## 常见误区

| 误区 | 真相 |
|------|------|
| 全局 `int g;` 是"未初始化" | 是定义为 0,放 .bss |
| static 局部每次重初始化 | 启动前初始化一次(C11 6.2.4p3),后续保留 |
| `.bss` 占可执行文件体积 | 不占,加载器分配并清零 |

## 实操

```bash
cat > t.c <<'EOF'
int g_init = 1; int g_zero; static int s_init = 2; static int s_zero;
const char *msg = "hi";
int main(void){ int x; return 0; }
EOF
gcc -c t.c && readelf -S t.o | grep -E 'text|rodata|data|bss'
nm t.o | sort        # D=g_init, B=g_zero, d=s_init, b=s_zero, R="hi"
```

## 代码自测

**题目 1：** 下面这段代码,static 局部 `n` 什么时候被初始化为 5？首次调用 `f()` 时函数体里有没有"把 5 写进 n"的指令？

```c
void f(void) {
    static int n = 5;
    n++;
}
```

<details>
<summary>参考答案</summary>

**程序启动前**初始化，不是首次调用。C11 6.2.4p3：静态存储期对象 "initialized only once, prior to program startup"。C11 6.7.9p4 要求初始化器是常量表达式，所以 5 直接烧进 `.data` 段镜像，加载器 mmap 时就位。函数体里**没有任何初始化指令**——objdump 反汇编只能看到 inc，nm 可以看到 `n` 是 D 类符号带初值。"首次调用时初始化"是 C++ 的动态初始化语义，C 没有这条。

</details>
