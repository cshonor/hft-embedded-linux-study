# 13.5 字符串常量

## 本节讲什么

字符串字面量（`"hello"`）在 C 里有两种截然不同的存在形态：作为**只读段中的常量**（`.rodata`），和作为**栈/堆上的字符数组**（`char buf[] = "hello"`）。这一节把两者的存储、可写性、生命周期讲清楚，并给出指针数组 of 常量 vs 动态 `strdup` 数组的选型对比。

认知锚点：字符串字面量是 C 工程里**最高频的 UB 来源之一**——`char *p = "hello"; p[0] = 'H';` 在某些平台崩溃、某些平台「能跑」，是典型的「实现定义 + UB」混合陷阱。理解字面量的存储位置，是写出可移植、无 UB 代码的前提。

## 要点

### 两种形态：只读引用 vs 栈拷贝

```c
const char *p = "hello";   /* 字面量在 .rodata，p 指向它 */
char buf[]  = "hello";     /* 字面量在 .rodata，但 buf 是栈数组，拷贝一份 */
```

| 形态 | 存储 | 可写 | sizeof | 生命周期 |
|------|------|------|--------|----------|
| `const char *p = "x"` | `.rodata` | 否 | 8（指针） | 程序全程 |
| `char *p = "x"` | `.rodata` | 否（但编译器允许写，UB） | 8 | 程序全程 |
| `char buf[] = "x"` | 栈 | 是 | 6（含 `\0`） | 函数返回即失效 |
| `char *p = malloc(6); strcpy(p, "x");` | 堆 | 是 | 8（指针） | free 前 |

**关键区别**：`char buf[] = "x"` 是**用字面量初始化一个栈数组**，字面量本身仍在 `.rodata`，但 `buf` 是独立拷贝，可写、`sizeof` 是数组大小（6 字节，含 `\0`）。`char *p = "x"` 是**指针指向只读字面量**，`sizeof(p)` 是指针大小（8 字节），写入是 UB。

### .rodata 段与只读保护

```c
const char *proto = "heartbeat";   /* 字面量在 .rodata */
char *bad = "text";                /* 旧代码；写 → SIGSEGV */
```

`.rodata` 段（read-only data）在程序启动时由操作系统映射为**只读页**。任何写入尝试触发硬件页错误，进程收到 `SIGSEGV` 崩溃。这是操作系统层面的保护，不依赖编译器检查。

```
进程虚拟地址空间:
  +------------------+
  | .text   (代码)    |  只读 + 可执行
  +------------------+
  | .rodata (常量)    |  只读          <-- 字面量在这里
  +------------------+
  | .data   (已初始化)|  读写
  +------------------+
  | .bss    (零初始化)|  读写
  +------------------+
  | heap             |  读写
  +------------------+
  | stack            |  读写
  +------------------+
```

字面量 `"heartbeat"` 编译后进入 `.rodata`，多个相同字面量通常合并（编译器去重，节省空间）。

### `char *p = "x"` 的历史包袱

```c
char *p = "hello";   /* C89 允许，C11 弃用，C23 移除 */
p[0] = 'H';          /* UB：写只读页，SIGSEGV */
```

C89 时代字面量存储区**不一定只读**（取决于实现），`char *p = "x"; p[0] = 'H';` 在某些老旧系统上「能跑」。C99 起 `char *p = "x"`（非 const）被标记为弃用，C23 正式移除该隐式转换。**现代代码必须用 `const char *`**：

```c
const char *p = "hello";   /* 正确 */
```

`-Wwrite-strings` 编译选项把 `char *p = "x"` 的警告升级为错误，强制 const。HFT 工程必开。

### 字面量拼接与相邻自动合并

```c
const char *msg = "hello, "
                  "world";   /* 等价 "hello, world" */
```

相邻字符串字面量在编译期自动合并，常用于长字符串换行书写、宏定义字符串组合。**运行期无拼接开销**，纯编译期处理。

### 字面量与字符常量的区别

```c
const char *s = "a";   /* 字符串字面量：'a' + '\0'，2 字节 */
char c = 'a';          /* 字符常量：int 类型，1 字节存储 */
```

`'a'` 是 `int` 类型（C 标准），不是 `char`。`sizeof('a') == 4`（x86-64）。这是 C 与 C++ 的差异之一——C++ 中 `'a'` 是 `char`。`<ctype.h>` 函数（`isdigit` 等）的参数是 `int`，正是为此设计（见 ch09 ctype）。

### 指针数组 of 常量

```c
const char *msgs[] = {
    "QUOTE",
    "ORDER",
    "CANCEL",
};

/* 内存布局：
   msgs[0] --> "QUOTE\0"   (.rodata)
   msgs[1] --> "ORDER\0"   (.rodata)
   msgs[2] --> "CANCEL\0"  (.rodata)
   msgs[3] = NULL          (如果显式初始化加 NULL)
*/
```

`msgs` 数组本身在 `.data` 或栈（取决于声明位置），每个元素是 `const char *` 指向 `.rodata` 的字面量。**这种结构无需分配堆内存，启动即就绪**，是协议名表、错误码字符串表的标准形态。

### 指针数组 of 常量 vs 动态 strdup 数组

| 维度 | `const char *msgs[]` | `char **table = calloc + strdup` |
|------|----------------------|----------------------------------|
| 存储 | `.rodata` + `.data` | 全堆 |
| 可写 | 否（字面量只读） | 是（strdup 拷贝可改） |
| 生命周期 | 程序全程 | 手动 free |
| 初始化开销 | 0（编译期完成） | 启动时 malloc + strcpy |
| 释放 | 无需 | 逐元素 free + 数组 free |
| 适用场景 | 固定常量表 | 动态构建的字符串集合 |

**选型口诀**：**编译期已知的字符串表 → 指针数组 of 常量**；**运行期动态生成的字符串 → strdup 数组**。HFT 协议名表、消息类型表用前者；订单日志、动态配置用后者。

### 字面量作函数参数

```c
/* 字面量直接传参：传的是 .rodata 的地址 */
log_msg("connection reset by peer");

/* 等价于 */
const char *tmp = "connection reset by peer";
log_msg(tmp);
```

字面量作参数传递的是 `.rodata` 中的地址，**零拷贝**。这是 C 工程里最高效的字符串传递方式，比 `std::string`（C++）构造析构快得多。

## HFT 关联

### 协议名表

```c
static const char *const msg_type_names[] = {
    [MSG_HEARTBEAT] = "HEARTBEAT",
    [MSG_QUOTE]     = "QUOTE",
    [MSG_TRADE]     = "TRADE",
    [MSG_ORDER]     = "ORDER",
    [MSG_CANCEL]    = "CANCEL",
};

_Static_assert(ARRAY_SIZE(msg_type_names) == MSG_TYPE_NUM,
               "msg type table mismatch");

const char *msg_type_name(uint16_t type)
{
    if (type < ARRAY_SIZE(msg_type_names))
        return msg_type_names[type];
    return "UNKNOWN";
}
```

`const char *const` 双 const：指针本身和指向的内容都不可变，放 `.rodata`。表驱动 + 类型枚举绑定，`_Static_assert` 编译期锁定表大小。HFT 日志、统计、调试输出全部依赖这种表。

### 错误码字符串表

```c
static const char *const err_str[] = {
    [ERR_OK]          = "ok",
    [ERR_TIMEOUT]     = "timeout",
    [ERR_INVALID]     = "invalid argument",
    [ERR_NO_MEM]      = "out of memory",
    [ERR_DISCONNECT]  = "connection lost",
};

const char *err_to_str(int err)
{
    if (err >= 0 && err < (int)ARRAY_SIZE(err_str) && err_str[err])
        return err_str[err];
    return "unknown error";
}
```

错误码 → 字符串的查表，**零运行开销**（编译期生成）。比 `strerror`（标准库但实现各异）更可控，HFT 工程倾向自建错误码表。

### 日志模板

```c
#define LOG_FMT_QUOTE  "quote sym=%s bid=%u ask=%u"
#define LOG_FMT_ORDER  "order id=%lu side=%c qty=%u"

log_info(LOG_FMT_QUOTE, sym, bid, ask);
```

日志格式字符串是 `.rodata` 字面量，宏定义集中管理，便于统一修改。`__attribute__((format(printf, ...)))` 让编译器检查格式与参数类型匹配，防格式串漏洞。

### 配置默认值的字面量

```c
static const char *const default_cfg = {
    .listen_port = "8080",
    .log_dir     = "/var/log/myapp",
    .pid_file    = "/var/run/myapp.pid",
};
```

配置默认值用字面量，启动时若配置文件未指定则用默认值。字面量只读，避免误改默认值。

### 字面量与 ASan

```c
char *p = "hello";
p[0] = 'H';   /* 写只读页 */
```

ASan 能在编译期或运行期捕获部分此类 UB（`-fsanitize=address` 配合 `-Wwrite-strings`）。但**`.rodata` 只读保护是硬件级的**，即使不开 ASan 也会触发 SIGSEGV。可移植代码必须 `const char *`，不依赖任何工具。

## UB 边界

| 情形 | 后果 | 防护 |
|------|------|------|
| `char *p = "x"; p[0] = 'X';` | SIGSEGV（写只读页） | `const char *` + `-Wwrite-strings` |
| `char buf[] = "x"; buf[1] = 'y';` 写到 `\0` | 字符串变 "xy"，无 `\0` 终止 | 显式 `buf[sizeof(buf)-1] = '\0'` |
| `char buf[3] = "abcd";` | 截断为 "ab\0"（C 标准允许） | 用 `char buf[5] = "abcd"` 或显式长度 |
| 字面量作 `strtok` 第一参数 | 写 `.rodata`，UB | `strtok` 只用于可写字符串 |
| 释放 `const char *p = "x"` | free 只读地址，UB | 字面量无需 free |
| 修改字面量拼接结果 | UB（拼接在 .rodata） | 视为只读 |

### `strtok` 的字面量陷阱

```c
char *tok = strtok("a,b,c", ",");   /* UB：strtok 会写入第一参数 */
```

`strtok` 会修改输入字符串（插入 `\0` 分割 token）。字面量在 `.rodata`，写入 UB。**必须先 `strdup`**：

```c
char *copy = strdup("a,b,c");
char *tok = strtok(copy, ",");
/* ... */
free(copy);
```

详见 ch09 strtok 的非重入性与 UB 分析。

### `char buf[3] = "abcd"` 的截断

```c
char buf[3] = "abcd";   /* C 标准允许，buf = {'a','b','\0'} */
```

数组太小放不下完整字面量，C 标准允许截断（与 `char buf[3] = {'a','b','\0'}` 等价）。**这不是 UB，但容易引发字符串长度误判**——`strlen(buf) == 2`，而字面量本意是 4 字符。`-Wstringop-truncation` 警告此类隐患。

### 字面量与 wide string

```c
const wchar_t *w = L"hello";   /* 宽字符串字面量 */
const char8_t *u8 = u8"hello"; /* C23 UTF-8 字面量 */
const char16_t *c16 = u"hello";
const char32_t *c32 = U"hello";
```

不同前缀的字面量存储在不同段（编码不同），但可写性规则一致：**全部只读**。HFT 国际化场景（中文报错信息）用 UTF-8 字面量，但数据面极少涉及，主要在管理面。
