# 7.4 格式化输出 printf

## 本节讲什么

**`printf`** 按格式串把各类型转为文本输出；**`fprintf`** 写到指定 `FILE*`，**`sprintf`/`snprintf`** 写到内存缓冲。日志、调试、配置生成的基础。

## 要点

### 常用转换说明符

| 符 | 类型 |
|----|------|
| `%d` `%i` | int |
| `%u` `%o` `%x` `%X` | unsigned / 八进制 / 十六进制 |
| `%c` | char |
| `%s` | 字符串 |
| `%f` `%e` `%g` | float/double |
| `%p` | 指针（实现定义格式，常十六进制） |
| `%%` | 字面 `%` |

### 修饰

- **宽度 / 精度**：`%8d`、`%.2f`、`%-10s`（左对齐）
- **长度修饰**：`%ld`、`%zu`、`%llx` 等
- **返回值**：成功输出的**字符数**；出错返回负值

### 文件与内存变体

```c
fprintf(stderr, "error: %s\n", msg);
fprintf(fp, "%d\n", n);

char buf[64];
snprintf(buf, sizeof buf, "tick=%lld", tick);  /* 推荐：有边界 */
```

## 考点

- **`sprintf` 无边界** → 缓冲区溢出；现代代码用 **`snprintf`**
- 格式与实参类型不匹配 → 未定义行为
- HFT 热路径避免 `printf`（锁 + 格式化开销），用预分配缓冲或二进制日志

## 常见陷阱

1. **格式说明符与实参类型不匹配是 UB**：`printf("%d", 3.14)`（double 用 %d）、`printf("%s", 42)`（int 用 %s）——编译器可能不报警告（变参无类型检查），运行时读到垃圾值甚至崩溃。64 位系统上 `printf("%d", 1LL)` 把 long long 当 int 读，高位/低位错位。用 `-Wformat` 编译选项让 GCC/Clang 检查。
2. **`sprintf` 缓冲区溢出**：`sprintf(buf, "...", data)` 无边界检查，输出超过 buf 大小就栈溢出。现代代码一律用 `snprintf(buf, sizeof buf, ...)`，它的返回值是"本应写入的字符数"（可能大于 size，说明被截断）。
3. **`%n` 格式符是安全漏洞**：`printf("%n", &n)` 会把已输出字符数写入 n 指向的内存——攻击者通过构造格式串可写任意地址。现代编译器（GCC/Clang）默认禁用 `%n` 支持。日志函数若接受用户输入作为格式串，用 `printf("%s", user_input)` 而非 `printf(user_input)`。

## 自测题

**1. 选择**：`printf("%d\n", 3.14)` 的行为是？
- A. 输出 3
- B. 输出 3.14
- C. 未定义行为，可能输出垃圾值
- D. 编译错误

<details><summary>答案</summary>
C。`%d` 期望 int，传入 double（8 字节）。变参函数不做类型检查，printf 按 int（4 字节）读 double 的低位字节，得到垃圾值。64 位系统上更混乱（寄存器传参规则不同）。开 `-Wformat` 编译选项可让编译器静态检查并报错。
</details>

**2. 判断**：`snprintf(buf, 64, "x")` 的返回值是 1（实际写入的字符数）。

<details><summary>答案</summary>
对（返回 1）。但注意 `snprintf` 的返回值是"**本应写入的字符数**"（不含 `\0`），不一定等于实际写入数。若返回值 ≥ 64，说明输出被截断。这个语义让调用方能判断是否需要更大缓冲——是 snprintf 比 sprintf 安全且有用的原因。
</details>

**3. 踩坑**：日志函数 `void log_msg(char *fmt)` 里直接 `printf(fmt)`，用户传入 `%s%s%s%s` 导致崩溃，为什么？

<details><summary>答案</summary>
这是**格式串漏洞**。`printf(fmt)` 把 fmt 当格式串，`%s` 会从栈上读指针参数——但没传任何参数，读到的是栈上的垃圾地址，解引用即崩溃（SIGSEGV）。攻击者可构造 `%n` 写任意内存。修复：`printf("%s", fmt)`——把 fmt 当普通字符串输出，不做格式解析。规则：**永远不要把外部输入直接作为 printf 的格式串**。
</details>

**4. 应用**：用 `snprintf` 安全拼接 `"tick=12345 level=INFO msg=hello"` 到 64 字节缓冲，并检查是否被截断。

<details><summary>答案</summary>
```c
char buf[64];
int n = snprintf(buf, sizeof buf, "tick=%d level=%s msg=%s",
                 12345, "INFO", "hello");
if (n < 0) {
    perror("snprintf");        /* 编码错误 */
} else if ((size_t)n >= sizeof buf) {
    /* 输出被截断，n 是本应写入的长度 */
    fprintf(stderr, "log truncated, need %d bytes\n", n);
}
```
关键：检查返回值，`n >= sizeof buf` 说明截断。这是安全日志拼接的标准模式。
</details>
