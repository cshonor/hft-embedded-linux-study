# 7.5 格式化输入 scanf

## 本节讲什么

**`scanf`** 按格式从 **stdin** 解析并写入变量；**`fscanf`** 对文件，**`sscanf`** 对内存字符串。与 `printf` 对称，但**更易出错**。

## 要点

- 除 **`%s` `%[]`** 等外，实参必须是**指针**：`scanf("%d", &n);`
- **数组名**已是地址：`scanf("%s", buf)` 无需 `&buf`
- **返回值**：成功匹配并赋值的**项数**；`EOF` 表示在读入前即结束
- **空白**：格式串中的空白匹配任意空白；`%d` 等前也会跳过 leading 空白

### 常用格式

| 符 | 含义 |
|----|------|
| `%d` | int |
| `%f` `%lf` | float / double |
| `%s` | 无空白字符串（**无长度上限，危险**） |
| `%c` | 字符（不跳过空白，常需 `" %c"`） |
| `%x` | 十六进制 |

### 变体

```c
fscanf(fp, "%d %s", &n, name);
sscanf(pkt, "MD:%lf", &price);   /* 报文内解析，无磁盘 IO */
```

## 考点

- **`%s` 溢出** → 用 **`%63s`** 限宽或改用 `fgets` + 解析
- 与 `printf` 类型不匹配 → UB
- 留字符在流中未读 → 下次 `scanf` 行为诡异

## 常见陷阱

1. **`%s` 无长度限制导致溢出**：`scanf("%s", buf)` 遇到超长输入直接写越界——和 `gets` 一样是经典安全漏洞。用 `%63s`（限 63 字符，留 1 给 `\0`）或改用 `fgets(buf, sizeof buf, stdin)` 再解析。
2. **忘记传指针，传了值**：`scanf("%d", n)` 而非 `scanf("%d", &n)`——把 n 的值当地址写入，轻则段错误，重则写穿内存。数组名已是地址（`scanf("%s", buf)` 无需 `&`），这是唯一例外。编译器开 `-Wformat` 可静态检查。
3. **`%c` 不跳过空白，读到遗留换行**：`scanf("%d", &n); scanf("%c", &c);` ——第二个 scanf 读到的是第一个遗留的 `\n` 而非用户输入。修复：格式串加空格 `scanf(" %c", &c)`（空格匹配任意空白）。

## 自测题

**1. 选择**：`scanf("%d %d", &a, &b)` 输入 `"10 20\n"`，返回值是？
- A. 0
- B. 1
- C. 2
- D. EOF

<details><summary>答案</summary>
C。scanf 返回成功匹配并赋值的项数，这里 a=10、b=20 都成功，返回 2。若输入 `"10 x\n"`，a=10 成功但 b 匹配 int 失败，返回 1。检查返回值是健壮输入的必备——不能假设用户一定输入正确。
</details>

**2. 判断**：`scanf("%s", buf)` 是安全的输入方式。

<details><summary>答案</summary>
错。`%s` 无长度限制，遇到超长输入直接越界写——和 `gets` 一样是缓冲区溢出的经典来源。安全写法：`scanf("%63s", buf)`（限 63 字符）或 `fgets(buf, sizeof buf, stdin)`。C11 的 `scanf_s` 强制传缓冲大小，但可移植性差。
</details>

**3. 踩坑**：`scanf("%d", &n); scanf("%c", &c);` 输入 `5\nx`，`c` 的值是 `'\n'` 而非 `'x'`，为什么？

<details><summary>答案</summary>
`%d` 读 5 后停下，`\n` 留在输入流。`%c` **不跳过前导空白**（和 `%d`/`%s` 不同），直接读走那个 `\n`，于是 c = '\n'。修复：`scanf(" %c", &c)`——格式串里的空格匹配任意空白（包括 `\n`、空格、Tab），跳过后再读真正的字符。这是 `%c` 最常见的坑。
</details>

**4. 应用**：用 `sscanf` 从 `"MD:123.45"` 解析出 double 价格，并检查是否成功。

<details><summary>答案</summary>
```c
const char *pkt = "MD:123.45";
double price;
int matched = sscanf(pkt, "MD:%lf", &price);
if (matched == 1) {
    printf("price = %f\n", price);   /* 123.450000 */
} else {
    fprintf(stderr, "parse failed\n");
}
```
关键：`%lf` 匹配 double（scanf 里 double 用 `%lf`，和 printf 的 `%f` 不同！）、检查返回值。`sscanf` 不做磁盘 IO，适合解析内存中的报文/配置字符串。
</details>

## 与后续衔接

HFT 简单文本协议可用 `sscanf`；二进制行情应用 `fread` + struct（7.6）而非 scanf。
