# 2.5 算术运算符

## 本节讲什么

二元算术：`+ - * / %` 及与整型、浮点混合时的行为。

## 要点

- **`/` 整数除法截断** toward zero：`5/2 == 2`，`-5/2` 实现定义前 C89 需注意
- **`%` 取模仅用于整数**；符号随实现，C99 后 `(a/b)*b + a%b == a`
- 浮点除法至少一侧为浮点：`5.0/2` → `2.5`
- 溢出：有符号溢出 **UB**；无符号溢出模 \(2^n\)

## 示例

```c
9 / 2;    /* 4 */
9 % 2;    /* 1 */
9 / 2.0;  /* 4.5 */
```

HFT/内核里计时、对齐常用 `%` 与 `/` 组合（如 `% align`）。

## 代码自测

**题目 1：** 以下表达式结果是多少？
```c
int x = -7 / 2;   // ?
int y = -7 % 2;   // ?
```

<details>
<summary>参考答案</summary>

C89 中行为实现定义——可能 -3/-1 或 -4/-1。C99 起规定向零截断：`-7 / 2 = -3`（截断小数），`-7 % 2 = -1`（符号与被除数相同）。这是 C89 和 C99 的一个重要区别。

</details>
