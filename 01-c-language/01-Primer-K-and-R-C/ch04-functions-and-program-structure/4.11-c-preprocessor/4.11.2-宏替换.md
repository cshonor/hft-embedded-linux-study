# 4.11.2 宏替换

## 本节讲什么

**`#define`** 定义符号常量与**带参宏**；预处理器做文本替换。第 1 章已用 `#define YES 1`，本节补充函数式宏与陷阱。

## 要点

### 简单宏

```c
#define MAXLINE 1000
#define PI 3.14159265
```

### 带参宏

```c
#define max(a, b) ((a) > (b) ? (a) : (b))
```

- 参数和整体表达式加 **`()`**，避免优先级与多次求值副作用
- 宏**无类型**；`a` 若带副作用（如 `i++`）可能被求值多次

### 宏 vs 函数

| 宏 | 函数 |
|----|------|
| 文本展开，无调用开销 | 类型检查、单点求值 |
| 无作用域，难调试 | 可断点、可 inline |

### 常用技巧

- **`#define` 续行** `\` 换行
- 字符串化 `#`、连接 `##`（高级用法，内核常见）

## 示例陷阱

```c
#define square(x) ((x) * (x))
square(z + 1)   /* 展开为 ((z + 1) * (z + 1))，正确因括号 */
```

```c
int i = 5;
max(i++, j)     /* 危险：i 可能被递增多次 */
```

## 常见陷阱

1. **宏参数未加括号，优先级错乱**：`#define square(x) x*x`，调用 `square(2+3)` 展开为 `2+3*2+3` = 11 而非 25。规则：**每个参数和整体表达式都加 `()`**：`#define square(x) ((x)*(x))`。
2. **带副作用参数被多次求值**：`#define max(a,b) ((a)>(b)?(a):(b))`，调用 `max(i++, j)` 时 `i++` 可能被求值两次。宏是文本展开，不保证单次求值——有副作用的表达式不要传给宏。
3. **宏不受作用域约束**：在函数内 `#define TMP 1` 后，TMP 在该文件后续所有位置都有效（直到 `#undef`），不会随函数结束而消失。宏没有 C 的块作用域概念。

## 自测题

**1. 选择**：`#define DOUBLE(x) x+x`，`DOUBLE(5)*3` 的值是？
- A. 30
- B. 20
- C. 15
- D. 25

<details><summary>答案</summary>
B。展开为 `5+5*3` = 5+15 = 20。因整体未加括号，乘法优先级高于加法。正确写法：`#define DOUBLE(x) ((x)+(x))`，展开 `((5)+(5))*3` = 30。
</details>

**2. 判断**：宏展开在编译阶段进行。

<details><summary>答案</summary>
错。宏展开在**预处理阶段**（编译之前）。预处理做纯文本替换，之后才进入编译阶段做语法分析、类型检查。这就是为什么宏的错误往往难以定位——预处理后的代码和源码不一致。
</details>

**3. 踩坑**：`#define max(a,b) ((a)>(b)?(a):(b))`，执行 `int i=3, j=5; int m = max(i++, j);` 后 `i` 的值是多少？

<details><summary>答案</summary>
`i` 可能变成 5（被递增两次）。展开为 `((i++)>(j)?(i++):(j))`：先比较 `i++`（i 从 3 变 4，用旧值 3），3>5 为假，走 else 分支返回 j=5。但如果编译器在条件判断后再次求值 `i++`（三目运算的某些实现），i 会再递增一次变 5。**带副作用的表达式绝不能传给宏**，改用 inline 函数：`static inline int max(int a, int b) { return a>b?a:b; }`。
</details>

**4. 应用**：用 `#`（字符串化）和 `##`（记号连接）写两个宏：`STR(x)` 把参数转为字符串，`CAT(a,b)` 连接两个记号。

<details><summary>答案</summary>
```c
#define STR(x) #x
#define CAT(a,b) a##b

printf("%s\n", STR(hello));   /* 输出 "hello" */
int CAT(foo, 12) = 0;         /* 等价于 int foo12 = 0; */
```
注意：宏内 `#` 和 `##` 是预处理运算符，内核中大量用于构造符号名（如 `DEFINE_MUTEX(name)` 展开为 `struct mutex name`）。
</details>
