## 1. 一句话 + 元素类型

`char *argv[]` 是**指针数组**；**每个元素是 pointer to char**（口语：`char *`）。  
声明语法上 `*` 跟名字走，见 [5.12.1](../ch05-pointers-and-arrays/5.12.1-声明中星号绑定名字.md)；**不是**把 `char*` 当成不可拆类型单元（对比 `int* a, b`）。

```c
char *argv[];
/* 本质：指针数组；argv[i] 的类型 = char * */
```

| 表达式 | 类型 | 含义 |
|--------|------|------|
| `argv[i]` | `char *` | 数组元素：指向某参数字符串 |
| `argv`（形参里） | `char **` | 退化后：指向「首个 `char *`」的指针 |
| `argv[i][0]` | `char` | 该串首字符 |

**不是**二维字符数组 `char argv[][]`：后者是连续字符块；前者是一排指针，字符串可分散存放。

```
argv[0] (char*) → "./app"
argv[1] (char*) → "input"
argv[2] (char*) → NULL
```

## 1b. 两处场景（核心矛盾：能否写 `char *argv[]`）

很多人把「不定长数组不能单独定义」套到 `main` 上，其实是**两处场景**：

### 场景 A：普通变量（局部 / 全局）

```c
char *argv[];                      /* ❌ 无长度、无初始化 → 非法 */
char *argv[] = {"a", "b", NULL};   /* ✅ 由初始化推导长度 */
```

普通对象里的数组必须能确定大小。

### 场景 B：函数形参（`main` 就在这里）

```c
int main(int argc, char *argv[]) { ... }
/* 标准允许；编译器等价为 */
int main(int argc, char **argv) { ... }
```

规则：形参里写 `T arr[]` **永远**等价 `T *arr`（第一维 `[]` 退化成指针）。  
`char *argv[]` 只是**语法糖**，形参位置**并不真正定义数组**；只收到「指针表」的首地址（通常来自 `execve`）。

| | 普通变量 `T a[]` | 函数形参 `T a[]` |
|--|------------------|------------------|
| 无长度无初始化 | 非法 | 合法，= `T *` |
| `sizeof` | 整数组字节数 | **一个指针**的大小 |

面试一句：形参里看起来像数组，**本质是指针**；函数内部局部变量才是真数组，不初始化就不能省略长度。  
**为何如此设计（栈/性能/规则 A+B）** → [5.3.1](../ch05-pointers-and-arrays/5.3.1-数组形参为何退化为指针.md) · 类型对比 [5.6.1](../ch05-pointers-and-arrays/5.6.1-指针数组vs数组指针-精炼.md)。

## 2. 索引规范（POSIX / C）

| 下标 | 内容 |
|------|------|
| `argv[0]` | 程序路径/名（由 `execve` 调用者决定，**可被篡改**；勿做业务硬依赖） |
| `argv[1]` … `argv[argc-1]` | 用户参数 |
| `argv[argc]` | **强制 `NULL`** |

`argc` **最小为 1**（无用户参数时仍有 `argv[0]`）。

安全遍历：

```c
/* 推荐：靠 argc */
for (int i = 0; i < argc; i++)
    puts(argv[i]);

/* 靠末尾 NULL（标准保证 argv[argc]==NULL） */
char **p = argv;
while (*p != NULL) {
    puts(*p);
    p++;
}
```

## 3. 工程坑（嵌入式 / Linux 后台通用）

1. 指向的字符串**通常可改内容**；长期改写 `argv[0]` 不推荐（日志/`ps` 等常依赖）。  
2. 全是 `\0` 结尾的 C 字符串；数字仍是串 → 用 `strtol` 等转换。  
3. shell 的 `*.txt` **由 shell 展开**；程序若收到字面量 `*.txt`，说明通配被关/未走 shell。  
4. 分段：空格切分；含空格用引号：`./a "my file"` → 一段。

## 4. 衔接 TLPI / 进程

`execve(path, argv, envp)` 在用户态构造这套数组。扩展签名（POSIX）：

```c
int main(int argc, char *argv[], char *envp[]);  /* envp 同结构，末尾 NULL */
```

## 自测

1. 局部 `char *argv[]` 与 `main` 形参为何含义不同？  
   → **普通变量**：真数组，须定长或初始化；**形参**：语法糖，= `char **`。  
2. 只写 `while (argv[i])` 不判 `i < argc`？  
   → 若保证 `argv[argc]==NULL` 且 `i` 递增则合法；优先 `i < argc`。  
3. 能 `free(argv[0])` 吗？  
   → **不能**。非本程序 `malloc`；`free` → UB。  
4. 形参里 `sizeof(argv)` 是多少？  
   → **一个指针大小**（如 8），不是「参数字符串总长度」。

## 面试速记

- **元素 = `char *`**；形参整体 = **`char **`（不是真数组对象）**  
- 普通变量 `char *a[];` 非法；形参里合法  
- `≠ char argv[][]`；`argc≥1`；勿 `free(argv[i])`
