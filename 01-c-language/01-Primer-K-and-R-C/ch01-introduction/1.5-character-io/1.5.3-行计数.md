# 1.5.3 行计数

## 本节讲什么

统计输入的行数——在字符循环中数 `\n` 的个数。核心：行不是库读出来的，是你在字符流里识别 `\n` 数出来的。

## 核心代码

```c
int c, nl = 0;

while ((c = getchar()) != EOF)
    if (c == '\n')
        ++nl;
printf("%d\n", nl);
```

### 逐行解析

| 代码 | 作用 |
|------|------|
| `nl = 0` | 行计数器初始化。变量名 `nl` = number of lines |
| `if (c == '\n')` | 当前字符是换行符就计数 |
| `'\n'` | 字符常量，值为 10。单引号，不是双引号 |

### 和 1.5.2 的关系

```c
/* 1.5.2 字符计数：每个字符都数 */
while ((c = getchar()) != EOF)
    ++nc;

/* 1.5.3 行计数：只数换行符 */
while ((c = getchar()) != EOF)
    if (c == '\n')
        ++nl;
```

框架完全相同，只多了一个 `if` 判断——**过滤条件变了，循环结构不变**。

### 行的定义

| 情况 | 行数 |
|------|------|
| `hello\nworld\n` | 2 |
| `hello\nworld` | 1（最后一行无 `\n` 不计入） |
| `\n\n\n` | 3（空行也是行） |
| 空输入 | 0 |

K&R 的逻辑是"见到 `\n` 计一行"，最后一行没换行符就不算。

### 字符常量 vs 字符串

```c
'\n'   /* 字符常量，int 类型，值为 10 */
"\n"   /* 字符串，char[2]，内容 {10, 0} */
```

`c == '\n'` 比较两个 `int`；`c == "\n"` 比较字符和指针——编译器会警告，逻辑错误。

## HFT 关联

行计数是文本协议解析的基础。FIX 协议以 `\n` 或 `SOH`(0x01) 分隔字段，解析器和这里数行逻辑一样——逐字节扫描找分隔符。

## 常见坑

1. **`'\n'` 写成 `"\n"`**：单引号是字符，双引号是字符串（指针）。`c == "\n"` 比较的是字符值和指针地址，永远不相等。
2. **`'/n'` 斜杠方向错**：`/n` 不是转义字符，是两个字符 `/` 和 `n`。
3. **最后一行无换行符**：K&R 的算法不计入最后一行。如果要精确计数，需在 EOF 后检查最后一个字符是否非 `\n`。

## 自测题

1. 输入 `abc\ndef\n`，`nl` 最终是多少？
<details><summary>答案</summary>

2。两个 `\n`，计两行。

</details>

2. 输入 `abc\ndef`（结尾无换行），`nl` 是多少？
<details><summary>答案</summary>

1。只见到一个 `\n`。最后一行 `def` 没有换行符，不计入。

</details>

3. `c == '\n'` 和 `c == "\n"` 有什么区别？
<details><summary>答案</summary>

`'\n'` 是字符常量（int 值 10），比较两个整数。`"\n"` 是字符串字面量（char 指针），比较字符和指针地址——逻辑错误，编译器会警告 `comparison between pointer and integer`。

</details>

4. 如何修改程序，让最后一行无换行符时也计入？
<details><summary>答案</summary>

EOF 后检查最后读到的字符是否非 `\n`：

```c
int c, nl = 0, last = 0;
while ((c = getchar()) != EOF) {
    if (c == '\n') ++nl;
    last = c;
}
if (last != '\n' && last != 0) ++nl;  /* 最后一行无换行符 */
```

</details>
