# 1.5.3 行计数

## 本节讲什么

统计文本**行数**：把换行符 `\n` 作为行的分隔标记。

## 要点

- 每读到 `'\n'`，行计数加一 —— **行不是库读出来的，是你在字符流里识别 `\n` 数出来的**（对比 `fgets` 一次读一行；本节用 `getchar` 刻意练底层流式逻辑，见 [1.5 总述](./1.5-字符输入输出.md)）
- 最后一行若无换行符，是否算一行取决于题意；K&R 按「见到 `\n` 计一行」
- 与 1.5.2 相同框架，仅增加对 `\n` 的判断

## 示例

```c
nl = 0;
while ((c = getchar()) != EOF)
    if (c == '\n')
        ++nl;
printf("%d\n", nl);
```

---

## 代码自测

**题目 1：** 以下行计数程序统计的是什么？
```c
int c, nl = 0;
while ((c = getchar()) != EOF)
    if (c == '\n') nl++;
printf("%d\n", nl);
```

<details>
<summary>参考答案</summary>

统计换行符 `\n` 的数量。注意：如果最后一行没有换行符，这行不会被计入。`\n` 是字符常量（值为 10），用单引号。常见错误是用双引号 `"\n"`（字符串）或 `'/n'`（斜杠方向错）。

</details>
