# 1.5.4 单词计数

## 本节讲什么

统计输入的单词数——以空格、制表符、换行符为分隔。这是 K&R 引入**状态机**的第一个例子：需要记住"当前是否在单词内部"。

## 核心代码

```c
#define IN  1   /* 在单词内部 */
#define OUT 0   /* 在单词外部 */

int c, nl, nw, nc, state;

state = OUT;
nl = nw = nc = 0;
while ((c = getchar()) != EOF) {
    ++nc;
    if (c == '\n')
        ++nl;
    if (c == ' ' || c == '\n' || c == '\t')
        state = OUT;
    else if (state == OUT) {
        state = IN;
        ++nw;
    }
}
printf("%d %d %d\n", nl, nw, nc);
```

### 逐行解析

| 代码 | 作用 |
|------|------|
| `#define IN 1` | 符号常量，比直接写 1 可读 |
| `state = OUT` | 初始状态：在单词外 |
| `c == ' ' \|\| c == '\n' \|\| c == '\t'` | 空白字符判断 |
| `state = OUT` | 遇到空白，标记离开单词 |
| `else if (state == OUT)` | 非空白且之前在单词外 → 进入新单词 |
| `state = IN; ++nw;` | 标记进入单词，计数加一 |

### 状态机图解

```
          遇到空白              遇到非空白
     ┌──────────────┐    ┌──────────────┐
     │              ↓    │              ↓
     │         ┌─────────┐         ┌─────────┐
     │         │  OUT    │────────→│   IN    │
     │         │ (单词外) │  非空白  │ (单词内) │
     │         └─────────┘         └─────────┘
     │              ↑                   │
     └──────────────┘                   │
              遇到空白                   │
                                   遇到非空白（已在单词内）
                                   → 不变，继续读字符
```

关键：**只在 OUT→IN 转换时 `++nw`**。连续空白不会误计，连续字母不会重复计。

### 为什么不用 `isspace()`

K&R 用 `c == ' ' || c == '\n' || c == '\t'` 手动判断。标准库 `isspace(c)` 功能相同且更完整（还覆盖 `\r`、`\f`、`\v`），但 K&R 此时还没介绍 `<ctype.h>`。

### 和前几节的关系

| 节 | 统计什么 | 循环条件 | 额外逻辑 |
|----|---------|---------|---------|
| 1.5.1 | 不统计，只复制 | `!= EOF` | 无 |
| 1.5.2 | 字符数 | `!= EOF` | `++nc` |
| 1.5.3 | 行数 | `!= EOF` | `if (c=='\n') ++nl` |
| 1.5.4 | 行+词+字符 | `!= EOF` | 状态机 `state` + 三路计数 |

框架不变，逻辑逐步加层。这是 K&R 的教学节奏。

## HFT 关联

状态机是协议解析的核心模式。FIX 协议解析器、二进制行情解码器都用类似结构：逐字节扫描，根据当前状态决定如何处理字节。`IN/OUT` 状态对应"正在解析一个字段 / 字段间分隔符"。

## 常见坑

1. **`++nw` 放错位置**：放在 `if (c == ' ' ...)` 分支里会数空白数而不是单词数。必须放在 `else if (state == OUT)` 里——只在进入单词时计数。
2. **初始化 `state`**：忘记 `state = OUT` 会导致第一段文本不被计入（如果 `state` 恰好不是 OUT）。
3. **连续空白**：`"hello   world"` 三个空格，状态机只在第一个空格 OUT，后两个空格已经是 OUT 不变——不会误计。

## 自测题

1. 输入 `"hello  world\n"`（两个空格），`nw` 是多少？
<details><summary>答案</summary>

2。`hello` 进入时 +1，`world` 进入时 +1。中间两个空格只是把 state 设为 OUT 两次，不影响计数。

</details>

2. 如果删掉 `else`，写成两个独立 `if`，会怎样？
<details><summary>答案</summary>

```c
if (c == ' ' || ...) state = OUT;
if (state == OUT) { state = IN; ++nw; }  /* 没有 else */
```

遇到空白时：第一个 if 设 OUT，第二个 if 立刻发现 OUT 又设 IN 并 +1。每个空白字符都被计为一个单词——完全错误。`else` 保证只有"非空白且之前在单词外"才计数。

</details>

3. `#define IN 1` 和 `int IN = 1` 有什么区别？
<details><summary>答案</summary>

`#define` 是预处理宏，编译前文本替换，不占内存，不可调试（调试器看不到符号名）。`int IN = 1` 是变量，占内存，可调试，但每次使用要读内存。K&R 用 `#define` 因为这里不需要变量特性。

</details>

4. 如何修改程序让它也统计 `\r`（Windows 换行）？
<details><summary>答案</summary>

在空白判断中加 `\r`：

```c
if (c == ' ' || c == '\n' || c == '\t' || c == '\r')
    state = OUT;
```

或者直接用 `isspace(c)`（需要 `#include <ctype.h>`）。

</details>
