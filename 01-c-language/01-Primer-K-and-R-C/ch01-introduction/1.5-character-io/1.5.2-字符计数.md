# 1.5.2 字符计数

## 本节讲什么

在复制循环上累加计数器，统计输入中的字符总数（含换行等所有读到的字符）。

## 要点

- 循环不变量：每读到一个非 EOF 字符，`nc` 加一
- 结束后用 `printf` 输出计数；大文件也只需 O(1) 额外空间

## 示例

```c
nc = 0;
while ((c = getchar()) != EOF)
    ++nc;
printf("%ld\n", nc);
```

（`long` 计数避免溢出；K&R 示例中类型随平台调整。）

---

## 代码自测

**题目 1：** 以下代码用 `long` 计数，如果字符数超过 `LONG_MAX` 会怎样？
```c
long nc = 0;
while (getchar() != EOF) nc++;
printf("%ld\n", nc);
```

<details>
<summary>参考答案</summary>

溢出——`nc` 超过 `LONG_MAX` 后回绕为负数，计数错误。对于大文件应使用 `long long`（C99）或 `int64_t`。这是整型溢出的经典案例。

</details>
