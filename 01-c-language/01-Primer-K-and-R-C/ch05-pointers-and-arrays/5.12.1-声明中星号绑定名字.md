# 5.12.1 声明里的 `*`：不绑定类型、绑定名字（精炼）

> **declaration mimics use**：声明怎么写，将来使用表达式就怎么写。  
> 详解：[5.12](./5.12-复杂声明.md) · [2.4 声明](../ch02-types-operators-expressions/2.4-声明.md) · argv：[1.1.1](../ch01-introduction/1.1.1-命令行参数-main-argc-argv.md)

---

## 0. 边界一句话（勿走极端）

**理解方向对，但要划严谨：**

| 层 | 结论 |
|----|------|
| **源码声明语法** | 不能把 `char*` / `int*` 当成**不可分割的拼写单元**；`*` **依附声明符（名字）**，不是和 `char`/`int` 绑成一体 |
| **类型语义 / 口语** | 编译器里确有 *pointer to char*；日常说「类型是 `char *`」完全可以 |

修正口误：  
❌「char 跟星在严格语法里绝对不能放一起做说明」  
✅「**声明语法解析**时不能把 `char*` 当原子单元；**讨论类型**时可以说 `char *` = 指向 char 的指针」

习惯：写 `int *a`，少写 `int* a`，减少视觉误导。

---

## 1. 语法本源：`*` 修饰名字

```c
int *p;
/* 将来 *p = 10; → *p 是 int → p 是「指向 int 的指针」 */
```

不要看成 `(int *) p`。C 声明语法里**没有**名为 `int*` 的原子类型单元。

### 铁证

```c
int* a, b;    /* 等价理解：只有 a 带 *；b 是普通 int */
int *a, *b;   /* 两个都是指针 */
```

若 `int*` 是完整独立类型，`b` 也该是指针——现实不是。  
→ **`*` 绑定变量名，不绑定前面的基础类型名。**

---

## 2. 两层勿混

| 层 | 用途 |
|----|------|
| 语法书写（啃标准 / 笔试） | 禁止把 `char*` 当整体解析；牢记 `*` 修饰变量 |
| 类型语义 / 工程交流 | 「`p` 是 `char *` / pointer to char」完全没问题 |

否定的是：「语法上 `char*` 是不可分割单元」。  
**没有否定**：存在「指向 char 的指针」这种类型。

---

## 3. `typedef` 是特例（勿与上混比）

```c
typedef char *CharPtr;
CharPtr a, b;   /* a、b 全是指针 */
```

`typedef` 给**完整类型语义**起别名；之后 `CharPtr a, b` 两个都是该类型。  
这和「原生声明里 `*` 跟名字」**不是同一套规则**，不要拿来反驳第 1 节。

---

## 4. 套到 `char *argv[]` / `char **argv`

`argv` 是数组；每项 *pointer to char*；`*(argv[i])` → `char`。自洽。

形参 `char *argv[]` ≡ `char **argv`：

| 表达式 | 概念类型 |
|--------|----------|
| `argv` | pointer to pointer to char |
| `*argv` / `argv[0]` | pointer to char |
| `**argv` / `argv[0][0]` | `char` |

```
argv ──→ [ char* | char* | ... | NULL ]
              └──→ "app\0"
```

## 5. 自测

1. `int* x, y;` 里 `y`？→ **`int`**。  
2. `typedef int *Ip; Ip x, y;` 里 `y`？→ **指针**（别名特例）。  
3. 口语「`argv[i]` 类型是 `char *`」和「语法上 `char*` 不是原子单元」冲突吗？→ **不冲突**（语义层 vs 语法层）。

## 代码自测

**题目 1：** 以下声明中 p2 和 p3 的类型分别是什么？为什么？
```c
int *p1, p2, p3;
```

<details>
<summary>参考答案</summary>

p1 是 int*（指针），p2 和 p3 都是 int（不是指针）。C 声明中 * 绑定到变量名而非类型名——int *p1, p2, p3 等价于 int (*p1), p2, p3。如果要声明三个指针，必须写 int *p1, *p2, *p3;。这是 C 声明语法最经典的陷阱。

</details>
