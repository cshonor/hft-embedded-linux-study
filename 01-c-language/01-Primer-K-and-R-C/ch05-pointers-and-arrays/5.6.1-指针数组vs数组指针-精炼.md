# 5.6.1 指针数组 vs 数组指针（精炼）

> 口诀：**看括号；`()` / `[]` 优先于 `*`**  
> - 名先跟 `[]` → **指针数组**（数组，元素是指针）  
> - `(*名)` 先绑定 → **数组指针**（指针，指向一整块数组）  
> 详解正文：[5.6](./5.6-指针数组以及指向指针的指针.md) · 联动 [1.1.1 argv](../ch01-introduction/1.1.1-命令行参数-main-argc-argv.md) · [5.10](./5.10-命令行参数.md)

---

## 1. 指针数组：`char *argv[]`（元素 = `char *`）

```c
char *argv[];   /* [] 优先 → 数组；每一项元素类型是 char * */
```

| 层 | 类型 | |
|----|------|--|
| `argv[i]` | `char *` | 指向某个 `\0` 结尾字符串 |
| 形参里的 `argv` | `char **` | 指向首个 `char *` 槽位 |

```
argv[0] (char*) → "app"
argv[1] (char*) → "input"
argv[2] (char*) → NULL
```

❌ 不是 `char argv[][]`（连续字符矩阵）；✔ 是指针表，串可分散。  
`main` 形参中 `char *argv[]` ≡ `char **argv`（**语法糖，不是在栈上开数组**）。  
普通局部 `char *a[];` **非法**；须 `char *a[] = {...};` 或给定长度。
---

## 2. 数组指针：`char (*p)[N]`

```c
char (*p)[128];   /* (*p) 先绑定 → p 是指针；指向 char[128] */
```

```c
char buf[128] = "hello";
char (*p)[128] = &buf;   /* 必须 &buf：类型是 pointer-to-array */
/* *p 相当于整数组；(*p)[i] / p[0][i] 访问元素 */
```

---

## 3. 对比表

| 写法 | 名称 | 本质 |
|------|------|------|
| `char *p[N]` | 指针数组 | **数组**；元素 `char *` |
| `char (*p)[N]` | 数组指针 | **指针**；指向 `char[N]` |

易混：`int *a[5]` = 指针数组；`int (*a)[5]` = 数组指针。

---

## 4. 与 `main` / argv

```c
char *argv[];     /* ✔ 指针数组（标准 main 形参） */
char (*argv)[];   /* ✘ 数组指针，不能当 main 参数用 */
```

---

## 5. 自测

1. `int (*parr)[10];` → **数组指针**（指向 `int[10]`）。  
2. `int *parr[10];` → **指针数组**（10 个 `int *`）。  
3. 为何赋值要用 `&数组名`？  
   → 裸数组名退化成 **`T *`（首元素指针）**；数组指针要 **`T (*)[N]`**，只有 `&arr` 类型匹配（无强制转换时）。

## 代码自测

**题目 1：** 以下两种声明有什么区别？
```c
int *a[10];     // A
int (*b)[10];   // B
```

<details>
<summary>参考答案</summary>

A 是指针数组——10 个 int* 元素的数组。B 是数组指针——一个指向 int[10] 数组的指针。判断方法：[] 优先级高于 *，所以 a 先和 [10] 结合是数组。(*b) 中括号让 b 先和 * 结合是指针。sizeof(a) = 10*sizeof(int*) = 80, sizeof(b) = sizeof(int(*)[10]) = 8。

</details>
