# 7.8.7 随机数发生器函数

## 本节讲什么

**`rand()`** 返回伪随机整数；**`srand(seed)`** 设种子。非密码学安全，适合仿真、测试、负载抽样。

## 要点

```c
srand((unsigned)time(NULL));
int r = rand() % N;   /* 0..N-1，% 有轻微偏差 */
```

- 周期与质量实现相关；**不要**用于安全/token
- C99 **`random()`** / **`srandom()`**（部分系统）质量更好
- 需要可重复测试：**固定 seed**

## 与 HFT / 回测

- 回测用固定 seed 复现随机成交
- 生产撮合随机性用硬件 RNG 或专用库，非 `rand()`

## 与后续衔接

Monte Carlo 仿真、 fuzz 测试入门；密码学见 `<stdint.h>` + OS 接口。

## 代码自测

**题目 1：** 以下代码生成的随机数有什么问题？
```c
srand(42);
for (int i = 0; i < 10; i++)
    printf("%d\n", rand() % 100);
```

<details>
<summary>参考答案</summary>

1) `srand(42)` 固定种子——每次运行产生相同的序列。如果需要不可预测的随机数，用 `srand(time(NULL))`。2) `rand() % 100` 有模偏差——`RAND_MAX` 可能不是 100 的倍数，导致低位数字出现频率更高。3) `rand()` 质量低（线性同余），不适合加密或科学计算。C11 的 `arc4random` 或自行实现 Mersenne Twister 更好。

</details>
