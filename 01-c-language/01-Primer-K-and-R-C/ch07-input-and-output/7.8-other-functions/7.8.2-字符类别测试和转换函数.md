# 7.8.2 字符类别测试和转换函数

## 本节讲什么

**`<ctype.h>`** 按字符属性分类与转换，解析文本协议、lexer、配置文件时常用。

## 要点

| 函数 | 含义 |
|------|------|
| `isalpha(c)` | 字母 |
| `isdigit(c)` | 数字 |
| `isspace(c)` | 空白（空格、`\t`、`\n` 等） |
| `isalnum` `isupper` `islower` | 组合/大小写 |
| `tolower(c)` `toupper(c)` | 转换 |

- 参数为 **`int`**，须为 **`unsigned char`** 值或 **`EOF`**
- 对 **`char`** 先转 **`unsigned char`** 再传入，避免负值 `char` 越界表访问

## 示例

```c
while (isspace(*p))
    p++;
if (isdigit(*p))
    /* 解析数字 */
```

## 代码自测

**题目 1：** 以下代码有什么问题？
```c
char c = getchar();
if (c >= 'A' && c <= 'Z')  // 判断大写字母
    c = c + 32;             // 转小写
```

<details>
<summary>参考答案</summary>

1) 假设 ASCII 编码——EBCDIC 平台上字母不连续。2) `c` 可能是 EOF（如果声明为 char）。用标准库函数更安全：
```c
int c = getchar();
if (isupper(c))
    c = tolower(c);
```
`isupper`/`tolower` 是可移植的，且正确处理负数参数（EOF 不触发）。注意：`tolower` 的参数应为 `int` 且值为 `unsigned char` 范围或 EOF。

</details>
