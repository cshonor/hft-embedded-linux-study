# 7.8.2 字符类别测试和转换函数

## 本节讲什么

**`<ctype.h>`** 按字符属性分类与转换，解析文本协议、lexer、配置文件时常用。

## 要点

| 函数 | 含义 |
|------|------|
| `isalpha(c)` | 字母 |
| `isdigit(c)` | 数字 |
| `isspace(c)` | 空白（空格、`\t`、`\n` 等） |
| `isalnum` `isupper` `islower` | 组合/大小写 |
| `tolower(c)` `toupper(c)` | 转换 |

- 参数为 **`int`**，须为 **`unsigned char`** 值或 **`EOF`**
- 对 **`char`** 先转 **`unsigned char`** 再传入，避免负值 `char` 越界表访问

## 示例

```c
while (isspace(*p))
    p++;
if (isdigit(*p))
    /* 解析数字 */
```

## 与后续衔接

手写 `scanf` 替代、JSON/CSV 轻量解析、编译器词法分析的基础工具。

## 常见陷阱

### 1. 传 `char`（非 `unsigned char`）给 `is*` 函数 — 负值越界

```c
char c = '\xff';   // signed char 时 c = -1
if (isalpha(c))    // ❌ UB — isalpha 用 c 做下标查表，-1 越界
    /* ... */;
```

`<ctype.h>` 函数的参数必须是 `unsigned char` 值或 `EOF`。`char` 在多数平台是 `signed`，高位字符（128-255）变成负数，用作查表下标时越界。修正：

```c
if (isalpha((unsigned char)c))   // ✓
```

### 2. `tolower`/`toupper` 返回 `int`，不是原地修改

```c
char c = 'A';
tolower(c);       // ❌ c 不变！返回值被丢弃
c = tolower(c);   // ✓ 接收返回值
```

这两个函数**不修改参数**，返回转换后的值。忘记接收返回值是常见错误。

### 3. 手写 ASCII 算术转换不移植

```c
if (c >= 'A' && c <= 'Z')
    c = c + 32;    // ❌ 假设 ASCII 编码
```

EBCDIC 平台上字母不连续，`'A'` 到 `'Z'` 之间夹着非字母字符。`isupper`/`tolower` 是可移植的，内部用查找表而非算术运算。即使确定用 ASCII，也应：

```c
if (isupper((unsigned char)c))
    c = tolower((unsigned char)c);
```

### 4. 链式调用不检查 EOF

```c
int c = getchar();
char lower = tolower(c);  // c 可能是 EOF(-1)
```

`tolower(EOF)` 行为未定义（EOF 不是有效的 `unsigned char` 值）。先检查 EOF：

```c
int c = getchar();
if (c != EOF)
    c = tolower(c);
```

## 代码自测

**题目 1：** 以下代码有什么问题？
```c
char c = getchar();
if (c >= 'A' && c <= 'Z')  // 判断大写字母
    c = c + 32;             // 转小写
```

<details>
<summary>参考答案</summary>

1) 假设 ASCII 编码——EBCDIC 平台上字母不连续。2) `c` 可能是 EOF（如果声明为 char）。用标准库函数更安全：
```c
int c = getchar();
if (isupper(c))
    c = tolower(c);
```
`isupper`/`tolower` 是可移植的，且正确处理负数参数（EOF 不触发）。注意：`tolower` 的参数应为 `int` 且值为 `unsigned char` 范围或 EOF。

</details>

**题目 2：** 以下代码的 bug 是什么？
```c
char c = '\xff';
if (isdigit(c))
    printf("digit\n");
```

<details>
<summary>参考答案</summary>

`char` 在多数平台是 `signed`，`\xff` = -1。`isdigit(-1)` 是未定义行为——函数内部用参数做下标查查找表，-1 越界。可能崩溃或返回错误结果。修正：`isdigit((unsigned char)c)`，将 255 而非 -1 传入。EOF(-1) 是唯一合法的负值参数，其他负值都是 UB。

</details>

**题目 3：** 以下代码能正确转小写吗？
```c
char s[] = "Hello World";
for (int i = 0; s[i]; i++)
    tolower(s[i]);
printf("%s\n", s);  // 输出？
```

<details>
<summary>参考答案</summary>

输出 `Hello World`——不变。`tolower` 返回转换后的值，**不修改参数**。代码丢弃了返回值。修正：
```c
for (int i = 0; s[i]; i++)
    s[i] = tolower((unsigned char)s[i]);
```
注意也要加 `(unsigned char)` 转换防止负值。

</details>

**题目 4：** `isspace('\t')` 和 `isspace(' ')` 都返回真，还有哪些字符 `isspace` 返回真？

<details>
<summary>参考答案</summary>

`isspace` 对 6 种标准空白字符返回非零：`' '`（空格, 0x20）、`'\t'`（水平制表, 0x09）、`'\n'`（换行, 0x0A）、`'\v'`（垂直制表, 0x0B）、`'\f'`（换页, 0x0C）、`'\r'`（回车, 0x0D）。手写 `c == ' ' || c == '\t' || c == '\n'` 常常漏掉 `\v`、`\f`、`\r`，导致解析器在遇到这些字符时出错。

</details>
