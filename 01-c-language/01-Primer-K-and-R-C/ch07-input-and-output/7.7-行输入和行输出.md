# 7.7 行输入和行输出

## 本节讲什么

**`fgets`/`fputs`** 按行读写文本；**`gets`** 已废弃。安全读配置、日志行、协议文本行的首选 stdio 方式。

## 要点

### fgets

```c
char line[256];
if (fgets(line, sizeof line, fp) != NULL) {
    /* line 含内容，可能含 '\n' */
}
```

- 最多读 **`size-1`** 个字符，保留 **`'\0'`**
- 遇 **`'\n'`** 或 EOF 停止；**超长行保留 `\n` 并截断**
- 返回值：`NULL` 表示 EOF 且无数据读入，或出错

### fputs

```c
fputs(line, fp);   /* 不自动追加换行 */
```

- 与 **`fputs(str, stdout)`** 输出一行（若 `str` 已含 `\n`）

### 避免 gets

- **`gets(buf)`** 无长度限制 → **永远不要用**
- 替代：`fgets` 或 POSIX **`getline`**

## 示例：读配置

```c
while (fgets(line, sizeof line, cfg) != NULL) {
    if (line[0] == '#' || line[0] == '\n')
        continue;
    /* sscanf 或手工解析 */
}
```

## 与后续衔接

文本协议「一行一条」；二进制 tick 用 7.5 `fread`。嵌入式配置文件、串口 AT 指令行常用 `fgets` 模式。

## 常见陷阱

1. **fgets 保留 `\n`，忘记去除行尾换行**：`fgets(buf, 100, fp)` 读入的行**包含** `\n`（如果缓冲够大）。直接用 `strcmp(buf, "quit")` 比较会失败——因为 buf 是 `"quit\n"` 而非 `"quit"`。修复：`buf[strcspn(buf, "\n")] = '\0';` 去掉换行。或者用 `strcmp(buf, "quit\n")` 但不通用。

2. **超长行被 fgets 截断但无错误指示**：`fgets(buf, 10, fp)` 读一个 100 字符的行——只读 9 个字符（+`\0`），返回非 NULL（成功），但行未读完。下次 fgets 继续读同一行的剩余部分。如果不检查 fgets 是否读到了 `\n`，可能把一行误当成多行。检查：`if (strchr(buf, '\n') == NULL) { /* 行被截断，需继续读 */ }`。

3. **fputs 不加换行，输出连成一行**：`fputs("hello", fp); fputs("world", fp);` 输出 `helloworld`。与 `puts`（自动加 `\n`）不同，`fputs` 原样输出不加换行。如果需要每行一个 `\n`，必须手动 `fputs("hello\n", fp)` 或 `fputc('\n', fp)`。这是 puts 和 fputs 的关键区别。

## 自测题

**1. 选择**：`fgets(buf, 10, fp)` 读一个 50 字符的行，返回值和 buf 内容是？
- A. 返回 NULL，buf 未修改
- B. 返回 buf，buf 含 9 个字符 + `\0`（不含 `\n`）
- C. 返回 buf，buf 含 50 个字符
- D. 返回 NULL，buf 含 9 个字符

<details><summary>答案</summary>
B。fgets 最多读 `size-1`（=9）个字符。50 字符的行只读前 9 个，buf = `"123456789\0"`（无 `\n`），返回值是 buf（非 NULL，表示成功读取）。剩余 41 字节留在流中，下次 fgets 继续读。检查 buf 是否含 `\n` 可以判断一行是否读完：`if (strchr(buf, '\n') == NULL) { /* 行被截断 */ }`。
</details>

**2. 判断**：`puts(str)` 和 `fputs(str, stdout)` 完全等价。

<details><summary>答案</summary>
错。`puts(str)` 在输出字符串后**自动追加 `\n`**，`fputs(str, stdout)` **不加换行**。`puts("hi")` 输出 `hi\n`，`fputs("hi", stdout)` 输出 `hi`。如果需要换行，`fputs` 要手动加。另外 `puts` 只能输出到 stdout，`fputs` 可以输出到任意 `FILE*`。实践中推荐用 `fputs` + 手动 `\n`，行为更明确。
</details>

**3. 踩坑**：以下代码比较用户输入与 "quit"，但永远不匹配，为什么？
```c
char input[100];
fgets(input, sizeof input, stdin);
if (strcmp(input, "quit") == 0)
    break;
```

<details><summary>答案</summary>
fgets 保留行尾 `\n`，所以 input 是 `"quit\n"` 而非 `"quit"`，`strcmp` 不等。修复：`input[strcspn(input, "\n")] = '\0';` 去掉换行后再比较。`strcspn(input, "\n")` 返回 `\n` 在 input 中的位置（如果有的话），将其替换为 `\0`。这是处理 fgets 输入的标准套路。
</details>

**4. 应用**：写一个 `read_line` 函数——用 fgets 安全读取一行，自动去除 `\n`，处理超长行（丢弃超出部分），返回行长度。

<details><summary>答案</summary>
```c
int read_line(FILE *fp, char *buf, int size) {
    if (fgets(buf, size, fp) == NULL)
        return -1;  /* EOF 或出错 */

    int len = strlen(buf);
    if (len > 0 && buf[len-1] == '\n') {
        buf[len-1] = '\0';   /* 去掉换行 */
        return len - 1;
    }

    /* 行被截断（buf 满了但无 \n），丢弃剩余 */
    if (len == size - 1) {
        int c;
        while ((c = fgetc(fp)) != '\n' && c != EOF)
            ;
    }
    return len;
}
```
关键：fgets 返回值检查、`\n` 去除、超长行处理（读取并丢弃剩余字符直到 `\n` 或 EOF）。这是文本处理的基础工具函数。
</details>
