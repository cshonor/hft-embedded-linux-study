# 8.1.1 数组名

## 本节讲什么

**数组名**在表达式中的精确含义：通常退化为首元素地址，但有三个例外。`&a` 和 `a` 数值常相同但类型不同——这是多维数组指针运算正确性的前提。

## 要点

```c
int a[10];
int *p = a;      /* a 退化为 &a[0] */
```

| 表达式 | 类型 | 含义 |
|--------|------|------|
| `a`（一般表达式） | `int *` | 首元素地址 `&a[0]` |
| `sizeof(a)` | `size_t` | 整个数组字节 `10*sizeof(int)` |
| `&a` | `int (*)[10]` | 指向整个数组的指针 |
| `&a[0]` | `int *` | 首元素地址 |

- **`&a`** 与 **`a`** 数值常相同（都是数组起始地址），**类型不同**
- `&a` 类型 `int (*)[10]`：`+1` 跳整个数组（10 个 int）
- `a` 退化后类型 `int *`：`+1` 跳一个 int

### 三种语义对比

```c
int a[10];
printf("%p %p %p\n", (void *)a, (void *)&a[0], (void *)&a);
/* 三者数值相同 */
printf("%zu %zu\n", sizeof(a), sizeof(&a));
/* 40（数组） vs 8（指针） */
printf("%p %p\n", (void *)(a + 1), (void *)(&a + 1));
/* a+1 跳 4 字节；&a+1 跳 40 字节（整个数组后） */
```

## 底层映射

### 为什么数值相同类型不同

数组在内存里是一段连续空间，起始地址只有一个。`a`、`&a[0]`、`&a` 都指向这个起始字节——所以数值相同。差异在"指针算术的步长"：步长由类型决定（**ch06 6.13.1**）。

```
地址:    0x1000        0x1004        0x1008        ...
内容:    a[0]          a[1]          a[2]          ...
         ↑             ↑
         a, &a[0], &a  a+1
                                     &a+1 = 0x1028（跳 40 字节，整个数组后）
```

### 汇编视角

```c
int a[10];
int *q = a;          /* 退化：lea rax, [rsp] */
int x = a[3];        /* 退化后 [rsp+12] */
size_t n = sizeof(a);/* 编译期常量 40，无指令 */
```

```
lea     rax, [rsp]            ; q = &a[0]（数组首地址）
mov     DWORD PTR [rsp+8], eax; 存 q
mov     eax, DWORD PTR [rsp+12]; x = a[3]，编译期算偏移
mov     QWORD PTR [rsp+16], 40; n = 40，立即数
```

`sizeof(a)` 是编译期常量，根本不生成访存指令——这就是"不退化"的体现：编译器知道 `a` 是 10 元数组。

## HFT / DPDK

| 用法 | 要点 |
|------|------|
| 传首地址 | `f(a)` 退化为 `&a[0]` |
| 整数组大小 | `sizeof(a)` 仅在定义域有效 |
| 尾后指针 | `&a + 1` 或 `a + 10`，合法比较不可解引用 |
| `memcpy` | `memcpy(dst, a, sizeof(a))` 整数组拷贝 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "`&a` 和 `a` 是一回事" | 数值相同，类型不同，`+1` 步长差 10 倍 |
| "`sizeof(a)` 在函数内能拿数组大小" | 退化后是指针，拿到 8 |
| "数组名能赋值 `a = b`" | 非法，数组不可整体赋值 |
| "`&a + 1` 越界" | 合法形成（one-past-end），但不可解引用 |

## 实操

```bash
# 打印 a, &a[0], &a 的值与 a+1, &a+1 的步长差
cat > t.c << 'EOF'
#include <stdio.h>
int main(void) {
    int a[10];
    printf("a=%p &a[0]=%p &a=%p\n",(void*)a,(void*)&a[0],(void*)&a);
    printf("a+1=%p &a+1=%p\n",(void*)(a+1),(void*)(&a+1));
    printf("sizeof(a)=%zu sizeof(&a)=%zu\n",sizeof(a),sizeof(&a));
    return 0;
}
EOF
gcc t.c -o t && ./t
# 汇编看 sizeof(a) 是立即数
gcc -O2 -S t.c -o - | grep -i 'mov.*40'
```

## 代码自测

**题目 1：** 以下代码能编译吗？为什么？
```c
int arr[5] = {1, 2, 3, 4, 5};
arr++;
```

<details>
<summary>参考答案</summary>

不能编译。数组名不是可修改的左值——它是地址常量（指向数组首元素），不能被赋值或自增。数组名虽然可以隐式转换为指针使用，但它本身不是指针变量。如果想遍历数组，需要用单独的指针变量：int *p = arr; p++;。

</details>
