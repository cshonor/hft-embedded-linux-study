# 8.1.6 作为函数参数的数组名

## 本节讲什么

数组作实参时**退化为指针**——形参收到的是**地址副本**，不是数组对象。这是 C 数组接口"必须传长度"的根因，也是 `sizeof(arr)` 在函数内失效的根源。

## 要点

```c
void f(int arr[], int n);   /* 形参 arr 退化为 int* */
void f(int *arr, int n);    /* 等价写法 */
```

- 函数内 **`sizeof(arr)` == `sizeof(int*)`**（通常 8），不是数组总字节
- **必须**另传 **`n`** 或约定 `\0` 结尾（字符串，**ch09**）
- 修改 `arr[i]` 会改调用者数组（同一内存，传的是地址）

```c
void fill(int arr[], int n) {
    for (int i = 0; i < n; i++) arr[i] = i;
    sizeof(arr);          /* 8，不是 n*4 */
}

int a[100];
fill(a, 100);              /* a 退化为 &a[0]，传地址副本 */
```

### 值传递的是指针副本

C 一律值传递（**ch07 7.3**）——传数组时，退化出的 `&a[0]` 被拷贝一份给形参 `arr`。`arr` 和 `a` 指向同一块内存，所以 `arr[i] = x` 改的是调用者的 `a[i]`。但改 `arr` 本身（`arr++`）不影响 `a`。

## 底层映射

### ABI 寄存器传参

```c
void fill(int *arr, int n) { ... }
```

```
; x86-64 SysV ABI
; arr → rdi（指针，8 字节）
; n   → esi（int，4 字节）
fill:
    mov     DWORD PTR [rdi + rcx*4], ecx   ; arr[i] = i
    ...
```

只传了 8 字节地址 + 4 字节长度，不拷贝整个数组。这是为什么传大数组几乎零开销——但代价是丢了大小信息。

### DPDK burst 的退化

```c
void handle(struct rte_mbuf *pkts[], uint16_t nb);
/* pkts 是 struct rte_mbuf *[32]，退化为 struct rte_mbuf ** */
```

`pkts[32]` 传参后变成 `struct rte_mbuf **`——指针的指针。函数内 `pkts[i]` 取第 i 个 mbuf 指针。

## HFT / DPDK

| 接口 | 退化后类型 |
|------|-----------|
| `void f(int arr[], int n)` | `int *arr` |
| `void g(struct mbuf *pkts[], int n)` | `struct mbuf **pkts` |
| `void h(char buf[2048])` | `char *buf` |

### 工程纪律

- 数组参数**必带长度参数**（`size_t n` 或 `uint16_t nb`）
- 只读加 `const`：`void f(const int *arr, size_t n)`
- 改调用者数组靠 `arr[i] =`（同内存）
- 不要在函数内 `sizeof(arr)` 试图拿数组大小

## 常见误区

| 误区 | 事实 |
|------|------|
| "`void f(int arr[100])` 能限定长度" | 不能，退化为指针，100 被忽略 |
| "函数内 sizeof(arr) 是数组大小" | 是指针大小 8 |
| "传数组是值拷贝整个数组" | 只拷贝地址，不拷贝元素 |
| "arr[i]= 改的是副本" | 改的是调用者原数组 |

## 实操

```bash
# 看函数内 sizeof(arr) 失效
cat > t.c << 'EOF'
#include <stdio.h>
void f(int arr[100]) { printf("in f: %zu\n", sizeof(arr)); }
int main(void) { int a[100]; printf("in main: %zu\n", sizeof(a)); f(a); return 0; }
EOF
gcc t.c -o t && ./t    # main: 400, f: 8
# 看退化后 arr 是指针
gcc -O2 -S t.c -o - | grep -A3 '^f:'
```

## 代码自测

**题目 1：** 以下函数中 sizeof(arr) 的值是多少？
```c
void process(int arr[100]) {
    printf("%d\n", (int)sizeof(arr));
}
```

<details>
<summary>参考答案</summary>

输出指针大小（4 或 8 字节），而不是 400。在函数参数中，数组声明 int arr[100] 会被编译器调整为 int *arr——数组参数实际上是指针参数。sizeof(arr) 得到的是指针大小。这就是为什么函数内无法用 sizeof 获取数组长度——必须另外传长度参数。

</details>
