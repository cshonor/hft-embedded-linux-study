# 8.1.10 计算数组长度

## 本节讲什么

**编译期**数组元素个数：`sizeof` 技巧；传参后**不可用**。这是 C 工程里最常见的宏 `ARRAY_SIZE` 的原理与局限。

## 要点

```c
int arr[10];
size_t n = sizeof(arr) / sizeof(arr[0]);   /* 10 */

void f(int arr[]) {
    /* sizeof(arr)/sizeof(arr[0]) 错误 → 得指针大小/元素大小 */
}
```

- `sizeof(arr)` 整个数组字节；`sizeof(arr[0])` 单元素字节；相除得元素个数
- **仅用于真实数组对象**，传参退化后失效（**8.1.6**）
- 宏 `ARRAY_SIZE(a)` = `sizeof(a)/sizeof((a)[0])`，**仅用于非退化数组**

### 内核 / DPDK 宏

```c
/* Linux 内核 */
#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))

/* DPDK */
#define RTE_DIM(a) (sizeof((a)) / sizeof((a)[0]))

int arr[100];
for (int i = 0; i < ARRAY_SIZE(arr); i++) ...;
```

### 误用：传指针进宏

```c
void f(int *arr) {
    int n = ARRAY_SIZE(arr);   /* 错！arr 是指针，得 8/4=2 */
}
```

`arr` 已退化为指针，`sizeof(arr)` 是 8，`sizeof(arr[0])` 是 4（int），得 2——完全错误。这就是为什么宏只能用于定义域的真实数组。

## 底层映射

### `sizeof` 是编译期常量

```c
int arr[10];
size_t n = sizeof(arr) / sizeof(arr[0]);
```

```
; x86-64 -O2
mov     DWORD PTR [rsp+16], 10    ; n = 10，立即数，无运行时计算
```

`sizeof` 在编译期就求值（数组不退化时），结果直接嵌成立即数。零运行时开销。

### 防误用：类型检查宏（Linux 内核版）

```c
/* 必须传数组，不能传指针——编译期拦截 */
#define ARRAY_SIZE(arr) \
    (sizeof(arr) / sizeof((arr)[0]) \
     + __builtin_types_compatible_p(typeof(arr), typeof(&arr[0])) ? 0 : 0)
```

更严格的 `must_be_array` 宏用 `__builtin_types_compatible_p` 检查"参数是数组类型而非指针"——传指针直接编译失败。这是大型项目防误用的手段。

## HFT / DPDK

| 用法 | 例子 |
|------|------|
| 遍历定长表 | `for (i=0;i<RTE_DIM(cfg);i++)` |
| 静态配置表 | `const struct cfg tables[N]; ... RTE_DIM(tables)` |
| 错误码表 | `const char *names[]; ... RTE_DIM(names)` |
| 函数内传参 | 必须显式传 `n`，不能用宏 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "`ARRAY_SIZE(ptr)` 能用" | 不能，退化后是指针，得错误值 |
| "`sizeof(arr)/sizeof(arr[0])` 在函数内有效" | 无效，退化 |
| "`sizeof` 有运行时开销" | 编译期常量，零开销 |
| "VLA 的 sizeof 也是编译期" | VLA 的 sizeof 是运行时值 |

## 实操

```bash
# 看宏在定义域 vs 函数内的差异
cat > t.c << 'EOF'
#include <stdio.h>
#define AS(a) (sizeof(a)/sizeof((a)[0]))
void f(int arr[100]) { printf("in f: %zu\n", AS(arr)); }
int main(void) { int a[100]; printf("in main: %zu\n", AS(a)); f(a); return 0; }
EOF
gcc t.c -o t && ./t    # main: 100, f: 2（错误！）
# 看 sizeof 是立即数
gcc -O2 -S t.c -o - | grep 'mov.*100'
# DPDK/Linux 宏定义
grep -r 'define ARRAY_SIZE\|define RTE_DIM' /usr/include
```
