# 8.1.5 数组和指针

## 本节讲什么

数组与指针的**本质区别**：数组是对象（有大小、有存储），指针是保存地址的变量。这一节彻底澄清"数组就是指针"这个最常见的误区——它们只在"数组名退化"这个特定上下文里等价。

## 要点

| | `int a[10]` | `int *p` |
|---|-------------|----------|
| 本质 | 对象（10 个 int 的连续块） | 变量（存一个地址） |
| `sizeof` | 40（10×4） | 8（指针宽度） |
| 赋值 `a = ...` | **非法**（不可整体赋值） | `p = a` 合法 |
| `&a` 类型 | `int (*)[10]` | `int **` |
| 存储 | 块/静态存储期 | 指针本身在栈/全局 |
| 能否 `++` | 不能（数组名不可改） | 能（`p++`） |

```c
int a[10];
int *p = a;        /* a 退化为 &a[0]，赋给 p */
p = a + 5;         /* OK：p 可改 */
a = p;             /* 非法：数组名不可赋值 */
a++;               /* 非法：数组名不可自增 */
```

### "数组就是指针"误区的来源

函数参数 `int arr[]` 等价 `int *arr`（**8.1.6** 退化）——这是唯一让两者"看起来一样"的上下文。在定义域、`sizeof`、`&` 三处，数组保留数组身份，和指针完全不同。

### 数组名的"不可变性"

数组名不是指针变量，而是编译期的"地址标签"。它没有自己的存储单元存"地址值"——`a` 直接代表那块数组的起始地址。所以：
- 不能 `a = ...`（给标签赋值无意义）
- 不能 `a++`（标签不能移动）
- `&a` 取的是"整个数组的地址"，数值同 `a` 但类型不同

## 底层映射

### 存储与符号表

```c
int g_arr[100];          /* 全局：.bss，符号 g_arr 是数组起始地址 */
int *g_ptr;              /* 全局：.bss，符号 g_ptr 是指针变量，内容待填 */
```

```
$ nm t.o
0000000000000000 B g_arr     # B = .bss，400 字节
0000000000000190 B g_ptr     # B = .bss，8 字节
```

`g_arr` 占 400 字节（100 个 int），`g_ptr` 占 8 字节（一个指针）。符号表里它们都是地址，但大小天差地别。

### 数组名退化是"临时指针"

`int *p = a;` 时，编译器生成一个临时的 `&a[0]` 存进 `p`——数组本身不变。这个"退化"是表达式求值时的临时行为，不是数组真的变成了指针。

```c
int a[10];
int *p = a;          /* p 得到 &a[0] 的副本 */
p[0] = 99;           /* 改的是 a[0]，因为 p 指向 a */
a[0] = 0;            /* 直接改数组 */
```

## HFT / DPDK

| 区分 | 例子 |
|------|------|
| 数组对象 | `char buf[2048]` 报文缓冲，sizeof 有效 |
| 指针变量 | `char *p = buf` 游标，可移动 |
| 指针数组 | `struct rte_mbuf *pkts[32]`（**8.3**） |
| 数组指针 | `int (*row)[COLS]`（**8.2.4**） |

## 常见误区

| 误区 | 事实 |
|------|------|
| "数组就是指针" | 不是——数组有大小，指针是变量 |
| "`int a[]` 永远等价 `int *a`" | 仅在函数参数里退化；定义域不同 |
| "数组名能 `++`" | 不能，数组名不可改 |
| "`sizeof(a)` 和 `sizeof(p)` 一样" | 数组是 40，指针是 8 |

## 实操

```bash
# 对比数组与指针的 sizeof
cat > t.c << 'EOF'
#include <stdio.h>
int main(void) {
    int a[10], *p = a;
    printf("sizeof(a)=%zu sizeof(p)=%zu\n", sizeof(a), sizeof(p));
    return 0;
}
EOF
gcc t.c -o t && ./t    # 40 vs 8
# 看符号表大小差异
cat > t.c << 'EOF'
int g_arr[100]; int *g_ptr;
EOF
gcc -c t.c -o t.o && nm --print-size t.o
# 试着 a++ 看编译报错
```

## 代码自测

**题目 1：** 以下两种声明有什么区别？
```c
// A: 文件1.c
int arr[100];
// B: 文件2.c
int *arr;
```

<details>
<summary>参考答案</summary>

A 定义了一个 100 个元素的 int 数组，分配了 100*sizeof(int) 的内存。B 定义了一个 int 指针，只分配了 sizeof(int*) 的内存。sizeof(arr) 在 A 中是 400（假设 int 4 字节），在 B 中是 8（64 位指针）。数组名不是指针——它只是能退化为指针。

</details>
