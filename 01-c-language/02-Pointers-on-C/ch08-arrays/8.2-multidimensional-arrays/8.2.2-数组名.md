# 8.2.2 数组名

## 本节讲什么

二维数组名 **`buf`** 的类型与退化规则——比一维多一层"剥皮"。这一节是 8.2 系列里类型最绕的地方，搞清 `buf`、`buf[i]`、`&buf` 的类型是 8.2.4 数组指针的前提。

## 要点

```c
int buf[4][3];
```

| 表达式 | 类型 | 含义 |
|--------|------|------|
| `buf` | `int (*)[3]`（退化后） | 指向第一行 `int[3]` |
| `buf[i]` | `int *`（退化后） | 第 i 行首元素地址 |
| `buf[i][j]` | `int` | 第 i 行第 j 列元素 |
| `&buf` | `int (*)[4][3]` | 指向整个二维数组 |
| `&buf[i]` | `int (*)[3]` | 指向第 i 行（整行） |
| `sizeof(buf)` | `size_t` | `4*3*sizeof(int)` = 48 |

- `buf` 退化为 `&buf[0]`，类型 `int (*)[3]`（指向一行的指针）
- `buf[i]` 退化为 `&buf[i][0]`，类型 `int *`
- `&buf` 类型 `int (*)[4][3]`：`+1` 跳整个二维数组

### 三层"剥皮"

```c
buf        /* "4 行的数组" → 退化为指向"1 行"的指针 int(*)[3] */
buf[i]     /* "第 i 行的 3 元数组" → 退化为指向 int 的指针 int* */
buf[i][j]  /* int 值 */
```

每加一个下标，剥掉最外层维度：`[4][3]` → `[3]` → `int`。

## 底层映射

### 数值相同类型不同

```c
int buf[4][3];
/* buf, &buf[0], &buf 数值都等于数组起始地址 */
/* 但类型不同，+1 步长不同 */
```

```
地址:    0x1000(起始)
buf      → int(*)[3]，+1 跳 12 字节（一行）
&buf[0]  → int(*)[3]，+1 跳 12 字节（同 buf）
&buf     → int(*)[4][3]，+1 跳 48 字节（整个数组）
buf[0]   → int*，+1 跳 4 字节（一个元素）
```

### 汇编视角

```c
int buf[4][3];
int x = buf[2][1];        /* *( *(buf+2) + 1 ) */
```

```
; x86-64 -O2（buf 在栈上）
lea     rax, [rsp]             ; buf 起始地址
mov     eax, DWORD PTR [rax + 2*12 + 1*4]   ; base + 28
; 编译期算好 (2*3+1)*4 = 28
```

二维下标编译期就能算出线性偏移，只要第二维已知。这就是传参必须保留第二维的原因（**8.2.5**）。

## HFT / DPDK

| 用法 | 类型 |
|------|------|
| 传二维表 | `void f(int (*tbl)[3], int rows)` |
| 整数组拷贝 | `memcpy(dst, buf, sizeof(buf))` |
| 行指针 | `int (*row)[3] = buf + 2` |
| 元素访问 | `buf[i][j]` 编译期线性化 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "`buf` 是 `int**`" | 不是，是 `int(*)[3]`（指向一行的指针） |
| "`buf[i]` 是 int" | 是第 i 行，退化 `int*` |
| "`&buf` 和 `buf` 类型一样" | 数值同，类型不同，+1 步长差 4 倍 |
| "`int **p = buf` 合法" | 非法，类型不匹配（行连续 vs 行分散） |

## 实操

```bash
# 打印 buf, &buf, buf[0], &buf[0] 的值与类型sizeof
cat > t.c << 'EOF'
#include <stdio.h>
int main(void){
  int buf[4][3];
  printf("buf=%p &buf=%p buf[0]=%p\n",(void*)buf,(void*)&buf,(void*)buf[0]);
  printf("sizeof(buf)=%zu sizeof(buf[0])=%zu sizeof(buf[0][0])=%zu\n",
    sizeof(buf),sizeof(buf[0]),sizeof(buf[0][0]));
  return 0;
}
EOF
gcc t.c -o t && ./t
# 试着 int **p = buf; 看编译报错
```
