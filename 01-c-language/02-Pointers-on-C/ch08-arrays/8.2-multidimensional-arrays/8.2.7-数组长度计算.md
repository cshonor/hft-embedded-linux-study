# 8.2.7 数组长度计算

## 本节讲什么

多维数组**各维长度**：定义域用 `sizeof` 技巧分层算；传参后仅保留已知维。这是 8.1.10 一维长度计算的二维推广。

## 要点

```c
int buf[4][3];
size_t rows = sizeof(buf) / sizeof(buf[0]);       /* 4 */
size_t cols = sizeof(buf[0]) / sizeof(buf[0][0]); /* 3 */
size_t total = sizeof(buf) / sizeof(buf[0][0]);   /* 12 */
```

### 分层计算

| 要素 | 公式 | 结果 |
|------|------|------|
| 行数 | `sizeof(buf)/sizeof(buf[0])` | 4 |
| 列数 | `sizeof(buf[0])/sizeof(buf[0][0])` | 3 |
| 总元素 | `sizeof(buf)/sizeof(buf[0][0])` | 12 |
| 总字节 | `sizeof(buf)` | 48 |

- `buf[0]` 是"第 0 行"（`int[3]`），`sizeof(buf[0])` = 12（不退化）
- `buf[0][0]` 是 int，`sizeof(buf[0][0])` = 4
- 宏 `ARRAY_SIZE` 可用于每一层

### 传参后失效

```c
void f(int tbl[][3], int rows) {
    /* sizeof(tbl) 是指针大小 8，不是数组大小 */
    /* 能算的只有列数：sizeof(tbl[0])/sizeof(tbl[0][0]) = 3 */
    /* 行数必须靠参数 rows 传入 */
}
```

传参退化后，`tbl` 变成 `int (*)[3]`——`sizeof(tbl)` 是指针大小。但 `tbl[0]` 仍是 `int[3]`？不，`tbl[0]` 此时是 `*tbl`，是 `int[3]` 的左值但...

实际上退化后 `tbl` 是 `int(*)[3]`，`tbl[0]` 类型是 `int[3]`（解引用数组指针得到数组），`sizeof(tbl[0])` 仍是 12。所以**列数能算，行数不能算**——这是多维传参的精确边界。

## 底层映射

### 宏的多维版本

```c
#define ROWS(a)  (sizeof(a) / sizeof((a)[0]))
#define COLS(a)  (sizeof((a)[0]) / sizeof((a)[0][0]))

int buf[4][3];
for (int i = 0; i < ROWS(buf); i++)
    for (int j = 0; j < COLS(buf); j++)
        buf[i][j] = 0;
```

`ROWS`/`COLS` 仅在定义域对真实数组有效——传参退化后 `ROWS` 失效（行数丢），`COLS` 仍有效（列数在类型里）。

### DPDK / Linux 宏

```c
/* Linux 内核 */
#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))

/* DPDK */
#define RTE_DIM(a) (sizeof((a)) / sizeof((a)[0]))

int cfg[N][M];
for (i = 0; i < RTE_DIM(cfg); i++)          /* 行数 N */
    for (j = 0; j < RTE_DIM(cfg[0]); j++)   /* 列数 M */
        ...
```

`RTE_DIM(cfg)` 给行数，`RTE_DIM(cfg[0])` 给列数——分层调用宏。

## HFT / DPDK

| 场景 | 用法 |
|------|------|
| 遍历定长二维表 | `for(i<RTE_DIM(t);i++) for(j<RTE_DIM(t[0]);j++)` |
| 函数内传参 | 显式传 `rows`，列数在类型里 |
| 多维 VLA | 行列都运行时传 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "传参后 `sizeof(tbl)` 是数组大小" | 是指针大小 8 |
| "传参后列数也丢了" | 列数在类型 `int(*)[3]` 里，仍能算 |
| "`RTE_DIM(cfg[0])` 非法" | 合法，算 cfg 第 0 行的元素数 |
| "VLA 也能用 sizeof 编译期算" | VLA 的 sizeof 是运行时 |

## 实操

```bash
# 验证定义域各维长度
cat > t.c << 'EOF'
#include <stdio.h>
int main(void){
  int buf[4][3];
  printf("rows=%zu cols=%zu total=%zu bytes=%zu\n",
    sizeof(buf)/sizeof(buf[0]),
    sizeof(buf[0])/sizeof(buf[0][0]),
    sizeof(buf)/sizeof(buf[0][0]),
    sizeof(buf));
  return 0;
}
EOF
gcc t.c -o t && ./t    # rows=4 cols=3 total=12 bytes=48
# 传参后：行数丢、列数留
cat > t2.c << 'EOF'
#include <stdio.h>
void f(int tbl[][3], int rows){
  printf("sizeof(tbl)=%zu cols=%zu\n",
    sizeof(tbl), sizeof(tbl[0])/sizeof(tbl[0][0]));
}
int main(void){int b[4][3];f(b,4);return 0;}
EOF
gcc t2.c -o t2 && ./t2   # sizeof(tbl)=8, cols=3
```
