# 5.1 操作符

## 本节讲什么

C **全部运算符**概览:算术、移位、位运算、关系、逻辑、一元、三元、赋值、逗号。这些是 DPDK mbuf 标志位、寄存器读写、报文解析的日常工具。本节给全景,5.4 系列再深挖求值顺序与 UB。**HFT 里大半"数值错乱"事故的根因在这一章。**

## 要点

### 算术 `+ - * / %`

| 运算 | 规则 | 例子 |
|------|------|------|
| 整数 `/` | 截断小数,向 0 取整 | `7/3=2`,`-7/3=-2` |
| `%` | 仅整型;符号随**被除数** | `7%3=1`,`-7%3=-1` |
| 无符号溢出 | 模 2^N 环绕(**定义良好**) | `uint32_t` 计数到 0xFFFFFFFF+1=0 |
| 有符号溢出 | **UB** | `INT_MAX+1` 行为未定义 |

```c
uint32_t seq = 0xFFFFFFFF;
seq++;                 /* 0, 定义良好 —— 序列号环绕合法 */
int32_t  v = INT_MAX;
v++;                   /* UB, 编译器可假定不溢出做激进优化 */
```

> **HFT 铁律**:价格用 `int64_t` 定点(如 1e-7 精度),序列号/时间戳用 `uint64_t`。避免 `double` 精度分歧,避免有符号溢出 UB。

### 移位 `<<` `>>`

| 运算 | 规则 | 陷阱 |
|------|------|------|
| `a << n` | 低位补 0,等价 ×2^n(正数/无符号安全) | 左移负数是 UB;溢出 UB |
| `a >> n`(无符号) | 逻辑右移,补 0 | 安全 |
| `a >> n`(有符号负数) | 算术右移,补符号位(**实现定义**) | 可移植性差 |
| 位数 ≥ 类型位宽 | **UB** | `1 << 32`(int 32 位)是 UB |
| 位数 < 0 | **UB** | 移位量必须 ≥ 0 且 < 位宽 |

```c
uint8_t b = pkt[0];
uint16_t len = (pkt[1] << 8) | pkt[2];   /* 大端读字段, 注意整型提升 */
uint32_t mask = 1u << 5;                  /* 第 5 位掩码, 用 1u 避免 UB */
uint32_t high = val >> 24;                /* 取最高字节(无符号安全) */
```

> ⚠️ `1 << 31`(int 32 位)是 UB(符号位溢出);要 `1u << 31` 或 `1ULL << 63`。

### 位运算 `~ & | ^`

| 符 | 用途 | 例子 |
|----|------|------|
| `&` | 提取/过滤位 | `flags & PKT_ORDER` |
| `\|` | 置位 | `flags \|= PKT_ERR` |
| `^` | 翻转位 | `flags ^= PKT_VLAN` |
| `~` | 掩码取反 | `flags &= ~PKT_VLAN`(清位) |

```c
flags |=  PKT_ERR;          /* 置位 */
flags &= ~PKT_VLAN;         /* 清位 */
flags ^= PKT_DUP;           /* 翻转 */
if (flags & PKT_ORDER) {    /* 测试位 —— 注意是 & 不是 && */
    /* ... */
}
```

> ⚠️ **`if (flags & MASK)` ≠ `if (flags && MASK)`**。前者位与,得到掩码内的值;后者逻辑与,只给 0/1。测试位必须用 `&`。

### 关系与判等 `< <= > >= == !=`

- 结果类型 `int`,值为 `1` 或 `0`
- **`=` vs `==`**:`if (flag = 1)` 恒真陷阱(4.2)
- 比较无符号与有符号负数 → 提升为无符号,负数变超大正数(5.4.2)

### 逻辑 `&&` `||`(短路)

```c
if (mbuf != NULL && mbuf->len > 0)   /* mbuf==NULL 时不解引用, 安全 */
    process(mbuf);
```

- **`A && B`**:A 假则不求 B(短路)
- **`A || B`**:A 真则不求 B
- 短路是"安全空指针"模式的语义基础,**不能重排序**

### 一元 `& * ! ~ sizeof ++ -- + -`

| 符 | 语义 |
|----|------|
| `&` | 取址(左值 → 指针),ch06 |
| `*` | 解引用(指针 → 左值),ch06 |
| `!` | 逻辑非,`!x` 等价 `x==0` |
| `~` | 按位取反 |
| `sizeof` | 编译期字节数;**数组传参后退化, sizeof(p) 是指针宽** |
| `++ --` | 自增自减,前置先变后用,后置先用后变 |
| `+ -` | 一元正负 |

```c
int arr[10];
sizeof(arr);          /* 40, 数组大小 */
void f(int a[10]){ sizeof(a); }   /* 8, 退化成指针 */

int a = 5, b;
b = a++;              /* b=5, a=6(后置: 先用后变) */
b = ++a;              /* a=6, b=6(前置: 先变后用) */
```

> **同一表达式多次 `++`/`--` 同一变量 → UB**(序列点规则,5.4.3):`a = a++ + ++a;`

### 三元 `?:`

```c
uint64_t price = (bid > 0) ? bid : ask;   /* 二选一 */
const char *s = (err == 0) ? "ok" : "err";
```

- 条件非 0 取第二操作数,否则取第三
- **短路**:只求值被选中的分支
- 三元是表达式,有值,可嵌套但可读性差

### 复合赋值 `+= -= *= /= %= <<= >>= &= ^= |=`

```c
a += b;     /* 等价 a = a + b, 但 a 只求值一次 */
a <<= 2;    /* 等价 a = a << 2 */
```

- 复合赋值中**左操作数只求值一次**:对复杂左值(`a[compute()] += b`)避免重复计算
- 与 `a = a + b` 在 a 是简单变量时等价;复杂左值时复合赋值更高效

### 逗号 `,`

```c
for (i = 0, j = n - 1; i < j; i++, j--)   /* 多变量循环 */
    swap(&a[i], &a[j]);

int x = (a, b);   /* 逗号表达式: 求值 a 丢弃, 取 b —— 几乎不用, 可读性差 */
```

- 逗号运算符:左到右求值,结果取最右
- 主要用途:for 循环多变量;其他场景少用

## 汇编证据:移位与位运算

```c
uint32_t shift_demo(uint32_t a){
    return (a << 4) | (a >> 28);   /* 循环左移 4 位 */
}
```

```asm
        mov     eax, edi
        rol     eax, 4        ; x86 有 rol 指令, 直接循环移位
        ret
```

- 移位常被编译器识别为更优指令(`rol`/`ror` 循环移位,`shld`/`shrd` 双精度移位)
- `*2`/`*4`/`*8` 编译为 `shl` 而非 `imul`,更快

## 与 HFT/DPDK

### mbuf 标志位操作

```c
struct rte_mbuf *m = ...;
m->ol_flags |= PKT_TX_IP_CKSUM | PKT_TX_L4_CKSUM;   /* 置多个标志 */
m->ol_flags &= ~PKT_TX_VLAN_PKT;                      /* 清标志 */
if (m->ol_flags & PKT_RX_IP_CKSUM_BAD) {              /* 测试位 */
    stats.rx_bad_cksum++;
}
```

### 寄存器位字段

```c
volatile uint32_t *ctrl = (volatile uint32_t *)NIC_CTRL;
*ctrl |= TX_ENABLE;          /* 置位启用发送 */
*ctrl &= ~RX_PROMISC;        /* 清位关闭混杂 */
uint32_t v = *ctrl;
if (v & LINK_UP) { ... }     /* 测试链路状态 */
```

### 报文字段提取(大端/小端)

```c
/* 网络字节序(大端)读 16 位字段 */
uint16_t len = (pkt[0] << 8) | pkt[1];
/* 读 32 位 */
uint32_t seq = ((uint32_t)pkt[0] << 24) |
               ((uint32_t)pkt[1] << 16) |
               ((uint32_t)pkt[2] <<  8) |
               ((uint32_t)pkt[3]);
```

- 注意整型提升:`pkt[0] << 8` 中 pkt[0] 是 uint8_t,先提升为 int 再移位
- 字段 ≥ 32 位要显式 cast 到 uint32_t/uint64_t,避免窄类型 UB

## 常见误区

| 误区 | 真相 |
|------|------|
| `1 << 31` 安全 | UB(int 符号位溢出),要 `1u << 31` |
| `if (flags && MASK)` 测试位 | 错,逻辑与只给 0/1,要用 `&` |
| 有符号溢出"环绕" | 不,UB;编译器可激进优化 |
| 无符号溢出是 bug | 不,定义良好,序列号环绕合法 |
| `a++ + a++` 是 2a | UB,序列点内多次修改 |
| `sizeof(arr)` 在函数内得数组大小 | 形参退化,得指针大小 |

## 实操

```bash
cat > t.c <<'EOF'
#include <stdio.h>
#include <stdint.h>
int main(void){
  uint8_t b = 0xFF;
  printf("b<<8 = %d\n", b << 8);          /* 整型提升: 0xFF00 = 65280 */
  printf("1<<31 = %d (UB!)\n", 1 << 31);   /* UB, 可能 -2147483648 */
  printf("1u<<31 = %u\n", 1u << 31);       /* 2147483648, 安全 */
  uint32_t v = 0xDEADBEEF;
  printf("high byte = 0x%x\n", v >> 24);   /* 0xde */
  uint32_t mask = 1u << 5;
  printf("mask = 0x%x\n", mask);           /* 0x20 */
  return 0;
}
EOF
gcc -std=c11 -Wall -Wconversion t.c -o t && ./t

# 移位汇编
cat > s.c <<'EOF'
unsigned rol4(unsigned a){ return (a<<4)|(a>>28); }
EOF
gcc -O2 -S s.c -o s.s && grep -E 'rol|shl|shr' s.s
```
