# 4.8 switch 语句

## 本节讲什么

**switch 语句** 是整型多路分支的标准结构:报文类型、错误码、设备状态枚举分发的首选。本节讲 switch 的语法规则、穿透(fall-through)的利与弊、case 内变量定义限制,以及**跳转表汇编优化** —— 这是 switch 比 if-else 链快的底层原因。

## 要点

### 基本语法

```c
switch (pkt->msg_type) {
case MSG_QUOTE:
    process_quote(pkt);
    break;
case MSG_ORDER:
    process_order(pkt);
    break;
default:
    log_err("unknown msg_type %d", pkt->msg_type);
    break;
}
```

### 规则表

| 规则 | 说明 |
|------|------|
| 控制表达式 | **整型**(char/short/int/enum/bool);**float/指针不行** |
| case 标签 | **编译期整型常量表达式** |
| case 值唯一 | 同一 switch 内不能重复 |
| 匹配后 | **顺序执行**直到 break/return/goto/结尾 |
| default | 可省,但建议保留兜底;位置任意 |

### 穿透(fall-through)

```c
/* 刻意合并: case 间无 break, 共享处理 */
case MSG_CANCEL:
case MSG_MODIFY:
    handle_transaction(pkt);
    break;

/* 意外穿透: 漏 break, 不同 case 逻辑串联 */
case MSG_ORDER:
    setup_order(pkt);
    /* ← 漏 break! */
case MSG_QUOTE:
    setup_quote(pkt);     /* ORDER 也会执行 */
    break;
```

- 刻意合并:加注释 `/* fall through */` 说明意图
- 意外漏 break → 线上偶发 bug,逻辑串联
- GCC/Clang:`-Wimplicit-fallthrough` 警告未标注的穿透,HFT 升 `-Werror`

### case 内定义变量

```c
switch (t) {
case A: {
    int x = compute();      /* C 要求 case 内定义变量需加 {} */
    use(x);
    break;
}
case B:
    break;
}
```

- case 内**定义带初值的变量必须用 `{}` 包围**(C 语法:跳过初始化是 UB)
- 否则编译错:`a label can only be part of a statement and a declaration is not a statement`

### enum + switch + 完整性检查

```c
enum pkt_type { ORDER, QUOTE, HEARTBEAT, PKT_TYPE_MAX };

const char *name(enum pkt_type t) {
    switch (t) {
        case ORDER:     return "order";
        case QUOTE:     return "quote";
        case HEARTBEAT: return "hb";
        /* 不加 default */
    }
    return "unknown";
}
```

- `-Wswitch-enum`:枚举有 case 漏掉时报警 —— 编译器帮你查完整性
- 不加 default 让警告生效;加了 default 反而吞掉新增枚举值的漏处理
- 加新枚举值后,所有 switch 都被警告强制审查 —— 这是 enum+switch 的核心价值

## 跳转表汇编优化(关键)

### if-else 链 vs switch 的底层差异

```c
/* if-else 链: 顺序比较, 最坏 N 次比较 */
if (t == 0) ...;
else if (t == 1) ...;
else if (t == 2) ...;
...

/* switch: 编译器可能生成跳转表 O(1) */
switch (t) {
case 0: ...; break;
case 1: ...; break;
case 2: ...; break;
}
```

**跳转表(jump table)汇编**(x86-64,case 0-3):

```asm
        mov     eax, edi              ; t
        cmp     eax, 3                ; 范围检查
        ja      .L_default            ; 超过 3 → default
        mov     eax, eax
        lea     rdx, [rip + .Ltable]  ; 跳转表基址
        movsxd  rax, DWORD PTR [rdx*4 + rdx]  ; 取偏移
        add     rax, rdx              ; 计算目标地址
        jmp     rax                    ; 间接跳转, O(1)
.Ltable:
        .long   .L0 - .Ltable
        .long   .L1 - .Ltable
        .long   .L2 - .Ltable
        .long   .L3 - .Ltable
```

- 一次范围检查 + 一次间接跳转,**与 case 数量无关,O(1)**
- if-else 链最坏要 N 次比较 + 分支预测失败累积
- 条件:case 值密集且数量足够(GCC 默认 ≥ 5 个左右)才生成跳转表;稀疏 case 用二分搜索树

### 用 godbolt 观察

```c
int sw(int t){
    switch(t){
    case 0: return 10;
    case 1: return 20;
    case 2: return 30;
    case 3: return 40;
    case 4: return 50;
    default: return -1;
    }
}
```

- `gcc -O2 -S` 看是否有 `.Ltable` 间接跳转
- 改成稀疏 case(0, 1000, 100000)看是否变成二分比较

## 与 HFT/DPDK

### 报文类型分发

```c
switch (pkt->msg_type) {
case MSG_ORDER:    dispatch_order(pkt);    break;
case MSG_QUOTE:    dispatch_quote(pkt);    break;
case MSG_CANCEL:   dispatch_cancel(pkt);   break;
case MSG_HEARTBEAT: dispatch_heartbeat(pkt); break;
default:
    stats.unknown++;
    rte_pktmbuf_free(pkt);
    break;
}
```

- 协议消息类型用 enum + switch,新增类型编译器强制审查所有分发点
- 跳转表 O(1) 比 if-else 链快,热路径敏感

### 设备状态机

```c
switch (dev->state) {
case DEV_INIT:    ...; dev->state = DEV_READY; break;
case DEV_READY:   ...; dev->state = DEV_RUN;   break;
case DEV_RUN:     ...; break;
case DEV_ERROR:   ...; dev->state = DEV_INIT;  break;
}
```

- 状态机用 enum + switch 表达,状态迁移清晰
- 加 `-Wswitch-enum` 防止新增状态漏处理

### Duff's device(循环展开奇技)

```c
/* Duff's device: switch 与循环交织, 经典循环展开 */
void send(int *to, int *from, int count) {
    int n = (count + 7) / 8;
    switch (count % 8) {
    case 0: do { *to = *from++;     /* fall through 故意 */
    case 7:      *to = *from++;
    case 6:      *to = *from++;
    /* ... */
    case 1:      *to = *from++;
               } while (--n > 0);
    }
}
```

- 故意利用穿透做循环展开,减少循环开销
- 现代编译器 `-funroll-loops` 自动做,手写已少;但理解它有助于读懂老驱动代码

## 常见误区

| 误区 | 真相 |
|------|------|
| switch 支持 float/指针 | 不,只整型/枚举 |
| case 值可重复 | 不能,编译错 |
| 漏 break 只是警告 | 不,可能 UB 级 bug;`-Wimplicit-fallthrough` 警告 |
| switch 一定比 if-else 快 | 不一定;稀疏 case 可能退化为二分 |
| case 内定义变量不需 {} | 要,C 语法要求避免跳过初始化 |
| 加 default 总是好 | 不;enum+switch 不加 default 才能让 `-Wswitch-enum` 查漏 |

## 实操

```bash
# 1. 跳转表观察
cat > t.c <<'EOF'
int sw(int t){
  switch(t){
  case 0: return 10;
  case 1: return 20;
  case 2: return 30;
  case 3: return 40;
  case 4: return 50;
  default: return -1;
  }
}
EOF
gcc -O2 -S t.c -o t.s
grep -E 'jmp|\.Ltable|cmp' t.s    # 看间接跳转

# 2. fall-through 警告
cat > ft.c <<'EOF'
int f(int t){
  switch(t){
  case 0: t++;
  case 1: t+=2; break;
  }
  return t;
}
EOF
gcc -std=c11 -Wall -Wimplicit-fallthrough ft.c -o ft   # warning

# 3. enum + switch-enum 完整性
cat > e.c <<'EOF'
typedef enum { A, B, C } E;
int name(E t){
  switch(t){ case A: return 1; case B: return 2; }
  return 0;    /* 漏 C */
}
EOF
gcc -std=c11 -Wall -Wswitch-enum e.c   # 警告漏 case C
```
