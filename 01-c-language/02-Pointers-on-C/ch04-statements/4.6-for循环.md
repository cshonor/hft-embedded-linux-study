# 4.6 for 循环

## 本节讲什么

**for 循环** 是计数与遍历的首选结构:`for (初始化; 条件; 更新)`。三部分均可省略,`for(;;)` 是 DPDK 数据面主循环的标准写法。本节讲 for 的等价 while 展开、continue 在 for 里的特殊语义、逗号表达式,以及 HFT 数组遍历惯例。

## 要点

### 基本语法

```c
for (init; cond; update)
    stmt;

/* 展开等价于 */
init;
while (cond) {
    stmt;
    update;
}
```

- **init** 只执行一次;**cond** 每轮前判;**update** 每轮体后执行
- **continue 在 for 里仍执行 update**(再判 cond)—— 这是 for 与 while 的关键差异

### 经典用法

```c
for (int i = 0; i < pkt_cnt; i++)     /* C99: init 可声明变量 */
    decode_mbuf(buf[i]);

for (i = 0, j = n - 1; i < j; i++, j--) {   /* 逗号表达式 */
    swap(&a[i], &a[j]);
}

for (;;) {          /* 无限循环: DPDK 数据面主循环 */
    rx_process();
    tx_process();
}
```

### 省略形式

| 形式 | 含义 |
|------|------|
| `for (;;)` | 无 init / 无 cond(恒真) / 无 update —— 无限循环 |
| `for (; i < n; )` | 无 init 无 update,等价 `while (i < n)` |
| `for (i = 0;; i++)` | 无 cond,恒真,靠 break 退出 |
| `for (i = 0, j = n; i < j; i++, j--)` | 逗号表达式多变量 |

### continue 在 for vs while 的差异(关键)

```c
/* for 版: continue 后仍执行 i++ */
for (int i = 0; i < 10; i++) {
    if (skip[i]) continue;     /* 跳过, 但 i++ 仍执行 */
    process(i);
}

/* while 等价版: 必须手动 i++ */
int i = 0;
while (i < 10) {
    if (skip[i]) { i++; continue; }   /* 漏 i++ 就死循环! */
    process(i);
    i++;
}
```

- 这是 for 比 while 安全的核心:**循环变量更新不会被 continue 跳过**
- while 改写 for 时,continue 分支必须手动 update,否则死循环

### C99 init 里的变量声明

```c
for (int i = 0; i < n; i++) {  /* i 的作用域仅 for 循环内 */
    /* ... */
}
/* i 不可见 —— 防止循环变量泄漏 */
```

- C99 起 init 可声明变量,作用域限 for 语句内
- 这是"最小作用域"原则的体现,避免循环变量污染外层

## 与 HFT/DPDK

### DPDK 数据面主循环

```c
/* DPDK lcore 主循环标准结构 */
static __rte_noreturn void worker_loop(void) {
    for (;;) {
        uint16_t nb = rte_eth_rx_burst(port, q, pkts, BURST);
        if (likely(nb > 0)) {
            for (int i = 0; i < nb; i++)
                process(pkts[i]);
        }
        tx_flush();
    }
}
```

- `for(;;)` 是 HFT 数据面"永不退出"循环的标准写法
- 内层 `for (i=0; i<nb; i++)` 批量处理 burst

### 数组遍历与缓存局部性

```c
/* 行优先遍历(快): 连续访问, cache 命中高 */
for (int i = 0; i < N; i++)
    for (int j = 0; j < M; j++)
        a[i][j]++;

/* 列优先遍历(慢): 跨行跳跃, cache miss 频繁 */
for (int j = 0; j < M; j++)
    for (int i = 0; i < N; i++)
        a[i][j]++;
```

- 遍历顺序决定 cache 命中率,影响可达 5-10 倍(ch08/ch13 详)
- for 循环是数据布局优化的直接载体

### 循环展开(loop unrolling)

```c
/* 手动展开: 减少循环开销(分支/计数) */
for (int i = 0; i < n; i += 4) {
    a[i]   = f(i);
    a[i+1] = f(i+1);
    a[i+2] = f(i+2);
    a[i+3] = f(i+3);
}
/* 剩余处理 */
for (; i < n; i++) a[i] = f(i);
```

- 现代编译器 `-funroll-loops` 自动展开,手写已少
- HFT 极端场景仍手动展开 + SIMD intrinsics,榨取最后几纳秒

### for 与指针遍历的等价

```c
int a[100];
/* 下标版 */
for (int i = 0; i < 100; i++) a[i] = 0;
/* 指针版(等价, ch08 详) */
for (int *p = a; p < a + 100; p++) *p = 0;
```

## 常见误区

| 误区 | 真相 |
|------|------|
| `for(;;)` 和 `while(1)` 有差异 | 无,等价;编译后都是 jmp |
| continue 跳过 for 的 update | 不跳,update 仍执行(与 while 关键差异) |
| `for (int i...)` 的 i 在循环外可用 | C99 起作用域限 for 内 |
| 逗号表达式 `i++, j--` 顺序未定义 | 顺序求值(左到右),是逗号运算符保证 |
| 循环变量必须是 int | 任意整型/枚举/指针;但浮点计数器有精度风险 |

## 实操

```bash
cat > t.c <<'EOF'
#include <stdio.h>
int main(void){
  /* for 版: continue 后 i++ 仍执行 */
  int cnt = 0;
  for (int i = 0; i < 10; i++) {
    if (i % 2) continue;   /* 奇数跳过, 但 i++ 仍执行 */
    cnt++;
  }
  printf("even count=%d\n", cnt);   /* 5 */

  /* while 等价: 必须手动 i++ */
  int i = 0, c2 = 0;
  while (i < 10) {
    if (i % 2) { i++; continue; }
    c2++; i++;
  }
  printf("while even=%d\n", c2);    /* 5 */
  return 0;
}
EOF
gcc -std=c11 -Wall t.c -o t && ./t

# 循环展开汇编
cat > u.c <<'EOF'
void add(int *a, int n){
  for (int i = 0; i < n; i++) a[i] += 1;
}
EOF
gcc -O3 -funroll-loops -S u.c -o u.s
grep -c 'addl' u.s          # 看展开后指令数
```
