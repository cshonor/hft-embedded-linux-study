# 4.7 do 循环

## 本节讲什么

**do-while 循环** 是"先执行、后判断":循环体**至少执行一次**。本节讲 do-while 的语法、与 while 的对比,以及它在 HFT/驱动里"至少读一次/发一次"的典型场景(寄存器重试、订单 EAGAIN 重发)。

## 要点

### 基本语法

```c
do
    stmt;
while (expr);      /* ← 末尾分号不能少 */

do {
    stmt1;
    stmt2;
} while (expr);
```

执行流程:

1. 执行循环体
2. 求值 `expr`,非 0 → 回到 1;0 → 退出

- **至少执行一次** —— 这是 do-while 与 while/for 的核心差异
- 末尾 `while (expr);` 的分号**不能省**,省了是语法错

### do-while vs while

| 维度 | while | do-while |
|------|-------|----------|
| 判断时机 | 前(先判后执行) | 后(先执行后判) |
| 最少次数 | 0 次 | 1 次 |
| 适用 | 可能零次循环(队列空) | 至少一次(重试/初始化) |
| 语法陷阱 | 无 | 末尾分号易漏 |

### 何时用 do-while

- 循环体必须执行**至少一次**才能获得判断条件
- 典型:读寄存器/状态、发送重试、菜单交互(至少读一次输入)

### break / continue

```c
do {
    val = read_reg(STATUS);
    if (val & ERROR) break;          /* 错误就跳出 */
    if (val & SKIP) continue;        /* 跳过, 回到 do 条件 */
} while (val & BUSY);
```

- break 跳出 do;continue 回到 `while (expr)` 条件
- 与 while 的 break/continue 语义一致(都回到条件)

## 与 HFT/DPDK

### 寄存器就绪轮询

```c
volatile uint32_t *status = (volatile uint32_t *)NIC_STATUS;
uint32_t val;
do {
    val = *status;                   /* 必须先读一次 */
} while (!(val & READY_MASK));       /* 未就绪就继续读 */
```

- 设备状态至少读一次才能判,do-while 比 while 更贴切
- MMIO 必须 volatile(3.2.3),否则编译器把循环优化成"读一次存寄存器"

### 订单发送 EAGAIN 重试

```c
int ret;
do {
    ret = send_order(order);
} while (ret == -EAGAIN);           /* 资源暂不可用就重试 */

if (ret < 0) handle_error(ret);
```

- 发送系统调用常返回 EAGAIN(非阻塞 socket 缓冲满),do-while 重试自然
- 注意加重试上限防死循环:`for (int i=0; i<MAX_RETRY && ret==EAGAIN; i++)`

### 交互菜单(至少读一次)

```c
int choice;
do {
    show_menu();
    choice = read_input();
} while (choice != EXIT);
```

- 用户至少看到一次菜单、读一次输入,do-while 语义贴切

### 与 while(0) 当"宏的复合语句"技巧

```c
/* 宏里多条语句用 do { ... } while(0) 包裹, 保证展开后是一条语句 */
#define LOG(fmt, ...) do { \
    time_t t = time(NULL); \
    fprintf(stderr, "[%ld] " fmt "\n", t, __VA_ARGS__); \
} while (0)

if (cond)
    LOG("error %d", err);     /* 不加 do-while 这里会断成两条 */
else
    do_other();
```

- `do { ... } while (0)` 是宏的经典技巧,保证宏展开是**单条语句**,不受外层 if/else 影响
- 见 ch14 预处理器,这是 HFT/内核宏的标准写法

## 常见误区

| 误区 | 真相 |
|------|------|
| do-while 末尾分号可省 | 不能省,语法错 |
| do-while 条件为假也执行一次 | 条件判断在体之后,体至少执行一次 |
| `do {} while (0)` 是死循环 | 不是,执行一次后条件假退出 |
| do-while 比 while 慢 | 无性能差;编译后都是回跳 + 条件判 |
| 寄存器轮询用 while 也行 | while 会先判,但判时还没读 —— do-while 更贴语义 |

## 实操

```bash
cat > t.c <<'EOF'
#include <stdio.h>
#include <errno.h>
static int mock_send(void){ static int n=0; return (++n < 3) ? -EAGAIN : 0; }
int main(void){
  int ret;
  do { ret = mock_send(); } while (ret == -EAGAIN);
  printf("final ret=%d\n", ret);   /* 0 */
  return 0;
}
EOF
gcc -std=c11 -Wall t.c -o t && ./t

# do { ... } while (0) 宏技巧
cat > m.c <<'EOF'
#include <stdio.h>
#define LOG(...) do { printf("L: "); printf(__VA_ARGS__); puts(""); } while(0)
int main(void){
  if (1) LOG("hi %d", 1); else LOG("no");
  return 0;
}
EOF
gcc -std=c11 m.c -o m && ./m
```

## 代码自测

**题目 1：** 以下代码输出什么？
```c
int i = 10;
do {
    printf("%d\n", i);
    i++;
} while (i < 5);
```

<details>
<summary>参考答案</summary>

输出 10。do-while 是先执行后判断——循环体至少执行一次。第一次执行打印 10，i 变成 11，然后检查 11 < 5 为假，退出循环。这是 do-while 和 while 的关键区别。

</details>
