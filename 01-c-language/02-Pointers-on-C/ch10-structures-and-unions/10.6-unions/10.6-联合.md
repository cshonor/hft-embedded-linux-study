# 10.6 联合

## 本节讲什么

**union** 让多个成员**共享同一块内存**，大小等于**最大成员**。union 是 C 的"类型双关"机制——同一块字节可以用不同类型解读。它用于字节拆分、寄存器多视图、变体载荷等场景，但**无类型标记**——读错成员是静默 UB，需配合判别字段（10.6.1 变体记录）。union 也是严格别名规则的关键例外（C 标准允许通过 union 做类型双关，但仍有陷阱）。

本节是 union 总览，子节展开变体记录和初始化。

## 要点

### 基本语法

```c
union raw_data {
    uint32_t word;
    uint8_t  bytes[4];
};

union raw_data u;
u.word = 0x12345678;
/* 此时 u.bytes 可读取同样 4 字节 */
printf("%02x %02x %02x %02x\n",
       u.bytes[0], u.bytes[1], u.bytes[2], u.bytes[3]);
/* 小端 x86 输出：78 56 34 12 */
```

- 所有成员**起始地址相同**，共享存储
- `sizeof(union)` = 最大成员的 `sizeof`
- 同一时刻**仅一个成员"有效"**——写入一个成员后读另一个是 UB（C99 前严格 UB，C99 后有例外）

### 内存布局

```
union raw_data:
偏移  0    1    2    3
     +----+----+----+----+
     | word (4 字节)       |
     +----+----+----+----+
     | b0 | b1 | b2 | b3 |   ← bytes[4] 同一存储
     +----+----+----+----+
```

- `word` 和 `bytes` 起点都是偏移 0
- 4 字节存储，两种解读

### union vs struct

| 维度 | **struct** | **union** |
|------|------------|-----------|
| 成员存储 | 各自独立，连续 | **共享**，重叠 |
| 大小 | Σ成员大小 + padding | max(成员大小) + padding |
| 同时有效 | **所有**成员 | **仅一个**成员 |
| 典型用途 | 字段绑定 | 类型双关、变体 |
| 访问开销 | 直接 | 直接（无间接） |

### 类型双关

```c
union {
    float f;
    uint32_t u;
} x;
x.f = 1.0f;
printf("%08x\n", x.u);   /* 读取 float 的位表示 */
```

- 用 union 实现 `float` 与 `uint32_t` 的位重新解读
- C99 起，写入一个成员后读另一个是**允许的**（类型双关例外）
- C++ 行为不同——C++ 标准说"未指定"，但 GCC/Clang 实践与 C 一致
- **比 `*(uint32_t *)&f` 更安全**——后者违反严格别名

### 严格别名与 union 例外

C 标准的严格别名规则（C11 6.5p7）禁止通过不兼容类型的指针访问对象：

```c
float f = 1.0f;
uint32_t u = *(uint32_t *)&f;   /* 严格别名 UB（除 char* 外） */
```

但 union 有**例外**（C11 6.5.2.3 脚注 95）：通过 union 做类型双关是**允许的**：

```c
union { float f; uint32_t u; } x;
x.f = 1.0f;
uint32_t u = x.u;   /* 合法：union 类型双关 */
```

- 这是 C 标准明确允许的类型双关方式
- GCC/Clang 都支持，MSVC 也支持
- 是可移植的"位重新解读"惯用法

### 大小端与 union

```c
union { uint32_t w; uint8_t b[4]; } u;
u.w = 0x12345678;

/* 小端 x86：b[0]=0x78, b[1]=0x56, b[2]=0x34, b[3]=0x12 */
/* 大端 SPARC：b[0]=0x12, b[1]=0x34, b[2]=0x56, b[3]=0x78 */
```

- union 的字节拆分**依赖大小端**
- 跨平台代码不能依赖 union 做字节序转换
- 应该用显式移位：`uint8_t b0 = (u.w >> 24) & 0xFF;`（大端语义）

### union 的大小

```c
union {
    uint8_t  a;    /* 1 字节 */
    uint32_t b;    /* 4 字节 */
    uint64_t c;    /* 8 字节 */
} u;
/* sizeof = 8（最大成员） */
/* _Alignof = 8（uint64_t 对齐） */
```

- 大小 = 最大成员
- 对齐 = 最大成员的对齐要求

```c
union {
    uint32_t a;    /* 4 字节 */
    char b[10];    /* 10 字节 */
} u;
/* sizeof = 12（10 字节 + 2 padding 满足 4 对齐） */
```

末尾 padding 让总大小是最大对齐的整数倍。

### 匿名 union/struct（C11）

```c
struct pkt {
    uint8_t type;
    union {                    /* 匿名 union */
        uint32_t seq;
        uint8_t  raw[4];
    };                         /* 直接 .seq 访问 */
};

struct pkt p;
p.type = 1;
p.seq = 0x12345678;           /* 直接访问，无需 p.anon.seq */
```

- C11 标准化（GCC 早就支持为扩展）
- 简化变体记录的访问语法
- 适用于"同一消息载荷多种解读"

### union 作为"变体载荷"

```c
struct msg {
    uint8_t type;   /* 判别字段 */
    union {
        struct { uint64_t order_id; } order;
        struct { uint32_t seq; } quote;
    } body;
};

struct msg m;
m.type = PKT_ORDER;
m.body.order.order_id = 1001;   /* 写入 order 分支 */

if (m.type == PKT_ORDER) {
    use(m.body.order.order_id);  /* 必须先判 type */
}
```

- 配合判别字段实现"带标签的联合"（tagged union）
- 详见 10.6.1 变体记录

## HFT 关联

- **DPDK mbuf**：`union { struct rte_mbuf *next; void *buf_addr; }` 多视图访问同一字段
- **报文载荷多视图**：`union { struct eth_hdr eth; uint8_t raw[14]; }` 同时按字段和原始字节访问
- **类型双关**：float 与 uint32_t 转换用 union，比指针强转安全
- **变体消息**：FIX/SBE 不同消息类型用 tagged union 建模
- **寄存器视图**：`union { uint32_t reg; struct { uint8_t a, b, c, d; } bytes; }` 硬件寄存器多视图

### 实操：DPDK mbuf 多视图

```c
/* mbuf 的 union 字段 */
struct rte_mbuf {
    union {
        struct {
            void *buf_addr;      /* 数据缓冲地址 */
        };
        struct {
            uint64_t buf_addr_64;   /* 64 位视图 */
        };
    };
    /* ... */
};
```

union 让同一字段有多种类型视图，便于不同场景访问。

### 实操：float 位解读

```c
#include <stdio.h>
#include <stdint.h>

void print_float_bits(float f) {
    union { float f; uint32_t u; } x;
    x.f = f;
    printf("float %f = 0x%08x\n", f, x.u);
    /* float 1.000000 = 0x3f800000 */
    /* float -1.000000 = 0xbf800000 */
}
```

### 实操：报文头多视图

```c
union eth_view {
    struct eth_hdr hdr;        /* 字段视图 */
    uint8_t raw[14];           /* 原始字节 */
};

union eth_view ev;
memcpy(&ev, pkt, 14);
uint16_t type = ntohs(ev.hdr.type);
printf("dst mac: %02x:%02x:%02x:%02x:%02x:%02x\n",
       ev.raw[0], ev.raw[1], ev.raw[2],
       ev.raw[3], ev.raw[4], ev.raw[5]);
```

注意：`struct eth_hdr` 必须 `packed`，否则 union 大小可能不等于 14。
