# 16.2 浮点型函数

## 本节讲什么

`<math.h>` 的浮点运算：基础运算（`sqrt`/`pow`/`exp`/`log`）、取整（`floor`/`ceil`/`round`/`trunc`）、绝对值（`fabs`）、三角函数、特殊值处理（`isnan`/`isinf`/`fpclassify`）。HFT 场景里浮点主要用于回测统计与风控计算，**绝不能用来存储订单价格或数量**——这是铁律。

## 要点

### 函数分类速查

| 类别 | 函数 | 用途 |
|------|------|------|
| 幂对数 | `sqrt`/`cbrt`/`pow`/`exp`/`log`/`log2`/`log10` | 回测统计 |
| 取整 | `floor`/`ceil`/`round`/`trunc`/`rint` | 价量边界 |
| 绝对值 | `fabs`/`fabsf`/`fabsl` | 盈亏统计 |
| 三角 | `sin`/`cos`/`tan`/`atan2` | 极少用（可能期权定价） |
| 特殊值 | `isnan`/`isinf`/`fpclassify`/`signbit` | 防御性检查 |
| 误差函数 | `erf`/`erfc`/`tgamma`/`lgamma` | 统计分布 |
| 浮点控制 | `fegetround`/`fesetround` | 舍入模式控制 |

### float/double/long double 三精度

```c
float sqrtf(float x);
double sqrt(double x);
long double sqrtl(long double x);
```

- `f` 后缀：单精度，32 位，精度约 7 位有效数字
- 无后缀：双精度，64 位，精度约 15-16 位
- `l` 后缀：扩展精度，x86 80 位 / 其他平台可能等同 double

HFT 回测默认 `double`，单精度累积误差不可接受。`long double` 在 x86-64 是 80 位扩展，精度更高但慢且跨平台不一致。

### 取整函数的细微差异

```c
floor(2.7)   /* 2.0, 向负无穷取整 */
ceil(2.7)    /* 3.0, 向正无穷取整 */
round(2.7)   /* 3.0, 四舍五入到最近整数 */
trunc(2.7)   /* 2.0, 向零取整 */
rint(2.7)    /* 3.0, 按当前舍入模式, 默认 round-to-nearest-even */
```

| 输入 | floor | ceil | round | trunc | rint(默认) |
|------|-------|------|-------|-------|------------|
| 2.7 | 2 | 3 | 3 | 2 | 3 |
| -2.7 | -3 | -2 | -3 | -2 | -3 |
| 0.5 | 0 | 1 | 1 | 0 | 0（banker's） |
| 2.5 | 2 | 3 | 3 | 2 | 2（banker's） |

`rint` 默认 round-to-nearest-even（银行家舍入），统计场景避免累积偏差。HFT 价量取整用 `floor`/`ceil` 明确方向，不用 `round` 避免 0.5 歧义。

### NaN 与 Inf 的传播

```c
double x = 0.0 / 0.0;   /* NaN */
double y = 1.0 / 0.0;   /* +Inf */
double z = -1.0 / 0.0;  /* -Inf */
```

- NaN 参与任何运算结果都是 NaN，且 `NaN != NaN`（唯一不等于自己的值）
- Inf 参与运算遵循极限规则：`Inf + 1 = Inf`，`Inf - Inf = NaN`
- 检测：`isnan(x)` / `isinf(x)` / `fpclassify(x)`

```c
double pnl = compute_pnl(...);
if (isnan(pnl) || isinf(pnl)) {
    /* 统计出错, 丢弃这条记录 */
}
```

HFT 回测每条 tick 计算后必须检查 NaN/Inf，否则一个坏值会污染整个统计。

### errno 与数学函数

```c
#include <errno.h>
errno = 0;
double r = sqrt(-1.0);   /* 返回 NaN, errno = EDOM */
if (errno == EDOM) { /* 域错误 */ }

errno = 0;
double r = pow(2.0, 1e308);  /* 返回 HUGE_VAL, errno = ERANGE */
if (errno == ERANGE) { /* 溢出 */ }
```

部分数学函数通过 errno 报告域错误（`EDOM`）和溢出（`ERANGE`）。检查 errno 是检测异常的可靠方式，但要注意 errno 是线程局部的且可能被中间调用覆盖。

### 浮点异常标志

```c
#include <fenv.h>
feclearexcept(FE_ALL_EXCEPT);
double r = x / y;
if (fetestexcept(FE_DIVBYZERO)) { /* 除零发生 */ }
if (fetestexcept(FE_OVERFLOW)) { /* 溢出 */ }
if (fetestexcept(FE_INVALID)) { /* 非法操作, 如 sqrt(-1) */ }
```

`<fenv.h>` 提供细粒度的浮点异常标志，比 errno 更精确。但开启 `-ftrapping-math` 才能可靠捕获，默认编译器假设不抛异常。

### HFT 价格存储铁律

**订单价格和数量绝不能用浮点存储，必须用整数定点小数。**

| 存储 | 精度 | 问题 |
|------|------|------|
| `float` | 7 位有效 | 0.1 + 0.2 = 0.3000000119... |
| `double` | 15-16 位 | 累积万次仍有偏差 |
| `uint64_t` 单位 0.0001 | 精确 | 3500000 = 350.0000，无误差 |
| `int64_t` 单位 0.0001 | 精确 | 带符号，支持价差负数 |

```c
typedef int64_t price_t;   /* 单位 0.0001 元 */
price_t bid = 3500000;     /* 350.0000 元 */
price_t ask = 3500100;     /* 350.0100 元 */
price_t spread = ask - bid; /* 100 = 0.0100 元, 精确 */
```

浮点仅用于：回测统计（均值/方差/夏普）、风控指标（VaR/Greeks）、可视化，且每次运算后检查 NaN/Inf。

### 浮点可重复性陷阱

```c
double a = 0.1 + 0.2;
double b = 0.3;
/* a == b? 可能不等, 也可能等, 取决于编译器优化和 FPU 模式 */
```

- `-ffast-math` 会重排浮点运算，破坏结合律，结果不可重复
- x87 80 位扩展精度与 SSE 64 位双精度结果不同
- 多线程浮点累积顺序不同导致结果微差

回测要可重复必须：固定 `-std=c11 -O2`（不开 fast-math）、固定 `-mfpmath=sse`、单线程或确定性归约顺序。

## HFT 关联

- **价格存储**：`int64_t` 定点，单位 0.0001，全链路无浮点
- **数量存储**：`uint64_t` 或 `int64_t`，单位手数或最小变动单位
- **价差统计**：`double` 计算均值/方差，每步检查 NaN/Inf
- **VaR/Greeks**：期权定价用 `exp`/`log`/`erf`，结果检查有限性
- **夏普比率**：`sqrt`/`pow` 计算年化，注意 `-ffast-math` 破坏可重复性
- **回测可重复性**：固定编译选项、固定 FPU 模式、确定性归约
- **浮点 SIMD**：`<immintrin.h>` 的 AVX 指令批量算价差，但仅用于统计非订单存储
- **DPDK 数学**：数据面几乎不用 `<math.h>`，所有计算预整理为定点整数运算
