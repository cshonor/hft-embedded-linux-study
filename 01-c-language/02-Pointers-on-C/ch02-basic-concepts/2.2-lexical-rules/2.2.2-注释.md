# 2.2.2 注释

## 本节讲什么

从**词法层**看注释：两种语法、**预处理阶段删除**、**不能嵌套**、字符串内的"伪注释"。本节与 1.1.1 互补——1.1.1 讲工程规范（好注释写 why），本节讲词法机制（注释怎么被处理、为什么嵌套出错）。

## 两种注释语法

```c
/* 块注释：可跨行，不能嵌套 */
// 行注释：C99+，到行尾
```

| 维度 | `/* */` | `//` |
|------|---------|------|
| 标准 | C89/C90 正式 | **C99** 才标准化 |
| 多行 | 原生支持 | 每行都要 `//` |
| 嵌套 | **不能** | 可在块注释内出现 |
| 屏蔽大段 | 不能（嵌套出错） | — |

## 预处理阶段删除（关键词法机制）

注释在**预处理阶段**被删除（替换成单个空格），发生在：

```
源码 → 预处理（删注释、展开宏/include） → 编译
```

推论：

1. **注释不进入编译产物**——`.o` 里没有注释，运行时也没有；注释不影响性能
2. **`.i` 文件里注释已消失**——`gcc -E main.c` 看不到原注释
3. **注释内的代码不生效**——`/* int x = 0; */` 的赋值不会执行
4. **注释内的关键字/符号完全无效**——`/* if while for */` 不影响编译

## 不能嵌套（词法陷阱）

```c
/* 外层注释开始
   /* 内层注释 */
   这一行已经不是注释了！*/   ← 第一个 */ 就结束了外层注释
```

- 词法分析器从 `/*` 开始进入注释状态，遇到**第一个** `*/` 就结束
- 第二个 `*/` 成了多余的符号 → 语法错误，或者"恰好"被当成除法×指针解引用

### 屏蔽大段代码的正确方法

```c
#if 0
/* ... 一大段代码，可能内含块注释 ... */
#endif
```

- `#if 0 ... #endif` 是**预处理指令**，可以嵌套，屏蔽任何内容
- 比 `/* */` 安全——不会因为内含 `*/` 出错
- 内核/工程代码屏蔽大段首选 `#if 0`

## 字符串内的"伪注释"

```c
char *s = "/* this is not a comment */";
char *t = "// not a comment either";
```

词法分析器**先识别字符串字面量，再识别注释**。所以字符串内的 `/*` 和 `//` 不被当注释。

> 这也解释了 `a/*p` 陷阱：词法分析器不区分"你想表达除法×解引用"还是"开始注释"，它机械地匹配 `/*`。详见 2.2。

## 行注释的续行

```c
// 这是一个行注释 \
继续注释（续行符 \ 把下一行接上）
```

- 行注释遇到 `\` + 换行会续到下一行——这是预处理行的续行规则
- 容易踩：行注释末尾不小心有个 `\`，下一行也被注释掉

## 注释 vs 代码的边界场景

| 写法 | 结果 |
|------|------|
| `int x = 1 /* comment */ + 2;` | x = 3（注释替换成空格） |
| `int x = 1/* */2;` | x = 12？还是 3？→ 标准规定替换成**一个空格**，所以是 `1 2` → 两个 token → 语法错误 |
| `// comment` 在 C89 | 非标准，老编译器可能报错或当 `//` 除法 |
| `/* */` 跨行 | 合法 |

## 工程规范差异

| 规范 | 偏好 |
|------|------|
| **Linux 内核** | 仅 `/* */`（Linus 明确要求） |
| **DPDK 应用层** | `//` 与 `/* */` 均可，团队统一 |
| **C99+ 通用** | 两者并存 |
| **老嵌入式编译器** | 可能不支持 `//`（C89 模式） |

> 工程铁律：项目内统一一种（或明确规则），用 `clang-format`/`checkpatch` 强制。详见 1.1.1 和 2.3。

## 常见误区

| 误区 | 纠正 |
|------|------|
| 注释会拖慢程序 | 预处理就删了，零运行时影响 |
| `/* */` 可以嵌套 | 不能，第一个 `*/` 就结束外层 |
| 用 `/* */` 屏蔽大段代码很方便 | 内含 `*/` 就出错；用 `#if 0` |
| 字符串里的 `/*` 是注释 | 不是，字符串先被识别 |
| `//` 是 C 一直就有的 | C99 才标准化，老编译器可能不支持 |
| 注释里的代码会执行 | 不会，预处理就删了 |
