# 15.6 打开流

## 本节讲什么

`fopen(path, mode)` 是 stdio 的入口——把文件路径绑定到 `FILE *` 流。这一节给出所有打开模式的对照、`b` 标志的跨平台意义、`fopen` 失败的错误处理，以及 HFT 工程里滚动日志、行情数据文件、配置文件的打开实践。

认知锚点：`fopen` 模式字符串看似简单（`r`/`w`/`a`），但每种模式对文件存在性、读写权限、文件指针位置有不同要求。选错模式会导致数据丢失（`w` 截断已有文件）或权限错误。

## 要点

### 打开模式对照表

| 模式 | 作用 | 文件不存在时 | 文件已存在时 | 读写 |
|------|------|--------------|--------------|------|
| `r` | 只读 | 失败 | 从头读 | 只读 |
| `w` | 只写 | 创建 | **截断为 0** | 只写 |
| `a` | 追加 | 创建 | 在末尾写 | 只写 |
| `r+` | 读写 | 失败 | 从头读写 | 读写 |
| `w+` | 读写 | 创建 | **截断为 0** | 读写 |
| `a+` | 读写 | 创建 | 读从头，写末尾 | 读写 |

**加 `b`**：`rb`/`wb`/`ab`/`r+b`/`w+b`/`a+b`，二进制模式，不转换换行。跨平台统一加 `b`。

### 模式选择的陷阱

```c
/* 陷阱 1：w 截断已有文件 */
FILE *fp = fopen("important.dat", "w");   /* 文件内容被清空！ */
/* 应该用 "r+" 或 "a" */

/* 陷阱 2：r 打开不存在的文件 */
FILE *fp = fopen("newfile.txt", "r");     /* 返回 NULL */
/* 应该用 "w" 或 "a" */

/* 陷阱 3：a 模式不能读 */
FILE *fp = fopen("log.txt", "a");
fgetc(fp);   /* 失败，a 是只写 */
/* 应该用 "a+" */
```

### 错误处理

```c
FILE *fp = fopen("data.dat", "rb");
if (!fp) {
    perror("fopen data.dat");
    /* 输出：fopen data.dat: No such file or directory */
    return -1;
}
```

`fopen` 失败返回 `NULL`，**必须检查**。`perror` 输出错误原因（errno 对应的消息）。

### freopen：重定向流

```c
/* 把 stdout 重定向到文件 */
freopen("output.txt", "w", stdout);
printf("this goes to file\n");   /* 写入 output.txt */

/* 把 stderr 重定向到 /dev/null */
freopen("/dev/null", "w", stderr);
```

`freopen` 关闭原流，重新绑定到新文件。用于重定向标准流。

### tmpfile：临时文件

```c
FILE *tmp = tmpfile();   /* 二进制临时文件，关闭后自动删除 */
if (tmp) {
    fprintf(tmp, "temporary data\n");
    rewind(tmp);
    char buf[256];
    fgets(buf, sizeof(buf), tmp);
}
fclose(tmp);   /* 文件自动删除 */
```

`tmpfile` 创建匿名临时文件，`fclose` 后自动删除。详见 15.15。

## HFT 关联

### 滚动日志用 `a` 追加

```c
FILE *log_fp = fopen("/var/log/hft.log", "a");
/* a 模式：文件不存在则创建，存在则追加 */
/* 多进程写同一日志文件时，a 模式保证原子追加（POSIX） */
fprintf(log_fp, "[INFO] %s\n", msg);
fclose(log_fp);
```

滚动日志每天一个文件，`a` 追加模式不覆盖旧内容。**POSIX 保证 `a` 模式的写操作原子追加**，多进程并发写同一文件不会交错（但 stdio 缓冲可能破坏原子性，需配合 `setvbuf` 无缓冲或 `fflush`）。

### 行情数据用 `wb` 截断写

```c
/* 每天新建行情文件 */
char path[256];
snprintf(path, sizeof(path), "/data/market_%04d%02d%02d.dat",
         tm->tm_year + 1900, tm->tm_mon + 1, tm->tm_mday);
FILE *fp = fopen(path, "wb");   /* 新文件，截断（文件不存在则创建） */
fwrite(batch, sizeof(batch[0]), n, fp);
```

行情数据每天新文件，`wb` 模式创建新文件。**不要用 `w` 打开已有文件**——会截断历史数据。

### 配置文件用 `r` 只读

```c
FILE *cfg_fp = fopen("/etc/hft/hft.conf", "r");
if (!cfg_fp) {
    perror("cannot open config");
    exit(EXIT_FAILURE);
}
char line[256];
while (fgets(line, sizeof(line), cfg_fp)) {
    parse_config(line);
}
fclose(cfg_fp);
```

配置文件只读，`r` 模式。文件不存在则 `fopen` 失败，程序退出。

### 二进制文件强制 `b`

```c
/* HFT 工程规范：所有 fopen 都加 b */
FILE *fp1 = fopen("data.dat", "rb");     /* 二进制读 */
FILE *fp2 = fopen("log.txt", "wb");      /* 文本也用 wb */
FILE *fp3 = fopen("config.cfg", "rb");   /* 配置也用 rb */
```

跨平台强制 `b`，避免 Windows 换行转换破坏数据。Linux 下 `b` 无影响，是零成本保险。

## UB 边界

| 情形 | 后果 | 防护 |
|------|------|------|
| `w` 打开已有文件 | 内容截断 | 确认意图，或用 `r+` |
| `r` 打开不存在的文件 | 返回 NULL | 检查返回值 |
| `a` 模式读 | 失败 | 用 `a+` |
| 不检查 `fopen` 返回值 | NULL 解引用，崩溃 | 必须检查 |
| 文本模式读二进制（Windows） | 换行转换破坏数据 | 统一加 `b` |
| `freopen` 失败 | 原流已关闭，新流未绑定 | 检查返回值 |

### `w` 截断的不可恢复

```c
FILE *fp = fopen("important.dat", "w");
/* 此刻文件已被截断为 0 字节，原内容丢失 */
/* 即使后续 fwrite 失败，数据也回不来 */
```

`w` 模式打开即截断，**不可恢复**。重要文件操作前先备份，或用 `r+` 避免误截断。
