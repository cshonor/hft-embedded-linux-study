# 17.4.4 树的遍历

## 本节讲什么

BST 的三种深度优先遍历（前序/中序/后序）和层序遍历（BFS），以及用回调函数做 foreach 处理。本节重点讲三种遍历的语义、应用场景、递归与迭代的实现，以及 HFT 订单簿快照、destroy 清理的遍历选择。

## 要点

### 三种深度优先遍历

```c
/* 前序: 根 → 左 → 右 */
void tree_preorder(TreeNode *root, void (*visit)(TreeNode *))
{
    if (!root) return;
    visit(root);
    tree_preorder(root->left, visit);
    tree_preorder(root->right, visit);
}

/* 中序: 左 → 根 → 右 */
void tree_inorder(TreeNode *root, void (*visit)(TreeNode *))
{
    if (!root) return;
    tree_inorder(root->left, visit);
    visit(root);
    tree_inorder(root->right, visit);
}

/* 后序: 左 → 右 → 根 */
void tree_postorder(TreeNode *root, void (*visit)(TreeNode *))
{
    if (!root) return;
    tree_postorder(root->left, visit);
    tree_postorder(root->right, visit);
    visit(root);
}
```

### 三种遍历的语义

对 BST：

```
        4
       / \
      2   6
     / \ / \
    1  3 5  7
```

| 遍历 | 顺序 | 用途 |
|------|------|------|
| 前序 | 4,2,1,3,6,5,7 | 复制树、序列化 |
| 中序 | 1,2,3,4,5,6,7 | **有序输出**（BST 特性） |
| 后序 | 1,3,2,5,7,6,4 | destroy 清理（先子后根） |

中序遍历 BST 得到有序序列——这是 BST 最有用的性质。前序用于序列化（先存根再存子树，反序列化时先读根）。后序用于 destroy（先释放子节点再释放根，避免访问已释放内存）。

### 中序遍历的有序性

BST 中序遍历天然有序，无需排序：

```c
void export_sorted(TreeNode *root, void (*emit)(void *))
{
    if (!root) return;
    export_sorted(root->left, emit);
    emit(root->key);   /* 按 cmp 升序输出 */
    export_sorted(root->right, emit);
}
```

这是 BST 相比哈希表的核心优势——有序遍历 O(n) 输出全部，哈希表需额外排序。

### 遍历的回调模式

```c
void tree_foreach(TreeNode *root, void (*handler)(void *key, void *arg), void *arg)
{
    if (!root) return;
    tree_foreach(root->left, handler, arg);
    handler(root->key, arg);   /* 用户回调 + 上下文 */
    tree_foreach(root->right, handler, arg);
}
```

`handler` 接受 key 和 `void *arg` 上下文。`arg` 是闭包模拟——C 没有闭包，用 `void*` 传递上下文。这是 C 语言 ADT 遍历的标准模式。

### 中序遍历的迭代实现

```c
void tree_inorder_iter(TreeNode *root, void (*visit)(TreeNode *))
{
    Stack *s = stack_create(256);
    TreeNode *cur = root;
    
    while (cur || !stack_empty(s)) {
        /* 一路向左, 全部入栈 */
        while (cur) {
            stack_push(s, cur);
            cur = cur->left;
        }
        /* 弹出并访问 */
        cur = stack_pop(s);
        visit(cur);
        /* 转向右子树 */
        cur = cur->right;
    }
    stack_destroy(&s, NULL);
}
```

迭代中序用显式栈模拟递归。避免递归栈开销，栈深度可控（最坏 O(h)，h 是树高）。

### Morris 遍历（O(1) 空间）

```c
void tree_morris_inorder(TreeNode *root, void (*visit)(TreeNode *))
{
    TreeNode *cur = root;
    while (cur) {
        if (!cur->left) {
            visit(cur);
            cur = cur->right;
        } else {
            /* 找前驱, 建临时链接 */
            TreeNode *pred = cur->left;
            while (pred->right && pred->right != cur) pred = pred->right;
            
            if (!pred->right) {
                pred->right = cur;   /* 临时链接 */
                cur = cur->left;
            } else {
                pred->right = NULL;  /* 恢复 */
                visit(cur);
                cur = cur->right;
            }
        }
    }
}
```

Morris 遍历用临时修改树结构（前驱的 right 指针）实现 O(1) 空间中序遍历。遍历后树恢复原状。理论价值高，实际因修改树 + 常数大少用。

### 层序遍历（BFS）

```c
void tree_levelorder(TreeNode *root, void (*visit)(TreeNode *))
{
    if (!root) return;
    Queue *q = queue_create(256);
    queue_enqueue(q, root);
    
    while (!queue_empty(q)) {
        TreeNode *n = queue_dequeue(q);
        visit(n);
        if (n->left) queue_enqueue(q, n->left);
        if (n->right) queue_enqueue(q, n->right);
    }
    queue_destroy(&q, NULL);
}
```

用队列实现层序——每层从左到右访问。用于按深度处理（如打印树形结构）。

### destroy 的后序遍历

```c
void tree_destroy(TreeNode **root, void (*free_cb)(void *))
{
    if (!root || !*root) return;
    tree_destroy(&(*root)->left, free_cb);    /* 先释放左子树 */
    tree_destroy(&(*root)->right, free_cb);   /* 再释放右子树 */
    if (free_cb) free_cb((*root)->key);       /* 释放载荷 */
    free(*root);                               /* 最后释放节点 */
    *root = NULL;
}
```

后序是 destroy 的唯一正确顺序——先释放子节点再释放根。若先释放根，子节点指针丢失，无法继续遍历，内存泄漏。

### 遍历与并发的只读安全

只读遍历在"无插入/删除"时多线程安全。但遍历期间若有线程修改树，可能读到中间状态或访问已 free 节点。HFT 订单簿快照通常：

- 单线程独占遍历
- 或用读写锁（遍历持读锁，修改持写锁）
- 或用 RCU（读无锁，写等读者完成）

### 遍历的中断

```c
int tree_foreach_stop(TreeNode *root, int (*pred)(void *, void *), void *arg)
{
    if (!root) return 1;   /* 继续 */
    if (tree_foreach_stop(root->left, pred, arg) == 0) return 0;
    if (pred(root->key, arg) == 0) return 0;   /* 用户要求停止 */
    return tree_foreach_stop(root->right, pred, arg);
}
```

回调返回 0 表示停止遍历。用于"找到第一个满足条件的就停"等场景。

### 范围遍历

```c
void tree_range_foreach(TreeNode *root, const void *low, const void *high,
                        cmp_fn cmp, void (*handler)(void *))
{
    if (!root) return;
    int cl = cmp(root->key, low);
    int ch = cmp(root->key, high);
    if (cl > 0) tree_range_foreach(root->left, low, high, cmp, handler);
    if (cl >= 0 && ch <= 0) handler(root->key);
    if (ch < 0) tree_range_foreach(root->right, low, high, cmp, handler);
}
```

利用 BST 性质剪枝——不在范围内的子树不遍历。O(log n + k)，k 是结果数。

## HFT 关联

- **订单簿快照**：中序遍历导出全量订单簿到文件，重启恢复
- **destroy 清理**：后序遍历释放订单簿所有价位节点 + 挂单
- **市场深度查询**：范围遍历输出某价格区间所有挂单
- **批量通知**：中序遍历所有会话，发送行情广播
- **序列化**：前序遍历存树结构，反序列化时按前序重建
- **回调 + void* arg**：C 遍历的闭包模拟，DPDK `rte_hash_iterate` 同模式
- **迭代版避免爆栈**：深树递归遍历可能爆栈，数据面用迭代版
- **RCU 读无锁**：订单簿遍历用 RCU，读不加锁，写等读者完成
