# 17.4.1 插入节点

## 本节讲什么

BST 的插入：按 cmp 递归找到空位，创建新节点挂上。这是 BST 维护有序性的基础操作，也是理解 BST 查找路径的钥匙。本节重点讲递归与迭代两种实现、重复键策略、退化与平衡。

## 要点

### 递归插入

```c
struct TreeNode {
    void *key;
    struct TreeNode *left, *right;
};

TreeNode *tree_insert(TreeNode *root, void *key,
                      int (*cmp)(const void *, const void *))
{
    if (!root) {
        /* 空位, 创建新节点 */
        TreeNode *n = calloc(1, sizeof *n);
        if (!n) return NULL;
        n->key = key;
        return n;
    }
    
    int c = cmp(key, root->key);
    if (c < 0)
        root->left = tree_insert(root->left, key, cmp);
    else if (c > 0)
        root->right = tree_insert(root->right, key, cmp);
    /* c == 0: 重复键, 按策略处理 */
    
    return root;   /* 返回当前子树根 */
}
```

递归插入的逻辑：

1. 当前子树为空 → 创建新节点返回
2. key < root.key → 递归左子树
3. key > root.key → 递归右子树
4. key == root.key → 重复键，按策略处理

### 返回值与重建链接

递归插入的精妙在于返回值——每层返回"当前子树的根"，父层用 `root->left = tree_insert(root->left, ...)` 重新挂接。空子树插入时，新节点通过返回值"长"出来，父层的 `root->left` 指向它。

这是函数式风格的树修改——不改变原树结构，而是返回新树。但在 C 里实际是原地修改（通过指针重新链接），不是真正的持久化结构。

### 迭代插入

```c
int tree_insert_iter(Tree *t, void *key, cmp_fn cmp)
{
    TreeNode *n = calloc(1, sizeof *n);
    if (!n) return -1;
    n->key = key;
    
    if (!t->root) {
        t->root = n;
        return 0;
    }
    
    TreeNode *cur = t->root;
    while (1) {
        int c = cmp(key, cur->key);
        if (c < 0) {
            if (!cur->left) { cur->left = n; return 0; }
            cur = cur->left;
        } else if (c > 0) {
            if (!cur->right) { cur->right = n; return 0; }
            cur = cur->right;
        } else {
            /* 重复键, 按策略 */
            free(n);
            return -1;   /* 或插入右子树等 */
        }
    }
}
```

迭代版避免递归栈开销，深树不怕爆栈。HFT 倾向迭代版——报文解析嵌套深度不可控时递归有风险。

### 递归 vs 迭代

| 维度 | 递归 | 迭代 |
|------|------|------|
| 代码 | 简洁 | 稍长 |
| 栈开销 | 每层一帧 | 无 |
| 深度限制 | 受栈大小 | 仅受堆 |
| 可读性 | 高 | 中 |
| HFT | 控制面可用 | 数据面首选 |

平衡树深度 O(log n)，递归安全。但极端不平衡退化为 O(n)，n 很大时栈溢出。HFT 数据面用迭代避免风险。

### 重复键策略

`cmp == 0` 时三种策略：

#### 策略 A：拒绝插入

```c
if (c == 0) {
    /* 已存在, 拒绝 */
    return root;   /* 或返回错误 */
}
```

适用于"键唯一"的集合（如合约代码表）。

#### 策略 B：放右子树

```c
if (c <= 0)
    root->left = tree_insert(root->left, key, cmp);   /* <= 而非 < */
else
    root->right = tree_insert(root->right, key, cmp);
```

重复键当"稍大"处理，放右子树。查找时会找到所有重复。但树可能因重复键退化。

#### 策略 C：节点存链表

```c
struct TreeNode {
    void *key;
    struct Node *duplicates;   /* 同 key 的多个载荷链表 */
    struct TreeNode *left, *right;
};

/* 插入时 key 已存在, append 到 duplicates 链表 */
```

每个 key 对应一个链表存所有重复载荷。订单簿同价位多笔挂单用此模式——价格档位是 key，挂单链表是 duplicates。

### cmp 函数的严格弱序

cmp 必须满足严格弱序（详见 16.1）：

- `cmp(a, b) < 0` 和 `cmp(b, a) > 0` 不能同时真
- `cmp(a, b) == 0` 等价 `cmp(b, a) == 0`
- 传递性：`cmp(a, b) < 0 && cmp(b, c) < 0` → `cmp(a, c) < 0`

违反会导致 BST 性质破坏，查找/删除行为未定义。常见错误：

- 浮点 cmp 含 NaN（NaN 比较恒 false，破坏传递性）
- 整数减法溢出（`return a - b` 当 a=INT_MAX, b=-1 时溢出）

### 退化与平衡

顺序插入 1,2,3,4,5 → 全在右子树，退化成链表，查找 O(n)。

平衡树的旋转：

```
插入 3 后右子树过高, 左旋:
    1                 2
     \               / \
      2      →      1   3
       \
        3
```

AVL 在插入后检查高度差，超 1 就旋转。红黑树用颜色约束近似平衡。Treap 用随机优先级。HFT 平衡树选型：

- 红黑树：Linux 内核、C++ std::map 标准，通用
- AVL：查找密集，插入/删除少
- Treap：实现简单，期望平衡
- 跳表：无锁友好，Redis 用

### 插入的内存分配

每次插入 `calloc` 新节点。HFT 数据面用 mempool：

```c
TreeNode *n = rte_mempool_get(tree_node_pool);
n->key = key;
n->left = n->right = NULL;
```

零运行时分配。节点归还 mempool 不 free。

### 插入的复杂度

| 情况 | 复杂度 |
|------|--------|
| 平衡 BST | O(log n) |
| 随机插入 | O(log n) 期望 |
| 顺序插入（退化） | O(n) |
| 平衡树旋转 | O(1) 每次, 总共 O(log n) |

HFT 订单簿插入要求 O(log n) 稳定，必须平衡树或专用结构。

## HFT 关联

- **订单簿挂单**：插入价格档位 O(log n)，平衡树保证延迟稳定
- **合约表**：启动时批量插入合约，运行时只读
- **会话表**：新连接插入会话节点，断开删除
- **mempool 节点**：BST 节点从预分配池获取，零运行时分配
- **迭代版优先**：数据面用迭代插入避免递归爆栈风险
- **重复键策略**：订单簿同价位多笔挂单用"节点存链表"策略
- **平衡树选型**：红黑树通用，AVL 查找优，跳表无锁友好
- **cmp 严格弱序**：订单簿按价格 cmp 必须无溢出、无 NaN
