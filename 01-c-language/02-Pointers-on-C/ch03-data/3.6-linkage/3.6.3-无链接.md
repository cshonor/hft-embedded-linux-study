# 3.6.3 无链接

## 本节讲什么

**无链接(none linkage)**:标识符完全不参与链接——不导出给链接器,也不引用别处。块内 auto 变量、函数形参、typedef 名都属于无链接。它们只在当前块内存在,各翻译单元间的同名标识符互不干扰。

## 要点

### 条件与示例

```c
void f(int param)              /* param: 无链接(形参) */
{
    int x = 1;                 /* x: 无链接(块域 auto) */
    typedef int my_int;        /* my_int: 无链接(typedef 名) */
}
```

- C11 §6.2.2p6:以下三种标识符无链接:
  1. 块作用域未声明为 `extern` 的标识符
  2. 函数形参
  3. typedef 名

### 与外部/内部链接的对比

```c
int g;                         /* 文件域,无 static → 外部链接 */
static int s;                  /* 文件域 + static → 内部链接 */
void f(void) {
    int local;                 /* 块域 → 无链接 */
    static int sl;             /* 块域 + static → 无链接(static 改存储期不改链接) */
}
```

- 无链接 = 链接器根本看不到这个符号,`nm` 输出里没有它
- static 局部虽然加了 static,但**链接仍是"无"**——static 在块内改的是存储期(自动→静态),不改链接
- 一句话区分:**内部链接 = 同一翻译单元内跨函数共享这个名字;无链接 = 连同文件里别的函数都看不见**——上例 `sl` 只在 f 内可用,同文件其他函数写 `sl` 直接编译错(`'sl' undeclared`)
- 口诀:**"外面分内外,里面全无链"**——文件域二选一(无 static → 外部,static → 内部),块内一律无链接(auto 和块内 static 都是)

### 无链接标识符不进符号表

```bash
cat > t.c <<'EOF'
int g = 1;                    /* 外部链接, nm 可见 */
static int s = 2;             /* 内部链接, nm 可见(小写) */
void f(void) {
    int local = 3;            /* 无链接, nm 里看不到 */
}
EOF
gcc -c t.c && nm t.o
# D g        ← 外部链接
# d s        ← 内部链接
# (local 不在符号表里!)
```

- 无链接的标识符在 `nm` 输出中**不存在**——它们是栈上的临时对象或编译期类型别名,没有链接器层面的存在

## 与 HFT/DPDK

### 块内变量天然线程安全(单线程栈)

- 无链接的 auto 变量在各自线程栈上,天然隔离,无需锁
- 多线程 HFT 收包:每个线程的局部计数器(无链接)互不干扰

### 形参的无链接保证

- 形参无链接意味着:不同函数可以同名形参,互不干扰
- 这保证了 API 设计的灵活性——形参名只是接口约定,不影响链接

## 常见误区

| 误区 | 真相 |
|------|------|
| 块内 `static int x` 有内部链接 | 不是,链接仍为"无"——static 在块内只改存储期 |
| 局部变量在 nm 里能看到 | 看不到,无链接标识符不进符号表 |
| typedef 名有链接 | 没有,typedef 名无链接(C11 §6.2.2p6) |
| 两个函数同名形参会冲突 | 不会,形参无链接,各函数独立 |

## 实操

```bash
# 验证无链接标识符不进符号表
cat > t.c <<'EOF'
int g = 1;
static int s = 2;
void f(int param) {
    int local = param * 2;
    g += local;
}
EOF
gcc -c t.c && nm t.o
# 只看到 D g, d s, T f —— param 和 local 不在符号表
```

## 与后续衔接

- **3.6.1 外部链接** extern 声明、定义全局唯一
- **3.6.2 内部链接** static 改链接为内部
- **3.7 存储类型** 无链接 ≠ 无存储期(auto 有自动存储期,static 局部有静态存储期)
- **3.8 static 关键字** static 在块内改存储期、在文件级改链接——最易混的双语义

## 代码自测

**题目 1：** 以下标识符各自的链接属性是什么？
```c
int a;                    // (1)
static int b;             // (2)
void f(int c) {           // (3)
    int d = c;            // (4)
    static int e;         // (5)
}
```

<details>
<summary>参考答案</summary>

(1) a：外部链接（文件域，无 static）。
(2) b：内部链接（文件域 + static）。
(3) c：无链接（形参）。
(4) d：无链接（块域 auto）。
(5) e：无链接（块域 static 改的是存储期，不是链接；C11 §6.2.2p6：块作用域未声明为 extern 的标识符无链接）。

</details>
