# 3.2.1 初始化

## 本节讲什么

**初始化**是声明时给对象一个初值。未显式初始化时,初值由**存储期**决定 —— 这条规则是 HFT 报文解析 bug 的头号温床:同一函数在 debug 版"恰好工作"、release 版偶发崩溃,根因常是栈上的 auto 变量没初始化。本节把"哪类对象自动清零、哪类不是"讲到底层段。

## 要点

### 初始化规则表(存储期决定)

| 对象 | 未显式初始化的初值 | 为什么 |
|------|-------------------|--------|
| 全局 / 文件域 static | **0**(整型)、`0.0`(浮点)、`NULL`(指针) | 加载器按 `.bss` 清零 |
| 块域 **auto** | **不确定**(栈垃圾) | 编译器不写栈,上次函数栈帧残留 |
| 块域 **static** | 0 / 0.0 / NULL | 与全局 static 同,进 `.bss/.data` |
| `malloc` 返回 | **不确定** | 不清零,性能优先 |
| `calloc` 返回 | **全 0** | 额外清零 |
| `_Thread_local` | 0(线程启动时初始化) | 类比静态 |

> ⚠️ 关键差异:**静态存储期自动清零,自动存储期不清零**。"静态"和"自动"是存储期分类,见 3.7。

**两个精确化**:

- **"读未初始化 auto 是 UB"的出处**(C11 6.3.2.1p2):对象为自动存储期、**从未取过地址**(本可声明为 register)且未初始化 → 左值转换即 UB。若取过 `&a` 再通过指针读,是不确定值(indeterminate),对无陷阱表示的类型不算严格 UB —— 但工程上一律按 UB 对待,开 `-Wuninitialized -Wmaybe-uninitialized -Werror`
- **`calloc` ≠ `malloc + memset` 的一个安全差异**:calloc 内部做 `n*size` **乘法溢出检查**;自己写 `malloc(n*size)` 可能整数溢出 → 分配出小缓冲后溢出(CVE 常客)。大分配优先 `calloc(n, size)`

### 段映射(为什么会自动清零)

```
源码: int g_init = 42;     int g_zero;       int main(){int x;}
ELF:  .data  [42]          .bss [reserve,  加载时由 ld/mmap 清零]
                                      栈 [运行时函数帧, 不清零]
```

- `.data`:有初值的全局/static,**占可执行文件体积**
- `.bss`:无初值或初值为 0 的全局/static,**不占文件**,只在加载/`mmap` 时按大小清零
- `.rodata`:const 只读数据,见 3.4

### 三种初始化形式

```c
int a = 10;                 /* 标量初值 */
int arr[5] = {1, 2, 3};     /* 聚合: 未列出的元素补 0 → {1,2,3,0,0} */
int arr[5] = {0};           /* 常见"清零"惯用法, 首元素 0, 余补 0 */
int b[2][2] = {{1,2},{3,4}};/* 多维按行 */
char s[] = "abc";            /* 数组初始化, sizeof==4 含'\0' */
char *p  = "abc";            /* 指针指向 .rodata 字符串, 不可改 */
struct T t = {.field = 1};  /* C99 指定初始化, 跳过前序字段 */
```

**指定初始化**(C99)在结构体/数组里特别有用 —— 协议字段多但只填几个时,可读且对字段顺序变更鲁棒,内核与 DPDK 驱动大量使用。

### static 局部何时初始化

```c
void f(void) {
    static int count = 0;   /* ✅ 合法:常量表达式,程序启动前初始化一次 */
    /* static int bad = heavy_init();  ❌ 约束违例:非初始化器常量表达式,编译报错 */
}
```

- **程序启动前**初始化一次(C11 6.2.4p3),不是"首次执行到该行"——那是 **C++** 的动态初始化语义
- `static int x = foo();` 在 C 里**从来编译不过**(C11 6.7.9p4:静态存储期初始化器必须是常量表达式;GCC 报 "initializer element is not constant")——不是"UB"、也不是"现代编译器都支持";C++ 才允许,且 C++11 起保证线程安全
- 初值烧进 `.data` 镜像(=0 进 `.bss`),函数体里**没有初始化指令**——objdump 验证见 3.8

## 与 HFT/DPDK

### 栈脏数据导致的报文 bug(真实模式)

```c
/* 反例: 解析报文, len 未初始化 */
int parse_pkt(const uint8_t *pkt) {
    int len;            /* 栈垃圾, debug 版可能恰好小, release 版巨大 */
    if (pkt[0] == 0x01)
        len = pkt[1];
    /* 若上面 if 不成立, len 仍是垃圾 */
    return process(pkt, len);   /* 越界读 → 段错或数据错乱 */
}
```

- 规范:**声明即初始化**(declaration with initializer),或显式 `= 0`
- GCC/Clang:`-Wmaybe-uninitialized -Wuninitialized`,HFT 工程必开并升 `-Werror`

### mempool 与 bss 清零

- DPDK `rte_mempool` 大缓冲常放 hugepage,手动初始化;别依赖"全局会清零"
- 嵌入式/裸机:.bss 清零由启动代码(`crt0`)完成,看 link map 确认 `_bss_start/_end`

### 静态配置表用指定初始化

```c
static const struct rte_eth_conf port_conf = {
    .rxmode = { .max_rx_pkt_len = RTE_ETHER_MAX_LEN },
    .txmode = { .mq_mode = ETH_MQ_TX_NONE },
    /* 其余字段自动 0, 顺序无关 */
};
```

## 常见误区

| 误区 | 真相 |
|------|------|
| 全局 `int x;` 是未初始化 | 是**定义为 0**,放 .bss,不是"没初始化" |
| `int arr[N] = {1};` 只有 arr[0]=1 | 其余元素补 0,这是语言保证 |
| 静态局部每次调用都重初始化 | 程序启动前初始化一次(C11 6.2.4p3),后续保留值 |
| `malloc` 后内存是 0 | 不保证;要 0 用 `calloc` 或显式 `memset` |
| 局部 `int x = 0;` 多此一举 | 不是;debug 不代表 release,栈垃圾不可预测 |

## 实操

```bash
# 1. 观察未初始化局部变量的垃圾值
cat > t.c <<'EOF'
#include <stdio.h>
void g(void){ int x; printf("%d\n", x); }
int main(void){ g(); g(); g(); return 0; }
EOF
gcc -O0 -Wno-uninitialized t.c -o t && ./t   # 多次输出常不同
gcc -O2 -Wmaybe-uninitialized t.c            # 警告

# 2. readelf 看 .data/.bss 边界
cat > t2.c <<'EOF'
int a = 1; int b; static int c = 2; static int d;
EOF
gcc -c t2.c && readelf -S t2.o | grep -E 'data|bss'
nm t2.o | sort        # 区分 d/D, b/B
```

## 代码自测

**题目 1：** 以下代码中 x、y、z 的值各是多少？
```c
int x = 1, y = x + 1, z = y + 1;
```

<details>
<summary>参考答案</summary>

x = 1, y = 2, z = 3。初始化列表中的表达式按顺序求值，每个变量可以使用前面已初始化的变量。但注意：全局变量的初始化必须用常量表达式，不能用其他变量的值。

</details>

**题目 2：** 以下函数能否编译？各变量未初始化时的初值分别是什么？
```c
int g;
static int sg;

void test(void) {
    int a;
    static int sa;
    _Thread_local int tl;
    printf("g=%d sg=%d sa=%d\n", g, sg, sa);
    printf("%d\n", a);
}
```

<details>
<summary>参考答案</summary>

**编译不过**——`_Thread_local int tl;` 在块作用域裸写是**约束违例**（C11 6.7.1：块内 `_Thread_local` 必须搭配 static/extern），改成 `static _Thread_local int tl;` 才合法。

改对后各初值：
- g、sg、sa、（修正后的 tl）：静态/线程存储期 → **零初始化**（.bss 清零 / 线程启动时清零）
- a：自动存储期 → **不确定值（栈垃圾）**，读取是 UB（C11 6.3.2.1p2：从未取地址的未初始化自动对象，左值转换即 UB）

</details>
