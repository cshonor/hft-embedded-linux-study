# 3.1.3 指针

## 本节讲什么

指针作为一种**数据类型**：它存的是**地址**，有**指向类型**。本节只从类型层面预告指针——完整的指针体系（`&`/`*`、间接访问、指针运算、野指针）在 **ch06** 展开。这里建立三个基础认知：指针的位宽、指针类型决定什么、限定符与指针的组合。

## 指针的类型层面

```c
int *p;              /* 指向 int 的指针 */
const char *s;       /* 指向只读 char 的指针 */
void *generic;       /* 泛型指针，使用前需 cast */
struct rte_mbuf *mbuf; /* 指向 struct rte_mbuf 的指针 */
int **pp;            /* 指向 int 指针的指针（二级指针） */
```

### 指针的两个组成部分

| 组成 | 说明 |
|------|------|
| **地址值** | 一个整数，表示内存位置（64 位系统通常 48 位有效） |
| **指向类型** | 告诉编译器"这个地址存的是什么类型的对象" |

> `int *p` 和 `char *q` 都占 8 字节（64 位），存的地址值格式相同，但**指向类型不同**——这是它们行为不同的根本原因。

## `sizeof(指针)` 与指向类型无关

```c
int *pi;
char *pc;
struct rte_mbuf *pm;
void *pv;

/* 64 位系统：全部是 8 字节 */
sizeof(pi) == sizeof(pc) == sizeof(pm) == sizeof(pv) == 8
```

- 指针的位宽 = 地址总线宽度 = 64 位系统 8 字节、32 位系统 4 字节
- **与指向类型无关**——`int *` 和 `char *` 一样大
- 用 `uintptr_t` 可以安全地把指针转成整数再转回来

### 指针地址的有效位

- 64 位 Linux/x86：用户态地址通常 48 位有效（高 16 位是符号扩展）
- `0x7fff...` 是典型用户态地址范围
- 内核态地址高 16 位全 1（`0xffff...`）
- 详见 ch18 虚拟地址空间

## 指针类型决定什么

### 1. 解引用宽度

```c
int *pi = (int *)0x1000;
char *pc = (char *)0x1000;

*pi;    /* 从 0x1000 读 4 字节（int 宽度） */
*pc;    /* 从 0x1000 读 1 字节（char 宽度） */
```

- `int *` 解引用读 4 字节，`char *` 读 1 字节——类型决定读几个
- 类型错 → 读错字节数 → 数据错位或越界

### 2. 指针算术步长

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

p + 1;     /* 地址增加 sizeof(int) = 4 字节 → 指向 arr[1] */
p + 2;     /* 增加 8 字节 → 指向 arr[2] */
```

- `p + 1` 不是地址加 1，而是加 `sizeof(指向类型)`
- `int *` 步长 4，`char *` 步长 1，`struct big *` 步长可能很大
- **步长由指向类型决定**——这是指针算术的核心（ch06.13 详解）

```c
char *pc = (char *)arr;
pc + 1;    /* 只加 1 字节 → 指向 arr 的第 2 个字节 */
```

### 3. 类型安全

```c
int x = 42;
float *pf = &x;    /* 编译警告/错误：int* → float* 不兼容 */
```

- 编译器用指针类型做**类型检查**——防止把 `int *` 当 `float *` 用
- `void *` 是例外：可以和任何指针互转，不做检查

## `void *`：泛型指针

```c
void *generic = &x;     /* int * → void *：隐式转换，安全 */
int *pi = generic;       /* void * → int *：需要显式 cast（C）或隐式（C++） */
```

| 要点 | 说明 |
|------|------|
| `void *` 存什么 | 任意地址，但**不知道指向什么类型** |
| 解引用 | **不能直接解引用**——编译器不知道读几个字节 |
| 算术 | **不能做算术**（C 标准未定义 `void *` 步长；GCC 扩展按 1 字节算） |
| 转换 | 可和任意指针互转；使用前必须 cast 到具体类型 |
| 用途 | `malloc` 返回值、`qsort` 比较函数、泛型容器 |

> `malloc` 返回 `void *`——"给你一块内存，你自己决定怎么解释"。`int *p = malloc(4)` 隐式转成 `int *`。

## 限定符与指针的组合

`const` 可以修饰"指针本身"或"指向的内容"——位置决定语义：

```c
const int *p;         /* 指向 const int：不能通过 p 改内容，但 p 可指向别处 */
int *const p = &x;    /* const 指针：p 本身不可改，但可以通过 *p 改 x */
const int *const p = &x;  /* 二者都只读 */
```

| 写法 | 指针可改？ | 内容可改？ | 记忆法 |
|------|----------|----------|--------|
| `const int *p` | ✅ | ❌ | const 在 * 前面 → 内容只读 |
| `int *const p` | ❌ | ✅ | const 在 * 后面 → 指针只读 |
| `const int *const p` | ❌ | ❌ | 两个 const → 都只读 |

### 阅读技巧

从右往左读：
- `const int *p` → p is pointer to const int
- `int *const p` → p is const pointer to int
- `const int *const p` → p is const pointer to const int

### HFT 常用

```c
/* 只读配置指针：函数不改配置 */
void process(const struct config *cfg);   /* cfg 指向的内容不可改 */

/* MMIO 寄存器：volatile 告诉编译器每次从内存读 */
volatile uint32_t *reg = (volatile uint32_t *)0x40000000;
```

## NULL：空指针

```c
int *p = NULL;     /* p 不指向任何有效对象 */
if (p == NULL) { /* 检查空指针 */ }
*p;               /* UB：解引用空指针 → 通常 SIGSEGV */
```

- `NULL` 在 C 中通常定义为 `((void *)0)`
- 解引用 NULL 是 **UB**——通常 SIGSEGV，但不保证
- **所有指针用前检查 NULL**——工程铁律
- C11 引入 `nullptr` 的前身，C23 正式有 `nullptr`

## 指针的指针（预告）

```c
int x = 42;
int *p = &x;       /* p 指向 x */
int **pp = &p;     /* pp 指向 p */

**pp;              /* 42：先解引用 pp 得到 p，再解引用 p 得到 x */
```

- 二级指针用于"修改调用者的指针"——如 `void alloc(int **pp)`
- 详见 ch06.10 和 ch13.1

## 常见误区

| 误区 | 纠正 |
|------|------|
| `int *` 和 `char *` 大小不同 | 指针大小与指向类型无关，64 位都是 8 字节 |
| `void *` 可以直接解引用 | 不能，编译器不知道读几个字节 |
| `void *` 可以做算术 | C 标准未定义；GCC 扩展按 1 字节 |
| `int *p = &x; float *f = p;` 安全 | 类型不兼容，编译警告，行为 UB |
| `const int *p` 表示指针不可改 | 不对，是内容不可改；指针可改 |
| 解引用 NULL 一定崩溃 | 是 UB，通常 SIGSEGV 但不保证 |
| 所有指针都是 8 字节 | 64 位系统是，32 位系统是 4 字节 |

## 实操

1. `printf("%zu\n", sizeof(int *))` 到 `sizeof(void *)`，看都是 8
2. `int arr[3]={1,2,3}; int *p=arr; printf("%p %p\n", p, p+1)` 看步长 4
3. `char *c=(char*)arr; printf("%p %p\n", c, c+1)` 看步长 1
4. 写 `const int *p` 和 `int *const p`，尝试修改，看编译错误
5. `void *v = &x; *v;` 看编译错误（不能解引用 void *）
6. `int *p = NULL; *p;` 看 SIGSEGV

## 代码自测

**题目 1：** 以下代码有什么错误？
```c
int x = 42;
float *fp = &x;
*fp = 3.14f;
```

<details>
<summary>参考答案</summary>

类型不匹配。&x 的类型是 int*，赋给 float* 需要强制转换。不转换是编译错误。即使强制转换了，通过 float* 访问 int 变量违反了严格别名规则（strict aliasing），是未定义行为——可能导致垃圾值或程序崩溃。

</details>
