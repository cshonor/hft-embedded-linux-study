# 3.8 static 关键字

## 本节讲什么

`static` 是 C 里唯一一个"在两个位置有不同语义"的关键字:**块内 static 改存储期**(自动→静态,不改链接),**文件级 static 改链接**(外部→内部,不改存储期)。这个双语义是 C 工程化最常考、最易混的点。本节把两种位置、四个组合讲清,并给出 HFT/DPDK 的标准用法。

## 要点

### static 的两个位置(语义对照)

```c
/* 位置 1: 块内 static —— 改存储期 */
void f(void) {
    static int n = 0;        /* 静态存储期, 仅首次初始化, 作用域仍限块 */
    n++;
}

/* 位置 2: 文件级 static —— 改链接 */
static int s_count = 0;      /* 内部链接, 仅本文件可见, 存储期本就静态 */
static void helper(void){}   /* 内部链接函数, 模块私有 */
```

| 位置 | 改了什么 | 没改什么 |
|------|----------|----------|
| 块内 `static` | **存储期**:自动→静态 | 链接(本就无)、作用域(仍限块) |
| 文件级 `static` | **链接**:外部→内部 | 存储期(本就静态)、作用域(仍文件级) |

> 记忆:**static 在哪就改哪个轴**。块内改存储期(因为链接本就无);文件级改链接(因为存储期本就静态)。

### 四种组合(三轴矩阵)

| 写法 | 存储期 | 链接 | 作用域 | 段 |
|------|--------|------|--------|----|
| `int x;`(块内,无修饰) | 自动 | 无 | 块 | 栈 |
| `static int x;`(块内) | **静态** | 无 | 块 | .data/.bss |
| `int g;`(文件级) | 静态 | **外部** | 文件 | .data/.bss |
| `static int s;`(文件级) | 静态 | **内部** | 文件 | .data/.bss |

### 块内 static:函数级单例

```c
void f(void) {
    static void *pool = NULL;       /* 仅首次执行到此行初始化 */
    if (!pool) pool = alloc_hugepage();
    /* 用 pool, 跨调用复用 */
}
```

- 存 `.data/.bss`,不是栈 —— 跨函数调用保留值
- **仅首次执行到声明时初始化**(C11 保证线程安全初始化)
- 作用域仍限块:只有 f 内能访问 pool,外部看不到 —— "函数级私有状态"
- 适用于"惰性初始化的全局缓存",但要注意可重入性(多线程访问需同步)

### 文件级 static:模块封装

```c
/* foo.c */
static int s_state = 0;             /* 内部链接, 其他 .c 看不到 */
static void helper(void){}          /* 内部链接函数 */

int foo_api(void){                  /* 外部链接, 暴露给其他 .c */
    s_state++;
    helper();
    return s_state;
}
```

- `nm foo.o` 看到 s_state / helper 是小写 `d/t`(local),foo_api 是大写 `D/T`(global)
- 这是 C 实现"私有成员"的标准手段 —— 模块只暴露头文件声明的 API
- Linux 内核、DPDK 驱动大量使用

### static 函数内联优化

```c
/* foo.h */
static inline int clamp(int x, int lo, int hi){   /* 头文件 static inline */
    return x < lo ? lo : (x > hi ? hi : x);
}
```

- `static inline` 在头文件:每个包含的 `.c` 各有一份,无需链接,直接内联
- 现代 C/C++ 性能关键小函数的标准写法,DPDK `rte_*_mbuf` 大量使用
- 注意:static 函数不会被链接器合并(各自独立),但 inline 后通常没有函数体

## 与 HFT/DPDK

### mempool 单例(块内 static)

```c
struct rte_mempool *get_pkt_pool(void){
    static struct rte_mempool *pool;
    if (!pool) {
        pool = rte_mempool_create("pkt_pool", 4096, 2048, ...);
    }
    return pool;
}
```

- 惰性初始化 + 跨调用复用,模块内私有
- 注意:C11 起静态局部初始化线程安全,但后续访问仍需同步(或保证单线程初始化)

### 模块私有状态(文件级 static)

```c
/* orderbook.c */
static struct order g_orders[MAX_ORDERS];   /* 模块私有, 不导出 */
static rte_spinlock_t g_lock;               /* 模块私有锁 */
static int g_order_count = 0;

/* orderbook.h */
int  orderbook_add(const struct order *o);  /* 公共 API */
int  orderbook_cancel(uint64_t id);
```

- 订单簿内部表、锁、计数器都 static,外部只能通过 API 操作 —— 封装
- `nm orderbook.o` 看不到 g_orders 等符号(已 local)

### 静态配置表(const static)

```c
static const struct rte_eth_conf default_eth_conf = {
    .rxmode = { .max_rx_pkt_len = RTE_ETHER_MAX_LEN },
    .txmode = { .mq_mode = ETH_MQ_TX_NONE },
};
```

- `static const` = 内部链接 + 只读,进 `.rodata`,模块私有且不可改
- 配置表常这样写,避免重复定义 + 编译期只读保护

### per-core 状态(无锁结构)

```c
static __thread struct worker_stats t_stats;   /* 每线程独立 + 静态 */
```

- `static __thread` / `_Thread_local static` = 每线程独立副本 + 静态存储期
- 多核收包时 per-lcore 计数器,避免共享缓存行伪共享 —— HFT 性能关键模式

## 常见误区

| 误区 | 真相 |
|------|------|
| static 让变量线程安全 | 不,只改存储期/链接,并发仍需同步 |
| static 局部每次重初始化 | 只首次,后续保留值 |
| static 全局其他 .c 可见 | 不可见,内部链接 |
| static 函数不能被同文件调用 | 能,内部链接不影响同文件内调用 |
| `static inline` 比 `inline` 快 | 关键是 static 让符号不导出,避免链接器复制问题 |

## 实操

```bash
# 1. 块内 static 跨调用保留
cat > t.c <<'EOF'
#include <stdio.h>
void f(void){ static int n=0; printf("n=%d\n", ++n); }
int main(void){ f(); f(); f(); return 0; }
EOF
gcc -std=c11 -Wall t.c -o t && ./t   # n=1, n=2, n=3

# 2. 文件级 static 隔离
cat > a.c <<'EOF'
#include <stdio.h>
static int x = 1;            /* 内部链接 */
void a_show(void){ printf("a.x=%d\n", x); }
EOF
cat > b.c <<'EOF'
#include <stdio.h>
static int x = 2;            /* 不同的 x, 与 a.c 不冲突 */
void b_show(void){ printf("b.x=%d\n", x); }
EOF
cat > m.c <<'EOF'
extern void a_show(void); extern void b_show(void);
int main(void){ a_show(); b_show(); return 0; }
EOF
gcc a.c b.c m.c -o m && ./m          # a.x=1, b.x=2
nm a.o | grep x      # d x(小写=local)
nm m | grep ' x'     # 两个 x 都在, 各自 local

# 3. static inline
cat > si.c <<'EOF'
#include <stdio.h>
static inline int sq(int x){ return x*x; }
int main(void){ printf("%d\n", sq(5)); return 0; }
EOF
gcc -O2 si.c -o si && ./si
nm si | grep sq      # 看是否被内联消除(可能看不到 sq 符号)
```

## 代码自测

**题目 1：** 以下代码输出什么？为什么？
```c
int counter(void) {
    static int count = 0;
    return ++count;
}
int main(void) {
    counter(); counter();
    printf("%d\n", counter());
}
```

<details>
<summary>参考答案</summary>

输出 3。static 局部变量只初始化一次，之后每次调用 counter() 都保留上次的值。三次调用分别返回 1、2、3。static 局部变量存储在 BSS/data 段而非栈上，生命周期是整个程序。

</details>
