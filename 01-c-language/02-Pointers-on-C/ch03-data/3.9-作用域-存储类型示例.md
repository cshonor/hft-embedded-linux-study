# 3.9 作用域、存储类型示例

## 本节讲什么

把 ch03 学的**作用域**(块/文件/原型/函数)、**存储期**(自动/静态/线程/动态)、**链接**(外部/内部/无)三个维度,放在**同一个程序**里综合演示。本节是 ch03 的总结性实验:用一段源码 + `readelf` + `nm` + gdb 验证每个变量落在哪个段、什么链接、什么可见性。建议照着敲一遍,用工具亲眼看一遍。

## 要点

### 典型布局(综合源码)

```c
#include <stdio.h>
#include <stdlib.h>

/* ===== 文件作用域(全局/static 文件级)===== */
int g_init = 42;              /* .data, 外部链接, 静态存储期 */
int g_zero;                   /* .bss,  外部链接, 自动 0 */
static int s_file = 1;        /* .data, 内部链接, 仅本文件 */
static int s_zero;            /* .bss,  内部链接, 自动 0 */
const char *g_msg = "hi";     /* ptr 在 .data, "hi" 在 .rodata */
const int g_const = 100;      /* .rodata, 外部链接只读 */

/* ===== 函数原型作用域 ===== */
extern void other(void);      /* 参数表空, 无原型参数名 */

/* ===== 块作用域 + 不同存储期 ===== */
void demo(int param /* 原型作用域, 此处即块 */) {
    auto int x;               /* 栈, 自动存储期, 未初始化(脏) */
    static int call = 0;      /* .data/.bss, 静态存储期, 仅 demo 可见 */
    register int i;           /* 现代编译器忽略 register, 概念上建议进寄存器 */
    call++;
    printf("call=%d x=%d g_init=%d\n", call, x, g_init);
    if (x) {
        int y = x + 1;        /* 子块, 块作用域, 自动 */
        printf("y=%d\n", y);
    }
    /* y 不可见 */
}

cleanup:                       /* 函数作用域 label, 整个 demo 内有效 */
    ;                         /* 占位 */

int main(void) {
    int *p = malloc(sizeof(int));   /* 堆, 动态存储期 */
    demo(1);
    demo(1);
    other();                   /* 跨文件调用, extern 声明 */
    free(p);
    return 0;
}
```

### 变量观察清单(三轴对应表)

| 变量 | 作用域 | 存储期 | 链接 | 段 | 初值 |
|------|--------|--------|------|----|----|
| `g_init` | 文件 | 静态 | 外部 | .data | 42 |
| `g_zero` | 文件 | 静态 | 外部 | .bss | 0(自动) |
| `s_file` | 文件 | 静态 | 内部 | .data | 1 |
| `s_zero` | 文件 | 静态 | 内部 | .bss | 0(自动) |
| `g_msg` | 文件 | 静态 | 外部 | .data(指针) + .rodata("hi") | 指向 "hi" |
| `g_const` | 文件 | 静态 | 外部 | .rodata | 100 |
| `param` | 块(demo 内) | 自动 | 无 | 栈 | 调用方传入 |
| `x` | 块 | 自动 | 无 | 栈 | 不确定(脏) |
| `call` | 块 | **静态** | 无 | .data/.bss | 0(首次) |
| `y` | 子块 | 自动 | 无 | 栈 | 计算得 |
| `p` | 块(main) | 自动 | 无 | 栈 | malloc 返回值 |
| `*p` | 堆 | 动态 | 无 | 堆 | 不确定 |

> 关键对照:`call` 与 `x` 作用域同(块),但存储期不同(静态 vs 自动);`s_file` 与 `g_init` 存储期同(静态),但链接不同(内部 vs 外部)。**三轴独立**,不能混。

### nm 符号验证

```
$ nm t.o | sort
0000000000000000 D g_const        # .rodata, 外部(大写)
0000000000000000 D g_init         # .data, 外部
0000000000000004 B g_msg          # .data, 外部(实际放 .data 段的指针)
0000000000000000 B g_zero         # .bss, 外部
0000000000000000 T main           # text, 外部函数
0000000000000010 T demo           # text, 外部函数
0000000000000004 d s_file         # .data, 内部(小写)
0000000000000004 b s_zero         # .bss, 内部(小写)
0000000000000000 r "hi"           # .rodata, 内部(字符串字面量)
                  U malloc        # 未定义, 链接器从 libc 找
                  U printf
                  U other         # 未定义, 链接器从别 .o 找
```

| 字符 | 段 | 链接 |
|------|----|----|
| 大写 `T/D/B/R` | text/data/bss/rodata | 外部 |
| 小写 `t/d/b/r` | text/data/bss/rodata | 内部(static) |
| `U` | 未定义 | 等链接器解析 |

> `call` 在 `demo.o` 里也应有符号(小写 b/d),验证它确实进 .bss/.data 而非栈。

### readelf 段布局

```
$ readelf -S t.o
[Nr] Name              Type     Address    Off    Size
[ 1] .text             PROGBITS ...        ...    ...   # 代码
[ 2] .rela.text        RELA     ...        ...    ...   # 重定位
[ 3] .data             PROGBITS ...        ...    ...   # g_init, s_file, g_msg(指针)
[ 4] .bss              NOBITS   ...        ...    ...   # g_zero, s_zero, call(无初值)
[ 5] .rodata           PROGBITS ...        ...    ...   # g_const, "hi", printf 格式串
```

- `.bss` 类型是 `NOBITS`:不占文件体积,只在加载时分配并清零
- `.rodata` 与 `.data` 都是 `PROGBITS`:占文件体积

### gdb 验证地址区间

```
$ gdb ./t
(gdb) break main
(gdb) run
(gdb) print &g_init       # 0x55...xxxx  (.data, 全局)
(gdb) print &call         # 0x55...yyyy  (.bss, 静态局部)
(gdb) print &x            # 0x7fff...zzzz (栈, 高地址)
(gdb) print p             # 0x55...aaaa  (堆, malloc 返回)
(gdb) info symbol &g_init # g_init in section .data
```

- 全局/static 在低地址(映射自可执行文件);栈在高地址(向下生长);堆在中间
- ch18 会用完整虚拟内存图串起来

## 与 HFT/DPDK 的延伸实验

### 实验 1:多文件 extern / static 链接

```c
/* config.h */ extern struct config g_cfg; void cfg_load(void);
/* config.c */ struct config g_cfg = {0}; static FILE *fp; void cfg_load(void){...}
/* main.c  */ #include "config.h"; int main(){ cfg_load(); return g_cfg.port; }
```

- 观察:`nm config.o` 看到 `g_cfg`(D 外部)、`cfg_load`(T 外部)、`fp`(d/b 内部)
- 把 `int g_cfg;` 放头文件,两个 .c include → 重复定义错误

### 实验 2:无符号 char 与 -1 比较(3.1.1 延伸)

```c
char c = -1;
if (c == -1) ...         /* 实现定义: signed char 时成立, unsigned char 时不成立 */
```

- 配合 `gcc -funsigned-char` 切换 char 的符号性,观察行为变化

### 实验 3:自写 htonl 理解大小端(3.1 延伸)

```c
uint32_t my_htonl(uint32_t v){
    return ((v & 0xFF) << 24) | ((v & 0xFF00) << 8) |
           ((v >> 8) & 0xFF00) | ((v >> 24) & 0xFF);
}
```

- x86(小端)运行后用 `hexdump` 看字节序,与网络字节序(大端)对比

## 常见误区

| 误区 | 真相 |
|------|------|
| `static int call;`(块内)在栈 | 在 .bss/.data,静态存储期 |
| `g_zero` 是"未初始化" | 是定义为 0,放 .bss |
| `g_msg` 整个对象在 .rodata | 指针在 .data,字符串字面量在 .rodata |
| 同名 static 在两个 .c 是同一对象 | 不是,各自独立,内部链接 |
| `.bss` 占可执行文件体积 | 不占,加载时分配清零 |

## 实操

```bash
# 完整三轴验证
cat > t.c <<'EOF'
#include <stdio.h>
#include <stdlib.h>
int g_init = 42; int g_zero; static int s_file = 1; static int s_zero;
const char *g_msg = "hi"; const int g_const = 100;
void demo(int p){ int x; static int call=0; call++; printf("%d %d\n", call, x); }
int main(void){ int *q=malloc(4); demo(1); demo(1); free(q); return 0; }
EOF
gcc -std=c11 -Wall -g t.c -o t
readelf -S t | grep -E '\.(text|data|bss|rodata)'
nm t | sort | grep -E 'g_|s_|call|demo|main'
gdb -batch -ex 'b main' -ex r \
  -ex 'p &g_init' -ex 'p &g_zero' -ex 'p &s_file' -ex 'p &g_const' \
  -ex 'info symbol &g_init' t
```

## 代码自测

**题目 1：** 以下代码能正确交换两个变量吗？为什么？
```c
void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}
int main(void) {
    int x = 1, y = 2;
    swap(x, y);
}
```

<details>
<summary>参考答案</summary>

不能。C 函数参数是值传递，swap 内交换的是 a 和 b 的副本，不影响 main 中的 x 和 y。要实现交换，需要传指针：void swap(int *a, int *b)，调用 swap(&x, &y)。

</details>
