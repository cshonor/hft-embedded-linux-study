# 3.4 常量

## 本节讲什么

"常量"在 C 里有两层:**字面量**(整型、浮点、字符、字符串、枚举)和 **const 对象**(只读变量,可进 `.rodata`)。本节把各类字面量、转义、字符串拼接、`enum`、`const` 对象的底层段布局讲透 —— 这些是写协议解析、寄存器掩码、配置表的日常。

## 要点

### 整型常量

| 进制 | 写法 | 用途 |
|------|------|------|
| 十进制 | `123` | 普通数值 |
| 八进制 | `0123` (= 83) | **易错**,C 没单独前缀,leading 0 即八进制 |
| 十六进制 | `0x1F` / `0X1F` | 寄存器地址、掩码、报文字段 |
| 二进制(C23) | `0b1010` | 位字段掩码(早期靠 `0b` GCC 扩展) |

**后缀**(控制类型):

| 后缀 | 类型 |
|------|------|
| 无 | 十进制:`int`/`long`/`long long` 取最小容纳 |
| `U`/`u` | 无符号版 |
| `L`/`l` | 至少 `long` |
| `LL`/`ll` | 至少 `long long` |
| `ULL` | `unsigned long long` |

> 命名常量优先**大写 + 后缀齐全**:`0xFFFFFFFFUL`、`1000ULL`,避免窄类型隐式转换。

### 字符与转义

```c
'A'      /* int, 字符常量是 int 不是 char */
'\n'     /* 换行 */
'\0'     /* 空字节 */
'\x0F'   /* 16 进制转义, 任意字节 */
'\101'   /* 8 进制转义, = 'A' */
```

| 转义 | 含义 |
|------|------|
| `\n \t \r` | 换行/制表/回车 |
| `\\ \' \"` | 字面 \ ' " |
| `\0` | NUL,字符串终止符 |
| `\xHH` | 任意 16 进制字节,**报文字节常量** |
| `\OOO` | 8 进制字节 |

- 字符常量类型在 C 是 `int`(C++ 是 `char`),`sizeof('A')` 在 C 得 4
- 报文字节:`uint8_t magic[] = {'T','I','C','\x01'};` 比裸数字可读

### 字符串常量

```c
"abc"               /* .rodata, 只读, 含 '\0' */
"hello" "world"     /* 编译期拼接 → "helloworld" */
sizeof("abc")       /* == 4(含 '\0') */
strlen("abc")       /* == 3(不含 '\0') */
```

- **拼接特性**常用于多行宏、长字符串断行:

```c
const char *help =
    "Usage: prog [-p port] [-v]\n"
    "  -p  监听端口\n"
    "  -v  详细输出\n";
```

- **修改字符串常量内容 = UB**:可能 SIGSEGV(放 `.rodata` 的平台),可能"恰好工作"(某些嵌入式放可写 RAM)

### 浮点常量

```c
3.14       /* double */
1e-6       /* double, 科学计数 */
3.14f      /* float */
3.14L      /* long double */
NAN        /* 需 <math.h> */
INFINITY   /* 需 <math.h> */
```

- 默认 `double`,加 `f` 才是 `float`;HFT 内部不用浮点存价格,但概率/统计可能用到

### enum

```c
enum pkt_type {
    PKT_ORDER    = 0,
    PKT_QUOTE,                /* 1 */
    PKT_HEARTBEAT,            /* 2 */
    PKT_CANCEL    = 0x10,     /* 可跳号 */
    PKT_ACK                    /* 0x11 */
};
enum pkt_type t = PKT_QUOTE;
```

- 编译期整型常量;底层类型通常是 `int`(C23 起可指定底层类型)
- 默认从 0 递增,可显式赋值跳号
- **优于 `#define`** 之处:① 调试器可见名字 ② 有作用域 ③ 可被 switch 检查完整性(`-Wswitch`)

### const 对象(只读变量)

```c
const int max_retry = 3;        /* 只读, 可进 .rodata */
static const char *g_name = "default";
```

- **不是编译期常量**:不能用作数组长度(需 C99 VLA)、case 标签、位域宽度
- 想要"编译期符号常量"用 `#define` / `enum` / `static const` + 编译器折叠

### 三种"常量"机制对比

| 机制 | 编译期? | 类型检查 | 作用域 | 调试可见 | 典型用途 |
|------|---------|----------|--------|----------|----------|
| `#define MAX 10` | 是 | 无 | 全文件 | 替换后不可见 | 数组长度、宏 |
| `enum { MAX=10 }` | 是 | 有(int) | 块/文件 | 可见名字 | 状态码、协议类型 |
| `const int x=10` | 否(运行期只读) | 有 | 块/文件 | 可见 | 配置、只读表 |

## 与 HFT/DPDK

### 协议魔数与掩码

```c
#define MAGIC 0x54494301UL       /* "TIC" + 0x01 */
enum { MASK_LEN = 0xFFFF, MASK_SEQ = 0xFFFF0000UL };
const uint32_t g_seq_mask = 0xFFFF0000UL;   /* .rodata, 可取地址 */
```

### 字符串拼接做 help/version

```c
static const char version[] =
    "hft-gw 1.0 (built " __DATE__ " " __TIME__ ")\n"
    "compile: gcc -O2 -std=c11\n";
```

### enum 让 switch 完整性检查生效

```c
enum pkt_type { ORDER, QUOTE, HEARTBEAT };
const char *name(enum pkt_type t){
    switch (t) {
        case ORDER:     return "order";
        case QUOTE:     return "quote";
        case HEARTBEAT: return "hb";
    }   /* -Wswitch-enum: 漏 case 报警, 编译器无法保证 default */
}
```

### 字符串常量修改陷阱

```c
char *s = "hello";
s[0] = 'H';          /* UB: 可能 SIGSEGV(.rodata 只读) */
char a[] = "hello";  /* a 是栈数组, 拷贝, 可改 */
a[0] = 'H';          /* ok */
```

HFT 代码静态扫描常禁 `char *` 直接接字符串字面量,要求 `const char *`。

## 常见误区

| 误区 | 真相 |
|------|------|
| 八进制 `012` 等于十进制 12 | 等于十进制 10;leading 0 即八进制 |
| `sizeof("abc")` == 3 | == 4,含 `\0` |
| 修改字符串常量安全 | UB;放 .rodata 时 SIGSEGV |
| `const int N=10; int a[N];` 合法 | C89 不合法(非编译期常量);C99 VLA 可,但 static 文件域仍要编译期常量 |
| enum 底层一定是 int | C23 前基本是,但实现可选;C23 可指定 `enum x : uint8_t` |
| `1 << 32` 没问题 | 32 位 int 移位 ≥ 宽度是 UB,要 `1UL << 32` |

## 实操

```bash
cat > t.c <<'EOF'
#include <stdio.h>
#include <string.h>
int main(void){
  printf("sizeof 'A'=%zu\n", sizeof('A'));          /* C: 4 */
  printf("sizeof \"abc\"=%zu strlen=%zu\n",
         sizeof("abc"), strlen("abc"));              /* 4, 3 */
  enum { A=0, B, C=0x10, D };
  printf("B=%d D=%d\n", B, D);                       /* 1, 0x11 */
  char *s = "hi"; s[0]='H';                         /* UB, 可能崩 */
  return 0;
}
EOF
gcc -std=c11 -Wall t.c -o t && ./t   # 最后那行常段错误
readelf -p .rodata t                  # 看字符串常量段
```

## 代码自测

**题目 1：** 以下代码有什么问题？
```c
const int SIZE = 100;
int arr[SIZE];
```

<details>
<summary>参考答案</summary>

在 C89 中，数组大小必须是编译期常量表达式，const int 变量不是编译期常量（C 的 const 只读变量不同于 C++ 的 const）。C99 起支持变长数组（VLA），但 VLA 不能在文件作用域声明。正确做法：用 #define SIZE 100 或 enum { SIZE = 100 };。

</details>
