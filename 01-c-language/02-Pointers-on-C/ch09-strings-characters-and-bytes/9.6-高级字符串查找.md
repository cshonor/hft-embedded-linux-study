# 9.6 高级字符串查找

## 本节讲什么

**`strspn` / `strcspn` / `strpbrk` / `strtok`** 是 str 系列的"高级"查找函数：按**字符集**跳过、分隔、分词。它们仍是**文本 API**，依赖 `\0`，但提供了比 `strchr`/`strstr` 更强的模式匹配能力。`strtok` 是其中**最危险**的——它**修改原字符串**、**非重入**、用**静态缓冲**保存上下文，多线程场景必须用 `strtok_r`/`strtok_s`。

本节剖析各函数机制、组合使用范式与 strtok 的重入陷阱。

## 要点

### 函数清单

| 函数 | 原型 | 作用 | 返回值 |
|------|------|------|--------|
| **`strspn`** | `size_t strspn(const char *s, const char *accept)` | 前缀中属于 `accept` 的字节数 | `size_t` |
| **`strcspn`** | `size_t strcspn(const char *s, const char *reject)` | 前缀中不属于 `reject` 的字节数 | `size_t` |
| **`strpbrk`** | `char *strpbrk(const char *s, const char *set)` | `set` 中任一字符的首个位置 | 指针或 NULL |
| **`strtok`** | `char *strtok(char *s, const char *delim)` | 分词 | token 指针或 NULL |

### strspn / strcspn：跨度查找

```c
size_t strspn(const char *s, const char *accept);   /* 前缀属于 accept 的长度 */
size_t strcspn(const char *s, const char *reject);  /* 前缀不属于 reject 的长度 */
```

实例：

```c
strspn("   hello", " \t");    /* 3 —— 前 3 个空白 */
strspn("hello", " \t");       /* 0 —— 第一个字符非空白 */
strcspn("hello,world", ",;"); /* 5 —— 到 ',' 前 */
strcspn("hello", ",;");       /* 5 —— 无分隔符，到 \0 */
```

**经典组合：trim 前导空白 + 提取 token**

```c
char *p = line;
p += strspn(p, " \t");             /* 跳过前导空白 */
size_t len = strcspn(p, " \t,;");  /* token 长度 */
if (len) {
    char save = p[len];
    p[len] = '\0';
    process(p);
    p[len] = save;   /* 恢复或不恢复 */
}
p += len;
```

`strspn` 和 `strcspn` 是**只读**的，不修改 `s`，比 `strtok` 安全。

### strpbrk：字符集查找

```c
char *p = strpbrk("hello world", "aeiou");  /* p 指向第一个 'e' */
char *q = strpbrk("hello", "xyz");          /* q == NULL */
```

- 在 `s` 中查找 `set` 中**任意**字符的第一个出现
- 返回位置指针或 NULL
- 与 `strcspn` 关系：`strpbrk(s, set) == s + strcspn(s, set)`（若找到）

### strtok：分词（危险）

```c
char *strtok(char *s, const char *delim);
```

**机制**：

1. 首次调用传非 NULL 的 `s`
2. 跳过前导分隔符，记录 token 起点
3. 找到下一个分隔符，**将其替换为 `\0`**
4. 保存下一个 token 的起点到**静态缓冲**
5. 返回当前 token 指针
6. 后续调用传 `NULL` 作为 `s`，从静态缓冲恢复
7. 无更多 token 时返回 NULL

```c
char buf[] = "a,b,,c";
char *tok = strtok(buf, ",");
while (tok) {
    printf("[%s]\n", tok);   /* [a] [b] [c] —— 注意空 token 被跳过 */
    tok = strtok(NULL, ",");
}
/* buf 已被改为 "a\0b\0\0c\0" */
```

**strtok 的三个坑**：

| 坑 | 说明 | 后果 |
|----|------|------|
| **修改原串** | 分隔符被替换为 `\0` | 不可用于 `const char *` 或只读区 |
| **非重入** | 用静态缓冲保存上下文 | 多线程或递归调用混乱 |
| **跳过空 token** | 连续分隔符视为一个 | `"a,,c"` 得到 `[a][c]` 而非 `[a][][c]` |

### strtok_r / strtok_s：重入版

```c
char *strtok_r(char *s, const char *delim, char **saveptr);   /* POSIX */
char *strtok_s(char *s, rsize_t *smax, const char *delim, char **ptr); /* C11 Annex K */
```

- 上下文由调用方提供（`saveptr`），无静态缓冲
- **线程安全**
- 可重入——同一函数内可对多个字符串交替分词

```c
char buf[] = "a,b,c";
char *save, *tok;
for (tok = strtok_r(buf, ",", &save); tok; tok = strtok_r(NULL, ",", &save)) {
    process(tok);
}
```

### strsep：BSD 的分词替代

```c
char *strsep(char **stringp, const char *delim);
```

- BSD 起源，Linux 也支持
- **不跳过空 token**——`"a,,c"` 得到 `[a][][c]`
- **不修改分隔符位置**——通过移动 `*stringp` 指针
- 上下文由 `stringp` 提供，重入
- 比 `strtok_r` 更现代，但**可移植性稍差**（MSVC 无）

```c
char *p = buf;
char *tok;
while ((tok = strsep(&p, ",")) != NULL) {
    process(tok);   /* 空 token 也处理 */
}
```

### 工程选择

| 场景 | 推荐 | 理由 |
|------|------|------|
| 单线程文本分词 | `strsep` 或 `strtok_r` | 重入安全 |
| 多线程文本分词 | `strtok_r` / `strsep` | 无静态缓冲 |
| 二进制分词 | `memchr` 手动循环 | 与 `\0` 无关 |
| 跳过空白 | `strspn` | 只读，安全 |
| 提取 token 长度 | `strcspn` | 只读，安全 |

## HFT 关联

- **FIX 报文分词**：SOH(0x01) 分隔，但**不用 `strtok`**——报文可能含 0x00，且需保留空字段。用手动 `memchr` 循环：

```c
uint8_t *p = pkt, *end = pkt + pkt_len;
while (p < end) {
    uint8_t *sep = memchr(p, 0x01, end - p);
    size_t field_len = sep ? (size_t)(sep - p) : (size_t)(end - p);
    process_field(p, field_len);
    if (!sep) break;
    p = sep + 1;
}
```

- **CSV 日志解析**：文本，可用 `strsep`，但生产用 `memchr` 更可控
- **SBE 编码**：定长字段，schema 编译期已知，**根本不分词**
- **配置文件**：`strtok_r` 可用，但 `strsep` 更现代
- **多线程铁律**：DPDK 多 lcore 并发解析，**严禁** `strtok`

### 实操：strtok 破坏原串

```c
const char *literal = "a,b,c";
char *tok = strtok(literal, ",");   /* UB：修改 .rodata 段，SIGSEGV */
```

修复：

```c
char buf[] = "a,b,c";   /* 栈上副本，可修改 */
char *tok = strtok(buf, ",");
```

### 实操：strtok 非重入

```c
char a[] = "1,2,3";
char b[] = "x,y,z";
char *ta = strtok(a, ",");
char *tb = strtok(b, ",");   /* 覆盖了 a 的上下文！ */
ta = strtok(NULL, ",");      /* 得到 'y' 而非 '2' —— 上下文已乱 */
```

修复用 `strtok_r`：

```c
char *sa, *sb;
char *ta = strtok_r(a, ",", &sa);
char *tb = strtok_r(b, ",", &sb);
ta = strtok_r(NULL, ",", &sa);   /* 正确得到 '2' */
```
