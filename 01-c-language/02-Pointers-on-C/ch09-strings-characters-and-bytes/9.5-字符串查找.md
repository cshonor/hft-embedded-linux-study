# 9.5 字符串查找

## 本节讲什么

**`strchr` / `strrchr` / `strstr`** 在 `\0` 终止的 C 字符串中查找**字符**或**子串**。它们是文本解析的基础工具（配置 `key=value`、CSV 分隔、命令行 token 化），但**完全依赖 `\0` 作为扫描终点**，**不能用于二进制缓冲**——二进制场景需用 `memchr`（9.9）。本节剖析其机制、返回值陷阱与文本解析范式。

## 要点

### 函数清单

| 函数 | 原型 | 作用 | 返回值 |
|------|------|------|--------|
| **`strchr`** | `char *strchr(const char *s, int c)` | 正向找字符 `c` | 位置指针或 NULL |
| **`strrchr`** | `char *strrchr(const char *s, int c)` | 反向找字符 `c` | 位置指针或 NULL |
| **`strstr`** | `char *strstr(const char *s, const char *sub)` | 找子串 `sub` | 位置指针或 NULL |

### strchr 行为细节

```c
char *p = strchr("a,b,c", ',');   /* p 指向第一个 ',' */
char *q = strchr("abc", '\0');    /* q 指向终止 \0 —— 合法！ */
char *r = strchr("abc", 'z');     /* r == NULL */
```

- `c` 被转为 `unsigned char` 后比较（与 `is*` 不同，这里 `int` 是历史原因）
- **查找 `\0` 是合法的**——返回指向终止 `\0` 的指针
- 扫描到第一个匹配或 `\0` 停止

### strrchr：反向查找

```c
char *p = strrchr("/path/to/file.txt", '/');  /* p 指向最后一个 '/' */
```

- 从字符串**末尾**（即 `\0` 处）向前扫描
- 用于提取文件名、扩展名、URL 末段
- glibc 实现：先 `strlen` 找末尾，再反向扫，O(n)

### strstr：子串查找

```c
char *p = strstr("hello world", "wor");   /* p 指向 'w' */
char *q = strstr("hello", "");            /* q 指向 'h' —— 空子串返回 s */
char *r = strstr("hello", "xyz");         /* r == NULL */
```

- 空子串 `""` 返回 `s` 本身（C 标准规定）
- 复杂度 O(n*m) 朴素算法，glibc 用 Two-Way 算法 O(n+m)
- **不**用于二进制——`sub` 中的 `\0` 会提前截断

### 返回值 NULL 陷阱

```c
char *p = strchr(line, '=');
*p = '\0';   /* 若无 '='，p == NULL，SIGSEGV */
```

**铁律**：查找函数返回值**必须先判 NULL**再解引用：

```c
char *p = strchr(line, '=');
if (p) {
    *p = '\0';
    const char *value = p + 1;
    /* ... */
} else {
    /* 无等号，跳过或报错 */
}
```

### 文本解析经典范式

**配置 key=value**：

```c
char line[] = "timeout = 30";
char *eq = strchr(line, '=');
if (eq) {
    *eq = '\0';
    char *key = line;
    char *val = eq + 1;
    /* trim 空白 */
    while (*val == ' ') val++;
    /* ... */
}
```

**指针遍历文本**：

```c
for (char *p = line; *p; p++) {
    if (*p == ',') { /* 分隔符处理 */ }
    else { /* 字符处理 */ }
}
```

**多分隔符分词（预告 9.6）**：

```c
/* 简单版：单字符分隔 */
char *tok = strchr(line, ',');
while (tok) {
    *tok = '\0';
    process(line);
    line = tok + 1;
    tok = strchr(line, ',');
}
process(line);   /* 最后一段 */
```

### strpbrk：字符集查找

```c
char *p = strpbrk("hello world", "aeiou");  /* p 指向第一个 'e' */
```

- 在 `s` 中查找 `set` 中**任意**字符的第一个出现
- 返回位置指针或 NULL
- 用于多分隔符检测（如 `" \t,;"` 任一即分隔）

### strspn / strcspn：跨度查找

```c
size_t strspn(const char *s, const char *accept);   /* 前缀中属于 accept 的字节数 */
size_t strcspn(const char *s, const char *reject);  /* 前缀中不属于 reject 的字节数 */

strspn("   hello", " \t");   /* 3 —— 前 3 个空白 */
strcspn("hello,world", ",;"); /* 5 —— 到 ',' 前 */
```

- `strspn`：跳过前导字符集（如空白）
- `strcspn`：找下一个分隔符前的长度
- 二者配合实现 trim 和 tokenize（详见 9.6）

## HFT 关联

- **FIX tag 分隔**：FIX 用 SOH(0x01) 分隔 tag-value，`memchr(pkt, 0x01, pkt_len)` 查找，**不**用 `strchr`（报文无 `\0`）
- **配置文件解析**：`rte_eal` 参数、INI 文件可用 `strchr` 找 `=`
- **日志字段提取**：`strchr(log, ' ')` 找时间戳边界
- **协议 ASCII 字段**：HTTP/SMTP 等文本协议可用 `strstr` 查找 `"\r\n\r\n"` 头部结束标志
- **二进制绝对禁用**：报文含 0x00 时 `strchr` 在 0x00 处停止，丢失后续字节

### 实操：FIX 报文分隔

```c
/* 错误：用 strchr 查 SOH */
char *p = strchr(fix_msg, '\x01');   /* 若 fix_msg 含 0x00 提前停 */

/* 正确：用 memchr 显式长度 */
uint8_t *p = memchr(pkt, 0x01, pkt_len);
while (p && p < end) {
    /* 处理一个 tag-value */
    size_t field_len = p - pkt;
    /* ... */
    pkt = p + 1;
    p = memchr(pkt, 0x01, end - pkt);
}
```

### 实操：HTTP 头部结束检测

```c
/* HTTP 头部以 \r\n\r\n 结束 */
const char *hdr_end = strstr(buf, "\r\n\r\n");
if (hdr_end) {
    size_t hdr_len = hdr_end - buf + 4;
    /* 处理头部 */
}
```

这是 `strstr` 在文本协议的合法用例——HTTP 头部是 ASCII 文本，无 0x00。
