# 7.3.1 值拷贝无例外（传参必懂）

> 配套 [7.3 函数的参数](./7.3-函数的参数.md) · 入门对照 [K&R 1.8](../../01-Primer-K-and-R-C/ch01-introduction/1.8-参数传值调用.md)  
> **一句话：C 没有引用传递；所有参数一律值拷贝。传指针 = 拷贝地址数字。**

---

## 核心结论

有人说「所有参数都是指针地址」——**不准确**。更精确：

| 说法 | 对不对 |
|------|--------|
| 全部是值拷贝 | ✅ |
| 传指针时拷贝的是地址值 | ✅ |
| 普通 int / 结构体 / 数组「都是指针」 | ❌ int、struct 按值拷贝数据本身；数组形参**退化**成指针 |

**C 不存在引用传递、地址传递（作为独立机制）。**  
传指针时：拷贝的是指针里存的**地址值**，不是拷贝指针指向的那块对象。

---

## 1. 普通 `int` / `char`：拷贝数据本身

```c
void f(int x) {
    x = 100;   /* 只改副本 */
}

int main(void) {
    int a = 10;
    f(a);      /* a 仍是 10 */
}
```

把 `a` 里的 `10` 复制给栈上形参 `x`；`x` 与 `a` 互相独立。

---

## 2. 指针参数：仍是值拷贝（拷贝地址数字）

```c
void f(int *p) {
    *p = 100;   /* 用副本里的地址，改外部 a */
}

int main(void) {
    int a = 10;
    f(&a);      /* 把 &a 这个地址数字拷给 p */
}
```

流程：

1. `&a` → 地址（如 `0x4000`）  
2. 该数字拷贝给形参 `p`（栈上新指针副本）  
3. `*p = 100` → 解引用，改 `main` 里 `a` 的内存  

**拷贝的是地址，不是 `a` 的数据。**  
若只改指针本身：

```c
void f(int *p) {
    p = NULL;   /* 只改函数内副本 p；外部指针不变 */
}
```

---

## 3. 结构体：整块字节值拷贝

```c
struct S { int arr[1000]; };

void f(struct S s) { /* ... */ }

int main(void) {
    struct S obj;
    f(obj);   /* 整份 obj 拷进形参 —— 很贵 */
}
```

HFT / 嵌入式：**传 `struct S *s`（或 `const struct S *`）**，只拷 8 字节地址（AArch64/x86-64）。

---

## 4. 数组形参：退化成指针

```c
void f(int arr[]);   /* 等价于 void f(int *arr); */
```

不会把全部元素拷进函数；拷贝的是**首元素地址**。  
这是**函数参数特有的退化**，不是处处「数组=指针」。

`arr[0] = xxx` / `*(arr+0)` 可改外部数组元素；`arr = NULL` 只改副本。

---

## 统一表

| 参数类型 | 拷贝的是什么 | 改副本本身影响外面？ | 想改外部原数据 |
|----------|--------------|----------------------|----------------|
| `int x` | int 数值 | ❌ | 传 `&x`，`int *p`，`*p = …` |
| `int *p` | 地址数字 | ❌（`p=NULL` 无效） | `*p = …` |
| `struct S s` | 整结构体字节 | ❌ | 传 `struct S *s` |
| `int arr[]` | 首地址 | ❌（`arr=…` 无效） | `arr[i]=…` |

---

## 坑：想改外部「指针变量本身」

外面 `int *ptr;`，希望函数里让 `ptr = NULL`——一级指针形参做不到。

```c
void f(int **pp) {
    *pp = NULL;   /* 改的是外部 ptr 变量 */
}

int main(void) {
    int *ptr;
    f(&ptr);      /* 传指针变量自己的地址 */
}
```

---

## HFT / 嵌入式意义

传指针只复制地址宽度（常见 8 字节），避免拷巨大缓冲区 / 结构体 → 省内存带宽与 CPU 拷贝。底层 API 大量指针入参，根因在此。

---

## 思考题

```c
void change(int *p)  { p = NULL; }
void change2(int *p) { *p = 999; }

int main(void) {
    int a = 10;
    int *ptr = &a;
    change(ptr);
    change2(ptr);
}
```

| 调用后 | `a` 等于？ | 原因 |
|--------|------------|------|
| `change(ptr)` | **仍是 10** | 只把副本 `p` 置 NULL，未碰 `a` |
| `change2(ptr)` | **999** | `*p` 解引用改了 `a` |

（`ptr` 本身在两次调用后仍指向 `a`，因为一级指针形参改不了外部 `ptr`。）
