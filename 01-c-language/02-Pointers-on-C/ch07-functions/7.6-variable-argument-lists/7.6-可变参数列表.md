# 7.6 可变参数列表

## 本节讲什么

**`...` 可变参数**函数：`printf`、`rte_log` 等的基础。可变参是 C 的"灵活陷阱"——能写通用接口，但类型不检查、靠格式串或 count 约定。这一节是总览，实现细节在 7.6.1（stdarg 宏），限制在 7.6.2。

## 要点

- 至少一个**固定参数**（常为 `format` 或 `count`），作为 `va_start` 的锚点
- 编译器**不检查**可变部分类型 → 传错 → **UB**
- 底层优先**固定签名** API；日志/格式化场景再用可变参

### 典型签名

```c
int printf(const char *format, ...);              /* C 标准库 */
void rte_log(uint32_t level, const char *format, ...); /* DPDK 日志 */
void err(int status, const char *format, ...);    /* 自定义错误 */
```

### 为什么需要至少一个固定参数

`va_start(ap, last)` 需要 `last` 作为"最后一个固定参数"来定位可变参在栈/寄存器里的起始位置（**7.6.1**）。没有固定参数就找不到起点——所以 `...` 不能是唯一的参数。

### 可变参 vs 数组传参

```c
/* 可变参：类型异质，不检查 */
void logf(const char *fmt, ...);          /* %d 给 int，%f 给 double */

/* 数组传参：类型同质，有 count，安全 */
void log_n(int n, const struct evt *evs); /* 每个元素都是 evt */
```

可变参适合"异质类型 + 格式化"；同质批量用数组 + count 更安全。

## 底层映射

### 寄存器 + 栈混合传递

x86-64 ABI：固定参数和可变参前 6 个走寄存器（`rdi..r9`），超出进栈。`va_list` 实现是"寄存器保存区 + 栈溢出区"的抽象——`va_arg` 按类型从对应位置取。

```
调用 logf("level=%d price=%f", 3, 9.9):
  rdi = "level=%d price=%f"   (固定参数 fmt)
  rsi = 3                      (可变参 1, int)
  xmm0 = 9.9                   (可变参 2, double)
  栈上可能还有保存区
```

`va_arg(ap, int)` 从 `rsi` 区取，`va_arg(ap, double)` 从 `xmm` 区取。类型错了就读错位置 → 垃圾或崩。

### 默认参数提升（**7.6.2** 详）

可变参里 `float` → `double`，`char/short` → `int`。所以 `va_arg(ap, float)` 是**错的**，要 `va_arg(ap, double)`。固定参数**不**做这个提升。

## HFT / DPDK

| 用法 | 例子 |
|------|------|
| 日志 | `RTE_LOG(INFO, "pkt=%p\n", pkt);` |
| 格式化 | `snprintf(buf, n, "%s:%d", host, port);` |
| 调试打印 | `debug_dump("hdr=%p len=%zu", hdr, len);` |
| 错误 | `errx(1, "bad magic: 0x%x", magic);` |

### 工程纪律

- **数据面核心路径禁用可变参**：类型不安全、格式串解析开销、分支不可预测
- 日志（非热路径）可用，配 `__attribute__((format))` 让编译器检查（**7.6.2**）
- 批量数据用数组 + count，不用 `...`

## 常见误区

| 误区 | 事实 |
|------|------|
| "`...` 能传任意类型" | 能传，但取回时类型必须对，否则 UB |
| "可变参比数组灵活更好" | 灵活但不安全，热路径禁用 |
| "`f(...)` 能不要固定参数" | 不能，至少一个固定参数作锚点 |
| "可变参类型编译器会检查" | 不会，靠 format 串或人工约定 |

## 实操

```bash
# 看 printf 的可变参实现
gcc -O2 -S t.c -o - | grep -A20 'logf'
# __attribute__((format)) 让编译器检查格式串（7.6.2）
gcc -Wformat -Wformat-security t.c
# 故意传错类型看 UB
cat > t.c << 'EOF'
#include <stdio.h>
int main(void) { printf("%d\n", 3.14); return 0; }  /* 给 double 取 int */
EOF
gcc -Wformat t.c -o t && ./t        # 告警 + 运行时垃圾值
```
