## 这是什么

一份指针「语法分水岭」笔记：**同一个 `*`，声明里和表达式里含义完全不同。**

---

## 1. `*` 的两个场景

### ① 声明：`int *p;`

- `*` 属于**声明语法**，修饰变量名 `p`：`p` 是指针变量  
- `p` 本身存**地址**；`*p` 表示该地址上的 `int`  
- **正确读法：**「`p` 是指向 `int` 的指针」  
- ❌ 不要读成「`*p` 是变量」

语法特点：**`*` 贴变量，不是贴类型。**

```c
int* a, b;   /* a 是指针；b 只是普通 int —— 常见误读 */
int *a, *b;  /* 若两个都要指针，每个变量前都写 * */
```

### ② 表达式：`*p = 10;`

- `*` 是**解引用运算符**  
- 含义：取出 `p` 保存的地址，访问该地址对应的内存  

---

## 2. `&` 与 `*` 配对

```c
int x = 10;
int *p = &x;   /* &：取 x 的地址，赋给 p */
*p = 20;       /* *：顺着地址改内存 → x 变成 20 */
```

| 符号 | 直觉 |
|------|------|
| **`&`** | 拿盒子的门牌号（地址） |
| **`*`** | 拿着门牌号找盒子，读写里面的内容 |

---

## 3. 和 `argv` 的关联

```c
char *argv[];
```

- **声明场景：** `*` 修饰数组元素 → 每个元素是 `char *`  
- 作函数参数时常**退化**为 `char **argv`，仍遵守：声明 vs 解引用两套 `*` 规则  

（指针数组 vs 数组指针 → 后文 [6.x](./README.md) / Expert C 对照。）

## 自测 1：`*ptr = 666` 之后 `num`？

```c
int num = 100;
int *ptr = &num;   /* 注意是 &num，不是错误写法 # */
*ptr = 666;
```

**答：`num = 666`。**

### 完整拆解

```c
int num = 100;     /* 开辟 int 空间，存入 100 */
int *ptr = &num;   /* &num 取地址；ptr 保存该地址 */
*ptr = 666;        /* 解引用：顺着 ptr 找到 num，写入 666 */
```

内存视角（地址仅示意）：

| 变量 | 自己的地址（示意） | 里面存的内容 |
|------|-------------------|--------------|
| `num` | `0x100` | 先是 `100`，后被写成 `666` |
| `ptr` | `0x200` | `0x100`（`num` 的地址） |

`*ptr = 666` → 往 `0x100` 写入 → **直接改 `num` 本身**。

要点：

- `ptr` 只存放地址  
- `*ptr` 相当于 **`num` 的别名**，代表那块内存对象  

### 易混对比

```c
int num = 100;
int *ptr = &num;

ptr = (int *)0x999;   /* 只改 ptr 自己存的地址；num 不受影响（且此地址通常非法） */
*ptr = 666;           /* 改 ptr 指向的那块内存（num）——前提是 ptr 仍指向合法对象 */
```

| 写法 | 改的是谁 |
|------|----------|
| `ptr = …` | 指针变量自己（门牌号换了） |
| `*ptr = …` | 指向的对象（盒子里的内容） |

## 自测 2（追问）

```c
int a = 10;
int *p = &a;
int b = *p;   /* 把 *p 的值拷贝给 b */
*p = 20;      /* 改 a */
/* b 等于多少？a 等于多少？ */
```

**答：`b = 10`，`a = 20`。**

- `int b = *p`：读出当时的 `a`（10），**拷贝**进 `b`；之后 `b` 与 `a` 独立  
- `*p = 20`：只改 `a`，**不会**回头改已经拷走的 `b`

## 4. 解引用放左边还是右边？`*p1 = *p2`？

### 问题 1：`*` 能不能放在 `=` 左边？

**可以，而且非常常用。**

```c
int num = 100;
int *ptr = &num;

*ptr = 666;   /* ✔ *ptr 在左边：写内存 */
```

| 位置 | 含义 |
|------|------|
| `*ptr` 在 **`=` 左边** | **左值 / 写**：往该地址写入 |
| `*ptr` 在 **`=` 右边** | **读**：取出该地址里的值 |

```c
int a, b;
int *p = &a;

*p = 10;     /* 左边：写 → a = 10 */
b = *p;      /* 右边：读 → b = 10 */
```

`*` **本身不分左右**；看整个表达式在赋值的哪一侧，决定读还是写。

⚠ **声明里的 `*` 不是解引用：**

```c
int *p;   /* 声明语法：p 是指针；此阶段没有「解引用操作」 */
```

### 问题 2：能不能写成 `*p1 = *p2`（两边都带星）？

**合法，经典「拷贝指向的数据」。**

```c
int x = 10, y = 20;
int *p1 = &x;
int *p2 = &y;

*p1 = *p2;   /* 读 y → 写入 x；结果 x=20, y=20 */
```

拆解：

1. 右边 `*p2`：读 → 得到 `17`  
2. 左边 `*p1`：写 → 把 `17` 写入 `x`  
3. **`p1`、`p2` 里存的地址不变**（仍分别指向 `x`、`y`）

对比（不带星）：

```c
p1 = p2;   /* 拷贝地址 → p1 也指向 y；x 的值不变 */
```

| 代码 | 做了什么 |
|------|----------|
| `*p1 = *p2;` | 拷贝**指向的数据** |
| `p1 = p2;` | 拷贝**指针里的地址** |

### 易错坑：野指针当左值

```c
int *p;
*p = 99;   /* ❌ 野指针写随机内存 → 崩溃 / UB */
```

解引用无论左右，前提：**指针必须指向合法对象。**

### 自测 3

```c
int m = 1, n = 2;
int *q1 = &m;
int *q2 = &n;
*q1 = *q2;   /* ① */
q1 = q2;     /* ② */
/* m、n 最终分别等于多少？ */
```

**答：`m = 2`，`n = 2`。**

1. `*q1 = *q2` → 把 `n` 的值 `2` 写入 `m` → `m=2, n=2`  
2. `q1 = q2` → 只让 `q1` 也指向 `n`；**不再改 `m`/`n` 的数值**（仍是 2 和 2）

## 5. 指针创建后还能改指向吗？

**能。** 普通 `int *p` 完全可以改它存的地址——**不带 `*`**，直接把指针名放在 `=` 左边。

```c
int a = 100, b = 200;
int *p = &a;   /* p 存 a 的地址 */
p = &b;        /* ✅ 改 p 本身 → 现在指向 b */
```

| 代码 | 操作对象 | 是否改变「指向哪里」 |
|------|----------|----------------------|
| `p = &xxx;` | 指针变量 `p` 本身 | ✅ 更新 `p` 里存的地址 |
| `*p = val;` | `p` 指向的内存 | ❌ 地址不变，只改目标数据 |

### 两段对比

```c
int a = 10, b = 20;
int *p = &a;

p = &b;    /* 不带 *：改指向 → p→b；a 仍是 10 */
*p = 99;   /* 带 *：改内容 → b 变成 99；p 仍指向 b */
```

示意：

```text
int *p = &a;   →  p 里是 a 的地址
p = &b;        →  p 里改成 b 的地址（指向切换）
*p = 99;       →  p 仍是 b 的地址；b 的内容写成 99
```

### `const` 时要小心

```c
int x = 1, y = 2;

const int *p = &x;
p = &y;      /* ✅ 可以改指向；不能 *p = 10 改内容 */

int * const q = &x;
q = &y;      /* ❌ q 本身被 const 锁住，不能改指向 */
```

普通 `int *p`（无 const）→ **指向随便改**。  
展开：`const` 四式见 [6.9 指针常量](./6.9-指针常量.md)。

### 自测 4

```c
int v1 = 11;
int v2 = 22;
int *ptr = &v1;
ptr = &v2;     /* ① 改指向 → 指向 v2 */
*ptr = 999;    /* ② 改 v2 的内容 */
/* v1、v2 最后分别是多少？ */
```

**答：`v1 = 11`，`v2 = 999`。**

- `ptr = &v2` 只切换指向，**不动 `v1`**  
- `*ptr = 999` 写的是当前指向的 `v2`

## 6. 指针能不能再 `&`？——`&p1` 合法

术语先分清：

| 符号 | 名字 | 作用 |
|------|------|------|
| **`&`** | 取地址（取指符） | 拿到变量的内存地址 |
| **`*`** | 解引用 | 顺着地址拿内容 |

`p1` 是指针变量，**它自己也占内存**，所以 **`&p1` 完全合法**。

```c
int a = 10;
int *p1 = &a;

/* p1  → 存着 a 的地址
 * *p1 → 解引用 → a 的值（10）
 * &p1 → 取 p1 自己的地址 → 类型是 int **
 */
int **pp = &p1;   /* ✅ */
```

层级：

```text
a     ：普通 int
p1    ：int *，保存 a 的地址
&p1   ：p1 自身的地址，类型 int **（二级指针）
```

| 表达式 | 含义 |
|--------|------|
| `pp` | 存 `p1` 的地址 |
| `*pp` | 等价于 `p1`（即 `a` 的地址） |
| `**pp` | 等价于 `*p1`（即 `a` 的值） |

`**pp` 拆解：先 `*pp` → 得到 `p1`；再 `*` → 得到 `a`。

### 易错

| 写法 | 含义 |
|------|------|
| `p1 = &a` | 把 `a` 的地址放进 `p1` → `p1` 指向 `a` |
| `pp = &p1` | 把 `p1` 自己的地址放进 `pp` → `pp` 指向 `p1` |

- `*p1` = 解引用（跟内容）  
- `&p1` = 取 `p1` 自身地址（产出二级指针）  
**两者完全不同。**

### 现实用途：函数里改外面指针的指向

```c
void func(int **pp) {
    *pp = NULL;   /* 改外面 p 里存的地址 */
}

int main(void) {
    int *p;
    func(&p);     /* 传 &p */
}
```

展开：[6.10 指针的指针](./6.10-指针的指针.md) · [7.3.1 值拷贝](../ch07-functions/7.3.1-值拷贝无例外.md)。

### 自测 5

```c
int x = 100;
int *p = &x;
int **pp = &p;

/* *pp 等于什么？
 * **pp 等于什么？
 * &p 是什么类型？
 */
```

**答：**

| 表达式 | 结果 |
|--------|------|
| `*pp` | 等于 `p`，即 `&x`（`x` 的地址） |
| `**pp` | 等于 `*p`，即 `x` 的值 **100** |
| `&p` | 类型 **`int **`** |

## 7. 内存与指针的本质

你的理解对：**指针存的是内存地址（编号）；`int *` / `char *` 里的 `int`/`char` 规定：从这个地址起，读多少字节、怎么翻译。**

### 1. 地址只是数字

例如 `0x2000` —— CPU 只知道「某个位置」。  
**不知道**从这里读几个字节、怎么解释。

### 2. 类型干两件事

```c
int  *p;
char *q;
```

`p`、`q` 里存的都是**地址数字**；差别在解引用时：

| 类型 | 解引用时 |
|------|----------|
| `int` | 通常读 **4** 字节，按整数规则拼 |
| `char` | 读 **1** 字节 |

例：`0x100..0x103` 存着字节 `01 00 00 00`（小端）：

- `int *pi` 指向 `0x100` → `*pi` 读 4 字节 → 得到 **1**  
- `char *pc` 指向 `0x100` → `*pc` 只读 1 字节 → 得到 **`0x01`**  

**同一地址、不同类型 → 读出结果可以完全不同。**  
（和 [SIGNED-UNSIGNED](../../../07-arm-architecture/aarch64-practice/SIGNED-UNSIGNED.md) 同一思路：比特靠「怎么读」解释。）

### 3. 指针变量自己也占内存

```c
int a = 10;
int *p = &a;
```

| | 是什么 |
|---|--------|
| `a` | 一块内存，存 `07`，按 `int` 解（常见 4 字节） |
| `p` | **另一块**内存，存的是 `a` 的地址（64 位常见 **8** 字节） |

`int *` 同时说明：

1. `p` 用来存地址  
2. 那地址指向的对象按 **`int`** 解析  

两层别混：

- **`p` 自己的内存** → 装地址编号  
- **`p` 指向的内存** → 靠类型告诉 CPU 怎么读  

### 4. 强制转换改的是「读法」，不是字节

```c
char *q;
int *pi = (int *)q;
```

一般**不改**内存里任何字节，只改解释规则：「请按 `int` 来读这个地址」。  
若实际只有 1 字节有效数据却用 `int *` 解引用 → 多读后面字节 → **越界 / UB**。

### 极简两句

1. **指针** = 存放内存地址编号的变量；地址负责定位起点。  
2. **`int*` / `char*` 里的类型** = 从该起点读多少字节、怎么翻译——不是「指针本身长什么样」。

### 自测 6（64 位机）

```c
int a;
int  *p = &a;
char *q = (char *)&a;   /* 或等价地讨论「指向同一地址的 char*」 */
/* p 占几个字节？q 占几个字节？ */
```

**答：`p` 和 `q` 作为指针变量，本身都占地址宽度——64 位上通常各 **8** 字节。**  
`int` / `char` 的差别在 **`*p` / `*q` 读几个字节**，不在指针变量自己的大小。  
（可用 `sizeof(p)`、`sizeof(q)` 验证；`sizeof(*p)` 才是 4，`sizeof(*q)` 才是 1。）

## 一句话

> 声明里的 `*` 告诉编译器「这是指针变量」；表达式里的 `*` 才是「跟着地址去读写」。  
> `*p` 可在 `=` 左（写）或右（读）；`*p1 = *p2` 拷数据，`p1 = p2` 拷地址。  
> **改指向用 `p = &x`（不带星）；改内容用 `*p = val`（带星）。**  
> **`&p` 取的是指针自己的地址 → `int **`；和 `*p` 不是一回事。**  
> **地址定位；类型规定怎么读。指针变量自己也只是一块存地址的内存。**

```c
int x = 42;
int *p = &x;  // 第一个 *
*p = 100;      // 第二个 *
```

<details>
<summary>参考答案</summary>

第一个 * 是声明中的指针修饰符——int *p 声明 p 是指向 int 的指针。第二个 * 是解引用操作符——*p 访问 p 指向的内存。同一个 * 符号在不同语境下含义完全不同：声明中是指针标记，表达式中是解引用。
