## 这是什么

一份指针「语法分水岭」笔记：**同一个 `*`，声明里和表达式里含义完全不同。**

---

## 1. `*` 的两个场景

### ① 声明：`int *p;`

- `*` 属于**声明语法**，修饰变量名 `p`：`p` 是指针变量  
- `p` 本身存**地址**；`*p` 表示该地址上的 `int`  
- **正确读法：**「`p` 是指向 `int` 的指针」  
- ❌ 不要读成「`*p` 是变量」

语法特点：**`*` 贴变量，不是贴类型。**

```c
int* a, b;   /* a 是指针；b 只是普通 int —— 常见误读 */
int *a, *b;  /* 若两个都要指针，每个变量前都写 * */
```

### ② 表达式：`*p = 10;`

- `*` 是**解引用运算符**  
- 含义：取出 `p` 保存的地址，访问该地址对应的内存  

---

## 2. `&` 与 `*` 配对

```c
int x = 10;
int *p = &x;   /* &：取 x 的地址，赋给 p */
*p = 20;       /* *：顺着地址改内存 → x 变成 20 */
```

| 符号 | 直觉 |
|------|------|
| **`&`** | 拿盒子的门牌号（地址） |
| **`*`** | 拿着门牌号找盒子，读写里面的内容 |

---

## 3. 和 `argv` 的关联

```c
char *argv[];
```

- **声明场景：** `*` 修饰数组元素 → 每个元素是 `char *`  
- 作函数参数时常**退化**为 `char **argv`，仍遵守：声明 vs 解引用两套 `*` 规则  

（指针数组 vs 数组指针 → 后文 [6.x](./README.md) / Expert C 对照。）

---

## 自测

```c
int num = 100;
int *ptr = &num;
*ptr = 666;
/* num 变成多少？为什么？ */
```

**答：** `num = 666`。`ptr` 存了 `num` 的地址；表达式 `*ptr` 就是 `num` 那块内存，赋值直接改写原变量。

---

## 一句话

> 声明里的 `*` 告诉编译器「这是指针变量」；表达式里的 `*` 才是「跟着地址去读写」。
