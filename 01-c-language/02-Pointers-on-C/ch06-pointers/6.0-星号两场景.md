## 这是什么

一份指针「语法分水岭」笔记：**同一个 `*`，声明里和表达式里含义完全不同。**

---

## 1. `*` 的两个场景

### ① 声明：`int *p;`

- `*` 属于**声明语法**，修饰变量名 `p`：`p` 是指针变量  
- `p` 本身存**地址**；`*p` 表示该地址上的 `int`  
- **正确读法：**「`p` 是指向 `int` 的指针」  
- ❌ 不要读成「`*p` 是变量」

语法特点：**`*` 贴变量，不是贴类型。**

```c
int* a, b;   /* a 是指针；b 只是普通 int —— 常见误读 */
int *a, *b;  /* 若两个都要指针，每个变量前都写 * */
```

### ② 表达式：`*p = 10;`

- `*` 是**解引用运算符**  
- 含义：取出 `p` 保存的地址，访问该地址对应的内存  

---

## 2. `&` 与 `*` 配对

```c
int x = 10;
int *p = &x;   /* &：取 x 的地址，赋给 p */
*p = 20;       /* *：顺着地址改内存 → x 变成 20 */
```

| 符号 | 直觉 |
|------|------|
| **`&`** | 拿盒子的门牌号（地址） |
| **`*`** | 拿着门牌号找盒子，读写里面的内容 |

---

## 3. 和 `argv` 的关联

```c
char *argv[];
```

- **声明场景：** `*` 修饰数组元素 → 每个元素是 `char *`  
- 作函数参数时常**退化**为 `char **argv`，仍遵守：声明 vs 解引用两套 `*` 规则

## 自测 1：`*ptr = 666` 之后 `num`？

```c
int num = 100;
int *ptr = &num;   /* 注意是 &num，不是错误写法 # */
*ptr = 666;
```

**答：`num = 666`。**

### 完整拆解

```c
int num = 100;     /* 开辟 int 空间，存入 100 */
int *ptr = &num;   /* &num 取地址；ptr 保存该地址 */
*ptr = 666;        /* 解引用：顺着 ptr 找到 num，写入 666 */
```

内存视角（地址仅示意）：

| 变量 | 自己的地址（示意） | 里面存的内容 |
|------|-------------------|--------------|
| `num` | `0x100` | 先是 `100`，后被写成 `666` |
| `ptr` | `0x200` | `0x100`（`num` 的地址） |

`*ptr = 666` → 往 `0x100` 写入 → **直接改 `num` 本身**。

要点：

- `ptr` 只存放地址  
- `*ptr` 相当于 **`num` 的别名**，代表那块内存对象  

### 易混对比

```c
int num = 100;
int *ptr = &num;

ptr = (int *)0x999;   /* 只改 ptr 自己存的地址；num 不受影响（且此地址通常非法） */
*ptr = 666;           /* 改 ptr 指向的那块内存（num）——前提是 ptr 仍指向合法对象 */
```

| 写法 | 改的是谁 |
|------|----------|
| `ptr = …` | 指针变量自己（门牌号换了） |
| `*ptr = …` | 指向的对象（盒子里的内容） |

## 自测 2（追问）

```c
int a = 10;
int *p = &a;
int b = *p;   /* 把 *p 的值拷贝给 b */
*p = 20;      /* 改 a */
/* b 等于多少？a 等于多少？ */
```

**答：`b = 10`，`a = 20`。**

- `int b = *p`：读出当时的 `a`（10），**拷贝**进 `b`；之后 `b` 与 `a` 独立  
- `*p = 20`：只改 `a`，**不会**回头改已经拷走的 `b`  

---

## 一句话

> 声明里的 `*` 告诉编译器「这是指针变量」；表达式里的 `*` 才是「跟着地址去读写」。  
> `*p = …` 改对象；`p = …` 改指针自己。
