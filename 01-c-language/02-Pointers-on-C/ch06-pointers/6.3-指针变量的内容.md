# 6.3 指针变量的内容

## 本节讲什么

指针变量**存储的内容**是一个**地址值**——本质上是一个无符号整数（`uintptr_t` 可互转）。指针变量自己也在内存里，自己也有地址。搞清"指针的内容""指针的地址""指针指向的对象"三者，是后面多级指针、调试、ABI 的基础。

## 要点

```c
int a = 1, b = 2;
int *p = &a;            /* p 的内容 = a 的地址 */

printf("%p\n", (void *)p);   /* p 的内容：a 的地址 */
p = &b;                      /* 指针变量自身可被赋值，改存 b 的地址 */
```

- 打印用 **`%p`** + **`(void *)`** cast（`%p` 规范要求 `void*`，否则 UB）
- 指针也有地址：`&p` 是"指向指针的指针"（**6.10**）
- 指针内容可转为整数：`uintptr_t addr = (uintptr_t)p;`（C99 定宽，往返合法）

### 三者关系图

```
变量名    内存地址      内存内容
 a      0x7ffd_0010  →  1          (int)
 p      0x7ffd_0008  →  0x7ffd_0010 (=&a，指针变量自身存的是 a 的地址)
&p      0x7ffd_0008   (p 这个变量自身的地址)
```

`p` 在地址 `0x7ffd_0008`，内容是 `0x7ffd_0010`（即 `a` 的地址）。`*p` 取 `p` 的内容当地址，去该地址读 → 得到 `1`。

## 底层映射

### 指针的存储位置

| 指针定义在哪 | 存储位置 | 生命周期 |
|-------------|---------|---------|
| 函数内局部 | 栈帧 | 函数返回即失效 |
| `static` / 全局 | `.data` / `.bss` | 程序全程 |
| `malloc` 出来的指针所指对象 | 堆 | `free` 前 |
| 指针本身是 `malloc` 的 | 堆 | 同上 |

### 寄存器分配（`-O2`）

优化器会把常用指针常驻寄存器，不落内存：

```c
int sum(const int *p, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += p[i];
    return s;
}
```

```
; x86-64 -O2 核心
.loop:
    mov     eax, DWORD PTR [rdi+rcx*4]   ; rdi = p（寄存器），无 &p
    add     esi, eax
    inc     rcx
    cmp     ecx, edx
    jl      .loop
```

`p` 全程在 `rdi`，没有"指针变量的内存地址"——取 `&p` 会强制 spill 到栈。所以**不要对循环里的指针取地址**，会破坏寄存器分配。

## HFT / DPDK

| 场景 | 用法 |
|------|------|
| 调试打印 | `RTE_LOG(DEBUG, "pkt=%p data=%p\n", (void *)m, (void *)m->buf_addr);` |
| 地址往返 | `(uintptr_t)ptr` 存进 32 位硬件寄存器（截断风险！） |
| 偏移计算 | `(char *)base + offsetof(...)` |
| 调试器 | `gdb: print &p` 看指针自身地址，`print p` 看内容 |

## 常见误区

| 误区 | 事实 |
|------|------|
| "`printf("%p", p)` 就行" | 规范要求 `%p` 配 `void*`，指针类型不匹配是 UB |
| "指针内容是 32 位" | 64 位系统指针 8 字节，强转 `uint32_t` 会截断高位 |
| "指针一直在内存里" | `-O2` 下常用指针在寄存器，取地址才落栈 |
| "`&p` 和 `p` 是一回事" | `&p` 是指针自身地址，`p` 是指向对象的地址 |

## 实操

```c
#include <stdio.h>
#include <stdint.h>
int main(void) {
    int a = 1;
    int *p = &a;
    printf("a     = %d   @ %p\n", a, (void *)&a);
    printf("p     = %p   (内容=a的地址)\n", (void *)p);
    printf("&p    = %p   (指针自身地址)\n", (void *)&p);
    printf("*p    = %d   (解引用)\n", *p);
    printf("as u  = 0x%lx\n", (unsigned long)(uintptr_t)p);
    return 0;
}
```
