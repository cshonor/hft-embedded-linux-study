# 6.7 指针和间接访问

## 本节讲什么

通过指针**间接读写的完整模式**——这是 C 函数"修改调用者变量"的唯一干净手段（值传递所致）。这一节把传址模式、ABI 寄存器传参、批量接口讲清，是 HFT 数据接口设计的地基。

## 要点

```c
void inc(int *p) {
    *p += 1;        /* 通过指针改调用者的变量 */
}

int x = 10;
inc(&x);           /* x 变为 11 —— 传的是 x 的地址 */
```

- C **一律值传递**：形参是实参的副本。要改外部变量，传**指针的副本**，通过解引用改原对象
- 读：`v = *p`；写：`*p = v`
- 多级间接：`**pp`（**6.10**）
- 函数参数指针常配 `const` 表示"不改所指对象"（**6.9**）

### 三种语义模型

| 声明 | 含义 | 调用者视角 |
|------|------|-----------|
| `void f(int v)` | 传值，函数拿副本 | 调用者变量不被改 |
| `void f(const int *p)` | 传只读指针 | 函数读但不改 |
| `void f(int *p)` | 传可写指针 | 函数能改原对象 |
| `void f(int **out)` | 传指针的指针 | 函数能改调用者的指针（**6.10**） |

## 底层映射

### ABI 寄存器传参

x86-64 System V：前 6 个整数/指针参数走寄存器（`rdi, rsi, rdx, rcx, r8, r9`），第 7 个起进栈。

```c
void inc(int *p) { *p += 1; }
```

```
; x86-64 -O2
inc:
    add     DWORD PTR [rdi], 1     ; 一条指令：p 在 rdi，直接 [rdi] += 1
    ret
```

`int *p` 走 `rdi`，函数体直接 `add [rdi], 1`——传指针几乎零开销（不拷贝整个对象）。传结构体则按字段规则，**ch10** 详。

### 为什么传指针比传大对象高效

```c
struct big { char data[1024]; };

void f_val(struct big b)     { /* 拷贝 1024 字节到栈 */ }
void f_ptr(const struct big *p) { /* 一条 mov，8 字节指针进寄存器 */ }
```

传 1KB 结构体要拷贝 1KB 到栈帧；传指针一条 `mov`。HFT 报文常上百字节，几乎全用指针。

## HFT / DPDK

### 输出参数模式

```c
/* 解析报文，成功返回 0，输出解析结果到 *out */
int parse(const uint8_t *in, size_t len, struct quote *out);

struct quote q;
if (parse(pkt, n, &q) == 0) {  /* &q 是输出参数 */
    use(&q);
}
```

返回值留作错误码，真正结果通过指针写回——Linux/DPDK 系统调用风格的标配。

### 批量接口

```c
/* DPDK 收包：把一批 mbuf 指针写入 pkts[]，返回数量 */
uint16_t n = rte_eth_rx_burst(port, q, pkts, BURST);
for (int i = 0; i < n; i++)
    process(pkts[i]);      /* pkts[i] 是 struct rte_mbuf* */
```

`pkts` 是 `struct rte_mbuf *[BURST]`——指针数组（**6.11**），调用者提供缓冲，函数填充。批量收发是 DPDK 性能关键。

## 常见误区

| 误区 | 事实 |
|------|------|
| "传指针一定比传值快" | 小对象（`int`）传值更快——少一次解引用 |
| "函数参数 `int a[]` 是数组" | 实际是 `int *a`，sizeof 退化（**6.11**） |
| "`const int *p` 不能改 p 自己" | 能改 p 指向，不能改 `*p`（**6.9**） |
| "输出参数必须用指针" | C23 引入 `out` 参数属性，但工程实践仍是指针 |

## 实操

```bash
# 看传指针生成的汇编（寄存器传参）
gcc -O2 -S t.c -o - | grep -A5 '^inc:'
# 看传结构体的开销对比
gcc -O2 -S t.c -o -         # f_val 会 sub rsp 大段，f_ptr 只 mov rdi
# ABI 文档：System V AMD64 ABI
```
