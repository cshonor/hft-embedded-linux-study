# 6.12 实例

## 本节讲什么

把前 11 节的指针知识**综合到一个实例**：模拟 DPDK 批量收包 + 指针遍历 + 空指针过滤 + const 报文缓冲。这一节是 ch06 的"综合演练"，把理论落到 HFT 数据面的真实代码模式。

## 要点

### 实例 1：指针数组批量处理（DPDK burst 模式）

```c
#define BURST 32
struct pkt { int type; /* ... */ };

void process_burst(struct pkt *pkts[BURST], int n)
{
    /* pkts 是指针数组，退化成 struct pkt ** */
    int i;
    for (i = 0; i < n; i++) {
        struct pkt *p = pkts[i];        /* *（pkts+i）取第 i 个指针 */
        if (p == NULL) continue;        /* 空指针过滤（6.6） */
        if (p->type == HEARTBEAT) continue;
        decode(p);
    }
}
```

关键点：
- `pkts[BURST]` 退化为 `struct pkt **`（**6.11**）
- `pkts[i]` ≡ `*(pkts+i)`，取"第 i 个指针"
- 判空 `p == NULL` 在解引用 `p->type` 之前（短路，**ch05**）

### 实例 2：连续数组的指针算术遍历

```c
void walk(struct pkt *base, int n)
{
    struct pkt *end = base + n;          /* 尾后一位（6.13.1） */
    for (; base < end; base++)           /* base 自增，步长 = sizeof(struct pkt) */
        decode(base);
}
```

关键点：
- `base + n` 是 one-past-end，合法但不能解引用（**6.13.1**）
- `base++` 步长 = `sizeof(struct pkt)`，不是 1 字节（**6.13.1**）
- `base < end` 同数组内比较，合法（**6.13.2**）
- 遍历改的是 `base` 本身，原数组不动（**6.8**）

### 实例 3：const 报文 + 可改元数据

```c
int handle(const uint8_t *in, size_t len, struct meta *out)
{
    /* in 只读：不改报文（6.9 const） */
    /* out 可写：写元数据 */
    if (len < HEADER_SIZE) return -1;            /* 边界检查 */
    const struct eth_hdr *h = (const struct eth_hdr *)in;
    out->ether_type = ntohs(h->ether_type);      /* 解析后写回 */
    return 0;
}
```

## 底层映射

### 两种遍历的 cache 行为对比

```
连续数组遍历（walk）：
  base, base+1, base+2 ... 地址连续
  → 预取器 detects 顺序访问 → 自动 prefetch → L1 命中率高

指针数组遍历（process_burst）：
  pkts[0] → 报文A（某地址）
  pkts[1] → 报文B（另一地址）
  → 每次解引用可能 cache miss → 延迟高
```

这是为什么 DPDK 把报文集中放 mempool（连续大块）而非零散 malloc——cache 友好。

### ABI 视角：`pkts` 走哪个寄存器

```c
void process_burst(struct pkt *pkts[32], int n);
```

x86-64 SysV ABI：`pkts`（`struct pkt **`）走 `rdi`，`n` 走 `esi`。函数体里 `pkts[i]` = `mov rax, [rdi + rsi*8]`（8 = 指针宽度）。

## 常见误区

| 误区 | 事实 |
|------|------|
| "`base + n` 解引用没事" | one-past-end 解引用是 UB |
| "指针数组遍历和连续数组一样快" | 指针数组每跳可能 miss，慢得多 |
| "const 报文也能改" | 改 `.rodata` 或 const 段会 `SIGSEGV` |
| "函数内 malloc 返回批量数组更方便" | 调用者管理生命周期更安全 |

## 代码自测

**题目 1：** 以下代码试图用指针遍历数组，有什么问题？
```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;
while (*p)
    printf("%d ", *p++);
```

<details>
<summary>参考答案</summary>

数组没有以 0 结尾，while (*p) 会在数组越界后继续读取内存，直到遇到值为 0 的内存位置才停止——这是未定义行为。对于非字符串数组，应该用索引或长度控制循环。

</details>
