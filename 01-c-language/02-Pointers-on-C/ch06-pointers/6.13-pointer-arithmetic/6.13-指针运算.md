# 6.13 指针运算

## 本节讲什么

指针的 **± 整数**、**相减**、**比较** 的规则与 **UB 边界**——DPDK 批量缓冲、报文偏移、ring buffer 的核心。这一节是总览，细节在 6.13.1（算术）和 6.13.2（关系）。**指针运算的 UB 边界是 C 最容易踩雷的地方之一**，本节先给全景。

## 要点

### 允许的运算

| 运算 | 含义 | 结果类型 |
|------|------|---------|
| `p + n` | 前进 n 个元素 | `T*` |
| `p - n` | 后退 n 个元素 | `T*` |
| `p - q` | 两指针间距（同数组） | `ptrdiff_t` |
| `p < q` / `==` / `!=` | 同数组内比较 | `int`（0/1） |
| `p++` / `p--` | 自增自减 | `T*` |

### 禁止的运算

| 运算 | 原因 |
|------|------|
| `p + q` | 两地址相加无意义 |
| `p * n` / `p / n` | 几何无意义 |
| `p << n` | 指针非整数 |
| 不同类型指针相减 | 步长不同，无意义 |
| 不同数组指针比较 | UB（除 `==`/`!=` 对 NULL 特例） |

### UB 边界（最易错）

| 操作 | 条件 | 后果 |
|------|------|------|
| `p + n` | 结果不在 `[数组头, 尾后一位]` | UB |
| `*p` | p 越界、悬垂、NULL | UB（常 SIGSEGV） |
| `p - q` | p、q 不在同一数组 | UB |
| `p < q` | p、q 不在同一数组（含尾后） | UB |
| `p == 0` | 任何指针都合法（判 NULL） | 合法 |

C99 6.5.6：指针加减结果必须在"同一数组对象内或尾后一位"，否则 UB。尾后一位（one-past-end）本身可形成可比较，但**不可解引用**。

## 底层映射

### 步长 = sizeof(T)

```c
int  *ip;  ip + 1;   /* 地址 + 4 字节 */
char *cp;  cp + 1;   /* 地址 + 1 字节 */
struct big *bp; bp + 1;  /* 地址 + sizeof(struct big) */
```

汇编上 `p + n` 通常是 `[reg + n*scale]`，scale = sizeof(T)，编译期常量。硬件 SIB 寻址（比例变址）原生支持 1/2/4/8 倍率：

```
; int *p; p[i] 访问
mov eax, [rdi + rsi*4]    ; scale=4，硬件比例变址
```

所以 `p[i]` 不生成 `imul`——比例因子在寻址模式里免费。

## HFT / DPDK

| 场景 | 运算 |
|------|------|
| 报文头部偏移 | `hdr = (struct eth_hdr *)(pkt + ETH_HLEN)` |
| ring buffer | `idx = (idx + 1) & mask`，指针版 `(p+1) == end ? base : p+1` |
| 批量收包 | `pkts[i]` ≡ `*(pkts + i)` |
| 长度计算 | `n = (struct pkt *)end - (struct pkt *)base` |

## 常见误区

| 误区 | 事实 |
|------|------|
| "`p + 1` 加 1 字节" | 加 sizeof(T) 字节 |
| "越界 1 个元素没事" | 形成尾后合法，解引用 UB |
| "两个指针总能相减" | 必须同数组，否则 UB |
| "指针能乘除" | 禁止，无几何意义 |
| "`p < q` 任何两指针都能比" | 必须同数组（含尾后），否则 UB |
