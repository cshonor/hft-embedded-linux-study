# 6.13.2 指针的关系运算

## 本节讲什么

同类型指针的 **`== != < > <= >=`** 比较与 **相减** 得元素个数的规则。这一节的关键是"**必须同一数组**"这个前提——违反就是 UB，而 UB 在 `-O2` 下会带来最阴险的静默错误。

## 要点

### 比较

- **同一数组**（含尾后一位）内比较有定义
- 不同无关对象的比较 → **UB**（除 `==`/`!=` 判 NULL 的特例）
- `NULL` 只用 **`==`** / **`!=`**（`p < NULL` 无意义）

```c
if (p == NULL) return;                        /* 合法 */
if (p >= arr && p < arr + n) { /* 在范围内 */ } /* 同数组，合法 */
if (p < q) { ... }                            /* p、q 必须同数组，否则 UB */
```

### 相减

```c
ptrdiff_t n = q - p;   /* 同数组：元素个数（不是字节数） */
```

- 类型 **`ptrdiff_t`**（有符号，`<stddef.h>`），通常 8 字节
- 结果是**元素个数**，不是字节数；要字节数先转 `char*`：`(char *)q - (char *)p`
- 不同数组相减 → **UB**
- 数组太大（`> PTRDIFF_MAX`）时相减也 UB——超大数组要小心

### `==` / `!=` 的特例

任意两指针（甚至不同类型）的 `==`/`!=` 在"都为 NULL"或"都指向同一对象"时有定义。这是判 NULL、判"两指针是否指向同一处"的基础。

## 底层映射

### `q - p` 的实现

```c
int arr[100];
int *p = arr + 10;
int *q = arr + 30;
ptrdiff_t d = q - p;   /* 20，元素个数 */
```

```
; x86-64 -O2
mov     rax, 30
sub     rax, 10          ; 地址差
sar     rax, 2           ; 除以 sizeof(int)=4（算术右移）
                            ; 结果 = 20
```

地址差 ÷ sizeof(T) = 元素个数。编译器用 `sar`（算术右移）除以 2 的幂——比 `idiv` 快得多。步长非 2 的幂时用 `imul` 凑倒数。

### 为什么"不同数组比较"是 UB

编译器假设"两指针比较只在其同一对象内有意义"，据此做优化：

```c
int a[10], b[10];
int *p = a, *q = b;
if (p < q) { ... }    /* UB：编译器可假设永远不成立或永远成立 */
```

`-O2` 下编译器可能直接折叠掉这个分支。真实行为"碰巧"成立不代表合法——下个编译器版本可能变。

## HFT / DPDK

| 场景 | 用法 |
|------|------|
| 范围检查 | `if (p >= base && p < base + n) { ... }` |
| 长度计算 | `size_t len = (char *)end - (char *)base;` |
| 元素个数 | `size_t cnt = (struct pkt *)end - (struct pkt *)base;` |
| ring buffer 满 | `(w + 1) % size == r`（用索引更安全） |
| 报文内偏移 | `off = (uint8_t *)cur - (uint8_t *)pkt;` |

### 字节数 vs 元素个数

```c
char  *base, *end;
size_t bytes = end - base;             /* char* 相减：字节数 */

int   *ib, *ie;
size_t elems = ie - ib;                /* int* 相减：元素个数 */
size_t bytes = (char *)ie - (char *)ib;/* 要字节数先转 char* */
```

记忆：**相减结果 = 元素个数，单位由指针类型决定**。要字节先 cast 成 `char*`。

## 常见误区

| 误区 | 事实 |
|------|------|
| "任意两指针都能 `<` 比较" | 必须同数组（含尾后），否则 UB |
| "`q - p` 是字节数" | 是元素个数；要字节先转 `char*` |
| "`p < NULL` 能判空" | 无意义，判空只用 `==`/`!=` |
| "不同数组相减碰巧对就行" | UB，下个编译版本可能错 |
| "`ptrdiff_t` 一定够大" | 超大数组（> PTRDIFF_MAX）相减 UB |

## 实操

```bash
# 看 q-p 生成的 sar/imul
cat > t.c << 'EOF'
#include <stddef.h>
ptrdiff_t sub_i(int *p, int *q)  { return q - p; }
ptrdiff_t sub_c(char *p, char *q){ return q - p; }
ptrdiff_t sub_s(short *p, short *q){ return q - p; }
EOF
gcc -O2 -S t.c -o -      # 对比 sar 2 / 无 / sar 1
# UBSan 抓跨数组比较
gcc -g -fsanitize=undefined t.c -o t && ./t
# 看链表跨节点比较的"碰巧行为"（演示 UB）
```
