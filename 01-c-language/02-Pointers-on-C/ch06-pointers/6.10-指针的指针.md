# 6.10 指针的指针

## 本节讲什么

**二级指针** `T **`：指向"指向 T 的指针"。它是"在函数内改调用者的指针"、"指针数组"、"argv"的语法基础。二级指针是新手最容易绕晕的地方，本节用内存图把它讲死。

## 要点

```c
int x = 10;
int *p = &x;        /* p 指向 x */
int **pp = &p;      /* pp 指向 p */

**pp = 20;          /* 改 x：**pp == *p == x */
*pp = &y;           /* 改 p 的指向：*pp == p，现在 p 指向 y */
```

### 三层关系图

```
地址         内容             变量
0x1000  →    10            ← x (int)
0x1008  →    0x1000        ← p  (int*)，内容是 x 的地址
0x1010  →    0x1008        ← pp (int**)，内容是 p 的地址

*pp   = 取 pp 内容当指针，去该地址 → 得到 p（即 &x 这个地址值本身）
**pp  = 取 *pp 内容当指针，去该地址 → 得到 x 的值（10）
```

记忆：`**pp` = "解两次引用"。每解一次就往数据方向走一层。

### 两种改动的区别（核心考点）

```c
**pp = 20;    /* 改 x 的值：p 不变，仍指向 x，但 x 变了 */
*pp  = &y;    /* 改 p 的指向：x 不变，p 现在指向 y */
```

## 底层映射

### 典型场景表

| 场景 | 签名 | 作用 |
|------|------|------|
| 改调用者的指针 | `void alloc(char **out)` | 函数内 `*out = malloc(...)` |
| 指针数组 | `char *argv[]` ≡ `char **` | main 参数 |
| 二维动态数组 | `int **` 行指针 | 每行独立 malloc |
| 链表删除 | `void del(node **head)` | 改头指针本身 |
| 回调注册 | `void reg(void **slot)` | 把句柄写回调用者 |

### "改调用者指针"完整示例

```c
int make_buf(char **out, size_t n) {
    char *p = malloc(n);
    if (!p) return -1;
    *out = p;          /* 把新指针写回调用者的 out */
    return 0;
}

int main(void) {
    char *buf = NULL;
    if (make_buf(&buf, 1024) == 0) {  /* 传 &buf，二级 */
        use(buf);
        free(buf); buf = NULL;
    }
}
```

为什么要二级？因为 C 值传递——`char *out` 形参是 `buf` 的副本，改 `out` 不影响 `buf`；传 `&buf`（`char**`），改 `*out` 才能真正写到 `buf`。

### 二维动态数组（行指针模型）

```c
int **grid = malloc(rows * sizeof(int *));
for (int i = 0; i < rows; i++)
    grid[i] = malloc(cols * sizeof(int));
grid[2][3] = 42;
```

```
grid ──→ [row0]──→ ┌──┬──┬──┬──┐
         [row1]──→ ┌──┬──┬──┬──┐
         [row2]──→ ┌──┬──┬──┬──┐  ← grid[2]
                   0  1  2  3     ← grid[2][3] = 42
```

行不连续——每行独立 malloc，遍历列可能 cache miss。HFT 要连续内存时改用一维数组 + 下标计算 `i*cols + j`（**ch08**）。

### argv 的真实类型

```c
int main(int argc, char *argv[]) {        /* argv 看似数组 */
    /* 实际退化成 char **argv */
    /* argv[i] 是 char*，指向第 i 个参数字符串 */
}
```

`char *argv[]` 在函数参数里**退化**为 `char **argv`（**6.11** 数组退化）。两者完全等价。

## 常见误区

| 误区 | 事实 |
|------|------|
| "`int **` 和 `int a[][]` 一回事" | 不是——`int **` 是行指针（每行独立），二维数组是连续 |
| "改 `*out` 就能改调用者指针" | 对，但 `out` 必须是 `T**`，传的是 `&调用者指针` |
| "`*pp = &y` 会改 x" | 只改 p 的指向，x 不变 |
| "argv 是数组" | 函数参数里退化成 `char**` |

## 实操

```c
#include <stdio.h>
int main(void) {
    int x = 10, y = 20;
    int *p = &x, **pp = &p;
    printf("x=%d *p=%d **pp=%d\n", x, *p, **pp);
    *pp = &y;                              /* p 改指向 y */
    printf("p now → y; x=%d y=%d *p=%d\n", x, y, *p);
    **pp = 99;                             /* 改 y */
    printf("y=%d\n", y);
    return 0;
}
```
