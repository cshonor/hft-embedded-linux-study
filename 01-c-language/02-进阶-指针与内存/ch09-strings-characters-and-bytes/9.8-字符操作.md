# 9.8 字符操作

## 本节讲什么

**`<ctype.h>`** 提供**字符分类**（`isalpha`/`isdigit`/`isspace` 等）和**大小写转换**（`tolower`/`toupper`）函数，用于 ASCII 文本解析（命令行 token、可读字段校验）。这族函数有一个**隐藏 UB 陷阱**：参数必须是 **`unsigned char` 的值或 `EOF`**，传 `signed char` 或 `int` 中带符号的 0x80-0xFF 会触发**未定义行为**。这个坑在处理 UTF-8 或扩展 ASCII 字节时尤其常见。

本节剖析机制、UB 陷阱与 HFT 文本场景的正确用法。

## 要点

### 函数清单

**分类函数**（返回非零为真，零为假）：

| 函数 | 判定 |
|------|------|
| `isalpha(c)` | 字母 `[A-Za-z]` |
| `isdigit(c)` | 数字 `[0-9]` |
| `isalnum(c)` | 字母或数字 |
| `isspace(c)` | 空白 ` \t\n\v\f\r` |
| `isupper(c)` / `islower(c)` | 大写 / 小写 |
| `isprint(c)` | 可打印（含空格） |
| `isgraph(c)` | 可打印（不含空格） |
| `ispunct(c)` | 标点 |
| `isxdigit(c)` | 十六进制 `[0-9a-fA-F]` |
| `iscntrl(c)` | 控制字符 |
| `isblank(c)` | 空白（仅 ` ` 和 `\t`，C99） |

**转换函数**：

| 函数 | 行为 |
|------|------|
| `tolower(c)` | 若大写转小写，否则原值 |
| `toupper(c)` | 若小写转大写，否则原值 |

### 正确用法

```c
#include <ctype.h>

if (isalpha((unsigned char)c))
    /* ... */;
if (isdigit((unsigned char)c))
    /* ... */;

int lower = tolower((unsigned char)c);
```

**铁律**：参数**必须**显式转 `(unsigned char)`，除非 `c` 已经是 `int` 且来自 `getchar()`（其值域已是 `0..255` 或 `EOF`）。

### UB 陷阱：signed char 传入

```c
char c = 0x80;          /* signed char，值 -128 */
isalpha(c);             /* UB！c 隐式提升为 int -128，不在 EOF 或 unsigned char 范围 */
```

**根因**：

- `is*` 函数的参数要求是 `int`，值域为 `0..UCHAR_MAX` 或 `EOF`（通常 -1）
- `char` 在 x86-64 Linux 上是 **signed**（`-fsigned-char` 默认）
- `char` 值 0x80 提升为 `int` 是 **-128**，不在合法值域
- glibc 实现用 `__ctype_b_loc()` 表查，负索引越界 UB
- 实际可能：返回随机值、段错误、或静默错误

**修复**：

```c
isalpha((unsigned char)c);   /* 0x80 作为 128 查表，安全 */
```

`unsigned char` 提升到 `int` 是 `0..255`，在合法值域内。

### 何时传 EOF

```c
int c = getchar();   /* 返回 0..255 或 EOF(-1) */
if (c == EOF) break;
if (isalpha(c))      /* 这里 c 可能是 EOF 或 0..255，都合法 */
    /* ... */;
```

`getchar`/`fgetc` 返回 `int` 正是为了能区分 EOF 和 0xFF 字节——若存到 `char` 再判 EOF，0xFF 会被误判为 EOF：

```c
char c = getchar();   /* 错误！0xFF 会被当作 EOF */
if (c == EOF) break;
```

### toupper/tolower 的返回值陷阱

```c
char c = 'a';
putchar(toupper(c));   /* 'A'，正确 */

/* 但若 c 已经是大写或非字母 */
toupper('A');   /* 'A'，原值返回 */
toupper('1');   /* '1'，原值返回 */
```

- 返回 `int`，需存 `int` 或转 `char`
- 同样需要 `(unsigned char)` 转换输入
- 不要写 `c += 'A' - 'a'`——可移植性差，且对非字母 UB

### 大小写不敏感比较

```c
int strcasecmp_safe(const char *a, const char *b) {
    while (*a && *b) {
        int ca = tolower((unsigned char)*a);
        int cb = tolower((unsigned char)*b);
        if (ca != cb) return ca - cb;
        a++; b++;
    }
    return (unsigned char)*a - (unsigned char)*b;
}
```

POSIX `strcasecmp` 已封装，但内部同样依赖 `unsigned char`。

### locale 影响

`is*` 和 `tolower`/`toupper` 行为受 `setlocale(LC_CTYPE, ...)` 影响：

- 默认 `"C"` locale：仅 ASCII 范围
- `setlocale(LC_CTYPE, "")`：使用环境 locale，可能识别 UTF-8 字母
- **HFT 场景**：协议解析应**禁用 locale**，固定 ASCII 语义，避免环境差异

### 性能特征

- glibc `is*` 用查表（`__ctype_b_loc()`），约 2-3 ns/次
- `tolower`/`toupper` 同样查表
- 简单范围判断（如 `'0' <= c && c <= '9'`）约 1 ns，更快但不可移植
- 热路径上批量分类可考虑手写内联

## HFT 关联

- **命令行 token 校验**：`rte_eal` 参数解析用 `isdigit` 校验端口号
- **可读 ASCII 字段**：FIX tag 名是数字，用 `isdigit` 校验
- **二进制 payload**：**严禁**用 `is*` 判定 payload 字节——payload 不是字符，是数值
- **大小写归一化**：协议字段（如 HTTP method `GET`/`get`）归一化用 `tolower`
- **locale 隔离**：HFT 进程启动时 `setlocale(LC_ALL, "C")`，确保 ASCII 语义
- **UTF-8 报文**：现代协议（如 JSON over WebSocket）可能含 UTF-8，`is*` 仅对 ASCII 字节有效，多字节序列需 ICU 库

### 实操：UB 复现

```c
#include <ctype.h>
#include <stdio.h>

int main(void) {
    char c = 0x80;   /* signed char = -128 */
    printf("isalpha(0x80 as char) = %d\n", isalpha(c));           /* UB */
    printf("isalpha(0x80 as uchar) = %d\n", isalpha((unsigned char)c));  /* 0 */
    return 0;
}
```

ASan/UBSan 下第一行会报：

```
runtime error: index -128 out of range for type 'const unsigned short (*)[256]'
```

### 实操：命令行端口号校验

```c
/* 安全版 */
int parse_port(const char *s) {
    for (const char *p = s; *p; p++)
        if (!isdigit((unsigned char)*p))
            return -1;
    long v = strtol(s, NULL, 10);
    if (v < 1 || v > 65535) return -1;
    return (int)v;
}
```

### 实操：二进制 payload 误用 is*

```c
/* 反例：用 isprint 过滤报文字节 */
for (size_t i = 0; i < pkt_len; i++)
    if (isprint(pkt[i])) putchar(pkt[i]);   /* UB：pkt[i] 是 uint8_t，但若 char 提升仍需转 */

/* 正例：直接打印十六进制 */
for (size_t i = 0; i < pkt_len; i++)
    printf("%02x ", pkt[i]);
```

`uint8_t` 提升到 `int` 是 `0..255`，技术上 `isprint((unsigned char)pkt[i])` 安全，但**语义错误**——payload 字节不是字符，`isprint` 判定无意义。
