# 15.5 流 I/O 总览

## 本节讲什么

stdio 按数据粒度分层：**字符 → 行 → 格式化 → 二进制块**。不同粒度对应不同接口，选型直接影响性能与正确性。这一节给出四层接口的总览、选型对照表，以及 HFT 工程里「禁止使用」的接口清单。

认知锚点：选对 I/O 接口是工程效率的第一步。配置文件用 `fgets`、日志用 `fprintf`、行情数据用 `fread`/`fwrite`——各有专攻。用错接口（如用 `fgetc` 读大文件、用 `sprintf` 拼字符串）是 C 工程的低级错误。

## 要点

### 四层粒度

```
字符     fgetc/fputc          逐字节，最细粒度
  ↓
行       fgets/fputs          文本行，配置/日志
  ↓
格式化   fprintf/snprintf     格式化文本，日志核心
  ↓
二进制   fread/fwrite         原始内存块，行情/struct
```

| 粒度 | 接口 | 典型场景 | 性能 |
|------|------|----------|------|
| 字符 | `fgetc`/`fputc` | 单字节解析、状态机 | 低（频繁函数调用） |
| 行 | `fgets`/`fputs` | 配置文件、文本日志 | 中 |
| 格式化 | `fprintf`/`snprintf` | 日志、调试输出 | 中（格式化开销） |
| 二进制 | `fread`/`fwrite` | 行情数据、struct 持久化 | 高（批量内存拷贝） |

### 选型对照表

| 数据类型 | 推荐接口 | 理由 |
|----------|----------|------|
| 文本配置 | `fgets` | 安全读行，含 `\n` |
| 日志输出 | `fprintf` + `fflush` | 格式化 + 落盘 |
| 二进制行情 | `fread`/`fwrite` | 批量内存拷贝 |
| 单字节解析 | `fgetc` | 状态机逐字节 |
| 字符串拼装 | `snprintf` | 限长安全 |
| 调试输出 | `fprintf(stderr, ...)` | 无缓冲立即输出 |

### 禁止使用的接口

| 接口 | 原因 | 替代 |
|------|------|------|
| `gets` | 无长度限制，缓冲区溢出 | `fgets` |
| `sprintf` | 无长度限制，缓冲区溢出 | `snprintf` |
| `scanf` 直接读用户输入 | 格式串漏洞 | `fgets` + `sscanf` |
| `vsprintf` | 无长度限制 | `vsnprintf` |

`gets` 已在 C11 移除。`sprintf` 仍在标准但**生产代码禁用**——缓冲区溢出是安全漏洞的高频来源。

### 接口的返回值检查

```c
/* 字符 I/O */
int c = fgetc(fp);
if (c == EOF) {
    if (feof(fp)) { /* 正常结束 */ }
    if (ferror(fp)) { perror("fgetc"); }
}

/* 行 I/O */
char *ret = fgets(buf, sizeof(buf), fp);
if (ret == NULL) {
    if (feof(fp)) { /* 正常结束 */ }
    if (ferror(fp)) { perror("fgets"); }
}

/* 二进制 I/O */
size_t n = fread(buf, sizeof(buf[0]), 32, fp);
if (n < 32 && ferror(fp)) {
    perror("fread");
}

/* 格式化 I/O */
int written = snprintf(buf, sizeof(buf), "x=%d", x);
if (written < 0 || (size_t)written >= sizeof(buf)) {
    /* 截断或错误 */
}
```

**每个 I/O 接口都要检查返回值**——不检查的 I/O 是 bug 来源。`feof`/`ferror` 区分正常结束与错误。

## HFT 关联

### 数据面绕过 stdio

```c
/* HFT 数据面不用 stdio 任何接口 */
/* 报文收发用 DPDK，日志用内存缓冲 */
struct rte_mbuf *pkts[32];
uint16_t n = rte_eth_rx_burst(port, q, pkts, 32);   /* 非 stdio */
```

数据面热路径完全绕过 stdio——缓冲、锁、格式化都是延迟敌人。用 DPDK 或直接系统调用。

### 控制面/管理面的选型

```c
/* 配置解析：fgets */
char line[256];
while (fgets(line, sizeof(line), cfg_fp)) {
    parse_config_line(line);
}

/* 日志输出：fprintf + fflush */
fprintf(log_fp, "[INFO] seq=%lu processed\n", seq);
fflush(log_fp);

/* 行情持久化：fwrite */
fwrite(batch, sizeof(batch[0]), 32, data_fp);

/* 历史回放：fread */
while (fread(&rec, sizeof(rec), 1, history_fp) == 1) {
    replay(&rec);
}
```

控制面/管理面对延迟不敏感，用 stdio 方便高效。**选型原则**：文本用 `fgets`/`fprintf`，二进制用 `fread`/`fwrite`。

### 日志格式化的安全拼装

```c
char line[512];
int n = snprintf(line, sizeof(line),
                 "seq=%lu bid=%u ask=%u ts=%lu",
                 seq, bid, ask, ts);
if (n < 0 || (size_t)n >= sizeof(line)) {
    /* 截断，标记 */
    line[sizeof(line) - 1] = '\0';
    fprintf(stderr, "log line truncated\n");
}
fputs(line, log_fp);
fputc('\n', log_fp);
```

`snprintf` 限长拼装，防止缓冲区溢出。检查返回值判断是否截断。**绝不使用 `sprintf`**。

## UB 边界

| 情形 | 后果 | 防护 |
|------|------|------|
| `gets` 使用 | 缓冲区溢出，安全漏洞 | 用 `fgets` |
| `sprintf` 使用 | 缓冲区溢出 | 用 `snprintf` |
| 不检查 `fread` 返回值 | 静默读错数据 | 检查返回元素个数 |
| `fgetc` 返回值存 `char` | EOF 误判 | 用 `int` 接收 |
| `fgets` 缓冲区过小 | 行被截断 | 缓冲区足够大 + 检查 `\n` |
