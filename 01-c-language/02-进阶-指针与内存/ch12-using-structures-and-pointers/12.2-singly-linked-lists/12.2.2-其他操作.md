# 12.2.2 其他操作

## 本节讲什么

单向链表的核心操作：**遍历、全链销毁、按 key 删除、头删**。这些是撤单、过期清理、防泄漏的核心。本节详细剖析每个操作的实现、陷阱、以及 HFT 线上常见 bug 模式。

## 要点

### 遍历

```c
void list_iterate(Quote *head) {
    for (Quote *cur = head; cur; cur = cur->next) {
        process_quote(cur);
    }
}
```

- `cur` 从 `head` 开始，沿 `next` 前进
- `cur == NULL` 时结束（末节点的 `next` 是 NULL）
- 复杂度 O(n)
- **禁止**在遍历中 free 当前节点——会丢失 `next`

### 全链销毁（防泄漏）

```c
void list_free_all(Quote **head) {
    Quote *cur = *head;
    while (cur) {
        Quote *tmp = cur;
        cur = cur->next;   /* 先存 next */
        free(tmp);         /* 再 free */
    }
    *head = NULL;
}
```

**铁律**：**先存 next，再 free 当前**

```c
/* 反例：free 后读 next，UB */
while (cur) {
    free(cur);
    cur = cur->next;   /* UAF！cur 已 free */
}
```

- free 后 `cur` 指向的内存可能被复用
- `cur->next` 读取的是已释放内存，UB
- 可能"看起来正常"（内存未复用），也可能立即崩溃

### 按 seq 删除

```c
int list_remove_by_seq(Quote **head, uint64_t target_seq) {
    Quote *cur = *head, *prev = NULL;
    while (cur) {
        if (cur->seq == target_seq) {
            if (prev)
                prev->next = cur->next;   /* 删中间/尾 */
            else
                *head = cur->next;        /* 删头节点 */
            free(cur);
            return 1;
        }
        prev = cur;
        cur = cur->next;
    }
    return 0;   /* 未找到 */
}
```

**关键点**：

- 需维护 `prev`（前驱指针）
- 删头节点时 `prev == NULL`，更新 `*head`
- 删中间/尾节点：`prev->next = cur->next`

### 二级指针简化删除

```c
int list_remove_v2(Quote **head, uint64_t target_seq) {
    Quote **pp = head;
    while (*pp) {
        if ((*pp)->seq == target_seq) {
            Quote *victim = *pp;
            *pp = victim->next;   /* 跳过 victim */
            free(victim);
            return 1;
        }
        pp = &(*pp)->next;
    }
    return 0;
}
```

`Quote **pp` 技巧：

- `pp` 始终指向"指向当前节点的指针"
- `*pp = victim->next` 自动处理头节点和中间节点
- 无需 `prev` 变量，代码更简洁

### 头删

```c
void list_pop_front(Quote **head) {
    if (!*head) return;   /* 空链表 */
    Quote *del = *head;
    *head = del->next;
    free(del);
}
```

- O(1)
- 需 `Quote **` 修改调用方的 head
- 空链表检查防 UB

### 查找

```c
Quote *list_find(Quote *head, uint64_t seq) {
    for (Quote *cur = head; cur; cur = cur->next) {
        if (cur->seq == seq) return cur;
    }
    return NULL;   /* 未找到 */
}
```

- O(n) 线性扫描
- 返回节点指针或 NULL
- **调用方必须判 NULL** 再解引用

### 长度

```c
size_t list_length(Quote *head) {
    size_t n = 0;
    for (Quote *cur = head; cur; cur = cur->next)
        n++;
    return n;
}
```

- O(n)
- 若频繁需要长度，应维护 `size` 字段（链表头结构体）

### 反转

```c
void list_reverse(Quote **head) {
    Quote *prev = NULL, *cur = *head;
    while (cur) {
        Quote *next = cur->next;
        cur->next = prev;   /* 反转指向 */
        prev = cur;
        cur = next;
    }
    *head = prev;
}
```

- O(n) 时间，O(1) 空间
- 三指针遍历：prev/cur/next

## 线上陷阱总结

### 陷阱 1：只 free 外层，漏嵌套堆指针

```c
typedef struct order {
    char *clordid;        /* 堆上字符串 */
    struct order *next;
} Order;

/* 反例：漏 free clordid */
void bad_free_all(Order **head) {
    Order *cur = *head;
    while (cur) {
        Order *tmp = cur;
        cur = cur->next;
        free(tmp);   /* 只 free 节点，clordid 泄漏！ */
    }
}

/* 正例：先 free 子对象 */
void good_free_all(Order **head) {
    Order *cur = *head;
    while (cur) {
        Order *tmp = cur;
        cur = cur->next;
        free(tmp->clordid);   /* 先 free 子对象 */
        free(tmp);            /* 再 free 节点 */
    }
    *head = NULL;
}
```

### 陷阱 2：free 后再读 next

```c
/* 反例 */
while (cur) {
    free(cur);
    cur = cur->next;   /* UAF！ */
}

/* 正例 */
while (cur) {
    Quote *next = cur->next;   /* 先存 */
    free(cur);
    cur = next;
}
```

### 陷阱 3：删头用 `Quote *` 无法改外部 head

```c
/* 反例 */
void bad_remove_head(Quote *head) {
    if (!head) return;
    Quote *del = head;
    head = head->next;   /* 只改局部变量！ */
    free(del);
}

Quote *mylist = /* ... */;
bad_remove_head(mylist);   /* mylist 不变，del 已 free → 悬垂 */
```

### 陷阱 4：malloc 未清零 → 野 next

```c
/* 反例 */
Quote *n = malloc(sizeof *n);   /* malloc，未清零 */
n->seq = 1001;
list_push_front(&head, n);   /* n->next 是垃圾值！遍历会越界 */

/* 正例 */
Quote *n = calloc(1, sizeof *n);   /* calloc，next 自动 NULL */
n->seq = 1001;
list_push_front(&head, n);   /* 安全 */
```

## HFT 关联

- **撤单处理**：`list_remove_by_seq` 按 order_id 删除
- **过期清理**：定时遍历，删除过期订单
- **批量释放**：`rte_pktmbuf_free` 批量归还 mbuf 到池
- **订单池销毁**：进程退出时 `list_free_all` 释放所有订单
- **valgrind 验证**：CI 流程用 valgrind 确保无泄漏

### 实操：撤单

```c
void cancel_order(Quote **order_pool, uint64_t order_id) {
    if (list_remove_by_seq(order_pool, order_id)) {
        log_info("order %lu cancelled", order_id);
    } else {
        log_warn("order %lu not found", order_id);
    }
}
```

### 实操：定时清理过期订单

```c
void purge_expired(Quote **head, uint64_t now_ts, uint64_t ttl) {
    Quote **pp = head;
    while (*pp) {
        if (now_ts - (*pp)->seq > ttl) {   /* seq 作为时间戳 */
            Quote *victim = *pp;
            *pp = victim->next;
            free(victim);
        } else {
            pp = &(*pp)->next;
        }
    }
}
```

注意：删除时 `pp` 不前进（因为 `*pp` 已变），保留时才前进。
