# 8.1.8 初始化

## 本节讲什么

数组**定义时**初始化；全局/static 未列元素自动补 **0**，栈数组未初始化是**脏值**。这一节还讲 VLA（变长数组）的栈溢出风险——HFT 热路径禁用。

## 要点

```c
int a[5] = {1, 2, 3};     /* a[0..2]=1,2,3；a[3..4]=0 */
int b[] = {1, 2, 3};      /* 长度推导为 3 */
int c[100] = {0};         /* 全部清零——工程常用 */
int d[10];                /* 栈：脏值；全局：全 0 */
```

| 存储 | 未初始化元素 |
|------|--------------|
| 全局/static | 0（`.bss` 运行时清零） |
| 栈 auto | 脏值（上一个栈帧残留） |

### 初始化规则

- initializer 列表元素少于数组大小 → 剩余补 **0**（C99 6.7.8）
- 列表多于数组大小 → 编译错误
- 不写 initializer：全局补 0，栈是脏值
- 指定初始化（C99）：`int a[10] = {[5] = 99};` 其余 0

### VLA（变长数组，C99）

```c
void f(int n) {
    char buf[n];   /* VLA，栈上，n 运行时定 */
}
```

- **HFT 热路径禁止大 VLA** → 栈溢出（n 运行时才知，无法预估）
- VLA 不可全局、不可初始化（`int v[n] = {0}` 非法）
- `sizeof(buf)` 是运行时值（非编译期常量）
- VLA 在 C11 降为可选特性（`__STDC_NO_VLA__` 可检测）

## 底层映射

### `.bss` 的自动清零

```c
int g[1000];   /* 全局，未初始化 */
```

```
$ objdump -h ./prog
.bss  000003e0 ...   # 0x3e0 = 992... 实际 4000 字节
```

`.bss` 段在 ELF 里只记大小不记内容——程序启动时内核把整段 mmap 清零（`/dev/zero` 映射），所以全局未初始化变量是 0，且**不占可执行文件空间**。这是为什么大缓冲放全局比放栈省可执行文件体积。

### 栈数组的脏值

```c
void f(void) {
    int a[10];   /* 栈，未初始化 */
    /* a 的内容是上一个用这段栈的函数留下的残值 */
}
```

栈帧复用：`f` 退出后，下一个函数的局部变量占用同一块栈，残留 `a` 的旧值。`-ftrivial-auto-var-init=zero` 强制栈变量清零（**ch06 6.5**）。

## HFT / DPDK

| 场景 | 选择 |
|------|------|
| 报文缓冲定长 | `char buf[2048] = {0}` 栈上 |
| 大缓冲 | `malloc` 或静态池（避免栈溢出） |
| 配置表 | 全局 `static const`，`.rodata`/`.bss` |
| 运行时大小缓冲 | 堆或 mempool，不用 VLA |

### 工程纪律

- 栈数组一律 `= {0}` 或显式赋值
- 大缓冲（> 几 KB）放堆或静态，不占栈
- VLA 仅在大小有上界且小、非热路径时用
- 全局大缓冲利用 `.bss` 自动清零，省代码体积

## 常见误区

| 误区 | 事实 |
|------|------|
| "栈数组自动清零" | 不，是脏值；全局才自动清零 |
| "VLA 和定长一样安全" | VLA 大小运行时定，栈溢出风险 |
| "全局大数组占可执行文件空间" | `.bss` 不占，只记大小 |
| "`int a[10] = {0}` 只清 a[0]" | 整个清零（剩余补 0 规则） |

## 实操

```bash
# 看栈数组脏值
cat > t.c << 'EOF'
#include <stdio.h>
void dirty(void){int a[4];printf("%d %d %d %d\n",a[0],a[1],a[2],a[3]);}
int main(void){int x[4]={0xdead,0xbeef,0xcafe,0xbabe};dirty();return 0;}
EOF
gcc -O0 t.c -o t && ./t   # 可能打印 0xdead 等残值
# 强制栈清零
gcc -ftrivial-auto-var-init=zero -O0 t.c -o t && ./t
# 看 .bss 大小
gcc -c t.c -o t.o && size t.o
```

## 代码自测

**题目 1：** 以下代码中 arr 的各元素值是什么？
```c
int arr[5] = {1, 2};
```

<details>
<summary>参考答案</summary>

arr = {1, 2, 0, 0, 0}。部分初始化时，未指定的元素自动初始化为 0。这是 C 的规则：只要有初始化列表，剩余元素就为零。如果完全不初始化（int arr[5];），在函数内是局部数组，元素值是不确定的。

</details>
