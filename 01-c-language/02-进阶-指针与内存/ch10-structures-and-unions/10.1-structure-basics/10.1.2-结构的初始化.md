# 10.1.2 结构的初始化

## 本节讲什么

struct 初始化有三种常用方式：**顺序初始化**（C89）、**指定成员初始化**（C99 `.field =`）、**零初始化**（`= {0}`）。DPDK mbuf 和协议头清零标配 `= {0}` 或 `memset`。本节剖析各方式、部分初始化的隐含规则、以及运行时清零的两种范式。

## 要点

### 顺序初始化（C89）

```c
QuoteHdr pkt = {1001, 9999, PKT_QUOTE};
```

- 值按**声明顺序**对应成员
- 顺序错位是常见 bug：`{9999, 1001, PKT_QUOTE}` 编译通过但语义错
- 可读性差，**不推荐**

### 指定成员初始化（C99，推荐）

```c
QuoteHdr pkt = {
    .seq      = 1001,
    .pkt_type = PKT_QUOTE,
    .price    = 9999,
};
```

- **顺序无关**，按名字绑定
- 可读性强，重构时改成员顺序不影响初始化
- 未列出的成员自动为 0
- GCC/Clang/MSVC（C99+）全支持

### 零初始化

```c
QuoteHdr pkt = {0};   /* 全部成员置 0 */
```

- `{0}` 是 C 标准约定的"通用零初始化"惯用法
- 对任意类型（struct/array/scalar）都有效
- 编译器展开为 `memset(&pkt, 0, sizeof pkt)` 或更优
- **DPDK/内核标配**：所有 struct 先零初始化再填字段

```c
/* 运行时清零 */
memset(&pkt, 0, sizeof pkt);   /* 等价于 pkt = (QuoteHdr){0}; */
```

### 部分初始化的规则

```c
QuoteHdr a = { .seq = 1001 };   /* price=0, pkt_type=0 */
QuoteHdr b = { 1001 };          /* price=0, pkt_type=0 */
```

**铁律**：**未列出的成员自动为 0**（C89/C99 一致）。这与局部变量"不初始化是垃圾值"**不同**——只要有初始化列表，未列出的成员都为 0。

**陷阱**：

```c
void f(void) {
    QuoteHdr pkt;   /* 无初始化列表 → 全部成员是垃圾值！ */
    pkt.seq = 1001; /* 仅 seq 有意义，price/pkt_type 仍是垃圾 */
}
```

### 嵌套 struct 的初始化

```c
struct pkt_head {
    uint32_t magic;
    struct quote_hdr quote;
    uint8_t  payload[64];
};

/* C99 指定成员 */
struct pkt_head h = {
    .magic   = 0xDEADBEEF,
    .quote   = { .seq = 1001, .price = 9999, .pkt_type = PKT_QUOTE },
    .payload = { 0x01, 0x02, 0x03 },   /* 其余自动 0 */
};

/* 嵌套可省略外层花括号（不推荐） */
struct pkt_head h2 = { 0xDEADBEEF, { 1001, 9999, PKT_QUOTE }, { 0x01 } };
```

### 数组成员的初始化

```c
struct buf {
    uint8_t data[8];
    size_t  len;
};

struct buf b = { .data = { 1, 2, 3 }, .len = 3 };   /* data[3..7] 自动 0 */
struct buf b2 = { .len = 0 };                        /* data 全 0 */
```

### 指定数组成员的初始化（C99）

```c
uint8_t crc_table[256] = {
    [0x00] = 0x00, [0x01] = 0x07, [0x02] = 0x0E,
    /* 其余自动 0 */
};
```

- 用 `[index] = value` 指定特定下标
- 适用于稀疏数组（如 CRC 表、字符映射表）

### 复合字面量（C99）

```c
pkt = (QuoteHdr){ .seq = 1001, .price = 9999 };   /* 运行时构造 */
```

- 在运行时创建临时 struct 值
- 可用于赋值、传参
- 生命周期到所在块结束

### 静态存储 vs 自动存储

```c
static QuoteHdr s_pkt = {0};   /* 静态存储：编译期初始化，进 .bss */
void f(void) {
    QuoteHdr a_pkt = {0};      /* 自动存储：运行时栈上初始化 */
}
```

- 静态 struct 的初始化值必须是**编译期常量**
- 自动 struct 可用运行时值初始化
- 静态零初始化进 `.bss` 段，无运行时开销

## HFT 关联

- **DPDK mbuf 初始化**：`struct rte_mbuf m = {0}` 是标准范式，避免未初始化字段导致 UB
- **协议头构造**：`struct eth_hdr eth = { .type = htons(0x0800) }`，其余字段后填
- **报文模板**：静态 `static struct order_tmpl = { .magic = MAGIC, .ver = 2 }`，复用时 `pkt = tmpl; pkt.seq = next_seq++;`
- **清零成本**：`memset(&pkt, 0, sizeof pkt)` 对 64 字节 struct 约 4-5 ns，HFT 热路径需评估是否可避免
- **共享内存初始化**：跨进程 struct 必须显式 `= {0}` 或 `memset`，不能依赖"BSS 自动清零"（共享内存不是 BSS）

### 实操：部分初始化陷阱

```c
void f(void) {
    QuoteHdr pkt;          /* 无初始化 → 垃圾值 */
    pkt.seq = 1001;
    /* pkt.price 和 pkt.pkt_type 是垃圾 */
    send_pkt(&pkt);        /* UB：发送了垃圾字段 */
}

/* 修复 */
void f_safe(void) {
    QuoteHdr pkt = {0};    /* 全 0 */
    pkt.seq = 1001;
    send_pkt(&pkt);        /* price=0, pkt_type=0，安全 */
}
```

### 实操：报文模板复用

```c
static const struct order_tmpl {
    uint32_t magic;
    uint16_t ver;
    uint8_t  type;
} order_base = {
    .magic = 0x4F524431,   /* "ORD1" */
    .ver   = 2,
    .type  = PKT_ORDER,
};

void send_order(uint64_t order_id, uint32_t qty) {
    struct order_pkt pkt = {0};
    memcpy(&pkt, &order_base, sizeof order_base);   /* 复制模板 */
    pkt.order_id = order_id;
    pkt.qty = qty;
    /* 发送 */
}
```
