# 13.3 在定义对象之前使用对象

> **Ch13 · Storage** · 《Modern C》第三版 · Jens Gustedt

## 前向引用与不完整类型

C 允许在完整定义之前"提到"一个类型或对象，但使用受限。

```c
/* 不完整类型：声明了但没定义大小 */
struct msg;          // 前向声明，此时 sizeof(struct msg) 未知
struct msg *p;       // ✅ 可以用指针（指针大小已知）

// p->field = 1;     // ❌ 不能访问成员（定义不完整）

/* 后面才给出完整定义 */
struct msg {
    uint16_t len;
    uint8_t  data[];
};

/* 现在 sizeof(struct msg) 已知，可以访问成员 */
p = malloc(sizeof(struct msg) + 100);
p->len = 100;
```

| 允许 | 不允许 |
|------|--------|
| 声明指向不完整类型的指针 | `sizeof(不完整类型)` |
| 传递不完整类型的指针给函数 | 解引用成员 |
| 函数原型中使用不完整类型 | 栈上分配不完整类型变量 |

> **HFT 应用**：DPDK 的 `struct rte_mbuf` 在头文件中是不完整类型，用户只持有指针，库内部才知道布局——这是 C 的封装手法（opaque struct 模式）。
