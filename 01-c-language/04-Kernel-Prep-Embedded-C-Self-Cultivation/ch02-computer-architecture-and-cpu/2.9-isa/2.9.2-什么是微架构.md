# 2.9.2 什么是微架构

## 本节讲什么

**同一 ISA 的不同硬件实现** —— 流水线深度、Cache、分支预测各异；二进制兼容，性能不同。

## 要点

```
ARMv8-A ISA
  ├── Cortex-A53（小核，低功耗）
  ├── Cortex-A78（大核，高性能）
  └── Apple M-series（定制宽发射）
```

| 微架构决定 | 与 ISA 无关的优化 |
|------------|-------------------|
| Cache 大小 | **2.4** |
| 流水线/OOO | **2.5** |
| 核数/互连 | **2.6** |

- **binfmt 相同** 可在同 ISA 不同芯片运行；benchmark 才反映微架构差异  
- DPDK release notes 常列 **经测 CPU 型号**（NUMA、Cache 相关）

## 代码自测

**题目 1：** 微架构设计中有哪些经典优化技术？它们分别解决什么问题？

<details>
<summary>参考答案</summary>

(1)流水线：提高吞吐量；(2)超标量：每周期多条指令；(3)乱序执行：利用 ILP；(4)分支预测：减少控制冒险；(5)Cache：减少内存延迟；(6)SMT：利用线程级并行；(7)SIMD：数据级并行。微架构设计是在面积、功耗、性能之间权衡——不同设计点面向不同市场。

</details>
