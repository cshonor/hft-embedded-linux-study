# 2.5.1 流水线工作原理

## 本节讲什么

**取指 → 译码 → 执行 → 访存 → 写回** 五级重叠 —— 同一时刻多条指令处于不同阶段。

## 要点

```
周期:  1    2    3    4    5
I1:   IF   ID   EX   MEM  WB
I2:        IF   ID   EX   MEM  WB
I3:             IF   ID   EX   ...
```

- **吞吐** ≈ 每周期完成一条（稳态）；**延迟** 仍是一条指令多级延迟之和  
- **流水线填满/排空** 时 CPI > 1  
- 嵌入式 Cortex-M 多为 **3 级简流水线**；x86/ARM A 系列 10+ 级

## 与后续衔接

**2.5.3** 冒险破坏重叠；**2.2.2** 各阶段对应 PC/ALU/寄存器写回。

## 代码自测

**题目 1：** 经典五级流水线的每个阶段做什么？
```
IF → ID → EX → MEM → WB
```

<details>
<summary>参考答案</summary>

IF（取指）：从 I-Cache 取指令。ID（译码）：解码指令、读寄存器。EX（执行）：ALU 运算。MEM（访存）：读写 D-Cache。WB（写回）：结果写回寄存器。理想情况下每个周期完成一条指令（CPI=1）。实际因冒险会导致 CPI > 1。

</details>
