# 2.5.7 单发射和多发射

## 本节讲什么

**每周期发射指令条数** —— 单发射（1 IPC 上限）vs 超标量多发射（>1 IPC）。

## 要点

| 类型 | 特点 |
|------|------|
| **单发射** | 简单 MCU，功耗低 |
| **多发射** | 多执行单元并行，需 OoO + 寄存器重命名 |

- **IPC × 频率 = 吞吐**；多发射受 **指令相关性、端口数** 限制  
- `perf stat` 可看 **instructions/cycles** 估算 IPC  
- DPDK 绑核 + 热路径内联，提高 **指令级并行** 利用率

## 与后续衔接

## 代码自测

**题目 1：** 单发射和多发射 CPU 的区别是什么？超标量的 IPC 为什么不能达到理论值？

<details>
<summary>参考答案</summary>

单发射：每周期取/执行 1 条指令，理论 IPC=1。多发射（超标量）：每周期取/执行多条指令，理论 IPC=N。实际 IPC 达不到理论值因为：(1)指令间有数据依赖；(2)资源冲突；(3)分支预测失败；(4)Cache 未命中。典型 CPU IPC 约 2-3。

</details>
