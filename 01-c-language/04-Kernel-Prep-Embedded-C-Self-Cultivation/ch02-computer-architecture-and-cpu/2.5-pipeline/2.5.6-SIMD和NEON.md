# 2.5.6 SIMD 和 NEON

## 本节讲什么

**单指令多数据（SIMD）** —— 一条指令处理多个数据元素；ARM **NEON**，x86 **SSE/AVX**。

## 要点

```c
/* 概念：4×float 并行加 */
vaddq_f32(a, b);  /* NEON 128-bit 向量 */
```

| ISA | 向量扩展 |
|-----|----------|
| **ARM** | NEON（AArch32/AArch64） |
| **x86** | SSE / AVX / AVX-512 |

- 适用：**checksum、CRC、批量 memcpy、图像/信号**  
- DPDK **`rte_vect`** 封装 SIMD 路径；HFT 批量行情解析可手动 intrinsics  
- 需 **内存对齐**（16/32B）；未对齐可能慢或 fault

## 与后续衔接

**2.7.2** GPU 更大规模并行；**ch03** ARM NEON 汇编指令。

## 代码自测

**题目 1：** SIMD 如何加速计算？以下操作用 NEON 需要几条指令？
```
// 4 个 int 加法
a[0]+=b[0]; a[1]+=b[1]; a[2]+=b[2]; a[3]+=b[3];
```

<details>
<summary>参考答案</summary>

SIMD（单指令多数据）用一条指令同时处理多个数据。NEON 是 ARM 的 SIMD 扩展，128 位寄存器可存 4 个 int32。4 个加法只需 1 条 NEON 指令：VADD.I32 Q0, Q0, Q1。SIMD 广泛用于图像处理、信号处理、AI 推理。

</details>
