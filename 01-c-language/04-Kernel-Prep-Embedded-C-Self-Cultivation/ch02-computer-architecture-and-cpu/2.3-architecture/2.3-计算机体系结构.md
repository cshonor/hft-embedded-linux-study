## 代码自测

**题目 1：** 冯诺依曼架构和哈佛架构的主要区别是什么？
```c
// 冯诺依曼：指令和数据共用一条总线
// 哈佛：指令和数据各有独立总线
```

<details>
<summary>参考答案</summary>

冯诺依曼：指令和数据存储在同一内存，共用一条总线——取指和访存不能同时进行。哈佛：指令和数据分开存储，各有独立总线——取指和访存可同时进行，吞吐量更高。现代 CPU 多用改进哈佛架构（L1 Cache 分指令/数据，L2/L3 统一）。

</details>
