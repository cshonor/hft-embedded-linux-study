# 2.3.1 冯·诺依曼架构

## 本节讲什么

**五大部件 + 统一存储** —— 现代通用计算机骨架；指令与数据同存于内存，总线分时复用。

## 要点

| 部件 | 作用 |
|------|------|
| **ALU** | 算术/逻辑运算 |
| **CU** | 取指、译码、控制时序 |
| **存储器** | RAM 运行态 + ROM/Flash 固件 |
| **输入** | 按键、串口、传感器 |
| **输出** | 屏、PWM、电机 |

### 数据流

```
取指(PC) → 译码 → 读操作数(内存/寄存器) → ALU → 写回 → 更新 PC
```

- **C 赋值 `a = b + c`**：Load 到寄存器 → Add → Store 回内存（**2.2.2**）

### 特性与代价

- 指令/数据**同一内存** → 结构简单  
- 指令与数据争用总线 → 带宽瓶颈  

## 与后续衔接

## 代码自测

**题目 1：** CPU 的流水线（pipeline）为什么能提高性能？有什么风险？

<details>
<summary>参考答案</summary>

流水线将指令执行分为多个阶段（取指→译码→执行→访存→写回），不同指令的不同阶段可并行执行——提高吞吐率。风险：1) 数据冒险（后续指令依赖前指令结果）；2) 控制冒险（分支跳转导致流水线清空）；3) 结构冒险（资源冲突）。HFT 场景需要关注分支预测失败的开销——用 `likely`/`unlikely` 或消除分支。

</details>
