# 2.1 一颗芯片是怎样诞生的

## 本节讲什么

**从硅到封装** 的芯片制造全景 —— 理解「硬件从哪来」，为后续 CPU/总线/寄存器打物理直觉。

## 要点

| 阶段 | 关键 |
|------|------|
| **2.1.1 单晶硅** | 高纯硅锭 → 晶圆（Wafer） |
| **2.1.2 PN 结** | 半导体开关基础 |
| **2.1.3 电路** | 光刻、掺杂、多层金属互联 |
| **2.1.4 封装** | Die → 引脚/BGA，散热与 IO |

- 一颗 **SoC**（手机/MCU/DPDK 网卡芯片）在同一晶圆上集成 CPU、Cache、DMA、MAC  
- 制程（nm）决定晶体管密度与功耗；嵌入式选型先看 **封装引脚** 与 **工作温度**

## 代码自测

**题目 1：** 芯片制造的基本流程是什么？从沙子到芯片经历哪些主要步骤？

<details>
<summary>参考答案</summary>

基本流程：硅提炼 → 单晶硅锭生长 → 切割晶圆 → 光刻（多次） → 刻蚀 → 离子注入 → 金属化 → 封装测试。光刻是核心步骤——用紫外光通过掩模在硅片上转印电路图案。芯片制造是现代工业皇冠上的明珠，涉及物理、化学、材料等多学科。

</details>
