# 2.8.2 总线的概念

## 本节讲什么

**地址总线、数据总线、控制总线** —— 连接 CPU、内存与外设的「公路系统」。

## 要点

| 总线 | 作用 |
|------|------|
| **地址** | 选从设备（宽度决定寻址空间） |
| **数据** | 传输字/字节（32/64 bit） |
| **控制** | R/W、中断、DMA 请求、时钟 |

- **片上总线**：AMBA AHB/AXI（ARM SoC）；**片外**：PCIe、DDR  
- **带宽** = 频率 × 位宽 × 效率；瓶颈常在 **DDR 与 PCIe**  
- 冯·诺依曼 **指令/数据争用** 同一总线（**2.3.1**）

- HFT/DPDK：NUMA 下 **本地 PCIe 插槽** 到本地内存路径最短

## 代码自测

**题目 1：** 总线仲裁是什么意思？为什么多核 CPU 需要总线仲裁？

<details>
<summary>参考答案</summary>

总线仲裁决定哪个设备在冲突时优先使用总线。多核 CPU 中多个核可能同时请求总线访问内存，仲裁器根据优先级或轮转策略决定顺序。仲裁方式：集中式（单个仲裁器）和分布式（各设备协商）。仲裁延迟是多核扩展性的瓶颈之一——核越多争用越严重。

</details>
