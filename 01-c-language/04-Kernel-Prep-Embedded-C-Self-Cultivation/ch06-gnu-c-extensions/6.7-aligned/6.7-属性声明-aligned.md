# 6.7 属性声明：aligned

## 本节讲什么

**对齐（alignment）** 决定变量/结构体首址是否为 **2/4/8/64…** 的倍数，影响 **原子访问、SIMD、DMA、cache line**。GCC **`__attribute__((aligned(n)))`** 与 **`packed`** 控制布局；内核 `____cacheline_aligned`、DPDK `__rte_cache_aligned` 同源。

## 要点

- CPU 未对齐访问：ARM 可能 fault 或 kernel fixup；x86 慢路径
- **`aligned(n)`**：最小对齐字节数，须为 2 的幂
- **`packed`**：取消成员间 padding（**6.7.4**）

## 代码自测

**题目 1：** 以下代码中 `cache_line` 的 `sizeof` 是多少？为什么？如何验证？
```c
struct alignas_demo {
    char c;
} __attribute__((aligned(64)));

int sz = sizeof(struct alignas_demo);
```

<details>
<summary>参考答案</summary>

`sizeof(struct alignas_demo)` = 64。`__attribute__((aligned(64)))` 强制结构体按 64 字节对齐，编译器在 `c` 后填充 63 字节 padding 使总大小为 64 的倍数。用途：缓存行对齐（避免 false sharing）、DMA 对齐、SIMD 对齐。验证：`_Static_assert(sizeof(struct alignas_demo) == 64, "");` 或 `printf("%zu\n", sizeof(struct alignas_demo));`。C11 标准等价物是 `_Alignas(64)`。

</details>
