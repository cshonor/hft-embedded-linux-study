# 6.3.2 语句表达式

## 本节讲什么

语句表达式 **`({ ... })`** 内可含声明、循环、分支；**最后一个表达式**（带分号）的值类型即为整个语句表达式的类型。GCC 扩展，Clang 兼容。

## 要点

```c
int abs_diff(int a, int b)
{
    return ({
        int _a = a;
        int _b = b;
        _a > _b ? _a - _b : _b - _a;
    });
}
```

```c
/* 指针版本 — typeof 配合 */
#define swap_ptr(a, b) do {             \
    typeof(a) _tmp = (a);               \
    (a) = (b);                          \
    (b) = _tmp;                         \
} while (0)
```

规则摘要：

- 可有多条语句；**最后一条必须是表达式**  followed by `;`
- 内部变量作用域仅在 `({})` 内
- 类型 = 最后表达式的类型（含 const/volatile）
- 在 `-pedantic` 下可用 `__extension__ ({ ... })` 压制警告

```bash
echo 'int x = ({ int a=1; a+1; });' | gcc -std=gnu11 -x c -c - -o /tmp/t.o
echo 'int x = ({ int a=1; a+1; });' | gcc -std=c11   -x c -c - - 2>&1 | head
```

## 代码自测

**题目 1：** 以下 GNU C 扩展各有什么用途？
```c
__attribute__((aligned(64))) int cache_line;
__attribute__((packed)) struct S { char a; int b; };
__attribute__((weak)) void handler(void) {}
typedef typeof(int) my_int;
```

<details>
<summary>参考答案</summary>

`aligned(64)`：指定缓存行对齐，避免 false sharing。
`packed`：取消结构体填充，节省空间（但可能影响性能和可移植性）。
`weak`：弱符号，允许被其他同名强符号覆盖——用于可选钩子。
`typeof`：获取表达式类型，用于泛型宏（如 `container_of`）。
这些扩展在 Linux 内核中大量使用。非标准 C，但 GCC/Clang 支持。

</details>
