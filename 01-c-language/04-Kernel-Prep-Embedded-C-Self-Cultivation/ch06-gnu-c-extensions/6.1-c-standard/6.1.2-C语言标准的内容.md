# 6.1.2 C语言标准的内容

## 本节讲什么

一份 C 标准通常包含：**语言语法与语义**、**诊断规则**、**标准库**、**可移植性限制** 与 **附录**（常见缺陷、库概要）。理解章节划分有助于查「某特性从哪版标准开始合法」。

## 要点

| 部分 | 内容 |
|------|------|
| **语法/约束** | 声明、表达式、语句、翻译阶段 |
| **语义** | 对象存储期、链接、类型规则 |
| **库** | `<stdio.h>`、`<string.h>`、`<stdint.h>` 等 |
| **附录** | 未指定/未定义/实现定义行为清单 |

**翻译阶段（简化）**：

1. 三字符组 → 源字符
2. 拼接行、注释删除
3. **预处理**（`#include`、`#define`）
4. 字符常量转义
5. 翻译单元
6. 链接

```bash
gcc -E hello.c | less          # 只看预处理结果
gcc -save-temps -c hello.c     # 保留 .i 中间文件
```

- **实现定义（implementation-defined）**：编译器文档必须说明（如 `int` 位宽）
- **未指定（unspecified）**：合法但顺序等由实现决定

## 代码自测

**题目 1：** `container_of` 宏的实现原理是什么？
```c
#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))
```

<details>
<summary>参考答案</summary>

`container_of` 通过成员指针反推包含结构体的指针：1) `offsetof(type, member)` 计算成员在结构体中的偏移；2) `(char*)ptr - offset` 得到结构体起始地址；3) `(type*)` 转换为结构体类型指针。这是 Linux 内核链表的核心——链表节点嵌入在数据结构中，通过节点指针反推数据结构。需要 `typeof` 和 `offsetof`。

</details>
