# 6.4.2 typeof使用示例

## 本节讲什么

通过 **链表节点嵌入**、**泛型 min 宏**、**指针赋值** 三类示例掌握 typeof 在工程中的典型用法。

## 要点

```c
struct list_node { struct list_node *next; };

struct task {
    struct list_node link;
    int id;
    char name[16];
};

/* 从 link 指针得到 task — 前置 container_of 概念 */
#define list_entry(ptr, type, member) \
    container_of(ptr, type, member)
```

```c
#define TYPE_SAFE_MIN(a, b) ({              \
    typeof(a) _a = (a);                     \
    typeof(b) _b = (b);                     \
    _a < _b ? _a : _b;                      \
})

/* 不同整数类型自动 promotion */
long lv = TYPE_SAFE_MIN(100L, (short)3);
```

```c
void set_u32(uint32_t *p, uint32_t v) { *p = v; }

#define SET_FIELD(field, value) do {        \
    typeof(field) __v = (value);            \
    (field) = __v;                          \
} while (0)
```

```bash
gcc -std=gnu11 -Wall -c typeof_demo.c
```

- 避免 `typeof` 与 **side effect 参数** 同用：先赋临时再运算

## 代码自测

**题目 1：** 用 typeof 实现一个类型安全的 swap 宏，和传统宏有什么区别？
```c
// typeof 版本
#define SWAP(a, b) do { \
    typeof(a) _tmp = (a); \
    (a) = (b); \
    (b) = _tmp; \
} while (0)

// 传统版本（无 typeof）
#define SWAP_INT(a, b) do { int _tmp = (a); (a) = (b); (b) = _tmp; } while (0)
```
<details>
<summary>参考答案</summary>

typeof 版本优势：
1. **通用性**：`SWAP(a, b)` 可用于 int/float/指针/结构体等任意类型，无需为每种类型写不同宏
2. **类型安全**：`_tmp` 自动匹配 `a` 的类型，不会因类型不匹配导致精度丢失
3. **传统版本限制**：`SWAP_INT` 只能交换 int，交换 double 需另写 `SWAP_DOUBLE`

用法：
```c
int x = 1, y = 2;
SWAP(x, y);           // OK

double a = 1.5, b = 2.5;
SWAP(a, b);           // OK, _tmp 自动是 double

struct point p1, p2;
SWAP(p1, p2);         // OK, _tmp 自动是 struct point
```

C++ 的 `std::swap` 用模板实现同样效果。C 没有模板，typeof 是替代方案。

</details>
