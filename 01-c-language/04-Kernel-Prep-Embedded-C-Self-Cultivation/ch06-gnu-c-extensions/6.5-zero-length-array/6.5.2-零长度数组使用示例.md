# 6.5.2 零长度数组使用示例

## 本节讲什么

演示 **动态分配**、**访问尾部数据**、**释放** 完整流程；对应 **demo05** 可编译验证 `sizeof` 与布局。

## 要点

```c
#include <stdlib.h>
#include <string.h>
#include <stdint.h>

struct flex_msg {
    uint32_t id;
    uint32_t len;
    uint8_t  payload[0];
};

struct flex_msg *flex_msg_new(uint32_t id, const void *data, uint32_t len)
{
    struct flex_msg *m = malloc(sizeof(*m) + len);
    if (!m)
        return NULL;
    m->id = id;
    m->len = len;
    memcpy(m->payload, data, len);
    return m;
}

void flex_msg_free(struct flex_msg *m)
{
    free(m);
}
```

```c
/* 多个变长段 — 内核常单 FAM；用户态可嵌套设计 */
struct nvme_cmd {
    uint8_t  opcode;
    uint16_t flags;
    uint8_t  cdw[0];   /* 后续 cdw 数量由 flags 决定 */

```

| 操作 | 注意 |
|------|------|
| `malloc(sizeof(hdr)+n)` | n 为 payload 字节 |
| 拷贝 | `payload` 与头 contiguous |
| 越界 | 无编译期边界，需 `len` 字段约束 |

## 代码自测

**题目 1：** `container_of` 宏的实现原理是什么？
```c
#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))
```

<details>
<summary>参考答案</summary>

`container_of` 通过成员指针反推包含结构体的指针：1) `offsetof(type, member)` 计算成员在结构体中的偏移；2) `(char*)ptr - offset` 得到结构体起始地址；3) `(type*)` 转换为结构体类型指针。这是 Linux 内核链表的核心——链表节点嵌入在数据结构中，通过节点指针反推数据结构。需要 `typeof` 和 `offsetof`。

</details>
