# 6.5 零长度数组

## 本节讲什么

**零长度数组**（GNU：`char data[0]`）与 C99 **灵活数组成员（FAM）** `char data[]` 允许结构体 **末尾变长 payload**，一次 `malloc(sizeof(hdr)+payload_len)` 分配。内核 skbuff、NVMe 命令、DPDK mbuf 扩展区都属此类模式。

## 要点

```c
struct pkt_hdr {
    uint32_t len;
    uint8_t  data[0];   /* GNU 零长度；C99 写 data[] */
};
```

- 只能作 **结构体最后成员**
-  sizeof(struct pkt_hdr) **不含** data 占用
- 分配：`malloc(sizeof(*h) + payload_len)`

## 代码自测

**题目 1：** 零长度数组 `data[0]` 和普通指针 `*data` 作为结构体末尾成员有什么区别？
```c
struct hdr0 { int len; char data[0]; };  // 零长度数组
struct hdr1 { int len; char *data; };     // 指针
```

<details>
<summary>参考答案</summary>

零长度数组 `data[0]`：(1) `sizeof(struct hdr0)` 不含 data（通常 4 字节）；(2) data 紧跟在 len 后面，一次 `malloc(sizeof(struct hdr0) + payload)` 即可；(3) data 和 len 内存连续，缓存友好。指针 `*data`：(1) `sizeof(struct hdr1)` 含指针（通常 16 字节）；(2) 需要两次 `malloc`（结构体一次 + data 一次）；(3) data 指向的内存不连续。零长度数组适合固定头 + 变长 payload（如网络包）。C99 用 `char data[]` 替代 GNU `char data[0]`。

</details>
