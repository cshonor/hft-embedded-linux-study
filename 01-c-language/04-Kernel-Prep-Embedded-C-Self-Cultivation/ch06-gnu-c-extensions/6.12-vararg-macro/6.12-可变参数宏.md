# 6.12 可变参数宏

## 本节讲什么

C99 **可变参数宏** 与 GNU **`##__VA_ARGS__`** 构成 **`printk`/`RTE_LOG`** 风格 API。

## 要点

```c
#define LOG(fmt, ...) fprintf(stderr, fmt, ##__VA_ARGS__)
```

## 代码自测

**题目 1：** 可变参数宏 `__VA_ARGS__` 和可变参数函数 `va_list` 有什么区别？
```c
// 宏
#define LOG(fmt, ...) printf(fmt, __VA_ARGS__)
// 函数
void log_fn(const char *fmt, ...) {
    va_list ap; va_start(ap, fmt);
    vprintf(fmt, ap); va_end(ap);
}
```

<details>
<summary>参考答案</summary>

可变参数宏是编译期文本展开，`__VA_ARGS__` 替换为 `...` 对应的实参序列，没有类型检查；可变参数函数是运行期处理，通过 `va_list` 遍历参数，需要格式串推断类型。区别：(1) 宏在编译期展开，无运行时开销；函数有调用开销；(2) 宏的 `__VA_ARGS__` 可以为空（GNU 扩展 `##__VA_ARGS__` 处理空参），`va_list` 需要知道参数个数；(3) 宏不能递归，函数可以。内核 `printk` 用宏实现，应用层 `printf` 是函数。

</details>
