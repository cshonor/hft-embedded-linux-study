## 代码自测

**题目 1：** GCC 内建函数（`__builtin_*`）和普通函数有什么区别？为什么不直接用对应的库函数？
```c
// 内建
int n = __builtin_popcount(0xFF);  // 8
// 库函数
int n2 = __builtin_popcount(volatile_var);
```

<details>
<summary>参考答案</summary>

区别：(1) 内建函数不需要 `#include`，编译器直接识别；(2) 常量参数时编译期求值（`__builtin_popcount(0xFF)` 编译期得到 8）；(3) 某些内建没有对应库函数（如 `__builtin_expect`、`__builtin_prefetch`）；(4) 内建直接映射到目标平台指令（如 `popcount` → x86 `POPCNT`、ARM `VCNT`），无函数调用开销。不用库函数的原因：库函数需要链接、有调用开销、且不是所有平台都有对应实现。

</details>
