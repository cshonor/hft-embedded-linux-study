# 6.10.2 什么是内联函数

## 本节讲什么

**内联** = 编译器把函数体 **插入调用点**，像宏但 **有类型检查** 与 **单求值**。C99 **`inline` 关键字** 与 **`static inline`** 头文件模式是内核/DPDK 默认写法。

## 要点

```c
static inline uint32_t rol32(uint32_t x, int n)
{
    return (x << n) | (x >> (32 - n));
}
```

```c
/* C99 extern inline 模型（少用，易 ODR 踩坑） */
inline int helper(int x) { return x + 1; }
```

| 形式 | ODR / 链接 |
|------|------------|
| `static inline` in .h | 每 TU 副本，无符号冲突 |
| 普通函数 | 单一定义，`call` 指令 |
| 宏 | 文本替换，无类型 |

- **代码膨胀**：大函数 inline 增大 I-cache 压力
- **函数指针** 取址时通常 **必须** 产生 out-of-line 副本
- DPDK **`static __rte_always_inline`** 强制热路径展开

```bash
gcc -O2 -S inline.c -o inline.s
grep -c 'call' inline.s
```

## 代码自测

**题目 1：** 以下 GNU C 扩展各有什么用途？
```c
__attribute__((aligned(64))) int cache_line;
__attribute__((packed)) struct S { char a; int b; };
__attribute__((weak)) void handler(void) {}
typedef typeof(int) my_int;
```

<details>
<summary>参考答案</summary>

`aligned(64)`：指定缓存行对齐，避免 false sharing。
`packed`：取消结构体填充，节省空间（但可能影响性能和可移植性）。
`weak`：弱符号，允许被其他同名强符号覆盖——用于可选钩子。
`typeof`：获取表达式类型，用于泛型宏（如 `container_of`）。
这些扩展在 Linux 内核中大量使用。非标准 C，但 GCC/Clang 支持。

</details>
