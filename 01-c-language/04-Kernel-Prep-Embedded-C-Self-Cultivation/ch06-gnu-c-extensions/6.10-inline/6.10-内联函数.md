# 6.10 内联函数

## 本节讲什么

**inline 函数** 建议编译器 **就地展开**，消除调用开销；C99 标准 inline 与 **GNU `always_inline`/`noinline`** 并存。内核/DPDK **热点路径**大量使用 **static inline** 于头文件。

## 要点

```c
static inline int square(int x) { return x * x; }
```

## 代码自测

**题目 1：** `inline` 关键字只是"建议"编译器内联，编译器可能不内联。GNU C 有哪些方式强制控制内联行为？
```c
inline void f1(void) { ... }           // (A)
static inline void f2(void) { ... }    // (B)
__attribute__((always_inline)) inline void f3(void) { ... }  // (C)
__attribute__((noinline)) void f4(void) { ... }  // (D)
```

<details>
<summary>参考答案</summary>

(A) `inline`：标准 C99，只是建议，编译器可忽略，且需要 out-of-line 副本；(B) `static inline`：GNU C 常用，建议内联，不产生外部符号；(C) `always_inline`：强制内联，编译器必须展开（除非不可行如递归）；(D) `noinline`：强制不内联。内核用 `__always_inline` 和 `noinline` 宏包装。`always_inline` 用于：(1) 性能关键路径；(2) 依赖编译期常量优化的代码（如 `container_of`）。

</details>
