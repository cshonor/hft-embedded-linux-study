# 10.10 进程、线程和协程

## 本节讲什么

Linux 上 **进程、线程、协程** 是三种不同的 **执行流抽象**；与 **RTOS 任务** 对照，理解 **隔离、切换成本、适用场景**。本节总览 **10.10.1–10.10.5**，收束全书 **并发 vs 并行、syscall、MMU** 主线。

## 要点

**三者对比**：

| | 进程 | 线程 | 协程 |
|---|------|------|------|
| 地址空间 | 独立 | 共享 | 共享（同线程内） |
| 切换成本 | 高（页表、FD） | 中 | 低（用户态） |
| 创建 API | `fork/exec` | `pthread_create` | `ucontext`/语言内置 |
| 阻塞 | 独立 | 阻塞不卡其他线程 | yield 让出 |
| 典型 OS | Linux | Linux/RTOS | Go/async C |

**与 RTOS 任务对照**：

| RTOS 任务 | 更接近 |
|-----------|--------|
| FreeRTOS 任务 | 线程（共享地址空间）+ 抢占 |
| 无 MMU 多任务 | 线程但 **无隔离** |
| Linux 进程 | 独立 MMU + 资源 |

**并行 vs 并发**（**10.1**）：

- **多进程/多线程** 在多核上 → **并行**
- **单核多线程** → **并发**（内核时间片）
- **DPDK lcore**：线程绑核 + 轮询 → **避免内核调度**，追求并行

**同步共性**（**10.2.4**）：

- Linux：`pthread_mutex`, `sem_t`, `eventfd`
- RTOS：`xSemaphore`, `xQueue`, EventGroup
- 问题同源：**死锁、优先级反转、饿死**

**选型速查**：

| 需求 | 选择 |
|------|------|
| 强隔离、独立崩溃 | 多进程 |
| 共享数据多、要 SMP | 多线程 + 锁 |
| 海量连接、I/O 密集 | 协程/异步 |
| 硬实时、确定延迟 | RTOS 任务或 RT 线程 |

## 代码自测

**题目 1：** 临界区保护的方式有哪些？各有什么优缺点？
```c
// 1. 关中断
// 2. 自旋锁
// 3. 互斥锁
// 4. 原子操作
```

<details>
<summary>参考答案</summary>

1) 关中断：单核最简单，`cli`/`sti`——但影响系统响应，不适合长时间临界区。
2) 自旋锁：多核忙等——适合极短临界区，不适合用户态（浪费 CPU）。
3) 互斥锁：阻塞等待——适合长临界区，有上下文切换开销。
4) 原子操作：`__atomic`/`stdatomic.h`——无锁，适合简单操作（计数器、标志位）。
HFT 场景通常用无锁数据结构（原子操作 + 内存序）。

</details>
