# 1.2.4 CMake 基础

## 本节讲什么

**CMakeLists.txt** 生成 Makefile —— 跨平台、大型工程标准入口。

## 要点

```cmake
cmake_minimum_required(VERSION 3.16)
project(demo C)

set(CMAKE_C_STANDARD 11)
add_compile_options(-Wall -Wextra -g)

add_executable(app main.c util.c)
```

```bash
mkdir -p build && cd build
cmake ..
make
```

| 步骤 | 作用 |
|------|------|
| **cmake ..** | 生成构建文件 |
| **make** | 编译 |

- 交叉编译：`cmake -DCMAKE_C_COMPILER=arm-linux-gnueabihf-gcc ..`  
- 产物放 **build/**，源码树干净  

## 与后续衔接

DPDK/内核用自有构建系统；CMake 用于用户态练习工程。

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
