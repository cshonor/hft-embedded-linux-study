# 1.2.3 使用 make 编译程序

## 本节讲什么

**Makefile** 语法：目标、依赖、自动变量 —— 多文件工程模板。

## 要点

```makefile
CC      ?= gcc
CFLAGS  ?= -Wall -Wextra -std=c11 -g
LDFLAGS ?=

app: main.o util.o
	$(CC) $(LDFLAGS) -o $@ $^

main.o: main.c util.h
	$(CC) $(CFLAGS) -c $< -o $@

util.o: util.c util.h
	$(CC) $(CFLAGS) -c $< -o $@

.PHONY: clean
clean:
	rm -f *.o app
```

| 自动变量 | 含义 |
|----------|------|
| **$@** | 目标 |
| **$<** | 首依赖 |
| **$^** | 全部依赖 |

```bash
make all
make clean
```

- **.PHONY`** 声明伪目标  
- 大型工程见 **1.2.4 CMake**

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
