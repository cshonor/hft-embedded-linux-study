# 1.3.1 什么是版本控制系统

## 本节讲什么

**VCS** 作用：历史追溯、分支实验、协作合并 —— 嵌入式多板型/多章节代码管理。

## 要点

| 能力 | 说明 |
|------|------|
| **提交** | 快照保存可回滚 |
| **分支** | ch01 实验不影响 main |
| **diff** | 对比汇编/源码改动 |

- 分布式 **Git**：每人本地完整仓库，离线可提交  
- 替代：拷贝文件夹 `proj_v2_final` 不可维护  

## 与后续衔接

**1.3.3** 日常命令；内核/DPDK 均用 Git。

## 代码自测

**题目 1：** 版本控制系统解决什么问题？集中式（SVN）和分布式（Git）有什么区别？

<details>
<summary>参考答案</summary>

解决代码版本管理、多人协作、变更追溯问题。集中式（SVN）：有中央服务器，提交需要联网，分支较重。分布式（Git）：每个仓库都是完整的，提交离线可用，分支轻量。Git 更适合大型项目和开源协作。

</details>
