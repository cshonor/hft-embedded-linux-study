# 1.3.3 Git 常用命令

## 本节讲什么

嵌入式工程 **Git 日常流程** 与 **.gitignore** 模板。

## 要点

```bash
git init
git add main.c Makefile
git commit -m "ch01: add gcc demo"
git branch feature-gdb
git checkout feature-gdb   # 或 git switch
git merge main
git log --oneline
git diff
```

### .gitignore（嵌入式）

```gitignore
*.o *.a *.so
*.i *.s
app app.arm
build/
core
*.swp
.vscode/
```

| 忽略 | 原因 |
|------|------|
| ***.o / build/** | 可再编译 |
| **core** | gdb 转储 |

### 冲突

```bash
git status
# 编辑冲突文件 → git add → git commit
```

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
