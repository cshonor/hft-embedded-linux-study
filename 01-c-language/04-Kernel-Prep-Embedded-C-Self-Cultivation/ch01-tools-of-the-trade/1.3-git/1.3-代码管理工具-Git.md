## 代码自测

**题目 1：** 以下 Git 命令实现了什么操作？
```bash
git checkout -b feature
git add .
git commit -m "add feature"
git merge feature
```

<details>
<summary>参考答案</summary>

创建并切换到 feature 分支、暂存所有修改、提交、然后合并回当前分支。Git 的分支模型是其核心优势——轻量级分支使得多人协作和功能开发互不干扰。嵌入式项目中常用 Git 管理内核补丁、驱动代码、配置文件。

</details>
