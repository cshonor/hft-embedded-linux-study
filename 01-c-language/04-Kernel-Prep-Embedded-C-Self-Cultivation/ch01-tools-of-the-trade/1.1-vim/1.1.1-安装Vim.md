# 1.1.1 安装 Vim

## 本节讲什么

在 **WSL2 / Linux** 安装 Vim 及 C 开发依赖包。

## 要点

```bash
# Debian/Ubuntu / WSL
sudo apt update
sudo apt install -y vim gcc gdb make cmake git binutils \
    build-essential file hexdump
```

| 包 | 用途 |
|----|------|
| **vim** | 编辑 |
| **gcc binutils** | 编译、objdump/readelf |
| **gdb** | 调试 |
| **make cmake** | 构建 |

### 验证

```bash
vim --version | head -1
gcc --version
```

- Windows 原生开发推荐 **WSL2**，与板端 Linux 工具链一致

## 与后续衔接

**devenv/buildenv.sh** 统一 PATH。

## 代码自测

**题目 1：** 在 Ubuntu 上安装 Vim 并验证版本，以下命令的作用是什么？
```c
sudo apt install vim
vim --version | head -3
```
<details>
<summary>参考答案</summary>

`apt install vim` 安装 Vim 编辑器。`vim --version` 显示编译选项和版本号，`+` 表示支持该特性（如 `+python`），`-` 表示不支持。嵌入式开发建议安装 `vim-nox` 或 `vim-gtk` 以获得完整功能（如剪贴板支持 `+clipboard`）。

</details>
