# 1.1.1 安装 Vim

## 本节讲什么

在 **WSL2 / Linux** 安装 Vim 及 C 开发依赖包。

## 要点

```bash
# Debian/Ubuntu / WSL
sudo apt update
sudo apt install -y vim gcc gdb make cmake git binutils \
    build-essential file hexdump
```

| 包 | 用途 |
|----|------|
| **vim** | 编辑 |
| **gcc binutils** | 编译、objdump/readelf |
| **gdb** | 调试 |
| **make cmake** | 构建 |

### 验证

```bash
vim --version | head -1
gcc --version
```

- Windows 原生开发推荐 **WSL2**，与板端 Linux 工具链一致

## 与后续衔接

**devenv/buildenv.sh** 统一 PATH。

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
