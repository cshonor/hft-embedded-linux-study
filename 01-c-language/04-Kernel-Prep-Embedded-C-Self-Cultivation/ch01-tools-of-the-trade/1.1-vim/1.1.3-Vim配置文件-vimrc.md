# 1.1.3 Vim 配置文件：vimrc

## 本节讲什么

**`~/.vimrc`** 基础配置 —— C 语法高亮、缩进、行号。

## 要点

```vim
syntax on
filetype plugin indent on
set number
set tabstop=4 shiftwidth=4 expandtab
set autoindent
set hlsearch
set incsearch
colorscheme desert
```

| 选项 | 作用 |
|------|------|
| **expandtab** | Tab → 空格，内核风格 |
| **shiftwidth=4** | C 缩进 4 格 |
| **hlsearch** | 搜索高亮 |

```bash
vim ~/.vimrc
```

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
