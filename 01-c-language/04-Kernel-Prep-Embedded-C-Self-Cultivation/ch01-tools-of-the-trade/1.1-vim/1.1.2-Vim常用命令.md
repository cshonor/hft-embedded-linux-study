# 1.1.2 Vim 常用命令

## 本节讲什么

Vim **模式切换**、移动、编辑、批量操作 —— 纯键盘编辑 C 源码。

## 要点

| 操作 | 命令 |
|------|------|
| 插入 | `i` `a` `o` |
| 退出插入 | `Esc` |
| 保存退出 | `:wq` |
| 不保存退出 | `:q!` |
| 跳转 | `gg` 文首 `G` 文末 `42G` 第 42 行 |
| 删除行 | `dd` |
| 撤销 | `u` |
| 搜索 | `/word` `n` 下一个 |
| 替换 | `:%s/old/new/g` |
| 批量注释 | `Ctrl+v` 块选 → `I//` → `Esc` |

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
