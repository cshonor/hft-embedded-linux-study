# 1.1.4 Vim 的按键映射

## 本节讲什么

**map / imap / nmap** 自定义快捷键 —— 可选，提升重复操作效率。

## 要点

```vim
" ~/.vimrc
nnoremap <F5> :make<CR>
nnoremap <F6> :!./a.out<CR>
inoremap jj <Esc>
```

| 前缀 | 模式 |
|------|------|
| **nmap** | 普通模式 |
| **imap** | 插入模式 |
| **nore** | 不递归映射 |

- 嵌入式课以**默认键位**为主；映射勿与插件冲突

## 代码自测

**题目 1：** 以下 Vim 按键映射的含义是什么？
```vim
map <F5> :w<CR>:!gcc % -o %< && ./%<<CR>
```

<details>
<summary>参考答案</summary>

按 F5 保存当前文件、用 gcc 编译（%是当前文件名，%<是不含扩展名的文件名）、编译成功后运行。这体现了 Vim 通过映射实现一键编译运行的能力，是嵌入式开发中常用的快捷操作。

</details>
