# 1.1 代码编辑工具：Vim

## 本节讲什么

**Linux Shell + Vim** —— 嵌入式标准开发方式：脱离 IDE，命令行可见、可追溯。

## 要点

### Shell 基础（WSL/Linux）

| 类别 | 命令 |
|------|------|
| 文件 | `cd` `ls` `mkdir` `cp` `rm` `find` `tree` |
| 文本 | `cat` `grep` `sed` `awk` |
| 进程 | `ps` `top` `kill` |
| 权限 | `chmod` `ln -s` |

```bash
grep -rn "main" *.c
find . -name "*.o" -delete
```

- **bash 脚本**为 **1.6 buildenv** 铺垫

### Vim 定位

- 服务器/板卡无 GUI IDE 时的默认编辑器
- 三种模式：**普通 / 插入 / 命令**

## 代码自测

**题目 1：** gcc 编译的四个阶段是什么？
```bash
gcc hello.c -o hello
```

<details>
<summary>参考答案</summary>

1) 预处理（cpp）：展开宏、包含头文件、条件编译 → `hello.i`
2) 编译（cc1）：语法分析、优化 → 汇编代码 `hello.s`
3) 汇编（as）：汇编代码 → 目标文件 `hello.o`
4) 链接（ld）：目标文件 + 库 → 可执行文件 `hello`
对应命令：`gcc -E` / `gcc -S` / `gcc -c` / `gcc`（全部）。理解编译流程对调试编译错误、分析二进制、优化至关重要。

</details>
