# 1.5.3 GDB 查看内存与变量

## print：打印变量/表达式

```bash
(gdb) print p                 # 打印变量 p 的值
(gdb) print *ptr              # 打印指针指向的值
(gdb) print arr[0]            # 打印数组元素
(gdb) print arr               # 打印数组（显示前几个元素）
(gdb) print *arr@10           # 打印 arr 指向的 10 个元素
(gdb) print sizeof(struct A)  # 打印类型大小
(gdb) print 1+2*3             # 算术表达式
(gdb) print/x 255             # 十六进制输出 → 0xff
(gdb) print (char)65          # → 'A'
```

### print 格式修饰符

| 修饰符 | 格式 | 示例 |
|--------|------|------|
| `/x` | 十六进制 | `print/x 255` → `0xff` |
| `/d` | 十进制 | `print/d 0xff` → `255` |
| `/t` | 二进制 | `print/t 10` → `1010` |
| `/o` | 八进制 | `print/o 64` → `0100` |
| `/c` | 字符 | `print/c 65` → `'A'` |
| `/f` | 浮点 | `print/f 0x40490fdb` → `3.14159...` |
| `/a` | 地址 | `print/a 0x555555555155` → `main` |
| `/s` | 字符串 | `print/s ptr` → `"hello"` |

### 打印数组

```bash
(gdb) print arr                # 只显示前几个元素
(gdb) set print elements 50    # 设置显示上限为 50 个元素
(gdb) print *arr@10            # 从 arr 开始打印 10 个元素
(gdb) print arr[2]@5           # 从 arr[2] 开始打印 5 个元素
```

### 修改变量值

```bash
(gdb) set var count = 100      # 把 count 改成 100
(gdb) set var *ptr = 42        # 把 ptr 指向的内存改成 42
(gdb) set var i = i + 1        # 表达式赋值
```

调试时不用改代码重新编译，直接在 GDB 里改值验证猜测。

## examine：检查内存

`x` 命令按地址查看原始内存，是最强大的内存检查工具。

### 语法

```
x/NFU addr
```

| 参数 | 含义 | 可选值 |
|------|------|--------|
| N | 显示几个单位 | 数字，如 16 |
| F | 显示格式 | x(十六进制) d(十进制) t(二进制) c(字符) s(字符串) |
| U | 单位大小 | b(1字节) h(2字节/半字) w(4字节/字) g(8字节/双字) |

### 示例

```bash
(gdb) x/16xb &buf              # 16 字节，十六进制，逐字节显示
(gdb) x/8xw &buf               # 8 个字（32位），十六进制
(gdb) x/4xg &buf               # 4 个双字（64位），十六进制
(gdb) x/16cb &buf              # 16 字节，字符显示
(gdb) x/s str                  # 以字符串形式显示
(gdb) x/16i $pc                # 从当前 PC 开始反汇编 16 条指令
(gdb) x/8xw $sp                # 查看栈顶 8 个字
```

### 示例输出

```
(gdb) x/16xb &buf
0x7fffffffe3f0: 0x48 0x65 0x6c 0x6c 0x6f 0x00 0x00 0x00
0x7fffffffe3f8: 0x00 0x00 0x00 0x00 0x00 0x00 0x00 0x00
```

这就是 "Hello" 的 ASCII（48 65 6c 6c 6f 00）。

### 常用组合

| 命令 | 用途 |
|------|------|
| `x/16xb &var` | 看变量的逐字节十六进制 |
| `x/8xw &arr` | 看 int 数组 |
| `x/s ptr` | 看字符串 |
| `x/16i $pc` | 反汇编当前位置 |
| `x/8xg $sp` | 看栈（64 位） |
| `x/16xb $sp` | 看栈（逐字节） |

## info registers：查看寄存器

```bash
(gdb) info registers              # 查看所有寄存器
(gdb) info registers rax rbp      # 查看指定寄存器
(gdb) i r                         # 简写
```

x86-64 关键寄存器：

| 寄存器 | 含义 |
|--------|------|
| `rax` | 返回值 / 通用 |
| `rbp` | 栈帧基址（Base Pointer） |
| `rsp` | 栈顶指针（Stack Pointer） |
| `rip` | 指令指针（PC，下一条要执行的指令） |
| `rdi` | 第 1 个参数 |
| `rsi` | 第 2 个参数 |
| `rdx` | 第 3 个参数 |
| `rcx` | 第 4 个参数 |

```bash
(gdb) print $rax                  # 也可以用 $ 引用寄存器
(gdb) print/x $rip                # 当前指令地址
(gdb) x/i $rip                    # 反汇编当前指令
```

## disassemble：反汇编

```bash
(gdb) disassemble main            # 反汇编 main 函数
(gdb) disas main                  # 简写
(gdb) disas/r main                # 带原始字节
(gdb) disas 0x1145,0x1160         # 反汇编指定地址范围
```

输出示例：

```
(gdb) disas main
Dump of assembler code for function main:
   0x0000555555555149 <+0>:     push   rbp
   0x000055555555514a <+1>:     mov    rbp,rsp
   0x0000555555555155 <+12>:    mov    DWORD PTR [rbp-0x4],0x0
   0x0000555555555163 <+26>:    mov    eax,0x0
   0x0000555555555168 <+31>:    pop    rbp
   0x0000555555555169 <+32>:    ret
End of assembler dump.
```

`=>` 标记当前即将执行的指令。

### 自动反汇编 + 源码对照

```bash
(gdb) set disassemble-next-line on     # 单步时自动显示下一行的汇编
(gdb) disas /m main                    # 汇编和源码混合显示
```

## backtrace：调用栈回溯

```bash
(gdb) backtrace               # 打印调用栈
(gdb) bt                      # 简写
(gdb) bt full                 # 带每个栈帧的局部变量
(gdb) bt 3                    # 只打印最内 3 层
(gdb) bt -3                   # 只打印最外 3 层
```

输出示例：

```
(gdb) bt
#0  0x0000555555555155 in main () at main.c:11
#1  0x00007ffff7dfc0b3 in __libc_start_main (main=0x555555555145 <main>,
    argc=1, argv=0x7fffffffe4d8, init=<optimized out>, fini=<optimized out>,
    rtld_fini=<optimized out>, stack_end=0x7fffffffe4c8) at ../csu/libc-start.c:308
```

### 切换栈帧

```bash
(gdb) frame 0                 # 切换到 0 号栈帧（最内层）
(gdb) frame 1                 # 切换到 1 号栈帧
(gdb) fr 2                    # 简写
(gdb) up                      # 往外层走一帧
(gdb) down                    # 往内层走一帧
```

切到某个栈帧后，`print`、`info locals` 都是基于那个帧的上下文。

## info locals / info args

```bash
(gdb) info locals             # 当前栈帧的所有局部变量
(gdb) info args               # 当前函数的参数
(gdb) info variables          # 所有全局/静态变量（可能很多）
```

## 实操：调试结构体内存布局

```c
#include <stdio.h>
struct A {
    char  c;     // 1 byte + 3 padding
    int   i;     // 4 bytes
    double d;    // 8 bytes
};
int main(void)
{
    struct A a = {'X', 42, 3.14};
    return 0;
}
```

```bash
(gdb) break main
(gdb) run
(gdb) next                     # 走过初始化
(gdb) print a                  # {c = 88 'X', i = 42, d = 3.1400000000000001}
(gdb) print sizeof(a)          # 16
(gdb) x/16xb &a                # 逐字节看内存
0x7fffffffe3e0: 0x58 0x00 0x00 0x00  0x2a 0x00 0x00 0x00
                  ↑ c + 3字节padding     ↑ i = 0x2a = 42
0x7fffffffe3e8: 0x1f 0x85 0xeb 0x51  0xb8 0x1e 0x09 0x40
                  ↑ d = 3.14 (IEEE 754 double)
```

可以直观看到 `char c` 后面有 3 字节 padding，结构体大小 16 字节。
