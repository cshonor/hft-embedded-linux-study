# 9.4.5 前向引用和前向声明

## 本节讲什么

当类型 A 仅需**指针**引用类型 B 时，不必 `#include "b.h"`——**前向声明**即可打断头文件依赖链，降低编译耦合与循环 include 风险。本节讲解不完整类型、前向声明语法及在模块接口中的典型用法。

## 要点

**前向声明语法**：

```c
struct uart_handle;          /* 不完整 struct */
typedef struct uart_handle uart_handle_t;

void app_process(uart_handle_t *uart);  /* 仅需指针，无需完整定义 */
```

| 需要完整类型 | 前向声明足够 |
|--------------|--------------|
| `sizeof(T)`、`T x;`（按值） | `T *p`、`T **` |
| 访问 `p->field` | 函数参数/返回值中的指针 |
| 继承嵌入 `struct base b;` | 指向 opaque 句柄的 API |

**打破循环依赖**：

```
/* 坏：a.h ↔ b.h 互 include */
a.h: #include "b.h"  →  struct B * 其实只需前向声明
b.h: #include "a.h"
```

```
/* 好 */
a.h:
    struct B;
    void a_use_b(struct B *b);

b.h:
    #include "a.h"   /* 单向 */
    struct B { ... };
```

**回调与 ops 表**（衔接 **ch08**、**9.7.2**）：

```c
/* event.h */
struct event;   /* 前向声明 */
typedef void (*event_cb_t)(struct event *e, void *ctx);

void event_register(event_cb_t cb, void *ctx);
```

- 回调签名里用指针 → 头文件无需 event 完整定义
- 实现文件 `#include "event_internal.h"` 访问字段

**不完整类型的限制**：

```c
struct foo;
struct foo x;        /* ❌ 编译错误：大小未知 */
struct foo *p;       /* ✅ */
void f(struct foo);  /* ❌ 按值传参需要完整类型 */
```

**typedef 前向声明**：

```c
typedef struct uart_handle uart_handle_t;  /* 头文件 */

/* .c 中 */
struct uart_handle {
    int fd;
};
```

## 代码自测

**题目 1：** 前向声明解决了什么问题？以下代码为什么需要前向声明？
```c
// node.h
struct node;  // 前向声明
typedef struct node *NodePtr;  // 可以用指针
typedef void (*NodeCallback)(struct node *);  // 参数可以用指针

struct node {  // 完整定义
    int data;
    NodePtr next;  // 自引用
    NodeCallback cb;
};
```
<details>
<summary>参考答案</summary>

前向声明（Forward Declaration）：只声明类型名 `struct node;`，不给出完整定义。

解决的问题：
1. **循环依赖**：A 结构体包含 B 指针，B 包含 A 指针
2. **自引用**：链表节点包含指向自身的指针
3. **减少头文件包含**：只在头文件中前向声明，不 include 对方头文件
4. **不透明指针**：`typedef struct impl *Handle;` 隐藏实现

能用前向声明的情况：只需要指针/引用，不需要访问成员。
不能用前向声明的情况：需要访问成员（`node->data`）、需要大小（`sizeof(struct node)`）、栈上分配。

```c
struct node;  // 前向声明
struct node *p;   // OK: 只需要指针
p->data;          // 错误: 需要 struct node 完整定义
sizeof(struct node);  // 错误: 需要完整定义
struct node n;    // 错误: 需要完整定义
```

原则：头文件中尽量用前向声明，减少 #include 依赖，加快编译速度。

</details>
