# 7.8.1 指针的本质

## 本节讲什么

指针变量自身也占内存（通常 4 或 8 字节），其**内容**是某对象的地址。类型 `T *` 告诉编译器：解引用时读多少字节、如何解释比特。没有类型的 `void *` 可保存任意地址，解引用前须转回具体类型。

## 要点

```
内存示意:
  地址 0x7fff1000: [ int x = 42 ]
  地址 0x7fff2000: [ int *p = 0x7fff1000 ]

p 的值是「门牌号」；*p 是打开那扇门看里面的 int。
```

```c
int x = 42;
int *p = &x;

sizeof x;   /* sizeof(int) */
sizeof p;   /* sizeof(int *) — 指针宽度 */
sizeof *p;  /* sizeof(int) — 指向对象的大小 */
```

| 概念 | 说明 |
|------|------|
| 地址 | 字节编址，打印用 `%p` + `(void *)` |
| NULL | 空指针常量，比较用 `== NULL` |
| 无效地址 | 0xdeadbeef、已释放堆块 → UB |

```gdb
(gdb) print &x
(gdb) print p
(gdb) print sizeof(*p)
(gdb) x/4xb p          # 查看指针变量自身字节（小端地址）
(gdb) x/wx (int*)p     # 查看所指 int
```

```c
/* 内核简化 */
void *kmalloc(size_t size, gfp_t flags);
struct device *dev = ...;
/* dev 存某 device 结构体首地址 */
```

- **指针与整数**：`uintptr_t` 转换用于打印/MMIO，勿随意算术
- **双重身份**：`&p` 是「指向指针的指针」→ **7.11**

## 代码自测

**题目 1：** 为什么说"指针就是地址"这个说法不完整？指针类型有什么作用？
```c
int x = 0x12345678;
int *pi = &x;
char *pc = (char *)&x;
printf("%x %x\n", *pi, *pc);  // 输出?
```
<details>
<summary>参考答案</summary>

输出 `12345678 78`（小端）。

"指针就是地址"不完整，因为指针还包含**类型信息**：
1. **决定解引用读取多少字节**：`*pi` 读取 4 字节（int），`*pc` 读取 1 字节（char）
2. **决定指针运算步长**：`pi+1` 增加 4 字节，`pc+1` 增加 1 字节
3. **决定类型安全**：`int *p` 不能直接赋值给 `char *`（需强制转换）

类型信息在编译期存在，运行时指针就是地址（没有类型标签）。

`void *` 是无类型指针：不知道指向什么类型，不能解引用也不能做指针运算，只能做地址传递。`malloc` 返回 `void *` 需要转换。

所以完整的说法是：**指针 = 地址 + 类型**。
