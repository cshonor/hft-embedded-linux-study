# 7.11.1 修改指针变量的值

## 本节讲什么

C 按值传递指针时，函数内改**形参指针本身**不影响实参；要让 `malloc`、`realloc` 结果回到调用方，须传**指针的地址**，即二级指针（或返回新指针）。这是资源管理与容器 API 的标准模式。

## 要点

```c
void bad(char *p) {
    p = malloc(100);   /* 只改副本 */
}

void good(char **pp) {
    *pp = malloc(100); /* 改调用方 char * 变量 */
}

char *buf = NULL;
good(&buf);
```

```c
/* realloc 须更新指针 */
int grow(char **list, size_t *cap, size_t need) {
    char **new_list = realloc(*list, need);
    if (!new_list) return -1;
    *list = new_list;
    *cap = need;
    return 0;
}
```

| 需求 | 传参 |
|------|------|
| 改所指对象 | `T *` |
| 改指针变量 | `T **` |
| 改 int 变量 | `int *` |

```c
/* demo02 append_string */
int append_string(char ***list, size_t *count, const char *s);
/* 实现里 *list = realloc(...); 调用 append_string(&argv_like, &n, "uart0"); */
```

- **检查 NULL**：解引用 `*pp` 前确认 `pp != NULL`
- **对称释放**：谁 `malloc` 谁 `free`，列表需逐元素释放
- **三级指针**：极少见，多为通用容器泛型（void ***）

## 代码自测

**题目 1：** 以下代码能正确修改 main 中的指针吗？为什么需要二级指针？
```c
void my_malloc(int *p, int size) {
    p = malloc(size);  // 能修改 main 中的 ptr 吗?
}
int main(void) {
    int *ptr = NULL;
    my_malloc(ptr, 100);
    *ptr = 42;  // 段错误!
    return 0;
}
```
<details>
<summary>参考答案</summary>

**段错误**。`my_malloc` 不能修改 main 中的 ptr。

原因：C 传值调用。`p` 是 `ptr` 的副本，`p = malloc(...)` 修改的是副本，函数返回后副本销毁，main 中的 ptr 仍为 NULL。

正确做法：传指针的地址（二级指针）：
```c
void my_malloc(int **pp, int size) {
    *pp = malloc(size);  // 修改 *pp = 修改 main 中的 ptr
}
int main(void) {
    int *ptr = NULL;
    my_malloc(&ptr, 100);  // 传 ptr 的地址
    *ptr = 42;  // OK
    free(ptr);
}
```

或者返回指针：
```c
int *my_malloc(int size) { return malloc(size); }
int *ptr = my_malloc(100);
```

原则：要在函数内修改调用者的变量，必须传变量的地址。修改 int 传 `int*`，修改 `int*` 传 `int**`。

</details>
