# 8.4 Linux内核中的OOP思想：继承

## 本节讲什么

内核大量使用 **struct 嵌套**模拟继承：`platform_device` 内含 `struct device`；`net_device` 扩展通用网络接口。首成员布局保证 **`to_platform_device(dev)`** 等宏能安全向下转型。本节总览继承在内核中的三种形态：**内嵌基类**、**抽象基类 + 纯虚 probe**、**多接口 mixin**。

## 要点

**继承模式对照**：

| 模式 | 内核示例 | C 技巧 |
|------|----------|--------|
| **单继承** | `platform_device.device` | 首成员 + `container_of` |
| **抽象基类** | `struct device` 不可单独使用 | 仅通过子类 `register` |
| **接口分离** | `struct dev_pm_ops` | 独立 ops 指针挂到 device |

```c
struct platform_device {
    const char *name;
    struct device dev;          /* 基类 — 通常放末尾或首部，内核用 dev 字段 */
    u32 num_resources;
    struct resource *resource;
};

#define to_platform_device(dev) \
    container_of(dev, struct platform_device, dev)
```

- **`dev`** 字段名固定，所有 bus 子类均可 `to_*_device(dev)` 转换
- 驱动 `probe` 收到 `struct device *`，第一时间 `to_platform_device` 取子类字段
- 与用户态 **demo02** `UartDev.base` 同构

## 代码自测

**题目 1：** Linux 内核如何用 C 实现继承？以下代码中 platform_device 如何继承 device？
```c
struct device {
    const char *name;
    struct device *parent;
    // ...
};
struct platform_device {
    const char *name;     // 冗余
    int id;
    struct device dev;    // 继承 device
    // ...
};
```
<details>
<summary>参考答案</summary>

内核继承实现：结构体嵌套

`struct platform_device` 继承 `struct device`：
- `dev` 成员是 `struct device` 类型
- platform_device 可以通过 `&pdev->dev` 获取父类指针
- 父类的方法（如 `device_register`）可以直接用于 `&pdev->dev`

注意：`platform_device` 也有 `name` 字段，但与 `dev.name` 不同（历史遗留）。

向上转型：
```c
struct platform_device *pdev = ...;
struct device *dev = &pdev->dev;  // 子类→父类，安全
```

向下转型（父类→子类）：
```c
struct device *dev = ...;
struct platform_device *pdev = to_platform_device(dev);
// to_platform_device 用 container_of 实现
#define to_platform_device(x) \
    container_of(x, struct platform_device, dev)
```

内核继承层次：device → platform_device/bus_device/usb_device/pci_device 等。
