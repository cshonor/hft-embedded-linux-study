# 3.2.7 跳转指令

## 本节讲什么

`B`/`BL`/`BX` 改变 **PC** 流向：本地分支、函数调用、Thumb/ARM 状态切换。`BL` 将返回地址写入 **LR（R14）**。

## 要点

```arm
b   loop              @ 无条件跳转
beq done              @ 条件分支
bl  printf           @ 调用：lr = 下条指令地址
bx  lr                @ 返回到 lr（可切换 Thumb）

@ demo/add_asm.S 返回范式
add r0, r0, r1
bx  lr
```

| 指令 | 作用 |
|------|------|
| B | 分支，不保存 LR |
| BL | 分支并链接（调用） |
| BX | 跳转并可切换 T 位 |

- **BLX** 可调用 Thumb 函数；GNU 汇编 `.thumb`/`.arm` 指定状态
- 尾调用优化：有时用 `b func` 代替 `bl` 省栈帧

## 与后续衔接

- **3.6.1** 被调者 `bx lr`；**3.6.3** 汇编调 C 用 `bl main`
- **ch04** 重定位类型 `R_ARM_CALL` 解析 `bl` 目标

## 代码自测

**题目 1：** ARM 的 RISC 设计与 x86 的 CISC 有什么区别？对 C 编程有什么影响？

<details>
<summary>参考答案</summary>

RISC（ARM）：定长指令（4 字节）、load-store 架构（内存访问只用 LDR/STR，运算只在寄存器间）、大量寄存器（R0-R30）。CISC（x86）：变长指令、内存操作数可直接参与运算。影响：1) ARM 对齐要求更严格（非对齐访问可能异常）；2) ARM 的函数调用约定不同（前 4 个参数用 R0-R3 传递）；3) 内联汇编语法不同。跨平台代码应避免假设特定架构行为。

</details>
