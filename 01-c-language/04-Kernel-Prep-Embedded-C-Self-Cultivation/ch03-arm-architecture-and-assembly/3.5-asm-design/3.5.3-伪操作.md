# 3.5.3 伪操作

## 本节讲什么

以 `.` 开头的 **汇编器指令**（非 CPU 指令）：定义段、对齐、数据、宏，把源文件组织成链接器可消费的 `.o`。

## 要点

```arm
    .text
    .data
val:
    .word 0x12345678
    .byte 0x12
    .ascii "OK\0"
    .space 64, 0
    .end
```

| 伪操作 | 作用 |
|--------|------|
| `.text` / `.data` / `.bss` | 段切换 |
| `.align n` | 2^n 字节对齐 |
| `.word` / `.byte` | _emit 数据 |
| `.equ SYM, 0` | 符号等价常量 |

- **3.7** 展开 GNU 专用伪操作（`.section`、`.ltorg`）
- 设备树 blob、中断向量表在 `.rodata`/`.text` 用 `.word` 填入口地址

## 代码自测

**题目 1：** ARM 的 RISC 设计与 x86 的 CISC 有什么区别？对 C 编程有什么影响？

<details>
<summary>参考答案</summary>

RISC（ARM）：定长指令（4 字节）、load-store 架构（内存访问只用 LDR/STR，运算只在寄存器间）、大量寄存器（R0-R30）。CISC（x86）：变长指令、内存操作数可直接参与运算。影响：1) ARM 对齐要求更严格（非对齐访问可能异常）；2) ARM 的函数调用约定不同（前 4 个参数用 R0-R3 传递）；3) 内联汇编语法不同。跨平台代码应避免假设特定架构行为。

</details>
