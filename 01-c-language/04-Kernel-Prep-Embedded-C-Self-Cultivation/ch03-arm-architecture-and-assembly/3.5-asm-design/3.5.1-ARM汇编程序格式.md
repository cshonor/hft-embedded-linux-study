# 3.5.1 ARM汇编程序格式

## 本节讲什么

GNU ARM 汇编源文件的标准骨架：指令行、标号、注释、指令与伪操作的分工。

## 要点

```arm
@ 文件头注释
    .syntax unified          @ 可选：统一 ARM/Thumb 语法
    .cpu cortex-a9           @ 目标 CPU
    .fpu neon

    .text
    .align 2                  @ 4 字节对齐
    .global _start
    .type _start, %function
_start:
    mov r0, #0
    bx  lr
```

- **标号**单独一行或以 `:` 结尾；**指令**必须缩进（常以 Tab）
- `.global` 导出链接可见；未导出为局部符号
- 内联在 C 里写汇编时通常省略段伪操作，由编译器放入 `.text`

## 代码自测

**题目 1：** ARM 的 RISC 设计与 x86 的 CISC 有什么区别？对 C 编程有什么影响？

<details>
<summary>参考答案</summary>

RISC（ARM）：定长指令（4 字节）、load-store 架构（内存访问只用 LDR/STR，运算只在寄存器间）、大量寄存器（R0-R30）。CISC（x86）：变长指令、内存操作数可直接参与运算。影响：1) ARM 对齐要求更严格（非对齐访问可能异常）；2) ARM 的函数调用约定不同（前 4 个参数用 R0-R3 传递）；3) 内联汇编语法不同。跨平台代码应避免假设特定架构行为。

</details>
