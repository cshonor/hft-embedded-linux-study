# 3.5.1 ARM汇编程序格式

## 本节讲什么

GNU ARM 汇编源文件的标准骨架：指令行、标号、注释、指令与伪操作的分工。

## 要点

```arm
@ 文件头注释
    .syntax unified          @ 可选：统一 ARM/Thumb 语法
    .cpu cortex-a9           @ 目标 CPU
    .fpu neon

    .text
    .align 2                  @ 4 字节对齐
    .global _start
    .type _start, %function
_start:
    mov r0, #0
    bx  lr
```

- **标号**单独一行或以 `:` 结尾；**指令**必须缩进（常以 Tab）
- `.global` 导出链接可见；未导出为局部符号
- 内联在 C 里写汇编时通常省略段伪操作，由编译器放入 `.text`

## 代码自测

**题目 1：** ARM 汇编指令的格式是什么？以下指令中各部分叫什么？
```c
Label:  MOVEQ R0, R1, LSL #2  @ comment
```
<details>
<summary>参考答案</summary>

格式：`Label: mnemonic{cond}{S} Rd, Rn, operand2 @ comment`

- `Label:`：标号（标记地址，可被 B/BL 跳转）
- `MOV`：助记符（指令操作）
- `EQ`：条件后缀（Equal，Z 标志为 1 时执行）
- `R0`：目标寄存器（Rd）
- `R1`：第一操作数寄存器（Rn）
- `LSL #2`：第二操作数（operand2，R1 逻辑左移 2 位）
- `@`：注释（GNU 汇编用 `@`，ARM 汇编器用 `;`）

该指令：若 Z=1，则 R0 = R1 << 2。

</details>
