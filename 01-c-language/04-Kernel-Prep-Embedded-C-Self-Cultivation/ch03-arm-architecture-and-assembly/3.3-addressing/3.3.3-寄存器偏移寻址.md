# 3.3.3 寄存器偏移寻址

## 本节讲什么

内存地址 = 基址寄存器 + **经移位的** 索引寄存器，适合数组、动态偏移结构体访问。

## 要点

```arm
ldr r0, [r1, r2]              @ addr = r1 + r2
ldr r0, [r1, r2, lsl #2]      @ addr = r1 + (r2<<2)，int 数组
str r3, [r4, r5, lsr #2]
```

- 仅 **load/store** 使用；移位类型：LSL/LSR/ASR/ROR
- C 代码 `arr[i]` 常编译为 `r_base + (r_i << 2)`

## 与后续衔接

- 与 **3.2.4** operand2 移位规则一致

## 代码自测

**题目 1：** 以下两条指令的寻址方式和执行结果是什么？
```c
LDR R0, [R1, #8]    @ 指令A
LDR R0, [R1, #8]!   @ 指令B
LDR R0, [R1], #8    @ 指令C
```
<details>
<summary>参考答案</summary>

三者都是寄存器偏移寻址，但基址更新方式不同：
- **指令 A** `LDR R0, [R1, #8]`：R0 = 内存[R1+8]，R1 不变（偏移寻址）
- **指令 B** `LDR R0, [R1, #8]!`：R0 = 内存[R1+8]，**R1 = R1+8**（前索引，`!` 表示回写）
- **指令 C** `LDR R0, [R1], #8`：R0 = 内存[R1]，**然后 R1 = R1+8**（后索引）

前索引 `!` 先更新基址再访问；后索引先访问再更新。用于数组/结构体遍历。

</details>
