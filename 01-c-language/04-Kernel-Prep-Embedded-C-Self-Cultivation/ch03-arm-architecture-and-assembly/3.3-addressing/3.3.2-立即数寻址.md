# 3.3.2 立即数寻址

## 本节讲什么

指令编码中直接嵌入常数（**8 位旋转立即数**），用于小常量、掩码、偏移。

## 要点

```arm
mov r0, #0xFF
add r1, r2, #1
and r0, r0, #0xFFFF0000
```

- 并非任意 32 位常数都可编码；编译器对大数用 **literal pool**（`ldr =sym`）
- `#0` 常用作清零：`mov r0, #0` 或 `eor r0, r0, r0`

## 与后续衔接

- 大立即数 **3.4.1**；基址偏移 **3.3.5** 也用 #imm

## 代码自测

**题目 1：** 以下 ARM 立即数哪些可以直接编码？
```asm
MOV R0, #0xFF        ; A
MOV R0, #0xFF00      ; B
MOV R0, #0x101       ; C
```

<details>
<summary>参考答案</summary>

A 和 B 可以，C 不行。ARM 立即数规则：8 位值循环右移偶数次得到 32 位数。0xFF = 8 位值 0xFF 右移 0 位。0xFF00 = 8 位值 0xFF 右移 8 位（偶数）。0x101 需要 9 位表示，无法由 8 位值移位得到。不合法的立即数用 LDR R0, =0x101 加载。

</details>
