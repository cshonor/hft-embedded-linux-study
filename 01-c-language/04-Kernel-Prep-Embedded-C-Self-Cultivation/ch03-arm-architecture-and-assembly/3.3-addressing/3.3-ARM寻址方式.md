# 3.3 ARM寻址方式

## 本节讲什么

ARM load/store 的地址表达式决定 `[...]` 如何计算。七种寻址覆盖从纯寄存器到 PC 相对访问，是读懂 `ldr`/`str` 反汇编和写内联汇编的前提。

## 要点

| 方式 | 形式示例 | 小节 |
|------|----------|------|
| 寄存器 | `mov r0, r1` | **3.3.1** |
| 立即数 | `mov r0, #1` | **3.3.2** |
| 寄存器偏移 | `[r1, r2]` `[r1, r2, lsl #2]` | **3.3.3** |
| 寄存器间接 | `[r1]` | **3.3.4** |
| 基址 | `[r1, #4]` `[r1], #4` | **3.3.5** |
| 多寄存器 | `{r0-r3}` | **3.3.6** |
| 相对寻址 | `[pc, #offset]` | **3.3.7** |

```arm
ldr r0, [r1, r2, lsl #2]   @ 数组下标：base + index*4
ldr r1, =my_var            @ 伪指令，见 3.4
```

- 偏移寄存器可选移位，适合结构体字段、环形缓冲区索引
- 内核链表遍历：`ldr r0, [r0]` 取 `next` 指针

## 代码自测

**题目 1：** ARM 的 RISC 设计与 x86 的 CISC 有什么区别？对 C 编程有什么影响？

<details>
<summary>参考答案</summary>

RISC（ARM）：定长指令（4 字节）、load-store 架构（内存访问只用 LDR/STR，运算只在寄存器间）、大量寄存器（R0-R30）。CISC（x86）：变长指令、内存操作数可直接参与运算。影响：1) ARM 对齐要求更严格（非对齐访问可能异常）；2) ARM 的函数调用约定不同（前 4 个参数用 R0-R3 传递）；3) 内联汇编语法不同。跨平台代码应避免假设特定架构行为。

</details>
