# 3.3.6 多寄存器寻址

## 本节讲什么

`LDM`/`STM` 用 `{r0-r3}` 列表一次传送多个寄存器——函数保存现场、中断入栈、块拷贝的高效手段。

## 要点

```arm
stmfd sp!, {r4-r11, lr}    @ 入栈（满递减，先减后存）
ldmfd sp!, {r4-r11, pc}    @ 出栈返回
ldmia r0!, {r2-r5}         @ 从 r0 批量加载，r0 递增
```

- **IA/IB/DA/DB** + **FD/FA/ED/EA**：递增/递减、前/后变址
- `fd` + `sp` 为 GNU/Linux 常用栈约定
- 寄存器列表中 **编号低者→低地址**（`stmfd` 时）

## 代码自测

**题目 1：** 以下 ARM 指令实现了什么操作？
```asm
LDMIA R0!, {R1-R4}
```

<details>
<summary>参考答案</summary>

LDMIA（Load Multiple Increment After）从 R0 指向的地址开始，依次加载 4 个字到 R1-R4，每次地址递增 4，最后更新 R0。IA 表示 After（先访问后递增）。等价于：R1=[R0], R2=[R0+4], R3=[R0+8], R4=[R0+12], R0=R0+16。多寄存器传送用于高效的数据搬运和栈操作。

</details>
