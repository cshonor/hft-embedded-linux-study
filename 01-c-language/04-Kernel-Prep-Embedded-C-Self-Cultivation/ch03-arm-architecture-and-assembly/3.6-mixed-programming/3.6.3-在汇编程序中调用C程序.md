# 3.6.3 在汇编程序中调用C程序

## 本节讲什么

启动代码、异常向量或裸机 `reset` 里用 **`bl main`** 跳入 C 世界；须先初始化 **栈 SP**、BSS，并遵守 AAPCS 传参。

## 要点

```arm
    .global _start
    .type _start, %function
_start:
    ldr sp, =stack_top      @ 必须：C 需要有效栈
    bl  main                @ 进入 C
    b   .                   @ main 返回后死循环

    .bss
    .space 4096
stack_top:
```

```arm
    mov r0, #3              @ main(int argc, ...) 可设 r0
    mov r1, #0
    bl  main
```

- `bl printf` 等同理；C 运行时可能依赖 `_start` → `__libc_start_main`
- 裸机链接脚本把 `stack_top` 放在 RAM 顶端
- U-Boot 跳内核前设好寄存器（ATAGs/DTB 指针曾用 r0–r2）

## 与后续衔接

- **ch04** 链接脚本 `ENTRY(_start)`；**ch10** OS 启动流程

## 代码自测

**题目 1：** 以下汇编代码如何调用 C 函数？需要遵守什么约定？
```c
// C 函数
int add(int a, int b) { return a + b; }

// 汇编调用
    MOV R0, #10     @ 第一个参数
    MOV R1, #20     @ 第二个参数
    BL add          @ 调用
    // R0 现在是返回值 30
```
<details>
<summary>参考答案</summary>

汇编调用 C 函数必须遵守 ATPCS/ABI 约定：
1. **参数传递**：前 4 个参数放 R0-R3，更多参数压栈
2. **调用**：`BL 函数名`（自动保存返回地址到 LR）
3. **返回值**：C 函数返回值在 R0
4. **寄存器保存**：C 函数会自动保存 R4-R11，R0-R3 可能被修改

本例：R0=10, R1=20 传参 → `BL add` 调用 → 返回后 R0=30。

注意：调用前确保栈指针 SP 有效（如果 C 函数用到栈），R0-R3 的值调用后不保证保留。

</details>
