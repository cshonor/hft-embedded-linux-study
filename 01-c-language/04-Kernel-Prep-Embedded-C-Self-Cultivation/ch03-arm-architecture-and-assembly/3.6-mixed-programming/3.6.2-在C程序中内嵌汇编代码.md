# 3.6.2 在C程序中内嵌汇编代码

## 本节讲什么

GCC **`asm` / `__asm__`** 把 ARM 指令嵌入 C；**`volatile`** 禁止优化删除/重排；**约束** 描述操作数与寄存器对应——内核 `read_cpuid`、`wfe`、`dmb` 的实现方式。

## 要点

```c
int add_inline(int a, int b)
{
    int sum;
    asm volatile (
        "add %0, %1, %2"
        : "=r" (sum)           /* 输出 */
        : "r" (a), "r" (b)     /* 输入 */
        : "cc"                 /* 破坏标志位 */
    );
    return sum;
}
```

| 要素 | 含义 |
|------|------|
| `volatile` | 有副作用，勿删勿挪 |
| `"=r"` | 写寄存器输出 |
| `"r"` | 读寄存器输入 |
| `"cc"` / `"memory"` |  clobber 标志 / 内存 |

```c
/* 内核风格：内存屏障 */
#define barrier() asm volatile("" ::: "memory")
```

- 多语句用 `\n\t` 连接；勿随意写 clobber，否则优化错误
- DPDK `rte_rmb()` 等平台屏障在 ARM 上常为 `dmb ish` 内联汇编

## 代码自测

**题目 1：** 以下内联汇编代码的作用是什么？输出操作数和输入操作数分别是什么？
```c
int result;
__asm__ volatile (
    "MRS %[res], CPSR"  // 指令
    : [res] "=r" (result)  // 输出
    : // 输入
    : // clobber
);
```
<details>
<summary>参考答案</summary>

该代码读取当前程序状态寄存器（CPSR）到 C 变量 `result`。

- `MRS %[res], CPSR`：将 CPSR 读入指定寄存器
- `[res] "=r" (result)`：输出操作数，`%[res]` 是占位符，`"=r"` 表示输出到任意寄存器，`(result)` 绑定到 C 变量
- `volatile`：禁止编译器优化掉这条汇编（读 CPSR 有副作用）

内联汇编格式：`asm volatile("指令" : 输出 : 输入 : clobber)`。内核中用于操作 CP15/系统寄存器。

</details>
