# 3.7.6 数据定义

## 本节讲什么

在汇编中 **静态分配** 数据：字符串、表、中断向量常数——与 C 全局对象一样进入 `.data`/`.rodata`。

## 要点

```arm
    .data
gpio_table:
    .word 0x1000, 0x1004, 0x1008
msg:
    .asciz "Hello\n"
    .align 2
count:
    .int 42
    .skip 16, 0xFF
```

| 伪操作 | 含义 |
|--------|------|
| `.int` / `.long` | 32 位字 |
| `.asciz` | 以 0 结尾字符串 |
| `.skip n, fill` | 预留 n 字节 |
| `.incbin "blob.bin"` | 嵌入二进制 |

- 向量表：`.word reset, undef, swi, prefetch, data, irq, fiq`
- 与 C `const uint32_t gpio_table[]` 可 `extern` 互引

## 代码自测

**题目 1：** ARM 的 RISC 设计与 x86 的 CISC 有什么区别？对 C 编程有什么影响？

<details>
<summary>参考答案</summary>

RISC（ARM）：定长指令（4 字节）、load-store 架构（内存访问只用 LDR/STR，运算只在寄存器间）、大量寄存器（R0-R30）。CISC（x86）：变长指令、内存操作数可直接参与运算。影响：1) ARM 对齐要求更严格（非对齐访问可能异常）；2) ARM 的函数调用约定不同（前 4 个参数用 R0-R3 传递）；3) 内联汇编语法不同。跨平台代码应避免假设特定架构行为。

</details>
