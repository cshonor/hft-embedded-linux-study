# 3.7.2 GNU ARM编译器的伪操作

## 本节讲什么

GNU `as` 特有伪操作：控制 ARM/Thumb、literal 池、CPU 特性——写启动代码与内联汇编外围 `.S` 时常用。

## 要点

```arm
.syntax unified
.arm                    @ 后续为 ARM 32 位指令
.thumb                  @ Thumb-2
.ltorg                  @ 在此放置 literal pool
.cpu cortex-a7
.fpu vfpv3-d16
.arch armv7-a
```

| 伪操作 | 作用 |
|--------|------|
| `.ltorg` | 防止 `ldr =` 跳转过远 |
| `.arm` / `.thumb` | 切换指令集 |
| `.code 32` / `.code 16` | 同义切换 |
| `.fnstart` / `.fnend` | 栈展开元数据（异常处理） |

- 内核 `ENTRY(vector)` 宏展开含 `.type`、`.align`
- DPDK 裸机移植 seldom 手写，但读 U-Boot 需认识 `.arch`

## 代码自测

**题目 1：** GNU ARM 汇编器和 ARM 汇编器的伪操作有什么差异？以下 GNU 伪操作的含义是什么？
```c
.section .text        @ ?
.align 4              @ ?
.type func, %function  @ ?
.size func, 16         @ ?
```
<details>
<summary>参考答案</summary>

GNU 汇编器（GAS）和 ARM 汇编器（armasm）伪操作不同：
- ARM: `AREA |text|, CODE, READONLY` vs GNU: `.section .text`
- ARM: `ALIGN` vs GNU: `.align 4`（4 表示 2^4=16 字节对齐）
- ARM: 无类型声明 vs GNU: `.type`/`.size`

- `.section .text`：声明代码段
- `.align 4`：4 字节对齐（ARM 上 `.align n` = 2^n 对齐，x86 上 `.align n` = n 字节对齐）
- `.type func, %function`：标记 func 为函数类型（调试信息）
- `.size func, 16`：标记 func 大小为 16 字节（调试信息）

内核代码用 GNU 汇编语法。

</details>
