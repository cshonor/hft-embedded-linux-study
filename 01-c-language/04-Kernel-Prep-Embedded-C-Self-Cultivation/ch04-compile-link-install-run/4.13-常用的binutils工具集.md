# 4.13 常用的binutils工具集

## 本节讲什么

**GNU Binutils** 贯穿编译链接全流程：`as`、`ld`、`ar`、`nm`、`objdump`、`readelf`、`strip` 等。掌握它们可在 **不运行程序** 的情况下检查 ELF 段、符号、重定位——排查 **4.4.2** 链接错误与 **4.8** 动态库问题的基本功。

## 要点

### 工具速查

| 工具 | 用途 |
|------|------|
| `gcc -E/-S/-c` | 预处理/汇编/编译（驱动） |
| `as` | `.s` → `.o` |
| `ld` | 链接（`gcc` 封装） |
| `ar` | 静库 `rcs` / 列表 `t` |
| `nm` | 符号表 |
| `readelf` | ELF 头、段、动态段、重定位 |
| `objdump` | 反汇编、段、`-r` 重定位 |
| `strip` | 删除符号/debug |
| `size` |段大小汇总 |

### 实战组合

```bash
# 四阶段产物
gcc -save-temps -c demo.c
ls demo.i demo.s demo.o

# ELF 结构
readelf -hWa demo.o
readelf -S demo.o
readelf -r demo.o

# 符号
nm -C demo.o
nm -D libdemo.so              # 动态符号

# 反汇编
objdump -d -S demo.o
objdump -R ./prog              # 动态重定位

# 静库
ar tv libdemo.a
nm libdemo.a

# 可执行
readelf -l ./prog
ldd ./prog
file demo.o libdemo.a libdemo.so ./prog
```

### 与 demo/ 目录

```bash
cd ch04-compile-link-install-run/demo
make demo01
readelf -S demo01.o demo01
nm demo01.o
```

## 代码自测

**题目 1：** 以下 binutils 工具各有什么用途？如何查看一个 .o 文件的反汇编？
```c
readelf -S main.o   # ?
objdump -d main.o     # ?
nm main.o            # ?
objcopy -O binary main.o main.bin  # ?
strip main           # ?
```
<details>
<summary>参考答案</summary>

- `readelf -S`：查看 ELF 节区表（.text/.data/.bss 的偏移、大小、属性）
- `objdump -d`：反汇编 .text 节（机器码 → 汇编指令）
- `nm`：查看符号表（函数名、变量名、类型 T/D/B/U）
- `objcopy -O binary`：将 ELF 转换为纯二进制（去除 ELF 头和段信息，裸机烧录用）
- `strip`：移除符号表和调试信息（减小文件体积，发布用）

其他：`size`（各段大小）、`strings`（提取字符串）、`addr2line`（地址→源码行号）、`ar`（创建静态库）。

</details>
