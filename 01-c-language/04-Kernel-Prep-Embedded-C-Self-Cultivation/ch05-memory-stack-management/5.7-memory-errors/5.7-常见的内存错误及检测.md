# 5.7 常见的内存错误及检测

## 本节讲什么

堆栈错误族：**越界读写、use-after-free、double free、未初始化、空指针**——表现从 **段错误** 到 **静默数据损坏**。工具链：**GDB+core、Valgrind、ASAN、mprotect guard**。

## 要点

| 错误 | 典型后果 |
|------|----------|
| 缓冲区溢出 | 踩栈/堆元数据 |
| UAF | 不可预测行为 |
| double free | glibc abort |
| 野指针 | SIGSEGV |

```bash
gcc -fsanitize=address -g -O0 -o t t.c && ./t
valgrind ./t
```

## 代码自测

**题目 1：** 以下代码有哪几种内存错误？分别叫什么？如何用编译选项检测？
```c
int *p = malloc(4);
*p = 10;       // (A)
p[1] = 20;     // (B)
free(p);
*p = 30;       // (C)
int a[5]; a[5] = 0;  // (D)
```

<details>
<summary>参考答案</summary>

(A) 正常写入；(B) 堆缓冲区溢出（heap-buffer-overflow），只分配 4 字节写第 2 个 int；(C) use-after-free（UAF），释放后写入；(D) 栈缓冲区溢出（stack-buffer-overflow），`a[5]` 越界。编译时加 `-fsanitize=address`（ASAN）可在运行时检测 B/C/D。ASAN 还检测 double-free 和内存泄漏。嵌入式可用 `-fsanitize=address -fno-omit-frame-pointer` 或 `mudflap`。

</details>
