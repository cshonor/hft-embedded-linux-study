# 5.6.4 广义上的内存泄漏

## 本节讲什么

除 **堆块永不释放** 外，「广义泄漏」包括：**文件描述符**、**mmap 未 munmap**、**线程/锁未销毁**、**内核引用计数泄漏**、**池化对象未归还**——资源总量有限，表现同为系统变慢或 OOM。

## 要点

### 类型

| 资源 | 症状 |
|------|------|
| FD | `Too many open files` |
| mmap | VMA 数量涨，`/proc/maps` 变长 |
| 线程 | pid/max 限制 |
| 内核模块引用 | `rmmod` 失败 |

```bash
ls /proc/self/fd | wc -l
cat /proc/self/maps | wc -l
lsof -p $$
```

### 与堆泄漏区别

- 进程退出 OS **回收** 用户堆，但 **泄漏期间** 仍占 RAM
- **嵌入式无 exit**：广义泄漏 = 致命
- **DPDK**：mbuf 未还 pool → 等价包缓冲区泄漏，最终无法收包

### 检测

- `valgrind --track-fds=yes`
- 内核：`/proc/meminfo`、`slabtop`、kmemleak

## 代码自测

**题目 1：** 除了 malloc 不 free，还有哪些"广义内存泄漏"？
<details>
<summary>参考答案</summary>

广义内存泄漏类型：

1. **文件描述符泄漏**：open 后没 close，fd 耗尽（`ulimit -n` 通常 1024）
2. **线程泄漏**：pthread_create 后没 pthread_join/detach，线程资源不释放
3. **socket 泄漏**：socket/accept 后没 close
4. **资源句柄泄漏**：数据库连接、图形上下文（X11/GDI）、信号量
5. **临时文件泄漏**：tmpfile/mkdtemp 后忘记删除
6. **缓存膨胀**：无上限的 cache 导致内存持续增长
7. **dlopen 泄漏**：dlopen 后没 dlclose

检测：`ls /proc/PID/fd | wc -l` 检查 fd 数量；`ps -L` 检查线程数；Valgrind 检查 fd 泄漏。

预防：为每类资源建立"获取-释放"配对约定，用 cleanup 模式处理错误路径。

</details>
