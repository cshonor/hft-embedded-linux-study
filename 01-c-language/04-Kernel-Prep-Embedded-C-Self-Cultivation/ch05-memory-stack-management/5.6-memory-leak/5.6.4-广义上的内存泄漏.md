# 5.6.4 广义上的内存泄漏

## 本节讲什么

除 **堆块永不释放** 外，「广义泄漏」包括：**文件描述符**、**mmap 未 munmap**、**线程/锁未销毁**、**内核引用计数泄漏**、**池化对象未归还**——资源总量有限，表现同为系统变慢或 OOM。

## 要点

### 类型

| 资源 | 症状 |
|------|------|
| FD | `Too many open files` |
| mmap | VMA 数量涨，`/proc/maps` 变长 |
| 线程 | pid/max 限制 |
| 内核模块引用 | `rmmod` 失败 |

```bash
ls /proc/self/fd | wc -l
cat /proc/self/maps | wc -l
lsof -p $$
```

### 与堆泄漏区别

- 进程退出 OS **回收** 用户堆，但 **泄漏期间** 仍占 RAM
- **嵌入式无 exit**：广义泄漏 = 致命
- **DPDK**：mbuf 未还 pool → 等价包缓冲区泄漏，最终无法收包

### 检测

- `valgrind --track-fds=yes`
- 内核：`/proc/meminfo`、`slabtop`、kmemleak

## 代码自测

**题目 1：** 函数调用栈帧（stack frame）的结构是什么？
```c
void f(int a, int b) {
    int local = a + b;
}
```

<details>
<summary>参考答案</summary>

栈帧包含：1) 返回地址（调用方的下一条指令）；2) 旧的帧指针（RBP/FP）；3) 局部变量（local）；4) 保存的寄存器；5) 参数（如果不在寄存器中传递）。`SP` 指向栈顶，`FP` 指向当前帧基址。函数序言（prologue）建立帧，函数结语（epilogue）恢复帧。栈溢出：递归太深或局部变量太大。用 `-fomit-frame-pointer` 省略帧指针（多一个寄存器，但调试困难）。

</details>
