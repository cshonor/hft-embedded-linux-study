# 5.5.2 mmap 映射实现机制分析

## 本节讲什么

用户态 `mmap()` → 内核 **`do_mmap`/`mmap_region`**：在进程 **mm_struct** 找空洞建 **VMA**，`mmap` 文件则挂 **file->f_mapping**，匿名则只 reserve 虚拟区；**首次访问** 触发缺页分配物理页或读入页缓存。

## 要点

### 流程

1. 找合适虚拟地址（`mmap_base` 向下或 `hint`）
2. 创建 VMA（`vm_area_struct`：start/end/prot/flags/file）
3. 读/写缺页 → **filemap_fault** 或 **匿名零页**
4. `munmap` 拆 VMA、释放页表项

```bash
cat /proc/self/maps
# 地址范围 权限 offset dev inode pathname
```

### 与 brk

| brk | mmap |
|-----|------|
| 堆顶连续 bump | 任意空洞 |
| 小对象 heap | 大块、文件、设备 |
| 单 main arena 延伸 | 独立 VMA |

- **TLB shootdown**：多核修改页表需 IPI
- **内核模块**：`ioremap` 把 **物理 MMIO** 映射到内核虚拟（非用户 mmap）

## 代码自测

**题目 1：** 函数调用栈帧（stack frame）的结构是什么？
```c
void f(int a, int b) {
    int local = a + b;
}
```

<details>
<summary>参考答案</summary>

栈帧包含：1) 返回地址（调用方的下一条指令）；2) 旧的帧指针（RBP/FP）；3) 局部变量（local）；4) 保存的寄存器；5) 参数（如果不在寄存器中传递）。`SP` 指向栈顶，`FP` 指向当前帧基址。函数序言（prologue）建立帧，函数结语（epilogue）恢复帧。栈溢出：递归太深或局部变量太大。用 `-fomit-frame-pointer` 省略帧指针（多一个寄存器，但调试困难）。

</details>
