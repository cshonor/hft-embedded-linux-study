# 5.5.3 把设备映射到内存

## 本节讲什么

**MMIO**：外设寄存器映射到物理地址，CPU **load/store** 即读写硬件。Linux 用户态通过 **`/dev/uio`、`/dev/mem` 或驱动 mmap** 把物理窗口映射进进程，指针访问替代 `in/out`（x86）或总线周期。

## 要点

### 用户态 UIO 示例（概念）

```c
int fd = open("/dev/uio0", O_RDWR);
void *regs = mmap(NULL, map_size, PROT_READ|PROT_WRITE,
                  MAP_SHARED, fd, 0);
volatile uint32_t *ctrl = (uint32_t *)((char *)regs + offset);
*ctrl = 1;   /* 写寄存器 */
```

```bash
ls -l /dev/uio* /dev/mem
# 需 root 或 udev 规则；优先用内核驱动抽象，勿裸 mmap /dev/mem
```

### 裸机 vs Linux

| 裸机 | Linux |
|------|-------|
| `#define REG (*(volatile uint32_t*)0x40001000)` | 驱动 `ioremap` + 用户 mmap |
| 物理固定 | 虚拟 + 驱动管理权限 |

- **volatile**：防止编译器优化掉对 MMIO 的访问
- **DPDK**：`rte_memzone`、`pci_map_device` 映射 BAR 到用户态做 PMD 轮询
- **缓存一致性**：DMA 缓冲区常需 **uncached** 或 explicit flush

## 代码自测

**题目 1：** 如何用 mmap 将硬件寄存器映射到用户空间？以下代码的作用是什么？
```c
int fd = open("/dev/mem", O_RDWR);
volatile unsigned int *gpio = mmap(NULL, 4096,
    PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0x3F200000);
gpio[1] = (1 << 5);  // 设置 GPIO5 输出
```
<details>
<summary>参考答案</summary>

将物理地址 0x3F200000（树莓派 GPIO 控制器）映射到用户空间虚拟地址，直接通过指针读写硬件寄存器。

关键点：
- `/dev/mem`：访问物理内存的设备文件
- `MAP_SHARED`：修改同步到设备（不是写时复制）
- `volatile`：防止编译器缓存寄存器值到 CPU 寄存器，每次访问必须真正读写内存
- 偏移参数是物理地址（页对齐）

用途：嵌入式 Linux 用户空间直接操作 GPIO/SPI/I2C 控制器，无需写驱动。

注意：需要 root 权限。内核态也可以用 `ioremap()` 映射寄存器。

</details>
