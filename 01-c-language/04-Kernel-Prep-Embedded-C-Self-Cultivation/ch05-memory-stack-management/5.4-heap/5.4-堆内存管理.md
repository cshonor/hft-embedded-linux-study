# 5.4 堆内存管理

## 本节讲什么

**堆（heap）** 供 **动态分配**：运行期按需求申请/释放，生命周期不受函数栈帧约束。实现从裸机 **固定内存池** 到 Linux **glibc ptmalloc**，再到自研 **chunk 链表**；核心问题：**碎片、泄漏、双重释放**。

## 要点

- 用户 API：`malloc`/`free`/`calloc`/`realloc`；C++ 对应 `new/delete`
- 底层：裸机静态数组；RTOS 位图/链表；Linux `brk` + `mmap` arena
- 观测：`malloc_stats`、**5.4.4** 测试程序、**Valgrind** / **mtrace**

```bash
man malloc
ldd $(which ls) | grep libc
```

## 代码自测

**题目 1：** 以下代码有什么内存问题？`malloc` 和 `calloc` 的关键区别是什么？
```c
int *p = malloc(10 * sizeof(int));
// 立即使用 p[0]~p[9]，未初始化
p = malloc(20 * sizeof(int));  // 原来的 10 个 int 泄漏了
```

<details>
<summary>参考答案</summary>

两个问题：(1) `malloc` 不清零内存，内容是未定义的垃圾值，应使用 `calloc` 或手动 `memset`；(2) 第二次 `malloc` 覆盖了 `p`，原来 10 个 int 的内存泄漏——没有 `free` 就重新赋值。`malloc` 分配但不初始化，`calloc` 分配并清零（相当于 `malloc` + `memset(p, 0, ...)`）。修法：先 `free(p)` 再重新分配。

</details>
