# 2.4 括号缺失与语句体

## 本节讲什么

`if` / `for` / `while` **没有 `{}` 时，语法上仅紧跟的「一条语句」属于体**；下一行已是独立语句，不受控制——与缩进无关。

## 要点

### 经典错误

```c
if (flag)
    a = 100;
    b = 200;   /* 永远执行！不属于 if */
```

等价于：

```c
if (flag)
    a = 100;
b = 200;
```

### 宏展开叠加（ch06 预告）

```c
#define INC(x) x++; x++
if (ok)
    INC(a);   /* 展开后多条语句，仅第一条受 if 控制 */
```

见 **ch06 预处理器**。

### 修复

```c
if (flag) {
    a = 100;
    b = 200;
}
```

### 工程规范

- **Mandatory braces**：内核风格、MISRA、多数 HFT 规范要求控制语句必带 `{}`
- 调试时在 `if` 下加 `log` 行，忘加 `{}` 极易引入新 bug

## 代码自测

**题目 1：** 以下宏展开后有什么问题？
```c
#define SQR(x) (x)*(x)
int y = 10 / SQR(2);  // 结果是？
```

<details>
<summary>参考答案</summary>

展开为 `10 / (2)*(2)` = `(10/2)*(2)` = 10，而非 `10/(2*2)` = 2。整个宏体应加外层括号：
```c
#define SQR(x) ((x)*(x))
```
展开为 `10 / ((2)*(2))` = 2。宏定义中每层括号都有作用：参数加括号防止参数表达式优先级问题，整体加括号防止宏在表达式中被错误组合。

</details>
