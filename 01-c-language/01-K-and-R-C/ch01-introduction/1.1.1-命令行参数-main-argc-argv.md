# 1.1.1 命令行参数 `main(int argc, char *argv[])`（精炼）

> 与 [1.1 入门](./1.1-入门.md) 衔接：无参用 `main(void)`；要读启动参数用本节。  
> 类型口诀：[5.6.1 指针数组 vs 数组指针](../ch05-pointers-and-arrays/5.6.1-指针数组vs数组指针-精炼.md) · 详解 [5.10](../ch05-pointers-and-arrays/5.10-命令行参数.md)。

---

## 1. 一句话 + 元素类型

`char *argv[]` 是**指针数组**；**每个元素类型是 `char *`**，各自指向以 `\0` 结尾的 C 字符串。

```c
char *argv[];
/* 本质：指针数组；argv[i] 的类型 = char * */
```

| 表达式 | 类型 | 含义 |
|--------|------|------|
| `argv[i]` | `char *` | 数组元素：指向某参数字符串 |
| `argv`（形参里） | `char **` | 退化后：指向「首个 `char *`」的指针 |
| `argv[i][0]` | `char` | 该串首字符 |

**不是**二维字符数组 `char argv[][]`：后者是连续字符块；前者是一排指针，字符串可分散存放。

```
argv[0] (char*) → "./app"
argv[1] (char*) → "input"
argv[2] (char*) → NULL
```

## 1b. 形参退化（仅函数参数）

```c
int main(int argc, char *argv[])
/* 完全等价于 */
int main(int argc, char **argv)
```

局部 `char *arr[4];` **不是** `char **`（`sizeof(arr)` 仍是数组）。详见 [5.6.1](../ch05-pointers-and-arrays/5.6.1-指针数组vs数组指针-精炼.md)。
---

## 2. 索引规范（POSIX / C）

| 下标 | 内容 |
|------|------|
| `argv[0]` | 程序路径/名（由 `execve` 调用者决定，**可被篡改**；勿做业务硬依赖） |
| `argv[1]` … `argv[argc-1]` | 用户参数 |
| `argv[argc]` | **强制 `NULL`** |

`argc` **最小为 1**（无用户参数时仍有 `argv[0]`）。

安全遍历：

```c
/* 推荐：靠 argc */
for (int i = 0; i < argc; i++)
    puts(argv[i]);

/* 靠末尾 NULL（标准保证 argv[argc]==NULL） */
char **p = argv;
while (*p != NULL) {
    puts(*p);
    p++;
}
```

---

## 3. 工程坑（嵌入式 / Linux 后台通用）

1. 指向的字符串**通常可改内容**；长期改写 `argv[0]` 不推荐（日志/`ps` 等常依赖）。  
2. 全是 `\0` 结尾的 C 字符串；数字仍是串 → 用 `strtol` 等转换。  
3. shell 的 `*.txt` **由 shell 展开**；程序若收到字面量 `*.txt`，说明通配被关/未走 shell。  
4. 分段：空格切分；含空格用引号：`./a "my file"` → 一段。

---

## 4. 衔接 TLPI / 进程

`execve(path, argv, envp)` 在用户态构造这套数组。扩展签名（POSIX）：

```c
int main(int argc, char *argv[], char *envp[]);  /* envp 同结构，末尾 NULL */
```

→ TLPI：[Ch24–27 进程/exec](../../../04-linux-userspace-api/CHAPTER-MAP.md)

## 自测

1. 局部 `char *argv[]` 与 `main` 形参为何含义不同？  
   → 形参退化成 `char **`；局部仍是指针数组对象。  
2. 只写 `while (argv[i])` 不判 `i < argc`？  
   → 若保证 `argv[argc]==NULL` 且 `i` 递增则合法；若乱改指针表或越界写则危险。优先 `i < argc`。  
3. 能 `free(argv[0])` 吗？  
   → **不能**。非本程序 `malloc`；`free` → UB。

## 面试速记

- **元素 = `char *`**；形参整体退化 = `char **`  
- `≠ char argv[][]`  
- `argc≥1`；`argv[argc]==NULL`；勿 `free(argv[i])`
