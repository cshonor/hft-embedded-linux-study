# 《ARM64体系结构编程与实践》— 全书实验目录（Pi5 适配版）

> **书：** 《ARM64体系结构编程与实践》· 奔跑吧Linux社区 · 人民邮电出版社 · ISBN 9787115582102
> **原书平台：** 树莓派 4B（BCM2711 · Cortex-A72 · ARMv8-A）
> **你的硬件：** 树莓派 5（BCM2712 · Cortex-A76 · ARMv9-A）
> **代码仓库：** [runninglinuxkernel/arm64_programming_practice](https://github.com/runninglinuxkernel/arm64_programming_practice)
> **适配总览：** [PI5-ADAPT.md](./PI5-ADAPT.md) · [Ch2 适配笔记](./chapter-02-raspberry-pi-lab/notes/section-0-Pi5适配与实验路线.md)

---

## 核心原则

| 策略 | 说明 |
|------|------|
| **架构实验走 QEMU** | A64 指令、EL、MMU、Cache、屏障、原子 → 与板外设无关，`-M virt -cpu cortex-a76` 全部可复现 |
| **外设实验才上 Pi5** | 串口、定时器中断、GIC → 需改 BCM2712 基址 + Pi5 `config.txt` |
| **照抄 4B 会死机** | CPU 指令兼容，但 PL011/GIC 寄存器基址不兼容 |

## Pi4B → Pi5 适配清单（6 个板级实验）

只有 6 个实验依赖 BCM2711 硬件外设，其余 50 个在 QEMU 或 Linux 用户态完成。

| # | 实验 | 4B 依赖什么 | Pi5 怎么改 |
|---|------|------------|-----------|
| 1 | 实验 2-1 "Welcome BenOS" | PL011 UART @ BCM2711 基址 | 改 BCM2712 PL011 基址 + Pi5 `config.txt` 串口映射 |
| 2 | 实验 2-3 J-Link 调试 | 4B JTAG 引脚 + `config.txt` | Pi5 JTAG 引脚布局不同；查 BCM2712 手册；前期可跳过 |
| 3 | 案例 7-4 LDXR 死机 | 4B 独占监视器 + SoC 行为 | QEMU 上更容易复现；真机行为可能不同 |
| 4 | 实验 11-3 触发异常指令 | 4B 外设地址访问 | 用 BCM2712 地址或 QEMU 非法地址触发 |
| 5 | 实验 12-1 定时器中断 | BCM2711 系统计时器 | 定时器寄存器基址 → BCM2712 |
| 6 | 实验 13-2 系统定时器 | GIC-400（GICv2）@ BCM2711 | Pi5 = GIC-600（GICv3）；寄存器布局不同，需改 GICv3 接口 |

> **最大的坑：** 实验 13-2 — 4B 用 GICv2（GIC-400），Pi5 用 GICv3（GIC-600）。GICv2 和 GICv3 的寄存器映射完全不同，不能简单改地址，要改初始化流程。建议先在 QEMU `virt`（支持 GICv3）上做，再上 Pi5。

## 推荐执行顺序（Pi5 适配版）

```
阶段①  QEMU 架构实验（Ch2-14，约 42 个实验）
       主力 QEMU -M virt -cpu cortex-a76 + GDB
       不碰板级外设，把 A64 / EL / MMU / GIC 逻辑全过一遍
       ↓
阶段②  Linux 用户态实验（Ch15-16, 22-23，约 7 个实验）
       QEMU+ARM64 Linux 或 Pi5 OS 上跑
       Cache 枚举 / 伪共享 / NEON / SVE
       ↓
阶段③  Pi5 板级实验（6 个适配实验）
       串口 → 定时器中断 → GICv3
       改 BCM2712 基址 + GICv3 接口 + config.txt
       ↓
阶段④  简易 OS（Ch21，5 个实验）
       在 QEMU 上搭进程/调度/syscall 骨架
```
