# §11.1 异常类型

> **来源：** [Ch11 完整概述](section-0-本章完整概述.md) · [章导读](../README.md)

## 本节讲什么

ARMv8 的异常分为同步异常和异步异常两大类。本节列举所有异常类型及其触发原因，区分同步（当前指令触发，PC 精确）与异步（与当前指令无关，中断随时到来）。

## 核心要点

| 类型 | 触发原因 | 同步/异步 |
|------|----------|-----------|
| **SVC** | `SVC #0` 指令（系统调用） | 同步 |
| **IRQ** | 外部硬件中断 | 异步 |
| **FIQ** | 快速中断（高优先级 IRQ） | 异步 |
| **SError** | System Error（异步外部错误） | 异步 |
| **同步异常** | 页错误、未定义指令、对齐错误、SP 对齐错误 | 同步 |

> **同步** = 当前指令触发的，PC 可确定（ELR 精确）
> **异步** = 与当前指令无关，中断随时到来

### 同步 vs 异步的关键区别

- 同步异常的 ELR 指向**触发指令本身**（如 SVC 指令的地址）
- 异步异常的 ELR 指向**下一条将要执行的指令**（中断打断时的 PC）
- 这影响异常返回后从哪里继续执行

## HFT 关联

HFT 系统中，页错误（同步异常）是性能杀手——一次 TLB miss + page fault 可能引入微秒级延迟。理解同步/异步异常的区别有助于区分"可预测的慢"（如内核态系统调用）和"不可预测的慢"（如异步 SError）。在裸金属 HFT 平台上，通常禁用 IRQ 以消除异步中断抖动，但同步异常（如调试断点）仍需处理。

## 自测题

1. **SVC 指令触发的是哪种异常？ELR 保存的地址是什么？**

<details>
<summary>答案</summary>

SVC 触发**同步异常**。ELR 保存的是 **SVC 指令本身的地址**（同步异常的 ELR 指向触发指令）。返回后可以重新执行或跳过。
</details>

2. **IRQ 和 SError 的共同点是什么？它们的 ELR 指向哪里？**

<details>
<summary>答案</summary>

共同点：都是**异步异常**，与当前执行的指令无关。ELR 指向**下一条将要执行的指令**（被中断时的 PC）。IRQ 来自外部硬件，SError 来自系统总线错误。
</details>

3. **页错误（Page Fault）属于哪类异常？为什么？**

<details>
<summary>答案</summary>

**同步异常**。页错误由具体的访存指令触发（如 `LDR X0, [X1]` 访问未映射页面），CPU 在执行该指令时检测到错误，PC 可以精确定位到触发指令。因此是同步的，ELR 指向触发指令。
</details>
