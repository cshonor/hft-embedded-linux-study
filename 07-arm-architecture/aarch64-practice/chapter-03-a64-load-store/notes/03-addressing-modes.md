# 3.3 五大寻址模式

> 来源：§3.3 · 精读 · [章总览](section-0-本章完整概述.md)

## 本节讲什么

AArch64 的五种内存寻址模式：基址偏移、前变基、后变基、LDUR 负偏移、寄存器偏移。

## 核心要点

| 模式 | 语法 | 基址变化 | 示例 |
|------|------|----------|------|
| 基址偏移 | `[Xn, #imm]` | 不变 | `ldr x0, [x1, #8]` |
| 前变基 | `[Xn, #imm]!` | 更新 | `ldr x0, [x1, #16]!` |
| 后变基 | `[Xn], #imm` | 更新 | `ldr x0, [x1], #24` |
| 负偏移 | `[Xn, #-imm]` | 不变 | `ldur x0, [x1, #-8]` |
| 寄存器偏移 | `[Xn, Xm]` | 不变 | `ldr x0, [x1, x2, lsl #3]` |

- 前变基：先算地址再访问，**写回基址**
- 后变基：先访问再改基址，**写回基址**
- `!` 是前变基的标志（writeback）
- `lsl #3` 适合 8 字节元素数组索引

## HFT 关联

寻址模式选择影响代码密度和性能：
- 数组遍历用后变基（`[x1], #8`）只需一条指令完成"取值+指针前进"
- 结构体字段访问用基址偏移（`[x1, #16]`），编译器自动计算字段偏移
- `lsl #3` 索引模式让数组访问 `arr[i]` 一条指令完成（i 放在寄存器中）
- 前变基 `!` 用于栈分配/释放，减少单独的 `add/sub sp` 指令

## 自测题

1. `ldr x0, [x1, #8]` 和 `ldr x0, [x1, #8]!` 执行后 x1 的值相同吗？
<details><summary>答案</summary>
不同。前者 x1 不变（基址偏移模式）。后者 x1 = x1 + 8（前变基模式，`!` 表示写回）。
</details>

2. 写出遍历 8 字节数组元素的代码，每次取一个元素并前进指针。
<details><summary>答案</summary>
```asm
loop:
    ldr x0, [x1], #8   ; 取 x1 处的 8 字节到 x0，然后 x1 += 8（后变基）
    ; 处理 x0...
    b loop
```
</details>

3. 为什么 LDUR 要单独存在？`ldr x0, [x1, #-8]` 不行吗？
<details><summary>答案</summary>
LDR 的立即数偏移是无符号的，不支持负偏移。LDUR（Unscaled）支持负偏移，常用于栈帧向下访问（如访问调用者的局部变量）。
</details>
