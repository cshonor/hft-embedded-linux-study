# 3.2 寄存器宽度与访存宽度

> 来源：§3.2 · 精读 · [章总览](section-0-本章完整概述.md)

## 本节讲什么

LDR/STR 家族的宽度变体（B/H/W/X）、符号扩展 vs 零扩展的区别、LDUR 负偏移支持。附中括号 `[]` 内部合法写法汇总。

## 核心要点

### 命名规则

| 后缀 | 含义 | 说明 |
|------|------|------|
| B | Byte 8bit | 读/写 1 字节 |
| H | Halfword 16bit | 读/写 2 字节 |
| W | Word 32bit | 读/写 4 字节（`ldr w0`） |
| X | 64bit | 读/写 8 字节（`ldr x0`） |
| S | Sign-extend 符号扩展 | 不带 S = 零扩展 |
| UR | Unscaled offset 非缩放偏移 | 支持有符号负立即数 |

- 没有 "LDRU" 这条指令——是 **LDUR**（UR = unscaled offset）
- 没有 "LDRS" 独立指令——S 是后缀：**LDRSB / LDRSH / LDRSW**

### 中括号 `[]` 内部可以放什么

`[]` 整体含义：括号内部表达式计算出一个内存有效地址，去这个地址读写内存。只允许以下 5 种写法：

| # | 写法 | 语法示例 | 有效地址 | 说明 |
|---|------|----------|----------|------|
| 1 | 单个基址寄存器 | `[x1]` | X1 | 最基本形式 |
| 2 | 基址 + 正立即数偏移 | `[x1, #16]` | X1 + 16 | 只支持正数 |
| 3 | 基址 + 立即数 + `!` 预索引 | `[x1, #16]!` | X1 + 16 | 访问后写回 X1 |
| 4 | 基址 + 偏移寄存器 | `[x1, x2]` | X1 + X2 | 寄存器偏移 |
| 5 | 基址 + 偏移寄存器 + 移位 | `[x1, x2, lsl #3]` | X1 + (X2<<3) | lsl 只能 0/1/2/3 |

**`!` vs 后索引的区别：**
- `!` 写在中括号**里面**末尾 → 预索引（前变基），属于中括号语法
- `#16` 写在中括号**外面** → 后索引（后变基），不属于中括号内部

```asm
ldr x0, [x1, #16]!   ; 预索引：地址=X1+16，访问后 X1=X1+16
ldr x0, [x1], #16    ; 后索引：地址=X1（[]内只算X1），读完 X1+=16
```

- ❌ 中括号不能直接放 C 变量符号：`ldr x0, [my_var]` 语法错误
- 要先 `adrp x1, my_var` 再 `ldr x0, [x1]`

### LDR 家族完整指令表（读内存 → 寄存器）

| 指令 | 示例 | 读取宽度 | 扩展行为 | 目标寄存器 | 注意点 |
|------|------|---------|---------|-----------|--------|
| LDR | `ldr x0, [x1]` | 64bit | 直接 64 位加载 | X 寄存器 | |
| LDR | `ldr w0, [x1]` | 32bit | 零扩展，高 32 位清零 | W 寄存器 | |
| LDRB | `ldrb w0, [x1]` | 8bit | 零扩展到 32 位 | **只能 Wn** | 不能写 Xn |
| LDRH | `ldrh w0, [x1]` | 16bit | 零扩展到 32 位 | **只能 Wn** | 不能写 Xn |
| LDRSB | `ldrsb x0, [x1]` | 8bit | **符号扩展**到 64bit | X 寄存器 | 有符号 int8_t |
| LDRSB | `ldrsb w0, [x1]` | 8bit | **符号扩展**到 32bit | W 寄存器 | 有符号 int8_t |
| LDRSH | `ldrsh x0, [x1]` | 16bit | **符号扩展**到 64bit | X 寄存器 | 有符号 int16_t |
| LDRSH | `ldrsh w0, [x1]` | 16bit | **符号扩展**到 32bit | W 寄存器 | 有符号 int16_t |
| LDRSW | `ldrsw x0, [x1]` | 32bit | **符号扩展**到 64bit | X 寄存器 | 有符号 int32_t |
| LDUR | `ldur x0, [x1, #-8]` | 64bit | 同 LDR | X 寄存器 | 支持负立即数偏移 |

### STR 家族完整指令表（寄存器 → 内存）

STR 没有符号扩展概念，存储只截取对应宽度：

| 指令 | 示例 | 存储宽度 | 说明 |
|------|------|---------|------|
| STR | `str x0, [x1]` | 64bit | 存完整 X 寄存器 |
| STR | `str w0, [x1]` | 32bit | 存低 32 位 |
| STRB | `strb w0, [x1]` | 8bit | 取最低字节写入内存 |
| STRH | `strh w0, [x1]` | 16bit | 取低 16 位写入内存 |
| STUR | `stur x0, [sp, #-8]` | 64bit | 支持负立即偏移，栈帧局部变量用 |

### 成对指令 LDP / STP（Load Pair / Store Pair）

一次读写两个 64 位寄存器，16 字节，栈操作专用，必须 16 字节对齐：

```asm
stp x0, x1, [sp, #-16]!   ; 预索引压栈：sp-=16，存 x0+x1
ldp x0, x1, [sp], #16     ; 后索引出栈：读 x0+x1，sp+=16
```

### 关键易错点汇总

| # | 易错点 | 正确做法 |
|---|--------|---------|
| 1 | `ldrb`/`ldrh` 只能写 W 寄存器，不能写 X | 硬件零扩展到 32 位，写 W 自动清零 X 高 32 位 |
| 2 | 有符号 32 位 int 读到 64 位 X 寄存器 | 必须用 `ldrsw`；普通 `ldr w0` 只是零扩展 |
| 3 | `ldr x0, [sp, #-8]` 语法报错 | 负立即偏移用 `ldur`/`stur` |
| 4 | `!` 在 `[]` 内 = 预索引；立即数在 `[]` 外 = 后索引 | 看清偏移在括号内还是外 |
| 5 | 中括号内全部算内存地址 | LDR：从右边 `[]` 地址读数据到左边寄存器 |

## HFT 关联

| 场景 | 推荐指令 | 原因 |
|------|---------|------|
| 读市场数据 1 字节价格类型 | `LDRB` | 比 `LDR`+移位更快，一步完成 |
| 读有符号 int8_t / int16_t | `LDRSB` / `LDRSH` | 符号扩展一步完成，避免额外 `SXTB`/`SXTH` |
| 读有符号 int32_t 到 64 位 | `LDRSW` | 零扩展 `ldr w0` 会丢失负号 |
| 栈帧局部变量访问 | `LDUR` / `STUR` | 支持负偏移，如 `[sp, #-8]` |
| 函数序言/结语 | `STP` / `LDP` | 一条指令存/取两个寄存器，减少指令数 |
| 热路径数据结构遍历 | `LDR` + 寄存器偏移 `lsl #3` | 一步完成数组索引计算 |

误用 `LDRB` 读取有符号负数会导致高位为 0 而非 1 → 数值错误（如读 -1 得到 255）。

## 自测题

1. `LDRSB w0, [x1]` 和 `LDRB w0, [x1]` 读同一个字节 0xFF，结果分别是什么？
<details><summary>答案</summary>
LDRSB（符号扩展）：w0 = 0xFFFFFFFF（-1）。LDRB（零扩展）：w0 = 0x000000FF（255）。
</details>

2. `LDRH x0, [x1]` 执行后，x0 的高 48 位是什么？
<details><summary>答案</summary>
全 0。LDRH 读取 2 字节并零扩展到 64 位，高位自动清零。
</details>

3. 为什么 `LDRSB` 的 S 不要和 `ADDS` 的 S 混淆？
<details><summary>答案</summary>
LDRSB 的 S = Sign-extend（符号扩展），控制读入数据如何扩展到目标宽度。ADDS 的 S = Set flags（设置条件标志 NZCV）。两者完全不同。
</details>

4. `ldrsb x2, [x3]` 读几字节？做什么扩展？写入哪个寄存器？
<details><summary>答案</summary>
读 **1 字节**（8bit），**符号扩展到 64 位**，写入 **x2**（X 寄存器）。LDRSB = LDR + Sign-extend + Byte。目标寄存器是 x2（64 位），所以符号扩展到 64 位。
</details>

5. 栈上 sp 向下 8 字节读取 64 位数据，用哪条指令？
<details><summary>答案</summary>
`ldur x0, [sp, #-8]`。普通 `ldr` 不支持负立即偏移，必须用 LDUR。`[sp, #-8]` 表示地址 = SP - 8，读取 8 字节（64 位）到 x0。
</details>

6. `ldr w0, [x1]` 执行完，x0 的高 32 位是什么？
<details><summary>答案</summary>
**全 0**。写 Wn 时硬件自动清零 Xn 的高 32 位（AArch64 寄存器规则）。即使 x0 原来高 32 位有值，执行 `ldr w0` 后也被清零。
</details>

7. 有符号 32 位 int 变量存在内存中，要读到 64 位寄存器做运算，用 `ldr w0` 还是 `ldrsw x0`？为什么？
<details><summary>答案</summary>
必须用 **`ldrsw x0`**。`ldr w0` 做零扩展——如果 int 是负数（最高位为 1），零扩展后变成大正数，丢失符号。`ldrsw` 做符号扩展——负数扩展后仍然是负数（高位补 1），数值正确。
</details>

8. `ldr x0, [x1, #16]!` 和 `ldr x0, [x1], #16` 有什么区别？
<details><summary>答案</summary>
- `[x1, #16]!`：**预索引**（前变基），`#16` 在中括号内，有效地址 = X1+16，访问后 X1 写回 X1+16
- `[x1], #16`：**后索引**（后变基），`#16` 在中括号外，有效地址 = X1（不变），访问后 X1 写回 X1+16
- 区别：预索引先算地址再访问，后索引先访问再更新基址
</details>
