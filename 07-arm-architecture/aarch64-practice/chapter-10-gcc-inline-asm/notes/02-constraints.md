# 10.2 约束字符

> 来源：§10.2 · 精读 · [章总览](section-0-本章完整概述.md)

## 本节讲什么

GCC 内联汇编的操作数约束字符。

## 核心要点

| 约束 | 含义 |
|------|------|
| `r` | 通用寄存器 |
| `i` | 立即数 |
| `I` | AArch64 12 位无符号立即数 |
| `m` | 内存地址 |
| `=&r` | early clobber 输出 |

修饰符：`=` 输出，`+` 输入输出，`&` early clobber

## HFT 关联

- `r` 让编译器自由分配寄存器 → 最灵活
- `=&r` 防止输入输出共用寄存器 → 避免数据覆盖

## 自测题

1. `"=r"` 和 `"+r"` 的区别？
<details><summary>答案</summary>
`"=r"` 是 write-only（只写），`"+r"` 是 read-write（既读又写）。汇编需要先读再修改时用 `"+r"`。
</details>

2. 什么时候需要 `&`（early clobber）？
<details><summary>答案</summary>
输出寄存器在所有输入使用完前就被写入时。防止编译器让输出和输入共用同一寄存器。
</details>

3. `"I"(0x1000)` 和 `"i"(0x1000)` 的区别？
<details><summary>答案</summary>
`I` 是 AArch64 特有约束，限制 0-4095 范围（12 位无符号）。`i` 是通用立即数，不限制范围。
</details>
