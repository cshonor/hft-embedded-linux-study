# 4.3 移位指令

> 来源：§4.3 · 精读 · [章总览](section-0-本章完整概述.md)

## 本节讲什么

LSL/LSR/ASR/ROR 四种移位操作，移位与补码的关系，以及移位在指令中的内嵌使用。

---

## 四种移位一览

| 指令 | 全称 | 补位规则 | 数学等价 | 用途 |
|------|------|---------|---------|------|
| **LSL** | Logical Shift Left | **低位补 0** | × 2^n | 无符号/有符号通用 |
| **LSR** | Logical Shift Right | **高位补 0** | ÷ 2^n（无符号） | 无符号右移 |
| **ASR** | Arithmetic Shift Right | **高位补符号位** | ÷ 2^n（有符号） | 有符号（补码）右移 |
| **ROR** | Rotate Right | **高位补移出的低位** | 循环右移 | 哈希/加密 |

> 注意：没有 ASL（算术左移）。LSL 既是逻辑左移也是算术左移，因为左移低位补 0 对补码和无符号都正确。

---

## 移位量限制

- **立即数移位**：移位量范围 0~63（64 位）/ 0~31（32 位）
- **寄存器移位**：只取低 6 位（0~63）/ 低 5 位（0~31）

```asm
lsl  x0, x1, #3            ; x0 = x1 << 3
lsl  x0, x1, x2            ; x0 = x1 << (x2 & 0x3F)  ← x2 只取低6位
```

---

## 二进制可视化

### LSL 逻辑左移（低位补 0）

```
LSL x0, x1, #4   ; 左移 4 位

  移位前:  0x0000_0000_0000_000F   (= 15)
           ...0000000000001111
  移位后:  0x0000_0000_0000_00F0   (= 240 = 15 × 16)

           高4位被推出丢弃 → 低4位补0
           ████ ←────→ 0000
```

> LSL #n 等价于 × 2^n。`LSL #3` = × 8，`LSL #10` = × 1024。

### LSR 逻辑右移（高位补 0）

```
LSR x0, x1, #4   ; 右移 4 位，高位补 0

  移位前:  0x0000_0000_0000_00F0   (= 240)
           ...0000000011110000
  移位后:  0x0000_0000_0000_000F   (= 15 = 240 ÷ 16)

           低4位被推出丢弃 → 高4位补0
           0000 ←────→ ████
```

> ⚠️ **负数用 LSR 会变正数**！`-1 (全1) >> 1` → 高位补 0 → 变成 `0x7FFF...` = 极大正数。

### ASR 算术右移（高位补符号位）

```
ASR x0, x1, #4   ; 算术右移 4 位，高位补符号位

  情况 A: 正数 (符号位 = 0)
  移位前:  0x0000_0000_0000_00F0   (= 240, 正数)
  移位后:  0x0000_0000_0000_000F   (= 15, 仍为正)

  情况 B: 负数 (符号位 = 1, 补码)
  移位前:  0xFFFF_FFFF_FFFF_FFF0   (= -16, 负数补码)
  移位后:  0xFFFF_FFFF_FFFF_FFFF   (= -1, 仍为负)

           低4位丢弃 → 高4位复制原符号位
           ssss ←────→ ████
           (s = 符号位: 正=0, 负=1)
```

> ASR 用于补码有符号数右移，保持符号正确。`-16 >> 4 = -1`，`-1 >> 1 = -1`。

### ROR 循环右移

```
ROR x0, x1, #4   ; 循环右移 4 位

  移位前:  0x0000_0000_0000_00AB
  移位后:  0xB000_0000_0000_000A

           低4位(B)绕回到高位 → 不是丢弃
           ████ ←────→ ████
             ↑________________↓ (绕回)
```

> ROR 主要用于加密算法（如 SHA-256 的循环移位）和位反转操作。

---

## 移位与补码的关系

| 移位 | 补码有符号 | 无符号 | 何时用 |
|------|----------|--------|--------|
| LSL #n | ✅ × 2^n | ✅ × 2^n | 通用（左移补 0 对两者都正确） |
| LSR #n | ❌ 破坏符号 | ✅ ÷ 2^n | 无符号右移 |
| ASR #n | ✅ ÷ 2^n（保持符号） | ❌ 符号位污染 | 有符号（补码）右移 |

> **一句话**：左移不分有符号无符号（都用 LSL）；右移分（有符号用 ASR，无符号用 LSR）。

### 负数右移对比示例

```asm
; x0 = 0xFFFFFFFFFFFFFFFF  (= -1, 补码)

asr  x1, x0, #1            ; 算术右移 → 0xFFFFFFFFFFFFFFFF (= -1, 正确)
lsr  x2, x0, #1            ; 逻辑右移 → 0x7FFFFFFFFFFFFFFF (= 极大正数, 错误!)

; x0 = 0xFFFFFFFFFFFFFFF8  (= -8, 补码)

asr  x1, x0, #1            ; → 0xFFFFFFFFFFFFFFFC (= -4, -8÷2=-4 正确)
lsr  x2, x0, #1            ; → 0x7FFFFFFFFFFFFFFC (= 极大正数, 错误!)
```

## 内嵌移位（Shift as Operand Modifier）

移位不只是独立指令，还可**内嵌在其他指令的操作数中**：

```asm
; ADD 的第三个操作数可以带移位
add  x0, x1, x2, lsl #3    ; x0 = x1 + (x2 << 3) = x1 + x2 * 8

; SUB 同理
sub  x0, x1, x2, lsl #2    ; x0 = x1 - (x2 << 2) = x1 - x2 * 4

; AND/ORR/EOR 也支持
and  x0, x1, x2, lsl #16   ; x0 = x1 & (x2 << 16)

; CMP 也支持
cmp  x0, x1, lsl #3        ; 比较 x0 和 x1*8
```

> 内嵌移位是 A64 的一大特色：一条指令完成"移位 + 运算"，省掉一条独立移位指令。

### 数组索引（最常见内嵌移位）

```asm
; x0 = base, x1 = index, 取 arr[index]（8 字节元素）
ldr  x2, [x0, x1, lsl #3]  ; 地址 = base + index * 8

; C 等价: x2 = ((long*)x0)[x1]
```

---

## ASR #31 / ASR #63 提取符号位

```asm
; 64 位：ASR #63 → 正数得 0，负数得 -1（全 1）
asr  x1, x0, #63           ; 正数 → x1 = 0; 负数 → x1 = -1 (全1)

; 32 位：ASR #31
asr  w1, w0, #31           ; 正数 → w1 = 0; 负数 → w1 = -1 (全1)
```

> 用途：提取符号位，配合 `AND` 做条件掩码。例如 `-x` = `(x >> 63) ^ x + 1`。

---

## HFT 关联

移位是高效的乘除法替代：

| 移位 | 替代 | 延迟 | 加速比 |
|------|------|------|--------|
| `lsl #3` | `*8` | 1 cycle vs 3-5 cycle 乘法 | ~3-5× |
| `lsr #10` | `/1024` | 1 cycle vs 20+ cycle 除法 | ~20× |
| `asr #2` | `/4`（有符号） | 同上 | ~20× |

- `lsl #3` 替代 `*8`（数组索引）→ 1 cycle
- `lsr #10` 替代 `/1024`（定点小数转换）→ 避免除法器延迟
- 内嵌移位 `add x0, x1, x2, lsl #3` 一条指令完成 → 减少指令数
- ASR 用于有符号定点运算（如价格精度转换），保持符号正确
- `ASR #63` 提取符号位 → 配合 CNEG 做无分支绝对值

## 自测题

1. `ASR x0, x1, #31` 的作用是什么？
<details><summary>答案</summary>

将 x1 算术右移 31 位。结果：如果 x1 为正数则 x0=0；如果 x1 为负数则 x0=0xFFFFFFFFFFFFFFFF（全1=-1）。用于提取符号位。

</details>

2. 以下两条指令等价吗？
```asm
add x0, x1, x2, lsl #3
lsl x3, x2, #3; add x0, x1, x3
```
<details><summary>答案</summary>

结果等价，但前者是 1 条指令，后者是 2 条指令。内嵌移位更高效，编译器优先使用内嵌形式。

</details>

3. 为什么有符号除法用 ASR 而不是 LSR？
<details><summary>答案</summary>

ASR 高位补符号位（负数补1），保持结果的符号正确。LSR 高位补0，负数右移后变成大正数，结果错误。例如 -8 >> 1：ASR=-4（正确），LSR=0x7FFFFFFC（错误）。

</details>

4. `LSL x0, x1, x2`，如果 x2 = 70，实际移多少位？
<details><summary>答案</summary>

移 **6 位**。寄存器移位量只取低 6 位（0~63），70 = 0b1000110，低 6 位 = 0b000110 = 6。

</details>

5. 为什么没有 ASL（算术左移）指令？
<details><summary>答案</summary>

因为 LSL 左移低位补 0，对补码有符号数和无符号数都正确（正数左移不会"破坏符号"，负数左移是补码的倍增）。所以不需要单独的算术左移指令，LSL 同时服务于有符号和无符号。

</details>

6. `ROR` 和 `LSR` 有什么区别？
<details><summary>答案</summary>

`LSR` 移出的低位**丢弃**，高位补 0。`ROR` 移出的低位**绕回**到高位，不丢弃。例如 `0x01` ROR #4 = `0x1000000000000000`（最低位绕到最高），而 `0x01` LSR #4 = `0x0`（丢弃）。

</details>
