## 4.1 算术指令（[详细 →](01-arithmetic.md)）

### 加减法

| 指令 | 行为 | 改 NZCV？ |
|------|------|----------|
| `ADD` / `ADDS` | 加法 | ADDS 设标志 |
| `SUB` / `SUBS` | 减法 | SUBS 设标志 |
| `ADC` / `SBC` | 带进位/借位 | 用于 128 位多精度 |
| `CMP` | ≡ `SUBS XZR` | ✅ |
| `CMN` | ≡ `ADDS XZR` | ✅ |
| `NEG` / `NEGS` | 取负 | NEGS 设标志 |

口诀：**带 S 改标志；不带 S 只算数值。**

### 乘法

| 指令 | 作用 | 补码关系 |
|------|------|---------|
| `MUL` | 低 64 位乘积 | 有符号/无符号**通用** |
| `MADD` | `Ra + Rn * Rm` | 乘加 |
| `MSUB` | `Ra - Rn * Rm` | 乘减 |
| `SMULH` | 有符号高位 | 与 `UMULH` **不同** |
| `UMULH` | 无符号高位 | 与 `SMULH` **不同** |

### 除法（唯一必须区分有符号/无符号的运算）

| 指令 | 作用 | 特性 |
|------|------|------|
| `SDIV` | 有符号除法 | 向零截断，除零结果=0 |
| `UDIV` | 无符号除法 | 除零结果=0 |

### 补码与运算总结

| 运算 | 指令是否区分有符号/无符号 | 说明 |
|------|------------------------|------|
| 加/减 | ✅ 相同（同一 ADD/SUB） | 只有溢出标志不同（C vs V） |
| 乘法（低位） | ✅ 相同（同一 MUL） | 补码性质：低 64 位相同 |
| 乘法（高位） | ❌ 不同 | SMULH vs UMULH |
| 除法 | ❌ 完全不同 | SDIV vs UDIV |

## 4.2 NZCV 四个条件标志 ⭐（[详细 →](02-nzcv.md)）

> **展开专篇：** [NZCV.md](../../NZCV.md) · [SIGNED-UNSIGNED.md](../../SIGNED-UNSIGNED.md)（补码 / 指令决定解读）

| 标志 | 含义 | 适用 |
|------|------|------|
| **N** Negative | 结果最高位为 1 | 有符号视角正负 |
| **Z** Zero | 结果为 0 | 相等判断 |
| **C** Carry | 无符号进位/借位**取反** | 无符号比较 |
| **V** oVerflow | 有符号溢出 | 有符号比较 |

> **C ≠ V**：C 管无符号；V 管有符号。一次 ADDS 同时设两套溢出标志。

### 条件后缀速查

| 后缀 | 条件 | 含义 |
|------|------|------|
| `EQ`/`NE` | Z=1/Z=0 | 相等/不等 |
| `HS`/`LO` | C=1/C=0 | 无符号 ≥ / < |
| `HI`/`LS` | C=1∧Z=0 / C=0∨Z=1 | 无符号 > / ≤ |
| `GE`/`LT` | N==V / N!=V | 有符号 ≥ / < |
| `GT`/`LE` | Z=0∧N==V / Z=1∨N!=V | 有符号 > / ≤ |
| `MI`/`PL` | N=1/N=0 | 负/正或零 |
| `VS`/`VC` | V=1/V=0 | 有符号溢出/无溢出 |

## 4.3 移位（[详细 →](03-shift.md)）

| 指令 | 补位 | 数学等价 | 适用 |
|------|------|---------|------|
| **LSL** | 低补 0 | × 2^n | 通用（左移不分有符号无符号） |
| **LSR** | 高补 0 | ÷ 2^n | **无符号**右移 |
| **ASR** | 高补符号位 | ÷ 2^n | **补码有符号**右移 |
| **ROR** | 循环 | 循环右移 | 加密/哈希 |

```asm
lsl x0, x1, #3            ; x0 = x1 << 3 = x1 * 8
add x0, x1, x2, lsl #3    ; x0 = x1 + (x2 << 3)  ; 内嵌移位
asr x0, x1, #63           ; 提取符号位：正→0，负→-1
```

> 左移都用 LSL；右移有符号用 ASR、无符号用 LSR。移位量取低 6 位（0~63）。

## 4.4 位操作（[详细 →](04-bit-ops.md)）

| 指令 | C 等价 | 用途 |
|------|--------|------|
| `AND`/`ANDS` | `a & b` | 提取/掩码 |
| `ORR` | `a \| b` | 置位 |
| `EOR` | `a ^ b` | 翻转/加密 |
| `BIC`/`BICS` | `a & ~b` | 清位 |
| `TST` | `a & b`（丢弃） | 测试位 |
| `ORN`/`EON` | `a \| ~b` / `a ^ ~b` | 或非/异或非 |

```asm
orr x0, x0, #(1<<4)   ; 置位第4位
bic x0, x0, #(1<<4)   ; 清除第4位
eor x0, x0, #(1<<4)   ; 翻转第4位
tst x0, #(1<<4)       ; 测试第4位
```

### MOV 系列

| 伪指令 | 展开为 | 用途 |
|--------|--------|------|
| `MOVZ` | 16位立即数 + 补0 | 加载低位 |
| `MOVK` | 16位立即数 + 保持 | 拼接高位 |
| `MOVN` | 16位立即数 + 取反 | 构造全1/掩码 |

> ⚠️ 位操作立即数不是任意 64 位值，必须是连续位段模式（13位编码）。非法立即数需 MOVZ/MOVK 组合。

## 4.5 位段提取 / 插入（[详细 →](05-bit-field.md)）

| 指令 | 作用 | 扩展 |
|------|------|------|
| `UBFX Rd, Rn, #lsb, #width` | 提取位段 | **零扩展** |
| `SBFX Rd, Rn, #lsb, #width` | 提取位段 | **符号扩展** |
| `BFI Rd, Rn, #lsb, #width` | 插入位段 | 不变 |
| `BFC Rd, #lsb, #width` | 清除位段 | 清零 |

```asm
ubfx x1, x0, #16, #8     ; 提取 x0[23:16]，零扩展
sbfx x1, x0, #5, #19     ; 提取 x0[23:5]，符号扩展
bfi  x0, x1, #4, #8     ; 把 x1[7:0] 插入 x0[11:4]
```

> 内核页表项解析（PTE 属性位）、协议字段打包（type+flags）的高频指令。

## 4.6 典型例子（[详细 →](06-examples.md)）

- **对齐**：`add x0, x0, #15; bic x0, x0, #0xF`（向上对齐 16）
- **位域打包**：`bfi` 一步插入字段
- **绝对值**：`asr + eor + sub` 或 `cneg`（无分支）
- **乘加**：`madd x0, price, qty, fee`
- **移位替代乘除**：`lsl #3` = ×8, `asr #2` = ÷4
- **无分支最大值**：`cmp; csel x0, x1, x2, ge`

## 4.7 易错坑（[详细 →](07-pitfalls.md)）

1. **有符号 vs 无符号比较**用错条件后缀（`LT` vs `LO`）→ 地址用 LO，价格用 LT
2. **ASR vs LSR** 选择错误（有符号用 ASR，无符号用 LSR）
3. **SUBS 的 C 标志是借位取反**（C=1 表示无借位/大于等于）
4. **UBFX vs SBFX** 选错（有符号字段用 SBFX）
5. **忘加 S** → NZCV 不更新 → 后续条件全错
6. **MUL 不支持立即数** → 用 `lsl`（2的幂）或 `madd + xzr`
7. **SDIV 向零截断** ≠ 向下取整（`-7/2 = -3` 不是 -4）
8. **除零不报错** → 结果为 0，不 crash（与 x86 不同）

## 补码与运算：一句话总结

> ARM64 寄存器/内存**只有二进制比特流**，不标记 signed/unsigned。有符号数用**补码**存放。**指令**决定怎么解释。
> - 加减法：同一条 ADD/SUB，补码和无符号结果完全相同，只有溢出标志不同（C vs V）
> - 乘法低 64 位：同一条 MUL，结果相同；高 64 位需 SMULH/UMULH 分
> - 除法：必须选 SDIV（有符号，向零截断）或 UDIV（无符号）

详见 → [SIGNED-UNSIGNED.md](../../SIGNED-UNSIGNED.md) · [NZCV.md](../../NZCV.md)

## 书中思考题（自测）

1. ADD 与 ADDS 区别？CMP 本质？  
2. C 与 V 分别代表什么？对应无符号还是有符号？  
3. LSR 与 ASR 差别？何时用哪个？  
4. BIC 作用？  
5. UBFX 与 SBFX 区别？  
6. MUL 取低 64 位时，有符号和无符号结果相同吗？  
7. SDIV 和 UDIV 有什么区别？`-7/2` 分别得多少？  
8. ARM64 除零会怎样？

**参考答案：**

1. ADD 不算标志；ADDS 更新 NZCV。CMP ≡ `SUBS XZR, …`。  
2. C=无符号进位/借位取反；V=有符号溢出。  
3. LSR 高位补 0（无符号）；ASR 填符号位（有符号）。  
4. `Rd = Rn & ~Op`，清指定位。  
5. 提取位段后：UBFX 零扩展，SBFX 符号扩展。  
6. **相同**。补码性质：低 64 位结果一致。高位才不同。  
7. SDIV 有符号向零截断，`-7/2=-3`；UDIV 无符号。**除法是唯一必须选的运算。**  
8. 结果为 0，不 crash 不 trap（软件需自行检查）。
