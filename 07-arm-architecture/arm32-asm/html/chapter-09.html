阶段 说明

9.3

section-9.3-overview

Ch 9 · 浮点简介 · 章导读

整数范围的局限

32 bit 无符号整数 最大约 4.3×10⁹ — 不够表示：

  • 天文距离、微观物理量
  • 跨度极大的传感器标定
  • 同时需要 很大 与 很小 动态范围的科学计算

浮点 tradeoff： 牺牲部分精度 → 换取 巨大动态范围。

单精度正数范围（量级）

约 1.18×10⁻³⁸ ~ 3.40×10³⁸ — 同一 32 bit 字宽，指数伸缩数量级。

非固定间距（与整数根本不同）

整数 int32 浮点 float
相邻值间隔 恒为 1（同阶） 随指数变大而变大
大数附近 精确到个位 可能 ULP 间距很大
小数附近 无法表示 1e-20 间距可很小

工程含义： float 不等于 「带小数点的整数」— 比较、累加要考虑 ULP/舍入（→ Ch10）。

HFT 对照： 价格 tick 常用 定点 int 就是为 均匀间距 + 确定性 — 与 float 哲学相反。

可复述要点

  1. 浮点 = 动态范围优先，不是无限精度小数。
  2. 间距随指数变 — 大 float 加 1 可能不变（ULP）。
  3. 嵌入式：有 FPU 用 float；无 FPU 用 Q 格式（Ch7.7）。

section-9.4-data-types

Ch 9 · 浮点简介 · 章导读

Cortex-M4 FPU 支持的格式

开发者名 IEEE bit byte 存储粒度 寄存器 M4 用途
f32 binary32 32 4 word s0–s31 主要硬件计算
（半精度） binary16 16 2 halfword 经转换 省 RAM，精度低
f64 binary64 64 8 双字（4 对齐） d0–d15 M4 常不硬件算 — 见实现

Ch2 映射： §2.2 标量与浮点 — f32 与 s32/u32 同占 4 byte，解释与 r vs s 寄存器 不同。

单精度位域（符号-幅度 + 偏置指数）

| S |   exp (8)   |      fraction f (23)      |
 1       bias=127           隐含 leading 1

正常值公式：

[ F = (-1)^s \times 2^{(exp - 127)} \times 1.f ]

字段 含义
S 0 正 · 1 负
exp 存储值 = 真实指数 + 127（bias）
f 小数部分；规格化数隐含前导 1（1.f）

Ch1 回顾： §1.5 已画框图 — 本章落到 M4 指令。

与整数比特

同一 32 bit 字 — 解释不同：

        VMOV    r0, s0          ; 位拷贝，非「转换」（§9.9）
        VCVT    …               ; 真转换（§9.11）

可复述要点

  1. f32 = 32 bit word 宽 · f64 = 64 bit 双字 — 与 Ch2 §2.2 整数表并列记忆。
  2. M4 主战场 = f32 / s 寄存器；8 exp + 23 frac + sign，bias 127。
  3. f64 / d 多为 A 核完整 VFP 或 软件 double；M4 以 single* 为主。
9.5

section-9.5-representable

Ch 9 · 浮点简介 · 章导读

五类值之前三类（§9.6 续：∞ · NaN）

1. 正常值 (Normal)

exp 既不全 0 也不全 1（典型），符合 (F = (-1)^s 2^{exp-127} 1.f)。

绝大多数日常 float 运算 在此类。

2. 次正常值 (Subnormal / Denormal)

当数值 太小，无法用正常格式表达：

Normal Subnormal
指数 正常 bias 解码 固定最小指数（单精度 -126）
隐含 leading 1. 0.
作用 标准精度 向 0 延伸 可表示范围
代价 — 精度更差

性能注： 某些 CPU 上 denormal 极慢 — HFT/实时代码或 flush-to-zero（→ Ch10/Ch11）。

3. 零 (Zeros)

exp 全 0，frac 全 0 → +0.0 与 -0.0（S 不同）。

为何保留 -0 说明
方向信息 趋近 0 的极限保留符号
比较 +0 == -0 为真，但 1/+0 vs 1/-0 符号不同（∞）

C： copysign、IEEE 比较规则 — 汇编层用 VMOV/VCMPE（Ch11）。

可复述要点

  1. Normal = 常规定义；Subnormal = 更靠近 0 的「残精度区」。
  2. ±0 比特不同、比较相等 — debug 浮点时别惊讶。
  3. 次正常常是 性能陷阱 — Ch10 FZ 模式相关。

合并精读（五类 + 定点 Qm）： 9.x-ieee754-special-and-fixed-point.md

9.6

section-9.6-special-values

Ch 9 · 浮点简介 · 章导读

4. 无穷大 (Infinities)

exp 全 1，fraction 全 0 → +∞ / -∞。

来源 例子
溢出 极大运算结果
除法 有限 / 0（非 NaN 路径）

比较： ∞ 参与 ordered compare 有特殊规则（Ch11 VCMPE）。

5. 非数字 (NaN — Not a Number)

exp 全 1，fraction ≠ 0 → NaN。

类型 行为
sNaN (signaling) 触发异常 — 非法使用时告警
qNaN (quiet) 静默传播 — NaN op x → NaN

典型产生：

  • 0.0 / 0.0
  • ∞ × 0
  • 未初始化 float 内存（若碰巧 bit 模式像 NaN）
  • 非法 sqrt(-1) 等

调试： 一旦出现 NaN，整条链污染 — 飞控/PID 必须 检测与 clamp。

五类一览

类 exp frac 例
Normal 中间 任意 3.14
Subnormal 0 ≠0 极小
±0 0 0 +0, -0
±∞ 全1 0 overflow
NaN 全1 ≠0 0/0

→ Ch10 舍入/异常标志在 FPSCR 累积。

可复述要点

  1. ∞ = 溢出/除零的极端；NaN = 未定义或未初始化。
  2. qNaN 静默传播 — C 里 isnan() 必备。
  3. 嵌入式：别让控制环跑出 NaN — 与 Ch7 SSAT 同类「防崩」。

合并精读（五类 + 定点 Qm）： 9.x-ieee754-special-and-fixed-point.md

section-9.7-fp-registers

Ch 9 · 浮点简介 · 章导读

与整数寄存器分离

银行 名称 数量
整数 r0–r12, sp, lr, pc Ch2
FPU 单精度 s0 – s31 32 × 32 bit
别名双精度 d0 – d15 每 d = 两个 s 拼成 64 bit 
s0, s1  →  d0
s2, s3  →  d1
…

M4 计算主线： 单精度 s* — Ch3 示例 VMOV.F / VADD.F 用 s。

调用约定（预告 Ch13/Ch18）

典型 AAPCS 规则
float 参数/返回值 s0, s1, …
double（若支持） d0, d1, …
与 r0–r3 并行 浮点 ABI 独立 — 混调 C 需遵守

Linux 内核： kernel_fpu_begin/end 保存 vfp 状态 — 用户态 s0–s31 与内核隔离。

可复述要点

  1. s0–s31 是 FPU 的「r 寄存器」。
  2. d 是 s 的 64 bit 视图 — M4 以 single* 为主。
  3. VMOV r,s 只是 位拷贝，不是 float↔int 换算。
9.8

section-9.8-fpu-control

Ch 9 · 浮点简介 · 章导读

CPACR — 必须先开 FPU

协处理器访问控制寄存器 — FPU = CP10 + CP11。

        ; 概念：对 CPACR 写 Full Access CP10/11
        ; 具体地址/位域见 CM4 手册（如 0xE000ED88 区）
未配置 后果
CP10/11 未授权 执行 V 指令 → UsageFault / Undefined*

Ch3 §3.6 第一步 — 任何 VLDR/VADD 之前。

FPSCR — 浮点状态与控制

类似整数 APSR，浮点侧 FPSCR 含：

类别 内容
比较标志 N Z C V（浮点比较后）
舍入模式 RMode 向 nearest/even 等（→ Ch10）
FZ (Flush-to-Zero) 次正常 → 0
DN (Default NaN) NaN 传播策略
累积异常标志 IDC/OFC/UFC/OFC/DZC/IOC 等 — 除零、溢出、下溢、不精确

读/写 FPSCR — 特权 MRS/MSR 类到系统寄存器（具体助记符见手册）。

与 Ch10–11 分工

章 FPSCR 内容
Ch9 知道 存在 + CPACR 使能
Ch10 舍入模式、异常 含义
Ch11 运算后 检查标志

可复述要点

  1. CPACR 开 CP10/11 — FPU 电源/门禁。
  2. FPSCR = 浮点标志 + 舍入 + 异常累积。
  3. 裸机启动代码常 Init FPU 一段 — 与 Init 时钟同级。

section-9.9-fp-transfer

Ch 9 · 浮点简介 · 章导读

内存 ↔ FPU：VLDR / VSTR

        VLDR    s5, [r6, #8]        ; s5 ← Mem32[r6+8]
        VSTR    s0, [sp, #-4]!      ; 压栈单精度（配合 Ch13）
        VLDR.F32 s1, =3.14159       ; 伪指令 → 文字池（Ch6）
指令 方向
VLDR 内存 → s
VSTR s → 内存

对齐： 单精度通常 4 字节对齐 — 违例 fault（同 Ch2/Ch5）。

与 Ch5： 同一 LDR/STR 寻址模式 — [Rn, #off]、!、post-index 可用于 VSTR/VLDR（语法随汇编器）。

整数 ↔ FPU：VMOV（位拷贝）

        VMOV    s0, r0              ; 32 bit 模式复制
        VMOV    r0, s0
        VMOV.F32 s1, #1.0            ; 部分「简单」浮点立即数
        VMOV    s2, s0              ; FPU 寄存器间
重要 说明
r ↔ s VMOV reinterpret — 不 做 int→float 数值转换
真转换 VCVT（§9.11）
Ch3 §3.7 已演示 r/s 搬运

数据流图

Mem  ←VSTR/VLDR→  s0–s31  ←VMOV→  r0–r12
                      ↓
                   VCVT / VADD…（Ch11）

可复述要点

  1. VLDR/VSTR = 浮点版 Load/Store。
  2. LDR = 浮点常数 同样走文字池。
  3. VMOV r,s ≠ VCVT — 别用 VMOV 当 (float)int。

section-9.10-precision-convert

Ch 9 · 浮点简介 · 章导读

为何半精度 (FP16)

收益 代价
存储减半 — 大数组、神经网络权重 精度/范围更低
总线/Flash 带宽 算前 often 转 single

M4： 硬件 single 为主 — half 多用于 load/store 压缩。

转换指令（书中）

指令 方向（概念）
VCVTB Bottom — single → half 存到 寄存器低 16 或内存半字
VCVTT Top — 类似，高 16 半字路径（成对打包）

用法模式： 两个 half 可 打包进一个 32 bit 字 — 类似 SIMD 打包思想。

具体语法 以 ARM 汇编手册为准 — 笔记记 「single ↔ half 硬件转换，省软件 bit-twiddle」。

与 Ch22 FP16/NEON

应用处理器 NEON FP16 算力更强 — M4 以 VCVT + 存储 为主。

可复述要点

  1. Half = 省内存；计算常用 promote to float。
  2. VCVTB/VCVTT = M4 硬件 half↔single。
  3. 别手写 shift 除非无 FPU。
9.11

section-9.11-int-float-convert

Ch 9 · 浮点简介 · 章导读

整数 ↔ 单精度 — VCVT

        VCVT    s0, r0                ; 有符号/无符号变体见手册 VCVT.xxx
        VCVT    r0, s0, #0            ; float → int，向零舍入（截断小数）
方向 行为
int → float 精确表示整数（在 float 可表示范围内）
float → int 默认 toward zero — (int)f 截断；溢出 → 饱和或异常（FPSCR）

与 VMOV 区别：

VMOV s0, r0   →  位模式拷贝（垃圾 int 当 float 解释）
VCVT s0, r0   →  数值 42 → 42.0f

定点 (Fixed-point) ↔ float

VCVT 带 #fbits（书中）： 指定 小数位数 的定点 interpreted 整数 ↔ single。

场景 说明
ADC 采样 驱动读 12 bit 左对齐 — 转 engineering unit float
DAC 输出 float PID 输出 → 定点 → 寄存器
vs Ch7 Q 格式 硬件 VCVT 省 shift + SSAT 软件

规则回顾（Ch7.7）： Qn×Qm → 乘积需 rescale；VCVT 把 rescale 放进 FPU。

C 对照

C 汇编倾向
(float)i VCVT
(int)f VCVT 向零
*(float*)&i VMOV — 类型双关，危险

可复述要点

  1. 数值转换用 VCVT；位模式用 VMOV。
  2. float→int 截断 — 控制环取整时要注意 bias。
  3. #fbits 定点 VCVT — ADC/DAC 与 23 飞控 接口实用。

速查表（先看这张）

设指数域宽度为 (w)，全 0 / 全 1 为特殊；bias：binary32=127，binary64=1023。

类别 指数 (e) 尾数 (f) 含义
Normal (1 \le e \le 2^w-2)（非全 0/全 1） 任意 隐含前导 1.
Subnormal 全 0 (f \ne 0) 隐含前导 0.；填 0 与最小正规数之间空隙
±0 全 0 全 0 仅符号位分 +0 / −0
±∞ 全 1 全 0 溢出 / 除以零等
NaN 全 1 (f \ne 0) 非数值；QNaN / SNaN

一、Normal（归一化 / 正规数）

  • (s)：符号
  • (e)：不是全 0、不是全 1（binary32：(e=1\ldots254)；bias=127 不是「e 最大等于 127」）
  • 值：(V = (-1)^s \times (1.f)_2 \times 2^{e-\mathrm{bias}})

日常 1.0、3.14、−25.6 等几乎都是正规数；精度与有效位数最好。

二、Subnormal（次正规 / 亚正常）

  • (e=0) 且 (f\neq0)
  • (V = (-1)^s \times (0.f)_2 \times 2^{1-\mathrm{bias}})

作用： 填满「最小正规数 → 0」之间的间隙，减轻「突然下溢成 0」。
binary32 最小正规 (\approx 1.175\times10^{-38})；次正规可表示更靠近 0 的正数。

代价： 无隐含 1.，有效位变少；软硬实现常更慢（MCU/部分 CPU 路径会顿）。

三、±0

  • (e=0,\ f=0)；(s=0) → +0，(s=1) → −0
行为 说明
相等 +0 == -0 为真（通常）
除法 1/(+0)=+∞，1/(-0)=-∞
存储 两种不同比特模式

四、±∞

  • (e=) 全 1，(f=0)

常见来源：大数溢出；有限数 / ±0。
规则直觉：∞+有限→∞；有限/∞→0（符号按规定）。

五、NaN

  • (e=) 全 1，(f\neq0)
类 尾数最高位（常见约定） 行为
QNaN（静默） 常为 1 传播 NaN，不一定立刻 trap
SNaN（信号） 常为 0 参与运算可触发无效操作异常（调试非法）

来源：0/0、∞−∞、√负数、无意义运算等。

关键： NaN == NaN → false；判 NaN 用 isnan 等，不要靠 ==。

六、无 FPU：定点小数替代浮点

为何要定点

Cortex-M0/M0+/M3 等常 无硬件 FPU：C 里写 float → 库软浮点，极慢；实时滤波 / PID / 紧循环忌用。
（有 FPU 的 M4F / A 系列另说；Linux 应用核一般有浮点，但驱动热路径仍常避开软浮点。）

原理（Qm）

把整数位模式 约定 小数点位置，用整数加减乘除模拟小数。
例 Q15（16 位）：1 符号 + 整数/小数划分依约定；值 (\approx) 原始整数 ( / 2^{15})。
亦常见 Q8 / Q31。

运算要点

运算 注意
加减 同 Q 格式可直接加减
乘 积位数变长，常需 右移 m 收回小数点
除 常先 左移 m 再除，保精度

取舍

  • 快、无 FPU 依赖
  • 范围与精度互斥；易溢出；手写缩放易错 → 用 CMSIS-DSP 等定点库

嵌入式滤波、电机 PID、传感器预处理大量用 Q 格式。

七、一句话

  1. 看 e 是否全 0/全 1 + f 是否 0 → 五类立刻分开
  2. 正规有隐含 1.；次正规填空隙但更慢更糙
  3. NaN 不可用 == 自比
  4. 无 FPU → 定点 Qm，别靠软 float 撑实时
