IEEE 754 五类特殊值 · 无 FPU 定点替代

锚定 Hohl/Hinds Ch9 §9.5–9.6 · 单/双精度规则同构（域宽不同）
§9.5 可表示值 · §9.6 无穷/NaN · Ch9 总览
标签：主线可跳；MCU / 滤波 / PID 与理解 float「坑」时精读

速查表（先看这张）

设指数域宽度为 (w)，全 0 / 全 1 为特殊；bias：binary32=127，binary64=1023。

类别 指数 (e) 尾数 (f) 含义
Normal (1 \le e \le 2^w-2)（非全 0/全 1） 任意 隐含前导 1.
Subnormal 全 0 (f \ne 0) 隐含前导 0.；填 0 与最小正规数之间空隙
±0 全 0 全 0 仅符号位分 +0 / −0
±∞ 全 1 全 0 溢出 / 除以零等
NaN 全 1 (f \ne 0) 非数值；QNaN / SNaN

一、Normal（归一化 / 正规数）

  • (s)：符号
  • (e)：不是全 0、不是全 1（binary32：(e=1\ldots254)；bias=127 不是「e 最大等于 127」）
  • 值：(V = (-1)^s \times (1.f)_2 \times 2^{e-\mathrm{bias}})

日常 1.0、3.14、−25.6 等几乎都是正规数；精度与有效位数最好。

二、Subnormal（次正规 / 亚正常）

  • (e=0) 且 (f\neq0)
  • (V = (-1)^s \times (0.f)_2 \times 2^{1-\mathrm{bias}})

作用： 填满「最小正规数 → 0」之间的间隙，减轻「突然下溢成 0」。
binary32 最小正规 (\approx 1.175\times10^{-38})；次正规可表示更靠近 0 的正数。

代价： 无隐含 1.，有效位变少；软硬实现常更慢（MCU/部分 CPU 路径会顿）。

三、±0

  • (e=0,\ f=0)；(s=0) → +0，(s=1) → −0
行为 说明
相等 +0 == -0 为真（通常）
除法 1/(+0)=+∞，1/(-0)=-∞
存储 两种不同比特模式

四、±∞

  • (e=) 全 1，(f=0)

常见来源：大数溢出；有限数 / ±0。
规则直觉：∞+有限→∞；有限/∞→0（符号按规定）。

五、NaN

  • (e=) 全 1，(f\neq0)
类 尾数最高位（常见约定） 行为
QNaN（静默） 常为 1 传播 NaN，不一定立刻 trap
SNaN（信号） 常为 0 参与运算可触发无效操作异常（调试非法）

来源：0/0、∞−∞、√负数、无意义运算等。

关键： NaN == NaN → false；判 NaN 用 isnan 等，不要靠 ==。

六、无 FPU：定点小数替代浮点

为何要定点

Cortex-M0/M0+/M3 等常 无硬件 FPU：C 里写 float → 库软浮点，极慢；实时滤波 / PID / 紧循环忌用。
（有 FPU 的 M4F / A 系列另说；Linux 应用核一般有浮点，但驱动热路径仍常避开软浮点。）

原理（Qm）

把整数位模式 约定 小数点位置，用整数加减乘除模拟小数。
例 Q15（16 位）：1 符号 + 整数/小数划分依约定；值 (\approx) 原始整数 ( / 2^{15})。
亦常见 Q8 / Q31。

运算要点

运算 注意
加减 同 Q 格式可直接加减
乘 积位数变长，常需 右移 m 收回小数点
除 常先 左移 m 再除，保精度

取舍

  • 快、无 FPU 依赖
  • 范围与精度互斥；易溢出；手写缩放易错 → 用 CMSIS-DSP 等定点库

嵌入式滤波、电机 PID、传感器预处理大量用 Q 格式。

七、一句话

  1. 看 e 是否全 0/全 1 + f 是否 0 → 五类立刻分开
  2. 正规有隐含 1.；次正规填空隙但更慢更糙
  3. NaN 不可用 == 自比
  4. 无 FPU → 定点 Qm，别靠软 float 撑实时
