4.2

section-4.2-module-structure

Ch 4 · 汇编器规则与伪指令 · 章导读 · 本章概述

一、核心：单行汇编四分段标准格式

{标签}  {指令/伪指令}  {操作数}  {; 注释}

四个字段均为 可选；有指令/伪指令时必须缩进 — ARM 汇编（Keil）与 GNU 汇编通用基础规范。

各字段强制规则

字段 书写规范 关键禁忌
标签 必须写在 行首（第 1 列），无前置空格 前面有空格会被当成指令 → 报错；末尾常加 :（部分汇编器可省略）
指令/伪指令 前方必须有 空格/Tab 缩进，不能顶格 顶格会被当成 标签 → 语法错误
操作数 跟在指令后，逗号分隔；无操作数可省略 —
注释 Keil/ARM： ; 至行尾
GNU as： @ 单行 · /* */ 块注释		 ; / @ 只作用本行，不跨行

背一句：

顶格 = 标签；缩进 = 指令。

二、示例逐行解析

loop            ; loop 标签：行首无空格，跳转目标
    ADD r0, r0, #1  ; ADD：前置 Tab；r0 = r0 + 1
    B   loop        ; 无条件跳转到 loop
行 作用
loop 标签 — 给当前指令地址起别名；B/BL/调用可引用
ADD r0, r0, #1 算术指令；必须缩进
B loop 无条件分支 → 标签 loop

三、标签（Label）完整讲解

1. 本质定义

标签是 代码/数据行内存地址的文字别名。

CPU 靠地址取指；手写数字地址易错。标签给位置起名，汇编器把名字换成对应 地址/偏移。

2. 书写硬性规则

  1. 必须顶格（第 1 列），前不能有空格/Tab：
loop            ; ✓ 正确：行首无空格
    ADD r0, r0, #1

    loop        ; ✗ 错误：前有空格 → 被当成指令名 → 报错
    ADD r0, r0, #1
  1. 可加冒号（ARM / GNU 都常见；省略多数也能认）：
loop:
    ADD r0, r0, #1

3. 三大核心用途

① 跳转 / 分支（最常用）

loop
    ADD r0, r0, #1
    B   loop        ; 无条件跳到 loop
; BEQ / BNE 等同理，靠标签定位目标

② 函数调用入口

main
    BL  func_sum    ; 带返回的跳转

func_sum            ; 函数入口标签
    ADD r0, r1, r2
    MOV pc, lr

③ 数据地址符号

str_msg:
    .asciz "hello"
; …
    LDR r0, =str_msg   ; str_msg = 字符串首地址

（Keil 侧常见 DCB "hello",0 + LDR r0, =str_msg，语义相同 → §4.4）

4. 底层原理（汇编两遍直觉）

  1. 读到标签 → 记下 「名字 ↔ 当前偏移/地址」
  2. 遇到 B / BL / LDR = 引用该名 → 换成数值地址

标签本身 不生成机器指令，只做记号。

5. 易混区分 ⚠

标签 指令（ADD / B / LDR…）
作用 标记 地址 变成可执行 机器码
占指令空间？ 否（不产生 opcode） 是

6. 极简记忆

标签 = 代码/数据位置的名字，给跳转、调用、取地址用 — 必须顶格写。

四、注释 · 易错 · 模块意义

1. 两种工具链注释

工具链 注释
ARM / Keil MDK ; … 至行尾
GNU as（GCC、Linux、裸机） @ 单行 · /* … */ 块

2. 易错坑 ⚠

  1. 指令顶格 → 当成标签 → 未定义符号 / 语法错
  2. 标签前加空格 → 标签失效，无法作跳转目标
  3. 行首先写 ; → 整行注释掉，后面的标签也不会生效

3. 模块结构整体意义

整个 .s / .asm = 多行四分段格式 + 段伪指令（Keil AREA / GNU .text · .data）→ 完整可汇编模块。
→ §4.4 伪指令

五、常量表示（本节约）

类型 典型写法
十进制 42
十六进制 Keil 0xFF · CCS 或见 0xFFh
字符 'A'
字符串 "Hello"（NUL / 转义随工具链略异）

C 对照：.rodata 的 "Hello\n\0" ↔ Keil DCB "Hello",0 / GNU .asciz "Hello"。

六、模块 = 一个源文件

概念 说明
多文件 每文件若干 段；链接器合并（→ Ch1 §1.7）
符号 LOCAL / EXPORT / GLOBAL — 跨文件靠全局符号
与 C 混合 .c + .s → 各自 .o → 链接（→ Ch18）

GNU (gas) 行格式示例

.global _start
_start:                     @ 标签（可带 :）
    mov     r0, #1          @ 指令须缩进
.Lloop:
    b       .Lloop
Keil GNU
标签第 1 列 同上
; @ 或 /* */

七、记忆要点

  1. 顶格 = 标签，缩进 = 指令
  2. 标签 = 地址别名；分支 / 调用 / 取数据地址全靠它
  3. 标签 不产生机器码；指令才产生
  4. 注释符跟 工具链（Keil ; · GNU @）
  5. 源文件 = 标签 + 指令 + 伪指令（段）→ .o

section-4.3-register-names

Ch 4 · 汇编器规则与伪指令 · 章导读

内置别名（区分大小写）

汇编器识别 寄存器名 与 r0–r15 编号 等价（Keil 等通常 小写）：

名称 等价 角色（Ch2）
r0 – r12 — 通用
r13 sp 堆栈指针 Stack Pointer
r14 lr 链接寄存器 Link Register
r15 pc 程序计数器 Program Counter
cpsr — 当前程序状态寄存器
spsr — 异常保存的 CPSR（ARM7 特权模式）

M4 扩展： msp / psp 作为 r13 的两种视图（CONTROL 选择）— 部分汇编器/ intrinsic 暴露。

浮点（M4F）： s0–s31、d0–d15（双精度对）— Ch9 详述。

为什么用别名

        PUSH    {lr}            ; 可读
        BL      handler
        POP     {pc}            ; 从 lr 返回（模式相关，Ch13 详述）
写法 评价
MOV sp, r0 清晰表达意图
MOV r13, r0 正确但可读性差

Linux 内核 .S： 普遍 r0–r15 + sp/lr 混用 — 与 AAPCS 文档一致。

状态寄存器访问

  • CPSR/xPSR 通常 不能 像通用寄存器随便 MOV — 需 MRS/MSR 等特权指令（Ch7/Ch15）。
  • 汇编器仍提供 cpsr 符号供 MRS/MSR 助记符使用。

AArch64 对照（奔跑吧）

v4T/v7-M AArch64
r0–r15 x0–x30 · sp · pc（不可直接写）
cpsr PSTATE 字段 · SPSR_elx

可复述要点

  1. sp/lr/pc = r13/r14/r15 — 汇编器预定义，大小写敏感。
  2. 别名只为 可读性 — 机器码里仍是编号。
  3. 读 U-Boot/内核启动代码时，先 认 sp/lr 再跟栈与返回。
4.4

section-4.4-directives

Ch 4 · 汇编器规则与伪指令 · 章导读

伪指令是什么

不交给 CPU 执行 — 在 汇编阶段 指导汇编器：放哪个段、占多少字节、符号等于多少、何时插入文字池。

对照表（书中 Keil vs CCS + 本路线 GNU）

用途 Keil (ARM) CCS (TI) GNU gas（Linux/WSL）
代码/数据段 AREA name, CODE, READONLY / DATA .sect "name" · 默认 .text/.data .section .text · .data · .bss · .rodata
寄存器重命名 name RN r0 .asg r0, name #define name r0（C 预处理器）或注释
符号常量 symbol EQU expr .set / .equ .equ symbol, expr 或 #define
程序入口 ENTRY label _c_int00 等 C 运行时 .global _start + 链接脚本 ENTRY
定义字节/半字/字 DCB / DCW / DCD .byte / .half / .word / .float .byte / .hword / .word / .float
对齐 ALIGN n（2^n 字节） .align n .align n 或 .balign 4
保留零初始化空间 label SPACE n .space / .bes .space n · .comm · .lcomm
文字池 LTORG 类似 literal pool 机制 .ltorg / 自动池
文件结束 END .end （文件自然结束，无强制）

分段 — 为何需要 AREA / .section

.text (CODE)     → 只读、可执行 — 指令
.rodata          → 只读 — 常量字符串、查找表
.data            → 可读写 — 已初始化全局变量
.bss / SPACE     → 可读写 — 零初始化变量、堆栈预留

链接脚本（奔跑吧 Ch9 · 20 构建）决定各段 最终 ROM/RAM 地址。

数据定义示例

Keil — 字符串与字常量：

        AREA    Data1, DATA, READONLY
msg     DCB     "Hello", 0
val     DCD     0x40001000        ; MMIO 地址常数

GNU：

        .section .rodata
msg:    .asciz  "Hello"
        .equ    UART_BASE, 0x40001000
val:    .word   UART_BASE

Ch5 预告： DCD 定义的地址会被 LDR rd, [pc, #offset] 或 LDR rd, =sym 引用。

ALIGN — 与 Ch2 对齐一致

要求 伪指令
下一条指令/数据从 4 字节边界 开始 Keil ALIGN 2（= 2²）· GNU .align 2

错对齐后果： ARM7 上 Data Abort；M4 可能性能差或 fault（→ Ch2 §2.2）。

LTORG / 文字池

问题： LDR r0, =0x12345678 等 大常数 不能总嵌在指令里 → 汇编器在附近放 literal pool（常数表），PC 相对加载。

LTORG： 强制 在此处 生成文字池 — 防止 pool 离 LDR 太远超出 ±4KB PC 相对范围（ARM 经典限制）。

→ 机制详解 Ch6 文字池。

EQU / .set — 像 #define

UART0_BASE   EQU    0x40001000
BIT_TXEN     EQU    0x00000001

驱动风格： 基址 + 位掩码 — 配合 LDR/STR 写 MMIO（Ch16）。

可复述要点

  1. AREA/.section 分代码与数据；DCB/DCD/.word 放常量；SPACE/.bss 留未初始化区。
  2. ENTRY/.global 声明入口；END 标记 Keil 文件尾。
  3. LTORG 解决大常数 PC 相对距离 — 与 Ch3 LDR = 一体。
  4. 本路线用 GNU 列 读 Linux 内核；Keil/CCS 懂语义即可。

section-4.5-macros

Ch 4 · 汇编器规则与伪指令 · 章导读

宏 vs 子程序

宏 (Macro) 子程序 (Subroutine)
展开时机 汇编时 文本替换 运行时 BL 跳转
代码体积 每调用 复制一份 指令 只有 一份 函数体
速度 无 调用/返回开销 有 BL/BX lr 成本
参数 汇编期 $ 参数替换 运行时寄存器/栈传参（Ch13）

选用： 极短、需内联 hot path（如 读/write 单个 MMIO 位）→ 宏；复杂逻辑 → 子程序。

Keil 宏语法

        MACRO
$label  wait_us $count
        ; 展开体 — $count 在汇编时替换
        MOV     r0, $count
        ; ... 延时循环 ...
        MEND

        ; 调用
        wait_us 100
元素 说明
MACRO / MEND 宏定义起止
$参数 形式参数；调用时 字面替换
$label 可选 — 生成 唯一标签 避免多次展开冲突

GNU 对照： C 预处理器 #define wait_us(n) ... 或 gas .macro wait_us count … .endm。

展开示例（概念）

; 定义
        MACRO
        set_bit $reg, $bit
        ORR     $reg, $reg, #$bit
        MEND

; 两次调用
        set_bit r1, 4
        set_bit r2, 8

汇编后 ≈ 两条独立的 ORR 指令 — 不是 BL set_bit。

风险与习惯

风险 对策
多次展开膨胀 Flash 大宏改子程序
标签重复 用 $label 或 .L 局部标签（GNU）
副作用 宏改寄存器要 文档化 — 与子程序 ABI 同问题

内核常见： macro 定义 寄存器保存/恢复、TLB/缓存 op 的重复序列。

可复述要点

  1. 宏 = 汇编期复制粘贴；子程序 = 运行时跳转。
  2. 参数用 $（Keil）；GNU 用 .macro 参数名。
  3. 省周期换体积 — HFT/中断 handler 里要想清楚。

section-4.6-assembler-misc

Ch 4 · 汇编器规则与伪指令 · 章导读

汇编器操作符（Assembly-time Operators）

在 汇编阶段 对 常量表达式 求值 — CPU 不执行这些运算。

操作符（Keil 风格） 含义 典型用途
:SHL: / :SHR: 逻辑左/右移 MASK EQU (1 :SHL: 5)
:AND: / :OR: 按位与/或 合并寄存器位域掩码
:MOD: 取模 对齐/分页常量
+ - * / 算术 TABLE_SIZE EQU ROWS * COLS

配合伪指令：

GPIO_BASE    EQU     0x40020000
PIN_MASK     EQU     (1 :SHL: 3) :OR: (1 :SHL: 7)
config_word  DCD     PIN_MASK

C 对照： 与 #define BIT(n) (1U << (n)) 同一层 — 编译/汇编前 就算出数。

GNU： 用 C 预处理器或 gas 表达式 (1 << 3) | (1 << 7)。

与子程序/指令的区别

EQU 表达式里的 :SHL:     → 汇编器算 → 写入 .o 的常数
指令 LSL r0, r1, #2      → CPU 运行时移位

混淆两者 = 读 listing 时 分不清哪行进了 Flash。

CCS 数学函数（选读 · TI 专用）

CCS 汇编器可在 数据段生成期 调用内置函数，例如：

函数 用途
$$sin / $$cos 生成 sin/cos 浮点常数表
$$sqrt 开方表

场景： 浮点查找表（→ Ch12 Tables）— 汇编时算好 .float 序列，避免 MCU 启动后逐点计算。

本路线： WSL + GNU 无 同等内置 — 用 Python/CMake 生成 .inc 或 C 数组更常见（23 飞控 姿态表）。

与 HFT / 驱动的联系

场景 汇编期常量
MMIO 位掩码 EQU + :SHL: — 所有平台
DMA 描述符 flags 同
