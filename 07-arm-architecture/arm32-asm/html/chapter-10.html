10.2

section-10.2-rounding

Ch 10 · 浮点舍入与异常 · 章导读

为何必须舍入

FPU 内部更高精度 运算 → 结果写入 单精度 23 bit 尾数 时，不能精确表示 的部分必须 舍入。

「反直觉」根源之一： 0.1 + 0.2 ≠ 0.3 在 binary float — 不是 bug，是 有限 frac + 舍入。

Guard bit (G) 与 Sticky bit (S)

决定 LSB 进位还是截断 的辅助位（概念上在 L 之后）：

…  L  |  G  |  (更低各位 OR 起来) = S
     ↑ LSB  ↑ 保护位    ↑ 粘滞位
位 含义
L 结果 最低有效尾数位
G (Guard) 紧跟 L 后一位
S (Sticky) G 之后 所有更低位的逻辑 OR — 「后面是否还有非零垃圾」

硬件用 G、S（及 L） 按当前 舍入模式 决定 ±1 ULP 或截断。

IEEE 754-2008 四种舍入模式（Cortex-M4）

模式 缩写 行为
就近舍入到偶数 RNE (roundTiesToEven) M4 默认 — 最近可表示值；恰 halfway (G=1,S=0) → 选 L 为偶数 的一侧
向 +∞ RP (roundTowardPositive) 正数向上、负数向 0（向更大代数方向）
向 −∞ RM (roundTowardNegative) 相反
向零 / 截断 RZ (roundTowardZero) 丢弃 G、S — 永不因 G 进位；float→int VCVT 常用

配置： FPSCR RMode 字段（→ Ch9 §9.8）。

RNE 为何默认

统计无偏： halfway 时 50% 进位、50% 截断（选偶数 L）— 大量运算不系统性偏大或偏小。

区间算术（RP+RM）： 同一式 上界用 RP、下界用 RM → 得到 误差包络 — 科学测量。

与 IXC

只要舍入发生（结果 ≠ 数学精确值）→ 常置 Inexact (IXC)（§10.3）— 即使 RNE 选对了「最近」。

可复述要点

  1. G/S 决定 进位还是截断 — 实现 RNE 等模式。
  2. RNE = M4 默认；RZ = 向零截断。
  3. 舍入 ≠ 错误 — 是 有限位宽必然；IXC 标记「发生过」。
10.3

section-10.3-exceptions

Ch 10 · 浮点舍入与异常 · 章导读

与整数异常对比

整数除零 IEEE 754 浮点异常
典型行为 trap / fault 默认结果 + FPSCR 标志 — 程序常继续
目的 硬错误 可查询、可忽略、或可选 trap

FPSCR 累积 DZC / IOC / OFC / UFC / IXC（及 IDC 等）— Ch9 §9.8。

五类异常

1. 被零除 (DZC — Division by Zero)

非零 normal/subnormal ÷ 0 → 默认 ±∞（符号规则），DZC=1。

与 0/0（Invalid）区分。

2. 无效操作 (IOC — Invalid Operation)

无公认数学定义 的操作，例如：

  • 0 ÷ 0
  • ∞ × 0
  • sqrt(-1)（实域）
  • float→int 超出整数可表示范围
  • 操作数含 sNaN（发信 NaN）

默认结果： 常 qNaN 或 最大整数（视操作）— IOC=1。

3. 溢出 (OFC — Overflow)

结果 绝对值太大 — 超出目标格式最大 normal 范围。

默认 RNE： 常返回 ±∞。必同时 IXC=1（舍入到 ∞ 视为 inexact）。

4. 下溢 (UFC — Underflow)

结果 绝对值太小 — 不能正常表示。

默认： 返回 subnormal 或 ±0（视 FTZ/FZ 与舍入）。若仍 inexact → IXC。

Ch9 Subnormal — 与 FZ _flush-to-zero（Ch11）联动。

5. 结果不精确 (IXC — Inexact)

任何舍入 使 存储结果 ≠ 数学无限精度结果 → IXC=1。

最频繁 — 大量「正常」运算都会 inexact。

程序员应对

策略 说明
忽略标志 多数嵌入式 C 代码 — 默认
周期读 FPSCR 调试/计量
检查 NaN/Inf 控制环 isnan/isinf — 23 飞控
启用 trap 少见 — 需 OS/ handler 支持

可复述要点

  1. 五标志：DZC IOC OFC UFC IXC — 写 FPSCR，默认不杀进程。
  2. 0/0→NaN，非零/0→∞ — 别与整数除零混淆。
  3. OFC 常伴 IXC；下溢 与 subnormal/FTZ 相关。
10.4

section-10.4-algebra

Ch 10 · 浮点舍入与异常 · 章导读

学校数学 vs 浮点代码

有限精度 + 每步舍入 → 部分代数定律失效 — 编译器重排可能 改结果（除非 strict FP pragma）。

仍成立（通常）

定律 浮点
交换律 A+B = B+A 加法、乘法 仍成立（同精度下）
对称性 等 比较层面另论 NaN

不一定成立

定律 反例直觉
结合律 (A+B)+C ≠ A+(B+C) 大数 吞小数 — 先加 tiny 可能被舍没
分配律 A×(B+C) ≠ A×B+A×C 中间两次舍入 vs 一次

极端例（概念）：

(1e30 + 1) - 1e30  →  0     （1 被吞）
1e30 - 1e30 + 1    →  1     （顺序不同）

一个表达式得 0，另一个得 ∞ — 在溢出/下溢边界也可能出现。

工程教训

实践 说明
Kahan summation 补偿求和 — 大量 float 累加
别假设结合律 -ffast-math 更危险
PID 积分 用 double 或 定点 减 drift
HFT int tick 避免此类 — 与 Ch7 Q 同源

Ch8 循环展开： 改变加法树形状 → float 结果可能变 — 确定性 vs 数值稳定性 tradeoff。

可复述要点

  1. 交换律 OK；结合律/分配律不保证。
  2. 运算顺序影响舍入路径 — 大动态范围混算最危险。
  3. 关键算法：稳定公式 或 定点/int。

section-10.5-normalization

Ch 10 · 浮点舍入与异常 · 章导读

后规格化 (Post-normalization)

尾数相乘 等运算 → 中间积尾数可能 ≥ 2.0（超出 1.xxx 规范形式）。

硬件：

尾数右移 1 bit，指数 +1  →  恢复 1.f 格式

与 Ch9 Normal — 维持 隐含 leading 1 约定；用户不可见，影响 舍入位 G/S 位置。

抵消 (Cancelation)

两个接近的数相减（或 异号大数相加 = 有效减法）：

  1.2345678
- 1.2345670
─────────────
  0.0000008   ← 高位大量消掉，前导零爆炸
后果 说明
有效位数暴跌 相对误差巨大 — 灾难性抵消
尾数左移重规格化 指数减小
可能 UFC/下溢 指数减太多 → subnormal 或 0
IXC 重规格化常伴随舍入

经典： sqrt(x+1)-sqrt(x) 用代数等价式改写 — 数值分析课内容；汇编手写 float 同样要避免。

与飞控 / 滤波

场景 风险
高通 = 输入 - 低通 接近频率处抵消
差分求导 小 Δt 放大噪声
协方差更新 需稳定算法（Kalman 平方根形式等）

无 FPU： Ch7 Q 格式 同样怕 相近大数相减 — 先 scale 再算。

可复述要点

  1. 乘后尾数>2 → 右移+指数增（后规格化）。
  2. 相近相减 → 前导零 → 精度损失 + 可能下溢。
  3. 算法层 改公式 比改舍入模式更重要。
