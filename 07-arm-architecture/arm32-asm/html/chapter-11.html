11.2

section-11.2-syntax

Ch 11 · 浮点数据处理 · 章导读

统一格式

        V<op>{cond}.F32   {<Sd>}, <Sn>, <Sm>
        ; 或 .F 作为 .F32 简写
元素 说明
V 向量/FPU 前缀（M4 单精度标量）
{cond} 可选 ARM 条件码 — 浮点算术本身不产标志（§11.4）
.F32 / .F 单精度 — M4 本章主战场
<Sd> 目标 s 寄存器 — 可省略（仅副作用，如 VCMP）
<Sn>, <Sm> 源 — s0–s31；Sd 可与 Sn/Sm 相同（in-place）

示例：

        VADD.F32    s0, s1, s2      ; s0 = s1 + s2
        VMUL.F      s4, s4, s5      ; s4 *= s5

与 Ch9 搬运指令分工

类 例 作用
Load/Store VLDR/VSTR Mem ↔ s（Ch9）
Convert VCVT int/fixed ↔ float（Ch9）
Data processing VADD/VMUL… 本章 — s ↔ s 运算

无双精度硬件运算（典型 M4）

d0–d15 别名存在 — 64 bit 运算 常软件或 仅存储；指令助记符本章以 .F32 为准。

可复述要点

  1. Vop.F32 Sd, Sn, Sm — 三寄存器形式为主。
  2. 仅单精度 数据处理；位操作回 整数 r。
  3. 目标可与源相同 — 累乘累加常见。

11.4

section-11.4-flags

Ch 11 · 浮点数据处理 · 章导读

浮点算术 不 设置 N,Z,C,V

与整数 ADDS 不同：

        VADD.F32    s0, s1, s2      ; ✗ 无 VADDS 设 APSR 用法

VADD/VMUL/… 不写 FPSCR 比较标志 — 不能 BNE 紧跟 VADD 判大小。

比较指令 — VCMP / VCMPE

        VCMP.F32    s0, s1          ; 比较 s0 与 s1 → 更新 **FPSCR** N,Z,C,V
        VCMPE.F32   s0, #0.0        ; 可能 **额外** 对 NaN 等触发 Invalid（E=exception）
VCMP VCMPE
更新 FPSCR 标志 ✓ ✓
无效操作 trap 倾向 较 quiet E 版更严格（实现相关）

比较结果编码（概念）： LT/EQ/GT/UN（NaN 无序）→ N,Z,C,V 组合 — 与整数 不同编码表。

VMRS — 把 FPSCR 标志拷到 APSR

        VCMP.F32    s0, s1
        VMRS        APSR_nzcv, FPSCR   ; 浮点标志 → 整数条件执行可见
        BGT         greater            ; 或 ITGT / VMOVGT 等
步骤 原因
VCMP 只改 FPSCR
VMRS APSR_nzcv, FPSCR Ch8 条件分支/IT 读 APSR，不直接读 FPSCR

易漏： 比较 float 后 忘记 VMRS → 分支条件 ** stale 整数标志** — 经典 bug。

与 Ch8 衔接

VCMP → VMRS → B{cond} / IT{cond} / VMOV{cond}

NaN： VCMP 与 NaN → UNordered — 条件分支行为需查 ARM 条件码表（通常 NE/EQ 组合 判 unordered）。

可复述要点

  1. 只有 VCMP/VCMPE 设浮点比较标志 — 在 FPSCR。
  2. 分支前必须 VMRS 到 APSR（若用 ARM 条件码）。
  3. NaN 比较 走 UN — 控制环要 显式 isnan 防护。
11.5

section-11.5-special-modes

Ch 11 · 浮点数据处理 · 章导读

配置位置

FPSCR 控制位（→ Ch9 §9.8）— FZ (Flush-to-Zero) · DN (Default NaN)。

Flush-to-Zero (FZ)

开启后 效果
输入 subnormal 当作 signed zero
输出 本应 subnormal 冲洗为 ±0

目的： 避免 denormal 慢路径 — 音频/DSP 常开；牺牲极小值精度。

与 Ch10 UFC/下溢： 更易得 0 而非 gradual underflow — IXC 行为仍查手册。

HFT 对照： 类似 绝不碰 denormal tick — 确定性/速度优先。

Default NaN (DN)

开启后 效果
任一操作数为 NaN 结果 = 固定 default qNaN（payload 全 0）
不保留 原始 NaN 的 payload 信息

目的： 简化硬件 NaN 传播 — 调试丢失 NaN 来源。

生产建议： 通常 DN 关 — 除非明确要简化语义。

可复述要点

  1. FZ = subnormal 当 0 — 快但丢极小值。
  2. DN = 所有 NaN 运算 → 同一种 qNaN。
  3. 科学/飞控 debug：慎用 DN；性能敏感 DSP：可能开 FZ。

section-11.6-non-arithmetic

Ch 11 · 浮点数据处理 · 章导读

VABS — 绝对值

        VABS.F32    s0, s1          ; s0 = |s1| — 强制 **符号位 = 0**

符号-幅度格式： 只改 S 位 — 尾数/指数不变。

VNEG — 求反

        VNEG.F32    s0, s1          ; s0 = -s1 — **翻转符号位**

与 NaN / 异常

点 说明
sNaN VABS/VNEG 通常不触发 IOC — 仅改符号位，不“运算” payload
qNaN 符号可能变 — 仍 NaN
±0 ABS 得 +0；NEG 翻转 ±0

对比 VADD 等： 真算术更易 Invalid — ABS/NEG 是 位级 操作。

C 对照

fabsf / 一元 - — 编译器出 VABS/VNEG 或等价。

可复述要点

  1. VABS/VNEG 只动符号位。
  2. 一般不触发 Invalid — 即使 sNaN。
  3. 需要 数学 sqrt/round 用 VSQRT 等 — 非本章两条。

section-11.7-arithmetic

Ch 11 · 浮点数据处理 · 章导读

基础四则 + 根号

指令 操作 异常提示（Ch10）
VADD / VSUB ± IXC 常见；抵消（§10.5）
VMUL × OFC/UFC/IXC
VDIV ÷ DZC（非零/0）· IXC
VSQRT √ 负数 → IOC NaN

Ch3 示例： VADD.F32 s0, s1, s2 — 本章展开异常与 MAC。

链式 MAC vs 融合 FMA（核心精度差异）

目标： 计算 acc + a×b（滤波/Dot/矩阵乘常见）。

链式 — VMLA（Multiply-Accumulate）

t = round(a × b)          ← **第一次舍入**
acc = round(acc + t)      ← **第二次舍入**

两次舍入 — 旧 FPU 行为；误差累积更大。

融合 — VFMA（Fused Multiply-Add, IEEE 754-2008）

acc = round(acc + a×b)    ← 内部 **无限精度积**，**仅最终舍入一次**
VMLA 链式 VFMA 融合
中间舍入 有 无
精度 较低 较高
极端 case 可能 无效零/误溢出 更稳
C 对应 分开 *++ 常类似链式 fmaf() / -ffma

M4 若支持 VFMA — 科学计算/DSP 优先 VFMA；legacy 库可能仍 VMLA。

相关： VMLS/VFMS — 乘减；VFNMA — negated FMA 等 — 见指令摘要表。

与 Ch10 异常联动

每次 舍入 → 可能 IXC；VDIV → DZC；大 VMUL → OFC — 读 FPSCR 或假设 C 语义。

可复述要点

  1. VDIV/VSQRT 最易 DZC/IOC。
  2. VMLA：两次舍入；VFMA：一次舍入 — 面试/数值常考。
  3. 滤波 inner loop：VFMA 是精度与性能 sweet spot。

section-11.8-examples

Ch 11 · 浮点数据处理 · 章导读

示例目的

全书 Ch9–11 综合 — 展示 M4 FPU 在 科学计算/信号 中的用法，非裸机驱动日常场景。

二分法 (Bisection) 求根

问题： 连续函数 f(x) 在 [a,b] 异号 → 中间有根。

while (b-a > tol):
    mid = (a+b)/2
    if f(mid) 与 f(a) 同号:
        a = mid
    else:
        b = mid

汇编要素：

步骤 浮点指令
中点 VADD + VMUL 0.5 或 VADD 半区间
判符号 VCMP + VMRS + B / IT
循环 Ch8 SUBS/BNE 或 CBNZ 计数

与 Ch12 二分查找表： 同名思想 — 表是 离散 key，此处 连续 f(x)。

子程序：泰勒级数 sin(x)

f(mid) 需 sin — 示例用 泰勒展开 多项式近似：

sin(x) ≈ x - x³/3! + x⁵/5! - …

展示：

  • VMUL/VFMA 累加多项式项
  • VNEG/VADD 交替符号
  • BL 子程序（Ch13）传参 s0 返回 s0
  • 精度 vs 项数 — IXC 每步舍入

工程现实： 生产用 C libm 或 查表+插值（Ch12）— 示例为 指令练习。

与 23 飞控 / Linux

路径 做法
飞控姿态 C sinf/cosf · 四元数 — 少手写泰勒
Linux libm + 硬 FPU；内核 kernel_fpu
本示例价值 读懂 VCMP/VMRS/BL/VFMA 组合

可复述要点

  1. 二分 = VCMP 判符号 + 区间减半循环。
  2. 泰勒 sin = MAC 密集型 — 练 VFMA/VMLA。
  3. 综合例 衔接 Ch8 分支 + Ch13 BL — 浮点三章闭环。
