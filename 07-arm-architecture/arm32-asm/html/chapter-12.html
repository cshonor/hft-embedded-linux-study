section-12.1-intro

Ch 12 · 表 · 章导读 · 本章概述

本章在全书中的位置

前几章解决了 算术、逻辑、分支、浮点；本章转向 数据在内存中的组织与检索：

  • 查找表（Lookup Table） — 预计算好的离散采样，运行时 O(1) 索引
  • 搜索算法（Search） — 在表中按 key 找记录（线性 vs 二分）

为什么嵌入式爱查表

场景 典型需求
音频 / 控制 固定采样率下 每 tick 必须按时完成
信号处理 sin/cos、滤波系数 — 算一次太慢就 表 + 插值
3D / 图形 1/√x 极高频 — 近似表 beat 完整开方

核心权衡： 牺牲 内存（有时还有 精度），换 执行时间可预测 与 无 FPU 依赖（整数 Q 格式表）。

  1. 查表 = 空间换时间 + 确定性延迟。

12.2

section-12.2-int-lookup

Ch 12 · 表 · 章导读 · 本章概述

表在内存中的布局

连续元素用 基址 + 索引×元素大小 访问（Ch5 缩放寻址）：

元素类型 字节偏移 典型指令
字（32 bit） index × 4 LDR r6, [r5, r4, LSL #2]
半字（16 bit） index × 2 LDRH r6, [r4, r5, LSL #1]
  • r5 — 表基址（SinTable 标签）
  • r4 — 元素索引（0, 1, 2, …）
  • LSL #2 — 硬件把索引左移 2 位 = ×4，对齐字地址

口述： 一条 Load 完成「第 n 项」，不必先 ADD 算地址。

用 DCD 定义表

SinTable
    DCD 0x00000000    ; sin(0°)   Q31
    DCD 0x0C8BD35E    ; sin(1°)
    ; … 仅 0°–90° 共 91 项

表在 只读段；链接后常驻 Flash。索引 = 角度（度） 或 采样序号。

正弦波查表 — 只存 0°–90°

动机： sin(0°…360°) 全表浪费 ROM；利用 对称性 只存第一象限。

流程（口述）：

输入角度 θ（度或归一化整数）
        ↓
归一化到 [0, 360) 或 [0, 90] 参考角
        ↓
判断象限（1–4）
        ↓
第一象限角 α → 索引查 SinTable
        ↓
按象限：结果 = +v / -v / sin(90-α) 等变换
象限 参考角 结果符号
I θ +sin(θ)
II 180° − θ +sin
III θ − 180° −sin
IV 360° − θ −sin

Q31 定点： Ch7 §7.7 — 值 ∈ [−1, 1) 映射到 32 位整数；无 FPU 的 Cortex-M0 也能跑。

精度 vs 表长

采样步长 ROM 误差
1° 91×4 B ≈ 364 B 较大
0.1° ~900 项 更小

更细可 线性插值：两相邻表项之间 (y1-y0)*frac + y0 — 本章以 直接查 为主。

与 Ch11 泰勒 sin 对比

Ch12 查表 Ch11 泰勒
CPU 1× LDR + 象限逻辑 多次 VMUL/VFMA
ROM 需要 几乎无
延迟 固定 随项数变
飞控/Linux MCU 常用；A 核多用 libm 教学/无表时

可复述要点

  1. LDR [base, index, LSL #2] = 字数组随机访问的标准写法。
  2. sin 表压缩 = 存 0°–90° + 象限归约 + 必要时取负。
  3. Q31 让整数核也能做「三角函数级」控制环。

section-12.3-float-lookup

Ch 12 · 表 · 章导读 · 本章概述

浮点表的加载方式

与整数表相同：基址 + 偏移；元素为 32/64 bit 浮点 时用 VLDR（Ch9）：

    VLDR.F  s5, [r0]              ; 绝对寻址
    VLDR.F  s6, [r1, r2, LSL #2]  ; 索引 ×4 访问 float 数组

文字池与 PC 相对加载

浮点 常量（π、e、系数）常放 literal pool，由汇编器在 VLDR 后自动插入：

    VLDR.F  s5, C_Pi    ; 汇编器算 PC 相对偏移
    …
C_Pi    DCD  0x40490FDB   ; 或 .float 语法依工具链

与 Ch6 整数文字池同源： 当前 PC 附近放不下立即数时，链接器/汇编器 把常数放在指令流后面，用 偏移加载。

案例：平方根倒数估计（rsqrt）

背景（3D 图形）： 法线归一化需要 1/√x，全精度 VSQRT + VDIV 在 Cortex-M4 FPU 上约 28 周期 — 每像素/每顶点都调用则不可接受。

思路：

  1. 用 半精度或低位 mantissa 建 小表 — 粗估 1/√x
  2. 利用 IEEE754 指数位：x = m × 2^e，则 1/√x ∝ 2^(-e/2) — e 奇偶 决定指数调整
  3. 表项 + 位操作/一次 Newton refinement（书中示例侧重 表驱动近似）

口述对比：

方法 周期量级 精度
VSQRT + VDIV ~28+ 全精度
查表 + 指数修正 很少 够用于光照
Quake III 经典 magic 极快 需迭代 polish

整数表 vs 浮点表

整数 Q / 定点表 浮点 VLDR 表
硬件 任意 ARM 需 VFP（Ch9 CPACR）
典型用途 无 FPU 的 M0/M3 M4/M7、A 核用户态
常数来源 DCD 文字池 + VLDR

可复述要点

  1. 浮点表访问 = VLDR + 缩放索引，与 LDR 模式平行。
  2. 文字池 解决「浮点立即数不能直接编码」— 标签 C_Pi 由汇编器算偏移。
  3. rsqrt 查表 是 高频、可牺牲精度 的经典 ROM 换 CPU 案例。

section-12.4-binary-search

Ch 12 · 表 · 章导读 · 本章概述

问题：在表里找 key

表项不仅是数字，常是 (key → payload)，例如：

key（排序） payload
10 "Mushroom"
25 "Pepperoni"
40 "Veggie"

目标：给定 target key，找到对应字符串或确认 不存在。

线性 vs 二分

线性搜索 二分搜索
前提 无 key 必须有序
比较次数 平均 N/2 最多 ⌈log₂ N⌉
表翻倍 时间 ×2 时间 +1 次循环
汇编 索引 0→N-1，逐项 CMP lo/hi/mid 减半区间

口述： N=1024 时，线性最坏 1024 次；二分约 10 次。

算法（与 Ch11 二分求根对照）

离散 key（本章）：

lo = 0, hi = N-1
while lo <= hi:
    mid = (lo + hi) / 2
    if table[mid].key == target:  found
    if target < table[mid].key:   hi = mid - 1
    else:                         lo = mid + 1
not found

连续函数（Ch11）： 区间 [a,b] 上 f(mid) 符号 — 同名 减半，对象不同（离散 key vs 连续 f(x)）。

汇编技巧：mid = (lo + hi) / 2

    ADD   r2, r0, r1      ; r0=lo, r1=hi
    MOV   r2, r2, ASR #1  ; 算术右移 1 位 = 除以 2（有符号安全）
  • 不要用 LSR 若 lo/hi 为有符号且可能为负（表中索引通常非负，ASR 仍与 C 语义一致）。
  • 取 table[mid]：LDR r3, [base, r2, LSL #2]（key 为字）。

循环骨架： Ch8 — CMP + BLT/BGT + B 回环，或 SUBS 计数上限。

完整流程口述

1. 读 target 到寄存器
2. lo=0, hi=N-1
3. 循环：mid=(lo+hi)>>1
4. LDR key[mid]，CMP target
5. 相等 → 取 payload 指针，退出
6. target 小 → hi=mid-1；大 → lo=mid+1
7. lo>hi → 未找到

书中 披萨配料 示例：key 与 字符串指针 同表或相邻结构 — 找到 key 后 LDR 字符串地址 再打印（Ch13 可 BL printf）。

何时不用二分

  • 表 很小（<8）— 线性更简单
  • 表 频繁插入 — 保持有序成本高 → 哈希或平衡树（超出本章）
  • Flash 只读静态表 — 二分非常合适

可复述要点

  1. 二分 前提：有序 key。
  2. mid = (lo+hi) ASR #1 — 汇编里除以 2 的标准写法。
  3. 表大小翻倍 → 线性慢一倍，二分只多 一轮 — O(log N)。
