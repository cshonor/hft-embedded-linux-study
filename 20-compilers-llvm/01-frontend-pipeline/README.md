# 01 · 前端流水线：词法 → 语法 → AST → IR

**任务**：跑通编译器前端最小闭环。
**验收**：对一小段 C 子集源码，本工具能输出合法 `.ll`，且 `lli` 能正确运行。

对应课程 **A 段：讲 1, 3–11**（10 讲 / 视频 **7.9 h**，实际约 12–16 h）
—— 映射表见 [`../_refs/c-compiler-llvm-course.md`](../_refs/c-compiler-llvm-course.md)。
