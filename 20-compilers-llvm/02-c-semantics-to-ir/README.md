# 02 · C 语义落 IR：控制流 / 指针 / 数组 / 结构体 / 函数

**任务**：把 C 语言的核心语义全部落到 LLVM IR 上。
**验收**：覆盖「必做」子任务全部语义点，生成的 IR 与 `clang -S -emit-llvm` 输出**逐条对照**，差异有解释。

对应课程 **B 段：讲 12–37**（26 讲 / 视频 23.7 h）
—— 映射表见 [`../_refs/c-compiler-llvm-course.md`](../_refs/c-compiler-llvm-course.md)。
