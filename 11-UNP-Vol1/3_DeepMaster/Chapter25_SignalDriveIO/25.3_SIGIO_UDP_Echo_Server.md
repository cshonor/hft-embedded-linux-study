## 架构：生产者-消费者

| 角色 | 职责 |
|------|------|
| **生产者（SIGIO 处理函数）** | 循环 **非阻塞** `recvfrom` 直至 EWOULDBLOCK（信号**不排队**，须抽干）→ 入**全局队列** |
| **消费者（主循环）** | 从队列取 → `sendto` 回射 |

---

## 竞态与信号掩码（黄金法则）

主循环与处理函数**并发**访问全局队列 — 须当多线程一样保护。

| 错误 | 后果 |
|------|------|
| `if (empty) sleep()` 无掩码 | 判断空与睡眠之间 SIGIO 入队 → **永久睡死** |

**正确流程**：

```text
1. sigprocmask 阻塞 SIGIO
2. 若队列空 → sigsuspend（原子解除阻塞并睡眠）
3. 取数据、改队列指针 — 均在 SIGIO 阻塞的临界区内
4. sigprocmask 恢复
```
