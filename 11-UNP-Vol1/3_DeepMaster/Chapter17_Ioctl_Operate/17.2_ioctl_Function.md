# 17.2 ioctl 函数

> [17.3](../17.3_Socket_Ioctl_Operate.md)

---

## 函数原型

```c
int ioctl(int fd, int request, ... /* void *arg */);
```

| 项 | 说明 |
|----|------|
| 成功 | 通常 **0** |
| 失败 | **-1**，`errno` |
| **`fd`** | 打开的文件或套接字描述符 |
| **`request`** | 命令宏（`FIONBIO`、`SIOCGIFCONF` 等） |
| **`arg`** | 指针或整数，**类型完全由 request 决定** |

---

## 重点结论

`request` 传统上编码操作类型、读写方向、参数大小 — **无类型安全**，调用方须与文档严格匹配。
