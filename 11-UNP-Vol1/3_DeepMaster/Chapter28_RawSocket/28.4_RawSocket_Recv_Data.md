## 内核上送原始套接字的 3 类报文

1. **内核不认识的 IP 协议**（如无模块的 OSPF 89 等）  
2. **多数 ICMP**（Echo Request 等常由内核自处理，**Echo Reply** 等多上报）  
3. **所有 IGMP**  

**绝不**上送 **TCP/UDP** 分节 → 嗅探用 Ch 29 BPF/pcap。

---

## 匹配条件（AND）

多进程多 raw fd 时，复制到某套接字须**全部**满足：

| # | 条件 |
|---|------|
| 1 | `socket` 时 **protocol≠0** → 到达报文 IP 协议字段须匹配 |
| 2 | **bind** 本地 IP → 目的 IP 须匹配 |
| 3 | **connect** 远端 IP → 源 IP 须匹配 |

---

## IPv4 vs IPv6 读取差异

| | IPv4 raw | IPv6 raw |
|--|----------|----------|
| **`recvfrom` 内容** | 含**完整 IPv4 首部** | **不含** IPv6 首部和扩展头 |
| 应用解析 | 须跳过 IP 头（≥20 字节，有选项更长） | 首字节即 ICMPv6 等上层 |
