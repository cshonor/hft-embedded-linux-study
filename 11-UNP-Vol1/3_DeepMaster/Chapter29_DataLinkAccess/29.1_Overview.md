## 核心主旨

Ch 28 **原始套接字** → **网络层（IP）**。

**数据链路层访问** → **OSI 第 2 层**，无统一 Unix 系统调用，各 OS 实现不同。

---

## 应用场景

| # | 场景 |
|---|------|
| 1 | **混杂嗅探** — `tcpdump`、`Wireshark`（非仅本机帧） |
| 2 | **非 IP 协议** — ARP、RARP 等不经 IP 栈的帧 |
| 3 | **自构以太网帧** — 完全控制 MAC/类型字段 |

---

## 与 Ch 28 分工

| 层 | API |
|----|-----|
| IP（ICMP 等） | **SOCK_RAW**（Ch 28） |
| **TCP/UDP 截获** | **不能** raw → **Ch 29** |
| 以太网帧 | BPF / PF_PACKET / **libpcap** |
