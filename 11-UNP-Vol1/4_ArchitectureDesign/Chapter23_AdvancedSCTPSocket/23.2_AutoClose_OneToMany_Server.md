## 核心痛点

**一到多**（`SOCK_SEQPACKET`）服务器单 fd 可维持**成千上万关联**。客户端异常断线或未发关闭 → 服务器堆积**僵死关联**，占内存。

---

## 解决方案：`SCTP_AUTOCLOSE`

```c
setsockopt(sockfd, IPPROTO_SCTP, SCTP_AUTOCLOSE, &seconds, ...);
```

| 项 | 说明 |
|----|------|
| 机制 | 关联在指定**空闲秒数**内无收发 → 内核**自动**发起终止并清理 |
| 适用 | **仅一到多**套接字 |
| 一到一 | 须手动 **`close`**（类 TCP） |

应用层无需逐个扫关联超时。
