## 结构：类 UDP + 可靠传输

```text
socket(AF_INET, SOCK_SEQPACKET, IPPROTO_SCTP)
→ bind(INADDR_ANY, port)  [可选 sctp_bindx 多宿]
→ setsockopt SCTP_EVENTS（sctp_data_io_event = 1）
→ listen
→ 循环 sctp_recvmsg → sctp_sendmsg 回射
```

---

## 关键：SCTP_EVENTS

必须订阅 **`sctp_data_io_event`**，内核才在每次数据时填充 **`sctp_sndrcvinfo`**（**流号**、**assoc_id** 等）。

无此步骤 → 无法按流/关联正确路由回射。

---

## 主循环要点

| 步 | API |
|----|-----|
| 收 | **`sctp_recvmsg`** + `sctp_sndrcvinfo` |
| 判 | 数据 vs **MSG_NOTIFICATION**（见 Ch 9.14） |
| 发 | **`sctp_sendmsg`** 回同一客户（示例可递增流号或原样返回） |

**无 `accept`** — 新关联由协议建立后直接在 recvmsg 上体现。
