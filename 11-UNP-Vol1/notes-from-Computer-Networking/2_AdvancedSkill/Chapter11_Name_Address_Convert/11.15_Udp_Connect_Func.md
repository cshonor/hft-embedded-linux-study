## 核心主旨

在 11.14 逻辑上增加 **`connect`** → **已连接 UDP 套接字**。

| 收益 | 说明 |
|------|------|
| API | 后续 **`write`/`read`** |
| 安全 | 内核过滤非绑定源 |
| 错误 | **ICMP 异步错误**可上报（如 `ECONNREFUSED`） |
