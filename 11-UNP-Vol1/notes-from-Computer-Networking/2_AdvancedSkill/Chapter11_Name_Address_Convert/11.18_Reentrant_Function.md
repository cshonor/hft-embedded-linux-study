# 11.18 可重入函数

> [11.3](../11.3_Gethostbyname_Func.md) · [11.19 _r 版](../11.19_Gethostbyname_r_Gethostbyaddr_r.md)

---

## 核心概念

历史函数（`gethostbyname`、`inet_ntoa` 等）在并发下的致命缺陷：**不可重入**。

---

## 根源

函数用 **静态内存** 存放结果并返回指针 → 多线程 **数据竞争**：

```text
线程 A 调用 → 结果写入静态区
上下文切换 → 线程 B 调用 → 覆盖
线程 A 再读 → 数据错误
```

---

## 解决方案（三层）

| 层级 | 做法 |
|------|------|
| 1 | 系统 **`_r` 可重入扩展**（11.19） |
| 2 | **互斥锁** / **线程特定数据 TLS** |
| 3 | **推荐**：`getaddrinfo` / `getnameinfo`（调用方分配缓冲区） |

---

## 重点结论

新代码：**全面换用 getaddrinfo 族**，天然线程安全。
