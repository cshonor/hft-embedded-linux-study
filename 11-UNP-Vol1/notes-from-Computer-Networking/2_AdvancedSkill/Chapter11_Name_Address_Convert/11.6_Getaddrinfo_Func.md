# 11.6 getaddrinfo 函数

> **本章核心** · [11.7](../11.7_Gai_strerror_Func.md) · [11.8](../11.8_Freeaddrinfo_Func.md) · [11.12 tcp_connect](../11.12_Tcp_Connect_Func.md)

---

## 核心主旨

现代解析基石：**主机名→IP** + **服务名→端口**，返回可直接用于 `socket`/`connect`/`bind` 的 **`addrinfo` 链表**；**IPv4/IPv6 协议无关**。

```c
int getaddrinfo(const char *hostname, const char *service,
                const struct addrinfo *hints, struct addrinfo **result);
```

---

## 参数要点

| 参数 | 说明 |
|------|------|
| `hostname` | 主机名、点分 IP，或 NULL（配合 `AI_PASSIVE`） |
| `service` | 服务名（"http"）或端口字符串（"80"） |
| `hints` | 调用者期望的套接字类型（**极关键**） |
| `result` | 输出链表头 |

### hints 常用字段

| 字段 | 典型值 |
|------|--------|
| `ai_family` | `AF_INET` / `AF_INET6` / **`AF_UNSPEC`** |
| `ai_socktype` | `SOCK_STREAM` / `SOCK_DGRAM` |
| `ai_flags` | **`AI_PASSIVE`**（bind 用通配地址） |

### result 节点

每个节点含 **`ai_addr`/`ai_addrlen`**，可直接传给套接字 API。

---

## 重点结论（防错实践）

```text
for (rp = res; rp; rp = rp->ai_next) {
    fd = socket(rp->ai_family, rp->ai_socktype, rp->ai_protocol);
    if (connect(fd, rp->ai_addr, rp->ai_addrlen) == 0)
        break;   /* 成功 */
    close(fd);
}
freeaddrinfo(res);
```

业务代码**不必**手写 `sockaddr_in` / `sockaddr_in6` — 遍历链表直到 `connect`/`bind` 成功。
