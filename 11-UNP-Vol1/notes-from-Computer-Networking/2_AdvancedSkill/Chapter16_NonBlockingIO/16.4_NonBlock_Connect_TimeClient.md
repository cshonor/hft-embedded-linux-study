# 16.4 非阻塞 connect：时间获取客户程序

> [16.3](../16.3_NonBlock_Connect.md) · [Ch 7.2 getsockopt](../../1_BasicFoundation/Chapter07_SocketOption/7.2_Getsockopt_Setsockopt.md)

---

## 核心演练

通用 **`connect_nonb`**（自定义超时）步骤：

```text
1. fcntl → O_NONBLOCK
2. connect：
     返回 0 → 极少（如本机）→ 清理后成功
     返回 -1 且非 EINPROGRESS → 失败
3. fd 加入 select 读集+写集，带超时
4. select 返回 0 → ETIMEDOUT，close
5. select 唤醒后 → 必须用 getsockopt(SO_ERROR) 验证（见下）
6. 按需恢复阻塞模式
```

---

## 致命陷阱：验证是否真成功

`select` 显示可写（或可读可写）**≠** 连接成功。

| 步骤 | 说明 |
|------|------|
| **`getsockopt(fd, SOL_SOCKET, SO_ERROR, &error, …)`** | |
| `error == 0` | **真正成功** |
| `error != 0`（如 **ECONNREFUSED**） | **失败** |

跨平台（BSD vs 早期 Solaris）差异下，**SO_ERROR 是最稳妥**判定方式。
