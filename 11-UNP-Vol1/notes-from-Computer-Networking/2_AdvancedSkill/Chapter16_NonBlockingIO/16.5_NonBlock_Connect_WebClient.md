## 架构设计

简易 **Web 客户端**：并行拉取多张图片。

| 阻塞串行 | 非阻塞并发 |
|----------|------------|
| 总耗时 ≈ 各连接 RTT+传输**累加** | 总耗时 ≈ **最慢一条**（带宽够时） |

---

## 状态机架构

```text
结构体数组：{ fd, 状态, 缓冲 }
状态：待连接 → 连接中 → 读取中 → 完成

循环：
  多个非阻塞 connect → 全部加入 select
  可写 → 发 HTTP GET → 状态=读取中，只监听读
  可读 → read 直至 EOF → 完成
```

---

## 性能结论

并发非阻塞 `connect` 压榨管道闲置时间 — 压测工具、代理、浏览器内核的基础模式。
