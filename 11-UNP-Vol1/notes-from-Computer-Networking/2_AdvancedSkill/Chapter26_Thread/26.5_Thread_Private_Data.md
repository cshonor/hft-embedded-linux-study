# 26.5 线程特定数据

> [Ch 11.18 不可重入](../Chapter11_Name_Address_Convert/11.18_Reentrant_Function.md) · [Ch 3.9 readline](../../1_BasicFoundation/Chapter03_SocketProgramIntro/3.9_Readn_Writen_Readline.md)

---

## 核心主旨

多线程调用**不可重入**函数（静态缓冲的 `readline`、`gethostbyname` 等）会**互相覆盖**。

若不能改函数签名传外部缓冲 → 用 **线程特定数据（TSD）**。

---

## TSD 流程

```text
1. pthread_key_create(&key, destructor)   /* 常配合 pthread_once 只建一次 */
2. ptr = malloc(...); pthread_setspecific(key, ptr)
3. 深处：pthread_getspecific(key) 得本线程副本
4. 线程结束：destructor 自动 free
```

---

## 重点结论

TSD = 每线程一份的「全局变量副本」，隔离遗留 API 的静态状态。
