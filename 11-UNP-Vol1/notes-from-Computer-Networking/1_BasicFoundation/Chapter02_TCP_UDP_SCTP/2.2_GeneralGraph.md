# 2.2 总图

## 核心知识点

协议栈全景与各组件依赖关系：

| 组件 | 说明 |
|------|------|
| **IPv4 / IPv6** | 网络层；32/128 位地址，为传输层提供分组递送 |
| **ICMP / ICMPv6** | 错误与控制消息（`ping`、`traceroute` 底层） |
| **IGMP / MLD** | 多播组管理 |
| **ARP / RARP** | IP → MAC（IPv4）；IPv6 由 **ICMPv6 邻居发现** 取代 |
| **BPF / DLPI** | **数据链路层访问**；可绕过 IP/传输层直接读写以太网帧 |

## 易错点与坑点

并非所有数据必经 TCP/UDP；通过 **Raw Socket** 或 **BPF/DLPI** 可与 IP 层甚至链路层直接交互（Ch 28/29）。
