# 7.6 IPv4 套接字选项

> 级别 **`IPPROTO_IP`** · 原始套接字：Ch 28

---

## 核心选项（IPv4 网络层）

| 选项 | 说明 |
|------|------|
| **IP_HDRINCL** | **原始套接字**：应用**自构完整 IP 首部**，内核不自动添加 |
| **IP_OPTIONS** | 获取/设置 IPv4 首部**选项**（源路由、记录路由等） |
| **IP_TOS** | **服务类型 TOS**，影响路由器排队（低延迟、高吞吐等） |
| **IP_TTL** | 默认 **TTL（跳数）** |

---

## 易错细节

- 普通 TCP/UDP **不要**乱开 `IP_HDRINCL`  
- `IP_TTL` 与 traceroute 探测相关（Ch 2 / Ch 28）
