## 边界条件防御策略（四条铁律）

| # | 策略 | 对应小节 |
|---|------|----------|
| **1** | **`fork` 并发时关闭不需要的 fd**（父关 connfd，子关 listenfd） | 5.2、5.7 |
| **2** | **`SIGCHLD` + `while (waitpid(..., WNOHANG))`** 防僵尸 | 5.9、5.10 |
| **3** | **慢系统调用**：包裹函数处理 **`EINTR`**，或 `SA_RESTART` | 5.8、Ch 3 |
| **4** | **阻塞 I/O 无法同时监听多源** → Ch 6 **`select`/`poll`** | 5.5、5.12 |

## 易错细节与重点结论

**自检四问**（部署前）：

1. 父进程是否在 `accept` 后 **close(connfd)**？  
2. 是否注册 **SIGCHLD** 且 **while waitpid WNOHANG**？  
3. 是否 **忽略 SIGPIPE**？  
4. 客户是否仍 **只阻塞 stdin**？（若是，规划 Ch 6）
