# 23.7 确定本端与对端地址信息

> [Ch 9.5 getpaddrs](../Chapter09_BasicSCTPSocket/9.5_Sctp_Getpaddrs_Func.md) · [Ch 9.7 getladdrs](../Chapter09_BasicSCTPSocket/9.7_Sctp_Getladdrs_Func.md) · [23.8 assoc_id](../23.8_IP_Association_ID_Match.md)

## 核心主旨

一到多模型单 fd 多关联 — 需随时查询某关联的**本端/对端 IP 列表**（多宿健康诊断）。

---

## API

| 函数 | 作用 |
|------|------|
| **`sctp_getpaddrs`** | 某关联的**对端**地址列表 |
| **`sctp_getladdrs`** | 某关联的**本端**地址列表 |

用完须 **`sctp_freepaddrs` / `sctp_freeladdrs`**（Ch 9.6、9.8）。

---

## 用途

路径监控、日志、与 **`SCTP_PEER_ADDR_CHANGE`** 通知联动。
