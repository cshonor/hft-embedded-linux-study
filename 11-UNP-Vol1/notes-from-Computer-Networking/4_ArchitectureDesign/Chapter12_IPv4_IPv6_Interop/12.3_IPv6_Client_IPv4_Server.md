# 12.3 IPv6 客户与 IPv4 服务器

> [Ch 11.9 AI_V4MAPPED](../../2_AdvancedSkill/Chapter11_Name_Address_Convert/11.9_Getaddrinfo_IPv6.md) · [12.2 反向场景](../12.2_IPv4_Client_IPv6_Server.md)

---

## 核心场景

双栈主机上的 **IPv6 客户** 连接 **纯 IPv4 服务器**。

---

## 底层交互步骤

```text
① 服：AF_INET 套接字，bind 0.0.0.0
② 客：getaddrinfo + AI_V4MAPPED
     DNS 仅 A 记录 → 转为 ::ffff:x.x.x.x 填入 addrinfo
③ 客：connect(映射地址)
④ 内核：发现 IPv6 套接字连 mapped 地址 → 底层发 IPv4 SYN
⑤ 服：正常 IPv4 连接，常规处理
```

---

## 与 12.2 的不对称性

| 方向 | 无额外设备时 |
|------|----------------|
| IPv4 客 → IPv6 服（双栈） | ✅ 内核映射 |
| IPv6 客 → IPv4 服（双栈客户侧） | ✅ 客户内核转换 |
| **纯 IPv6 客 → 纯 IPv4 服** | ❌ IPv4 栈无法理解 128 位地址 |

跨协议需 **NAT64 / DNS64** 等网络层设施 — 非本章双栈本地机制。
