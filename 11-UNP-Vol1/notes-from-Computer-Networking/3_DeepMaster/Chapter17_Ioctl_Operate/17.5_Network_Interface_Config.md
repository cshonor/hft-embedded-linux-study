# 17.5 接口配置

> [17.6 get_ifi_info](../17.6_Get_Ifi_Info_Func.md) · [17.7](../17.7_Interface_Control_Operate.md)

---

## 核心主旨

多播、路由守护进程、代理等启动时常需：**本机有哪些网卡？IP、掩码？**

`ioctl` + **`<net/if.h>`** 提供拓扑发现。

---

## 核心结构

| 结构 | 用途 |
|------|------|
| **`struct ifreq`** | **单个接口** 单项属性（`ifr_name`、`ifr_addr`、`ifr_netmask`…） |
| **`struct ifconf`** | 缓冲区数组，装**多个 ifreq** |

---

## SIOCGIFCONF（值—结果参数）

```c
ioctl(fd, SIOCGIFCONF, &ifc);
```

| 调用前 | 调用后 |
|--------|--------|
| `ifc.ifc_buf` 指向大缓冲区 | 内核填入各接口 `ifreq` |
| `ifc.ifc_len` = 缓冲区大小 | `ifc.ifc_len` = **实际写入字节数** |

---

## 致命陷阱：缓冲区截断

缓冲区**过小**时，许多传统 Unix **不报错**，只**静默截断**填满缓冲区。

**防错**：循环**加倍**分配并重试 `SIOCGIFCONF`，直到返回的 `ifc.ifc_len` **严格小于** 提供的容量，才确认无截断。
