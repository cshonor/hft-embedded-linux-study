# 29.5 libpcap：分组捕获函数库

> [29.2 BPF](../29.2_BSD_Packet_Filter.md) · [29.4 Linux](../29.4_Linux_Packet_Socket.md)

---

## 核心主旨

**libpcap** 统一 BPF / DLPI / PF_PACKET 差异 — 跨平台**读**链路层。

**tcpdump** 基于 libpcap。

---

## 典型流程

| 步骤 | API |
|------|-----|
| 1 打开设备 | `pcap_open_live`（可混杂模式） |
| 2 编译过滤 | `pcap_compile` — 如 `"tcp port 80 and host 192.168.1.1"` → BPF 字节码 |
| 3 安装过滤 | `pcap_setfilter` — 注入内核 |
| 4 抓包 | `pcap_loop` / `pcap_next` — 完整以太网帧 |

---

## 黄金法则

需要抓包 / 读链路层 → **用 libpcap**，勿手写 `/dev/bpf` 或 PF_PACKET（除非维护库本身）。
