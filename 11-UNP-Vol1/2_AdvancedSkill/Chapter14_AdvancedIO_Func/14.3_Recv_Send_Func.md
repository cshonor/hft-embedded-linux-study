# 14.3 recv 和 send 函数

> [Ch 8.11 已连接 UDP](../../1_BasicFoundation/Chapter08_BasicUDPSocket/8.11_UDP_Connect_Usage.md) · [Ch 3.9 readn](../../1_BasicFoundation/Chapter03_SocketProgramIntro/3.9_Readn_Writen_Readline.md)

---

## 核心主旨

类似 `read`/`write`，但**仅用于套接字**，多 **`flags`** 参数。

```c
ssize_t recv(int sockfd, void *buff, size_t nbytes, int flags);
ssize_t send(int sockfd, const void *buff, size_t nbytes, int flags);
```

---

## 常用 flags

| 标志 | 方向 | 作用 |
|------|------|------|
| **`MSG_DONTROUTE`** | send | 绕过路由（直连网段；RIP/诊断） |
| **`MSG_DONTWAIT`** | 两者 | **单次**非阻塞，不改 fcntl |
| **`MSG_OOB`** | 两者 | 带外数据（Ch 24） |
| **`MSG_PEEK`** | recv | **窥看**缓冲区，**不移除**数据 |
| **`MSG_WAITALL`** | recv | 尽量读满 nbytes（类 readn） |

---

## 易错细节

- **`MSG_WAITALL`**：遇信号、断开、错误仍可能 **短读**  
- **`MSG_PEEK`** + 再 read = **两次系统调用**（见 14.7）
