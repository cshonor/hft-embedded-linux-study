# 11.3 gethostbyname 函数

> [11.4 gethostbyaddr](../11.4_Gethostbyaddr_Func.md) · 替代：[11.6](../11.6_Getaddrinfo_Func.md)

---

## 核心主旨

最早 POSIX 主机名解析 API：**主机名 → IPv4**。

```c
struct hostent *gethostbyname(const char *hostname);
```

| 结果 | 说明 |
|------|------|
| 成功 | `hostent *` |
| 失败 | `NULL`，查 **`h_errno`** |

---

## hostent 要点

- **`h_aliases`**：别名数组  
- **`h_addr_list`**：多个 IPv4 地址指针（多宿）

---

## 易错细节与局限性

| 问题 | 说明 |
|------|------|
| **仅 IPv4** | 无协议无关性 |
| **线程不安全** | 返回**静态** `hostent`，多线程易覆盖 |
| **现状** | 新代码应改用 **`getaddrinfo`** |
