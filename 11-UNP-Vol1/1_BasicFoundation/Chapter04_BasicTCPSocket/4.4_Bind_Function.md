# 4.4 bind 函数

## 核心主旨与关键论据

**`bind`** 把**本地协议地址**（IP + 端口）赋给套接字；服务器向系统**注册身份**的核心步骤。

```c
int bind(int sockfd, const struct sockaddr *myaddr, socklen_t addrlen);
```

---

## 地址与端口捆绑组合

| IP | 端口 | 典型场景 |
|----|------|----------|
| 不指定（0） | 不指定（0） | **客户端**；内核选临时端口 + 外出源 IP |
| 任意 | **0** | 内核选**临时端口** |
| **通配**（`INADDR_ANY` / `in6addr_any`） | 指定 | **服务器**；任意网卡上的连接 |
| **指定 IP** | 指定 | 只监听某块网卡（如内网 IP:80） |

---

## 易错细节

**EADDRINUSE**：端口被占用或 **TIME_WAIT** 占用本地四元组 → **`SO_REUSEADDR`**（Ch 7）。

---

> - `SO_REUSEPORT` 多进程同端口监听
