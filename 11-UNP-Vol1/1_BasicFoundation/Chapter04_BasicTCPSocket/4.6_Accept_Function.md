# 4.6 accept 函数

> [4.8 并发](../4.8_ConcurrentServer.md)

---

## 核心主旨与关键论据

**`accept`** 从**已完成连接队列**队头取下一个连接；队列为空则**阻塞**（除非非阻塞）。

```c
int accept(int sockfd, struct sockaddr *cliaddr, socklen_t *addrlen);
```

- `cliaddr`、`addrlen`：**值—结果参数**；成功填入**客户 IP + 端口**  
- 不关心客户 → 传 **`NULL`**

---

## 监听套接字 vs 已连接套接字（全书核心区分）

| | listenfd | accept 返回值 connfd |
|--|----------|----------------------|
| 数量 | 通常 **1 个** | **每客户 1 个** |
| 生命周期 | 进程全程 | 服务该客户期间 |
| 用途 | 只 `accept` | 只与该客户 read/write |
