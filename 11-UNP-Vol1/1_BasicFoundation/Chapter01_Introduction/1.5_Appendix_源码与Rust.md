## 一、C 原版（UNP 标准 · 大写包裹）

```c
#include "unp.h"

int main(int argc, char **argv)
{
    int listenfd, connfd;
    struct sockaddr_in servaddr;
    char buff[MAXLINE];
    time_t ticks;

    listenfd = Socket(AF_INET, SOCK_STREAM, 0);

    bzero(&servaddr, sizeof(servaddr));
    servaddr.sin_family      = AF_INET;
    servaddr.sin_addr.s_addr = htonl(INADDR_ANY); /* 0.0.0.0 全网卡 */
    servaddr.sin_port        = htons(13);

    Bind(listenfd, (SA *)&servaddr, sizeof(servaddr));
    Listen(listenfd, LISTENQ);

    for (;;) {
        connfd = Accept(listenfd, NULL, NULL);

        ticks = time(NULL);
        snprintf(buff, sizeof(buff), "%.24s\r\n", ctime(&ticks));
        Write(connfd, buff, strlen(buff));

        Close(connfd);
    }
}
```

## 二、Rust 对等（迭代逻辑）

**仓库实现**用 `loop { listener.accept()? }`（与 C `for(;;) Accept` 一一对应）。  
下面为等价的 `incoming()` 写法（旧风格，语义相同）：

```rust
use std::io::Write;
use std::net::TcpListener;
use std::time::SystemTime;

fn main() -> std::io::Result<()> {
    let listener = TcpListener::bind("0.0.0.0:13")?;
    println!("daytime server listen on :13");

    for stream in listener.incoming() {
        let mut conn = stream?;
        let time_str = format!("{:?}\r\n", SystemTime::now());
        conn.write_all(time_str.as_bytes())?;
    }
    Ok(())
}
```

| C | Rust |
|---|------|
| `listenfd` | `listener` 全程存活 |
| `connfd` | 每次 `accept` / `incoming` 的 `TcpStream`，块结束 **Drop** = `Close` |
