# P5d — 多线程传感器融合 + 延迟 p99 统计

> 多个传感器并发采样、线程融合数据，统计端到端延迟分布（p50/p99/p999），把嵌入式实时性量化。

## 项目目标

把"多线程 + 延迟统计"做到嵌入式场景：传感器线程采集、融合线程合并、输出线程下发，测量从采样到输出的延迟分布。这也是 HFT 延迟统计方法在嵌入式侧的预演。

## 交付物

- [ ] 采集线程（每个传感器一个，或 epoll 多路）
- [ ] 融合线程（Kalman 或加权平均，共享缓冲 + 锁/无锁队列）
- [ ] 输出/控制线程（消费融合结果）
- [ ] 时间戳打点：采样时刻、融合完成、输出时刻
- [ ] 延迟直方图：p50/p99/p999，用 `CLOCK_MONOTONIC`
- [ ] 对比：普通内核 vs PREEMPT_RT 的延迟分布

## 学习目标

- 多线程同步：互斥锁 vs 无锁队列在嵌入式实时性的差异
- `CLOCK_MONOTONIC` vs `CLOCK_REALTIME`，时间源精度
- 延迟分布统计（直方图、尾延迟 p99/p999）
- PREEMPT_RT 对尾延迟的实际影响
- 优先级反转、调度延迟的现场观测

## 里程碑

1. **M1** 单线程采样 + 输出，基线延迟
2. **M2** 多线程 + 锁，延迟分布采集
3. **M3** 换无锁队列，对比 p99
4. **M4** 开 PREEMPT_RT，对比尾延迟改善
