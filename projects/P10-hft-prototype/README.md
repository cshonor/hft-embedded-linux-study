# P10 — HFT 单机原型（终局项目）

> 把 P7（DPDK 行情接收）+ P8（撮合引擎）+ 策略 + 风控 + 回测 串成完整链路。
> **目标：** 仿真环境下跑通"接收行情 → 更新订单簿 → 生成信号 → 风控检查 → 模拟下单 → 统计 PnL"。
> **不是：** 可上实盘的生产系统。详见 [12-MONTH-ROADMAP.md](../../12-MONTH-ROADMAP.md) 的原型 vs 生产对比表。

## 组件清单

| # | 组件 | 来源 | 说明 |
|---|------|------|------|
| 1 | 行情模拟器 | 新建 | 二进制格式行情回放，UDP 组播发送 |
| 2 | DPDK 收包 | P7 | 用户态收包，bypass 内核 |
| 3 | 订单簿 | P8 | 红黑树 + 哈希表，price-time priority |
| 4 | 内存池 | P8 | 预分配 slab，热路径零 malloc |
| 5 | 策略引擎 | 新建 | 简单策略：价差套利 / 做市 / 动量 |
| 6 | 风控层 | 新建 | 仓位上限 / 重复检测 / 频率限制 / 熔断 |
| 7 | 撮合模拟 | P8 扩展 | 模拟成交回报（不接真实交易所） |
| 8 | 回测框架 | 新建 | 行情回放 + PnL 统计 + 延迟分布 |
| 9 | 延迟监控 | 新建 | RDTSC 时间戳 + histogram + p50/p99/p999 |
| 10 | 低延迟日志 | 新建 | lock-free 日志，不影响热路径 |

## 原型边界（不能做什么）

| 功能 | 原型 | 生产系统 |
|------|------|---------|
| 行情 | 模拟器回放 | 交易所专线 UDP + 二进制协议 |
| 下单 | 模拟成交 | 交易所真实订单接口 + 认证 |
| 风控 | 基础仓位/频次 | 成千上万边界 + 实时熔断 + 多层校验 |
| 容错 | 单机 crash 即停 | 双机热备 + 故障切换 + 状态恢复 |
| 时间 | RDTSC / clock_gettime | 硬件 PTP + 多源比对 |
| 压测 | 百万级回放 | 千万级 + 线上持续 + 概率性 bug |

**这个原型的价值：学习全链路技术 + 求职展示，不直接上实盘。**
