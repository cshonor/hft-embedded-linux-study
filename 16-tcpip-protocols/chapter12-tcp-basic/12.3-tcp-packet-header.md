# 12.3 TCP 头部和封装

> 章级精读：[../study.md#ch12-3](../study.md#ch12-3) · 图示：[tcp_header.png](../../../top_down/03_transport_layer/assets/tcp_header.png)

## 本节核心目标

熟记 **20B 基本首部**、标志位、窗口与关键**选项**。

---

## 核心字段

| 字段 | 作用 |
|------|------|
| 源/目的端口 | + IP → **四元组** 标识连接 |
| **Seq** | 本段数据起始字节序号 |
| **Ack** | 期望对端下一字节（ACK=1 时有效） |
| 数据偏移 | 首部长度 |
| 标志位 | 见下表 |
| **Window** | 通告 rwnd（16 bit，可 WSCALE 扩展） |
| 校验和 | 含伪首部 |
| 紧急指针 | 配合 URG（少用） |

---

## 标志位（必背）

| 标志 | 含义 |
|------|------|
| **SYN** | 建连 |
| **FIN** | 关连 |
| **ACK** | 确认有效 |
| **RST** | 重置/拒绝 |
| **PSH** | 推送（尽快上交应用） |
| **URG** | 紧急（少用） |

---

## 常见选项

| 选项 | 用途 |
|------|------|
| **MSS** | 最大段载荷，避免 IP 分片 |
| **Window Scale** | 扩展 rwnd > 64KB |
| **SACK** | 选择性确认 |
| **Timestamps** | RTTM、PAWS |

---

## 封装

```text
以太网 → IP → TCP 首部 + 应用数据（字节流片段）
```
