# 11.12 与 DNS 相关的攻击

> 章级精读：[../study.md#ch11-12](../study.md#ch11-12) · DNSSEC：章级精读 [§DNSSEC](../study.md)

## 本节核心目标

认识 **缓存投毒** 与 **DNS 放大 DDoS**。

---

## 缓存投毒 / 欺骗

- 攻击者在合法应答前注入**伪造 RR** → 用户访问钓鱼 IP。
- 缓解：**DNSSEC**、随机化查询 ID/源端口、0x20 编码等。

---

## 放大反射

- 伪造受害者源 IP → 向开放解析器发**小查询** → 大应答打向受害者。
- 与 [ch10 §10.14](../../chapter10-udp-ip-fragment/10.14-udp-security.md) 联动。

---

## 运维

- 勿运行**开放递归**；启用 **RRL**（响应速率限制）。
