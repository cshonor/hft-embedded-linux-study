# 11.5 DNS 协议

> 章级精读：[../study.md#ch11-5](../study.md#ch11-5)

## 本节核心目标

掌握报文格式、**UDP/TCP**、**EDNS0**、核心 **RR 类型**。

---

## 传输

| 场景 | 协议 |
|------|------|
| 常规查询 | **UDP/53** |
| 应答 **TC** 截断 / 区域传输 | **TCP/53** |

---

## EDNS0

- 突破经典 **512 B** UDP 限制；携带更大应答、**DNSSEC** 数据等。

---

## 必知 RR

| 类型 | 用途 |
|------|------|
| **A** | IPv4 |
| **AAAA** | IPv6 |
| **CNAME** | 别名 |
| **MX** | 邮件服务器 |
| **NS** | 子域权威 |
| **TXT** | 验证、SPF 等 |

---

## 动态更新
