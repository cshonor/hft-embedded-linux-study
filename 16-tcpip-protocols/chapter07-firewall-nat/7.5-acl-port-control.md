## 一、ACL 访问控制列表

### 1. 匹配规则

| 原则 | 说明 |
|------|------|
| **遍历顺序** | **自上而下**逐条匹配 |
| **First Match** | **第一条命中**规则立即执行，**不再**后续匹配 |
| **默认策略** | 末尾通常 **DENY/DROP**（隐式或显式） |

### 2. 编写原则

| 原则 | 说明 |
|------|------|
| **细在前、宽在后** | **精细化**规则靠前，**宽泛**规则靠后 |
| **默认拒绝** | 末尾配置 **默认拒绝（DENY/DROP）** — 白名单思维 |
| **先过滤后 NAT** | **过滤规则应先于 NAT 转换**；否则攻击/垃圾流占满状态表 → [study 架构要点](./study.md#ch07-5) |

### 3. 标准规则顺序（实战 / 考点）

与 [7.2 §三条基础规则 + iptables](7.2-packet-filter-firewall.md#ch07-2-rules-order) 一致：

| 顺序 | 规则 | 动作 |
|------|------|------|
| **1** | **黑名单**拦截恶意 IP/网段 | DROP |
| **2** | 拒绝外网主动 **纯 SYN** 连接 | DROP |
| **3** | 放行业务端口（如 **80/443**）及已建立会话 | ACCEPT |
| **4** | **全部默认丢弃** | DROP |

```text
黑名单 → 拒 SYN → 允许 80/443 → 默认 DROP
```

**一句**：**先匹配先生效，细规则在前，默认拒绝收尾。**

## 二、动态端口映射协议（Open NAT）

终端/应用**自动**向边界 NAT 设备申请**入站端口映射**，实现「外网能连进来」（游戏、P2P、VoIP 等）。

| 协议 | 特点 |
|------|------|
| **UPnP IGD** | **传统主流**；终端自动申请入站映射；家用路由器常见；**认证弱** |
| **NAT-PMP** | Apple 等早期方案；较 UPnP 简洁 |
| **PCP** | **IETF 新一代**；映射生命周期、安全性、功能优于 UPnP；**CGN** 环境更规范 |

| 场景 | 策略 |
|------|------|
| **家用** | 常**开启** — 游戏/BT/VoIP 依赖 Open NAT |
| **企业** | 一般**禁用** — 防恶意端口暴露、未授权入站、入侵 |

**风险提示**：UPnP 允许内网应用**自行打洞**入站 → 企业网视为**扩大攻击面**。

→ NAT 类型与 P2P：[7.3](7.3-nat-napt.md#ch07-3-mapping-types) · 穿透：[7.4](7.4-nat-traversal.md)

## 三、运维要点

### 连接跟踪表 `conntrack`

| 项 | 说明 |
|----|------|
| **作用** | 记录 **NAT / 防火墙** 会话状态（五元组映射、TCP 状态等） |
| **查看** | Linux：`conntrack -L` · `/proc/net/nf_conntrack` |
| **iptables** | `iptables -L -n -v` 查看规则命中计数 |

### 状态表耗尽

| 现象 | 原因 |
|------|------|
| **无法新建连接** | `conntrack` / NAT 映射表**占满** |
| **业务中断** | 新用户/新会话无法建立；已有连接可能仍存活 |
| **安全类** | 攻击者伪造大量半开连接 → **状态表耗尽 DoS** → [7.7](7.7-security-attacks.md) |

**缓解**：限制每源新建速率、合理超时、扩容表项（仍有限）；关键服务 **DMZ** 或公网 v6。

<a id="ch07-5-cheat"></a>

## 考点速记

| # | 要点 |
|---|------|
| 1 | **ACL**：**先匹配先生效**；**细规则在前**；**默认拒绝收尾** |
| 2 | **标准顺序**：黑名单 → 拒 SYN → 80/443 → 默认 DROP |
| 3 | **动态映射**：**UPnP** 经典；**NAT-PMP/PCP** 替代/增强；**企业多关闭** |
| 4 | **conntrack 满** → 新连接失败（**状态表耗尽**） |
| 5 | **先过滤后 NAT** — 避免垃圾流占满映射表 |

| 易错 | 正确 |
|------|------|
| 规则越宽泛越靠前 | **具体规则在前**，默认 DROP **最后** |
| UPnP 企业标配 | 企业一般**禁用**；家用常见 |
| NAT 表满只影响 NAT | **防火墙 conntrack** 满同样断新连接 |

## 疑问与总结

**背：ACL 自上而下 First Match；黑→SYN→80/443→DROP；UPnP 家用/企业禁；conntrack 满则断新连。**
