# 3.1 引言

> 章级精读：[../study.md#ch03-1](../study.md#ch03-1) · 上一章：[ch02](../../chapter02-ip-address-architecture/study.md)

## 本节核心目标

明确链路层在 TCP/IP 中的使命：**收发 IP 数据报**，屏蔽物理介质差异。

---

## 核心要点

- 链路层为**网络层**提供本地交付与封装（以太网、Wi‑Fi、PPP 等）。
- 多种链路技术并存 → 上层 **IP** 保持统一（**IP-on-everything**）。
- **MTU**：单链路一次可传的最大载荷上限（以太网常见 **1500 B**）→ [3.8](3.8-mtu.md)。

---

## 与上下层

```text
应用 → TCP/UDP → IP 数据报 → 链路层帧 → 物理比特
```

- 换链路类型（光纤/Wi‑Fi）通常**不必改 IP 语义**。
