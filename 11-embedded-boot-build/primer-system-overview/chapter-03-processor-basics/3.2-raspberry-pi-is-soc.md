# 树莓派 BCM：按本书标准属于 SoC，不是独立处理器

> FAQ · 锚定 Primer Ch3 分类 · 章摘要：[notes.md](./notes.md)  
> 板级动手：[Pi Labs](../../../13-embedded-projects/RASPBERRY-PI5-LABS.md)

---

## 结论

树莓派核心 **Broadcom BCM 系列是 ARM 架构集成 SoC（Integrated Processor）**，  
**不属于** Ch3 定义的 **Stand-Alone Processor（独立 CPU + 南北桥）**。

---

## 一、书中二分法（对照 Ch3）

| 类型 | 书中标准 | 例子 |
|------|----------|------|
| **独立处理器** | 几乎只有算力核；**无**内置内存控制器 / 以太 / USB / GPU / 串口等完整外设集；必须配北桥、南桥（或等价桥片） | Pentium M、Atom、MPC7448、IBM 970FX |
| **SoC** | 单片：CPU + 内存控制器 + 通信/多媒体/IO；板级只需电源、Flash/SD、PHY 等少量辅芯片 | TI OMAP、Freescale i.MX、Broadcom MIPS 线；**树莓 BCM 同属此类** |

---

## 二、BCM 系列即 SoC 证据

| 板 | SoC | CPU（均带 MMU，可跑 Linux） |
|----|-----|------------------------------|
| 初代 / Zero | BCM2835 | ARM1176 |
| Pi 2 | BCM2836 | 4× Cortex-A7 |
| Pi 3 | BCM2837 | 4× A53 |
| Pi 4 | BCM2711 | 4× A72 |
| **Pi 5** | **BCM2712** | 4× A76 |

单片内常见集成（无需南北桥）：

- ARM CPU（+ MMU）  
- VideoCore GPU / 编解码  
- LPDDR 内存控制器  
- HDMI / DSI、CSI、USB 控制器  
- 以太 MAC、I2C / SPI / UART / GPIO  
- 片内总线与中断控制  

**PCB：** 主板上无南北桥大芯片；辅件多为 PHY、电源、Wi‑Fi/BT 模组、（Pi5）**RP1** 等南桥式 I/O 伴侣——那是 SoC 生态里的**外设芯片**，不是 Ch3 那种「独立 CPU 必备南北桥芯片组」叙事。

> Pi5：应用核在 BCM2712，丰富 GPIO/外设常经 **RP1**；分类上整机仍是 **SoC 方案**，不是 Stand-Alone + 经典南北桥。

---

## 三、与书中 ARM 小节对标

Ch3 的 OMAP / i.MX：**消费多媒体 SoC、CPU+GPU+IO、跑嵌入式 Linux、开发板形态**。  
树莓 BCM 定位同一格；只是厂商从 TI/Freescale 换成 Broadcom，年代更新到 BCM2712。

---

## 四、易混概念

| 说法 | 澄清 |
|------|------|
| **SoM**（如 Compute Module） | 小电路板模组 = SoC + 内存/eMMC 等；**上面那颗核仍是 SoC**，SoM ≠ SoC |
| 独立 CPU + 南北桥 | 老式 x86 工控 / 书中 Stand-Alone |
| 单颗（或 SoC+RP1）集成方案 | 树莓、手机、路由、机顶盒 |

Bootloader 侧：这类板走 **厂商固件 / U-Boot** 嵌入式路径，不是 PC BIOS/UEFI 独立 CPU 故事 → [2.1 FAQ](../chapter-02-big-picture/2.1-uboot-bios-uefi.md)。

---

## 五、一句话

按 Primer Ch3：**树莓派 Broadcom BCM = ARM 集成 SoC**；读独立处理器节时用它当反例即可，精读应对齐 **§3.2 SoC / ARM**。
