## 一、基础概念

**NZCV** = PSTATE 里 4 个 1-bit 标志，记录**上一次（带 S 的）运算**结果的特征，供后续 `b.xx`、`csel` 等使用。

| 规则 | 说明 |
|------|------|
| **谁改** | 只有带 **S** 的指令：`ADDS` / `SUBS` / `ANDS` / `ORRS` / `EORS` / `BICS` 等 |
| **谁不改** | 普通 `ADD` / `SUB` / `AND` … **不刷新** NZCV |
| **谁读** | 条件跳转 / 条件选择；跳转本身**只读不改** NZCV |

口诀（Ch4）：**带 S 改标志；不带 S 只算数值。**

## 二、四位分开讲

### 1. N = Negative（符号 / 最高位）

- 规则：结果**最高比特 = 1** → N=1；否则 N=0。  
- 用途：有符号视角看正负。  
- 例：结果 `0xFFFF_FFFF_FFFF_FFFF` → 最高位 1 → **N=1**。

### 2. Z = Zero

- 规则：结果**全 0** → Z=1；否则 Z=0。  
- 用途：相等判断（`subs` 后若两数相等 → Z=1 → `b.eq`）。

### 3. C = Carry（**仅无符号**进位 / 借位）

| 场景 | C 的典型含义 |
|------|----------------|
| **无符号加法** | 超出位宽、产生进位 → **C=1**（如全 1 + 1） |
| **无符号减法** | 不够减、发生借位 → **C=0** |

口诀：**无符号加进出 C=1；无符号减借位 C=0。**  
无符号大小：`HS`/`LO` 等靠 **C**。

### 4. V = Overflow（**仅有符号**溢出）

- 规则：有符号加/减结果超出有符号可表示范围 → **V=1**；否则 V=0。  
- 例：两大正数相加变负 → 硬件置 **V=1**。

> **C 与 V 完全独立：** C = 无符号；V = 有符号。勿混用。  
> 为何一次运算两套标志、以及 LDRB/LDRSB 的「同一比特不同解读」→ [SIGNED-UNSIGNED.md](./SIGNED-UNSIGNED.md)。

## 三、常用条件后缀（书里高频）

| 后缀 | 规则 | 含义 |
|------|------|------|
| **EQ** | Z == 1 | 相等 |
| **NE** | Z == 0 | 不等 |
| **HS** | C == 1 | 无符号 ≥ |
| **LO** | C == 0 | 无符号 < |
| **GE** | N == V | 有符号 ≥ |
| **LT** | N != V | 有符号 < |

（完整条件表见原书 / ARM ARM；跳转细节 → Ch5。）

## 四、实操例子

### 例 1：`1 - 3`（小减大）

```asm
mov  w0, #1
mov  w1, #3
subs w2, w0, w1   ; 1 - 3
```

| 标志 | 预期 |
|------|------|
| N | 1（结果最高位为 1） |
| Z | 0（非零） |
| C | 0（无符号借位） |
| V | 0（有符号未溢出） |

### 例 2：全 1 + 1

```asm
mov  x0, #0xFFFFFFFFFFFFFFFF
adds x0, x0, #1
```

| 标志 | 预期 |
|------|------|
| C | 1（无符号进位） |
| Z | 1（结果为 0） |
| N | 0（最高位清 0） |
| V | 1（有符号溢出） |

GDB：单步后看 PSTATE；或 `mrs x0, nzcv` 把四标志读到通用寄存器再查。

---

## 五、易错点

1. 忘加 **S** → NZCV 不更新 → 后面条件全错。  
2. **C ≠ V**：无符号看 C，有符号看 V / N↔V。  
3. 读标志：`mrs x0, nzcv`。  
4. **`b.eq` 等只读 NZCV，不修改。**

---

## 一句话

> NZCV 是「带 S 运算」留下的四比特摘要：N/Z 看符号与是否为零；**C 管无符号进借位，V 管有符号溢出**；条件跳转只读这些位做决定。
