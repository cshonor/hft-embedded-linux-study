## 4.1 算术指令

口诀：**带 S 改标志；不带 S 只算数值。**

### 加法

| 指令 | 行为 |
|------|------|
| `ADD` | 普通加，**不改** NZCV |
| `ADDS` | 加并 **Set flags**（更新 NZCV） |
| `ADC` | `Rd = Rn + Op + C`，大数（128/256 位）加法 |

```asm
add  x0, x1, x2   ; x0 = x1 + x2（不改标志）
adds x0, x1, x2   ; 同上并更新 NZCV
```

### 减法

| 指令 | 行为 |
|------|------|
| `SUB` | 普通减，不改标志 |
| `SUBS` | 减并更新 NZCV |
| `SBC` | 借位减（用 C），多大数减法 |

> **`CMP Xn, Xm`** = 伪指令 ≡ **`SUBS XZR, Xn, Xm`**：结果丢弃，只改条件标志。

## 4.2 NZCV 四个条件标志 ⭐

> **展开专篇：** [NZCV.md](../../NZCV.md)（N/Z/C/V 规则 · 条件表 · 两道例题 · `mrs nzcv`）

只有 `ADDS` / `SUBS` 等带 **S** 的指令才会改写（以及部分带 S 的位运算）。

| 标志 | 含义 |
|------|------|
| **N** Negative | 结果最高位为 1（有符号视角为负） |
| **Z** Zero | 结果为 0 |
| **C** Carry | **无符号** 进位 / 借位（减法发生借位时常见 C=0） |
| **V** Overflow | **有符号** 溢出（超出有符号可表示范围） |

> **C ≠ V**：C 管无符号；V 管有符号。面试常考「有符号/无符号大小」看哪组标志。

### 常见条件后缀（挂在跳转 / 选择指令上）

| 后缀 | 含义 |
|------|------|
| `EQ` | Z=1 |
| `NE` | Z=0 |
| `HS` | C=1，无符号 ≥（Higher or Same） |
| `LT` | N≠V，有符号 < |
| `GE` | N==V，有符号 ≥ |

（条件跳转细节见 Ch5。）

## 4.3 移位

可单独成指令，也可作算术操作数修饰。

| 指令 | 含义 |
|------|------|
| **LSL** | 逻辑左移，低位补 0（×2ⁿ） |
| **LSR** | 逻辑右移，高位补 0（**无符号**） |
| **ASR** | 算术右移，高位填符号位（**有符号**） |
| **ROR** | 循环右移 |

```asm
lsl x0, x1, #3            ; x0 = x1 << 3
add x0, x1, x2, lsl #3    ; x0 = x1 + (x2 << 3)  ; 8 字节元素数组常用
```

---

## 4.4 位操作

| 指令 | 含义 |
|------|------|
| `AND` | 按位与 |
| `ORR` | 按位或 |
| `EOR` | 按位异或 |
| `BIC` | Bit Clear：`Rd = Rn & (~Op)`，清指定位 |

同样有 `ANDS` / `ORRS` / `EORS` / `BICS`（带 S 更新 NZCV）。

```asm
bic x0, x0, #(1 << 5)   ; 清 x0 第 5 位
```

> BIC **不是**「整寄存器取反」，而是与「取反后的操作数」做 AND。

---

## 4.5 位段提取 / 插入（内核高频）

| 指令 | 含义 |
|------|------|
| `UBFX Rd, Rn, #lsb, #width` | 从 Rn 的 lsb 起取 width 位，**零扩展** → Rd |
| `SBFX Rd, Rn, #lsb, #width` | 同上，**符号扩展** |
| `BFI Rd, Rn, #lsb, #width` | 把 Rn 低 width 位写入 Rd 的 lsb，其余不变 |

读系统寄存器、解析页表项时常用 UBFX/SBFX。

## 4.7 易错坑

1. 忘加 **S** → NZCV 不更新 → 后续条件全错。  
2. **C**（无符号）与 **V**（有符号）勿混。  
3. 无符号右移 **LSR**；有符号负数右移用 **ASR**。  
4. **BIC** = AND NOT，不是 NOT。  
5. **UBFX** 零扩展 / **SBFX** 符号扩展。

## 书中思考题（自测）

1. ADD 与 ADDS 区别？CMP 本质？  
2. C 与 V 分别代表什么？对应无符号还是有符号？  
3. LSR 与 ASR 差别？何时用哪个？  
4. BIC 作用？  
5. UBFX 与 SBFX 区别？

**参考答案：**

1. ADD 不算标志；ADDS 更新 NZCV。CMP ≡ `SUBS XZR, …`。  
2. C=无符号进位/借位；V=有符号溢出。  
3. LSR 高位补 0（无符号）；ASR 填符号位（有符号）。  
4. `Rd = Rn & ~Op`，清指定位。  
5. 提取位段后：UBFX 零扩展，SBFX 符号扩展。
