# CH7 · shell / bash：工作台语言

> **这一章解决什么困惑：** 06.6 / 06.6.5 / 06.7 三个模块里有 73 个 `.sh` 脚本——
> 工作里到底用 shell 还是 C？shell 值不值得专门学？
>
> 答案：**都用，各管各的层**。C/C++ 是执行路径的语言（微秒纳秒预算，shell 起一次进程就要几毫秒，
> 物理上不可能）；shell 是**工作台语言**——排查、观测、实验编排、构建链、CI 的母语。
> 前者是武功，后者是手艺，两个都要。

## 本章定位（与模块里其他章的区别）

- **不开书式精读**：shell 没有内核/TLPI 那种机制深度，逐章做笔记是挂积分
- **学习路径是"用会"不是"学会"**：① TLPI 前几章把 shell 当 REPL 用（文件描述符、管道、重定向
  就是 Ch5/Ch44 的内容）；② 敲过三遍的命令固化成 `.sh`；③ 卡住查 `man bash`
- **判断三问**：主体是调外部命令 → shell；有数据结构/算法/性能预算 → C/C++；
  逻辑复杂但本质是文本/数据胶水 → Python。经验法则：脚本开始需要数组、复杂错误处理、
  函数返回值，就是它在求你换语言（约 100 行是道坎）
