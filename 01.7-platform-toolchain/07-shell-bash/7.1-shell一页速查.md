# 7.1 shell 一页速查

[← CH7](./README.md) · [模块首页](../README.md)

> 一页纸。只放日常脚本里真会用的；解释往 [7.2 坑点清单](./7.2-坑点清单.md) 跳。
> 这里的"shell"= **bash**（`#!/usr/bin/env bash`），不追求 POSIX sh 兼容——你的脚本都在 Linux 上跑。

---

## ① 头部纪律（每个脚本前两行）

```bash
#!/usr/bin/env bash
set -euo pipefail
```

| 标志 | 作用 | 没有它会怎样 |
|---|---|---|
| `-e` | 任何命令失败立即退出 | 错误被吞，脚本带着坏状态继续跑 |
| `-u` | 引用未定义变量即报错 | 打错变量名 = 静默拿到空字符串 |
| `pipefail` | 管道中任一环节失败都算失败 | `cmd1 \| grep x` 里 cmd1 挂了脚本照样成功（坑点 #3） |

## ② 变量与引号（90% 的 bug 在这）

| 写法 | 含义 | 记法 |
|---|---|---|
| `"$var"` | 引用变量（**永远加双引号**） | 不加引号 = 单词分割 + glob 展开，文件名带空格必碎 |
| `'$var'` | 字面量，不展开 | 单引号里什么都不会发生 |
| `$(cmd)` | 命令替换 | 别再用反引号 `` `cmd` ``，不能嵌套、可读性差 |
| `"$@"` | 全部参数（保持各自边界） | 转发参数的**唯一**正确写法 |
| `$#` / `$1` / `shift` | 参数个数 / 第 N 个 / 左移 | — |
| `${var:-默认}` | 空则用默认值 | 可选参数：`ENV=${1:-prod}` |

## ③ 判断（`[` 是命令，`[[` 是关键字）

```bash
if cmd; then ... fi                    # 直接用退出码判断，不要 if [ $? -eq 0 ]
[[ -f "$f" ]]    # 文件存在        [[ -z "$s" ]]  # 字符串为空
[[ "$a" = "$b" ]] # 字符串相等      [[ "$n" -gt 3 ]] # 数值比较用 -gt -eq -lt
cmd1 && cmd2     # 成功才执行
cmd1 || cmd2     # 失败才执行（兜底：|| { echo "失败"; exit 1; }）
```

> 优先 `[[ ]]`：bash 关键字，**内部不做单词分割和 glob**，比 `[` 安全（坑点 #4）。

## ④ 循环与读行

```bash
for f in *.log; do ... done            # glob 直接展开，不会被空格切碎
while IFS= read -r line; do ... done < file     # 逐行读文件的唯一正确姿势
cmd | while read -r x; do ... done     # ⚠ 管道开的 while 在子 shell 里，改的变量外面看不见
```

反模式：`for f in $(ls *.log)` —— 见坑点 #2。

## ⑤ 重定向与管道

| 写法 | 作用 |
|---|---|
| `cmd > out 2>&1` | stdout+stderr 都进文件（顺序不能反） |
| `cmd 2>/dev/null` | 只丢错误输出 |
| `cmd \| tee log` | 既看又存 |
| `cmd1 \| grep pat \| awk '{print $2}'` | 三剑客最小集：grep 挑行，awk 取列 |
| `sed -i.bak 's/旧/新/g' file` | 就地替换留备份（macOS 的 sed 必须给 `-i` 一个后缀参数） |
| `<<< "$str"` | here-string，把变量喂给读 stdin 的命令 |
| `<<'EOF'` | here-doc（引号阻止变量展开，写嵌入脚本时用） |

## ⑥ 常用惯用法

```bash
command -v bpftool >/dev/null || { echo "缺 bpftool"; exit 1; }   # 依赖检查
cd "$(dirname "$0")/.."        # 切到脚本所在目录（脚本从哪调都不怕）
trap 'echo "失败于第 $LINENO 行" >&2' ERR     # 出错时带行号
sudo -n true 2>/dev/null || echo "需要 sudo"  # 探测权限
```

## ⑦ 调试

```bash
bash -x script.sh     # 每条命令展开后打印再执行（首选）
set -x                # 脚本内局部开启；set +x 关闭
shellcheck script.sh  # 静态检查器，能装就装（apt/brew 都有）
```
