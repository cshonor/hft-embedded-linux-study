# 4.1 GNU 工具链：没有 IDE 的那个世界

[← CH4 Linux/GNU](./README.md) · 下一节：[4.2 三道防线全部沉默 →](./4.2-三道防线全部沉默.md)

## 本节讲什么

Linux 这边和前两个平台最本质的区别是：

> **Linux 上没有"Visual Studio"，也没有"Xcode"。**
> 从来就没有过一个官方的、统治性的 C/C++ IDE。

后果有两面 —— 坏消息是新手不知道该点哪里；好消息是**你被迫看见每一个零件**，
而这正是学 TLPI 需要的心智模型。

这一节先把这些零件认全，数据全部来自你的 Pi（Debian 13 aarch64）。

### 关键认知：gcc 不是编译器，gcc 是司机

这一点 Windows 和 Mac 都一样容易被误解（见 [1.1](../01-common-core/1.1-IDE不是编译器.md)），
但在 Linux 上最容易自己验证：

```console
$ gcc -### -O0 ptrbug.c -o /dev/null
/usr/libexec/gcc/aarch64-linux-gnu/14/cc1        ← 1. 真正的 C 编译器（预处理+编译）
/usr/libexec/gcc/aarch64-linux-gnu/14/collect2   ← 3. 链接协调者（它再去调 ld）
-plugin-opt=-pass-through=-lgcc                  ←   顺手带上 gcc 运行时
-plugin-opt=-pass-through=-lc                    ←   和 glibc
```

完整链条是四个程序接力：

```
hello.c
  │  cpp/cc1：预处理 + 编译
  ▼
hello.s     （人能读的汇编）
  │  as：汇编
  ▼
hello.o     （机器码 + 重定位表）
  │  ld（由 collect2 召集）：链接 libc + crt0 + 你的 .o
  ▼
hello       （ELF 可执行文件）
```

想看每一阶段的中间产物：

```bash
gcc -save-temps hello.c -o hello      # 留下 .i / .s / .o
gcc -E hello.c | less                 # 只看预处理结果
gcc -S hello.c                        # 只到汇编
gcc -c hello.c                        # 只到目标文件
```

> 这条链条和 `01.5-cmake-build` 里讲的构建流程是同一件事：
> **CMake / Make 只是调度 Update 这四个程序的调度员，它们自己一行代码都不编译。**

### 为什么推荐同时装 clang

| 理由 | 说明 |
|---|---|
| 诊断信息更友好 | clang 的错误提示会画出出错位置的列、给出 fix-it 建议 |
| 两套优化器 = 两双眼睛 | UB 在一个编译器上"正常"不等于真的没问题，见 [4.2](./4.2-三道防线全部沉默.md) |
| sanitizer 生态同源 | ASan/UBSan/TSan 在两边都支持，写法基本一致 |
| 交叉手感 | 你在 Mac 上用的也是 clang，习惯一致 |

你的 Pi 上已经有 **gcc 14.2 + clang 19.1.7**，这是做双验证的完美起步配置。

### 关于 musl——提一句就够

除了 glibc，Linux 还有 musl libc（Alpine Linux 用的）。
它更小、更适合静态链接和容器；但**行为差异足以让部分程序出问题**
（DNS 解析、locale、线程栈默认大小）。

学 TLPI 期间认准 glibc，等你要做最小容器镜像时再回头看 musl。

<details>
<summary>Q&amp;A：这么多工具，哪些现在就该会，哪些可以先不管？</summary>

**立刻要会：** `gcc/clang` 的选项（`-g -O0 -Wall -std=`）、`gdb` 五件套、
`ldd`（看依赖）、`nm`（看符号）。

**一个月内会用：** `readelf -S`（看节）、`objdump -d`（反汇编）、
`strip`、`ar`（打静态库）—— 这几样在学 `03-linux-userspace-api` 时会反复出现。

**用到再查：** `objcopy`（分离调试信息）、`patchelf`（改 RPATH）、
`ld --verbose`（看默认链接脚本）。知道它们存在即可。
</details>
