# 2.2 选项对照全表

[← 2.1 cl.exe 一条命令](./2.1-cl.exe一条命令长什么样.md) · 下一节：[2.3 版本号迷宫 →](./2.3-版本号迷宫.md)

## 本节讲什么

本模块**最常被回查的一节**。把三族编译器的选项按"你想干什么"横向排开。
用法不是背，是遇到需求时来查。

> ⚠️ MSVC 列按 Microsoft Learn 编译器选项文档整理，**本机为 macOS 无法复跑**。
> clang/gcc 列中标记 ✅ 的为 `cdev` 环境 clang 23.1.0 实测验证过的写法。

## 要点

### A. 输出与预处理

| 你想做的事 | MSVC | clang / gcc |
|-----------|------|-------------|
| 只编译不链接 | `/c` | `-c` ✅ |
| 指定可执行文件输出名 | `/Fe:app.exe` | `-o app` ✅ |
| 指定目标文件输出名 | `/Fo:dir\file.obj` | `-o dir/file.o` ✅ |
| 加头文件搜索路径 | `/I<dir>` | `-I<dir>` ✅ |
| 只做预处理，输出到文件 | `/P` | `-E` ✅ |
| 预处理时保留注释 | `/C` | `-C` |
| 打印 `#include` 依赖树 | `/showIncludes` | `-H` / `-MD`（生成依赖文件） |
| 定义宏 | `/DNAME` `/DNAME=value` | `-DNAME` `-DNAME=value` ✅ |

### B. 优化

| 你想做的事 | MSVC | clang / gcc |
|-----------|------|-------------|
| 关闭优化（调试用） | `/Od` | `-O0` ✅ |
| 优化：倾向体积 | `/O1` | `-Os` ✅ |
| 优化：倾向速度（最常用） | `/O2` | `-O2` ✅ |
| 激进优化（不完全等价于 O3） | `/Ox` | `-O3` ✅ |
| 链接时优化 / 全程序优化 | `/GL`（编译）+ `/LTCG`（链接） | `-flto`（编译+链接都加） ✅ |
| 指定指令集 | `/arch:AVX2` | `-mavx2` ✅ |
| 多线程并行编译 | `/MP` | 交给 `make -jN`（`-j` 在构建系统层） ✅ |

### C. 调试信息与运行时检查

| 你想做的事 | MSVC | clang / gcc |
|-----------|------|-------------|
| 生成调试信息 | `/Zi`（进 `.pdb`）| `-g` ✅ |
| 调试信息内嵌于目标文件 | `/Z7` | —（DWARF 本就在对象里） |
| 支持"编辑并继续" | `/ZI`（与 `/Od` 搭配） | —（无对应概念） |
| 指定 DWARF 版本 | — | `-gdwarf-5` |
| 栈溢出保护（canary） | `/GS`（默认开） | `-fstack-protector-strong` |
| 运行时错误检查（**仅 `/Od` 下可用**） | `/RTC1`（栈帧 + 未初始化变量） | `-fsanitize=undefined,address` ✅ |
| 地址消毒剂 | —（`/fsanitize=address` 在较新版本提供） | `-fsanitize=address` ✅ |
| 安全开发生命周期检查 | `/sdl`（把部分警告升级为错误） | `-D_FORTIFY_SOURCE=2` |
| 保留帧指针 | `/Oy-`（关闭帧指针省略） | `-fno-omit-frame-pointer` ✅ |

### D. 警告与诊断

| 你想做的事 | MSVC | clang / gcc |
|-----------|------|-------------|
| 常用警告全开 | `/W4` | `-Wall -Wextra` ✅ |
| 编译器所有可用警告（噪音大） | `/Wall` | `-Weverything`（仅 clang） |
| 警告升级为错误 | `/WX` | `-Werror` ✅ |
| 关闭某个警告 | `/wd4996` | `-Wno-deprecated-declarations` ✅ |
| 把某个警告变成错误 | `/we4996` | `-Werror=<name>` ✅ |
| 严格一致性 / 禁用扩展 | `/permissive-`（C++） | `-pedantic` / `-std=c17`（而非 gnu17） |
| 静态分析 | `/analyze` | `clang --analyze` / `scan-build` ✅ |

> 数字对照：`/W4` ≈ `-Wall -Wextra`；MSVC 的默认级别是 `/W3`，
> 比 clang 默认的（无 `-Wall`）略严，比 `-Wall -Wextra` 略松。

### E. 语言标准

| 你想做的事 | MSVC | clang / gcc |
|-----------|------|-------------|
| C 语言标准 | `/std:c11` `/std:c17` `/std:clatest` | `-std=c11` `-std=c17` ✅ |
| C++ 语言标准 | `/std:c++20` `/std:c++23` `/std:c++latest` | `-std=c++20` `-std=c++23` |
| 一致性预处理器 | `/Zc:preprocessor`（`/std:c11` 以上隐式打开） | 默认就是一致性实现 |
| `__cplusplus` 宏正确报告版本 | `/Zc:__cplusplus` | 默认正确 |

> ⚠️ MSVC 的 C 标准支持有明确边界 —— **VLA / `<threads.h>` / `_Complex` / `aligned_alloc` 全缺**。
> 详见 [4.1](../05-boundary/5.1-MSVC的C标准边界.md)。

### F. 链接

| 你想做的事 | `link.exe` | clang / gcc 驱动的链接器 |
|-----------|-----------|--------------------------|
| 指定输出 | `/OUT:app.exe` | `-o app` ✅ |
| 附加库目录 | `/LIBPATH:<dir>` | `-L<dir>` ✅ |
| 链接某个库 | `foo.lib` 直接列出，或 `/DEFAULTLIB:foo` | `-lfoo` ✅ |
| 生成调试信息 | `/DEBUG`（配合 `/Zi`） | `-g` 即可 ✅ |
| 去掉未引用函数，减小体积 | `/OPT:REF` | `-ffunction-sections`（编译）+ `-Wl,--gc-sections`（链接） |
| 子系统 | `/SUBSYSTEM:CONSOLE` | —（ELF 无此概念） |
| 全程序优化 | `/LTCG` | `-flto` ✅ |

### G. MSVC 独有（GNU/Clang 无对应）

| 选项 | 作用 |
|------|------|
| `/MD` `/MDd` `/MT` `/MTd` | CRT 链接方式，见 [2.4](./2.4-CRT选型.md) |
| `/EHsc` | 异常模型（`/EH` 系列决定能 catch 什么） |
| `/GR` `/GR-` | 启用 / 关闭 RTTI（clang 用 `-frtti` / `-fno-rtti`） |
| `/bigobj` | 允许超过 65536 个节的 `.obj`（模板重的 C++ 项目常需要） |
| `/Zc:*` 系列 | 逐项微调语言一致性（历史的偏离太多，只能逐项开关） |
| `/analyze` | 静态分析（GNU 侧用外部工具或 `-fanalyzer`） |
