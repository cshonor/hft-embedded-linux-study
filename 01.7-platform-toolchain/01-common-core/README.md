# CH1 · 公共认知层：三平台共用同一套心智模型

> **这一章解决什么困惑：** 在 VS 里按 F5 就能跑，但换到 Mac/Linux 命令行就不知道该敲什么。
> 原因是 IDE 把四件事藏起来了。这一章把它们挖出来摊平。
>
> **这一章是平台无关的。** 它是 [CH2 Windows](../02-windows-msvc/README.md)、
> [CH3 macOS](../03-macos-xcode/README.md)、[CH4 Linux](../04-linux-gnu/README.md)
> 三条支线共用的地基 —— 读任何一条支线之前，先过一遍这里。

---

## 本章的收获

读完你应该能回答：

1. 「Visual Studio」和「MSVC」是一回事吗？（不是）
2. `.sln` 和 `.vcxproj` 谁指挥谁？（`.sln` 是解决方案容器，`.vcxproj` 才是 MSBuild 的输入）
3. VS 里的「生成」到底调用了谁？（MSBuild → cl.exe + link.exe）
4. 这套东西映射到 `CMakeLists.txt` / `Makefile` 是什么？

## 一句话结论（赶时间只看这行）

> **IDE 只是把「编译 + 链接 + 构建调度 + 调试」这四个独立程序包装成按钮的任何东西。**
> 按住 Qt Creator、VS Code、Xcode、CLion 全都成立。认准这四件事，换任何 IDE 都不会慌。
