## 笔记

### 极简口诀

| 句 | |
|----|--|
| 组合 | 无记忆，并行运算但 **不受控** |
| 锁存 / FF | 电平透明 vs **边沿**采样；CPU 用 FF |
| 同步时序 | **统一时钟** 总指挥；FF→组合→FF |
| Setup / Hold | 稳定运行的 **最低底线** |
| FSM | 状态寄存器 + 次态/输出组合 = **控制模型** |
| 可控并行 | 在时钟节拍内 **同时多路** 计算 |

### 对你的实用价值

主攻：嵌入式 Linux、Rust、HFT 低延迟。

| 方向 | 带走什么 |
|------|----------|
| **CSAPP / CPU** | 流水线按时钟推进；级间寄存器 = D-FF |
| **主频与出错** | setup 违例 / 亚稳态 → 功能偶发错 |
| **跨时钟** | GPIO、UART、网卡 → 同步器 / FIFO |
| **嵌入式驱动** | 外设 = FSM；读状态位 = 读现态 |
| **HFT** | 时钟质量与关键路径定延迟下限 |
| **后文** | Ch5 寄存器堆/FIFO；Ch7 冒险与流水线 |
