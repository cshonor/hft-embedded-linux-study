### 3.5.1 两个黄金约束：Setup / Hold

| 约束 | 含义（钉死） |
|------|----------------|
| **建立时间 Setup (tsu)** | 时钟边沿到来 **之前**，D 必须已经稳定，并维持至少 tsu |
| **保持时间 Hold (th)** | 时钟边沿到来 **之后**，D **不能立刻变**，还须再稳至少 th |

通俗：

- Setup：开枪前，人要提前站好  
- Hold：枪响瞬间，人不能马上乱跑  

| ❌ | ✅ |
|----|-----|
| 「边沿一到马上改 D 也没事」 | 边沿后还要守 hold |
| 「只要最终逻辑对就行」 | 采样瞬间 D 不稳 → 本拍就可能采错 |

和组合延迟的桥（→ [2.9](../ch02_combinational/2.9_时序.md)）：

```
上一级 FF 发出 Q
  → 组合逻辑（延迟约在 tc … tp 之间）
  → 本级 FF 的 D

Setup 要满足：  组合最慢路径也不能太慢
  → 大致： Tclk ≥ tp_组合 + tsu +（FF 时钟到 Q 等开销）

Hold 要满足：   组合最快路径也不能太快
  → 大致： tc_组合 ≥ th −（时钟到 Q 等）
```

- **Setup 紧** → 时钟开不快（主频上限）  
- **Hold 紧** → 哪怕降频也修不好，要加缓冲 / 改路径（最短路径太短）

### 3.5.2 建立时间违反之后会发生什么？

按严重程度：

| 情况 | 后果 |
|------|------|
| D 在边沿附近仍在跳，但最后碰巧落在合法 0/1 | **本拍采到错误逻辑值**（静悄悄的功能 bug） |
| D 变化时刻落入触发器 **孔径 / 分辨窗口** | 进入 **亚稳态**（见下）：Q 长时间非 0 非 1，或随机落 0/1 |
| 下游当稳定电平用 | 后级门乱判、再放大成整条链路错拍 |

> Setup 违反 ≠「芯片烧掉」；= **这一拍采样不可信**。高频、跨时钟、异步输入时概率陡增。

Hold 违反：边沿刚过后 D 已被新组合结果污染 → 同样可能采错 / 进亚稳态；且 **降时钟频率通常救不了 hold**。

### 3.5.3 系统时序与最高频率

已知：组合关键路径 tp、FF 的 tsu / tpcq（时钟到 Q）等 → 算 **最大时钟频率**。

```
Tclk_min ≈ tpcq + tp_逻辑关键路径 + tsu   （再留裕量）
f_max = 1 / Tclk_min
```

直接限制 CPU/外设能跑多快。流水线把长组合切开，就是为了缩短每段 tp → 抬 f_max（→ CSAPP Ch4 / 本书 Ch7）。

### *3.5.3b 时钟偏移 Clock Skew（可选 · 高性能）

同一 CLK 到达不同触发器的时间差；高频下吃掉 setup/hold **裕量**。  
知概念即可；深挖留到看时钟树 / 板级高速时。

### 3.5.4 亚稳态 Metastability（值得深挖）

**何时：** 异步输入，或两时钟域交接，使 D 恰在采样边沿「中途」变化。  
**是何：** Q 既不是干净的 0 也不是干净的 1，在中间电压区 **悬着**；过一段时间才随机落到 0 或 1。

| 要点 | |
|------|--|
| 不能「设计成永不出」 | 只能 **把传到下游的概率压到极低** |
| 等待越久 | 退出亚稳态的概率越高（分辨时间） |
| 典型场景 | GPIO 异步按键、UART RX、网卡 DMA 与 CPU 不同源时钟、中断线 |

**和 Setup 的关系：** Setup/Hold 窗口 = 「保证不进亚稳态」的数字契约；窗口外跳变 → 契约作废 → 亚稳态风险。

### 3.5.5 同步器（嵌入式跨时钟域高频考点）

典型：**两级（或更多）触发器** 串起来采异步信号。

```
异步信号 → FF1 → FF2 → 同步域内使用
              ↑
         给 FF1 的亚稳态时间衰减；
         FF2 再采一次，下游看到坏电平的概率极低
```

注意：同步器 **减的是亚稳态传播概率**，不保证「第一拍就采到正确新值」（可能多等 1～2 拍）——协议上要按此设计。
