## 笔记

### 3.3.1 有问题的异步电路

无统一时钟 → 易振荡、难分析延迟、行为难预测。  
芯片设计 **禁止** 大规模乱异步。

### 3.3.2 同步时序标准范式（工业 / CPU 全采用）

✅ **定义：** 电路里 **所有触发器共用同一个全局时钟 CLK**。  
所有触发器只在 **同一个时钟边沿**（上升沿或下降沿）**统一更新状态**。

时钟 = 统一的「发令枪」：

```
时钟边沿 N：全体 FF 同时锁住当前 D → 更新 Q
    ↓
两个边沿之间：中间组合逻辑对 Q 并行运算（算下一拍的 D）
    ↓
时钟边沿 N+1：全体 FF 再同时锁住已稳定的结果
```

标准骨架：

1. **全局统一时钟** 驱动所有触发器  
2. 触发器输出 → **纯组合逻辑** → 下一级触发器输入  
3. 状态 **仅在时钟边沿** 更新  

ARM MCU、PC CPU 的通用设计标准（本书 HDL/FPGA 流程可跳，范式本身要）。

### 3.3.3 同步 vs 异步

| | 同步 | 异步 |
|--|------|------|
| 时序分析 | 易（约束清晰） | 极难收敛 |
| 稳定性 / 工具链 | 强 | 弱 |
| 用途 | **嵌入式 / PC CPU 主流** | 小众低功耗、局部特殊结构 |

❌ 异步：没有统一时钟，触发器靠信号互相触发 → 难分析、易不稳。  
✅ 工业芯片统一走 **同步时序**。

> **一句话：** 边沿之间随便（受控地）并行算；边沿上全体一起存 —— 这就是同步。
