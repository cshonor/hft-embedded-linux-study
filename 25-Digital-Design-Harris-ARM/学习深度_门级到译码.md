# 学习深度：门级 → 译码（HFT / Linux / CSAPP 路线）

> **目标：** Harris 数电 + CSAPP 体系结构 + 底层 / HFT 延迟直觉  
> **原则：** 分层吃透，不钻微电子工艺

## 三层边界

| 层 | 内容 | 态度 |
|----|------|------|
| **① 必须吃透（有边界）** | CMOS 搭 NOT / NAND / NOR；AND=NAND+NOT，OR=NOR+NOT | 看懂门级电路图与高低电平路径；知工业为何偏爱 NAND/NOR |
| **② 强烈建议** | 基础门 → 3–8 译码、MUX、全加器（**门级**原理） | 能从 74HC138 逻辑图推出真值表；打通最小项 ↔ 地址译码 ↔ 片选 |
| **③ 浅尝即可** | 译码器再拆成版图 / 每管连线；离子注入、μ、Vt 公式等 | **体系结构向不做**；工艺细节止步 |

**对已学 PN/CMOS 的纠偏：**  
[1.7](./ch01_binary/1.7_CMOS晶体管.md) 里 PN、互补开关、PUN/PDN **已经够用**。不要再往「半导体物理公式 / 工艺步骤」钻；底线是 **看得懂门怎么由管搭出**，不是做器件工程师。

## 学到什么程度算够（①）

1. CMOS 反相器：1P+1N，高低如何互锁输出  
2. 2 输入 CMOS NAND / NOR 拓扑（串并联对偶）  
3. 工业事实：芯片里优先 NAND/NOR（原生、管少、常更快）  
4. NAND（或 NOR）万能：可搭任意组合逻辑  

细节 → [1.5](./ch01_binary/1.5_逻辑门.md) · [1.7](./ch01_binary/1.7_CMOS晶体管.md)

## 学到什么程度算够（②）

拿 74HC138 内部逻辑图：

- 3 地址 → 原变量 / 反变量  
- 每一路 \(\overline{Y_i}\) 如何由与非（+ 使能）生成  
- 三个使能如何与进逻辑  
- 给你图能推出真值表  

门级表达式与结构 → [2.8](./ch02_combinational/2.8_组合逻辑模块.md)（内部门级专节）。  
地址高位 → 片选、低位 → 片内 → 同文件「内存片选」。

**表述修正：** 现代 CPU 不是「外挂无数颗 138」，而是存储控制器 / SoC 里**同类思想**的译码（最小项 / 地址译码阵列）。分立 138 是教学与板级最简模型。

## 明确不要做（③）

- ❌ 把译码器每个门再拆成版图级 CMOS 布线死背  
- ❌ 深挖载流子、耗尽层公式、光刻工艺链  

分界：

```
要：晶体管 → 基础门（NAND/NOR/NOT）
要：基础门 → 译码器 / MUX / 全加器（门级）
不要：译码器 → 再拆每颗管子的版图
```

## 学习链条（对路线）

```
CMOS 管 → 反相器 → NAND/NOR（万能）
    → 与/或/异或（NAND 拼）
    → 全加器、MUX、3–8 译码、比较器   ← 当前重点
    → ALU、寄存器、寻址 / 内存译码、总线时序
    → CSAPP：流水线、Cache、VM；HFT：路径延迟
```

## 为何门级值得看（收益）

看懂「门怎么拼成译码器」才能真正理解：

- 高位译码为何能片选  
- 组合逻辑为何有**传播延迟**  
- 路径越长、级数越多 → 延迟越大（HFT 敏感）  
- [2.9](./ch02_combinational/2.9_时序.md) **竞争冒险 / 毛刺**：多级延迟不同步 → 瞬时错误；只背器件功能很难直觉  

## 行动清单

1. 吃透 CMOS 反相器、2 输入 NAND/NOR（止于门级）  
2. 确认：任意组合可用 NAND 搭  
3. 按 [2.8](./ch02_combinational/2.8_组合逻辑模块.md) 梳一遍 138 内部门级式  
4. 顺带看 8:1 MUX 门级（与译码配套）  
5. **止步**，不钻晶体管物理 / 版图
