### 2.7.0 图为什么能化简？

合并律：只差一个变量的两项可并。

| | 公式 | 图上 |
|--|------|------|
| 最小项 | XY + X/Y = X | 相邻两格 **1** 圈一起 → 消掉 Y |
| 最大项 | (X+Y)(X+/Y)=X | 相邻两格 **0** 圈一起 → 消掉 Y |

**邻接条件：** 两格对应输入码 **恰好差 1 bit**（汉明距离 1）。  
所以行列标签用 **格雷码**（00-01-11-10），不是普通二进制 00-01-10-11——否则「几何相邻」≠「逻辑相邻」。

| ❌ | ✅ |
|----|-----|
| 行标写成 00,01,10,11 | 行/列用格雷：00,01,11,10 |
| 以为只有左右邻接 | **上下、左右、卷绕**（首尾相接、四角）凡差 1 bit 都算邻 |

### 2.7.1 怎么填、怎么圈、怎么读

#### 填图

1. 真值表 → 每个输入组合进一格（编号 i = 二进制下标）  
2. 格内写 F 的值：1 / 0 / X（无关）  
3. **圈 1 路线：** 盯所有 1（X 可当 1 用）  
4. **圈 0 路线：** 盯所有 0（X 可当 0 用）

#### 画圈规则

| 规则 | 说明 |
|------|------|
| 尺寸 | 1、2、4、8…（**2 的整数次幂**）个格 |
| 形状 | 矩形（含卷绕成的「环」） |
| 越大越好 | 圈越大 → 消掉的变量越多 → 项越简 |
| 全覆盖 | 每个目标格（1 或 0）至少进一圈；可重叠 |
| 少圈 | 在覆盖前提下圈数尽量少（对应项数少） |

#### 读圈（圈 1 → 与项）

看圈内 **哪些变量取值不变**：

- 某变量在圈内 **始终为 1** → 与项里写原变量  
- **始终为 0** → 写反变量 /A  
- **有 0 有 1** → 该变量被消去，不出现  

各与项再 **相或** → 最简（或较简）SOP。

#### 读圈（圈 0 → 或项）对偶

- 圈内某变量 **始终为 0** → 或项里写原变量（使该项在这些点上能为 0）  
- **始终为 1** → 写反变量  
- 有 0 有 1 → 消去  

各或项再 **相与** → 最简 POS。  
合并细节、M2·M3 例 → [2.2.5](./2.2_布尔表达式.md)。

### 2.7.2 变量数与图的样子（要会画）

#### 二变量（2×2）

```
       B
     0   1
A 0  m0  m1
  1  m2  m3
```

（具体行列谁是 A/B 按教材习惯；关键是邻接 = 格雷。）

#### 三变量（常用 2×4）

行：A = 0 / 1  
列：BC 用格雷 **00, 01, 11, 10**

| A\BC | 00 | 01 | 11 | 10 |
|------|----|----|----|----|
| 0 | m0 | m1 | m3 | m2 |
| 1 | m4 | m5 | m7 | m6 |

注意：列上 **m2 在 m3 右边**（因 10 邻 11），不是按十进制 0,1,2,3 顺序排。

#### 四变量（4×4）

行 AB、列 CD 都用格雷 00,01,11,10。  
左右边、上下边、四角可卷绕邻接——四角四个 1 能圈成一项（消掉全部变量以外的……实际消掉两个变量，剩两变量与项，视具体哪四格而定）。

> 五变量以上：两张四变量图 + 「立体」邻接，或改用软件 / Quine–McCluskey；手算以 ≤4 为主。

### 2.7.3 路线对照（考试必分清）

| | **圈 1** | **圈 0** |
|--|----------|----------|
| 盯 | 格内 **1** | 格内 **0** |
| 每圈 | 一个 **与项** | 一个 **或项** |
| 圈与圈 | **相或** → SOP | **相与** → POS |
| 硬件骨架 | 与 → 或 | 或 → 与 |
| CMOS 适配 | 常再推气泡 → 与非阵列 | → 或非阵列 |

| ❌ | ✅ |
|----|-----|
| 圈 0 得到的项直接相加 | 圈 0：块间是 **与** |
| 只圈 1、从不看圈 0 | 0 很少时圈 0 往往更短 → [2.2.1b](./2.2_布尔表达式.md) |

**小例（三变量）：** 仅 m1、m3 为 1 → 两格相邻（差 B），圈成 F=/A·C（消 B）。  
仅 M2、M3 为 0 → 圈 0 得 F=A+/B（→ [2.2.5](./2.2_布尔表达式.md)）。

### 2.7.4 无关项 (Don't care) X

| 含义 | 用法 |
|------|------|
| 输入组合 **永不出现** | 可当 0 或 1，任选有利者 |
| 出现了但输出 **不关心** | 同上 |

**圈图策略：** 把 X 并进能 **放大圈** 的一侧；不需要覆盖的 X 可以不管（不必为 X 单独开圈）。

例：某格是 X，与两个 1 组成 4 格大圈 → 宁可把 X 当 1，换更简的与项。

---

### 2.7.5 和冒险 / 毛刺的接点（进阶一眼）

最简圈有时刚好停在「相邻 1 的边界」：输入跳变时，一圈刚灭、另一圈未亮 → **静态-1 冒险**（输出该保持 1，却闪 0）。  

消法之一：在卡诺图上 **加冗余圈**（多覆盖交界上的一对 1），用冗余与项搭桥。  
细节 → [2.9](./2.9_时序.md) · [2.8.9](./2.8.6_比较校验码制冒险.md)。

> 化简追求最少门；消毛刺有时要 **故意多一项**——又是面积 vs 时序权衡。

---

### 2.7.6 小结清单

1. 标签用格雷，邻接 = 差 1 bit（含卷绕）  
2. 圈尺寸 = 2 的幂；尽量大、尽量少、盖全  
3. 圈 1 → 与项相或；圈 0 → 或项相与  
4. X 用来撑大圈，不必强行覆盖  
5. 读完式 → [2.4](./2.4_从逻辑到门.md) 画门；要 NAND → [2.5 推气泡](./2.5_多级组合逻辑.md)

> **一句话：** 卡诺图 = 把「相邻合并」画出来；圈 1/圈 0 是两条对偶硬件路径，不是两种无关玩法。
