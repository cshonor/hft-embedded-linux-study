### 5.4.0 寄存器堆

CPU **GPR** 的硬件 ≈ 多端口寄存器堆（常为多端口 SRAM）。

| 要点 | |
|------|--|
| 端口 | 典型两读一写 |
| 通路 | 读出 → ALU → 写回 |
| 软件 | 你看到的 R0–R14/PC（AArch32） |

### 5.4.1 计数器

```
寄存器 ← ±步进 ← 时钟沿；可复位
```

| 硬件 | 软件近亲 |
|------|----------|
| 定时器、波特率分频、DMA 地址计数 | `jiffies`、hrtimer、PWM 周期 |

读手册：自由运行计数器、比较匹配、溢出中断 —— 都是计数器积木。

### 5.4.2 移位寄存器

串↔并：UART/SPI 移位出字节。  
DFT 扫描链：测试用，驱动开发可忽略。

### 5.4.3 FIFO

| 要点 | |
|------|--|
| 结构 | 双端口存储 + 读/写指针 + 满/空 |
| 用途 | CPU↔外设、跨时钟域弹性缓冲 |
| Linux | UART/网络环形缓冲、kfifo、DMA 描述符环 —— **同构思想** |

跨时钟：指针常格雷码 + 同步（→ [3.5](../ch03_sequential/3.5_时序逻辑电路的时序.md)）。  
驱动：空/满要查状态寄存器；勿在硬中断里死等满。

### 5.4.4 外设寄存器（配置空间）

手册里的 CTRL/STATUS/DATA —— 对软件是 **MMIO 寄存器**；硬件上就是带译码的寄存器堆/阵列。  
`readl`/`writel` ↔ LDR/STR 到 Device 属性地址（→ [8.4](../ch08_memory/8.4_虚拟存储器.md)）。

> **一句话：** 堆=CPU 临时仓；计数器=节拍；移位=串口皮肉；FIFO=速率/时钟缓冲；MMIO=给软件看的寄存器窗口。
