## 笔记

把触发器拼成 **可直接上数据通路 / 外设** 的块。

### 5.4.0 寄存器堆 (Register File)

ARM 里存临时数据的 **通用寄存器组（GPR：R0–R14、PC 等，视架构）** 硬件形态 ≈ **多端口寄存器堆**：

| 要点 | |
|------|--|
| 结构 | 一排寄存器 + 译码选路；常实现为 **多端口 SRAM**（→ [5.5](./5.5_存储器阵列.md)） |
| 典型端口 | 两读一写（一拍内读两个操作数、写回一路） |
| 在通路中 | 读出 → ALU/移位 → 写回堆 |

> 逻辑角色在本节；存储单元技术（6T SRAM）在 5.5 —— 同一零件两个视角。

### 5.4.1 计数器

结构直觉：

```
寄存器 ← 加法器(当前值 ± 步进) ← 时钟沿更新；可带复位
```

每拍递增/递减；嵌入式里常见：**定时器、波特率分频、地址计数**。

### 5.4.2 移位寄存器

多个触发器**串联**：每时钟沿数据移一位。

| 用途 | 说明 |
|------|------|
| 串→并 / 并→串 | UART、SPI 数据通路常见 |
| **扫描链（Scan chain）** | 测试时把内部 FF 串成链，可观察/注入状态（DFT） |

对照 Ch3：仍是边沿触发寄存器，只是拓扑变成「串行流水」。

### 5.4.3 FIFO（先进先出缓冲）

| 要点 | |
|------|--|
| 结构 | 双端口存储 + 写指针/读指针（常再加满/空标志） |
| 用途 | **处理器 ↔ 外设**、两时钟域之间的 **弹性缓冲** |
| 为何常用 | 生产与消费速率不同、或跨异步时钟时，避免握手丢数 |

跨时钟时指针往往要 **格雷码 + 同步器**（接 [3.5 亚稳态](../ch03_sequential/3.5_时序逻辑电路的时序.md)）——知概念即可。

> **一句话：** 寄存器堆 = CPU 临时仓库；计数器/移位 = 外设常用件；FIFO = 异步/速率匹配缓冲。
