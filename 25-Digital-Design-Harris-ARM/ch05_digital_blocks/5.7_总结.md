## 笔记

### 本章带走

1. **算术：** 半加/全加 → 行波/先行/前缀；补码减法；比较；ALU + **NZCV**；移位；乘除很贵。  
2. **数制：** 补码与溢出语义；定点 vs IEEE 浮点（含 0 / ∞ / NaN）。  
3. **时序积木：** **寄存器堆**、计数器、移位寄存器、**FIFO**。  
4. **存储：** wordline/bitline；**SRAM≈Cache/堆 · DRAM≈主存 · ROM/Flash≈固件**；阵列可当 LUT。  
5. **逻辑阵列：** PLA → PAL → **FPGA**（按需；非软件主线可浅）。

### 串成数据通路雏形

```
寄存器堆（5.4/5.5）
    → ALU / 移位 / 比较（5.2）+ 数制语义（5.3）
    → 写回堆 或 经总线 ↔ FIFO（5.4）↔ 外设
    → 更大数据：Cache SRAM / 主存 DRAM / Flash（5.5）
```

控制（译码、FSM、流水线）在 Ch6–7 补齐；零件已经在本章。

### 折中贯穿

行波 vs 前缀加法器、DRAM vs SRAM、硬连线 vs FPGA —— 同一功能不同面积/延迟/功耗点。
