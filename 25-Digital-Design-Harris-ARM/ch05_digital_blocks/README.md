# 第5章 数字构建模块

> **定位：** 把 Ch1–3 的组合 / 时序落地成 CPU 里可复用的 **标准零件**；Ch7 用它们拼微处理器数据通路。  
> **桥梁：** 门与触发器 → 标准化大模块 → 面积 / 速度 / 功耗折中。  
> **HDL (Ch4)：** 可跳；本章按 **黑盒端口 + 硬件直觉** 读即可。

**一句话：** 算术 ALU · 数制 · 寄存器堆/计数器/FIFO · SRAM/DRAM/ROM ·（可选）PLA→FPGA —— 串起来 ≈ 简易 ARM 数据通路雏形。

**对你两条线：**

| 路线 | 作用 |
|------|------|
| **嵌入式 Linux** | 计数器、移位寄存器、FIFO、片上 SRAM / Flash；对照寄存器手册 |
| **HFT** | ALU/移位关键路径；**SRAM 寄存器堆**；主存 DRAM 延迟量级；（若走加速卡再精读 FPGA） |
