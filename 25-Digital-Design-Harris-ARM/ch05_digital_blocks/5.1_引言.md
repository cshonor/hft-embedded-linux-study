## 笔记

**数字构建模块：** 前面组合逻辑、时序逻辑的知识，落地成处理器里能直接复用的「标准零件」。

| 小节 | 模块族 | ARM / 系统里像什么 |
|------|--------|---------------------|
| [5.2](./5.2_算术电路.md) | 加法器族、比较器、移位器、**ALU** | 执行级运算与分支条件 |
| [5.3](./5.3_数制系统.md) | 补码、定点、浮点、溢出 | 减法变加法、运算异常、浮点基础 |
| [5.4](./5.4_时序电路模块.md) | **寄存器堆**、计数器、移位寄存器、**FIFO** | GPR；定时/串口；与外设缓冲 |
| [5.5](./5.5_存储器阵列.md) | ROM / **SRAM** / **DRAM** | 固件；Cache/片上；主存 → 内存管理 |
| [5.6](./5.6_逻辑阵列.md) | PLA → PAL → FPGA | 硬核之外的可定制逻辑（按需） |

**黑盒视角：** 先关心端口与功能（加什么、存多少、延迟量级），内部实现按需下钻——和第7章搭 CPU 的方式一致。

```
寄存器堆 ──► ALU / 移位器 ──► 写回寄存器堆
    │              ▲
    │         比较 / Flags → 分支
    └──── 访存路径 → Cache(SRAM) / 主存(DRAM)
```

串起来 ≈ **简易 ARM 处理器数据通路雏形**（控制还要 FSM / 译码，见 Ch6–7）。
