# 1.7g 硅片上怎么做 CMOS：N阱工艺

> 拆自 [1.7_CMOS晶体管.md](./1.7_CMOS晶体管.md) · 内容完整保留

### 4. 硅片上怎么做 CMOS：N阱工艺全流程

> **最重要一句：** CMOS **不是一种晶体管**，是「同一块硅片同时造出 NMOS + PMOS」；核心解法 = 在整块 **P型衬底**上局部改造出一块 **N阱** 放 PMOS。

#### 收口定型（你现在理解正确）

1. 基底原材料：整块 **P-Sub（P型硅衬底）**  
2. 离子注入+退火 → **局部一小块**改造成 N型硅 = **N阱（N-well）**  
3. **PMOS 制造在这块人工 N阱里面**（N阱 = PMOS 需要的 N型衬底 / Body）

复习 PMOS 原生要求：Body=N；S/D=P+；P+↔N阱接触面 = PN结。

| 电位（防漏电） | |
|----------------|--|
| 外围原生 **P衬底** | → **GND**（给 NMOS） |
| 内部人工 **N阱** | → **VDD**（给 PMOS） |

→ 相关 PN结 **永久反偏**，不导通漏电。

```
┌────────────────────── 整片 P衬底 ──────────────────────┐
│  ← NMOS（直接长在 P 上）│ ████████ N阱（人工N硅）████ │
│  N+S        N+D         │ █ PMOS 做在阱内           █ │
│                         │ █ P+S          P+D       █ │
│                         │ ██████████████████████████ │
└────────────────────────────────────────────────────────┘
```

> **一句话：** P衬底上造独立 N阱，**N阱充当 PMOS 的 N型衬底**；外面原生 P 做 NMOS → 同片两种基底 → 才能搭 CMOS。

**易混补一句：** N阱 **只是一块 N型基底，N阱本身不是 PMOS**。  
还要在阱内注入 P+ 源漏 + 栅氧 + 多晶硅栅，才是完整 PMOS。  
同理：外面 P衬底 ≠ NMOS，必须再注入 N+ 源漏才形成 NMOS。

#### N阱 vs 原生整片 N衬底（功能等价，物理不等同）

**结论：** 功能上 **等价于** PMOS 需要的 N衬底；但 **≠**「原生整块 N衬底晶圆」——是 **局部人造、有限范围** 的 N型区域。

| | **相同（你最关心）** | **不同（不能划等号）** |
|--|----------------------|------------------------|
| | 阱内晶格整体呈 **N型**（多子电子）→ 可当 PMOS 的 **Body**；满足 Body=N、S/D=P+ | **原生 N晶圆**：整片从头到尾全是 N；**N阱**：大 P衬底里 **局部** 改成 N，四周·底部被 P包围 |
| | | 阱 ↔ 外围 P → 天然一个 **巨大 PN结** |

**硬性规则（防这个大结正向漏电）：**

| | |
|--|--|
| ✅ N阱 | 持续接芯片 **最高电压 VDD** |
| ✅ 外层 P衬底 | 持续接 **最低电压 GND** |

→ 阱–衬底 PN结始终 **反偏**，耗尽层隔离 → 电学上 N阱近似一块 **独立 N衬底**。

**为何接 VDD/GND 就是反偏？（接 PN结零偏知识）**  
扩散后内建电场方向是 **N→P**（N正、P负）。N阱=高、P衬底=低 → 外加场与内建场 **同向** → 反偏加宽耗尽层、隔离漏电。详见 [补充_PN结 · 标准答案速记](./补充_PN结.md)。

> **极简：** 电学上充当 PMOS 的 N衬底；物理上只是被 P 包围的 **局部 N型孤岛**，不是独立整片 N晶圆。  
> 外面大片 P = NMOS 天然 P衬底；内部孤岛 N阱 = PMOS 人造 N衬底 → 一块 P晶圆即可 CMOS。

#### 同片无数管：反相器 vs 与非门，衬底规则一样

**三句结论：**

1. **一块硅片**上可做 **无数** NMOS、PMOS。  
2. 标准 CMOS：**N 与 P 不能共用同一导电类型衬底** —— N 在 P-sub，P 必须在 **N阱**。  
3. 反相器（1N+1P）、二输入与非（2N+2P）遵守 **同一套版图规则**；同门内多管共衬底/共阱，差别在数量与金属串并联。

| 谁 | 放哪 | 共享范围 |
|----|------|----------|
| **NMOS** | 整片 **P-sub** | 全芯片 N 都在这片基底上（有源区隔离，电气独立） |
| **同门内 PMOS** | **一块** N阱 | ✅ 同单元多只 P **共阱**（省面积） |
| **不同门的 PMOS** | **各自** N阱 | ❌ **不**把多门 P 塞进同一大阱（标准单元约定） |
| ❌ | PMOS 直接做在 P-sub 上 | 禁止 |

**偏置：** P-sub→GND；**每一块** N阱→VDD。

| 门 | P-sub 上 | 该门专属 N阱内 | 金属连线 |
|----|----------|----------------|----------|
| 反相器 | 1×NMOS | 1×PMOS | 两漏共输出、两栅共输入 |
| 2 输入与非 | 2×NMOS（**串联**） | 2×PMOS（**并联**） | 串/并路径不同，**阱规则不变** |

#### 门间：一单元一阱（版图铁律）

例 \(F=\overline{\overline{AB}\cdot\overline{CD}}\) → **3 个独立与非门**：

| 单元 | P-sub | N阱 |
|------|-------|-----|
| 门1 \(\overline{AB}\) | 2 N | **阱①**：2 P |
| 门2 \(\overline{CD}\) | 2 N | **阱②**：2 P（另一孤岛） |
| 门3 \(\overline{Y_1 Y_2}\) | 2 N | **阱③**：2 P |

底层 P-sub 连通；三块 N阱是互相隔离的孤岛。  
**标准单元库：** 一个标准单元 = 一个逻辑门 = **自带专属 N阱**；单元间物理隔离，减串扰/噪声/时序偏差。

> 拓展：布局上偶见相关门合并阱，但 **数字标准单元库不会这么做**；基础学习记住 **一单元一阱**。

**别混：**

| 概念 | |
|------|--|
| **硅衬底 / 晶圆** | 整片底层共用的 P-sub；所有 NMOS 建在其上 |
| **N阱** | 局部隔离区；**一门一阱**（同门多 P 共阱；异门分阱） |

> **一句话：** 同门所有 PMOS → 共一块 N阱；不同逻辑门 → **独立、隔离的不同 N阱**；所有 NMOS 在同一 P-sub 上但有源区隔离。

#### 架构 vs 工艺：别把两层焊死

**大方向对：** 课堂默认的 **P-sub + N-well（单阱）** 是最经典实现；反相器/与非/或非全复用：N 在 P-sub、同门 P 共阱、P-sub=GND、阱=VDD。

**但 CMOS ≠「全世界只有 P衬底+N阱」！**

| 层 | 是什么 | 和工艺关系 |
|----|--------|------------|
| **上层：CMOS 架构** | PUN(PMOS)+PDN(NMOS)、上下互斥 | **与用哪种阱无关**；满足互补规则就是 CMOS 逻辑 |
| **下层：N阱工艺** | P 基底上造 N阱放 PMOS | 解决「PMOS 不能直接做在 P 硅上」的 **物理制造** 问题 |

❌ CMOS 架构 ≠ P-sub+N-well  
✅ **P-sub+N-well = 落地 CMOS 架构的一种成熟手段**（教学默认）

**其他制造方案（了解）：**

| 工艺 | 做法 | 备注 |
|------|------|------|
| **N-sub / P-well** | N 基底；P 直接做在 N 上；N 管放 **P阱** | 对偶工艺，教学少提 |
| **双阱 Dual-well** | 同时独立 P阱+N阱；N 在 P阱、P 在 N阱 | **先进芯片主流**；可独立调管特性、抑噪声；CPU/FPGA 常见 |

**教学场景：** 可默认固定用单阱：改门 = 改管数 + 金属串并，基底规则不变。

**串联链：** 布尔 → 与非/或非门 → CMOS 互补拓扑 → **P-sub+N-well 版图** → 流片。

#### 再分一层：面包板电路 vs 硅片集成电路

| | 初高中物理电路 | **CMOS 芯片内部** |
|--|----------------|-------------------|
| 形态 | **分立元件**：开关、电阻、电源是独立零件 | MOS **不是**可拆零件；光刻/掺杂/金属 **一次刻进硅片** |
| 连线 | 导线临时接，可拔可改 | 金属互连 **出厂写死**，不能像面包板重接 |
| 比喻 | **乐高**，拆开再拼 | **注塑模型**，内部一体固化 |
| 「开关」 | 机械开关，手扳 | MOS = **电控开关**（栅压控通断），无形、无机械结构 |

设计顺序：布尔 → 管数与串并 → 画版图（阱/摆管/金属）→ 光罩流片 → **拓扑永久固定**。

> **一句话：** 分立 = 先有零件再自由连线；IC = 管与布线一起造进硅，内部接线不可硬件改。  
> **例外：** FPGA 片内有大量预制管 + **可编程互连**，上电可配逻辑；普通与非门芯片、CPU 数据通路多为布线固化。

#### 隔离逻辑一次性打通（PN结 → N阱 → CMOS）

把零偏 PN结知识串进整片 CMOS：

**① 结构回顾**

| | |
|--|--|
| 整片基底 | **P-Sub（P区）** |
| 局部孤岛 | **N阱（N区）** |
| 接触面 | 一个 **巨大 PN结**（P侧=衬底，N侧=阱） |
| 内建电场 | **N阱 → P衬底**（N正、P负） |

**② 规定接法 → 让大结反偏 → 隔离**

| 谁 | 接 | 目的 |
|----|-----|------|
| P-Sub | **GND（最低）** | |
| N阱 | **VDD（最高）** | |

外加：N阱电位 > P衬底 → 外电场 **N阱 → P衬底**，与内建场 **同向** → **反向偏置**。  
效果：耗尽层变宽，几乎无载流子流过 → **N阱电学上成独立孤岛**，与外围 P 隔离。

**③ 孤岛内外各自放管；源漏小结也要反偏**

| 位置 | 放什么 | Body | S/D | 小 PN结 | 电位保证 |
|------|--------|------|-----|---------|----------|
| 外侧 P-Sub | **NMOS** | P-Sub | N+ | N+ ↔ P-Sub | P-Sub=GND → 小结 **反偏截止** |
| N阱孤岛内 | **PMOS** | N阱 | P+ | P+ ↔ N阱 | N阱=VDD → 小结 **反偏截止** |

**④ 连贯背诵链**

1. N区电子向 P区扩散 → 耗尽层；内电场 **N→P**  
2. P衬底 + 内嵌 N阱 → 大 PN结  
3. P衬底=GND、N阱=VDD → **反偏隔离**  
4. 外面 P 做 NMOS，阱内做 PMOS  
5. 金属按互补连线 → **CMOS 电路**（典型：反相器）

**⑤ 文字剖面（电位 + 结）**

```
VDD ───────────────────────────────────────────────► 接 N阱、PMOS 源
GND ───────────────────────────────────────────────► 接 P-Sub、NMOS 源

────────────────────────── P-Sub (=GND) ──────────────────────────
│ 【NMOS】                         │ ████ N阱 (=VDD) ████████████ │
│  N+S        N+D                  │ █  P+S        P+D          █ │
│   ▲          ▲                   │ █   ▲          ▲           █ │
│   └──小PN结──┘（反偏）            │ █   └──小PN结──┘（反偏）    █ │
│                                  │ █                           █ │
│         ▲                        │ █         ▲                 █ │
│         └── 大PN结 / 耗尽层（反偏加宽）──┘                       │
└────────────────────────────────────────────────────────────────┘
```

**⑥ 关键风险：闩锁（Latch-up）**

P衬底、N阱、N+、P+ 层层嵌套 → 寄生出 **可控硅 SCR** 结构。  
电压异常时，原本反偏的结被 **正向导通** → VDD 直通 GND 大电流 → 芯片可烧毁。  
版图对策：**保护环** + 严格保持 P-Sub=GND、N阱=VDD；先进工艺常用 **双阱** 进一步抑闩锁。

#### 核心矛盾（为何需要阱）

| 管子 | 需要的衬底 |
|------|------------|
| **NMOS** | **P型衬底** |
| **PMOS** | **N型衬底** |

初始原料：整片晶圆 = **P-Sub**。  
✅ NMOS 可直接做在此；❌ PMOS 不能直接做在原生 P 上 → 必须人工造 **N阱**。

---

#### 步骤 1：制造 N阱（最关键！解决衬底矛盾）

1. 硅片表面长一层 SiO₂  
2. 光刻+刻蚀，只打开要做 PMOS 的窗口  
3. **离子注入磷（N型杂质）**，高温退火向内扩散  
4. 窗口下形成独立 **N型区域 = N阱**

剖面：左边原生 P（放 NMOS）；右边人工 N阱（放 PMOS）。  
N阱与周围 P 形成大面积 PN结；工作时 N阱接 **VDD** → 该结 **反偏隔离**。

#### 步骤 2：器件隔离（场氧 / STI）

管与管之间隔开，防漏电、寄生管。  
不做管的区域长厚 SiO₂（场氧）或挖沟槽填介质（STI），阻断寄生沟道；  
只留 NMOS、PMOS 所在区域 = **有源区**。

#### 步骤 3：栅氧 + 多晶硅栅极 G

1. 有源区高温生长极薄高质量 SiO₂（**栅氧**，绝缘，栅与硅隔开）  
2. 淀积多晶硅，光刻刻出栅线条 → 即 **栅极 G**  

> 多晶硅栅充当 **自对准掩膜**：后面注源漏时，栅底下不被掺杂，自动留出沟道区。

#### 步骤 4：分别掺杂两组 S、D

**① NMOS 区（P衬底上）**  
遮住 N阱，只开 NMOS 有源区；注入 **砷（N型）** → **N+ 源、N+ 漏**。  
栅挡住离子 → 栅下仍是纯净 P（未来 N沟道）。

**② PMOS 区（N阱内）**  
换掩膜遮住 NMOS；注入 **硼（P型）** → **P+ 源、P+ 漏**。  
栅挡住离子 → 栅下仍是纯净 N（未来 P沟道）。

至此两管结构成型：

| | NMOS | PMOS |
|--|------|------|
| 衬底 | 原生 P | **人工 N阱** |
| S/D | N+ | P+ |
| 栅 | 栅氧 + 多晶硅 | 同左 |

#### 步骤 5：接触孔 + 金属布线（连成 CMOS 反相器）

1. 整片再覆绝缘 SiO₂  
2. 光刻接触孔，扎到 S/D、栅、衬底、N阱  
3. 淀积铝/铜，光刻出导线，按反相器接线：

| 连线 | |
|------|--|
| PMOS 源 → **VDD** | NMOS 源 → **GND** |
| 两漏短接 → **OUT** | 两栅短接 → **A** |
| **P衬底 → GND** | **N阱 → VDD**（防结正向漏电） |

#### 步骤 6：钝化保护

覆 SiO₂/氮化硅保护层，只露焊盘 → 晶圆完成，再切割封装。

| 问 | 答 |

| 谁 | 接哪里 |
|----|--------|
| 整片 P-Sub | **GND（最低）** |
| N阱 | **VDD（最高）** |

#### 拓展：双阱（了解）

先进工艺同时做 **N阱（PMOS）+ P阱（NMOS）** → 衬底电位可独立调，抑闩锁；CPU/FPGA 常见。  
与上文「架构 vs 工艺」一致：双阱仍是 **实现 CMOS 架构** 的制造方案，不是另一种逻辑思想。  
闩锁细节见「隔离逻辑 · ⑥」；对策仍是保护环 + 正确电位。

软件 / CSAPP / HFT：记住 **「P 上 N管、阱里 P管」+ 衬底接地阱接电源 + 金属连成互补**；光刻步序知概念即可。
