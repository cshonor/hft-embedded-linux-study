# 2.2 按位拷贝 vs 逐成员拷贝

> 第 2 章 · 上一节：[2.1 合成默认构造](01-synthesized-default-ctor.md) · 下一节：[2.3 成员初始化列表](03-init-list.md)

## 这节讲什么

拷贝构造默认是按位拷贝（逐字节复制）。只有当类含四种情况之一时，编译器才合成逐成员拷贝。按位拷贝对含指针的类是灾难。

---

## 两种拷贝

- **按位拷贝（bitwise copy）**：逐字节 `memcpy`——默认行为
- **逐成员拷贝（memberwise copy）**：调用各成员/基类的拷贝构造——编译器合成

按位拷贝仅在类是"平凡可拷贝"时安全。含指针的类按位拷贝 = 浅拷贝 → 双重释放：

```cpp
class Bad {
    int* data;
public:
    Bad() : data(new int[100]) {}
    // 没写拷贝构造 → 按位拷贝 → 两个对象指向同一块内存 → double free！
};
```

---

## 新手要点（和 C 的区别）

- **C 的结构体赋值就是按位拷贝**：C 的 `struct A b = a;` 就是 `memcpy`。对含指针的结构体也有同样的浅拷贝问题——C 程序员应该熟悉这个坑。
- **C++ 的"大三律"**：如果你需要手写析构/拷贝构造/拷贝赋值中的任何一个，你就需要写全部三个。这是 C++ 对 C 的改进——让编译器帮你管理。

---

## HFT 关联

- **POD 可安全 memcpy**：POD 类型按位拷贝是安全的——这是 HFT 热路径数据结构用 POD 的原因。
