# 1.1 对象模型的三个规则

> 第 1 章 关于对象 · 上一节：[本章导读](README.md) · 下一节：[1.2 虚函数与 vptr](02-vptr-vtable.md)

## 这节讲什么

C++ 对象在内存里到底长什么样？三条规则决定了 `sizeof` 的结果——哪些在对象内，哪些不在。

---

## 三条规则

1. **非静态数据成员**：在对象内部（占用对象空间）
2. **静态数据成员**：在对象外部（全局/静态区，唯一一份）
3. **成员函数**（静态/非静态）：在对象外部（代码段），对象只存数据

```cpp
class Point {
    int x, y;          // 在对象内
    static int count;  // 在对象外（全局/静态区）
    void draw();       // 在对象外（代码段）
};
// sizeof(Point) = 8（两个 int），不含 count 和 draw
```

---

## 新手要点（和 C 的区别）

- **C 的 struct 只有数据**：C 的结构体就是数据的集合，`sizeof` 等于各成员 + padding。C++ 的 class 可以有函数，但函数不在对象里——对象只存数据。
- **空类的 sizeof 是 1**：`class Empty {};` 的 `sizeof` 是 1（不是 0），为了让两个对象地址不同。C 程序员常觉得这很奇怪。
- **static 成员全局唯一**：`Point::count` 不占任何对象的内存，所有对象共享一份。

---

## HFT 关联

- **sizeof 影响 cache**：对象大小直接决定一个 cache 行（64B）能装几个对象。`vptr` 让对象多 8 字节，可能让每行对象数减半。
