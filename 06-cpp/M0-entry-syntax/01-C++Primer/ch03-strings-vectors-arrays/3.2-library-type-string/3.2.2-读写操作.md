# 3.2.2 读写操作

## 本节讲什么

`string` 的输入输出：`cout <<`、`cin >>` 与 `getline` 的分隔规则，以及 HFT 里结构化字段 vs 整行备注的选型。

## 输出

```cpp
std::string msg = "order sent";
std::cout << msg << std::endl;
```

## 输入：`>>` vs `getline`

**统一规则**：`>>` 把**任意数量、连续**的空白符（空格、换行 `\n`、制表符 `\t` 等）都当作**分隔符**——开头、中间、结尾的空白都会被**跳过**，只依次取出非空白字段。`getline` **逻辑相反**：不跳过开头/中间空白，只在**换行**处停止，换行前的字符（含空格、Tab）**原样**存入 `string`。

| 方式 | 停止条件 | 空白处理 | 典型场景 |
|------|----------|----------|----------|
| `cin >> s` | 遇**任意空白**即停 | **跳过**所有连续空白（前/中/后当分隔符） | 结构化字段：订单号、价格、数量 |
| `getline(cin, s)` | 仅遇**换行 `\n`** 才停 | **保留**开头与中间空格、Tab | 带空格备注、整行日志 |

### 同一行输入，两种读法对比

假设键盘输入（`·` 表示空格）：

```
···hello···world⏎
（3 个前导空格 + hello + 3 个中间空格 + world + 回车）
```

| 读法 | 结果 |
|------|------|
| `cin >> w1 >> w2` | `w1="hello"`, `w2="world"`（前后、中间空白全当分隔符忽略） |
| `getline(cin, line)` | `line="···hello···world"`（前导与中间空格**全部保留**） |

简单输入 `"hello world"` + 回车，`cin >> word1 >> word2` 同样得到 `"hello"` / `"world"`。

### 常见误解：`cin >>` 是不是不按回车就会一直读？

**不是。** 碰到**空白符**就停；回车只是产生换行空白的一种。剩余内容留在**输入缓冲区**，供下一次 `>>` 使用：

```
键盘输入:   [空格空格] hello world [回车]
            ─────────────────────────────► 输入缓冲区

第 1 次 cin >> word1:
  跳过开头所有空白 → 读 "hello" → 遇空格停止
  缓冲区剩余: " world\n"

第 2 次 cin >> word2:
  跳过空白 → 读 "world" → 遇换行停止
```

### HFT：结构化订单流 vs 带空格备注

**`cin >>` —— 逐字段拆分**（每行空格分隔，中间多个空格也会自动合并跳过分隔）：

```cpp
// 输入一行:  OID1001  3750.5  10   （字段间可有多个空格）
std::string order_id;
double      price = 0;
int         qty   = 0;

std::cin >> order_id >> price >> qty;
// order_id == "OID1001", price == 3750.5, qty == 10
// 不必自己写循环跳过多个空格
```

适合：测试单、回放文件里**固定列**的订单流（订单号 / 价格 / 数量）。

**`getline` —— 保留空格的全文**：

```cpp
// 备注: "urgent  buy IF2406"（含多个空格）
std::string remark;
std::getline(std::cin, remark);   // 整行原样，直到回车
```

适合：带格式的**日志行**、带空格的**订单备注**、人工可读说明。

```
结构化字段（空格当分隔）  →  cin >>
保留空格的全行文本        →  getline
```

### `>>` 与 `getline` 混用注意

`cin >> n` 后若直接 `getline(cin, line)`，可能读到**空行**——因为 `>>` 留下行尾的 `\n` 在缓冲区里。常见写法：

```cpp
int qty;
std::string remark;
std::cin >> qty;
std::cin.ignore();              // 吃掉 >> 留下的换行
std::getline(std::cin, remark);
```

```cpp
std::string word, line;
std::cin >> word;
std::getline(std::cin, line);   // 读同一行剩余，或下一整行（视缓冲区而定）
```

## 和 C 的区别

string 的 IO 对应 C 的字符串读写，但类型安全得多：

| 对比点 | C | C++ |
|--------|---|-----|
| 读单词 | `scanf("%s", buf)` 怕越界 | `cin >> s` 自动管理 |
| 读整行 | `gets(buf)`（已废弃，危险）/ `fgets` | `getline(cin, s)` 安全 |
| 输出 | `printf("%s", s)` | `cout << s` |

**给 C 程序员的关键提醒：**
1. `gets()` 在 C11 被正式删除（缓冲区溢出漏洞），C++ 的 `getline` 是安全替代——不用担心越界。
2. `cin >> s` 不需要你提供缓冲区大小（不像 `scanf` 要保证 `buf` 够大），`string` 自动扩容。
3. `>>` 和 `scanf("%s")` 一样遇空白就停；`getline` 和 `fgets` 一样遇换行停，但 `getline` 不保留换行符（`fgets` 保留）。

## 常见错误

**1. `>>` 和 `getline` 混用读到空行**
`cin >> n` 后缓冲区留着 `\n`，直接 `getline` 会读到空行。用 `cin.ignore()` 吃掉换行。

**2. 以为 `cin >> s` 能读带空格的字符串**
`cin >> s` 遇空格就停，"hello world" 只读到 "hello"。要读带空格的整行用 `getline`。

## 自测题

**1（选择）** 输入 `  hello world  `（前后有空格），`getline(cin, s)` 的 `s` 是什么？
- A. `"hello world"`（去掉首尾空格）
- B. `"  hello world  "`（原样保留）

**2（判断）** C 的 `fgets(buf, n, stdin)` 和 C++ 的 `getline(cin, s)` 都保留换行符。

**3（踩坑）** 下面代码 `getline` 读到什么？
```cpp
int n;
std::cin >> n;
std::string line;
std::getline(std::cin, line);
```

<details><summary>参考答案</summary>
1. B。`getline` 保留开头和中间的空格、Tab，只在换行处停止。要去首尾空格要手动处理。
2. 错。`fgets` 会把换行符 `\n` 读进缓冲区（如果有空间）；`getline` **不保留**换行符，丢弃它。这是两者的一个差异。
3. 读到空行。`cin >> n` 后缓冲区留着 `\n`，`getline` 立刻遇到 `\n` 就停，`line` 为空。要先 `cin.ignore()` 吃掉换行。
</details>
