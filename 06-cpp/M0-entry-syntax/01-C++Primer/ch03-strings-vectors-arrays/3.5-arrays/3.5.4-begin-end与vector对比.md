# 3.5.4 begin/end 与 vector 对比

## 本节讲什么

C++11 对原生数组的 `begin`/`end`，以及内置数组 vs `std::vector` 的全面对比与现代 C++ 建议。

## std::begin / std::end（C++11）

原生数组**没有成员函数** `begin()`；标准库提供**全局模板**：

```cpp
#include <iterator>

int arr[] = {1, 2, 3};
auto first = std::begin(arr);   // &arr[0]
auto last  = std::end(arr);     // 尾后指针，不可解引用

for (auto it = std::begin(arr); it != std::end(arr); ++it)
    std::cout << *it << " ";
```

与 [3.4.2 `v.begin()`](../3.4-introducing-iterators/3.4.2-begin-end与常量迭代器.md) 语义一致，便于同一套循环写法对接第 10 章算法。

## 内置数组 vs std::vector

| 特性 | 内置数组 | `vector` |
|------|----------|----------|
| **大小** | 编译期固定，不可扩容 | 运行时动态增减 |
| **内存** | 局部多在**栈**（过大易栈溢出） | 元素多在**堆**，较安全 |
| **拷贝/赋值** | ❌ 不支持整体拷贝赋值 | ✅ 支持 `=`、拷贝构造 |
| **长度** | `sizeof(arr)/sizeof(arr[0])`；**传参后丢失** | `.size()` 始终可用 |
| **越界** | 无检查，UB | `.at()` 抛异常；`[]` 仍无检查 |
| **内存管理** | 栈自动释放；`new[]` 须 `delete[]` | RAII 自动析构 |
| **适用** | C 接口、固定尺寸底层、极热路径小缓冲 | **绝大多数业务首选** |

## 教材核心编程建议

1. 元素数量**不确定** → **`vector`**
2. 字符串 → **`std::string`**，不要 `char[]`（除非热路径固定缓冲，见 [3.2.4](../3.2-library-type-string/3.2.4-string与C风格字符串.md)）
3. 避免**裸指针 + 裸数组**组合 → 越界、泄漏、悬垂
4. 必须用数组时 → **`begin`/`end` 遍历**，少手写指针算术

## 和 C 的区别（std::begin/end 是 C++ 独有，让数组也能像容器遍历）

C 程序员遍历数组的标准写法是 `for (p = arr; p < arr + n; ++p)`，自己算 `arr + n`。C++11 引入 `std::begin`/`std::end` 让原生数组也能用"迭代器风格"遍历：

| 对比点 | C | C++ |
|--------|----|------|
| 取首 | `arr` 或 `&arr[0]` | `std::begin(arr)`（等价 `&arr[0]`） |
| 取尾后 | `arr + n`（自己算长度） | `std::end(arr)`（自动算） |
| 遍历 | `for (p=arr; p<arr+n; ++p)` | `for (it=begin(arr); it!=end(arr); ++it)` |
| 长度 | `sizeof(arr)/sizeof(arr[0])`（传参后失效） | `end(arr) - begin(arr)`（模板内有效） |
| 适配算法库 | 无统一接口 | `<algorithm>` 全部接受 begin/end |

**给 C 程序员的关键提醒：**
1. **`std::begin`/`std::end` 是模板函数**，能对原生数组和所有 STL 容器工作——同一套遍历写法对接第 10 章 `<algorithm>`（如 `std::sort`、`std::find`）。
2. **`std::end(arr)` 自动算"尾后指针"**，不用手写 `arr + N`。避免算错长度的坑。
3. **C++ 推荐用 `std::array` 替代裸数组**——`std::array<int, 5>` 有成员函数 `.begin()`/`.end()`/`.size()`，比 `std::begin(裸数组)` 更面向对象。

## 常见错误

### 1. 对已退化为指针的"数组"调 `std::end`

```cpp
void f(int* arr) {
    auto end = std::end(arr);   // ❌ 编译错误：arr 是指针不是数组
}
```

`std::end` 需要知道数组长度才能算尾后，**只对真正的数组类型生效**。传参后 `arr` 已退化为指针，`std::end` 无法工作。这是 C++ 比 C 安全的地方——编译期就拦住，不会算出错误的尾后指针。

### 2. 把 `std::begin(arr)` 当成"第一个元素的值"

```cpp
int arr[5] = {1,2,3,4,5};
int first = std::begin(arr);   // ❌ 类型不匹配，begin 返回指针不是 int
```

`std::begin(arr)` 返回**指针**（指向首元素），不是首元素的值。要值用 `*std::begin(arr)` 或 `arr[0]`。C 程序员对 `arr` 退化为指针很熟，但 `std::begin` 这个新名字容易让人误以为是"第一个元素"。

### 3. 数组 vs `vector` 选错

```cpp
int arr[100];   // ❌ HFT 启动配置读 100 个参数，数量运行时才知
```

数组大小**编译期固定**，运行时才知数量时硬写大数组浪费内存，写小了越界。**数量不确定用 `vector`**，数量确定且热路径敏感用 `std::array`（栈上，无堆分配）或内置数组。

## 自测题

**1. 选择题**　`std::begin(arr)` 和 `std::end(arr)` 对原生数组分别返回什么？

- A. 首元素的值 / 末元素的值
- B. 首元素的指针 / 末元素的指针
- C. 首元素的指针 / 尾后指针（末元素下一个位置）
- D. 首元素的引用 / 末元素的引用

<details><summary>答案</summary>

**C**。`std::begin(arr)` 等价 `&arr[0]`（首元素指针），`std::end(arr)` 等价 `&arr[N]`（尾后指针，指向末元素下一个位置）。语义和 `arr.begin()`/`arr.end()` 一致，半开区间 `[begin, end)`。

</details>

**2. 判断题**　`std::begin`/`std::end` 对 `std::vector` 和原生数组都能用。

<details><summary>答案</summary>

**对**。这是 C++11 引入 `std::begin`/`std::end` 的目的——统一原生数组和容器的遍历接口。`std::begin(v)` 等价 `v.begin()`，`std::begin(arr)` 等价 `&arr[0]`。同一套算法（`std::sort`、`std::find`）能同时处理两者。

</details>

**3. 踩坑题**　下面这段代码用 `std::begin`/`std::end` 遍历数组，为什么编译失败？

```cpp
void print(int arr[]) {
    for (auto it = std::begin(arr); it != std::end(arr); ++it)
        std::cout << *it << " ";
}
```

<details><summary>答案</summary>

**数组传参已退化为指针**，`arr` 在函数内是 `int*` 不是数组类型，`std::end(arr)` 无法算尾后（不知道长度），编译错误。

**修复**（三种）：

```cpp
// 方法 1：C 风格，另传长度
void print(int* arr, size_t n) {
    for (size_t i = 0; i < n; ++i) std::cout << arr[i] << " ";
}

// 方法 2：模板引用数组，保留数组类型
template <size_t N>
void print(int (&arr)[N]) {
    for (auto it = std::begin(arr); it != std::end(arr); ++it)
        std::cout << *it << " ";
}

// 方法 3：用 std::array 或 vector
void print(const std::vector<int>& v) {
    for (auto x : v) std::cout << x << " ";
}
```

C 程序员习惯了"另传 n"，C++ 推荐用容器或模板引用避开退化。

</details>

**4. 应用题**　用 `std::begin`/`std::end` 和 `std::find` 在原生数组中查找一个值。

<details><summary>答案</summary>

```cpp
#include <iostream>
#include <iterator>
#include <algorithm>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int target = 30;

    auto it = std::find(std::begin(arr), std::end(arr), target);
    if (it != std::end(arr))
        std::cout << "找到，下标 " << (it - std::begin(arr)) << "\n";
    else
        std::cout << "没找到\n";
}
```

要点：
- `std::find` 接受任意迭代器/指针范围，原生数组也能用
- `it - std::begin(arr)` 算下标（指针差 = 元素个数）
- 找不到返回 `end`，要先判断再用

C 等价是 `for (i=0; i<n; i++) if (arr[i]==target) break;`——C++ 用算法库更简洁、更通用。

</details>
