# 3.5.3 数组退化与指针

## 本节讲什么

**数组名自动退化为指针**的核心规则、三种不退化例外，以及 `&arr` 与 `&arr[0]` 的类型区别。

## 核心规则：数组退化（Decay）

**绝大多数表达式中**，数组名自动转换为**指向首元素的指针**：

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;        // 等价 int *p = &arr[0];

*arr == arr[0];      // true
arr + 1 == &arr[1];  // true
```

因此数组**传参进函数**时常退化为 `int*`，**丢失长度信息**——这是「必须另传 `size`」或改用 `vector` 的根源。

## 不会退化的 3 种例外（必考）

| 场景 | 行为 |
|------|------|
| **`sizeof(arr)`** | 整个数组的字节大小，不是指针大小 |
| **`&arr`** | 取**整个数组**的地址，类型 `int (*)[5]` |
| **用字符串字面量初始化 `char` 数组** | 按数组初始化规则，不退化为指针 |

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

sizeof(arr);    // 5 * sizeof(int)，如 20（int 为 4 字节）
sizeof(p);      // 指针大小，如 8（64 位）

&arr;           // int (*)[5]——指向「含 5 个 int 的数组」
&arr[0];        // int*——指向单个 int

// &arr 与 &arr[0] 地址**数值**常相同，但**类型不同**，指针算术步长不同：
// &arr + 1 跳过整个数组；&arr[0] + 1 跳过 1 个 int
```

## 与 [3.4 迭代器](../3.4-introducing-iterators/3.4-迭代器介绍.md) 的关系

退化后，`arr` 可当指针遍历；C++11 用 **`std::begin`/`std::end`** 更安全统一（见 [3.5.4](./3.5.4-begin-end与vector对比.md)）。

## 和 C 的区别（数组退化：C/C++ 规则一致，C++ 有更好替代）

数组退化（decay）是 C 和 C++ **共享**的规则——数组名在大多数表达式中退化为指向首元素的指针。C 程序员这部分无需转变，但 C++ 提供了更安全的替代：

| 对比点 | C | C++ |
|--------|----|------|
| 退化规则 | `int arr[5]; int *p = arr;` | 完全一致 |
| `sizeof(arr)` 不退化 | ✅ 得数组总字节 | ✅ 一致 |
| `&arr` 不退化 | ✅ 类型 `int(*)[5]` | ✅ 一致 |
| 传参退化 | `void f(int arr[])` 实为 `int*` | 完全一致 |
| 避免退化的替代 | 无（C 只有裸数组） | `std::array<T,N>` 不退化、`std::vector` 不退化 |

**给 C 程序员的关键提醒：**
1. **退化规则两边一模一样**——C 程序员的肌肉记忆直接用。`arr` 退化为 `&arr[0]`、传参丢长度、`sizeof` 不退化，这三条 C/C++ 共享。
2. **C++ 的"解药"是 `std::array` 和 `std::vector`**——它们有 `.size()` 成员，传参不退化、不丢长度。`std::array<int, 5>` 内存布局和 `int[5]` 完全一样，但接口安全得多。
3. **`&arr` 和 `&arr[0]` 的类型差异**是 C 和 C++ 共同的考点：`&arr` 是"指向整个数组的指针"（`int(*)[5]`），`&arr[0]` 是"指向首元素的指针"（`int*`）。`&arr + 1` 跳过整个数组，`&arr[0] + 1` 跳过一个元素。

## 常见错误

### 1. 函数内 `sizeof` 拿不到数组长度

```cpp
void f(int arr[]) {
    size_t n = sizeof(arr) / sizeof(arr[0]);   // ❌ arr 已退化为 int*，n = 8/4 = 2（不是数组长度）
}
```

数组传参时退化为指针，函数内 `sizeof(arr)` 是指针大小（如 8 字节），不是数组总字节。C 和 C++ 都有这个坑。**正确做法**：

- C 风格：另传长度参数 `void f(int* arr, size_t n);`
- C++ 风格：用 `std::array<int, N>&` 或 `std::vector<int>&`，自带 `size()`
- 用模板保留数组类型：`template<size_t N> void f(int (&arr)[N]);`（编译期推导长度）

### 2. 误用 `&arr + 1` 当"末元素 +1"

```cpp
int arr[5] = {1,2,3,4,5};
int* end = &arr + 1;        // 指向"下一个数组"，地址 = arr + 5
int* wrong = &arr[0] + 1;   // 指向 arr[1]
// 两者地址不同！
```

`&arr` 是"指向整个数组的指针"，`&arr + 1` 跳过**整个数组**（5 个 int），地址上等于 `arr + 5`（即尾后）。这其实是构造"尾后指针"的合法方式，但容易和 `&arr[0] + 1`（指向第二个元素）混淆。

### 3. 二维数组退化后用错指针类型

```cpp
int matrix[3][4];
int** p = matrix;   // ❌ 类型不匹配
```

`matrix` 退化为 `int(*)[4]`（指向"含 4 个 int 的数组"的指针），不是 `int**`。C 程序员也踩这个——二维数组和"指针的指针"是不同类型。正确：

```cpp
int (*p)[4] = matrix;   // ✅ 指向"含 4 个 int 的数组"
```

或用 C++ 的 `std::array<std::array<int, 4>, 3>` 避开这种复杂声明。

## 自测题

**1. 选择题**　`int arr[5];` 在下列哪种用法中**不会**退化为指针？

- A. `int* p = arr;`
- B. `void f(int arr[]); f(arr);`
- C. `sizeof(arr)`
- D. `arr + 1`

<details><summary>答案</summary>

**C**。`sizeof` 是数组不退化的三种例外之一（另两种是 `&arr` 和用字符串字面量初始化 `char` 数组）。A、B、D 都退化为 `int*`。

</details>

**2. 判断题**　`int arr[5]; int* p1 = &arr[0]; int (*p2)[5] = &arr;` 中 `p1` 和 `p2` 的地址数值相同，类型也相同。

<details><summary>答案</summary>

**错**。地址数值相同（都指向数组起始字节），但**类型不同**：`p1` 是 `int*`（指向单个 int），`p2` 是 `int(*)[5]`（指向整个数组）。`p1 + 1` 跳一个 int（4 字节），`p2 + 1` 跳整个数组（20 字节）。类型不同导致指针算术步长不同。

</details>

**3. 踩坑题**　下面这段代码想计算数组长度，问题出在哪？

```cpp
void process(int arr[]) {
    size_t len = sizeof(arr) / sizeof(int);
    for (size_t i = 0; i < len; ++i)
        std::cout << arr[i] << " ";
}

int main() {
    int data[5] = {1,2,3,4,5};
    process(data);
}
```

<details><summary>答案</summary>

**`sizeof(arr)` 在函数内是指针大小，不是数组大小**。若 64 位系统指针 8 字节、int 4 字节，`len = 8/4 = 2`，只打印前 2 个元素。

**修复**（三种）：

```cpp
// 方法 1：C 风格，另传长度
void process(int* arr, size_t n);

// 方法 2：C++ 模板，编译期推导数组长度
template<size_t N>
void process(int (&arr)[N]) {
    for (size_t i = 0; i < N; ++i) std::cout << arr[i] << " ";
}

// 方法 3：用 std::array 或 vector
void process(const std::array<int, 5>& arr);   // 自带 size
```

C 程序员习惯了"另传 n"，C++ 推荐 `std::array`/`vector` 或模板引用。

</details>

**4. 应用题**　写一个模板函数 `print_all`，能接受任意大小的一维数组并打印所有元素，**不依赖退化**。

<details><summary>答案</summary>

```cpp
#include <iostream>

template <typename T, size_t N>
void print_all(const T (&arr)[N]) {   // 引用数组，不退化
    for (size_t i = 0; i < N; ++i)
        std::cout << arr[i] << " ";
    std::cout << "\n";
}

int main() {
    int a[5] = {1,2,3,4,5};
    double b[3] = {1.1, 2.2, 3.3};
    print_all(a);   // 模板推导 T=int, N=5
    print_all(b);   // 模板推导 T=double, N=3
}
```

要点：
- `const T (&arr)[N]` 是"对数组的引用"，**不退化**为指针
- 模板参数推导自动得到 `N`，函数内 `N` 是编译期常量
- 比手写 `sizeof(arr)/sizeof(arr[0])` 更安全、更通用

C 没有这种能力——C 的数组传参必然退化，只能另传 `n`。

</details>
