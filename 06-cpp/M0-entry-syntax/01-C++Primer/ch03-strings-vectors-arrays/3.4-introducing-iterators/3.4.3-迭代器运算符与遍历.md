# 3.4.3 迭代器运算符与遍历

## 本节讲什么

迭代器必考运算符与全书通用的 `for` 遍历模板。

## 基础运算符（必考）

| 运算符 | 含义 |
|--------|------|
| `*it` | 解引用，得到所指元素的引用 |
| `it->成员` | 等价 `(*it).成员`，访问类/结构体成员 |
| `++it` / `it++` | 移到**下一个**元素（**前置 `++` 更高效**） |
| `--it` / `it--` | 移到**上一个**元素（`vector` / `string` / `list` 等支持；因容器而异） |
| `it1 == it2` / `!=` | 是否指向**同一位置** |

> **规范**：遍历一律写 **`it != v.end()`**，不要用 **`it < v.end()`**——链表等容器的迭代器**不支持** `<` 比较（随机访问迭代器才支持，见 [3.4.4](./3.4.4-随机访问算术运算.md)）。

### 前置 `++` vs 后置 `++`

```cpp
++it;   // ✅ 推荐：直接前移，无多余临时
it++;   // 后置会拷贝旧迭代器再前移，性能更差
```

## 标准遍历模板（全书通用）

```cpp
std::vector<int> v = {1, 2, 3};
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << std::endl;
}
```

只读版本：

```cpp
for (auto cit = v.cbegin(); cit != v.cend(); ++cit)
    std::cout << *cit << " ";
```

### `string` 同样适用

```cpp
std::string s = "hello";
for (auto it = s.begin(); it != s.end(); ++it)
    *it = static_cast<char>(std::toupper(static_cast<unsigned char>(*it)));
```

C++11 范围 for 等价于对 `begin`/`end` 的封装（见第 5 章）：

```cpp
for (int x : v) { /* ... */ }   // 底层即迭代器遍历
```

## 和 C 的区别（迭代器运算符 vs 指针运算）

C 程序员对"用指针遍历数组"再熟不过：

```c
int arr[5] = {1,2,3,4,5};
for (int *p = arr; p != arr + 5; ++p)
    printf("%d\n", *p);
```

C++ 迭代器的运算符和这套指针用法**几乎一一对应**，但适用范围更广：

| 操作 | C（指针遍历数组） | C++（迭代器遍历容器） |
|------|-------------------|----------------------|
| 解引用 | `*p` | `*it` |
| 成员访问 | `p->field`（struct 数组） | `it->field` |
| 前进 | `++p` / `p++` | `++it` / `it++` |
| 后退 | `--p` | `--it`（双向迭代器才支持） |
| 比较 | `p != end` | `it != v.end()` |
| 适用范围 | 只能连续内存（数组） | 所有 STL 容器（含 `list`/`map`） |

**给 C 程序员的关键提醒：**
1. **C 的指针只对连续内存有效**——`list`、`map` 这些节点容器，指针算术（`p++`）跳不到下一个节点。迭代器重载了 `++`，知道怎么跳到下一个元素（`list` 跟 `next` 指针，`map` 走树的中序）。
2. **遍历写 `it != end()`，不写 `it < end()`**——C 里 `p < arr + n` 对指针成立（连续内存地址递增），但 `list`/`map` 的迭代器**不支持 `<`**。养成 `!=` 习惯，代码能无缝换容器。
3. **`++it` 比 `it++` 高效**——后置要先拷贝一份旧值再前进，对迭代器（可能含多个成员）有开销。C 里 `p++` 和 `++p` 对裸指针一样快，但到迭代器要改习惯。

## 常见错误

### 1. 用 `<` 比较迭代器（链表场景编译失败或行为错）

```cpp
for (auto it = v.begin(); it < v.end(); ++it) { ... }   // vector 能过，list 不行
```

`vector`/`string`/`array` 是随机访问迭代器，支持 `<`；但 `list`/`map` 的迭代器只支持 `==`/`!=`。**一律写 `it != v.end()`**，代码换容器不用改。

### 2. 后置 `++` 当习惯

```cpp
for (auto it = v.begin(); it != v.end(); it++) { ... }   // 能跑但低效
```

`it++` 要先拷贝旧迭代器返回再前进，循环里每次多一次拷贝。**改 `++it`** 是免费的性能提升。C 程序员写 `p++` 习惯了（裸指针无差异），到 C++ 要换。

### 3. 在 `for` 循环里改容器导致迭代器失效

```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == target) v.push_back(0);   // ❌ 扩容让 it 失效
}
```

`push_back` 可能扩容，所有迭代器失效，`++it` 接着用就是 UB。详见 [3.4.5](./3.4.5-易错点失效与考点.md)。C 里写 `for (p=arr; p!=arr+n; ++p) { arr = realloc(...); }` 同样会崩，但 C 程序员通常不会这么写——`vector` 的"动态"特性容易让人放松警惕。

## 自测题

**1. 选择题**　下列哪种写法在 `std::list<int>` 上**能正确遍历**？

- A. `for (auto it = l.begin(); it < l.end(); ++it)`
- B. `for (auto it = l.begin(); it != l.end(); ++it)`
- C. `for (size_t i = 0; i < l.size(); ++i) l[i]`
- D. `for (auto it = l.begin(); it != l.end(); it++)`

<details><summary>答案</summary>

**B**（最规范）。A 错：`list` 迭代器不支持 `<`；C 错：`list` 不支持下标；D 能跑但 `it++` 后置低效，不如 `++it`。B 是**所有容器通用的标准写法**。

</details>

**2. 判断题**　迭代器的 `->` 运算符等价于先解引用再取成员：`it->field` ≡ `(*it).field`。

<details><summary>答案</summary>

**对**。这和 C 指针的 `p->field` ≡ `(*p).field` 完全一致。当元素是 struct/class 时，`it->price` 比 `(*it).price` 简洁。

</details>

**3. 踩坑题**　C 程序员写下面这段遍历 `vector<struct>` 的代码，有什么可改进？

```cpp
std::vector<Tick> ticks;
// ... 填充 ticks ...
for (size_t i = 0; i < ticks.size(); i++) {
    std::cout << ticks[i].price << " " << ticks[i].qty << "\n";
}
```

<details><summary>答案</summary>

能用但有几处可改：

1. **下标遍历不通用**——换 `list` 就废，改用迭代器：
   ```cpp
   for (auto it = ticks.begin(); it != ticks.end(); ++it)
       std::cout << it->price << " " << it->qty << "\n";
   ```
2. **`i++` 后置**（虽然这里是 `size_t` 不是迭代器，影响小）
3. **更现代的写法**用范围 for：
   ```cpp
   for (const auto& t : ticks)
       std::cout << t.price << " " << t.qty << "\n";
   ```

C 程序员的下标思维能跑，但迭代器/范围 for 更通用、更安全。

</details>

**4. 应用题**　写一个函数，把 `vector<int>` 中所有奇数翻倍，用迭代器遍历。

<details><summary>答案</summary>

```cpp
void double_odds(std::vector<int>& v) {
    for (auto it = v.begin(); it != v.end(); ++it) {
        if (*it % 2 != 0)
            *it *= 2;
    }
}
```

要点：
- 用 `auto it = v.begin()` 让编译器推导类型（`vector<int>::iterator`）
- `it != v.end()` 而非 `<`
- `++it` 前置
- `*it` 既是左值也是右值，能读能写

C 等价写法是 `for (int *p = arr; p != arr + n; ++p) if (*p % 2) *p *= 2;`，几乎一一对应。

</details>
