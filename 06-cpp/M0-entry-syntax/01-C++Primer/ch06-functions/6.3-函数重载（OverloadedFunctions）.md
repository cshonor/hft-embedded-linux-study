# 6.3 函数重载（Overloaded Functions）

## 本节讲什么

C++ 的**函数重载**：同一作用域内，函数名相同但形参列表不同。编译器通过**重载匹配**（overload resolution）决定调用哪个版本。这是 **C 没有的特性**，C 程序员必须理解匹配规则。

## 核心用法

### 重载的条件

函数名相同，但下列任一不同即可重载：
- 形参**个数**不同
- 形参**类型**不同
- 形参**顺序**不同（类型层面）

```cpp
void print(int i);          // #1
void print(double d);       // #2  类型不同
void print(const char* s);  // #3  类型不同
void print(int a, int b);   // #4  个数不同

print(42);        // 调 #1
print(3.14);      // 调 #2
print("hi");      // 调 #3
print(1, 2);      // 调 #4
```

**注意**：返回类型**不参与**重载区分——`int f(int)` 和 `void f(int)` 不能共存（调用 `f(1)` 无法区分）。

### 重载匹配三档

1. **精确匹配**：类型完全一致，或仅顶层 const 区别
2. **类型转换后匹配**：算术转换（int→double）、派生→基类
3. **二义性**：多个版本都"差不多好"，编译器报错

```cpp
void f(int);
void f(double);
f(3.14);     // 精确匹配 f(double)
f(42);       // 精确匹配 f(int)
f(3.14f);    // float→double 或 float→int 都行，二义性！报错
```

## 和 C 的区别

| 维度 | C | C++ |
|------|---|-----|
| 函数重载 | ❌ 同名函数只能有一个 | ✅ 形参列表不同即可 |
| 处理多类型 | C 用不同名字：`print_int`/`print_double` | 统一 `print`，编译器分派 |
| 名字修饰 | C 简单（`_func`） | C++ name mangling（`_f_i`/`_f_d`） |
| `extern "C"` | — | C++ 用来禁用重载、与 C 互操作 |

**C 程序员的认知转变**：C 里 `print_int`、`print_double`、`print_string` 是常态；C++ 里统一叫 `print`，编译器按实参类型自动分派。这能显著减少命名负担，但要注意匹配二义性。

```c
/* C：每个类型一个名字 */
void print_int(int x);
void print_double(double x);
void print_str(const char* s);
```
```cpp
// C++：统一名字，编译器分派
void print(int x);
void print(double x);
void print(const char* s);
```

**与 C 互操作**：C++ 为了能调用 C 库，提供 `extern "C"` 关闭 name mangling：
```cpp
extern "C" void c_func(int);   // 用 C 链接规则，不 mangling
```

## 常见错误

1. **二义性调用**：`void f(long); void f(double); f(3);` —— int→long 和 int→double 都是标准转换，谁也不比谁好，二义性报错。**修正**：显式转换 `f(static_cast<long>(3))` 或加 `f(int)` 重载。
2. **重载与默认实参冲突**：`void f(int); void f(int, int=0); f(1);` —— 调用 `f(1)` 二义性。**修正**：避免这种设计。
3. **以为返回类型参与重载**：`int f(int); void f(int);` —— 编译错误"重复定义"。返回类型不区分重载。

## 自测题

**1. 选择题**：下面哪些能构成合法重载（同作用域内）？
- A) `int f(int)` 与 `void f(int)`
- B) `int f(int)` 与 `int f(const int)`
- C) `int f(int)` 与 `int f(int&)`
- D) `int f(int)` 与 `int f(int, int)`

<details><summary>答案</summary>

C 和 D。A 返回类型不同不构成重载（重复定义）；B 顶层 const 不区分（`f(1)` 无法区分 `int` 和 `const int` 形参）；C 形参类型不同（值 vs 引用），合法；D 个数不同，合法。

</details>

**2. 判断题**：C++ 中 `void f(int&)` 和 `void f(const int&)` 可以重载，且 `f(42)` 调用后者。

<details><summary>答案</summary>

正确。非 const 引用不能绑右值，`42` 是右值，所以 `f(42)` 精确匹配 `f(const int&)`（const 引用能绑右值）。`int x=1; f(x)` 则优先匹配 `f(int&)`（非 const 优先）。这是容器 `operator[]` 常见的 const/非 const 重载模式。

</details>

**3. 踩坑题**：下面调用合法吗？为什么？
```cpp
void f(long);
void f(double);
f(42);
```

<details><summary>答案</summary>

二义性，编译错误。`42` 是 int，int→long 和 int→double 都是"标准转换"（同一优先级），编译器无法选最优。**修正**：`f(static_cast<long>(42))` 或 `f(42L)` 显式指定，或添加 `void f(int)` 重载。

</details>

**4. 应用题**：为一个日志函数设计重载集，支持 `int`、`double`、`const char*`、`const std::string&` 四种参数，写出声明并说明 `log("hello")`（字符串字面量）会匹配哪个。

<details><summary>答案</summary>

```cpp
void log(int x);
void log(double x);
void log(const char* s);
void log(const std::string& s);
```
`log("hello")` 中 `"hello"` 是 `const char[6]`，**精确匹配** `log(const char*)`（数组退化到指针），优先于 `log(const std::string&)`（后者要类类型转换，优先级低）。所以调 `log(const char*)`。如果想强制走 string 版，写 `log(std::string("hello"))`。

</details>
