## 术语表（带 C 对照）

| 术语 | 含义 | C 程序员视角 |
|------|------|--------------|
| **内置类型** | 语言自带的 `int`/`double`/`char` | 和 C 一样 |
| **命名空间** | `std::cin` 避免名字冲突 | C 没有命名空间，靠命名约定 |
| **实参 / 形参** | 调用时传的值 / 定义里的参数 | 和 C 一样 |
| **缓冲区** | IO 流读写用的内存区，`endl` 刷新 | C 的 `fflush(stdout)` 类似 |
| **类** | 数据 + 函数 + 访问控制 | C 的 `struct` 只有数据 |
| **头文件** | `<iostream>`、`"Sales_item.h"` | 和 C 一样，但 C++ 有 `class` |

## 第 1 章给 C 程序员的 5 个要点

1. **`cin/cout` 替代 `scanf/printf`** —— 类型安全，不用记格式串，不会忘 `&`
2. **`//` 注释放心用** —— C89 没有，C99 起和 C++ 都支持
3. **`for` 变量作用域收紧** —— C++ 里 `for(int i...)` 的 `i` 出循环就没了，C 会泄漏到外层
4. **`class` 比 `struct` 多了方法和访问控制** —— 数据和行为绑定，这是 C→C++ 的核心转变
5. **`while(cin>>x)` 替代 `scanf` 返回值检查** —— 流的状态自带 bool 转换

## 综合示例

```cpp
// 第 1 章综合：循环读取不定数量输入并求和
#include <iostream>
int main() {
    std::cout << "Enter numbers (Ctrl+Z then Enter on Windows to end):\n";
    int sum = 0, value = 0;
    while (std::cin >> value)   // 读至 EOF
        sum += value;
    std::cout << "Sum = " << sum << std::endl;
    return 0;
}
```

## 自测题（全章回顾）

**1（概念）** 列出 C++ 相对 C 在第 1 章里出现的 3 个差异。

**2（判断）** C++ 的 `class` 和 C 的 `struct` 本质相同，都只是装数据。

**3（应用）** 用 C++ 流 IO 重写下面的 C 代码：
```c
int a, b;
scanf("%d %d", &a, &b);
printf("sum = %d\n", a + b);
```

<details><summary>参考答案</summary>
1. ① `cin/cout` 类型安全的流 IO 替代 `scanf/printf`；② `for` 变量作用域只在循环内（C 会泄漏）；③ `class` 把数据和函数绑定并提供访问控制（C 的 `struct` 只有数据）。另外 `//` 注释、命名空间也是差异。
2. 错。C++ 的 `class`（和 `struct`）可以有成员函数和 `public/private` 访问控制；C 的 `struct` 只有数据成员，没有方法也没有访问控制（虽然 C++ 的 `struct` 也能有方法，默认访问是 public，而 class 默认 private）。
3. 
```cpp
int a, b;
std::cin >> a >> b;
std::cout << "sum = " << a + b << std::endl;
```
</details>
