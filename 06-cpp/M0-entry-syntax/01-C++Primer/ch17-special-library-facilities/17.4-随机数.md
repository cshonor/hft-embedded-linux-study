# 随机数

## 本节讲什么

本节讲解 C++11 `<random>` 库的现代随机数架构：**引擎**（生成底层无符号原始数）+ **分布器**（映射到目标区间和分布）。摒弃 C 的 `rand()`——它质量差、范围不均、不可复现。C++ 的引擎 + 分布分离让随机数可控、可复现、分布均匀，适合仿真、抽奖、测试、蒙特卡洛。

> **一句话定位**：`engine` 产出原始随机数，`distribution` 把它映射到你想要的区间和分布——分离让两者各自最优。

## 核心用法

### 1. 引擎 + 分布器

```cpp
#include <random>
// 引擎：生成 [0, max] 的无符号随机数
std::mt19937 eng;                    // 梅森旋转引擎（最常用）
std::default_random_engine eng2;     // 默认引擎（实现定义）

// 分布器：把引擎的原始数映射到目标区间
std::uniform_int_distribution<int> dist(1, 6);    // 1-6 均匀整数（骰子）
int roll = dist(eng);               // 调用：传入引擎，返回分布后的数
```

每次调用 `dist(eng)`：`dist` 从 `eng` 取一个原始数，按分布映射成目标区间的数。

### 2. 常用分布

```cpp
std::mt19937 eng;
std::uniform_int_distribution<int>    d1(1, 100);    // 均匀整数 [1,100]
std::uniform_real_distribution<double> d2(0.0, 1.0); // 均匀浮点 [0,1)
std::normal_distribution<double>      d3(0.0, 1.0);  // 正态分布（均值0，标准差1）
std::bernoulli_distribution           d4(0.7);        // 伯努利：70% 概率 true
std::binomial_distribution<int>       d5(10, 0.5);   // 二项分布
for (int i = 0; i < 5; ++i) std::cout << d3(eng) << " ";  // 正态分布采样
```

### 3. 种子控制

```cpp
// 固定种子：可复现（测试、调试）
std::mt19937 eng1(42);               // 每次运行结果相同

// 随机种子：每次不同
std::random_device rd;               // 真随机源（硬件熵）
std::mt19937 eng2(rd());             // 用 rd 播种

// C++11 推荐：random_device 一次性播种
std::mt19937 eng3(std::random_device{}());
```

> **可复现性**对测试至关重要——用固定种子，bug 可重现。生产环境用 `random_device` 播种保证不可预测。

### 4. 正确使用模式

```cpp
// 模式：引擎做成局部 static 或成员，只构造一次
int roll_dice() {
    static std::mt19937 eng(std::random_device{}());    // 只构造一次
    static std::uniform_int_distribution<int> dist(1, 6);
    return dist(eng);
}
// 不要：
int bad_roll() {
    std::mt19937 eng(std::random_device{}());    // ❌ 每次调用都重新构造 + 播种
    return eng() % 6 + 1;                         // ❌ % 6 分布不均（见下）
}
```

引擎构造开销大（尤其 `mt19937` 状态 2.5KB），**不要在循环或频繁调用的函数里反复构造**。

## 和 C 的区别

C 的 `rand()` 有严重缺陷：

| 维度 | C `rand()` | C++ `<random>` |
|------|----------|---------------|
| 质量 | 线性同余，低位周期短 | 梅森旋转，周期 2^19937-1 |
| 分布 | `rand()%N` 分布不均 | 分布器精确映射 |
| 区间 | `rand()%N` 手算 | `uniform_int_distribution(a,b)` |
| 可复现 | 种子固定即可 | 引擎种子明确 |
| 浮点 | 手动 `rand()/RAND_MAX` | `uniform_real_distribution` |
| 多种分布 | 无 | 正态/伯努利/二项等几十种 |

### `rand() % N` 的分布不均问题

```c
// C：rand() % 6 + 1 模拟骰子
int roll = rand() % 6 + 1;
// 问题：若 RAND_MAX = 32767，32767 不是 6 的倍数
// 余数 0-1 出现 5462 次，余数 2-5 出现 5461 次——轻微不均
// 对密码学、蒙特卡洛这种偏差不可接受
```

```cpp
// C++：分布器精确映射
std::uniform_int_distribution<int> dist(1, 6);
int roll = dist(eng);   // 精确均匀，无偏差
```

> **HFT 视角**：蒙特卡洛定价、回测模拟需高质量随机数。`mt19937` 周期极长、通过统计检验，是金融仿真的标准选择。密码学场景用 `std::random_device`（硬件熵）或专门密码库。

## 常见错误

### 错误 1：`rand() % N` 分布不均

见上文。**修复**：用 `uniform_int_distribution`，或至少用 `int(double(rand()) / RAND_MAX * N)`（仍有偏差但较小）。

### 错误 2：循环里反复构造引擎

```cpp
for (int i = 0; i < 1000; ++i) {
    std::mt19937 eng(std::random_device{}());   // ❌ 每次构造 2.5KB 状态 + 系统调用
    result += eng();
}
```

**修复**：引擎提循环外：
```cpp
std::mt19937 eng(std::random_device{}());
for (int i = 0; i < 1000; ++i) result += eng();
```

### 错误 3：忘记播种（默认种子每次相同）

```cpp
std::mt19937 eng;    // 默认种子，每次运行结果相同
// 看似"随机"，实则是固定的——不适合需要不可预测性的场景
```

若需要每次不同，用 `random_device` 播种。若需要可复现（测试），用固定种子——这是特性不是 bug。

### 错误 4：浮点分布范围搞错

```cpp
std::uniform_real_distribution<double> d(0.0, 1.0);
// 区间是 [0.0, 1.0) ——包含 0 不包含 1
// 若需 [0,1] 闭区间，用 d(0.0, std::nextafter(1.0, 2.0))
```

`uniform_real_distribution` 默认是半开区间 `[a, b)`，不含 `b`。整数分布 `uniform_int_distribution(a,b)` 是闭区间 `[a,b]`，含两端。

## 自测题

**1. 选择题**：C++ 随机数架构的"引擎"和"分布器"各自负责什么？

A. 引擎生成分布，分布器生成原始数
B. 引擎生成原始无符号数，分布器映射到目标区间和分布
C. 两者都生成最终随机数
D. 引擎播种，分布器生成

<details>
<summary>答案</summary>

**B**。引擎（如 `mt19937`）生成 `[0, max]` 的无符号原始数；分布器（如 `uniform_int_distribution`）从引擎取原始数，按目标分布映射到指定区间。分离让引擎专注质量、分布器专注映射，各司其职。

</details>

**2. 判断题**：`std::mt19937 eng(42);` 每次程序运行生成的随机数序列都相同。

<details>
<summary>答案</summary>

**对**。种子 `42` 固定，`mt19937` 是确定性算法，每次运行生成相同序列——这正是"可复现性"，对测试和调试极有用。若需每次不同，用 `std::random_device{}()` 播种。

</details>

**3. 踩坑题**：以下代码有什么问题？

```cpp
#include <cstdlib>
#include <ctime>
int roll_dice() {
    srand(time(nullptr));      // 每次调用都播种
    return rand() % 6 + 1;
}
```

<details>
<summary>答案</summary>

三个问题：
1. `srand(time(nullptr))` 在循环里反复调——同秒内 `time` 返回相同值，导致种子相同，后续 `rand()` 序列相同（非随机）。
2. `rand() % 6` 分布不均（RAND_MAX 不是 6 倍数）。
3. C 风格 `rand()` 质量低。

**修复**（C++ 风格）：
```cpp
#include <random>
int roll_dice() {
    static std::mt19937 eng(std::random_device{}());   // 只构造播种一次
    static std::uniform_int_distribution<int> dist(1, 6);
    return dist(eng);    // 精确均匀
}
```

</details>

**4. 应用题**：写一个函数，模拟掷 2 个骰子 10000 次，统计各点数（2-12）出现频率。要求用现代 C++ 随机数。

<details>
<summary>答案</summary>

```cpp
#include <random>
#include <vector>
#include <iostream>
std::vector<int> simulate_dice(int times) {
    static std::mt19937 eng(std::random_device{}());
    static std::uniform_int_distribution<int> die(1, 6);
    std::vector<int> counts(13, 0);    // 索引 2-12
    for (int i = 0; i < times; ++i) {
        int sum = die(eng) + die(eng);
        counts[sum]++;
    }
    return counts;
}
int main() {
    auto counts = simulate_dice(10000);
    for (int s = 2; s <= 12; ++s)
        std::cout << s << ": " << counts[s] << "\n";
    // 7 应该最多（概率 1/6），2 和 12 最少（概率 1/36）
}
```

要点：`static` 引擎只构造一次、`uniform_int_distribution` 精确均匀、两个骰子分别采样再求和、`counts` 数组统计。理论分布：7 出现 ~1667 次，2/12 各 ~278 次。

</details>
