# 2.3.2 指针与 nullptr

## 本节讲什么

const 指针、nullptr、Rust 对照。

## 指针：`int*` 与 `const`（和引用放一起记）

| 写法 | 读法 | 谁能改 |
|------|------|--------|
| `int*` / `int *p` | 普通指针 | 指针可变指向；可通过 `*p` 改对象 |
| `const int*` / `int const *p` | 指向常量的指针 | **不能**通过 `*p` 改对象；`p` 可改指向 |
| `int* const p` | 常量指针 | 可通过 `*p` 改对象；**不能**改 `p` 的指向 |
| `const int* const p` | 都 const | 指向和对象都不改 |

```cpp
int i = 0, j = 1;
const int *p = &i;   // *p 不可改，p 可指向 j
p = &j;              // ✅
// *p = 2;           // ❌

int *const cp = &i;  // cp 不可改指向，*cp 可改
*cp = 2;             // ✅
// cp = &j;          // ❌
```

**和引用的对应：**

| 引用 | 近似指针含义 |
|------|--------------|
| `int&` | 像绑死的 `int*`，必须有效，可读写 `*p` |
| `const int&` | 像 `const int*`，只读，不能 `*p = ...` |

引用不能重新绑定 ≈ 没有「改指向」这回事；指针可以 `p = &other`。

## `nullptr`：为什么优于 `NULL` / `0`（C++11）

### 三者分别是什么

| | 本质 | 类型 |
|---|------|------|
| **`0`** | 整数零 | `int` |
| **`NULL`** | 宏，通常 `#define NULL 0`（有的编译器 `(void*)0`，不一致） | 仍是**整数语境** |
| **`nullptr`** | **关键字**，专用空指针字面值 | **`std::nullptr_t`** |

```cpp
void func(int);
void func(char*);

func(0);        // 调用 func(int) —— 不是指针！
func(NULL);     // 同上，仍是 int 语境
func(nullptr);  // 调用 func(char*) —— 正确
```

### 核心优势

**① 重载不踩坑**

```cpp
void foo(int)  { std::cout << "int\n"; }
void foo(char*) { std::cout << "pointer\n"; }

foo(0);        // int
foo(NULL);     // int
foo(nullptr);  // pointer ✅
```

**② 模板推导正确** — `0`/`NULL` 推成 `int`；`nullptr` 推成 `std::nullptr_t`，智能指针等接口只认后者。

**③ 类型安全**

```cpp
int a = nullptr;  // ❌ 编译错误
int b = NULL;     // ⚠️ 往往能通过，隐藏 bug
```

**④ 兼容所有指针类型**

```cpp
int *p = nullptr;
void (*fn)() = nullptr;
```

`std::nullptr_t` 可隐式转为任意指针类型，**不能**隐式转为整型——安全根源在此。

### 什么时候用哪个

| 写法 | 用途 |
|------|------|
| **`nullptr`** | **所有**表示空指针的场景（现代 C++ 唯一推荐） |
| **`NULL`** | 老代码遗留，新项目别写 |
| **`0`** | 只表示数字零，**绝不**表示空指针 |

**极简总结**：`0` / `NULL` 是整数，重载和模板易错；`nullptr` 是专门的空指针类型，无歧义、类型安全。

## 和 C 的区别

指针是 C 和 C++ **高度重合**的部分——`int*`、`const int*`、`int* const`、指针运算全部一样。差异主要在空指针表示和引用的存在：

| 对比点 | C | C++ |
|--------|---|-----|
| 指针语法/运算 | 一样 | 一样 |
| 空指针 | `NULL`（宏，通常是 `0`） | `nullptr`（关键字，专用类型） |
| 引用 | ❌ 没有 | ✅ 优先用引用 |
| `void*` 隐式转其他指针 | ✅ 允许 | ❌ 必须显式 cast |

**给 C 程序员的关键提醒：**
1. **`NULL` 在 C++ 里是坑**——它通常是 `0`（整数），重载时 `func(NULL)` 可能匹配 `func(int)` 而不是 `func(char*)`。C++ 一律用 `nullptr`。
2. C 的 `void*` 能隐式赋给 `int*`，C++ 不行，要 `static_cast<int*>(vp)`。
3. C 程序员习惯"能用指针就别用值"，C++ 反过来——"能用引用就别用指针"。

```c
/* C 写法 */
int *p = NULL;          // 空指针
void *vp = malloc(4);
int *ip = vp;           // void* 隐式转 int*，C 允许
```
```cpp
// C++ 写法
int *p = nullptr;       // 专用空指针类型
void *vp = malloc(4);
int *ip = static_cast<int*>(vp);  // 必须显式 cast
```

**`const` 指针四种形态（C 和 C++ 完全一样，照搬）：**

| 写法 | 谁能改 | 记忆 |
|------|--------|------|
| `int* p` | 都能改 | 普通指针 |
| `const int* p` | 只能改指向，不能改 `*p` | "指向常量" |
| `int* const p` | 只能改 `*p`，不能改指向 | "常量指针" |
| `const int* const p` | 都不能改 | 全锁 |

**速记：** `const` 在 `*` 左边管"指向的对象"，在 `*` 右边管"指针本身"。

## 示例

```cpp
#include <iostream>
#include <string>

void read_only(const std::string &s) {
    std::cout << s << std::endl;
}

void bump(int &n) {
    ++n;
}

int main() {
    int ival = 42;

    int &refVal = ival;
    refVal = 1024;
    std::cout << ival << std::endl;  // 1024

    const int &cref = ival;
    std::cout << cref << std::endl;

    int *p = &ival;
    *p = 0;
    std::cout << ival << std::endl;  // 0

    const int *pc = &ival;           // 指向常量：不能 *pc 改值
    int *const cp = &ival;           // 常量指针：cp 不能改指向

    read_only("hello");
    bump(ival);

    return 0;
}
```

## 常见错误

**1. `NULL` 重载歧义（C 程序员的坑）**
```cpp
void f(int);
void f(char*);
f(NULL);   // 可能调 f(int)！NULL 通常是 0
```
C++ 一律用 `nullptr`，无歧义。

**2. 野指针 / 悬空指针**
```cpp
int *p = nullptr;
{
    int x = 42;
    p = &x;     // x 出作用域后 p 悬空
}
*p = 10;        // UB
```
C 和 C++ 共同问题。C++ 用智能指针（`unique_ptr`/`shared_ptr`）解决，C 要手动管理。

**3. `void*` 忘了 cast**
```cpp
void *vp = ...;
int *ip = vp;   // C 允许，C++ 编译错误
```
C++ 要求 `static_cast<int*>(vp)`。

## 自测题

**1（选择）** 下面哪个能正确把空指针传给 `void f(char*)`？
- A. `f(NULL)`
- B. `f(0)`
- C. `f(nullptr)`

**2（踩坑）** 下面代码 `const` 管的是谁？
```cpp
const int *p = &x;
```
- A. 指针 `p` 不能改指向
- B. 不能通过 `*p` 改 `x` 的值

**3（判断）** C++ 中 `void*` 可以隐式赋值给 `int*`。

<details><summary>参考答案</summary>
1. C。`nullptr` 是专用空指针类型，会正确匹配 `f(char*)`。`NULL`/`0` 是整数，可能匹配 `f(int)`（若有重载）。
2. B。`const` 在 `*` 左边管"指向的对象"——不能通过 `*p` 改值，但 `p` 可以改指向别的。要锁指针本身用 `int* const`。
3. 错。C 允许 `void*` 隐式转其他指针类型，C++ 要求显式 `static_cast`。这是 C→C++ 的一个常见编译错误来源。
</details>
