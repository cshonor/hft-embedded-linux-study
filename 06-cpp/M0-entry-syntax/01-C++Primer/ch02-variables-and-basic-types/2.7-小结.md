# 2.7 小结

> 第 2 章 · 上一节：[2.6 自定义数据结构](./2.6-custom-data-structures/2.6-自定义数据结构.md) · 下一章：[第 3 章 字符串、向量和数组](../ch03-strings-vectors-arrays/README.md)

## 本节讲什么

回顾第 2 章核心内容，建立完整知识框架。第 2 章是 C→C++ 转变的关键章——内置类型和 C 几乎一样，但引用、const 链接性、auto/decltype、类内初始值都是 C++ 的新能力。

## 第 2 章术语表（带 C 对照）

| 术语 | 含义 | C 程序员视角 |
|------|------|--------------|
| **内置类型** | `int`/`double`/`char` 等 | 和 C 一样，大小同样因平台而异 |
| **变量/常量** | `int x` / `const int x` | `const` 链接性不同（C++ 内部链接） |
| **引用** | `int& r = x`，别名 | **C 没有**，是 C++ 独有 |
| **指针** | `int* p` | 和 C 一样，但用 `nullptr` 替代 `NULL` |
| **顶层/底层 const** | 自身只读 / 指向只读 | 和 C 一样 |
| **constexpr** | 编译期常量 | **C 没有**，C 用 `#define`/`enum` |
| **auto/decltype** | 类型推导 | **C 没有**（C 的 auto 是存储类） |
| **struct** | 数据 + 函数 + 访问控制 | C 的 struct 只有数据 |

## 第 2 章给 C 程序员的 8 个要点

1. **引用是 C++ 独有** —— 函数传参优先 `const T&`，替代 C 的 `const T*`
2. **`nullptr` 替代 `NULL`** —— 类型安全，重载不踩坑
3. **`const` 全局默认内部链接** —— 头文件可直接放 `const` 定义（C 不行）
4. **`constexpr` 替代 `#define`** —— 有类型、有作用域、编译期求值
5. **`auto` 是类型推导** —— 忘掉 C 的 auto（存储类），C++11 起含义变了
6. **`decltype` 精确复刻类型** —— `decltype((x))` 双括号变引用
7. **类内初始值** —— `struct { int x = 0; }`，C 不支持
8. **`struct` 能有成员函数** —— 和 C 的 struct 本质不同，等于默认 public 的 class

## 综合示例

```cpp
#include <iostream>
int main() {
    // 第 2 章综合回顾：引用、指针、auto、decltype
    int x = 10;
    int &rx = x;        // 引用（C++ 独有）
    int *px = &x;       // 指针（和 C 一样）
    rx = 20;

    auto y = 30;                // 类型推导（C++ 独有）
    decltype(y + 1) z = 31;     // 表达式类型推导

    constexpr int N = 100;      // 编译期常量（C 用 #define）
    int arr[N];

    std::cout << *px << " " << z << std::endl;
    return 0;
}
```

## 自测题（全章回顾）

**1（概念）** 列出第 2 章里 C++ 相对 C 新增的 5 个特性。

**2（判断）** C++ 的 `const int x = 10;` 放头文件被多文件包含会重定义（和 C 一样）。

**3（应用）** 把下面的 C 代码改写成 C++ 风格（用引用、auto、constexpr）：
```c
#define MAX 100
void bump(int *p) { (*p)++; }
int main() {
    int arr[MAX];
    int x = 5;
    bump(&x);
}
```

<details><summary>参考答案</summary>
1. ① 引用 `T&`；② `nullptr`；③ `const` 全局内部链接；④ `constexpr`；⑤ `auto`/`decltype`；⑥ 类内初始值；⑦ struct 能有成员函数。（任选 5 个）
2. 错。C++ 的 `const` 全局默认内部链接，头文件放 `const` 定义每个 .cpp 各一份，不重定义。C 才会重定义。这是 C/C++ 关键差异。
3. 
```cpp
constexpr int MAX = 100;        // 替代 #define
void bump(int &r) { r++; }      // 引用替代指针
int main() {
    int arr[MAX];
    int x = 5;
    bump(x);                    // 不用写 &
}
```
</details>
