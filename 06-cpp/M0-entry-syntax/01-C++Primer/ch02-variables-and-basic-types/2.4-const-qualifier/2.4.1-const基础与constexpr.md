# 2.4.1 const 基础与 constexpr

## 本节讲什么

顶层/底层 const、指针、constexpr。

## 一、普通 const 常量

```cpp
const int ci = 0;
// ci = 10;   // ❌ 顶层 const，绝对不能改
// const int ci;  // ❌ 必须初始化
```

- `ci` 是**顶层 const**：变量本身只读
- 仅有 `const` **不保证编译期常量**——若用运行时才知的值初始化，仍是运行时常量：

```cpp
int x = rand();
const int ci = x;   // ci 不可改，但值运行期才确定
```

## 二、常量引用 `const int &r`（底层 const）

1. **底层 const**：不能通过 `r` 修改绑定对象 → `r = 100;` ❌
2. **唯一能绑字面量的引用**：

```cpp
const int &r1 = 10;   // ✅
// int &r2 = 10;      // ❌ 普通引用不能绑临时/字面量
```

3. 只限制「通过 `r` 改」，不限制原变量：

```cpp
int a = 5;
const int &r = a;
a = 10;    // ✅ 直接改 a 可以
// r = 20; // ❌ 通过 r 不行
```

4. 引用没有「顶层 const」说法——带 `const` 的引用**全是底层 const**

## 三、const 修饰指针

### 易混纠正：「指向常量的指针」vs「常量指针」

名字很像，**锁定的对象不同**：

| 写法 | 俗称 | `*p` 能改值？ | `p` 能改指向？ |
|------|------|--------------|--------------|
| `const int *p` | **指向常量的指针** | ❌ 不能通过 `p` 改内容 | ✅ 可以指向别的地址 |
| `int *const p` | **常量指针** | ✅ 可以通过 `p` 改内容 | ❌ 指向不能改 |

```cpp
int a = 1, b = 2;

const int *p1 = &a;   // 指向常量的指针：内容只读，指针能挪
p1 = &b;              // ✅
// *p1 = 99;          // ❌

int *const p2 = &a;   // 常量指针：指向钉死，内容可改
*p2 = 99;             // ✅
// p2 = &b;           // ❌
```

**记法**：`const` **靠近类型**（`const int *`）→ 指向的内容不能改；`const` **靠近变量名**（`int *const p`）→ 指针本身不能改。

与 [3.2.4 string 与 C 风格字符串](../ch03-strings-vectors-arrays/3.2-library-type-string/3.2.4-string与C风格字符串.md) 里 C 风格 `char*` / `const char*` 读旧接口时也会用到。

### 1. 指向常量的指针：`const int *p` / `int const *p`（底层 const）

- 不能 `*p` 改所指对象；**`p` 本身可改指向**

```cpp
int num = 10;
const int *p = &num;
// *p = 20;   // ❌
p = &ci;      // ✅
num = 30;     // ✅ 原变量仍可改
```

### 2. 常量指针：`int *const p`（顶层 const）

- 地址固定，不能换指向；**可通过 `*p` 改值**

```cpp
int num = 10;
int *const p = &num;
// p = &ci;   // ❌
*p = 50;      // ✅
```

### 3. 双重 const：`const int *const p`

- 顶层 + 底层：`p` 不能改指向，`*p` 不能改值

### 记忆口诀（从右往左读）

- `int *const p` → `p` 是 **const 指针**（顶层），指向 `int`
- `const int *p` → `p` 是指针，指向 **const int**（底层）

## 四、顶层 const vs 底层 const

| | **顶层 const** | **底层 const** |
|---|----------------|----------------|
| **修饰谁** | 对象/指针**自身** | 指针/引用**所指/所绑**的对象 |
| **例子** | `const int a`、`int *const p` | `const int *p`、`const int &r` |
| **拷贝时** | 顶层 const **可丢弃** | 底层 const **必须匹配** |

```cpp
const int a = 10;
int b = a;           // ✅ 拷贝时丢弃顶层 const

const int *p1 = &x;
// int *p2 = p1;     // ❌ 不能丢失底层 const
```

**极简**：顶层 = **自己不能变**；底层 = **通过它不能改指向的东西**。

## 五、`constexpr`（编译期常量）

`constexpr` = **constant expression**，强制**编译期求值**，可作数组长度、模板实参。与 `const` 区别：`const` 只保证只读，值可能运行期才确定。

```cpp
constexpr int val = 2 + 3;
int arr[val];        // ✅

int x = rand();
const int c = x;     // const 只读，但 c 是运行期常量
// constexpr int err = x;  // ❌
```

**完整详解**（变量/函数/构造、C++11/14 区别、`if constexpr`、数组例题）：见 **[2.4.3 constexpr 详解](./2.4.3-constexpr详解.md)**。数组维度考点见 [3.5.1](../ch03-strings-vectors-arrays/3.5-arrays/3.5.1-定义与初始化.md)。

## 六、综合示例

```cpp
#include <iostream>

int main() {
    const int ci = 0;
    // ci = 10;

    const int &r = ci;
    // r = 20;

    int num = 100;

    const int *p1 = &num;       // 底层：*p1 不可改
    // *p1 = 200;
    p1 = &ci;

    int *const p2 = &num;       // 顶层：p2 指向不可改
    // p2 = &ci;
    *p2 = 200;

    const int *const p3 = &ci; // 双重
    // p3 = &num; *p3 = 5;

    constexpr int MAX = 1024;
    int buf[MAX];

    return 0;
}
```

## 和 C 的区别

`const` 基本语义 C 和 C++ 一样（只读），但有几个关键差异：

| 对比点 | C | C++ |
|--------|---|-----|
| `const` 全局默认链接 | **外部链接**（和普通全局一样） | **内部链接**（相当于隐式 `static`） |
| `const` 能否当数组大小 | ❌ 不是常量表达式（C99 变长数组除外） | ✅ 整型 `const` 可当数组维度 |
| `constexpr` | ❌ 没有 | ✅ C++11，编译期常量 |
| `const int &r = 42` | ❌ C 无引用 | ✅ 常量引用可绑字面量 |

**给 C 程序员的关键提醒：**
1. **`const` 链接性差异最坑：** C 的 `const int x = 10;` 放头文件被多文件包含会重定义；C++ 的 `const` 全局默认内部链接，放头文件每个 `.cpp` 各一份，不冲突。
2. **C++ 的 `const int N = 10; int arr[N];` 合法**（const 是常量表达式）；C 里 `const` 不是常量表达式，`int arr[N]` 是变长数组（C99）或非法（C89）。C++ 要编译期大小用 `constexpr`。
3. `constexpr` 是 C++ 独有，强制编译期求值，C 没有（C 用 `#define` 或 `enum`）。

```c
/* C：const 不能当数组大小（C89），要用 #define */
#define SIZE 10
int arr[SIZE];

/* C99 变长数组（运行期大小，不是编译期常量）*/
const int n = 10;
int arr[n];   /* C99 VLA，C++ 不支持 */
```
```cpp
// C++：const/constexpr 可当数组大小
constexpr int N = 10;
int arr[N];   // 合法，编译期常量
```

## 常见错误

**1. 搞混"指向常量的指针"和"常量指针"**
```cpp
const int *p;     // 指向常量：*p 不能改，p 能改指向
int *const p=&x;  // 常量指针：p 不能改指向，*p 能改
```
口诀：`const` 在 `*` 左边管内容，在 `*` 右边管指针本身。

**2. 拷贝时丢底层 const**
```cpp
const int *p = &x;
int *q = p;   // ❌ 不能丢底层 const（否则能通过 q 改"常量"）
```
顶层 const 拷贝时可丢（`const int` → `int` 是值拷贝），底层 const 必须匹配。

**3. `const` 当 C 用导致重定义**
```cpp
// 头文件（C++ 没问题，C 会重定义）
const int kMax = 100;   // C++: 内部链接，安全；C: 外部链接，多文件重定义
```

## 自测题

**1（选择）** `const int *const p = &x;` 里两个 `const` 分别管什么？
- A. 都管指针
- B. 左边管 `*p`（内容），右边管 `p`（指向）
- C. 都管内容

**2（判断）** C++ 中 `const int N = 10; int arr[N];` 合法。

**3（踩坑）** 下面代码哪里错？
```cpp
const int ci = 10;
int *p = &ci;
```

**4（概念）** `const` 和 `constexpr` 的区别是什么？

<details><summary>参考答案</summary>
1. B。左 `const`（`const int *`）管指向的内容不能通过 `*p` 改；右 `const`（`* const p`）管指针 `p` 不能改指向。
2. 合法。C++ 的整型 `const` 初始化为常量表达式时可当数组维度。C 里 `const` 不是常量表达式（C99 会变成变长数组 VLA，C++ 不支持 VLA）。
3. `&ci` 是 `const int*`，赋给 `int*` 会丢底层 const——如果能成功，就能通过 `*p` 改 `ci` 这个"常量"，破坏了 const 语义。编译器拒绝。要 `const int *p = &ci;`。
4. `const` 只保证"运行期不可改"，值可能运行时才确定（`const int c = rand();`）；`constexpr` 强制"编译期就能确定"，能当数组大小、模板实参。`constexpr` 是 `const` 的加强版。
</details>
