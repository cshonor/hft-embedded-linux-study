# 5.4 迭代语句（循环）

## 本节讲什么

四种循环：`while`、传统 `for`、**范围 for（range-for，C++11）**、`do-while`。重点讲范围 for 的用法与限制——这是 C 程序员最该学的新东西。

## 核心用法

| 语句 | 形式 | 适用场景 |
|------|------|---------|
| `while` | `while (cond) stmt` | 次数未知，先判断后执行 |
| 传统 `for` | `for (init; cond; expr) stmt` | 按步骤迭代，可控制增量 |
| 范围 for | `for (decl : coll) stmt` | 遍历容器/数组的每个元素 |
| `do-while` | `do stmt while (cond);` | 至少执行一次 |

### 范围 for（C++11）

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

// 只读遍历：用 const auto&
for (const auto& x : v)
    std::cout << x << " ";

// 修改元素：用 auto&
for (auto& x : v)
    x *= 2;

// 注意：不要在范围 for 中改变容器大小（push_back/erase）
```

范围 for 等价于：
```cpp
auto it = v.begin();
auto end = v.end();
for (; it != end; ++it) {
    auto& x = *it;
    // 循环体
}
```

## 和 C 的区别

| 维度 | C | C++ |
|------|---|-----|
| `while` / `for` / `do-while` | 完全一致 | 完全一致 |
| `for` 变量作用域 | C89：循环外可见；C99 起：块作用域 | 一直是块作用域 |
| 范围 for | ❌ C 没有任何等价语法 | ✅ C++11 起有 |
| 遍历容器 | C 要手写索引或指针循环 | 范围 for 一行搞定 |

**范围 for 是 C 程序员转 C++ 最直接受益的特性之一**——C 里遍历数组只能写 `for (int i=0; i<n; ++i) a[i]`，C++ 里直接 `for (auto& x : a)`，且不会越界。

```c
/* C：手写索引，容易越界 */
int sum = 0;
for (int i = 0; i < n; ++i)   // n 维护错了就 UB
    sum += arr[i];
```
```cpp
// C++：范围 for，无需维护索引
int sum = 0;
for (int x : arr)   // arr 是数组或容器，自动取 begin/end
    sum += x;
```

## 常见错误

1. **范围 for 用值类型导致无法修改 + 性能损耗**：`for (auto x : v)` 会拷贝每个元素，既不能修改原元素，大对象还慢。**修正**：只读用 `const auto&`，要改用 `auto&`。
2. **范围 for 中修改容器大小**：`for (auto& x : v) v.push_back(x);` —— `end()` 在循环开始时缓存，扩容后迭代器失效，UB。**修正**：先拷贝或用索引循环。
3. **范围 for 遍历 `vector<bool>` 用 `auto&`**：`vector<bool>` 的元素不是真正的 bool，是代理对象，`auto&` 推导出的是代理引用而非 bool&。**修正**：用 `auto` 或 `const auto&`。

## 自测题

**1. 选择题**：下面哪种写法能正确地把 `vector<int>` 每个元素翻倍？
- A) `for (auto x : v) x *= 2;`
- B) `for (auto& x : v) x *= 2;`
- C) `for (const auto& x : v) x *= 2;`
- D) `for (auto x : v) v[x] *= 2;`

<details><summary>答案</summary>

B。`auto&` 是引用绑定，能修改原元素。A 是拷贝改不动原值；C 是 const 引用不能修改；D 的 `x` 是元素值不是索引，逻辑错误。

</details>

**2. 判断题**：范围 for 循环里调用 `v.clear()` 是安全的。

<details><summary>答案</summary>

错误。`clear()` 让所有迭代器失效，范围 for 内部持有的 `end()` 和当前迭代器都会失效，属于未定义行为。范围 for 只适合"只读遍历"或"就地修改元素值"，不能增删元素。

</details>

**3. 踩坑题**：下面代码打印什么？为什么？
```cpp
std::vector<int> v = {1, 2, 3};
for (auto x : v) {
    v.push_back(x);   // 想复制一份
}
std::cout << v.size();
```

<details><summary>答案</summary>

未定义行为。范围 for 开始时缓存了 `end()`，但 `push_back` 可能触发扩容使 `end()` 失效，循环无法正确终止，可能死循环或崩溃。**正确做法**：先记录要添加的元素，循环结束后再批量 push，或用索引循环并提前 reserve。

</details>

**4. 应用题**：用范围 for 统计一个 `std::string` 中元音字母的个数，要求高效（不拷贝）。

<details><summary>答案</summary>

```cpp
std::string s = "hello world";
int vowels = 0;
for (char c : s) {                 // char 是小类型，用值即可；大对象用 const auto&
    if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u' ||
        c=='A'||c=='E'||c=='I'||c=='O'||c=='U')
        ++vowels;
}
std::cout << vowels;  // 3
```
`char` 是 trivially copyable 类型，用值比引用更高效（引用底层是指针，反而多一次间接寻址）。

</details>
