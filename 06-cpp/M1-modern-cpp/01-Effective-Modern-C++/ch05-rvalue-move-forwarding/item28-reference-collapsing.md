# Item 28：理解引用折叠

> 第 5 章 · Item 28 · 上一节：[Item 27 替代方案](item27-alternatives.md)

## 这节讲什么

引用折叠是万能引用与完美转发的底层机制。四条规则的核心：**只要有左值引用参与，折叠结果是左值引用**。

---

## 四条规则

| 组合 | 结果 |
|------|------|
| `&` + `&` | `&` |
| `&` + `&&` | `&` |
| `&&` + `&` | `&` |
| `&&` + `&&` | `&&` |

**口诀：左值引用是"毒"——碰一下就变左值引用。只有两个右值引用才折叠为右值引用。**

折叠发生在四个语境：
1. 模板推导
2. `auto` 推导
3. `typedef` / `using`
4. `decltype`

---

## 为什么万能引用能绑左值

```cpp
template<class T> void f(T&& x);

Widget w;
f(w);    // 左值实参：T 推为 Widget&，T&& = Widget& && → 折叠为 Widget&
f(Widget{});  // 右值实参：T 推为 Widget，T&& = Widget&&
```

左值实参时 `T` 推为 `Widget&`，`T&&` = `Widget& &&`，折叠为 `Widget&`——这就是万能引用能绑左值的原理。

---

## 新手要点（和 C 的区别）

- **C 没有引用**，更没有引用折叠。这是 C++ 类型系统独有的机制。
- **不需要背规则**：记住一句——"左值引用碰一下就传染"。两个 `&&` 才能保持 `&&`。
