# 4.4 指向成员函数的指针

> 第 4 章 · 上一节：[4.3 虚基类下的虚函数](03-virtual-base-vfunc.md) · 下一节：[4.5 inline](05-inline.md)

## 这节讲什么

`void (Shape::*fp)() = &Shape::draw;` 不是普通函数指针——对虚函数它是 vtable 偏移，对非虚函数它是函数地址 + this 调整信息。大小通常是 2 个指针。

---

## 核心概念

```cpp
void (Shape::*fp)() = &Shape::draw;
(shape->*fp)();  // 调用
```

指向成员函数的指针比普通函数指针大（通常 2 倍）：
- 对非虚函数：存函数地址 + this 调整量（多继承时需要）
- 对虚函数：存 vtable slot 偏移 + this 调整信息

---

## 新手要点（和 C 的区别）

- **C 没有指向成员函数的指针**：C 用 `void (*func)(void* self)` 模拟——显式传 `this`。C++ 的 `Shape::*` 自动处理 `this` 绑定。
- **很少直接用**：主要在泛型库/事件系统里见到。新手了解概念即可。
