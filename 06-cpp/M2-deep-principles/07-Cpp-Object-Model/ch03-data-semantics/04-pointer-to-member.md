# 3.4 指向数据成员的指针

> 第 3 章 · 上一节：[3.3 sizeof 的真相](03-sizeof-truth.md) · 下一章：[第 4 章 函数语义](../ch04-function-semantics/README.md)

## 这节讲什么

`int Point::* p = &Point::x;` 是什么？它不是真实地址，而是**偏移量**——在具体对象上定位成员。

---

## 核心概念

```cpp
int Point::* p = &Point::x;  // 指向成员的指针，本质是偏移量
Point obj;
obj.*p = 10;                  // 在 obj 上用偏移量定位 x
```

`Point::*` 不是普通指针——它存的是"从对象起始地址到成员 x 的偏移量"。通过 `obj.*p` 在具体对象上加上偏移量定位成员。

虚继承下偏移计算更复杂（需经虚基类偏移表）。

---

## 新手要点（和 C 的区别）

- **C 没有指向成员的指针**：C 用 `offsetof(struct, member)` 宏获取偏移量。C++ 的 `Point::*` 是类型安全的偏移量。
- **很少直接用**：日常编程很少写 `Point::*`，主要在泛型库/序列化框架里见到。新手了解概念即可。

---

## HFT 关联

- **序列化/反射**：`offsetof` 或指向成员的指针用于按偏移量批量访问字段——协议解析器常用。
