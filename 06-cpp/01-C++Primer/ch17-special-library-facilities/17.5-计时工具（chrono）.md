# 计时工具（chrono）

## 本节讲什么

本节讲解 C++11 `<chrono>` 库——现代计时工具：三种时钟（`system_clock`/`steady_clock`/`high_resolution_clock`）、`duration`（时长，带单位）、`time_point`（时间点）。用于统计代码耗时、定时、时间戳转换。`chrono` 是 HFT 和性能调优的基础工具。

> **一句话定位**：`chrono` = "类型安全的时间计算"——时长带单位编译期检查，不会把毫秒当微秒用。

## 核心用法

### 1. 三种时钟

| 时钟 | 特点 | 用途 |
|------|------|------|
| `system_clock` | 墙上时钟，可调（NTP 同步会跳） | 时间戳、日历时间 |
| `steady_clock` | 单调递增，不被调整 | **测量耗时**（首选） |
| `high_resolution_clock` | 最高精度（通常=steady_clock） | 高精度计时 |

```cpp
#include <chrono>
// 测量耗时——用 steady_clock（不会被 NTP 调整）
auto start = std::chrono::steady_clock::now();
// ... 被测代码 ...
auto end = std::chrono::steady_clock::now();
auto elapsed = end - start;
```

> **关键**：测耗时**永远用 `steady_clock`**，不用 `system_clock`（NTP 同步会让时间倒退，测出负耗时）。

### 2. duration：时长

```cpp
using namespace std::chrono;
milliseconds ms(100);       // 100 毫秒
microseconds us(1000);      // 1000 微秒
nanoseconds ns(1000000);    // 1000000 纳秒

// 单位转换：duration_cast
auto ms_from_us = duration_cast<milliseconds>(us);   // 1000us → 1ms
auto ns_from_ms = duration_cast<nanoseconds>(ms);    // 100ms → 100000000ns

// count() 取数值
std::cout << ms.count();    // 100
```

`duration<Rep, Period>` 是模板：`Rep` 是数值类型（`int`/`double`），`Period` 是单位比例（`std::ratio<1,1000>` 表示毫秒）。常用别名：`nanoseconds`/`microseconds`/`milliseconds`/`seconds`/`minutes`/`hours`。

### 3. time_point：时间点

```cpp
using namespace std::chrono;
auto tp = steady_clock::now();                    // 当前时间点
auto later = tp + seconds(5);                      // 5 秒后
auto diff = later - tp;                            // duration：5 秒
duration_cast<milliseconds>(diff).count();         // 5000
```

### 4. 完整耗时测量

```cpp
#include <chrono>
#include <iostream>
template <typename Func>
auto measure(Func f) {
    using namespace std::chrono;
    auto start = steady_clock::now();
    f();
    auto end = steady_clock::now();
    return duration_cast<microseconds>(end - start).count();
}
int main() {
    auto us = measure([]{
        volatile int sum = 0;          // volatile 防优化
        for (int i = 0; i < 1000000; ++i) sum += i;
    });
    std::cout << us << " us\n";
}
```

### 5. 睡眠与定时

```cpp
#include <thread>
#include <chrono>
std::this_thread::sleep_for(std::chrono::milliseconds(100));   // 睡 100ms
std::this_thread::sleep_until(std::chrono::steady_clock::now() + std::chrono::seconds(1));
```

### 6. C++20 的 chrono 增强

C++20 让 chrono 支持日历和格式化：
```cpp
// C++20：年月日
using namespace std::chrono;
auto today = year{2025}/July/19;
std::cout << today;   // 2025-07-19
// 时区支持
auto now = zoned_time{current_zone(), system_clock::now()};
```

## 和 C 的区别

C 用 `clock()`/`time()`/`gettimeofday()`，精度和类型安全都差：

| 维度 | C（clock/time） | C++ chrono |
|------|--------------|-----------|
| 类型安全 | 无（全是整数，单位靠记） | duration 带单位编译期检查 |
| 精度 | `clock()` 毫秒级，`gettimeofday` 微秒 | 纳秒级（平台支持的话） |
| 单位转换 | 手算除法 | `duration_cast` 自动 |
| 单调时钟 | 无标准（POSIX `clock_gettime`） | `steady_clock` 标准 |
| 可读性 | `clock()/CLOCKS_PER_SEC` | `milliseconds(100)` |

```c
// C：clock() 测耗时
#include <time.h>
clock_t start = clock();
// ... 代码 ...
clock_t end = clock();
double seconds = (double)(end - start) / CLOCKS_PER_SEC;
// 问题：clock() 测 CPU 时间（不含 sleep），且精度毫秒级
// 测墙钟时间要用 gettimeofday（非标准 C，POSIX）
```

```cpp
// C++：steady_clock 测墙钟耗时，纳秒精度
auto start = std::chrono::steady_clock::now();
// ... 代码 ...
auto end = std::chrono::steady_clock::now();
auto us = std::chrono::duration_cast<std::chrono::microseconds>(end - start).count();
```

> **HFT 视角**：纳秒级计时对延迟测量至关重要。`steady_clock` 在 x86 上通常基于 `RDTSC` 指令，纳秒精度且单调。测一段代码的尾部延迟（P99/P999）用 `steady_clock` 采样 + 排序统计。注意 `now()` 本身有开销（~20-50ns），测量极短代码时要减去基准。

## 常见错误

### 错误 1：用 `system_clock` 测耗时

```cpp
auto start = std::chrono::system_clock::now();
// ... 长任务 ...
auto end = std::chrono::system_clock::now();
auto diff = end - start;    // ❌ 若期间 NTP 调整时钟，diff 可能是负的或异常
```

**修复**：测耗时用 `steady_clock`（单调递增，不被调整）。`system_clock` 只用于时间戳/日历。

### 错误 2：`duration_cast` 截断

```cpp
using namespace std::chrono;
auto us = microseconds(1500);
auto ms = duration_cast<milliseconds>(us);   // 1ms（截断，丢了 500us）
auto ms_d = duration<double, std::milli>(us); // 1.5ms（用浮点保留）
```

整数 `duration_cast` 向零截断。若需保留小数，用浮点 `duration<double, ...>`。

### 错误 3：单位混淆

```cpp
using namespace std::chrono;
auto t = seconds(1) + milliseconds(500);   // 1.5 秒（自动提升到毫秒）
// t 的类型是 milliseconds，count() = 1500
auto wrong = seconds(1) + 500;             // ❌ 500 是 int 不是 duration，编译错
```

`duration` 之间可相加（自动提升到更精细单位），但不能直接加裸整数——要用 `milliseconds(500)` 包裹。

## 自测题

**1. 选择题**：测量一段代码的执行耗时，应使用哪个时钟？

A. `system_clock`
B. `steady_clock`
C. `time(nullptr)`
D. `clock()`

<details>
<summary>答案</summary>

**B**。`steady_clock` 单调递增、不被 NTP 调整，是测耗时的首选。`system_clock` 会被调整（可能倒退，测出负值）；`time()`/`clock()` 是 C 接口，精度低且 `clock()` 测 CPU 时间非墙钟。

</details>

**2. 判断题**：`std::chrono::duration_cast<std::chrono::milliseconds>(std::chrono::microseconds(1500))` 的结果是 1 毫秒。

<details>
<summary>答案</summary>

**对**。整数 `duration_cast` 向零截断，1500 微秒 = 1.5 毫秒，截断为 1 毫秒。若需 1.5 毫秒，用 `std::chrono::duration<double, std::milli>` 浮点 duration。

</details>

**3. 踩坑题**：以下代码有什么问题？

```cpp
auto start = std::chrono::system_clock::now();
std::this_thread::sleep_for(std::chrono::seconds(2));
auto end = std::chrono::system_clock::now();
auto diff = std::chrono::duration_cast<std::chrono::seconds>(end - start).count();
std::cout << diff;    // 期望 2
```

<details>
<summary>答案</summary>

用 `system_clock` 测耗时——若期间 NTP 同步调整了系统时钟，`diff` 可能不是 2（甚至为负）。测耗时应用 `steady_clock`：
```cpp
auto start = std::chrono::steady_clock::now();
std::this_thread::sleep_for(std::chrono::seconds(2));
auto end = std::chrono::steady_clock::now();
auto diff = std::chrono::duration_cast<std::chrono::seconds>(end - start).count();
```
`steady_clock` 单调递增，保证 diff 为 2（或略大于 2，因 sleep 精度）。

</details>

**4. 应用题**：写一个 `benchmark(func, n)` 模板函数，调用 `func` `n` 次，返回平均耗时（纳秒）。

<details>
<summary>答案</summary>

```cpp
#include <chrono>
template <typename Func>
double benchmark(Func func, int n) {
    using namespace std::chrono;
    auto start = steady_clock::now();
    for (int i = 0; i < n; ++i) func();
    auto end = steady_clock::now();
    auto total_ns = duration_cast<nanoseconds>(end - start).count();
    return static_cast<double>(total_ns) / n;   // 平均纳秒
}
// 用法：
double avg = benchmark([]{
    volatile int x = 0;
    for (int i = 0; i < 100; ++i) x += i;
}, 1000);
std::cout << avg << " ns/call\n";
```

要点：`steady_clock` 测耗时、`nanoseconds` 高精度、模板接受任意可调用对象、`volatile` 防优化掉循环。注意 `now()` 自身有 ~20-50ns 开销，测极短函数时要扣除基准。

</details>
