# tuple 元组

## 本节讲什么

本节讲解 `std::tuple`——一个固定大小、可存放**不同类型**元素的容器模板。它是 `std::pair` 的泛化版（`pair` 只能 2 个，`tuple` 任意个），常用于"函数一次返回多个不同类型结果"、"异构数据打包"等场景。

> **一句话定位**：`tuple` = "能装不同类型元素的 struct，但不用先定义 struct"。

## 核心用法

### 1. 创建与访问

```cpp
#include <tuple>
#include <string>
// 构造
std::tuple<std::string, int, double> t1{"book", 10, 9.9};
auto t2 = std::make_tuple("pen", 5, 1.5);    // 推导类型

// 访问：get<索引>
std::cout << std::get<0>(t1);    // "book"（string）
std::cout << std::get<1>(t1);    // 10（int）
// std::get<3>(t1);              // ❌ 编译错误：越界（只有 3 个元素）

// 按类型访问（要求该类型在 tuple 中唯一）
std::cout << std::get<std::string>(t1);   // "book"
```

### 2. 元素个数与类型查询

```cpp
auto t = std::make_tuple(1, 2.0, "hi");
std::cout << std::tuple_size<decltype(t)>::value;   // 3
// 获取第 i 个元素的类型：
std::tuple_element<0, decltype(t)>::type;   // int
```

### 3. 解包：tie 与结构化绑定

```cpp
std::tuple<std::string, int> get_person() { return {"Alice", 30}; }

// C++11：tie 解包
std::string name; int age;
std::tie(name, age) = get_person();

// C++17：结构化绑定（更优雅）
auto [name, age] = get_person();
```

### 4. tuple 的常见场景

- **函数返回多值**：`return std::make_tuple(result, status, error_msg);`
- **异构数据临时打包**：把不同类型数据一起传递，避免定义专用 struct
- **模板元编程**：作为"类型列表"载体

## 和 C 的区别

C 没有 `tuple`，要返回多个不同类型值只能定义 `struct` 或用 `void*`：

| 维度 | C（struct） | C++ tuple |
|------|-----------|----------|
| 定义成本 | 每处都定义 struct | 即用即写，无需预定义 |
| 访问 | `s.name`（有名字） | `get<i>`（按位置）或结构化绑定 |
| 通用性 | 每种组合一个 struct 类型 | 模板，任意类型组合 |
| 解包 | 逐字段赋值 | `tie` / 结构化绑定一行搞定 |

```c
// C：必须先定义 struct
struct Person { char name[32]; int age; };
struct Person get_person() { struct Person p = {"Alice", 30}; return p; }
// 用：struct Person p = get_person(); printf("%s %d", p.name, p.age);
```

```cpp
// C++：tuple 即用即写
std::tuple<std::string, int> get_person() { return {"Alice", 30}; }
auto [name, age] = get_person();   // C++17 一行解包
```

> **取舍**：若某个多值组合**反复出现**，定义 `struct` 更清晰（有字段名、可加方法）；若只是**临时**返回一次，`tuple` 更轻便。

## 常见错误

### 错误 1：`get` 索引越界或类型不匹配

```cpp
std::tuple<int, double> t{1, 2.0};
std::get<2>(t);                  // ❌ 编译错误：只有 2 个元素
std::get<std::string>(t);        // ❌ 编译错误：没有 string 类型
std::get<int>(t);                // ❌ 若有多个 int 会二义；这里只有 1 个 int，OK
```

`get` 越界和类型不匹配都是**编译期**错误——这是 `tuple` 相对 `void*` 的安全优势。

### 错误 2：按类型访问时类型不唯一

```cpp
auto t = std::make_tuple(1, 2);    // 两个 int
std::get<int>(t);                  // ❌ 编译错误：int 不唯一
std::get<0>(t);                    // ✅ 用索引
```

按类型访问要求该类型在 tuple 中唯一。

### 错误 3：忘记 `tie` 的左值语义

```cpp
std::tuple<int,int> f() { return {1, 2}; }
int a, b;
std::tie(a, b) = f();    // ✅ tie 返回引用 tuple，赋值写入 a, b
// 对比：auto t = f();   // 这是拷贝到 t，不写入 a, b
```

## 自测题

**1. 选择题**：`std::tuple<int, double, std::string> t{1, 2.0, "hi"};` 以下哪个访问**合法**？

A. `std::get<3>(t)`
B. `std::get<double>(t)`
C. `std::get<int>(t)`
D. `t[0]`

<details>
<summary>答案</summary>

**B**。A 越界（只有 3 个元素，索引 0-2）；C 的 `int` 虽然唯一合法，但选项 B 也合法且更典型；D 错误——`tuple` 不支持 `[]` 运算符，只能用 `get`。`get<double>` 因 double 唯一而合法。若问"哪个非法"，答案是 A 和 D。

</details>

**2. 判断题**：`std::tuple` 的大小（元素个数）在编译期确定，不能运行期改变。

<details>
<summary>答案</summary>

**对**。`tuple` 是固定大小的模板，元素个数和类型在编译期已确定。若需运行期可变长度的异构容器，考虑 `std::vector<std::variant<...>>` 或 `std::any`。

</details>

**3. 踩坑题**：以下代码有什么问题？

```cpp
std::tuple<int, int> get_coords() { return {3, 4}; }
int main() {
    int x, y;
    auto t = get_coords();
    std::tie(x, y);
    std::cout << x << " " << y;
}
```

<details>
<summary>答案</summary>

`std::tie(x, y)` 只是构造了一个引用 tuple，没有赋值——`x`/`y` 仍为未初始化。正确写法是 `std::tie(x, y) = get_coords();`（tie 在等号左边）。或用 C++17 结构化绑定：`auto [x, y] = get_coords();`。

</details>

**4. 应用题**：写一个函数 `divide(int a, int b)` 返回 `(商, 余数, 是否成功)`，成功时 `true`，除零时 `false`。用 `tuple` 返回，调用方用结构化绑定接收。

<details>
<summary>答案</summary>

```cpp
#include <tuple>
std::tuple<int, int, bool> divide(int a, int b) {
    if (b == 0) return {0, 0, false};
    return {a / b, a % b, true};
}
int main() {
    auto [q, r, ok] = divide(17, 5);    // C++17 结构化绑定
    if (ok) std::cout << q << " " << r;  // 3 2
    auto [q2, r2, ok2] = divide(10, 0);
    if (!ok2) std::cout << "div by zero";
}
```

要点：`tuple` 打包多返回值、结构化绑定一行解包、`ok` 标志处理错误（也可用 `std::optional<tuple>`）。

</details>
