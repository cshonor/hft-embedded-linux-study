# bitset 位集

## 本节讲什么

本节讲解 `std::bitset`——一个**编译期固定大小**的二进制位容器，专门做位运算（与、或、异或、置位、清位、翻转、计数）。它比手写 `unsigned int` + 位操作更安全（有边界检查接口）、更易读（`bs.set(3)` vs `flags |= (1<<3)`）、且支持任意位数（不限于 64）。

> **一句话定位**：`bitset` = "类型安全的位标志数组"，权限掩码、状态标记的高效工具。

## 核心用法

### 1. 构造

```cpp
#include <bitset>
std::bitset<8> b1;                    // 全 0：00000000
std::bitset<8> b2(0xFF);              // 从整数：11111111
std::bitset<8> b3("10101010");        // 从字符串：10101010
std::bitset<16> b4(0xABCD);           // 1010101111001101
```

`bitset<N>` 的 `N` 是**编译期常量**（模板非类型参数），不同 `N` 是不同类型。

### 2. 位操作

```cpp
std::bitset<8> b("10101010");
b.set(0);          // 置位第 0 位：10101011
b.reset(0);        // 清位第 0 位：10101010
b.flip(0);         // 翻转第 0 位：10101011
b.flip();          // 全部翻转：01010100
b[0];              // 访问第 0 位（返回代理引用，可读可写）
b.test(0);         // 测试第 0 位（返回 bool，有边界检查）
b.any();           // 是否有任意 1
b.none();          // 是否全 0
b.count();         // 1 的个数
b.size();          // 总位数（编译期已知）
b.all();           // 是否全 1
```

### 3. 位运算

`bitset` 重载了 `&`/`|`/`^`/`~`/`<<`/`>>`，像整数一样运算：

```cpp
std::bitset<8> a("11001010");
std::bitset<8> b("10110101");
auto c = a & b;    // 按位与：10000000
auto d = a | b;    // 按位或：11111111
auto e = a ^ b;    // 按位异或：01111111
auto f = ~a;       // 按位取反：00110101
auto g = a << 2;   // 左移 2 位
```

### 4. 转换

```cpp
std::bitset<8> b("10101010");
b.to_string();     // "10101010"
b.to_ulong();      // 170（unsigned long）
b.to_ullong();     // 170（unsigned long long，C++11）
```

### 5. 典型场景

```cpp
// 权限掩码
std::bitset<4> permissions("1010");   // 读=1, 写=0, 执行=1, 删除=0
if (permissions.test(0)) { /* 可删除 */ }

// 状态标记集合
std::bitset<32> flags;
flags.set(3);    // 标记第 3 号事件发生
if (flags.any()) { /* 有事件 */ }

// 布尔数组（比 vector<bool> 或 bool[] 省内存 8 倍）
std::bitset<1000> present;   // 1000 个布尔，只用 125 字节
```

## 和 C 的区别

C 用 `unsigned int` + 位操作，手写掩码：

| 维度 | C（unsigned int + 宏） | C++ bitset |
|------|--------------------|-----------|
| 位数 | 限于 32/64 | 任意编译期常量 |
| 边界检查 | 无（越界 UB） | `test()` 有检查 |
| 可读性 | `flags |= (1<<3)` | `flags.set(3)` |
| 运算 | 手写 `&`/`\|` | 重载运算符 |
| 字符串/整数转换 | 手写 | `to_string`/`to_ulong` |

```c
// C：手写位操作
unsigned int flags = 0;
flags |= (1u << 3);          // 置位 3
flags &= ~(1u << 3);         // 清位 3
if (flags & (1u << 3)) { }   // 测试位 3
int count = __builtin_popcount(flags);  // 数 1（GCC 扩展，非标准）
// 超过 32 位要手动拼接多个 int
```

```cpp
// C++：bitset
std::bitset<64> flags;
flags.set(3);
flags.reset(3);
if (flags.test(3)) { }
int count = flags.count();   // 标准、可移植
```

> **HFT 视角**：`bitset` 的位操作编译后通常是一条 CPU 指令（`AND`/`OR`/`POPCNT`），零额外开销。权限检查、状态标记用 `bitset` 比手写掩码更清晰，且性能不损。

## 常见错误

### 错误 1：大小不是编译期常量

```cpp
int n = 64;
std::bitset<n> b;     // ❌ n 不是编译期常量
constexpr int N = 64;
std::bitset<N> b2;    // ✅
```

`bitset` 的 `N` 是模板非类型参数，必须编译期常量。运行期可变大小用 `std::vector<bool>`（虽有争议，但能动态扩容）。

### 错误 2：`[]` 越界无检查

```cpp
std::bitset<8> b;
b[10] = 1;    // ❌ 越界，未定义行为（[] 不检查边界）
b.test(10);   // 抛 std::out_of_range 异常（test 有检查）
```

`operator[]` 不检查边界（性能优先），`test()` 检查。调试期用 `test()`，确认无误后可用 `[]`。

### 错误 3：`to_ulong` 溢出

```cpp
std::bitset<64> b("1111111111111111111111111111111111111111111111111111111111111111");
b.to_ulong();    // ❌ 若值超 unsigned long 范围，抛 overflow_error
b.to_ullong();   // C++11，用 unsigned long long，范围更大但仍可能溢出
```

`bitset` 大小可以超过 `unsigned long` 位数，此时 `to_ulong` 会溢出抛异常。检查 `size() <= sizeof(unsigned long)*8` 再转换。

## 自测题

**1. 选择题**：`std::bitset<8> b("10101010"); b.count()` 返回什么？

A. 8（总位数）
B. 4（1 的个数）
C. 170（整数值）
D. 0

<details>
<summary>答案</summary>

**B**。`count()` 返回 **1 的个数**，"10101010" 有 4 个 1。`size()` 返回总位数 8，`to_ulong()` 返回整数值 170。

</details>

**2. 判断题**：`std::bitset<N>` 的 `N` 可以是运行期变量。

<details>
<summary>答案</summary>

**错**。`N` 是模板非类型参数，必须是**编译期常量**（字面量、`constexpr`、枚举）。运行期可变大小需用 `std::vector<bool>` 或自己管理动态位数组。

</details>

**3. 踩坑题**：以下代码有什么问题？

```cpp
std::bitset<8> b;
for (int i = 0; i <= 8; ++i) b[i] = 1;
```

<details>
<summary>答案</summary>

`i <= 8` 越界——`bitset<8>` 的合法索引是 0-7。`b[8]` 是未定义行为（`operator[]` 不检查边界）。应改为 `i < 8`。若用 `b.set(i)` 仍越界但会抛异常（`set` 带边界检查）；`operator[]` 不检查是为了性能。

</details>

**4. 应用题**：用 `bitset` 实现一个简单的权限系统——4 种权限（读/写/执行/删除），函数 `can(permission_set, perm)` 检查是否有某权限。

<details>
<summary>答案</summary>

```cpp
#include <bitset>
#include <iostream>
enum Perm { READ = 0, WRITE = 1, EXEC = 2, DELETE = 3 };
bool can(const std::bitset<4> &perms, Perm p) {
    return perms.test(p);
}
int main() {
    std::bitset<4> user_perms("1010");   // 读=1, 写=0, 执行=1, 删除=0
    std::cout << can(user_perms, READ);    // 1
    std::cout << can(user_perms, WRITE);   // 0
    std::cout << can(user_perms, DELETE);  // 0
}
```

要点：`enum` 定义权限位、`bitset<4>` 存权限、`test()` 安全检查、字符串初始化直观。

</details>
