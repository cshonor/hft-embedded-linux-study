# 6.1 函数基础与参数传递

## 本节讲什么

函数的组成（返回类型、函数名、形参列表、函数体），以及 C++ 两种关键的参数传递方式：**传值**和**传引用**。传引用是 C 没有、C 程序员必须掌握的特性。

## 核心用法

### 函数形参

| 形参形式 | 写法 | 作用 |
|---------|------|------|
| 传值 | `void f(int x)` | 拷贝实参，形参改动不影响实参 |
| 传引用 | `void f(int& x)` | 绑定实参，可改实参 |
| 传 const 引用 | `void f(const int& x)` | 绑定实参，只读，避免拷贝 |
| 传指针 | `void f(int* p)` | 通过指针改实参（C 也能） |
| 数组形参 | `void f(int* a)` / `void f(int a[])` | 退化为指针 |

### 传引用 vs 传指针

```cpp
// 传引用：语法更干净，函数体内直接用 x
void inc(int& x) { ++x; }
int a = 10;
inc(a);              // a 变 11，调用处看不出在修改

// 传指针：调用处要取地址，更明显
void inc(int* p) { ++(*p); }
int a = 10;
inc(&a);             // a 变 11，调用处知道会改
```

### 可变形参

```cpp
#include <initializer_list>
void log(std::initializer_list<int> args) {
    for (auto x : args) std::cout << x << " ";
}
log({1, 2, 3, 4});   // 4 个参数
```

## 和 C 的区别

| 维度 | C | C++ |
|------|---|-----|
| 传值 | ✅ | ✅ |
| 传指针 | ✅ | ✅ |
| 传引用 | ❌ C 完全没有 | ✅ `&` 是 C++ 独有 |
| 传 const 引用避免拷贝 | ❌（只能传指针） | ✅ |
| 可变形参 | `va_list`（不安全，无类型检查） | `initializer_list<T>`（类型安全） |
| `main(int, char**)` | 一致 | 一致 |

**C 程序员最该学的**：传引用。C 里要让函数修改实参，只能传指针（`f(&a)`）；C++ 可以直接传引用（`f(a)`），代码更干净。但**只读大对象避免拷贝**用 `const T&` 是 C++ 的惯用法，C 做不到——C 里只能传指针（仍是间接寻址）或传值（拷贝开销）。

```c
/* C：要让函数改实参，必须传指针 */
void inc(int* p) { ++(*p); }
int a = 10; inc(&a);
```
```cpp
// C++：传引用，更干净
void inc(int& x) { ++x; }
int a = 10; inc(a);

// C++ 独有：const 引用避免拷贝大对象
void print(const std::string& s) { std::cout << s; }  // 不拷贝
```

## 常见错误

1. **传引用导致调用处看不出副作用**：`inc(a)` 表面看像传值，实际改了 `a`。大型工程里这降低可读性。**建议**：要修改实参用指针或非 const 引用，且命名体现（`out_param`）；只读用 `const T&`。
2. **`const T&` 绑定临时对象后长期使用**：`const std::string& s = compute();` 合法且延长临时对象生命周期，但若 `compute()` 返回引用指向已销毁对象则悬垂。区分"返回引用"和"返回值"。
3. **数组形参sizeof误判**：`void f(int a[10]) { int n = sizeof(a); }` —— `a` 退化为指针，`sizeof(a)` 是指针大小不是数组大小。C/C++ 共同坑。

## 自测题

**1. 选择题**：下面函数想避免拷贝又只读访问 `vector`，哪种形参最合适？
- A) `void f(std::vector<int> v)`
- B) `void f(std::vector<int>& v)`
- C) `void f(const std::vector<int>& v)`
- D) `void f(std::vector<int>* v)`

<details><summary>答案</summary>

C) `const std::vector<int>&`。`const` 保证只读，`&` 避免拷贝。A 会拷贝整个 vector；B 不能绑定 const 对象；D 要调用方取地址，且没 const 不保证只读。

</details>

**2. 判断题**：C++ 中 `void f(int& x)` 可以接受字面量 `f(42)`。

<details><summary>答案</summary>

错误。非 const 引用不能绑定到右值（字面量、临时对象）。`f(42)` 编译错误。如果要接受字面量，形参改为 `int x`（传值）或 `const int& x`（const 引用可绑定右值）。

</details>

**3. 踩坑题**：下面代码想返回数组的引用供调用者修改，但有问题吗？
```cpp
int (&f())[10] {
    int arr[10] = {0};
    return arr;     // 返回数组引用
}
```

<details><summary>答案</summary>

悬垂引用。`arr` 是局部数组，函数返回后销毁，返回的引用指向已释放内存，使用即 UB。**修正**：返回 `std::array`（值返回，会移动/拷贝），或返回堆上 `std::vector`，或传入外部数组引用由调用者管理。C++ 不要返回局部数组的指针/引用。

</details>

**4. 应用题**：写一个 `swap` 函数，分别用 C 指针风格和 C++ 引用风格实现，对比可读性。

<details><summary>答案</summary>

```cpp
// C 风格：指针
void swap_c(int* a, int* b) { int t=*a; *a=*b; *b=t; }
int x=1, y=2; swap_c(&x, &y);

// C++ 风格：引用
void swap_cpp(int& a, int& b) { int t=a; a=b; b=t; }
int x=1, y=2; swap_cpp(x, y);
```
引用版本函数体内 `a`、`b` 直接当变量用，无需解引用 `*a`，可读性好得多。标准库的 `std::swap` 就是引用风格。

</details>
