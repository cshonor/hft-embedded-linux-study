# 5.1 强制拷贝省略机制

> 第 5 章 强制拷贝省略与未物化传值 · 下一节：[5.2 未物化传值与返回值优化](02-未物化传值与返回值优化.md)

## 这节讲什么

C++17 之前，拷贝省略（copy elision）是编译器可选优化——可能做也可能不做，RVO/NRVO 不是保证的。C++17 规定了**强制性拷贝省略**（mandatory copy elision）——在某些场景下，编译器必须省略拷贝，不再当成优化。

## 为什么要学这个（先建立直觉）

C 程序员传结构体给函数：

```c
// C：值传递 = 拷贝整个结构体
struct Big { int data[1000]; };
void process(struct Big b) { ... }  // 拷贝 4000 字节

struct Big b = {{...}};
process(b);  // 拷贝一次
```

C++ 返回值也有类似问题：

```cpp
// C++14：返回大对象可能拷贝
std::vector<int> make_data() {
    std::vector<int> v(1000);
    // 填充 v...
    return v;  // 可能 NRVO 省略拷贝，但不保证
}

auto data = make_data();  // 可能再拷贝一次（RVO 省略，但不保证）
```

C++17 保证某些场景下不拷贝：

```cpp
// C++17：返回 prvalue 必须省略拷贝
std::vector<int> make_data() {
    return std::vector<int>(1000);  // prvalue，保证不拷贝
}

auto data = make_data();  // 保证不拷贝，直接在 data 的位置构造
```

## 什么是 prvalue 和"未物化"

C++17 引入了"值类别"新规则：

- **prvalue**（pure rvalue）：纯右值——还没有物化到内存中的值。如 `std::vector<int>(1000)`、`42`、`x + 1`
- **xvalue**（expiring value）：将亡值——即将移动的对象。如 `std::move(x)`
- **lvalue**：左值——有名字、有地址的对象。如 `x`

C++17 的核心变化：**prvalue 不再是对象**——它只是一个"值的描述"，只有在需要时才会"物化"（materialize）成临时对象。

## 强制省略的场景

### 场景 1：prvalue 初始化同类型对象

```cpp
// C++17：保证不拷贝
std::string s = std::string("hello");  // prvalue 初始化 s，直接构造

// 等价于
std::string s("hello");  // 直接构造，没有中间临时对象
```

### 场景 2：函数返回 prvalue

```cpp
std::vector<int> make() {
    return std::vector<int>(1000);  // 返回 prvalue
}

auto v = make();  // C++17 保证：vector 直接在 v 的位置构造
                  // 零拷贝、零移动
```

### 场景 3：函数参数传 prvalue

```cpp
void process(std::vector<int> v);

process(std::vector<int>(1000));  // C++17 保证：直接在参数位置构造
```

## 不保证省略的场景

### NRVO（Named Return Value Optimization）

```cpp
std::vector<int> make() {
    std::vector<int> v(1000);
    // 填充 v...
    return v;  // 命名变量，NRVO 是可选优化，不保证
}
```

C++17 不保证 NRVO——因为 `v` 是个有名字的对象，编译器理论上可以不省略。

### 传入已存在的对象

```cpp
std::vector<int> existing(1000);
auto copy = existing;  // 拷贝！不是省略
```

## 有可访问的拷贝/移动构造函数的要求

C++17 之前，即使编译器省略了拷贝，拷贝/移动构造函数仍然必须存在且可访问：

```cpp
// C++14：不可拷贝不可移动的类型
struct NonCopyable {
    NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable(NonCopyable&&) = delete;
};

NonCopyable make() {
    return NonCopyable();  // C++14：可能编译错误（拷贝构造被删除）
                           // 即使编译器想省略，规则要求拷贝构造可访问
}

// C++17：保证省略，不需要拷贝/移动构造函数
NonCopyable make() {
    return NonCopyable();  // C++17：OK！不需要拷贝/移动构造
}

auto x = make();  // C++17：OK！
```

这是 C++17 强制省略的最大实际影响——不可拷贝不可移动的类型可以通过 prvalue 返回。

## HFT 关联

```cpp
// 不可拷贝的独占资源（如 SPSC 队列）
struct RingBuffer {
    void* buf;
    size_t size;
    RingBuffer(size_t n) : buf(malloc(n)), size(n) {}
    ~RingBuffer() { free(buf); }
    RingBuffer(const RingBuffer&) = delete;  // 禁拷贝
    RingBuffer(RingBuffer&&) = delete;       // 禁移动
};

// C++17：可以返回不可拷贝不可移动的对象
RingBuffer make_ring(size_t n) {
    return RingBuffer(n);  // prvalue，强制省略
}

auto ring = make_ring(65536);  // 直接构造，零拷贝零移动
```

## 小结

| 场景 | C++14 | C++17 |
|------|-------|-------|
| prvalue 初始化 | 可选省略 | 强制省略 |
| 返回 prvalue | 可选 RVO | 强制省略 |
| 返回命名变量 | 可选 NRVO | 可选 NRVO（未变） |
| 需要拷贝构造可访问 | 是 | 否（prvalue 场景） |
