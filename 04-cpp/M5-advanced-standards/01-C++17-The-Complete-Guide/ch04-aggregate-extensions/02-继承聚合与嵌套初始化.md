# 4.2 继承聚合与嵌套初始化

> 第 4 章 聚合类型扩展 · 上一节：[4.1 聚合类型的定义变化](01-聚合类型定义变化.md)

## 这节讲什么

C++17 允许带基类的聚合类型用花括号初始化。本节深入讲解继承聚合的初始化语法、多继承场景、以及常见陷阱。

## 基本语法

```cpp
struct Base { int a; };
struct Derived : Base { int b; };

// 方式 1：扁平初始化（推荐）
Derived d1{1, 2};        // a=1, b=2

// 方式 2：显式基类初始化
Derived d2{{1}, 2};      // Base{1}, b=2

// 方式 3：双花括号（完全显式）
Derived d3{{1, 2}};      // 编译错误！a=1 后多了一个 2
// 正确：Base 只有一个成员
Derived d4{{1}};         // Base{a=1}, b 值初始化为 0
```

## 多继承聚合

```cpp
struct A { int a; };
struct B { int b; };
struct C : A, B { int c; };

// 扁平初始化
C c1{1, 2, 3};    // a=1, b=2, c=3

// 显式基类初始化
C c2{{1}, {2}, 3}; // A{1}, B{2}, c=3
```

### 基类顺序

```cpp
struct A { int a; };
struct B { int b; };
struct C : A, B { int c; };  // 先 A 后 B

C c{1, 2, 3};
// a=1 (A 先初始化)
// b=2 (B 后初始化)
// c=3 (C 自己的成员最后)
```

基类按**声明顺序**初始化，不是字母序。

## 嵌套聚合

```cpp
struct Inner { int x, y; };
struct Outer { Inner pos; int id; };

// 扁平（C++17 不支持，需要双花括号）
Outer o1{{1, 2}, 3};    // pos={1,2}, id=3

// C++17 聚合初始化不支持省略嵌套花括号（C++20 才支持 designated init）
```

## 带基类的嵌套聚合

```cpp
struct Base { int id; };
struct Derived : Base {
    int data[3];
    double value;
};

Derived d{{1}, {2, 3, 4}, 5.0};
// Base{id=1}
// data={2,3,4}
// value=5.0
```

## 常见陷阱

### 陷阱 1：扁平 vs 显式混淆

```cpp
struct Base { int a; };
struct Derived : Base { int b; };

Derived d1{1, 2};      // 扁平：a=1, b=2 ✅
Derived d2{{1, 2}};    // Base{a=1, b=2}？❌ Base 只有 a，2 是多余的
Derived d3{{1}, 2};    // Base{a=1}, b=2 ✅
```

### 陷阱 2：基类有多个成员时的花括号

```cpp
struct Base { int a, b; };
struct Derived : Base { int c; };

Derived d1{1, 2, 3};     // 扁平：a=1, b=2, c=3 ✅
Derived d2{{1, 2}, 3};   // Base{a=1, b=2}, c=3 ✅
Derived d3{{1}, 2, 3};   // Base{a=1}, b=??? ❌ 编译错误
```

### 陷阱 3：私有继承不是聚合

```cpp
struct Base { int a; };
struct Derived : private Base { int b; };  // 私有继承

Derived d{1, 2};  // ❌ 编译错误：私有基类 → 不是聚合
```

### 陷阱 4：有虚函数的基类

```cpp
struct Base { virtual void f() {} int a; };
struct Derived : Base { int b; };

Derived d{1, 2};  // ❌ Base 有虚函数 → Derived 不是聚合
```

## 聚合初始化 vs 构造函数

```cpp
// 方式 1：聚合初始化（无构造函数）
struct TickV1 {
    int ts;
    double price;
};
TickV1 t1{100, 12.5};  // 聚合初始化

// 方式 2：构造函数
struct TickV2 {
    int ts;
    double price;
    TickV2(int t, double p) : ts(t), price(p) {}
};
TickV2 t2{100, 12.5};  // 构造函数调用

// 性能差异：无（编译器优化后一样）
// 灵活性：聚合初始化更简单，但不能做参数校验
```

## HFT 关联

```cpp
// HFT 消息头 + 消息体
struct MsgHeader {
    uint32_t seq;
    uint32_t ts;
    uint16_t type;
    uint16_t size;
};

struct OrderMsg : MsgHeader {
    uint32_t symbol_id;
    double price;
    uint32_t qty;
    uint8_t side;
    uint8_t padding[3];
};

// 零开销初始化
OrderMsg msg{
    {1, 1000, 0x01, sizeof(OrderMsg)},  // header
    1001, 12.5, 200, 1                  // body
};
// 直接内存布局，无构造函数开销
```

## 小结

| 初始化方式 | 语法 | 适用 |
|-----------|------|------|
| 扁平 | `D{1, 2, 3}` | 简单继承 |
| 显式基类 | `D{{1}, 2}` | 多继承/嵌套 |
| 嵌套 | `O{{1,2}, 3}` | 含子对象 |
