# 4.1 聚合类型的定义变化

> 第 4 章 聚合类型扩展 · 下一节：[4.2 继承聚合与嵌套初始化](02-继承聚合与嵌套初始化.md)

## 这节讲什么

C++17 重新定义了"聚合类型"（aggregate），放宽了限制——有基类的类也可以是聚合，只要有公开的非虚基类。这让继承结构的对象可以用花括号直接初始化，不需要构造函数。

## 什么是聚合类型

聚合类型是"纯数据"类型——没有用户定义构造函数、没有私有/保护非静态成员、没有虚函数、没有虚基类。C++17 之前还要求"没有基类"，C++17 放宽了这条。

### C++14 的聚合定义

```cpp
// C++14 聚合类型
struct Point { int x, y; };           // ✅ 聚合
struct Data { int a; double b; };     // ✅ 聚合

// C++14 非聚合
struct Derived : Base { int x; };     // ❌ 有基类，不是聚合
struct WithCtor { int x; WithCtor(){}; }; // ❌ 有用户构造函数
```

### C++17 的聚合定义

```cpp
// C++17 新增：有公开非虚基类也可以是聚合
struct Base { int a; };
struct Derived : Base { int b; };  // ✅ C++17 聚合！

// 仍然不是聚合
struct WithCtor { int x; WithCtor(){}; };          // ❌ 有构造函数
struct Private { private: int x; public: int y; }; // ❌ 有私有成员
struct Virtual : virtual Base { int x; };          // ❌ 有虚基类
struct Abstract { virtual void f() = 0; };          // ❌ 有虚函数
```

## 聚合初始化

聚合类型可以用花括号直接初始化，不需要构造函数：

```cpp
// 基本聚合初始化
struct Point { int x, y; };
Point p{1, 2};  // 聚合初始化，不需要构造函数

// C++17 带基类的聚合初始化
struct Base { int a; };
struct Derived : Base { int b; };

Derived d{1, 2};       // a=1, b=2（先基类后派生类）
Derived d2{{1}, 2};    // 显式基类初始化
```

### 初始化顺序

```cpp
struct Base { int a; int b; };
struct Derived : Base { int c; int d; };

Derived d{1, 2, 3, 4};
// a=1, b=2 (Base 的成员)
// c=3, d=4 (Derived 的成员)
// 顺序：先基类成员（声明序），后派生类成员（声明序）
```

## C++17 聚合类型完整定义

一个类型是聚合类型，当且仅当：
1. 是类类型（struct/class/union）
2. 没有**用户声明**的构造函数（`= default` 和 `= delete` 不算用户声明）
3. 没有私有或保护的非静态数据成员
4. 没有虚函数
5. 没有虚基类
6. 没有私有/保护的直接基类（C++17 新增条件）

### `= default` 不破坏聚合

```cpp
struct Point {
    int x, y;
    Point() = default;  // ✅ 仍然是聚合！
};

Point p{1, 2};  // OK
```

### `= delete` 也不破坏聚合

```cpp
struct Point {
    int x, y;
    Point() = delete;  // ✅ 仍然是聚合！
};

// Point p;       // 编译错误：默认构造被删除
Point p{1, 2};    // OK：聚合初始化不走默认构造
```

## HFT 关联

```cpp
// HFT tick 数据结构：纯数据，用聚合初始化
struct TickHeader {
    uint32_t ts;
    uint32_t symbol_id;
};

struct Tick : TickHeader {  // 继承基类
    double price;
    uint32_t qty;
};

// C++17 聚合初始化
Tick t{1000, 1, 12.5, 200};
// ts=1000, symbol_id=1, price=12.5, qty=200

// 零开销：没有构造函数调用，直接内存布局
```

## 小结

| 条件 | C++14 | C++17 |
|------|-------|-------|
| 有公开基类 | ❌ 非聚合 | ✅ 聚合 |
| 有虚基类 | ❌ | ❌ |
| 有用户构造函数 | ❌ | ❌ |
| 有 `= default` 构造 | ❌ (C++14) | ✅ (C++17) |
| 有私有成员 | ❌ | ❌ |
