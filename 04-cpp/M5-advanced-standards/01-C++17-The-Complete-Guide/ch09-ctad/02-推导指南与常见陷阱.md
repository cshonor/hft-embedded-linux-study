# 9.2 推导指南与常见陷阱

> 第 9 章 CTAD · 上一节：[9.1 CTAD 基本概念](01-CTAD基本概念.md)

## 这节讲什么

CTAD 不总是能正确推导——有时编译器推导出的类型不是你想要的。C++17 引入"推导指南"（deduction guide）来指导编译器。本节讲解推导指南的写法和常见陷阱。

## 推导指南

### 问题：推导结果不符合预期

```cpp
std::vector v = {1, 2, 3};  // vector<int> ✅

// 但字符数组呢？
std::vector v = {"hello", "world"};  // vector<const char*>，不是 vector<string>!
```

### 标准库的推导指南

标准库为 `vector` 提供了推导指南：

```cpp
// 标准库内部（简化）
template<typename T, typename Alloc = std::allocator<T>>
class vector {
public:
    vector(std::initializer_list<T> il, const Alloc& = Alloc());
};

// 推导指南：从 initializer_list 推导 T
template<typename T> vector(std::initializer_list<T>) -> vector<T>;
```

### 自定义推导指南

```cpp
// 自定义容器
template<typename T>
struct MyContainer {
    MyContainer(T val) : value(val) {}
    T value;
};

// 默认推导
MyContainer c(42);     // MyContainer<int>

// 添加推导指南：字符串字面量 → string
MyContainer(const char*) -> MyContainer<std::string>;

// 现在：
MyContainer s("hello"); // MyContainer<std::string>（不是 MyContainer<const char*>）
```

### 推导指南语法

```cpp
// ClassName(参数列表) -> ClassName<模板参数>;
template<typename T>
Wrapper(T) -> Wrapper<std::decay_t<T>>;  // 衰减：数组→指针，引用→值
```

## 常见陷阱

### 陷阱 1：字符串字面量推导为 const char*

```cpp
std::pair p(1, "hello");  // pair<int, const char*>，不是 pair<int, string>!

// 如果需要 string，显式写
std::pair<int, std::string> p(1, "hello");
```

### 陷阱 2：数值类型窄化

```cpp
std::pair p(1, 2.0);   // pair<int, double>
std::pair p(1.0, 2);   // pair<double, int>

// 但：
// std::pair p(1, 2.0);  // int, double
// 如果想要 pair<double, double>：
std::pair<double, double> p(1, 2.0);  // 显式写
```

### 陷阱 3：CTAD 不适用于聚合初始化（有时）

```cpp
template<typename T>
struct Point {
    T x, y;
};

// C++17：聚合类型 CTAD 可能不支持（取决于编译器版本）
// Point p(1, 2);       // 可能编译错误
Point<int> p(1, 2);    // 显式写模板参数

// C++20：聚合类型 CTAD 更完善
// Point p(1, 2);       // C++20: OK
```

### 陷阱 4：继承构造函数的 CTAD

```cpp
template<typename T>
struct Base {
    Base(T val) {}
};

struct Derived : Base<int> {
    using Base::Base;
};

// Derived d(42);  // CTAD 可能不工作（继承构造函数的推导有限制）
Derived d(42);     // 可能需要显式写
```

### 陷阱 5：默认模板参数不参与推导

```cpp
template<typename T, typename Alloc = std::allocator<T>>
class MyVec {};

// MyVec v = {1, 2, 3};  // 需要推导指南才能推导 Alloc
// 标准库为 vector 提供了推导指南
```

## 实际用法

### 工厂函数 + CTAD

```cpp
// 自定义推导指南
template<typename T>
struct Result {
    T value;
    int code;
    Result(T v, int c) : value(v), code(c) {}
};

// 推导指南
template<typename T>
Result(T, int) -> Result<T>;

// 使用
Result r(42, 0);         // Result<int>
Result r2("ok", 1);      // Result<const char*>
```

### 标准库中的推导指南示例

```cpp
// std::array 推导指南
std::array a{1, 2, 3, 4};  // array<int, 4>（推导元素类型和大小）

// std::span（C++20）
int arr[] = {1, 2, 3};
std::span s(arr);          // span<int, 3>（C++20）

// std::optional
std::optional o(42);       // optional<int>
```

## HFT 关联

```cpp
// 简化类型声明
template<typename T>
struct RingBuffer {
    RingBuffer(size_t n) : size_(n) {}
    size_t size_;
    T data_[];
};

// 推导指南
template<typename T>
RingBuffer(size_t, T) -> RingBuffer<T>;

// 使用
RingBuffer rb(65536, 0);  // RingBuffer<int>

// 避免写出冗长的模板类型
auto lock = std::lock_guard(mtx);  // 不用写 lock_guard<std::mutex>
```

## 小结

| 概念 | 说明 |
|------|------|
| 推导指南 | `ClassName(参数) -> ClassName<T>` |
| 字符串字面量 | CTAD 推导为 `const char*`，不是 `string` |
| 聚合 CTAD | C++17 支持有限，C++20 完善 |
| 显式写模板参数 | 不确定时最安全的选择 |
