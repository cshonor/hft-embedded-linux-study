导读

本章讲什么

C++17 仍不能直接用字符串字面量做模板参数（C++20 才行），但本章讲几种变通方法实现"字符串编译期参数化"——用于策略名、日志标签等的编译期传递。

要点

问题：字符串字面量为什么不能直接做模板参数

template <const char* N>
struct Named {};
Named<"foo"> x;   // 编译错！字符串字面量是 const char[N]，不是指针，且无链接

模板的非类型参数（NTTP）要求有外部链接的地址，字符串字面量是 static 链接的数组，不满足。

变通方法 1：外部链接的变量

extern const char NAME[] = "foo";   // 外部链接
Named<NAME> x;   // OK

缺点：每个名字要在 namespace 作用域定义一个变量，啰嗦。

变通方法 2：固定长度字符数组

template <size_t N>
struct FixedString {
    char data[N];
    constexpr FixedString(const char (&s)[N]) {
        std::copy_n(s, N, data);
    }
};

template <FixedString S>
struct Named {
    static constexpr const char* name = S.data;
};

Named<"foo"> x;   // C++17 OK！FixedString 是字面量类型，可做 NTTP

这是 C++17 最常用的方法。FixedString 是字面量类型（constexpr 构造），可作 NTTP。C++20 直接支持字符串字面量做 NTTP，此法就不必要了。

变通方法 3：std::string_view（运行期）

constexpr std::string_view name = "foo";   // 但 string_view 不能做 NTTP（C++17）

string_view 在 C++17 不是字面量类型的 NTTP 候选（构造函数非 constexpr 直到 C++20 某些实现）。

用途

  • 编译期策略名：Strategy<"Alpha"> 类型本身带名字，日志/调试无需存字符串。
  • 编译期日志标签：Logger<"FEED"> 每个 logger 类型唯一，编译期解析。
  • 编译期配置键：Config<"timeout"> 类型安全的键。

HFT 关联

  • 编译期策略名：Strategy<FixedString{"Alpha"}> 让策略类型带名字，日志打印无需存运行期 string，零分配。
  • 编译期日志标签：Logger<"FEED"> 不同模块不同 logger 类型，编译期区分，运行期无字符串比较。
  • FixedString 技巧是 C++17 的过渡：C++20 直接支持字符串 NTTP，但 C++17 项目仍需此法。
  • 零开销：编译期处理，运行期只有固定字符串字面量，无堆分配。
  • 类型安全：Strategy<"Alpha"> 和 Strategy<"Beta"> 是不同类型，编译期防混淆。
12.1

字符串字面量作模板参数的挑战

第 12 章 字符串字面量作模板参数

这节讲什么

C++17 之前，字符串字面量不能直接作非类型模板参数（NTTP）。本节讲解为什么这是个问题，以及 C++17 的变通方案。

问题

// C++14：字符串字面量不能直接作模板参数
// template<const char* Name>  ← 需要外部链接的指针
// struct Config { static constexpr const char* name = Name; };

// 正确写法：需要外部链接
extern const char MY_NAME[] = "HFT";
template<const char* Name> struct Config { /* ... */ };
Config<MY_NAME> cfg;  // OK，但 MY_NAME 必须是 extern

为什么不能直接用字面量？

字符串字面量 "hello" 的类型是 const char[6]，但数组到指针的衰减在模板参数推导中有限制。C++14 要求非类型模板参数必须是编译期常量表达式，而字符串字面量的地址在不同翻译单元中可能不同。

C++17 的改进

C++17 放宽了 NTTP 的限制，允许更多类型（包括 constexpr 构造的类），但仍不能直接用字符串字面量。

变通方案 1：用 const char* + extern

// header.h
extern constexpr char NAME[] = "HFT";  // C++17: constexpr extern
template<const char* N> struct Config { static const char* name() { return N; } };

// 使用
Config<NAME> cfg;

变通方案 2：用固定字符串结构

// 用结构体包装字符串
template<size_t N>
struct StringLiteral {
    constexpr StringLiteral(const char (&str)[N]) {
        for (size_t i = 0; i < N; ++i) value[i] = str[i];
    }
    char value[N];
};

// C++17：StringLiteral 可以作 NTTP（因为它是 literal type）
template<StringLiteral S>
struct NamedConfig {
    static constexpr const char* name() { return S.value; }
};

// 使用
NamedConfig<"HFT"> cfg;  // C++17: OK!
std::cout << cfg.name();  // "HFT"

变通方案 3：用 std::string_view（C++20 更好）

// C++20：string_view 可以作 NTTP
// template<std::string_view S>
// struct Config { static constexpr auto name = S; };

// Config<"HFT"> cfg;  // C++20: OK

// C++17 变通：用 const char* + 函数
template<auto S>
struct Config { static constexpr auto name = S; };

实际用法

编译期日志标签

// 用 StringLiteral 包装
template<StringLiteral Tag>
void log_msg(const char* msg) {
    std::cout << "[" << Tag.value << "] " << msg << "\n";
}

log_msg<"ORDER">("Order placed");
log_msg<"RISK">("Risk check passed");

配置名编译期绑定

template<StringLiteral Name>
struct NamedValue {
    static constexpr const char* name = Name.value;
    int value;
};

NamedValue<"max_qty"> max_q{1000};
NamedValue<"min_spread"> min_s{1};

C++20 预告

C++20 引入了 class NTTP（非类型模板参数可以是类类型），并且 std::string_view 是 literal type，可以直接作 NTTP：

// C++20
template<std::string_view S>
struct Config {
    static constexpr std::string_view name = S;
};

Config<"HFT"> cfg;  // C++20: 直接可用

HFT 关联

// 编译期绑定策略名
template<StringLiteral StrategyName>
class Strategy {
public:
    void on_tick(const Tick& t) {
        log<StrategyName>("tick received");
        // ...
    }
};

Strategy<"Alpha1"> alpha1;
Strategy<"MeanRev"> mean_rev;
// 每个策略实例在编译期绑定名字，运行时零开销

小结

方案 C++ 版本 复杂度
extern const char* C++14 低
StringLiteral 包装 C++17 中
string_view NTTP C++20 低

Q1constexpr 字符串处理
// C++17: constexpr 可以处理更多逻辑
constexpr int str_length(const char* s) {
    int n = 0;
    while (*s++) ++n;
    return n;
}
static_assert(str_length("hello") == 5);  // 编译期字符串长度

C++17 的 constexpr 相比 C++14 放宽了哪些限制？

答案与复习指引

C++17 constexpr 放宽： 1. 循环：允许 for/while（C++14 起允许） 2. 变量声明：允许在 constexpr 函数内声明局部变量（C++14 起允许非 const） 3. if/switch：允许 if 和 switch 语句 4. constexpr if（C++17 新增）：编译期条件分支 5. constexpr lambda（C++17 新增）

C++17 仍不能：动态内存分配（new/delete）、虚函数、try/catch（C++20 才放宽）。
