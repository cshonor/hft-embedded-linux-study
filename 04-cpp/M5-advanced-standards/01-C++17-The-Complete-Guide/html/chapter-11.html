导读

本章讲什么

C++17 让可变参数模板的参数包（args...）能用一个二元运算符"折叠"成一个值，替代 C++14 的递归展开模板。

要点

四种折叠

template <typename... Args>
auto sum(Args... args) {
    return (... + args);   // 一元右折叠：(args[0] + (args[1] + (... + args[n])))
}

template <typename... Args>
auto sum_left(Args... args) {
    return (args + ...);   // 一元左折叠：(((args[0] + args[1]) + ...) + args[n])
}

template <typename... Args>
auto sum_init(Args... args) {
    return (0 + ... + args);   // 二元左折叠：((0 + args[0]) + ...) + args[n]
}

template <typename... Args>
auto sum_init_right(Args... args) {
    return (args + ... + 0);   // 二元右折叠
}
形式 语法 含义
一元右折叠 (... op pack) (p1 op (p2 op (p3 op p4)))
一元左折叠 (pack op ...) (((p1 op p2) op p3) op p4)
二元右折叠 (pack op ... op init) (p1 op (p2 op (init op p4))) 等价
二元左折叠 (init op ... op pack) (((init op p1) op p2) op p3)

空包的默认值

一元折叠对空参数包： - && 折叠空包 → true - || 折叠空包 → false - , 折叠空包 → void() - 其他运算符折叠空包 → 编译错（需用二元折叠提供初值）

template <typename... Args>
bool all(Args... args) { return (... && args); }   // 空包返回 true

template <typename... Args>
auto sum(Args... args) { return (... + args); }    // 空包编译错！
template <typename... Args>
auto sum_safe(Args... args) { return (0 + ... + args); }  // 空包返回 0

实用例子

// 1. 打印所有参数
template <typename... Args>
void print(Args... args) {
    (std::cout << ... << args);   // 二元左折叠，初值 std::cout
}

// 2. 全部满足条件
template <typename... Args>
bool all_positive(Args... args) {
    return (... && (args > 0));
}

// 3. 逐个调用
template <typename F, typename... Args>
void for_each(F f, Args... args) {
    (f(args), ...);   // 一元左折叠逗号运算符
}

// 4. 检查所有类型
template <typename... Ts>
constexpr bool all_integral = (std::is_integral_v<Ts> && ...);

运算符可以是任意二元运算符

+、-、*、/、&&、||、,、->*、<<、>>、==、< 等都行。

HFT 关联

  • 编译期参数校验：constexpr bool all_numeric = (is_arithmetic_v<Ts> && ...); 静态断言所有模板参数是数值类型。
  • 批量字段序列化：(os << args, ...); 一行展开所有字段写入，替代手写递归。
  • 批量注册回调：(handlers.push_back(args), ...); 注册多个回调。
  • 编译期求和：策略参数表的元素总数用 (... + sizeof(Ts)) 编译期算。
  • 日志聚合：log(args...) 一行折叠输出，无运行期递归开销。
11.1

折叠表达式基础

第 11 章 折叠表达式 · 下一节：11.2 实际用法与常见模式

这节讲什么

C++17 折叠表达式（fold expression）让可变参数模板的展开变得极其简洁。C++14 需要递归模板或逗号表达式技巧，C++17 一行搞定。

为什么要学这个（先建立直觉）

C++14 可变参数求和：

// C++14：递归展开
int sum() { return 0; }  // 终止条件

template<typename T, typename... Args>
int sum(T first, Args... rest) {
    return first + sum(rest...);  // 递归
}

sum(1, 2, 3, 4);  // 10
// 需要 2 个函数 + 递归展开

C++17 折叠表达式：

// C++17：一行搞定
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 一元右折叠
}

sum(1, 2, 3, 4);  // 10
// 一个函数，无递归

四种折叠形式

一元右折叠（unary right fold）

(pack op ...)
// 展开：e1 op (e2 op (... op eN))

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);
    // 展开：1 + (2 + (3 + 4))
}

sum(1, 2, 3, 4);  // 10

一元左折叠（unary left fold）

(... op pack)
// 展开：((e1 op e2) op ...) op eN

template<typename... Args>
auto sum(Args... args) {
    return (... + args);
    // 展开：((1 + 2) + 3) + 4
}

sum(1, 2, 3, 4);  // 10

二元右折叠（binary right fold）

(pack op ... op init)
// 展开：e1 op (e2 op (... op (eN op init)))

template<typename... Args>
auto sum(Args... args) {
    return (args + ... + 0);  // init=0
    // 展开：1 + (2 + (3 + (4 + 0)))
}

sum();  // 0（空包，返回 init 值）

二元左折叠（binary left fold）

(init op ... op pack)
// 展开：(((init op e1) op e2) op ...) op eN

template<typename... Args>
auto sum(Args... args) {
    return (0 + ... + args);  // init=0
    // 展开：(((0 + 1) + 2) + 3) + 4
}

sum();  // 0（空包，返回 init 值）

左折叠 vs 右折叠的区别

对于 +（加法），左右折叠结果相同（加法可交换可结合）。但对于 -、/ 等不可交换的运算符：

template<typename... Args>
auto left_sub(Args... args) { return (... - args); }   // 左折叠
template<typename... Args>
auto right_sub(Args... args) { return (args - ...); }  // 右折叠

left_sub(10, 3, 2);   // ((10 - 3) - 2) = 5
right_sub(10, 3, 2);  // (10 - (3 - 2)) = 9

空包的处理

一元折叠（没有 init 值）对空包的行为：

运算符 空包结果
&& true
\|\| false
, void()
其他运算符 编译错误（空包不允许） 
template<typename... Args>
bool all_true(Args... args) {
    return (... && args);  // 一元左折叠
}

all_true(true, true, false);  // false
all_true(true, true);          // true
all_true();                    // true（空包 && → true）

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 一元右折叠
}
// sum();  // ❌ 编译错误：空包不能用 +

// 修正：用二元折叠加 init
template<typename... Args>
auto sum(Args... args) {
    return (args + ... + 0);  // 二元右折叠
}
sum();  // 0 ✅

HFT 关联

// 编译期校验所有约束
template<typename... Args>
constexpr bool all_integral() {
    return (std::is_integral_v<Args> && ...);
}

static_assert(all_integral<int, long, char>());
static_assert(!all_integral<int, double>());

// 批量打印
template<typename... Args>
void log(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << "\n";
}

log("ts=", 1000, " price=", 12.5, " qty=", 200);
// 输出: ts= 1000 price= 12.5 qty= 200

小结

形式 语法 展开
一元右折叠 (pack op ...) e1 op (e2 op (... op eN))
一元左折叠 (... op pack) ((e1 op e2) op ...) op eN
二元右折叠 (pack op ... op init) e1 op (e2 op (... op (eN op init)))
二元左折叠 (init op ... op pack) (((init op e1) op e2) op ...) op eN

11.2

实际用法与常见模式

第 11 章 折叠表达式 · 上一节：11.1 折叠表达式基础

这节讲什么

本节展示折叠表达式在实际工程中的常见模式：批量调用、编译期校验、可变参数遍历、链式操作等。

模式 1：批量函数调用

// 调用多个回调
template<typename... Callbacks>
void notify_all(Callbacks... cbs) {
    (cbs(), ...);  // 逐个调用
}

notify_all(
    [] { std::cout << "cb1\n"; },
    [] { std::cout << "cb2\n"; },
    [] { std::cout << "cb3\n"; }
);
// 输出: cb1 cb2 cb3

模式 2：编译期约束校验

// 检查所有类型是否满足约束
template<typename... Args>
constexpr bool all_integral_v = (std::is_integral_v<Args> && ...);

template<typename... Args>
constexpr bool any_floating_v = (std::is_floating_point_v<Args> || ...);

// 使用
static_assert(all_integral_v<int, long, char>);
static_assert(!all_integral_v<int, double>);
static_assert(any_floating_v<int, double, char>);

模式 3：可变参数遍历

// 遍历所有参数
template<typename... Args>
void for_each_arg(Args... args) {
    ((std::cout << args << "\n"), ...);
}

// 带索引遍历
template<typename... Args>
void for_each_indexed(Args... args) {
    size_t i = 0;
    ((std::cout << "[" << i++ << "] " << args << "\n"), ...);
}

for_each_indexed("a", 42, 3.14);
// [0] a
// [1] 42
// [2] 3.14

模式 4：可变参数 max/min

template<typename T, typename... Args>
T max_of(T first, Args... rest) {
    T result = first;
    ((result = rest > result ? rest : result), ...);
    return result;
}

max_of(1, 5, 3, 8, 2);  // 8

模式 5：字符串拼接

template<typename... Args>
std::string concat(Args... args) {
    std::string result;
    (result.append(std::to_string(args)), ...);
    return result;
}

// 或者用流
template<typename... Args>
std::string concat_str(Args... args) {
    std::ostringstream oss;
    (oss << ... << args);  // 二元左折叠，init=oss
    return oss.str();
}

模式 6：逗号折叠执行副作用

// 按顺序执行多个操作
template<typename... Fs>
void execute_all(Fs... fs) {
    (fs(), ...);  // 一元右折叠，逐个调用
}

// 带状态传递
template<typename State, typename... Fs>
State pipeline(State initial, Fs... fs) {
    State s = initial;
    ((s = fs(s)), ...);  // 每个 fs 接收并返回 State
    return s;
}

auto result = pipeline(
    0,
    [](int x) { return x + 1; },
    [](int x) { return x * 2; },
    [](int x) { return x - 3; }
);
// 0 → 1 → 2 → -1

模式 7：类型列表操作

// 编译期检查类型唯一性
template<typename T, typename... Rest>
constexpr bool contains() {
    return (std::is_same_v<T, Rest> || ...);
}

// 检查类型列表是否有重复
template<typename... Ts>
constexpr bool all_unique() {
    // 每个类型检查是否在后面的类型中出现
    size_t check[] = {
        (contains<Ts, Ts...>() ? 0 : 1)...  // 简化版
    };
    return true;  // 实际实现更复杂
}

模式 8：展开 lambda

// 编译期生成多个特化
template<typename... Ts>
void process_all(auto& container) {
    // 对每种类型调用 processor
    (process_one<Ts>(container), ...);
}

// 用法
process_all<int, double, float>(data);
// 展开：process_one<int>(data), process_one<double>(data), process_one<float>(data)

HFT 关联

// 批量风控检查
template<typename... Checks>
bool risk_check(const Order& ord, Checks... checks) {
    return (... && checks(ord));  // 全部通过才放行
}

auto ok = risk_check(order,
    [](const Order& o) { return o.qty > 0; },
    [](const Order& o) { return o.qty <= MAX_QTY; },
    [](const Order& o) { return o.price > 0; },
    [](const Order& o) { return o.price < MAX_PRICE; }
);

// 批量指标更新
template<typename... Metrics>
void update_metrics(uint64_t latency, Metrics&... metrics) {
    ((metrics.update(latency)), ...);
}

update_metrics(42, p50, p90, p99, max_latency);
// 一次性更新所有延迟分桶

小结

模式 折叠形式 用途
批量调用 (f(), ...) 逐个执行
约束校验 (cond && ...) 全部满足
累加 (args + ... + 0) 求和
max (result = max(result, args), ...) 求最大值
管道 (s = f(s), ...) 链式处理

章节自测

Q1可变参数模板的简化
// C++14: 递归展开
template<typename T>
auto sum14(T t) { return t; }
template<typename T, typename... Args>
auto sum14(T t, Args... args) { return t + sum14(args...); }

// C++17: fold expression
template<typename... Args>
auto sum17(Args... args) { return (args + ...); }

sum17(1, 2, 3, 4);  // 10

(args + ...) 是什么语法？有哪些 fold 形式？

答案与复习指引

fold expression 语法：(pack op ...) 或 (... op pack) 或 (pack op ... op init)。

形式 名称 展开
(args + ...) 一元右 fold ((a1 + a2) + a3) + ...
(... + args) 一元左 fold a1 + (a2 + (a3 + ...))
(args + ... + 0) 二元右 fold ((a1 + a2) + a3) + 0
(0 + ... + args) 二元左 fold 0 + (a1 + (a2 + ...))

二元 fold 的初始值：用于空包（零参数）的 fallback。(args + ... + 0) 空包返回 0；一元 fold 空包是编译错误（+ 无单位元）。

用途：打印所有参数(std::cout << ... << args)，检查全部为 true(args && ...)`。
