# 1.3 适用场景与限制

> 第 1 章 结构化绑定 · 上一节：[1.2 值语义与引用语义](02-值语义与引用语义.md)

## 这节讲什么

结构化绑定虽好，但不是万能的。了解它不能用在哪里、以及常见替代方案，才能在实际工程中正确选择。

## 不能用结构化绑定的场景

### 1. 有私有成员的类

```cpp
class Secret {
private:
    int secret_;
public:
    int pub;
    Secret(int s, int p) : secret_(s), pub(p) {}
};

Secret obj(42, 100);
auto [a, b] = obj;  // 编译错误：secret_ 是 private
```

**替代方案**：提供 getter 或用 tuple-like 协议（特化 `std::tuple_size` / `get<I>`）。

### 2. 绑定数量不匹配

```cpp
struct Triple { int a, b, c; };
Triple t{1, 2, 3};

auto [a, b] = t;    // 编译错误：2 != 3
auto [a, b, c, d] = t; // 编译错误：4 != 3
```

### 3. 不能直接忽略某些成员

```cpp
struct Triple { int a, b, c; };
Triple t{1, 2, 3};

// C++17 不能只绑定部分成员
auto [a, , c] = t;  // 编译错误：语法不支持

// 变通：用 std::tie + std::ignore（但不是结构化绑定）
int a, c;
std::tie(a, std::ignore, c) = std::make_tuple(1, 2, 3);

// C++26 将支持 [[maybe_unused]] 标记未用绑定
// auto [[maybe_unused]] a, b, c] = t;  // C++26
```

### 4. 不能用于位域

```cpp
struct Flags {
    unsigned a : 3;
    unsigned b : 5;
};
Flags f{1, 2};
auto [a, b] = f;  // 编译错误：不能绑定到位域
```

### 5. 不能嵌套结构化绑定

```cpp
struct Inner { int x, y; };
struct Outer { Inner a; int b; };
Outer o{{1, 2}, 3};

// C++17 不支持嵌套绑定
// auto [[x, y], b] = o;  // 编译错误（C++26 可能支持）

// 变通：分两步
auto [a, b] = o;
auto [x, y] = a;
```

## 最佳实践

### 默认用 const auto&

```cpp
// 好：默认只读引用
for (const auto& [key, val] : map) { ... }

// 需要修改才用 auto&
for (auto& [key, val] : map) { val.update(); }
```

### 不要对简单单成员用结构化绑定

```cpp
struct JustOne { int x; };
JustOne obj{42};

auto [x] = obj;  // 可以，但多此一举
int x = obj.x;   // 更直接
```

### 配合 if-init 使用

```cpp
// if-init + 结构化绑定
if (auto [it, inserted] = m.try_emplace(key, val); inserted) {
    // 新插入
} else {
    // 已存在，it 指向已有元素
}
```

## 为自定义类型启用结构化绑定

### 方法 1：公有结构体（最简单）

```cpp
struct Vector3 { float x, y, z; };  // 全 public
Vector3 v{1, 2, 3};
auto [x, y, z] = v;  // 直接可用
```

### 方法 2：tuple-like 协议（给有封装的类用）

```cpp
class Order {
    int id_; double price_;
public:
    Order(int id, double p) : id_(id), price_(p) {}
    int id() const { return id_; }
    double price() const { return price_; }
};

// 特化 tuple_size
template<> struct std::tuple_size<Order> { static constexpr int value = 2; };

// 特化 tuple_element
template<> struct std::tuple_element<0, Order> { using type = int; };
template<> struct std::tuple_element<1, Order> { using type = double; };

// 特化 get
template<size_t I> auto get(const Order& o) {
    if constexpr (I == 0) return o.id();
    else return o.price();
}

// 现在可以用了
Order ord{1001, 12.5};
auto [id, price] = ord;  // id=1001, price=12.5
```

## HFT 场景应用

```cpp
// 1. tick 解包
struct Tick { uint32_t ts; double price; uint32_t qty; };
auto [ts, price, qty] = recv_tick();

// 2. map 遍历合约表
for (const auto& [symbol, book] : order_books) {
    if (book.best_bid() > threshold) { ... }
}

// 3. pair 返回值解包
auto [ptr, ok] = pool.allocate(size);
if (!ok) handle_oom();

// 4. if-init 配合
if (auto [it, inserted] = cache.try_emplace(key, compute()); inserted) {
    // 新缓存项
}
```

## 小结

| 场景 | 能用？ | 替代方案 |
|------|--------|---------|
| 全 public 结构体 | ✅ | — |
| 有 private 成员的类 | ❌ | tuple-like 协议 / getter |
| 原生数组 | ✅ | — |
| pair/tuple/array | ✅ | — |
| 位域 | ❌ | 手动取成员 |
| 嵌套解包 | ❌ (C++17) | 分步绑定 |
| 忽略成员 | ❌ (C++17) | `std::tie` + `std::ignore` |
