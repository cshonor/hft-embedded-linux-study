# 11.1 折叠表达式基础

> 第 11 章 折叠表达式 · 下一节：[11.2 实际用法与常见模式](02-实际用法与常见模式.md)

## 这节讲什么

C++17 折叠表达式（fold expression）让可变参数模板的展开变得极其简洁。C++14 需要递归模板或逗号表达式技巧，C++17 一行搞定。

## 为什么要学这个（先建立直觉）

C++14 可变参数求和：

```cpp
// C++14：递归展开
int sum() { return 0; }  // 终止条件

template<typename T, typename... Args>
int sum(T first, Args... rest) {
    return first + sum(rest...);  // 递归
}

sum(1, 2, 3, 4);  // 10
// 需要 2 个函数 + 递归展开
```

C++17 折叠表达式：

```cpp
// C++17：一行搞定
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 一元右折叠
}

sum(1, 2, 3, 4);  // 10
// 一个函数，无递归
```

## 四种折叠形式

### 一元右折叠（unary right fold）

```cpp
(pack op ...)
// 展开：e1 op (e2 op (... op eN))
```

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);
    // 展开：1 + (2 + (3 + 4))
}

sum(1, 2, 3, 4);  // 10
```

### 一元左折叠（unary left fold）

```cpp
(... op pack)
// 展开：((e1 op e2) op ...) op eN
```

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (... + args);
    // 展开：((1 + 2) + 3) + 4
}

sum(1, 2, 3, 4);  // 10
```

### 二元右折叠（binary right fold）

```cpp
(pack op ... op init)
// 展开：e1 op (e2 op (... op (eN op init)))
```

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ... + 0);  // init=0
    // 展开：1 + (2 + (3 + (4 + 0)))
}

sum();  // 0（空包，返回 init 值）
```

### 二元左折叠（binary left fold）

```cpp
(init op ... op pack)
// 展开：(((init op e1) op e2) op ...) op eN
```

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (0 + ... + args);  // init=0
    // 展开：(((0 + 1) + 2) + 3) + 4
}

sum();  // 0（空包，返回 init 值）
```

## 左折叠 vs 右折叠的区别

对于 `+`（加法），左右折叠结果相同（加法可交换可结合）。但对于 `-`、`/` 等不可交换的运算符：

```cpp
template<typename... Args>
auto left_sub(Args... args) { return (... - args); }   // 左折叠
template<typename... Args>
auto right_sub(Args... args) { return (args - ...); }  // 右折叠

left_sub(10, 3, 2);   // ((10 - 3) - 2) = 5
right_sub(10, 3, 2);  // (10 - (3 - 2)) = 9
```

## 空包的处理

一元折叠（没有 init 值）对空包的行为：

| 运算符 | 空包结果 |
|--------|---------|
| `&&` | `true` |
| `\|\|` | `false` |
| `,` | `void()` |
| 其他运算符 | **编译错误**（空包不允许） |

```cpp
template<typename... Args>
bool all_true(Args... args) {
    return (... && args);  // 一元左折叠
}

all_true(true, true, false);  // false
all_true(true, true);          // true
all_true();                    // true（空包 && → true）

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 一元右折叠
}
// sum();  // ❌ 编译错误：空包不能用 +

// 修正：用二元折叠加 init
template<typename... Args>
auto sum(Args... args) {
    return (args + ... + 0);  // 二元右折叠
}
sum();  // 0 ✅
```

## HFT 关联

```cpp
// 编译期校验所有约束
template<typename... Args>
constexpr bool all_integral() {
    return (std::is_integral_v<Args> && ...);
}

static_assert(all_integral<int, long, char>());
static_assert(!all_integral<int, double>());

// 批量打印
template<typename... Args>
void log(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << "\n";
}

log("ts=", 1000, " price=", 12.5, " qty=", 200);
// 输出: ts= 1000 price= 12.5 qty= 200
```

## 小结

| 形式 | 语法 | 展开 |
|------|------|------|
| 一元右折叠 | `(pack op ...)` | `e1 op (e2 op (... op eN))` |
| 一元左折叠 | `(... op pack)` | `((e1 op e2) op ...) op eN` |
| 二元右折叠 | `(pack op ... op init)` | `e1 op (e2 op (... op (eN op init)))` |
| 二元左折叠 | `(init op ... op pack)` | `(((init op e1) op e2) op ...) op eN` |
