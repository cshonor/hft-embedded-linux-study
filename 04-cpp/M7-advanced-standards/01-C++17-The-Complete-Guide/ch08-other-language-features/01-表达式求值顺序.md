# 8.1 表达式求值顺序

> 第 8 章 其他语言特性 · 下一节：[8.2 UTF-8 字面量与 noexcept](02-utf8字面量与noexcept.md)

## 这节讲什么

C++17 重新规定了表达式求值顺序，解决了长期困扰 C++ 程序员的"不确定求值顺序"问题。这对写出正确的代码至关重要——C++14 之前很多看起来正确的代码实际上是 UB。

## C++14 的问题

```cpp
// C++14：求值顺序未定义
std::cout << f() << g() << h();
// f()/g()/h() 的调用顺序未定义！可能是任意顺序

// C++14：这行可能是 UB
int i = 0;
std::cout << i << i++;  // 先求值左边的 i 还是右边的 i++？未定义

// C++14：函数参数求值顺序未定义
foo(f(), g(), h());  // f/g/h 的调用顺序任意
```

## C++17 的新规则

### 1. `<<` 和 `>>` 运算符左结合求值

```cpp
// C++17：保证从左到右求值
std::cout << f() << g() << h();
// 保证 f() 先于 g() 先于 h() 调用
```

### 2. 赋值运算符右侧先于左侧

```cpp
// C++17：右侧先求值
a = b;
// 保证 b 先求值，然后 a

// 这解决了一个经典陷阱
int i = 0;
i = i++;  // C++14: UB。C++17: i = 0（右侧 i++ 先求值）
```

### 3. 后缀表达式从左到右

```cpp
// C++17：成员访问从左到右
a.b.c.d;  // a 先求值，然后 .b，然后 .c，然后 .d

a.b().c().d();  // 从左到右调用
```

### 4. 函数参数仍然未指定

```cpp
// C++17：函数参数求值顺序仍然未指定！
foo(f(), g(), h());  // f/g/h 的顺序仍然未定义
// 只是保证它们都在函数调用前完成
```

## 仍然未定义的场景

```cpp
// 函数参数顺序：仍然未定义
foo(f(), g());  // f 和 g 谁先？C++17 也不保证

// 重载运算符的参数：如果是函数调用形式
operator<<(std::cout, f()) << g();  // f 和 g 的顺序未定义

// 逗号表达式：仍然从左到右（C++17 未变）
a, b, c;  // 保证 a → b → c（逗号运算符一直是从左到右）
```

## 实际影响

### 修正的 bug

```cpp
// C++14：UB（求值顺序未定义）
int i = 0;
foo(i, i++);  // 可能 foo(0, 0) 或 foo(1, 0)

// C++17：仍然未定义（函数参数顺序未变）
// 但赋值修正了
i = i++;  // C++17: i = 0（右侧先求值）

// 流输出修正了
std::map<int, int> m;
m[0] = m.size();  // C++14: UB。C++17: m[0] = 0（右侧先求值）
```

### 安全的链式输出

```cpp
// C++17：保证顺序
std::cout << "ts=" << get_ts() << " price=" << get_price() << "\n";
// 保证 get_ts() 先于 get_price() 调用
// C++14 不保证
```

## HFT 关联

```cpp
// 日志输出顺序保证
log() << "[" << timestamp() << "] " << symbol() << " @ " << price() << "\n";
// C++17 保证 timestamp → symbol → price 的调用顺序

// 注意：函数参数仍然不保证
printf("%d %d %d\n", get_a(), get_b(), get_c());
// C++17 也不保证 get_a/get_b/get_c 的顺序！
// 如果有副作用依赖顺序，仍然有 bug
```

## 小结

| 表达式 | C++14 | C++17 |
|--------|-------|-------|
| `a << b << c` | 未定义 | 左→右 |
| `a = b` | 未定义 | 右→左 |
| `a.b.c` | 未定义 | 左→右 |
| `foo(f(), g())` | 未定义 | **仍然未定义** |
| `a, b, c`（逗号） | 左→右 | 左→右 |
