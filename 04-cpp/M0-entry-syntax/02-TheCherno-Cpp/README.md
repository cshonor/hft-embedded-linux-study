# The Cherno · C++ 系列（视频课笔记）

> **定位**：04-cpp / M0 的**视频补充**，与 [01-C++Primer](../01-C++Primer/) 互为对照 ——
> 视频给**直觉与工程动机**，Primer 给**标准条文与完整语法**。

## 为什么单独建一个目录

视频讲解是「心智模型」级别：它追求**五分钟让人会用**，因此会用「引用就是被隐藏的指针」这类简化说法。这话在 90% 的场景下好用，但在标准层面不成立——于是本系列笔记的写法是：

1. 保留视频的直觉与动机（**为什么要这么设计**）；
2. 逐条标注哪些是**简化说法**、哪些是**标准事实**；
3. 给出 cppreference 原文 + **本机 clang 23.1.0 实测**（汇编 / `sizeof` / 拷贝计数）。

> 原则：**不臆测视频内容**。凡视频里没明说、由本笔记补充的部分，都会标为「本节实测补充」。
