# 学习优先级与本章回顾

## 本节讲什么

本节是第 17 章的回顾与学习优先级建议——哪些工具业务开发必学、哪些可后学，以及一个综合示例把 `tuple` + `chrono` + `optional` 串起来。

## 学习优先级

| 工具 | 优先级 | 理由 |
|------|--------|------|
| **chrono 计时** | ⭐⭐⭐ 必学 | 性能调优、日志时间戳、定时——几乎所有项目都用 |
| **随机数 `<random>`** | ⭐⭐⭐ 必学 | 测试、仿真、抽奖；彻底替代 `rand()` |
| **tuple** | ⭐⭐ 常用 | 多返回值、异构打包；结构化绑定让解包优雅 |
| **optional** | ⭐⭐ 常用 | "可能失败的查找"标配，替代裸指针返回 |
| **regex 正则** | ⭐⭐ 常用 | 文本校验、提取；但性能敏感场景慎用 |
| **bitset** | ⭐ 按需 | 权限掩码、位标志；不涉及位操作可后学 |
| **variant/any** | ⭐ 按需 | 状态机、多类型值；简单场景可后学 |
| **numeric_limits** | ⭐ 按需 | 需要类型数值边界时查一下即可 |

> **业务开发路径**：先 chrono + 随机数 + tuple + optional（日常高频），再 regex（文本处理），其余按需学。

## 和 C 的区别（全章总览）

第 17 章的工具整体上体现了 C++ 相对 C 的"类型安全 + RAII + 标准化"优势：

| 工具 | C 对应 | C++ 优势 |
|------|--------|---------|
| tuple | 自定义 struct | 即用即写，无需预定义 |
| bitset | unsigned int + 宏 | 边界检查、任意位数、运算符重载 |
| regex | POSIX regex.h / 第三方 | 标准化、RAII、跨平台 |
| 随机数 | rand() | 质量、分布、可复现 |
| chrono | clock()/time() | 类型安全、纳秒、单调时钟 |
| optional | T* + nullptr | 栈上无悬垂 |
| variant | union | 类型安全标签 |
| numeric_limits | INT_MAX 宏 | 模板化、类型安全 |

**核心主题**：C 的工具靠"程序员记忆 + 约定"，C++ 的工具靠"编译器检查 + RAII"——同样的功能，C++ 版本更安全、更易读、更难出错。

## 综合示例

把本章几个工具串起来——一个"带计时的随机抽样配置查询"：

```cpp
#include <chrono>
#include <optional>
#include <random>
#include <string>
#include <unordered_map>
#include <iostream>
#include <tuple>

// 配置查找：可能失败，返回 optional
std::optional<std::string> get_config(
    const std::unordered_map<std::string, std::string> &cfg,
    const std::string &key) {
    auto it = cfg.find(key);
    if (it != cfg.end()) return it->second;
    return std::nullopt;
}

// 随机抽样：从 N 个元素中随机选一个索引
template <typename T>
size_t random_index(const T &container) {
    static std::mt19937 eng(std::random_device{}());
    std::uniform_int_distribution<size_t> dist(0, container.size() - 1);
    return dist(eng);
}

// 带计时的操作：返回 (结果, 耗时纳秒)
template <typename Func>
auto timed(Func f) {
    auto start = std::chrono::steady_clock::now();
    auto result = f();
    auto end = std::chrono::steady_clock::now();
    auto ns = std::chrono::duration_cast<std::chrono::nanoseconds>(end - start).count();
    return std::make_tuple(std::move(result), ns);
}

int main() {
    std::unordered_map<std::string, std::string> cfg = {
        {"host", "localhost"}, {"port", "8080"}, {"db", "test"}
    };
    std::vector<std::string> keys = {"host", "port", "db", "cache"};

    // 随机选一个 key 查询，并计时
    auto random_key = keys[random_index(keys)];
    auto [result, ns] = timed([&] { return get_config(cfg, random_key); });

    std::cout << "key: " << random_key << "\n";
    if (result) {
        std::cout << "value: " << *result << "\n";
    } else {
        std::cout << "not found\n";
    }
    std::cout << "took " << ns << " ns\n";
    return 0;
}
```

这个示例综合了：
- **optional**：配置查找可能失败
- **随机数**：随机选 key（mt19937 + uniform_int_distribution）
- **chrono**：steady_clock 测耗时
- **tuple + 结构化绑定**：`timed` 返回 `(结果, 耗时)`，`auto [result, ns] = ...` 解包
- **模板 + lambda**：`timed` 接受任意可调用对象

## 自测题

**1. 选择题**：以下哪个 C++ 工具最适合表达"函数可能返回有效值，也可能找不到结果"？

A. 返回裸指针 `T*`，找不到返回 nullptr
B. 抛异常 `std::runtime_error`
C. `std::optional<T>`
D. 返回 `std::vector<T>`，空表示没找到

<details>
<summary>答案</summary>

**C**。`optional<T>` 是表达"可能没有的值"的标准方式——栈上存储无堆分配、无悬垂风险、`value_or` 提供默认值。A 有悬垂和堆分配问题；B 抛异常开销大且语义不对（找不到不是异常情况）；D 语义混淆（空 vector 可能表示"找到了但是空集合"）。

</details>

**2. 判断题**：测量代码执行耗时时，应使用 `std::chrono::system_clock`，因为它代表真实墙钟时间。

<details>
<summary>答案</summary>

**错**。测耗时应用 `steady_clock`——它单调递增、不被 NTP 调整。`system_clock` 会被 NTP 同步调整（可能倒退），导致测出负耗时或异常值。`system_clock` 用于时间戳/日历转换，不用于测耗时。

</details>

**3. 应用题**：综合题——写一个函数，从 `vector<int>` 中随机选一个偶数，返回 `optional<int>`（若无偶数返回空），并打印查询耗时。

<details>
<summary>答案</summary>

```cpp
#include <optional>
#include <random>
#include <vector>
#include <chrono>
#include <iostream>
std::optional<int> random_even(const std::vector<int> &v) {
    if (v.empty()) return std::nullopt;
    static std::mt19937 eng(std::random_device{}());
    // 收集所有偶数（简化：多次随机尝试）
    std::uniform_int_distribution<size_t> dist(0, v.size() - 1);
    for (int attempt = 0; attempt < 100; ++attempt) {
        size_t idx = dist(eng);
        if (v[idx] % 2 == 0) return v[idx];
    }
    return std::nullopt;   // 尝试 100 次都没偶数，认为没有
}
int main() {
    std::vector<int> v = {1, 3, 5, 7, 2, 9, 4, 6};
    auto start = std::chrono::steady_clock::now();
    auto result = random_even(v);
    auto end = std::chrono::steady_clock::now();
    auto ns = std::chrono::duration_cast<std::chrono::nanoseconds>(end - start).count();
    if (result) std::cout << "found: " << *result << "\n";
    else std::cout << "no even\n";
    std::cout << "took " << ns << " ns\n";
}
```

要点：`optional<int>` 表示可能无结果、`mt19937` + `uniform_int_distribution` 随机采样、`steady_clock` 测耗时、`value_or`/`*result` 访问。（更严谨的做法是先收集所有偶数再随机选，这里为简洁用了尝试法。）

</details>
