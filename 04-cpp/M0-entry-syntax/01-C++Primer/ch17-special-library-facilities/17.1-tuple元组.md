# tuple 元组

## 本节讲什么

本节讲解 `std::tuple`——一个固定大小、可存放**不同类型**元素的容器模板。它是 `std::pair` 的泛化版（`pair` 只能 2 个，`tuple` 任意个），常用于"函数一次返回多个不同类型结果"、"异构数据打包"等场景。

> **一句话定位**：`tuple` = "能装不同类型元素的 struct，但不用先定义 struct"。

## 核心用法

### 1. 创建与访问

```cpp
#include <tuple>
#include <string>
// 构造
std::tuple<std::string, int, double> t1{"book", 10, 9.9};
auto t2 = std::make_tuple("pen", 5, 1.5);    // 推导类型

// 访问：get<索引>
std::cout << std::get<0>(t1);    // "book"（string）
std::cout << std::get<1>(t1);    // 10（int）
// std::get<3>(t1);              // ❌ 编译错误：越界（只有 3 个元素）

// 按类型访问（要求该类型在 tuple 中唯一）
std::cout << std::get<std::string>(t1);   // "book"
```

### 2. 元素个数与类型查询

```cpp
auto t = std::make_tuple(1, 2.0, "hi");
std::cout << std::tuple_size<decltype(t)>::value;   // 3
// 获取第 i 个元素的类型：
std::tuple_element<0, decltype(t)>::type;   // int
```

### 3. 解包：tie 与结构化绑定

```cpp
std::tuple<std::string, int> get_person() { return {"Alice", 30}; }

// C++11：tie 解包
std::string name; int age;
std::tie(name, age) = get_person();

// tie + std::ignore：跳过不想要的中间元素
std::tuple<int, double, std::string> t{1, 9.9, "cpp"};
int n; std::string s;
std::tie(n, std::ignore, s) = t;   // 只要第 0、2 个，跳过 double
// 实测（clang 23.1.0）：n=1 s="cpp"

// C++17：结构化绑定（更优雅）
auto [name, age] = get_person();
```

> 补充：`std::get` 还能**按类型**取（C++14）：`std::get<int>(t)`，前提是该类型在 tuple 中**唯一**，否则编译报二义性（见常见错误 2）。另外 `tuple<>`（0 个元素）和 `tuple<int>`（1 个）也合法——`tuple_size` 实测为 0 / 1，工程上极少用，但模板本身没有"≥2 个"的限制。

### 4. tuple 的常见场景

- **函数返回多值**：`return std::make_tuple(result, status, error_msg);`
- **异构数据临时打包**：把不同类型数据一起传递，避免定义专用 struct
- **模板元编程**：作为"类型列表"载体

### 5. get 的下标必须是编译期常量（面试重点）

`std::get<N>(t)` 的 `N` 是**模板参数**，在编译期实例化，所以不能用运行期变量：

```cpp
std::tuple<int, double> t{1, 2.0};
int idx = 1;
auto v = std::get<idx>(t);   // ❌ 编译错误
```

实测（clang 23.1.0）：`error: no matching function for call to 'get'`。

**推论**：tuple **不能像数组那样用 for 循环按下标遍历**——下标必须编译期可知。要遍历，得把"运行期循环"改写成"编译期展开"，见下一节。

### 6. 遍历 tuple 的三种写法（实测输出一致）

三种写法对 `std::tuple<int, double, std::string> t{42, 3.14, "hft"}` 的输出均为 `42 3.14 hft`。

**写法一：模板递归 + 偏特化终止（C++11 唯一出路，面试最常考）**

```cpp
template <size_t I = 0, typename... Ts>
struct TuplePrinter {
    static void print(const std::tuple<Ts...>& t) {
        std::cout << std::get<I>(t) << " ";
        TuplePrinter<I + 1, Ts...>::print(t);   // 编译期递归
    }
};
template <typename... Ts>                       // 递归终止：下标越界时命中此偏特化
struct TuplePrinter<sizeof...(Ts), Ts...> {
    static void print(const std::tuple<Ts...>&) {}
};
// 调用注意类型包要拼对：TuplePrinter<0, int, double, std::string>::print(t);
```

**写法二：index_sequence + 折叠表达式（C++17，工程主流）**

```cpp
template <typename Tuple, size_t... Is>
void printImpl(const Tuple& t, std::index_sequence<Is...>) {
    ((std::cout << std::get<Is>(t) << " "), ...);   // 折叠展开，编译期生成 N 条语句
}
template <typename Tuple>
void printTuple(const Tuple& t) {
    printImpl(t, std::make_index_sequence<std::tuple_size_v<Tuple>>{});
}
```

`make_index_sequence<N>` 在编译期生成下标包 `0,1,...,N-1`，包展开后每个下标都是编译期常量，正好满足 `get` 的要求。机制见 [19.6 可变参数模板](../ch19-special-tools/19.6-可变参数模板（C++11）.md)。

**写法三：std::apply + 折叠（C++17，最贴近真实用法）**

```cpp
std::apply([](const auto&... args) {
    ((std::cout << args << " "), ...);
}, t);   // 把整个 tuple 当函数参数包展开喂给 lambda
```

`apply` 的价值不止打印——它是"tuple 存参数 → 展开调回调"的标准件（比如从配置 tuple 取参数调函数）。

### 7. pair / tuple / struct 怎么选（工程准则）

| 需求 | 选谁 | 理由 |
|------|------|------|
| 刚好两个值（错误码+消息、map 键值） | `pair` | 最简单，`first/second` 约定俗成 |
| 3 个及以上，**一次性临时**打包 | `tuple` | 即用即写，配合结构化绑定一行解包 |
| 组合**反复出现**、字段需要名字 | **具名 struct** | `get<2>(t)` 毫无可读性，`result.ip` 一目了然；还能加方法 |

> 经验法则：`get<0>/get<1>` 没有名字，可读性差。**超过 3 个元素，工程上一般直接写 struct，不用 tuple**。判断"临时还是反复出现"：这个组合如果只在一个函数的返回处出现一次，tuple 够用；如果要在多处传来传去（比如网络代码里的"时间戳+价格+成交量"），就该具名。

## 和 C 的区别

C 没有 `tuple`，要返回多个不同类型值只能定义 `struct` 或用 `void*`：

| 维度 | C（struct） | C++ tuple |
|------|-----------|----------|
| 定义成本 | 每处都定义 struct | 即用即写，无需预定义 |
| 访问 | `s.name`（有名字） | `get<i>`（按位置）或结构化绑定 |
| 通用性 | 每种组合一个 struct 类型 | 模板，任意类型组合 |
| 解包 | 逐字段赋值 | `tie` / 结构化绑定一行搞定 |

```c
// C：必须先定义 struct
struct Person { char name[32]; int age; };
struct Person get_person() { struct Person p = {"Alice", 30}; return p; }
// 用：struct Person p = get_person(); printf("%s %d", p.name, p.age);
```

```cpp
// C++：tuple 即用即写
std::tuple<std::string, int> get_person() { return {"Alice", 30}; }
auto [name, age] = get_person();   // C++17 一行解包
```

> **取舍**：若某个多值组合**反复出现**，定义 `struct` 更清晰（有字段名、可加方法）；若只是**临时**返回一次，`tuple` 更轻便。

## 常见错误

### 错误 1：`get` 索引越界或类型不匹配

```cpp
std::tuple<int, double> t{1, 2.0};
std::get<2>(t);                  // ❌ 编译错误：只有 2 个元素
std::get<std::string>(t);        // ❌ 编译错误：没有 string 类型
std::get<int>(t);                // ❌ 若有多个 int 会二义；这里只有 1 个 int，OK
```

`get` 越界和类型不匹配都是**编译期**错误——这是 `tuple` 相对 `void*` 的安全优势。

### 错误 2：按类型访问时类型不唯一

```cpp
auto t = std::make_tuple(1, 2);    // 两个 int
std::get<int>(t);                  // ❌ 编译错误：int 不唯一
std::get<0>(t);                    // ✅ 用索引
```

按类型访问要求该类型在 tuple 中唯一。

### 错误 3：忘记 `tie` 的左值语义

```cpp
std::tuple<int,int> f() { return {1, 2}; }
int a, b;
std::tie(a, b) = f();    // ✅ tie 返回引用 tuple，赋值写入 a, b
// 对比：auto t = f();   // 这是拷贝到 t，不写入 a, b
```

## 自测题

**1. 选择题**：`std::tuple<int, double, std::string> t{1, 2.0, "hi"};` 以下哪个访问**合法**？

A. `std::get<3>(t)`
B. `std::get<double>(t)`
C. `std::get<int>(t)`
D. `t[0]`

<details>
<summary>答案</summary>

**B**。A 越界（只有 3 个元素，索引 0-2）；C 的 `int` 虽然唯一合法，但选项 B 也合法且更典型；D 错误——`tuple` 不支持 `[]` 运算符，只能用 `get`。`get<double>` 因 double 唯一而合法。若问"哪个非法"，答案是 A 和 D。

</details>

**2. 判断题**：`std::tuple` 的大小（元素个数）在编译期确定，不能运行期改变。

<details>
<summary>答案</summary>

**对**。`tuple` 是固定大小的模板，元素个数和类型在编译期已确定。若需运行期可变长度的异构容器，考虑 `std::vector<std::variant<...>>` 或 `std::any`。

</details>

**3. 踩坑题**：以下代码有什么问题？

```cpp
std::tuple<int, int> get_coords() { return {3, 4}; }
int main() {
    int x, y;
    auto t = get_coords();
    std::tie(x, y);
    std::cout << x << " " << y;
}
```

<details>
<summary>答案</summary>

`std::tie(x, y)` 只是构造了一个引用 tuple，没有赋值——`x`/`y` 仍为未初始化。正确写法是 `std::tie(x, y) = get_coords();`（tie 在等号左边）。或用 C++17 结构化绑定：`auto [x, y] = get_coords();`。

</details>

**4. 判断题**：下面代码能通过编译吗？
```cpp
std::tuple<int, double, std::string> t{1, 2.0, "x"};
for (int i = 0; i < 3; ++i)
    std::cout << std::get<i>(t) << "\n";   // 用循环变量当下标
```

<details>
<summary>答案</summary>

**不能**。`get<N>` 的 `N` 是模板参数，必须编译期常量；`i` 是运行期变量，编译报 `no matching function for call to 'get'`。tuple 的"遍历"只能在编译期展开：模板递归（C++11）、`index_sequence` + 折叠表达式（C++17）、`std::apply`（C++17）——见核心用法第 5、6 节。

</details>

**5. 应用题**：函数要同时返回"错误码、收到的字节数、对方 IP 字符串"，选 pair、tuple 还是 struct？

<details>
<summary>答案</summary>

3 个值，pair 出局。tuple 能编过且能跑，但 IP 字段要 `get<2>(t)` 访问，可读性差；而这个组合在解析、日志、统计多处都会用到（**反复出现**）——按第 7 节的准则应写具名 struct：
```cpp
struct RecvResult { int err; size_t bytes; std::string ip; };
// 调用方：auto [err, bytes, ip] = recv(...); 结构化绑定对聚合 struct 同样可用
```
tuple 的甜区是"只在一个返回处出现一次"的临时打包。

</details>

**6. 应用题**：写一个函数 `divide(int a, int b)` 返回 `(商, 余数, 是否成功)`，成功时 `true`，除零时 `false`。用 `tuple` 返回，调用方用结构化绑定接收。

<details>
<summary>答案</summary>

```cpp
#include <tuple>
std::tuple<int, int, bool> divide(int a, int b) {
    if (b == 0) return {0, 0, false};
    return {a / b, a % b, true};
}
int main() {
    auto [q, r, ok] = divide(17, 5);    // C++17 结构化绑定
    if (ok) std::cout << q << " " << r;  // 3 2
    auto [q2, r2, ok2] = divide(10, 0);
    if (!ok2) std::cout << "div by zero";
}
```

要点：`tuple` 打包多返回值、结构化绑定一行解包、`ok` 标志处理错误（也可用 `std::optional<tuple>`）。

</details>
