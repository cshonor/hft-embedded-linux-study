# 1.1 编写一个简单的 C++ 程序

> 第 1 章 开始 · 下一节：[1.2 初识输入输出](./1.2-初识输入输出.md)

## 本节讲什么

介绍 C++ 程序的基本结构。每个程序必须有一个 `main` 函数——操作系统通过调用它来运行程序。函数定义包含四部分：**返回类型**、**函数名**、**形参列表**、**函数体**。`main` 返回 `0` 表示执行成功。

## 最简单的 C++ 程序

```cpp
int main() {
    return 0;  // 返回 0 表示程序正常结束
}
```

函数定义四要素：

| 部分 | 上例中的值 | 说明 |
|------|-----------|------|
| 返回类型 | `int` | `main` 必须返回 `int`，操作系统靠这个返回值判断程序是否成功 |
| 函数名 | `main` | 程序入口，必须叫 `main`（全小写） |
| 形参列表 | `()`（空） | 这里不带参数；1.1 节先用空列表，带参数的写法后面讲 |
| 函数体 | `{ return 0; }` | 花括号包起来的语句块 |

程序要运行，还需经**编译**（源码 → 目标文件）和**链接**（目标文件 → 可执行文件）两步，1.5.2 会详讲。

## 和 C 的区别

| 维度 | C | C++ | 说明 |
|------|---|-----|------|
| `main` 返回类型 | `int` | `int` | 一样，都必须是 `int` |
| 不写 `return` | 返回值未定义（UB） | **`main` 特例：默认返回 0** | C++ 只有 `main` 有这个豁免，其他函数不写 return 行为未定义 |
| `return 0` 含义 | 成功 | 成功 | 一样，非 0 通常表示错误 |
| 头文件 | `#include <stdio.h>` | `#include <iostream>` | C++ 标准库头文件不带 `.h`（下节讲） |

**一句话：** C 程序员看 C++ 的 `main` 基本无障碍，唯一的"小惊喜"是 C++ 里 `main` 不写 `return` 也合法且默认返回 0——但**别依赖这个**，养成写 `return 0;` 的习惯更安全（也方便和 C 互移植）。

## 常见错误（新手踩坑）

**错误 1：`main` 拼错或大小写不对**
```cpp
int Main() { return 0; }   // ❌ 编译能过，但链接报错：找不到 main
int main() { return 0; }   // ✅
```
**为什么：** 链接器找的是小写 `main`，`Main` 不会被当成入口。

**错误 2：返回类型写成 `void`**
```cpp
void main() { }   // ❌ C++ 标准不允许（某些编译器放行，但不可移植）
int main() { }    // ✅
```
**为什么：** C++ 标准规定 `main` 必须返回 `int`。有些老编译器（MSVC）容忍 `void main`，但换编译器就崩，别养成坏习惯。

**错误 3：忘 `#include` 就用库**
```cpp
main() { std::cout << "hi"; }  // ❌ 没包含 <iostream>
```
这节还没讲输入输出（1.2 才讲），先记住：**用任何标准库设施都要先 `#include` 对应头文件**。

## 自测题

1. C++ 程序的入口函数必须叫什么？返回类型必须是什么？
2. `main` 函数不写 `return` 语句，程序行为是什么？这和 C 有什么不同？
3. 下面哪个能作为合法的 C++ 程序入口？为什么？
```cpp
(a) int main() { return 0; }
(b) void main() { }
(c) int Main() { return 0; }
```
4. `return 0;` 和 `return 1;` 对操作系统意味着什么？

<details>
<summary>参考答案</summary>

1. 入口函数必须叫 **`main`（全小写）**，返回类型必须是 **`int`**。操作系统/运行时只认这一个符号：`main` 由启动代码调用，其返回值作为进程退出码交回父进程。函数名外的四要素里，形参列表允许 `()` 或 `(int argc, char* argv[])`，但名字和返回类型没有商量余地。

2. C++：`main` 是 **唯一豁免** 的函数——控制流走到函数体结尾的 `}` 等价于 `return 0;`（标准规定，其它函数漏 `return` 仍是未定义行为）。C：C89/C90 下走到 `main` 结尾返回的是 **未定义值**（实现通常把某个寄存器的残留值当退出码，于是出现"运行结果随机"的现象）；**C99 起（5.1.2.2.3）C 也规定等价于 `return 0`**。所以真正的 C/C++ 差异只存在于 C89 及更早。仍然建议显式写 `return 0;`：可移植、意图清晰。

3. 只有 **(a)** 能作为入口。
   - (a) `int main() { return 0; }` ✅ 名字、返回类型都符合标准。
   - (b) `void main() { }` ❌ 返回类型必须是 `int`；`void main()` 只是某些实现（如 MSVC）的扩展，换编译器就报错，不可移植。
   - (c) `int Main() { return 0; }` ❌ C++ **大小写敏感**，`Main` 是一个普通函数，链接器找不到 `main` 符号 → 链接期报 "undefined reference to main"。

4. 返回值就是进程的**退出状态码（exit status）**：`0` 表示成功，非 `0` 表示失败（具体非零值含义由程序自己定义，如 `1`＝通用错误、`2`＝用法错误）。父进程/shell 用它决定成败：`$?` 查看，`&&`/`||`、`set -e`、make/CI 都据此判断。注意 POSIX 上只有**低 8 位**会被传出去（`exit(256)` 看起来等于 `exit(0)`），所以自定义错误码建议只用 0–125。

</details>
