# 4.9 sizeof 运算符

## 本节讲什么

计算类型或表达式占用的**字节数**；返回 `size_t`（无符号）。

## 两种写法

```cpp
sizeof(int);     // 类型
sizeof(var);     // 表达式（一般不求值 var，见下）
sizeof var;      // 变量可省略括号（不推荐与类型混淆）
```

## 两大特性（必考）

### 1. 数组名 vs 指针

```cpp
int arr[10];
sizeof(arr);     // 整个数组：10 * sizeof(int)
int *p = arr;
sizeof(p);       // 指针大小，如 8（64 位）
```

数组**不退化**的例外之一（见 [3.5.3](../../ch03-strings-vectors-arrays/3.5-arrays/3.5.3-数组退化与指针.md)）。

### 2. 不对指针解引用

```cpp
int *p = nullptr;
sizeof(*p);      // ✅ 只算 int 的大小，不访问 *p，不崩溃
```

## 用途

- 估算结构体/数组占用  
- `sizeof(arr)/sizeof(arr[0])` 得数组元素个数（**仅当 `arr` 仍是数组名时**）  

## 和 C 的区别（sizeof：C/C++ 几乎一致，C++ 多了成员/类类型支持）

| 对比点 | C | C++ |
|--------|----|------|
| `sizeof(type)` | ✅ 一致 | ✅ 一致 |
| `sizeof(expr)` | ✅ 一致 | ✅ 一致 |
| 返回 `size_t` | ✅ | ✅ 一致 |
| 数组不退化 | ✅ | ✅ 一致 |
| 不求值操作数 | ✅ | ✅ 一致 |
| `sizeof` 类/struct 成员 | C99 起部分支持 | ✅ 完整支持 |
| `sizeof` 类类型本身 | C 无 class | ✅ |
| 编译期常量 | ✅（除 VLA） | ✅（C++ 无 VLA，恒编译期） |

**给 C 程序员的关键提醒：**
1. **`sizeof` 语义两边几乎一致**——`sizeof(int)`、`sizeof(arr)`、`sizeof(arr)/sizeof(arr[0])` 这些用法 C 学的直接用。
2. **C++ 多了对类类型的支持**——`sizeof(std::string)`、`sizeof(std::vector<int>)`、`sizeof(MyClass)` 都合法。但要注意：`sizeof(std::string)` 是 string 对象本身的大小（通常 24/32 字节），**不是**字符串内容长度（用 `s.size()`）。
3. **C 的 VLA 让 `sizeof` 可能是运行期**——C99 的 VLA `int arr[n];` 让 `sizeof(arr)` 在运行期求值。C++ 不支持 VLA（标准层面），`sizeof` 恒编译期常量。这是少数 C++ 比 C 更"静态"的地方。

## 常见错误

### 1. 数组传参后 `sizeof` 拿不到长度

```cpp
void f(int arr[]) {
    size_t n = sizeof(arr) / sizeof(arr[0]);   // ❌ arr 退化指针，n = 8/4 = 2
}
```

数组传参退化为指针，`sizeof(arr)` 是指针大小。C 和 C++ 都有这个坑。**用 `std::array`/`vector` 或模板引用**避开。

### 2. `sizeof(string)` 误以为是字符串长度

```cpp
std::string s = "hello";
std::cout << sizeof(s);   // 24 或 32（string 对象大小），不是 5
std::cout << s.size();    // 5（字符串长度）
```

`sizeof(std::string)` 是 string 对象本身的字节大小（固定，通常 24/32 字节，含指针/长度/容量），**不是**字符串内容长度。内容长度用 `s.size()` 或 `s.length()`。C 程序员习惯了 `sizeof(char[])` 算字符数组长度，到 `string` 要改用 `size()`。

### 3. `sizeof(*nullptr)` 以为会崩

```cpp
int* p = nullptr;
std::cout << sizeof(*p);   // ✅ 4（int 大小），不崩溃
```

`sizeof` 的操作数**不求值**——编译器只看类型，不执行解引用。所以 `sizeof(*p)` 安全，等于 `sizeof(int)`。但**别依赖这个写运行期代码**——`*p` 在运行期仍是 UB，只是 `sizeof` 上下文不求值。

## 九个真相（本机实测，`examples/4.9-1-sizeof-traps.cpp`）

| # | 真相 | 实测 |
|---|---|---|
| 1 | **编译期常量**，不是运行时函数 | `int fixed[sizeof(int)*4]` 合法，`static_assert` 可用 |
| 2 | **不对操作数求值** | `sizeof(i++)` 之后 `i` 仍是 5 —— `++` 根本没执行 |
| 3 | 数组传参后**退化** | 定义处 `sizeof(arr)=40`，形参里 `sizeof(a)=8` |
| 4 | 字符串字面量含 `\0` | `sizeof("abc")=4`，`strlen("abc")=3` |
| 5 | 结构体有**对齐填充** | `{char;int;char}=12`，换成 `{int;char;char}=8`（省 4 字节） |
| 6 | 空类是 **1 字节** | 若为 0，两个不同对象地址会相同 |
| 7 | 有虚函数 **+8** | vptr |
| 8 | `sizeof` 引用 = 被引用类型 | `sizeof(int&)=4`，引用没有自己的大小 |
| 9 | 返回 `size_t`（**无符号**） | `sizeof(int) - 5` = 18446744073709551615（下溢） |

### 三条最容易踩的

**① 不求值**——`sizeof(i++)` 不会执行 `++`。clang 会警告：
```
warning: expression with side effects has no effect in an unevaluated context [-Wunevaluated-expression]
```
这也是 `sizeof` 能安全地用在模板/decltype 里的原因：只要类型，不要值。

**② 数组一传参就退化**——函数内部 `sizeof(形参)` 拿到的是指针大小。clang 也会警告：
```
warning: sizeof on array function parameter will return size of 'int *' instead of 'int[10]' [-Wsizeof-array-argument]
```
**长度必须显式传**（或改用 `std::array` / `std::span`）。

**③ 无符号下溢**——`sizeof(x) - n` 当 `n > sizeof(x)` 时是个巨大正数。`if (sizeof(a) - 5 > 0)` 永远是真。

### 标准库类型的大小（SSO 实证）

```
sizeof(std::string)      = 24     ← libc++：ptr + size + SSO 联合体
sizeof(std::vector<int>) = 24     ← begin + end + capacity 三指针
```
短字符串 `"abc"` 的 `c_str()` 距对象首地址 **0 字节**（就在对象内部 = SSO，无堆分配）；31 字符的长字符串则指向堆。这解释了"为什么短字符串构造没有 malloc"。

### 常见错误补充

4. **以为 `sizeof(i++)` 会执行 `++`**：`sizeof` 是未求值操作数（unevaluated operand），`++` 不执行（-Wunevaluated-expression）。
5. **`sizeof` 结果参与有符号运算**：`sizeof` 返回 `size_t`，与 `int` 混算会整体提升为无符号，`sizeof(a) - 10` 可能是个天文数字。
6. **以为成员顺序不影响结构体大小**：实测 `{char;int;char}` 是 12 字节，`{int;char;char}` 是 8 字节——**把大成员往前放**。

## 自测题

**1. 选择题**　`int arr[5]; int* p = arr;` 下列哪个表达式返回**指针大小**（而非数组大小）？

- A. `sizeof(arr)`
- B. `sizeof(arr[0])`
- C. `sizeof(p)`
- D. `sizeof(*p)`

<details><summary>答案</summary>

**C**。`sizeof(p)` 是指针大小（如 8 字节，64 位）。`sizeof(arr)` 是整个数组大小（5*4=20）；`sizeof(arr[0])` 是单个 int 大小（4）；`sizeof(*p)` 是 `int` 大小（4）。C 也是同样规则。

</details>

**2. 判断题**　`std::string s = "hello"; sizeof(s)` 返回 5。

<details><summary>答案</summary>

**错**。`sizeof(s)` 返回 `std::string` 对象本身的字节大小（固定，通常 24 或 32 字节，含内部指针/长度/容量），**不是**字符串内容长度。内容长度用 `s.size()`（返回 5）。C 程序员习惯 `sizeof(char[])` 算字符数组长度，到 `string` 要改用 `size()`。

</details>

**3. 踩坑题**　C 程序员写下面这段 C++ 代码，想算数组长度，哪里有问题？

```cpp
void process(int arr[]) {
    size_t n = sizeof(arr) / sizeof(arr[0]);
    for (size_t i = 0; i < n; ++i) {
        std::cout << arr[i] << " ";
    }
}
```

<details><summary>答案</summary>

**`sizeof(arr)` 在函数内是指针大小，不是数组大小**。数组传参退化为指针，`sizeof(arr)` 是 8（64 位指针），`sizeof(arr[0])` 是 4，`n = 8/4 = 2`，只打印前 2 个元素。

**修复**（三种）：

```cpp
// 方法 1：C 风格，另传长度
void process(int* arr, size_t n);

// 方法 2：C++ 模板引用数组，保留类型
template <size_t N>
void process(int (&arr)[N]) {
    for (size_t i = 0; i < N; ++i) std::cout << arr[i] << " ";
}

// 方法 3：用 std::array 或 vector
void process(const std::vector<int>& v);
```

C 程序员习惯了"另传 n"，C++ 推荐用容器或模板引用避开退化。

</details>

**4. 应用题**　写一个模板函数 `array_size`，编译期返回任意内置数组的元素个数。

<details><summary>答案</summary>

```cpp
#include <cstddef>

template <typename T, size_t N>
constexpr size_t array_size(const T (&)[N]) {
    return N;
}

// 用法
int arr[10];
constexpr size_t n = array_size(arr);   // 编译期得 10
double vals[5];
constexpr size_t m = array_size(vals);  // 5
```

要点：
- `const T (&)[N]` 是"对数组的引用"，**不退化**
- 模板推导自动得 `N`，函数内返回 `N`
- `constexpr` 让结果可在编译期使用（C++ 独有，替代 `#define` 那种宏）

C 没有这种能力——C 的数组传参必然退化，只能 `#define ARRAY_SIZE(a) (sizeof(a)/sizeof((a)[0]))` 用宏，但宏在传参后同样失效。

C++17 起还有 `std::size(arr)`，直接返回数组长度。

</details>

**4. 选择题**：`void f(int a[10]) { ... }` 里的 `sizeof(a)` 是多少？
- A) 40
- B) 8（`int*` 的大小）
- C) 10
- D) 取决于实参

<details><summary>答案</summary>

**B（64 位上是 8）**。

数组作为**形参**时会退化成指针，`void f(int a[10])` 等价于 `void f(int* a)`，所以 `sizeof(a) == sizeof(int*) == 8`。clang 会警告 `-Wsizeof-array-argument`。

A 是"定义处"的 `sizeof`（`int arr[10]` 才是 40）。**函数内部拿不到数组长度，必须额外传 size**，或用 `std::array<int,10>` / `std::span<int>`（C++20）保住尺寸信息。

</details>

**5. 代码题**：下面代码输出什么？
```cpp
int i = 5;
size_t s = sizeof(i++);
printf("%zu %d", s, i);
```

<details><summary>答案</summary>

输出 **`4 5`**——`i` 没有被自增。

`sizeof` 的操作数是**未求值**的：编译器只需要它的类型，不会生成执行 `++` 的代码。clang 会给出 `-Wunevaluated-expression` 警告提醒你"这个副作用不会发生"。

同理 `sizeof(f())` 不会真的调用 `f`——哪怕 `f()` 有副作用、哪怕 `f` 只有声明没有定义也能编译通过。

</details>
