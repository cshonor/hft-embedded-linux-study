19.1

内存分配与 new 重载

本节讲什么

本节讲解「内存分配与 new 重载」。

要点

  • 全局 operator new / operator delete 底层内存分配
  • 类内重载专属分配器：自定义内存池、对齐分配
  • 定位 new（placement new）：在已分配内存上构造对象，不申请堆内存
  • 内存释放、析构与 placement new 配套使用

示例

#include <iostream>
void *operator new(std::size_t sz) {
    std::cout << "alloc " << sz << " bytes\n";
    return ::operator new(sz);
}
int main() {
    int *p = new int(42);
    delete p;
    return 0;
}

代码自测

题目 1： new 和 operator new 有什么区别？

Widget* p = new Widget;  // ?
void* mem = operator new(sizeof(Widget)); // ?
new(mem) Widget;  // ?
参考答案

new Widget（new 表达式）：调用 operator new 分配内存 + 调用构造函数。 operator new(...)（函数）：只分配内存，返回 void*，类似 malloc。 new(mem) Widget（placement new）：在已有内存上构造对象，不分配。 重载 operator new 可实现内存池，但不影响 new 表达式的语法。delete 对应 operator delete + 析构。

19.2

运行时类型信息补充 & 枚举进阶

本节讲什么

本节讲解「运行时类型信息补充 & 枚举进阶」。

要点

  • 强类型枚举 enum class：对比传统无作用域 enum，类型更安全、不会隐式转整型

示例

#include <iostream>
enum class Color { Red, Green, Blue };
int main() {
    Color c = Color::Red;
    if (c == Color::Red)
        std::cout << "red\n";
    return 0;
}

代码自测

题目 1： enum class 和传统 enum 有什么区别？

enum Color { RED, GREEN, BLUE };         // 传统
enum class Color2 { RED, GREEN, BLUE };  // C++11
参考答案

传统 enum：隐式转 int、名称泄漏到外层作用域、不能指定底层类型。enum class（C++11）：不隐式转换（需 static_cast）、名称限定（Color2::RED）、可指定底层类型（enum class Color : uint8_t）。推荐用 enum class——更安全、更清晰。

19.3

类成员指针

本节讲什么

本节讲解「类成员指针」。

要点

  • ::* 成员指针语法：指向类的成员变量、成员函数
  • 绑定到具体对象后才能访问；用于通用框架、简易反射

示例

#include <iostream>
void f(int) { std::cout << "int\n"; }
void f(int *) { std::cout << "pointer\n"; }
int main() {
    f(nullptr);  // 调用 f(int*)
    return 0;
}

代码自测

题目 1： 成员指针和普通指针有什么区别？

struct Widget { int val; void show(); };
int Widget::* pmi = &Widget::val;     // ?
void (Widget::*pmf)() = &Widget::show; // ?
Widget w;
(w.*pmi) = 42;   // ?
(w.*pmf)();      // ?
参考答案

成员指针不指向具体地址，而是「相对于对象起始的偏移」（数据成员）或「vtable 条目」（函数成员）。w.*pmi 通过成员指针访问 w 的成员。.* 和 ->* 是成员指针解引用运算符。成员指针类型包含了类类型信息——int Widget::* 和 int Other::* 是不同类型。主要用于通用回调/序列化框架。

19.4

嵌套类

本节讲什么

类内部再定义类，作用域仅限外部类，控制封装、隐藏辅助结构。

示例

#include <iostream>
class Outer {
public:
    class Inner {
    public:
        void show() const { std::cout << "inner\n"; }
    };
};
int main() {
    Outer::Inner i;
    i.show();
    return 0;
}

代码自测

题目 1： 嵌套类和外部类有什么访问关系？

class Outer {
    int private_data;
    class Inner {
        void f(Outer& o) {
            o.private_data = 42;  // C++11 前合法吗？
        }
    };
};
参考答案

C++11 起：嵌套类可以访问外部类的 private 成员（包括静态和非静态）。C++11 前：嵌套类不能直接访问外部类的非静态 private 成员（需要友元声明）。嵌套类主要用于实现细节隐藏——如迭代器类通常嵌套在容器类内部。

19.5

联合（union）与位域

本节讲什么

  1. union：多个成员共用同一块内存，同一时刻只有一个有效，节省内存
  2. 位域 bit-field：指定成员占用 bit 数，极致压缩内存；驱动、协议解析常用

示例

#include <iostream>
union Data {
    int i;
    char c[4];
};
struct Flags {
    unsigned ready : 1;
    unsigned mode  : 3;
};
int main() {
    Data d{};
    d.i = 0x41424344;
    Flags f{1, 5};
    std::cout << (int)f.ready << " " << (int)f.mode << std::endl;
    return 0;
}

代码自测

题目 1： C++ 的 union 和 C 的有什么区别？

union U {
    int i;
    std::string s;  // C++ 合法吗？
    U() : s() {}     // 需要构造函数？
    ~U() { s.~string(); }
};
参考答案

C++ 的 union 可以包含有构造/析构函数的类型（如 string），但必须手动管理——构造哪个成员就析构哪个，不能同时持有多个活跃成员。C 的 union 只能包含 POD 类型。C++17 的 std::variant 是类型安全的 union 替代品——推荐用 variant 而非手写 union。

19.6

可变参数模板（C++11）

本节讲什么

模板参数包 Args...，接收任意数量、任意类型参数。现代 STL 大量基于它：tuple、emplace_back、万能转发等。

示例

#include <iostream>
template<typename... Args>
void print(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << std::endl;
}
int main() {
    print(1, 2.5, "hi");
    return 0;
}

代码自测

题目 1： 以下可变参数模板如何展开参数包？

template<typename... Args>
void print(Args... args) {
    // 如何展开 args？
}
参考答案

C++17 用折叠表达式：

template<typename... Args>
void print(Args... args) {
    ((std::cout << args << ' '), ...);  // C++17 折叠
}

C++11/14 用递归 + 基本情况：

void print() {}  // 基本情况
template<typename T, typename... Rest>
void print(T first, Rest... rest) {
    std::cout << first;
    print(rest...);  // 递归
}

sizeof...(args) 返回参数个数。

19.7

转发引用与完美转发

本节讲什么

结合可变参数，把参数原值类别（左值/右值）完整转发给内部函数，std::forward 原理应用。

示例

#include <iostream>
#include <utility>
void process(int &)  { std::cout << "lvalue\n"; }
void process(int &&) { std::cout << "rvalue\n"; }
template<typename T>
void forward_call(T &&arg) {
    process(std::forward<T>(arg));
}
int main() {
    int x = 1;
    forward_call(x);
    forward_call(2);
    return 0;
}

代码自测

题目 1： 以下代码中 && 是右值引用还是转发引用？

template<typename T>
void f(T&& x);  // T&& 是什么？
int a = 1;
f(a);   // T 推导为？
f(42);  // T 推导为？
参考答案

T&& 在模板中是转发引用（forwarding reference，也叫万能引用），不是右值引用。f(a) 中 T 推导为 int&（左值引用），x 类型为 int& && 折叠为 int&。f(42) 中 T 推导为 int，x 类型为 int&&。std::forward<T>(x) 保持值类别——这是完美转发的核心。非模板的 int&& 才是右值引用。

19.8

其他底层工具

本节讲什么

type_traits 类型萃取、编译期类型判断、void_t、decltype 高阶用法、编译期编程基础。

示例

#include <iostream>
#include <memory>
int main() {
    alignas(16) char buf[64];
    int *p = new (buf) int(42);  // placement new
    std::cout << *p << std::endl;
    p->~int();
    return 0;
}

代码自测

题目 1： alignas 和 alignof 的作用是什么？

struct alignas(16) AlignedBlock {
    char data[64];
};
std::cout << alignof(AlignedBlock);  // 输出？
参考答案

alignas(16) 指定对齐要求为 16 字节。alignof(T) 返回类型 T 的对齐要求——输出 16。对齐在 HFT 和 SIMD 中很重要：1) 缓存行对齐（64 字节）避免 false sharing；2) SIMD 指令要求 16/32 字节对齐；3) DMA 传输要求对齐。std::aligned_alloc 或 operator new 配合 alignval_t 分配对齐内存。

19.9

学习优先级

本节讲什么

写框架、高性能库、底层组件再啃本章；业务 CRUD 基本用不上。

示例

#include <iostream>
// 第 19 章回顾：完美转发 + 可变参模板
#include <utility>
template<typename T>
void wrap(T &&v) {
    std::cout << std::forward<T>(v) << std::endl;
}
int main() {
    wrap(42);
    return 0;
}

代码自测

题目 1： C++Primer 第 19 章（特殊工具与技术）中哪些主题对 HFT 最重要？

参考答案

1) 内存分配重载——自定义内存池消除热路径 malloc；2) 对齐（alignas/alignof）——缓存行对齐避免 false sharing；3) 完美转发——泛型工厂减少拷贝。可变参数模板对模板元编程有用但非必需。union/位域/成员指针在特定场景有用，非优先。建议优先学 19.1（内存分配）和 19.7（完美转发）。

章节自测

Q1operator new 重载
class FastAlloc {
    void *operator new(size_t n) {
        // 从内存池分配，不走 malloc
        return pool_alloc(n);
    }
    void operator delete(void *p) {
        pool_free(p);
    }
};
FastAlloc *obj = new FastAlloc;  // 调用谁的 new？
delete obj;                       // 调用谁的 delete？

new FastAlloc 的两步分别调用什么？类级 operator new 有什么用？

答案与复习指引

两步： 1. FastAlloc::operator new(sizeof(FastAlloc)) — 从内存池分配（不走全局 malloc） 2. FastAlloc 的构造函数 — 在分配的内存上构造对象

类级 operator new 用途： - 自定义内存池（避免 malloc 锁竞争 + 碎片） - 统计内存使用 - HFT 对象池：预分配 + 回收，零运行时分配

delete 同理： 先调析构，再调 FastAlloc::operator delete 释放回池。

Q2成员指针
struct Point { int x, y; };
int Point::*px = &Point::x;  // 指向成员的指针
Point p{10, 20};
Point *pp = &p;
std::cout << p.*px << " " << pp->*px;

输出是什么？成员指针和普通指针有什么区别？

答案与复习指引

输出： 10 10

成员指针 vs 普通指针： - 普通指针指向具体内存地址 - 成员指针是偏移量——记录"成员在对象内的位置偏移" - 使用时需要结合具体对象：p.*px 或 pp->*px - 成员函数指针更复杂（可能含 vtable 偏移 + this 调整信息），大小通常是 2 个指针

C 没有成员指针——C 的 struct 没有成员函数，不需要这种机制。

Q3union 限制
union Value {
    int i;
    std::string s;  // C++11: 合法吗？
    Value() : s() {}
    ~Value() {}
};

C++11 中 union 含 std::string 成员合法吗？有什么限制？

答案与复习指引

C++11 起合法，但有限制： 1. 含非平凡成员（有构造/析构/拷贝）的 union，必须手动管理哪个成员是活跃的 2. 不能同时使用多个成员——写入一个成员后读取另一个是 UB 3. union 需要自定义构造/析构来管理非平凡成员的生命周期

C 的 union： 只能含 POD 类型（无构造/析构），简单按位覆盖。

典型用途： std::variant/std::any 的底层实现用 tagged union——外加一个 tag 标记当前活跃成员。

Q4完美转发深入
template<typename T, typename... Args>
auto make_unique(Args&&... args) -> std::unique_ptr<T> {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
// 调用 make_unique<Widget>(42, "hello", 3.14)
// args 的类型分别是什么？

Args&&... 是什么？std::forward<Args>(args)... 做了什么？

答案与复习指引

Args&&...： 万能引用参数包——每个参数都能接受左值或右值。

`std::forward(args)...： 逐个参数完美转发——保留每个参数的原始左右值性。如果原始参数是左值就转发为左值引用，是右值就转发为右值引用。

这是 std::make_unique 的核心——它把构造参数原封不动地转发给 T 的构造函数，不丢失任何信息（左右值性、const 性）。如果不用 forward，所有参数都会变成左值，无法触发移动构造。
