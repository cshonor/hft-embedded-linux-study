# 19.2 运行时类型信息补充 & 枚举进阶

## 本节讲什么

本节讲解「运行时类型信息补充 & 枚举进阶」。

## 要点

- 强类型枚举 **`enum class`**：对比传统无作用域 `enum`，类型更安全、不会隐式转整型

## 示例

```cpp
#include <iostream>
enum class Color { Red, Green, Blue };
int main() {
    Color c = Color::Red;
    if (c == Color::Red)
        std::cout << "red\n";
    return 0;
}
```

---

## 代码自测

**题目 1：** `enum class` 和传统 `enum` 有什么区别？
```cpp
enum Color { RED, GREEN, BLUE };         // 传统
enum class Color2 { RED, GREEN, BLUE };  // C++11
```

<details>
<summary>参考答案</summary>

传统 enum：隐式转 int、名称泄漏到外层作用域、不能指定底层类型。`enum class`（C++11）：不隐式转换（需 `static_cast`）、名称限定（`Color2::RED`）、可指定底层类型（`enum class Color : uint8_t`）。推荐用 `enum class`——更安全、更清晰。

</details>
