# 19.1 内存分配与 new 重载

## 本节讲什么

本节讲解「内存分配与 new 重载」。

## 要点

- 全局 `operator new` / `operator delete` 底层内存分配
- 类内重载专属分配器：自定义内存池、对齐分配
- **定位 new（placement new）**：在已分配内存上构造对象，不申请堆内存
- 内存释放、析构与 placement new 配套使用

## 示例

```cpp
#include <iostream>
void *operator new(std::size_t sz) {
    std::cout << "alloc " << sz << " bytes\n";
    return ::operator new(sz);
}
int main() {
    int *p = new int(42);
    delete p;
    return 0;
}
```

## 代码自测

**题目 1：** `new` 和 `operator new` 有什么区别？
```cpp
Widget* p = new Widget;  // ?
void* mem = operator new(sizeof(Widget)); // ?
new(mem) Widget;  // ?
```

<details>
<summary>参考答案</summary>

`new Widget`（new 表达式）：调用 `operator new` 分配内存 + 调用构造函数。
`operator new(...)`（函数）：只分配内存，返回 `void*`，类似 malloc。
`new(mem) Widget`（placement new）：在已有内存上构造对象，不分配。
重载 `operator new` 可实现内存池，但不影响 `new` 表达式的语法。`delete` 对应 `operator delete` + 析构。

</details>
