# 19.4 嵌套类

## 本节讲什么

类内部再定义类，作用域仅限外部类，控制封装、隐藏辅助结构。

## 示例

```cpp
#include <iostream>
class Outer {
public:
    class Inner {
    public:
        void show() const { std::cout << "inner\n"; }
    };
};
int main() {
    Outer::Inner i;
    i.show();
    return 0;
}
```

## 代码自测

**题目 1：** 嵌套类和外部类有什么访问关系？
```cpp
class Outer {
    int private_data;
    class Inner {
        void f(Outer& o) {
            o.private_data = 42;  // C++11 前合法吗？
        }
    };
};
```

<details>
<summary>参考答案</summary>

C++11 起：嵌套类可以访问外部类的 private 成员（包括静态和非静态）。C++11 前：嵌套类不能直接访问外部类的非静态 private 成员（需要友元声明）。嵌套类主要用于实现细节隐藏——如迭代器类通常嵌套在容器类内部。

</details>
