# 19.6 可变参数模板（C++11）

## 本节讲什么

模板参数包 `Args...`，接收任意数量、任意类型参数。现代 STL 大量基于它：`tuple`、`emplace_back`、万能转发等。

## 示例

```cpp
#include <iostream>
template<typename... Args>
void print(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << std::endl;
}
int main() {
    print(1, 2.5, "hi");
    return 0;
}
```

## 代码自测

**题目 1：** 以下可变参数模板如何展开参数包？
```cpp
template<typename... Args>
void print(Args... args) {
    // 如何展开 args？
}
```

<details>
<summary>参考答案</summary>

C++17 用折叠表达式：
```cpp
template<typename... Args>
void print(Args... args) {
    ((std::cout << args << ' '), ...);  // C++17 折叠
}
```
C++11/14 用递归 + 基本情况：
```cpp
void print() {}  // 基本情况
template<typename T, typename... Rest>
void print(T first, Rest... rest) {
    std::cout << first;
    print(rest...);  // 递归
}
```
`sizeof...(args)` 返回参数个数。

</details>
