# 学习优先级

## 本节讲什么

**写框架、高性能库、底层组件**再啃本章；业务 CRUD 基本用不上。

## 示例

```cpp
#include <iostream>
// 第 19 章回顾：完美转发 + 可变参模板
#include <utility>
template<typename T>
void wrap(T &&v) {
    std::cout << std::forward<T>(v) << std::endl;
}
int main() {
    wrap(42);
    return 0;
}
```

## 代码自测

**题目 1：** C++Primer 第 19 章（特殊工具与技术）中哪些主题对 HFT 最重要？

<details>
<summary>参考答案</summary>

1) 内存分配重载——自定义内存池消除热路径 malloc；2) 对齐（alignas/alignof）——缓存行对齐避免 false sharing；3) 完美转发——泛型工厂减少拷贝。可变参数模板对模板元编程有用但非必需。union/位域/成员指针在特定场景有用，非优先。建议优先学 19.1（内存分配）和 19.7（完美转发）。

</details>
