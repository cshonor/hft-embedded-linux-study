# 19.3 类成员指针

## 本节讲什么

本节讲解「类成员指针」。

## 要点

- `::*` 成员指针语法：指向类的成员变量、成员函数
- 绑定到具体对象后才能访问；用于通用框架、简易反射

## 示例

```cpp
#include <iostream>
void f(int) { std::cout << "int\n"; }
void f(int *) { std::cout << "pointer\n"; }
int main() {
    f(nullptr);  // 调用 f(int*)
    return 0;
}
```

## 代码自测

**题目 1：** 成员指针和普通指针有什么区别？
```cpp
struct Widget { int val; void show(); };
int Widget::* pmi = &Widget::val;     // ?
void (Widget::*pmf)() = &Widget::show; // ?
Widget w;
(w.*pmi) = 42;   // ?
(w.*pmf)();      // ?
```

<details>
<summary>参考答案</summary>

成员指针不指向具体地址，而是「相对于对象起始的偏移」（数据成员）或「vtable 条目」（函数成员）。`w.*pmi` 通过成员指针访问 w 的成员。`.*` 和 `->*` 是成员指针解引用运算符。成员指针类型包含了类类型信息——`int Widget::*` 和 `int Other::*` 是不同类型。主要用于通用回调/序列化框架。

</details>
