# 19.7 转发引用与完美转发

## 本节讲什么

结合可变参数，把参数原值类别（左值/右值）完整转发给内部函数，`std::forward` 原理应用。

## 示例

```cpp
#include <iostream>
#include <utility>
void process(int &)  { std::cout << "lvalue\n"; }
void process(int &&) { std::cout << "rvalue\n"; }
template<typename T>
void forward_call(T &&arg) {
    process(std::forward<T>(arg));
}
int main() {
    int x = 1;
    forward_call(x);
    forward_call(2);
    return 0;
}
```

## 代码自测

**题目 1：** 以下代码中 `&&` 是右值引用还是转发引用？
```cpp
template<typename T>
void f(T&& x);  // T&& 是什么？
int a = 1;
f(a);   // T 推导为？
f(42);  // T 推导为？
```

<details>
<summary>参考答案</summary>

`T&&` 在模板中是转发引用（forwarding reference，也叫万能引用），不是右值引用。`f(a)` 中 T 推导为 `int&`（左值引用），`x` 类型为 `int& &&` 折叠为 `int&`。`f(42)` 中 T 推导为 `int`，`x` 类型为 `int&&`。`std::forward<T>(x)` 保持值类别——这是完美转发的核心。非模板的 `int&&` 才是右值引用。

</details>
