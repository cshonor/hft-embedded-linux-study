# 19.8 其他底层工具

## 本节讲什么

`type_traits` 类型萃取、编译期类型判断、`void_t`、`decltype` 高阶用法、编译期编程基础。

## 示例

```cpp
#include <iostream>
#include <memory>
int main() {
    alignas(16) char buf[64];
    int *p = new (buf) int(42);  // placement new
    std::cout << *p << std::endl;
    p->~int();
    return 0;
}
```

## 代码自测

**题目 1：** `alignas` 和 `alignof` 的作用是什么？
```cpp
struct alignas(16) AlignedBlock {
    char data[64];
};
std::cout << alignof(AlignedBlock);  // 输出？
```

<details>
<summary>参考答案</summary>

`alignas(16)` 指定对齐要求为 16 字节。`alignof(T)` 返回类型 T 的对齐要求——输出 16。对齐在 HFT 和 SIMD 中很重要：1) 缓存行对齐（64 字节）避免 false sharing；2) SIMD 指令要求 16/32 字节对齐；3) DMA 传输要求对齐。`std::aligned_alloc` 或 `operator new` 配合 `alignval_t` 分配对齐内存。

</details>
