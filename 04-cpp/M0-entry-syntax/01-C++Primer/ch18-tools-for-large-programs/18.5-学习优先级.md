## 代码自测

**题目 1：** C++Primer 第 18 章（大型程序工具）中哪些主题对 HFT 最重要？

<details>
<summary>参考答案</summary>

**异常安全（18.1）**最重要——不是因为在热路径用异常（恰恰相反，热路径零异常），
而是因为 RAII + noexcept 的纪律决定了你的容器/队列在异常路径和扩容路径上的性能下限
（noexcept 移动 vs 拷贝的实测差异见 18.1 ②）。
其次是**命名空间纪律（18.2）**——大项目编译期工程。
多重继承和 RTTI 理解机制即可，热路径反而要主动避开。

</details>

**题目 2：** 为什么 `-fno-exceptions` 不能"整个仓库一刀切"？

<details>
<summary>参考答案</summary>

标准库大量 API 以异常报错误（`vector::at`、`stoi`、regex、filesystem、new 失败）——
关异常的 TU 里这些 API 要么不可用要么行为改变（`new` 返回空）。
工程做法：**按库切分**——热路径库（行情/订单/撮合）`-fno-exceptions -fno-rtti`，
错误全走返回码；外围（配置加载、启动、工具链）保留异常。
两个世界之间用"边界层"翻译（异常 catch 住转错误码），别让 noexcept 边界含糊。

</details>
