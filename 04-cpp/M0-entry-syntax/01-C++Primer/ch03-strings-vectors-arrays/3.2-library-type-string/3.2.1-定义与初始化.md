# 3.2.1 定义与初始化

> 第 3 章 · 上一节：[3.2 string](./3.2-标准库类型string.md) · 下一节：[3.2.2 读写操作](./3.2.2-读写操作.md)

## 本节讲什么

`std::string` 的多种构造方式：默认空串、字面值、拷贝、`string(n, c)` 重复字符、C++11 列表初始化。

## 核心用法

```cpp
#include <string>

std::string s1;                    // 空串 ""
std::string s2 = "hello";          // 字面值
std::string s3(s2);                // 拷贝
std::string s4(10, 'c');           // "cccccccccc"
std::string s5 = std::string(5, 'x');  // "xxxxx"
std::string s6{"IF2406"};          // C++11 列表初始化
```

| 写法 | 结果 |
|------|------|
| `string s;` | 默认构造，空串 |
| `string s = "abc";` | 从 C 风格字面量拷贝内容 |
| `string s(other);` | 深拷贝 `other` 的字符序列 |
| `string s(n, c);` | `n` 个字符 `c` |
| `string s{"abc"};` | C++11 列表初始化 |

## 和 C 的区别（string vs char 数组）

这是 C→C++ 的**核心升级**——C 用 `char[]` 手动管理，C++ 用 `string` 自动管理：

| 对比点 | C（`char[]`/`char*`） | C++（`std::string`） |
|--------|----------------------|----------------------|
| 长度 | `strlen(s)` 扫 `\0` | `s.size()` 直接拿 |
| 初始化 | `char s[] = "hello";` 固定大小 | `string s = "hello";` 自动管理 |
| 拷贝 | `strcpy(dst, src)` 怕越界 | `string s2 = s1;` 深拷贝，安全 |
| 重复字符 | `memset(buf, 'c', 10); buf[10]=0;` | `string s(10, 'c');` |
| 内存释放 | 手动 `free`/`delete[]` | 析构自动释放（RAII） |

**给 C 程序员的关键提醒：**
1. `string` 不需要你管 `\0`、不需要你算长度、不需要你手动释放——析构时自动回收内存。
2. `string s2 = s1;` 是**深拷贝**（独立内存），不是 C 里 `char* p = s` 的指针复制（浅拷贝）。
3. `string` 可变长，不用像 C 的 `char[64]` 那样提前估大小。

```c
/* C：char 数组，手动管理 */
char s1[16] = "hello";        /* 固定大小，长了截断 */
char s2[16];
strcpy(s2, s1);               /* 怕越界 */
size_t len = strlen(s2);      /* 扫 \0 */
/* 离开作用域自动回收（栈），但堆的要 free */
```
```cpp
// C++：string 自动管理
std::string s1 = "hello";     /* 可变长，不截断 */
std::string s2 = s1;          /* 深拷贝，安全 */
size_t len = s2.size();       /* 直接拿，不扫 \0 */
/* 离开作用域析构自动释放 */
```

## 常见错误

**1. 以为 `string s2 = s1` 是浅拷贝**
C 里 `char* p = s` 是指针复制（两个指针指向同一块）；C++ 的 `string s2 = s1` 是深拷贝（独立内存）。改 `s2` 不影响 `s1`。

**2. `string s = 'c';` 单字符赋值**
```cpp
std::string s = 'c';   // ❌ 不合法：单字符不是字符串
std::string s(1, 'c'); // ✅ 一个 'c'："c"
std::string s = "c";   // ✅ 字符串字面量
```

## 自测题

**1（选择）** `std::string s2 = s1;` 后修改 `s2`，`s1` 会变吗？
- A. 会变（浅拷贝）
- B. 不变（深拷贝）

**2（判断）** C++ 的 `string` 需要手动管理 `\0` 结束符。

**3（应用）** 用 C++ string 实现：创建一个 20 个 `'-'` 的字符串（分割线）。

<details><summary>参考答案</summary>
1. B。`string` 的拷贝是深拷贝，`s2` 有独立内存，改 `s2` 不影响 `s1`。C 里 `char* p = s` 才是浅拷贝（指针复制）。
2. 错。`string` 内部维护长度和结束符，你不用管 `\0`。`size()` 返回字符数，不含 `\0`。只有调 `c_str()` 和 C 接口互操作时才关心 `\0`。
3. `std::string line(20, '-');` —— 第一个参数是数量，第二个是字符。
</details>
