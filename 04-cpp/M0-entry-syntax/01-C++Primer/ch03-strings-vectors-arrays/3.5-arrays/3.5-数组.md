# 3.5 数组

## 本节讲什么

介绍 C++ **内置原生数组**：与 `vector` 一样存**同类型连续元素**，但尺寸**编译期固定、不可扩容**。重点：定义与初始化、下标、**数组名退化为指针**、`std::begin`/`end`；现代 C++ **优先 `vector`/`string`**。

## 要点

- **语法**：`T name[常量表达式]`；维度须编译期常量，**不能拷贝/整体赋值**
- **初始化**：列表初始化可省略维度；`char[]` 用字符串字面量会**自动加 `\0`**
- **下标**：从 0 开始，`arr[i]` ≡ `*(arr+i)`；**无边界检查**，越界 UB
- **退化**：数组名多数情况变**指向首元素的指针**；`sizeof(arr)`、`&arr`、初始化时不退化
- **`begin(arr)`/`end(arr)`**：C++11 全局函数，原生数组也能按迭代器风格遍历
- **vs vector**：数组固定、传参丢长度；业务开发优先 vector（见 [3.3](../3.3-library-type-vector/3.3-标准库类型vector.md)）
- **C++ 补的三层**：`std::size`/`std::ssize` 取长度、`std::array<T,N>`（布局等价 `T[N]`）、`std::span<T,N>` 零拷贝切外部缓冲区——见 [3.5.6](./3.5.6-C++在内建数组之上补的三层.md)
- **最易误判**：`auto a = {1,2,3}` 推导出的是 `initializer_list<int>`，**不是数组**

## 代码自测

**题目 1：** C++ 中数组和 `std::array` 有什么区别？
```cpp
int arr[5] = {1, 2, 3, 4, 5};
std::array<int, 5> a = {1, 2, 3, 4, 5};
```

<details>
<summary>参考答案</summary>

C 数组：多数用法中退化为指针（传参后 `sizeof` 信息丢失）、不能整体赋值/拷贝；**但 `sizeof(arr)`、`&arr`、字符串字面量初始化 `char[]` 三处不退化**；支持范围 `for`（C++11 起即可）。

`std::array`：有 `.size()`、可整体赋值/拷贝、是 standard-layout 且 trivially-copyable。

**注意一个常见误解**：`std::array` **不走内建数组的退化规则**——退化只作用于数组类型（`T[N]`），`std::array<T,N>` 是类类型，按值传参是**拷贝整个对象**（实测 `sizeof` 仍是 16，不是 8）。真要注意的是**别按值传**（拷贝开销），改传引用即可。详见 [3.5.6](./3.5.6-C++在内建数组之上补的三层.md)。

</details>
