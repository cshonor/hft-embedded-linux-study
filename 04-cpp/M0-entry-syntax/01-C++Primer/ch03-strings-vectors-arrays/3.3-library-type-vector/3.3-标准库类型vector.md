# 3.3 标准库类型 vector

## 本节讲什么

`std::vector` 是 C++ 标准库**动态数组 / 容器**——存放**同类型元素**的可变长序列。重点：**`()` 与 `{}` 初始化**、**下标规则**、**元素类型与拷贝**、**HFT 越界与 POD 选型**。

## 名字别搞混：vector ≠ 宿主

| 英文 | 常见中文 | 在 C++ / HFT 里指什么 |
|------|----------|------------------------|
| **vector** | **向量、容器** | `std::vector<T>`：标准库动态数组，本章主题 |
| **host** | **宿主** | 网络/系统语境：本机、宿主机（如 host byte order、宿主机 NIC） |

`vector` 来自数学「向量」的命名，在 C++ 里语义是**一维元素序列容器**，和网络里的「宿主机器」毫无关系。

## 要点

- `#include <vector>`；`std::vector<T>` 存放类型 `T` 的对象序列（**元素类型必须相同**）
- **动态数组**：长度不固定，元素在内存中**连续存放**（对缓存友好；HFT 批量 tick 常用）
- **初始化**：`v(10)` 十个默认值；`v{1,2,3}` 三个元素（勿混）
- **`push_back`**：运行时增容、添加新元素的正确方式
- **下标从 0 开始**：合法 `0 … size()-1`；**`v[v.size()]` 永远越界**
- **元素类型**：自定义类、指针、嵌套 `vector`；扩容依赖拷贝/移动，HFT 常选 POD

## 代码自测

**题目 1：** 以下两种添加元素的方式有什么区别？
```cpp
std::vector<int> v;
// 方式A
v.push_back(42);
// 方式B (C++11)
v.emplace_back(42);
```

<details>
<summary>参考答案</summary>

`push_back` 接受一个已构造的对象（可能产生临时对象和移动）。`emplace_back` 直接在容器内部用参数构造对象——避免临时对象。对于简单类型（int）无区别，对于复杂类型 `emplace_back` 更高效：
```cpp
v.emplace_back("hello", 5);  // 直接构造 string("hello", 5)
v.push_back(std::string("hello", 5));  // 先构造临时再移动
```

</details>
