# 2.3 成员初始化列表

> 第 2 章 · 上一节：[2.2 按位拷贝 vs 逐成员拷贝](02-bitwise-vs-memberwise.md) · 下一节：[2.4 NRVO](04-nrvo.md)

## 这节讲什么

`const` 成员、引用成员、无默认构造的成员对象**必须**在初始化列表初始化。初始化列表比构造体赋值更高效。

---

## 三种必须用初始化列表的情况

```cpp
class A {
    const int x;        // const 成员 → 必须初始化列表
    int& r;             // 引用成员 → 必须初始化列表
    Widget w;           // 无默认构造的成员 → 必须初始化列表
public:
    A(int v, int& ref) : x(v), r(ref), w(v) {}
};
```

### 为什么比构造体赋值高效

```cpp
// 低效：默认构造 + 赋值
A(int v) { x = v; }  // x 先默认构造，再赋值（2 步）

// 高效：直接构造
A(int v) : x(v) {}   // x 直接用 v 构造（1 步）
```

---

## 新手要点

- **初始化列表 = 直接构造**：成员在进入构造体之前就已完成构造。构造体里的 `x = v` 是赋值（先默认构造再赋值），初始化列表的 `x(v)` 是直接构造——省一步。
- **初始化顺序 = 声明顺序**：初始化列表按成员**声明顺序**执行，不是你写的列表顺序。别在列表里用前面的成员初始化后面的。

---

## HFT 关联

- **热路径配置对象用列表**：成员对象用初始化列表省一次默认构造 + 赋值。
