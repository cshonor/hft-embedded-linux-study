# 3.2 继承布局

> 第 3 章 · 上一节：[3.1 成员布局](01-member-layout.md) · 下一节：[3.3 sizeof 的真相](03-sizeof-truth.md)

## 这节讲什么

继承下成员布局的细节——单继承、多继承、虚继承各有不同的数据排列方式。

---

## 三种继承的数据布局

- **单继承**：基类成员在前，派生成员追加其后；共用一个 vptr
- **多继承**：多个基类子对象依次排列，各含自己的 vptr；访问非首基类成员需 this 调整
- **虚继承**：虚基类子对象只存一份，通过虚基类指针/偏移表定位——额外间接

---

## 新手要点（和 C 的区别）

- **C 用嵌套结构体模拟继承**：`struct Derived { Base base; int extra; };`，手动管理。C++ 的继承让编译器自动布局。
- **多继承的 this 调整**：访问非首基类的成员时，`this` 要偏移到对应基类子对象的开头——这是隐藏代价。

---

## HFT 关联

- **避免虚继承**：虚继承让对象膨胀（偏移表指针），热路径数据结构避免虚继承。
