# 12.1 字符串字面量作模板参数的挑战

> 第 12 章 字符串字面量作模板参数

## 这节讲什么

C++17 之前，字符串字面量不能直接作非类型模板参数（NTTP）。本节讲解为什么这是个问题，以及 C++17 的变通方案。

## 问题

```cpp
// C++14：字符串字面量不能直接作模板参数
// template<const char* Name>  ← 需要外部链接的指针
// struct Config { static constexpr const char* name = Name; };

// 正确写法：需要外部链接
extern const char MY_NAME[] = "HFT";
template<const char* Name> struct Config { /* ... */ };
Config<MY_NAME> cfg;  // OK，但 MY_NAME 必须是 extern
```

### 为什么不能直接用字面量？

字符串字面量 `"hello"` 的类型是 `const char[6]`，但数组到指针的衰减在模板参数推导中有限制。C++14 要求非类型模板参数必须是编译期常量表达式，而字符串字面量的地址在不同翻译单元中可能不同。

## C++17 的改进

C++17 放宽了 NTTP 的限制，允许更多类型（包括 `constexpr` 构造的类），但仍不能直接用字符串字面量。

### 变通方案 1：用 `const char*` + extern

```cpp
// header.h
extern constexpr char NAME[] = "HFT";  // C++17: constexpr extern
template<const char* N> struct Config { static const char* name() { return N; } };

// 使用
Config<NAME> cfg;
```

### 变通方案 2：用固定字符串结构

```cpp
// 用结构体包装字符串
template<size_t N>
struct StringLiteral {
    constexpr StringLiteral(const char (&str)[N]) {
        for (size_t i = 0; i < N; ++i) value[i] = str[i];
    }
    char value[N];
};

// C++17：StringLiteral 可以作 NTTP（因为它是 literal type）
template<StringLiteral S>
struct NamedConfig {
    static constexpr const char* name() { return S.value; }
};

// 使用
NamedConfig<"HFT"> cfg;  // C++17: OK!
std::cout << cfg.name();  // "HFT"
```

### 变通方案 3：用 `std::string_view`（C++20 更好）

```cpp
// C++20：string_view 可以作 NTTP
// template<std::string_view S>
// struct Config { static constexpr auto name = S; };

// Config<"HFT"> cfg;  // C++20: OK

// C++17 变通：用 const char* + 函数
template<auto S>
struct Config { static constexpr auto name = S; };
```

## 实际用法

### 编译期日志标签

```cpp
// 用 StringLiteral 包装
template<StringLiteral Tag>
void log_msg(const char* msg) {
    std::cout << "[" << Tag.value << "] " << msg << "\n";
}

log_msg<"ORDER">("Order placed");
log_msg<"RISK">("Risk check passed");
```

### 配置名编译期绑定

```cpp
template<StringLiteral Name>
struct NamedValue {
    static constexpr const char* name = Name.value;
    int value;
};

NamedValue<"max_qty"> max_q{1000};
NamedValue<"min_spread"> min_s{1};
```

## C++20 预告

C++20 引入了 class NTTP（非类型模板参数可以是类类型），并且 `std::string_view` 是 literal type，可以直接作 NTTP：

```cpp
// C++20
template<std::string_view S>
struct Config {
    static constexpr std::string_view name = S;
};

Config<"HFT"> cfg;  // C++20: 直接可用
```

## HFT 关联

```cpp
// 编译期绑定策略名
template<StringLiteral StrategyName>
class Strategy {
public:
    void on_tick(const Tick& t) {
        log<StrategyName>("tick received");
        // ...
    }
};

Strategy<"Alpha1"> alpha1;
Strategy<"MeanRev"> mean_rev;
// 每个策略实例在编译期绑定名字，运行时零开销
```

## 小结

| 方案 | C++ 版本 | 复杂度 |
|------|---------|--------|
| extern const char* | C++14 | 低 |
| StringLiteral 包装 | C++17 | 中 |
| string_view NTTP | C++20 | 低 |
