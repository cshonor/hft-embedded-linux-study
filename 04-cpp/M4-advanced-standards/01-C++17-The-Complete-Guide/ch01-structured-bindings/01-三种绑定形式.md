# 1.1 结构化绑定的三种形式

> 第 1 章 结构化绑定 · 下一节：[1.2 值语义与引用语义](02-值语义与引用语义.md)

## 这节讲什么

C++17 之前，从 struct/pair/tuple 取出多个成员要写一堆 `.first`/`.second` 或 `std::tie`。结构化绑定让你一条语句把多个成员"解包"到独立变量，代码更简洁、意图更清晰。

## 为什么要学这个（先建立直觉）

C 程序员熟悉的结构体解包：

```c
// C：逐个取成员
struct Point { int x, y; };
struct Point p = {1, 2};
int x = p.x;
int y = p.y;
// 问题：字段多了很啰嗦
```

C++11 有了 `std::tie`，但它是"写回"不是"读出"，而且要先声明变量：

```cpp
// C++11：std::tie 只能写回已有变量
int x, y;
std::tie(x, y) = std::make_pair(1, 2);  // 先声明再赋值
// 问题：x/y 默认初始化浪费，且语义是"赋值"不是"初始化"
```

C++17 结构化绑定一步到位：

```cpp
// C++17：声明即初始化
auto [x, y] = std::make_pair(1, 2);  // x=1, y=2
```

## 三种绑定形式

### 形式 1：结构体/类的公有成员

```cpp
struct Point { int x, y; };
Point p{1, 2};
auto [x, y] = p;          // x=1, y=2

struct Order {
    int id;
    double price;
    int qty;
};
Order ord{1001, 12.5, 200};
auto [id, price, qty] = ord;  // 一步解包三个字段
```

**条件**：所有成员必须都是 `public`。有私有成员的类不能绑定全部成员。

### 形式 2：原生数组

```cpp
int arr[3] = {10, 20, 30};
auto [a, b, c] = arr;  // a=10, b=20, c=30

// 拷贝数组元素到 a/b/c
// 改 a 不影响 arr[0]
```

### 形式 3：tuple-like（pair / tuple / array）

```cpp
// pair
std::pair pr{1, "hello"};
auto [k, v] = pr;  // k=1, v="hello"

// tuple
std::tuple t{1, 2.0, "three"};
auto [a, b, c] = t;  // a=1, b=2.0, c="three"

// array
std::array<int, 4> arr{1, 2, 3, 4};
auto [w, x, y, z] = arr;
```

### 最常见用法：遍历 map

```cpp
std::map<std::string, int> prices = {{"AAPL", 180}, {"GOOG", 140}};

// C++11：啰嗦
for (const auto& p : prices) {
    std::cout << p.first << ": " << p.second << "\n";
}

// C++17：干净
for (const auto& [symbol, price] : prices) {
    std::cout << symbol << ": " << price << "\n";
}
```

## 绑定数量必须匹配

```cpp
struct Point { int x, y; };
Point p{1, 2};

auto [x] = p;       // 编译错误：1 < 2，数量不够
auto [x, y, z] = p; // 编译错误：3 > 2，数量太多
auto [x, y] = p;    // 正确：2 == 2
```

## 底层机制（编译器视角）

`auto [x, y] = p` 并不是魔法，编译器把它展开为：

```cpp
// 编译器生成的等价代码
auto e = p;           // 1. 创建匿名变量 e（拷贝 p）
auto& x = e.x;        // 2. x 是 e.x 的引用（别名）
auto& y = e.y;        // 3. y 是 e.y 的引用
// e 在作用域结束时销毁
```

对于 tuple-like 类型，编译器用 `std::tuple_size`、`std::tuple_element` 和 `get<I>()` 来提取：

```cpp
// auto [a, b] = my_tuple; 展开为：
auto e = my_tuple;
auto& a = std::get<0>(e);
auto& b = std::get<1>(e);
```

理解这一点是理解值语义 vs 引用语义的关键——`x/y` 本质上是匿名变量 `e` 的成员引用。

## HFT 关联

```cpp
// 解包 tick 字段
struct Tick { double price; int qty; int side; };
auto [price, qty, side] = get_tick();
// 比 tick.price / tick.qty / tick.side 更简洁

// 遍历合约表
for (auto& [symbol, handler] : symbol_handlers) {
    handler->on_tick(tick);
}
```

**零开销**：编译期完成，运行时和手写 `.x/.y` 等价。

## 小结

| 形式 | 适用类型 | 条件 |
|------|---------|------|
| 结构体成员 | `struct`/`class` | 全部成员 public |
| 数组 | 原生数组 `T[N]` | 元素可拷贝 |
| tuple-like | `pair`/`tuple`/`array` | 有 `get<I>()` 或 `tuple_size` |
