# 2.1 if 带初始化

> 第 2 章 if/switch 带初始化 · 下一节：[2.2 switch 带初始化与最佳实践](02-switch带初始化与最佳实践.md)

## 这节讲什么

C++17 让 `if` 语句可以带一个初始化语句，把临时变量的作用域限制在 if/else 块内。这是一个小语法糖，但极大减少了变量泄漏和误用。

## 为什么要学这个（先建立直觉）

C 程序员常见的模式——查找 + 检查：

```c
// C：变量泄漏到外层
struct entry *it = map_find(map, key);
if (it != NULL) {
    use(it->value);
}
/* it 还在作用域，可能被误用 */
it->value = 0;  /* 意外的 bug */
```

C++11/14 同样的问题：

```cpp
// C++14：it 泄漏到外层
auto it = m.find(key);
if (it != m.end()) {
    use(it->second);
}
// it 还在作用域！下面可能误用
if (it != m.end()) { ... }  // it 可能已被其他逻辑改过
```

C++17 if-init 把变量关进 if/else 块：

```cpp
// C++17：it 只在 if/else 内可见
if (auto it = m.find(key); it != m.end()) {
    use(it->second);
}
// it 已出作用域，不能误用
```

## 语法

```cpp
if (init-statement; condition) {
    // condition 为 true 时执行
} else {
    // condition 为 false 时执行
    // init-statement 的变量在这里也可见
}
```

- `init-statement` 可以是：声明语句（`auto x = ...`）或表达式语句（`std::lock_guard lk(m)`）
- `condition` 是传统的条件表达式
- init 的变量在整个 if-else 块（含 else 分支）内可见

## 典型用法

### 1. 查找 + 检查

```cpp
std::map<std::string, int> m = {{"AAPL", 180}, {"GOOG", 140}};

if (auto it = m.find("AAPL"); it != m.end()) {
    std::cout << "Found: " << it->second << "\n";
} else {
    std::cout << "Not found\n";
    // it 也可见，但 it == m.end()
}
```

### 2. 锁 + 检查

```cpp
std::mutex m;
std::queue<Task> q;

// C++14：锁变量泄漏
{
    std::lock_guard<std::mutex> lk(m);
    if (!q.empty()) {
        process(q.front());
        q.pop();
    }
}

// C++17：一行搞定
if (std::lock_guard lk(m); !q.empty()) {
    process(q.front());
    q.pop();
}
```

### 3. optional 解包

```cpp
std::optional<Config> load_config();

if (auto cfg = load_config(); cfg.has_value()) {
    use(*cfg);
} else {
    // 加载失败
}
```

### 4. 文件/资源获取 + 检查

```cpp
if (auto f = std::ifstream("data.txt"); f) {
    // 读文件
    std::string line;
    while (std::getline(f, line)) { ... }
}
// f 自动关闭
```

### 5. 插入 + 检查

```cpp
if (auto [it, inserted] = m.try_emplace(key, value); inserted) {
    // 新插入成功
} else {
    // key 已存在，it 指向已有元素
    it->second = value;  // 覆盖
}
```

## 作用域细节

```cpp
if (auto x = compute(); x > 0) {
    // x 可见
} else {
    // x 也可见（整个 if-else 块）
}

// x 不可见！已经出作用域
// std::cout << x;  // 编译错误
```

对比：init 变量的作用域是**整个 if 语句**（含 else），不是只限 if 分支。

## 嵌套 if-init

```cpp
if (auto it = m.find(key); it != m.end()) {
    if (auto sub = it->second.find(subkey); sub != it->second.end()) {
        use(sub->second);
    }
}
```

## HFT 关联

```cpp
// 1. 行情字典查找
if (auto it = sym2id.find(symbol); it != sym2id.end()) {
    auto id = it->second;
    route(id, tick);
}

// 2. 锁 + 队列检查（热路径）
if (std::lock_guard lk(mtx); !order_queue.empty()) {
    auto order = order_queue.front();
    order_queue.pop();
    send(order);
}

// 3. optional 配合
if (auto best = book.best_bid(); best.has_value()) {
    match(*best);
}
```

**零开销**：纯语法糖，编译后和分开写完全等价。

## 小结

| 特性 | 说明 |
|------|------|
| 语法 | `if (init; cond) { ... } else { ... }` |
| init 变量作用域 | 整个 if-else 块（含 else） |
| 运行时开销 | 零 |
| 解决的问题 | 变量泄漏、误用 |
