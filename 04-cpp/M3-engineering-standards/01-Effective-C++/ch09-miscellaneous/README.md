## 代码自测

### Q1: 标准库优先

```cpp
// 手写版本
char* to_upper(char* s) {
    for (char* p = s; *p; ++p) *p = toupper(*p);
    return s;
}
// 标准库版本
std::string to_upper(std::string s) {
    std::transform(s.begin(), s.end(), s.begin(), ::toupper);
    return s;
}
```

> 为什么应该优先使用标准库？

<details>
<summary>答案与复习指引</summary>

**优先标准库的理由：**
1. **正确性**：标准库经过充分测试，手写容易出 bug（如 `toupper` 入参应为 `unsigned char`）
2. **可维护性**：其他 C++ 程序员都认识标准库，减少阅读成本
3. **性能**：标准库实现经过优化（如 `std::sort` 通常比手写快排快）
4. **可移植**：跨平台一致行为

**教训：** 不要重复造轮子。熟悉标准库是提升效率的最直接方式——`algorithm`/`string`/`vector`/`chrono`/`random` 等覆盖了大量日常需求。
