## 代码自测

**题目 1：** 以下代码中哪些地方产生了不必要的临时对象？
```cpp
string s1 = "hello";
string s2 = " world";
string s3 = s1 + s2 + "!";  // 产生了几个临时对象？
```

<details>
<summary>参考答案</summary>

`s1 + s2` 产生一个临时 string，再 `+ "!"` 又产生一个临时 string——共 2 个临时对象（如果编译器没优化）。减少临时对象的方法：1) `s3 = s1; s3 += s2; s3 += "!";`（用 `+=` 避免 `+` 的返回值拷贝）；2) `s3.reserve(s1.size() + s2.size() + 1);` 预分配。C++11 的 move 语义可减少拷贝，但 `+=` 仍更直接。

</details>
