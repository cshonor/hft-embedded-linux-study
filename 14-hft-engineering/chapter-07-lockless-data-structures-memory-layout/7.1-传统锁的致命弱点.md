# 7.1 传统锁的致命弱点

> 等锁 → sleep → 上下文切换 — mutex 把 μs 路径变成 ms 路径

← 上一章：[chapter-05 OS 调优](../chapter-05-os-kernel-tuning/README.md) · 下一节：[7.2 无锁 FIFO 队列](./7.2-无锁FIFO队列.md)

---

| 问题 | 说明 |
|------|------|
| **Lock contention** | 多线程 **抢锁** — 串行化 |
| **Deadlock** | 循环等待 |
| **Priority inversion** | 低优先级 **持锁** → 高优先级 **被挡** |
| **Convoying（护航）** | 醒来的线程 **排队抢锁** — 全员慢 |
| **阻塞 + 切换** | 等锁 → **sleep** → [chapter-05 上下文切换](../chapter-05-os-kernel-tuning/5.1-上下文切换的代价.md) |

**HFT 结论：** 关键路径 **不用 mutex** — 用 **无锁环** 或 **SPSC 单写单读**。
