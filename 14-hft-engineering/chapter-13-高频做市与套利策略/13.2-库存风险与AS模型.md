# 13.2 库存风险管理（Avellaneda-Stoikov 直觉）

> 最优报价 = 公允价 ± (半价差 + 库存惩罚项) — 模型在冷路径算，热路径只查表

← 上一节：[13.1 做市核心等式与逆向选择](./13.1-做市核心等式与逆向选择.md) · 下一节：[13.3 排队位置经济学](./13.3-排队位置经济学.md)

经典模型的工程直觉：**最优报价 = 公允价 ± (半价差 + 库存惩罚项)**

```
bid = mid − (γ/2)·σ²·(T−t) − δ·inventory     … inventory > 0 时 bid 更低
ask = mid + (γ/2)·σ²·(T−t) + δ·inventory
        ↑ 波动率越大，报价越宽（保护自己）
                          ↑ 持仓越多，越急着卖（偏斜）
```

| 参数 | 冷路径更新（每秒级） |
|------|---------------------|
| `σ`（波动率） | EWMA 估计，快市检测联动 |
| `inventory` | 热路径原子计数（→ [chapter-11 持仓上限](../chapter-11-风控合规与滑点控制/11.1-本地拒单链.md)） |
| `γ`（风险厌恶） | 日内常数，风控下发 |

**注意**：模型计算全部在冷路径，热路径只执行「查表拿报价 ± tick」——和风控同一个模式（→ [chapter-11 §1 热路径预算](../chapter-11-风控合规与滑点控制/11.1-本地拒单链.md)）。
