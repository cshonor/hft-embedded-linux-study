## Bypass 核心

| 机制 | 说明 |
|------|------|
| **User-space spinning** | 交易线程 **100% poll** NIC ring — **无阻塞 · 无 IRQ 等待** |
| **Zero copy** | DMA 数据 **映射/直达** 用户缓冲 — **无 memcpy** |

| 产品（示例） | |
|--------------|---|
| **OpenOnload** | Solarflare / AMD |
| **VMA** | Mellanox / NVIDIA |
| **DPDK** | 通用 PMD |

**效果（书中量级）：** UDP/TCP 读写 **1.5–10 μs → 0.5–2 μs**。
