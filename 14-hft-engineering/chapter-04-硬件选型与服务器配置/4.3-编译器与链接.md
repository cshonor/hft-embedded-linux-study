## 编译期优化

| 优化 | 作用 |
|------|------|
| **Loop unrolling** | 减分支与循环控制 |
| **Function inlining** | 消除 call 开销 · 助 **常量传播** |
| **LTO / -O3 -march=native** | 目标 CPU 指令集 |

**配合 C++：** 模板/CRTP 让 **多态在编译期** — [chapter-08 编码规范](../chapter-08-超低延迟核心引擎开发/README.md)

## 静态链接 vs 动态链接

| | **Static** | **Dynamic (.so)** |
|---|------------|-------------------|
| **部署** | 单二进制 | 共享库省磁盘 |
| **调用** | 直接地址 | **PLT 间接跳转** |
| **HFT** | **首选** — 跨库 **LTO** · 无运行时解析 |

```bash
# 示意
g++ -O3 -static -o gateway main.cpp ...
```
