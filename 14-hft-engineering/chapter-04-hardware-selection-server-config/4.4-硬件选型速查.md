| 项 | 建议 |
|----|------|
| **CPU** | 高 **单核频率** · 少跨 NUMA |
| **BIOS** | 关 HT / Turbo / C-states |
| **NIC** | 硬件时间戳 · Bypass 生态（Solarflare/DPDK） |
| **FPGA** | 软件 **1–5 μs** 不够时 — ns 级确定性 |
