## 要点

| 操作 | 消息队列 | 信号量 | 共享内存 | 类比 |
|------|----------|--------|----------|------|
| 创建/打开 | `msgget` | `semget` | `shmget` | open |
| 控制/删 | `msgctl` | `semctl` | `shmctl` | fcntl |
| 主体操作 | `msgsnd`/`msgrcv` | `semop` | `shmat`/`shmdt` | 读写 |

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/types.h>
#include <sys/msg.h>
#include <sys/sem.h>
#include <sys/shm.h>
/* SysV IPC API 总览: get/ctl/op 三类操作 */
int main(void) {
    /* 三类 IPC 共有的模式:
     * 1. xxxget(key, ...)  — 创建/获取 IPC 对象
     * 2. xxxctl(id, cmd, ...) — 控制(查看/设置/删除)
     * 3. xxxop(id, ...)    — 操作(发送/接收/同步)
     */
    printf("SysV IPC API overview:\n");
    printf("  msgget/msgctl/msgsnd/msgrcv\n");
    printf("  semget/semctl/semop\n");
    printf("  shmget/shmctl/shmat/shmdt\n");

    /* IPC_CREAT: 创建, IPC_EXCL: 排他创建 */
    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);
    printf("\nCreated msgq: id=%d\n", msqid);

    /* IPC_STAT: 查看属性 */
    struct msqid_ds ds;
    msgctl(msqid, IPC_STAT, &ds);
    printf("  owner uid=%u, mode=%o\n", ds.msg_perm.uid, ds.msg_perm.mode);

    /* IPC_RMID: 删除 (必须显式做, 否则泄漏!) */
    msgctl(msqid, IPC_RMID, NULL);
    printf("  deleted\n");
    return 0;
}
```
