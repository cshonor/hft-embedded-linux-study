## 要点

1. 非 fd，无多路复用  
2. 易泄漏，无自动回收  
3. 无路径名，`ls`/`rm` 管不了  
4. API 老旧；新项目优先 POSIX IPC  

限额：`/proc/sys/kernel/msg*`、`sem`、`shm*`；超限常 `ENOSPC`。

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <unistd.h>
/* SysV IPC 的缺陷: 泄漏/配额/无引用计数 */
int main(void) {
    /* 缺陷1: 内核持久, 进程退出不自动删除 */
    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);
    printf("Created msgq id=%d\n", msqid);
    printf("If we forget to delete, it LEAKS until reboot!\n");

    /* 缺陷2: 系统配额限制 */
    struct msqid_ds ds;
    msgctl(msqid, IPC_STAT, &ds);
    printf("Max queue bytes: %lu\n", (unsigned long)ds.msg_qbytes);

    /* 查看系统限制 */
    printf("System limits (ipcs -l):\n");
    printf("  max queues: %ld\n", sysconf(_SC_MQ_OPEN_MAX));

    /* 缺陷3: key 冲突可能 */
    printf("\nftok may collide if files share inode low bits\n");

    /* 正确做法: 用完立即删 */
    msgctl(msqid, IPC_RMID, NULL);
    printf("Deleted (no leak)\n");
    return 0;
}
```
