---

## 要点

`msgget(key, flag)`，`flag` = `IPC_CREAT` / `IPC_EXCL` + mode：

1. 按 key 查找  
2. **不存在**：无 `IPC_CREAT` → `ENOENT`；有则创建  
3. **已存在**：`CREAT|EXCL` → `EEXIST`；仅 `CREAT` → 返回已有 id  

服务端常用：`get(key, IPC_CREAT | IPC_EXCL | 0600)`。

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | IPC_CREAT\|IPC_EXCL 原子排他创建，服务端首个创建者唯一，无竞态 |
| HFT | 排他创建语义防多实例抢同一对象；EEXIST 判已有实例 |

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <sys/sem.h>
#include <sys/shm.h>
/* xxxget: 创建/获取 IPC 对象 */
int main(void) {
    /* msgget: 消息队列 */
    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);
    printf("msgget: id=%d\n", msqid);

    /* semget: 信号量集 (第二个参数=信号量个数) */
    int semid = semget(IPC_PRIVATE, 2, IPC_CREAT | 0666);
    printf("semget: id=%d (2 semaphores)\n", semid);

    /* shmget: 共享内存 (第二个参数=大小) */
    int shmid = shmget(IPC_PRIVATE, 4096, IPC_CREAT | 0666);
    printf("shmget: id=%d (4096 bytes)\n", shmid);

    /* IPC_CREAT | IPC_EXCL: 排他创建 (如果已存在则失败) */
    /* key = IPC_PRIVATE 总是创建新对象 */
    printf("\nIPC_CREAT: create if not exists\n");
    printf("IPC_EXCL: fail if already exists\n");
    printf("IPC_PRIVATE: always create new\n");

    /* 清理 */
    msgctl(msqid, IPC_RMID, NULL);
    semctl(semid, 0, IPC_RMID);
    shmctl(shmid, IPC_RMID, NULL);
    return 0;
}
```
