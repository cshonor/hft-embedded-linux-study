## 要点

- **key**：外部约定名  
- **id**（msgid/semid/shmid）：内核句柄；后续全用 id  
- **不是 fd** → 不能 select/poll/epoll  

`struct ipc_perm`：uid/gid、cuid/cgid、mode（r/w，无执行语义）。权限逻辑类似文件。
