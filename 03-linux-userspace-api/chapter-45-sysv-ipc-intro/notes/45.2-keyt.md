## 要点

跨进程定位同一对象 ≈「文件名」。

| 方式 | 说明 |
|------|------|
| `IPC_PRIVATE` | 每次 `get` 新建；适合亲缘进程（传 id） |
| 硬编码整数 | 易冲突 |
| **`ftok(path, proj_id)`** | inode+设备+`proj_id`；文件重建 → key 变 |
