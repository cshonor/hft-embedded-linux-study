# 45.10 Exercises

> 本章：[TLPI 第 45 章 — System V IPC Introduction](../README.md)

## 练习题

### 练习 1：ftok 生成 key

编写程序，使用 `ftok()` 从指定路径和项目号生成 IPC key，并创建一个消息队列。

### 练习 2：查看 IPC 状态

编写程序，使用 `msgctl(IPC_STAT)`/`semctl(IPC_STAT)`/`shmctl(IPC_STAT)` 查看 IPC 对象的属性。

### 练习 3：清理 IPC 对象

编写程序，扫描所有 SysV IPC 对象，删除属于指定用户的对象（清理脚本）。

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"
#include <sys/ipc.h>
#include <sys/msg.h>

int main(int argc, char *argv[]) {
    if (argc != 3)
        usageErr("usage: %s <path> <proj_id_char>\n", argv[0]);

    key_t key = ftok(argv[1], argv[2][0]);
    if (key == -1) errExit("ftok");

    printf("key = 0x%08x\n", (unsigned int)key);

    int msqid = msgget(key, IPC_CREAT | IPC_EXCL | 0660);
    if (msqid == -1) {
        if (errno == EEXIST)
            printf("queue already exists, key=0x%x\n", (unsigned int)key);
        else
            errExit("msgget");
    } else {
        printf("created msqid=%d\n", msqid);
    }
    return 0;
}
```

### 练习 2 参考代码

```c
#include "tlpi_hdr.h"
#include <sys/msg.h>
#include <sys/sem.h>
#include <sys/shm.h>
#include <time.h>

void show_msgq(int msqid) {
    struct msqid_ds ds;
    if (msgctl(msqid, IPC_STAT, &ds) == -1) return;

    printf("Message Queue (id=%d):\n", msqid);
    printf("  owner uid=%d gid=%d mode=%o\n",
           ds.msg_perm.uid, ds.msg_perm.gid, ds.msg_perm.mode);
    printf("  bytes=%lu messages=%lu\n",
           (unsigned long)ds.msg_cbytes,
           (unsigned long)ds.msg_qnum);
    printf("  max bytes=%lu\n", (unsigned long)ds.msg_qbytes);
    printf("  last send=%s", ctime(&ds.msg_stime));
    printf("  last recv=%s", ctime(&ds.msg_rtime));
    printf("  last change=%s", ctime(&ds.msg_perm.__key ? 0 : 0));
}

/* 类似函数 show_sem() show_shm() 省略 */
```

### 练习 3 参考代码

```c
/* 清理脚本（需 root 权限扫描所有对象） */
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <sys/sem.h>
#include <sys/shm.h>

/* 注意：Linux 没有 API 枚举所有 IPC 对象。
 * 实际清理使用 ipcs/ipcrm 命令。
 * 以下用 system() 调用 ipcrm */
void cleanup_ipc(uid_t target_uid) {
    char cmd[256];
    snprintf(cmd, sizeof(cmd),
        "ipcs -q | awk '$3==\"%d\" {print $2}' | xargs -r ipcrm -q", target_uid);
    system(cmd);

    snprintf(cmd, sizeof(cmd),
        "ipcs -s | awk '$3==\"%d\" {print $2}' | xargs -r ipcrm -s", target_uid);
    system(cmd);

    snprintf(cmd, sizeof(cmd),
        "ipcs -m | awk '$3==\"%d\" {print $2}' | xargs -r ipcrm -m", target_uid);
    system(cmd);
}
```

**Shell 脚本替代**：
```bash
#!/bin/bash
USER=$1
ipcs -q | awk -v u=$USER '$3==u {print $2}' | xargs -r ipcrm -q
ipcs -s | awk -v u=$USER '$3==u {print $2}' | xargs -r ipcrm -s
ipcs -m | awk -v u=$USER '$3==u {print $2}' | xargs -r ipcrm -m
```

## HFT / 嵌入式关联

- **IPC 泄漏**：HFT 服务崩溃后可能遗留 IPC 对象，需要清理脚本
- **启动检查**：HFT 服务启动前检查是否有遗留 IPC 对象，避免冲突
- **监控**：`ipcs` 数据纳入运维监控
- **嵌入式**：精简系统用 `ipcs`/`ipcrm` 管理有限 IPC 资源
