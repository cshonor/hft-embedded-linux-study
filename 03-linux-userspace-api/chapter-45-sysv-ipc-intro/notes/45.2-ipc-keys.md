---

## 要点

跨进程定位同一对象 ≈「文件名」。

| 方式 | 说明 |
|------|------|
| `IPC_PRIVATE` | 每次 `get` 新建；适合亲缘进程（传 id） |
| 硬编码整数 | 易冲突 |
| **`ftok(path, proj_id)`** | inode+设备+`proj_id`；文件重建 → key 变 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | IPC_PRIVATE 每次新建适合亲缘传 id；ftok(path,proj) 跨进程定位同一对象 |
| HFT | ftok 依赖文件 inode，文件重建 key 变致进程失联，用固定路径+proj 管理 |

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/types.h>
#include <fcntl.h>
/* ftok: 用文件路径 + 项目号生成 IPC key */
int main(void) {
    /* 创建一个临时文件用于 ftok */
    int fd = open("/tmp/ftok_demo", O_CREAT | O_RDWR, 0644);
    close(fd);

    /* ftok: 组合文件的 inode 号 + 项目号(low 8 bits) */
    key_t k1 = ftok("/tmp/ftok_demo", 'A');  /* proj='A' */
    key_t k2 = ftok("/tmp/ftok_demo", 'B');  /* proj='B' */
    key_t k3 = ftok("/tmp/ftok_demo", 'A');  /* 相同参数 = 相同 key */

    printf("ftok('A') = 0x%x\n", (unsigned)k1);
    printf("ftok('B') = 0x%x (different proj)\n", (unsigned)k2);
    printf("ftok('A') = 0x%x (same as first)\n", (unsigned)k3);

    /* IPC_PRIVATE: 总是创建新对象 (key=0) */
    printf("IPC_PRIVATE = 0x%x\n", (unsigned)IPC_PRIVATE);

    remove("/tmp/ftok_demo");
    return 0;
}
```
