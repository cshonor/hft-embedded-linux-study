## 要点

### 变更

`IN_ACCESS` · `IN_MODIFY` · `IN_ATTRIB` · `IN_CLOSE_WRITE` · `IN_CLOSE_NOWRITE` · `IN_OPEN`

### 创建 / 删除 / 移动

| 掩码 | 含义 |
|------|------|
| `IN_CREATE` / `IN_DELETE` | 目录内建/删 |
| `IN_DELETE_SELF` / `IN_MOVE_SELF` | 被监控对象自身删/改名 |
| `IN_MOVED_FROM` / `IN_MOVED_TO` | 移出/移入；**同 cookie** 配对 |

### 添加 watch 时的辅助

`IN_DONT_FOLLOW` · `IN_ONESHOT` · `IN_ONLYDIR`

### 内核通知

| 掩码 | 含义 |
|------|------|
| `IN_IGNORED` | watch 已失效（删/卸等） |
| `IN_Q_OVERFLOW` | **队列溢出，丢事件** |
| `IN_UNMOUNT` | FS 卸载 |

## 与 C 语言学习的关系

文件系统操作是 Unix 系统编程的核心。`stat`/`readdir`/`link`/`unlink` 等 API 需要 C 语言的 struct、指针和错误处理知识。注意 `readdir` 返回的 `struct dirent*` 指向静态存储，下次调用会覆盖——这是 C 语言指针生命周期的经典陷阱。对照 K&R 8.4-8.6 节学习文件系统接口。

## 常见陷阱

1. **stat/lstat/fstat 混用**

```c
/* stat: 跟随符号链接 */
/* lstat: 不跟随符号链接 */
lstat(path, &sb);  /* 获取符号链接自身信息 */
```

stat 会跟随符号链接获取目标文件信息。想获取链接本身用 lstat。搞混会导致权限判断错误。

2. **readdir 返回值被覆盖**

```c
struct dirent *d1 = readdir(dir);
struct dirent *d2 = readdir(dir);
/* d1 指向的内容可能已被 d2 覆盖! */
```

readdir 返回指向静态存储的指针。下次调用会覆盖。需要保存信息应复制 d_name 到自己的缓冲区。

3. **符号链接循环**

```c
ln -s b a; ln -s a b;  /* 循环链接 */
/* 递归遍历时会无限循环 */
```

符号链接可能形成循环。递归遍历目录时应限制深度或检测已访问的 inode。

## 自测题

**题目 1（选择）：** `lstat()` 和 `stat()` 的区别？
A. 没有区别
B. lstat 不跟随符号链接
C. stat 不跟随符号链接
D. lstat 只用于链接

<details>
<summary>参考答案</summary>

B。lstat 获取符号链接自身的信息（不跟随），stat 跟随符号链接获取目标文件的信息。

</details>

**题目 2（判断）：** `readdir()` 返回的 `struct dirent*` 可以长期保存。

<details>
<summary>参考答案</summary>

错误。readdir 返回指向静态存储的指针，下次调用会覆盖。需要保存应复制 d_name 等字段到自己的缓冲区。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
DIR *dir = opendir(".");
struct dirent *d;
while ((d = readdir(dir)) != NULL) {
    printf("%s
", d->d_name);
}
/* 没有 closedir */
```

<details>
<summary>参考答案</summary>

没有 closedir(dir)，导致目录流泄漏。应在所有路径上 closedir。

</details>

**题目 4（应用）：** 写代码递归遍历目录，打印所有文件路径。

<details>
<summary>参考答案</summary>

```c
void list_dir(const char *path) {
    DIR *dir = opendir(path);
    if (!dir) return;
    struct dirent *d;
    while ((d = readdir(dir)) != NULL) {
        if (d->d_name[0] == '.') continue;
        printf("%s/%s
", path, d->d_name);
    }
    closedir(dir);
}
```

</details>
