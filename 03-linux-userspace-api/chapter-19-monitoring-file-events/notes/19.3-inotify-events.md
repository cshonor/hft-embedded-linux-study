## 本节讲什么

struct inotify_event { int      wd; uint32_t mask;

---

## 要点

```c
struct inotify_event {
    int      wd;
    uint32_t mask;
    uint32_t cookie;   /* 关联 IN_MOVED_FROM / IN_MOVED_TO */
    uint32_t len;
    char     name[];   /* 变长；监控目录时多为子名 */
};
```

| 监控对象 | `name` |
|----------|--------|
| 普通文件 | 通常空 |
| 目录 | 子项事件时常有子文件名 |

一次 `read` 可能含**多个**变长事件；缓冲要够大，按 `sizeof(struct inotify_event) + NAME_MAX + 1` 倍数预留。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `struct inotify_event` 在嵌入式系统的应用场景 |
| HFT | `struct inotify_event` 对低延迟和性能的影响 |

## 代码示例

```c
#include <stdio.h>
#include <stdlib.h>
#include <sys/inotify.h>
#include <unistd.h>
#include <fcntl.h>
/* struct inotify_event 结构解析 */
int main(void) {
    int fd = inotify_init1(IN_NONBLOCK);
    int wd = inotify_add_watch(fd, "/tmp", IN_CREATE | IN_DELETE | IN_MODIFY);

    /* 触发事件 */
    int tfd = open("/tmp/inotify_struct_test.txt", O_CREAT, 0644);
    close(tfd);
    remove("/tmp/inotify_struct_test.txt");
    usleep(100000);  /* 等内核推送事件 */

    char buf[4096] __attribute__((aligned(8)));
    ssize_t len = read(fd, buf, sizeof(buf));
    if (len > 0) {
        for (char *p = buf; p < buf + len; ) {
            struct inotify_event *ev = (struct inotify_event *)p;
            printf("wd=%d mask=0x%x cookie=%u len=%u",
                   ev->wd, ev->mask, ev->cookie, ev->len);
            if (ev->len > 0)
                printf(" name=%s", ev->name);
            if (ev->mask & IN_CREATE) printf(" [CREATE]");
            if (ev->mask & IN_DELETE) printf(" [DELETE]");
            if (ev->mask & IN_MODIFY) printf(" [MODIFY]");
            printf("\n");
            p += sizeof(struct inotify_event) + ev->len;
        }
    }
    inotify_rm_watch(fd, wd);
    close(fd);
    return 0;
}
```
