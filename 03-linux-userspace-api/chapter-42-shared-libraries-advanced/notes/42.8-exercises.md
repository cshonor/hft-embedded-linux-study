## 要点

Linker namespaces：Linux 扩展，隔离多套全局符号空间（了解即可）。

| 变量 | 作用 |
|------|------|
| `LD_LIBRARY_PATH` | 搜索路径（SUID 忽略） |
| `LD_BIND_NOW` | 强制立即绑定 |
| `LD_PRELOAD` | 预加载劫持（SUID 忽略） |
| `LD_DEBUG=libs` / `all` | 调试动态链接 |

## 代码示例

```c
#include <stdio.h>
int main(void) {
    /* LD_* 环境变量:
     * LD_LIBRARY_PATH: 额外搜索路径
     * LD_PRELOAD: 预加载库
     * LD_DEBUG: 调试动态链接过程
     * 注意: SUID 程序忽略所有 LD_* (安全)
     */
    printf("LD_DEBUG=libs ./program → 显示库搜索过程\n");
    printf("LD_DEBUG=symbols → 显示符号解析\n");
    return 0;
}
```
