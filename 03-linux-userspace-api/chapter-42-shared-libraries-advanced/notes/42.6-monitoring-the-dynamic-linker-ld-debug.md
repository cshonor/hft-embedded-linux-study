# 42.6 初始化 / 终止

## 本节讲什么

加载时 constructor（优先级升序）；卸载时 destructor（反向）。 ---

---

## 要点

| 方式 | 说明 |
|------|------|
| `_init` / `_fini` | 老式，不推荐 |
| `__attribute__((constructor))` / `destructor` | 现代推荐；可带优先级 `(100)` |

加载时 constructor（优先级升序）；卸载时 destructor（反向）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 初始化 / 终止 在嵌入式系统的应用场景 |
| HFT | 初始化 / 终止 对低延迟和性能的影响 |

## 代码示例

```c
#include <stdio.h>
/* 共享库的初始化/终止函数 */
void __attribute__((constructor)) my_init(void) {
    printf("库加载时自动调用 (constructor)\n");
}
void __attribute__((destructor)) my_fini(void) {
    printf("库卸载时自动调用 (destructor)\n");
}
int main(void) {
    printf("主函数\n");
    return 0;
}
```
