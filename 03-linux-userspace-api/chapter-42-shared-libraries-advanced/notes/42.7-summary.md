## 本节讲什么

gcc -fvisibility=hidden -fPIC -c ... __attribute__((visibility("default"))) void exported_api(void); 缩小导出表、减轻符号冲突/介入、利于内部优化。

---

## 要点

```bash
gcc -fvisibility=hidden -fPIC -c ...
```

```c
__attribute__((visibility("default"))) void exported_api(void);
```

缩小导出表、减轻符号冲突/介入、利于内部优化。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 符号可见性 在嵌入式系统的应用场景 |
| HFT | 符号可见性 对低延迟和性能的影响 |

## 代码示例

```c
#include <stdio.h>
int main(void) {
    /* 符号可见性:
     * default: 导出 (外部可见)
     * hidden: 不导出 (仅库内部可见)
     * gcc -fvisibility=hidden → 默认隐藏, 只导出标记的
     */
    printf("符号可见性: default/hidden/protected\n");
    printf("__attribute__((visibility(\"hidden\"))) → 不导出\n");
    return 0;
}
```
