## 本节讲什么

`sigaction()` — POSIX 标准的信号处置设置接口，替代不可移植的 `signal()`。

---

## 要点

### 结构体

```c
struct sigaction {
    void     (*sa_handler)(int);          /* 简单处理函数 */
    void     (*sa_sigaction)(int, siginfo_t *, void *);  /* 扩展处理函数 */
    sigset_t   sa_mask;    /* 处理期间额外阻塞的信号集 */
    int        sa_flags;   /* 控制行为 */
};
```

### sa_flags 常用值

| flag | 含义 |
|------|------|
| `0` | 使用 sa_handler，默认语义 |
| `SA_RESTART` | 被信号中断的系统调用自动重启 |
| `SA_SIGINFO` | 使用 sa_sigaction（带 siginfo_t 详情） |
| `SA_NOCLDSTOP` | SIGCHLD 仅在子进程终止时发 |
| `SA_RESETHAND` | 信号传递后重置为 SIG_DFL（一次性） |

### sigaction vs signal

| | `signal()` | `sigaction()` |
|--|-----------|---------------|
| 可移植性 | 行为不一致（BSD vs SysV） | POSIX 标准 |
| SA_RESTART | 不支持 | 支持 |
| sa_mask | 不支持 | 支持 |
| SA_SIGINFO | 不支持 | 支持 |
| **结论** | **不要用** | **永远用 sigaction** |

### 典型用法

```c
struct sigaction sa;
memset(&sa, 0, sizeof(sa));
sa.sa_handler = handler;
sigemptyset(&sa.sa_mask);
sa.sa_flags = SA_RESTART;
sigaction(SIGINT, &sa, NULL);
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `SA_RESTART` 避免信号中断 read/write 后手动重试 |
| HFT | `SA_SIGINFO` 可获取信号来源 PID，用于审计 |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
#include <string.h>
#include <unistd.h>
/* sigaction: 三种处置方式 */
void handler(int sig) { printf("caught SIGUSR1\n"); }
void handler_info(int sig, siginfo_t *si, void *ctx) {
    printf("caught %d from pid=%d\n", sig, si->si_pid);
}

int main(void) {
    struct sigaction sa;

    /* 1. 简单 handler + SA_RESTART */
    memset(&sa, 0, sizeof(sa));
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = SA_RESTART;
    sigaction(SIGUSR1, &sa, NULL);

    /* 2. SA_SIGINFO: 获取发送者信息 */
    memset(&sa, 0, sizeof(sa));
    sa.sa_sigaction = handler_info;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = SA_SIGINFO;
    sigaction(SIGUSR2, &sa, NULL);

    raise(SIGUSR1);
    raise(SIGUSR2);
    printf("handlers done\n");
    return 0;
}
```
