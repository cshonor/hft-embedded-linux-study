## 本节讲什么

`sigpending()` — 查询哪些信号已被产生但因阻塞而尚未传递。

---

## 要点

### API

```c
int sigpending(sigset_t *set);
```
- 返回当前进程的 pending 信号集（已产生但被阻塞的信号）
- 仅查询，不修改信号状态

### 核心行为

1. 信号产生 → 检查掩码 → 被阻塞 → 标记 pending
2. 解除阻塞 → pending 信号立即传递
3. 同类型多次产生 → pending 中只标记一次（标准信号不排队）

### 典型用法

```c
sigset_t pending;
sigpending(&pending);
if (sigismember(&pending, SIGINT)) {
    printf("SIGINT is pending!\n");
}
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 临界区结束后检查 pending，决定是否需要特殊处理 |
| HFT | 长时间阻塞后检查 pending 可辅助诊断"丢失"的信号事件 |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>
/* sigpending: 查询被阻塞的待处理信号 */
int main(void) {
    sigset_t blockset, oldmask, pending;
    sigemptyset(&blockset);
    sigaddset(&blockset, SIGUSR1);

    sigprocmask(SIG_BLOCK, &blockset, &oldmask);
    raise(SIGUSR1);  /* 被阻塞, 标记 pending */

    sigpending(&pending);
    if (sigismember(&pending, SIGUSR1)) {
        printf("SIGUSR1 is pending (blocked)\n");
    }

    signal(SIGUSR1, SIG_IGN);  /* 改成忽略避免退出 */
    sigprocmask(SIG_SETMASK, &oldmask, NULL);
    printf("unblocked, SIGUSR1 delivered (ignored)\n");
    return 0;
}
```
