## 本节讲什么

`sigset_t` 类型及 5 个操作函数，用于批量管理信号集合。

---

## 要点

### 数据类型

```c
typedef struct { /* 实现定义，通常 long[] 位图 */ } sigset_t;
```

### 操作函数

| 函数 | 作用 |
|------|------|
| `sigemptyset(&set)` | 清空（所有 bit = 0） |
| `sigfillset(&set)` | 填满（所有 bit = 1） |
| `sigaddset(&set, sig)` | 添加信号 sig |
| `sigdelset(&set, sig)` | 移除信号 sig |
| `sigismember(&set, sig)` | 查询 sig 是否在集合中（1/0） |

### 关键约束

- **必须先 `sigemptyset` 或 `sigfillset` 初始化**，不能直接 `sigaddset`
- `sigismember` 返回 1（在集合中）/ 0（不在）/ -1（错误）

### 典型用法

```c
sigset_t set;
sigemptyset(&set);
sigaddset(&set, SIGINT);
sigaddset(&set, SIGTERM);
// 后续用于 sigprocmask() 或 sigaction.sa_mask
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 信号集是信号管理的基石，`sigprocmask` 批量阻塞避免竞态 |
| HFT | 临界区前用 `sigset_t` 批量阻塞信号，事后恢复，保证原子性 |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
/* 信号集操作: sigemptyset/sigaddset/sigismember */
int main(void) {
    sigset_t set;
    sigemptyset(&set);
    sigaddset(&set, SIGINT);
    sigaddset(&set, SIGTERM);
    sigaddset(&set, SIGUSR1);

    printf("SIGINT in set: %d\n", sigismember(&set, SIGINT));   /* 1 */
    printf("SIGKILL in set: %d\n", sigismember(&set, SIGKILL)); /* 0 */

    sigdelset(&set, SIGUSR1);
    printf("SIGUSR1 in set: %d\n", sigismember(&set, SIGUSR1)); /* 0 */

    sigfillset(&set);
    printf("SIGKILL in full set: %d\n", sigismember(&set, SIGKILL)); /* 1 */
    return 0;
}
```
