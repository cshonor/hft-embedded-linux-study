# 20.8 显示信号描述

## 本节讲什么

如何用库函数将信号编号翻译为人类可读的描述字符串。

---

## 要点

| 函数 | 头文件 | 作用 |
|------|--------|------|
| `strsignal(int sig)` | `<string.h>` | 返回信号描述字符串指针 |
| `psignal(int sig, const char *prefix)` | `<signal.h>` | 向 stderr 打印 `prefix: description` |
| `sigdescr_np(int sig)` | `<signal.h>` | GNU 扩展，线程安全版 strsignal |

- `strsignal` 返回的字符串可能被后续调用覆盖（非线程安全）
- `psignal` 是诊断工具的标准写法，类似 `perror`

### 常见信号描述速查

| 信号 | 描述 |
|------|------|
| SIGINT | Interrupt |
| SIGSEGV | Segmentation fault |
| SIGKILL | Killed |
| SIGTERM | Terminated |
| SIGALRM | Alarm clock |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `psignal` 是最小诊断手段，无 logger 时直接写 stderr |
| HFT | 信号处理中用 `psignal` 做最小化日志，避免 printf 线程不安全 |

## 代码示例

```c
#include <stdio.h>
#include <string.h>
#include <signal.h>
/* 显示信号描述: strsignal / psignal */
int main(void) {
    printf("SIGINT: %s\n", strsignal(SIGINT));
    printf("SIGSEGV: %s\n", strsignal(SIGSEGV));
    psignal(SIGTERM, "got signal");
    psignal(SIGKILL, "force kill");

    int sigs[] = {SIGHUP, SIGINT, SIGQUIT, SIGILL, SIGABRT,
                  SIGFPE, SIGKILL, SIGSEGV, SIGPIPE, SIGALRM,
                  SIGTERM, SIGCHLD, SIGSTOP, SIGCONT};
    for (size_t i = 0; i < sizeof(sigs)/sizeof(sigs[0]); i++) {
        printf("  [%2d] %s\n", sigs[i], strsignal(sigs[i]));
    }
    return 0;
}
```
