# 63.5 同时等待信号和文件描述符

> 本章：[TLPI 第 63 章 — 备用 I/O 模型](./README.md)

## 本节讲什么

`pselect()` / `ppoll()` / `epoll_pwait()` — 原子地等待信号和 fd，消除竞态。

---

## 要点

### 问题：信号与 I/O 的竞态

```c
/* 竞态: 信号在 sigprocmask 和 select 之间到达 */
sigprocmask(SIG_UNBLOCK, &sigset, NULL);  /* 解除阻塞 */
select(...);  /* 如果信号在此行之前到达, select 永远不醒 */
```

### 解决方案：原子"解除阻塞 + 等待"

| 函数 | 替代 | 优势 |
|------|------|------|
| `pselect` | `select` | 原子解除信号阻塞 + 等待 fd |
| `ppoll` | `poll` | 同上 |
| `epoll_pwait` | `epoll_wait` | 同上 |

### pselect 签名

```c
int pselect(int nfds, fd_set *rfds, fd_set *wfds, fd_set *efds,
            const struct timespec *timeout, const sigset_t *sigmask);
```
- `sigmask`：等待期间临时替换信号掩码（原子操作）
- 返回后信号掩码恢复原值

### signalfd + epoll 方案

```c
/* 更优雅的方案: signalfd 融入 epoll */
int sfd = signalfd(-1, &sigmask, 0);
epoll_ctl(epfd, EPOLL_CTL_ADD, sfd, &ev);
/* epoll_wait 同时返回 fd 事件和信号事件 */
```

### 三种方案对比

| 方案 | 优势 | 劣势 |
|------|------|------|
| pselect/ppoll | POSIX 标准化 | 仍需 handler |
| epoll_pwait | Linux 高效 | Linux 专有 |
| signalfd + epoll | 统一事件循环，无 handler | Linux 专有 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | ppoll 是可移植的方案，适合嵌入式 |
| HFT | signalfd + epoll 统一事件循环，零信号中断延迟 |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
#include <poll.h>
#include <unistd.h>
#include <sys/signalfd.h>
/* 方案: signalfd + poll 统一等待信号和 fd */
int main(void) {
    /* 阻塞 SIGINT */
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGINT);
    sigprocmask(SIG_BLOCK, &mask, NULL);

    /* 创建 signalfd */
    int sfd = signalfd(-1, &mask, 0);

    /* poll 同时等 stdin 和 signalfd */
    struct pollfd fds[2];
    fds[0].fd = STDIN_FILENO;  fds[0].events = POLLIN;
    fds[1].fd = sfd;            fds[1].events = POLLIN;

    printf("type input or Ctrl+C (5s timeout):\n");
    int n = poll(fds, 2, 5000);
    if (n == 0) {
        printf("timeout\n");
    } else {
        if (fds[0].revents & POLLIN) {
            char buf[64];
            fgets(buf, sizeof(buf), stdin);
            printf("stdin: %s", buf);
        }
        if (fds[1].revents & POLLIN) {
            struct signalfd_siginfo si;
            read(sfd, &si, sizeof(si));
            printf("signal: %d\n", si.ssi_signo);
        }
    }
    close(sfd);
    return 0;
}
```
