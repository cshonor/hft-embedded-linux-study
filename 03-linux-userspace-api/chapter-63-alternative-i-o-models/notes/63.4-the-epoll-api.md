## 本节讲什么

`epoll` — Linux 高性能 I/O 多路复用，O(1) 复杂度，适合大量连接。

---

## 要点

### API 三件套

| 函数 | 作用 |
|------|------|
| `epoll_create1(flags)` | 创建 epoll 实例，返回 fd |
| `epoll_ctl(epfd, op, fd, &event)` | 添加/修改/删除监听 fd |
| `epoll_wait(epfd, events, maxevents, timeout)` | 等待事件 |

### epoll_ctl 的 op

| op | 作用 |
|----|------|
| `EPOLL_CTL_ADD` | 添加 fd |
| `EPOLL_CTL_MOD` | 修改监听事件 |
| `EPOLL_CTL_DEL` | 删除 fd |

### 事件类型

| 事件 | 含义 |
|------|------|
| `EPOLLIN` | 可读 |
| `EPOLLOUT` | 可写 |
| `EPOLLET` | 边沿触发（只通知一次） |
| `EPOLLONESHOT` | 通知一次后需重新 armed |

### 两种触发模式

| 模式 | 行为 | 推荐 |
|------|------|------|
| 水平触发 (LT, 默认) | fd 可读就一直通知 | 简单，但可能多余通知 |
| 边沿触发 (ET) | 状态变化时通知一次 | 高性能，需非阻塞 + 读到 EAGAIN |

### 与 select/poll 的对比

| | select | poll | epoll |
|--|--------|------|-------|
| fd 上限 | 1024 (FD_SETSIZE) | 无限制 | 无限制 |
| 复杂度 | O(n) | O(n) | O(1) |
| 返回方式 | 全量遍历检查 | 全量遍历检查 | 只返回就绪的 |
| 内核维护 | 每次拷贝 fd_set | 每次拷贝 pollfd | 内核维护红黑树 |
| 大量连接 | 慢 | 慢 | 快 |

### epoll_event 结构

```c
struct epoll_event {
    uint32_t events;       /* EPOLLIN | EPOLLOUT | ... */
    epoll_data_t data;     /* fd / ptr / u32 / u64 */
};
```

### 边沿触发 (ET) 模式要点

```c
/* ET 模式必须循环读到 EAGAIN */
while (1) {
    ssize_t n = read(fd, buf, sizeof(buf));
    if (n == -1 && errno == EAGAIN) break;  /* 读完了 */
    if (n <= 0) break;  /* EOF 或错误 */
    /* 处理 buf */
}
```

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | epoll 是 Linux 高并发服务端的标准方案 |
| HFT | ET 模式 + 非阻塞 fd + 批量 read 是最低延迟方案 |

## 代码示例

```c
#include <stdio.h>
#include <sys/epoll.h>
#include <unistd.h>
#include <fcntl.h>
#include <string.h>
/* epoll: 监听 stdin + 定时器 fd */
int main(void) {
    int epfd = epoll_create1(0);

    /* 添加 stdin (ET 模式) */
    struct epoll_event ev;
    ev.events = EPOLLIN | EPOLLET;
    ev.data.fd = STDIN_FILENO;
    fcntl(STDIN_FILENO, F_SETFL, O_NONBLOCK);
    epoll_ctl(epfd, EPOLL_CTL_ADD, STDIN_FILENO, &ev);

    /* 事件循环 */
    struct epoll_event events[10];
    printf("type something (Ctrl+D to exit):\n");
    while (1) {
        int n = epoll_wait(epfd, events, 10, -1);  /* 无限等待 */
        for (int i = 0; i < n; i++) {
            if (events[i].data.fd == STDIN_FILENO) {
                char buf[256];
                /* ET 模式: 循环读到 EAGAIN */
                while (1) {
                    ssize_t r = read(STDIN_FILENO, buf, sizeof(buf)-1);
                    if (r <= 0) break;
                    buf[r] = 0;
                    printf("read: %s", buf);
                }
                if (r == 0) goto done;  /* EOF */
            }
        }
    }
done:
    close(epfd);
    return 0;
}
```
