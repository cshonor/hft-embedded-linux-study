# 13.4 Summary of I/O Buffering

> 本章：[TLPI 第 13 章](./README.md)

## 本节讲什么

两层缓冲总结。

### 缓冲层次
```
用户空间:  stdio 缓冲 (FILE*)
              ↓ fwrite/fread
              ↓ fflush
内核空间:  页缓存 (page cache)
              ↓ write/read
              ↓ fsync/fdatasync
磁盘:      实际存储
```

### 对比
| 层 | 管理 | 刷写方式 |
|----|------|---------|
| stdio | 用户态 | fflush() |
| page cache | 内核 | fsync() / 延迟写 |
