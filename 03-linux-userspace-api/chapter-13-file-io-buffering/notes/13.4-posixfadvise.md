## 要点

```c
int posix_fadvise(int fd, off_t offset, off_t len, int advice);
```

仅**建议**内核；常用：

| advice | 含义 |
|--------|------|
| `POSIX_FADV_NORMAL` | 默认 |
| `POSIX_FADV_SEQUENTIAL` | 顺序 → 加大预读 |
| `POSIX_FADV_RANDOM` | 随机 → 少预读 |
| `POSIX_FADV_DONTNEED` | 短期不用 → 可回收缓存 |
| `POSIX_FADV_WILLNEED` | 即将用 → 预加载 |
