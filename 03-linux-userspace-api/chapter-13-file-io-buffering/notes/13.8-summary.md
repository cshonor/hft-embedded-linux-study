## 要点

**写：** 应用 → stdio 用户缓冲 →（`fflush`）→ `write` → 内核脏页 →（`fsync`/flusher）→ 磁盘  

**读：** 磁盘 → 页缓存 → `read` → stdio 缓冲 → `fgets`/… → 应用

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

/* 缓冲层次总结:
 * 1. stdio 缓冲 (用户空间): setvbuf/fflush 控制
 * 2. 内核页缓存: posix_fadvise 提示, O_DIRECT 绕过
 * 3. fsync/fdatasync: 强制刷盘
 */
int main(void) {
    FILE *fp = fopen("/tmp/buf_summary.txt", "w");
    fprintf(fp, "hello");
    /* 数据在 stdio 缓冲 → fflush 后进内核页缓存 */
    fflush(fp);
    /* 内核页缓存 → fsync 后才真正落盘 */
    int fd = fileno(fp);
    fsync(fd);
    printf("数据已落盘 (stdio → 内核 → 磁盘)\n");
    fclose(fp);

    /* 总结:
     * write() → 内核页缓存 (不落盘)
     * fsync() → 强制页缓存写入磁盘
     * O_DIRECT → 绕过页缓存 (直接磁盘 I/O)
     * posix_fadvise → 给内核缓存提示
     */
    return 0;
}
```
