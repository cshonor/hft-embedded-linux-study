## 要点

`printf` / `fwrite` / `fgets` 先打用户缓冲；满或刷新时才 `read`/`write`。

### `setvbuf` 三种模式

```c
int setvbuf(FILE *stream, char *buf, int mode, size_t size);
```

| mode | 行为 | 典型默认 |
|------|------|----------|
| `_IOFBF` | 全缓冲：满才刷 | 普通磁盘文件 |
| `_IOLBF` | 行缓冲：`\n` 或满 | **终端上的 stdout** |
| `_IONBF` | 无缓冲 | **stderr** |

### 刷新

```c
int fflush(FILE *stream);   /* NULL = 刷新所有输出流 */
```

自动刷新：`fclose`、正常退出。  
> **不要**依赖 `fflush` 丢弃**输入**缓冲（未标准化）。

**重定向坑：** stdout 接到管道/文件时，常从行缓冲变成**全缓冲** → 无 `\n`/`fflush` 时日志「卡住」。

Demo：[`code/stdio_buffering.c`](../code/stdio_buffering.c)

### `fileno()` — `FILE*` 与 `fd` 的桥梁

```c
#include <stdio.h>
int   fileno(FILE *stream);              /* FILE* → int fd（向下拆箱） */
FILE *fdopen(int fd, const char *mode);  /* int fd → FILE*（向上装箱） */
```

| | `fileno(fp)` | `fdopen(fd, mode)` |
|---|---|---|
| 方向 | `FILE*` → `fd` | `fd` → `FILE*` |
| 缓冲 | 不改变现有缓冲 | **新建**一个用户缓冲区 |
| 所有权 | `fclose(fp)` 会关闭 `fd` | `fclose(fp)` 会关闭 `fd` |
| 典型用途 | 对 stdio 流调系统调用 | 给 `open()` 的 fd 加缓冲 |

三个标准流：`fileno(stdin)→0`、`fileno(stdout)→1`、`fileno(stderr)→2`。

**系统调用只认 `fd`，不认 `FILE*`**——需要 `fileno` 的场景：

| 场景 | 代码 |
|------|------|
| 强制落盘 | `fsync(fileno(fp))` |
| 设非阻塞 | `fcntl(fileno(fp), F_SETFL, O_NONBLOCK)` |
| 内存映射 | `mmap(NULL, len, PROT_READ, MAP_SHARED, fileno(fp), 0)` |
| 判断终端 | `isatty(fileno(stdout))` |
| 取文件属性 | `fstat(fileno(fp), &sb)` |

**混用规则**：`fprintf` 走用户缓冲，`write(fileno(fp))` 直接进内核，两者各走各的。混用前必须 `fflush(fp)` 同步，否则数据顺序错乱（详见 13.3 节）。

```c
FILE *fp = fopen("log.txt", "w");
fprintf(fp, "AAA");            /* 还在用户 buf */
fflush(fp);                    /* 刷干净 */
write(fileno(fp), "BBB", 3);  /* 现在顺序正确 */
```

POSIX.1-2008 要求 `fileno()` 不加锁（只读 `FILE` 结构的 `_fileno` 字段），线程安全；但拿到 `fd` 后的操作不一定线程安全。

| 路线 | 要点 |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>

int main(void) {
    /* stdio 缓冲 vs 内核缓冲 */
    FILE *fp = fopen("/tmp/bufdemo.txt", "w");

    /* 行缓冲: 遇到 \n 才 flush */
    fprintf(fp, "这行在缓冲区");
    fprintf(fp, "还没写入\n");  /* \n 触发 flush (行缓冲模式) */

    /* 手动 flush */
    fprintf(fp, "手动flush前");
    fflush(fp);  /* 强制写入内核 */

    /* setvbuf 设置缓冲模式 */
    setvbuf(fp, NULL, _IOFBF, 8192);  /* 全缓冲, 8KB */
    fprintf(fp, "全缓冲模式\n");

    fclose(fp);  /* fclose 自动 flush */

    /* 对比: write() 无用户缓冲, 直接进内核 */
    int fd = fileno(fp);
    write(fd, "直接写fd\n", 10);
    return 0;
}
```
