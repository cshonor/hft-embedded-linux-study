## 要点

```c
int ioctl(int fd, int request, ...);
```

通用流式读写之外：终端、声卡、磁盘等 **设备专属命令**。

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <termios.h>    /* struct winsize */
#include <stdio.h>

int main(void) {
    /* ioctl 获取终端窗口大小 — read/write 做不到的事 */
    struct winsize ws;

    if (ioctl(STDIN_FILENO, TIOCGWINSZ, &ws) == 0) {
        printf("终端: %d 行 x %d 列\n", ws.ws_row, ws.ws_col);
        printf("像素: %d x %d\n", ws.ws_ypixel, ws.ws_xpixel);
    } else {
        perror("ioctl TIOCGWINSZ");
        printf("（非终端环境，如管道/重定向）\n");
    }
    return 0;
}
```
