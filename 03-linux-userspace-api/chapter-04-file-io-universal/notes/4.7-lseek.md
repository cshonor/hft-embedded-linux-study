## 要点

```c
off_t lseek(int fd, off_t offset, int whence);
```

| whence | 基准 |
|--------|------|
| `SEEK_SET` | 文件起始 |
| `SEEK_CUR` | 当前偏移 |
| `SEEK_END` | 文件末尾 |

| 特性 | |
|------|--|
| 只改偏移 | 改的是 **打开文件描述** 内的 offset；**本身不产生 I/O** |
| **文件空洞** | 跳过尾部再 `write`，中间可不占磁盘块；读空洞区得 0 |
| **不可 seek** | 管道、socket、终端 → `-1`，`errno=ESPIPE` |

## 常见陷阱

1. **管道上 lseek 失败**

```c
lseek(pipe_fd, 0, SEEK_SET);  /* ESPIPE */
```

管道、socket、终端不支持 seek。lseek 返回 -1，errno=ESPIPE。

2. **空洞文件浪费磁盘**

```c
lseek(fd, 1024*1024, SEEK_SET);
write(fd, "x", 1);  /* 中间是空洞 */
```

lseek 超过文件末尾再 write 会产生空洞。空洞在读时返回 0，但不一定占磁盘块。

3. **lseek 返回值未检查**

```c
lseek(fd, offset, SEEK_SET);
read(fd, buf, n);  /* 偏移可能没变 */
```

lseek 返回新的文件偏移。不检查返回值可能导致后续读写位置错误。

## 自测题

**题目 1（选择）：** `lseek(fd, 0, SEEK_CUR)` 的作用是？
A. 跳到开头
B. 跳到末尾
C. 获取当前偏移
D. 重置偏移

<details>
<summary>参考答案</summary>

C。SEEK_CUR 从当前位置偏移 0 字节，相当于获取当前文件偏移量而不移动。

</details>

**题目 2（判断）：** 所有文件类型都支持 lseek。

<details>
<summary>参考答案</summary>

错误。管道、socket、终端不支持 lseek，返回 -1 且 errno=ESPIPE。

</details>

**题目 3（踩坑）：** 以下代码试图在管道上随机访问，会怎样？
```c
int fd = open("pipe", O_RDWR);
lseek(fd, 100, SEEK_SET);
```

<details>
<summary>参考答案</summary>

如果 fd 是管道，lseek 返回 -1 且 errno=ESPIPE。管道是流式数据，不支持随机访问。

</details>

**题目 4（应用）：** 写代码获取文件大小（不用 stat）。

<details>
<summary>参考答案</summary>

```c
off_t cur = lseek(fd, 0, SEEK_CUR);
off_t size = lseek(fd, 0, SEEK_END);
lseek(fd, cur, SEEK_SET);  /* 恢复 */
```

</details>

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
/* lseek(): 调整文件偏移量 SEEK_SET/SEEK_CUR/SEEK_END */
int main(void) {
    int fd = open("/tmp/ch4_lseek.txt", O_RDWR | O_CREAT | O_TRUNC, 0644);
    write(fd, "ABCDEFGHIJ", 10);

    lseek(fd, 3, SEEK_SET);   /* 移到偏移 3 */
    char c;
    read(fd, &c, 1);
    printf("byte at offset 3: %c\n", c);

    off_t pos = lseek(fd, 0, SEEK_CUR);  /* 当前位置 */
    printf("current offset: %ld\n", (long)pos);

    lseek(fd, -1, SEEK_END);  /* 从末尾回退1 */
    read(fd, &c, 1);
    printf("last byte: %c\n", c);
    close(fd);
    return 0;
}
```
