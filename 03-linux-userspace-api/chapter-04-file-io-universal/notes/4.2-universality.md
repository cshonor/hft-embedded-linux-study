## 要点

| 点 | 说明 |
|----|------|
| 同一套 API | 拷贝磁盘文件与读写 `/dev/tty` 可用同一段代码 |
| 差异在哪 | 设备/文件系统逻辑在 **内核驱动**；应用层无感 |
| 通用不够时 | 设备专属控制用 **`ioctl()`** |

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>

/* 同一套 open/read/write/close 适用于所有文件类型 */
int main(void) {
    /* 操作普通文件 */
    int fd = open("/tmp/demo.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd < 0) { perror("open file"); return 1; }
    write(fd, "hello\n", 6);
    close(fd);

    /* 操作设备文件 /dev/null — 同一套 API */
    int dev = open("/dev/null", O_WRONLY);
    if (dev < 0) { perror("open /dev/null"); return 1; }
    write(dev, "anything", 8);  /* 数据被丢弃，但调用成功 */
    close(dev);

    /* 读 /proc/version — 还是同一套 API */
    int proc = open("/proc/version", O_RDONLY);
    if (proc < 0) { perror("open /proc"); return 1; }
    char buf[256];
    ssize_t n = read(proc, buf, sizeof(buf) - 1);
    if (n > 0) { buf[n] = '\0'; printf("%s", buf); }
    close(proc);
    return 0;
}
```
