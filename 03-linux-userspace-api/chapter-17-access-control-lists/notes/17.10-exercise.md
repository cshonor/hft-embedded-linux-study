## 17-1 显示指定 user/group 的 ACL 条目权限 ⛔→✅（Linux 复测）

**任务**：程序接 `u|g` 与用户/组（名字或数字）两个参数，显示该身份对应 ACL 条目的权限；若条目受 mask 约束，显示**与 mask 求交后的有效权限**；若无对应条目，说明其落入 other/组类判定。

**实现**：[`code/ex17_1_listacls.c`](../code/ex17_1_listacls.c)（libacl，Linux 编译 `-lacl`）。要点：

- 名字→id 复用 Listing 8-1 的 `userIdFromName` 思路（passwd/group 查询，数字直接 atoi）；
- 两遍遍历：先取 mask 条目，再找 `ACL_USER`/`ACL_GROUP` 目标条目；
- 有效权限 = 条目 permset **逐位 AND** mask，输出 `raw → effective` 两列；
- 无专属条目时**明确告知将落入哪条判定路径**——这正是 §17.2 算法的应用。

**实测状态（诚实标注）**：libacl 是 Linux 专有，macOS 无此 API——本机不编译不运行；Pi5(ext4) 复测清单：

```bash
gcc -Wall -o ex17_1_listacls ex17_1_listacls.c -lacl
setfacl -m u:liming:rx /tmp/data          # 造一条 named user
./ex17_1_listacls u liming /tmp/data      # 期望: user:1001 原始权限=r-x mask=... 有效权限=...
./ex17_1_listacls u nobody /tmp/data      # 期望: 无专属条目 → 落入 other/组类
```

**算法侧的替代验证**：判定语义的全平台实测见 [`code/c17_1_acl_algorithm.c`](../code/c17_1_acl_algorithm.c)（17.2 的 9 用例 + mask 清零实验，本机已跑通）。
