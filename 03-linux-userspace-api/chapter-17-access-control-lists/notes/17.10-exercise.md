## 练习

### 练习 1：ACL 读取器

编写程序 `acl_show`，接受文件路径参数，打印该文件的所有 ACL 条目（格式类似于 `getfacl` 输出）。

**要求**：
- 区分 access ACL 和 default ACL（对目录）
- 对 `ACL_USER`/`ACL_GROUP` 条目显示用户名/组名（用 `getpwuid`/`getgrgid`）
- 显示 `#effective:` 权限（当存在 MASK 时）

### 练习 2：ACL 权限委托

编写程序 `acl_grant`，用法：`acl_grant <path> <user:perms> [user:perms ...]`

**要求**：
- 解析 `user:perms` 格式（如 `alice:rw`、`1000:rx`）
- 支持用户名或 UID
- 修改后自动更新 MASK 为所有 extended 条目的并集
- 调用 `acl_valid()` 校验

### 练习 3：Default ACL 继承验证

1. 创建目录 `testdir`，设置 default ACL：`setfacl -d -m u:alice:rwx testdir`
2. 在目录中创建文件 `testdir/file.txt`，检查其 access ACL
3. 在目录中创建子目录 `testdir/subdir`，检查其 default ACL
4. 解释继承规则：文件继承时如何处理 `x` 权限？

## 参考答案

### 练习 1 参考框架

```c
#include <sys/acl.h>
#include <pwd.h>
#include <grp.h>
#include <stdio.h>

void print_perm(acl_permset_t p) {
    printf("%c%c%c",
        acl_get_perm(p, ACL_READ) ? 'r' : '-',
        acl_get_perm(p, ACL_WRITE) ? 'w' : '-',
        acl_get_perm(p, ACL_EXECUTE) ? 'x' : '-');
}

void show_acl(const char *path, acl_type_t type) {
    acl_t acl = acl_get_file(path, type);
    if (!acl) return;

    /* 获取 mask 用于 effective 计算 */
    acl_entry_t e;
    acl_permset_t mask_perm = NULL;
    int id = ACL_FIRST_ENTRY;
    while (acl_get_entry(acl, id, &e) == 1) {
        id = ACL_NEXT_ENTRY;
        acl_tag_t tag;
        acl_get_tagtype(e, &tag);
        if (tag == ACL_MASK) {
            acl_get_permset(e, &mask_perm);
            break;
        }
    }

    /* 第二遍：打印 */
    id = ACL_FIRST_ENTRY;
    while (acl_get_entry(acl, id, &e) == 1) {
        id = ACL_NEXT_ENTRY;
        acl_tag_t tag;
        acl_get_tagtype(e, &tag);
        acl_permset_t ps;
        acl_get_permset(e, &ps);

        switch (tag) {
        case ACL_USER_OBJ: printf("user:");  print_perm(ps); break;
        case ACL_USER: {
            uid_t *u = acl_get_qualifier(e);
            struct passwd *pw = getpwuid(*u);
            printf("user:%s", pw ? pw->pw_name : "???");
            print_perm(ps);
            if (mask_perm) { printf("\t\t#effective:"); print_perm(ps & *(acl_permset_t*)mask_perm); }
            break;
        }
        case ACL_GROUP_OBJ: printf("group:"); print_perm(ps); break;
        case ACL_GROUP: {
            gid_t *g = acl_get_qualifier(e);
            struct group *gr = getgrgid(*g);
            printf("group:%s", gr ? gr->gr_name : "???");
            print_perm(ps);
            break;
        }
        case ACL_MASK: printf("mask:"); print_perm(ps); break;
        case ACL_OTHER: printf("other:"); print_perm(ps); break;
        }
        printf("\n");
    }
    acl_free(acl);
}
```

### 练习 3 答案

**继承规则**：
- 新文件继承目录的 default ACL 作为 access ACL
- 但新建普通文件的 `ACL_EXECUTE` 杁会被清除（`umask` 不影响 ACL 继承，但执行位继承有限制）
- 新建子目录继承 default ACL 作为自己的 default ACL（递归继承）
- 具体行为：`acl_create_entry` 时内核根据对象类型自动过滤
