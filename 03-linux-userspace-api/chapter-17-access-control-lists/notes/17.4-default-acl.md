## 要点

父目录设 Default ACL 后：

| 新建对象 | 行为 |
|----------|------|
| 普通文件 | Default → 自身 Access ACL；创建 `mode` 仍约束；**umask 通常不再按传统方式生效** |
| 子目录 | Access + **自己的 Default** 都从父 Default 继承（可继续向下传） |

> Default **不改**目录里**已有**文件，只影响之后新建的对象。
