## API 骨架

```c
#include <sys/acl.h>      /* 基础 ACL API（POSIX draft） */
#include <acl/libacl.h>   /* libacl 扩展：acl_get_perm_np / acl_to_any_text 等 */
/* 编译： gcc ... -lacl */

acl_t acl_get_file(const char *path, acl_type_t type);   /* ACCESS / DEFAULT */
int  acl_get_entry(acl_t acl, int id, acl_entry_t *e);   /* FIRST/NEXT 遍历 */
int  acl_get_tag_type(acl_entry_t e, acl_tag_t *t);
void *acl_get_qualifier(acl_entry_t e);                  /* named 条目的 uid/gid */
int  acl_get_permset(acl_entry_t e, acl_permset_t *ps);
int  acl_get_perm_np(acl_permset_t ps, acl_perm_t p);    /* 逐位探测（非标准扩展） */
int  acl_set_file(const char *path, acl_type_t type, acl_t acl);
/* 均为 -1/NULL 出错；遍历用 ACL_FIRST_ENTRY / ACL_NEXT_ENTRY */
```

**两遍遍历模式**（原书 acl_view.c 与 ex17_1 都这么写）：
1. 第一遍找 `ACL_MASK`（决定要不要做 effective 计算）；
2. 第二遍逐条处理（打文本 / 求交 / 找目标条目）。

**内存规则**：`acl_t`/qualifier 都是堆对象，`acl_free()` 逐个释放——忘了 qualifier 就泄漏。

## 常见坑

| 坑 | 正解 |
|----|------|
| 忘记 `-lacl` | 链接错误：`acl_get_file` 未定义（基础 acl_* 在 libc 的头有声明，实现要 libacl） |
| `acl_get_perm()` 当标准 API | 非标准（`_np` 后缀 = non-portable）；draft 里它返回值语义未定稿 |
| qualifier 不 free | `acl_get_qualifier` 返回 malloc 的 id；每次都要 `acl_free` |
| DEFAULT 与 ACCESS 混用 type | `acl_get_file(path, ACL_TYPE_DEFAULT)` 只对目录合法，文件上 ENOTSUP |

## HFT / 嵌入式关联

| 场景 | 本节机制怎么兑现 |
|------|----------------|
| 权限审计工具 | acl_get_file 遍历 + 输出 JSON，替代脆弱的文本解析 |
| 启动自检 | 服务启动时用 ACL API 验证数据目录授权（named 条目是否存在、mask 是否足够），缺了即 fail-fast |
| 双遍遍历模式 | 处理任何"条目集合 + 全局约束（mask）"的通用套路 |
