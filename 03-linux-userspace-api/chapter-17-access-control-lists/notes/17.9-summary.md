## 全章一张表

| 主题 | 一句话 | 出处 |
|------|--------|------|
| 条目模型 | 6 种 tag；最小 ACL=三条，加 named 条目必带 mask | 17.1 |
| 存储 | `system.posix_acl_access/default` xattr | 17.1/16 |
| 判定 | ①属主 ②named ③组类(OR∩mask) ④other；mask 不碰①④ | 17.2 实测 |
| 文本 | 短形式（setfacl 参数）与长形式（getfacl 输出，带 #effective） | 17.3 |
| mask | chmod 组位的 ACL 形态；`ls -l` group 位在有 mask 时显示它 | 17.4 |
| 工具 | setfacl -m/-x/-b/--restore 与 getfacl 快照 | 17.5 |
| default ACL | 目录的新文件模板；AND 语义；**忽略 umask**；随子目录递归传播 | 17.6 |
| 限制 | 条目 ≥32 保证；FS 支持面（ext4/xfs/tmpfs ✅，squashfs ❌） | 17.7 |
| API | libacl 两遍遍历（先 mask 后条目）；qualifier 要 free | 17.8 |
