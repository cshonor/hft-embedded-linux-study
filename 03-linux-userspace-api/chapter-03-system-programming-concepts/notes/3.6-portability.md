## 要点

### 功能测试宏（Feature Test Macros）

须放在 **所有 `#include` 之前**，控制 glibc 暴露哪些 API：

| 宏 | 含义 |
|----|------|
| `_POSIX_C_SOURCE` | POSIX |
| `_XOPEN_SOURCE` | SUS |
| `_GNU_SOURCE` | Linux / glibc 扩展（TLPI 示例常用） |

### 标准 typedef（`<sys/types.h>` 等）

| 类型 | 用途 |
|------|------|
| `pid_t` | 进程 ID |
| `off_t` | 文件偏移（`lseek`） |
| `size_t` / `ssize_t` | 长度；`read`/`write` 返回常用 `ssize_t` |
| `uid_t` / `gid_t` | 用户 / 组 ID |

勿随意写死 `int`/`long` 当跨 32/64 位 ID/偏移。

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
/* SUSv3 标准: POSIX 超集 */
int main(void) {
#ifdef _POSIX_C_SOURCE
    printf("_POSIX_C_SOURCE = %ldL\n", (long)_POSIX_C_SOURCE);
#endif
    printf("sysconf(_SC_OPEN_MAX) = %ld\n", sysconf(_SC_OPEN_MAX));
    return 0;
}
```
