## 要点

### 功能测试宏（Feature Test Macros）

须放在 **所有 `#include` 之前**，控制 glibc 暴露哪些 API：

| 宏 | 含义 |
|----|------|
| `_POSIX_C_SOURCE` | POSIX |
| `_XOPEN_SOURCE` | SUS |
| `_GNU_SOURCE` | Linux / glibc 扩展（TLPI 示例常用） |

### 标准 typedef（`<sys/types.h>` 等）

| 类型 | 用途 |
|------|------|
| `pid_t` | 进程 ID |
| `off_t` | 文件偏移（`lseek`） |
| `size_t` / `ssize_t` | 长度；`read`/`write` 返回常用 `ssize_t` |
| `uid_t` / `gid_t` | 用户 / 组 ID |

勿随意写死 `int`/`long` 当跨 32/64 位 ID/偏移。

## 与 C 语言学习的关系

本节涉及的 `open()` 是 C 语言文件操作的基础系统调用。与 K&R 第 8 章的 `fopen()` 不同，`open()` 是 POSIX 系统调用而非 C 标准库函数。理解 `open()` 的 flags 参数（O_RDONLY、O_CREAT 等）是掌握 Unix 系统编程的第一步。对照 K&R 8.3 节的 `open/creat/close` 学习，注意 C 标准库 `fopen` 的 "r"/"w"/"a" 模式如何映射到 `open` 的 flags。

## 常见陷阱

1. **短读未处理**

```c
/* 假设一次读完 */
ssize_t n = read(fd, buf, 1024);
/* n 可能 < 1024 */
```

read 返回值可能小于请求字节数（short read）。网络和管道尤其常见，必须循环读。

2. **EINTR 未处理**

```c
/* 信号中断后 read 返回 -1, errno=EINTR */
/* 不是错误，应重试 */
```

信号中断系统调用时返回 -1 且 errno=EINTR。应该重试，或用 SA_RESTART 自动重启。

3. **EOF 判断错误**

```c
/* 用 feof 预判 EOF → 多读一次 */
while (!feof(fp)) { fgets(...); }
/* 正确：检查返回值 */
while (fgets(buf, sz, fp) != NULL) { ... }
```

read 返回 0 表示 EOF。不要用 feof 预判（feof 只在读取越过后才为真）。

## 自测题

**题目 1（选择）：** `read()` 返回 0 表示什么？
A. 出错
B. EOF
C. 没有数据
D. 需要重试

<details>
<summary>参考答案</summary>

B。返回 0 表示已到达文件末尾（EOF）。返回 -1 表示出错，返回 >0 表示读到的字节数。

</details>

**题目 2（判断）：** `read` 一定会读满请求的字节数。

<details>
<summary>参考答案</summary>

错误。read 可能返回少于请求的字节数（short read），尤其在管道、socket、终端上。必须循环读。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
char buf[1024];
read(fd, buf, sizeof(buf));
buf[strlen(buf)] = '\0';
```

<details>
<summary>参考答案</summary>

1) read 不保证以 null 结尾；2) 没检查返回值；3) strlen 在未终止的 buf 上越界。应检查返回值并手动加 `\0`。

</details>

**题目 4（应用）：** 写一个安全的 readall 函数，确保读满 n 字节或遇到 EOF。

<details>
<summary>参考答案</summary>

```c
ssize_t readall(int fd, void *buf, size_t n) {
    size_t total = 0;
    while (total < n) {
        ssize_t r = read(fd, (char*)buf+total, n-total);
        if (r < 0 && errno == EINTR) continue;
        if (r < 0) return -1;
        if (r == 0) break; /* EOF */
        total += r;
    }
    return total;
}
```

</details>
