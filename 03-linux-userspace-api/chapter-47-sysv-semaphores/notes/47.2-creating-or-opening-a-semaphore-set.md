## 要点

### `semget(key, nsems, semflg)`

创建时指定 `nsems`；打开已有集时 `nsems` 不能大于集大小。  
⚠️ **只分配，不初始化数值**。

### `semctl` · 须自声明 `union semun`

| cmd | |
|-----|--|
| `SETVAL` / `GETVAL` | 单个 |
| `SETALL` / `GETALL` | 整集 |
| `IPC_STAT` / `IPC_SET` | 属性 |
| `IPC_RMID` | **立即删整集**；唤醒阻塞者 |

### `semop(semid, sops, nsops)`

```c
struct sembuf { unsigned short sem_num; short sem_op; short sem_flg; };
```

| `sem_op` | 行为 |
|----------|------|
| `>0` | V，不阻塞 |
| `<0` | P；值不够则阻塞（或 `IPC_NOWAIT`→`EAGAIN`） |
| `==0` | 等变为 0 |

`sem_flg`：`IPC_NOWAIT` · **`SEM_UNDO`**。  
多条 `sembuf`：**原子 all-or-nothing**（可一次拿多锁，减死锁）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | semget 只分配不初始化，semop 原子 all-or-nothing 可一次拿多锁 |
| HFT | semop 原子多锁减少死锁；IPC_NOWAIT 非阻塞避免热路径阻塞 |

## 代码示例

```c
#include <stdio.h>
#include <sys/sem.h>
#include <unistd.h>
/* 信号量 API: semget/semctl/semop */
union semun { int val; struct semid_ds *buf; unsigned short *array; };

int main(void) {
    /* semget: 创建信号量集 */
    int semid = semget(IPC_PRIVATE, 1, IPC_CREAT | 0666);

    /* semctl: 控制操作 */
    union semun arg;
    arg.val = 1;
    semctl(semid, 0, SETVAL, arg);          /* 设置值为 1 */
    printf("After SETVAL(1): %d\n", semctl(semid, 0, GETVAL));

    /* semop: P/V 操作 */
    struct sembuf sop;
    /* P 操作 (等待) */
    sop.sem_num = 0; sop.sem_op = -1; sop.sem_flg = 0;
    semop(semid, &sop, 1);
    printf("After P: %d\n", semctl(semid, 0, GETVAL));

    /* V 操作 (释放) */
    sop.sem_op = 1;
    semop(semid, &sop, 1);
    printf("After V: %d\n", semctl(semid, 0, GETVAL));

    /* IPC_NOWAIT: 非阻塞 P */
    sop.sem_op = -1; sop.sem_flg = IPC_NOWAIT;
    if (semop(semid, &sop, 1) < 0)
        perror("non-blocking P (EAGAIN expected)");

    semctl(semid, 0, IPC_RMID);
    return 0;
}
```
