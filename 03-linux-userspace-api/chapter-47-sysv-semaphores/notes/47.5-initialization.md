## 本节讲什么

A `semget(CREAT)` 尚未 `SETVAL`，B 已 `semop` → 值未定义。 **解法**：仅 `IPC_CREAT|IPC_EXCL` 成功者初始化；`EEXIST` 则再 `semget` 打开。 semid = semget(key, 1, IPC_CREAT | IPC_EXCL | 0600);

---

## 要点

A `semget(CREAT)` 尚未 `SETVAL`，B 已 `semop` → 值未定义。

**解法**：仅 `IPC_CREAT|IPC_EXCL` 成功者初始化；`EEXIST` 则再 `semget` 打开。

```c
semid = semget(key, 1, IPC_CREAT | IPC_EXCL | 0600);
if (semid >= 0) {
    union semun su = { .val = 1 };
    semctl(semid, 0, SETVAL, su);
} else if (errno == EEXIST) {
    semid = semget(key, 1, 0600);
}
```

## 代码示例

```c
#include <stdio.h>
#include <sys/sem.h>
#include <string.h>
/* 信号量初始化: SETVAL vs SETALL (注意竞态!) */
union semun { int val; struct semid_ds *buf; unsigned short *array; };

int main(void) {
    int semid = semget(IPC_PRIVATE, 3, IPC_CREAT | 0666);

    /* 方式1: SETVAL 逐个设置 */
    for (int i = 0; i < 3; i++) {
        union semun arg;
        arg.val = i + 1;
        semctl(semid, i, SETVAL, arg);
    }
    printf("After SETVAL: %d %d %d\n",
           semctl(semid, 0, GETVAL),
           semctl(semid, 1, GETVAL),
           semctl(semid, 2, GETVAL));

    /* 方式2: SETALL 一次性设置所有 */
    union semun arg;
    unsigned short vals[3] = {10, 20, 30};
    arg.array = vals;
    semctl(semid, 0, SETALL, arg);
    printf("After SETALL: %d %d %d\n",
           semctl(semid, 0, GETVAL),
           semctl(semid, 1, GETVAL),
           semctl(semid, 2, GETVAL));

    /* GETALL: 一次性读取所有 */
    unsigned short get_vals[3];
    arg.array = get_vals;
    semctl(semid, 0, GETALL, arg);
    printf("GETALL: %d %d %d\n", get_vals[0], get_vals[1], get_vals[2]);

    /* 竞态问题: semget 创建后到 SETVAL 之前, 信号量值为 0 */
    /* 如果另一个进程在这期间做 P 操作, 可能意外阻塞 */
    /* 解决: 用 IPC_CREAT|IPC_EXCL, 只有创建者做初始化 */
    semctl(semid, 0, IPC_RMID);
    return 0;
}
```
