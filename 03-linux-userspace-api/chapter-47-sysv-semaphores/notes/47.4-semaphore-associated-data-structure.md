# 47.4 Semaphore Associated Data Structure

> 本章：[TLPI 第 47 章](../README.md)

## 本节讲什么

System V 信号量集关联的 `semid_ds` 结构，包含权限信息、时间戳和统计字段。了解其布局有助于调试和监控。

## 要点

### struct semid_ds 完整字段

```c
struct semid_ds {
    struct ipc_perm sem_perm;   /* 所有权和权限 */
    time_t          sem_otime;  /* 最后 semop 时间 */
    time_t          sem_ctime;  /* 最后 semctl 修改时间 */
    unsigned long   sem_nsems;  /* 信号量集中的数量 */
    /* 内核内部字段... */
};
```

### struct ipc_perm

```c
struct ipc_perm {
    key_t          __key;   /* IPC key (ftok) */
    uid_t          uid;     /* 所有者 UID */
    gid_t          gid;     /* 所有者 GID */
    uid_t          cuid;    /* 创建者 UID */
    gid_t          cgid;    /* 创建者 GID */
    unsigned short mode;    /* 权限位 */
    unsigned short __seq;   /* 序列号 */
};
```

### 权限位语义

| 权限 | 读 | 修改(写) |
|------|----|-------|
| 所有者 | GETVAL/GETALL | SETVAL/SETALL/semop |
| 组 | 同上 | 同上 |
| 其他 | 同上 | 同上 |

### sem_otime vs sem_ctime

| 字段 | 何时更新 | 更新者 |
|------|---------|--------|
| `sem_otime` | 成功 `semop()` | 内核 |
| `sem_ctime` | `semctl(IPC_SET/SETVAL/SETALL)` | 内核 |

### 查看系统信号量

```bash
# 查看所有 SysV 信号量
ipcs -s

# 输出示例
------ Semaphore Arrays --------
key  semid owner perms nsems
0x12345678 0x10 hft 660  3
```

### 监控字段含义

| 字段 | 监控用途 |
|------|---------|
| `sem_otime` | 活跃度：最近操作时间 |
| `sem_ctime` | 配置变更时间 |
| `sem_perm.mode` | 权限审计 |
| `sem_nsems` | 集合大小 |

## HFT / 嵌入式关联

- SysV 信号量监控：定期 `IPC_STAT` 检查活跃度
- 权限审计：确保只有授权进程可操作
- 嵌入式调试：用 `ipcs -s` 检查信号量泄漏

## 代码示例

```c
#include <sys/sem.h>
#include <stdio.h>
#include <time.h>

union semun { int val; struct semid_ds *buf; unsigned short *array; };

void monitor_semaphore(int semid) {
    struct semid_ds ds;
    union semun arg;
    arg.buf = &ds;

    if (semctl(semid, 0, IPC_STAT, arg) == -1) {
        perror("semctl");
        return;
    }

    time_t now = time(NULL);
    printf("Semaphore set ID:  %d\n", semid);
    printf("Key:               0x%x\n", ds.sem_perm.__key);
    printf("Owner:             %d:%d\n", ds.sem_perm.uid, ds.sem_perm.gid);
    printf("Creator:           %d:%d\n", ds.sem_perm.cuid, ds.sem_perm.cgid);
    printf("Permissions:       %04o\n", ds.sem_perm.mode);
    printf("Num semaphores:    %lu\n", ds.sem_nsems);

    if (ds.sem_otime == 0)
        printf("Last semop:        never\n");
    else
        printf("Last semop:        %ld sec ago\n", now - ds.sem_otime);

    printf("Last change:       %ld sec ago\n", now - ds.sem_ctime);
}
```

## 代码自测

<details>
<summary>sem_otime 为 0 表示什么？</summary>

`sem_otime` 记录最后一次成功 `semop()` 的时间。值为 0 表示该信号量集创建后从未被 `semop()` 操作过。这是判断信号量是否被正确初始化的关键线索：`semget()` 创建的信号量初始值为 0，必须通过 `semctl(SETVAL/SETALL)` 设置初始值后才能使用。sem_otime 为 0 可能意味着初始化尚未完成。

</details>
