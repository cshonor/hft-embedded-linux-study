## 本节讲什么

- 对象是**信号量集**（`semid` + 下标 0..nsems-1），非单个变量。 - 操作：P（减，不足则阻塞）· V（加，可唤醒）· 等值变为 0（`sem_op==0`）。 - **不传数据**，只同步；典型保护 SysV shm。

---

## 要点

- 对象是**信号量集**（`semid` + 下标 0..nsems-1），非单个变量。  
- 操作：P（减，不足则阻塞）· V（加，可唤醒）· 等值变为 0（`sem_op==0`）。  
- **不传数据**，只同步；典型保护 SysV shm。  
- **内核持久** → `IPC_RMID` / 重启。

## 代码示例

```c
#include <stdio.h>
#include <sys/sem.h>
/* 信号量概念: 计数器, P(减) / V(加), 用于同步 */
int main(void) {
    /* 信号量是一个内核维护的计数器 */
    /* P (wait): value--, 如果 < 0 则阻塞 */
    /* V (signal): value++, 如果 <= 0 则唤醒一个等待者 */

    /* SysV 信号量是"集合", 可以同时操作多个 */
    int semid = semget(IPC_PRIVATE, 3, IPC_CREAT | 0666);
    printf("Created semaphore set: id=%d, 3 semaphores\n", semid);

    /* 初始化每个信号量 */
    semctl(semid, 0, SETVAL, 1);  /* sem 0 = 1 (mutex) */
    semctl(semid, 1, SETVAL, 0);  /* sem 1 = 0 (event) */
    semctl(semid, 2, SETVAL, 5);  /* sem 2 = 5 (counting) */

    printf("sem[0]=%d (mutex, binary)\n", semctl(semid, 0, GETVAL));
    printf("sem[1]=%d (event, initially blocked)\n", semctl(semid, 1, GETVAL));
    printf("sem[2]=%d (counting, 5 resources)\n", semctl(semid, 2, GETVAL));

    semctl(semid, 0, IPC_RMID);
    return 0;
}
```
