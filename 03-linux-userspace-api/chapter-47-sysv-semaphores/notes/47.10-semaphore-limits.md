## 本节讲什么

`SEMMNI`/`SEMMNS`/`SEMMSL`/`SEMOPM`/`SEMVMX`(32767) — 见 `/proc/sys/kernel/sem`。 `ipcs -s` · `ipcrm -s id`。 缺陷：非 fd、创建/初始化两步竞态、内核持久、API 笨重、无超时、集设计过剩。TLPI：优先 **POSIX 信号量**。

## 要点

`SEMMNI`/`SEMMNS`/`SEMMSL`/`SEMOPM`/`SEMVMX`(32767) — 见 `/proc/sys/kernel/sem`。  
`ipcs -s` · `ipcrm -s id`。

## 代码示例

```c
#include <stdio.h>
#include <sys/sem.h>
/* SysV 信号量的缺陷 */
int main(void) {
    /* 缺陷1: API 过于复杂 (集合操作, 需要联合体初始化) */
    /* 缺陷2: 初始化有竞态 (semget 后到 SETVAL 前, 值为0) */
    /* 缺陷3: 没有简单的"等待任意信号量"机制 */
    /* 缺陷4: 配额限制 */

    /* 查看系统限制 */
    FILE *fp;
    char buf[32];

    fp = fopen("/proc/sys/kernel/sem", "r");
    if (fp) {
        fgets(buf, sizeof(buf), fp);
        printf("SEM settings: %s", buf);
        /* 格式: SEMMSL SEMMNS SEMOPM SEMMNI */
        fclose(fp);
    }

    printf("\nDefects summary:\n");
    printf("  1. Complex API (semaphore SETS, not individual)\n");
    printf("  2. Initialization race condition\n");
    printf("  3. No wait-for-any mechanism\n");
    printf("  4. System-wide quotas\n");
    printf("\nBetter: POSIX semaphores (sem_open/sem_wait/sem_post)\n");
    return 0;
}
```
