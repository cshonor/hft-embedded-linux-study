# 47.3 Semaphore Control Operations: semctl()

> 本章：[TLPI 第 47 章](../README.md)

## 本节讲什么

`semctl()` 是 System V 信号量的控制接口，用于获取/设置信号量权限、删除信号量集、获取统计信息等。

## 要点

### semctl() 函数

```c
#include <sys/sem.h>
int semctl(int semid, int semnum, int cmd, ... /* union semun arg */);
```

### union semun

```c
union semun {
    int val;              /* SETVAL 用 */
    struct semid_ds *buf; /* IPC_STAT / IPC_SET 用 */
    unsigned short *array; /* GETALL / SETALL 用 */
};
/* 注意：需程序自定义，glibc 不提供 */
```

### 命令一览

| cmd | 说明 | 需要 arg? |
|-----|------|-----------|
| `IPC_RMID` | 立即删除信号量集 | 否 |
| `IPC_STAT` | 获取 semid_ds | 是 (buf) |
| `IPC_SET` | 设置权限 | 是 (buf) |
| `GETVAL` | 获取单个信号量值 | 否 |
| `SETVAL` | 设置单个信号量值 | 是 (val) |
| `GETALL` | 获取所有信号量值 | 是 (array) |
| `SETALL` | 设置所有信号量值 | 是 (array) |
| `GETPID` | 获取最后操作者 PID | 否 |
| `GETNCNT` | 等待值增加的进程数 | 否 |
| `GETZCNT` | 等待值为0的进程数 | 否 |

### struct semid_ds

```c
struct semid_ds {
    struct ipc_perm sem_perm;  /* 权限 */
    time_t sem_otime;          /* 最后操作时间 */
    time_t sem_ctime;         /* 最后修改时间 */
    unsigned long sem_nsems;   /* 信号量数量 */
};
```

### 关键操作示例

```c
/* 删除信号量集 */
semctl(semid, 0, IPC_RMID);

/* 设置信号量值为 1 */
union semun arg;
arg.val = 1;
semctl(semid, 0, SETVAL, arg);

/* 获取所有信号量值 */
unsigned short vals[10];
union semun arg;
arg.array = vals;
semctl(semid, 0, GETALL, arg);

/* 获取权限和统计信息 */
struct semid_ds ds;
union semun arg;
arg.buf = &ds;
semctl(semid, 0, IPC_STAT, arg);
```

## HFT / 嵌入式关联

- SysV 信号量在 HFT 中使用减少，主要被 POSIX 信号量/互斥锁替代
- 嵌入式遗留系统可能使用 SysV 信号量做进程间同步
- `IPC_RMID` 清理泄漏的信号量集

## 代码示例

```c
#include <sys/sem.h>
#include <stdio.h>
#include <string.h>
#include <time.h>

/* union semun 需自定义 */
union semun {
    int val;
    struct semid_ds *buf;
    unsigned short *array;
};

void dump_sem_info(int semid, int num_sems) {
    struct semid_ds ds;
    union semun arg;
    arg.buf = &ds;

    if (semctl(semid, 0, IPC_STAT, arg) == -1) {
        perror("semctl IPC_STAT");
        return;
    }

    printf("=== Semaphore Set %d ===\n", semid);
    printf("Owner UID: %d  GID: %d\n",
           ds.sem_perm.cuid, ds.sem_perm.cgid);
    printf("Permissions: %04o\n", ds.sem_perm.mode);
    printf("Num sems: %lu\n", ds.sem_nsems);
    printf("Last op:  %s", ctime(&ds.sem_otime));
    printf("Last chg: %s", ctime(&ds.sem_ctime));

    /* 获取所有信号量值 */
    unsigned short vals[num_sems];
    arg.array = vals;
    if (semctl(semid, 0, GETALL, arg) != -1) {
        for (int i = 0; i < num_sems; i++)
            printf("  sem[%d] = %d\n", i, vals[i]);
    }
}
```

## 代码自测

<details>
<summary>为什么 union semun 需要程序自己定义？</summary>

POSIX 标准规定 `union semun` 由应用程序定义，而非系统头文件提供。不同系统的定义方式可能不同（某些 BSD 系统在头文件中提供），为保证可移植性，应用程序需要自己定义。这是 POSIX 规范的设计选择，避免将实现细节固化在标准中。

</details>
