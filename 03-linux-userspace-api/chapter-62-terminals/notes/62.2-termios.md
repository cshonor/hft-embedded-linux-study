## 要点

```c
tcgetattr(fd, &t);
tcsetattr(fd, TCSANOW|TCSADRAIN|TCSAFLUSH, &t);
```

| 何时生效 | |
|----------|--|
| `TCSANOW` | 立即 |
| `TCSADRAIN` | 输出排空后（改输出标志优先） |
| `TCSAFLUSH` | 排空输出并丢弃未读输入 |

字段：`c_iflag` / `c_oflag` / `c_cflag` / `c_lflag` / `c_cc[]`。
