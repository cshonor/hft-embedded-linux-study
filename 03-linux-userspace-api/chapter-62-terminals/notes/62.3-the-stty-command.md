## 要点

| 模式 | |
|------|--|
| **规范**（`ICANON`） | 按行；行编辑；shell 默认 |
| **非规范** | 关 ICANON；`VMIN`+`VTIME` 控 `read` |
| **原始 Raw** | 非规范 + 关信号/回显/输出加工等 |
| Cooked | 口语=规范 |

VMIN/VTIME 四组合：MIN>0 等够字节；MIN=0 可轮询/短超时（TIME 单位 0.1s）。

Demo：[`code/`](../code/)（关 ECHO 读一行再恢复）

## 代码示例

```c

/* 规范模式 (canonical) vs 原始模式 (raw) */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <termios.h>
#include <unistd.h>

int main(void) {
    struct termios oldtio, newtio;
    tcgetattr(STDIN_FILENO, &oldtio);
    newtio = oldtio;

    /* 原始模式：关闭 ICANON + ECHO，设置 VMIN=1, VTIME=0 */
    newtio.c_lflag &= ~(ICANON | ECHO);
    newtio.c_cc[VMIN] = 1;   /* 至少读 1 字节 */
    newtio.c_cc[VTIME] = 0;  /* 无超时 */
    tcsetattr(STDIN_FILENO, TCSANOW, &newtio);

    printf("Raw mode: press any key (no Enter needed), 'q' to quit\n");
    fflush(stdout);

    char c;
    while (read(STDIN_FILENO, &c, 1) == 1) {
        printf("got: 0x%02x '%c'\n", (unsigned char)c, c >= 32 ? c : '.');
        fflush(stdout);
        if (c == 'q') break;
    }

    /* 恢复规范模式 */
    tcsetattr(STDIN_FILENO, TCSANOW, &oldtio);
    printf("\nRestored to canonical mode\n");
    return 0;
}

```
