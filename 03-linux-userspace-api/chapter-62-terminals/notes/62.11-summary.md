# 62.11 Summary

> 本章：[TLPI 第 62 章](../README.md)

## 本节讲什么

第 62 章总结：终端 I/O 的 termios API、输入输出标志、规范/原始模式和终端识别。

## 要点

### API 总览

| API | 用途 |
|-----|------|
| `tcgetattr()` | 获取 termios 属性 |
| `tcsetattr()` | 设置 termios 属性 |
| `cfmakeraw()` | 设置原始模式 |
| `cfsetispeed()`/`cfsetospeed()` | 设置波特率 |
| `tcdrain()` | 等待输出完成 |
| `tcflush()` | 刷新输入/输出队列 |
| `tcflow()` | 流控（XON/XOFF） |
| `isatty()` | 检查是否为终端 |
| `ttyname()` | 获取终端设备名 |
| `ctermid()` | 获取控制终端名 |
| `ioctl(TIOCGWINSZ)` | 获取窗口大小 |

### termios 四组标志

| 标志组 | 名称 | 主要功能 |
|--------|------|---------|
| c_iflag | 输入标志 | CR/NL 映射、流控、奇偶 |
| c_oflag | 输出标志 | NL/CR 映射、延迟 |
| c_cflag | 控制标志 | 波特率、字符大小、停止位 |
| c_lflag | 本地标志 | 规范模式、回显、信号 |

### 两种 I/O 模式

| 模式 | 标志 | 特性 |
|------|------|------|
| 规范模式 | ICANON on | 行缓冲、行编辑、信号 |
| 原始模式 | ICANON off | 按字符/超时、无编辑 |

### VMIN/VTIME 四种组合

| VMIN | VTIME | 行为 |
|------|-------|------|
| 1 | 0 | 阻塞等1字符 |
| 0 | 0 | 非阻塞轮询 |
| 0 | N | 超时返回 |
| 1 | N | 等1字符或超时 |

### 特殊字符 (c_cc)

| 索引 | 默认键 | 功能 |
|------|--------|------|
| VINTR | ^C | 产生 SIGINT |
| VQUIT | ^\ | 产生 SIGQUIT |
| VERASE | ^? | 删除前一个字符 |
| VKILL | ^U | 删除整行 |
| VEOF | ^D | 文件结束 |
| VSTOP | ^S | 暂停输出 |
| VSTART | ^Q | 恢复输出 |
| VMIN | - | 原始模式最小读取 |
| VTIME | - | 原始模式超时 |

## HFT / 嵌入式关联

- 嵌入式串口通信：原始模式 + VMIN/VTIME
- 交易终端 TUI：原始模式捕获按键 + SIGWINCH 自适应
- 守护进程：isatty 检查是否有控制终端

<summary>规范模式和原始模式的主要区别是什么？</summary>

规范模式（ICANON）：内核对输入进行行缓冲和行编辑。用户输入的字符先在内核缓冲区中积累，直到收到 NL/EOF 才提交给 read()。支持 ERASE（删除前一个字符）和 KILL（删除整行）。适合交互式命令输入（如 shell）。原始模式（~ICANON）：无行缓冲，read() 直接返回已输入的字符，无行编辑功能。用 VMIN/VTIME 控制读取行为。适合串口通信和 TUI 程序。

</details>
