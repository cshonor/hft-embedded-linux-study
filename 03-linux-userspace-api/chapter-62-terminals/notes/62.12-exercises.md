### 练习 1：密码输入

**题目**：编写函数 `getpass_safe()`，提示用户输入密码，输入时回显星号。

<details>
<summary>参考答案</summary>

```c
#include <termios.h>
#include <unistd.h>
#include <string.h>
#include <stdio.h>

char *getpass_safe(const char *prompt, char *buf, size_t len) {
    struct termios orig, noecho;

    /* 输出提示 */
    fputs(prompt, stdout);
    fflush(stdout);

    /* 关闭回显 */
    tcgetattr(STDIN_FILENO, &orig);
    noecho = orig;
    noecho.c_lflag &= ~(ECHO | ECHOE | ECHOK);
    tcsetattr(STDIN_FILENO, TCSANOW, &noecho);

    /* 读取输入 */
    char *result = fgets(buf, len, stdin);

    /* 恢复回显 */
    tcsetattr(STDIN_FILENO, TCSANOW, &orig);
    fputc('\n', stdout);

    /* 去除换行 */
    if (result) {
        char *nl = strchr(buf, '\n');
        if (nl) *nl = '\0';
    }

    return result;
}
```

</details>

### 练习 2：串口配置

**题目**：配置串口 `/dev/ttyS0` 为 115200 波特率、8N1、原始模式、VMIN=1/VTIME=10。

<details>
<summary>参考答案</summary>

```c
#include <termios.h>
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>

int open_serial(const char *dev) {
    int fd = open(dev, O_RDWR | O_NOCTTY | O_CLOEXEC);
    if (fd < 0) return -1;

    struct termios t;
    tcgetattr(fd, &t);

    /* 原始模式 */
    cfmakeraw(&t);

    /* 波特率 115200 */
    cfsetispeed(&t, B115200);
    cfsetospeed(&t, B115200);

    /* 8N1 */
    t.c_cflag &= ~PARENB;   /* 无奇偶 */
    t.c_cflag &= ~CSTOPB;   /* 1 停止位 */
    t.c_cflag &= ~CSIZE;    /* 清除字符大小 */
    t.c_cflag |= CS8;       /* 8 位 */

    /* 启用接收 */
    t.c_cflag |= CREAD | CLOCAL;

    /* VMIN/VTIME */
    t.c_cc[VMIN] = 1;        /* 最少1字符 */
    t.c_cc[VTIME] = 10;      /* 1秒超时(100ms*10) */

    tcsetattr(fd, TCSANOW, &t);
    return fd;
}
```

</details>

### 练习 3：检测重定向

**题目**：编写程序检测 stdout 是否被重定向到文件或管道，如果被重定向则禁用颜色输出。

<details>
<summary>参考答案</summary>

```c
#include <unistd.h>
#include <stdio.h>
#include <string.h>

int use_color(void) {
    /* 检查 stdout 是否为终端 */
    if (!isatty(STDOUT_FILENO)) return 0;

    /* 检查 TERM 环境变量 */
    char *term = getenv("TERM");
    if (term == NULL) return 0;
    if (strcmp(term, "dumb") == 0) return 0;

    return 1;
}

int main() {
    const char *red   = use_color() ? "\033[31m" : "";
    const char *reset = use_color() ? "\033[0m"  : "";

    printf("%sERROR:%s Something went wrong\n", red, reset);
    return 0;
}
```

</details>
