# 62.5 Terminal Flags

> 本章：[TLPI 第 62 章](./README.md)

## 本节讲什么

`termios` 结构中的 `c_iflag`（输入）、`c_oflag`（输出）、`c_cflag`（控制）和 `c_lflag`（本地）四组标志位控制终端的行行为。

## 要点

### termios 结构回顾

```c
struct termios {
    tcflag_t  c_iflag;   /* 输入标志 */
    tcflag_t  c_oflag;   /* 输出标志 */
    tcflag_t  c_cflag;   /* 控制标志 */
    tcflag_t  c_lflag;   /* 本地标志 */
    cc_t      c_cc[NCCS]; /* 特殊字符 */
};
```

### 输入标志 (c_iflag)

| 标志 | 说明 |
|------|------|
| `ICRNL` | 将 CR 映射为 NL |
| `INLCR` | 将 NL 映射为 CR |
| `IGNCR` | 忽略 CR |
| `IXON` | 启用 XON/XOFF 流控 |
| `IXOFF` | 输入时启用 XON/XOFF |
| `IXANY` | 任意字符恢复输出 |
| `ISTRIP` | 去除第8位 |
| `IGNBRK` | 忽略 BREAK |
| `BRKINT` | BREAK 产生 SIGINT |

### 输出标志 (c_oflag)

| 标志 | 说明 |
|------|------|
| `OPOST` | 启用输出处理 |
| `ONLCR` | 将 NL 映射为 CR-NL |
| `OCRNL` | 将 CR 映射为 NL |
| `ONOCR` | 第一列不输出 CR |
| `TABDLY` | 制表符延迟 |
| `NL0`/`NL1` | NL 延迟 |

### 控制标志 (c_cflag)

| 标志 | 说明 |
|------|------|
| `CLOCAL` | 忽略调制解调器控制 |
| `CREAD` | 启用接收 |
| `CS5`-`CS8` | 字符大小 |
| `CSTOPB` | 2 个停止位 |
| `PARENB` | 启用奇偶校验 |
| `PARODD` | 奇校验 |

### 本地标志 (c_lflag)

| 标志 | 说明 | 关闭效果 |
|------|------|---------|
| `ICANON` | 规范模式 | 原始模式 |
| `ECHO` | 回显输入 | 不回显 |
| `ECHOE` | ERASE 删除前一个字符 | |
| `ECHOK` | KILL 删除行 | |
| `ECHONL` | 回显 NL | |
| `ISIG` | 信号字符 (INTR/QUIT) | 不产生信号 |
| `IEXTEN` | 扩展处理 | |

### 典用组合

| 模式 | 设置 |
|------|------|
| 规范模式（默认） | `ICANON | ECHO | ISIG` |
| 原始模式 | 清除 `ICANON | ECHO | ISIG | IEXTEN` |
| 密码输入 | `ICANON` on, `ECHO` off |
| 8位原始 | `CS8` + 清除 `ISTRIP` + 原始 |

## HFT / 嵌入式关联

- 嵌入式串口通信：配置波特率、8N1、原始模式
- 交易终端交互：规范模式读取命令
- 串口协议解析：原始模式 + VMIN/VTIME

## 代码示例

```c
#include <termios.h>
#include <unistd.h>
#include <stdio.h>

/* 打印当前终端标志 */
void print_termios_flags(int fd) {
    struct termios t;
    tcgetattr(fd, &t);

    printf("iflag: 0x%lx\n", (long)t.c_iflag);
    printf("  ICRNL:  %s\n", (t.c_iflag & ICRNL)  ? "on" : "off");
    printf("  IXON:   %s\n", (t.c_iflag & IXON)   ? "on" : "off");
    printf("oflag: 0x%lx\n", (long)t.c_oflag);
    printf("  OPOST:  %s\n", (t.c_oflag & OPOST)  ? "on" : "off");
    printf("  ONLCR:  %s\n", (t.c_oflag & ONLCR)  ? "on" : "off");
    printf("cflag: 0x%lx\n", (long)t.c_cflag);
    printf("  CSIZE:  CS%d\n", (t.c_cflag & CSIZE) >> 4);
    printf("  CREAD:  %s\n", (t.c_cflag & CREAD)  ? "on" : "off");
    printf("lflag: 0x%lx\n", (long)t.c_lflag);
    printf("  ICANON: %s\n", (t.c_lflag & ICANON) ? "on" : "off");
    printf("  ECHO:   %s\n", (t.c_lflag & ECHO)   ? "on" : "off");
    printf("  ISIG:   %s\n", (t.c_lflag & ISIG)   ? "on" : "off");
}
```

## 代码自测

<details>
<summary>ICRNL 和 INLCR 有什么区别？</summary>

- `ICRNL`：将输入的 CR (回车, \r) 转换为 NL (换行, \n)。这是默认行为，让终端的回车键作为行结束符。
- `INLCR`：将输入的 NL (换行) 转换为 CR (回车)。较少使用，主要用于特殊协议解析。

两者方向相反：ICRNL 是 CR→NL，INLCR 是 NL→CR。

</details>
