# 62.9 Terminal Window Size

> 本章：[TLPI 第 62 章](../README.md)

## 本节讲什么

通过 `ioctl(TIOCGWINSZ)` 获取终端窗口大小（行列数），以及窗口大小变化时的 `SIGWINCH` 信号处理。

## 要点

### 获取窗口大小

```c
#include <sys/ioctl.h>
#include <termios.h>

struct winsize ws;
if (ioctl(STDOUT_FILENO, TIOCGWINSZ, &ws) == -1) {
    perror("ioctl TIOCGWINSZ");
} else {
    printf("Rows: %d, Cols: %d\n", ws.ws_row, ws.ws_col);
    printf "Pixel: %d x %d\n", ws.ws_ypixel, ws.ws_xpixel);
}
```

### struct winsize

```c
struct winsize {
    unsigned short ws_row;     /* 行数 */
    unsigned short ws_col;     /* 列数 */
    unsigned short ws_xpixel;  /* 水平像素（通常未用） */
    unsigned short ws_ypixel;  /* 垂直像素（通常未用） */
};
```

### SIGWINCH 信号

| 事件 | 信号 | 默认行为 |
|------|------|---------|
| 终端窗口大小变化 | `SIGWINCH` | 忽略（需注册处理函数） |

```c
volatile sig_atomic_t win_changed = 0;

void winch_handler(int sig) {
    win_changed = 1;
}

/* 注册 */
struct sigaction sa = {0};
sa.sa_handler = winch_handler;
sigaction(SIGWINCH, &sa, NULL);

/* 在事件循环中检查 */
while (1) {
    if (win_changed) {
        win_changed = 0;
        /* 重新获取窗口大小，重绘界面 */
        struct winsize ws;
        ioctl(STDOUT_FILENO, TIOCGWINSZ, &ws);
        resize_ui(ws.ws_row, ws.ws_col);
    }
    /* ... 其他处理 ... */
}
```

### 获取窗口大小的替代方法

```c
/* 方法1：ioctl TIOCGWINSZ（推荐） */
ioctl(fd, TIOCGWINSZ, &ws);

/* 方法2：环境变量 LINES/COLUMNS */
char *lines = getenv("LINES");
char *cols = getenv("COLUMNS");

/* 方法3：tput 命令 */
/* tput lines; tput cols */
```

### 注意事项

| 问题 | 说明 |
|------|------|
| 非终端 fd | ioctl 返回 ENOTTY |
| IDE/重定向 | stdout 可能不是终端 |
| 像素值 | 通常为 0，不被填 |
| 信号竞争 | SIGWINCH 可能丢失，需轮询 |

## HFT / 嵌入式关联

- 交易终端 TUI 界面自适应窗口大小
- 嵌入式串口终端重绘
- 监控面板动态调整行列布局

## 代码示例

```c
#include <sys/ioctl.h>
#include <signal.h>
#include <stdio.h>
#include <unistd.h>

static volatile sig_atomic_t resized = 1;

static void on_winch(int sig) { resized = 1; }

int get_terminal_size(int *rows, int *cols) {
    struct winsize ws;
    if (ioctl(STDOUT_FILENO, TIOCGWINSZ, &ws) == -1)
        return -1;
    *rows = ws.ws_row;
    *cols = ws.ws_col;
    return 0;
}

int main() {
    /* 注册 SIGWINCH */
    struct sigaction sa = {0};
    sa.sa_handler = on_winch;
    sigaction(SIGWINCH, &sa, NULL);

    int rows, cols;
    while (1) {
        if (resized) {
            resized = 0;
            if (get_terminal_size(&rows, &cols) == 0)
                printf("\rTerminal: %dx%d\n", cols, rows);
        }
        pause(); /* 等待信号 */
    }
    return 0;
}
```

## 代码自测

<details>
<summary>为什么 SIGWINCH 的默认行为是忽略？程序如何知道窗口大小变化？</summary>

SIGWINCH 默认被忽略是因为不是所有程序都关心窗口大小变化（如非交互式程序）。关心窗口大小的交互式程序（如编辑器、TUI）需要注册信号处理函数，在信号到达后重新调用 `ioctl(TIOCGWINSZ)` 获取新大小并重绘界面。信号只通知"变化了"，不包含新尺寸，必须主动查询。

</details>
