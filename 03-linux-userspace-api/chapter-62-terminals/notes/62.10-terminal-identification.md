# 62.10 Terminal Identification

> 本章：[TLPI 第 62 章](./README.md)

## 本节讲什么

终端设备的识别方法：`isatty()` 检查是否为终端，`ttyname()` 获取终端设备名，`ctermid()` 获取控制终端名。

## 要点

### 核心 API

```c
#include <unistd.h>
int isatty(int fd);            /* 检查 fd 是否为终端 */
char *ttyname(int fd);          /* 返回终端设备路径 */
char *ctermid(char *s);        /* 返回控制终端名 */
```

### 使用示例

```c
if (isatty(STDIN_FILENO)) {
    printf("STDIN is terminal: %s\n", ttyname(STDIN_FILENO));
} else {
    printf("STDIN is not a terminal (redirected)\n");
}
```

### isatty 行为

| 输入 fd | 返回值 | 说明 |
|---------|--------|------|
| 终端设备 | 1 (true) | 如 /dev/tty1, /dev/pts/0 |
| 普通文件 | 0 (false) | 重定向到文件 |
| 管道 | 0 (false) | `echo "data" | app` |
| socket | 0 (false) | 网络连接 |
| 无效 fd | 0 (false) | errno = EBADF |

### ttyname 实现

`ttyname(fd)` 内部：
1. `isatty(fd)` 确认是终端
2. `fstat(fd)` 获取设备号
3. 扫描 `/dev/` 查找匹配设备号的文件
4. 返回匹配的路径

### ctermid

```c
char *name = ctermid(NULL);
/* 返回进程的控制终端路径，如 "/dev/tty" */
```

`/dev/tty` 是特殊设备文件，总是指向当前进程的控制终端。

### 检测重定向

```c
/* 检查 stdin/stdout/stderr 是否被重定向 */
if (!isatty(STDIN_FILENO))  { /* stdin 被重定向 */ }
if (!isatty(STDOUT_FILENO)) { /* stdout 被重定向 */ }
if (!isatty(STDERR_FILENO)) { /* stderr 被重定向 */ }
```

### /proc/self/fd 代替方案

```bash
# 查看进程 fd 对应的设备
ls -la /proc/self/fd/
# 0 -> /dev/pts/0
# 1 -> /dev/pts/0
# 2 -> /dev/pts/0
```

## HFT / 嵌入式关联

- 交易系统日志：检测 stdout 是否为终端，决定是否着色
- 嵌入式串口设备识别：`ttyname` 确认设备路径
- 守护进程：`isatty` 检查是否有关联终端

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main() {
    /* 检查各标准流 */
    const char *streams[] = { "STDIN", "STDOUT", "STDERR" };
    int fds[] = { STDIN_FILENO, STDOUT_FILENO, STDERR_FILENO };

    for (int i = 0; i < 3; i++) {
        if (isatty(fds[i])) {
            char *name = ttyname(fds[i]);
            printf("%s is terminal: %s\n", streams[i],
                   name ? name : "(unknown)");
        } else {
            printf("%s is NOT a terminal\n", streams[i]);
        }
    }

    /* 控制终端 */
    char term[L_ctermid];
    ctermid(term);
    printf("Control terminal: %s\n", term);

    return 0;
}
```

## 代码自测

<details>
<summary>ttyname 和 ctermid 有什么区别？</summary>

- `ttyname(fd)`：返回**指定 fd** 对应的终端设备路径（如 `/dev/pts/0`），需要传入一个已打开的终端 fd
- `ctermid(s)`：返回**进程控制终端**的路径（通常总是 `/dev/tty`），不依赖任何 fd。`/dev/tty` 是一个特殊文件，打开它总是获得当前进程的控制终端

</details>
