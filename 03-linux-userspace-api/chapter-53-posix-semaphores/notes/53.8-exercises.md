# 53.8 Exercises

> 本章：[TLPI 第 53 章 — POSIX Semaphores](../README.md)

## 练习题

### 练习 1：生产者-消费者

使用 POSIX 未命名信号量 + 共享内存实现生产者-消费者队列。

### 练习 2：命名信号量进程间同步

两个无亲缘关系的进程通过命名信号量同步：进程 A 等待，进程 B 释放。

### 练习 3：超时等待

使用 `sem_timedwait` 实现带超时的等待，超时后打印警告。

## 参考答案

### 练习 1 参考代码

```c
#include <semaphore.h>
#include <sys/mman.h>
#include <stdio.h>

typedef struct {
    int buf[1024];
    int head, tail;
    sem_t sem_data;   /* 数据可用 */
    sem_t sem_space;  /* 空间可用 */
} shm_queue_t;

shm_queue_t *q;

void producer(void) {
    for (int i = 0; i < 10000; i++) {
        sem_wait(&q->sem_space);    /* 等空间 */
        q->buf[q->tail] = i;
        q->tail = (q->tail + 1) % 1024;
        sem_post(&q->sem_data);     /* 通知有数据 */
    }
}

void consumer(void) {
    for (int i = 0; i < 10000; i++) {
        sem_wait(&q->sem_data);     /* 等数据 */
        int item = q->buf[q->head];
        q->head = (q->head + 1) % 1024;
        sem_post(&q->sem_space);    /* 通知有空间 */
    }
}

int main(void) {
    q = mmap(NULL, sizeof(*q), PROT_READ|PROT_WRITE,
             MAP_SHARED|MAP_ANONYMOUS, -1, 0);
    sem_init(&q->sem_data, 1, 0);     /* pshared=1 */
    sem_init(&q->sem_space, 1, 1024);

    if (fork() == 0) { consumer(); _exit(0); }
    producer();
    wait(NULL);
    sem_destroy(&q->sem_data);
    sem_destroy(&q->sem_space);
    munmap(q, sizeof(*q));
    return 0;
}
```

### 练习 2 参考代码

```c
/* 进程 A (等待方) */
#include <semaphore.h>
#include <fcntl.h>
#include <stdio.h>

int main(void) {
    sem_t *sem = sem_open("/hft_sync", O_CREAT, 0644, 0);
    if (sem == SEM_FAILED) { perror("sem_open"); return 1; }
    printf("waiting...\n");
    sem_wait(sem);
    printf("received signal\n");
    sem_close(sem);
    return 0;
}

/* 进程 B (释放方) */
#include <semaphore.h>
#include <fcntl.h>

int main(void) {
    sem_t *sem = sem_open("/hft_sync", 0);
    if (sem == SEM_FAILED) { perror("sem_open"); return 1; }
    sem_post(sem);
    printf("signal sent\n");
    sem_close(sem);
    return 0;
}
```

### 练习 3 参考代码

```c
#include <semaphore.h>
#include <time.h>
#include <stdio.h>

int main(void) {
    sem_t *sem = sem_open("/hft_timeout", O_CREAT, 0644, 0);

    struct timespec ts;
    clock_gettime(CLOCK_REALTIME, &ts);
    ts.tv_sec += 5;  /* 5 秒超时 */

    printf("waiting with 5s timeout...\n");
    if (sem_timedwait(sem, &ts) == -1) {
        if (errno == ETIMEDOUT)
            printf("timeout! no signal received\n");
        else perror("sem_timedwait");
    } else {
        printf("signal received\n");
    }
    sem_close(sem);
    sem_unlink("/hft_timeout");
    return 0;
}
```

## HFT / 嵌入式关联

- **共享内存 + 信号量**：HFT 行情分发标准方案
- **超时保护**：`sem_timedwait` 防止死锁卡死
- **命名信号量**：无亲缘进程间同步（服务/监控进程）
