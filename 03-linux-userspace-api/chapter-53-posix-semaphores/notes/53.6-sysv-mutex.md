## 本节讲什么

工程：多锁原子 / SEM_UNDO → SysV；简洁单计数器 → POSIX。 线程互斥优先 **`pthread_mutex`**（有所有权、常更快）；跨进程用信号量。 ---

---

## 要点

| | SysV | POSIX |
|--|------|-------|
| 形态 | 集、多计数器 | 单个 |
| 初始化 | get+ctl 竞态 | open/init 原子 |
| 多 op 原子 | `semop` ✅ | ❌ |
| 崩溃撤销 | `SEM_UNDO` | **无** |
| 超时 | 弱 | `sem_timedwait` |

工程：多锁原子 / SEM_UNDO → SysV；简洁单计数器 → POSIX。  
线程互斥优先 **`pthread_mutex`**（有所有权、常更快）；跨进程用信号量。
