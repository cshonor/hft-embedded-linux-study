## 要点

```c
int statx(int dirfd, const char *pathname, int flags,
          unsigned int mask, struct statx *buf);
```

优势：纳秒、btime、统一 flags、按需字段。  
可移植代码仍用 `stat`/`lstat`/`fstat`。

Demo（可选）：[`code/statx_btime.c`](./code/statx_btime.c)

## 代码示例

```c
#include <sys/stat.h>
#include <stdio.h>

int main(void) {
    /* statx: Linux 4.11+ 增强版 stat */
    struct statx sx;
    /* 需要 #include <sys/syscall.h> 和 syscall(SYS_statx, ...) */
    /* 这里用 stat 代替演示概念 */

    struct stat sb;
    if (stat("/etc/passwd", &sb) != 0) { perror("stat"); return 1; }

    printf("inode:  %lu\n", sb.st_ino);
    printf("size:   %ld\n", sb.st_size);
    printf("mode:   0%o\n", sb.st_mode);
    printf("nlink:  %lu\n", sb.st_nlink);
    printf("uid:    %d\n", sb.st_uid);
    printf("gid:    %d\n", sb.st_gid);
    printf("blocks: %ld\n", sb.st_blocks);

    /* statx 额外提供:
     * - 创建时间 (stx_btime, 普通 stat 没有)
     * - 更精细的 inode 版本号
     * - 可选择只请求部分字段 (减少开销)
     */
    return 0;
}
```
