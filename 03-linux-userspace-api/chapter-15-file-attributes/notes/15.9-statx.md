## 要点

```c
int statx(int dirfd, const char *pathname, int flags,
          unsigned int mask, struct statx *buf);
```

优势：纳秒、btime、统一 flags、按需字段。  
可移植代码仍用 `stat`/`lstat`/`fstat`。
