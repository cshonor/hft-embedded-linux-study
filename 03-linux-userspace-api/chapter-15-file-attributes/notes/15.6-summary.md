## 一张图记住 `struct stat`

| 字段组 | 字段 | 谁写 | 本节实测要点 |
|--------|------|------|-------------|
| 定位 | `st_dev` / `st_ino` / `st_rdev` | FS | `(dev,ino)` 唯一；rdev 仅设备文件 |
| 类型+权限 | `st_mode` | FS | 三选一判定算法；特殊位在高位 |
| 链接 | `st_nlink` | FS | unlink/rename 的背后推手（Ch18） |
| 属主 | `st_uid` / `st_gid` | chown | 非特权 chown 清 SUID/SGID |
| 大小 | `st_size` / `st_blocks` / `st_blksize` | FS | 逻辑/物理/优选 IO 三回事 |
| 时间 | `st_atim` / `st_mtim` / `st_ctim` | 内核 | ctime 不可伪造；atime 有 relatime 变数 |
| 行为 | i-node flags（Linux） | ioctl | append-only/immutable |

## 三个实测修正的"书外知识"

1. **rename 与 ctime**：Linux 不动文件戳；macOS(BSD) 动 ctime（15.2 实测）——跨平台审计别把它当不变量；
2. **新文件属组**：SYSV/Linux=进程 egid；BSD/macOS=父目录属组（15.3 实测 /tmp 下 gid=0）；
3. **no-op chown 与 ctime**：POSIX 要求动，Linux 动，macOS 短路不动（15.3 实测）。
