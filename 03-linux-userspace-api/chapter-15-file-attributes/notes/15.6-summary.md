## 要点

```c
mode_t umask(mode_t mask);   /* 设新值，返回旧值 */
```

最终权限 ≈ `创建 mode & ~umask`  
例：`0666` + umask `022` → `0644`  
只影响**新建**，不改已有文件。

Demo：[`code/umask_demo.c`](../code/umask_demo.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `umask` 裁剪新文件默认权限（`0666 & ~umask`），进程启动时设定防止权限过宽 |
| HFT | 部署脚本显式设置 `umask`，确保日志/临时文件不被其他用户读写，防止敏感数据泄露 |

## 代码示例

```c
#include <sys/stat.h>
#include <fcntl.h>
#include <stdio.h>

int main(void) {
    /* umask: 设置创建文件时的权限掩码 */
    /* 最终权限 = open 请求的权限 & ~umask */

    mode_t old = umask(0022);  /* 022 是常见默认值 */
    printf("旧 umask = 0%o\n", old);
    printf("新 umask = 0%o\n", 0022);

    /* umask=022 时: open(..., 0666) → 实际 0644 */
    int fd = open("/tmp/umask_test1.txt", O_CREAT, 0666);
    if (fd >= 0) {
        struct stat sb;
        fstat(fd, &sb);
        printf("open 0666 + umask 022 → 实际 0%o\n", sb.st_mode & 0777);
        close(fd);
    }

    /* 改 umask 为 0: 不屏蔽任何权限 */
    umask(0);
    fd = open("/tmp/umask_test2.txt", O_CREAT, 0666);
    if (fd >= 0) {
        struct stat sb;
        fstat(fd, &sb);
        printf("open 0666 + umask 000 → 实际 0%o\n", sb.st_mode & 0777);
        close(fd);
    }

    /* 恢复 */
    umask(old);
    return 0;
}
```
