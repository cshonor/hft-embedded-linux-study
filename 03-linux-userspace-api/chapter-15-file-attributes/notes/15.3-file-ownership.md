## 本节讲什么

int chmod(const char *pathname, mode_t mode); int fchmod(int fd, mode_t mode); - 属主或 root 可改

---

## 要点

```c
int chmod(const char *pathname, mode_t mode);
int fchmod(int fd, mode_t mode);
```

- 属主或 root 可改  
- `mode` 是**最终**权限，非增量  
- 普通用户设 SUID/SGID 有安全限制  
- 创建时 `open`/`mkdir` 的 mode 还受 **`umask`** 裁剪  

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `chmod` / `fchmod` 在嵌入式系统的应用场景 |
| HFT | `chmod` / `fchmod` 对低延迟和性能的影响 |

## 代码示例

```c
#include <sys/stat.h>
#include <fcntl.h>
#include <stdio.h>

int main(void) {
    /* chmod: 按路径改权限 */
    if (chmod("/tmp/chmod_test.txt", 0644) != 0) {
        perror("chmod");
        /* 文件可能不存在, 先创建 */
        int fd = open("/tmp/chmod_test.txt", O_CREAT, 0644);
        if (fd >= 0) { close(fd); chmod("/tmp/chmod_test.txt", 0644); }
    }
    printf("chmod 0644 (rw-r--r--)\n");

    /* fchmod: 按 fd 改权限 */
    int fd = open("/tmp/chmod_test.txt", O_RDWR);
    if (fd >= 0) {
        fchmod(fd, 0600);  /* rw------- */
        printf("fchmod 0600 (rw-------)\n");
        close(fd);
    }

    /* 权限只能由文件属主或 root 修改 */
    /* 注意: chmod 不改变 umask (umask 只影响 open 时的默认权限) */
    return 0;
}
```
