## 要点

### 类型宏

`S_ISREG` · `S_ISDIR` · `S_ISLNK` · `S_ISCHR` · `S_ISBLK` · `S_ISFIFO` · `S_ISSOCK`

### 九位权限

`S_IRUSR/WUSR/XUSR` · `S_IRGRP/...` · `S_IROTH/...`

### 特殊位

| 位 | 含义 |
|----|------|
| `S_ISUID` | Set-User-ID |
| `S_ISGID` | Set-Group-ID |
| `S_ISVTX` | 粘滞位：在**目录**上 → 仅属主/root 可删目录内条目（如 `/tmp`） |

> 普通文件上的 sticky：现代 Linux 基本无实际意义。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `st_mode` 编码文件类型+权限+特殊位，用 `S_ISREG` 等宏判断类型而非位掩码手算 |
| HFT | 权限位检查（`S_IXUSR` 等）决定可执行文件与目录访问；误判权限会阻断交易进程启动 |

## 代码示例

```c
#include <sys/stat.h>
#include <stdio.h>

int main(void) {
    struct stat sb;
    if (stat("/etc/passwd", &sb) != 0) { perror("stat"); return 1; }

    /* st_mode 包含: 文件类型 + 权限 */
    printf("st_mode = 0%o\n", sb.st_mode);

    /* 文件类型判断 */
    if (S_ISREG(sb.st_mode))  printf("类型: 普通文件\n");
    if (S_ISDIR(sb.st_mode))  printf("类型: 目录\n");
    if (S_ISCHR(sb.st_mode))  printf("类型: 字符设备\n");
    if (S_ISBLK(sb.st_mode))  printf("类型: 块设备\n");
    if (S_ISLNK(sb.st_mode))  printf("类型: 符号链接\n");
    if (S_ISFIFO(sb.st_mode)) printf("类型: 管道\n");
    if (S_ISSOCK(sb.st_mode)) printf("类型: 套接字\n");

    /* 权限位 */
    printf("权限: %o\n", sb.st_mode & 0777);
    printf("setuid: %s\n", (sb.st_mode & S_ISUID) ? "YES" : "NO");
    printf("setgid: %s\n", (sb.st_mode & S_ISGID) ? "YES" : "NO");
    printf("sticky: %s\n", (sb.st_mode & S_ISVTX) ? "YES" : "NO");
    return 0;
}
```
