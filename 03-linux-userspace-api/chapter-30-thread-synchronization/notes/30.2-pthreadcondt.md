## 本节讲什么

mutex = 互斥访问；cond = **等某个状态成立**。cond **必须**与 mutex 一起用。 pthread_cond_t cond = PTHREAD_COND_INITIALIZER; pthread_cond_wait / timedwait / signal / broadcast

---

## 要点

mutex = 互斥访问；cond = **等某个状态成立**。cond **必须**与 mutex 一起用。

```c
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;
pthread_cond_wait / timedwait / signal / broadcast
```

### `wait` 语义

原子：放锁 → 睡 → 醒后**再拿锁**再返回。避免「先 signal、后 wait」丢唤醒（在持锁改状态 + wait 的正确用法下）。

### 谓词必须 `while`

存在**虚假唤醒**；也可能 broadcast 后条件仍不满足：

```c
pthread_mutex_lock(&mtx);
while (!predicate)
    pthread_cond_wait(&cond, &mtx);
/* use shared state */
pthread_mutex_unlock(&mtx);
```

| | |
|--|--|
| `signal` | 唤醒至少一个等待者 |
| `broadcast` | 唤醒全部（多等待者 / 不确定谁该醒） |

### 生产者-消费者

mutex 保护缓冲与计数；空/满时 `wait`；变更后 `signal`/`broadcast`。

Demo：[`code/prod_condvar.c`](./code/prod_condvar.c)

## 常见陷阱

1. **短读未处理**

```c
/* 假设一次读完 */
ssize_t n = read(fd, buf, 1024);
/* n 可能 < 1024 */
```

read 返回值可能小于请求字节数（short read）。网络和管道尤其常见，必须循环读。

2. **EINTR 未处理**

```c
/* 信号中断后 read 返回 -1, errno=EINTR */
/* 不是错误，应重试 */
```

信号中断系统调用时返回 -1 且 errno=EINTR。应该重试，或用 SA_RESTART 自动重启。

3. **EOF 判断错误**

```c
/* 用 feof 预判 EOF → 多读一次 */
while (!feof(fp)) { fgets(...); }
/* 正确：检查返回值 */
while (fgets(buf, sz, fp) != NULL) { ... }
```

read 返回 0 表示 EOF。不要用 feof 预判（feof 只在读取越过后才为真）。

## 自测题

**题目 1（选择）：** `read()` 返回 0 表示什么？
A. 出错
B. EOF
C. 没有数据
D. 需要重试

<details>
<summary>参考答案</summary>

B。返回 0 表示已到达文件末尾（EOF）。返回 -1 表示出错，返回 >0 表示读到的字节数。

</details>

**题目 2（判断）：** `read` 一定会读满请求的字节数。

<details>
<summary>参考答案</summary>

错误。read 可能返回少于请求的字节数（short read），尤其在管道、socket、终端上。必须循环读。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
char buf[1024];
read(fd, buf, sizeof(buf));
buf[strlen(buf)] = '\0';
```

<details>
<summary>参考答案</summary>

1) read 不保证以 null 结尾；2) 没检查返回值；3) strlen 在未终止的 buf 上越界。应检查返回值并手动加 `\0`。

</details>

**题目 4（应用）：** 写一个安全的 readall 函数，确保读满 n 字节或遇到 EOF。

<details>
<summary>参考答案</summary>

```c
ssize_t readall(int fd, void *buf, size_t n) {
    size_t total = 0;
    while (total < n) {
        ssize_t r = read(fd, (char*)buf+total, n-total);
        if (r < 0 && errno == EINTR) continue;
        if (r < 0) return -1;
        if (r == 0) break; /* EOF */
        total += r;
    }
    return total;
}
```

</details>
