## 练习题

### 练习 1：生产者-消费者队列

用互斥锁和条件变量实现一个线程安全的固定大小队列，支持多生产者多消费者。

**要求**：
- 队列容量固定（如 1024 个元素）
- `push()`：队列满时阻塞
- `pop()`：队列空时阻塞
- 支持优雅关闭（所有消费者在队列空且关闭后退出）

### 练习 2：读写锁 vs 互斥锁性能对比

编写基准测试程序，对比 `pthread_rwlock` 和 `pthread_mutex` 在读多写少场景下的性能。

### 练习 3：避免死锁

编写程序演示两个线程各持有一把锁并请求对方锁导致死锁，然后修复为使用 `trylock` + 退避策略或固定锁顺序。

## 参考答案

### 练习 1 参考代码

```c
#include <pthread.h>
#include <stdlib.h>

#define QUEUE_CAP 1024

typedef struct {
    void *buf[QUEUE_CAP];
    int head, tail, count;
    int closed;
    pthread_mutex_t lock;
    pthread_cond_t not_full;
    pthread_cond_t not_empty;
} blocking_queue_t;

void bq_init(blocking_queue_t *q) {
    q->head = q->tail = q->count = 0;
    q->closed = 0;
    pthread_mutex_init(&q->lock, NULL);
    pthread_cond_init(&q->not_full, NULL);
    pthread_cond_init(&q->not_empty, NULL);
}

void bq_push(blocking_queue_t *q, void *item) {
    pthread_mutex_lock(&q->lock);
    while (q->count == QUEUE_CAP && !q->closed)
        pthread_cond_wait(&q->not_full, &q->lock);
    if (q->closed) { pthread_mutex_unlock(&q->lock); return; }
    q->buf[q->tail] = item;
    q->tail = (q->tail + 1) % QUEUE_CAP;
    q->count++;
    pthread_cond_signal(&q->not_empty);
    pthread_mutex_unlock(&q->lock);
}

void *bq_pop(blocking_queue_t *q) {
    pthread_mutex_lock(&q->lock);
    while (q->count == 0 && !q->closed)
        pthread_cond_wait(&q->not_empty, &q->lock);
    if (q->count == 0) { pthread_mutex_unlock(&q->lock); return NULL; }
    void *item = q->buf[q->head];
    q->head = (q->head + 1) % QUEUE_CAP;
    q->count--;
    pthread_cond_signal(&q->not_full);
    pthread_mutex_unlock(&q->lock);
    return item;
}

void bq_close(blocking_queue_t *q) {
    pthread_mutex_lock(&q->lock);
    q->closed = 1;
    pthread_cond_broadcast(&q->not_empty);
    pthread_cond_broadcast(&q->not_full);
    pthread_mutex_unlock(&q->lock);
}
```

### 练习 2 答案

读写锁在读多写少场景显著优于互斥锁：
- 多个读线程可以同时持有读锁
- 写锁需要等待所有读锁释放

```c
/* 基准测试框架 */
#define N_READERS 8
#define N_WRITERS 1
#define ITERATIONS 1000000

void *reader(void *arg) {
    for (int i = 0; i < ITERATIONS; i++) {
        pthread_rwlock_rdlock(&rwlock);
        /* 读操作 */
        pthread_rwlock_unlock(&rwlock);
    }
    return NULL;
}

void *writer(void *arg) {
    for (int i = 0; i < ITERATIONS / 100; i++) {
        pthread_rwlock_wrlock(&rwlock);
        /* 写操作 */
        pthread_rwlock_unlock(&rwlock);
    }
    return NULL;
}
```

预期结果：8 读 1 写场景下 rwlock 比 mutex 快 3-5 倍。

### 练习 3 答案

**死锁代码**：
```c
/* 线程 A：先 lock1 再 lock2 */
/* 线程 B：先 lock2 再 lock1 */
/* → 死锁 */
```

**修复方案 1：固定锁顺序**
```c
/* 总是先锁 ID 小的锁 */
void transfer(account_t *from, account_t *to, int amount) {
    account_t *first = (from < to) ? from : to;
    account_t *second = (from < to) ? to : from;
    pthread_mutex_lock(&first->lock);
    pthread_mutex_lock(&second->lock);
    /* 转账 */
    pthread_mutex_unlock(&second->lock);
    pthread_mutex_unlock(&first->lock);
}
```

**修复方案 2：trylock + 退避**
```c
while (1) {
    pthread_mutex_lock(&lock1);
    if (pthread_mutex_trylock(&lock2) == 0) break;
    pthread_mutex_unlock(&lock1);
    usleep(1000);  /* 退避 */
}
```

## HFT / 嵌入式关联

- **无锁队列**：HFT 热路径用 `SPSC`（单生产者单消费者）无锁队列，避免锁开销
- **自旋锁**：HFT 低延迟场景用 `pthread_spinlock`（忙等，无上下文切换）
- **读写锁**：行情数据（读多写少）用 rwlock 提高并发
- **嵌入式**：RTOS 可能无 pthread，用平台特定同步原语
