## 要点

| 路径 | 方式 | 特点 |
|------|------|------|
| 小块 | `sbrk` 扩主堆 | 释放后常留在空闲链表 |
| 大块（默认约 >128KB，可配） | `mmap(MAP_ANONYMOUS)` | `free` 时常**立刻还内核**；不绑在 program break 上 |
