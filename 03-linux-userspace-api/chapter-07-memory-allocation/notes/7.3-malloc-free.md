## 要点

```c
#include <stdlib.h>
void *malloc(size_t size);   /* 未初始化；失败 NULL + errno */
void free(void *ptr);
```

### 块布局

用户指针**不含**分配器头部；元数据（大小、链表指针等）在用户区**前方**。  
越界写 → 破坏头部 → `free` 常直接崩。

### `free` 要点

1. `ptr` 必须来自 `malloc`/`calloc`/`realloc`；否则 UB。  
2. `free(NULL)` 安全、空操作。  
3. **`free` 不一定下调 program break**  
   - 小块：进 glibc 空闲链表，供后续复用（少 syscall）  
   - 大块连续空闲：才可能 `sbrk(-n)` 还虚拟内存  
4. `free` **不清零**内容（信息残留风险）。

Demo：[`code/free_and_sbrk.c`](./code/free_and_sbrk.c)（Listing 7-1 精神）

## 代码示例

```c
#include <stdlib.h>
#include <stdio.h>
#include <errno.h>
#include <string.h>

int main(void) {
    /* malloc 基本用法 + 错误检查 */
    int *arr = malloc(10 * sizeof(int));
    if (arr == NULL) {
        fprintf(stderr, "malloc 失败: %s\n", strerror(errno));
        return 1;
    }

    /* malloc 不清零！内容不确定 */
    for (int i = 0; i < 10; i++) {
        arr[i] = i * i;
    }
    printf("arr[5] = %d\n", arr[5]);  /* 25 */

    /* realloc 改变大小 */
    int *bigger = realloc(arr, 20 * sizeof(int));
    if (bigger == NULL) {
        free(arr);  /* 原 arr 仍有效 */
        perror("realloc");
        return 1;
    }
    arr = bigger;  /* realloc 成功后旧指针已失效 */
    arr[15] = 999;
    printf("arr[15] = %d (realloc 后的新区域)\n", arr[15]);

    /* free(NULL) 安全，什么都不做 */
    free(NULL);
    printf("free(NULL) 安全\n");

    /* free 后指针变悬挂 — 置 NULL 是好习惯 */
    free(arr);
    arr = NULL;
    printf("free 完成, arr = NULL\n");

    return 0;
}
```
