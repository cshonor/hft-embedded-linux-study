## 本节讲什么

堆在 BSS 上方；**program break** = 堆当前上边界。 ---

---

## 要点

堆在 BSS 上方；**program break** = 堆当前上边界。

| 动作 | 效果 |
|------|------|
| 上移断点 | 扩大堆，获得更多**虚拟**地址空间 |
| 下移断点 | 缩小堆，归还虚拟地址给内核 |

> **关键：** 抬高断点**只预留虚拟地址**；**首次访问**时才通过缺页异常分配物理页（延迟分配）。

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    /* sbrk(0) 返回当前 program break（堆上边界） */
    void *brk1 = sbrk(0);
    printf("初始 program break = %p\n", brk1);

    /* 手动抬高断点 4096 字节（分配虚拟地址） */
    void *brk2 = sbrk(4096);
    printf("sbrk(4096) 返回旧 break = %p\n", brk2);
    printf("新 break = %p (差 %ld 字节)\n", sbrk(0), (char *)sbrk(0) - (char *)brk1);

    /* 可以在抬高的区域写数据 */
    char *p = (char *)brk2;
    p[0] = 'X';
    p[4095] = 'Y';
    printf("写入成功: p[0]=%c p[4095]=%c\n", p[0], p[4095]);

    /* 下移断点，归还虚拟地址 */
    sbrk(-4096);
    printf("sbrk(-4096) 后 break = %p (回到原位)\n", sbrk(0));

    return 0;
}
```
