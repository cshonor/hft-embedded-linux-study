## 要点

POSIX 允许返回 `NULL` **或** 可 `free` 的非空指针。  
**glibc：常返回有效指针，必须 `free`**，不能当「失败」处理。

## 代码示例

```c
#include <stdlib.h>
#include <stdio.h>

int main(void) {
    /* malloc(0) 的行为: POSIX 允许返回 NULL 或可 free 的非空指针 */
    void *p = malloc(0);
    printf("malloc(0) = %p\n", p);

    if (p != NULL) {
        printf("glibc 返回非空指针 → 必须 free!\n");
        /* 不能解引用！大小为 0，访问是 UB */
        free(p);
        printf("已 free\n");
    } else {
        printf("返回 NULL → 不需要 free\n");
    }

    /* 实际场景: size 变量为 0 时 */
    size_t n = 0;  /* 可能来自计算结果 */
    char *buf = malloc(n);
    if (buf == NULL && n > 0) {
        perror("malloc");
        return 1;
    }
    /* 无论 NULL 还是非空，free 都安全 */
    free(buf);

    return 0;
}
```
