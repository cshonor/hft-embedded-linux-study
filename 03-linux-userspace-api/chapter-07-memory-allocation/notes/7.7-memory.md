## 要点

1. **泄漏**：丢指针未 `free`  
2. **双重 free**：破坏空闲链表  
3. **野指针 free**：栈/全局/非堆指针  
4. **越界**：覆盖块头  
5. **悬挂指针**：`free` 后继续用
