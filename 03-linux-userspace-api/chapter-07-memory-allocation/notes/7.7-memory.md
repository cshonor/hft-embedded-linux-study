## 本节讲什么

1. **泄漏**：丢指针未 `free` 2. **双重 free**：破坏空闲链表 3. **野指针 free**：栈/全局/非堆指针

---

## 要点

1. **泄漏**：丢指针未 `free`  
2. **双重 free**：破坏空闲链表  
3. **野指针 free**：栈/全局/非堆指针  
4. **越界**：覆盖块头  
5. **悬挂指针**：`free` 后继续用  

## 代码示例

```c
#include <stdlib.h>
#include <stdio.h>

int main(void) {
    /* 1. 内存泄漏: 丢指针未 free */
    {
        int *p = malloc(sizeof(int));
        *p = 42;
        /* 作用域结束, p 消失, 但堆内存没 free → 泄漏 */
    }
    printf("1. 泄漏: 块无法回收\n");

    /* 2. 正确做法: 用完就 free */
    {
        int *p = malloc(sizeof(int));
        *p = 42;
        free(p);       /* 释放内存 */
        p = NULL;      /* 置空防悬挂 */
    }
    printf("2. 正确: free + 置 NULL\n");

    /* 3. free(NULL) 安全 */
    int *p = NULL;
    free(p);
    printf("3. free(NULL) 安全\n");

    /* 4. calloc 自动清零 (对比 malloc 不清零) */
    int *arr = calloc(5, sizeof(int));
    printf("4. calloc 清零: arr[0]=%d, arr[4]=%d\n", arr[0], arr[4]);
    free(arr);

    /* 5. 越界写破坏块头 (演示概念, 不要这样做!) */
    int *bad = malloc(4);
    /* bad[10] = 0xDEAD;  // 越界! 破坏分配器元数据, free 时崩溃 */
    free(bad);
    printf("5. 越界写 → free 时可能崩溃 (未演示)\n");

    return 0;
}
```
