## 要点

```c
#include <unistd.h>
int brk(void *end_data_segment);     /* 断点设到绝对地址；0 成功，-1 失败 */
void *sbrk(intptr_t increment);      /* 相对移动；成功返回调整前地址 */
```

| 规则 | |
|------|--|
| `sbrk(0)` | **不移动**，返回当前 break（查边界） |
| `sbrk` 成功 | 返回**调整前**的 break；失败 `(void *)-1` |
| Linux | `sbrk` 多是 glibc 封装，底层 `brk` |
| 业务代码 | **禁止**直接 `brk`/`sbrk`；只为理解 `malloc` |
| 下移过猛 | 勿把断点压到初始堆底以下 → 易 `SIGSEGV` |

Demo：[`code/sbrk_probe.c`](./code/sbrk_probe.c)

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    void *initial = sbrk(0);
    printf("初始 break = %p\n", initial);

    /* sbrk(n): 相对移动 n 字节，返回调整前的 break */
    void *old = sbrk(1024);
    if (old == (void *)-1) { perror("sbrk"); return 1; }
    printf("sbrk(1024): old=%p, new=%p\n", old, sbrk(0));

    /* 在新分配的区域使用 */
    char *buf = (char *)old;
    buf[0] = 'A';
    buf[1023] = 'Z';
    printf("写入: buf[0]=%c, buf[1023]=%c\n", buf[0], buf[1023]);

    /* brk(addr): 设置绝对断点地址 */
    void *target = (char *)initial + 2048;
    if (brk(target) != 0) { perror("brk"); return 1; }
    printf("brk(%p) 后 break = %p\n", target, sbrk(0));

    /* 恢复到初始位置 */
    brk(initial);
    printf("恢复 break = %p\n", sbrk(0));

    /* 注意：业务代码永远不要直接用 brk/sbrk，用 malloc/free */
    return 0;
}
```
