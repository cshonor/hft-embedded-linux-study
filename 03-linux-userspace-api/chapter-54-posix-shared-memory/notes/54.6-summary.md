## 要点

| | SysV | POSIX |
|--|------|-------|
| 句柄 | shmid 非 fd | **fd** |
| 后端 | 内核对象 | `/dev/shm` |
| 大小 | 创建固定 | `ftruncate` 可调 |
| 映射 | shmat/dt | mmap/munmap |
| 运维 | ipcs | `ls /dev/shm` |
| 重启 | 内核持久至 RMID | tmpfs 清 |

工程：**POSIX shm + 命名/共享区信号量**；通信完 munmap/close；一方 unlink。

## 代码示例

```c

/* POSIX 共享内存 vs SysV 共享内存对比 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <sys/mman.h>
#include <sys/shm.h>
#include <unistd.h>

int main(void) {
    /* --- POSIX 方式 --- */
    int pfd = shm_open("/vs_shm", O_CREAT | O_RDWR, 0644);
    ftruncate(pfd, 256);
    char *posix_shm = mmap(NULL, 256, PROT_READ | PROT_WRITE, MAP_SHARED, pfd, 0);
    close(pfd);
    strcpy(posix_shm, "POSIX shm");
    printf("POSIX: name='/vs_shm', mmap, data='%s'\n", posix_shm);
    munmap(posix_shm, 256);
    shm_unlink("/vs_shm");

    /* --- SysV 方式（对比） --- */
    key_t key = IPC_PRIVATE;  /* 简化：用私有 key */
    int shmid = shmget(key, 256, IPC_CREAT | 0644);
    if (shmid >= 0) {
        char *sysv_shm = shmat(shmid, NULL, 0);
        if ((long)sysv_shm != -1) {
            strcpy(sysv_shm, "SysV shm");
            printf("SysV:  key=IPC_PRIVATE, shmget+shmat, data='%s'\n", sysv_shm);
            shmdt(sysv_shm);
        }
        shmctl(shmid, IPC_RMID, NULL);
    }

    printf("\n对比:\n");
    printf("  POSIX: name-based, shm_open+ftruncate+mmap\n");
    printf("  SysV:  key-based,  shmget+shmat+shmdt+shmctl\n");
    return 0;
}

```
