# 54.7 Exercise

> 本章：[TLPI 第 54 章 — POSIX Shared Memory](../README.md)

## 练习题

### 练习 1：共享内存计数器

两个进程通过 POSIX 共享内存 + POSIX 信号量实现一个共享计数器：一个递增，一个递减。

### 练习 2：行情数据分发

模拟 HFT 行情分发：进程 A 创建共享内存写入行情数据，进程 B 映射读取。

### 练习 3：安全清理

编写带安全清理的共享内存创建函数，处理崩溃残留。

## 参考答案

### 练习 1 参考代码

```c
#include <sys/mman.h>
#include <fcntl.h>
#include <semaphore.h>
#include <stdio.h>
#include <unistd.h>

typedef struct {
    int counter;
    sem_t sem;
} shared_data_t;

int main(void) {
    /* 创建共享内存 */
    int fd = shm_open("/hft_counter", O_CREAT|O_RDWR, 0644);
    ftruncate(fd, sizeof(shared_data_t));
    shared_data_t *sd = mmap(NULL, sizeof(*sd),
                             PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    close(fd);

    sem_init(&sd->sem, 1, 1);  /* pshared=1, 初始=1 (mutex) */
    sd->counter = 0;

    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程：递增 */
        for (int i = 0; i < 100000; i++) {
            sem_wait(&sd->sem);
            sd->counter++;
            sem_post(&sd->sem);
        }
        _exit(0);
    }
    /* 父进程：递减 */
    for (int i = 0; i < 100000; i++) {
        sem_wait(&sd->sem);
        sd->counter--;
        sem_post(&sd->sem);
    }
    wait(NULL);

    printf("final counter: %d (expected 0)\n", sd->counter);
    sem_destroy(&sd->sem);
    munmap(sd, sizeof(*sd));
    shm_unlink("/hft_counter");
    return 0;
}
```

### 练习 2 参考代码

```c
/* 行情写入进程 */
#include <sys/mman.h>
#include <fcntl.h>
#include <string.h>
#include <stdio.h>

#define SHM_NAME "/hft_market"
#define SHM_SIZE (sizeof(market_data_t))

typedef struct {
    int seq;
    double price;
    long volume;
} market_data_t;

int main(void) {
    int fd = shm_open(SHM_NAME, O_CREAT|O_RDWR, 0644);
    ftruncate(fd, SHM_SIZE);
    market_data_t *md = mmap(NULL, SHM_SIZE,
                             PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    close(fd);

    for (int i = 0; i < 1000; i++) {
        md->seq = i;
        md->price = 100.0 + i * 0.01;
        md->volume = 1000 + i;
        usleep(1000);
    }
    munmap(md, SHM_SIZE);
    shm_unlink(SHM_NAME);
    return 0;
}

/* 行情读取进程 */
/* shm_open(SHM_NAME, O_RDONLY, 0) → mmap(PROT_READ) → 轮询 md->seq 变化 */
```

### 练习 3 参考代码

```c
void *safe_shm_create(const char *name, size_t size) {
    /* 尝试创建，O_EXCL 确保新建 */
    int fd = shm_open(name, O_CREAT|O_EXCL|O_RDWR, 0600);
    if (fd == -1 && errno == EEXIST) {
        /* 残留对象，清理后重建 */
        shm_unlink(name);
        fd = shm_open(name, O_CREAT|O_EXCL|O_RDWR, 0600);
    }
    if (fd == -1) return NULL;

    ftruncate(fd, size);
    void *p = mmap(NULL, size, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    close(fd);
    if (p == MAP_FAILED) { shm_unlink(name); return NULL; }

    /* 立即 unlink 防止再次残留 */
    shm_unlink(name);
    return p;
}
```

## HFT / 嵌入式关联

- **共享内存行情**：HFT 标准模式——行情进程写入，策略进程读取
- **序列号轮询**：策略进程通过 `md->seq` 变化检测新数据
- **无锁设计**：练习 2 可以扩展为无锁 SPSC 队列（原子操作替代信号量）
- **嵌入式**：`/dev/shm` 空间有限，需控制共享内存大小
