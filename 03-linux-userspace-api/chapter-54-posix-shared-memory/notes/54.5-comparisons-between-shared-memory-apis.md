## 本节讲什么

`close(fd)`：降引用，不销毁。 `shm_unlink(name)`：删名。 真正销毁：已 unlink + **全部 close + 全部 munmap**。

---

## 要点

`close(fd)`：降引用，不销毁。  
`shm_unlink(name)`：删名。  
真正销毁：已 unlink + **全部 close + 全部 munmap**。  

`fork`：继承 fd 与映射。  
`exec`：映射销毁；fd 默认保留（可 `FD_CLOEXEC`）。

## 代码示例

```c

/* POSIX 共享内存生命周期：open → mmap → munmap → close → unlink */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void) {
    /* 1. 创建 + 设置大小 */
    int fd = shm_open("/life_shm", O_CREAT | O_RDWR, 0644);
    ftruncate(fd, 128);

    /* 2. 映射 */
    char *p = mmap(NULL, 128, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);

    /* 3. 使用 */
    strcpy(p, "lifecycle demo");

    /* 4. 解除映射（数据仍在 tmpfs 中） */
    munmap(p, 128);
    printf("munmap: mapping removed, object still exists\n");

    /* 5. 关闭 fd（对象仍存在） */
    close(fd);
    printf("close: fd closed, object still exists\n");

    /* 6. 重新打开验证数据持久 */
    fd = shm_open("/life_shm", O_RDWR, 0);
    p = mmap(NULL, 128, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    printf("reopen: data = '%s'\n", p);
    munmap(p, 128);
    close(fd);

    /* 7. unlink 删除（所有引用关闭后释放） */
    shm_unlink("/life_shm");
    printf("shm_unlink: object name removed\n");
    return 0;
}

```
