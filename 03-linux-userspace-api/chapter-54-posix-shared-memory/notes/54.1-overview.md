## 要点

本质：`/dev/shm` **tmpfs** 上的命名对象（常驻 RAM，默认不落盘）。

## 代码示例

```c

/* POSIX 共享内存原理：shm_open 创建文件 → mmap 映射 → 多进程共享 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <sys/mman.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void) {
    /* 步骤 1: shm_open 创建共享内存对象（tmpfs 中的文件） */
    int fd = shm_open("/principle_shm", O_CREAT | O_RDWR, 0644);
    if (fd < 0) { perror("shm_open"); exit(1); }
    ftruncate(fd, 256);

    /* 步骤 2: mmap 映射到虚拟地址空间 */
    char *shm = mmap(NULL, 256, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if (shm == MAP_FAILED) { perror("mmap"); exit(1); }
    close(fd);

    strcpy(shm, "shared data");

    /* fork 后子进程继承映射 */
    pid_t pid = fork();
    if (pid == 0) {
        printf("child reads: %s\n", shm);
        strcpy(shm, "child modified");
        _exit(0);
    }
    wait(NULL);
    printf("parent reads: %s\n", shm);

    munmap(shm, 256);
    shm_unlink("/principle_shm");
    return 0;
}

```
