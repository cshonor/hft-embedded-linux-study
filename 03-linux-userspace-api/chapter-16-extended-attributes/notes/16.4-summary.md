## 全章一张表

| 维度 | 结论 | 出处 |
|------|------|------|
| 是什么 | inode 上的 name=value（二进制安全） | 16.1 |
| 名字宪法 | namespace 前缀定特权；只有 `user.*` 对应用完全开放 | 16.1 实测 |
| 存哪 | inode 内 / 独立块（ext4）；单值 ≤64KiB，总量 FS 相关 | 16.2 |
| 权限 | `user.*` 读写=文件读写权限（实测 0444 拒写）；**不是后门** | 16.2 实测 |
| 接口 | 路径/fd 两套 × set/get/list + remove；探大小惯用法 | 16.3 实测 |
| 语义开关 | `XATTR_CREATE`（EEXIST）/ `XATTR_REPLACE`（ENOATTR） | 16.3 |
| 跨平台 | macOS 多 position/options 参数；ENOATTR(93) vs ENODATA(61)；namespace 特权不强制 | 全章实测 |

## 编译实测结论（macOS / clang 23.1.0）

- 自编 3 个程序：编译零警告、运行成功，输出钉进 16.1/16.2/16.3；
- 原书 `xattr_view.c`：镜像保留；macOS 可编但依赖 5 参 xattr 的部分仅 Linux（镜像本身逐字不动，验证平台 Pi5）。
