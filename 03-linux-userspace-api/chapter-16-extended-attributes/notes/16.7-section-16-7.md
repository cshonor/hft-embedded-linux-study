## 代码示例

```c
#include <sys/xattr.h>
#include <stdio.h>

int main(void) {
    /* 扩展属性速查:
     * API: setxattr/getxattr/listxattr/removexattr
     * 命名空间: user.* (普通), trusted.* (root), security.*, system.*
     * 限制: 单值 ~64KB, key ≤255B, 总和受文件系统限制
     */
    const char *path = "/tmp";
    char list[512];
    ssize_t n = listxattr(path, list, sizeof(list));
    printf("listxattr(/tmp) = %zd (0 = 无 xattr)\n", n);
    return 0;
}
```
