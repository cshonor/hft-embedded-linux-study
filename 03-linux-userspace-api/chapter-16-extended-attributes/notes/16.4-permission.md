## 要点

| 命名空间 | set / remove | get |
|----------|--------------|-----|
| `user.*` | 文件**写**权限 | 文件**读**权限 |
| `trusted.*` | 仅 root | 仅 root |
| `security.*` / `system.*` | 多为特权/内核 | 视策略 |

`user.*`：**不是**「创建者永久拥有」——换人改权限后规则仍按当前 r/w。
