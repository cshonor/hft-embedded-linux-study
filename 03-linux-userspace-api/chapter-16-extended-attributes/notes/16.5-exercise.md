## 16-1 简易版 setfattr(1) ✅ 实测

**任务**：写一个程序创建/修改文件的 **user** 扩展属性，文件名、属性名、属性值从命令行给出。

**实现**：[`code/ex16_1_setfattr.c`](../code/ex16_1_setfattr.c)：

- 属性名自动限定进 `user.*` namespace（不带前缀则补上；带了 `user.` 就按原样）；
- 写入后**回读验证**（getxattr 对拍），如实报告字节数；
- 错误路径完整：文件不存在 → ENOENT，权限不足 → EACCES，namespace 拒绝 → 按平台错误码上报。

实测：

```text
$ touch /tmp/x16.txt
$ ./ex16_1_setfattr /tmp/x16.txt origin tokyo
/tmp/x16.txt: user.origin = "tokyo" (5 bytes) 已写入并回读验证
```

**对照 setfattr(1) 还缺什么**（诚实清单）：`-n/-v/-x` 选项解析、十六进制/文本值编码、枚举全部属性（配合 listxattr）。本实现覆盖习题要求的"创建或修改"主路径。
