## 本节讲什么

1. 单文件 EA **总量**有限（ext4 inode 内空间有限，过大则外挂块） 2. 单 value 有上限 → 只适小元数据 3. 旧挂载可能要 `user_xattr`；ext4 默认通常已开

---

## 要点

1. 单文件 EA **总量**有限（ext4 inode 内空间有限，过大则外挂块）  
2. 单 value 有上限 → 只适小元数据  
3. 旧挂载可能要 `user_xattr`；ext4 默认通常已开  
4. **`cp` 默认不带 EA**；`cp --preserve=xattr`、`rsync -X`  
5. 硬链接共享 inode → xattr 一改全见  
6. 程序须处理 `ENOTSUP` / `EOPNOTSUPP`  

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | EA 总量/单值有上限只适小元数据；`cp`/`rsync` 默认不带 EA（需 `--preserve=xattr`/`-X`）；硬链接共享 inode 一改全见 |
| HFT | 备份/迁移行情文件记得带 `-X` 否则标签丢失；程序须处理 `ENOTSUP`，勿假设所有 FS 支持 xattr |

## 代码示例

```c
#include <sys/xattr.h>
#include <stdio.h>

int main(void) {
    /* xattr 大小限制:
     * - 单个值: 通常 64KB (VFS 限制)
     * - 所有 xattr 总和: 取决于文件系统 (ext4 通常一个块)
     * - key 长度: 通常 255 字节
     */

    const char *path = "/tmp/xattr_limit_test.txt";
    FILE *fp = fopen(path, "w");
    if (fp) { fclose(fp); }

    /* 测试: 设置大 value */
    char big[65536];
    memset(big, 'X', sizeof(big));

    int ret = setxattr(path, "user.big", big, sizeof(big), 0);
    if (ret != 0) {
        printf("设置 64KB xattr 失败: ");
        perror("");
        printf("(可能超出文件系统限制)\n");
    } else {
        printf("设置 64KB xattr 成功\n");
    }

    /* 查看各文件系统的限制 */
    printf("\n常见限制:\n");
    printf("ext4: 单值最大 ~64KB, 总和受块大小限制\n");
    printf("XFS:  支持更大 xattr\n");
    return 0;
}
```
