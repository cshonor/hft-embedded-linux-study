章节目标

getrusage；软/硬 rlimit；超限信号/错误；fork/exec 继承；与 shell ulimit / systemd 的关系。

易错清单

  1. CHILDREN 必须 wait 才进账
  2. ru_maxrss 是峰值
  3. 硬限降了回不去（非特权）
  4. NOFILE 与「最大 fd 编号」关系：大约 cur-1
  5. 启动时主动抬软限是常见服务套路

实验清单

  1. getrusage 看 CPU/RSS/切换
  2. CHILDREN + wait
  3. 打印默认 rlimit
  4. 抬高 RLIMIT_NOFILE（不超硬限）
  5. （选）硬限不可升

背诵卡

# 要点
1 rusage：消耗；rlimit：上限
2 软 ≤ 硬；非特权硬限只降
3 CHILDREN = 已 wait 子进程
4 fork/exec 保留限制
5 daemon 勿只靠交互 shell ulimit
6 服务常调 NOFILE

#include <stdio.h>
#include <sys/resource.h>
#include <sys/time.h>
#include <unistd.h>

/* Ch36 进程资源 — getrusage/setrlimit/getrlimit。
 * 演示资源使用统计 + 资源限制设置。
 * 编译: gcc -o ch36_demo ch36_demo.c */

int main(void) {
    /* getrusage: 获取资源使用情况 */
    struct rusage usage;
    if (getrusage(RUSAGE_SELF, &usage) == 0) {
        printf("Resource usage (self):\n");
        printf("  user CPU time:   %ld.%06ld sec\n",
               (long)usage.ru_utime.tv_sec, (long)usage.ru_utime.tv_usec);
        printf("  system CPU time: %ld.%06ld sec\n",
               (long)usage.ru_stime.tv_sec, (long)usage.ru_stime.tv_usec);
        printf("  max RSS:         %ld KB\n", (long)usage.ru_maxrss);
        printf("  minor faults:    %ld\n", (long)usage.ru_minflt);
        printf("  major faults:    %ld\n", (long)usage.ru_majflt);
        printf("  voluntary CS:    %ld\n", (long)usage.ru_nvcsw);
        printf("  involuntary CS:  %ld\n", (long)usage.ru_nivcsw);
    }

    /* getrlimit/setrlimit: 资源限制 */
    struct rlimit lim;
    getrlimit(RLIMIT_NOFILE, &lim);
    printf("\nRLIMIT_NOFILE: soft=%lu, hard=%lu\n",
           (unsigned long)lim.rlim_cur, (unsigned long)lim.rlim_max);

    getrlimit(RLIMIT_STACK, &lim);
    printf("RLIMIT_STACK:   soft=%lu, hard=%lu\n",
           (unsigned long)lim.rlim_cur, (unsigned long)lim.rlim_max);

    /* 降低文件描述符上限 */
    lim.rlim_cur = 256;
    if (setrlimit(RLIMIT_NOFILE, &lim) == 0) {
        getrlimit(RLIMIT_NOFILE, &lim);
        printf("After setrlimit: soft=%lu\n", (unsigned long)lim.rlim_cur);
    }
    return 0;
}

本节讲什么

struct rlimit { rlim_t rlim_cur; / soft / rlim_t rlim_max; / hard / }; / RLIM_INFINITY / 服务常调：NOFILE、STACK、CORE。

要点

struct rlimit { rlim_t rlim_cur; /* soft */ rlim_t rlim_max; /* hard */ };
/* RLIM_INFINITY */
角色 软限 硬限
非特权 可在 [0, hard] 内改 只能降，不能升
CAP_SYS_RESOURCE 任意 任意
resource 超限常见结果
RLIMIT_CPU SIGXCPU → 再超 SIGKILL
RLIMIT_FSIZE SIGXFSZ / EFBIG
RLIMIT_DATA / AS ENOMEM
RLIMIT_STACK SIGSEGV
RLIMIT_NOFILE EMFILE（可用 fd 约到 cur-1）
RLIMIT_NPROC EAGAIN（fork/线程）
RLIMIT_CORE 0 = 禁止 core
RLIMIT_SIGPENDING sigqueue 失败
RLIMIT_MEMLOCK mlock 失败

服务常调：NOFILE、STACK、CORE。
Linux：prlimit(pid, …) 可改他进程（需权）。

fork / exec：完整继承/保留限制。
ulimit 改的是 shell 再派生；systemd unit / 程序内 setrlimit 才管 daemon。

Demo：code/print_rlimit.c · code/raise_nofile.c

路线 要点

代码示例

#include <sys/resource.h>
#include <stdio.h>
int main(void) {
    struct rlimit rl;
    /* 查看 fd 上限 */
    getrlimit(RLIMIT_NOFILE, &rl);
    printf("NOFILE: soft=%lu hard=%lu\n", rl.rlim_cur, rl.rlim_max);

    /* 提高软限制 */
    rl.rlim_cur = 4096;
    setrlimit(RLIMIT_NOFILE, &rl);
    printf("NOFILE soft 提高到 4096\n");

    /* 其他限制: RLIMIT_CPU, RLIMIT_AS, RLIMIT_CORE */
    getrlimit(RLIMIT_CORE, &rl);
    printf("CORE: soft=%lu hard=%lu\n", rl.rlim_cur, rl.rlim_max);
    return 0;
}

36.3

Details of Specific Resource Limits

本章：TLPI 第 36 章 — Process Resources

本节讲什么

详细介绍每个 RLIMIT_* 资源限制的含义、默认值和实际影响。

要点

资源限制一览

限制 含义 典型默认 HFT 关注
RLIMIT_AS 虚拟内存上限 无限 防止 OOM
RLIMIT_CORE core 文件大小 0 调试时设大
RLIMIT_CPU CPU 时间（秒） 无限 防 CPU 飙升
RLIMIT_DATA 数据段大小 无限 —
RLIMIT_FSIZE 文件大小 无限 日志大小
RLIMIT_NOFILE 最大 fd 数 1024 HFT 需调高
RLIMIT_NPROC 最大进程/线程数 无限 线程池控制
RLIMIT_RSS 驻留内存 无限 —
RLIMIT_STACK 栈大小 8MB 线程栈
RLIMIT_MEMLOCK mlock 锁定上限 64KB HFT 需调大
RLIMIT_RTPRIO 实时优先级上限 0 HFT 需要
RLIMIT_RTTIME 实时 CPU 时间 无限 防死循环
RLIMIT_SIGPENDING 挂起信号数 无限 —

重要限制详解

RLIMIT_NOFILE（最大 fd 数）：

默认 1024 → HFT 需要大量 fd（网络连接、文件、epoll）
调整：ulimit -n 1000000 或 setrlimit(RLIMIT_NOFILE, ...)
systemd: LimitNOFILE=1000000

RLIMIT_MEMLOCK（mlock 上限）：

默认 64KB → HFT mlockall 锁定全部内存会失败
调整：ulimit -l unlimited
systemd: LimitMEMLOCK=infinity

RLIMIT_NPROC（进程/线程数）：

限制用户能创建的进程+线程总数
HFT 线程池场景需调高
systemd: LimitNPROC=10000

RLIMIT_CPU（CPU 秒数）：

超过限制 → SIGXCPU 信号
继续超 → SIGKILL
HFT 不设此限制（可能误杀长时间运行的回测）

RLIMIT_CORE（core 文件大小）：

0 = 不生成 core 文件
unlimited = 完整 core
HFT 调试时设为 unlimited

RLIMIT_RTTIME（实时 CPU 时间，微秒）：

SCHED_FIFO/RR 线程连续运行超过限制 → SIGXCPU
设计目的是防止实时线程死循环冻系统
HFT 策略线程需注意：长时间纯计算可能触发

setrlimit / getrlimit API

struct rlimit {
    rlim_t rlim_cur;  /* 软限制（当前值） */
    rlim_t rlim_max;  /* 硬限制（上限） */
};

int getrlimit(int resource, struct rlimit *rlim);
int setrlimit(int resource, const struct rlimit *rlim);
规则 说明
rlim_cur <= rlim_max 软限制不超过硬限制
非 root 可降低 rlim_max 但不可升高（不可逆）
root 可调高 rlim_max 需 CAP_SYS_RESOURCE
RLIM_INFINITY 无限制

prlimit 系统调用

int prlimit(pid_t pid, int resource,
            const struct rlimit *new_limit,
            struct rlimit *old_limit);

优势：可设置其他进程的限制，且原子地获取旧值并设置新值。

HFT / 嵌入式关联

  • NOFILE 调高：HFT 可能需要数万 fd（交易所连接 + 行情订阅 + 日志）
  • MEMLOCK 调大：HFT 用 mlockall 锁定所有内存防止换页
  • RTPRIO 调高：HFT 策略线程需要 SCHED_FIFO 实时优先级
  • RTTIME 注意：长时间纯计算策略可能触发 SIGXCPU，需设置足够大或改用非实时策略
  • 嵌入式：资源受限系统设置严格 RLIMIT 防止失控

代码示例

#include <sys/resource.h>
#include <stdio.h>

void setup_hft_limits(void) {
    struct rlimit rl;

    /* 最大 fd 数 */
    rl.rlim_cur = 1000000;
    rl.rlim_max = 1000000;
    if (setrlimit(RLIMIT_NOFILE, &rl) != 0) perror("NOFILE");

    /* mlock 上限 */
    rl.rlim_cur = RLIM_INFINITY;
    rl.rlim_max = RLIM_INFINITY;
    if (setrlimit(RLIMIT_MEMLOCK, &rl) != 0) perror("MEMLOCK");

    /* core 文件 */
    rl.rlim_cur = RLIM_INFINITY;
    rl.rlim_max = RLIM_INFINITY;
    if (setrlimit(RLIMIT_CORE, &rl) != 0) perror("CORE");

    /* 实时优先级 */
    rl.rlim_cur = 99;
    rl.rlim_max = 99;
    if (setrlimit(RLIMIT_RTPRIO, &rl) != 0) perror("RTPRIO");
}

void show_limits(void) {
    struct rlimit rl;
    const char *names[] = {"CPU", "FSIZE", "DATA", "STACK", "CORE",
                           "RSS", "NPROC", "NOFILE", "MEMLOCK",
                           "AS", "LOCKS", "SIGPENDING", "RTPRIO"};
    int resources[] = {RLIMIT_CPU, RLIMIT_FSIZE, RLIMIT_DATA, RLIMIT_STACK,
                       RLIMIT_CORE, RLIMIT_RSS, RLIMIT_NPROC, RLIMIT_NOFILE,
                       RLIMIT_MEMLOCK, RLIMIT_AS, RLIMIT_LOCKS,
                       RLIMIT_SIGPENDING, RLIMIT_RTPRIO};
    for (int i = 0; i < 13; i++) {
        getrlimit(resources[i], &rl);
        printf("%-12s: soft=%ld hard=%ld\n", names[i],
               (long)rl.rlim_cur, (long)rl.rlim_max);
    }
}

代码自测

1. 软限制和硬限制的区别？
  • 软限制（rlim_cur）：当前生效的限制值，进程可以自由地在 0~硬限制之间调整
  • 硬限制（rlim_max）：软限制的上限。非特权进程只能降低硬限制（不可逆），不能升高。root 可以升高。
  • 系统管理员通过 /etc/security/limits.conf 或 systemd 设置硬限制
2. RLIMIT_CPU 超限后会发生什么？

进程 CPU 累计时间超过软限制时，内核发送 SIGXCPU 信号。如果进程忽略或捕获 SIGXCPU 继续运行，每秒再发一次。超过硬限制时，发送 SIGKILL。SIGXCPU 的默认行为是终止进程并生成 core 文件。

3. 为什么 HFT 需要调高 RLIMIT_MEMLOCK？

HFT 用 mlockall(MCL_CURRENT | MCL_FUTURE) 锁定所有内存页，防止被换出到 swap。如果页被换出，访问时会触发缺页中断从磁盘读回，延迟从纳秒跳到毫秒级。默认 MEMLOCK 限制只有 64KB，mlockall 会失败。需要设为 unlimited 或足够大。

代码自测

1. RLIMIT_NPROC 限制的是进程数还是线程数？

两者都限制。Linux 中线程也是通过 clone() 创建的轻量级进程，RLIMIT_NPROC 限制的是用户能创建的进程（包括线程）总数。当 fork 或 pthread_create 超过限制时，返回 EAGAIN。注意这是每用户限制，不是每进程限制。

2. getrusage(RUSAGE_THREAD) 返回什么？

返回当前线程（而非进程）的资源使用。ru_utime 和 ru_stime 是该线程的 CPU 时间，ru_nvcsw 和 ru_nivcsw 是该线程的上下文切换次数。这是 Linux 特有扩展，用于多线程程序中分析单个线程的资源消耗。

#include <sys/resource.h>
#include <stdio.h>

int main(void) {
    struct rlimit rl;

    /* 打印原始值 */

    printf("NOFILE: before soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    rl.rlim_max = 1000000;
    if (setrlimit(RLIMIT_NOFILE, &rl) != 0) perror("setrlimit NOFILE");

    getrlimit(RLIMIT_NOFILE, &rl);
    printf("NOFILE: after  soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    /* MEMLOCK */
    getrlimit(RLIMIT_MEMLOCK, &rl);
    printf("MEMLOCK: before soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    rl.rlim_cur = RLIM_INFINITY;
    rl.rlim_max = RLIM_INFINITY;
    if (setrlimit(RLIMIT_MEMLOCK, &rl) != 0) perror("setrlimit MEMLOCK");

    getrlimit(RLIMIT_MEMLOCK, &rl);
    printf("MEMLOCK: after  soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);
    return 0;
}

练习 3 答案

设置 RLIMIT_FSIZE=1024 后： - write() 写入超过 1024 字节时返回 -1，errno=EFBIG - 或内核发送 SIGXFSZ 信号（如果信号未被屏蔽） - 默认 SIGXFSZ 终止进程

struct rlimit rl = { .rlim_cur = 1024, .rlim_max = 1024 };
setrlimit(RLIMIT_FSIZE, &rl);

int fd = open("test.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
char buf[2048];
memset(buf, 'x', sizeof(buf));
ssize_t n = write(fd, buf, sizeof(buf));
if (n == -1) perror("write");  /* EFBIG */
