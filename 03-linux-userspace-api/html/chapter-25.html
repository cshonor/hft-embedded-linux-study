导读

章节目标

区分正常/异常终止；对比 exit / _exit / _Exit；掌握退出状态与 atexit；理解内核回收与僵尸；衔接 wait。

25.9 易错清单

  1. fork 子用 exit → atexit 双跑
  2. _exit 不刷 stdio → 输出可能丢
  3. 退出码截断到 8 位
  4. 信号杀跳过全部用户清理；SIGKILL 尤甚
  5. on_exit 不可移植；优先 atexit

速查

API 回调 刷 stdio 典型用途
exit ✅ ✅ 正常结束进程
_exit/_Exit ❌ ❌ fork 子、信号敏感路径
abort 经信号 — 异常自毁

练习

  1. atexit 逆序
  2. exit vs _exit 缓冲差异
  3. fork + exit 复现双 atexit；改 _exit
  4. waitpid + WEXITSTATUS

背诵卡

# 要点
1 exit = atexit + fflush + _Exit
2 fork 子（不 exec）用 _exit
3 退出码仅低 8 位
4 atexit LIFO；信号/_exit 不跑
5 内核收尸后僵尸等 wait
6 用户缓冲 ≠ 内核刷盘

参考

  • Kerrisk · TLPI Ch25
  • man 3 exit · man 2 _exit · man 3 atexit · man 3 abort

代码示例

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

/* Ch25 进程终止 — exit/_exit/atexit/on_exit。
 * exit() 调用 atexit 注册的函数 + flush stdio；
 * _exit() 直接进入内核，不清理。
 * 编译: gcc -o ch25_demo ch25_demo.c */

static void cleanup1(void) {
    printf("atexit handler 1 (called by exit, LIFO order)\n");
}

static void cleanup2(void) {
    printf("atexit handler 2 (called first, LIFO)\n");
}

int main(void) {
    /* atexit: 注册退出处理函数，LIFO 顺序调用 */
    atexit(cleanup1);
    atexit(cleanup2);

    printf("Program running...\n");

    /* fork 后子进程继承 atexit 注册 */
    pid_t pid = fork();
    if (pid == 0) {
        printf("Child: calling _exit (skips atexit handlers)\n");
        _exit(0);  /* 不调 atexit，不 flush stdio */
    }

    /* 父进程用 exit() */
    printf("Parent: calling exit (runs atexit handlers + flush stdio)\n");
    exit(0);
    /* 以下不会执行 */
    printf("This line never prints\n");
}

25.1

终止分类

本章：TLPI 第 25 章 — Process Termination - 上一节：本章首页 - 下一节：25.2 exit vs _exit / _Exit（核心）

本节讲什么

最终都进内核销毁路径。 ---

要点

类型 方式
正常 main return · exit · _exit / _Exit
异常 致命信号 · abort() → SIGABRT

最终都进内核销毁路径。

HFT / 嵌入式关联

路线 要点
嵌入式 正常（main return/exit）vs 异常（abort/信号）分流，daemon 需区分清理路径
HFT 异常终止绕过清理直进内核，HFT 需区分退出类型并快速重启

代码示例

#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("子进程正常退出\n");
        _exit(0);  /* 正常退出 */
    }
    int status;
    waitpid(pid, &status, 0);
    if (WIFEXITED(status)) printf("正常退出: code=%d\n", WEXITSTATUS(status));
    else if (WIFSIGNALED(status)) printf("被信号杀死: sig=%d\n", WTERMSIG(status));
    return 0;
}

25.2

`exit` vs `_exit` / `_Exit`（核心）

本章：TLPI 第 25 章 — Process Termination - 上一节：25.1 终止分类 - 下一节：25.3 main return

本节讲什么

void exit(int status); / stdlib：库清理后进内核 / void _Exit(int status); / C99：直进内核 / void _exit(int status); / POSIX：与 _Exit 等价（Linux） /

要点

void exit(int status);    /* stdlib：库清理后进内核 */
void _Exit(int status);   /* C99：直进内核 */
void _exit(int status);   /* POSIX：与 _Exit 等价（Linux） */
步骤 exit _exit / _Exit
atexit / on_exit ✅ 逆序跑 ❌
刷 stdio ✅ ❌（用户缓冲可能丢）
进内核销毁 ✅ ✅

fork 规范

if (fork() == 0)
    _exit(EXIT_FAILURE);   /* 不 exec 时禁止 exit() */

fork 复制了 atexit 列表与 stdio 缓冲 → 子调 exit 易重复回调/重复刷缓冲。

Demo：code/exit_vs_exit.c · code/fork_atexit.c

HFT / 嵌入式关联

路线 要点
嵌入式 _exit 直进内核不刷 stdio；fork 子进程必须 _exit 防重复刷缓冲
HFT 热路径退出用 _exit 绕过 atexit/刷缓冲延迟；fork 子进程禁止 exit()

代码示例

#include <stdlib.h>
#include <unistd.h>
#include <stdio.h>
void cleanup(void) { printf("atexit cleanup\n"); }
int main(void) {
    atexit(cleanup);  /* 注册退出处理函数 */
    printf("三种退出方式:\n");
    printf("  exit(n)   → 调 atexit + flush stdio + 调 _exit\n");
    printf("  _exit(n)  → 直接进内核, 不 flush\n");
    printf("  _Exit(n)  → 同 _exit (ISO C)\n");

    fork();
    /* 子进程用 _exit 避免重复 flush */
    exit(0);  /* 父进程用 exit */
}

25.3

`main` return

本章：TLPI 第 25 章 — Process Termination - 上一节：25.2 exit vs _exit / _Exit（核心） - 下一节：25.4 退出状态

本节讲什么

return N; ≈ exit(N)。无 return 时 C99+ 默认 return 0。 ---

要点

return N; ≈ exit(N)。无 return 时 C99+ 默认 return 0。

HFT / 嵌入式关联

路线 要点
嵌入式 main return ≈ exit，走 atexit + 刷缓冲清理路径
HFT main return 会跑 atexit + 刷缓冲，延迟敏感退出点改用 _exit

代码示例

#include <stdio.h>
/* main 的 return(n) 等价于 exit(n):
 * - 调用 atexit 注册的函数
 * - flush 并关闭 stdio 流
 * - 调用 _exit(n)
 */
int main(void) {
    printf("main 中 return 0 == exit(0)\n");
    return 0;
    /* 如果 main 不写 return, C99 起默认 return 0 */
}

25.4

退出状态

本章：TLPI 第 25 章 — Process Termination - 上一节：25.3 main return - 下一节：25.5 atexit / on_exit

本节讲什么

仅低 8 位有效（0–255）。 0 / EXIT_SUCCESS · 非 0 / EXIT_FAILURE。 父用 wait/waitpid 取状态：

要点

仅低 8 位有效（0–255）。
0 / EXIT_SUCCESS · 非 0 / EXIT_FAILURE。

父用 wait/waitpid 取状态：

宏 含义
WIFEXITED 正常终止
WEXITSTATUS 退出码（仅当 WIFEXITED）
（信号杀） WIFSIGNALED 等；勿读 WEXITSTATUS

HFT / 嵌入式关联

路线 要点
嵌入式 退出状态仅低 8 位（0-255），是父子协作契约
HFT 退出码 + wstatus 宏（WIFEXITED/WIFSIGNALED）是监控 worker 健康的关键信号

代码示例

#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("子进程运行中...\n");
        sleep(2);
        _exit(0);
    }
    /* 子进程退出但父进程还没 wait → 变僵尸 (Z 状态) */
    sleep(1);
    printf("查看: ps -p %d -o stat,pid (应为 Z)\n", pid);
    sleep(3);
    wait(NULL);  /* 回收僵尸 */
    printf("已回收\n");
    return 0;
}

25.5

`atexit` / `on_exit`

本章：TLPI 第 25 章 — Process Termination - 上一节：25.4 退出状态 - 下一节：25.6 内核销毁时做什么

本节讲什么

int atexit(void (func)(void)); int on_exit(void (func)(int, void ), void arg); / Linux 扩展 / - 注册：LIFO 逆序执行

要点

int atexit(void (*func)(void));
int on_exit(void (*func)(int, void *), void *arg);  /* Linux 扩展 */
  • 注册：LIFO 逆序执行
  • 仅 exit / main return 触发
  • _exit / 信号杀：不跑
  • fork 复制列表；exec 成功清空
  • 回调里勿再乱调 exit（易乱序/递归感）

Demo：code/atexit_order.c

HFT / 嵌入式关联

路线 要点
嵌入式 atexit 注册清理（关 fd/写日志），LIFO 逆序执行
HFT atexit 注册资源清理；但 _exit/信号杀不跑，崩溃路径需另设防护

代码示例

#include <stdlib.h>
#include <stdio.h>
void f1(void) { printf("f1\n"); }
void f2(void) { printf("f2\n"); }
int main(void) {
    /* atexit: 注册函数, exit 时逆序调用 */
    atexit(f1);
    atexit(f2);
    printf("exit 时调用顺序: f2 → f1 (逆序)\n");
    /* 最多注册 32 个 (sysconf(_SC_ATEXIT_MAX)) */
    return 0;
}

25.6

内核销毁时做什么

本章：TLPI 第 25 章 — Process Termination - 上一节：25.5 atexit / on_exit - 下一节：25.7 僵尸（衔 Ch26）

本节讲什么

关 fd、放内存与多数资源 → 进程成僵尸（保留 PID/退出状态）→ 向父发 SIGCHLD → 父 wait* 才摘掉僵尸。 ---

要点

关 fd、放内存与多数资源 → 进程成僵尸（保留 PID/退出状态）→ 向父发 SIGCHLD → 父 wait* 才摘掉僵尸。
刷 stdio 用户缓冲 仅 exit 路径
内核页缓存 / 关 fd _exit 也会走内核清理（≠ 用户态 fflush）

HFT / 嵌入式关联

路线 要点
嵌入式 内核关 fd 放内存 → 僵尸 → SIGCHLD → 父 wait 摘僵尸
HFT 理解内核销毁流程避免资源泄漏；僵尸堆积耗尽 PID，长期运行必须 wait 收尸

代码示例

#include <stdlib.h>
#include <stdio.h>
void cleanup(void) { printf("cleanup\n"); }
int main(void) {
    atexit(cleanup);
    printf("退出流程: atexit → flush → _exit\n");
    return 0;
}
