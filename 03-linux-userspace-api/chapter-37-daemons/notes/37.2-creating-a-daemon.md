## 要点

| 步 | 动作 | 为何 |
|----|------|------|
| 1 | `fork`，父 `_exit` | shell 归还提示符；子非组 Leader → 可 `setsid` |
| 2 | `setsid` | 新会话+新组，脱离控制终端 |
| 3 | **再 fork**，中间父退出 | 最终进程**非会话首**，难再抢终端 |
| 4 | `umask(0)` | 自控创建 mode |
| 5 | `chdir("/")`（或 `/var`） | 不挡 umount |
| 6 | 关继承 fd | 防泄漏 |
| 7 | 0/1/2 → `/dev/null` | 用 `open`+`dup2`，勿只 `close` 被抢 fd |

glibc `daemon()`：常**缺第二次 fork** → 仍可能是会话首；生产宜自写 `becomeDaemon`。

Demo：[`code/become_daemon.c`](../code/become_daemon.c) · [`code/mini_daemon.c`](../code/mini_daemon.c)

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 7 步：`fork`→`setsid`→再 `fork`→`umask(0)`→`chdir("/")`→关 fd→0/1/2 到 `/dev/null`；glibc `daemon()` 缺第二次 fork |
| HFT | 生产用自写 `becomeDaemon`（含第二次 fork），彻底脱离终端防信号干扰 |

## 代码示例

```c
#include <unistd.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <stdio.h>
/* 创建守护进程步骤 */
int main(void) {
    /* 1. fork + 父退出 */
    pid_t pid = fork();
    if (pid > 0) return 0;  /* 父退出 */
    if (pid < 0) return 1;

    /* 2. setsid: 脱离控制终端 */
    setsid();

    /* 3. fork 再次 (防止重新获取终端) */
    pid = fork();
    if (pid > 0) return 0;

    /* 4. chdir("/") */
    chdir("/");

    /* 5. 关闭/重定向 fd 0/1/2 */
    int devnull = open("/dev/null", O_RDWR);
    dup2(devnull, 0); dup2(devnull, 1); dup2(devnull, 2);

    /* 6. umask(0) */
    umask(0);

    /* 守护进程已创建 */
    for (;;) sleep(1);
    return 0;
}
```
