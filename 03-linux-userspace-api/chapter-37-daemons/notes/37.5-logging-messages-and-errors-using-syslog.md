## 要点

```c
openlog(ident, LOG_PID|LOG_NDELAY, LOG_DAEMON);
syslog(LOG_INFO, "msg %d", n);
closelog();
```

facility：`LOG_DAEMON`/`USER`…  
priority：`EMERG`…`DEBUG`。  
走 `/dev/log` → rsyslog 等；分级、轮转由系统管。

Demo：[`code/t_syslog.c`](../code/t_syslog.c)

## 代码示例

```c
#include <syslog.h>
#include <stdio.h>
int main(void) {
    /* syslog: 守护进程标准日志接口 */
    openlog("mydaemon", LOG_PID | LOG_CONS, LOG_DAEMON);
    syslog(LOG_INFO, "守护进程启动 PID=%d", getpid());
    syslog(LOG_WARNING, "这是一个警告");
    syslog(LOG_ERR, "这是一个错误");
    closelog();
    printf("日志已写入 syslog (查看: journalctl 或 /var/log/syslog)\n");
    return 0;
}
```
