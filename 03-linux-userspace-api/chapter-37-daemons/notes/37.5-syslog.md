## 要点

```c
openlog(ident, LOG_PID|LOG_NDELAY, LOG_DAEMON);
syslog(LOG_INFO, "msg %d", n);
closelog();
```

facility：`LOG_DAEMON`/`USER`…  
priority：`EMERG`…`DEBUG`。  
走 `/dev/log` → rsyslog 等；分级、轮转由系统管。

Demo：[`code/t_syslog.c`](./code/t_syslog.c)
