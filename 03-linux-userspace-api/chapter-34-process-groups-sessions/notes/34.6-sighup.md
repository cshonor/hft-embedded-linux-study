## 本节讲什么

默认：终止。典型： 1. **控制进程退出** → 向前台组发 `SIGHUP`；会话失终端 2. 关终端 → shell 收 `SIGHUP`，常转发作业

---

## 要点

默认：终止。典型：

1. **控制进程退出** → 向前台组发 `SIGHUP`；会话失终端  
2. 关终端 → shell 收 `SIGHUP`，常转发作业  
3. **孤儿进程组**内有停止进程 → 组内 `SIGHUP` 再 `SIGCONT`  

`nohup`：忽略 `SIGHUP`。  
挂断 ≠ 仅「网络断」；终端关闭/控制进程死都会走相关路径。

## 代码示例

```c
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
/* SIGHUP: 控制终端断开时发给前台进程组
 * 守护进程重用 SIGHUP 做配置重载
 */
void handler(int sig) { printf("收到 SIGHUP (重载配置?)\n"); }
int main(void) {
    signal(SIGHUP, handler);
    printf("终端断开 → SIGHUP → 前台进程组\n");
    return 0;
}
```
