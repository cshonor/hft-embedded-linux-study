## 本节讲什么

默认：终止。典型： 1. **控制进程退出** → 向前台组发 `SIGHUP`；会话失终端 2. 关终端 → shell 收 `SIGHUP`，常转发作业

---

## 要点

默认：终止。典型：

1. **控制进程退出** → 向前台组发 `SIGHUP`；会话失终端  
2. 关终端 → shell 收 `SIGHUP`，常转发作业  
3. **孤儿进程组**内有停止进程 → 组内 `SIGHUP` 再 `SIGCONT`  

`nohup`：忽略 `SIGHUP`。  
挂断 ≠ 仅「网络断」；终端关闭/控制进程死都会走相关路径。
