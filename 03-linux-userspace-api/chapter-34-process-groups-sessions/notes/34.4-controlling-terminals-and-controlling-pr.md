## 本节讲什么

会话最多一控制终端；终端属一会话。 Leader 首次打开终端（无 `O_NOCTTY`）→ 控制终端；Leader = 控制进程。 `/dev/tty` = 控制终端别名；无终端 → `ENXIO`。

---

## 要点

会话最多一控制终端；终端属一会话。  
Leader 首次打开终端（无 `O_NOCTTY`）→ 控制终端；Leader = 控制进程。  
`/dev/tty` = 控制终端别名；无终端 → `ENXIO`。  
`ioctl(…, TIOCNOTTY)` 解除；控制进程解除可连锁 `SIGHUP`。

---

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    /* 控制终端: 会话关联的终端
     * /dev/tty: 当前进程的控制终端
     * 前台进程组: 可读终端的进程组
     */
    int fd = open("/dev/tty", O_RDONLY);
    if (fd >= 0) { printf("有控制终端\n"); close(fd); }
    else { printf("无控制终端\n"); }
    printf("前台进程组: %d\n", tcgetpgrp(STDIN_FILENO));
    return 0;
}
```
