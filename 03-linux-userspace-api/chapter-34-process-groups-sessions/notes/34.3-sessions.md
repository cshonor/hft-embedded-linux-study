## 本节讲什么

SID；Leader：`PID == SID`。通常对应一次登录/SSH。 pid_t setsid(void); `setsid` 三件事：成新会话 Leader；成新进程组 Leader；**脱离原控制终端**（新会话暂无终端）。

---

## 要点

SID；Leader：`PID == SID`。通常对应一次登录/SSH。

```c
pid_t setsid(void);
```

`setsid` 三件事：成新会话 Leader；成新进程组 Leader；**脱离原控制终端**（新会话暂无终端）。

❌ **进程组 Leader 不能 `setsid`** → 标准：`fork()`，**子进程** `setsid()`。

Demo：[`code/setsid_demo.c`](../code/setsid_demo.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `setsid` 三件事（新会话 Leader+新进程组 Leader+脱离控制终端）；进程组 Leader 不能 `setsid` 须 `fork` 后子进程调用 |
| HFT | daemon 化关键步骤，脱离控制终端防 `SIGHUP`/终端信号干扰交易服务 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
/* 会话 (session): 进程组的集合
 * setsid: 创建新会话, 成为会话组长
 * 会话最多有一个控制终端
 */
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        setsid();
        printf("新会话: SID=%d, PGID=%d\n", getsid(0), getpgrp());
        _exit(0);
    }
    wait(NULL);
    return 0;
}
```
