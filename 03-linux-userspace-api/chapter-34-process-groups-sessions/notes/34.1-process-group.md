## 本节讲什么

Job ≈ 一进程组（如管道 `cmd1|cmd2|cmd3`）。 每进程唯一 PGID；**Leader**：`PID == PGID`。组长退出 ≠ 组立刻消失（组内还有成员）。 `fork` 默认继承 PGID。

---

## 要点

Job ≈ 一进程组（如管道 `cmd1|cmd2|cmd3`）。  
每进程唯一 PGID；**Leader**：`PID == PGID`。组长退出 ≠ 组立刻消失（组内还有成员）。  
`fork` 默认继承 PGID。

```c
pid_t getpgrp(void);
pid_t getpgid(pid_t pid);
int setpgid(pid_t pid, pid_t pgid);
```

`setpgid` 约束：只改自身或子；子 **exec 后不能再改**；不跨会话；`setpgid(0,0)` → 自立为新组长。  
`kill(-pgid, sig)` → 整组。

Demo：[`code/print_ids.c`](./code/print_ids.c)

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    printf("PID=%d, PGID=%d, SID=%d\n", getpid(), getpgrp(), getsid(0));
    /* setpgid: 加入/创建进程组 */
    pid_t pid = fork();
    if (pid == 0) {
        setpgid(0, 0);  /* 自己成为组长 */
        printf("子: PGID=%d\n", getpgrp());
        _exit(0);
    }
    wait(NULL);
    return 0;
}
```
