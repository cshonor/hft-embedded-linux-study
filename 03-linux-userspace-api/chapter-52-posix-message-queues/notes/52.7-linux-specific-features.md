## 要点

空队列收到**第一条**消息时通知一次。

1. 每队列同时只一个注册者（新盖旧）  
2. 触发后**自动注销** → 须再 `mq_notify`  
3. 队列非空时再发**不**触发  

模式：`SIGEV_SIGNAL` / `SIGEV_THREAD` / `SIGEV_NONE`。  
标准环：注册 → 等信号 → **立刻重注册** → 循环 `mq_receive` 抽干。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 空队列收首条消息通知一次，触发后自动注销须重注册；SIGEV_SIGNAL/THREAD |
| HFT | 异步到达通知避免轮询；标准环注册→等信号→立刻重注册→mq_receive 抽干 |

## 代码示例

```c

/* mq_notify 异步通知：消息到达时发信号 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <signal.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <mqueue.h>
#include <unistd.h>

static mqd_t g_mq;
static void notify_handler(int sig) {
    char buf[64];
    unsigned int prio;
    ssize_t n = mq_receive(g_mq, buf, sizeof(buf), &prio);
    if (n >= 0) {
        buf[n] = '\0';
        printf("notify: received '%s' (prio=%u)\n", buf, prio);
    }
}

int main(void) {
    struct mq_attr attr = { .mq_maxmsg = 10, .mq_msgsize = 64 };
    g_mq = mq_open("/notify_demo", O_CREAT | O_RDWR | O_NONBLOCK, 0644, &attr);
    if (g_mq == (mqd_t)-1) { perror("mq_open"); exit(1); }

    /* 注册异步通知 */
    struct sigevent sev = {
        .sigev_notify = SIGEV_SIGNAL,
        .sigev_signo = SIGUSR1,
    };
    if (mq_notify(g_mq, &sev) < 0) { perror("mq_notify"); exit(1); }
    signal(SIGUSR1, notify_handler);
    printf("notify registered, waiting for message...\n");

    /* fork 子进程发消息 */
    pid_t pid = fork();
    if (pid == 0) {
        sleep(1);  /* 等父进程注册完毕 */
        mqd_t child_mq = mq_open("/notify_demo", O_WRONLY);
        mq_send(child_mq, "async msg", 10, 1);
        mq_close(child_mq);
        _exit(0);
    }
    wait(NULL);

    /* 等信号处理完成 */
    sleep(1);
    printf("done\n");

    mq_close(g_mq);
    mq_unlink("/notify_demo");
    return 0;
}

```
