## 要点

- 消息边界；优先级（数值越大越高；同级 FIFO）  
- `mqd_t` ≈ fd → Linux **select/poll/epoll**  
- unlink 删名；**全 close 才销毁**（丢残留消息）  
- 创建时固定 `mq_maxmsg` / `mq_msgsize`，运行期不可改
