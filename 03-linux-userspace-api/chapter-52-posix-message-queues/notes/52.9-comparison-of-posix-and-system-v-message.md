## 本节讲什么

`/proc/sys/fs/mqueue/`：`msg_max`、`msgsize_max`、`queues_max`。 另：`RLIMIT_MSGQUEUE`。 ---

---

## 要点

`/proc/sys/fs/mqueue/`：`msg_max`、`msgsize_max`、`queues_max`。  
另：`RLIMIT_MSGQUEUE`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | /proc/sys/fs/mqueue/ msg_max/msgsize_max/queues_max；RLIMIT_MSGQUEUE |
| HFT | 队列容量/条数上限防突发积压，启动前按峰值调大 |

## 代码示例

```c

/* POSIX MQ 配额限制：mq_maxmsg / mq_msgsize */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <mqueue.h>

int main(void) {
    /* 查看系统限制 */
    printf("MQ_PRIO_MAX = %ld\n", sysconf(_SC_MQ_PRIO_MAX));

    /* 尝试设置较大配额 */
    struct mq_attr attr = { .mq_maxmsg = 100, .mq_msgsize = 4096 };
    mqd_t mq = mq_open("/quota_demo", O_CREAT | O_RDWR, 0644, &attr);
    if (mq == (mqd_t)-1) {
        printf("mq_open with large quota failed: %s\n", strerror(errno));
        printf("check: /proc/sys/fs/mqueue/msg_max, msgsize_max\n");
        /* 用默认配额重试 */
        mq = mq_open("/quota_demo", O_CREAT | O_RDWR, 0644, NULL);
        if (mq == (mqd_t)-1) { perror("mq_open default"); exit(1); }
    }

    struct mq_attr cur;
    mq_getattr(mq, &cur);
    printf("MQ quota: maxmsg=%ld, msgsize=%ld\n", cur.mq_maxmsg, cur.mq_msgsize);

    /* 查看系统配额 */
    FILE *fp = fopen("/proc/sys/fs/mqueue/msg_max", "r");
    if (fp) { char buf[32]; fgets(buf, sizeof(buf), fp); printf("msg_max=%s", buf); fclose(fp); }
    fp = fopen("/proc/sys/fs/mqueue/msgsize_max", "r");
    if (fp) { char buf[32]; fgets(buf, sizeof(buf), fp); printf("msgsize_max=%s", buf); fclose(fp); }

    mq_close(mq);
    mq_unlink("/quota_demo");
    return 0;
}

```
