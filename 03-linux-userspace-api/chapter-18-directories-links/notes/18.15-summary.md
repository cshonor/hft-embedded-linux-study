# 18.15 Summary

> 本章：[TLPI 第 18 章](../README.md)

## 本节讲什么

第 18 章总结：目录和链接相关的所有 API，包括目录操作、硬链接/符号链接、路径解析和目录树遍历。

## 要点

### 本章 API 总览

| API | 头文件 | 功能 |
|-----|--------|------|
| `mkdir()` | `sys/stat.h` | 创建目录 |
| `rmdir()` | `unistd.h` | 删除空目录 |
| `remove()` | `stdio.h` | 统一删除文件/空目录 |
| `link()` | `unistd.h` | 创建硬链接 |
| `symlink()` | `unistd.h` | 创建符号链接 |
| `readlink()` | `unistd.h` | 读取符号链接目标 |
| `unlink()` | `unistd.h` | 删除文件 |
| `rename()` | `stdio.h` | 重命名/移动 |
| `opendir()` | `dirent.h` | 打开目录流 |
| `readdir()` | `dirent.h` | 读取目录项 |
| `closedir()` | `dirent.h` | 关闭目录流 |
| `nftw()` | `ftw.h` | 递归遍历目录树 |
| `getcwd()` | `unistd.h` | 获取当前工作目录 |
| `chdir()` | `unistd.h` | 修改当前工作目录 |
| `fchdir()` | `unistd.h` | 通过 fd 修改 CWD |
| `chroot()` | `unistd.h` | 修改根目录 |
| `realpath()` | `stdlib.h` | 解析规范路径 |
| `dirname()` | `libgen.h` | 提取目录部分 |
| `basename()` | `libgen.h` | 提取文件部分 |
| `openat()` | `fcntl.h` | 相对目录打开文件 |
| `unlinkat()` | `fcntl.h` | 相对目录删除 |
| `fstatat()` | `sys/stat.h` | 相对目录获取属性 |

### 硬链接 vs 符号链接

| 特性 | 硬链接 | 符号链接 |
|------|--------|---------|
| 本质 | 目录项指向同一 inode | 独立文件含目标路径 |
| 跨文件系统 | 否 | 是 |
| 链接目录 | 否（root 除外） | 是 |
| 目标删除后 | 仍有效 | 断链 (dangling) |
| inode | 与原文件相同 | 不同 |
| 创建 | `link()` | `symlink()` |
| 读取目标 | 不需要 | `readlink()` |

### 安全注意点

1. `chroot` 后必须 `chdir("/")` 再 `drop privileges`
2. `dirname`/`basename` 会修改输入字符串
3. `readdir` 返回 NULL 需检查 errno 区分错误和遍历完毕
4. `realpath(path, NULL)` 避免缓冲区溢出
5. `*at()` 函数族消除 TOCTOU 竞争

## HFT / 嵌入式关联

- 交易系统日志管理：目录遍历、日志轮转、路径规范化
- 安全沙箱：`chroot` + 权限丢弃
- 路径安全：`realpath` 防目录穿越、`*at` 消除竞争
- 配置管理：`basename` 提取文件名做 key
