## 要点

```c
DIR *opendir(const char *name);
DIR *fdopendir(int fd);
struct dirent *readdir(DIR *dirp);
int closedir(DIR *dirp);
```

`d_name` 文件名；`d_ino` 等视平台。  
可移植：类型靠再 `lstat`/`stat`；Linux `d_type` 是扩展。

Demo：[`code/list_dir.c`](../code/list_dir.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `opendir`/`readdir` 遍历目录，`readdir` 返回 `struct dirent` 含 inode 号与名字 |
| HFT | 扫描行情文件目录用 `readdir`；注意其非线程安全（用 `readdir_r`），多线程遍历需加锁或本地缓冲 |

## 代码示例

```c
#include <stdio.h>
#include <dirent.h>
#include <string.h>
/* readdir vs scandir: 遍历 vs 排序过滤 */
static int filter(const struct dirent *d) {
    return d->d_name[0] != '.';  /* 跳过隐藏文件 */
}

int main(void) {
    /* scandir: 自动排序 + 过滤 */
    struct dirent **namelist;
    int n = scandir("/tmp", &namelist, filter, alphasort);
    if (n < 0) { perror("scandir"); return 1; }

    printf("scandir results (sorted):\n");
    for (int i = 0; i < n; i++) {
        printf("  %s\n", namelist[i]->d_name);
        free(namelist[i]);
    }
    free(namelist);

    /* rewinddir: 重置目录流位置 */
    DIR *dir = opendir("/tmp");
    struct dirent *e;
    int count1 = 0;
    while ((e = readdir(dir))) count1++;

    rewinddir(dir);  /* 重置到开头 */
    int count2 = 0;
    while ((e = readdir(dir))) count2++;

    printf("\nrewinddir: first pass=%d, second pass=%d\n", count1, count2);
    closedir(dir);
    return 0;
}
```
