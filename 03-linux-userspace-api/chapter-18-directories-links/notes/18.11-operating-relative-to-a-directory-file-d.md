# 18.11 Operating Relative to a Directory File Descriptor

> 本章：[TLPI 第 18 章](../README.md)

## 本节讲什么

Linux 2.6.39+ 和 POSIX.1-2008 引入了以目录 fd 为基准的文件操作 API：`openat()`、`fstatat()`、`linkat()`、`unlinkat()` 等，避免 CWD 全局状态带来的竞争和安全问题。

## 要点

### *at() 函数族

| 函数 | 对应旧 API | 说明 |
|------|-----------|------|
| `openat()` | `open()` | 相对目录 fd 打开文件 |
| `fstatat()` | `stat()` | 相对目录 fd 获取属性 |
| `linkat()` | `link()` | 相对目录 fd 创建硬链接 |
| `unlinkat()` | `unlink()` | 相对目录 fd 删除 |
| `renameat()` | `rename()` | 相对目录 fd 重命名 |
| `readlinkat()` | `readlink()` | 相对目录 fd 读取符号链接 |
| `fchmodat()` | `chmod()` | 相对目录 fd 修改权限 |
| `fchownat()` | `chown()` | 相对目录 fd 修改属主 |
| `futimensat()` | `utimensat()` | 相对目录 fd 修改时间戳 |

### openat() 原型

```c
#include <fcntl.h>
int openat(int dirfd, const char *pathname, int flags, ... /* mode_t */);
```

### dirfd 参数规则

| dirfd 值 | pathname | 行为 |
|-----------|----------|------|
| `AT_FDCWD` | 相对路径 | 相对 CWD（等同 `open`） |
| `AT_FDCWD` | 绝对路径 | 忽略 dirfd，使用绝对路径 |
| 有效目录 fd | 相对路径 | 相对该目录 |
| 有效目录 fd | 绝对路径 | 忽略 dirfd，使用绝对路径 |

### unlinkat() flags

| 标志 | 效果 |
|------|------|
| 0 | 删除文件（等同 unlink） |
| `AT_REMOVEDIR` | 删除空目录（等同 rmdir） |

### 优势：消除 TOCTOU 竞争

```c
/* 旧方式：有竞争窗口 */
chdir("/srv/data");        // step 1
fd = open("config", ...);  // step 2: 可能在 1-2 之间被替换

/* 新方式：原子操作 */
dirfd = open("/srv/data", O_RDONLY | O_DIRECTORY);
fd = openat(dirfd, "config", ...);  // 基于已验证的目录
```

## HFT / 嵌入式关联

- 多线程交易系统：每个线程用自己的目录 fd，避免 CWD 竞争
- 安全审计：验证目录未被符号链接劫持后操作
- 容器/沙箱：`openat` 配合 `O_PATH` 实现受限文件系统访问

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
#include <sys/stat.h>

int main() {
    /* 打开基准目录 */
    int dirfd = open("/srv/data", O_RDONLY | O_DIRECTORY);
    if (dirfd < 0) { perror("open dir"); return 1; }

    /* 相对 dirfd 打开文件 */
    int fd = openat(dirfd, "config.json", O_RDONLY);
    if (fd < 0) { perror("openat"); close(dirfd); return 1; }

    /* 相对 dirfd 获取文件属性 */
    struct stat st;
    if (fstatat(dirfd, "config.json", &st, 0) == 0)
        printf("size: %ld\n", st.st_size);

    /* 相对 dirfd 删除临时文件 */
    unlinkat(dirfd, "config.tmp", 0);

    close(fd);
    close(dirfd);
    return 0;
}
```

## 代码自测

<details>
<summary>openat 的 dirfd 参数为 AT_FDCWD 时行为如何？</summary>

`AT_FDCWD` 表示使用进程的当前工作目录作为基准。此时 `openat(AT_FDCWD, "file", flags)` 等同于 `open("file", flags)`。如果 pathname 是绝对路径，则忽略 dirfd（无论是 AT_FDCWD 还是有效 fd），直接使用绝对路径。

</details>
