# 18.10 The Current Working Directory of a Process

> 本章：[TLPI 第 18 章](./README.md)

## 本节讲什么

每个进程有一个当前工作目录（CWD），作为相对路径解析的基准。`getcwd()` 获取当前路径，`chdir()` 修改当前目录。这是 shell `cd` 命令的底层机制。

## 要点

### 核心 API

```c
#include <unistd.h>
char *getcwd(char *buf, size_t size);   // 获取当前工作目录
char *getwd(char *buf);                  // 已废弃，不安全
char *get_current_dir_name(void);        // GNU 扩展，malloc 分配
int chdir(const char *path);             // 修改当前工作目录
int fchdir(int fd);                       // 通过已打开的目录 fd 修改
```

### getcwd 行为

| 情况 | 返回 | errno |
|------|------|-------|
| 成功 | buf 指针 | - |
| buf 太小 | NULL | `ERANGE` |
| 当前目录已被删除 | NULL | `ENOENT` |
| 无权限访问父目录 | NULL | `EACCES` |

### CWD 内核机制

```
task_struct {
    struct fs_struct *fs;  // 文件系统信息
    // fs->pwd 是 CWD 的 path 结构
    // 内核解析相对路径时以此为基准
}
```

### fchdir() 的优势

| 特性 | `chdir()` | `fchdir()` |
|------|-----------|------------|
| 参数 | 路径字符串 | 已打开的 fd |
| 竞争安全 | 有 TOCTOU | 无 |
| 适用场景 | 普通切换 | 保存/恢复 CWD |

### 保存和恢复 CWD 的模式

```c
/* 模式1：open + fchdir（推荐） */
int saved = open(".", O_RDONLY | O_DIRECTORY);
chdir("/some/path");
/* ... 在新目录工作 ... */
fchdir(saved);  /* 恢复 */
close(saved);

/* 模式2：getcwd + chdir（有竞争窗口） */
char cwd[PATH_MAX];
getcwd(cwd, sizeof(cwd));
chdir("/some/path");
/* ... */
chdir(cwd);  /* 如果 cwd 被删除/改名会失败 */
```

## HFT / 嵌入式关联

- 交易策略切换工作目录加载不同配置文件集
- 日志系统切换到日志目录写入
- 嵌入式系统 `fchdir` 避免 `chdir` 的符号链接竞争

## 代码示例

```c
#include <unistd.h>
#include <fcntl.h>
#include <stdio.h>
#include <limits.h>

int main() {
    char buf[PATH_MAX];
    if (getcwd(buf, sizeof(buf)) == NULL) {
        perror("getcwd");
        return 1;
    }
    printf("CWD: %s\n", buf);

    /* 保存 CWD，切换到 /tmp，再恢复 */
    int saved = open(".", O_RDONLY | O_DIRECTORY);
    if (saved < 0) { perror("open"); return 1; }

    chdir("/tmp");
    getcwd(buf, sizeof(buf));
    printf("Now in: %s\n", buf);

    fchdir(saved);
    close(saved);
    getcwd(buf, sizeof(buf));
    printf("Restored: %s\n", buf);
    return 0;
}
```

## 代码自测

<details>
<summary>当前目录被删除后 getcwd() 返回什么？</summary>

如果当前目录被其他进程删除（`unlink` 或 `rmdir`），`getcwd()` 会失败并返回 NULL，errno 设置为 `ENOENT`。因为内核中的 CWD 路径已无效。在 Linux 上，`getcwd` 会返回带 `(deleted)` 后缀的路径，表示目录已被删除。程序应检测此情况并 `chdir` 到有效目录。

</details>
