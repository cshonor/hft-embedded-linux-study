---

## 要点

```c
int symlink(const char *target, const char *linkpath);
ssize_t readlink(const char *pathname, char *buf, size_t bufsiz);
```

独立 inode，内容 = 目标路径字符串。可跨 FS、可指目录、可悬空。  
`stat` 跟随；`lstat` 看链接本身；`readlink` 只读字符串（不解析）。

### 硬链 vs 软链

| | 硬链接 | 符号链接 |
|--|--------|----------|
| inode | 共享 | 独立 |
| 跨 FS | ❌ | ✅ |
| 指目录 | ❌（用户） | ✅ |
| 目标删后 | 数据仍在 | 悬空 |
| | | `stat` 跟 / `lstat` 看链 |

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 符号链接 在嵌入式系统的应用场景 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    /* 硬链接: link() — 多个文件名指向同一 inode */
    int ret = link("/tmp/link_demo.txt", "/tmp/hardlink.txt");
    if (ret == 0) {
        printf("硬链接创建成功 (同一 inode, nlink+1)\n");
    } else {
        /* 先创建源文件 */
        FILE *fp = fopen("/tmp/link_demo.txt", "w");
        if (fp) { fprintf(fp, "hello"); fclose(fp); }
        link("/tmp/link_demo.txt", "/tmp/hardlink.txt");
        printf("硬链接创建成功\n");
    }

    /* 符号链接: symlink() — 特殊文件, 内容是目标路径 */
    ret = symlink("/tmp/link_demo.txt", "/tmp/softlink.txt");
    if (ret == 0) {
        printf("符号链接创建成功\n");
    }

    /* 读符号链接目标 */
    char buf[256];
    ssize_t n = readlink("/tmp/softlink.txt", buf, sizeof(buf) - 1);
    if (n > 0) {
        buf[n] = '\0';
        printf("符号链接指向: %s\n", buf);
    }

    /* 区别:
     * 硬链接: 不能跨文件系统, 不能链接目录, 删除源文件仍可用
     * 符号链接: 可跨文件系统, 可链接目录, 删除源文件则失效
     */
    return 0;
}
```
