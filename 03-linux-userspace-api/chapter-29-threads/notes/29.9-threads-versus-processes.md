# 29.9 线程 vs 进程

## 本节讲什么

线程和进程的优劣对比，何时用线程、何时用进程。

---

## 要点

### 对比表

| 维度 | 线程 | 进程 |
|------|------|------|
| 创建开销 | ~10-50μs | ~100-1000μs（fork 拷贝页表） |
| 上下文切换 | ~1-10μs | ~5-50μs |
| 地址空间 | 共享 | 独立 |
| 数据共享 | 直接访问全局变量 | 需 IPC（管道/共享内存） |
| 隔离性 | 差（一个崩溃全挂） | 好（独立地址空间） |
| 同步开销 | 低（互斥锁） | 高（IPC） |
| 调试 | 难（竞态条件） | 相对容易 |

### 何时用线程

- 需要大量数据共享（如图像处理、矩阵运算）
- 低延迟通信（共享变量 vs IPC）
- I/O 并行（一个线程阻塞不影响其他）
- 资源受限（线程比进程轻量）

### 何时用进程

- 需要隔离（一个崩溃不能拖垮其他）
- 安全性要求高（权限分离）
- 可用性优先（子进程崩溃可重启）
- 避免锁竞争（Chrome/Nginx 多进程模型）

### 混合模型

| 模型 | 例子 |
|------|------|
| 多进程 | Nginx（master + workers） |
| 多线程 | 数据库（一个连接一个线程） |
| 多进程 + 多线程 | Chrome（每 tab 一个进程，每进程多线程） |
| 事件驱动 | Redis/Node.js（单线程 + epoll） |

### HFT 场景选择

| 场景 | 推荐 | 原因 |
|------|------|------|
| 行情处理 + 策略 | 多线程 | 共享内存零拷贝 |
| 风控独立 | 多进程 | 隔离性，风控崩不拖垮交易 |
| 回测引擎 | 多进程 | 可并行多个回测任务 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 资源受限优先线程，但关键模块用进程隔离 |
| HFT | 线程共享内存零延迟，但风控/日志用独立进程保证隔离 |

## 代码示例

```c
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>
#include <sys/wait.h>
#include <string.h>
/* 线程 vs 进程: 创建开销对比 */
void *thread_worker(void *arg) { return NULL; }

int main(void) {
    /* 线程创建: 共享地址空间 */
    pthread_t tid;
    int shared_var = 42;
    pthread_create(&tid, NULL, thread_worker, NULL);
    /* 线程可直接访问 shared_var */
    printf("thread: shared_var = %d (same address space)\n", shared_var);
    pthread_join(tid, NULL);

    /* 进程创建: 独立地址空间 */
    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程有自己的副本, 修改不影响父进程 */
        shared_var = 99;
        printf("child: shared_var = %d (own copy)\n", shared_var);
        _exit(0);
    }
    wait(NULL);
    printf("parent: shared_var = %d (unchanged)\n", shared_var);
    return 0;
}
```
