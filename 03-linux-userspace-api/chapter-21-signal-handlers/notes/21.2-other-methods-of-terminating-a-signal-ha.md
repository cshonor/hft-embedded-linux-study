# 21.2 `sa_mask`（临时叠加）

> 本章：[TLPI 第 21 章 — Signals: Signal Handlers](../README.md)

---

## 本节讲什么

handler 运行期间： 1. 默认**自动阻塞**正在处理的那个信号（防递归） 2. **额外**阻塞 `sa_mask`

---

## 要点

handler 运行期间：

1. 默认**自动阻塞**正在处理的那个信号（防递归）  
2. **额外**阻塞 `sa_mask`  
3. handler 返回后恢复原线程掩码  

| | `sigprocmask` | `sa_mask` |
|--|---------------|-----------|
| 时效 | 长期（直到再改） | **仅 handler 期间** |
| 作用 | 改线程掩码 | 临时追加阻塞 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | handler 期间默认阻塞本信号防重入，配合 sa_mask 可临时阻塞相关信号，保证嵌入式时序敏感的 handler「执行完前不被同族打断」 |
| HFT | sa_mask 的阻塞只持续 handler 生命周期，不改长期掩码；HFT 信号 handler 应短到微秒级，阻塞窗口越小对延迟影响越小，别在 handler 里做重活 |

## 代码示例

```c
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
void handler(int sig) {
    printf("handler: sig=%d\n", sig);
}
int main(void) {
    struct sigaction sa = {0};
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sigaddset(&sa.sa_mask, SIGQUIT);  /* handler 期间阻塞 SIGQUIT */
    sa.sa_flags = SA_RESTART;
    sigaction(SIGINT, &sa, NULL);
    printf("Ctrl+C → handler 执行期间 SIGQUIT 被阻塞\n");
    for (;;) pause();
    return 0;
}
```
