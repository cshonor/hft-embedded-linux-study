## 本节讲什么

阻塞在慢系统调用时递送信号 → 跑完 handler 后： - 默认：调用失败，`errno == EINTR` - `SA_RESTART`：许多调用自动重启

---

## 要点

阻塞在慢系统调用时递送信号 → 跑完 handler 后：

- 默认：调用失败，`errno == EINTR`  
- `SA_RESTART`：许多调用自动重启  

⚠️ **并非所有**调用都可重启（`epoll_wait`、部分 `accept`/`sleep` 等因平台而异）。  
业务应**统一处理 `EINTR`**（重试或显式退出）。

Demo：[`code/eintr_read.c`](../code/eintr_read.c)

## 代码示例

```c
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
void handler(int sig) { printf("handler: %d\n", sig); }
int main(void) {
    struct sigaction sa = {0};
    sa.sa_handler = handler;
    sa.sa_flags = 0;  /* 不设 SA_RESTART → read 返回 EINTR */
    sigaction(SIGUSR1, &sa, NULL);

    /* 对比: 设 SA_RESTART 后 read 自动重启 */
    printf("不设 SA_RESTART: read 被 SIGUSR1 中断 → 返回 -1 errno=EINTR\n");
    printf("设 SA_RESTART: read 自动重启\n");
    raise(SIGUSR1);
    return 0;
}
```
