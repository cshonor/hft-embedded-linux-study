## 本节讲什么

---

## 要点

| | `signal()` | `sigaction()` |
|--|------------|---------------|
| `sa_mask` / flags | ❌ / 不一致 | ✅ |
| `SA_SIGINFO` | ❌ | ✅ |
| `SA_RESTART` | 实现不一 | 可显式设 |
| 生产 | 弃用 | **首选** |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | signal() 在各 libc 间语义漂移（是否复位、是否阻塞自身），交叉编译平台各异；sigaction 显式声明 mask/flags，是嵌入式可移植代码的唯一选择 |
| HFT | 用 signal() 等于把 handler 语义交给平台决定，竞态难复现；HFT 生产统一 sigaction，行为确定、延迟可测，这是低延迟系统的底线 |

## 代码示例

```c
#include <signal.h>
#include <stdio.h>
void handler(int sig) { printf("sig=%d\n", sig); }
int main(void) {
    /* signal(): 行为不一致, 不推荐 */
    /* signal(SIGINT, handler); */

    /* sigaction(): 行为确定, 推荐 */
    struct sigaction sa = {0};
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = SA_RESTART;
    sigaction(SIGINT, &sa, NULL);

    printf("sigaction vs signal:\n");
    printf("  signal: 不确定是否自动复位、是否阻塞自身\n");
    printf("  sigaction: 行为明确, 可设 mask/flags\n");
    return 0;
}
```
