## 要点

子进程退出 → 父收 `SIGCHLD`。

| 做法 | |
|------|--|
| handler 里 | 循环 `waitpid(-1, …, WNOHANG)` 收尸（标准信号不排队，一次可能对应多个子） |
| `SA_NOCLDWAIT` | 内核自动收，不留僵尸 |

Demo：[`code/sigchld_reap.c`](../code/sigchld_reap.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 标准信号不排队，一次 SIGCHLD 可能对应多个子进程，嵌入式多进程服务必须 `while(waitpid(-1,WNOHANG))` 收净，否则留僵尸 |
| HFT | HFT 极少 fork 子进程（fork 有写时复制抖动），若用则 SA_NOCLDWAIT 让内核自动收尸、省去 handler；子进程只做隔离性重活，别在关键路径 fork |

## 代码示例

```c
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
#include <sys/wait.h>
/* SIGCHLD: 子进程状态变化时发给父进程 */
void handler(int sig) {
    int status;
    pid_t pid = waitpid(-1, &status, WNOHANG);
    if (pid > 0) {
        char buf[64];
        int n = snprintf(buf, sizeof(buf), "子进程 %d 退出\n", pid);
        write(STDOUT_FILENO, buf, n);
    }
}
int main(void) {
    struct sigaction sa = {0};
    sa.sa_handler = handler;
    sa.sa_flags = SA_RESTART | SA_NOCLDSTOP;
    sigaction(SIGCHLD, &sa, NULL);

    pid_t pid = fork();
    if (pid == 0) { _exit(0); }
    printf("父进程: 子PID=%d, 等待 SIGCHLD\n", pid);
    sleep(2);
    return 0;
}
```
