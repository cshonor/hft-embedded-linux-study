## 本节讲什么

int kill(pid_t pid, int sig); /* pid>0 指定进程；0 同进程组；-1 权限内全部；<-1 进程组 |pid| */ int raise(int sig);   /* 发给自己 */

---

## 要点

```c
int kill(pid_t pid, int sig);
/* pid>0 指定进程；0 同进程组；-1 权限内全部；<-1 进程组 |pid| */
int raise(int sig);   /* 发给自己 */
```

`kill` = **发信号**，≠ 必定杀死；常规结束常用 `SIGTERM`。  
`kill(pid, 0)`：不投递，只测权限/是否存在。

Demo：[`code/kill_probe.c`](../code/kill_probe.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | kill(pid,0) 不投递只测「进程是否存在/有权限」，是守护进程健康探针的零副作用手段；kill 发 SIGTERM 是嵌入式服务优雅停机的标准入口 |
| HFT | kill 本质是系统调用，有固定开销；HFT 内部线程/进程通知应走共享内存原子变量或 eventfd，信号只留给外部运维控制（启停） |

## 代码示例

```c
#include <signal.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    printf("PID=%d\n", getpid());
    raise(SIGUSR1);  /* 给自己发信号 */
    printf("raise 后 (如果没被终止)\n");

    /* kill: 给指定进程发信号 */
    kill(getpid(), SIGUSR1);
    printf("kill 后\n");

    /* kill -0: 检查进程是否存在 */
    if (kill(getpid(), 0) == 0) printf("进程存在\n");

    /* killpg: 给进程组发信号 */
    /* killpg(getpgrp(), SIGUSR1); */
    return 0;
}
```
