## 本节讲什么

`sigprocmask()` — 阻塞（延迟）信号传递，控制何时处理信号而非是否处理。

---

## 要点

### 核心概念

- **信号掩码** = 内核为每个进程维护的"被阻塞信号集合"
- 被阻塞的信号 **不会丢失**，标记为 pending，解除阻塞后传递
- `SIGKILL` 和 `SIGSTOP` **无法阻塞**

### sigprocmask API

```c
int sigprocmask(int how, const sigset_t *set, sigset_t *oldset);
```

| `how` | 语义 |
|-------|------|
| `SIG_BLOCK` | 掩码 = 旧掩码 ∪ set（添加阻塞） |
| `SIG_UNBLOCK` | 掩码 = 旧掩码 \ set（解除阻塞） |
| `SIG_SETMASK` | 掩码 = set（直接替换） |

### 关键模式：临界区保护

```c
sigset_t oldmask, blockset;
sigemptyset(&blockset);
sigaddset(&blockset, SIGINT);
sigprocmask(SIG_BLOCK, &blockset, &oldmask);  /* 进入临界区 */
/* ... 临界区代码 ... */
sigprocmask(SIG_SETMASK, &oldmask, NULL);     /* 退出临界区 */
```

### 常见误区

- 阻塞 ≠ 忽略：阻塞延迟传递，忽略直接丢弃
- 多线程用 `pthread_sigmask`，不用 `sigprocmask`

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 临界区保护数据结构一致性，避免信号处理函数重入导致竞态 |
| HFT | 订单簿更新期间阻塞 SIGINT，防止处理函数中断热路径 |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>
/* sigprocmask: 阻塞 SIGINT 3 秒后解除 */
int main(void) {
    sigset_t blockset, oldmask;
    sigemptyset(&blockset);
    sigaddset(&blockset, SIGINT);

    sigprocmask(SIG_BLOCK, &blockset, &oldmask);
    printf("SIGINT blocked for 3s, try Ctrl+C...\n");
    sleep(3);

    printf("unblocking SIGINT...\n");
    sigprocmask(SIG_SETMASK, &oldmask, NULL);
    printf("done\n");
    return 0;
}
```
