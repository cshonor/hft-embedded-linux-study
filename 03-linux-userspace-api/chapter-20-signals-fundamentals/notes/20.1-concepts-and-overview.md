## 本节讲什么

信号 = 内核发给进程的**异步通知**。处置： **例外：** `SIGKILL`、`SIGSTOP` — 不能捕获、忽略、阻塞。 终端（`SIGINT`/`SIGTSTP`）· 内核异常（`SIGSEGV`/`SIGFPE`/`SIGPIPE`）· `kill`/`raise`/`sigqueue` · 定时器（`SIGALRM`）等。

---

## 要点

信号 = 内核发给进程的**异步通知**。处置：

| 处置 | 行为 |
|------|------|
| 默认 | 终止 / core / 停止 / 继续 / 忽略（因信号而异） |
| 忽略 | 丢弃 |
| 捕获 | 调自定义 handler |

**例外：** `SIGKILL`、`SIGSTOP` — 不能捕获、忽略、阻塞。

### 来源

终端（`SIGINT`/`SIGTSTP`）· 内核异常（`SIGSEGV`/`SIGFPE`/`SIGPIPE`）· `kill`/`raise`/`sigqueue` · 定时器（`SIGALRM`）等。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 信号是 Linux 最轻量的进程级异步通知，嵌入式控制环常用它做「优雅停机」（SIGTERM）与「超时告警」（SIGALRM）；SIGKILL/SIGSTOP 不可捕获，是 watchdog 强制回收失控进程的最后保障 |
| HFT | 信号是**异步抢占**，会打断正在跑的关键路径（报文解析/spinloop），产生不可控延迟毛刺；HFT 主循环应屏蔽无关信号、只留 SIGTERM 做停机，其余交给 signalfd/事件循环 |

## 代码示例

```c
#include <signal.h>
#include <stdio.h>
void handler(int sig) { printf("收到信号 %d\n", sig); }
int main(void) {
    signal(SIGINT, handler);
    printf("按 Ctrl+C 触发 SIGINT (PID=%d)\n", getpid());
    for (;;) pause();
    return 0;
}
```
