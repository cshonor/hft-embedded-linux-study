## 本节讲什么

原书第 20 章练习题要点。

<details>
<summary>1. 实现 sigHandler 包装函数，在调用真实 handler 前保存/恢复 errno</summary>

```c
void sigHandlerWrapper(int sig, void (*realHandler)(int)) {
    int saved_errno = errno;
    realHandler(sig);
    errno = saved_errno;
}
```
原因：信号处理函数中调用函数可能修改 errno，覆盖被中断代码的 errno 值。
</details>

<details>
<summary>2. 为什么不能用 printf 在信号处理函数中输出？</summary>

printf 是非异步信号安全函数：它使用内部缓冲区和锁，如果信号中断了主线程的 printf，handler 中再调 printf 会导致死锁或缓冲区损坏。替代方案：`write(STDOUT_FILENO, ...)` + 预格式化字符串。
</details>

<details>
<summary>3. 实现一个安全的 sleep 函数，使用 nanosleep 并处理信号中断</summary>

```c
int safe_sleep(unsigned int seconds) {
    struct timespec req = { .tv_sec = seconds, .tv_nsec = 0 };
    struct timespec rem;
    while (nanosleep(&req, &rem) == -1 && errno == EINTR) {
        req = rem;  /* 被信号中断，继续睡剩余时间 */
    }
    return 0;
}
```
</details>
