# 23.7 通过文件描述符通知的定时器

## 本节讲什么

`timerfd` 系列 API — Linux 特有，将定时器事件变为可从文件描述符读取的事件，融入 epoll。

---

## 要点

### API

| 函数 | 作用 |
|------|------|
| `timerfd_create(clockid, flags)` | 创建 timerfd |
| `timerfd_settime(fd, flags, &its, &old_its)` | 启动/停止 |
| `timerfd_gettime(fd, &its)` | 查询剩余时间 |

### 核心行为

1. 定时器超时时，内核向 fd 写入 `uint64_t`（超时次数）
2. `read(fd, &expirations, 8)` 读取并清零计数
3. 可设 `TFD_NONBLOCK` / `TFD_CLOEXEC`

### 与其他定时器 API 的对比

| | `alarm` | `setitimer` | POSIX `timer_create` | `timerfd` |
|--|---------|-------------|---------------------|-----------|
| 实例数 | 1 | 3 | 无限 | 无限 |
| 通知 | 信号 | 信号 | 信号/线程 | fd (epoll) |
| 融入 epoll | 否 | 否 | 否 | **是** |
| 精度 | 秒 | 微秒 | 纳秒 | 纳秒 |
| 可携带数据 | 否 | 否 | 是 | 否（仅计数） |

### 优势

- 统一事件循环：定时器 + I/O + 信号全在 epoll 中处理
- 无信号处理函数，纯同步
- 多个 timerfd 可融入同一个 epoll 实例

### 典型用法

```c
int tfd = timerfd_create(CLOCK_MONOTONIC, TFD_NONBLOCK | TFD_CLOEXEC);
struct itimerspec its = {
    .it_interval = { .tv_sec = 1, .tv_nsec = 0 },
    .it_value = { .tv_sec = 1, .tv_nsec = 0 },
};
timerfd_settime(tfd, 0, &its, NULL);
/* 将 tfd 加入 epoll，epoll_wait 返回后 read(tfd, &count, 8) */
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | timerfd + epoll 统一事件循环，替代信号+回调的复杂架构 |
| HFT | 心跳/超时检测用 timerfd 融入 epoll，避免信号中断热路径 |

## 代码示例

```c
#include <stdio.h>
#include <sys/timerfd.h>
#include <unistd.h>
#include <time.h>
#include <string.h>
/* timerfd: 通过文件描述符读取定时器事件 */
int main(void) {
    int tfd = timerfd_create(CLOCK_MONOTONIC, 0);
    if (tfd < 0) { perror("timerfd_create"); return 1; }

    /* 每 0.5 秒触发一次 */
    struct itimerspec its;
    memset(&its, 0, sizeof(its));
    its.it_value.tv_nsec = 500000000;
    its.it_interval.tv_nsec = 500000000;
    timerfd_settime(tfd, 0, &its, NULL);

    /* 读取 4 次超时 */
    for (int i = 0; i < 4; i++) {
        uint64_t expirations;
        read(tfd, &expirations, sizeof(expirations));
        printf("tick %d: %lu expiration(s)\n",
               i + 1, (unsigned long)expirations);
    }

    close(tfd);
    return 0;
}
```
