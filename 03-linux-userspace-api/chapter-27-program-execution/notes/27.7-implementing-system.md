## 本节讲什么

无 `e`：用 `environ`。有 `e`：自定义 `envp`，末项 `NULL`。 特权启动宜清理危险变量（如 `LD_*`）。 ---

## 要点

无 `e`：用 `environ`。有 `e`：自定义 `envp`，末项 `NULL`。  
特权启动宜清理危险变量（如 `LD_*`）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 无 e 用 environ，有 e 自定义 envp；特权启动清理 LD_* |
| HFT | 环境变量传配置；特权 worker 清理 LD_* 防劫持 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
extern char **environ;
int main(void) {
    /* execle/execve: 传自定义环境变量 */
    char *args[] = {"env", NULL};
    char *envp[] = {"MY_VAR=hello", "PATH=/usr/bin", NULL};

    pid_t pid = fork();
    if (pid == 0) {
        execve("/usr/bin/env", args, envp);
        perror("execve");
        _exit(1);
    }
    wait(NULL);
    /* execvp/execlp: 继承当前环境变量 */
    return 0;
}
```
