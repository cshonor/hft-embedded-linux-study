## 本节讲什么

PID/PPID/PGID/SID · cwd · umask · **未设 CLOEXEC 的 fd** · 凭证（SUID 见 Ch9）· **信号掩码** · rlimit 等 整块地址空间 · 其它线程 · **信号处理器 → `SIG_DFL`** · pending 清空 · atexit 清空 · 多数定时器/文件锁/AIO 等 ---

---

## 要点

### ✅ 大致保留

PID/PPID/PGID/SID · cwd · umask · **未设 CLOEXEC 的 fd** · 凭证（SUID 见 Ch9）· **信号掩码** · rlimit 等

### ❌ 销毁 / 重置

整块地址空间 · 其它线程 · **信号处理器 → `SIG_DFL`** · pending 清空 · atexit 清空 · 多数定时器/文件锁/AIO 等

| | fork | exec |
|--|------|------|
| 信号 handler | 继承 | **重置默认** |
| 信号掩码 | 继承 | **保留** |
| pending | 清空 | 清空 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | exec 保留 PID/cwd/fd(非CLOEXEC)/信号掩码，销毁地址空间/线程/handler |
| HFT | exec 后信号 handler 重置为默认，worker 需重新安装；fd 带 CLOEXEC 才关 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    char *args[] = {"echo", "hello", "exec", NULL};
    /* exec 系列六函数:
     * execl/execlp/execle: 参数列表 (l)
     * execv/execvp/execve: 参数数组 (v)
     * p 后缀: 搜索 PATH
     * e 后缀: 自定义环境变量
     */
    pid_t pid = fork();
    if (pid == 0) { execvp("echo", args); perror("execvp"); _exit(1); }
    wait(NULL);
    return 0;
}
```
