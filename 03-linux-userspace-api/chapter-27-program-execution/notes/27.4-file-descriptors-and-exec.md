# 27.4 PATH（`*p`）

## 本节讲什么

- 名中无 `/` → 按 `PATH` 搜 - 含 `/` → 当路径，不搜 PATH - 特权程序慎用 `*p`（PATH 含 `.` 等劫持风险）

---

## 要点

- 名中无 `/` → 按 `PATH` 搜  
- 含 `/` → 当路径，不搜 PATH  
- 特权程序慎用 `*p`（PATH 含 `.` 等劫持风险）

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | PATH（`*p`） 在嵌入式系统的应用场景 |
| HFT | PATH（`*p`） 对低延迟和性能的影响 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    /* execvp/execlp: 搜索 PATH */
    char *args[] = {"date", NULL};

    pid_t pid = fork();
    if (pid == 0) {
        execvp("date", args);  /* 自动找 /bin/date */
        perror("execvp");
        _exit(1);
    }
    wait(NULL);

    /* execv/execl: 不搜索 PATH, 需要完整路径 */
    pid = fork();
    if (pid == 0) {
        char *args2[] = {"date", NULL};
        execv("/bin/date", args2);  /* 必须完整路径 */
        _exit(1);
    }
    wait(NULL);
    return 0;
}
```
