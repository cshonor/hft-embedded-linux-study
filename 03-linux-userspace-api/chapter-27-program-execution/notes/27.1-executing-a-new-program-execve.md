真正的系统调用是 **`execve`**；其余为库封装。 int execve(const char *pathname, char *const argv[], char *const envp[]); int execl / execlp / execle(...);

---

## 要点

真正的系统调用是 **`execve`**；其余为库封装。

| 后缀 | 含义 |
|------|------|
| `l` | 参数列表，末尾 `(char *)NULL` |
| `v` | `argv[]` 向量 |
| `p` | 用 `PATH` 搜文件名 |
| `e` | 自带 `envp[]`；否则继承 `environ` |

```c
int execve(const char *pathname, char *const argv[], char *const envp[]);
int execl / execlp / execle(...);
int execv / execvp(...);
```

**成功永不返回；失败返回 -1。**

```c
execvp("ls", argv);
_exit(127);
```

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        /* exec: 替换当前进程映像 */
        char *args[] = {"ls", "-la", "/tmp", NULL};
        execvp("ls", args);
        perror("execvp");  /* 只有失败才返回 */
        _exit(1);
    }
    wait(NULL);
    return 0;
}
```
