# 27.9 Exercises

> 本章：[TLPI 第 27 章 — Program Execution](../README.md)

## 练习题

### 练习 1：实现简易 shell

编写程序，循环读取用户命令，`fork()` + `execvp()` 执行，`waitpid()` 等待。

**要求**：
- 支持命令参数（空格分隔）
- 支持 `PATH` 搜索
- 处理 exec 失败
- Ctrl-D 退出

### 练习 2：exec 前清理环境

编写程序，exec 前设置干净的环境变量（只保留必要的）。

**要求**：
- 只保留 `PATH`、`HOME`、`USER`
- 用 `execve` 传入自定义 envp

### 练习 3：safe_system 实现

实现一个安全的 `safe_system()` 函数，不经过 shell 执行命令（避免命令注入）。

**要求**：
- 接受程序路径和参数数组
- 使用 `fork()` + `execvp()`
- 返回子进程退出状态

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"
#include <sys/wait.h>
#include <wordexp.h>

#define MAX_ARGS 64

int main(void) {
    char line[1024];
    char *argv[MAX_ARGS];

    while (1) {
        printf("$ ");
        fflush(stdout);
        if (fgets(line, sizeof(line), stdin) == NULL) break;  /* EOF */

        /* 解析参数 */
        int argc = 0;
        char *tok = strtok(line, " \t\n");
        while (tok && argc < MAX_ARGS - 1) {
            argv[argc++] = tok;
            tok = strtok(NULL, " \t\n");
        }
        argv[argc] = NULL;

        if (argc == 0) continue;  /* 空行 */
        if (strcmp(argv[0], "exit") == 0) break;

        pid_t pid = fork();
        if (pid == -1) { perror("fork"); continue; }
        if (pid == 0) {
            execvp(argv[0], argv);
            /* exec 失败 */
            fprintf(stderr, "%s: %s\n", argv[0], strerror(errno));
            _exit(127);
        }
        int status;
        waitpid(pid, &status, 0);
        if (WIFEXITED(status) && WEXITSTATUS(status) != 0)
            fprintf(stderr, "exit code: %d\n", WEXITSTATUS(status));
    }
    return 0;
}
```

### 练习 2 参考代码

```c
#include "tlpi_hdr.h"

int main(void) {
    char *envp[] = {
        "PATH=/usr/bin:/bin",
        "HOME=/root",
        "USER=root",
        NULL
    };

    char *argv[] = {"env", NULL};

    /* execve 传入干净的环境 */
    execve("/usr/bin/env", argv, envp);
    errExit("execve");
}
```

### 练习 3 参考代码

```c
#include <unistd.h>
#include <sys/wait.h>
#include <stdarg.h>
#include <string.h>

int safe_system(const char *file, char *const argv[]) {
    pid_t pid = fork();
    if (pid == -1) return -1;

    if (pid == 0) {
        execvp(file, argv);
        _exit(127);  /* exec 失败 */
    }

    int status;
    if (waitpid(pid, &status, 0) == -1) return -1;
    return status;  /* 调用者用 WEXITSTATUS 解析 */
}

/* 用法示例 */
int main(void) {
    char *argv[] = {"ls", "-l", "/tmp", NULL};
    int status = safe_system("ls", argv);
    if (status != -1 && WIFEXITED(status))
        printf("exit code: %d\n", WEXITSTATUS(status));
    return 0;
}
```

## HFT / 嵌入式关联

- **HFT 进程管理**：用 `fork()` + `execvp()` 启动策略/行情/风控子进程
- **安全执行**：所有外部命令调用用 `safe_system` 模式，绝不用 `system()`
- **FD_CLOEXEC**：防止网络 fd 泄漏到子进程
- **嵌入式**：BusyBox 中命令路径可能不同，`execvp` + PATH 搜索更灵活
