## 要点

```c
struct sockaddr_un {
    sa_family_t sun_family;  /* AF_UNIX */
    char sun_path[108];      /* Linux 常见长度；勿假定可移植 */
};
```

- 路径用 `snprintf` 防溢出  
- `bind` 的 `addrlen` = `offsetof(sun_path) + strlen(path) + 1`（路径型）；抽象名另算（含前导 `\0` 后的名字长度）  
- 路径型：文件系统可见 socket 文件
