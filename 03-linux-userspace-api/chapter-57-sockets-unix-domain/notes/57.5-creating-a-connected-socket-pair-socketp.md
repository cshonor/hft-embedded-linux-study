## 本节讲什么

int socketpair(int domain, int type, int protocol, int sv[2]); 仅 `AF_UNIX`；一对已互连、**无名**（无路径文件）。父子 IPC、双向替代 pipe。 fork 后各方关闭不用的端（同 pipe 纪律）。

---

## 要点

```c
int socketpair(int domain, int type, int protocol, int sv[2]);
```

仅 `AF_UNIX`；一对已互连、**无名**（无路径文件）。父子 IPC、双向替代 pipe。  
fork 后各方关闭不用的端（同 pipe 纪律）。

## 常见陷阱

1. **SIGPIPE**

```c
send(fd, buf, n, 0);  /* 对端关闭 → SIGPIPE */
send(fd, buf, n, MSG_NOSIGNAL);  /* 安全 */
```

向已关闭连接的 socket 写数据触发 SIGPIPE。用 MSG_NOSIGNAL 或忽略 SIGPIPE。

2. **TIME_WAIT**

```c
bind(fd, (struct sockaddr*)&addr, len);
/* EADDRINUSE if port in TIME_WAIT */
```

服务端重启时端口可能还在 TIME_WAIT。用 SO_REUSEADDR 允许绑定。

3. **accept 返回值未检查**

```c
int cfd = accept(lfd, NULL, NULL);
/* cfd 可能 -1 (EMFILE/ENFILE) */
```

accept 可能因 fd 耗尽返回 -1。不检查直接用会导致后续操作失败。

## 自测题

**题目 1（选择）：** `listen()` 的第二个参数 backlog 表示什么？
A. 最大连接数
B. 等待 accept 的队列长度
C. 缓冲区大小
D. 超时秒数

<details>
<summary>参考答案</summary>

B。backlog 是已完成连接但尚未 accept 的队列长度。超过后新连接可能被拒绝。

</details>

**题目 2（判断）：** `bind` 可以绑定任意端口号。

<details>
<summary>参考答案</summary>

错误。1-1023 是特权端口，需要 root 权限。已占用的端口会返回 EADDRINUSE。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
connect(sfd, (struct sockaddr*)&addr, sizeof(addr));
send(sfd, "data", 4, 0);
```

<details>
<summary>参考答案</summary>

没有检查 connect 返回值。connect 可能失败（连接被拒绝、超时等），不检查直接 send 会导致错误。

</details>

**题目 4（应用）：** 写代码创建 TCP 服务端 socket 并监听。

<details>
<summary>参考答案</summary>

```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
int opt = 1;
setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port = htons(8080);
addr.sin_addr.s_addr = INADDR_ANY;
bind(sfd, (struct sockaddr*)&addr, sizeof(addr));
listen(sfd, 128);
```

</details>

## 代码示例

```c

/* socketpair 创建双向通信管道 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <sys/wait.h>

int main(void) {
    int sv[2];
    /* socketpair 创建一对已连接的 socket */
    if (socketpair(AF_UNIX, SOCK_STREAM, 0, sv) < 0) {
        perror("socketpair"); exit(1);
    }
    printf("socketpair: sv[0]=%d, sv[1]=%d (connected)\n", sv[0], sv[1]);

    pid_t pid = fork();
    if (pid == 0) {
        close(sv[1]);  /* 子关闭另一端 */
        char buf[64];
        ssize_t n = read(sv[0], buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("child: received '%s'\n", buf); }
        write(sv[0], "child reply", 12);
        close(sv[0]);
        _exit(0);
    }

    close(sv[0]);  /* 父关闭另一端 */
    write(sv[1], "parent msg", 11);

    char buf[64];
    ssize_t n = read(sv[1], buf, sizeof(buf) - 1);
    if (n > 0) { buf[n] = '\0'; printf("parent: received '%s'\n", buf); }

    wait(NULL);
    close(sv[1]);
    return 0;
}

```
