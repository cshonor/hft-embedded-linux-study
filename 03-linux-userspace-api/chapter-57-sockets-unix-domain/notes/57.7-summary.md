# 57.7 Summary

> 本章：[TLPI 第 57 章 — Sockets: Unix Domain](../README.md)

## 本章回顾

### Unix 域套接字 vs TCP

| 特性 | Unix 域套接字 | TCP (127.0.0.1) |
|------|-------------|-----------------|
| 通信范围 | 同一主机 | 本地或远程 |
| 延迟 | 1-5μs | 5-20μs |
| 带宽 | 最高 | 中 |
| 数据拷贝 | 0（内核内存映射） | 2（内核中转） |
| 路径 | 文件系统路径 | IP:端口 |
| 权限 | 文件权限控制 | 无 |

### Unix 域套接字 API

| 函数 | 说明 |
|------|------|
| `socket(AF_UNIX, ...)` | 创建 Unix 域套接字 |
| `bind(sockfd, &addr_un, len)` | 绑定路径名 |
| `connect(sockfd, &addr_un, len)` | 连接服务器路径 |
| `listen/accept` | 同 TCP |
| `send/recv` | 同 TCP |

### struct sockaddr_un

```c
struct sockaddr_un {
    sa_family_t sun_family;  /* AF_UNIX */
    char        sun_path[108]; /* 路径名 */
};
```

### 绑定模式

```c
/* 服务器端 */
struct sockaddr_un addr;
memset(&addr, 0, sizeof(addr));
addr.sun_family = AF_UNIX;
strncpy(addr.sun_path, "/tmp/hft.sock", sizeof(addr.sun_path)-1);
unlink(addr.sun_path);  /* 清理旧文件 */
bind(sockfd, (struct sockaddr *)&addr, sizeof(addr));
```

### Linux 抽象地址命名空间

```c
addr.sun_path[0] = '\0';  /* 第一个字节为空 */
strncpy(addr.sun_path + 1, "hft_sock", sizeof(addr.sun_path) - 1);
/* 不在文件系统创建文件，自动随 fd 关闭消失 */
```

| 特性 | 路径名 | 抽象地址 |
|------|--------|---------|
| 文件 | 创建 sock 文件 | 不创建文件 |
| 权限 | 文件权限 | 无权限检查 |
| 持久性 | 需手动 unlink | fd 关闭自动消失 |
| 可移植性 | POSIX | 仅 Linux |

### SCM_RIGHTS 文件描述符传递

```c
/* 发送 fd */
struct msghdr msg = {0};
struct cmsghdr *cmsg;
char buf[CMSG_SPACE(sizeof(int))];
cmsg = CMSG_FIRSTHDR(&msg);
cmsg->cmsg_level = SOL_SOCKET;
cmsg->cmsg_type = SCM_RIGHTS;
cmsg->cmsg_len = CMSG_LEN(sizeof(int));
*(int *)CMSG_DATA(cmsg) = fd_to_send;
msg.msg_control = buf;
msg.msg_controllen = sizeof(buf);
sendmsg(sockfd, &msg, 0);

/* 接收 fd */
recvmsg(sockfd, &msg, 0);
cmsg = CMSG_FIRSTHDR(&msg);
int received_fd = *(int *)CMSG_DATA(cmsg);
```

## HFT / 嵍入式关联

- **本地通信**：HFT 同机进程间用 Unix 域套接字比 TCP 快 2-5 倍
- **fd 传递**：通过 `SCM_RIGHTS` 传递共享内存 fd 或网络连接 fd
- **抽象地址**：不创建文件，无权限问题，适合临时通信
- **嵌入式**：路径名绑定需注意文件系统可写
- **与管道对比**：Unix 域套接字支持双向、带外数据、fd 传递

## 代码自测

<details>
<summary>1. Unix 域套接字比 TCP 快多少？为什么？</summary>

Unix 域套接字比 TCP 快约 2-5 倍。原因：(1) 无需 TCP/IP 协议栈处理（无分片/重组/校验和/ACK）；(2) 数据在内核内存中直接拷贝，不经过网络层；(3) 无需路由表查找。典型延迟：Unix 域 1-5μs，TCP 本地 5-20μs。
</details>

<details>
<summary>2. SCM_RIGHTS 的作用是什么？</summary>

`SCM_RIGHTS` 允许通过 Unix 域套接字传递文件描述符。发送进程将一个 fd 序列化到辅助数据中，接收进程获得一个新的 fd（编号不同，指向同一个内核打开文件表项）。用途：传递共享内存 fd、网络连接 fd、pipe fd 等，实现高效的进程间资源共享。
</details>

<details>
<summary>3. 抽象地址和路径名绑定的区别？</summary>

路径名绑定在文件系统创建一个 sock 文件，需要清理（unlink），有文件权限控制。抽象地址绑定不创建文件，使用 `\0` + 名字，无需清理（fd 关闭自动消失），无权限检查，但仅 Linux 支持。HFT 临时通信推荐抽象地址。
</details>
