## 要点

| | fork | exec |
|--|------|------|
| CLOEXEC fd | 不关（标记可复制） | **关掉** |

打开即 `O_CLOEXEC`，避免 fork 与 exec 之间的竞态。见 [Ch27 cloexec demo](../chapter-27-program-execution/code/cloexec_demo.c)。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `FD_CLOEXEC` / `O_CLOEXEC` 在嵌入式系统的应用场景 |
| HFT | `FD_CLOEXEC` / `O_CLOEXEC` 对低延迟和性能的影响 |

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    /* 对比: open(O_CLOEXEC) vs fcntl(FD_CLOEXEC) */
    /* O_CLOEXEC: 原子操作, 无竞态 */
    int fd1 = open("/tmp/a.txt", O_CREAT | O_CLOEXEC, 0644);

    /* fcntl: open + fcntl 之间有竞态 (多线程 exec) */
    int fd2 = open("/tmp/b.txt", O_CREAT, 0644);
    fcntl(fd2, F_SETFD, FD_CLOEXEC);  /* 有间隙! */

    printf("O_CLOEXEC (原子) > open+fcntl (有竞态)\n");
    close(fd1); close(fd2);
    return 0;
}
```
