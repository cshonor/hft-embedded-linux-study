## 要点

共享地址空间；父阻塞至子 `_exit`/`exec`；子勿乱改内存。新代码用 fork+COW，**禁用 vfork**。

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
/* vfork:
 * - 子进程借用父进程地址空间 (不 COW)
 * - 父进程阻塞直到子进程 _exit/exec
 * - 子进程不能 return, 不能修改变量
 * - 现代: 用 posix_spawn 或 fork+exec 替代
 */
int main(void) {
    pid_t pid = vfork();
    if (pid == 0) {
        char *args[] = {"echo", "vfork+exec", NULL};
        execvp("echo", args);
        _exit(1);  /* 必须 _exit */
    }
    wait(NULL);
    return 0;
}
```
