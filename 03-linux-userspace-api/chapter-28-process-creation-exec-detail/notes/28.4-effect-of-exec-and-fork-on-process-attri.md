## 本节讲什么

---

## 要点

`fork` / `pthread_create` 均基于 `clone` 标志组合：

| 标志例 | 含义 |
|--------|------|
| `CLONE_VM` | 共享地址空间（线程） |
| `CLONE_FILES` | 共享 fd 表 |
| `CLONE_SIGHAND` | 共享信号处置 |

`fork` ≈ 不共享上述、并带 `SIGCHLD` 的 clone 特例。

## 代码示例

```c
#include <sched.h>
#include <unistd.h>
#include <sys/wait.h>
#include <stdio.h>
/* clone: Linux 特有, 比 fork 更灵活
 * 可控制: 共享地址空间/fd表/信号处理器/...
 * 线程本质就是 clone(CLONE_VM | CLONE_FILES | ...)
 */
static int child_fn(void *arg) {
    printf("clone 子: PID=%d\n", getpid());
    return 0;
}
int main(void) {
    char stack[65536];
    int flags = CLONE_VM | SIGCHLD;  /* 共享地址空间 */
    pid_t pid = clone(child_fn, stack + sizeof(stack), flags, NULL);
    if (pid < 0) { perror("clone"); return 1; }
    waitpid(pid, NULL, 0);
    printf("clone 完成 (共享 VM = 线程)\n");
    return 0;
}
```
