# 31.6 Exercises

> 本章：[TLPI 第 31 章 — Thread Safety (Per-Thread Variables and Thread-Specific Data)](../README.md)

## 练习题

### 练习 1：线程安全的 strerror

实现一个线程安全的 `strerror_r()` 包装函数，使用 per-thread 变量存储错误字符串。

### 练习 2：线程特定数据 (TSD)

使用 `pthread_key_create`/`pthread_setspecific`/`pthread_getspecific` 实现每个线程独立的 errno 变量。

### 练习 3：可重入 vs 线程安全

解释可重入（reentrant）和线程安全（thread-safe）的区别，各举一个例子。

## 参考答案

### 练习 1 参考代码

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

/* 方法 1：使用 strerror_r（POSIX 版本） */
void safe_strerror(int err, char *buf, size_t len) {
    strerror_r(err, buf, len);
}

/* 方法 2：使用 __thread（TLS） */
static __thread char err_buf[128];

const char *my_strerror(int err) {
    strerror_r(err, err_buf, sizeof(err_buf));
    return err_buf;
}
```

### 练习 2 参考代码

```c
#include <pthread.h>

static pthread_key_t errno_key;

void errno_destructor(void *ptr) {
    free(ptr);
}

void tsd_init(void) {
    pthread_key_create(&errno_key, errno_destructor);
}

int tsd_get_errno(void) {
    int *p = pthread_getspecific(errno_key);
    if (p == NULL) {
        p = malloc(sizeof(int));
        *p = 0;
        pthread_setspecific(errno_key, p);
    }
    return *p;
}

void tsd_set_errno(int e) {
    int *p = pthread_getspecific(errno_key);
    if (p == NULL) {
        p = malloc(sizeof(int));
        pthread_setspecific(errno_key, p);
    }
    *p = e;
}
```

### 练习 3 答案

| 特性 | 可重入 (reentrant) | 线程安全 (thread-safe) |
|------|-------------------|----------------------|
| 定义 | 可被信号处理器安全调用 | 可被多线程安全调用 |
| 静态/全局变量 | 不使用 | 可用锁保护 |
| 标准 | 严格 | 较宽松 |
| 关系 | 可重入 → 线程安全 | 线程安全 ≠ 可重入 |

**示例**：
- **可重入**：`strtok_r(str, delim, &saveptr)` — 不使用静态变量，可被信号处理器调用
- **线程安全但不可重入**：`strtok` + mutex — 多线程安全，但信号处理器中调用可能死锁（如果被信号打断的线程已持有 mutex）
- **既不可重入也不线程安全**：`strtok()` — 使用静态变量

## HFT / 嵌入式关联

- **TLS**：HFT 使用 `__thread` 存储每线程上下文（如线程 ID、策略句柄）
- **无锁设计**：HFT 热路径避免锁，用 per-thread 数据 + 原子操作
- **errno**：系统调用的 errno 在 glibc 中是 TLS 变量，每线程独立
- **嵌入式**：`__thread` 需要编译器和运行时支持，裸机/RTOS 可能不支持
