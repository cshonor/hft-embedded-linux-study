## 要点

痛点：接口不能加参数，但内部曾靠静态变量 → 用「每线程一份指针」。

```c
int pthread_key_create(pthread_key_t *key, void (*destructor)(void *));
int pthread_setspecific(pthread_key_t key, const void *value);
void *pthread_getspecific(pthread_key_t key);
int pthread_key_delete(pthread_key_t key);
```

| 点 | |
|----|--|
| key | 进程内全局一份 |
| 值 | **每线程**独立指针 |
| 线程退出 | value≠NULL → 调 destructor |
| `key_delete` | **不**对现有线程跑析构；易泄漏 |

范式（类 strerror）：

1. `pthread_once` → `key_create`  
2. 首次：`malloc` + `setspecific`  
3. 之后：`getspecific`  
4. 退出：destructor `free`  

Demo：[`code/strerror_tsd.c`](./code/strerror_tsd.c)

## 与 C 语言学习的关系

Pthreads 是 C 语言多线程编程的标准。`pthread_create` 接收函数指针和 `void*` 参数——这是 C 语言回调模式的核心。线程返回 `void*` 需要 C 语言指针和类型转换的知识。注意 Pthreads 函数返回错误码（而非设置 errno），不能用 perror，要用 strerror。在 HFT 场景中，线程是低延迟并发的基础。
---

## HFT / 嵌入式关联

| 栈 | |
|----|--|
| C++ | `thread_local` ≈ TLS；可直接调 pthread；**勿混**两套线程生命周期模型 |
| 用户态 only | 内核驱动无 POSIX TSD |
| HFT | `__thread` 放连接/缓冲，少锁、少抖动；禁 `strtok`/`localtime` 一类 |

## 常见陷阱

1. **返回值 vs errno**

```c
if (pthread_create(&t, NULL, func, arg) < 0)  /* 错误! */
    perror("pthread_create");
/* 正确：返回错误码，不是 -1 */
if ((err = pthread_create(&t, NULL, func, arg)) != 0)
    strerror(err);
```

Pthreads 函数返回错误码而不是设置 errno。不能用 perror，要用 strerror(err)。

2. **忘记 join 或 detach**

```c
pthread_create(&t, NULL, func, arg);
/* 不 join 也不 detach → 资源泄漏 */
```

线程结束后如果不 join 或 detach，资源不会回收。必须 join 或 detach。

3. **mutex 忘记 unlock**

```c
pthread_mutex_lock(&m);
if (error) return;  /* 没 unlock! */
pthread_mutex_unlock(&m);
```

mutex lock 后在所有路径都必须 unlock。用 goto cleanup 或 pthread_mutex_trylock + cleanup。

## 自测题

**题目 1（选择）：** `pthread_create` 失败时返回什么？
A. -1
B. 0
C. 错误码（正整数）
D. NULL

<details>
<summary>参考答案</summary>

C。Pthreads 函数返回错误码（如 EAGAIN）而不是 -1，也不设置 errno。用 strerror(err) 获取描述。

</details>

**题目 2（判断）：** 主线程退出时其他线程会继续运行。

<details>
<summary>参考答案</summary>

错误。主线程调用 exit() 或从 main() 返回时，所有线程都会被终止。只有 pthread_exit 才允许其他线程继续。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
void *thread_func(void *arg) {
    int x = *(int*)arg;
    return NULL;
}
int val = 42;
pthread_create(&t, NULL, thread_func, &val);
```

<details>
<summary>参考答案</summary>

如果 thread_func 在 val 被修改后才执行，会读到错误的值。应确保 arg 的生命周期覆盖线程执行期，或动态分配。

</details>

**题目 4（应用）：** 写代码创建线程、等待线程结束并获取返回值。

<details>
<summary>参考答案</summary>

```c
void *func(void *arg) { return (void*)42; }
pthread_t t;
pthread_create(&t, NULL, func, NULL);
void *retval;
pthread_join(t, &retval);
printf("result: %ld\n", (long)retval);
```

</details>
