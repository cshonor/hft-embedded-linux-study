## 要点

痛点：接口不能加参数，但内部曾靠静态变量 → 用「每线程一份指针」。

```c
int pthread_key_create(pthread_key_t *key, void (*destructor)(void *));
int pthread_setspecific(pthread_key_t key, const void *value);
void *pthread_getspecific(pthread_key_t key);
int pthread_key_delete(pthread_key_t key);
```

| 点 | |
|----|--|
| key | 进程内全局一份 |
| 值 | **每线程**独立指针 |
| 线程退出 | value≠NULL → 调 destructor |
| `key_delete` | **不**对现有线程跑析构；易泄漏 |

范式（类 strerror）：

1. `pthread_once` → `key_create`  
2. 首次：`malloc` + `setspecific`  
3. 之后：`getspecific`  
4. 退出：destructor `free`  

Demo：[`code/strerror_tsd.c`](../code/strerror_tsd.c)

## 代码示例

```c
#include <stdio.h>
#include <pthread.h>
#include <string.h>
#include <stdlib.h>
/* 线程特定数据 (TSD): pthread_key_create/setspecific/getspecific */
static pthread_key_t key;

void destructor(void *value) {
    printf("TSD destructor: freeing '%s'\n", (char *)value);
    free(value);
}

void *worker(void *arg) {
    int id = *(int *)arg;

    /* 每个线程设置自己的 TSD */
    char *msg = malloc(64);
    snprintf(msg, 64, "private data of thread %d", id);
    pthread_setspecific(key, msg);

    /* 读取自己的 TSD */
    char *my = pthread_getspecific(key);
    printf("Thread %d: TSD = %s\n", id, my);
    return NULL;
}

int main(void) {
    pthread_key_create(&key, destructor);

    pthread_t t1, t2;
    int id1 = 1, id2 = 2;
    pthread_create(&t1, NULL, worker, &id1);
    pthread_create(&t2, NULL, worker, &id2);
    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    pthread_key_delete(key);
    return 0;
}
```
