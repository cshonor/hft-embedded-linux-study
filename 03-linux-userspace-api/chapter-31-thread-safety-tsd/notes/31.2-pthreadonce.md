## 要点

```c
pthread_once_t once = PTHREAD_ONCE_INIT;   /* 必须静态初始化 */
int pthread_once(pthread_once_t *once_control, void (*init_routine)(void));
```

多线程下 init **只跑一次**；常与 `pthread_key_create` 搭配。  
`once_control` **不要** malloc。
