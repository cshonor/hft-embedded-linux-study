## 本节讲什么

int getrusage(int who, struct rusage *usage); 常用字段：`ru_utime` / `ru_stime` · `ru_maxrss`（峰值 KB，**非累加**）· `ru_minflt`/`ru_majflt` · `ru_nvcsw`/`ru_nivcsw`。 Demo：[`code/rusage_demo.c`](../code/rusage_demo.c)

---

## 要点

```c
int getrusage(int who, struct rusage *usage);
```

| who | 含义 |
|-----|------|
| `RUSAGE_SELF` | 本进程 |
| `RUSAGE_CHILDREN` | **已 wait 回收**的子进程汇总（未 wait 不计） |
| `RUSAGE_THREAD` | 当前线程（Linux） |

常用字段：`ru_utime` / `ru_stime` · `ru_maxrss`（峰值 KB，**非累加**）· `ru_minflt`/`ru_majflt` · `ru_nvcsw`/`ru_nivcsw`。

Demo：[`code/rusage_demo.c`](../code/rusage_demo.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `getrusage` 取 CPU 时间/峰值 RSS/缺页/上下文切换，`RUSAGE_SELF`/`CHILDREN`/`THREAD` |
| HFT | 用 `ru_minflt`/`ru_majflt` 监控缺页毛刺、`ru_nivcsw` 监控被抢占次数，量化延迟抖动来源 |

## 代码示例

```c
#include <sys/resource.h>
#include <stdio.h>
int main(void) {
    struct rusage ru;
    getrusage(RUSAGE_SELF, &ru);
    printf("用户 CPU: %ld.%06ld s\n", ru.ru_utime.tv_sec, ru.ru_utime.tv_usec);
    printf("系统 CPU: %ld.%06ld s\n", ru.ru_stime.tv_sec, ru.ru_stime.tv_usec);
    printf("最大 RSS: %ld KB\n", ru.ru_maxrss);
    printf("页面错误: soft=%ld hard=%ld\n", ru.ru_minflt, ru.ru_majflt);
    printf("自愿切换: %ld, 非自愿: %ld\n", ru.ru_nvcsw, ru.ru_nivcsw);
    return 0;
}
```
