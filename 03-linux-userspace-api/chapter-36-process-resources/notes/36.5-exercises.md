# 36.5 Exercises

> 本章：[TLPI 第 36 章 — Process Resources](../README.md)

## 练习题

### 练习 1：设置资源限制

编写程序，设置 RLIMIT_NOFILE 和 RLIMIT_MEMLOCK 为较大值，打印设置前后的值。

### 练习 2：CPU 使用监控

使用 `getrusage()` 编写程序，测量一段代码的用户 CPU 时间、系统 CPU 时间和页错误数。

### 练习 3：限制文件写入大小

设置 RLIMIT_FSIZE 为 1024 字节，然后尝试写入超过限制的文件，观察行为。

## 参考答案

### 练习 1 参考代码

```c
#include <sys/resource.h>
#include <stdio.h>

int main(void) {
    struct rlimit rl;

    /* 打印原始值 */
    getrlimit(RLIMIT_NOFILE, &rl);
    printf("NOFILE: before soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    /* 设置 */
    rl.rlim_cur = 1000000;
    rl.rlim_max = 1000000;
    if (setrlimit(RLIMIT_NOFILE, &rl) != 0) perror("setrlimit NOFILE");

    getrlimit(RLIMIT_NOFILE, &rl);
    printf("NOFILE: after  soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    /* MEMLOCK */
    getrlimit(RLIMIT_MEMLOCK, &rl);
    printf("MEMLOCK: before soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);

    rl.rlim_cur = RLIM_INFINITY;
    rl.rlim_max = RLIM_INFINITY;
    if (setrlimit(RLIMIT_MEMLOCK, &rl) != 0) perror("setrlimit MEMLOCK");

    getrlimit(RLIMIT_MEMLOCK, &rl);
    printf("MEMLOCK: after  soft=%ld hard=%ld\n",
           (long)rl.rlim_cur, (long)rl.rlim_max);
    return 0;
}
```

### 练习 2 参考代码

```c
#include <sys/resource.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    struct rusage before, after;
    getrusage(RUSAGE_SELF, &before);

    /* 待测代码 */
    volatile long sum = 0;
    for (long i = 0; i < 100000000L; i++) sum += i;

    getrusage(RUSAGE_SELF, &after);

    double utime = (after.ru_utime.tv_sec - before.ru_utime.tv_sec)
                 + (after.ru_utime.tv_usec - before.ru_utime.tv_usec) / 1e6;
    double stime = (after.ru_stime.tv_sec - before.ru_stime.tv_sec)
                 + (after.ru_stime.tv_usec - before.ru_stime.tv_usec) / 1e6;

    printf("User CPU:   %.3f s\n", utime);
    printf("System CPU:  %.3f s\n", stime);
    printf("Major faults: %ld → %ld (delta %ld)\n",
           before.ru_majflt, after.ru_majflt,
           after.ru_majflt - before.ru_majflt);
    printf("Minor faults: %ld → %ld (delta %ld)\n",
           before.ru_minflt, after.ru_minflt,
           after.ru_minflt - before.ru_minflt);
    printf("Voluntary switches:   %ld → %ld\n",
           before.ru_nvcsw, after.ru_nvcsw);
    printf("Involuntary switches: %ld → %ld\n",
           before.ru_nivcsw, after.ru_nivcsw);
    printf("Max RSS: %ld KB\n", after.ru_maxrss);
    return 0;
}
```

### 练习 3 答案

设置 RLIMIT_FSIZE=1024 后：
- `write()` 写入超过 1024 字节时返回 -1，errno=EFBIG
- 或内核发送 SIGXFSZ 信号（如果信号未被屏蔽）
- 默认 SIGXFSZ 终止进程

```c
struct rlimit rl = { .rlim_cur = 1024, .rlim_max = 1024 };
setrlimit(RLIMIT_FSIZE, &rl);

int fd = open("test.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
char buf[2048];
memset(buf, 'x', sizeof(buf));
ssize_t n = write(fd, buf, sizeof(buf));
if (n == -1) perror("write");  /* EFBIG */
```

## HFT / 嵌入式关联

- **资源监控**：HFT 监控页面读取 getrusage 数据展示 CPU/内存/页错误
- **上下文切换**：高 nivcsw → 需要更好的 CPU 隔离
- **页错误**：高 majflt → 需要 mlockall
- **嵌入式**：限制资源防止失控进程拖垮系统
