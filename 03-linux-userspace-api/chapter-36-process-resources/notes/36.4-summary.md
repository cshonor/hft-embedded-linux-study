# 36.4 Summary

> 本章：[TLPI 第 36 章 — Process Resources](../README.md)

## 本章回顾

### 资源限制 API

| 函数 | 说明 |
|------|------|
| `getrlimit(res, *rlim)` | 获取限制 |
| `setrlimit(res, *rlim)` | 设置限制 |
| `prlimit(pid, res, *new, *old)` | 获取+设置（Linux 2.6.36+） |
| `getrusage(who, *usage)` | 获取资源使用量 |
| `sysinfo(*info)` | 系统级统计 |

### 资源限制速查

| 限制 | 含义 | 超限后果 |
|------|------|---------|
| `RLIMIT_AS` | 虚拟内存 | mmap/brk 失败 (ENOMEM) |
| `RLIMIT_CORE` | core 文件大小 | 不生成 core |
| `RLIMIT_CPU` | CPU 秒数 | SIGXCPU → SIGKILL |
| `RLIMIT_DATA` | 数据段 | brk 失败 |
| `RLIMIT_FSIZE` | 文件大小 | SIGXFSZ / write 失败 |
| `RLIMIT_NOFILE` | fd 数 | open/socket 失败 (EMFILE) |
| `RLIMIT_NPROC` | 进程/线程数 | fork 失败 (EAGAIN) |
| `RLIMIT_STACK` | 栈大小 | 栈溢出 |
| `RLIMIT_MEMLOCK` | mlock | mlock 失败 (EPERM) |
| `RLIMIT_RTPRIO` | 实时优先级上限 | sched_setscheduler 失败 |
| `RLIMIT_RTTIME` | 实时 CPU 时间 | SIGXCPU |

### getrusage

```c
struct rusage {
    struct timeval ru_utime;   /* 用户 CPU 时间 */
    struct timeval ru_stime;   /* 系统 CPU 时间 */
    long   ru_maxrss;          /* 最大 RSS (KB) */
    long   ru_minflt;         /* 软页错误 */
    long   ru_majflt;         /* 硬页错误 */
    long   ru_nvcsw;          /* 自愿上下文切换 */
    long   ru_nivcsw;         /* 非自愿上下文切换 */
    /* ... 更多字段 */
};
```

| who 参数 | 说明 |
|---------|------|
| `RUSAGE_SELF` | 当前进程 |
| `RUSAGE_CHILDREN` | 已等待的子进程 |
| `RUSAGE_THREAD` | 当前线程（Linux 特有） |

## HFT / 嵌入式关联

- **NOFILE/MEMLOCK/RTPRIO**：HFT 必须调高的三个限制
- **getrusage**：HFT 监控 CPU 使用、页错误、上下文切换次数
- **ru_nivcsw**：非自愿切换次数高 → 被其他进程抢占，需隔离核心
- **ru_majflt**：硬页错误多 → 内存被换出，需 mlockall
- **嵌入式**：受限系统用 RLIMIT 防止内存/CPU 失控

## 衔接

- **Ch38** 安全/特权 — `setrlimit(RLIMIT_CORE, 0)` 防信息泄露
- **Ch35** 调度策略 — RLIMIT_RTPRIO 与 SCHED_FIFO 配合
- **Ch50** 虚拟内存 — RLIMIT_AS 与 mmap/brk

## 代码自测

<details>
<summary>1. RLIMIT_NPROC 限制的是进程数还是线程数？</summary>

两者都限制。Linux 中线程也是通过 `clone()` 创建的轻量级进程，RLIMIT_NPROC 限制的是用户能创建的进程（包括线程）总数。当 fork 或 pthread_create 超过限制时，返回 EAGAIN。注意这是每用户限制，不是每进程限制。
</details>

<details>
<summary>2. getrusage(RUSAGE_THREAD) 返回什么？</summary>

返回当前线程（而非进程）的资源使用。`ru_utime` 和 `ru_stime` 是该线程的 CPU 时间，`ru_nvcsw` 和 `ru_nivcsw` 是该线程的上下文切换次数。这是 Linux 特有扩展，用于多线程程序中分析单个线程的资源消耗。
</details>
