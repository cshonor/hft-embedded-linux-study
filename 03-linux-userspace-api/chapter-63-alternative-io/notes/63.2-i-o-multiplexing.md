## 要点

```c
select(nfds, &rfds, &wfds, &efds, &tv);  /* nfds = maxfd+1 */
poll(fds, nfds, timeout_ms);
```

| | select | poll |
|--|--------|------|
| 上限 | `FD_SETSIZE`(~1024) | 无硬上限 |
| 集合 | 每次重填 `fd_set` | `events`/`revents` 分离 |
| 代价 | 拷贝+线性扫 | 仍拷贝+线性扫 |

`POLLIN` 可读；`POLLOUT` 可写；`POLLHUP` 挂断（TCP FIN 常伴可读，`recv`→0）。  
timeout：NULL/负=永久；0=立即；>0=限时。

## 常见陷阱

1. **SIGPIPE 未处理**

```c
send(fd, buf, n, 0);  /* 对端关闭 → SIGPIPE */
send(fd, buf, n, MSG_NOSIGNAL);  /* 安全 */
```

向已关闭连接的 socket 写数据触发 SIGPIPE。用 MSG_NOSIGNAL 或忽略 SIGPIPE。

2. **TIME_WAIT 导致端口复用失败**

```c
bind(fd, (struct sockaddr*)&addr, len);
/* EADDRINUSE if port in TIME_WAIT */
/* 解决：SO_REUSEADDR */
```

服务端重启时端口可能还在 TIME_WAIT。用 SO_REUSEADDR 允许绑定。

3. **connect 返回值未检查**

```c
connect(sfd, (struct sockaddr*)&addr, sizeof(addr));
send(sfd, "data", 4, 0);  /* connect 可能失败! */
```

connect 可能失败（连接被拒绝、超时等）。不检查直接 send 会导致错误。

## 自测题

**题目 1（选择）：** TCP 服务端的 socket API 调用顺序是？
A. connect → send → recv
B. socket → bind → listen → accept
C. socket → connect → send
D. bind → socket → listen

<details>
<summary>参考答案</summary>

B。服务端：socket() → bind() → listen() → accept()。客户端：socket() → connect()。

</details>

**题目 2（判断）：** `bind` 可以绑定任意端口号。

<details>
<summary>参考答案</summary>

错误。1-1023 是特权端口，需要 root 权限。已占用的端口会返回 EADDRINUSE。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
struct sockaddr_in addr;
addr.sin_family = AF_INET;
addr.sin_port = 8080;  /* 没有用 htons! */
addr.sin_addr.s_addr = INADDR_ANY;
bind(fd, (struct sockaddr*)&addr, sizeof(addr));
```

<details>
<summary>参考答案</summary>

端口号没有用 htons 转换字节序。8080 = 0x1F90，在小端机器上变成 0x901F = 36895。应该 `addr.sin_port = htons(8080);`

</details>

**题目 4（应用）：** 写代码创建 TCP 服务端 socket 并监听。

<details>
<summary>参考答案</summary>

```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
int opt = 1;
setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port = htons(8080);
addr.sin_addr.s_addr = INADDR_ANY;
bind(sfd, (struct sockaddr*)&addr, sizeof(addr));
listen(sfd, 128);
```

</details>

## 代码示例

```c

/* select vs poll vs epoll 性能对比 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/select.h>
#include <poll.h>
#include <sys/epoll.h>

int main(void) {
    /* --- select: 固定大小位图 --- */
    fd_set rfds;
    FD_ZERO(&rfds);
    FD_SET(STDIN_FILENO, &rfds);
    struct timeval tv = { .tv_sec = 0, .tv_usec = 100 };
    select(STDIN_FILENO + 1, &rfds, NULL, NULL, &tv);
    printf("select: FD_SETSIZE=%d, uses bitmask (fixed size)\n", FD_SETSIZE);

    /* --- poll: 动态数组 --- */
    struct pollfd pfds[1];
    pfds[0].fd = STDIN_FILENO;
    pfds[0].events = POLLIN;
    poll(pfds, 1, 100);
    printf("poll: nfds=1, uses struct array (dynamic)\n");

    /* --- epoll: 内核维护兴趣列表 --- */
    int epfd = epoll_create1(0);
    struct epoll_event ev = { .events = EPOLLIN, .data.fd = STDIN_FILENO };
    epoll_ctl(epfd, EPOLL_CTL_ADD, STDIN_FILENO, &ev);
    struct epoll_event events[4];
    epoll_wait(epfd, events, 4, 100);
    printf("epoll: O(1) per event, kernel-managed interest list\n");

    printf("\n=== Comparison ===\n");
    printf("select: O(n) scan, FD_SETSIZE limit, bitmask copy each call\n");
    printf("poll:   O(n) scan, no limit, struct array each call\n");
    printf("epoll:  O(1) ready events, no limit, kernel state persists\n");

    close(epfd);
    return 0;
}

```
