# 63.1 五模型（读 socket 两阶段：就绪 → 拷到用户态）

## 本节讲什么

信号驱动：只报「就绪」。AIO：拷贝也由内核做完。 ---

---

## 要点

| 模型 | 要点 |
|------|------|
| **阻塞** | `read` 睡到拷完；编码简；单线程难多 fd |
| **非阻塞** | 未就绪 → `EAGAIN`；纯轮询空转 CPU |
| **多路复用** | select/poll/epoll：一线程等**任一** fd 就绪再读写 |
| **信号驱动** | `O_ASYNC`+`SIGIO`；难辨多 fd；网络少用 |
| **POSIX AIO** | 内核完成就绪+拷贝再通知；Linux 对 socket 弱 |

信号驱动：只报「就绪」。AIO：拷贝也由内核做完。

## 常见陷阱

1. **SIGPIPE**

```c
send(fd, buf, n, 0);  /* 对端关闭 → SIGPIPE */
send(fd, buf, n, MSG_NOSIGNAL);  /* 安全 */
```

向已关闭连接的 socket 写数据触发 SIGPIPE。用 MSG_NOSIGNAL 或忽略 SIGPIPE。

2. **TIME_WAIT**

```c
bind(fd, (struct sockaddr*)&addr, len);
/* EADDRINUSE if port in TIME_WAIT */
```

服务端重启时端口可能还在 TIME_WAIT。用 SO_REUSEADDR 允许绑定。

3. **accept 返回值未检查**

```c
int cfd = accept(lfd, NULL, NULL);
/* cfd 可能 -1 (EMFILE/ENFILE) */
```

accept 可能因 fd 耗尽返回 -1。不检查直接用会导致后续操作失败。

## 自测题

**题目 1（选择）：** `listen()` 的第二个参数 backlog 表示什么？
A. 最大连接数
B. 等待 accept 的队列长度
C. 缓冲区大小
D. 超时秒数

<details>
<summary>参考答案</summary>

B。backlog 是已完成连接但尚未 accept 的队列长度。超过后新连接可能被拒绝。

</details>

**题目 2（判断）：** `bind` 可以绑定任意端口号。

<details>
<summary>参考答案</summary>

错误。1-1023 是特权端口，需要 root 权限。已占用的端口会返回 EADDRINUSE。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
connect(sfd, (struct sockaddr*)&addr, sizeof(addr));
send(sfd, "data", 4, 0);
```

<details>
<summary>参考答案</summary>

没有检查 connect 返回值。connect 可能失败（连接被拒绝、超时等），不检查直接 send 会导致错误。

</details>

**题目 4（应用）：** 写代码创建 TCP 服务端 socket 并监听。

<details>
<summary>参考答案</summary>

```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
int opt = 1;
setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port = htons(8080);
addr.sin_addr.s_addr = INADDR_ANY;
bind(sfd, (struct sockaddr*)&addr, sizeof(addr));
listen(sfd, 128);
```

</details>

## 代码示例

```c

/* 非阻塞 socket + epoll */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/socket.h>
#include <sys/epoll.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <errno.h>

int main(void) {
    int sfd = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
    struct sockaddr_in addr = { .sin_family = AF_INET, .sin_port = htons(9988) };
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    int opt = 1; setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    bind(sfd, (struct sockaddr *)&addr, sizeof(addr));
    listen(sfd, 5);

    /* 创建 epoll */
    int epfd = epoll_create1(0);
    struct epoll_event ev = { .events = EPOLLIN, .data.fd = sfd };
    epoll_ctl(epfd, EPOLL_CTL_ADD, sfd, &ev);

    printf("non-blocking server with epoll on port 9988\n");

    struct epoll_event events[8];
    int n = epoll_wait(epfd, events, 8, 3000);
    if (n > 0) {
        for (int i = 0; i < n; i++) {
            if (events[i].data.fd == sfd) {
                int cfd = accept(sfd, NULL, NULL);
                if (cfd >= 0) {
                    printf("accepted: fd=%d\n", cfd);
                    /* 设置非阻塞 + 加入 epoll */
                    int flags = fcntl(cfd, F_GETFL, 0);
                    fcntl(cfd, F_SETFL, flags | O_NONBLOCK);
                    ev.events = EPOLLIN | EPOLLET;  /* 边缘触发 */
                    ev.data.fd = cfd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, cfd, &ev);
                }
            } else {
                char buf[64];
                ssize_t len;
                while ((len = recv(events[i].data.fd, buf, sizeof(buf), 0)) > 0) {
                    buf[len] = '\0';
                    printf("recv from fd=%d: %s\n", events[i].data.fd, buf);
                }
                if (len == 0 || (len < 0 && errno != EAGAIN)) {
                    close(events[i].data.fd);
                    printf("closed fd=%d\n", events[i].data.fd);
                }
            }
        }
    } else {
        printf("no events (timeout)\n");
    }

    close(epfd);
    close(sfd);
    return 0;
}

```
