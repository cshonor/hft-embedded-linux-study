# 13-iobench — 文件 I/O 缓冲基准

**触发**：学完 `chapter-13-file-io-buffering` 笔记后开写。
**前置章节**：Ch04–05（通用文件 I/O）、Ch13（缓冲）。

## 目标

用三种方式拷贝同一个大文件（建议 200MB+），实测并解释性能差异：

1. `read()/write()` 1 字节为单位
2. `read()/write()` 块大小可调（1K/4K/64K/1M）
3. stdio（`fgetc()/fputc()` 与 `fread()/fwrite()`）

## 需求清单

- [ ] 块大小可由命令行参数指定
- [ ] 每种方式打印总耗时与有效吞吐（MB/s）
- [ ] 对比后用一句话在输出里解释差异来源（syscall 次数 × 内核缓冲）

## 验收标准

- 三种方式都能完整拷贝且 `cmp` 校验一致
- 结论能解释：为什么 1 字节 read/write 慢几个数量级、stdio 如何追平

## HFT / 嵌入式关联

行情落地盘、日志写入的块大小选择直接由本实验的数字决定；O_DIRECT 与对齐问题（Ch13 习题延伸）后续在 shmring 落盘路径里复用。
