# 54-shmring — SHM 无锁环形缓冲 + 延迟基准（P2）

**触发**：学完 Ch49–55（内存映射、POSIX IPC、文件锁）笔记后开写。
**关键前置回补**：Ch35（SCHED_FIFO、sched_setaffinity）、Ch50（mlock）。

## 目标

一个生产者进程、一个消费者进程，通过 POSIX 共享内存上的无锁 SPSC 环形缓冲互发带时间戳的消息，测量单向延迟分布。

## 需求清单

- [ ] `shm_open` + `mmap` 建共享区，`mlock` 锁页防缺页抖动
- [ ] SPSC ring：head/tail 用 `__atomic`（acquire/release），缓存行 64B 对齐防伪共享
- [ ] `sem_post/sem_wait`（Ch53）做「有数据可收」的睡眠唤醒，且可切换为纯自旋模式
- [ ] 两种模式可配：轮询（最低延迟）vs 信号量（省 CPU），各测一组
- [ ] 采集 ≥100 万条样本，输出 P50/P90/P99/P99.9（单位 ns）
- [ ] 同机对比基线：同尺寸数据的 pipe 往返延迟

## 验收标准

- Pi 5 上：自旋模式单向 P99 落在个位数 µs 以内，且两模式差异、与 pipe 的差异都写成表格进本 README
- 长跑 10 分钟无丢消息、无僵尸、内存占用稳定

## HFT / 嵌入式关联

这就是行情解码进程 → 策略进程之间真实在用的通道；本项目的 ring buffer 代码会被 63-t2t 直接复用。
