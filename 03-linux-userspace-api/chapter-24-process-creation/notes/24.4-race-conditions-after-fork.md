## 本节讲什么

父子指向同一打开文件描述 → **共享文件偏移**与状态标志。 策略：用完 `close`；`FD_CLOEXEC` 只在 **exec** 时关，**fork 不会**因它关 fd。 Demo：[`code/fork_fd_offset.c`](../code/fork_fd_offset.c)

## 要点

父子指向同一打开文件描述 → **共享文件偏移**与状态标志。  
策略：用完 `close`；`FD_CLOEXEC` 只在 **exec** 时关，**fork 不会**因它关 fd。

Demo：[`code/fork_fd_offset.c`](../code/fork_fd_offset.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 父子共享 fd 偏移，多进程写同一文件需同步或各自 close |
| HFT | fork 后父子共享 socket 偏移会竞态，立即 exec 或明确分工规避 |

## 代码示例

```c
#include <unistd.h>
#include <fcntl.h>
#include <stdio.h>
int main(void) {
    int fd = open("/tmp/fork_fd.txt", O_CREAT | O_RDWR, 0644);
    write(fd, "before", 6);

    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程继承 fd, 指向同一个打开文件描述 (共享偏移) */
        write(fd, "_child", 6);
        printf("子: fd=%d\n", fd);
        close(fd);
        _exit(0);
    }
    wait(NULL);
    write(fd, "_parent", 7);
    printf("父: fd=%d (与子共享偏移)\n", fd);
    close(fd);
    return 0;
}
```
