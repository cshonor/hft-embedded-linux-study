## 本节讲什么

`printf` 无 `\n`（全缓冲时）→ 用户缓冲未刷 → fork **复制缓冲** → 父子各打一份。 **fork 前 `fflush(NULL)` / `fflush(stdout)`。** Demo：[`code/fork_stdio_buf.c`](../code/fork_stdio_buf.c)

---

## 要点

`printf` 无 `\n`（全缓冲时）→ 用户缓冲未刷 → fork **复制缓冲** → 父子各打一份。  
**fork 前 `fflush(NULL)` / `fflush(stdout)`。**

Demo：[`code/fork_stdio_buf.c`](../code/fork_stdio_buf.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | fork 前 fflush，否则缓冲复制导致重复输出 |
| HFT | fork 前 fflush 避免日志重复/污染，HFT 日志完整性关键 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    printf("before fork (未 flush)");
    pid_t pid = fork();
    if (pid == 0) {
        printf("child\n");
        _exit(0);
    }
    wait(NULL);
    printf("parent\n");
    fflush(stdout);
    /* 问题: fork 时 stdout 缓冲区被复制
     * "before fork" 可能被输出两次!
     * 解决: fork 前 fflush(stdout) */
    return 0;
}
```
