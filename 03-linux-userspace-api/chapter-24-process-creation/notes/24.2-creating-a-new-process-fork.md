## 要点

fork 瞬间共享页（标只读）；一方写入 → 缺页 → 内核复制该页。  
逻辑上地址空间独立；COW 只是加速。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | Copy-On-Write（COW） 在嵌入式系统的应用场景 |
| HFT | Copy-On-Write（COW） 对低延迟和性能的影响 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int global = 100;  /* 全局变量, fork 后共享页 (COW) */
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        global = 200;  /* 子进程写入 → 触发 COW → 复制该页 */
        printf("子: global=%d\n", global);  /* 200 */
        _exit(0);
    } else {
        wait(NULL);
        printf("父: global=%d (不受子修改影响)\n", global);  /* 100 */
    }
    return 0;
}
```
