## 要点

```c
#include <unistd.h>
pid_t fork(void);
```

| 返回 | 含义 |
|------|------|
| `> 0` | 父进程：子 PID |
| `0` | 子进程 |
| `-1` | 失败 |

Demo：[`code/fork_basic.c`](../code/fork_basic.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | fork 复制出子进程（watchdog/守护），父子按返回值三态分流 |
| HFT | fork 页表复制开销是启动延迟预算大头；热路径避免频繁 fork、改用线程池 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid < 0) { perror("fork"); return 1; }
    if (pid == 0) {
        printf("子进程: PID=%d, PPID=%d\n", getpid(), getppid());
        _exit(0);
    } else {
        printf("父进程: PID=%d, 子PID=%d\n", getpid(), pid);
        wait(NULL);
    }
    return 0;
}
```
