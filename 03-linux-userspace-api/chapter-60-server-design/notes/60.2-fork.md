---

## 要点

```
accept → fork
  子: close(listen); handle; close(conn); _exit
  父: close(conn); 继续 accept
```

| 要点 | |
|------|--|
| fd 引用 | fork 后 +1；双方关无用端 |
| 僵尸 | `SIGCHLD` 里循环 `waitpid(-1,NULL,WNOHANG)` |
| 隔离 | 强；崩溃不易拖垮主服务 |
| 代价 | fork/页表贵；海量连接受限 |

Demo：[`code/fork_sv.c`](./code/fork_sv.c)
