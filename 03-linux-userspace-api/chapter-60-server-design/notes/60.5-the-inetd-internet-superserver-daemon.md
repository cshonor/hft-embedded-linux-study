# 60.5 事件驱动（select/poll 入门）

## 本节讲什么

单线程监视 listen + 多 conn 的可读/可写；无 per-conn 线程。 高并发基础（C10K）；状态机复杂；select 有 fd 上限；CPU 密集堵事件环。 **epoll** 见后文 Ch63 Alternative I/O。

---

## 要点

单线程监视 listen + 多 conn 的可读/可写；无 per-conn 线程。  
高并发基础（C10K）；状态机复杂；select 有 fd 上限；CPU 密集堵事件环。  
**epoll** 见后文 Ch63 Alternative I/O。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 单线程多连接无 per-conn 线程，嵌入式高并发（C10K）基础；select fd 上限、CPU 密集堵事件环 |
| HFT | HFT 首选事件驱动——单线程 epoll 监听多连接，零线程切换开销；select 有 FD_SETSIZE 上限且 O(n) 扫描，生产用 epoll（Ch63） |

## 代码示例

```c

/* I/O 多路复用服务器：select + poll */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <sys/select.h>

int main(void) {
    int sfd = socket(AF_INET, SOCK_STREAM, 0);
    struct sockaddr_in addr = { .sin_family = AF_INET, .sin_port = htons(9992) };
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    int opt = 1; setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    bind(sfd, (struct sockaddr *)&addr, sizeof(addr));
    listen(sfd, 5);

    printf("select server: port 9992\n");

    fd_set readfds;
    int clients[FD_SETSIZE];
    for (int i = 0; i < FD_SETSIZE; i++) clients[i] = -1;
    int maxfd = sfd;

    for (int loop = 0; loop < 3; loop++) {
        FD_ZERO(&readfds);
        FD_SET(sfd, &readfds);

        for (int i = 0; i < FD_SETSIZE; i++) {
            if (clients[i] > 0) {
                FD_SET(clients[i], &readfds);
                if (clients[i] > maxfd) maxfd = clients[i];
            }
        }

        struct timeval tv = { .tv_sec = 5, .tv_usec = 0 };
        int n = select(maxfd + 1, &readfds, NULL, NULL, &tv);
        if (n <= 0) { printf("select timeout\n"); break; }

        if (FD_ISSET(sfd, &readfds)) {
            int cfd = accept(sfd, NULL, NULL);
            printf("new client: fd=%d\n", cfd);
            for (int i = 0; i < FD_SETSIZE; i++) {
                if (clients[i] < 0) { clients[i] = cfd; break; }
            }
        }

        for (int i = 0; i < FD_SETSIZE; i++) {
            if (clients[i] > 0 && FD_ISSET(clients[i], &readfds)) {
                char buf[64];
                ssize_t len = recv(clients[i], buf, sizeof(buf)-1, 0);
                if (len <= 0) { close(clients[i]); clients[i] = -1; }
                else { buf[len]='\0'; printf("recv: %s\n", buf); }
            }
        }
    }

    close(sfd);
    return 0;
}

```
