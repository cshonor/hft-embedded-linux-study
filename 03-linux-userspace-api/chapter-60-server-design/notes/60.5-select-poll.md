## 本节讲什么

单线程监视 listen + 多 conn 的可读/可写；无 per-conn 线程。 高并发基础（C10K）；状态机复杂；select 有 fd 上限；CPU 密集堵事件环。 **epoll** 见后文 [Ch63 Alternative I/O](../chapter-63-alternative-io/notes.md)。

---

## 要点

单线程监视 listen + 多 conn 的可读/可写；无 per-conn 线程。
