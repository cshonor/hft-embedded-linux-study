## 要点

| 模型 | 并发 | 隔离 | 开销 | 难度 |
|------|------|------|------|------|
| 迭代 | 无 | — | 最低 | 最简 |
| fork | 中 | 强 | 高 | 中 |
| pthread | 中高 | 弱 | 中 | 中高 |
| select/poll | 高 | 单进程 | 低 | 高 |

选型：稳 → fork；共享状态中等并发 → 线程/池；高连接 → 多路复用（生产常 epoll）。
