## 要点

| 问题 | 处理 |
|------|------|
| `Address already in use` / TIME_WAIT | `SO_REUSEADDR`（与 `SO_REUSEPORT` 不同） |
| 惊群 | 多进程堵同一 accept 时全醒；现代内核 listen 侧已改善 |
| fd 耗尽 | `ulimit -n` / `RLIMIT_NOFILE` |
| 慢客户端 | 迭代最惨；事件环须超时踢闲置 |

## 代码示例

```c

/* 服务器设计要点总结 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/socket.h>

int main(void) {
    printf("=== Server Design Summary ===\n\n");

    printf("1. Iterative: accept→handle→close→loop\n");
    printf("   pros: simple, no overhead\n");
    printf("   cons: one client at a time\n\n");

    printf("2. Fork per connection:\n");
    printf("   pros: isolation, simple model\n");
    printf("   cons: fork overhead, PID limits\n\n");

    printf("3. Thread per connection:\n");
    printf("   pros: lower overhead than fork\n");
    printf("   cons: shared state, race conditions\n\n");

    printf("4. I/O multiplexing (select/poll/epoll):\n");
    printf("   pros: single thread, many connections\n");
    printf("   cons: complexity, non-blocking I/O\n\n");

    /* SO_REUSEADDR: 服务器重启时快速绑定 */
    int fd = socket(AF_INET, SOCK_STREAM, 0);
    int opt = 1;
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    printf("SO_REUSEADDR: allows quick restart after crash\n");
    close(fd);
    return 0;
}

```
