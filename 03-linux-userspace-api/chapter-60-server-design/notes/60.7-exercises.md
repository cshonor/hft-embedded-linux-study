## 本节讲什么

选型：稳 → fork；共享状态中等并发 → 线程/池；高连接 → 多路复用（生产常 epoll）。 ---

---

## 要点

| 模型 | 并发 | 隔离 | 开销 | 难度 |
|------|------|------|------|------|
| 迭代 | 无 | — | 最低 | 最简 |
| fork | 中 | 强 | 高 | 中 |
| pthread | 中高 | 弱 | 中 | 中高 |
| select/poll | 高 | 单进程 | 低 | 高 |

选型：稳 → fork；共享状态中等并发 → 线程/池；高连接 → 多路复用（生产常 epoll）。

## 代码示例

```c

/* 各种服务器模型对比表 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/socket.h>
#include <sys/wait.h>
#include <pthread.h>

int main(void) {
    printf("=== Server Model Comparison ===\n\n");

    printf("| Model       | Concurrency | Overhead | Isolation | Max Conn |\n");
    printf("|-------------|-------------|----------|-----------|----------|\n");
    printf("| Iterative   | 1           | none     | N/A       | 1        |\n");
    printf("| Fork        | per-conn    | high     | process   | ~1000    |\n");
    printf("| Thread      | per-conn    | medium   | shared    | ~10000   |\n");
    printf("| select      | multiplex   | low      | single    | FD_SETSIZE|\n");
    printf("| poll        | multiplex   | low      | single    | ulimit   |\n");
    printf("| epoll       | multiplex   | lowest   | single    | ~100000+ |\n\n");

    /* 演示获取 fd 上限 */
    printf("FD limit (ulimit -n): %ld\n", sysconf(_SC_OPEN_MAX));
    printf("FD_SETSIZE: %d\n", FD_SETSIZE);

    /* 推荐选择 */
    printf("\nRecommendation:\n");
    printf("  < 100 connections:    iterative or fork\n");
    printf("  100-10000:            thread or poll\n");
    printf("  > 10000 (C10K+):      epoll (edge-triggered)\n");
    return 0;
}

```
