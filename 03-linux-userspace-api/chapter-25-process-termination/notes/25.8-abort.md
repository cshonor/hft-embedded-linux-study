## 本节讲什么

发 `SIGABRT`；默认可 core；标准要求最终仍终止（即使用户 handler）。 ---

---

## 要点

发 `SIGABRT`；默认可 core；标准要求最终仍终止（即使用户 handler）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `abort` 在嵌入式系统的应用场景 |
| HFT | `abort` 对低延迟和性能的影响 |

## 代码示例

```c
#include <stdlib.h>
#include <signal.h>
#include <stdio.h>
int main(void) {
    printf("abort() → 发送 SIGABRT → 进程终止 + core dump\n");
    /* abort() 等价于: raise(SIGABRT) */
    /* 即使捕获 SIGABRT, abort 仍会确保终止 */
    /* abort: 异常终止, 不调 atexit, 但 flush stdio */
    return 0;
}
```
