## 要点

子先退、父未 wait → zombie。父退则由 init/systemd 收养并回收。

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) { _exit(42); }
    int status;
    wait(&status);
    printf("子进程退出码: %d\n", WEXITSTATUS(status));
    return 0;
}
```
