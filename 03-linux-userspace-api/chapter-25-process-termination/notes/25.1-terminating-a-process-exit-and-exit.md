## 本节讲什么

最终都进内核销毁路径。 ---

---

## 要点

| 类型 | 方式 |
|------|------|
| **正常** | `main` return · `exit` · `_exit` / `_Exit` |
| **异常** | 致命信号 · `abort()` → `SIGABRT` |

最终都进内核销毁路径。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 正常（main return/exit）vs 异常（abort/信号）分流，daemon 需区分清理路径 |
| HFT | 异常终止绕过清理直进内核，HFT 需区分退出类型并快速重启 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("子进程正常退出\n");
        _exit(0);  /* 正常退出 */
    }
    int status;
    waitpid(pid, &status, 0);
    if (WIFEXITED(status)) printf("正常退出: code=%d\n", WEXITSTATUS(status));
    else if (WIFSIGNALED(status)) printf("被信号杀死: sig=%d\n", WTERMSIG(status));
    return 0;
}
```
