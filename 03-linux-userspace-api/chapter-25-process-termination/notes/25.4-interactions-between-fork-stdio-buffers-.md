## 要点

仅**低 8 位**有效（0–255）。  
`0` / `EXIT_SUCCESS` · 非 0 / `EXIT_FAILURE`。

父用 `wait`/`waitpid` 取状态：

| 宏 | 含义 |
|----|------|
| `WIFEXITED` | 正常终止 |
| `WEXITSTATUS` | 退出码（仅当 WIFEXITED） |
| （信号杀） | `WIFSIGNALED` 等；勿读 WEXITSTATUS |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 退出状态 在嵌入式系统的应用场景 |
| HFT | 退出状态 对低延迟和性能的影响 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("子进程运行中...\n");
        sleep(2);
        _exit(0);
    }
    /* 子进程退出但父进程还没 wait → 变僵尸 (Z 状态) */
    sleep(1);
    printf("查看: ps -p %d -o stat,pid (应为 Z)\n", pid);
    sleep(3);
    wait(NULL);  /* 回收僵尸 */
    printf("已回收\n");
    return 0;
}
```
