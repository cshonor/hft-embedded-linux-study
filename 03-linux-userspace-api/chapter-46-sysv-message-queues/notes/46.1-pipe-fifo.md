## 要点

| | Pipe/FIFO | SysV mq |
|--|-----------|---------|
| 模型 | 字节流 | **整条消息** |
| 筛选 | 无 | **`mtype`** |
| 句柄 | fd → epoll | msqid → **不能** |
| 持久 | 进程持久 | **内核持久** |
