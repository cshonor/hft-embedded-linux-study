## 本节讲什么

数据在内核缓冲，不落盘。 ---

## 要点

| | Pipe/FIFO | SysV mq |
|--|-----------|---------|
| 模型 | 字节流 | **整条消息** |
| 筛选 | 无 | **`mtype`** |
| 句柄 | fd → epoll | msqid → **不能** |
| 持久 | 进程持久 | **内核持久** |

数据在内核缓冲，不落盘。

## 代码示例

```c
#include <stdio.h>
#include <sys/msg.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>
/* 消息队列 vs 管道: 有消息边界 + 类型过滤 */
int main(void) {
    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);

    /* 消息队列: 每条消息有类型, 可以按类型过滤接收 */
    struct { long mtype; char mtext[64]; } msg;

    /* 发送不同类型的消息 */
    msg.mtype = 1; strcpy(msg.mtext, "urgent"); msgsnd(msqid, &msg, 7, 0);
    msg.mtype = 2; strcpy(msg.mtext, "normal"); msgsnd(msqid, &msg, 7, 0);
    msg.mtype = 3; strcpy(msg.mtext, "low");    msgsnd(msqid, &msg, 3, 0);

    /* 管道是字节流, 没有边界; 消息队列有边界 */
    printf("Messages sent with types 1, 2, 3\n");

    /* 按类型接收: 只收类型 2 */
    msgrcv(msqid, &msg, sizeof(msg.mtext), 2, 0);
    printf("Received type 2: %s\n", msg.mtext);

    /* 接收所有类型 (msgtyp=0: 按顺序) */
    msgrcv(msqid, &msg, sizeof(msg.mtext), 0, 0);
    printf("Received (FIFO): type=%ld text=%s\n", msg.mtype, msg.mtext);

    /* 接收类型 <= 3 的最大类型 */
    msgrcv(msqid, &msg, sizeof(msg.mtext), 3, 0);
    printf("Received type 3: %s\n", msg.mtext);

    msgctl(msqid, IPC_RMID, NULL);
    return 0;
}
```
