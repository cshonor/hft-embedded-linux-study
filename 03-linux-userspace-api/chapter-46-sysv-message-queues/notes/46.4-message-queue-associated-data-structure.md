# 46.4 Message Queue Associated Data Structure

> 本章：[TLPI 第 46 章](./README.md)

## 本节讲什么

System V 消息队列关联的 `msqid_ds` 结构，包含权限、时间戳和队列统计信息。通过 `msgctl(IPC_STAT)` 获取。

## 要点

### struct msqid_ds

```c
struct msqid_ds {
    struct ipc_perm msg_perm;   /* 权限 */
    time_t         msg_stime;   /* 最后 msgsnd 时间 */
    time_t         msg_rtime;   /* 最后 msgrcv 时间 */
    time_t         msg_ctime;   /* 最后 msgctl 修改时间 */
    unsigned long  msg_cbytes;  /* 当前队列字节数 */
    unsigned long  msg_qnum;   /* 当前消息数 */
    unsigned long  msg_qbytes;  /* 最大字节限制 */
    pid_t          msg_lspid;   /* 最后发送者 PID */
    pid_t          msg_lrpid;   /* 最后接收者 PID */
};
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `msg_perm` | ipc_perm | 权限和属主 |
| `msg_stime` | time_t | 最后 `msgsnd` 时间 |
| `msg_rtime` | time_t | 最后 `msgrcv` 时间 |
| `msg_ctime` | time_t | 最后 `msgctl` 修改时间 |
| `msg_cbytes` | unsigned long | 当前队列大小（字节） |
| `msg_qnum` | unsigned long | 当前消息数 |
| `msg_qbytes` | unsigned long | 队列最大字节限制 |
| `msg_lspid` | pid_t | 最后发送进程 PID |
| `msg_lrpid` | pid_t | 最后接收进程 PID |

### 监控指标

| 指标 | 计算方式 | 用途 |
|------|---------|------|
| 队列利用率 | `msg_cbytes / msg_qbytes` | 容量监控 |
| 消息积压 | `msg_qnum` | 消费者是否跟上 |
| 最后活跃 | `max(stime, rtime)` | 队列是否被使用 |
| 发送者/接收者 | `lspid`/`lrpid` | 审计 |

### 查看消息队列

```bash
ipcs -q
# ------ Message Queues --------
# key msqid owner perms used-bytes messages
# 0xabcd1234 0 hft 660 2048 10
```

## HFT / 嵌入式关联

- 监控消息积压：`msg_qnum` 过高表示消费者跟不上
- 队列容量告警：`msg_cbytes` 接近 `msg_qbytes`
- 嵌入式系统调试：`ipcs -q` 检查消息队列泄漏

## 代码示例

```c
#include <sys/msg.h>
#include <stdio.h>
#include <time.h>

void monitor_msgqueue(int msqid) {
    struct msqid_ds ds;
    if (msgctl(msqid, IPC_STAT, &ds) == -1) {
        perror("msgctl");
        return;
    }

    time_t now = time(NULL);
    double usage = (double)ds.msg_cbytes / ds.msg_qbytes * 100;

    printf("=== Message Queue %d ===\n", msqid);
    printf("Key:            0x%x\n", ds.msg_perm.__key);
    printf("Owner:          %d:%d\n", ds.msg_perm.uid, ds.msg_perm.gid);
    printf("Permissions:   %04o\n", ds.msg_perm.mode);
    printf("Messages:       %lu\n", ds.msg_qnum);
    printf("Bytes:          %lu / %lu (%.1f%%)\n",
           ds.msg_cbytes, ds.msg_qbytes, usage);
    printf("Last snd:       %s", ctime(&ds.msg_stime));
    printf("Last rcv:       %s", ctime(&ds.msg_rtime));
    printf("Last snd PID:   %d\n", ds.msg_lspid);
    printf("Last rcv PID:   %d\n", ds.msg_lrpid);

    if (ds.msg_qnum > 1000)
        printf("WARNING: %lu messages backlog!\n", ds.msg_qnum);
    if (usage > 80)
        printf("WARNING: queue %.1f%% full!\n", usage);
}
```

## 代码自测

<details>
<summary>msg_qbytes 为 0 意味着什么？</summary>

`msg_qbytes` 是队列最大字节限制，默认值由系统参数 `MSGMNB` 决定（通常 16384 字节）。如果设置为 0，队列不能存储任何消息，`msgsnd` 会立即返回 `EAGAIN`（队列满）。可以通过 `msgctl(IPC_SET)` 修改此限制（需要适当权限或 CAP_SYS_RESOURCE）。

</details>
