## 本节讲什么

多进程对同一队列 `msgrcv`：一条消息只被一个消费者拿走（简陋分发）。 缺陷：无 epoll、易泄漏、无原生超时、本机 only、`ftok` 坑。TLPI：**新项目少用 SysV mq**。 ---

---

## 要点

多进程对同一队列 `msgrcv`：一条消息只被一个消费者拿走（简陋分发）。  
缺陷：无 epoll、易泄漏、无原生超时、本机 only、`ftok` 坑。TLPI：**新项目少用 SysV mq**。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 多进程 msgrcv 一条消息只一消费者（简陋分发）；无 epoll/超时 |
| HFT | 无 epoll+内核拷贝，实时分发用 AF_UNIX 或 shm+队列；新项目少用 SysV mq |

## 代码示例

```c
#include <stdio.h>
#include <sys/msg.h>
#include <string.h>
/* 消息队列的缺陷与替代方案 */
int main(void) {
    /* 缺陷1: 消息大小有上限 (MSGMAX, 通常 8KB) */
    /* 缺陷2: 队列总容量有限 (MSGMNB, 通常 16KB) */
    /* 缺陷3: 内核持久, 容易泄漏 */
    /* 缺陷4: 无等待通知机制 (不像 POSIX mq 的 mq_notify) */
    /* 缺陷5: 性能不如管道/共享内存 (数据拷贝) */

    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);

    /* 测试消息大小限制 */
    struct { long mtype; char mtext[8192]; } msg;
    msg.mtype = 1;
    memset(msg.mtext, 'X', 8192);

    /* 尝试发送大消息 */
    if (msgsnd(msqid, &msg, 8192, IPC_NOWAIT) < 0)
        perror("msgsnd 8KB (may exceed MSGMAX)");

    /* 查看队列限制 */
    FILE *fp = fopen("/proc/sys/kernel/msgmax", "r");
    if (fp) {
        char buf[32];
        fgets(buf, sizeof(buf), fp);
        printf("MSGMAX = %s", buf);
        fclose(fp);
    }

    printf("\nBetter alternatives:\n");
    printf("  POSIX mq: mq_notify, per-process limits\n");
    printf("  Unix socket: message boundary + SCM_RIGHTS\n");
    printf("  Shared memory: for large data\n");

    msgctl(msqid, IPC_RMID, NULL);
    return 0;
}
```
