# 61.14 Summary

> 本章：[TLPI 第 61 章](./README.md)

## 本节讲什么

第 61 章总结：套接字高级主题，包括 tcpdump 抓包、socket 选项、accept 继承规则、TCP vs UDP 选择和高级特性。

## 要点

### 核心 API 总览

| API | 用途 |
|-----|------|
| `getsockopt()`/`setsockopt()` | 查询/设置套接字选项 |
| `accept4()` | accept + 原子设置标志 |
| `tcpdump` | 网络抓包分析 |
| `TCP_INFO` | 连接诊断信息 |

### 关键 socket 选项

| 选项 | 层级 | 用途 |
|------|------|------|
| `SO_REUSEADDR` | SOL_SOCKET | TIME_WAIT 地址重用 |
| `SO_REUSEPORT` | SOL_SOCKET | 多进程负载均衡 |
| `SO_KEEPALIVE` | SOL_SOCKET | 保活探测 |
| `SO_RCVBUF`/`SO_SNDBUF` | SOL_SOCKET | 缓冲区大小 |
| `SO_LINGER` | SOL_SOCKET | close() 行为 |
| `TCP_NODELAY` | IPPROTO_TCP | 禁用 Nagle |
| `TCP_CORK` | IPPROTO_TCP | 批量发送模式 |
| `TCP_QUICKACK` | IPPROTO_TCP | 禁用延迟 ACK |
| `TCP_FASTOPEN` | IPPROTO_TCP | 省一个 RTT |
| `SO_BUSY_POLL` | SOL_SOCKET | 网卡轮询 |

### accept() 继承规则速查

| 继承 | 不继承 |
|------|--------|
| SO_REUSEADDR | SO_RCVBUF/SO_SNDBUF |
| SO_KEEPALIVE | TCP_NODELAY |
| SO_OOBINLINE | TCP_CORK |
| SO_TYPE/SO_DOMAIN | SO_LINGER |
| 选项 | O_NONBLOCK（用 accept4） |

### TCP vs UDP 选择

| 需求 | 协议 |
|------|------|
| 可靠交付 | TCP |
| 低延迟广播 | UDP |
| 请求-响应 | TCP |
| 实时行情 | UDP 多播 |
| 交易订单 | TCP + NODELAY |

## HFT / 嵌入式关联

- 订单通道：TCP + `TCP_NODELAY` + `TCP_FASTOPEN` + 大缓冲区
- 行情通道：UDP 多播
- 服务器：`SO_REUSEPORT` + `accept4` + epoll
- 诊断：`TCP_INFO` 监控 RTT/重传，`tcpdump` 抓包分析
- 高级：`SO_BUSY_POLL` + `IP_TOS` 流量优先级

## 代码自测

<details>
<summary>本章涉及的三大类 socket 选项分别是什么？</summary>

1. **SOL_SOCKET** — 通用套接字选项：地址重用、保活、缓冲区、超时、linger 等
2. **IPPROTO_TCP** — TCP 协议特定选项：Nagle 控制、保活参数、Cork、FastOpen 等
3. **IPPROTO_IP** — IP 层选项：TOS/DSCP 标记、多播、透明代理等

</details>
