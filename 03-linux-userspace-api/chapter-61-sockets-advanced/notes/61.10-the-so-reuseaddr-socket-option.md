## 要点

如 `FIONREAD`：待读字节；TCP 不含 OOB；UDP=下一条报大小。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | FIONREAD 查待读字节，TCP 不含 OOB、UDP=下一条报大小；非阻塞读前先 FIONREAD 探数据量 |
| HFT | FIONREAD 是额外系统调用，热路径别用它预判——直接 recv 靠返回值判断；UDP 下 FIONREAD=下一条报大小可用于预分配缓冲 |

## 代码示例

```c

/* ioctl socket 操作：获取网络接口信息 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <net/if.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

int main(void) {
    int fd = socket(AF_INET, SOCK_DGRAM, 0);

    /* 获取接口列表 */
    struct ifconf ifc;
    char buf[1024];
    ifc.ifc_len = sizeof(buf);
    ifc.ifc_buf = buf;

    if (ioctl(fd, SIOCGIFCONF, &ifc) < 0) {
        perror("ioctl SIOCGIFCONF"); exit(1);
    }

    int nifs = ifc.ifc_len / sizeof(struct ifreq);
    printf("Network interfaces (%d):\n", nifs);

    for (int i = 0; i < nifs; i++) {
        struct ifreq *ifr = &ifc.ifc_req[i];
        printf("  %s: %s\n", ifr->ifr_name,
               inet_ntoa(((struct sockaddr_in *)&ifr->ifr_addr)->sin_addr));

        /* 获取接口标志 */
        struct ifreq flags_req;
        strncpy(flags_req.ifr_name, ifr->ifr_name, IFNAMSIZ);
        ioctl(fd, SIOCGIFFLAGS, &flags_req);
        printf("    flags: 0x%x (UP=%d, RUNNING=%d)\n",
               flags_req.ifr_flags,
               flags_req.ifr_flags & IFF_UP ? 1 : 0,
               flags_req.ifr_flags & IFF_RUNNING ? 1 : 0);
    }

    close(fd);
    return 0;
}

```
