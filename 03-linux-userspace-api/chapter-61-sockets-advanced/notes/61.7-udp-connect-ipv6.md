## 本节讲什么

`getsockname` / `getpeername`：本端 / 对端（UDP 未 connect 无 peer）。 UDP `connect`：**无网络握手**；记下默认对端 → 可用 send/recv；非对端报文丢弃；可收异步 ICMP；**仍可丢包**。`AF_UNSPEC` 可“断开”。 `IPV6_V6ONLY`：开=纯 v6；关（Linux 默认可双栈映射）。

---

## 要点

`getsockname` / `getpeername`：本端 / 对端（UDP 未 connect 无 peer）。  

UDP `connect`：**无网络握手**；记下默认对端 → 可用 send/recv；非对端报文丢弃；可收异步 ICMP；**仍可丢包**。`AF_UNSPEC` 可“断开”。  

`IPV6_V6ONLY`：开=纯 v6；关（Linux 默认可双栈映射）。
