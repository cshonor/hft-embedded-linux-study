## 本节讲什么

getsockopt(fd, level, optname, optval, &optlen); setsockopt(fd, level, optname, optval, optlen); `level`：`SOL_SOCKET` · `IPPROTO_TCP` · `IPPROTO_IP`/`IPV6`。

---

## 要点

```c
getsockopt(fd, level, optname, optval, &optlen);
setsockopt(fd, level, optname, optval, optlen);
```

`level`：`SOL_SOCKET` · `IPPROTO_TCP` · `IPPROTO_IP`/`IPV6`。  
部分选项须 **bind/connect 前**设置。

## 代码示例

```c

/* getsockopt / setsockopt API 用法 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/socket.h>

int main(void) {
    int fd = socket(AF_INET, SOCK_STREAM, 0);

    /* getsockopt: 读取当前选项值 */
    int optval = 0;
    socklen_t optlen = sizeof(optval);

    getsockopt(fd, SOL_SOCKET, SO_TYPE, &optval, &optlen);
    printf("SO_TYPE: %d (SOCK_STREAM=%d)\n", optval, SOCK_STREAM);

    getsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &optval, &optlen);
    printf("SO_REUSEADDR: %d (default)\n", optval);

    /* setsockopt: 设置选项 */
    optval = 1;
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));
    printf("set SO_REUSEADDR = 1\n");

    getsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &optval, &optlen);
    printf("SO_REUSEADDR now: %d\n", optval);

    /* SO_ERROR: 获取异步错误 */
    int err = 0;
    optlen = sizeof(err);
    getsockopt(fd, SOL_SOCKET, SO_ERROR, &err, &optlen);
    printf("SO_ERROR: %d\n", err);

    close(fd);
    return 0;
}

```
