## 要点

| `TCP_NODELAY` | 关 Nagle → 小包立刻发（交互/低延迟） |
| `TCP_KEEPIDLE` 等 | 配 SO_KEEPALIVE |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | TCP_NODELAY 关 Nagle 让小包立刻发，交互/低延迟协议必开；TCP_KEEPIDLE 等配 SO_KEEPALIVE 探测死连接 |
| HFT | **TCP_NODELAY 是 HFT 铁律**——Nagle 会攒够 MSS 才发，让订单/行情小包延迟毫秒级；所有 TCP 连接必设 TCP_NODELAY=1 |

## 代码示例

```c

/* IPPROTO_TCP 级别选项 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/tcp.h>

int main(void) {
    int fd = socket(AF_INET, SOCK_STREAM, 0);

    /* TCP_NODELAY: 禁用 Nagle 算法 */
    /* Nagle: 攒够 MSS 才发，减少小包；禁用后立即发送（HFT 必用） */
    int opt = 1;
    setsockopt(fd, IPPROTO_TCP, TCP_NODELAY, &opt, sizeof(opt));
    printf("TCP_NODELAY: 1 (Nagle disabled, send immediately)\n");

    /* TCP_MAXSEG: 最大段大小 */
    int mss = 0; socklen_t len = sizeof(mss);
    getsockopt(fd, IPPROTO_TCP, TCP_MAXSEG, &mss, &len);
    printf("TCP_MAXSEG (MSS): %d\n", mss);

    /* TCP_KEEPIDLE: 保活探测间隔 */
    opt = 60;
    setsockopt(fd, IPPROTO_TCP, TCP_KEEPIDLE, &opt, sizeof(opt));
    printf("TCP_KEEPIDLE: %d seconds\n", opt);

    /* TCP_KEEPINTVL: 保活探测重试间隔 */
    opt = 10;
    setsockopt(fd, IPPROTO_TCP, TCP_KEEPINTVL, &opt, sizeof(opt));
    printf("TCP_KEEPINTVL: %d seconds\n", opt);

    /* TCP_KEEPCNT: 保活探测最大重试次数 */
    opt = 3;
    setsockopt(fd, IPPROTO_TCP, TCP_KEEPCNT, &opt, sizeof(opt));
    printf("TCP_KEEPCNT: %d retries\n", opt);

    close(fd);
    return 0;
}

```
