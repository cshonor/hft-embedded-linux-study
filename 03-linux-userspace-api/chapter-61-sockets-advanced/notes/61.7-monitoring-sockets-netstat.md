## 本节讲什么

`getsockname` / `getpeername`：本端 / 对端（UDP 未 connect 无 peer）。 UDP `connect`：**无网络握手**；记下默认对端 → 可用 send/recv；非对端报文丢弃；可收异步 ICMP；**仍可丢包**。`AF_UNSPEC` 可“断开”。 `IPV6_V6ONLY`：开=纯 v6；关（Linux 默认可双栈映射）。

---

## 要点

`getsockname` / `getpeername`：本端 / 对端（UDP 未 connect 无 peer）。  

UDP `connect`：**无网络握手**；记下默认对端 → 可用 send/recv；非对端报文丢弃；可收异步 ICMP；**仍可丢包**。`AF_UNSPEC` 可“断开”。  

`IPV6_V6ONLY`：开=纯 v6；关（Linux 默认可双栈映射）。

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | UDP connect 无网络握手只记默认对端，可用 send/recv 且收异步 ICMP；getsockname/getpeername 查本端/对端 |
| HFT | UDP connect 后可用 send/recv（少一次拷贝）且内核过滤非对端报文，UDP 行情通路用 connect 定点收；IPV6_V6ONLY 控制双栈映射 |

## 代码示例

```c

/* UDP connect + IPv6 socket */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

int main(void) {
    /* UDP connect: 不实际建立连接，只绑定默认对端 */
    int ufd = socket(AF_INET, SOCK_DGRAM, 0);
    struct sockaddr_in dest = { .sin_family = AF_INET, .sin_port = htons(9990) };
    inet_pton(AF_INET, "127.0.0.1", &dest.sin_addr);
    connect(ufd, (struct sockaddr *)&dest, sizeof(dest));
    printf("UDP connect: can now use send/recv instead of sendto/recvfrom\n");

    /* IPv6 socket */
    int s6 = socket(AF_INET6, SOCK_STREAM, 0);
    if (s6 >= 0) {
        struct sockaddr_in6 addr6;
        memset(&addr6, 0, sizeof(addr6));
        addr6.sin6_family = AF_INET6;
        addr6.sin6_port = htons(9989);
        addr6.sin6_addr = in6addr_loopback;  /* ::1 */

        char str[INET6_ADDRSTRLEN];
        inet_ntop(AF_INET6, &addr6.sin6_addr, str, sizeof(str));
        printf("IPv6 socket: [%s]:%u\n", str, ntohs(addr6.sin6_port));

        /* IPv6 dual-stack: 默认同时接受 IPv4 和 IPv6 */
        int off = 0;
        setsockopt(s6, IPPROTO_IPV6, IPV6_V6ONLY, &off, sizeof(off));
        printf("IPV6_V6ONLY=0: dual-stack (accepts IPv4-mapped)\n");
        close(s6);
    }

    close(ufd);
    return 0;
}

```
