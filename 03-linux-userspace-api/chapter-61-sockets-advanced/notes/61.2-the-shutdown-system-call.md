## 要点

| 选项 | 要点 |
|------|------|
| `SO_REUSEADDR` | TIME_WAIT 端口可再 bind；**listen 前开** |
| `SO_REUSEPORT` | 多进程同 IP:port，内核负载分担 |
| `SO_RCVBUF`/`SNDBUF` | 建议值，内核对齐；影响窗口 |
| `SO_LINGER` | close 行为；`linger=0`→RST，慎用 |
| `SO_KEEPALIVE` | 死连接探测；业务心跳更可控 |
| `SO_ERROR` | 取异步错（如非阻塞 connect）后清零 |
| `SO_RCVTIMEO`/`SNDTIMEO` | 超时；主要作用于 recv/send/…（对 `read`/`write` 因实现而异） |
| `SO_BROADCAST` | UDP 广播 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | SO_REUSEADDR 重启快绑、SO_REUSEPORT 多进程同端口负载分担；SO_RCVBUF/SNDBUF 影响窗口，按带宽调 |
| HFT | SO_RCVBUF/SNDBUF 决定 TCP 窗口，大报文吞吐要调大；SO_LINGER=0 发 RST 慎用（丢数据）；SO_REUSEPORT 多进程收行情分散负载；SIGPIPE 用 MSG_NOSIGNAL 规避 |

---

## 常见陷阱

1. **SIGPIPE**

```c
send(fd, buf, n, 0);  /* 对端关闭 → SIGPIPE */
send(fd, buf, n, MSG_NOSIGNAL);  /* 安全 */
```

向已关闭连接的 socket 写数据触发 SIGPIPE。用 MSG_NOSIGNAL 或忽略 SIGPIPE。

2. **TIME_WAIT**

```c
bind(fd, (struct sockaddr*)&addr, len);
/* EADDRINUSE if port in TIME_WAIT */
```

服务端重启时端口可能还在 TIME_WAIT。用 SO_REUSEADDR 允许绑定。

3. **accept 返回值未检查**

```c
int cfd = accept(lfd, NULL, NULL);
/* cfd 可能 -1 (EMFILE/ENFILE) */
```

accept 可能因 fd 耗尽返回 -1。不检查直接用会导致后续操作失败。

## 自测题

**题目 1（选择）：** `listen()` 的第二个参数 backlog 表示什么？
A. 最大连接数
B. 等待 accept 的队列长度
C. 缓冲区大小
D. 超时秒数

<details>
<summary>参考答案</summary>

B。backlog 是已完成连接但尚未 accept 的队列长度。超过后新连接可能被拒绝。

</details>

**题目 2（判断）：** `bind` 可以绑定任意端口号。

<details>
<summary>参考答案</summary>

错误。1-1023 是特权端口，需要 root 权限。已占用的端口会返回 EADDRINUSE。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
connect(sfd, (struct sockaddr*)&addr, sizeof(addr));
send(sfd, "data", 4, 0);
```

<details>
<summary>参考答案</summary>

没有检查 connect 返回值。connect 可能失败（连接被拒绝、超时等），不检查直接 send 会导致错误。

</details>

**题目 4（应用）：** 写代码创建 TCP 服务端 socket 并监听。

<details>
<summary>参考答案</summary>

```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
int opt = 1;
setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port = htons(8080);
addr.sin_addr.s_addr = INADDR_ANY;
bind(sfd, (struct sockaddr*)&addr, sizeof(addr));
listen(sfd, 128);
```

</details>

## 代码示例

```c

/* SOL_SOCKET 级别选项 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/socket.h>

int main(void) {
    int fd = socket(AF_INET, SOCK_STREAM, 0);

    /* SO_REUSEADDR: 地址重用 */
    int opt = 1;
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    /* SO_KEEPALIVE: TCP 保活 */
    setsockopt(fd, SOL_SOCKET, SO_KEEPALIVE, &opt, sizeof(opt));

    /* SO_BROADCAST: 允许广播 */
    setsockopt(fd, SOL_SOCKET, SO_BROADCAST, &opt, sizeof(opt));

    /* SO_RCVBUF / SO_SNDBUF: 缓冲区大小 */
    int buf = 65536;
    setsockopt(fd, SOL_SOCKET, SO_RCVBUF, &buf, sizeof(buf));
    setsockopt(fd, SOL_SOCKET, SO_SNDBUF, &buf, sizeof(buf));

    /* 验证设置 */
    int val; socklen_t len = sizeof(val);
    getsockopt(fd, SOL_SOCKET, SO_RCVBUF, &val, &len);
    printf("SO_RCVBUF: %d (requested %d, kernel may double it)\n", val, buf);

    getsockopt(fd, SOL_SOCKET, SO_SNDBUF, &val, &len);
    printf("SO_SNDBUF: %d\n", val);

    /* SO_RCVTIMEO / SO_SNDTIMEO: 超时 */
    struct timeval tv = { .tv_sec = 5, .tv_usec = 0 };
    setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));
    printf("SO_RCVTIMEO: 5s\n");

    close(fd);
    return 0;
}

```
