## 本节讲什么

最强收发：`msg_iov` 分散聚集；`msg_control` **辅助数据** → UNIX **传 fd / 凭证**。普通 send 做不到。 ---

---

## 要点

最强收发：`msg_iov` 分散聚集；`msg_control` **辅助数据** → UNIX **传 fd / 凭证**。普通 send 做不到。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | sendmsg/recvmsg 分散聚集 I/O + SCM_RIGHTS 传 fd，进程间零拷贝传 fd（如 epoll fd、事件 fd）省去重建 |
| HFT | recvmsg 分散聚集一次收多段（报文头+负载）省拷贝；SCM_RIGHTS 传 fd 让风控进程把事件 fd 交给策略进程，进程间优雅共享 I/O 对象 |

## 代码示例

```c

/* sendmsg / recvmsg：分散/聚集 I/O + 辅助数据 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <sys/un.h>
#include <sys/wait.h>

int main(void) {
    int sv[2];
    socketpair(AF_UNIX, SOCK_STREAM, 0, sv);

    pid_t pid = fork();
    if (pid == 0) {
        close(sv[0]);
        /* sendmsg: 多缓冲区发送 */
        struct iovec iov[2];
        char part1[] = "hello ";
        char part2[] = "world";
        iov[0].iov_base = part1; iov[0].iov_len = 6;
        iov[1].iov_base = part2; iov[1].iov_len = 5;

        struct msghdr msg;
        memset(&msg, 0, sizeof(msg));
        msg.msg_iov = iov;
        msg.msg_iovlen = 2;

        ssize_t n = sendmsg(sv[1], &msg, 0);
        printf("sendmsg: sent %zd bytes (scatter-gather)\n", n);
        close(sv[1]);
        _exit(0);
    }

    close(sv[1]);
    /* recvmsg: 接收到一个缓冲区 */
    char buf[64];
    struct iovec iov = { .iov_base = buf, .iov_len = sizeof(buf) };
    struct msghdr msg;
    memset(&msg, 0, sizeof(msg));
    msg.msg_iov = &iov;
    msg.msg_iovlen = 1;

    ssize_t n = recvmsg(sv[0], &msg, 0);
    if (n > 0) { buf[n] = '\0'; printf("recvmsg: received '%s' (%zd bytes)\n", buf, n); }

    wait(NULL);
    close(sv[0]);
    return 0;
}

```
