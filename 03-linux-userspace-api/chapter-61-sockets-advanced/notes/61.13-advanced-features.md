# 61.13 Advanced Features

> 本章：[TLPI 第 61 章](./README.md)

## 本节讲什么

Linux 套接字的高级特性：`SO_REUSEPORT`（多进程负载均衡）、`TCP_FASTOPEN`（快速打开）、`IP_TRANSPARENT`（透明代理）、`TCP_INFO`（连接诊断）等。

## 要点

### SO_REUSEPORT (Linux 3.9+)

允许多个套接字绑定同一地址端口，内核实现连接负载均衡。

```c
int opt = 1;
setsockopt(fd, SOL_SOCKET, SO_REUSEPORT, &opt, sizeof(opt));
```

| 特性 | 说明 |
|------|------|
| 多进程监听 | N 个进程绑定同一端口 |
| 内核负载均衡 | 连接均匀分发到各进程 |
| 避免惊群 | 只唤醒一个进程 |
| 连接亲和性 | Linux 4.6+ 支持（同一客户端固定到同一进程） |

### TCP_FASTOPEN (Linux 3.6+)

在 SYN 中携带数据，省去一个 RTT。

```c
/* 服务端 */
int opt = 5;  /* 队列长度 */
setsockopt(fd, IPPROTO_TCP, TCP_FASTOPEN, &opt, sizeof(opt));

/* 客户端 */
sendto(fd, data, len, MSG_FASTOPEN, addr, addrlen);
/* 或 */
connect(fd + sendto -> TFO cookie */
```

| 步骤 | 正常 TCP | TCP FastOpen |
|------|---------|---------------|
| 1 | SYN → | SYN + 数据 → |
| 2 | ← SYN-ACK | ← SYN-ACK + ACK |
| 3 | ACK → | (数据已在步骤1发送) |
| 4 | 数据 → | 完成（省 1 RTT） |

### TCP_INFO 连接诊断

```c
struct tcp_info info;
socklen_t len = sizeof(info);
getsockopt(fd, IPPROTO_TCP, TCP_INFO, &info, &len);

/* 关键字段 */
info.tcpi_rtt;          /* 平滑 RTT（微秒） */
info.tcpi_rttvar;       /* RTT 方差 */
info.tcpi_snd_mss;      /* 发送 MSS */
info.tcpi_rcv_mss;      /* 接收 MSS */
info.tcpi_total_retrans;/* 总重传次数 */
info.tcpi_rto;          /* 重传超时 */
info.tcpi_snd_cwnd;     /* 拥塞窗口 */
info.tcpi_snd_wnd;      /* 发送窗口 */
```

### IP_TRANSPARENT 透明代理

```c
int opt = 1;
setsockopt(fd, SOL_IP, IP_TRANSPARENT, &opt, sizeof(opt));
/* 允许 bind 非本机 IP */
bind(fd, (struct sockaddr*)&fake_addr, sizeof(fake_addr));
```

### 其他高级选项

| 选项 | 说明 |
|------|------|
| `SO_BUSY_POLL` | 网卡轮询模式，减少中断延迟 |
| `IP_TOS` | 设置 DSCP/TOS 标记 |
| `TCP_REPAIR` | 连接迁移（容器 checkpoint/restore） |
| `SO_ATTACH_REUSEPORT_EBPF` | eBPF 自定义负载均衡策略 |

## HFT / 嵌入式关联

- `SO_REUSEPORT`：多核 worker 进程均匀分担连接
- `TCP_FASTOPEN`：省去 RTT，降低连接延迟
- `TCP_INFO`：实时监控连接 RTT 和重传
- `SO_BUSY_POLL`：减少中断延迟，提升吞吐
- `IP_TOS`：标记交易流量高优先级

## 代码示例

```c
#include <sys/socket.h>
#include <netinet/tcp.h>
#include <stdio.h>

/* HFT 服务器高级配置 */
void setup_advanced_server(int lfd) {
    int opt;

    /* 1. SO_REUSEPORT：多进程负载均衡 */
    opt = 1;
    setsockopt(lfd, SOL_SOCKET, SO_REUSEPORT, &opt, sizeof(opt));

    /* 2. TCP_FASTOPEN */
    opt = 10;  /* backlog */
    setsockopt(lfd, IPPROTO_TCP, TCP_FASTOPEN, &opt, sizeof(opt));

    /* 3. Busy polling（微秒级） */
    opt = 50;  /* 50微秒 */
    setsockopt(lfd, SOL_SOCKET, SO_BUSY_POLL, &opt, sizeof(opt));
}

/* 连接诊断 */
void diagnose_connection(int fd) {
    struct tcp_info info;
    socklen_t len = sizeof(info);

    if (getsockopt(fd, IPPROTO_TCP, TCP_INFO, &info, &len) == 0) {
        printf("RTT:        %u us\n", info.tcpi_rtt);
        printf("RTT var:    %u us\n", info.tcpi_rttvar);
        printf("RTO:        %u us\n", info.tcpi_rto);
        printf("Cwnd:       %u\n", info.tcpi_snd_cwnd);
        printf("Snd wnd:    %u\n", info.tcpi_snd_wnd);
        printf("Retrans:    %u\n", info.tcpi_total_retrans);
        printf("Snd MSS:    %u\n", info.tcpi_snd_mss);
    }
}
```

## 代码自测

<details>
<summary>SO_REUSEPORT 和 SO_REUSEADDR 有什么区别？</summary>

- **SO_REUSEADDR**：允许 bind 处于 TIME_WAIT 状态的地址，或绑定通配地址与本机地址共存。主要解决服务器重启时端口占用问题。
- **SO_REUSEPORT**：允许**多个套接字**绑定**完全相同的**地址和端口，内核将新连接在多个套接字间负载均衡。适用于多进程/多线程服务器，避免 accept 惊群。SO_REUSEPORT 是 SO_REUSEADDR 的超集功能，解决了连接分发问题。

</details>
