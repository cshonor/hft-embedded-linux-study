# 61.9 Socket Options

> 本章：[TLPI 第 61 章](../README.md)

## 本节讲什么

`getsockopt()` / `setsockopt()` 用于查询和设置套接字选项，控制 TCP 行为、缓冲区、超时等。本节覆盖 SOL_SOCKET、IPPROTO_TCP、IPPROTO_IP 三个主要选项层。

## 要点

### API

```c
#include <sys/socket.h>
int getsockopt(int sockfd, int level, int optname, void *optval, socklen_t *optlen);
int setsockopt(int sockfd, int level, int optname, const void *optval, socklen_t optlen);
```

### SOL_SOCKET 层选项

| 选项 | 类型 | 说明 |
|------|------|------|
| `SO_REUSEADDR` | int | 允许地址重用（bind TIME_WAIT） |
| `SO_KEEPALIVE` | int | 启用 TCP 保活探测 |
| `SO_RCVBUF` | int | 接收缓冲区大小 |
| `SO_SNDBUF` | int | 发送缓冲区大小 |
| `SO_RCVTIMEO` | timeval | 接收超时 |
| `SO_SNDTIMEO` | timeval | 发送超时 |
| `SO_BROADCAST` | int | 允许广播 |
| `SO_LINGER` | linger | close() 行为控制 |
| `SO_OOBINLINE` | int | 带外数据内联接收 |
| `SO_DOMAIN` | int | 协议域（只读） |
| `SO_TYPE` | int | 套接字类型（只读） |
| `SO_ERROR` | int | 待处理错误（只读） |

### IPPROTO_TCP 层选项

| 选项 | 类型 | 说明 |
|------|------|------|
| `TCP_NODELAY` | int | 禁用 Nagle 算法 |
| `TCP_MAXSEG` | int | 最大段大小 (MSS) |
| `TCP_CORK` | int | 启用 Cork 模式 |
| `TCP_KEEPIDLE` | int | 保活空闲时间（秒） |
| `TCP_KEEPINTVL` | int | 保活探测间隔 |
| `TCP_KEEPCNT` | int | 保活探测次数 |
| `TCP_QUICKACK` | int | 快速 ACK（禁止延迟 ACK） |

### SO_LINGER 结构

```c
struct linger {
    int l_onoff;   // 0=禁用, 1=启用
    int l_linger;  // 超时（秒）
};
```

| l_onoff | l_linger | close() 行为 |
|---------|----------|-------------|
| 0 | - | 默认：立即返回，后台发送 |
| 1 | 0 | 立即关闭，丢弃数据，发 RST |
| 1 | >0 | 阻塞等待数据发送完毕或超时 |

### Nagle 算法 vs TCP_NODELAY vs TCP_CORK

| 选项 | 效果 | 适用场景 |
|------|------|---------|
| 默认 (Nagle on) | 小包合并发送 | 节省带宽 |
| `TCP_NODELAY=1` | 禁用 Nagle，立即发送 | 低延迟交互 |
| `TCP_CORK=1` | 缓存所有数据直到取消 | 批量传输 |
| `TCP_CORK=0` | 刷新缓存的包 | 取消 Cork 后发送 |

## HFT / 嵌入式关联

- HFT 必设 `TCP_NODELAY`：交易消息立即发送，不等待合并
- `SO_RCVBUF`/`SO_SNDBUF` 调大：减少丢包和重传
- `TCP_QUICKACK`：禁用延迟 ACK，降低交互延迟
- `SO_KEEPALIVE` + 自定义探测参数：检测断线

## 代码示例

```c
#include <sys/socket.h>
#include <netinet/tcp.h>
#include <stdio.h>

void setup_hft_socket(int sockfd) {
    int opt;

    /* 1. 禁用 Nagle：立即发送小包 */
    opt = 1;
    setsockopt(sockfd, IPPROTO_TCP, TCP_NODELAY, &opt, sizeof(opt));

    /* 2. 快速 ACK：禁用延迟确认 */
    opt = 1;
    setsockopt(sockfd, IPPROTO_TCP, TCP_QUICKACK, &opt, sizeof(opt));

    /* 3. 增大缓冲区 */
    opt = 4 * 1024 * 1024;  /* 4MB */
    setsockopt(sockfd, SOL_SOCKET, SO_RCVBUF, &opt, sizeof(opt));
    setsockopt(sockfd, SOL_SOCKET, SO_SNDBUF, &opt, sizeof(opt));

    /* 4. 地址重用 */
    opt = 1;
    setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    /* 5. TCP 保活：10秒空闲，3秒间隔，3次探测 */
    opt = 1;
    setsockopt(sockfd, SOL_SOCKET, SO_KEEPALIVE, &opt, sizeof(opt));
    opt = 10;  /* 10秒空闲后开始探测 */
    setsockopt(sockfd, IPPROTO_TCP, TCP_KEEPIDLE, &opt, sizeof(opt));
    opt = 3;   /* 探测间隔3秒 */
    setsockopt(sockfd, IPPROTO_TCP, TCP_KEEPINTVL, &opt, sizeof(opt));
    opt = 3;   /* 3次探测失败后判定断连 */
    setsockopt(sockfd, IPPROTO_TCP, TCP_KEEPCNT, &opt, sizeof(opt));
}
```

## 代码自测

<details>
<summary>TCP_NODELAY 和 TCP_CORK 有什么区别？何时该用哪个？</summary>

`TCP_NODELAY` 禁用 Nagle 算法，每个 `write()` 立即作为单独的 TCP 段发送，适合小延迟敏感的交互式协议（如 HFT 交易消息）。`TCP_CORK` 更进一步，缓存所有数据（包括带 PSH 的），直到主动取消 Cork 或缓冲区满才发送，适合批量数据传输（如 HTTP 响应头+body 一并发出）。HFT 交易消息通常用 `TCP_NODELAY`，而批量行情快照用 `TCP_CORK` + 显式 flush。

</details>
