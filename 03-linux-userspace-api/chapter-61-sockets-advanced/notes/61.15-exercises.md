### 练习 1：HFT 服务器 socket 配置

**题目**：为 HFT 交易服务器编写 socket 配置函数，要求：支持快速重启、低延迟、保活检测、大缓冲区。

<details>
<summary>参考答案</summary>

```c
void setup_hft_server(int lfd) {
    int opt;
    struct linger ling;

    /* 快速重启 */
    opt = 1;
    setsockopt(lfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    /* 多进程负载均衡 */
    opt = 1;
    setsockopt(lfd, SOL_SOCKET, SO_REUSEPORT, &opt, sizeof(opt));

    /* TCP FastOpen */
    opt = 10;
    setsockopt(lfd, IPPROTO_TCP, TCP_FASTOPEN, &opt, sizeof(opt));

    /* 大缓冲区 */
    opt = 4 * 1024 * 1024;
    setsockopt(lfd, SOL_SOCKET, SO_RCVBUF, &opt, sizeof(opt));
    setsockopt(lfd, SOL_SOCKET, SO_SNDBUF, &opt, sizeof(opt));

    /* 保活：5秒空闲，1秒间隔，3次探测 */
    opt = 1;
    setsockopt(lfd, SOL_SOCKET, SO_KEEPALIVE, &opt, sizeof(opt));
    opt = 5;
    setsockopt(lfd, IPPROTO_TCP, TCP_KEEPIDLE, &opt, sizeof(opt));
    opt = 1;
    setsockopt(lfd, IPPROTO_TCP, TCP_KEEPINTVL, &opt, sizeof(opt));
    opt = 3;
    setsockopt(lfd, IPPROTO_TCP, TCP_KEEPCNT, &opt, sizeof(opt));
}

/* 新连接配置（accept4 后） */
void setup_hft_conn(int connfd) {
    int opt;

    /* 禁用 Nagle */
    opt = 1;
    setsockopt(connfd, IPPROTO_TCP, TCP_NODELAY, &opt, sizeof(opt));

    /* 快速 ACK */
    opt = 1;
    setsockopt(connfd, IPPROTO_TCP, TCP_QUICKACK, &opt, sizeof(opt));

    /* 大缓冲区（不继承） */
    opt = 4 * 1024 * 1024;
    setsockopt(connfd, SOL_SOCKET, SO_RCVBUF, &opt, sizeof(opt));
    setsockopt(connfd, SOL_SOCKET, SO_SNDBUF, &opt, sizeof(opt));
}
```

</details>

### 练习 2：TCP_INFO 诊断

**题目**：编写函数，使用 `TCP_INFO` 输出连接的 RTT、重传次数和拥塞窗口。

<details>
<summary>参考答案</summary>

```c
#include <netinet/tcp.h>
#include <stdio.h>

void print_tcp_info(int fd) {
    struct tcp_info info;
    socklen_t len = sizeof(info);

    if (getsockopt(fd, IPPROTO_TCP, TCP_INFO, &info, &len) < 0) {
        perror("getsockopt TCP_INFO");
        return;
    }

    printf("=== TCP Connection Info ===\n");
    printf("Smoothed RTT:  %u us\n", info.tcpi_rtt);
    printf("RTT variance:  %u us\n", info.tcpi_rttvar);
    printf("RTO:           %u us\n", info.tcpi_rto);
    printf("Send cwnd:     %u\n", info.tcpi_snd_cwnd);
    printf("Send window:   %u\n", info.tcpi_snd_wnd);
    printf("Recv window:   %u\n", info.tcpi_rcv_wnd);
    printf("Retransmits:   %u\n", info.tcpi_total_retrans);
    printf("Send MSS:      %u\n", info.tcpi_snd_mss);

    if (info.tcpi_total_retrans > 0)
        printf("WARNING: %u retransmissions detected!\n",
               info.tcpi_total_retrans);
}
```

</details>

### 练习 3：accept4 优势

**题目**：解释 `accept4(lfd, NULL, NULL, SOCK_NONBLOCK | SOCK_CLOEXEC)` 相比 `accept` + `fcntl` 的优势。

<details>
<summary>参考答案</summary>

1. **原子性**：accept4 在一次系统调用中完成 accept 和设置标志，避免 accept + fcntl 之间的竞争窗口
2. **CLOEXEC 安全**：如果其他线程在 accept 返回后、fcntl 之前调用 exec()，fd 会泄漏到新进程。accept4 的 SOCK_CLOEXEC 是原子的
3. **性能**：一次系统调用代替两次，减少上下文切换开销
4. **代码简洁**：单行代码即可完成 accept + 设置

</details>
