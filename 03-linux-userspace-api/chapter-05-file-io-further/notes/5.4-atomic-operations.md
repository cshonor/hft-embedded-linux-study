## 要点

### 反例：检查再创建（竞态）

```c
/* ❌ 非原子：两进程可同时「不存在」再各自 create */
if (open("a.txt", O_RDONLY) == -1)
    open("a.txt", O_WRONLY | O_CREAT, mode);
```

```c
/* ✅ 检查+创建一步完成 */
fd = open(path, O_WRONLY | O_CREAT | O_EXCL, mode);
```

`O_EXCL` + `O_CREAT`：已存在则失败。  
Demo：[`code/o_excl_create.c`](./code/o_excl_create.c)

### `O_APPEND` 原子追加

多进程同文件：带 `O_APPEND` 时每次 write 内核先到 EOF 再写。  
无则 `lseek(SEEK_END)+write` 可互相覆盖。

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <string.h>
/* 原子操作: O_CREAT|O_EXCL 防止竞态 */
int main(void) {
    /* 原子创建: 如果文件已存在则失败 */
    int fd = open("/tmp/atomic_test.txt", O_CREAT | O_EXCL | O_WRONLY, 0644);
    if (fd < 0)
        printf("File already exists (atomic check worked)\n");
    else {
        write(fd, "created atomically", 18);
        close(fd);
    }

    /* 原子追加: O_APPEND 保证追加是原子的 */
    fd = open("/tmp/atomic_test.txt", O_WRONLY | O_APPEND);
    if (fd >= 0) {
        write(fd, " appended", 9);
        close(fd);
    }
    return 0;
}
```
