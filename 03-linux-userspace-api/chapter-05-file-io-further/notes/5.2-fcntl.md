## 要点

```c
int fcntl(int fd, int cmd, ...);
```

| cmd | 作用 |
|-----|------|
| `F_DUPFD` | 复制 fd（类似 dup） |
| `F_GETFD` / `F_SETFD` | **fd 标志**（进程 fd 表）：主要 `FD_CLOEXEC` |
| `F_GETFL` / `F_SETFL` | **文件状态标志**（打开描述）：可改 `O_APPEND`、`O_NONBLOCK`；**不能**改 `O_RDONLY`/`O_WRONLY`/`O_RDWR` |

### 两组标志勿混

| | 存在哪 | 例子 | 共享？ |
|--|--------|------|--------|
| **fd 标志** | 进程 fd 表项 | `FD_CLOEXEC` | 每个 fd **私有** |
| **文件状态标志** | 打开文件描述 | `O_APPEND`、`O_NONBLOCK` | `dup` 的 fd **共享** |

`FD_CLOEXEC`：`exec` 时自动关该 fd，防泄漏。  
Demo：[`code/fcntl_nonblock.c`](./code/fcntl_nonblock.c)（管道上设 `O_NONBLOCK`）

## 常见陷阱

1. **fd 标志 vs 文件状态标志混淆**

```c
/* 错误：F_SETFL 改不了访问模式 */
fcntl(fd, F_SETFL, O_WRONLY);  /* 无效 */
```

F_SETFL 只能改 O_APPEND/O_NONBLOCK 等，不能改 O_RDONLY/O_WRONLY/O_RDWR。访问模式在 open 时确定。

2. **F_GETFL 解析访问模式**

```c
int flags = fcntl(fd, F_GETFL);
int acc = flags & O_ACCMODE;  /* O_RDONLY/O_WRONLY/O_RDWR */
```

不能直接用 `flags & O_WRONLY` 判断，因为 O_RDONLY 通常是 0。必须用 O_ACCMODE 掩码。

3. **FD_CLOEXEC 竞态**

```c
int fd = open(...);
fcntl(fd, F_SETFD, FD_CLOEXEC);  /* open 和 fcntl 之间有间隙 */
/* 多线程中 exec 可能在此间隙发生 */
```

open + fcntl(F_SETFD) 之间存在竞态窗口。用 O_CLOEXEC 标志一步到位。

## 自测题

**题目 1（选择）：** `fcntl(fd, F_SETFL, flags)` 可以改变以下哪个标志？
A. O_RDONLY
B. O_WRONLY
C. O_NONBLOCK
D. O_CREAT

<details>
<summary>参考答案</summary>

C。F_SETFL 只能改 O_APPEND、O_NONBLOCK、O_ASYNC 等状态标志，不能改访问模式（O_RDONLY 等）。

</details>

**题目 2（判断）：** `FD_CLOEXEC` 是文件状态标志，存在打开文件描述中。

<details>
<summary>参考答案</summary>

错误。FD_CLOEXEC 是 fd 标志，存在进程 fd 表中，每个 fd 私有。文件状态标志（如 O_APPEND）才在打开文件描述中。

</details>

**题目 3（踩坑）：** 以下代码试图将文件改为非阻塞，有什么问题？
```c
fcntl(fd, F_SETFL, O_NONBLOCK);
```

<details>
<summary>参考答案</summary>

问题：F_SETFL 会覆盖所有状态标志。应该先 F_GETFL 取回当前标志，再 OR 上 O_NONBLOCK：
`fcntl(fd, F_SETFL, fcntl(fd, F_GETFL) | O_NONBLOCK);`

</details>

**题目 4（应用）：** 写代码设置 fd 为非阻塞模式。

<details>
<summary>参考答案</summary>

```c
int flags = fcntl(fd, F_GETFL);
if (flags < 0) return -1;
return fcntl(fd, F_SETFL, flags | O_NONBLOCK);
```

</details>

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
/* fcntl: 获取/设置文件描述符属性 */
int main(void) {
    int fd = open("/tmp/fcntl_test.txt", O_RDWR | O_CREAT, 0644);

    /* 获取文件状态标志 */
    int flags = fcntl(fd, F_GETFL);
    printf("access mode: %s\n",
           (flags & O_ACCMODE) == O_RDONLY ? "RDONLY" :
           (flags & O_ACCMODE) == O_WRONLY ? "WRONLY" : "RDWR");

    /* 设置 O_NONBLOCK */
    fcntl(fd, F_SETFL, flags | O_NONBLOCK);
    flags = fcntl(fd, F_GETFL);
    printf("O_NONBLOCK set: %s\n", (flags & O_NONBLOCK) ? "yes" : "no");

    /* 获取文件描述符标志 */
    int fdflags = fcntl(fd, F_GETFD);
    printf("FD_CLOEXEC: %s\n", (fdflags & FD_CLOEXEC) ? "yes" : "no");

    close(fd);
    return 0;
}
```
