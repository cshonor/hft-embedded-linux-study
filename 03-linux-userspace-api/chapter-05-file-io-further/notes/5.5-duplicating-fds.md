## 要点

```c
#include <unistd.h>
int dup(int oldfd);                        /* 最小可用编号，同一打开描述 */
int dup2(int oldfd, int newfd);            /* newfd 已开则先 close；再复制 */
int dup3(int oldfd, int newfd, int flags); /* Linux；可带 O_CLOEXEC */
```

典型用途：重定向 stdin/stdout（shell 管道、`exec` 前重定向）。  
Demo：[`code/dup_share_offset.c`](../code/dup_share_offset.c)

## 常见陷阱

1. **dup2 的 close-on-exec**

```c
dup2(oldfd, newfd);  /* newfd 没有 CLOEXEC */
```

dup2 复制的 fd 不继承 close-on-exec 标志。exec 前需要手动设置，或用 dup3(fd, newfd, O_CLOEXEC)。

2. **dup2 目标已打开**

```c
dup2(oldfd, newfd);  /* 如果 newfd 已打开，先关闭 */
```

dup2 如果 newfd 已打开，会先关闭再复制。如果不希望这样，应先检查。

3. **共享偏移的意外**

```c
int fd2 = dup(fd1);
/* fd1 和 fd2 共享文件偏移 */
lseek(fd1, 0, SEEK_SET);  /* fd2 的偏移也变了! */
```

dup 复制的 fd 共享同一个打开文件描述（包括偏移）。lseek 通过一个 fd 会影响另一个。

## 自测题

**题目 1（选择）：** `dup2(oldfd, newfd)` 和 `dup(oldfd)` 的区别？
A. 没有区别
B. dup2 可以指定目标 fd 编号
C. dup2 更快
D. dup 只能复制到 0

<details>
<summary>参考答案</summary>

B。dup 返回最小可用 fd，dup2 可以指定目标 fd 编号 newfd。

</details>

**题目 2（判断）：** `dup` 复制的 fd 有独立的文件偏移。

<details>
<summary>参考答案</summary>

错误。dup 复制的 fd 共享同一个打开文件描述，包括文件偏移和状态标志。

</details>

**题目 3（踩坑）：** 以下代码在 exec 后会发生什么？
```c
int fd = open("f.txt", O_RDONLY);
dup2(fd, STDIN_FILENO);
execvp("cat", argv);
```

<details>
<summary>参考答案</summary>

dup2 复制的 fd 默认没有 FD_CLOEXEC，所以 exec 后 stdin 仍然指向 f.txt。这正是 shell 重定向的原理。

</details>

**题目 4（应用）：** 写代码实现 shell 的输出重定向 `cmd > file.txt`。

<details>
<summary>参考答案</summary>

```c
int fd = open("file.txt", O_WRONLY|O_CREAT|O_TRUNC, 0644);
dup2(fd, STDOUT_FILENO);
close(fd);
execvp(cmd, argv);
```

</details>

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
/* dup/dup2/dup3: 复制文件描述符 */
int main(void) {
    int fd = open("/dev/null", O_WRONLY);
    int new_fd = dup(fd);          /* 返回最小可用 fd */
    int fd10 = dup2(fd, 10);       /* 复制到 fd=10 */
    printf("dup: %d, dup2(fd,10): %d\n", new_fd, fd10);
    close(fd); close(new_fd); close(fd10);
    return 0;
}
```
