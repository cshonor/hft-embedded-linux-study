## 要点

| 标志 | 含义 |
|------|------|
| `O_SYNC` | 同步写：数据+元数据落盘才返回 |
| `O_DSYNC` | 主要数据落盘；元数据可延迟（通常比 `O_SYNC` 轻） |
| `O_CLOEXEC` | 打开时设 close-on-exec；避免 `open`+`fcntl` 之间竞态 |
| `O_NOATIME` | 读时不更新 atime，少写盘 |

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>

int main(void) {
    /* O_CLOEXEC: exec 时自动关闭 fd，避免泄漏 */
    int fd = open("/tmp/cloexec_demo.txt", O_WRONLY | O_CREAT | O_CLOEXEC, 0644);
    if (fd < 0) { perror("open"); return 1; }
    printf("fd=%d (带 O_CLOEXEC)\n", fd);

    /* 检查 FD_CLOEXEC 是否设置 */
    int flags = fcntl(fd, F_GETFD);
    printf("FD_CLOEXEC = %s\n", (flags & FD_CLOEXEC) ? "YES" : "NO");

    /* O_SYNC: 每次 write 都等数据落盘才返回 */
    int sfd = open("/tmp/sync_demo.txt", O_WRONLY | O_CREAT | O_SYNC, 0644);
    if (sfd < 0) { perror("open O_SYNC"); return 1; }
    write(sfd, "synced", 6);  /* 阻塞直到数据写入磁盘 */
    printf("O_SYNC write 完成（已落盘）\n");

    close(fd);
    close(sfd);
    return 0;
}
```
