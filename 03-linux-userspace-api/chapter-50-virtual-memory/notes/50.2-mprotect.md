## 本节讲什么

int mprotect(void *addr, size_t length, int prot); `PROT_NONE|READ|WRITE|EXEC`。违例 → **SIGSEGV**。 不能超过后备权限（只读文件映射 → 不可 `PROT_WRITE` → `EACCES`）。

---

## 要点

```c
int mprotect(void *addr, size_t length, int prot);
```

`PROT_NONE|READ|WRITE|EXEC`。违例 → **SIGSEGV**。  
不能超过后备权限（只读文件映射 → 不可 `PROT_WRITE` → `EACCES`）。  
JIT：`W` 写码 → 改成 `R|X`；现代常强制 **W^X**（不可同时 W+X）。
