## 要点

```c
int madvise(void *addr, size_t length, int advice);
```

内核**可忽略**。常用：

| advice | 含义 |
|--------|------|
| `MADV_NORMAL` | 默认 |
| `MADV_RANDOM` | 少预读 |
| `MADV_SEQUENTIAL` | 激进预读、用过可早收 |
| `MADV_WILLNEED` | 提前装入 |
| `MADV_DONTNEED` | Linux PRIVATE：**丢本地修改**；SHARED 多为丢页缓存语义 |

Linux 另有 `MADV_FREE` 等。
