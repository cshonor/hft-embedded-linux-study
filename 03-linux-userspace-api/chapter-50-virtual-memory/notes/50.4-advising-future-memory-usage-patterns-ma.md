## 要点

```c
int mincore(void *addr, size_t length, unsigned char *vec);
```

`vec[i] & 1`：页是否在物理内存。  
⚠️ **瞬时、非原子**；不能当同步条件。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 启动后核查关键页是否驻留（flash XIP 就地执行场景）；瞬时非原子，仅作诊断 |
| HFT | 预热后 mincore 验证热缓冲确已驻留（配合 mlock 确认）；因瞬时非原子，不能当同步条件用 |

## 代码示例

```c

/* mincore 查询页是否驻留在物理内存 */
#include <stdio.h>
#include <stdlib.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void) {
    long page_size = sysconf(_SC_PAGESIZE);
    int num_pages = 4;
    size_t len = (size_t)page_size * num_pages;

    char *p = mmap(NULL, len, PROT_READ | PROT_WRITE,
                   MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
    if (p == MAP_FAILED) { perror("mmap"); exit(1); }

    /* 触摸前两页使其驻留 */
    p[0] = 'a';
    p[page_size] = 'b';

    /* mincore 返回每页驻留状态 */
    unsigned char vec[num_pages];
    if (mincore(p, len, vec) < 0) { perror("mincore"); exit(1); }

    for (int i = 0; i < num_pages; i++) {
        printf("page %d: %s\n", i, (vec[i] & 1) ? "resident" : "not resident");
    }

    munmap(p, len);
    return 0;
}

```
