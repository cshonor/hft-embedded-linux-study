## 要点

```c
int gethostname(char *name, size_t len);
int sethostname(const char *name, size_t len);   /* 特权 */

int getdomainname(char *name, size_t len);
int setdomainname(const char *name, size_t len); /* 特权 */
```

`gethostname` ≈ `uname().nodename`。
