## 要点

| 方案 | API | 场景 |
|------|-----|------|
| **可移植** | `uname`、`gethostname` | 所有 UNIX |
| **Linux** | `/proc`、`sysinfo`、`get_nprocs` | 功能全；BSD/macOS 勿依赖 |
