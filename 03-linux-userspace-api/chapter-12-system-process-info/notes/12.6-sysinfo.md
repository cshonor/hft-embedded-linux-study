## 要点

```c
#include <sys/sysinfo.h>
struct sysinfo info;
int sysinfo(&info);
```

| 成员 | 含义 |
|------|------|
| `uptime` | 启动以来秒数 |
| `loads[3]` | 1/5/15 负载 |
| `totalram` / `freeram` / … | 内存（注意 **`mem_unit`**） |
| `totalswap` / `freeswap` | 交换区 |

> 老内核有溢出风险；现代监控优先 **`/proc/meminfo`**。  
> 字节数 ≈ 字段 × `mem_unit`。

## 代码示例

```c
#include <sys/sysinfo.h>
#include <stdio.h>

int main(void) {
    struct sysinfo info;
    if (sysinfo(&info) != 0) { perror("sysinfo"); return 1; }

    printf("系统运行时间: %ld 秒 (%.1f 天)\n",
           info.uptime, info.uptime / 86400.0);
    printf("总内存: %lu MB\n", info.totalram * info.mem_unit / (1024 * 1024));
    printf("空闲内存: %lu MB\n", info.freeram * info.mem_unit / (1024 * 1024));
    printf("Swap 总量: %lu MB\n", info.totalswap * info.mem_unit / (1024 * 1024));
    printf("进程数: %d\n", info.procs);
    printf("平均负载: %.2f %.2f %.2f\n",
           info.loads[0] / 65536.0,
           info.loads[1] / 65536.0,
           info.loads[2] / 65536.0);
    return 0;
}
```
