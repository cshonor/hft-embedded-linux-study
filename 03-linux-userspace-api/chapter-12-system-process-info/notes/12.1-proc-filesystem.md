## 本节讲什么

虚拟文件系统：不占磁盘，内容由内核**实时生成**。 `mount | grep proc` Demo：[`code/proc_self_status.c`](../code/proc_self_status.c) · [`code/mini_ps.c`](../code/mini_ps.c)

---

## 要点

虚拟文件系统：不占磁盘，内容由内核**实时生成**。  
`mount | grep proc`

| 类 | 路径 | 内容 |
|----|------|------|
| 全局 | `/proc/xxx` | 整机信息 |
| 进程 | `/proc/[pid]/` | 每进程一份；`/proc/self` = 当前进程 |

### 常用全局文件

| 路径 | 用途 |
|------|------|
| `/proc/meminfo` | MemTotal / MemFree / Buffers / Cached… |
| `/proc/cpuinfo` | CPU 型号、核、缓存 |
| `/proc/version` | 内核版本字符串 |
| `/proc/loadavg` | 1/5/15 负载、运行中任务、最近 PID |
| `/proc/sys/` | 可调内核参数（`sysctl`） |
| `/proc/sys/kernel/pid_max` | PID 上限 |
| `/proc/sys/fs/file-max` | 系统级文件句柄上限 |

### `/proc/[pid]/` 关键项

| 路径 | 用途 |
|------|------|
| `cmdline` | 启动命令；参数以 **`\0`** 分隔 |
| `status` | 易读：UID/GID、VmRSS、VmSize、线程数 |
| `stat` | 紧凑数字字段（`ps` 数据源之一） |
| `statm` | 内存页数概览 |
| `maps` | 虚拟地址区域（库 / 堆 / 栈 / mmap） |
| `fd/` | 已打开 fd 的符号链接 |
| `cwd` / `exe` | 工作目录 / 可执行文件（符号链接） |
| `environ` | 环境变量；`\0` 分隔 |

Demo：[`code/proc_self_status.c`](../code/proc_self_status.c) · [`code/mini_ps.c`](../code/mini_ps.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | /proc 是内核信息文本接口，不占磁盘实时生成；嵌入式板子靠 /proc/meminfo、/proc/cpuinfo、/proc/loadavg 做资源监控与调优 |
| HFT | 交易进程自检/监控读 /proc/self/status、/proc/loadavg 评估系统压力；/proc 是纯文本读但实时生成有开销，不宜放热路径高频读 |

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

/* /proc 文件系统: 内核信息的文本接口 */
int main(void) {
    char buf[4096];

    /* /proc/version: 内核版本 */
    int fd = open("/proc/version", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("内核: %s", buf); }
        close(fd);
    }

    /* /proc/loadavg: 系统负载 */
    fd = open("/proc/loadavg", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("负载: %s", buf); }
        close(fd);
    }

    /* /proc/self/status: 当前进程信息 */
    fd = open("/proc/self/status", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("进程状态:\n%s", buf); }
        close(fd);
    }
    return 0;
}
```

# 12.3 读 `/proc` 编程要点

> 本章：[TLPI 第 12 章 — System and Process Information](../README.md)
> - 上一节：[12.2 `/proc` — Linux 核心特色（非 POSIX）](12.1-proc-filesystem.md)
> - 下一节：[12.4 `sysctl()` 系统调用](12.4-exercises.md)

---

## 本节讲什么

1. 内容**动态变**，多次读可能不一致 2. 行格式 / 字段顺序**无铁律**，跨内核要容错 3. 权限：未必能读别人进程的部分文件

---

## 要点

1. 内容**动态变**，多次读可能不一致  
2. 行格式 / 字段顺序**无铁律**，跨内核要容错  
3. 权限：未必能读别人进程的部分文件  
4. 按**文本行**解析，勿当巨型二进制一次吞  
5. 进程会退出 → 打开时可能已 **ENOENT**  
6. **不要 `mmap` `/proc` 文件**（非普通磁盘文件）

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | /proc 内容动态变、行格式无铁律，跨内核要容错；按文本行解析勿当二进制一次吞；不要 mmap /proc（非普通磁盘文件） |
| HFT | 进程监控读 /proc/[pid]/stat 时进程可能已退出（ENOENT）须处理；高帧率采集要控制读频率，避免 /proc 实时生成拖慢主循环 |

## 代码示例

```c
#include <stdio.h>
#include <stdlib.h>

/* /proc/self/ 下的关键文件 */
int main(void) {
    char buf[4096];

    /* /proc/self/maps: 进程内存映射 */
    FILE *fp = fopen("/proc/self/maps", "r");
    if (fp) {
        printf("=== 内存映射 (前5行) ===\n");
        for (int i = 0; i < 5 && fgets(buf, sizeof(buf), fp); i++)
            printf("%s", buf);
        fclose(fp);
    }

    /* /proc/self/stat: 进程统计信息 */
    fp = fopen("/proc/self/stat", "r");
    if (fp) {
        printf("\n进程 stat: %s", fgets(buf, sizeof(buf), fp) ?: "");
        fclose(fp);
    }

    /* /proc/self/cmdline: 命令行参数 (null 分隔) */
    fp = fopen("/proc/self/cmdline", "r");
    if (fp) {
        printf("\n命令行: ");
        int c;
        while ((c = fgetc(fp)) != EOF)
            putchar(c == '\0' ? ' ' : c);
        putchar('\n');
        fclose(fp);
    }
    return 0;
}
```

## 本节讲什么

早期读写内核参数，对应 `/proc/sys`。 ---

---

## 要点

早期读写内核参数，对应 `/proc/sys`。  
> **新代码不推荐**；直接读写 `/proc/sys/...` 或用命令 `sysctl`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | sysctl(2) 已废弃，新代码直接读写 /proc/sys/ 或用 sysctl 命令调内核参数（如内核调优） |
| HFT | 调内核参数（网络缓冲、调度等）走 /proc/sys 写文件，不用废弃的 sysctl(2)；启动时一次性配置，避免热路径写 /proc/sys |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
#include <fcntl.h>

/* sysctl(2) 已废弃, 现代用 /proc/sys/ 替代 */
int main(void) {
    char buf[256];

    /* /proc/sys/kernel/hostname */
    int fd = open("/proc/sys/kernel/hostname", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("主机名: %s", buf); }
        close(fd);
    }

    /* /proc/sys/kernel/osrelease */
    fd = open("/proc/sys/kernel/osrelease", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("内核版本: %s", buf); }
        close(fd);
    }

    /* /proc/sys/kernel/pid_max */
    fd = open("/proc/sys/kernel/pid_max", O_RDONLY);
    if (fd >= 0) {
        ssize_t n = read(fd, buf, sizeof(buf) - 1);
        if (n > 0) { buf[n] = '\0'; printf("PID 最大值: %s", buf); }
        close(fd);
    }
    return 0;
}
```

## 代码示例

```c
#include <stdio.h>
#include <sys/sysinfo.h>
#include <unistd.h>
/* /proc 文件系统: 内核暴露的进程/系统信息 */
int main(void) {
    /* sysinfo: 系统统计 */
    struct sysinfo si;
    sysinfo(&si);
    printf("uptime=%ld, freeram=%lu MB\n",

    printf("\n/proc/self/status (first 5 lines):\n");
    FILE *fp = fopen("/proc/self/status", "r");
    if (fp) {
        char line[256];
        for (int i = 0; i < 5 && fgets(line, sizeof(line), fp); i++)
            printf("  %s", line);
        fclose(fp);
    }
    return 0;
}
```

# 12.6 `sysinfo()` — Linux

> 本章：[TLPI 第 12 章 — System and Process Information](../README.md)
> - 上一节：[12.5 主机名 / 域名](../../../12.5-modern-networking)
> - 下一节：12.7 `get_nprocs()` — GNU

---

## 本节讲什么

#include <sys/sysinfo.h> struct sysinfo info; int sysinfo(&info);

---

## 要点

```c
#include <sys/sysinfo.h>
struct sysinfo info;
int sysinfo(&info);
```

| 成员 | 含义 |
|------|------|
| `uptime` | 启动以来秒数 |
| `loads[3]` | 1/5/15 负载 |
| `totalram` / `freeram` / … | 内存（注意 **`mem_unit`**） |
| `totalswap` / `freeswap` | 交换区 |

> 老内核有溢出风险；现代监控优先 **`/proc/meminfo`**。  
> 字节数 ≈ 字段 × `mem_unit`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | sysinfo 拿 uptime/负载/内存概览，嵌入式看门狗与监控用；注意字节数 = 字段 × mem_unit，老内核有溢出风险 |
| HFT | 内存/负载监控优先 /proc/meminfo（避免 sysinfo 老内核溢出）；sysinfo 的 loads[] 用于判断系统过载，触发降载/熔断 |

## 代码示例

```c
#include <sys/sysinfo.h>
#include <stdio.h>

int main(void) {
    struct sysinfo info;
    if (sysinfo(&info) != 0) { perror("sysinfo"); return 1; }

    printf("系统运行时间: %ld 秒 (%.1f 天)\n",
           info.uptime, info.uptime / 86400.0);
    printf("总内存: %lu MB\n", info.totalram * info.mem_unit / (1024 * 1024));
    printf("空闲内存: %lu MB\n", info.freeram * info.mem_unit / (1024 * 1024));
    printf("Swap 总量: %lu MB\n", info.totalswap * info.mem_unit / (1024 * 1024));
    printf("进程数: %d\n", info.procs);
    printf("平均负载: %.2f %.2f %.2f\n",
           info.loads[0] / 65536.0,
           info.loads[1] / 65536.0,
           info.loads[2] / 65536.0);
    return 0;
}
```

# 12.7 `get_nprocs()` — GNU

> 本章：[TLPI 第 12 章 — System and Process Information](../README.md)
> - 上一节：12.6 `sysinfo()` — Linux
> - 下一节：12.8 可移植 vs Linux

## 本节讲什么

#include <sys/sysinfo.h> int get_nprocs(void);       /* 当前可用 CPU */ int get_nprocs_conf(void);  /* 配置的 CPU 总数 */

---

## 要点

```c
#include <sys/sysinfo.h>
int get_nprocs(void);       /* 当前可用 CPU */
int get_nprocs_conf(void);  /* 配置的 CPU 总数 */
```

便于多核检测（底层常读 `/proc`）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | get_nprocs/get_nprocs_conf 检测可用 CPU 数，嵌入式多核任务据此分配线程；底层常读 /proc |
| HFT | 交易进程按可用 CPU 数（get_nprocs 而非配置数）绑定亲和性、划分 worker 线程，避免把任务分到被隔离/离线的核 |

## 代码示例

```c
#include <sys/sysinfo.h>
#include <stdio.h>

int main(void) {
    /* get_nprocs: 可用 CPU 数 (GNU 扩展) */
    int nprocs = get_nprocs();
    int nprocs_conf = get_nprocs_conf();

    printf("配置的 CPU 数: %d\n", nprocs_conf);
    printf("可用的 CPU 数: %d\n", nprocs);

    /* 替代: sysconf(_SC_NPROCESSORS_ONLN) */
    long online = sysconf(_SC_NPROCESSORS_ONLN);
    long configured = sysconf(_SC_NPROCESSORS_CONF);
    printf("sysconf: online=%ld, configured=%ld\n", online, configured);
    return 0;
}
```

| **可移植** | `uname`、`gethostname` | 所有 UNIX |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 可移植用 uname/gethostname，Linux 专属用 /proc/sysinfo/get_nprocs 功能全；ps/top/htop 核心数据源都是 /proc |
| HFT | 功能全选 /proc（Linux 固化机房无移植顾虑）；监控工具（ps/top）读 /proc，交易自研监控也可直读 /proc 获取第一手数据 |

## 代码示例

```c
#include <sys/utsname.h>
#include <sys/sysinfo.h>
#include <unistd.h>
#include <stdio.h>

/* 系统信息查询速查 */
int main(void) {
    struct utsname uts;
    uname(&uts);
    printf("系统: %s %s (%s)\n", uts.sysname, uts.release, uts.machine);

    struct sysinfo si;
    sysinfo(&si);
    printf("内存: %lu/%lu MB (free/total)\n",
           si.freeram * si.mem_unit / (1024*1024),
           si.totalram * si.mem_unit / (1024*1024));
    printf("CPU: %d 核, 进程: %d\n", get_nprocs(), si.procs);
    return 0;
}
```

1. **`/proc/[pid]/stat`**：第 2 字段是 `(comm)`；进程名含 `)` 时简易解析会炸  
2. **`cmdline` / `environ`**：`\0` 分隔，不是空格/换行；打印时把 `\0` 换成空格  
3. 勿 `mmap` `/proc`  
4. **`sysinfo` 内存单位**看 `mem_unit`  
5. **容器**里 `/proc` 是命名空间视图，不是宿主机全局  

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | /proc/[pid]/stat 第 2 字段 (comm) 含 ) 时简易解析会炸；cmdline/environ 是 \0 分隔；容器里 /proc 是命名空间视图非宿主机全局 |
| HFT | 容器/命名空间下 /proc 是隔离视图，交易容器读到的 CPU/内存是配额视图而非宿主机；解析 stat 的 comm 字段要正确处理含 ) 的进程名 |

## 代码示例

```c
#include <stdio.h>
#include <sys/utsname.h>
#include <sys/sysinfo.h>
#include <unistd.h>

/* 系统信息三来源:
 * 1. uname() → 内核名称/版本/架构
 * 2. /proc/ → 详细运行时信息 (maps, stat, status...)
 * 3. sysinfo() → 内存/负载/进程数概览
 */
int main(void) {
    struct utsname uts;
    uname(&uts);
    printf("uname: %s %s\n", uts.sysname, uts.machine);

    printf("sysconf OPEN_MAX=%ld, CPU=%ld\n",
           sysconf(_SC_OPEN_MAX),
           sysconf(_SC_NPROCESSORS_ONLN));

    struct sysinfo si;
    sysinfo(&si);
    printf("sysinfo: uptime=%lds, procs=%d\n", si.uptime, si.procs);
    return 0;
}
```
