### 核心要点

1. **永远用 `getaddrinfo`/`getnameinfo`** 替代 `gethostbyname` 等旧函数
2. **协议无关编程**：用 `AF_UNSPEC` 让代码同时支持 IPv4/IPv6
3. **网络字节序**：所有多字节整数传输前必须 `htonl`/`htons`
4. **inet_pton/ntop** 用于 IP 字符串与二进制互转（无 DNS 查询）
5. UNIX 域 socket 比 TCP 快 2-3 倍，本机通信优先用

## 代码自测

<details>
<summary>1. 为什么 getaddrinfo 比 gethostbyname 好？</summary>

getaddrinfo 支持 IPv6、线程安全（可重入）、一个函数替代多个旧函数（gethostbyname + getservbyname）。gethostbyname 只支持 IPv4 且使用静态缓冲区，不可重入。
</details>

<details>
<summary>2. inet_pton 和 getaddrinfo 的区别？</summary>

inet_pton 只将点分 IP 字符串转为二进制，不做 DNS 查询。getaddrinfo 解析主机名（可触发 DNS 查询）并返回完整的 sockaddr 结构链表，支持服务名到端口的转换。
</details>
