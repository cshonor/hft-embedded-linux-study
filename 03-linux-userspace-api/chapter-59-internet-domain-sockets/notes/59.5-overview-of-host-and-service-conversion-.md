# 59.5 主机与服务转换概览

## 本节讲什么

主机名 ↔ IP 地址、服务名 ↔ 端口号的转换 API 概览。

---

## 要点

### 两类转换

| 转换 | 新 API | 旧 API |
|------|--------|--------|
| 主机名 ↔ IP | `getaddrinfo` / `getnameinfo` | `gethostbyname` / `gethostbyaddr` |
| 服务名 ↔ 端口 | `getaddrinfo` / `getnameinfo` | `getservbyname` / `getservbyport` |

### 旧 API 的问题

| 旧 API | 问题 |
|--------|------|
| `gethostbyname` | 不支持 IPv6 |
| `gethostbyaddr` | 不可重入（静态缓冲区） |
| `getservbyname` | 不可重入 |

### 新 API: getaddrinfo / getnameinfo

| 特性 | 优势 |
|------|------|
| IPv4 + IPv6 | 协议无关 |
| 可重入 | 线程安全 |
| 替代多个旧函数 | 一个函数搞定 |

### getaddrinfo 流程

```
主机名 + 服务名 → getaddrinfo → sockaddr 结构链表
```

### getnameinfo 流程

```
sockaddr 结构 → getnameinfo → 主机名 + 服务名字符串
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `getaddrinfo` 可重入，适合多线程环境 |
| HFT | 启动时解析地址一次，运行时直接用 sockaddr，避免 DNS 查询延迟 |

## 代码示例

```c
#include <stdio.h>
#include <netdb.h>
#include <string.h>
/* getaddrinfo: 主机名+服务名 → sockaddr */
int main(void) {
    struct addrinfo hints, *res;
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;      /* IPv4 或 IPv6 */
    hints.ai_socktype = SOCK_STREAM;  /* TCP */

    int err = getaddrinfo("localhost", "80", &hints, &res);
    if (err) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(err));
        return 1;
    }

    /* 遍历所有结果 */
    for (struct addrinfo *p = res; p; p = p->ai_next) {
        char host[NI_MAXHOST], serv[NI_MAXSERV];
        getnameinfo(p->ai_addr, p->ai_addrlen,
                    host, sizeof(host),
                    serv, sizeof(serv),
                    NI_NUMERICHOST | NI_NUMERICSERV);
        printf("addr: %s:%s (family=%d)\n", host, serv, p->ai_family);
    }

    freeaddrinfo(res);
    return 0;
}
```
