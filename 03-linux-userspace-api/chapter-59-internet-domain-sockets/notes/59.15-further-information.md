## 要点

### 参考资源

| 资源 | 说明 |
|------|------|
| RFC 793 | TCP 协议规范 |
| RFC 768 | UDP 协议规范 |
| RFC 3493 | IPv6 基本套接字扩展 |
| Stevens《UNIX 网络编程》 | 网络编程圣经 |
| `man 7 ip` | Linux IP 套接字文档 |
| `man 7 tcp` | Linux TCP 文档 |

### 实用工具

| 工具 | 用途 |
|------|------|
| `ss` / `netstat` | 查看套接字状态 |
| `tcpdump` / `wireshark` | 抓包分析 |
| `nc` (netcat) | 命令行 TCP/UDP 工具 |
| `curl` | HTTP 客户端调试 |
| `strace -e network` | 追踪网络系统调用 |

### 进阶主题

- **SO_REUSEPORT**: 多进程/线程 bind 同一端口（负载均衡）
- **TCP_FASTOPEN**: 减少 TCP 握手延迟
- **零拷贝**: `sendfile` / `MSG_ZEROCOPY`
- **io_uring**: Linux 最新异步 I/O 框架

| 路线 | 要点 |
