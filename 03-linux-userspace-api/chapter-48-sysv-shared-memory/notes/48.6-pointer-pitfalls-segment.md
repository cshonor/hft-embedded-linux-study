## 本节讲什么

各进程映射**虚址可能不同** → 绝对指针在对方无效 → SIGSEGV。 ✅ 只存相对段基址的 **offset**（或固定布局 struct，无堆指针）。 ---

---

## 要点

各进程映射**虚址可能不同** → 绝对指针在对方无效 → SIGSEGV。  
✅ 只存相对段基址的 **offset**（或固定布局 struct，无堆指针）。
