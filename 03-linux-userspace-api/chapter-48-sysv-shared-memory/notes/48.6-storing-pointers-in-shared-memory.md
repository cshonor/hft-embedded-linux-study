# 48.6 陷阱：段内勿存指针

> 本章：[TLPI 第 48 章 — System V Shared Memory](../README.md)

## 本节讲什么

各进程映射**虚址可能不同** → 绝对指针在对方无效 → SIGSEGV。 ✅ 只存相对段基址的 **offset**（或固定布局 struct，无堆指针）。 ---

---

## 要点

各进程映射**虚址可能不同** → 绝对指针在对方无效 → SIGSEGV。  
✅ 只存相对段基址的 **offset**（或固定布局 struct，无堆指针）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 陷阱：段内勿存指针 在嵌入式系统的应用场景 |
| HFT | 陷阱：段内勿存指针 对低延迟和性能的影响 |

## 代码示例

```c
#include <stdio.h>
#include <sys/shm.h>
#include <string.h>
/* 共享内存中的指针陷阱: 不能存指针! */
typedef struct {
    int count;
    char name[64];
    /* 不要在这里放指针! */
    /* char *ptr;  // 错误: 指针在不同进程中地址不同 */
} shared_data_t;

int main(void) {
    int shmid = shmget(IPC_PRIVATE, sizeof(shared_data_t),
                       IPC_CREAT | 0666);
    shared_data_t *data = shmat(shmid, NULL, 0);

    /* 正确: 使用偏移量或内联数据 */
    data->count = 42;
    strcpy(data->name, "inline data (OK)");

    printf("count=%d name=%s\n", data->count, data->name);

    /* 陷阱: 如果在共享内存中存了指针, 指针值在另一个进程中无效 */
    /* 因为不同进程的地址空间布局不同 */
    printf("\nPointer pitfall: pointers in shared memory are INVALID\n");
    printf("  Use offsets or inline data instead\n");

    shmdt(data);
    shmctl(shmid, IPC_RMID, NULL);
    return 0;
}
```
