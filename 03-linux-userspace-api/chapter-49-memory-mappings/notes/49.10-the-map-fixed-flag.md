# 49.10 MAP_FIXED 标志

> 本章：[TLPI 第 49 章 — 内存映射](../README.md)

## 本节讲什么

`MAP_FIXED` — 强制 mmap 在指定地址创建映射，覆盖已有映射。

---

## 要点

### 行为

```c
void *p = mmap(addr, length, prot, flags|MAP_FIXED, fd, offset);
```
- `addr` 必须页对齐
- 如果 `[addr, addr+length)` 已有映射 → **静默覆盖**
- 返回值等于 `addr`（成功）或 `MAP_FAILED`（失败）

### 危险性

- **覆盖已有映射**（包括栈、代码段等）→ 段错误
- 必须确保 `addr` 区域空闲
- 可移植性差：不同 UNIX 行为不一致

### 何时使用

| 场景 | 用途 |
|------|------|
| 动态链接器 | 在固定地址加载共享库 |
| 自定义内存布局 | 线程栈、自定义分配器 |
| 兼容旧代码 | 需要固定地址的遗留程序 |

### 推荐做法

- **不要直接用 `MAP_FIXED`** — 太危险
- 用 `mmap(NULL, ...)` 获取地址，再检查是否在期望范围
- Linux 4.17+ 提供 `MAP_FIXED_NOREPLACE`：不覆盖已有映射

### MAP_FIXED_NOREPLACE (Linux 4.17+)

```c
/* 如果地址已被占用, 失败而非覆盖 */
p = mmap(hint_addr, length, prot, MAP_FIXED_NOREPLACE|flags, fd, offset);
```

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 固定地址映射用于访问硬件寄存器（如 `/dev/mem`） |
| HFT | 不常用，固定地址映射可移植性差 |

## 代码示例

```c
#include <stdio.h>
#include <sys/mman.h>
#include <string.h>
/* MAP_FIXED: 在指定地址创建映射 (危险!) */
int main(void) {
    /* 先正常映射一块内存 */
    char *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE,
                   MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
    strcpy(p, "original");

    /* 用 MAP_FIXED 在同一地址重新映射 */
    char *q = mmap(p, 4096, PROT_READ|PROT_WRITE,
                   MAP_PRIVATE|MAP_ANONYMOUS|MAP_FIXED, -1, 0);
    if (q == MAP_FAILED) { perror("mmap FIXED"); return 1; }

    printf("p=%p, q=%p (same address)\n", p, q);
    /* 原内容被覆盖 */
    printf("content after MAP_FIXED: '%s' (empty = overwritten)\n", q);

    munmap(q, 4096);
    return 0;
}
```
