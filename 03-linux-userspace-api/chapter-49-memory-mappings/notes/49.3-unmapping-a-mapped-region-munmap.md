# 49.3 解除映射：munmap()

> 本章：[TLPI 第 49 章 — 内存映射](./README.md)

## 本节讲什么

`munmap()` — 解除内存映射，释放虚拟地址空间。

---

## 要点

### API

```c
int munmap(void *addr, size_t length);
```
- 解除从 `addr` 开始、长度 `length` 的映射
- `addr` 必须页对齐
- `length` 自动向上取整到页边界
- 成功返回 0，失败返回 -1

### 核心行为

| 行为 | 说明 |
|------|------|
| 解除映射 | 虚拟地址空间不再有效 |
| 丢弃修改 | MAP_PRIVATE 的修改被丢弃 |
| 写回文件 | MAP_SHARED 的脏页写回文件（异步） |
| 部分解除 | 可以只解除部分区域 |
| 进程退出 | 自动 munmap 所有映射 |

### 部分解除

```c
/* 映射 4 页 */
char *p = mmap(NULL, 4096*4, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);

/* 解除中间 2 页 */
munmap(p + 4096, 4096*2);
/* 现在: p[0..4095] 映射, p[4096..8191] 解除, p[8192..12287] 映射 */
```

### 注意事项

- munmap 不会立即写回脏页（MAP_SHARED），需要 `msync` 确保落盘
- munmap 后访问该区域 → SIGSEGV
- `addr` 不对齐 → 失败，errno = EINVAL
- 可以 munmap 一段未映射的区域（静默成功）

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 及时 munmap 释放虚拟地址空间，避免耗尽 |
| HFT | mmap 共享内存区域在生命周期结束时立即 munmap，防止悬空引用 |

## 代码示例

```c
#include <stdio.h>
#include <sys/mman.h>
#include <fcntl.h>
#include <unistd.h>
#include <string.h>
/* munmap: 解除内存映射 */
int main(void) {
    int fd = open("/tmp/test_mmap", O_RDWR|O_CREAT|O_TRUNC, 0644);
    write(fd, "hello mmap", 10);

    /* 映射 */
    char *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    if (p == MAP_FAILED) { perror("mmap"); return 1; }
    printf("mapped: %.10s\n", p);

    /* 修改 */
    memcpy(p, "HELLO", 5);

    /* 解除映射 */
    if (munmap(p, 4096) == 0) {
        printf("munmap: success\n");
    }

    /* p 不再有效, 访问会 SIGSEGV */
    close(fd);
    unlink("/tmp/test_mmap");
    return 0;
}
```
