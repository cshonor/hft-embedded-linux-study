### 核心要点

1. `mmap` 两大用途：文件映射（I/O 高效）+ 匿名映射（共享内存）
2. `MAP_SHARED` fork 后共享，`MAP_PRIVATE` fork 后 COW
3. 匿名共享映射是父子 IPC 最简单方式
4. `msync` 确保 MAP_SHARED 脏页落盘
5. `mremap` 扩展映射避免拷贝（Linux 特有）
6. MAP_FIXED 危险，优先用 `MAP_FIXED_NOREPLACE`

## 代码自测

<details>
<summary>1. MAP_SHARED 和 MAP_PRIVATE 的区别？</summary>

MAP_SHARED：多个进程映射同一文件区域时共享同一物理页，写入对其他进程可见且写回文件。MAP_PRIVATE：写入触发 COW（copy-on-write），每个进程有独立副本，修改不影响其他进程和文件。
</details>

<details>
<summary>2. 匿名共享映射如何实现父子进程通信？</summary>

父进程用 `mmap(NULL, size, PROT_READ|PROT_WRITE, MAP_SHARED|MAP_ANONYMOUS, -1, 0)` 创建共享映射，fork 后子进程继承同一映射，父子共享同一物理内存，写入互相可见。
</details>
