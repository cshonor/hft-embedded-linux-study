### 反直觉真相 TOP 5

1. **PRIVATE 未写过的页跟随 page cache**——copy-on-write 不是 copy-on-access；「以为的快照」只在写过之后存在（实测三连 v1→v3）。
2. **写页内 1 字节 = 整页 COW**——COW 粒度是页（v2 实测意外发现）。
3. **MS_ASYNC 是 no-op**——TLPI 时代语义已被内核自动回写取代；确定性落盘只有 MS_SYNC。
4. **mremap 搬家零拷贝**——搬的是页表不是数据；DONTUNMAP 让旧虚址变零页（不是保留旧数据）。
5. **munmap 中间一页 → VMA 分裂成两个**——但相邻同 flags 的分配又会 merge 回去（实验 A 的 vma_merge 活体演示）。

### mmap vs read/write（延续 49.1 的对比）

| 维度 | read/write | mmap |
|------|-----------|------|
| 路径 | syscall + 页缓存 ↔ 用户缓冲两次拷贝 | 缺页直连页缓存，访问即 I/O |
| 小文件顺序读 | 系统调用摊薄后往往更快 | 首触缺页贵，未必赢 |
| 随机大文件 | 每次 read syscall | 页缓存命中后纯内存访问 |
| 崩溃一致性 | fsync 语义清晰 | msync + SIGBUS 风险（truncate） |
| 共享 | 借 SHARED 映射或 IPC | 天然（page cache 唯一真相） |

## 自测题

**题目（综合）：** 一句话各答——① mmap 后 Rss 是多少？② PRIVATE 读到别人修改的条件？③ MS_ASYNC 现在是什么？④ mremap 搬家搬的是什么？⑤ DONTUNMAP 后旧地址读到什么？

<details>
<summary>参考答案</summary>

① 0（画区不填页，POPULATE 例外）；② 该页自己从未写过（PTE 还指 page cache 原页）；③ no-op（2.6.19 起内核自动回写）；④ 页表项（物理页不动，零拷贝）；⑤ 全 0（空壳 VMA + 零页，旧数据不保留）。
