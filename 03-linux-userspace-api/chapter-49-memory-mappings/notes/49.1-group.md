## 要点

| | `MAP_PRIVATE` | `MAP_SHARED` |
|--|---------------|--------------|
| **文件** | COW；改不回文件；加载 text/只读文件 | 改可见且可回盘；无关进程 IPC |
| **匿名** | 私有堆式分配（malloc 一类） | **仅亲缘**（fork 继承）IPC |

生命周期：`fork` 继承映射；**`exec` / 退出** 销毁全部映射。
