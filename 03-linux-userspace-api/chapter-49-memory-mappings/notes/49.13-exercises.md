## 练习题

### 练习 1：共享内存计数器（fork IPC）

用 `MAP_SHARED|MAP_ANONYMOUS` 实现父子计数器，各加 10000 次，观察竞态。

### 练习 2：解释计数器为什么不是 20000

`(*counter)++` 非原子——丢失更新。

### 练习 3：mmap 映射的文件被 truncate 会怎样？

访问被截掉的部分触发 `SIGBUS`（映射合法但页无后备）。

### 实验 4（实测）：mmap 生命周期三态 + VMA 分裂

mmap 3 页 → 未触碰/读触碰/写触碰三态的 Rss 演化；munmap 中间页观察 maps 条数 1→2。

### 实验 5（实测）：PRIVATE vs SHARED 可见性三连

对照页设计（页 0 不写 / 页 1 预写 'K'）：fork 后子改 SHARED，父读 PRIVATE——页 0 跟随 page cache、页 1 COW 快照定格。

### 实验 6（实测）：mremap 全景 + MAP_FIXED_NOREPLACE

自造空洞原地扩展 / 紧贴阻挡 ENOMEM / MAYMOVE 搬家 / 收缩 / DONTUNMAP 旧址零填充 / NOREPLACE EEXIST。

### 实验 7（实测）：MAP_POPULATE 预填充对比

lazy 与 populate 各 16MB：Rss 0 vs 16384 kB；memset 首触 15ms vs 1ms。

## 参考答案

### 练习 1 参考代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <sys/mman.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void)
{
    int *counter = mmap(NULL, sizeof(int), PROT_READ | PROT_WRITE,
                        MAP_SHARED | MAP_ANONYMOUS, -1, 0);
    if (counter == MAP_FAILED) { perror("mmap"); return 1; }
    *counter = 0;

    pid_t pid = fork();
    if (pid == 0) {
        for (int i = 0; i < 10000; i++) (*counter)++;
        _exit(0);
    }
    for (int i = 0; i < 10000; i++) (*counter)++;
    wait(NULL);
    /* 注意: 结果可能不是 20000, 因为 ++ 不是原子操作 */
    printf("counter: %d (race condition: not 20000)\n", *counter);
    return 0;
}
```

### 练习 2 答案

`(*counter)++` 是读-改-写三步操作，非原子。父子进程可能同时读到相同值，各自加 1 后写回，导致丢失更新。修复：信号量（Ch53）/文件锁（Ch55）/`__sync_fetch_and_add` 原子操作/带 mutex 的 pthread 共享（Ch30）。

### 练习 3 答案

访问被截断的部分触发 **SIGBUS**：虚址在 VMA 内（映射合法），但缺页处理发现 offset ≥ i_size（无后备数据页），发 SIGBUS。与 SIGSEGV（VMA 不存在）是两个不同层次的死法。防护：访问前对 `fstat` 的大小做区间校验，或捕获 SIGBUS（sigsetjmp 方案，见 49.4 实测）。

### 实验 4 参考代码（实测：2026-09-05，WSL Ubuntu，gcc -O2 -Wall -Wextra 零告警）

完整代码见 [49.2 代码示例](49.2-creating-a-mapping-mmap.md) 与 [49.3 代码示例](49.3-unmapping-a-mapped-region-munmap.md)。实测输出：

```
步骤1 mmap p=0x7ef676812000（未触碰，两侧 guard 为 PROT_NONE）
  [未触碰] VMA条数=1  Rss=0 kB
步骤2 读触碰第 0 页（do_anonymous_page 走零页分支）
  [读触碰] VMA条数=1  Rss=0 kB
步骤3 写触碰第 0 页（分配私有物理页）
  [写触碰] VMA条数=1  Rss=4 kB
步骤4 munmap 中间页（VMA 分裂）
  [分裂后] VMA条数=2  Rss=4 kB
步骤5 close(fd) 后读文件映射："FDLIFE" ← fd 已关，映射仍存活
```

**三个教学点**：
1. 画区≠填页：mmap 后 Rss=0，物理页零消耗
2. 零页不计 RSS：读触碰后 Rss 仍 0（零页全系统共享一份）；写触碰才 4 kB
3. munmap 中间页 → VMA 分裂（`do_vmi_align_munmap` 两端切割）；PROT_NONE guard 防相邻 vma_merge 吞并观察区

### 实验 5 参考代码

完整代码见 [49.4 代码示例](49.4-file-mappings.md)。实测输出：

```
fork 后父观察:
  priv[0]='S'（页 0 未写→跟随 page cache）
  priv[4096]='K'（页 1 写过→整页 COW 快照）
  shar[0]='S' shar[4096]='T'（SHARED 全局可见）
文件截断到 1 页，访问映射第 2 页 shar[4096]……捕获 SIGBUS ✓
```

**实验设计的进化史**（本批最重要的方法论）：
- v1：priv[0] 预写 'O'，实测读到 'S'——**推翻**「PRIVATE=快照」直觉
- v2：priv[1] 预写 'K' 后 priv[0] 读回 'O'——**意外发现** COW 粒度是页（同页写定格整页）
- v3：对照组放**不同页**——两个结论同时验证

### 实验 7 参考代码（实测：2026-09-05）

```c

/* MAP_POPULATE vs 惰性映射：Rss 与首触耗时
 * 实测（WSL Ubuntu，gcc -O2 -Wall -Wextra，2026-09-05）：
 *   lazy     mmap 后 Rss=0 kB
 *   populate mmap 后 Rss=16384 kB
 *   lazy     区 memset 首触 15 ms（4096 次缺页）
 *   populate 区 memset      1 ms（纯写内存）——15 倍差
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void)
{
    size_t len = 16UL << 20;                 /* 16MB = 4096 页 */

    char *lazy = mmap(NULL, len, PROT_READ | PROT_WRITE,
                      MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
    char *pop  = mmap(NULL, len, PROT_READ | PROT_WRITE,
                      MAP_PRIVATE | MAP_ANONYMOUS | MAP_POPULATE, -1, 0);
    if (lazy == MAP_FAILED || pop == MAP_FAILED) { perror("mmap"); return 1; }

    struct timespec t0, t1;
    clock_gettime(CLOCK_MONOTONIC, &t0);
    memset(lazy, 1, len);                    /* 首触：4096 次缺页 */
    clock_gettime(CLOCK_MONOTONIC, &t1);
    printf("lazy     memset %ld ms\n",
           (t1.tv_sec - t0.tv_sec) * 1000 + (t1.tv_nsec - t0.tv_nsec) / 1000000);

    clock_gettime(CLOCK_MONOTONIC, &t0);
    memset(pop, 1, len);                     /* 无缺页 */
    clock_gettime(CLOCK_MONOTONIC, &t1);
    printf("populate memset %ld ms\n",
           (t1.tv_sec - t0.tv_sec) * 1000 + (t1.tv_nsec - t0.tv_nsec) / 1000000);

    munmap(lazy, len);
    munmap(pop, len);
    return 0;
}
```

（Rss 口径验证的 smaps 解析版见 [49.6 代码示例](49.6-additional-mmap-flags.md)。）
