# 49.13 练习题

> 本章：[TLPI 第 49 章 — 内存映射](./README.md)

## 本节讲什么

原书第 49 章练习题要点。

<details>
<summary>1. 用 mmap 实现一个简单的共享内存计数器，父子进程各加 10000 次</summary>

```c
int *counter = mmap(NULL, sizeof(int), PROT_READ|PROT_WRITE,
                    MAP_SHARED|MAP_ANONYMOUS, -1, 0);
*counter = 0;
if (fork() == 0) {
    for (int i = 0; i < 10000; i++) (*counter)++;
    _exit(0);
}
for (int i = 0; i < 10000; i++) (*counter)++;
wait(NULL);
/* 注意: 结果可能不是 20000, 因为 ++ 不是原子操作 */
printf("counter: %d (race condition: not 20000)\n", *counter);
```
</details>

<details>
<summary>2. 为什么上述计数器结果可能不正确？</summary>

`(*counter)++` 是读-改-写三步操作，非原子。父子进程可能同时读到相同值，各自加 1 后写回，导致丢失更新。需要用信号量或原子操作（`__sync_fetch_and_add`）保证原子性。
</details>

<details>
<summary>3. mmap 映射文件后，文件被 truncate 会怎样？</summary>

访问被截断的部分会触发 `SIGBUS` 信号。因为文件实际大小不够，内核无法提供数据页。解决方法：在访问映射区域前检查文件大小，或注册 `SIGBUS` 信号处理函数。
</details>
