## 要点

```c
int msync(void *addr, size_t length, int flags);
```

`MS_SYNC` 阻塞落盘 · `MS_ASYNC` 后台 · `MS_INVALIDATE` 作废缓存。  
仅对 **SHARED** 有意义。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 掉电保护：关键配置/日志 MS_SYNC 强制落 flash；MS_INVALIDATE 同步外设缓存一致性 |
| HFT | 热路径不碰 msync；审计/持久化日志用 MS_ASYNC 后台刷盘，避免阻塞引入延迟毛刺 |

## 代码示例

```c

/* msync 三种模式：MS_SYNC / MS_ASYNC / MS_INVALIDATE */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void) {
    int fd = open("/tmp/ch49_msync.txt", O_RDWR | O_CREAT | O_TRUNC, 0644);
    ftruncate(fd, 4096);
    char *m = mmap(NULL, 4096, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if (m == MAP_FAILED) { perror("mmap"); exit(1); }

    strcpy(m, "msync demo data");

    /* MS_SYNC：同步刷盘，阻塞直到写回完成 */
    if (msync(m, 4096, MS_SYNC) < 0) perror("msync MS_SYNC");
    printf("MS_SYNC done — data flushed to disk\n");

    /* MS_ASYNC：异步刷盘，立即返回 */
    strcpy(m, "async update");
    if (msync(m, 4096, MS_ASYNC) < 0) perror("msync MS_ASYNC");
    printf("MS_ASYNC submitted\n");

    munmap(m, 4096);
    close(fd);
    return 0;
}

```
