# 49.7 匿名映射

## 本节讲什么

匿名映射 — 不关联任何文件的内存映射，用于分配初始化为零的内存或进程间共享内存。

---

## 要点

### 两种匿名映射方式

| 方式 | flags | 可移植性 |
|------|-------|----------|
| `MAP_ANONYMOUS` | `MAP_SHARED\|MAP_ANONYMOUS`, fd=-1 | Linux/BSD（非 POSIX） |
| `/dev/zero` | 映射 `/dev/zero` 文件 | POSIX 可移植 |

### MAP_SHARED vs MAP_PRIVATE 匿名映射

| | `MAP_SHARED\|MAP_ANONYMOUS` | `MAP_PRIVATE\|MAP_ANONYMOUS` |
|--|----------------------------|------------------------------|
| 用途 | 父子进程共享内存 | 分配零初始化内存 |
| fork 后 | 子进程共享同一映射 | 子进程获得 COW 副本 |
| 等价于 | 共享内存 IPC | 类似 `malloc`（但无 free） |

### 典型用法：父子进程共享内存

```c
/* MAP_ANONYMOUS | MAP_SHARED: fork 后父子共享 */
int *shared = mmap(NULL, sizeof(int), PROT_READ|PROT_WRITE,
                   MAP_SHARED|MAP_ANONYMOUS, -1, 0);
*shared = 0;
if (fork() == 0) {
    *shared = 42;  /* 子进程写 */
    _exit(0);
}
wait(NULL);
printf("parent sees: %d\n", *shared);  /* 42 */
```

### 与 malloc 的区别

| | `malloc` | `mmap(MAP_ANONYMOUS)` |
|--|---------|----------------------|
| 可 free | 是 | 否（需 munmap） |
| 粒度 | 任意大小 | 页对齐（4KB） |
| 共享 | 否 | 可（MAP_SHARED） |
| 初始化 | 不保证 | 零初始化 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 匿名共享映射是父子进程 IPC 最简单方式 |
| HFT | `MAP_SHARED\|MAP_ANONYMOUS` 用于父子进程共享行情数据，零拷贝 |

## 代码示例

```c
#include <stdio.h>
#include <sys/mman.h>
#include <unistd.h>
#include <sys/wait.h>
/* 匿名共享映射: 父子进程通信 */
int main(void) {
    /* 分配共享内存 */
    int *shared = mmap(NULL, sizeof(int), PROT_READ|PROT_WRITE,
                       MAP_SHARED|MAP_ANONYMOUS, -1, 0);
    if (shared == MAP_FAILED) { perror("mmap"); return 1; }
    *shared = 100;

    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程: 修改共享内存 */
        *shared += 50;
        printf("child: shared = %d\n", *shared);
        _exit(0);
    }
    wait(NULL);
    printf("parent: shared = %d\n", *shared);  /* 150 */

    munmap(shared, sizeof(int));
    return 0;
}
```
