## 本节讲什么

原书第 23 章练习题要点。

<details>
<summary>1. 实现 buftimedread 函数：在指定时间内从 stdin 读取一行，超时返回</summary>

```c
ssize_t buftimedread(char *buf, size_t len, struct timespec *timeout) {
    fd_set rfds;
    FD_ZERO(&rfds);
    FD_SET(STDIN_FILENO, &rfds);

    int ret = pselect(STDIN_FILENO + 1, &rfds, NULL, NULL, timeout, NULL);
    if (ret <= 0) return -1;  /* 超时或错误 */

    return read(STDIN_FILENO, buf, len);
}
```
用 `pselect` 而非 `select` + `alarm`，避免信号竞态。
</details>

<details>
<summary>2. setitimer 和 timer_create 各能创建多少个定时器？</summary>

setitimer 每进程只有 3 个（ITIMER_REAL、ITIMER_VIRTUAL、ITIMER_PROF），因为它们是固定编号的全局资源。timer_create 可创建无限多个（受系统资源限制），每个返回独立的 timer_t。
</details>

<details>
<summary>3. timer_getoverrun 返回什么？什么时候需要检查它？</summary>

返回自上次通知以来"丢失"的超时次数。当使用 SIGEV_SIGNAL 通知标准信号时，信号不排队，多次超时可能只通知一次。在 handler 中调用 timer_getoverrun 获取丢失次数，以修正时间计算。
</details>
