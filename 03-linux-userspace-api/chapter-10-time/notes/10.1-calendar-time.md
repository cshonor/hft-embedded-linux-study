# 10.1 Calendar Time

> 本章：[TLPI 第 10 章](./README.md)

## 本节讲什么

日历时间：从 Epoch(1970-01-01 00:00:00 UTC) 起的秒数。

### API
- `time()` — 秒级精度
- `gettimeofday()` — 微秒级精度（已废弃，推荐 clock_gettime）
- `clock_gettime(CLOCK_REALTIME, &ts)` — 纳秒级精度

### timespec 结构
```c
struct timespec {
    time_t   tv_sec;    // 秒
    long     tv_nsec;   // 纳秒 [0, 999999999]
};
```
