## 本节讲什么

本章回顾时间 API。

| 时间类型 | API | 精度 |
|---------|-----|------|
| 日历时间 | time()/clock_gettime() | 秒~纳秒 |
| 时间转换 | localtime()/strftime() | - |
| 进程时间 | times()/clock() | 时钟滴答 |
| 定时器 | timer_create()/timerfd | 纳秒 |
