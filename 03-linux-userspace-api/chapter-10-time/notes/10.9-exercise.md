### 练习 1：代码执行时间测量

编写程序，使用 `clock_gettime(CLOCK_MONOTONIC)` 测量一段代码的执行时间（纳秒级）。

**要求**：
- 实现一个计时器宏/函数，支持开始和结束
- 测量一个循环的执行时间
- 同时用 `CLOCK_MONOTONIC_RAW` 对比，观察 NTP 调整的影响
- 打印纳秒级结果

### 练习 2：CLOCK_REALTIME vs CLOCK_MONOTONIC

解释 `CLOCK_REALTIME` 和 `CLOCK_MONOTONIC` 的区别，在什么场景下应该用哪个？

### 练习 3：时间格式化

编写程序，获取当前时间并格式化输出为 "2026-08-12 19:30:45.123456" 格式（带微秒）。

## 参考答案

### 练习 1 参考代码

```c
#include <time.h>
#include <stdio.h>

#define TIMING_START(ts) clock_gettime(CLOCK_MONOTONIC, &(ts))
#define TIMING_NS(start, end) \
    (((end).tv_sec - (start).tv_sec) * 1000000000LL \
   + ((end).tv_nsec - (start).tv_nsec))

int main(void) {
    struct timespec start, end, raw_start, raw_end;

    clock_gettime(CLOCK_MONOTONIC, &start);
    clock_gettime(CLOCK_MONOTONIC_RAW, &raw_start);

    /* 待测代码：计算 sum */
    volatile long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++) sum += i;

    clock_gettime(CLOCK_MONOTONIC, &end);
    clock_gettime(CLOCK_MONOTONIC_RAW, &raw_end);

    long long ns_monotonic = TIMING_NS(start, end);
    long long ns_raw       = TIMING_NS(raw_start, raw_end);

    printf("CLOCK_MONOTONIC     : %lld.%09lld s (%lld ns)\n",
           ns_monotonic / 1000000000LL, ns_monotonic % 1000000000LL, ns_monotonic);
    printf("CLOCK_MONOTONIC_RAW : %lld.%09lld s (%lld ns)\n",
           ns_raw / 1000000000LL, ns_raw % 1000000000LL, ns_raw);
    printf("diff                 : %lld ns\n", ns_monotonic - ns_raw);
    return 0;
}
```

### 练习 2 答案

| 特性 | CLOCK_REALTIME | CLOCK_MONOTONIC |
|------|---------------|-----------------|
| 含义 | 实际日期时间 | 从启动起单调递增 |
| 单调性 | 否（可能跳变） | 是（单调递增） |
| 受 settimeofday 影响 | 是 | 否 |
| 受 adjtime 影响 | 是 | 是（平滑调整速率） |
| 起点 | 1970-01-01 UTC | 未定义（通常系统启动） |

**使用场景**：
- **CLOCK_REALTIME**：需要日期时间的场景（日志时间戳、文件 mtime、定时唤醒到特定时刻）
- **CLOCK_MONOTONIC**：测量时间间隔（延迟、性能、超时），绝不能用于计算日期

### 练习 3 参考代码

```c
#include <time.h>
#include <stdio.h>

int main(void) {
    struct timespec ts;
    clock_gettime(CLOCK_REALTIME, &ts);

    struct tm tm_buf;
    localtime_r(&ts.tv_sec, &tm_buf);

    /* 格式: 2026-08-12 19:30:45.123456 */
    char buf[64];
    strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", &tm_buf);
    printf("%s.%06ld\n", buf, ts.tv_nsec / 1000);  /* 纳秒→微秒 */
    return 0;
}
```

## HFT / 嵌入式关联

- **延迟测量**：HFT 每条消息记录 `CLOCK_MONOTONIC` 时间戳用于延迟分析
- **TSC 直接读取**：x86 用 `rdtsc` 指令避免系统调用开销（约 20-40ns vs 200ns+）
- **嵌入式 ARM**：用 `CNTVCT_EL0` 或 Generic Timer
- **PTP 时间戳**：HFT 行情数据带交换机硬件时间戳（IEEE 1588）
