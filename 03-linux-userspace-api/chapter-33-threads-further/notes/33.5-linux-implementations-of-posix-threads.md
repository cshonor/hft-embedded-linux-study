## 本节讲什么

勿混：`pthread_t` ≠ 内核 TID（`gettid`）。 ---

---

## 要点

| | LinuxThreads（废） | **NPTL**（现行） |
|--|-------------------|------------------|
| PID | 每线程一 PID（非 POSIX） | 同进程 TGID 相同；独立 TID |
| 信号 | 怪异 | POSIX 语义 |
| 同步 | — | 常基于 futex |

勿混：`pthread_t` ≠ 内核 TID（`gettid`）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | NPTL 现行，同进程共享 TGID、独立 TID |
| HFT | NPTL 同步基于 futex（无竞争不陷内核）；pthread_t ≠ TID |

## 代码示例

```c
#include <pthread.h>
#include <stdio.h>
int main(void) {
    /* LinuxThreads (旧) vs NPTL (新):
     * LinuxThreads: 每个线程有不同 PID, 信号处理有问题
     * NPTL (2.6+): 同进程线程共享 PID, 符合 POSIX
     */
    pthread_t tid;
    pthread_create(&tid, NULL, (void *(*)(void *))sleep, (void *)0);
    printf("PID=%d (NPTL: 线程共享 PID)\n", getpid());
    pthread_join(tid, NULL);
    return 0;
}
```
