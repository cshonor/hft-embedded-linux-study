## 要点

| 模型 | 要点 |
|------|------|
| M:1 | 用户级；快；难多核；阻塞拖死全体 |
| **1:1** | Linux NPTL；每 pthread ≈ 一内核任务；可多核 |
| M:N | 复杂；Linux 未走 |
