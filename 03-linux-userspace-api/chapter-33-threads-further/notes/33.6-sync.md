## 要点

| 原语 | 用途 |
|------|------|
| `pthread_rwlock_t` | 读共享、写独占 |
| `pthread_barrier_t` | 集合点；一人得 `PTHREAD_BARRIER_SERIAL_THREAD` |
| `pthread_spinlock_t` | 短临界区忙等 |
| `PTHREAD_PROCESS_SHARED` | 放共享内存可跨进程 |
