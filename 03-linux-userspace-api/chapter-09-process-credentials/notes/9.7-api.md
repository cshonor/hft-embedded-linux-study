## 本节讲什么

#include <unistd.h> #include <sys/types.h> uid_t getuid(void);      /* RUID */

---

## 要点

```c
#include <unistd.h>
#include <sys/types.h>

uid_t getuid(void);      /* RUID */
uid_t geteuid(void);     /* EUID */
gid_t getgid(void);      /* RGID */
gid_t getegid(void);     /* EGID */

#define _GNU_SOURCE
#include <unistd.h>
int getresuid(uid_t *ruid, uid_t *euid, uid_t *suid);
int getresgid(gid_t *rgid, gid_t *egid, gid_t *sgid);

int getgroups(int size, gid_t list[]);  /* size==0 时返回组个数 */
```

FUID 无标准 getter；现代可视为 = EUID（除非调用过 `setfsuid`）。

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
/* setuid/seteuid/setreuid/setresuid 的区别 */
int main(void) {
    uid_t ruid = getuid();
    uid_t euid = geteuid();
    printf("before: real=%u eff=%u\n", (unsigned)ruid, (unsigned)euid);

    /* seteuid: 只改 effective (最常用, 最安全) */
    /* setuid: root 下改全部三个; 普通用户只改 effective */
    /* setreuid: 交换/设置 real 和 effective */
    /* setresuid: 分别设置三个 */

    /* 普通用户演示: seteuid 到自己的 real uid */
    seteuid(ruid);
    printf("after seteuid(ruid): eff=%u\n", (unsigned)geteuid());
    return 0;
}
```

# 9.6 –9.7 修改凭证（重难点）

> 本章：[TLPI 第 09 章 — Process Credentials](../README.md)
> - 上一节：[9.5 获取凭证 API](9.5-fs-uid-gid.md)
> - 下一节：[9.8 fork / exec 对凭证（必考）](9.8-summary.md)

---

## 本节讲什么

`setgid` / `setegid` / `setregid` / `setresgid` 与上表对称（UID→GID）。 历史：BSD → SUSv3 → Linux 扩展；能力递增，旧接口保留兼容。 新代码在 Linux 上若需精细控制：优先想清要不要 **`seteuid`（临时）** 还是 **`setresuid`（一次钉死 R/E/S）**。

---

## 要点

> **特权进程 = EUID==0**（不是 RUID==0）。  
> 参数 **`-1`** = 该项不改（`setreuid` / `setresuid` 系）。

### 对比总表

| 调用 | 改什么 | 特权进程 (EUID=0) | 非特权（含 setuid 程序） |
|------|--------|-------------------|--------------------------|
| `setuid(uid)` | 视情况 | **R+E+S 全改为 uid** | 仅能改 **EUID** → `uid` 须为 RUID 或 Saved-UID |
| `seteuid(e)` | 仅 EUID | 任意合法 uid | 仅能设为 **RUID 或 Saved-UID** |
| `setreuid(r,e)` | R 与/或 E | 能力更宽（见 man） | 受 R/Saved 约束；规则细看 `man 2 setreuid` |
| `setresuid(r,e,s)` | R/E/S 各独立 | 任意组合（`-1` 跳过） | 每项只能是当前 R/E/S 之一等（见 man）；**Linux 扩展** |
| `setfsuid` / `setfsgid` | FUID/FGID | 见 man | 几乎不用 |
| `setgroups` | 补充组列表 | 可改 | **失败**（需特权） |

`setgid` / `setegid` / `setregid` / `setresgid` 与上表对称（UID→GID）。

### 为何有这么多接口？

历史：BSD → SUSv3 → Linux 扩展；能力递增，旧接口保留兼容。  
新代码在 Linux 上若需精细控制：优先想清要不要 **`seteuid`（临时）** 还是 **`setresuid`（一次钉死 R/E/S）**。

Demo：[`code/seteuid_drop_restore.c`](../code/seteuid_drop_restore.c)（需自行 `chmod u+s` + 属主 root 才能看全路径）

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

/* setuid-root 程序示范: 临时降权 → 做普通工作 → 恢复特权
 * 编译: gcc -o demo 9.6-credentials.c
 * 设置: sudo chown root demo && sudo chmod u+s demo
 */
int main(void) {
    uid_t ruid = getuid();
    uid_t euid = geteuid();

    printf("初始: RUID=%d EUID=%d\n", ruid, euid);

    if (euid == 0) {
        /* 有特权 → 临时降为普通用户 */
        printf("降权: seteuid(%d)\n", ruid);
        if (seteuid(ruid) != 0) { perror("seteuid drop"); return 1; }
        printf("现在: RUID=%d EUID=%d (普通权限)\n", getuid(), geteuid());

        /* 在普通权限下做不安全的操作... */

        /* 恢复特权 (因为 Saved-ID 仍为 0) */
        printf("恢复: seteuid(0)\n");
        if (seteuid(0) != 0) { perror("seteuid restore"); return 1; }
        printf("现在: RUID=%d EUID=%d (恢复特权)\n", getuid(), geteuid());

        /* 永久丢弃特权 (做完后) */
        printf("永久丢弃: setuid(%d)\n", ruid);
        if (setuid(ruid) != 0) { perror("setuid permanent"); return 1; }
        printf("现在: RUID=%d EUID=%d (无法恢复)\n", getuid(), geteuid());
    } else {
        printf("非特权进程, 演示需要 setuid-root\n");
    }
    return 0;
}
```
