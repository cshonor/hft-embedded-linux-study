# 9.8 Summary

> 本章：[TLPI 第 9 章](./README.md)

## 本节讲什么

本章回顾进程凭证。

| 凭证 | 说明 | 修改 API |
|------|------|---------|
| Real UID/GID | 启动用户 | setuid()/setgid() |
| Effective UID/GID | 权限检查 | seteuid()/setegid() |
| Saved set-UID/GID | exec 保存 | (通过 setuid 间接) |
| FS UID/GID | Linux 特有 | setfsuid() (已废弃) |
| Supplementary groups | 附属组 | setgroups() |
