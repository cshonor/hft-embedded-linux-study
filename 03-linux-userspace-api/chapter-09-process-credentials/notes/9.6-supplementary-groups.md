# 9.6 Supplementary Group IDs

> 本章：[TLPI 第 9 章](./README.md)

## 本节讲什么

附属组：用户除了主组外还可以属于多个组。

### 相关 API
- `getgroups()` — 获取附属组列表
- `setgroups()` — 设置附属组（需特权）
- `initgroups()` — 从 /etc/group 加载用户的附属组

### 权限检查顺序
1. 如果 effective UID == 0 (root) → 允许
2. 检查文件 owner 与 effective UID
3. 检查文件 group 与 effective GID + 附属组
4. 检查 other 权限
