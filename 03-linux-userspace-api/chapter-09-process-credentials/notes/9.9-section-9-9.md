## 要点

1. **特权进程 ≠ RUID=0**  
   判据：**EUID==0**。普通用户跑 setuid-root：`RUID≠0, EUID=0` → 仍是特权进程。

2. **`setuid` vs `seteuid`**  
   特权下 `setuid(uid)` 常把 R+E+S 一并钉死；`seteuid` 只动有效 ID（可配合 Saved 来回切）。

3. **Saved-ID**  
   支持 setuid 程序 **多次** 降权 / 提权；对外服务结束应用 `setuid(getuid())` 永久丢弃。

4. **环境变量**  
   SUID 程序须警惕 `LD_PRELOAD` / `LD_LIBRARY_PATH` 等劫持；见 Ch38。

5. **FUID**  
   现代默认=EUID；POSIX 无；别写进可移植逻辑。

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    uid_t ruid, euid, suid;

    /* 要点1: 特权判据是 EUID==0, 不是 RUID==0 */
    getresuid(&ruid, &euid, &suid);
    printf("RUID=%d EUID=%d SUID=%d\n", ruid, euid, suid);

    if (euid == 0 && ruid != 0) {
        printf("→ setuid-root 程序: RUID≠0 但 EUID=0 → 仍是特权进程\n");
    } else if (euid == 0) {
        printf("→ root 进程: RUID=0 EUID=0\n");
    } else {
        printf("→ 普通进程: EUID≠0\n");
    }

    /* 要点2: setuid vs seteuid
     * - 特权下 setuid(uid) 把 R+E+S 全钉死 → 不可恢复
     * - seteuid(uid) 只改 EUID → 可用 Saved 恢复
     */

    /* 要点3: 永久丢弃特权的标准写法 */
    if (euid == 0) {
        printf("永久丢权: setuid(%d)\n", ruid);
        setuid(ruid);  /* R+E+S 全改为 ruid */
        printf("现在 EUID=%d (无法恢复特权)\n", geteuid());
    }

    /* 要点4: SUID 程序警惕环境变量
     * - LD_PRELOAD / LD_LIBRARY_PATH 在 SUID 程序中被忽略
     * - IFS, PATH 等也需净化
     */
    return 0;
}
```
