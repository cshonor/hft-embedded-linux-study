## 本节讲什么

要点： - **只有 exec 加载带 SUID 位的程序**才会把 euid 换成文件属主；**fork 永不改 UID**。 - SUID 进程再 fork：子**继承 euid 特权**；子若再 exec **普通**程序，euid **不会自动掉回** ruid。

---

## 要点

| 行为 | ruid | euid | saved-set UID |
|------|------|------|---------------|
| **fork()** | 继承 | 继承 | 继承 |
| **exec 普通程序**（无 SUID 位） | 不变 | **不变** | ← 拷贝当前 euid |
| **exec SUID 程序** | 不变 | = 文件属主 | ← 拷贝**新** euid（exec 前旧 euid 已反映在切换逻辑中；见 man/书表） |

要点：

- **只有 exec 加载带 SUID 位的程序**才会把 euid 换成文件属主；**fork 永不改 UID**。  
- SUID 进程再 fork：子**继承 euid 特权**；子若再 exec **普通**程序，euid **不会自动掉回** ruid。  
- Linux 上 shebang 脚本的 SUID/SGID **无效**（防脚本提权）。  
- 补充组：`getgroups`/`setgroups`（仅 root 可改）；exec/SUID **不改**附属组列表。

文件访问判定（看 euid / egid+附属组，Linux 文件侧还有 fsuid≈euid）：属主位 → 组位 → other。

> 写安全代码时用 `getresuid` **打印验证**；边角见 `man 2 execve` / `man 7 credentials`。

## 与 C 语言学习的关系

## 常见陷阱

1. **TOCTOU 竞态**

```c
if (access("f.txt", R_OK) == 0) {
    /* 攻击者在此期间替换文件 */
    fd = open("f.txt", O_RDONLY);
}
```

access() 和 open() 之间文件可能被替换（TOCTOU）。应直接 open 并检查错误，或用 fstat 验证已打开的 fd。

2. **setuid 程序未降权**

```c
/* setuid root 程序 */
fd = open("/etc/shadow", O_RDONLY);
/* ... 处理 ... */
/* 忘记降权就执行用户代码 → 提权! */
```

setuid 程序应在完成特权操作后立即降权（seteuid(getuid())），遵循最小权限原则。

3. **混淆 real UID 和 effective UID**

```c
/* real UID: 启动进程的用户 */
/* effective UID: 当前有效权限 */
/* setuid 程序中两者不同! */
```

real UID 是登录用户，effective UID 决定当前权限。setuid 程序中 effective UID 变为文件属主。

## 自测题

**题目 1（选择）：** setuid 程序执行时，哪个 UID 会改变？
A. real UID
B. effective UID
C. saved set-user-ID
D. 所有 UID

<details>
<summary>参考答案</summary>

B。setuid 程序执行时 effective UID 变为文件属主的 UID。real UID 不变。saved set-user-ID 也被设为 effective UID。

</details>

**题目 2（判断）：** `access()` 和 `open()` 组合使用是安全的权限检查方式。

<details>
<summary>参考答案</summary>

错误。access() 基于 real UID 检查，open() 基于 effective UID。而且两者之间有 TOCTOU 竞态。应直接 open 并检查。

</details>

**题目 3（踩坑）：** 以下 setuid root 程序有什么安全隐患？
```c
int main() {
    system("ls /root");
}
```

<details>
<summary>参考答案</summary>

system() 调用 shell，shell 会解析 PATH 环境变量。攻击者可以修改 PATH 让恶意程序替代 ls。setuid 程序应直接用 execve 指定完整路径。

</details>

**题目 4（应用）：** 写代码：setuid 程序先打开特权文件，然后降权到普通用户。

<details>
<summary>参考答案</summary>

```c
int fd = open("/etc/shadow", O_RDONLY);
if (fd < 0) { perror("open"); exit(1); }
/* 立即降权 */
seteuid(getuid());
/* 现在以普通用户身份运行 */
```

</details>
