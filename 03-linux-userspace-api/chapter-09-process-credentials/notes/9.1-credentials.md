## 要点

### 1. Real UID / GID（RUID / RGID）

| | |
|--|--|
| 含义 | **真正属于谁**（登录者身份） |
| 继承 | `fork` 继承；`exec` **默认不变** |
| 用途 | 发送信号权限、资源归属等 |
| 获取 | `getuid()` / `getgid()` |

### 2. Effective UID / GID（EUID / EGID）

| | |
|--|--|
| 含义 | **权限检查用的 ID**（文件、IPC 等） |
| 特权 | **EUID == 0** → 特权进程（root 能力意义上的） |
| 获取 | `geteuid()` / `getegid()` |

### 3. Saved set-user-ID / set-group-ID（SUID / SGID）

| | |
|--|--|
| 用途 | 专为 **set-UID / set-GID 程序** |
| `exec` | 新 EUID/EGID **复制到 Saved-ID** |
| 作用 | 允许在「普通身份 ↔ 文件属主身份」间**多次切换** |

### 4. File-system UID / GID（FUID / FGID · Linux 专有）

| | |
|--|--|
| 历史 | 早期想把「文件权限」与「其它」检查拆开 |
| 现状 | 自 2.2 起 **默认恒等于 EUID/EGID** |
| 修改 | `setfsuid()` / `setfsgid()`（现代代码几乎不用） |
| 移植 | **POSIX 无此概念**，跨平台勿依赖 |

### 5. Supplementary group IDs（补充组）

| | |
|--|--|
| 含义 | 用户所属多个组；权限检查一并计入 |
| 获取 | `getgroups(size, list)` |
| 修改 | `setgroups()` — **仅特权进程** |

## 与 C 语言学习的关系

`fork()` 是 C 语言系统编程的核心。C 语言没有内置的并发原语——`fork` 是 Unix 创建进程的唯一方式。理解 `fork` 的返回值（父返回子 PID，子返回 0）需要扎实的 C 语言指针和返回值概念。

## 常见陷阱

1. **fork 返回值未区分**

```c
pid_t pid = fork();
/* 父子都执行同一代码 */
```

fork 返回两次：父进程返回子 PID，子进程返回 0，失败返回 -1。必须区分三个分支。

2. **fd 继承导致泄漏**

```c
int fd = open(...);
fork();
/* 父子都有 fd，都不关 → 泄漏 */
```

fork 后子进程继承父的 fd 表。父子都需要 close 各自的 fd。

3. **缓冲区被复制**

```c
printf("hello");  /* 在缓冲区，未 flush */
fork();  /* 子进程也会输出 hello */
```

fork 前如果 stdio 缓冲区有数据，子进程会复制并重复输出。fork 前应 fflush 或用 write。

## 自测题

**题目 1（选择）：** `fork()` 在子进程中返回什么？
A. 子进程 PID
B. 0
C. -1
D. 父进程 PID

<details>
<summary>参考答案</summary>

B。子进程中 fork 返回 0，父进程中返回子进程 PID，失败返回 -1。

</details>

**题目 2（判断）：** `fork` 后子进程和父进程的执行顺序是确定的。

<details>
<summary>参考答案</summary>

错误。fork 后父子进程的执行顺序不确定，取决于调度器。不能用 sleep 来保证顺序。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
printf("before fork\n");
fork();
printf("after fork\n");
```

<details>
<summary>参考答案</summary>

如果 stdout 是行缓冲（终端），"before fork" 会立即输出。但如果是全缓冲（管道/文件），缓冲区被复制，子进程也会输出 "before fork"。fork 前应 fflush(stdout)。

</details>

**题目 4（应用）：** 写代码：fork 一个子进程，父进程打印子 PID，子进程打印自己的 PID。

<details>
<summary>参考答案</summary>

```c
pid_t pid = fork();
if (pid < 0) { perror("fork"); exit(1); }
if (pid == 0) {
    printf("child: %d\n", getpid());
} else {
    printf("parent: child=%d\n", pid);
}
```

</details>
