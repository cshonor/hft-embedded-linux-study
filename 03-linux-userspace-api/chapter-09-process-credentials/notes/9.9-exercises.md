# 9.9 Exercises

## 练习题

### 练习 1：set-user-ID 程序

编写 set-user-ID-root 程序，临时提升权限写文件后立即 drop privilege。

**要求**：
- 程序以 root owner + setuid 位安装
- 启动后用 effective UID = root 写特权文件
- 写完后永久降权到 real UID
- 打印每步的 real/effective/saved UID

### 练习 2：fork/exec 凭证传递

解释 real/effective/saved UID 在以下场景下的变化：
1. `fork()` 后子进程
2. `exec()` 一个普通程序
3. `exec()` 一个 set-user-ID-root 程序（非 root 用户执行）

### 练习 3：完整 drop privilege

编写函数 `drop_priv_forever(uid_t uid, gid_t gid)`，安全地永久放弃所有 root 权限。

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"
#include <fcntl.h>

int main(void) {
    uid_t real = getuid();
    uid_t eff  = geteuid();
    uid_t saved;
    getresuid(NULL, NULL, &saved);   /* 获取 saved */

    printf("start: real=%d eff=%d saved=%d\n", real, eff, saved);

    /* 以 root 身份写文件 */
    int fd = open("/var/log/myapp.log", O_WRONLY|O_CREAT|O_APPEND, 0644);
    if (fd == -1) errExit("open");
    write(fd, "log entry\n", 10);
    close(fd);

    /* 永久降权 */
    if (setuid(real) == -1) errExit("setuid");

    printf("after drop: real=%d eff=%d\n", getuid(), geteuid());

    /* 尝试恢复（应该失败） */
    if (seteuid(0) == -1)
        printf("cannot regain root (expected)\n");
    return 0;
}
```

**编译安装**：
```bash
gcc -o setuid_demo setuid_demo.c
sudo chown root setuid_demo
sudo chmod u+s setuid_demo
```

### 练习 2 答案

| 场景 | Real | Effective | Saved |
|------|------|-----------|-------|
| **初始状态**（setuid root 程序由 alice 运行） | alice(1000) | root(0) | root(0) |
| **fork 后**子进程 | alice | root | root |
| **exec 普通程序** | alice | alice | alice |
| **exec setuid-root 程序** | alice | root | root |

关键规则：
- `fork`：子进程继承全部凭证
- `exec`（无 setuid 位）：effective 不变，**saved 设为 effective**（如果 effective != real 则 saved = effective）
- `exec`（有 setuid 位）：effective 设为文件 owner UID，saved 设为新的 effective

### 练习 3 参考代码

```c
#include <unistd.h>
#include <grp.h>

int drop_priv_forever(uid_t uid, gid_t gid) {
    /* 1. 清空附属组 */
    if (setgroups(0, NULL) != 0) return -1;
    /* 2. 设 GID（real=eff=saved=gid） */
    if (setgid(gid) != 0) return -1;
    /* 3. 设 UID（real=eff=saved=uid，不可逆） */
    if (setuid(uid) != 0) return -1;

    /* 验证 */
    if (geteuid() != uid || getegid() != gid) return -1;
    return 0;
}
```

**调用**：
```c
/* root 程序绑定端口后降权 */
int main() {
    bind_server_socket(80);    /* 需要 root */
    drop_priv_forever(1000, 1000);  /* 永久降为普通用户 */
    /* 此后无法恢复 root */
    serve_requests();
}
```

## HFT / 嵌入式关联

- **端口绑定后降权**：HFT 服务绑定 1024 以下端口后 drop privilege
- **安全审计**：降权后验证凭证是否正确（防御编程）
- **嵌入式**：通常无降权需求，全 root 运行
- **容器化**：容器以特定 UID 运行，`docker run -u 1000`
