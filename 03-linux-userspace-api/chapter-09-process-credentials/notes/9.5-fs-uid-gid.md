# 9.5 File-System User ID and File-System Group ID

> 本章：[TLPI 第 9 章](./README.md)

## 本节讲什么

Linux 特有的 FS UID/GID，用于文件系统权限检查。

### 为什么需要 FS UID
- Linux 历史上 NFS 需要区分 effective UID 和文件系统 UID
- FS UID 默认 = effective UID
- `setfsuid()`/`setfsgid()` 修改（仅 Linux）

### 现代系统
- FS UID 基本被废弃，始终等于 effective UID
- 了解概念即可，不需要主动使用
