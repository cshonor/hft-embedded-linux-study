# 26.4 `wstatus` 宏（必用宏，勿裸打数值）

> 本章：[TLPI 第 26 章 — Monitoring Child Processes](./README.md)

> - 下一节：[26.5 `SIGCHLD` 循环收割（经典）](./26.5-sigchld.md)

---

## 本节讲什么

仅当 `WIFEXITED` 为真时用 `WEXITSTATUS`。 ---

---

## 要点

| 宏 | 含义 |
|----|------|
| `WIFEXITED` → `WEXITSTATUS` | 正常退出 + 退出码 |
| `WIFSIGNALED` → `WTERMSIG` | 信号杀死；`WCOREDUMP`（Linux） |
| `WIFSTOPPED` → `WSTOPSIG` | 暂停（需 WUNTRACED） |
| `WIFCONTINUED` | 继续（需 WCONTINUED） |

仅当 `WIFEXITED` 为真时用 `WEXITSTATUS`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `wstatus` 宏（必用宏，勿裸打数值） 在嵌入式系统的应用场景 |
| HFT | `wstatus` 宏（必用宏，勿裸打数值） 对低延迟和性能的影响 |

## 代码示例

```c
#include <sys/wait.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) { _exit(7); }
    int status;
    wait(&status);
    if (WIFEXITED(status)) printf("正常退出: code=%d\n", WEXITSTATUS(status));
    else if (WIFSIGNALED(status)) printf("信号终止: sig=%d\n", WTERMSIG(status));
    else if (WIFSTOPPED(status)) printf("暂停: sig=%d\n", WSTOPSIG(status));
    return 0;
}
```
