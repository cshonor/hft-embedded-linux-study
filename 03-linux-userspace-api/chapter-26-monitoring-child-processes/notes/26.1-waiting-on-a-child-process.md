# 26.1 僵尸

## 本节讲什么

子终止 → 资源大多释放，内核表留 PID/退出状态 → **zombie** → 父 `wait*` 后条目删除。 父先退 → init/systemd 收养并 wait。长期不收 → PID 耗尽风险。 ---

---

## 要点

子终止 → 资源大多释放，内核表留 PID/退出状态 → **zombie** → 父 `wait*` 后条目删除。  
父先退 → init/systemd 收养并 wait。长期不收 → PID 耗尽风险。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 僵尸占内核表项留 PID/退出状态，父 wait 才删；父先退 init 收养 |
| HFT | 长期运行 HFT 进程必须收尸，僵尸堆积耗尽 PID 致无法 fork |

## 代码示例

```c
#include <sys/wait.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) { _exit(5); }
    int status;
    wait(&status);
    if (WIFEXITED(status)) printf("退出码=%d\n", WEXITSTATUS(status));
    return 0;
}
```
