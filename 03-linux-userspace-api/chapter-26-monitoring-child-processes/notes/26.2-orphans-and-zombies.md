## 要点

```c
pid_t wait(int *wstatus);   /* 阻塞至任意子终止；无子 → -1 */
```

不能指定 PID、无 `WNOHANG`、默认不管 stop/continue → 业务优先 `waitpid`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | wait 阻塞等任意子，不能指定 PID 也无 WNOHANG |
| HFT | wait 阻塞会卡父进程，业务优先 waitpid（非阻塞 WNOHANG） |

## 代码示例

```c
#include <sys/wait.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    for (int i = 0; i < 2; i++) {
        if (fork() == 0) { _exit(i + 1); }
    }
    int status;
    pid_t pid;
    /* wait: 阻塞等任意子进程 */
    while ((pid = wait(&status)) > 0) {
        printf("子进程 %d 退出: code=%d\n", pid, WEXITSTATUS(status));
    }
    return 0;
}
```
