## 要点

```c
pid_t waitpid(pid_t pid, int *wstatus, int options);
```

### `pid`

| 值 | 含义 |
|----|------|
| `> 0` | 指定子 PID |
| `0` | 同进程组任意子 |
| `< -1` | 进程组 `\|pid\|` 内任意子 |
| `-1` | 任意子（≈ `wait`） |

### `options`

| 标志 | 含义 |
|------|------|
| `WNOHANG` | 非阻塞；无就绪返回 `0` |
| `WUNTRACED` | 也报被停的子 |
| `WCONTINUED` | 也报 `SIGCONT` 恢复 |

返回：`>0` 子 PID · `0`（仅 WNOHANG）· `-1` 出错。

Demo：[`code/waitpid_status.c`](../code/waitpid_status.c)

## 代码示例

```c
#include <sys/wait.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    pid_t pid = fork();
    if (pid == 0) { sleep(1); _exit(3); }

    int status;
    /* waitpid: 指定 PID, 可非阻塞 */
    /* WNOHANG: 无子进程退出时立即返回 0 */
    while (waitpid(pid, &status, WNOHANG) == 0) {
        printf("等待中...\n");
        sleep(1);
    }
    printf("子进程退出: code=%d\n", WEXITSTATUS(status));
    return 0;
}
```
