## 要点

标准信号**不排队** → 一次 handler 可能对应多个子退出。

```c
while ((pid = waitpid(-1, &wstatus, WNOHANG)) > 0) {
    /* handle */
}
```

| 点 | |
|----|--|
| 默认 | SIGCHLD 默认忽略；要收须 `sigaction` |
| `SA_NOCLDWAIT` | 内核自收、无僵尸；通常也不再靠 SIGCHLD 拿状态 |
| handler | 尽量轻；只收割或设标志 |
