## 要点

```c
pid_t waitpid(pid_t pid, int *wstatus, int options);
```

### `pid`

| 值 | 含义 |
|----|------|
| `> 0` | 指定子 PID |
| `0` | 同进程组任意子 |
| `< -1` | 进程组 `\|pid\|` 内任意子 |
| `-1` | 任意子（≈ `wait`） |

### `options`

| 标志 | 含义 |
|------|------|
| `WNOHANG` | 非阻塞；无就绪返回 `0` |
| `WUNTRACED` | 也报被停的子 |
| `WCONTINUED` | 也报 `SIGCONT` 恢复 |

返回：`>0` 子 PID · `0`（仅 WNOHANG）· `-1` 出错。

Demo：[`code/waitpid_status.c`](./code/waitpid_status.c)
