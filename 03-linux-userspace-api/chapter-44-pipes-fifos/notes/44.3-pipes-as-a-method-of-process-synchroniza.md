## 要点

**read**

| 条件 | 行为 |
|------|------|
| 有数据 | 返回已读长度 |
| 空且仍有写端 | 阻塞 |
| 空且写端全关 | **0（EOF）** |

**write**

| 条件 | 行为 |
|------|------|
| 有空间 | 写入 |
| 缓冲满 | 阻塞 |
| 读端全关 | **SIGPIPE**（默认同亡）；忽略则 `-1`/`EPIPE` |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/wait.h>
/* 管道阻塞规则: 读空管道阻塞, 写满管道阻塞 */
int main(void) {
    int fd[2];
    pipe(fd);

    /* 默认阻塞: read 空管道会阻塞直到有数据 */
    /* O_NONBLOCK: 非阻塞模式 */
    fcntl(fd[0], F_SETFL, O_NONBLOCK);

    char buf[64];
    ssize_t n = read(fd[0], buf, sizeof(buf));
    if (n < 0)
        perror("non-blocking read (EAGAIN expected)");

    /* 恢复阻塞模式 */
    fcntl(fd[0], F_SETFL, 0);

    /* 写满后也会阻塞: PIPE_BUF 通常是 4096 或 65536 */
    long pipe_buf = fpathconf(fd[1], _PC_PIPE_BUF);
    printf("PIPE_BUF = %ld\n", pipe_buf);

    /* 测试: 关闭所有写端后, read 返回 0 (EOF) */
    close(fd[1]);
    n = read(fd[0], buf, sizeof(buf));
    printf("After write end closed: read returned %zd (EOF)\n", n);
    close(fd[0]);
    return 0;
}
```
