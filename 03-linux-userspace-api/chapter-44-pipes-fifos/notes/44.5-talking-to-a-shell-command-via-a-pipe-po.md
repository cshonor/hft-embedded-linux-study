# 44.5 –44.6 `O_NONBLOCK` · `popen`

## 本节讲什么

非阻塞：空读/`写满` → `-1`/`EAGAIN`（细节见 `man 7 pipe`）。 FILE *popen(const char *command, const char *type);  /* "r"|"w" */ int pclose(FILE *stream);

---

## 要点

非阻塞：空读/`写满` → `-1`/`EAGAIN`（细节见 `man 7 pipe`）。

```c
FILE *popen(const char *command, const char *type);  /* "r"|"w" */
int pclose(FILE *stream);
```

内部 fork+pipe+shell → **注入风险**；单向；难控 fd 标志。替代：自管 `pipe`+`fork`+`exec`（无 shell）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | O_NONBLOCK 空读/满写返回 EAGAIN，配 epoll 做非阻塞管道 |
| HFT | popen 内部 fork+shell 有注入风险+开销，热路径用自管 pipe+fork+exec（无 shell） |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>
/* popen: 管道 + fork + exec 的封装 */
int main(void) {
    /* popen: 执行命令并获取其输出 */
    FILE *fp = popen("ls -l /tmp", "r");
    if (!fp) { perror("popen"); return 1; }

    char line[256];
    while (fgets(line, sizeof(line), fp))
        printf("  %s", line);
    pclose(fp);

    /* popen("w") 可以向命令的 stdin 写 */
    fp = popen("wc -l", "w");
    if (fp) {
        for (int i = 0; i < 10; i++)
            fprintf(fp, "line %d\n", i);
        pclose(fp);
    }

    /* O_NONBLOCK 管道: 非阻塞读写 */
    int fd[2];
    pipe(fd);
    fcntl(fd[0], F_SETFL, O_NONBLOCK);
    char buf[64];
    ssize_t n = read(fd[0], buf, sizeof(buf));
    printf("\nNon-blocking read: n=%zd (EAGAIN if empty)\n", n);
    close(fd[0]); close(fd[1]);
    return 0;
}
```
