# 44.10 Semantics of read() and write() on Pipes and FIFOs

> 本章：[TLPI 第 44 章](../README.md)

## 本节讲什么

管道和 FIFO 上 `read()`/`write()` 的特殊语义：原子性、PIPE_BUF 限制、EOF 行为、SIGPIPE 信号。

## 要点

### PIPE_BUF 原子性

| 写入量 | 行为 |
|--------|------|
| ≤ PIPE_BUF (通常 4096) | 原子写入，不与其他进程交错 |
| > PIPE_BUF | 非原子，可能被交错 |

### EOF 语义

| 情况 | read 返回 |
|------|-----------|
| 有数据 | 实际字节数 |
| 无数据，所有 writer 已关闭 | 0 (EOF) |
| 无数据，有 writer 打开 | 阻塞 |

### write 阻塞

| 情况 | write 行为 |
|------|-----------|
| 管道有空间 | 立即返回 |
| 管道满 | 阻塞（无 reader 时 SIGPIPE） |
| 无 reader | SIGPIPE 信号 |

### SIGPIPE 处理

```c
/* 方法1：忽略信号 */
signal(SIGPIPE, SIG_IGN);
/* 方法2：send + MSG_NOSIGNAL */
send(fd, buf, len, MSG_NOSIGNAL);
/* 方法3：检查 errno */
if (write(fd, buf, len) == -1 && errno == EPIPE) { /* reader gone */ }
```

### 非阻塞模式

| 条件 | read 返回 | write 返回 |
|------|-----------|-----------|
| 无数据/满 | -1 EAGAIN | -1 EAGAIN |
| 有数据/空间 | 数据 | 写入数 |

### 管道容量

```bash
# 查看系统 PIPE_BUF
cat /proc/sys/fs/pipe-max-size   # 最大管道大小
getconf PIPE_BUF                  # 原子写入限制
```

| 参数 | 典型值 | 说明 |
|------|--------|------|
| PIPE_BUF | 4096 | 原子写入最大字节数 |
| 管道总容量 | 65536 | 默认管道缓冲区 |
| 最大管道 | 1048576 | 可设最大值 |

## HFT / 嵌式关联

- 交易系统管道消息 ≤ PIPE_BUF 确保原子性
- 信号处理：忽略 SIGPIPE 避免被杀
- 嵌入式管道容量有限，需流量控制

## 代码示例

```c
#include <unistd.h>
#include <signal.h>
#include <stdio.h>
#include <string.h>
#include <errno.h>

int safe_write_pipe(int fd, const char *msg, size_t len) {
    /* 忽略 SIGPIPE */
    signal(SIGPIPE, SIG_IGN);

    if (len > 4096) {
        fprintf(stderr, "Message > PIPE_BUF, not atomic\n");
    }
    ssize_t n = write(fd, msg, len);
    if (n < 0 && errno == EPIPE) {
        fprintf(stderr, "Reader closed pipe\n");
        return -1;
    }
    return n;
}
```
