## 要点

半双工；无消息边界；仅本机；匿名仅亲缘；无优先级。复杂并发 → socket / mq / shm+sync。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 半双工/无边界/仅本机/匿名仅亲缘/无优先级，复杂并发要 socket/mq/shm |
| HFT | 字节流无消息边界+内核拷贝，实时数据用 shm+信号量或 AF_UNIX |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
/* 管道与 FIFO 的局限性 */
int main(void) {
    /* 1. pipe 只能用于有亲缘关系的进程 (fork 继承 fd) */
    /* 2. FIFO 可用于无关进程, 但只在本机 */
    /* 3. 管道是字节流, 无消息边界 */
    /* 4. 管道缓冲区有限 (通常 64KB) */

    int fd[2];
    pipe(fd);

    /* 字节流: 两次 write 可能被一次 read 读出 */
    write(fd[1], "AAA", 3);
    write(fd[1], "BBB", 3);

    char buf[16];
    ssize_t n = read(fd[0], buf, sizeof(buf));
    buf[n] = '\0';
    printf("Read %zd bytes: %s (no message boundary!)\n", n, buf);

    /* 查看管道缓冲区大小 */
    long buf_size = fpathconf(fd[0], _PC_PIPE_BUF);
    printf("PIPE_BUF (atomic write): %ld\n", buf_size);

    /* 管道容量: 通常 64KB (可查询) */
    int pipe_size = fcntl(fd[0], F_GETPIPE_SZ);
    printf("Pipe capacity: %d bytes\n", pipe_size);

    close(fd[0]); close(fd[1]);
    printf("\nLimitations: byte stream, no boundary, same machine only\n");
    return 0;
}
```
