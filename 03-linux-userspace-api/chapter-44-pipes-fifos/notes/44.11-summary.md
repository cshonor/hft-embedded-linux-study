# 44.11 Summary

> 本章：[TLPI 第 44 章](./README.md)

## 本节讲什么

第 44 章总结：管道（pipe）和 FIFO（命名管道）的 API、语义和使用场景。

## 要点

### API 总览

| API | 用途 |
|-----|------|
| `pipe()` | 创建匿名管道 |
| `pipe2()` | 创建管道+标志（O_NONBLOCK/CLOEXEC） |
| `mkfifo()` | 创建 FIFO |
| `open()` | 打开 FIFO |
| `read()`/`write()` | 读写 |

### 管道 vs FIFO

| 特性 | 管道 (pipe) | FIFO (命名管道) |
|------|------------|-----------------|
| 创建 | `pipe()` | `mkfifo()` |
| 标识 | fd | 文件系统路径 |
| 生命周期 | 进程 | 文件系统持久 |
| 进程关系 | 父子进程 | 任意进程 |
| 通信方向 | 单向 | 单向 |

### 关键语义

| 语义 | 说明 |
|------|------|
| PIPE_BUF | ≤ 此值的写入原子 |
| EOF | 所有 writer 关闭后 read 返回 0 |
| SIGPIPE | 无 reader 时 write 触发 |
| 阻塞 | 默认阻塞，O_NONBLOCK 非阻塞 |

### 适用场景

| 场景 | 推荐 |
|------|------|
| 父子通信 | pipe |
| 任意进程通信 | FIFO |
| 消息边界 | 无（需自行协议化） |
| 流式数据 | 适合 |

## HFT / 嵌入式关联

- 管道用于子进程通信（如交易引擎+监控进程）
- FIFO 用于简单 IPC（如配置控制）
- 注意无消息边界：需自定义帧协议
