## 本节讲什么

`> PIPE_BUF` 不保证原子。 ---

---

## 要点

| | |
|--|--|
| **PIPE_BUF** | Linux 常 4096；`≤` 此长度的 write **原子**（多写者不交错） |
| **Pipe capacity** | 总缓冲（Linux 常约 64KB）；满则阻塞 |

`> PIPE_BUF` 不保证原子。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | ≤PIPE_BUF 的 write 原子，多进程写日志/状态不会交错 |
| HFT | 多生产者写同一管道用 ≤PIPE_BUF 保证原子；超长消息自加锁或改用 mq |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <string.h>
/* PIPE_BUF: 原子写入保证 */
int main(void) {
    long pipe_buf = fpathconf(STDOUT_FILENO, _PC_PIPE_BUF);
    printf("PIPE_BUF = %ld bytes\n", pipe_buf);
    printf("Writes <= PIPE_BUF are atomic\n");
    printf("Writes > PIPE_BUF may be interleaved\n");

    /* 多进程同时写管道: 小于 PIPE_BUF 的写不会交错 */
    int fd[2];
    pipe(fd);

    for (int i = 0; i < 3; i++) {
        if (fork() == 0) {
            close(fd[0]);
            char msg[64];
            int len = snprintf(msg, sizeof(msg), "child %d\n", i);
            /* 如果 len <= PIPE_BUF, 这个 write 是原子的 */
            write(fd[1], msg, len);
            close(fd[1]);
            _exit(0);
        }
    }

    close(fd[1]);
    char buf[256];
    ssize_t n;
    while ((n = read(fd[0], buf, sizeof(buf))) > 0)
        write(STDOUT_FILENO, buf, n);
    close(fd[0]);

    while (wait(NULL) > 0);
    return 0;
}
```
