## 本节讲什么

mkfifo(path, mode); open(path, O_RDONLY);   /* 阻塞到有写端 */ open(path, O_WRONLY);   /* 阻塞到有读端 */

---

## 要点

```c
mkfifo(path, mode);
open(path, O_RDONLY);   /* 阻塞到有写端 */
open(path, O_WRONLY);   /* 阻塞到有读端 */
```

`O_NONBLOCK`：`O_RDONLY` 常立刻成功；`O_WRONLY` 无读端 → **`ENXIO`**。  
勿依赖 `O_RDWR` 开 FIFO（可移植性差）。

简单 C/S：一服务端读 FIFO，多客户端写 — 并发写仍可能交织（≤`PIPE_BUF` 可原子）。

Demo：[`code/fifo_demo.c`](../code/fifo_demo.c) + README 双进程用法。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | open O_WRONLY 无读端 ENXIO；一服务端读+多客户端写，≤PIPE_BUF 可原子 |
| HFT | FIFO 有路径名跨无关进程，但字节流无边界+多客户端交织，仅低频控制 |

## 代码示例

```c
#include <stdio.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/wait.h>
#include <string.h>
/* FIFO (命名管道): 无关进程间通信 */
#define FIFO_PATH "/tmp/ch44_fifo_demo2"

int main(void) {
    /* mkfifo: 创建 FIFO 特殊文件 */
    mkfifo(FIFO_PATH, 0644);

    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程: 写端 */
        int fd = open(FIFO_PATH, O_WRONLY);
        write(fd, "hello FIFO", 10);
        close(fd);
        _exit(0);
    }

    /* 父进程: 读端 (open 会阻塞直到有写端) */
    int fd = open(FIFO_PATH, O_RDONLY);
    char buf[64];
    ssize_t n = read(fd, buf, sizeof(buf));
    buf[n] = '\0';
    printf("Received: %s\n", buf);
    close(fd);

    waitpid(pid, NULL, 0);
    unlink(FIFO_PATH);  /* 删除 FIFO 文件 */
    return 0;
}
```
