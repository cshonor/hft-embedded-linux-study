int fd[2]; pipe(fd);          /* fd[0] 读, fd[1] 写 */ fork();

---

## 要点

```c
int fd[2];
pipe(fd);          /* fd[0] 读, fd[1] 写 */
fork();
/* 父写子读：父 close(fd[0]); 子 close(fd[1]); */
```

双向 → 两根管道。通信完 close。
