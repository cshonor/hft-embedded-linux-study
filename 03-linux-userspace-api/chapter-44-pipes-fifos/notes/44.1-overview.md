# 44.1 Pipe vs FIFO

## 本节讲什么

FIFO 文件名 ≠ 磁盘数据；缓冲在内核。 ---

---

## 要点

| | 匿名管道 | FIFO |
|--|----------|------|
| 创建 | `pipe(fd[2])` | `mkfifo` / `mkfifo(3)` |
| 名称 | 无 | 路径（`ls` 类型 `p`） |
| 进程 | 仅亲缘（继承 fd） | 任意本地（路径 + 权限） |
| 打开 | 创建即有两端 fd | 读写双方互相等待（默认可阻塞） |
| IO | 半双工字节流 | 同左 |
| 持久 | 进程持久（全 close 毁） | 节点可留；缓冲仍进程/内核语义 |

FIFO 文件名 ≠ 磁盘数据；缓冲在内核。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 匿名 pipe 只限 fork 亲缘进程；FIFO 有路径+权限，供无关进程（采集→处理）通信 |
| HFT | 管道是字节流经内核缓冲有拷贝，热路径共享数据用 shm；FIFO 用于低频控制/日志通道 |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/stat.h>
#include <fcntl.h>
/* pipe (匿名) vs FIFO (命名): 区别与使用场景 */
int main(void) {
    /* pipe: 匿名管道, 只能有亲缘进程使用 */
    int pfd[2];
    pipe(pfd);
    printf("pipe created: read=%d, write=%d\n", pfd[0], pfd[1]);

    /* FIFO: 命名管道, 任何进程都能打开 */
    const char *fifopath = "/tmp/ch44_fifo_demo";
    mkfifo(fifopath, 0644);
    printf("FIFO created at %s\n", fifopath);

    /* FIFO 本质是内核缓冲区, 有路径名 */
    /* 读端阻塞直到有写端打开, 反之亦然 */
    if (fork() == 0) {
        int fd = open(fifopath, O_WRONLY);
        write(fd, "via FIFO", 8);
        close(fd);
        _exit(0);
    }
    int fd = open(fifopath, O_RDONLY);
    char buf[16];
    read(fd, buf, 8);
    buf[8] = '\0';
    printf("FIFO received: %s\n", buf);
    close(fd);
    wait(NULL);
    unlink(fifopath);
    return 0;
}
```
