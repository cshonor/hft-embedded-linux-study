## 要点

**read**

| 条件 | 行为 |
|------|------|
| 有数据 | 返回已读长度 |
| 空且仍有写端 | 阻塞 |
| 空且写端全关 | **0（EOF）** |

**write**

| 条件 | 行为 |
|------|------|
| 有空间 | 写入 |
| 缓冲满 | 阻塞 |
| 读端全关 | **SIGPIPE**（默认同亡）；忽略则 `-1`/`EPIPE` |
