## 本节讲什么

int fd[2]; pipe(fd);          /* fd[0] 读, fd[1] 写 */ fork();

## 要点

```c
int fd[2];
pipe(fd);          /* fd[0] 读, fd[1] 写 */
fork();
/* 父写子读：父 close(fd[0]); 子 close(fd[1]); */
```

双向 → 两根管道。通信完 close。

Demo：[`code/pipe_demo.c`](../code/pipe_demo.c)

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>
/* pipe() 范式: fd[0]读, fd[1]写, fork后各自关闭一端 */
int main(void) {
    int fd[2];
    if (pipe(fd) < 0) { perror("pipe"); return 1; }

    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程: 关闭读端, 只写 */
        close(fd[0]);
        const char *msg = "hello pipe";
        write(fd[1], msg, strlen(msg) + 1);
        close(fd[1]);
        _exit(0);
    }

    /* 父进程: 关闭写端, 只读 */
    close(fd[1]);
    char buf[64];
    ssize_t n = read(fd[0], buf, sizeof(buf));
    printf("Parent received %zd bytes: %s\n", n, buf);
    close(fd[0]);
    waitpid(pid, NULL, 0);
    return 0;
}
```
