- 内核处理在 **slave** 侧 - `TIOCPKT`：master 收状态事件前缀（SSH 等） - `TIOCGWINSZ` / `TIOCSWINSZ`：窗尺寸；改后子进程可收 **`SIGWINCH`**

## 要点

- 内核处理在 **slave** 侧  
- `TIOCPKT`：master 收状态事件前缀（SSH 等）  
- `TIOCGWINSZ` / `TIOCSWINSZ`：窗尺寸；改后子进程可收 **`SIGWINCH`**

## 代码示例

```c

/* openpty / forkpty 便捷 API */
#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <pty.h>
#include <sys/wait.h>

int main(void) {
    int master, slave;
    /* openpty: 一步创建 PTY 对，返回 master+slave fd */
    if (openpty(&master, &slave, NULL, NULL, NULL) < 0) {
        perror("openpty"); exit(1);
    }
    printf("openpty: master=%d, slave=%d\n", master, slave);
    printf("slave name: %s\n", ttyname(slave));

    write(master, "via openpty\n", 12);
    char buf[32];
    int n = read(slave, buf, sizeof(buf) - 1);
    if (n > 0) { buf[n] = '\0'; printf("slave read: %s", buf); }

    close(master);
    close(slave);

    /* forkpty: 创建 PTY + fork，一步到位 */
    pid_t pid = forkpty(&master, NULL, NULL, NULL);
    if (pid == 0) {
        /* 子进程：stdin/stdout 已连到 PTY slave */
        printf("child via forkpty\n");
        _exit(0);
    }

    char fbuf[64];
    n = read(master, fbuf, sizeof(fbuf) - 1);
    if (n > 0) { fbuf[n] = '\0'; printf("parent: %s", fbuf); }
    wait(NULL);
    close(master);
    return 0;
}

```
