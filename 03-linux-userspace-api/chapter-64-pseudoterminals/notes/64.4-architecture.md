## 要点

```c
mfd = posix_openpt(O_RDWR | O_NOCTTY);
grantpt(mfd); unlockpt(mfd);
slave = ptsname(mfd);
sfd = open(slave, O_RDWR | O_NOCTTY);
```

父持 master；子：`close(master)` → `setsid()` → dup2(slave, 0/1/2) → `exec` shell。  
`setsid` 后打开 slave → 常成为**控制终端**。  
**termios 只改 slave**，勿在 master 上改。

## 与 C 语言学习的关系

终端 I/O 涉及 `termios` 结构体和终端模式切换。这需要 C 语言的 struct、位运算（`c_iflag`/`c_oflag`/`c_cflag`/`c_lflag`）和错误处理知识。终端编程的常见陷阱是修改终端模式后程序异常退出，导致终端处于混乱状态——这是 C 语言资源管理（cleanup）的典型训练场景。

## 常见陷阱

1. **终端模式未恢复**

```c
struct termios old, new;
tcgetattr(fd, &old);
new = old;
new.c_lflag &= ~(ICANON|ECHO);
tcsetattr(fd, TCSANOW, &new);
/* 程序异常退出 → 终端混乱! */
```

修改终端模式后必须在退出时恢复。用 atexit 注册恢复函数，或在信号处理中恢复。

2. **canonical 和 non-canonical 混淆**

```c
/* canonical: 行缓冲，按 Enter 发送 */
/* non-canonical: 字符级输入 */
new.c_lflag &= ~ICANON;  /* 切到 non-canonical */
```

canonical 模式下行编辑（Backspace 等）由终端处理。non-canonical 模式下每个字符立即可读，需要自己处理编辑。

3. **信号生成键未处理**

```c
/* Ctrl+C → SIGINT, Ctrl+Z → SIGTSTP */
/* non-canonical 下这些键可能不生成信号 */
```

在 non-canonical 模式下，ISIG 标志控制是否生成信号。如果清除了 ISIG，Ctrl+C 变成普通字符。

## 自测题

**题目 1（选择）：** canonical 模式的特点是？
A. 每输入一个字符就可读
B. 按行缓冲，Enter 后才可读
C. 不支持特殊字符
D. 只能用于串口

<details>
<summary>参考答案</summary>

B。canonical（规范模式）按行缓冲，用户按 Enter 后整行才可读。non-canonical 模式下每个字符立即可读。

</details>

**题目 2（判断）：** 修改终端模式后，程序退出时终端会自动恢复。

<details>
<summary>参考答案</summary>

错误。终端模式不会自动恢复。必须在程序退出前显式调用 tcsetattr 恢复原始设置，否则终端会处于混乱状态。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
struct termios old, new;
tcgetattr(STDIN_FILENO, &old);
new = old;
new.c_lflag &= ~ECHO;  /* 关闭回显 */
tcsetattr(STDIN_FILENO, TCSANOW, &new);
char pwd[32];
read(STDIN_FILENO, pwd, 32);
/* 程序直接退出 */
```

<details>
<summary>参考答案</summary>

关闭了回显但没有恢复。程序退出后终端没有回显，用户看不到输入。应该在读取后恢复：`tcsetattr(STDIN_FILENO, TCSANOW, &old);`

</details>

**题目 4（应用）：** 写代码读取密码（关闭回显），读完后恢复终端。

<details>
<summary>参考答案</summary>

```c
struct termios old, new;
tcgetattr(STDIN_FILENO, &old);
new = old;
new.c_lflag &= ~ECHO;
tcsetattr(STDIN_FILENO, TCSANOW, &new);
char pwd[32];
fgets(pwd, sizeof(pwd), stdin);
tcsetattr(STDIN_FILENO, TCSANOW, &old);  /* 恢复 */
```

</details>
