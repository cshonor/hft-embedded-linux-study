## 要点

```c
mfd = posix_openpt(O_RDWR | O_NOCTTY);
grantpt(mfd); unlockpt(mfd);
slave = ptsname(mfd);
sfd = open(slave, O_RDWR | O_NOCTTY);
```

父持 master；子：`close(master)` → `setsid()` → dup2(slave, 0/1/2) → `exec` shell。  
`setsid` 后打开 slave → 常成为**控制终端**。  
**termios 只改 slave**，勿在 master 上改。
