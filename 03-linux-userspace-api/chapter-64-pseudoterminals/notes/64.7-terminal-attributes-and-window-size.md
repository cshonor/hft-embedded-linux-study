# 64.7 Terminal Attributes and Window Size

> 本章：[TLPI 第 64 章](../README.md)

## 本节讲什么

PTY 主从两端的 termios 属性和窗口大小的关系：修改从设备属性会影响主设备的数据处理，窗口大小通过 `TIOCSWINSZ` 设置。

## 要点

### 主从 termios 关系

```
tcgetattr(slavefd) ←→ 内核 termios ←→ tcgetattr(masterfd)
tcsetattr(slavefd) ←→ 修改内核 termios ←→ 影响数据流
```

| 操作 | 效果 |
|------|------|
| `tcsetattr(slavefd, ...)` | 修改 termios，影响数据处理 |
| `tcgetattr(slavefd)` | 获取当前 termios |
| `tcsetattr(masterfd, ...)` | 等效于设置从设备（某些实现） |

**关键**：termios 属性作用于从设备端，但影响两端的数据流。

### 设置终端大小

```c
struct winsize ws = {
    .ws_row = 24,
    .ws_col = 80,
    .ws_xpixel = 0,
    .ws_ypixel = 0,
};
ioctl(slavefd, TIOCSWINSZ, &ws);
```

子进程通过 `ioctl(TIOCGWINSZ)` 或 SIGWINCH 获取大小。

### 窗口大小变化通知

```c
/* 修改从设备窗口大小 → 子进程收到 SIGWINCH */
ioctl(slavefd, TIOCSWINSZ, &ws);
/* 子进程的 SIGWINCH 处理函数被调用 */
```

### 主从端属性同步

| 属性 | 设置端 | 影响端 |
|------|--------|--------|
| 波特率 | slave | master 和 slave 数据流 |
| 字符大小 | slave | 传输的每个字符 |
| 回显 | slave | master 端读到的数据 |
| 规范/原始 | slave | 数据缓冲行为 |
| 窗口大小 | slave (TIOCSWINSZ) | 子进程环境 |

### 远程终端场景

```
┌──────────┐   TCP    ┌──────────┐   PTY   ┌──────────┐
│ 客户端    │ ←─────→ │ 服务端    │ ←─────→ │ 子进程    │
│ 终端属性  │         │ 转发属性  │         │ bash     │
│ 窗口大小  │         │ 设置 PTY  │         │          │
└──────────┘         └──────────┘         └──────────┘
```

客户端的终端属性通过网络传到服务端，服务端设置 PTY 从设备属性。

## HFT / 嵌入式关联

- 远程终端管理：通过网络同步终端属性到 PTY
- 嵌入式设备串口属性配置
- 自动化测试：设置固定窗口大小确保一致输出

## 代码示例

```c
#include <sys/ioctl.h>
#include <termios.h>
#include <unistd.h>
#include <stdio.h>
#include <signal.h>
#include <fcntl.h>
#include <stdlib.h>

/* 同步当前终端属性到 PTY 从设备 */
void sync_terminal_attrs(int masterfd, int slavefd) {
    struct termios t;
    struct winsize ws;

    /* 获取当前终端属性 */
    tcgetattr(STDIN_FILENO, &t);
    ioctl(STDIN_FILENO, TIOCGWINSZ, &ws);

    /* 设置到 PTY 从设备 */
    tcsetattr(slavefd, TCSANOW, &t);
    ioctl(slavefd, TIOCSWINSZ, &ws);
}

/* SIGWINCH 处理：转发窗口大小变化 */
static int g_masterfd;
static void forward_winsize(int sig) {
    struct winsize ws;
    if (ioctl(STDIN_FILENO, TIOCGWINSZ, &ws) == 0)
        ioctl(g_masterfd, TIOCSWINSZ, &ws);
}

int main() {
    /* 创建 PTY */
    g_masterfd = posix_openpt(O_RDWR | O_NOCTTY);
    grantpt(g_masterfd);
    unlockpt(g_masterfd);
    char *slavename = ptsname(g_masterfd);

    /* fork 子进程 */
    pid_t pid = fork();
    if (pid == 0) {
        close(g_masterfd);
        setsid();
        int slavefd = open(slavename, O_RDWR);
        /* 同步终端属性 */
        struct termios t;
        struct winsize ws;
        tcgetattr(STDIN_FILENO, &t);
        tcsetattr(slavefd, TCSANOW, &t);
        ioctl(STDIN_FILENO, TIOCGWINSZ, &ws);
        ioctl(slavefd, TIOCSWINSZ, &ws);

        dup2(slavefd, 0);
        dup2(slavefd, 1);
        dup2(slavefd, 2);
        close(slavefd);
        execlp("vim", "vim", NULL);
        _exit(1);
    }

    /* 父进程：注册 SIGWINCH 转发 */
    struct sigaction sa = {0};
    sa.sa_handler = forward_winsize;
    sigaction(SIGWINCH, &sa, NULL);

    /* 数据转发循环... */
    /* ... */

    close(g_masterfd);
    return 0;
}
```

## 代码自测

<details>
<summary>在 PTY 中修改从设备的窗口大小后，子进程如何得知？</summary>

设置 `ioctl(slavefd, TIOCSWINSZ, &ws)` 时，如果 `ws_row` 或 `ws_col` 与当前值不同，内核会向从设备的会话组发送 SIGWINCH 信号。子进程需注册 SIGWINCH 处理函数，在信号处理中调用 `ioctl(STDIN_FILENO, TIOCGWINSZ, &ws)` 获取新大小并重绘界面。如果子进程未注册处理函数，信号被忽略，子进程不会自动感知变化。

</details>
