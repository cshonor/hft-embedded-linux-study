## 本节讲什么

一对虚拟字符设备： **master**（`/dev/ptmx`）↔ **slave**（`/dev/pts/N`）。 写 master → 到 slave；写 slave → 到 master。

---

## 要点

一对虚拟字符设备：  
**master**（`/dev/ptmx`）↔ **slave**（`/dev/pts/N`）。  
写 master → 到 slave；写 slave → 到 master。  
Slave 走终端子系统（规范模式、ECHO、SIGINT…）。  

场景：xterm、sshd、tmux、expect、`script`。

## 代码示例

```c

/* PTY 概念：master/slave 对，终端模拟 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>

int main(void) {
    printf("=== Pseudoterminal (PTY) Concepts ===\n\n");

    printf("PTY = pair of devices:\n");
    printf("  master: one end (like keyboard)\n");
    printf("  slave:  other end (looks like a real terminal)\n\n");

    printf("Typical use cases:\n");
    printf("  - terminal emulators (xterm, ssh)\n");
    printf("  - expect scripts (automate interactive programs)\n");
    printf("  - screen/tmux multiplexers\n\n");

    /* 实际创建一个 PTY */
    int master = posix_openpt(O_RDWR | O_NOCTTY);
    if (master < 0) { perror("posix_openpt"); exit(1); }
    grantpt(master);
    unlockpt(master);

    char *name = ptsname(master);
    printf("Created PTY:\n");
    printf("  master fd:  %d (write here → slave reads)\n", master);
    printf("  slave name: %s (open this to get terminal fd)\n", name);
    printf("  slave appears as a tty to programs\n");

    close(master);
    return 0;
}

```
