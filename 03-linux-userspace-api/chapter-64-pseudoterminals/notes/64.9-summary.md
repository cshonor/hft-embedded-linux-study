`/dev/ptyXX`+`/dev/ttyXX`：数量固定、扫描空闲 — **新项目禁用**，用 `posix_openpt`。 ---

## 要点

`/dev/ptyXX`+`/dev/ttyXX`：数量固定、扫描空闲 — **新项目禁用**，用 `posix_openpt`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 老式 BSD PTY 数量固定、需扫描空闲节点，嵌入式系统设备节点有限，应禁用 BSD 方式改用 `posix_openpt` |
| HFT | BSD PTY 遍历 `/dev/pty[p-za-e]` 找空闲既有竞态又慢，高频部署一律用 `posix_openpt` 单 API 创建，省去扫描的系统调用延迟 |

## 代码示例

```c

/* BSD 风格 PTY：/dev/ptyXX + /dev/ttyXX */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>

int main(void) {
    /* BSD PTY: 遍历 /dev/pty[p-za-e][0-9a-f] 找可用 master */
    char master_name[32], slave_name[32];
    int master_fd = -1;

    /* 现代系统通常用 posix_openpt，BSD 方式已过时 */
    /* 这里仅演示概念 */
    printf("=== BSD-style PTY ===\n\n");
    printf("BSD: master=/dev/ptyXX, slave=/dev/ttyXX\n");
    printf("  Need to iterate pty[p-za-e][0-9a-f] to find available\n");
    printf("  No grantpt/unlockpt needed\n\n");

    printf("POSIX (preferred):\n");
    printf("  posix_openpt() -> grantpt() -> unlockpt() -> ptsname()\n");
    printf("  Single API, no guessing\n\n");

    /* 尝试 POSIX 方式 */
    master_fd = posix_openpt(O_RDWR | O_NOCTTY);
    if (master_fd >= 0) {
        grantpt(master_fd);
        unlockpt(master_fd);
        char *name = ptsname(master_fd);
        printf("POSIX PTY created: master=%d, slave=%s\n", master_fd, name);
        close(master_fd);
    }

    return 0;
}

```
