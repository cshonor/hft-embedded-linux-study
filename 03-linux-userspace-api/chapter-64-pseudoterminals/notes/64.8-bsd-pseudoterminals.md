# 64.8 BSD Pseudoterminals

> 本章：[TLPI 第 64 章](../README.md)

## 本节讲什么

BSD 风格的伪终端接口，与 Unix 98 标准的对比。BSD PTY 使用固定的 `/dev/ptyXX`（主）和 `/dev/ttyXX`（从）设备文件对，通过遍历查找可用设备。

## 要点

### BSD vs Unix 98 对比

| 特性 | BSD PTY | Unix 98 PTY |
|------|---------|-------------|
| 主设备 | `/dev/pty[p-za-e][0-9a-f]` | `posix_openpt()` 动态分配 |
| 从设备 | `/dev/tty[p-za-e][0-9a-f]` | `ptsname()` 返回 |
| 查找方式 | 遍历设备文件直到成功 | 自动分配 |
| 并发限制 | 固定设备数（通常 256） | 动态，几乎无限制 |
| 标准 | BSD 历史 | SUSv3+ |
| 推荐 | 不推荐（遗留） | 推荐 |

### BSD PTY 使用流程

```c
/* 1. 遍历主设备名查找可用 */
char name[] = "/dev/ptyXY";
for (char major = 'p'; major <= 'z'; major++) {
    for (char minor = '0'; minor <= '9'; minor++) {
        name[8] = major; name[9] = minor;
        int masterfd = open(name, O_RDWR);
        if (masterfd >= 0) {
            /* 找到可用主设备 */
            name[5] = 't'; name[6] = 't';  /* /dev/ttyXY */
            char *slavename = strdup(name);
            break;
        }
    }
}

/* 2. fork，子进程打开从设备 */
/* 3. grantpt/unlockpt 不需要 */
```

### BSD PTY 的缺点

| 问题 | 说明 |
|------|------|
| 竞争窗口 | 遍历查找是 racy 的 |
| 有限设备数 | 固定设备文件数量 |
| 权限处理 | 需手动 chown/chmod 从设备 |
| 移植性 | 仅 BSD 系统原生支持 |
| 命名复杂 | 设备文件名规则混乱 |

### 现代系统支持

大多数现代 Unix/Linux 同时支持 BSD 和 Unix 98 PTY：
- Linux: 两种都支持，推荐 Unix 98
- macOS: 两种都支持
- FreeBSD: 两种都支持

### openpty() 封装

```c
#include <pty.h>  /* BSD 风格封装 */
int masterfd, slavefd;
char name[256];
openpty(&masterfd, &slavefd, name, NULL, NULL);
/* 自动选择 Unix 98 或 BSD，简化编程 */
```

### 检测可用 PTY

```c
/* 优先使用 Unix 98 */
int fd = posix_openpt(O_RDWR);
if (fd >= 0) {
    /* Unix 98 可用 */
} else {
    /* 回退到 BSD 遍历 */
}
```

## HFT / 嵌入式关联

- 嵌入式旧系统可能只有 BSD PTY
- 新开发统一使用 `posix_openpt` 或 `openpty`
- 跨平台库应检测并回退

## 代码示例

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

/* BSD PTY 遍历查找（回退方案） */
int open_bsd_pty(char **slavename) {
    char master[] = "/dev/ptyXY";
    char slave[]  = "/dev/ttyXY";

    for (char p1 = 'p'; p1 <= 'z'; p1++) {
        for (char p2 = '0'; p2 <= 'f'; p2++) {
            if (p2 > '9' && p2 < 'a') continue;

            master[9] = p1; master[10] = p2;
            int fd = open(master, O_RDWR | O_NOCTTY);
            if (fd >= 0) {
                slave[8] = p1; slave[9] = p2;
                *slavename = strdup(slave);
                return fd;
            }
        }
    }
    return -1;  /* 无可用 PTY */
}

/* 优先 Unix 98，回退 BSD */
int open_pty(char **slavename) {
    /* 尝试 Unix 98 */
    int fd = posix_openpt(O_RDWR | O_NOCTTY);
    if (fd >= 0) {
        grantpt(fd);
        unlockpt(fd);
        *slavename = strdup(ptsname(fd));
        return fd;
    }
    /* 回退 BSD */
    return open_bsd_pty(slavename);
}
```

## 代码自测

<details>
<summary>为什么现代系统推荐 Unix 98 PTY 而非 BSD PTY？</summary>

1. **无竞争**：`posix_openpt` 原子分配可用设备，BSD 需要遍历查找，存在竞争窗口
2. **无限数量**：Unix 98 动态分配从设备号（/dev/pts/N），几乎无数量限制；BSD 固定 256 对
3. **自动权限**：`grantpt` 自动设置从设备权限，BSD 需手动 chown
4. **标准化**：Unix 98 是 POSIX/SUS 标准，BSD PTY 各系统实现不一致
5. **安全**：BSD 遍历可能遗漏权限设置，Unix 98 自动处理

</details>
