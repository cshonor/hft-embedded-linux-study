## 本节讲什么

纯字节流 → pipe；跑交互 shell → **PTY**。 ---

---

## 要点

| | Pipe | PTY slave |
|--|------|-----------|
| `isatty` | false | **true** |
| termios / 信号 / 作业控制 | 无 | **有** |

纯字节流 → pipe；跑交互 shell → **PTY**。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 管道只是纯字节流、无终端语义，跑交互程序（如 busybox shell）必须用 PTY，让程序自认连着真终端 |
| HFT | 自动化脚本驱动交互式 CLI（expect 式）用 PTY 而非管道：交互程序检测到 `isatty` 才会输出提示符并做行缓冲，避免协议错乱 |

## 代码示例

```c

/* PTY vs pipe：PTY 提供终端语义 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <termios.h>

int main(void) {
    /* pipe: 原始字节流，无终端处理 */
    int pipefd[2];
    pipe(pipefd);
    write(pipefd[1], "hello\r\n", 7);
    char buf[16];
    int n = read(pipefd[0], buf, sizeof(buf));
    printf("pipe: read %d bytes: '%.*s' (raw, no terminal processing)\n",
           n, n, buf);
    close(pipefd[0]); close(pipefd[1]);

    /* PTY: 有终端处理（ICRNL 等） */
    int master = posix_openpt(O_RDWR | O_NOCTTY);
    grantpt(master);
    unlockpt(master);
    char *name = ptsname(master);
    int slave = open(name, O_RDWR);

    /* PTY slave 是一个真正的终端 */
    printf("\nPTY slave isatty: %s\n", isatty(slave) ? "yes" : "no");
    printf("pipe read end isatty: (would be no)\n");

    /* PTY 会做终端处理：ICRNL 把 \r 转成 \n */
    write(master, "hello\r", 6);
    n = read(slave, buf, sizeof(buf));
    printf("PTY: read %d bytes (ICRNL converts CR to NL)\n", n);

    close(slave);
    close(master);
    return 0;
}

```
