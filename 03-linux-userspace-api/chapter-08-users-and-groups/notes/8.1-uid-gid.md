## 要点

| | |
|--|--|
| **UID** | 用户数值 ID；`0` = root |
| 系统账号 | 常见约 1–999（发行版略有差异）；守护进程，常无登录 shell |
| 普通用户 | 常见 ≥1000 |
| **GID** | 组 ID；每用户有**主组**；可加多个**附属组** |
| 用途 | 文件所有权、资源访问判定 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    uid_t uid = getuid();    /* Real UID: 真正属于谁 */
    gid_t gid = getgid();    /* Real GID */
    uid_t euid = geteuid();  /* Effective UID: 权限检查用 */
    gid_t egid = getegid();  /* Effective GID */

    printf("UID  = %d\n", uid);
    printf("GID  = %d\n", gid);
    printf("EUID = %d\n", euid);
    printf("EGID = %d\n", egid);

    if (euid == 0) {
        printf("→ 特权进程 (root)\n");
    } else if (euid != uid) {
        printf("→ setuid 程序 (EUID ≠ RUID)\n");
    } else {
        printf("→ 普通进程\n");
    }

    return 0;
}
```
