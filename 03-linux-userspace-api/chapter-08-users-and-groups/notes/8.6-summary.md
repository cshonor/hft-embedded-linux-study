# 8.6 Summary

> 本章：[TLPI 第 8 章](./README.md)

## 本节讲什么

本章回顾用户和组。

| 文件 | 用途 | 权限 |
|------|------|------|
| /etc/passwd | 用户基本信息 | 全局可读 |
| /etc/shadow | 密码哈希 | 仅 root |
| /etc/group | 组信息 | 全局可读 |

### 关键 API
- `getpwuid()`/`getpwnam()` — 查询用户信息
- `getgrgid()`/`getgrnam()` — 查询组信息
- `getgroups()`/`setgroups()` — 附属组
