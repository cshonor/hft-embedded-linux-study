## 练习题

### 练习 1：UID 查询用户信息

编写程序，给定 UID 参数，打印用户名、主组名和所有附属组。

**要求**：
- 使用 `getpwuid` 查用户信息
- 使用 `getgrgid` 查主组名
- 使用 `getgroups` 查附属组列表
- 附属组用 `getgrgid` 转换为组名

### 练习 2：/etc/shadow 的必要性

解释为什么 `/etc/shadow` 的引入是必要的。如果没有 shadow 文件，会带来什么安全问题？

### 练习 3：遍历所有用户

编写程序遍历 `/etc/passwd`，打印所有用户的 UID 和用户名。

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"
#include <pwd.h>
#include <grp.h>

int main(int argc, char *argv[]) {
    if (argc != 2)
        usageErr("usage: %s <uid>\n", argv[0]);

    uid_t uid = atoi(argv[1]);

    /* 查用户信息 */
    struct passwd *pw = getpwuid(uid);
    if (pw == NULL) {
        fprintf(stderr, "UID %d not found\n", uid);
        exit(EXIT_FAILURE);
    }

    /* 查主组 */
    struct group *gr = getgrgid(pw->pw_gid);
    printf("user=%s  uid=%d  primary_group=%s(%d)\n",
           pw->pw_name, pw->pw_uid,
           gr ? gr->gr_name : "???", pw->pw_gid);

    /* 查附属组 */
    int n = getgroups(0, NULL);
    if (n > 0) {
        gid_t *groups = malloc(n * sizeof(gid_t));
        getgroups(n, groups);

        printf("supplementary groups:");
        for (int i = 0; i < n; i++) {
            struct group *g = getgrgid(groups[i]);
            printf(" %s(%d)", g ? g->gr_name : "???", groups[i]);
        }
        printf("\n");
        free(groups);
    }
    return 0;
}
```

### 练习 2 答案

**没有 shadow 的问题**：
1. `/etc/passwd` 必须全局可读——`ls -l` 需要查 UID→用户名，`sshd` 需要验证用户存在
2. 密码哈希在 passwd 中 → 任何用户可获取哈希 → 离线字典攻击/彩虹表
3. 无密码过期策略，无法强制定期修改

**shadow 的优势**：
1. 哈希仅 root 可读（权限 600 或 640 + shadow 组）
2. 支持过期、锁定、宽限等策略
3. 即使非 root 用户获取 passwd 也无法看到哈希

### 练习 3 参考代码

```c
#include <pwd.h>
#include <stdio.h>

int main(void) {
    struct passwd *pw;
    setpwent();                 /* 回到文件开头 */
    while ((pw = getpwent()) != NULL) {
        printf("%5d  %s\n", pw->pw_uid, pw->pw_name);
    }
    endpwent();                 /* 关闭 */
    return 0;
}
```

## HFT / 嵌入式关联

- **权限审计**：HFT 部署脚本检查服务用户 UID 和附属组，确保最小权限
- **嵌入式**：精简系统通常只有 root 用户，简化 passwd/group
- **NSS**：网络环境下可能用 LDAP/NIS，`/etc/nsswitch.conf` 配置查询顺序
