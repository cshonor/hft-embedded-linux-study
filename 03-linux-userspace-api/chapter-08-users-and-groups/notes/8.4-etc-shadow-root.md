## 要点

把加密密码从公开 `passwd` 拆出。

字段概要：`username:encrypted:…`（含最后修改、最小/最大间隔、警告、宽限、失效等）。

```c
#include <shadow.h>
struct spwd {
    char *sp_namp;
    char *sp_pwdp;   /* 加密密码 */
    long sp_lstchg, sp_min, sp_max, sp_warn, sp_inact, sp_expire;
};
```

```c
struct spwd *getspnam(const char *name);
void setspent(void);
struct spwd *getspent(void);
void endspent(void);
```

普通用户调 `getspnam` → 常失败，`errno=EACCES`。
