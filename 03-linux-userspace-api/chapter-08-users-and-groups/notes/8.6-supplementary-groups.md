## 要点

进程可有一组附属 GID，访问多组资源时一并参与校验（与主组一起）。

```c
#include <grp.h>
int getgroups(int size, gid_t list[]);
int setgroups(size_t size, const gid_t *list);  /* 特权 */
```

> 附属组 ≠ 主组；文件权限看有效 GID **+** 全部附属组。细节与「当前进程凭证」仍属 Ch9。

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
#include <grp.h>
/* 附属组: getgroups/setgroups */
int main(void) {
    int n = getgroups(0, NULL);
    printf("supplementary groups count: %d\n", n);

    if (n > 0) {
        gid_t groups[32];
        getgroups(n, groups);
        for (int i = 0; i < n; i++) {
            struct group *g = getgrgid(groups[i]);
            printf("  [%d] gid=%u name=%s\n",
                   i, (unsigned)groups[i], g ? g->gr_name : "?");
        }
    }
    return 0;
}
```
