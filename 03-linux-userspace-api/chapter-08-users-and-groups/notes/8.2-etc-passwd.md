## 要点

格式（7 字段，冒号分隔）：

```
name:x:uid:gid:comment:home:shell
```

| 字段 | 含义 |
|------|------|
| name | 登录名 |
| x | 密码占位；真密文在 `/etc/shadow` |
| uid / gid | 用户 ID / 主组 ID |
| comment | GECOS / finger |
| home | 家目录 |
| shell | 登录 shell；`/sbin/nologin` 等禁止登录 |

```c
#include <pwd.h>
struct passwd {
    char *pw_name;
    char *pw_passwd;   /* 占位，非真密文 */
    uid_t pw_uid;
    gid_t pw_gid;
    char *pw_gecos;
    char *pw_dir;
    char *pw_shell;
};
```

### 查询 API

```c
struct passwd *getpwnam(const char *name);
struct passwd *getpwuid(uid_t uid);

void setpwent(void);
struct passwd *getpwent(void);
void endpwent(void);
```

找不到用户：返回 `NULL`，**可能不改 errno**。范式：

```c
errno = 0;
pwd = getpwnam("nobody");
if (pwd == NULL) {
    if (errno == 0) { /* 不存在 */ }
    else { /* 系统错误 */ }
}
```

> 返回值指向**静态缓冲**；连续调用会覆盖；多线程不安全。

## 常见陷阱

1. **返回值未检查**

```c
/* 调用后不检查返回值直接继续 */
result = some_call(...);
use(result);  /* 如果失败? */
```

系统调用和库函数的返回值必须检查。失败时通常返回 -1 或 NULL 并设置 errno。不检查会导致后续操作在错误状态下继续。

2. **资源泄漏**

```c
/* 打开资源后在错误路径未释放 */
fd = open(...);
if (error) return;  /* fd 泄漏 */
```

所有分配的资源（fd、内存、锁）在所有代码路径上都必须释放。用 goto cleanup 模式确保清理。

3. **可移植性假设**

```c
/* 假设特定平台行为 */
/* 如假设 int 是 4 字节、指针是 8 字节 */
```

不要硬编码平台相关假设。用 sizeof、stdint.h 类型（uint32_t 等）和 POSIX 宏确保可移植性。

## 自测题

**题目 1（选择）：** 系统调用失败时通常如何报告错误？
A. 打印错误信息
B. 返回 -1 并设置 errno
C. 调用 exit
D. 抛出异常

<details>
<summary>参考答案</summary>

B。系统调用失败时返回 -1 并设置 errno。用 perror 或 strerror(errno) 获取描述。Pthreads 例外，返回错误码。

</details>

**题目 2（判断）：** errno 在函数成功时会被清零。

<details>
<summary>参考答案</summary>

错误。errno 只在失败时被设置，成功时不会清零。不能通过 errno 判断是否出错，必须先检查返回值。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
if (some_call() < 0) {
    printf("error: %s\n", strerror(errno));
    /* 但中间可能调用了其他函数，errno 被覆盖 */
}
```

<details>
<summary>参考答案</summary>

errno 可能在 strerror 调用前被其他函数覆盖。应该先保存 errno：`int e = errno;` 然后用 strerror(e)。或在 some_call 失败后立即处理。

</details>

**题目 4（应用）：** 写一个错误处理模板：调用系统调用，失败时打印错误并退出。

<details>
<summary>参考答案</summary>

```c
if (some_syscall(args) < 0) {
    perror("some_syscall");
    exit(EXIT_FAILURE);
}
/* 成功继续 */
```

</details>
