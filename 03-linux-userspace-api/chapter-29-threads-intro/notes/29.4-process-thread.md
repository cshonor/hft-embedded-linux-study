## 要点

| | 进程 fork | 线程 pthread |
|--|-----------|--------------|
| 地址空间 | 独立（COW） | 共享 |
| 创建开销 | 更高 | 更低 |
| 共享数据 | IPC | 直接全局/堆 |
| `exit` | 只杀本进程 | 杀**全部**线程 |
| 回收 | `waitpid` | join / detach |
