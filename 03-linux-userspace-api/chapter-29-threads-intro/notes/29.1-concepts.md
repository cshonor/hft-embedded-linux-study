## 要点

线程 = 进程内执行流；至少有主线程。共享虚拟地址空间；**每线程独立栈**。

| ✅ 共享 | ❌ 私有 |
|---------|---------|
| 代码/全局/堆、库 | `pthread_t`、线程栈 |
| PID/PPID/PGID/SID、终端 | 线程信号掩码 |
| fd 表、文件锁、cwd、umask | **每线程 `errno`** |
| 信号 handler、rlimit、定时器 | 浮点上下文、调度属性等 |
| UID/GID 凭证 | |

同进程线程切换无需换页表/刷 TLB，通常比进程切换便宜。
