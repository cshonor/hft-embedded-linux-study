## 要点

当 `-1` 且 `errno==0`：

1. 用 `_POSIX_*` **最小值**保守分配  
2. 启发式固定缓冲（如 4096）— 权宜  
3. **动态扩容**（推荐：路径解析、readline 一类）

典型坑：`PATH_MAX` 在部分系统**未定义**；静态大数组仍可能不够或浪费。

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
#include <limits.h>

int main(void) {
    /* 某些限制"不确定" → sysconf 返回 -1 且 errno 不设 */
    errno = 0;
    long val = sysconf(_SC_RE_DUP_MAX);
    if (val == -1) {
        if (errno == 0) {
            printf("RE_DUP_MAX: 不确定 (无限制)\n");
        } else {
            perror("sysconf");
        }
    } else {
        printf("RE_DUP_MAX = %ld\n", val);
    }

    /* 管道缓冲区大小: fpathconf */
    int pipefd[2];
    pipe(pipefd);
    long pipe_buf = fpathconf(pipefd[0], _PC_PIPE_BUF);
    printf("PIPE_BUF = %ld\n", pipe_buf);
    close(pipefd[0]);
    close(pipefd[1]);
    return 0;
}
```
