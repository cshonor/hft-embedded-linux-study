## 要点

| 时机 | 方式 |
|------|------|
| 编译期 | `<unistd.h>` 的 `_POSIX_*` |
| 运行期 | `sysconf(_SC_*)`（如 `_SC_THREADS`） |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    /* 检查系统是否支持某特性 (_SC_*_C89 / _SC_*_200112) */
    struct { int constant; const char *name; } opts[] = {
        { _SC_FSYNC,           "FSYNC" },
        { _SC_MAPPED_FILES,    "MAPPED_FILES" },
        { _SC_MEMORY_PROTECTION, "MEMORY_PROTECTION" },
        { _SC_THREADS,         "THREADS" },
        { _SC_TIMERS,          "TIMERS" },
        { _SC_ASYNCHRONOUS_IO, "ASYNC_IO" },
    };

    for (int i = 0; i < 6; i++) {
        long val = sysconf(opts[i].constant);
        printf("%-25s = %s\n", opts[i].name,
               val > 0 ? "支持" : "不支持");
    }

    /* 编译时用 #if _POSIX_* 检查, 运行时用 sysconf */
    return 0;
}
```
