## 本节讲什么

进程是 Linux 中程序运行的实例。每个进程拥有独立的虚拟地址空间、fd 表、PID、信号掩码等。理解进程的组成和生命周期，是学习 fork/exec/wait 的基础。

---

## 要点

### 进程是什么

程序是磁盘上的可执行文件；进程是程序被加载到内存后的**运行实例**。一个程序可以对应多个进程（比如同时开多个终端运行 `bash`）。

每个进程内核中对应一个 `task_struct`（也叫进程控制块 PCB），包含：

| 组成 | 说明 |
|------|------|
| **代码段** (.text) | CPU 执行的机器指令，只读 |
| **数据段** (.data/.bss) | 全局变量、静态变量 |
| **堆** (heap) | `malloc` 分配，向上增长 |
| **栈** (stack) | 函数调用帧、局部变量，向下增长 |
| **fd 表** | 打开的文件描述符列表 |
| **信号掩码** | 哪些信号被阻塞 |
| **权限信息** | UID/GID，决定能访问什么 |
| **PID** | 进程标识符，唯一正整数 |

### 独立虚拟地址空间

每个进程有自己的虚拟地址空间（x86-64 上通常是 48 位，256TB）。进程 A **不能直接**读写进程 B 的内存——这是内核通过页表实现的隔离。

```
进程 A 的 VA 0x400000 → 物理页帧 #1234
进程 B 的 VA 0x400000 → 物理页帧 #5678  （不同的物理页！）
```

### 创建：fork()

```c
pid_t pid = fork();
if (pid == 0) {
    /* 子进程：拿到父进程的副本 */
} else if (pid > 0) {
    /* 父进程：pid 是子进程的 PID */
} else {
    /* 出错 */
}
```

`fork()` 创建调用者的**副本**：代码、数据、堆、栈、fd 表都被复制（写时复制 COW）。但 PID 不同。

### 线程 vs 进程

| | 进程 | 线程 |
|--|------|------|
| 地址空间 | **独立** | **共享**（同进程内） |
| 创建开销 | 大（复制页表等） | 小（共享地址空间） |
| 通信方式 | IPC（管道、shm、socket） | 直接读写共享内存 |
| 栈 | 各自独立 | 各自独立（但共享堆和全局） |

线程可以理解为"轻量级进程"——共享地址空间但各有独立栈。

### 和 C 语言的关系

- C 语言的 `main()` 函数就是进程的入口点
- `fork()` 是 POSIX 系统调用，不是 C 标准的一部分——K&R 不会讲
- C 程序中全局变量在 `.data`/`.bss` 段，`malloc` 在堆上，局部变量在栈上——理解进程内存布局对 C 程序员至关重要

### HFT / 嵌入式关联

- **嵌入式**：进程是资源隔离的基本单位；`fork` + `exec` 是启动新程序的标准模式
- **HFT**：进程间上下文切换有 TLB flush 开销；同核多线程（SMT）共享 L1 缓存；HFT 常用多进程而非多线程来做故障隔离

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
/* 进程: pid, ppid, 内存布局 */
int main(void) {
    printf("pid=%d, ppid=%d\n", (int)getpid(), (int)getppid());
    int stack_var;
    static int data_var;
    printf("stack near %p, data near %p\n",
           (void*)&stack_var, (void*)&data_var);
    return 0;
}
```
