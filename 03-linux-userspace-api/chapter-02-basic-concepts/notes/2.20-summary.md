### HFT 最短路径

从本章出发，HFT 学习者应优先深入：
1. 文件 I/O (ch4-5) — 理解 fd 和 I/O 模型
2. 信号 (ch20-22) — 异步事件处理
3. 线程 (ch29-30) — 并发编程
4. 内存映射 (ch49) — 零拷贝和高性能 I/O
5. 套接字 (ch56-61) — 网络通信
6. epoll (ch63) — I/O 多路复用
