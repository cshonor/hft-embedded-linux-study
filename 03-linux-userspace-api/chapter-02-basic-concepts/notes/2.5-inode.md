## 本节讲什么

Linux 文件系统的基础概念：inode 存储文件元数据，文件名只是 inode 的别名（目录项）。理解 inode 才能理解硬链接、软链接、`unlink`、`stat` 等概念。

---

## 要点

### inode：文件的"身份证"

磁盘上的文件分两部分存储：

```
目录项 (dentry)          inode                数据块
┌──────────────┐    ┌─────────────────┐    ┌──────────┐
│ "a.txt" → 42 │    │ inode #42       │    │ block 0  │
│ "b.txt" → 42 │    │  - 大小: 1024   │───→│ block 1  │
│ "c.txt" → 77 │    │  - 权限: 0644   │    │ block 2  │
└──────────────┘    │  - 所有者: uid   │    └──────────┘
                    │  - 块指针: [0,1,2]│
                    │  - 时间戳        │
                    └─────────────────┘
```

- **inode** 存元数据：大小、权限、所有者、时间戳、数据块指针——**不含文件名**
- **目录项** 存文件名 → inode 号的映射
- **文件名** 只是目录里的一个标签，不是文件本身

### 查看 inode

```bash
ls -i a.txt          # 显示 inode 号
stat a.txt           # 显示完整 inode 信息
ls -il               # 同时显示 inode 号和详细信息
```

### 硬链接 vs 软链接

| | 硬链接 (hard link) | 软链接 (symlink) |
|--|--------------------|-------------------|
| 本质 | 多个文件名指向**同一个 inode** | 一个特殊文件，内容是**另一路径的字符串** |
| 创建 | `ln original hardlink` | `ln -s original symlink` |
| 删除原文件 | 硬链接仍可访问数据（inode 引用计数减 1） | 软链接变成死链接（dangling） |
| 跨文件系统 | 不行（inode 号是局部的） | 可以 |
| 硬链接目录 | 不允许（避免循环） | 可以 |

```bash
ln a.txt hardlink      # hardlink 和 a.txt 共享 inode #42
ln -s a.txt symlink    # symlink 是新 inode，内容 = "a.txt"

rm a.txt               # inode #42 引用计数 2→1，hardlink 仍可用
                       # symlink 指向不存在的 "a.txt" → 死链接
```

### inode 引用计数

每个 inode 有一个**链接计数**（`st_nlink`）：
- `open` 创建文件 → nlink = 1
- `ln` 创建硬链接 → nlink++
- `unlink`（删除文件名）→ nlink--
- nlink 归零 **且** 没有进程打开该文件 → 内核释放数据块

### 和 C 语言的关系

```c
struct stat sb;
stat("a.txt", &sb);
printf("inode: %lu\n", sb.st_ino);        // inode 号
printf("size: %ld\n", sb.st_size);        // 文件大小
printf("nlink: %lu\n", sb.st_nlink);      // 硬链接数
printf("mode: %o\n", sb.st_mode & 0777);  // 权限位
```

C 程序通过 `stat()`/`fstat()`/`lstat()` 读取 inode 信息。`struct stat` 就是 inode 在用户态的投影。

### HFT / 嵌入式关联

- **嵌入式**：理解 inode 有助于理解 flash 文件系统（jffs2/ubifs）的磨损均衡
- **HFT**：减少文件系统操作（open/stat），热路径用 fd 缓存；`O_TMPFILE` 创建匿名文件避免目录项开销

## 代码示例

```c
#include <stdio.h>
#include <sys/stat.h>
/* inode: 文件的内部标识 */
int main(void) {
    struct stat sb;
    if (stat("/etc/hostname", &sb) == 0)
        printf("inode=%lu, size=%ld, mode=%o\n",
               (unsigned long)sb.st_ino, (long)sb.st_size,
               sb.st_mode & 07777);
    return 0;
}
```
