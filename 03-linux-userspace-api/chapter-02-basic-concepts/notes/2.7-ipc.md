## HFT / 嵌入式关联

### 嵌入式 Linux 应用
- fd、权限、进程继承、`/dev` 设备文件 = 应用与驱动交互基础  
- 用户态 **不能** 绕过 syscall 直接操作硬件  
### HFT 低延迟
1. 少 syscall、少线程切换（上下文切换成本）  
2. 测耗时：**别用墙上时钟**  
3. 信号要管控，避免异步打断热路径  
4. 理解 VA 隔离 → 后续 `mlock` 防换页

## 常见陷阱

1. **SIGPIPE**

```c
send(fd, buf, n, 0);  /* 对端关闭 → SIGPIPE */
send(fd, buf, n, MSG_NOSIGNAL);  /* 安全 */
```

向已关闭连接的 socket 写数据触发 SIGPIPE。用 MSG_NOSIGNAL 或忽略 SIGPIPE。

2. **TIME_WAIT**

```c
bind(fd, (struct sockaddr*)&addr, len);
/* EADDRINUSE if port in TIME_WAIT */
```

服务端重启时端口可能还在 TIME_WAIT。用 SO_REUSEADDR 允许绑定。

3. **accept 返回值未检查**

```c
int cfd = accept(lfd, NULL, NULL);
/* cfd 可能 -1 (EMFILE/ENFILE) */
```

accept 可能因 fd 耗尽返回 -1。不检查直接用会导致后续操作失败。

## 自测题

**题目 1（选择）：** `listen()` 的第二个参数 backlog 表示什么？
A. 最大连接数
B. 等待 accept 的队列长度
C. 缓冲区大小
D. 超时秒数

<details>
<summary>参考答案</summary>

B。backlog 是已完成连接但尚未 accept 的队列长度。超过后新连接可能被拒绝。

</details>

**题目 2（判断）：** `bind` 可以绑定任意端口号。

<details>
<summary>参考答案</summary>

错误。1-1023 是特权端口，需要 root 权限。已占用的端口会返回 EADDRINUSE。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
connect(sfd, (struct sockaddr*)&addr, sizeof(addr));
send(sfd, "data", 4, 0);
```

<details>
<summary>参考答案</summary>

没有检查 connect 返回值。connect 可能失败（连接被拒绝、超时等），不检查直接 send 会导致错误。

</details>

**题目 4（应用）：** 写代码创建 TCP 服务端 socket 并监听。

<details>
<summary>参考答案</summary>

```c
int sfd = socket(AF_INET, SOCK_STREAM, 0);
int opt = 1;
setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port = htons(8080);
addr.sin_addr.s_addr = INADDR_ANY;
bind(sfd, (struct sockaddr*)&addr, sizeof(addr));
listen(sfd, 128);
```

</details>
