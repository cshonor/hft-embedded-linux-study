## 本节讲什么

Linux 的基本权限模型：文件的 rwx 权限位，进程的 RUID/EUID 区别，以及 setuid 机制。这是理解 `chmod`、`sudo`、特权程序工作原理的基础。

---

## 要点

### 文件权限

每个文件有 3 组权限位，对应 3 类用户：

```
-rwxr-xr--   1  user  group  1024  Aug 12  a.txt
 ├┤├┤├┤
 │ │ │ └── other:  r--  (只读)
 │ │ └──── group:  r-x  (读+执行)
 │ └────── user:   rwx  (读写执行)
 └──────── 文件类型: - 普通文件, d 目录, l 符号链接
```

| 权限 | 对文件 | 对目录 |
|------|--------|--------|
| r | 读内容 | 列出目录内文件名 |
| w | 修改内容 | 在目录中创建/删除文件 |
| x | 执行 | 进入目录（cd）/ 访问目录内文件 |

目录的 x 权限常被新手忽略——没有 x，即使有 r 也无法 `cd` 进去。

### 进程的身份：RUID vs EUID

每个进程有两套 UID/GID：

| 身份 | 含义 | 何时用 |
|------|------|--------|
| **RUID** (Real UID) | 谁启动了这个进程 | `kill` 权限检查、信号发送 |
| **EUID** (Effective UID) | 当前做权限检查时用的身份 | 文件访问、系统调用权限 |

普通情况下 RUID == EUID。但 **setuid 程序**例外：

### setuid 机制

```bash
ls -l /usr/bin/passwd
-rwsr-xr-x 1 root root 59976 ... /usr/bin/passwd
  ^
  s = setuid 位：执行此程序时，EUID 暂时变成文件所有者 (root)
```

`passwd` 程序需要修改 `/etc/shadow`（只有 root 能写）。通过 setuid 位，普通用户执行 `passwd` 时 EUID 变成 root，就能写 shadow 文件。

```c
/* 程序运行时的身份变化 */
/* 普通用户 (uid=1000) 执行 setuid-root 程序 */
getuid();  → 1000  (RUID: 谁启动的)
geteuid(); → 0     (EUID: root，因为 setuid 位)
/* EUID=0 时可以访问 root 文件 */
/* 完成后 seteuid(getuid()) 恢复成普通用户 */
```

### 权限检查流程

内核在每次文件访问时检查：

1. 如果 EUID == 0 (root) → 允许（除非有额外限制）
2. 如果 EUID == 文件所有者 → 检查 user 权限位
3. 如果 EGID == 文件所属组 → 检查 group 权限位
4. 否则 → 检查 other 权限位

### 和 C 语言的关系

```c
uid_t ruid = getuid();   /* 真实 UID */
uid_t euid = geteuid();  /* 有效 UID */
seteuid(ruid);           /* 放弃特权，恢复真实身份 */
chmod("a.txt", 0644);    /* 修改权限位 */
```

C 程序中可以用 `getuid()`/`geteuid()` 查询身份，用 `setuid()`/`seteuid()` 切换身份。特权程序的安全原则：**尽早放弃特权**。

### HFT / 嵌入式关联

- **嵌入式**：嵌入式系统常以 root 运行所有程序，权限模型形同虚设；但了解权限对理解文件访问错误有帮助
- **HFT**：交易系统通常以非特权用户运行，但需要绑定特权端口（< 1024）→ 用 `setcap` 或 setuid
- **安全**：setuid 程序是安全重灾区——缓冲区溢出 + setuid-root = 系统被接管

## 代码示例

```c
#include <stdio.h>
#include <sys/stat.h>
/* 权限模型: rwx for user/group/other */
int main(void) {
    struct stat sb;
    if (stat("/etc/passwd", &sb) == 0) {
        printf("/etc/passwd mode: %04o\n", sb.st_mode & 07777);
        printf("owner read: %s\n", (sb.st_mode & 0400) ? "yes" : "no");
    }
    return 0;
}
```
