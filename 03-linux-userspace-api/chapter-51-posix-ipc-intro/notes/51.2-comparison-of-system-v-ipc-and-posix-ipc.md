## 要点

1. **open**：`mq_open` / `sem_open` / `shm_open`（`O_CREAT|O_EXCL` + mode）→ **fd/句柄**  
2. **操作**：send/recv · wait/post · mmap  
3. **close**：关本进程引用，**不销毁对象**  
4. **unlink**：删名字；**已打开者仍可用**；**全部 close 后内核销毁**

命名（Linux）：`/myqueue` ✅；`/ipc/queue` ❌。挂载点示意：`/dev/mqueue`、`/dev/shm`。

Demo：[`code/`](../code/)（`shm_open` 开闭 unlink）

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | open→操作→close(降引用)→unlink(删名)，全 close 才销毁 |
| HFT | unlink 后已打开者仍可用，进程崩溃 fd 自动回收，无 SysV 僵尸对象 |

## 代码示例

```c

/* POSIX IPC 三种对象的 open/close/unlink 模型 */
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <mqueue.h>
#include <semaphore.h>
#include <sys/mman.h>

int main(void) {
    /* 统一模型：open -> use -> close -> unlink */

    /* 1) 消息队列 */
    mqd_t mq = mq_open("/demo_mq", O_CREAT | O_RDWR, 0644, NULL);
    if (mq != (mqd_t)-1) {
        printf("MQ: open(%d) -> close -> unlink\n", (int)mq);
        mq_close(mq); mq_unlink("/demo_mq");
    }

    /* 2) 信号量 */
    sem_t *s = sem_open("/demo_sem", O_CREAT, 0644, 1);
    if (s != SEM_FAILED) {
        printf("SEM: open -> wait/post -> close -> unlink\n");
        sem_close(s); sem_unlink("/demo_sem");
    }

    /* 3) 共享内存 */
    int fd = shm_open("/demo_shm", O_CREAT | O_RDWR, 0644);
    if (fd >= 0) {
        ftruncate(fd, 4096);
        printf("SHM: open(%d) -> ftruncate -> mmap -> munmap -> close -> unlink\n", fd);
        close(fd); shm_unlink("/demo_shm");
    }

    return 0;
}

```
