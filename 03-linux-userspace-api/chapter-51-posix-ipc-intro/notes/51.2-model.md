## 要点

1. **open**：`mq_open` / `sem_open` / `shm_open`（`O_CREAT|O_EXCL` + mode）→ **fd/句柄**  
2. **操作**：send/recv · wait/post · mmap  
3. **close**：关本进程引用，**不销毁对象**  
4. **unlink**：删名字；**已打开者仍可用**；**全部 close 后内核销毁**

命名（Linux）：`/myqueue` ✅；`/ipc/queue` ❌。挂载点示意：`/dev/mqueue`、`/dev/shm`。
