## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 嵌入式 Linux 属「类 UNIX」（未认证商标），但行为兼容 UNIX 设计哲学；选型认准「类 UNIX」语义即可，不必追 UNIX 商标认证 |
| HFT | HFT 全栈跑在类 UNIX（Linux）上，syscall/文件/进程模型继承 UNIX 语义；延迟敏感设计（epoll、SCHED_FIFO）是 Linux 在 UNIX 传统上的私有扩展 |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
/* UNIX = 内核 + 系统调用 + 工具链 */
int main(void) {
    printf("kernel: %s\n", "Linux");
    printf("syscall example: getpid() = %d\n", (int)getpid());
    return 0;
}
```

## 要点

1. **1969** Ken Thompson，Bell 实验室，PDP-7 汇编初代 UNIX  
2. **1973** Ritchie 发明 C；UNIX 内核用 C 重写 → **可移植革命**  
3. **1979** UNIX V7 后分裂两大分支：  
   - **BSD**（伯克利）：TCP/IP 套接字、信号、csh；FreeBSD、macOS XNU 源自此  
   - **System V**：IPC（消息队列、信号量、共享内存）  
4. 分支接口分歧 → 移植成本高 → **催生 POSIX 标准化**

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | BSD 分支带来 TCP/IP 套接字，是嵌入式联网设备网络栈源头；System V 带来 IPC（消息队列/信号量/共享内存），嵌入式进程间通信常用 |
| HFT | 套接字（BSD）是行情/下单网络通道基础，共享内存（SysV/POSIX）是跨进程零拷贝低延迟共享行情的核心手段；两大分支接口分歧正是 POSIX 标准化的动因 |

## 代码示例

```c
#include <stdio.h>
#include <time.h>
/* C/UNIX 时间线: C89 -> C99 -> C11 */
int main(void) {
    printf("time(NULL) = %ld\n", (long)time(NULL));
    printf("__STDC_VERSION__ = %ldL\n", (long)__STDC_VERSION__);
    return 0;
}
```
