## 要点

| 术语 | 一句话 |
|------|--------|
| User / Kernel space | 用户态 / 内核态（Ch2 展开） |
| System call | 用户进内核的合法入口 |
| glibc | GNU C 库；封装 syscall + 高层接口；**你写的 open() 在这里，不在内核 .c 里** — [1.x](../1.x-syscall-interface-is-c.md) |
| POSIX | 可移植 OS **C 接口**标准（契约，非内核实现） |
| SUS | Single UNIX Specification |
| BSD / System V | 两大经典 UNIX 分支 |
| Linux 内核 vs GNU | 内核 ≠ 用户态工具链 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 术语表是嵌入式系统编程地基：syscall 是进内核合法入口、glibc 封装 syscall、POSIX 是可移植契约；明确分层才不会在裁剪系统里写错接口 |
| HFT | 交易代码里 open/read 实际经 glibc 封装再进内核；理解 syscall 与库函数分层，才能在热路径上选对「直接系统调用 vs 缓冲库函数」以省开销 |

## 代码示例

```c
#include <stdio.h>
#include <unistd.h>
/* 术语: syscall, libc, glibc, POSIX, SUS */
int main(void) {
    printf("pid=%d (syscall getpid)\n", (int)getpid());
    printf("ppid=%d (syscall getppid)\n", (int)getppid());
    return 0;
}
```
