## 要点

**一句话（双线共用）：主力标准 POSIX；SUS 当拓展参考；LSB 工程里忘掉。**

| 标准 | 层级 | 作用 | 对本仓库 |
|------|------|------|----------|
| **POSIX**（IEEE 1003.1） | 源码级可移植 | 定义 syscall/文件 I/O/进程/信号/pthread/实时接口、`clock_gettime`、`mmap`… | **主力**；Linux 尽可能兼容（未花钱官方认证，日常按这套语义写） |
| **SUS**（Single UNIX Specification） | POSIX + 额外扩展 | 通过认证才能合法用 **「UNIX」商标** | 了解即可；发行版几乎不花钱认证；写代码很少刻意追 SUS |
| **LSB**（Linux Standard Base） | 曾求跨发行版**二进制**兼容 | 一份编译产物多发行版跑 | **已废**：末版约 2015，停维护；Yocto/主流发行版已撤；嵌入式/HFT **不考虑**。Primer 为何仍写：见 [08-lsb-vs-posix](../../08-embedded-boot-build/primer-system-overview/chapter-01-introduction/1.4-lsb-vs-posix.md) |

### 易混考点：Linux ≠ UNIX（商标）

- **UNIX（商标）**：须通过 SUS 等认证。  
- **Linux**：遵循 POSIX 接口语义，但**没有**官方 UNIX 认证 → 习惯称「类 UNIX」。

## 常见陷阱

1. **MAP_FAILED vs NULL**

```c
void *p = mmap(NULL, size, PROT_READ|PROT_WRITE,
              MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
if (p == NULL) ...  /* 错误! */
if (p == MAP_FAILED) ...  /* 正确 */
```

mmap 失败返回 MAP_FAILED ((void*)-1)，不是 NULL。检查方式与 malloc 不同。

2. **munmap 忘记调用**

```c
void *p = mmap(NULL, 4096, ...);
/* 使用 p ... */
/* 没有 munmap → 内存泄漏 */
```

mmap 分配的内存不会自动释放。必须 munmap(p, size) 显式释放。

3. **信号处理中的 SIGSEGV**

```c
mmap(NULL, size, PROT_READ, MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
/* 写只读映射 → SIGSEGV */
```

对 PROT_READ 的映射写入会触发 SIGSEGV。确保保护属性和访问操作匹配。

## 自测题

**题目 1（选择）：** `mmap` 失败时返回什么？
A. NULL
B. -1
C. MAP_FAILED
D. 0

<details>
<summary>参考答案</summary>

C。mmap 失败返回 MAP_FAILED（定义为 (void *)-1），不是 NULL。这与 malloc 不同。

</details>

**题目 2（判断）：** `mmap` 映射的内存会在进程退出时自动释放。

<details>
<summary>参考答案</summary>

正确。进程退出时所有映射自动解除。但在长时间运行的程序中仍需手动 munmap。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
void *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE,
               MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
memset(p, 0, 8192);
```

<details>
<summary>参考答案</summary>

写入了 8192 字节但只映射了 4096 字节。超出映射区域会触发 SIGSEGV。应确保操作不超过映射大小。

</details>

**题目 4（应用）：** 写代码用 mmap 分配匿名内存并初始化为 0。

<details>
<summary>参考答案</summary>

```c
void *p = mmap(NULL, 4096, PROT_READ|PROT_WRITE,
               MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
if (p == MAP_FAILED) { perror("mmap"); exit(1); }
memset(p, 0, 4096);
/* ... 使用 ... */
munmap(p, 4096);
```

</details>
