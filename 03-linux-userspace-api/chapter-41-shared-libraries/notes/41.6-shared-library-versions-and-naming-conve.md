## 要点

主版本变（`.so.1`→`.so.2`）= ABI 不兼容。  
安装到库目录 + `ld.so.conf.d` + **`ldconfig`**（刷软链与 `/etc/ld.so.cache`）。

## 代码示例

```c
#include <stdio.h>
int main(void) {
    printf("共享库命名: libXXX.so.major.minor\n");
    printf("  libfoo.so → libfoo.so.1 → libfoo.so.1.0\n");
    printf("  soname: libfoo.so.1 (运行时链接名)\n");
    printf("  real name: libfoo.so.1.0.0 (实际文件)\n");
    printf("  linker name: libfoo.so (编译时 -lfoo)\n");
    return 0;
}
```
