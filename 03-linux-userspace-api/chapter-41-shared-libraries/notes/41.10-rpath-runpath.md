## 要点

| | |
|--|--|
| **DT_RPATH**（旧） | 常 **高于** `LD_LIBRARY_PATH` |
| **DT_RUNPATH**（推荐，`--enable-new-dtags`） | **低于** `LD_LIBRARY_PATH` |

`$ORIGIN` = 可执行文件目录。

查找（库名无 `/` 时，示意）：

1. RPATH（若无 RUNPATH）  
2. `LD_LIBRARY_PATH`（**SUID/SGID 忽略**）  
3. RUNPATH  
4. `ld.so.cache`  
5. `/lib` `/usr/lib`（及 64 位变体）
