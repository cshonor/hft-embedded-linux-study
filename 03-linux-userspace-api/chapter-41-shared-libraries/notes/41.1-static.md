## 要点

| | 静态 `.a` | 共享 `.so` |
|--|-----------|------------|
| 链接 | 代码拷进可执行文件 | 记 `DT_NEEDED` |
| 运行 | 无外部库依赖 | `ld-linux` 加载；多进程可共享映射 |
| 升级 | 须重链程序 | ABI 兼容可换库 |

## 代码示例

```c
#include <stdio.h>
/* 静态链接 vs 动态链接:
 * 静态: 代码拷入可执行文件, 体积大但独立
 * 动态: 运行时加载 .so, 多进程共享代码
 * 编译:
 *   静态: gcc -static main.c
 *   动态: gcc main.c -lmylib
 */
int main(void) {
    printf("静态链接: 独立可执行, 无依赖\n");
    printf("动态链接: 共享 .so, 节省内存\n");
    return 0;
}
```
