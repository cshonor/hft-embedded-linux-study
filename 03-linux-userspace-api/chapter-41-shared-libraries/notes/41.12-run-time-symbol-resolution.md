## 本节讲什么

默认全局符号扁平：主程序全局符号可覆盖库内同名符号（库内调用也可能进主程序）→ **符号介入**。 缓解：库链 `-Bsymbolic`。 绑定：默认 **lazy**（PLT 首次调用解析）；`LD_BIND_NOW=1` 立即绑定。

## 要点

默认全局符号扁平：主程序全局符号可覆盖库内同名符号（库内调用也可能进主程序）→ **符号介入**。

绑定：默认 **lazy**（PLT 首次调用解析）；`LD_BIND_NOW=1` 立即绑定。

## 代码示例

```c
#include <stdio.h>
#include <dlfcn.h>
/* 符号插桩 (interposition):
 * LD_PRELOAD 可以在程序和库之间插入自定义函数
 * 常用于: 内存检查, 性能分析, mock 测试
 */
int main(void) {
    printf("LD_PRELOAD 插桩:\n");
    printf("  LD_PRELOAD=./myhook.so ./program\n");
    printf("  myhook.so 中的 malloc/free 会替换 libc 的\n");

    /* dlopen: 运行时动态加载 */
    void *handle = dlopen(NULL, RTLD_LAZY);
    if (handle) {
        printf("dlopen(NULL) 成功 (打开主程序)\n");
        dlclose(handle);
    }
    return 0;
}
```
