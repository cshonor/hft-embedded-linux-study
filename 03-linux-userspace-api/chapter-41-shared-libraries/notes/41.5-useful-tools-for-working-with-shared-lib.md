## 要点

`ldd ./app` · `readelf -d`（NEEDED/SONAME/RPATH/RUNPATH）· `objdump -T`  
⚠️ 对不可信二进制慎用 `ldd`（会跑动态链接器）；静态看依赖用 `readelf`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `ldd` 看依赖、`readelf -d` 看 NEEDED/SONAME/RPATH、`objdump -T` 看符号；对不可信二进制慎用 `ldd` |
| HFT | 部署前用 `readelf`/`ldd` 核对依赖，避免缺库导致启动失败或运行期崩溃 |

## 代码示例

```c
#include <stdio.h>
int main(void) {
    /* 共享库工具:
     * ldd: 查看依赖的共享库
     * nm: 查看符号表
     * objdump: 反汇编
     * readelf: 查看 ELF 信息
     * ldconfig: 更新共享库缓存
     */
    printf("工具速查:\n");
    printf("  ldd <bin>     → 依赖的 .so\n");
    printf("  nm <lib.so>   → 符号表\n");
    printf("  readelf -d    → 动态段\n");
    printf("  ldconfig -p   → 缓存中的库\n");
    return 0;
}
```
