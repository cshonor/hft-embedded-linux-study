# 41.7 Installing Shared Libraries

> 本章：[TLPI 第 41 章](./README.md)

## 本节讲什么

共享库的安装涉及文件放置、符号链接创建、soname 记录和动态链接器缓存更新。

## 要点

### 安装步骤

```
1. 复制 real name → /lib 或 /usr/lib
2. 创建 SONAME 符号链接 → libfoo.so.1 → libfoo.so.1.0.0
3. 创建链接器名符号链接 → libfoo.so → libfoo.so.1
4. 运行 ldconfig 更新缓存
```

### 三种名称的关系

```
libfoo.so        → 开发时链接器搜索（-lfoo）
  └── libfoo.so.1 → 运行时加载名（ELF DT_NEEDED 中记录）
        └── libfoo.so.1.0.0 → 实际文件（real name）
```

### 标准安装目录

| 目录 | 用途 | 标准 |
|------|------|------|
| `/lib` | 系统核心库（C 库等） | FHS |
| `/usr/lib` | 系统应用库 | FHS |
| `/usr/local/lib` | 本地安装库 | 约定 |
| `/lib64` | 64 位库（部分发行版） | x86_64 |
| 自定义 | `LD_LIBRARY_PATH` 或 ld.so.conf | 开发用 |

### ldconfig

```bash
# 更新共享库缓存（/etc/ld.so.cache）
sudo ldconfig

# 查看缓存中的库
ldconfig -p | grep libfoo

# 指定配置目录
sudo ldconfig /opt/mylib
```

### 配置动态链接器搜索路径

```
# /etc/ld.so.conf.d/myapp.conf
/opt/myapp/lib
```

```bash
sudo ldconfig  # 使配置生效
```

## HFT / 嵌入式关联

- 交易系统自定义库安装到 `/opt/hft/lib`，配置 ld.so.conf
- 嵌入式系统交叉编译后 `make install DESTDIR=/target`
- 版本管理：同时安装多个版本库，通过 soname 选择

## 代码示例

```bash
#!/bin/bash
# 安装共享库的完整流程

VERSION=1.2.3
SONAME=libhft.so.1
REAL=libhft.so.${VERSION}

# 1. 复制实际文件
install -m 755 ${REAL} /usr/local/lib/

# 2. 创建 SONAME 符号链接
ln -sf ${REAL} /usr/local/lib/${SONAME}

# 3. 创建链接器符号链接
ln -sf ${SONAME} /usr/local/lib/libhft.so

# 4. 更新动态链接器缓存
ldconfig

# 5. 验证安装
echo "=== 验证 ==="
ls -la /usr/local/lib/libhft.so*
echo "---"
ldconfig -p | grep libhft
```

## 代码自测

<details>
<summary>ldconfig 的作用是什么？不执行会怎样？</summary>

`ldconfig` 扫描标准库目录，创建 SONAME 到 real name 的符号链接，并生成 `/etc/ld.so.cache` 缓存文件。缓存加速运行时动态链接器查找库的速度。如果不执行 `ldconfig`，新安装的库可能无法被找到（除非用 `LD_LIBRARY_PATH`），因为旧缓存中没有新库的记录。`ldconfig` 还会自动创建/修复 SONAME 符号链接。

</details>
