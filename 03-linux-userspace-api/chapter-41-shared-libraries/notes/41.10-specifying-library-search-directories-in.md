## 本节讲什么

`$ORIGIN` = 可执行文件目录。 查找（库名无 `/` 时，示意）： 1. RPATH（若无 RUNPATH）

---

## 要点

| | |
|--|--|
| **DT_RPATH**（旧） | 常 **高于** `LD_LIBRARY_PATH` |
| **DT_RUNPATH**（推荐，`--enable-new-dtags`） | **低于** `LD_LIBRARY_PATH` |

`$ORIGIN` = 可执行文件目录。

查找（库名无 `/` 时，示意）：

1. RPATH（若无 RUNPATH）  
2. `LD_LIBRARY_PATH`（**SUID/SGID 忽略**）  
3. RUNPATH  
4. `ld.so.cache`  
5. `/lib` `/usr/lib`（及 64 位变体）

## 代码示例

```c
#include <stdio.h>
int main(void) {
    /* rpath/runpath: 编译时嵌入的库搜索路径
     * gcc -Wl,-rpath,/opt/lib main.c
     * DT_RPATH: 旧, 优先级高于 LD_LIBRARY_PATH
     * DT_RUNPATH: 新, 优先级低于 LD_LIBRARY_PATH
     */
    printf("rpath: 编译时嵌入的 .so 搜索路径\n");
    printf("查看: readelf -d <bin> | grep -E 'RPATH|RUNPATH'\n");
    return 0;
}
```
