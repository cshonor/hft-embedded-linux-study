## 与 C 语言学习的关系

系统调用与 C 标准库的关系是 C 语言系统编程的核心概念。C 标准只定义函数接口（如 `fopen`），不规定实现；Linux 上由 glibc 实现并最终调用内核系统调用。理解这一分层对掌握 Unix C 编程至关重要。对照 K&R 第 8 章学习文件 I/O 的 C 标准库接口，与本模块的 POSIX 系统调用接口对比。

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | netlink socket（NETLINK_ROUTE）是嵌入式查询/配置网络接口（网卡、路由、地址）的内核通道，比 ioctl 更现代，支持异步事件订阅 |
| HFT | 交易机用 netlink 监听网卡/路由变化（热插拔、故障切换）实时感知网络拓扑，比轮询快；RTM_GETLINK 批量 dump 接口信息做监控 |

## 常见陷阱

1. **混淆系统调用与库函数**

```c
/* printf 是库函数，write 是系统调用 */
printf("hello
");      /* glibc 处理缓冲+格式化 */
write(1, "hello
", 6);  /* 直接陷入内核 */
```

系统调用是内核接口（open/read/write），库函数是用户态封装（fopen/fread/fwrite）。库函数内部可能调用系统调用，但不是系统调用本身。

2. **errno 检查时机错误**

```c
int fd = open("f.txt", O_RDONLY);
if (errno) perror("open");  /* 错误! */
if (fd < 0) perror("open");  /* 正确 */
```

errno 只在系统调用失败时被设置，成功时不清零。必须先检查返回值判断是否出错，再读 errno。

3. **假设系统调用跨平台一致**

```c
/* Linux: signal() 不恢复默认handler */
/* BSD: signal() 恢复默认handler */
signal(SIGINT, handler);
```

同名的系统调用/库函数在不同 Unix 变体上行为可能不同。生产代码应查文档并用 POSIX 接口（如 sigaction 代替 signal）。

## 自测题

**题目 1（选择）：** 系统调用失败时通常返回什么？
A. 0
B. -1
C. NULL
D. 取决于函数

<details>
<summary>参考答案</summary>

B。大多数系统调用失败时返回 -1 并设置 errno。但 pthread 函数返回错误码，mmap 返回 MAP_FAILED。

</details>

**题目 2（判断）：** errno 在函数成功返回时会被清零。

<details>
<summary>参考答案</summary>

错误。errno 只在失败时被设置，成功时不会清零。不能通过 errno 判断是否出错，必须先检查返回值。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
FILE *fp = fopen("f.txt", "r");
if (errno) {
    printf("error: %s
", strerror(errno));
}
```

<details>
<summary>参考答案</summary>

fopen 成功时 errno 不被清零——可能保留前一次调用的错误值。应检查返回值：`if (fp == NULL)` 而非 `if (errno)`。

</details>

**题目 4（应用）：** 写一个通用的错误检查宏，检查系统调用返回值并在失败时报错退出。

<details>
<summary>参考答案</summary>

```c
#define CHECK(call) do { \
    if ((call) < 0) { \
        perror(#call); \
        exit(EXIT_FAILURE); \
    } \
} while(0)
CHECK(open("f.txt", O_RDONLY));
```

</details>

## 代码示例

```c

/* NETLINK socket：获取网络接口信息 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>
#include <arpa/inet.h>

int main(void) {
    int fd = socket(AF_NETLINK, SOCK_RAW, NETLINK_ROUTE);
    if (fd < 0) { perror("socket AF_NETLINK"); exit(1); }

    struct sockaddr_nl addr = {
        .nl_family = AF_NETLINK,
        .nl_pid = getpid(),
        .nl_groups = 0
    };
    bind(fd, (struct sockaddr *)&addr, sizeof(addr));

    /* 发送 RTM_GETLINK 请求：获取所有网络接口 */
    struct {
        struct nlmsghdr nlh;
        struct ifinfomsg ifi;
    } req;

    memset(&req, 0, sizeof(req));
    req.nlh.nlmsg_len = NLMSG_LENGTH(sizeof(struct ifinfomsg));
    req.nlh.nlmsg_type = RTM_GETLINK;
    req.nlh.nlmsg_flags = NLM_F_REQUEST | NLM_F_DUMP;
    req.nlh.nlmsg_seq = 1;
    req.ifi.ifi_family = AF_UNSPEC;

    struct sockaddr_nl kernel = { .nl_family = AF_NETLINK };
    sendto(fd, &req, req.nlh.nlmsg_len, 0,
           (struct sockaddr *)&kernel, sizeof(kernel));

    /* 接收响应 */
    char buf[8192];
    int n = recv(fd, buf, sizeof(buf), 0);
    if (n < 0) { perror("recv"); exit(1); }

    /* 解析 netlink 消息 */
    struct nlmsghdr *nlh = (struct nlmsghdr *)buf;
    printf("Network interfaces (via NETLINK_ROUTE):\n");

    for (; NLMSG_OK(nlh, n); nlh = NLMSG_NEXT(nlh, n)) {
        if (nlh->nlmsg_type == NLMSG_DONE) break;
        if (nlh->nlmsg_type == NLMSG_ERROR) {
            printf("  netlink error\n"); break;
        }

        struct ifinfomsg *ifi = NLMSG_DATA(nlh);
        printf("  interface index=%d, type=%d, flags=0x%x\n",
               ifi->ifi_index, ifi->ifi_type, ifi->ifi_flags);

        /* 解析属性 IFLA_IFNAME */
        struct rtattr *rta = IFLA_RTA(ifi);
        int attrlen = IFLA_PAYLOAD(nlh);
        for (; RTA_OK(rta, attrlen); rta = RTA_NEXT(rta, attrlen)) {
            if (rta->rta_type == IFLA_IFNAME) {
                printf("    name: %s\n", (char *)RTA_DATA(rta));
            }
        }
    }

    close(fd);
    return 0;
}

```
