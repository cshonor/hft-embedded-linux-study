## 要点

```c
prctl(PR_SET_PDEATHSIG, sig);  /* 父死则本进程收 sig */
```

感知**直接父进程**死亡；常见于 worker 跟随父退出。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | PR_SET_PDEATHSIG 让 worker 在父进程死后自动收信号退出，是嵌入式守护进程防止孤儿残留的简洁做法 |
| HFT | 策略 worker 绑定父进程生命周期，父崩了 worker 跟着退，避免「半死」交易进程继续下单；注意它感知的是直接父进程，中间层转手要重设 |

## 代码示例

```c
#include <sys/prctl.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    /* PR_SET_PDEATHSIG: 父进程退出时收到信号 */
    prctl(PR_SET_PDEATHSIG, SIGTERM);
    printf("父退出时本进程将收到 SIGTERM\n");

    /* PR_SET_NAME: 设置线程名 */
    prctl(PR_SET_NAME, "my_process", 0, 0, 0);
    char name[16] = {0};
    prctl(PR_GET_NAME, name);
    printf("线程名: %s\n", name);
    return 0;
}
```
