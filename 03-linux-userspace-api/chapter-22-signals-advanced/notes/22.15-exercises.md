## 练习 1：用 `sigsuspend` 实现原子的「等待 SIGUSR1 或 SIGUSR2」

写出完整代码，要求解除阻塞与进入睡眠之间**不能有竞态窗口**。

<details>
<summary>参考答案</summary>

```c
#define _GNU_SOURCE
#include <signal.h>
#include <stdio.h>
#include <unistd.h>
#include <errno.h>

static volatile sig_atomic_t got = 0;

static void handler(int sig) { got = sig; }        /* 只置标志，安全 */

int main(void)
{
    sigset_t wait_set, prev_mask, block_set;
    struct sigaction sa = {0};

    /* ① 装 handler（必须在解除阻塞之前）*/
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;                        /* 显式写 0，不依赖默认值 */
    sigaction(SIGUSR1, &sa, NULL);
    sigaction(SIGUSR2, &sa, NULL);

    /* ② 先阻塞目标信号 */
    sigemptyset(&block_set);
    sigaddset(&block_set, SIGUSR1);
    sigaddset(&block_set, SIGUSR2);
    sigprocmask(SIG_BLOCK, &block_set, &prev_mask);

    /* ③ 构造「睡眠期间的掩码」= 原掩码（不含 SIGUSR1/SIGUSR2）
     *
     *    关键点：prev_mask 是【阻塞之前】的掩码，所以这两个信号
     *    在 prev_mask 里是【未阻塞】的 —— 传给 sigsuspend 后
     *    它们被放开，其他信号保持原有阻塞状态。
     */
    wait_set = prev_mask;
    sigdelset(&wait_set, SIGUSR1);
    sigdelset(&wait_set, SIGUSR2);

    printf("等待 SIGUSR1(%d) 或 SIGUSR2(%d)...\n", SIGUSR1, SIGUSR2);

    /* ④ 原子：换掩码 + 睡，一步完成，无窗口 */
    sigsuspend(&wait_set);                  /* 永远返回 -1/EINTR */

    printf("收到信号 %d\n", got);

    /* ⑤ 恢复原掩码（sigsuspend 返回时已自动恢复，这步是保险）*/
    sigprocmask(SIG_SETMASK, &prev_mask, NULL);
    return 0;
}
```

**为什么没有竞态**：

```c
/* kernel/signal.c:4650 */
SYSCALL_DEFINE3(sigsuspend, int, unused1, int, unused2, old_sigset_t, mask)
{
	...
	set_current_blocked(&new_mask);              /* ① 换掩码 */
	current->saved_sigmask = current->blocked;
	__set_current_state(TASK_INTERRUPTIBLE);     /* ② 睡   */
	schedule();
	set_restore_sigmask();                       /* ③ 恢复 */
	return -ERESTARTNOHAND;
}
```

对比 `pause():4639` 的方案：

```c
sigprocmask(SIG_SETMASK, &wait_set, NULL);    /* ① 解除阻塞 */
                                             /* ← 信号在此到达 → 递送、handler 跑完 */
pause();                                     /* ② 睡 → 永远等不到 */
```

`sigsuspend` 从不「先解除再睡」，而是**直接睡在新掩码上**，所以中间没有任何可执行用户代码的窗口。

**最容易犯的错**：把「只含目标信号」的集合传给 `sigsuspend`：

```c
sigset_t bad;
sigemptyset(&bad);
sigaddset(&bad, SIGUSR1);
sigaddset(&bad, SIGUSR2);
sigsuspend(&bad);        /* ✗ 语义完全反了！ */
```

`sigsuspend` 的参数是「**睡眠期间的完整掩码**」，不是「要等哪些信号」。传 `bad` 意味着睡眠期间**只阻塞** SIGUSR1/2，其他全部放开——而 SIGUSR1/2 是你要等的，反而没被阻塞……等等，这看起来好像也能工作？

**不能**。因为 `sigsuspend` 的语义是「放开某些信号然后睡」，传 `bad` 时 SIGUSR1/2 **不在**掩码里（未阻塞）→ 能递送 → 确实能等到。但其他**所有**信号也都被放开了（`bad` 里没有它们）→ 你无意中解除了 SIGTERM、SIGINT 等的阻塞，睡眠期间一个 `Ctrl-C` 就杀掉进程。正确做法永远是「取当前掩码 → 增删目标信号 → 传入」。

</details>

## 练习 2：`sigwaitinfo` 与 `sigsuspend` 的本质区别

从「信号是否被 handler 处理」「返回值语义」「是否需要装 handler」三个角度对比，并说明为什么多线程程序应该选前者。

<details>
<summary>参考答案</summary>

| 维度 | `sigsuspend(&mask)` | `sigwaitinfo(&set, &info)` |
|------|---------------------|----------------------------|
| **信号被怎么消费** | **递送**——触发 handler，handler 返回后 `sigsuspend` 才返回 | **取走**——直接从 pending 队列摘除，不触发 handler |
| 返回值 | 恒为 `-1`，`errno=EINTR` | 信号编号（≥1），失败 `-1` |
| `siginfo_t` | 要拿就得装 `SA_SIGINFO` handler | **直接**填进 `info` 出参 |
| 需要装 handler？ | ✅ 必须（否则默认动作可能杀进程） | ❌ 不需要 |
| 参数语义 | 睡眠期间的**完整掩码** | 想取走的**信号集合** |
| 超时 | ❌ | ✅ `sigtimedwait(set, info, &ts)` |
| async-signal-safe 约束 | ✅ handler 里受严格约束 | ❌ **完全不受**——普通同步代码 |

内核实现对照：

```c
/* sigsuspend:4650 —— 换掩码睡觉，醒来后让 handler 跑 */
set_current_blocked(&new_mask);
__set_current_state(TASK_INTERRUPTIBLE);
schedule();
set_restore_sigmask();

/* rt_sigtimedwait:3663 —— 直接从 pending 里摘出返回给用户 */
for (;;) {
	ret = dequeue_signal(current, &ksig, ...);
	if (ret) {
		if (copy_to_user(info, &ksig.info, sizeof(*info)))
			return -EFAULT;
		return ret;                     /* 返回信号编号，不跑 handler */
	}
	if (tout && hrtimer...)
		return -EAGAIN;                 /* 超时 */
	__set_current_state(TASK_INTERRUPTIBLE);
	schedule();
}
```

**为什么多线程程序选 `sigwaitinfo`**：

```
模型 A：handler 模型
  ┌──────────────────────────────────────────┐
  │ 任意 worker 线程 ── 被信号打断 ──→ handler │
  │   · 打断点是【不确定的】（任意一条指令）  │
  │   · handler 里只能用 async-signal-safe 函数│
  │   · 加锁会自我死锁                        │
  │   · 抖动不可预测（HFT 大忌）              │
  └──────────────────────────────────────────┘

模型 B：专用信号线程（推荐）
  ┌──────────────────────────────────────────┐
  │ main: pthread_sigmask(SIG_BLOCK, {全部})  │
  │   ↓ 所有后续 pthread_create 的线程继承     │
  │ worker 线程：天然不受打扰                 │
  │                                          │
  │ 信号线程: for(;;) {                       │
  │     sig = sigwaitinfo(&set, &info);       │
  │     handle(sig, &info);   ← 普通同步代码！ │
  │ }                                         │
  └──────────────────────────────────────────┘
```

三个决定性优势：

1. **不受 async-signal-safe 约束**：`handle()` 里可以 `malloc`、`printf`、加锁、调任何库函数
2. **抖动可控**：worker 线程永远不会被信号打断，延迟分布干净
3. **信号自动串行化**：所有信号在单一线程里排队处理，天然无并发

见 [Ch22.10](22.10-synchronously-waiting-for-a-signal.md)。

</details>

## 练习 3：为什么 `signalfd` 要求信号先被阻塞？

如果不阻塞会怎样？写出正确的初始化顺序。

<details>
<summary>参考答案</summary>

**分支图**：

```
  信号到达
     │
     ├─ 未被阻塞 ──→ 触发 handler / 执行默认动作
     │                  · 有 handler → handler 跑，signalfd 上永远没数据
     │                  · 无 handler → 默认动作（如 SIGTERM 直接杀进程）
     │
     └─ 已被阻塞 ──→ 进 pending 队列 ──→ signalfd 可读，read() 取走
```

不阻塞的话，进程会**先被信号本身处理掉**，根本轮不到 fd。`signalfd` 的设计前提是「信号留在 pending 队列里等我去取」。

**正确顺序**（三个步骤不能颠倒）：

```c
#define _GNU_SOURCE
#include <sys/signalfd.h>
#include <signal.h>
#include <unistd.h>

int setup_signalfd(void)
{
    sigset_t mask;

    /* ① 构造要经 fd 接收的信号集合 */
    sigemptyset(&mask);
    sigaddset(&mask, SIGINT);
    sigaddset(&mask, SIGTERM);
    sigaddset(&mask, SIGHUP);
    sigaddset(&mask, SIGUSR1);

    /* ② 【必须先阻塞】—— 放在 signalfd() 之前 */
    if (sigprocmask(SIG_BLOCK, &mask, NULL) == -1)
        return -1;

    /* ③ 建 fd（SFD_NONBLOCK 让 read 不阻塞，便于 epoll）*/
    int sfd = signalfd(-1, &mask, SFD_NONBLOCK | SFD_CLOEXEC);
    return sfd;                 /* -1 = 失败 */
}

/* 读取：缓冲区必须 ≥ sizeof(struct signalfd_siginfo)，否则 EINVAL */
void drain_signalfd(int sfd)
{
    struct signalfd_siginfo si;

    for (;;) {
        ssize_t n = read(sfd, &si, sizeof(si));
        if (n == -1) {
            if (errno == EAGAIN || errno == EWOULDBLOCK)
                break;                      /* 读干净了 */
            if (errno == EINTR)
                continue;
            break;
        }
        if (n != sizeof(si))                /* 短读：内核要么给完整一个，要么 EINVAL */
            break;
        handle_signal(si.ssi_signo, &si);
    }
}
```

**`read()` 缓冲区的坑**（`fs/signalfd.c:202`）：

```c
static ssize_t signalfd_read(struct file *file, char __user *buf, size_t count, ...)
{
	...
	count /= sizeof(struct signalfd_siginfo);      /* 能装几个？*/
	if (!count)                                    /* 一个都装不下 */
		return -EINVAL;                        /* :211-213 ← 不是 ENOBUFS！*/
	...
}
```

用一个 8 字节的 `int` 去读 → `count / sizeof(signalfd_siginfo)` = 0 → 返回 **`-EINVAL`**。这是 `signalfd` 最经典的新手错误，报错信息（"Invalid argument"）完全不提示「缓冲区太小」。

**限制**（同样重要）：`signalfd` **抓不到** `SIGSEGV`/`SIGBUS`/`SIGFPE`/`SIGILL`——这些同步故障信号走 `force_sig_info_to_task():1336`，内核会**撤销 `SIG_IGN`、解除阻塞、线程定向直投**，压根不进 pending 队列。崩溃兜底只能用 `sigaction` + `SA_ONSTACK`。

</details>

## 练习 4：实时信号排队与队列溢出

用 `sigqueue` 向自己发 10 个带数据的实时信号，然后全部取出。要求：处理队列溢出（`EAGAIN`），并对比用标准信号做同样的事会怎样。

<details>
<summary>参考答案</summary>

```c
#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <signal.h>
#include <unistd.h>
#include <errno.h>

#define SIG_CTRL   (SIGRTMIN + 0)      /* 注意：SIGRTMIN 是宏，不能写死 34 */

int main(void)
{
    sigset_t set;

    /* ① 阻塞，准备用 sigwaitinfo 同步取 */
    sigemptyset(&set);
    sigaddset(&set, SIG_CTRL);
    sigprocmask(SIG_BLOCK, &set, NULL);

    /* ② 发 10 个带数据的实时信号 */
    int sent = 0, failed = 0;
    for (int i = 0; i < 10; i++) {
        union sigval sv = { .sival_int = 100 + i };
        if (sigqueue(getpid(), SIG_CTRL, sv) == 0) {
            sent++;
        } else {
            failed++;
            /* 队列满 → EAGAIN（RLIMIT_SIGPENDING 限制）
             * 正确做法：不能简单丢弃！控制类信号丢了可能导致状态不一致 */
            fprintf(stderr, "sigqueue #%d 失败: %s\n", i, strerror(errno));
        }
    }
    printf("发送: 成功 %d, 失败 %d\n", sent, failed);

    /* ③ 全部取出（实时信号排队，10 个都在）*/
    for (;;) {
        siginfo_t info;
        struct timespec zero = {0, 0};      /* 零超时 = 非阻塞轮询 */
        int sig = sigtimedwait(&set, &info, &zero);

        if (sig == -1) {
            if (errno == EAGAIN) break;     /* 队列空了 —— 超时，正常结束 */
            if (errno == EINTR) continue;   /* 被【集合外】的信号打断，重试 */
            perror("sigtimedwait");
            break;
        }
        printf("  取出 sig=%d  si_int=%d  si_code=%d  si_pid=%d\n",
               sig, info.si_value.sival_int, info.si_code, info.si_pid);
    }

    /* ④ 对比：标准信号不排队 */
    printf("\n--- 对照：标准信号 SIGUSR1 连发 10 次 ---\n");

    sigset_t s1;
    sigemptyset(&s1);
    sigaddset(&s1, SIGUSR1);
    sigprocmask(SIG_BLOCK, &s1, NULL);

    for (int i = 0; i < 10; i++)
        kill(getpid(), SIGUSR1);            /* 全部成功（位图记 1 个）*/

    int got = 0;
    for (;;) {
        siginfo_t info;
        struct timespec zero = {0, 0};
        int sig = sigtimedwait(&s1, &info, &zero);
        if (sig == -1) break;
        got++;
    }
    printf("  发 10 次 SIGUSR1 → 只取到 %d 个（位图，不排队）\n", got);

    return 0;
}
```

**预期输出**：

```
发送: 成功 10, 失败 0
  取出 sig=34  si_int=100  si_code=-1  si_pid=12345
  取出 sig=34  si_int=101  si_code=-1  si_pid=12345
  ...（共 10 行，按 FIFO 顺序）

--- 对照：标准信号 SIGUSR1 连发 10 次 ---
  发 10 次 SIGUSR1 → 只取到 1 个（位图，不排队）
```

**关键差异的根源**（`kernel/signal.c:1079`）：

```c
static bool legacy_queue(struct sigpending *signals, int sig)
{
	return (sig < SIGRTMIN) && sigismember(&signals->signal, sig);
	/*      ^^^^^^^^^^^^^^^^ 标准信号才检查 */
}
```

实时信号走的是链表队列（`__sigqueue_alloc():414` + `list_add_tail:1132`），每个信号分配一个 `struct sigqueue`，携带 `siginfo`。

**`EAGAIN` 队列溢出的正确处理**：

```c
/* ✗ 危险：直接丢弃控制指令 */
if (sigqueue(pid, SIG_CTRL, sv) == -1 && errno == EAGAIN)
    ;  /* 丢了 —— 接收方的状态机可能就此卡死 */

/* ✓ 正确：降级到可靠的旁路 */
if (sigqueue(pid, SIG_CTRL, sv) == -1 && errno == EAGAIN) {
    /* 方案 A：写入共享内存 / eventfd 计数的旁路队列，让接收方下次来取
     * 方案 B：自己重排（退避重试），并计数告警
     * 方案 C：改用「信号只通知、数据走共享内存」的分层设计（推荐）*/
    write(fd_fallback, &sv, sizeof(sv));
    eventfd_write(notify_fd, 1);        /* 再补一个通知 */
}
```

**推荐的分层设计**（见 [22.12](22.12-interprocess-communication-with-signals.md)）：信号只当「门铃」，真正的数据放共享内存 / ring buffer。这样即使队列溢出丢了一个门铃，接收方下次处理时也会把队列里积压的数据全部消费掉——**不会丢失状态**。

</details>

## 练习 5：core dump 拿不到的六道开关

进程明明 `SIGSEGV` 了却拿不到 core 文件，列出全部可能原因并给出排查命令。

<details>
<summary>参考答案</summary>

| # | 开关 | 检查命令 | 修法 |
|---|------|----------|------|
| 1 | `RLIMIT_CORE = 0` | `ulimit -c` | `ulimit -c unlimited`（启动脚本里设，或 `setrlimit(RLIMIT_CORE, ...)`） |
| 2 | `core_pattern` 指向不可写 / 是 `|` 管道但 handler 程序缺失 | `cat /proc/sys/kernel/core_pattern` | 改成可写路径，或确保管道程序存在（如 systemd-coredump） |
| 3 | 进程 `dumpable = 0`（setuid 程序、`PR_SET_DUMPABLE 0`、或 Docker 默认） | `cat /proc/PID/coredump_filter` 是否存在；`grep CoreDumping /proc/PID/status` | `prctl(PR_SET_DUMPABLE, 1)`；对 setuid 程序这是**安全特性**，不要轻易开 |
| 4 | 信号不在 `SIG_KERNEL_COREDUMP_MASK` | （`SIGKILL`/`SIGTERM` 就不在名单里） | 用 `kill -QUIT`（SIGQUIT 在名单里）触发诊断性 core |
| 5 | 信号被 handler 捕获或忽略 | `sigaction(sig, NULL, &sa)` 读回 | 崩溃兜底 handler 应该在写完现场后 `_exit(128+sig)`，**不要**试图恢复执行 |
| 6 | 目录不可写 / 磁盘满 / `fs.suid_dumpable` | `df -h`；`cat /proc/sys/fs/suid_dumpable` | 换目录或清理空间 |

**内核侧的判定链**（`kernel/signal.c`）：

```c
get_signal():2660
    ↓
if (sig_kernel_coredump(signr)) {        /* :2866 —— 名单判定 */
        proc_coredump_connector(current);
        do_coredump(&ksig->info);        /* :2878 —— 六道开关在这里全查一遍 */
}
do_group_exit(ksig->info.si_signo);      /* :2892 —— 无论如何都要死 */
```

**哪些信号会 dump**（`include/linux/signal.h:425`）：

```c
#define SIG_KERNEL_COREDUMP_MASK (\
        rt_sigmask(SIGQUIT) | rt_sigmask(SIGILL) | rt_sigmask(SIGTRAP) | \
        rt_sigmask(SIGABRT) | rt_sigmask(SIGFPE) | rt_sigmask(SIGSEGV) | \
        rt_sigmask(SIGBUS)  | rt_sigmask(SIGSYS) | rt_sigmask(SIGXCPU) | \
        rt_sigmask(SIGXFSZ) | SIGEMT_MASK)
```

注意 **`SIGKILL`(9) 和 `SIGTERM`(15) 都不在名单里**——所以运维上让「挂死」的进程留 core 的标准手段是 `kill -QUIT`（前提是该进程没捕获 SIGQUIT）。

**排查脚本**：

```bash
#!/bin/bash
# core_check.sh —— 一次性核对六道开关
echo "1) RLIMIT_CORE      : $(ulimit -c)"
echo "2) core_pattern     : $(cat /proc/sys/kernel/core_pattern)"
echo "3) suid_dumpable    : $(cat /proc/sys/fs/suid_dumpable 2>/dev/null)"
echo "4) core 目录可写?   : $(touch "$(dirname "$(cat /proc/sys/kernel/core_pattern | grep -v '^|' || echo './core')")/.wtest" 2>&1 && echo yes || echo NO)"
echo "5) 磁盘剩余         : $(df -h . | tail -1)"
echo "6) systemd-coredump?: $(command -v coredumpctl >/dev/null && coredumpctl list -1 || echo 'n/a')"

# 速测：跑一个必段错误的程序
cat > /tmp/segv.c <<'EOF'
int main(void) { int *p = 0; *p = 1; return 0; }
EOF
gcc -g -o /tmp/segv /tmp/segv.c && /tmp/segv
echo "退出码: $? （139 = 128+11 = SIGSEGV）"
ls -l core* /var/lib/systemd/coredump/* 2>/dev/null | tail -5
```

**生产 HFT 的反向考量**：交易进程通常**主动关 core**（`RLIMIT_CORE=0` + `PR_SET_DUMPABLE 0`）——8GB 持仓共享内存 dump 一次会卡数秒、打满磁盘 I/O，反而拖垮同机进程；且 core 含客户数据，落地即合规风险。替代方案是 `SA_ONSTACK` 的 SIGSEGV handler 写**最小现场**（backtrace + 关键寄存器）到预分配缓冲，微秒级完成。详见 [22.1](22.1-core-dump-files.md)。

</details>

## 练习 6：`kill -9` 杀不掉的进程怎么诊断？

<details>
<summary>参考答案</summary>

**根因**：进程处于 `TASK_UNINTERRUPTIBLE`（`ps` 里的 `D` 状态）。

```c
/* kernel/signal.c:769 */
void signal_wake_up_state(struct task_struct *t, unsigned int state)
{
	set_tsk_thread_flag(t, TIF_SIGPENDING);       /* ① 打标记 */

	if (!wake_up_state(t, state | TASK_INTERRUPTIBLE))
		kick_process(t);                      /* ② 跨 CPU 时踢一脚 */
	/*                    ^^^^^^^^^^^^^^^^^^^^ 只唤醒状态匹配的 */
}
```

`wake_up_state()` 只唤醒**状态位匹配**的任务。`UNINTERRUPTIBLE` 没有 `TASK_INTERRUPTIBLE` 位，**叫不醒**——SIGKILL 只是挂在它的 pending 队列上，等它自己醒来才处理。

| 状态 | `sched.h` | `kill -9` 能唤醒 | 典型来源 |
|------|-----------|------------------|----------|
| `TASK_INTERRUPTIBLE` | `:87` | ✅ | 绝大多数阻塞 syscall |
| `TASK_KILLABLE` | `:116` | ✅（仅致命信号） | `*_killable()` 系列内核等待 |
| `TASK_UNINTERRUPTIBLE` | `:88` | ❌ | 磁盘/NFS I/O、驱动临界区 |
| `TASK_IDLE` | `:120` | ❌ | 内核线程空闲 |

**诊断步骤**：

```bash
# ① 找出所有 D 状态进程
ps -eo pid,ppid,stat,wchan:30,comm | awk '$3 ~ /D/'

# 字段说明：
#   stat  = D 表示不可中断睡眠
#   wchan = 卡在哪个内核函数（最有价值的一列）

# ② 看信号是否挂上了（SigPnd=线程私有, ShdPnd=线程组共享）
grep -E '^(State|SigPnd|ShdPnd|SigBlk|SigCgt)' /proc/PID/status

# ③ 看内核栈（需要 root + CONFIG_STACKTRACE）
cat /proc/PID/stack

# ④ 看它在等哪个 syscall / 哪个文件
ls -l /proc/PID/fd
cat /proc/PID/syscall          # 系统调用号 + 参数
cat /proc/PID/wchan

# ⑤ 全局看有没有大量 D 状态（通常是存储故障的信号）
ps -eo stat --no-headers | grep -c '^D'
dmesg | tail -50                # 找 I/O error / NFS timeout / 磁盘坏道
```

**判读要点**：

```
$ ps -eo pid,stat,wchan:30,comm | awk '$2 ~ /D/'
  1234 D    nfs_wait_bit_killable      myapp
  1235 D    __wait_on_buffer           myapp

$ grep -E '^(State|SigPnd|ShdPnd)' /proc/1234/status
  State:  D (disk sleep)
  SigPnd: 0000000000000000
  ShdPnd: 0000000000000100      ← bit 8 = 信号 9 (SIGKILL) 已挂在共享 pending
```

`ShdPnd` 有 SIGKILL 但状态仍是 `D` → **信号已经送到，只是进程还没醒**。此时：

- 若 `wchan` 是 `nfs_*` → 检查 NFS 服务器 / 网络，或用 `umount -f -l` 强制卸载
- 若 `wchan` 是块设备等待 → 检查磁盘健康（`smartctl -a /dev/sdX`）、`dmesg`
- 若是驱动的 `UNINTERRUPTIBLE` 等待 → 驱动 bug，应该改用 `TASK_KILLABLE`
- **硬件不恢复就只能重启**——这也是嵌入式设备必须设计硬件 watchdog 的原因

**对比：`TASK_KILLABLE` 为什么更好**（`sched.h:116`）

```c
#define TASK_KILLABLE  (TASK_WAKEKILL | TASK_UNINTERRUPTIBLE)
```

它保持了「不被普通信号打断」的语义（避免 `EINTR` 路径），但**保留了对致命信号的响应能力**。内核里那些可能长时间等待的地方（如 `wait_for_completion_killable()`）应该用这个而不是裸 `UNINTERRUPTIBLE`。

</details>

## 练习 7：遗留信号 API 迁移审查

给出一段使用遗留 API 的老代码，找出所有问题并改写成 POSIX 版本。

```c
/* legacy_server.c —— 20 年前的嵌入式守护进程片段 */
#include <signal.h>
#include <stdio.h>
#include <unistd.h>

void on_term(int sig) {
    printf("terminating\n");          /* ← 有问题 */
    cleanup();                        /* ← 有问题 */
    exit(0);                          /* ← 有问题 */
}

void on_child(int sig) {
    wait(NULL);                       /* ← 有问题 */
}

int main(void) {
    signal(SIGTERM, on_term);
    signal(SIGCHLD, on_child);
    signal(SIGPIPE, SIG_IGN);

    sighold(SIGUSR1);
    /* ... 主循环 read()/write() ... */
    sigpause(SIGUSR1);
    sigrelse(SIGUSR1);
    return 0;
}
```

<details>
<summary>参考答案</summary>

### 问题清单

| # | 位置 | 问题 | 后果 |
|---|------|------|------|
| 1 | `signal(SIGTERM, on_term)` | `signal()` 语义不可移植 | SysV 上处置一次性（第二次 SIGTERM 直接杀进程）；自动重启行为依赖平台 |
| 2 | `printf()` in handler | **非** async-signal-safe | stdio 有内部锁 + 缓冲区；信号在 `printf` 持锁时到达 → **死锁** |
| 3 | `cleanup()` in handler | 大概率含锁/`free`/非安全调用 | 同上，死锁或堆损坏 |
| 4 | `exit(0)` in handler | **非** async-signal-safe | 会跑 atexit 处理器 + 冲刷 stdio；若 stdio 锁被持有 → 死锁。应用 `_exit()` |
| 5 | `wait(NULL)` 一次 | SIGCHLD 不排队 | 多子进程同时退出 → 只回收一个 → 其余**永久僵尸** |
| 6 | 无 `SA_RESTART` | （若用 `sigaction` 则默认不重启） | `read()` 偶发 `EINTR`，表现为丢数据 |
| 7 | `sighold` / `sigrelse` | System V 遗留 | 应改 `sigprocmask` |
| 8 | `sigpause(SIGUSR1)` | SysV/BSD 同名不同义 | 语义依赖编译宏；且**非原子**（原始 SysV 是「解除 + pause」两步） |
| 9 | 未 `sigemptyset(&sa.sa_mask)` | （改写时易漏） | 栈上结构体未初始化 → 掩码是**垃圾位** |

### 改写后的 POSIX 版本

```c
#define _GNU_SOURCE
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <sys/wait.h>
#include <string.h>

static volatile sig_atomic_t got_term = 0;   /* 唯一允许的通信方式 */
static volatile sig_atomic_t got_usr1 = 0;

/* handler 只做一件事：置标志。绝对不调 printf/cleanup/exit */
static void on_term(int sig)
{
    (void)sig;
    got_term = 1;
}

static void on_usr1(int sig)
{
    (void)sig;
    got_usr1 = 1;
}

static void on_child(int sig)
{
    int saved = errno;                       /* ① 保护 errno */
    (void)sig;
    /* ② 循环回收 —— SIGCHLD 不排队，来一个信号可能对应多个子进程 */
    while (waitpid(-1, NULL, WNOHANG) > 0)
        ;
    errno = saved;                           /* ③ 恢复 errno */
}

static int install(int sig, void (*h)(int), int flags)
{
    struct sigaction sa, verify;

    memset(&sa, 0, sizeof(sa));              /* ④ 清零（含 sa_mask）*/
    sa.sa_handler = h;
    sigemptyset(&sa.sa_mask);                /* ⑤ 显式初始化，双保险 */
    sa.sa_flags = flags;
    if (sigaction(sig, &sa, NULL) == -1)
        return -1;

    /* ⑥ 读回校验 —— 内核会静默清除未知 flag（do_sigaction():4153-4156）*/
    sigaction(sig, NULL, &verify);
    if (verify.sa_handler != h || (verify.sa_flags & flags) != (unsigned)flags)
        return -1;
    return 0;
}

int main(void)
{
    sigset_t usr1_set, prev;
    ssize_t  n;
    char     buf[4096];

    /* ---- ① 信号处置（全部显式 sa_flags）---- */
    install(SIGTERM, on_term, SA_RESTART);
    install(SIGINT,  on_term, SA_RESTART);
    install(SIGUSR1, on_usr1, SA_RESTART);
    /* SIGCHLD 用 SA_NOCLDSTOP 过滤停止/恢复，减少无谓 handler 调用 */
    install(SIGCHLD, on_child, SA_RESTART | SA_NOCLDSTOP);

    {
        struct sigaction sa;
        memset(&sa, 0, sizeof(sa));
        sa.sa_handler = SIG_IGN;
        sigemptyset(&sa.sa_mask);
        sa.sa_flags = 0;
        sigaction(SIGPIPE, &sa, NULL);
    }

    /* ---- ② 阻塞 SIGUSR1（取代 sighold）---- */
    sigemptyset(&usr1_set);
    sigaddset(&usr1_set, SIGUSR1);
    sigprocmask(SIG_BLOCK, &usr1_set, &prev);

    /* ---- ③ 主循环 ---- */
    for (;;) {
        n = read(STDIN_FILENO, buf, sizeof(buf));
        if (n == -1) {
            if (errno == EINTR) {
                /* SA_RESTART 已自动重启；这里只是兜底 */
                if (got_term) break;
                continue;
            }
            break;
        }
        if (n == 0) break;

        if (got_term) break;                 /* 在【安全点】处理，不在 handler 里 */
        if (got_usr1) { got_usr1 = 0; do_reload_config(); }
    }

    /* ---- ④ 取代 sigpause：原子等待 SIGUSR1（取代 sighold/sigrelse）---- */
    {
        sigset_t wait_mask = prev;           /* 取阻塞前的掩码 */
        sigdelset(&wait_mask, SIGUSR1);      /* 放开 SIGUSR1 */
        sigsuspend(&wait_mask);              /* 换掩码 + 睡，原子 */
    }

    /* ---- ⑤ 优雅退出（在普通上下文里做，不在 handler 里）---- */
    cleanup();
    fflush(NULL);
    _exit(0);                                /* 或 return 0 —— 这里是正常流程 */
}
```

### 迁移检查清单

- [ ] `grep -nE '\b(signal|sigset|sighold|sigrelse|sigignore|sigpause|sigblock|sigvec|sigsetmask|siggetmask)\s*\(' src/` 命中数 = 0
- [ ] 每处 `sigaction` 都**显式**写了 `sa_flags`（含 `0`）
- [ ] 每处都先 `memset(&sa, 0, sizeof(sa))` **且** `sigemptyset(&sa.sa_mask)`
- [ ] handler 里只有：置 `volatile sig_atomic_t`、保护/恢复 `errno`、`_exit()`
- [ ] `SIGCHLD` handler 里**循环** `waitpid(..., WNOHANG)`
- [ ] 初始化完成后 `sigaction(sig, NULL, &verify)` **读回校验**
- [ ] 等待信号一律用 `sigsuspend`（完整掩码语义），不用 `pause` / `sigpause`

详见 [22.13](22.13-earlier-signal-apis-system-v-and-bsd.md) 与 [Ch21.1](../../chapter-21-signal-handlers/notes/21.1-designing-signal-handlers.md)。

</details>

## 综合题：生产级信号管理模块

**要求**：实现一个可复用的 `signal_mgr`，满足：

1. **专用线程模型**：main 阻塞所有关心的信号 → 起一个 `sigwaitinfo` 线程处理
2. **崩溃兜底**：`SIGSEGV`/`SIGBUS`/`SIGFPE`/`SIGILL` 用 `sigaltstack` + `SA_ONSTACK` + `SA_SIGINFO` handler 写最小现场
3. **优雅关闭状态机**：第一次 `SIGTERM` → 通知主循环优雅停；第二次 → 立即 `_exit`
4. **处置审计**：初始化后读回校验，检测第三方库是否覆盖
5. **core 开关**：`setrlimit(RLIMIT_CORE)` + `PR_SET_DUMPABLE` 按配置控制

<details>
<summary>参考实现</summary>

```c
/* signal_mgr.c —— 生产级信号管理模块
 *
 * 架构：
 *   main()
 *     ├─ block_all()                 阻塞关心的信号（worker 线程继承）
 *     ├─ install_crash_handlers()    sigaltstack + SA_ONSTACK（唯一保留 handler 处）
 *     ├─ pthread_create(sigthread)   sigwaitinfo 循环
 *     └─ 主业务循环（不受信号打扰）
 *
 * 编译: gcc -Wall -Wextra -O2 -pthread -o signal_mgr signal_mgr.c -ldl
 */
#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <signal.h>
#include <unistd.h>
#include <errno.h>
#include <pthread.h>
#include <sys/prctl.h>
#include <sys/resource.h>
#include <sys/wait.h>
#include <execinfo.h>

/* ───────────── 配置 ───────────── */

typedef struct {
    int   enable_core;        /* 是否允许 core dump */
    int   graceful_timeout_ms;/* 第一次 SIGTERM 后的宽限期 */
} sig_mgr_cfg_t;

/* ───────────── 内部状态 ───────────── */

static volatile sig_atomic_t g_shutdown_req = 0;   /* 优雅停止请求 */
static volatile sig_atomic_t g_term_count   = 0;   /* SIGTERM 次数 */
static pthread_mutex_t       g_lock = PTHREAD_MUTEX_INITIALIZER;
static pthread_cond_t        g_cond = PTHREAD_COND_INITIALIZER;
static sig_mgr_cfg_t         g_cfg  = { .enable_core = 0, .graceful_timeout_ms = 5000 };

/* 用户回调（在【信号线程】的普通上下文里跑，可以随便调任何函数）*/
typedef void (*sig_handler_fn)(int sig, siginfo_t *info, void *user);
static sig_handler_fn g_user_handler = NULL;
static void          *g_user_arg     = NULL;

/* ───────────── ① 崩溃兜底 handler ───────────── */

#define BACKTRACE_MAX 32
#define CRASH_MSG_MAX 4096

static void crash_write(int fd, const char *s)
{
    size_t len = strlen(s);
    while (len > 0) {
        ssize_t n = write(fd, s, len);
        if (n <= 0) {
            if (n == -1 && errno == EINTR) continue;
            break;
        }
        s += n; len -= (size_t)n;
    }
}

/* 只能调 async-signal-safe 函数：write / backtrace_symbols_fd / _exit */
static void crash_handler(int sig, siginfo_t *si, void *ctx)
{
    (void)ctx;
    static const char hdr[] = "\n===== FATAL SIGNAL =====\n";
    crash_write(STDERR_FILENO, hdr);

    char buf[256];
    int n;

    n = snprintf(buf, sizeof(buf), "  signal : %d (%s)\n", sig, strsignal(sig));
    crash_write(STDERR_FILENO, buf); (void)n;

    n = snprintf(buf, sizeof(buf), "  si_code: %d  (%s)\n",
                 si->si_code, SI_FROMKERNEL(si) ? "kernel/hw" : "user");
    crash_write(STDERR_FILENO, buf); (void)n;

    /* si_addr 语义：SIGSEGV/SIGBUS → 内存地址；SIGFPE/SIGILL → 指令地址 */
    n = snprintf(buf, sizeof(buf), "  si_addr: %p\n", si->si_addr);
    crash_write(STDERR_FILENO, buf); (void)n;

    /* 最小 backtrace —— 不 malloc，直接写 fd */
    crash_write(STDERR_FILENO, "  backtrace:\n");
    void *bt[BACKTRACE_MAX];
    int bt_n = backtrace(bt, BACKTRACE_MAX);
    backtrace_symbols_fd(bt, bt_n, STDERR_FILENO);

    crash_write(STDERR_FILENO, "========================\n");

    /* 关键：不能正常返回！CPU 会重试同一条指令 → 无限循环
     * 用默认处置 re-raise，让内核产生 core（若已开启）*/
    signal(sig, SIG_DFL);            /* signal() 在这里无害：下一行就死了 */
    raise(sig);
    _exit(128 + sig);                /* 保险 */
}

static int install_crash_handlers(void)
{
    static char stack_buf[SIGSTKSZ * 4];      /* 静态分配，永不 free */
    stack_t ss = {
        .ss_sp    = stack_buf,
        .ss_size  = sizeof(stack_buf),
        .ss_flags = 0,
    };

    /* ① 先设备用栈（栈溢出时原栈已不可用）*/
    if (sigaltstack(&ss, NULL) == -1)
        return -1;

    /* ② 逐个注册 —— SA_ONSTACK 是【按信号】注册的，不是全局 */
    static const int crash_sigs[] = { SIGSEGV, SIGBUS, SIGFPE, SIGILL, SIGSYS };

    for (size_t i = 0; i < sizeof(crash_sigs) / sizeof(crash_sigs[0]); i++) {
        struct sigaction sa;
        memset(&sa, 0, sizeof(sa));
        sa.sa_sigaction = crash_handler;         /* 注意：与 sa_handler 是 union */
        sigemptyset(&sa.sa_mask);
        /* SA_ONSTACK 走备用栈 | SA_SIGINFO 拿 siginfo | SA_NODEFER 允许嵌套兜底 */
        sa.sa_flags = SA_ONSTACK | SA_SIGINFO | SA_NODEFER;
        if (sigaction(crash_sigs[i], &sa, NULL) == -1)
            return -1;
    }
    return 0;
}

/* ───────────── ② 处置审计 ───────────── */

static int audit_dispositions(void)
{
    static const int watch[] = {
        SIGTERM, SIGINT, SIGHUP, SIGQUIT, SIGUSR1, SIGUSR2,
        SIGSEGV, SIGBUS, SIGFPE, SIGILL, SIGCHLD, SIGPIPE, SIGALRM
    };
    int suspect = 0;

    for (size_t i = 0; i < sizeof(watch) / sizeof(watch[0]); i++) {
        struct sigaction sa;
        if (sigaction(watch[i], NULL, &sa) == -1)
            continue;

        int is_custom = (sa.sa_handler != SIG_DFL && sa.sa_handler != SIG_IGN);

        /* 崩溃信号：必须是我们的 crash_handler（除非在崩溃列表里由我们装的） */
        if ((watch[i] == SIGSEGV || watch[i] == SIGBUS ||
             watch[i] == SIGFPE  || watch[i] == SIGILL) && is_custom) {
            if (!(sa.sa_flags & SA_ONSTACK)) {
                fprintf(stderr, "[audit] 警告: 信号 %d 的 handler 未设 SA_ONSTACK\n",
                        watch[i]);
                suspect++;
            }
            continue;                    /* 崩溃信号是我们自己装的，跳过 */
        }

        /* 其他信号：不该有自定义 handler（我们走 sigwaitinfo 模型）*/
        if (is_custom) {
            fprintf(stderr, "[audit] 警告: 信号 %d 被装了自定义 handler "
                            "(可能是第三方库)，sigwaitinfo 将收不到它\n", watch[i]);
            suspect++;
        }
    }
    return suspect;
}

/* ───────────── ③ core 开关 ───────────── */

static int configure_core(int enable)
{
    struct rlimit rl;

    /* ① RLIMIT_CORE */
    rl.rlim_cur = enable ? RLIM_INFINITY : 0;
    rl.rlim_max = enable ? RLIM_INFINITY : 0;
    if (setrlimit(RLIMIT_CORE, &rl) == -1)
        return -1;

    /* ② dumpable 标志（setuid 程序、容器里默认是 0）*/
    if (prctl(PR_SET_DUMPABLE, enable ? 1 : 0) == -1)
        return -1;

    return 0;
}

/* ───────────── ④ 信号线程 ───────────── */

static void *sig_thread_main(void *arg)
{
    (void)arg;
    sigset_t set;

    /* 要同步取走的信号 */
    sigemptyset(&set);
    sigaddset(&set, SIGTERM);
    sigaddset(&set, SIGINT);
    sigaddset(&set, SIGHUP);
    sigaddset(&set, SIGUSR1);
    sigaddset(&set, SIGUSR2);
    sigaddset(&set, SIGCHLD);
    sigaddset(&set, SIGQUIT);

    for (;;) {
        siginfo_t info;
        int sig = sigwaitinfo(&set, &info);      /* 不跑 handler，直接取走 */

        if (sig == -1) {
            if (errno == EINTR) continue;        /* 被集合外的信号打断 */
            continue;
        }

        switch (sig) {
        case SIGTERM:
        case SIGINT: {
            int cnt = ++g_term_count;
            if (cnt >= 2) {
                /* 第二次 → 强制退出（不再给宽限期）*/
                crash_write(STDERR_FILENO, "第二次终止请求 → 强制退出\n");
                _exit(128 + sig);
            }
            /* 第一次 → 请求优雅停止 */
            g_shutdown_req = 1;
            pthread_mutex_lock(&g_lock);
            pthread_cond_broadcast(&g_cond);      /* 唤醒主循环 */
            pthread_mutex_unlock(&g_lock);
            break;
        }

        case SIGCHLD:
            /* 在【普通上下文】里循环回收，无 async-signal-safe 约束 */
            {
                int status;
                pid_t pid;
                while ((pid = waitpid(-1, &status, WNOHANG)) > 0) {
                    if (WIFEXITED(status))
                        fprintf(stderr, "child %d exited code=%d\n",
                                pid, WEXITSTATUS(status));
                    else if (WIFSIGNALED(status))
                        fprintf(stderr, "child %d killed by %d%s\n",
                                pid, WTERMSIG(status),
                                WCOREDUMP(status) ? " (core)" : "");
                }
            }
            break;

        default:
            if (g_user_handler)
                g_user_handler(sig, &info, g_user_arg);
            break;
        }
    }
    return NULL;
}

/* ───────────── ⑤ 对外接口 ───────────── */

int sig_mgr_init(const sig_mgr_cfg_t *cfg, sig_handler_fn usr, void *usr_arg)
{
    sigset_t all;
    pthread_t tid;

    if (cfg) g_cfg = *cfg;
    g_user_handler = usr;
    g_user_arg     = usr_arg;

    /* ① core 开关（HFT 生产通常关；盘后复现环境开）*/
    if (configure_core(g_cfg.enable_core) == -1) {
        perror("configure_core");
        return -1;
    }

    /* ② 崩溃兜底 handler —— 这是唯一保留 handler 的地方 */
    if (install_crash_handlers() == -1) {
        perror("install_crash_handlers");
        return -1;
    }

    /* ③ 【关键】阻塞所有关心的信号
     *    必须在 pthread_create 之前——pthread_create 出来的线程会继承掩码，
     *    于是所有 worker 天然不受异步信号打扰。 */
    sigemptyset(&all);
    sigaddset(&all, SIGTERM);
    sigaddset(&all, SIGINT);
    sigaddset(&all, SIGHUP);
    sigaddset(&all, SIGQUIT);
    sigaddset(&all, SIGUSR1);
    sigaddset(&all, SIGUSR2);
    sigaddset(&all, SIGCHLD);
    sigaddset(&all, SIGPIPE);
    if (pthread_sigmask(SIG_BLOCK, &all, NULL) != 0) {
        perror("pthread_sigmask");
        return -1;
    }

    /* ④ 起信号线程（继承阻塞掩码 → sigwaitinfo 才能取到）*/
    if (pthread_create(&tid, NULL, sig_thread_main, NULL) != 0) {
        perror("pthread_create");
        return -1;
    }
    pthread_detach(tid);

    /* ⑤ 审计（放在所有第三方库初始化【之后】）*/
    int suspect = audit_dispositions();
    if (suspect)
        fprintf(stderr, "[audit] 发现 %d 处可疑处置\n", suspect);

    return 0;
}

int sig_mgr_shutdown_requested(void)
{
    return g_shutdown_req;
}

int sig_mgr_wait_shutdown(void)
{
    struct timespec ts;
    pthread_mutex_lock(&g_lock);
    clock_gettime(CLOCK_REALTIME, &ts);
    ts.tv_sec  += g_cfg.graceful_timeout_ms / 1000;
    ts.tv_nsec += (long)(g_cfg.graceful_timeout_ms % 1000) * 1000000L;
    if (ts.tv_nsec >= 1000000000L) { ts.tv_sec++; ts.tv_nsec -= 1000000000L; }

    while (!g_shutdown_req) {
        int rc = pthread_cond_timedwait(&g_cond, &g_lock, &ts);
        if (rc == ETIMEDOUT) { pthread_mutex_unlock(&g_lock); return -1; }
    }
    pthread_mutex_unlock(&g_lock);
    return 0;
}

/* ───────────── ⑥ demo ───────────── */

static void on_user_signal(int sig, siginfo_t *info, void *arg)
{
    (void)arg;
    fprintf(stderr, "[handler] 收到信号 %d, si_pid=%d, si_int=%d\n",
            sig, info->si_pid, info->si_value.sival_int);
}

int main(void)
{
    sig_mgr_cfg_t cfg = { .enable_core = 0, .graceful_timeout_ms = 10000 };

    if (sig_mgr_init(&cfg, on_user_signal, NULL) != 0)
        return 1;

    fprintf(stderr, "pid=%d  就绪。测试:\n"
                    "  kill -TERM %d   → 优雅停止\n"
                    "  kill -USR1 %d   → 用户回调\n"
                    "  kill -SEGV %d   → 崩溃兜底（写 backtrace 后 re-raise）\n",
            getpid(), getpid(), getpid(), getpid());

    /* 主业务循环 —— 完全不受信号打扰 */
    unsigned long iter = 0;
    while (!sig_mgr_shutdown_requested()) {
        /* ... 真正的业务 ... */
        iter++;
        if ((iter % 1000000UL) == 0)
            fprintf(stderr, "  iter=%lu\n", iter);
        usleep(100);
    }

    fprintf(stderr, "收到停止请求，开始优雅关闭...\n");
    /* cleanup(); 落盘、撤单、关闭连接 */
    fprintf(stderr, "已退出\n");
    return 0;
}
```

### 设计要点回顾

| 要点 | 为什么 |
|------|--------|
| **先阻塞，再 `pthread_create`** | 子线程继承掩码 → 所有 worker 天然不受异步信号打扰，抖动可控 |
| **崩溃信号单独用 handler** | `SIGSEGV`/`SIGBUS` 等是**同步**信号，走 `force_sig_info_to_task():1336` 线程定向直投，`signalfd` / `sigwaitinfo` **抓不到** |
| **`sigaltstack` + `SA_ONSTACK`** | 栈溢出时原栈已不可用，handler 必须跑在备用栈上，否则死局 |
| **`SA_ONSTACK` 按信号注册** | 不是全局开关，每个崩溃信号都要单独设 |
| **handler 只写最小现场后 re-raise** | CPU 会重试肇事指令，handler 正常返回 = 无限循环。re-raise 让内核按默认处置处理（若开了 core 就会 dump） |
| **信号线程里是普通同步代码** | `sigwaitinfo` 不跑 handler → 无 async-signal-safe 约束，可 `printf` / 加锁 / 调库 |
| **两次 SIGTERM 强制退出** | 优雅关闭可能卡住（如撤单超时），运维需要一条强制通路 |
| **初始化后审计处置** | 第三方库（尤其闭源 SDK）可能在构造函数里装 handler，覆盖你的；`do_sigaction` 还会**静默清除未知 flag**，只有读回比对能发现 |
| **生产关 core，盘后开** | 8GB 持仓内存 dump 一次卡数秒 + 打满 I/O；且 core 含客户数据，落地即合规风险 |

</details>
