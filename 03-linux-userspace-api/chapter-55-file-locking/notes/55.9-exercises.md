### 练习 1：字节范围锁

**题目**：多进程并发写入同一文件的不同区域，使用 `fcntl` 范围锁确保各自区域互斥。

<details>
<summary>参考答案</summary>

```c
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
#include <string.h>
#include <sys/wait.h>

#define REGION_SIZE 1024

void write_region(int fd, int region_idx, const char *data) {
    off_t offset = region_idx * REGION_SIZE;
    struct flock fl = {
        .l_type = F_WRLCK,
        .l_whence = SEEK_SET,
        .l_start = offset,
        .l_len = REGION_SIZE,
    };
    fcntl(fd, F_SETLKW, &fl);
    pwrite(fd, data, strlen(data), offset);
    fl.l_type = F_UNLCK;
    fcntl(fd, F_SETLK, &fl);
}

int main() {
    int fd = open("shared.dat", O_CREAT | O_RDWR, 0644);
    ftruncate(fd, 10 * REGION_SIZE);

    for (int i = 0; i < 5; i++)
        if (fork() == 0) {
            char buf[64];
            snprintf(buf, sizeof(buf), "Process %d data\n", i);
            write_region(fd, i, buf);
            _exit(0);
        }

    while (wait(NULL) > 0);
    close(fd);
    return 0;
}
```

</details>

### 练习 2：close 释放锁陷阱

**题目**：解释以下代码为什么不能保护文件不被其他进程修改。

```c
int fd1 = open("file", O_RDWR);
fcntl(fd1, F_SETLK, &lock);  /* 加锁 */
int fd2 = open("file", O_RDWR);
fcntl(fd2, F_SETLK, &lock);  /* 又加锁（同进程成功） */
close(fd2);                   /* 关闭 fd2 → 所有锁被释放！ */
```

<details>
<summary>参考答案</summary>

`fcntl` 锁是进程级的，同一进程可以对同一文件多次加锁（不会阻塞自己）。但关键陷阱：关闭该文件的**任一**描述符会释放该进程在该文件上的**所有**锁。`close(fd2)` 会释放 fd1 和 fd2 上的所有锁，因为内核按 (pid, inode) 而非 (pid, fd) 管理锁。这在多线程程序中尤其危险——某个线程不知情地关闭一个 fd 就会释放其他线程的锁。

</details>
