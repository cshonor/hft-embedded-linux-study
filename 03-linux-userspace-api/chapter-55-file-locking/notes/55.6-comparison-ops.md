## 要点

| | flock | fcntl |
|--|-------|-------|
| 标准 | BSD | POSIX |
| 区域 | 整文件 | 任意字节 |
| 绑定 | OFD | 进程+inode |
| close | 该 OFD 的锁 | **进程全锁** |
| 强制锁 | 否 | 可（勿用） |
