## 要点

```c
struct flock { short l_type, l_whence; off_t l_start, l_len; pid_t l_pid; };
/* F_SETLK / F_SETLKW / F_GETLK */
```

- `l_len=0`：从 start **锁到 EOF（含后续追加）**  
- `F_GETLK`：仅探测（TOCTOU）；冲突填 `l_pid`  
- 读锁需可读打开；写锁需可写打开  
- 绑定 **进程 + inode**；同进程多 fd 新锁覆盖同区旧锁  
- **任一 fd close → 该进程对此文件全部记录锁没了**  
- fork：**不继承**；退出自动释放；死锁阻塞可 `EDEADLK`

`lockf`：fcntl 封装，仅排他锁，与 fcntl **互通**。

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `fcntl` 记录锁按字节范围，进程+inode 绑定，任一 fd close 释放该进程全部记录锁 |
| HFT | `F_SETLKW` 阻塞会卡住热路径，用 `F_SETLK` 非阻塞 + 重试；注意 close 误释放全局锁的坑 |

## 代码示例

```c

/* fcntl 记录锁（字节范围锁）完整用法 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>

int main(void) {
    int fd = open("/tmp/ch55_fcntl.txt", O_RDWR | O_CREAT, 0644);
    write(fd, "0123456789ABCDEF", 16);

    /* 写锁（排他）: 锁定字节 0-4 */
    struct flock wrlk = {
        .l_type = F_WRLCK, .l_whence = SEEK_SET,
        .l_start = 0, .l_len = 5
    };
    if (fcntl(fd, F_SETLK, &wrlk) < 0) {
        perror("F_SETLK F_WRLCK");
    } else {
        printf("Write lock: bytes 0-4\n");
    }

    /* 查询锁信息：F_GETLK */
    struct flock query = {
        .l_type = F_WRLCK, .l_whence = SEEK_SET,
        .l_start = 0, .l_len = 5
    };
    fcntl(fd, F_GETLK, &query);
    if (query.l_type == F_UNLCK) {
        printf("GETLK: bytes 0-4 unlocked\n");
    } else {
        printf("GETLK: bytes 0-4 locked (type=%d, pid=%d)\n",
               query.l_type, query.l_pid);
    }

    /* 解锁 */
    wrlk.l_type = F_UNLCK;
    fcntl(fd, F_SETLK, &wrlk);
    printf("Unlocked bytes 0-4\n");

    /* 阻塞式写锁：F_SETLKW */
    wrlk.l_type = F_WRLCK;
    printf("Calling F_SETLKW (blocks if conflicting lock)...\n");
    fcntl(fd, F_SETLKW, &wrlk);
    printf("F_SETLKW: acquired\n");

    wrlk.l_type = F_UNLCK;
    fcntl(fd, F_SETLK, &wrlk);
    close(fd);
    return 0;
}

```
