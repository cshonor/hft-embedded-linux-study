# 55.8 Summary

> 本章：[TLPI 第 55 章](../README.md)

## 本节讲什么

第 55 章总结：文件锁的三种 API（fcntl/flock/lockf）、强制锁与建议锁、锁的陷阱和最佳实践。

## 要点

### API 总览

| API | 粒度 | 类型 | 推荐 |
|-----|------|------|------|
| `fcntl(F_SETLK)` | 字节范围 | 建议锁 | 是（标准） |
| `flock()` | 整个文件 | 建议锁 | 简单场景 |
| `lockf()` | 字节范围 | 建议锁 | 较少用 |
| `open(O_EXCL)` | 文件级 | 存在性 | 单实例 |

### fcntl 锁关键特性

- 字节范围锁：可锁定文件的一部分
- 进程级：同进程不同 fd 不互斥
- fork 不继承，exec 继承
- 锁在 close 时释放（可能产生意外释放）
- NFS 支持（需 lockd）

### 锁选择决策

| 场景 | 推荐 |
|------|------|
| 字节范围锁 | `fcntl` |
| 整个文件锁 | `flock`（简单）或 `fcntl` |
| 单实例守护 | `open(O_EXCL)` |
| 多进程写不同部分 | `fcntl` 范围锁 |
| 多进程写整个文件 | `flock` 或 `fcntl` 全文件 |

### 陷阱

1. close 释放所有锁（包括其他 fd 的锁）
2. fork 不继承锁
3. 强制锁性能差且非标准
4. flock 和 fcntl 语义不一致
5. NFS 上锁行为可能不同

## HFT / 嵌入式关联

- 配置文件并发写入保护：fcntl 范围锁
- 单实例守护进程：O_EXCL 锁文件
- 日志文件追加写入：flock 或 O_APPEND
