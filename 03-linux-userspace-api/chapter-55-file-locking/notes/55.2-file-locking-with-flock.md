## 要点

```c
int flock(int fd, int operation);  /* LOCK_SH|EX|UN [| LOCK_NB] */
```

| 规则 | |
|------|--|
| 粒度 | **整文件** |
| 绑定 | **打开文件描述（OFD）** |
| dup/fork 出的 fd | 同 OFD → **共享同一 flock**；任一 close 可放锁 |
| 同文件不同 open | 不同 OFD → 独立锁 |
| fork | **不继承** flock |
| vs fcntl | Linux **互不阻塞** |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `flock` 整文件锁，绑定 OFD，fork 后子进程共享同一锁，close 该 OFD 才释放 |
| HFT | 用 `flock` 保护日志文件追加，避免多写者交错；整文件粒度足够且开销低于 fcntl |

## 代码示例

```c

/* flock 完整 API：LOCK_SH / LOCK_EX / LOCK_UN / LOCK_NB */
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/file.h>
#include <sys/wait.h>

int main(void) {
    int fd = open("/tmp/ch55_flock.txt", O_RDWR | O_CREAT, 0644);

    /* 共享锁（读锁） */
    if (flock(fd, LOCK_SH | LOCK_NB) == 0) {
        printf("LOCK_SH: shared lock acquired\n");
    }

    /* 尝试排他锁（会失败，因为已有共享锁） */
    int fd2 = open("/tmp/ch55_flock.txt", O_RDWR);
    if (flock(fd2, LOCK_EX | LOCK_NB) < 0) {
        printf("LOCK_EX failed (expected): shared lock held\n");
    }

    /* 释放共享锁 */
    flock(fd, LOCK_UN);
    printf("LOCK_UN: shared lock released\n");

    /* 现在可以获取排他锁 */
    if (flock(fd2, LOCK_EX | LOCK_NB) == 0) {
        printf("LOCK_EX: exclusive lock acquired\n");
    }
    flock(fd2, LOCK_UN);

    close(fd);
    close(fd2);
    return 0;
}

```
