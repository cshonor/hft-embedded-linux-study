# 55.7 Older Locking Techniques

> 本章：[TLPI 第 55 章](../README.md)

## 本节讲什么

早期的文件锁技术：`flock()`、`lockf()`，以及它们与 `fcntl()` 锁的区别和兼容性。

## 要点

### 三种锁 API 对比

| API | 来源 | 锁类型 | 粒度 | 端口性 |
|-----|------|--------|------|--------|
| `fcntl(F_SETLK)` | POSIX | 建议锁 | 字节范围 | 标准 |
| `flock()` | BSD | 建议锁 | 整个文件 | BSD→POSIX |
| `lockf()` | SVR4 | 建议锁 | 字节范围 | POSIX |
| `open(O_EXCL)` | POSIX | 文件存在性 | 文件级 | 标准 |

### flock()

```c
#include <sys/file.h>
int flock(int fd, int operation);
// operation: LOCK_SH, LOCK_EX, LOCK_UN, LOCK_NB
```

| 操作 | 说明 |
|------|------|
| `LOCK_SH` | 共享锁（读锁） |
| `LOCK_EX` | 排他锁（写锁） |
| `LOCK_UN` | 解锁 |
| `LOCK_NB` | 非阻塞（OR 以上） |

### lockf()

```c
#include <unistd.h>
int lockf(int fd, int op, off_t len);
// op: F_LOCK, F_TLOCK, F_ULOCK, F_TEST
```

### fcntl vs flock vs lockf

| 特性 | fcntl | flock | lockf |
|------|-------|-------|-------|
| 粒度 | 字节范围 | 整个文件 | 字节范围 |
| 进程级/文件级 | 进程级 | 文件描述符级* | 进程级 |
| fork 继承 | 不继承 | 继承（dup） | 不继承 |
| 网络 FS | 支持 | 可能不支持 | 支持 |
| 推荐 | 是 | 简单场景 | 较少用 |

*Linux 上 flock 是文件描述符级，同一进程的 dup 共享锁。

### open(O_EXCL) 锁文件

```c
/* 原子创建锁文件 */
int fd = open("/var/run/app.lock", O_CREAT | O_EXCL | O_RDWR, 0600);
if (fd == -1 && errno == EEXIST) {
    /* 已有实例在运行 */
    exit(1);
}
/* 程序运行... */
unlink("/var/run/app.lock");
```

## HFT / 嵌入式关联

- HFT 进程单实例控制：`O_EXCL` 锁文件
- 嵌入式简单文件锁：`flock` 比 `fcntl` 简洁
- 遗留代码维护：了解 `lockf` 语义

## 代码示例

```c
#include <sys/file.h>
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
#include <errno.h>
#include <string.h>

/* 使用 O_EXCL 确保单实例 */
int ensure_single_instance(const char *lockfile) {
    int fd = open(lockfile, O_CREAT | O_EXCL | O_RDWR, 0600);
    if (fd < 0) {
        if (errno == EEXIST) {
            fprintf(stderr, "Already running\n");
            return -1;
        }
        perror("open lockfile");
        return -1;
    }
    /* 写入 PID 方便调试 */
    char buf[32];
    snprintf(buf, sizeof(buf), "%d\n", getpid());
    write(fd, buf, strlen(buf));
    return fd;  /* 程序退出时 unlink */
}

/* 使用 flock 保护文件 */
int with_flock(int fd, int op) {
    return flock(fd, op | LOCK_NB);  /* 非阻塞 */
}
```

## 代码自测

<details>
<summary>flock 和 fcntl 锁为什么不兼容？</summary>

Linux 早期 flock 和 fcntl 使用不同的锁机制（文件描述符级 vs 进程级），互不感知。Linux 2.0+ 做了兼容映射，但语义仍有差异：flock 锁与文件描述符关联（dup 共享），fcntl 锁与进程关联（同进程不同 fd 不互斥）。在网络文件系统（NFS）上行为也不同。混用时可能出现意外行为。

</details>
