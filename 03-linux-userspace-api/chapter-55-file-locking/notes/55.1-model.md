## 与 C 语言学习的关系

文件锁是 Unix 系统编程中协调并发访问的机制。C 语言中 `flock`（BSD 锁，整个文件级）和 `fcntl` 记录锁（POSIX，字节范围级）是两套不兼容的锁机制。理解它们的区别和继承行为需要 C 语言的 struct 和 flag 操作知识。

## 常见陷阱

1. **建议性锁 vs 强制性锁混淆**

```c
/* flock 和 fcntl 默认都是建议性锁 */
/* 不检查锁的程序可以直接读写! */
```

Linux 上 flock 和 fcntl 默认是建议性锁——只有协作的程序才会检查。强制性锁需要特殊挂载参数和文件权限设置。

2. **flock 和 fcntl 锁不兼容**

```c
flock(fd, LOCK_EX);     /* BSD 锁 */
fcntl(fd, F_SETLK, &fl); /* POSIX 锁 */
/* 两者互不影响! */
```

flock 是整个文件级锁，fcntl 是字节范围锁。它们是两套独立的机制，互不感知。混用会导致竞态。

3. **fork 后锁的继承**

```c
flock(fd, LOCK_EX);
fork();
/* 子进程共享同一个 fd → 共享锁 */
/* fcntl 记录锁: 子进程不继承! */
```

flock 锁关联到打开文件描述，fork 后子进程共享 fd 即共享锁。fcntl 记录锁关联到进程，fork 后子进程不继承。

## 自测题

**题目 1（选择）：** `flock()` 和 `fcntl()` 记录锁的主要区别？
A. 没有区别
B. flock 是文件级锁，fcntl 是字节范围锁
C. flock 只能用于网络文件系统
D. fcntl 更快

<details>
<summary>参考答案</summary>

B。flock 锁整个文件，fcntl 锁文件的字节范围（可以精确到区域）。两者是独立机制，互不感知。

</details>

**题目 2（判断）：** Linux 上 `flock()` 锁是强制性锁。

<details>
<summary>参考答案</summary>

错误。Linux 上 flock 默认是建议性锁——只有协作的程序才会检查锁。强制性锁需要特殊配置。

</details>

**题目 3（踩坑）：** 以下代码试图用 flock 保护文件，有什么问题？
```c
int fd = open("data.txt", O_RDWR);
flock(fd, LOCK_EX);
/* 另一个程序不检查锁，直接 open+write */
```

<details>
<summary>参考答案</summary>

flock 是建议性锁，不检查锁的程序可以直接写入。需要所有访问者都配合使用 flock 才有效。

</details>

**题目 4（应用）：** 写代码用 fcntl 设置字节范围写锁。

<details>
<summary>参考答案</summary>

```c
struct flock fl = {0};
fl.l_type = F_WRLCK;
fl.l_whence = SEEK_SET;
fl.l_start = 0;
fl.l_len = 100;  /* 锁前100字节 */
fcntl(fd, F_SETLK, &fl);
```

</details>
