## 要点

延迟模式下在标准函数内检查 pending，如：  
`read`/`write`/`poll`/`select`/`accept`/`connect`/`pthread_cond_wait`/`sleep`/`open`…

纯计算循环须手动：

```c
void pthread_testcancel(void);
```

Demo：[`code/thread_testcancel.c`](../code/thread_testcancel.c)

## 代码示例

```c
#include <pthread.h>
#include <stdio.h>
void *worker(void *arg) {
    /* 延迟取消: 只在取消点检查 (read/write/sleep/pthread_testcancel) */
    while (1) { pthread_testcancel(); /* 显式取消点 */ }
    return NULL;
}
int main(void) {
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);
    pthread_cancel(tid);
    pthread_join(tid, NULL);
    return 0;
}
```
