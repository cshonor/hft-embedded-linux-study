## 本节讲什么

---

## 要点

1. A：`pthread_cancel(B)`  
2. B：ENABLE+DEFERRED → 到取消点  
3. 跑 cleanup 栈  
4. 终止，状态 `PTHREAD_CANCELED`  
5. join 回收  

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | cancel→到取消点→跑 cleanup 栈→终止 `PTHREAD_CANCELED`→join 回收，完整生命周期五步 |
| HFT | 理解延迟取消五步，确保工作线程停止后资源全部回收，不留僵尸线程 |

## 代码示例

```c
#include <pthread.h>
#include <stdio.h>
/* 线程生命周期: create → running → join/detach → terminated */
void *worker(void *arg) { printf("工作线程\n"); return NULL; }
int main(void) {
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);
    /* join: 等待线程结束, 回收资源 */
    pthread_join(tid, NULL);
    /* detach: 自动回收, 不能 join */
    /* pthread_detach(tid); */
    printf("线程生命周期完成\n");
    return 0;
}
```
