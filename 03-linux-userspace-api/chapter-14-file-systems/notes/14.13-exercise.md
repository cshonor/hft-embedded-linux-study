### 练习 1：statvfs 文件系统信息

**要求**：

- 格式化输出（GB/MB 单位）

编写程序，使用 `stat()` 获取文件信息，打印 inode 号、块大小、硬链接数。

### 练习 3：tmpfs vs 磁盘性能对比

编写程序，分别在 tmpfs（`/dev/shm`）和磁盘文件系统上创建 100MB 文件，对比写入和读取性能。

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"
#include <sys/statvfs.h>

int main(int argc, char *argv[]) {
    if (argc != 2) usageErr("usage: %s <path>\n", argv[0]);

    struct statvfs buf;
    if (statvfs(argv[1], &buf) != 0) errExit("statvfs");

    unsigned long block_size = buf.f_frsize;
    unsigned long total = buf.f_blocks * block_size;
    unsigned long free = buf.f_bfree * block_size;
    unsigned long avail = buf.f_bavail * block_size;
    unsigned long used = total - free;

    printf("File system: %s\n", argv[1]);
    printf("Block size    : %lu bytes\n", block_size);
    printf("Total size    : %.2f GB\n", (double)total / (1<<30));
    printf("Used          : %.2f GB (%.1f%%)\n",
           (double)used / (1<<30), 100.0 * used / total);
    printf("Available     : %.2f GB\n", (double)avail / (1<<30));
    printf("Total inodes  : %lu\n", buf.f_files);
    printf("Free inodes   : %lu\n", buf.f_ffree);
    printf("Max name len  : %lu\n", buf.f_namemax);
    return 0;
}
```

### 练习 2 参考代码

```c
#include "tlpi_hdr.h"
#include <sys/stat.h>

int main(int argc, char *argv[]) {
    if (argc != 2) usageErr("usage: %s <path>\n", argv[0]);

    struct stat sb;
    if (stat(argv[1], &sb) != 0) errExit("stat");

    printf("File          : %s\n", argv[1]);
    printf("Inode number  : %lu\n", (unsigned long)sb.st_ino);
    printf("Block size    : %lu bytes\n", (unsigned long)sb.st_blksize);
    printf("Blocks (512B) : %lu\n", (unsigned long)sb.st_blocks);
    printf("Size          : %lu bytes\n", (unsigned long)sb.st_size);
    printf("Hard links    : %lu\n", (unsigned long)sb.st_nlink);
    printf("UID           : %d\n", sb.st_uid);
    printf("GID           : %d\n", sb.st_gid);
    printf("Mode          : %o\n", sb.st_mode & 0777);

    /* 文件类型 */
    if (S_ISREG(sb.st_mode)) printf("Type          : regular file\n");
    else if (S_ISDIR(sb.st_mode)) printf("Type          : directory\n");
    else if (S_ISLNK(sb.st_mode)) printf("Type          : symlink\n");
    else if (S_ISCHR(sb.st_mode)) printf("Type          : char device\n");
    else if (S_ISBLK(sb.st_mode)) printf("Type          : block device\n");
    else if (S_ISFIFO(sb.st_mode)) printf("Type          : FIFO\n");
    else if (S_ISSOCK(sb.st_mode)) printf("Type          : socket\n");
    return 0;
}
```

### 练习 3 参考代码

```c
#include <stdio.h>
#include <fcntl.h>
#include <time.h>
#include <unistd.h>
#include <string.h>

#define SIZE (100 * 1024 * 1024)  /* 100MB */
#define BUF_SIZE 4096

void bench_write(const char *path) {
    int fd = open(path, O_WRONLY | O_CREAT | O_TRUNC, 0644);
    char buf[BUF_SIZE];
    memset(buf, 'x', sizeof(buf));

    struct timespec start, end;
    clock_gettime(CLOCK_MONOTONIC, &start);
    for (int i = 0; i < SIZE / BUF_SIZE; i++)
        write(fd, buf, sizeof(buf));
    fsync(fd);
    clock_gettime(CLOCK_MONOTONIC, &end);
    close(fd);

    long long ns = (end.tv_sec - start.tv_sec) * 1000000000LL
                 + (end.tv_nsec - start.tv_nsec);
    printf("%-20s write: %lld ms (%.1f MB/s)\n", path,
           ns / 1000000, (double)SIZE / (ns / 1000) * 1000 / (1<<20));
    unlink(path);
}

int main(void) {
    bench_write("/dev/shm/tmpfs_test");
    bench_write("./disk_test");
    return 0;
}
```

**预期结果**：tmpfs 写入速度通常比 SSD 快 2-5 倍，比 HDD 快 10-50 倍。

## HFT / 嵌入式关联

- **磁盘监控**：HFT 系统监控数据盘使用率，防止写满导致丢数据
- **tmpfs 性能**：HFT 临时计算数据放 `/dev/shm`，接近内存速度
- **inode 监控**：大量小文件（行情快照）可能耗尽 inode
- **嵌入式**：JFFS2/UBIFS 与 ext4 性能特性不同，需针对性优化
