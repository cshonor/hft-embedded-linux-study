## 本节讲什么

分区 FS 必须挂到某目录（挂载点）才可访问。 挂载后：**挂载点原内容被遮住**；卸载后恢复。 - 同一 FS 可挂到多处

---

## 要点

分区 FS 必须挂到某目录（挂载点）才可访问。  
挂载后：**挂载点原内容被遮住**；卸载后恢复。

- 同一 FS 可挂到多处  
- 可在已有树上再叠一层挂载
