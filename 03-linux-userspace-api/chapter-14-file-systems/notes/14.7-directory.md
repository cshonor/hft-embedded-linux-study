## 要点

分区 FS 必须挂到某目录（挂载点）才可访问。  
挂载后：**挂载点原内容被遮住**；卸载后恢复。

- 同一 FS 可挂到多处  
- 可在已有树上再叠一层挂载

## 代码示例

```c
#include <dirent.h>
#include <sys/stat.h>
#include <stdio.h>

int main(void) {
    /* 目录的本质: 存储文件名→inode 映射表 */
    DIR *dir = opendir("/tmp");
    if (!dir) { perror("opendir"); return 1; }

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        /* 跳过 . 和 .. */
        if (entry->d_name[0] == '.' && entry->d_name[1] == '\0') continue;
        if (entry->d_name[0] == '.' && entry->d_name[1] == '.') continue;

        /* d_type: 文件类型 */
        const char *type;
        switch (entry->d_type) {
            case DT_REG:  type = "文件"; break;
            case DT_DIR:  type = "目录"; break;
            case DT_LNK:  type = "链接"; break;
            case DT_CHR:  type = "字符设备"; break;
            case DT_BLK:  type = "块设备"; break;
            default:      type = "其他"; break;
        }
        printf("%-20s inode=%-10lu %s\n", entry->d_name, entry->d_ino, type);
    }
    closedir(dir);
    return 0;
}
```
