## 要点

统一 `open`/`read`/`write`；下层可以是 ext4 / xfs / tmpfs / nfs…

| 对象 | 角色 |
|------|------|
| `super_block` | 一次挂载实例 |
| `inode` | FS 内对象 |
| `dentry` | 名字 ↔ inode 缓存（**内存**，加速查找） |
| `file` | 打开文件上下文（与 fd 对应） |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | VFS 用 super_block/inode/dentry/file 四对象统一不同 FS，让所有 FS 共用同一套系统调用 |
| HFT | VFS 层 dentry 缓存命中与否决定 `open`/`stat` 延迟；冷路径 `open` 会触发磁盘元数据读，需预热 |

## 代码示例

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
/* VFS: 虚拟文件系统, 统一接口访问不同文件系统 */
int main(void) {
    /* 同样的 open/read/write 接口:
     * 普通文件 (ext4), 设备文件 (/dev/null), proc (/proc/version) */
    int fd1 = open("/etc/hostname", O_RDONLY);
    int fd2 = open("/dev/null", O_WRONLY);
    int fd3 = open("/proc/version", O_RDONLY);

    char buf[256];
    if (fd1 >= 0) { read(fd1, buf, 20); buf[20]='\0'; printf("file: %s", buf); close(fd1); }
    if (fd3 >= 0) { read(fd3, buf, 50); buf[50]='\0'; printf("proc: %.50s...\n", buf); close(fd3); }
    if (fd2 >= 0) { write(fd2, "anything", 8); close(fd2); }
    return 0;
}
```
