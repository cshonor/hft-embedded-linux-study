## 要点

| 区域 | 作用 |
|------|------|
| **Boot block** | 引导；首块常保留 |
| **Superblock** | 全局元数据：块数、inode 数、块大小、空闲量、类型/挂载状态；ext2 多处备份 |
| **inode table** | 所有 inode |
| **Data blocks** | 文件内容、**目录条目** |

> **文件名不在 inode 里**，在目录的数据块：`(name → inode#)`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | ext2 无日志，掉电后需 `fsck`，适合只读 rootfs；读写频繁场景用带日志 FS 换取掉电一致性 |
| HFT | 理解块组/超级块布局可定制块大小、inode 数等参数，减少元数据开销、优化顺序写吞吐 |

## 代码示例

```c
#include <sys/statfs.h>
#include <stdio.h>

/* ext2/ext3/ext4 文件系统结构概念演示 */
int main(void) {
    struct statfs fs;
    if (statfs("/", &fs) != 0) { perror("statfs"); return 1; }

    /* ext 系列的 magic number */
    if (fs.f_type == 0xEF53) {
        printf("文件系统: ext2/ext3/ext4\n");
    } else {
        printf("文件系统 magic: 0x%lx (非 ext)\n", fs.f_type);
    }

    /* ext 文件系统结构:
     * - 引导块 (boot block)
     * - 块组 (block group): 超级块 + 组描述符 + 块位图 + inode位图 + inode表 + 数据块
     * - inode: 存文件元数据 (大小/权限/时间/数据块指针)
     * - 目录: 特殊文件, 内容是 entry 列表 (文件名→inode)
     */
    printf("块大小: %ld\n", fs.f_bsize);
    printf("每组 inode 数: %ld\n", fs.f_files);
    return 0;
}
```
