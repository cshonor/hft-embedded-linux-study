## 本节讲什么

一块盘可多分区；**一分区上 `mkfs` 出一个独立文件系统**。 Linux **单一目录树**：各 FS 通过**挂载**接到树上，应用只见路径。 ---

## 要点

一块盘可多分区；**一分区上 `mkfs` 出一个独立文件系统**。  
Linux **单一目录树**：各 FS 通过**挂载**接到树上，应用只见路径。
