## 要点

一块盘可多分区；**一分区上 `mkfs` 出一个独立文件系统**。  
Linux **单一目录树**：各 FS 通过**挂载**接到树上，应用只见路径。

## 代码示例

```c
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>

int main(void) {
    /* 设备文件: 块设备 vs 字符设备 */
    struct stat sb;

    /* 查看根分区设备 */
    if (stat("/", &sb) == 0) {
        printf("/ 的设备: major=%u minor=%u\n",
               major(sb.st_dev), minor(sb.st_dev));
        printf("/ 的类型: %s\n",
               S_ISDIR(sb.st_mode) ? "目录" : "其他");
    }

    /* /dev/null 是字符设备 */
    if (stat("/dev/null", &sb) == 0) {
        printf("/dev/null: %s (major=%u minor=%u)\n",
               S_ISCHR(sb.st_mode) ? "字符设备" : "其他",
               major(sb.st_rdev), minor(sb.st_rdev));
    }

    /* /dev/sda 是块设备 */
    if (stat("/dev/sda", &sb) == 0) {
        printf("/dev/sda: %s\n",
               S_ISBLK(sb.st_mode) ? "块设备" : "其他");
    }
    return 0;
}
```
