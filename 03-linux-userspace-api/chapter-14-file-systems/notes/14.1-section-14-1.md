## 要点

`/dev` 下节点代表设备；内容不在该「文件」里，内核用**主/次设备号**找驱动。

| 类型 | 访问方式 | 例子 |
|------|----------|------|
| **块设备** | 可随机、按块、可经页缓存 | `/dev/sda1`、NVMe 分区 |
| **字符设备** | 流式、通常无块缓冲语义 | `/dev/tty`、串口 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `/dev` 下字符/块设备节点让用户态统一 `open` 设备；`mknod` 创建设备文件是嵌入式固件定制常用手段 |
| HFT | 设备文件统一抽象，访问特殊设备（FPGA/网卡寄存器）走同一套 `read`/`write` 接口，无需专用 API |

## 代码示例

```c
#include <sys/statfs.h>
#include <stdio.h>

int main(void) {
    /* 查看文件系统信息 */
    struct statfs fs;
    if (statfs("/", &fs) != 0) { perror("statfs"); return 1; }

    printf("文件系统类型 magic = 0x%lx\n", fs.f_type);
    printf("块大小       = %ld\n", fs.f_bsize);
    printf("总块数       = %ld\n", fs.f_blocks);
    printf("空闲块数     = %ld\n", fs.f_bfree);
    printf("可用块数     = %ld\n", fs.f_bavail);
    printf("总 inode     = %ld\n", fs.f_files);
    printf("空闲 inode   = %ld\n", fs.f_ffree);

    /* 常见 f_type:
     * 0xEF53 → ext2/ext3/ext4
     * 0x58465342 → XFS
     * 0x9123683E → Btrfs
     */
    return 0;
}
```
