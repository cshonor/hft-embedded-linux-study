## 要点

```c
#include <sys/statfs.h>   /* Linux */
int statfs(const char *path, struct statfs *buf);
int fstatfs(int fd, struct statfs *buf);

#include <sys/statvfs.h>  /* SUSv3，可移植优先 */
int statvfs(const char *path, struct statvfs *buf);
int fstatvfs(int fd, struct statvfs *buf);
```

字段侧重：块大小、总/可用块、inode 总量/空闲。`df` 一类工具底层用这套。  
⚠️ 结构体不同；**可移植代码用 `statvfs`**。

内核挂载表：读 `/proc/mounts`（或 `/proc/self/mounts`）。

Demo：[`code/mini_df.c`](../code/mini_df.c) · [`code/proc_mounts.c`](../code/proc_mounts.c)

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `statfs`/`statvfs` 查询剩余空间与 inode 数，防止磁盘写满导致进程崩溃或数据丢失 |
| HFT | 写盘前 `statvfs` 检查可用空间，避免磁盘满时静默丢日志/订单，触发空间告警 |

## 代码示例

```c
#include <stdio.h>
#include <sys/statfs.h>
#include <sys/vfs.h>
/* statfs/fstatfs: 获取文件系统信息 */
int main(void) {
    struct statfs fs;
    if (statfs("/", &fs) == 0) {
        printf("/ filesystem:\n");
        printf("  type=0x%x bsize=%ld\n", (unsigned)fs.f_type, (long)fs.f_bsize);
        printf("  total=%ld free=%ld avail=%ld\n",
               (long)fs.f_blocks, (long)fs.f_bfree, (long)fs.f_bavail);
    }

    if (statfs("/tmp", &fs) == 0)
        printf("/tmp type=0x%x\n", (unsigned)fs.f_type);

    if (statfs("/dev", &fs) == 0)
        printf("/dev type=0x%x\n", (unsigned)fs.f_type);
    return 0;
}
```
