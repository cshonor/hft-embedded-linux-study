## 要点

| | TCP | UDP |
|--|-----|-----|
| 连接 | 有（握手/挥手） | 无 |
| 可靠 | ACK/重传/去重 | 可丢/乱序/重复 |
| 模型 | 字节流 | 报文边界 |
| 控流 | 有 | 无 |
| 场景 | HTTP/SSH/文件 | DNS/直播/低延迟容忍丢包 |

再记：UNIX DGRAM **可靠**；INET UDP **不可靠**。

## 代码示例

```c

/* TCP vs UDP socket 创建对比 */
#include <stdio.h>
#include <stdlib.h>
#include <sys/socket.h>
#include <unistd.h>

int main(void) {
    /* TCP: SOCK_STREAM — 面向连接，可靠，有序 */
    int tcp_fd = socket(AF_INET, SOCK_STREAM, 0);
    printf("TCP socket (SOCK_STREAM):\n");
    printf("  - connection-oriented (need connect/accept)\n");
    printf("  - reliable delivery, ordered\n");
    printf("  - flow control, congestion control\n");
    printf("  - use send/recv\n\n");

    /* UDP: SOCK_DGRAM — 无连接，不可靠 */
    int udp_fd = socket(AF_INET, SOCK_DGRAM, 0);
    printf("UDP socket (SOCK_DGRAM):\n");
    printf("  - connectionless (sendto/recvfrom)\n");
    printf("  - unreliable, may lose/reorder\n");
    printf("  - no flow control\n");
    printf("  - lower overhead, suitable for real-time\n");

    close(tcp_fd);
    close(udp_fd);
    return 0;
}

```
