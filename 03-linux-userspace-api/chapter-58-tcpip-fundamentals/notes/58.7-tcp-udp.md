## 要点

| | TCP | UDP |
|--|-----|-----|
| 连接 | 有（握手/挥手） | 无 |
| 可靠 | ACK/重传/去重 | 可丢/乱序/重复 |
| 模型 | 字节流 | 报文边界 |
| 控流 | 有 | 无 |
| 场景 | HTTP/SSH/文件 | DNS/直播/低延迟容忍丢包 |

再记：UNIX DGRAM **可靠**；INET UDP **不可靠**。
