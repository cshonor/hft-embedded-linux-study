---

## 要点

```c
struct sockaddr_in {
    sa_family_t    sin_family;  /* AF_INET */
    in_port_t      sin_port;    /* 网络序 */
    struct in_addr sin_addr;    /* s_addr 网络序 */
    unsigned char  sin_zero[8]; /* 置 0 */
};
```

传给 bind/connect 时转为 `struct sockaddr *`。
