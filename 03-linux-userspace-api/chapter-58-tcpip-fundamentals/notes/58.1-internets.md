## 本节讲什么

`SOCK_STREAM`→TCP；`SOCK_DGRAM`→UDP。 ---

---

## 要点

| | AF_UNIX | AF_INET(6) |
|--|---------|------------|
| 定位 | 路径/抽象名 | **IP + 端口** |
| 范围 | 仅本机 | 跨机 / 回环 |

`SOCK_STREAM`→TCP；`SOCK_DGRAM`→UDP。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | AF_UNIX 仅本机、定位靠路径名，嵌入式本机服务用 AF_UNIX 省去 IP 栈开销；跨机/回环才用 AF_INET |
| HFT | AF_UNIX 无 IP/TCP 头、零网络栈开销，同机进程 IPC 延迟最低；行情分发/策略进程间通信用 AF_UNIX，跨主机才走 AF_INET |

## 代码示例

```c

/* 网络层与 IPv4 地址结构 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <arpa/inet.h>
#include <netinet/in.h>

int main(void) {
    /* IPv4 地址：32 位，4 字节 */
    printf("IPv4 address: 32 bits, 4 bytes\n");
    printf("INADDR_ANY  = 0x%08x (0.0.0.0)\n", ntohl(htonl(INADDR_ANY)));
    printf("INADDR_LOOPBACK = 0x%08x (127.0.0.1)\n",
           ntohl(htonl(INADDR_LOOPBACK)));
    printf("INADDR_BROADCAST = 0x%08x (255.255.255.255)\n",
           ntohl(htonl(INADDR_BROADCAST)));

    /* 私有地址范围 */
    const char *priv[] = { "10.0.0.1", "172.16.0.1", "192.168.1.1" };
    for (int i = 0; i < 3; i++) {
        struct in_addr addr;
        inet_pton(AF_INET, priv[i], &addr);
        printf("private %s -> 0x%08x\n", priv[i], ntohl(addr.s_addr));
    }

    /* 回环地址 */
    struct in_addr lo;
    inet_pton(AF_INET, "127.0.0.1", &lo);
    printf("loopback: 0x%08x (host byte order)\n", ntohl(lo.s_addr));
    return 0;
}

```
