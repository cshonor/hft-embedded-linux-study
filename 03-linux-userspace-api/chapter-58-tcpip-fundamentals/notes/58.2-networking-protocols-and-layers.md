## 本节讲什么

- 32 位；点分十进制；`127.0.0.1` 回环（不经物理网卡） - **`INADDR_ANY` (0.0.0.0)**：服务端 bind 全网卡；**客户端 connect 不用** - 私有：`10/8`、`172.16/12`、`192.168/16`

---

## 要点

- 32 位；点分十进制；`127.0.0.1` 回环（不经物理网卡）  
- **`INADDR_ANY` (0.0.0.0)**：服务端 bind 全网卡；**客户端 connect 不用**  
- 私有：`10/8`、`172.16/12`、`192.168/16`  

端口 0–65535：知名 0–1023（常需 root）；注册 1024–49151；临时 49152–65535（客户端常自动分配，**一般不手 bind**）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | INADDR_ANY 绑全网卡，多网卡设备服务端 bind 全网卡；客户端 connect 不用 bind，端口由内核临时分配 |
| HFT | INADDR_ANY 监听所有网卡，HFT 跨机房要 bind 特定 IP 走专线网卡；端口分段（临时 49152+）避免与知名端口冲突 |

## 代码示例

```c

/* IPv4 地址分类与子网掩码 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <arpa/inet.h>

int main(void) {
    /* A/B/C 类地址判断 */
    const char *addrs[] = {
        "10.1.2.3",      /* A 类: 1.0.0.0 ~ 126.255.255.255 */
        "172.16.1.2",    /* B 类: 128.0.0.0 ~ 191.255.255.255 */
        "192.168.1.1",   /* C 类: 192.0.0.0 ~ 223.255.255.255 */
        "127.0.0.1",     /* 回环 */
        "224.0.0.1"      /* D 类组播 */
    };

    for (int i = 0; i < 5; i++) {
        struct in_addr addr;
        inet_pton(AF_INET, addrs[i], &addr);
        unsigned int a = ntohl(addr.s_addr);
        unsigned char first = (a >> 24) & 0xFF;

        const char *cls;
        if (first < 128) cls = "A";
        else if (first < 192) cls = "B";
        else if (first < 224) cls = "C";
        else if (first < 240) cls = "D (multicast)";
        else cls = "E (reserved)";

        printf("%-16s first=%3d -> class %s\n", addrs[i], first, cls);
    }
    return 0;
}

```
