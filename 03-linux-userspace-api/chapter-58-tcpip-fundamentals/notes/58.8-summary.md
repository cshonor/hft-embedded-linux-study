## 本节讲什么

`sockaddr_storage`：够大装 v4/v6，写双栈通用代码。 服务端：`sin_addr.s_addr = htonl(INADDR_ANY)`。 ---

## 要点

`sockaddr_storage`：够大装 v4/v6，写双栈通用代码。  
服务端：`sin_addr.s_addr = htonl(INADDR_ANY)`。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | sockaddr_storage 足够大装 v4/v6，写双栈通用代码用它避免地址族截断；服务端 INADDR_ANY 绑全网卡 |
| HFT | sockaddr_storage 是通用地址容器，同时监听 v4/v6 时用它避免 sockaddr_in 截断；INADDR_ANY 绑所有网卡可能收非预期流量，生产指定网卡 IP |

## 代码示例

```c

/* sockaddr_storage 与 INADDR_ANY 的使用 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

int main(void) {
    /* sockaddr_storage: 通用存储，足够容纳任何地址族 */
    struct sockaddr_storage ss;
    memset(&ss, 0, sizeof(ss));
    printf("sizeof(sockaddr_storage) = %zu\n", sizeof(ss));
    printf("sizeof(sockaddr_in)      = %zu\n", sizeof(struct sockaddr_in));
    printf("sizeof(sockaddr_in6)     = %zu\n", sizeof(struct sockaddr_in6));

    /* INADDR_ANY: 绑定所有网络接口 */
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_port = htons(8080);
    addr.sin_addr.s_addr = htonl(INADDR_ANY);  /* 0.0.0.0 */

    char ipstr[INET_ADDRSTRLEN];
    inet_ntop(AF_INET, &addr.sin_addr, ipstr, sizeof(ipstr));
    printf("\nINADDR_ANY bind: %s:%u\n", ipstr, ntohs(addr.sin_port));
    printf("(server listens on all interfaces: lo, eth0, wlan0, ...)\n");

    /* 对比指定地址 */
    inet_pton(AF_INET, "127.0.0.1", &addr.sin_addr);
    inet_ntop(AF_INET, &addr.sin_addr, ipstr, sizeof(ipstr));
    printf("specific bind:  %s:%u (only loopback)\n", ipstr, ntohs(addr.sin_port));
    return 0;
}

```
