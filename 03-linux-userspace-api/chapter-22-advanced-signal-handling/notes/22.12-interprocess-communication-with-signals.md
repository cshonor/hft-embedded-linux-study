## 本节讲什么

用信号在进程间传递数据：`sigqueue()` 发送 + `SA_SIGINFO` 接收。

---

## 要点

### sigqueue API

```c
int sigqueue(pid_t pid, int sig, const union sigval value);
```
- `union sigval` 可携带 `int` 或 `void*`
- 需配合 `SA_SIGINFO` 的 `sa_sigaction` 接收
- 实时信号可排队，标准信号不排队

### 数据传递

```c
/* 发送方 */
union sigval sv;
sv.sival_int = 42;
sigqueue(pid, SIGRTMIN, sv);

/* 接收方 (SA_SIGINFO handler) */
void handler(int sig, siginfo_t *si, void *ctx) {
    printf("got data: %d\n", si->si_value.sival_int);
}
```

### 实时信号 vs 标准信号

| | 标准信号 (1-31) | 实时信号 (SIGRTMIN-SIGRTMAX) |
|--|----------------|---------------------------|
| 排队 | 不排队 | 排队（保证顺序） |
| 数据 | 不保证携带 | 携带 sigval |
| 多次发送 | 只传递一次 | 每次都传递 |
| 编号 | 固定 | 可用范围 SIGRTMIN+0..N |

### 限制

- `SIGRTMIN`/`SIGRTMAX` 在 glibc 中预留了部分编号给 pthread 库
- 可用范围通常从 `SIGRTMIN+2` 开始
- 信号数据量很小（一个 int 或一个指针）

### 替代方案对比

| 方案 | 数据量 | 顺序保证 | 性能 |
|------|--------|----------|------|
| `sigqueue` | 1 int/ptr | 实时信号有 | 中（内核态） |
| 管道 | 任意 | 有 | 中（拷贝） |
| 共享内存 | 任意 | 需自同步 | 高（零拷贝） |
| eventfd | 1 uint64 | 有 | 高 |

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | sigqueue 携带少量数据适合简单通知，但管道更通用 |
| HFT | 不用信号传数据——延迟不可控，用共享内存 + eventfd |

## 代码示例

```c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>
/* sigqueue + SA_SIGINFO: 进程间带数据信号通信 */
void handler(int sig, siginfo_t *si, void *ctx) {
    printf("child got signal %d, data=%d, from pid=%d\n",
           sig, si->si_value.sival_int, si->si_pid);
}

int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        /* 子进程: 注册 handler, 等待信号 */
        struct sigaction sa;
        memset(&sa, 0, sizeof(sa));
        sa.sa_sigaction = handler;
        sa.sa_flags = SA_SIGINFO;
        sigaction(SIGRTMIN, &sa, NULL);

        printf("child waiting (pid=%d)...\n", getpid());
        sleep(2);
        _exit(0);
    }

    /* 父进程: 发送带数据的实时信号 */
    sleep(1);
    union sigval sv;
    sv.sival_int = 99;
    sigqueue(pid, SIGRTMIN, sv);
    printf("parent sent SIGRTMIN with data=99\n");

    wait(NULL);
    return 0;
}
```
