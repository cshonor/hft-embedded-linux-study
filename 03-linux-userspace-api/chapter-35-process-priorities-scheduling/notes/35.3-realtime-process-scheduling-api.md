## 本节讲什么

**实时 (1–99) > OTHER (0)。** ---

---

## 要点

| 策略 | 静态优先级 | 要点 |
|------|------------|------|
| **SCHED_FIFO** | 1–99（越大越高） | 跑到阻塞/`yield`/被更高优先级抢；同级无时间片轮转 |
| **SCHED_RR** | 1–99 | 同 FIFO，但同级有时间片；`sched_rr_get_interval` |
| **SCHED_OTHER** | 固定 0 | nice 调权重；可被任意就绪实时进程抢占 |

**实时 (1–99) > OTHER (0)。**

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | 三大策略 在嵌入式系统的应用场景 |
| HFT | 三大策略 对低延迟和性能的影响 |

## 代码示例

```c
#include <sched.h>
#include <stdio.h>
int main(void) {
    /* 调度策略:
     * SCHED_OTHER: 普通分时 (默认)
     * SCHED_FIFO: 实时, 先到先服务, 不被抢占直到主动让出
     * SCHED_RR: 实时, 轮转, 有时间片
     */
    struct sched_param sp;
    sp.sched_priority = 0;
    printf("当前策略: %d\n", sched_getscheduler(0));
    printf("SCHED_OTHER=%d SCHED_FIFO=%d SCHED_RR=%d\n",
           SCHED_OTHER, SCHED_FIFO, SCHED_RR);
    return 0;
}
```
