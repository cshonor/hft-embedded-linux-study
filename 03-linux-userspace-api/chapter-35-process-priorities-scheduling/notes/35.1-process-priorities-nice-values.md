## 本节讲什么

区间 **-20（更优先）…19（更低）**，默认 0；是权重，非绝对优先级。 int getpriority(int which, id_t who); int setpriority(int which, id_t who, int prio);

---

## 要点

区间 **-20（更优先）…19（更低）**，默认 0；是权重，非绝对优先级。

```c
int getpriority(int which, id_t who);
int setpriority(int which, id_t who, int prio);
/* which: PRIO_PROCESS | PRIO_PGRP | PRIO_USER */
```

| 谁 | 能做什么 |
|----|----------|
| 非特权 | 通常只能把自己 nice **调大**（降权） |
| `CAP_SYS_NICE` | 任意改 |

fork 继承；exec 保持。对 FIFO/RR **无效**。

Demo：[`code/t_nice.c`](../code/t_nice.c)

## 代码示例

```c
#include <sched.h>
#include <unistd.h>
#include <stdio.h>
int main(void) {
    /* SCHED_OTHER: 普通调度 (默认) */
    /* nice 值: -20 (高) 到 19 (低), 默认 0 */
    int nice_val = nice(0);  /* 0 = 不改, 返回当前 */
    printf("nice = %d\n", nice_val);

    /* setpriority: 设置优先级 */
    setpriority(PRIO_PROCESS, 0, 5);  /* 降低优先级 */
    printf("nice 设为 5\n");
    return 0;
}
```
