## 要点

```c
int sched_setscheduler(pid_t pid, int policy, const struct sched_param *param);
int sched_getscheduler(pid_t pid);
int sched_setparam / sched_getparam(...);
int sched_rr_get_interval(pid_t pid, struct timespec *tp);
int sched_yield(void);   /* 勿当同步原语用 */
```

`struct sched_param { int sched_priority; };`

### `SCHED_RESET_ON_FORK`

可或进 policy：子进程 fork 后回到 `SCHED_OTHER`/优先级清零，防实时父进程繁衍占满 CPU（需特权）。

## 代码示例

```c
#include <stdio.h>
#include <sys/resource.h>
#include <sched.h>
#include <unistd.h>
/* 调度 API: nice/getpriority/setpriority/sched_getscheduler */
int main(void) {
    /* nice 值: -20 到 +19, 越低优先级越高 */
    printf("nice(0) = %d\n", nice(0));
    printf("getpriority(PRIO_PROCESS, 0) = %d\n",
           getpriority(PRIO_PROCESS, 0));

    /* setpriority: 普通用户只能降低 */
    if (setpriority(PRIO_PROCESS, 0, 10) == 0)
        printf("nice set to 10\n");

    /* 调度策略 */
    int pol = sched_getscheduler(0);
    printf("scheduler: %d (%s)\n", pol,
           pol == SCHED_OTHER ? "OTHER" :
           pol == SCHED_FIFO ? "FIFO" :
           pol == SCHED_RR ? "RR" : "?");

    /* 调度参数: 实时优先级 1-99 */
    struct sched_param sp;
    sched_getparam(0, &sp);
    printf("sched_priority = %d\n", sp.sched_priority);

    /* CPU 亲和性 */
    cpu_set_t set;
    CPU_ZERO(&set);
    CPU_SET(0, &set);
    sched_setaffinity(0, sizeof(set), &set);
    printf("Pinned to CPU 0\n");
    return 0;
}
```
