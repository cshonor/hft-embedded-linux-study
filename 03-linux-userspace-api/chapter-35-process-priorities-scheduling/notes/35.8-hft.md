## 本节讲什么

1. 实时死循环无阻塞 → 饿死系统 2. 持锁被抢 → 优先级反转（天花板等） 3. nice 不改实时线程

---

## 要点

1. 实时死循环无阻塞 → 饿死系统  
2. 持锁被抢 → 优先级反转（天花板等）  
3. nice 不改实时线程  
4. 别全员 priority=99  
5. 实时线程少做阻塞 I/O  
6. `sched_yield` ≠ 锁/条件变量  

---

## 代码示例

```c
#define _GNU_SOURCE
#include <sched.h>
#include <pthread.h>
#include <stdio.h>
/* HFT 调优:
 * 1. SCHED_FIFO + 高优先级 (减少调度延迟)
 * 2. CPU 绑核 (减少 cache miss)
 * 3. 隔离 CPU (isolcpus 内核参数)
 * 4. 关闭超线程
 */
int main(void) {
    cpu_set_t set;
    CPU_ZERO(&set);
    CPU_SET(2, &set);  /* 绑到 CPU 2 */
    sched_setaffinity(0, sizeof(set), &set);

    struct sched_param sp = { .sched_priority = 80 };
    /* sched_setscheduler(0, SCHED_FIFO, &sp); */  /* 需 root */
    printf("HFT: 绑核 + 实时调度 + CPU 隔离\n");
    return 0;
}
```
