1. 实时死循环无阻塞 → 饿死系统 2. 持锁被抢 → 优先级反转（天花板等） 3. nice 不改实时线程

---

## 要点

1. 实时死循环无阻塞 → 饿死系统  
2. 持锁被抢 → 优先级反转（天花板等）  
3. nice 不改实时线程  
4. 别全员 priority=99  
5. 实时线程少做阻塞 I/O  
6. `sched_yield` ≠ 锁/条件变量
