## 要点

底层：`capget`/`capset`。推荐 **libcap**（`-lcap`）：

```c
cap_t cap_get_proc(void);
int cap_set_proc(cap_t);
int cap_set_flag(..., CAP_EFFECTIVE, ..., CAP_SET|CAP_CLEAR);
void cap_free(cap_t);
```

| 程序类型 | |
|----------|--|
| capability-aware | 自己抬/清 Effective |
| capability-dumb | 靠文件 Effective bit=1 |

Demo：[`code/cap_view.c`](../code/cap_view.c)

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | `capget`/`capset` 底层，推荐 libcap（`cap_get_proc`/`cap_set_proc`/`cap_set_flag`） |
| HFT | capability-aware 程序用 libcap 精确抬/清 Effective，避免整个进程常驻特权 |

## 代码示例

```c
#include <stdio.h>
#include <linux/capability.h>
#include <unistd.h>
#include <string.h>
/* Capabilities API: capget/capset/cap_from_text/cap_to_text */
int main(void) {
    struct __user_cap_header_struct hdr;
    struct __user_cap_data_struct data[2];

    hdr.version = _LINUX_CAPABILITY_VERSION_3;
    hdr.pid = 0;  /* 0 = current process */

    /* capget: 获取当前能力 */
    if (capget(&hdr, data) < 0) {
        perror("capget");
        return 1;
    }

    printf("Effective: 0x%08x 0x%08x\n", data[0].effective, data[1].effective);
    printf("Permitted: 0x%08x 0x%08x\n", data[0].permitted, data[1].permitted);
    printf("Inheritable: 0x%08x 0x%08x\n", data[0].inheritable, data[1].inheritable);

    /* 检查特定能力 */
    int caps[] = {CAP_NET_BIND_SERVICE, CAP_SYS_ADMIN, CAP_KILL, CAP_SYS_RAWIO};
    const char *names[] = {"NET_BIND_SERVICE", "SYS_ADMIN", "KILL", "SYS_RAWIO"};
    for (int i = 0; i < 4; i++) {
        int idx = caps[i] / 32;
        int bit = caps[i] % 32;
        printf("CAP_%s: %s\n", names[i],
               (data[idx].effective & (1 << bit)) ? "yes" : "no");
    }

    /* 文件能力: 用 setcap 命令行设置 */
    printf("\nFile caps: use 'setcap cap_net_bind_service=ep ./binary'\n");
    return 0;
}
```
