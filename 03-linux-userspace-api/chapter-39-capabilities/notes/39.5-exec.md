新 P ≈ (旧 Inh ∩ File Inh) ∪ (File Prm ∩ Bounding) ∪ Ambient 新 E ≈ FileEff ? 新P : Ambient 新 Inh ≈ 旧 Inh

---

## 要点

```text
新 P ≈ (旧 Inh ∩ File Inh) ∪ (File Prm ∩ Bounding) ∪ Ambient
新 E ≈ FileEff ? 新P : Ambient
新 Inh ≈ 旧 Inh
```

Ambient 须同时在进程 Prm 与 Inh 中；EUID=0 的 exec 清空 Ambient。
