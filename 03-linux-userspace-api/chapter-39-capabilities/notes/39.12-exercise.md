## 要点

### 练习 1：安全权限设置

**题目**：一个 Web 服务器需要绑定 80 端口和锁定内存。用 capabilities 实现无需 root 运行。

<details>
<summary>参考答案</summary>

```bash
# 1. 编译程序（不需特殊处理）
gcc -o webserver main.c -lcap

# 2. 设置文件 capabilities
sudo setcap cap_net_bind_service,cap_ipc_lock=ep ./webserver

# 3. 以普通用户运行
sudo -u www-data ./webserver

# 4. 验证
getcap ./webserver
# 输出: ./webserver = cap_net_bind_service,cap_ipc_lock+ep

# 5. systemd 服务配置
cat > /etc/systemd/system/webserver.service << 'EOF'
[Service]
User=www-data
ExecStart=/opt/webserver/webserver
AmbientCapabilities=CAP_NET_BIND_SERVICE CAP_IPC_LOCK
CapabilityBoundingSet=CAP_NET_BIND_SERVICE CAP_IPC_LOCK
NoNewPrivileges=yes
EOF
```

</details>

### 练习 2：丢弃不必要的 capabilities

**题目**：编写 C 代码，在程序启动后丢弃所有 capabilities，只保留 `CAP_NET_BIND_SERVICE`。同时缩小 Bounding Set。

<details>
<summary>参考答案</summary>

```c
#include <sys/capability.h>
#include <sys/prctl.h>
#include <linux/capability.h>
#include <stdio.h>

int main() {
    /* 1. 缩小 Bounding Set：丢弃除 NET_BIND_SERVICE 外的所有 caps */
    int last_cap;
    if (prctl(PR_CAPBSET_READ, -1) >= 0)
        last_cap = prctl(PR_CAPBSET_READ, -1);
    else
        last_cap = 40;  /* 默认值 */

    for (int cap = 0; cap <= last_cap; cap++) {
        if (cap != CAP_NET_BIND_SERVICE) {
            if (prctl(PR_CAPBSET_DROP, cap) < 0 && errno != EINVAL) {
                perror("prctl DROP");
            }
        }
    }

    /* 2. 清除进程 caps，只保留 NET_BIND_SERVICE */
    cap_t caps = cap_get_proc();
    cap_clear_flag(caps, CAP_EFFECTIVE);
    cap_clear_flag(caps, CAP_PERMITTED);
    cap_clear_flag(caps, CAP_INHERITABLE);

    cap_value_t keep = CAP_NET_BIND_SERVICE;
    cap_set_flag(caps, CAP_PERMITTED, 1, &keep, CAP_SET);
    cap_set_flag(caps, CAP_EFFECTIVE, 1, &keep, CAP_SET);

    if (cap_set_proc(caps) < 0) {
        perror("cap_set_proc");
        return 1;
    }
    cap_free(caps);

    /* 3. 验证 */
    caps = cap_get_proc();
    char *str = cap_to_text(caps, NULL);
    printf("Capabilities: %s\n", str);
    cap_free(str);
    cap_free(caps);

    return 0;
}
```

</details>

### 练习 3：capability 分析

**题目**：以下程序在普通用户下运行时哪些操作会失败？需要哪些 capabilities？

```c
int fd = socket(AF_PACKET, SOCK_RAW, htons(ETH_P_ALL));
mlockall(MCL_CURRENT | MCL_FUTURE);
setpriority(PRIO_PROCESS, 0, -20);
bind(sockfd, addr, sizeof(*addr));  // port=80
```

<details>
<summary>参考答案</summary>

| 操作 | 失败 | 所需 capability |
|------|------|-----------------|
| `socket(AF_PACKET, SOCK_RAW)` | `EPERM` | `CAP_NET_RAW` |
| `mlockall()` | `EPERM` | `CAP_IPC_LOCK` |
| `setpriority(-20)` | `EPERM` | `CAP_SYS_NICE` |
| `bind(port=80)` | `EACCES` | `CAP_NET_BIND_SERVICE` |

一次性设置：
```bash
setcap cap_net_raw,cap_ipc_lock,cap_sys_nice,cap_net_bind_service=ep ./app
```

</details>
