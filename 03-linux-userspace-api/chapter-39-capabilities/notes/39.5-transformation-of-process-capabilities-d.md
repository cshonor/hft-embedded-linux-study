## 本节讲什么

新 P ≈ (旧 Inh ∩ File Inh) ∪ (File Prm ∩ Bounding) ∪ Ambient 新 E ≈ FileEff ? 新P : Ambient 新 Inh ≈ 旧 Inh

---

## 要点

```text
新 P ≈ (旧 Inh ∩ File Inh) ∪ (File Prm ∩ Bounding) ∪ Ambient
新 E ≈ FileEff ? 新P : Ambient
新 Inh ≈ 旧 Inh
```

Ambient 须同时在进程 Prm 与 Inh 中；EUID=0 的 exec 清空 Ambient。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | exec 后新 Permitted ≈ (旧 Inh ∩ File Inh) ∪ (File Prm ∩ Bounding) ∪ Ambient，新 E 取决于 File Effective bit |
| HFT | 理解 exec 能力转换才能正确给子进程/升级进程授予最小能力，避免能力意外丢失或扩散 |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
/* exec 后 capability 变换规则:
 * - 新 permitted = (file inheritable & cap_bset) | (file permitted & old inheritable)
 * - 新 effective = file permitted (if file has setuid) | new permitted
 * 复杂规则 → 实践中直接测试
 */
int main(void) {
    printf("exec 后 capabilities 取决于文件的 file capabilities\n");
    printf("查看: getcap <binary>\n");
    printf("设置: setcap cap_net_bind_service=ep <binary>\n");
    return 0;
}
```
