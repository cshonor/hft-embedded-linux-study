# 40.2 The utmpx API

> 本章：[TLPI 第 40 章](../README.md)

## 本节讲什么

`utmpx` API 用于读写登录记账文件 `/var/run/utmp`（当前登录）和 `/var/log/wtmp`（历史登录）。记录用户登录、注销和系统启动/关机事件。

## 要点

### 核心 API

```c
#include <utmpx.h>
void setutxent(void);            /* 重置到文件开头 */
struct utmpx *getutxent(void);     /* 读取下一条记录 */
struct utmpx *getutxid(const struct utmpx *ut); /* 按 ID 查找 */
struct utmpx *getutxline(const struct utmpx *ut); /* 按行号查找 */
int pututxline(const struct utmpx *ut); /* 写入记录 */
void endutxent(void);             /* 关闭文件 */
int utmpxname(const char *file);  /* 指定替代文件 */
```

### struct utmpx

| 字段 | 说明 |
|------|------|
| `ut_type` | 记录类型 (BOOT_TIME/USER_PROCESS/DEAD_PROCESS 等) |
| `ut_pid` | 登录进程 PID |
| `ut_line` | 设备名 (tty/pts) |
| `ut_id` | 行 ID |
| `ut_user` | 用户名 |
| `ut_tv` | 时间戳 |
| `ut_host` | 远程主机 |
| `ut_addr` | 远程 IP |

### 记录类型

| 类型 | 说明 |
|------|------|
| `BOOT_TIME` | 系统启动 |
| `USER_PROCESS` | 用户登录 |
| `DEAD_PROCESS` | 进程退出（注销） |
| `INIT_PROCESS` | init 生成的进程 |
| `LOGIN_PROCESS` | getty 等待登录 |

### 查看命令

```bash
who     # 读 /var/run/utmp（当前登录）
last    # 读 /var/log/wtmp（历史登录）
lastlog # 读 /var/log/lastlog（最后登录时间）
```

## HFT / 嵌入式关联

- 嵌入式系统登录审计
- HFT 运维监控登录用户
- 安全合规：记录所有登录/注销事件

## 代码示例

```c
#include <utmpx.h>
#include <stdio.h>
#include <time.h>

void list_logged_in_users(void) {
    setutxent();
    struct utmpx *ut;
    while ((ut = getutxent()) != NULL) {
        if (ut->ut_type == USER_PROCESS) {
            printf("%-8s %-8s %s",
                   ut->ut_user, ut->ut_line,
                   ctime(&ut->ut_tv.tv_sec));
        }
    }
    endutxent();
}
```

## 代码自测

<details>
<summary>utmp 和 wtmp 有什么区别？</summary>

`utmp`（/var/run/utmp）记录**当前**登录的会话，每次登录覆盖旧记录，注销时清除。`wtmp`（/var/log/wtmp）记录**历史**登录和注销事件，只追加不覆盖，用于审计。`who` 读 utmp，`last` 读 wtmp。

</details>
