## 要点

关键字段：`ut_type` · `ut_pid` · `ut_line` · `ut_user` · `ut_host` · `ut_tv` · `ut_session`…

| `ut_type` | 含义 |
|-----------|------|
| `USER_PROCESS` | 有效用户登录（who 主要关心） |
| `DEAD_PROCESS` | 会话结束（写入 wtmp） |
| `BOOT_TIME` | 系统启动 |
| `LOGIN_PROCESS` / `INIT_PROCESS` | getty/init 等 |
| `EMPTY` | 空槽 |

## 代码示例

```c
#include <utmpx.h>
#include <stdio.h>
int main(void) {
    /* struct utmpx 字段:
     * ut_type: 登录/注销/启动...
     * ut_user: 用户名
     * ut_line: 终端名
     * ut_pid:  进程 PID
     * ut_host: 远程主机
     */
    struct utmpx ut = {0};
    ut.ut_type = USER_PROCESS;
    ut.ut_pid = getpid();
    strcpy(ut.ut_user, "demo");
    strcpy(ut.ut_line, "tty1");
    printf("utmpx 结构: type=%d user=%s line=%s\n",
           ut.ut_type, ut.ut_user, ut.ut_line);
    return 0;
}
```
