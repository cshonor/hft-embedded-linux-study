# 40.8 Summary

> 本章：[TLPI 第 40 章](./README.md)

## 本节讲什么

第 40 章总结：登录记账系统——utmp/wtmp/lastlog 三个文件的 API 和用途。

## 要点

### 三大文件

| 文件 | 路径 | 记录内容 | API |
|------|------|---------|-----|
| utmp | /var/run/utmp | 当前登录 | utmpx |
| wtmp | /var/log/wtmp | 历史登录/注销 | utmpx |
| lastlog | /var/log/lastlog | 每用户最后登录 | 文件 I/O |

### 记录类型

| ut_type | 说明 |
|---------|------|
| BOOT_TIME | 系统启动 |
| USER_PROCESS | 用户登录 |
| DEAD_PROCESS | 进程退出 |
| INIT_PROCESS | init 子进程 |

### 命令工具

| 命令 | 读取文件 | 用途 |
|------|---------|------|
| `who` | utmp | 当前登录用户 |
| `w` | utmp + 进程 | 登录+活动 |
| `last` | wtmp | 历史登录 |
| `lastlog` | lastlog | 最后登录 |

### struct utmpx 关键字段

`ut_user`(用户名) `ut_line`(终端) `ut_pid`(PID) `ut_type`(类型) `ut_tv`(时间) `ut_host`(来源)

## HFT / 嵌入式关联

- 运维安全：监控登录用户
- 合规审计：记录登录历史
- 嵌入式：精简记账，可只保留 wtmp
