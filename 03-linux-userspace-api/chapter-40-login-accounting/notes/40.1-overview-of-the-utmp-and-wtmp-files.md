## 要点

| 文件 | 作用 | 典型路径 | 命令 |
|------|------|----------|------|
| **utmp** | 当前会话 | `/var/run/utmp` 或 `/run/utmp` | `who`/`w` |
| **wtmp** | 登录/登出历史 | `/var/log/wtmp` | `last` |
| **btmp** | 失败登录 | `/var/log/btmp` | `lastb` |

## 代码示例

```c
#include <utmpx.h>
#include <stdio.h>
int main(void) {
    /* utmp/wtmp: 登录记录 */
    setutxent();
    struct utmpx *ut;
    int count = 0;
    while ((ut = getutxent()) != NULL && count < 5) {
        if (ut->ut_type == USER_PROCESS) {
            printf("用户: %-8s 终端: %-12s PID: %d\n",
                   ut->ut_user, ut->ut_line, ut->ut_pid);
            count++;
        }
    }
    endutxent();
    return 0;
}
```
