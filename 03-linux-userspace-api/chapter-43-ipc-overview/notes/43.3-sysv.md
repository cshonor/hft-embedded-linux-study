## 要点

| | System V | POSIX |
|--|----------|-------|
| 时代 | 80 年代 SysV | 后标准化 |
| 命名 | key + id | `/name` 类路径 |
| 句柄 | IPC id | 偏 fd / 专用类型 |
| 持久 | 内核持久 | 有名对象多为内核持久 |
| 清理 | 易忘显式删 | 有 open/close/unlink 语义 |
| I/O 多路复用 | 弱 | mq 等更易接 poll/epoll（视实现） |

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/msg.h>
/* SysV IPC: key-based, kernel-persistent */
int main(void) {
    /* IPC_PRIVATE: 每次创建新的 (适合父子进程) */
    int msqid = msgget(IPC_PRIVATE, IPC_CREAT | 0666);
    if (msqid >= 0) {
        printf("SysV msgq created: id=%d\n", msqid);
        /* 查看属性 */
        struct msqid_ds ds;
        msgctl(msqid, IPC_STAT, &ds);
        printf("  max bytes: %lu, messages: %lu\n",
               (unsigned long)ds.msg_qbytes,
               (unsigned long)ds.msg_qnum);
        msgctl(msqid, IPC_RMID, NULL);
        printf("  deleted\n");
    }
    /* 注意: SysV IPC 对象不会因进程退出而自动删除 */
    /* 忘记删除 -> 泄漏, 需要 ipcrm 清理 */
    return 0;
}
```
