## 本节讲什么

痛点：SysV 独立 key/id，无标准路径名 → POSIX 用类文件名改良。 ---

---

## 要点

| 工具 | 跨进程识别名 | 进程内句柄 |
|------|--------------|------------|
| 匿名管道 | 无 | fd |
| FIFO | 路径名 | fd |
| UNIX / Internet socket | 路径或 IP:port | fd |
| System V IPC | `key_t` | IPC id |
| POSIX mq / 有名 sem / shm | `/` 路径名 | `mqd_t` / `sem_t*` / fd |
| POSIX 无名 sem | 无（放共享内存） | `sem_t*` |
| mmap 文件映射 | 文件路径 | fd |

痛点：SysV 独立 key/id，无标准路径名 → POSIX 用类文件名改良。

## 代码示例

```c
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/types.h>
/* IPC 命名与句柄: 路径/fd vs key/id */
int main(void) {
    /* 管道/FIFO: 用 fd, 继承获取 */
    printf("Pipe/FIFO: named by path, accessed by fd\n");

    /* SysV IPC: 用 key 生成, 返回 id */
    printf("SysV IPC: ftok() -> key -> get() -> id\n");

    /* POSIX IPC: 用名字 (/name) */
    printf("POSIX IPC: named by /name (like /myqueue)\n");

    /* Socket: 用地址 (path/IP:port) */
    printf("Socket: named by address (AF_UNIX path / AF_INET IP:port)\n");
    return 0;
}
```
