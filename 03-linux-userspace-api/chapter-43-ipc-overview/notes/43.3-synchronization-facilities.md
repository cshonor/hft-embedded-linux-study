# 43.3 同步设施（Synchronization Facilities）

## 本节讲什么

逐一介绍各种 **同步型** IPC 设施：信号量（SysV / POSIX 有名 / POSIX 无名）与文件锁（`flock` / `fcntl` 记录锁）。

---

## 要点

### 信号量

| 设施 | 命名 | 范围 | 持久性 | 备注 |
|------|------|------|--------|------|
| **SysV 信号量** | key/id | 本机任意 | 内核持久 | 复杂 API，支持信号量集 |
| **POSIX 有名信号量** | `/name` | 本机任意 | 内核持久 | `sem_open/sem_wait/sem_post` |
| **POSIX 无名信号量** | 无（放共享内存） | 仅相关进程 | 随共享内存 | `sem_init/sem_wait/sem_post` |

### 文件锁

| 设施 | 粒度 | 备注 |
|------|------|------|
| **flock** | 整个文件 | BSD 风格，仅咨询锁 |
| **fcntl 记录锁** | 字节范围 | POSIX 标准， advisory + mandatory |

### SysV vs POSIX 信号量

| | System V | POSIX |
|--|----------|-------|
| 时代 | 80 年代 SysV | 后标准化 |
| 命名 | key + id | `/name` 类路径 |
| 句柄 | IPC id | `sem_t*` |
| 持久 | 内核持久 | 有名对象内核持久 |
| 清理 | 易忘显式删 | 有 open/close/unlink 语义 |
| I/O 多路复用 | 弱 | 更易接 poll/epoll（视实现） |

细读：Ch45–48（SysV）· Ch51–54（POSIX）。

---

## HFT / 嵌入式关联

| 路线 | 要点 |
|------|------|
| 嵌入式 | POSIX 无名信号量 + 匿名共享内存最轻量；避免 SysV 复杂 API |
| HFT | futex-based 用户态自旋优先；信号量仅作 fallback（内核态切换开销大） |

## 代码示例

```c
#include <stdio.h>
#include <semaphore.h>
#include <sys/mman.h>
#include <sys/wait.h>
#include <unistd.h>
/* 同步设施: POSIX 无名信号量 (放共享内存) */
int main(void) {
    /* 在共享内存中创建无名信号量 */
    sem_t *sem = mmap(NULL, sizeof(sem_t), PROT_READ|PROT_WRITE,
                      MAP_SHARED|MAP_ANONYMOUS, -1, 0);
    sem_init(sem, 1, 0);  /* pshared=1, 初始值=0 */

    if (fork() == 0) {
        printf("child: working...\n");
        sleep(1);
        sem_post(sem);  /* 子进程通知 */
        _exit(0);
    }
    sem_wait(sem);  /* 父进程等待 */
    printf("parent: child signaled\n");
    wait(NULL);
    sem_destroy(sem);
    munmap(sem, sizeof(sem_t));
    return 0;
}
```
