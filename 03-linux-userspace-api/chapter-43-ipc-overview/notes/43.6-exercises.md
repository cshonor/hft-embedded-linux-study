# 43.6 Exercises

> 本章：[TLPI 第 43 章 — IPC Overview](./README.md)

## 练习题

### 练习 1：IPC 机制比较

列出至少 5 种 IPC 机制，从延迟、带宽、数据边界、多路复用支持四个维度对比。

### 练习 2：选择合适的 IPC

针对以下场景选择最合适的 IPC 机制并说明理由：
1. 父进程向子进程传递配置参数
2. HFT 行情进程向策略进程分发 1MB 行情快照
3. 多个客户端向服务器发送短请求
4. 两个进程需要同步访问共享文件

## 参考答案

### 练习 1 答案

| 机制 | 延迟 | 带宽 | 数据边界 | 多路复用 |
|------|------|------|---------|---------|
| 管道 | 5-20μs | 中 | 无（字节流） | 支持（poll/epoll） |
| FIFO | 5-20μs | 中 | 无 | 支持 |
| SysV 消息队列 | 5-15μs | 中 | 有（消息+类型） | 不支持 |
| SysV 共享内存 | <1μs | 最高 | N/A | N/A |
| Unix socket | 5-20μs | 中 | 可选（SOCK_DGRAM） | 支持 |
| POSIX 消息队列 | 5-15μs | 中 | 有 | 支持（mq_notify） |
| TCP socket | 10-50μs | 中 | 无 | 支持 |

### 练习 2 答案

**1. 父进程向子进程传递配置参数**
→ **管道**：简单，父子关系天然存在。fork 后子进程继承管道读端。

**2. HFT 行情进程向策略进程分发 1MB 行情快照**
→ **共享内存**：零拷贝，纳秒级延迟。行情进程写入共享内存，策略进程直接读取。配合信号量或无锁环形缓冲同步。管道/socket 需要两次内核拷贝 1MB 数据，延迟毫秒级。

**3. 多个客户端向服务器发送短请求**
→ **Unix socket**：支持多路复用（epoll），多客户端各自连接，服务器统一管理。命名简单（路径），权限可控。

**4. 两个进程需要同步访问共享文件**
→ **文件锁（fcntl F_SETLK）**：专为文件设计，字节范围锁，自动释放。信号量也行但文件锁更自然。

## HFT / 嵌入式关联

- **共享内存 + 无锁队列**：HFT 标准行情分发方案
- **Unix socket**：控制平面通信
- **嵌入式**：管道最简单可靠；共享内存需硬件支持
