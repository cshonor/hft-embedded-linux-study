# 43.5 Summary

> 本章：[TLPI 第 43 章 — IPC Overview](./README.md)

## 本章回顾

### IPC 机制一览

| 机制 | 数据流 | 范围 | 特点 | 章节 |
|------|--------|------|------|------|
| 管道 (pipe) | 单向 | 父子进程 | 简单，有亲缘关系 | Ch44 |
| FIFO | 单向 | 任意进程 | 命名管道 | Ch44 |
| SysV 消息队列 | 双向 | 任意进程 | 消息边界，有类型 | Ch46 |
| SysV 信号量 | — | 任意进程 | 进程间同步 | Ch47 |
| SysV 共享内存 | — | 任意进程 | 最快 IPC | Ch48 |
| POSIX 消息队列 | 双向 | 任意进程 | 优先级，异步通知 | Ch52 |
| POSIX 信号量 | — | 任意进程 | 轻量 | Ch53 |
| POSIX 共享内存 | — | 任意进程 | /dev/shm 文件 | Ch54 |
| 套接字 (socket) | 双向 | 本地/网络 | 最通用 | Ch56-61 |
| 内存映射 (mmap) | — | 有亲缘关系 | 文件共享 | Ch49 |
| `memfd_create` | 双向 | 任意进程 | 匿名共享文件 | — |

### IPC 机制选择决策

| 需求 | 推荐 |
|------|------|
| 父子间简单通信 | pipe |
| 任意进程间简单通信 | FIFO / Unix socket |
| 高性能大数据传输 | 共享内存 |
| 进程间同步 | 信号量 |
| 网络通信 | TCP/UDP socket |
| 消息边界 + 优先级 | POSIX 消息队列 |
| 多路复用 I/O | socket + epoll（pipe/FIFO 支持） |
| HFT 行情数据 | 共享内存 + 信号量/环形缓冲 |

### IPC 性能对比

| 机制 | 延迟 | 带宽 | 复制次数 |
|------|------|------|---------|
| 共享内存 | <1μs | 最高 | 0（直接访问） |
| 管道/FIFO | 5-20μs | 中 | 2（内核中转） |
| Unix socket | 5-20μs | 中 | 2 |
| TCP socket | 10-50μs | 中 | 2+（网络栈） |
| SysV 消息队列 | 5-15μs | 中 | 2 |
| POSIX 消息队列 | 5-15μs | 中 | 2 |

### IPC 持久性

| 类型 | 生命周期 |
|------|---------|
| pipe/FIFO | 进程终止 |
| SysV IPC | 直到显式删除或系统重启 |
| POSIX IPC (named) | 直到显式删除 |
| mmap | munmap 或进程终止 |
| socket | close 或进程终止 |

## HFT / 嵌入式关联

- **共享内存**：HFT 行情数据分发首选——零拷贝、纳秒级延迟
- **Unix socket**：HFT 控制消息（策略↔风控）
- **信号量**：共享内存同步保护
- **管道**：简单进程间通信（如策略进程的 stdout 给监控进程）
- **嵌入式**：通常用管道或共享内存；精简系统可能不支持 SysV IPC
- **无锁设计**：HFT 用 SPSC 无锁环形缓冲 + 共享内存替代信号量

## 衔接

- **Ch44** Pipes/FIFOs — 管道和命名管道
- **Ch46-48** SysV IPC — 消息队列/信号量/共享内存
- **Ch52-54** POSIX IPC — 消息队列/信号量/共享内存
- **Ch55** File Locking — 替代同步机制
- **Ch56** Sockets — 网络通信

## 代码自测

<details>
<summary>1. 为什么共享内存是最快的 IPC？</summary>

共享内存映射到多个进程的虚拟地址空间，访问共享数据如同访问本地内存——无需内核中转，无需数据拷贝。其他 IPC（管道/socket/消息队列）每次通信都需要系统调用 + 数据从用户空间到内核再到另一个进程的两次拷贝。共享内存只需一次映射，后续访问是普通内存读写。
</details>

<details>
<summary>2. SysV IPC 和 POSIX IPC 的区别？</summary>

| 特性 | SysV IPC | POSIX IPC |
|------|---------|-----------|
| API 复杂度 | 复杂 | 简洁 |
| 文件系统接口 | 无（用 key/id） | 有（/dev/shm） |
| 多路复用 | 不支持 | 支持（mq 可以 poll） |
| 信号通知 | 无 | 有（mq_notify） |
| 超时 | 部分支持 | 支持（mq_timedsend） |
| 现代 | 逐渐弃用 | 推荐 |
</details>
