## 要点

```c
extern char **environ;   /* NAME=VALUE 字符串数组，NULL 结尾 */
```

### API

```c
#include <stdlib.h>
char *getenv(const char *name);
int putenv(char *string);                                      /* 持有传入缓冲，慎用 */
int setenv(const char *name, const char *value, int overwrite); /* 推荐 */
int unsetenv(const char *name);
int clearenv(void);
```

| 要点 | |
|------|--|
| 继承 | 子进程默认继承父环境（`fork` 复制） |
| 作用域 | 进程内修改只影响**自己**及之后创建的子进程；**不影响**父进程/外层 shell |
| `setenv` vs `putenv` | `setenv` 复制字符串；`putenv` 直接用传入缓冲 → 局部数组会变野指针 |
| `getenv` | 返回指向环境区的指针；**不要 `free`** |
| `main` 第三参 `envp` | 非标准扩展，不推荐；用 `environ` |

典型用途：`PATH`、`LC_*`、`LD_LIBRARY_PATH`、配置传递。

Demo：[`code/t_getenv.c`](./code/t_getenv.c)

## 与 C 语言学习的关系

本节的 `write()` 对应 K&R 8.2 节。K&R 的 copy.c 用 `write(1, buf, n)` 输出到 stdout。注意 `write` 与 `printf`/`fprintf` 的区别：`write` 是无格式化的字节流输出，`printf` 有格式化和缓冲。HFT 场景中 `write` 比 `printf` 更可控。

## 常见陷阱

1. **fork 返回值未区分**

```c
pid_t pid = fork();
/* 父子都执行同一代码 */
```

fork 返回两次：父进程返回子 PID，子进程返回 0，失败返回 -1。必须区分三个分支。

2. **fd 继承导致泄漏**

```c
int fd = open(...);
fork();
/* 父子都有 fd，都不关 → 泄漏 */
```

fork 后子进程继承父的 fd 表。父子都需要 close 各自的 fd。

3. **缓冲区被复制**

```c
printf("hello");  /* 在缓冲区，未 flush */
fork();  /* 子进程也会输出 hello */
```

fork 前如果 stdio 缓冲区有数据，子进程会复制并重复输出。fork 前应 fflush 或用 write。

## 自测题

**题目 1（选择）：** `fork()` 在子进程中返回什么？
A. 子进程 PID
B. 0
C. -1
D. 父进程 PID

<details>
<summary>参考答案</summary>

B。子进程中 fork 返回 0，父进程中返回子进程 PID，失败返回 -1。

</details>

**题目 2（判断）：** `fork` 后子进程和父进程的执行顺序是确定的。

<details>
<summary>参考答案</summary>

错误。fork 后父子进程的执行顺序不确定，取决于调度器。不能用 sleep 来保证顺序。

</details>

**题目 3（踩坑）：** 以下代码有什么问题？
```c
printf("before fork\n");
fork();
printf("after fork\n");
```

<details>
<summary>参考答案</summary>

如果 stdout 是行缓冲（终端），"before fork" 会立即输出。但如果是全缓冲（管道/文件），缓冲区被复制，子进程也会输出 "before fork"。fork 前应 fflush(stdout)。

</details>

**题目 4（应用）：** 写代码：fork 一个子进程，父进程打印子 PID，子进程打印自己的 PID。

<details>
<summary>参考答案</summary>

```c
pid_t pid = fork();
if (pid < 0) { perror("fork"); exit(1); }
if (pid == 0) {
    printf("child: %d\n", getpid());
} else {
    printf("parent: child=%d\n", pid);
}
```

</details>
