# 6.10 Exercises

## 练习题

### 练习 1：打印进程信息

编写程序打印自己的 PID、PPID、命令行参数和环境变量。

### 练习 2：setjmp/longjmp 错误恢复

使用 `setjmp`/`longjmp` 实现一个简单的错误恢复机制：主函数设置跳转点，调用链中的任意函数出错时 `longjmp` 跳回。

### 练习 3：信号处理器中的 longjmp

解释为什么在信号处理器中调用 `longjmp` 是危险的，如何安全替代？

## 参考答案

### 练习 1 参考代码

```c
#include "tlpi_hdr.h"

int main(int argc, char *argv[]) {
    printf("PID=%d, PPID=%d\n", (int)getpid(), (int)getppid());
    printf("argc=%d\n", argc);
    for (int i = 0; i < argc; i++)
        printf("  argv[%d]=%s\n", i, argv[i]);

    extern char **environ;
    for (char **p = environ; *p != NULL; p++)
        printf("  %s\n", *p);
    return 0;
}
```

### 练习 2 参考代码

```c
#include "tlpi_hdr.h"
#include <setjmp.h>

static jmp_buf err_env;
static int err_code;

/* 模拟深层调用链 */
void level3(int fail) {
    if (fail) {
        err_code = 42;
        longjmp(err_env, err_code);
    }
    printf("level3: success\n");
}

void level2(int fail) { level3(fail); }
void level1(int fail) { level2(fail); }

int main(void) {
    int r = setjmp(err_env);
    if (r == 0) {
        printf("第一次调用（正常路径）\n");
        level1(0);       /* 不出错 */
        level1(1);       /* 出错 → longjmp */
        printf("这行不会执行\n");
    } else {
        printf("错误恢复：err_code=%d\n", r);
    }
    return 0;
}
```

### 练习 3 答案

**危险性**：
1. **信号掩码未恢复**：`longjmp` 不恢复信号掩码，处理器期间被屏蔽的信号不会被重新启用
2. **非异步信号安全函数**：如果信号打断 `malloc` 等，`longjmp` 跳过释放步骤，导致堆损坏或死锁
3. **栈帧可能无效**：如果信号打断的函数已返回，目标栈帧可能已销毁

**安全替代**：
```c
#include <signal.h>
#include <setjmp.h>

static sigjmp_buf sig_env;

void handler(int sig) {
    siglongjmp(sig_env, 1);  /* 保存/恢复信号掩码 */
}

/* 使用 */
if (sigsetjmp(sig_env, 1) == 0) {
    signal(SIGINT, handler);
    /* 危险操作... */
} else {
    printf("被信号中断\n");
}
```

`sigsetjmp(buf, savesigs)` 的第二个参数为 1 表示保存信号掩码。`siglongjmp` 会恢复掩码。
