## 要点

```c
int main(int argc, char *argv[])
```

| | |
|--|--|
| `argc` | 参数个数 |
| `argv[0]` | 程序名（可为任意字符串；POSIX 允许与真实路径不一致） |
| `argv[argc]` | `NULL` |
| 来源 | 父进程 `fork`+`exec` 传入 |
| 可改性 | 可改字符串内容；勿随意改 `argv` 指针数组语义 |
