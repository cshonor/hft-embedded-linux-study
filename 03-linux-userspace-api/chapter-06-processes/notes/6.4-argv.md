## 本节讲什么

int main(int argc, char *argv[]) ---

---

## 要点

```c
int main(int argc, char *argv[])
```

| | |
|--|--|
| `argc` | 参数个数 |
| `argv[0]` | 程序名（可为任意字符串；POSIX 允许与真实路径不一致） |
| `argv[argc]` | `NULL` |
| 来源 | 父进程 `fork`+`exec` 传入 |
| 可改性 | 可改字符串内容；勿随意改 `argv` 指针数组语义 |

## 代码示例

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("argc = %d\n", argc);

    /* argv[0] 是程序名（可能是路径） */
    printf("argv[0] = %s\n", argv[0]);

    /* 打印所有参数 */
    for (int i = 1; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    /* argv[argc] == NULL（C 标准保证） */
    printf("argv[%d] = %s\n", argc, argv[argc] ? "非NULL" : "NULL");

    /* 简单参数解析示例 */
    if (argc > 1 && argv[1][0] == '-') {
        printf("检测到选项: %s\n", argv[1]);
    }
    return 0;
}
```
