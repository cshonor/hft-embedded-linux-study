## 本节讲什么

#include <unistd.h> pid_t getpid(void);   /* 当前 PID；永不失败 */ pid_t getppid(void);  /* 父进程 PID */

---

## 要点

```c
#include <unistd.h>
pid_t getpid(void);   /* 当前 PID；永不失败 */
pid_t getppid(void);  /* 父进程 PID */
```

| 点 | |
|----|--|
| PID | 正整数；历史上常见上限 32767，见 `/proc/sys/kernel/pid_max`（现代可更大） |
| PID 1 | `init` / `systemd`，系统初代进程 |
| **孤儿进程** | 父先退出 → 被 PID 1 收养 → `getppid()` 常为 1 |
| 错误处理 | `getpid`/`getppid` **不会失败**，不必查 `-1` |

## 代码示例

```c
#include <unistd.h>
#include <stdio.h>
#include <sys/types.h>

int main(void) {
    pid_t pid = getpid();     /* 当前 PID，永不失败 */
    pid_t ppid = getppid();   /* 父进程 PID */

    printf("PID  = %d\n", pid);
    printf("PPID = %d\n", ppid);

    /* 孤儿进程：父进程先退出 → 被 PID 1 收养 */
    pid_t child = fork();
    if (child == 0) {
        /* 子进程 */
        sleep(1);  /* 等父进程先退出 */
        printf("子进程: PID=%d, PPID=%d\n", getpid(), getppid());
        /* 如果父进程已退出，PPID 会变成 1（被 init 收养） */
        _exit(0);
    } else if (child > 0) {
        printf("父进程: PID=%d, 子PID=%d\n", pid, child);
        /* 父进程立即退出，子进程变孤儿 */
    } else {
        perror("fork");
        return 1;
    }
    return 0;
}
```
