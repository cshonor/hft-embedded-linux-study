# 18.3 网络威胁

> 章级精读：[../study.md](../study.md)

## 本节核心目标

了解主要网络攻击类型和特征。

---

## 攻击分类

| 类型 | 机制 | 示例 |
|------|------|------|
| **被动监听** | 窃听流量 | Wireshark 抓包、端口镜像 |
| **主动修改** | 篡改/注入 | MITM、DNS 投毒 |
| **伪装** | 伪造身份 | IP 欺骗、ARP 欺骗 |
| **DoS/DDoS** | 耗尽资源 | SYN Flood、放大攻击 |
| **会话劫持** | 接管连接 | 序号预测、RST 注入 |

---

## MITM (中间人攻击)

```
Client ←→ 攻击者 ←→ Server
攻击者转发双方流量，可窃听/篡改
```

**防御**：TLS 证书验证 → 攻击者无法伪造证书 → MITM 失败。

---

## HFT 关联

| 威胁 | HFT 影响 |
|------|---------|
| 被动监听 | 交易策略泄露 |
| MITM | 订单被篡改 |
| DDoS | 交易中断 |
| 会话劫持 | 交易被接管 |
