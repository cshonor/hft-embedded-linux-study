# 18.1 引言

> 章级精读：[../study.md](../study.md)

## 本节核心目标

建立网络安全的全局视角：威胁 → 原则 → 密码学 → 协议层防御。

---

## 安全三要素 (CIA)

| 要素 | 含义 | 网络威胁 |
|------|------|----------|
| **机密性** (Confidentiality) | 数据不被窃听 | 明文传输、中间人 |
| **完整性** (Integrity) | 数据不被篡改 | 伪造、注入 |
| **可用性** (Availability) | 服务不被中断 | DDoS、RST 注入 |

---

## 网络安全层次

```
应用层:  HTTPS / SFTP / SSH
传输层:  TLS / DTLS
网络层:  IPSec / VPN
链路层:  802.1X / MACSec
```

每一层都有自己的安全机制，但**端到端加密**（TLS）是最常用的。

---

## HFT 关联

| 安全维度 | HFT 需求 |
|----------|---------|
| 机密性 | 交易策略/订单不可泄露 → TLS/专线 |
| 完整性 | 行情/订单不可篡改 → MAC/签名 |
| 可用性 | 交易不可中断 → DDoS 防护 + 冗余 |
