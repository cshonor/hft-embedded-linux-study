# 6.5 以太网上的 PPP (PPPoE)

> 章级精读：[study.md#ch06-5](./study.md#ch06-5) · PPP 基础/LCP/认证：[ch03 §3.6](../chapter03-link-layer/3.6-ppp-protocol.md#ch03-6-pppoe) · 内网 DHCP：[6.2](6.2-dhcp-protocol.md)

## 本节核心目标

掌握 **PPPoE** 的作用、**三阶段流程** 与 **外网 PPPoE + 内网 DHCP** 的双层地址架构。

<a id="ch06-5"></a>

---

<a id="ch06-5-role"></a>

## 一、作用与本质

| 项 | 说明 |
|----|------|
| **场景** | **家庭宽带接入** — 在**以太网**环境实现 **PPP 点到点**特性 |
| **核心诉求** | 运营商完成**账号认证**、**动态分配公网 IP** |
| **封装** | PPP 报文封装进以太网帧 → **PPP over Ethernet（PPPoE）** |

```text
[光猫/路由器] --以太网--> [运营商 BRAS] 
         以太网帧内载荷 = PPP（认证 + IPCP 配址）
```

**一句**：PPPoE = **以太网承载 PPP**，用于宽带**拨号认证 + 地址分配**。

→ PPP 未废止、LCP/PAP/CHAP：[ch03 §3.6](../chapter03-link-layer/3.6-ppp-protocol.md)

<a id="ch06-5-flow"></a>

## 二、完整工作流程

### 1. 发现阶段（PPPoE Discovery）

通过 **PADI → PADO → PADR → PADS** 交互，在以太网上建立 **PPPoE 会话**（获得 Session ID）。

| 报文 | 方向 | 含义 |
|------|------|------|
| **PADI** | 客户端 → 广播 | PPPoE Active Discovery **Initiation** |
| **PADO** | 服务器 → 单播 | **Offer** |
| **PADR** | 客户端 → 单播 | **Request** |
| **PADS** | 服务器 → 单播 | **Session-confirmation** |

### 2. 链路 & 认证（PPP 阶段）

| 步骤 | 协议 | 说明 |
|------|------|------|
| **LCP** | Link Control Protocol | 协商链路参数（MRU、认证方式等） |
| **认证** | **PAP / CHAP** | **账号密码**验证（CHAP 更安全） |

### 3. 地址协商

| 步骤 | 协议 | 说明 |
|------|------|------|
| **IPCP** | IP Control Protocol（NCP 之一） | 获取**公网 IP**、网关、**DNS** 等参数 |

```text
发现(PADI/PADO/PADR/PADS) → LCP → PAP/CHAP → IPCP → 数据传输
```

**三阶段口诀**：**会话发现 → LCP+认证 → IPCP 配 IP**

<a id="ch06-5-dhcp"></a>

## 三、与 DHCP 的层级关系

| 层级 | 机制 | 获得地址 |
|------|------|----------|
| **外网侧** | 路由器/光猫 **PPPoE 拨号** | 运营商分配的**公网 IP** |
| **内网侧** | 终端 **DHCP** 向路由器申请 | **私网 IP**（192.168.x.x 等） |

```text
[PC DHCP] → [家用路由器 内网私网] 
              ↓ PPPoE 拨号
         [运营商 公网 IP]
```

**二者分属不同层级，互不冲突** — 典型架构：**外网 PPPoE + 内网 DHCP**，**双层地址分配**。

→ DHCP DORA：[6.2](6.2-dhcp-protocol.md)

<a id="ch06-5-cheat"></a>

## 考点速记

| # | 要点 |
|---|------|
| 1 | **PPPoE** = 以太网承载 PPP；宽带**拨号认证 + 地址分配** |
| 2 | **三阶段**：**会话发现** → **LCP + 认证** → **IPCP 配 IP** |
| 3 | **典型架构**：外网 **PPPoE** + 内网 **DHCP** |

| 易错 | 正确 |
|------|------|
| PPPoE 与 DHCP 互斥 | **不同层级** — 外网 PPPoE、内网 DHCP |
| 发现阶段用 LCP | **PADI/PADO/PADR/PADS** 先建 PPPoE 会话 |
| PPPoE 不要认证 | 需 **PAP/CHAP** 账号认证 |
| IPCP 属于发现阶段 | IPCP 在 **PPP 阶段**，发现之后 |

## 疑问与总结

**背：PPPoE=以太网包PPP；PADI四步发现→LCP→PAP/CHAP→IPCP拿公网IP；家里DHCP私网、光猫PPPoE公网。**
