## 一、局域网里：交换机 vs 路由器（网关）

### 1. 核心分工

| 设备 | 层次 | 认什么 | 作用 |
|------|------|--------|------|
| **交换机** | **二层**（数据链路层） | **MAC 地址** | **同网段内**转发；**不路由、不跨网段** |
| **路由器（网关）** | **三层**（网络层） | **IP 地址** | **跨网段、跨 LAN** 路由转发 |

→ 硬件/MAC表/路由表/交换矩阵：[ch03 §3.12](../chapter03-link-layer/3.12-switch-router-hardware.md#ch03-12-glossary)

```text
同网段 A ↔ B     → 全程交换机（MAC 转发），不经网关
A → 其他网段/外网 → 包发给网关（路由器），由路由器按 IP 路由
```

**一句**：**同局域网靠交换机，跨网关/跨网段靠路由器** ✅

| 补充 | 说明 |
|------|------|
| **三层交换机** | 二层交换 + 三层路由；内网不同 VLAN/网段可不经外接路由器，**分工逻辑不变** |

### 2. 广播与交换机

收到**广播帧**（MAC **`FF:FF:FF:FF:FF:FF`**）→ 交换机默认**转发到所有端口** → 局域网广播泛滥。

→ [9.2 广播](9.2-ipv4-broadcast-address.md)

## 二、组播：设备怎么记录？交换机有没有对应功能？

### 1. 两个关键协议/技术

| 技术 | 运行位置 | 作用 |
|------|----------|------|
| **IGMP** | **主机 ↔ 路由器/三层设备** | 主机报告 **加入/退出** 组播组；三层设备记录：**哪个网段有哪些主机订阅哪个组播 IP** |
| **IGMP Snooping** | **二层交换机** | 交换机**不认 IP**，**偷听 IGMP** → 建 **组播地址 → 端口** 表 |

```text
IGMP：三层维护「谁要哪个组播 IP」（软状态）
Snooping：二层根据偷听到的 IGMP，维护「组播流量走哪些端口」
```

→ 加组命令/API：[9.4 §加入组播](9.4-igmp-mld-snooping.md#ch09-4-join-principle)

### 2. 两种交换机，行为完全不同

#### 情况 1：傻瓜交换机（无 IGMP Snooping）

| 项 | 行为 |
|----|------|
| **能力** | 只认 MAC，不懂 IGMP |
| **组播帧** | 与**广播帧一样** → **全端口泛洪** |
| **主机端** | **未加组**的主机：网卡**硬件丢弃**，不上 CPU — 与广播不同 |

#### 情况 2：网管型交换机（开启 IGMP Snooping）

| 步骤 | 行为 |
|------|------|
| ① | 主机发 **IGMP Join** → 交换机**侦听** |
| ② | 记录：**该组播组 = 接收 Join 的端口** |
| ③ | 后续组播流量 → **只转发到已记录端口**，不全网泛洪 |

**结论**：**交换机靠 IGMP Snooping 管理组播转发**；**订阅信息源头**由路由器/三层设备通过 **IGMP** 维护。

→ [9.1 §误区：看起来没区别](9.1-broadcast-multicast-concept.md#ch09-1-myth)

<a id="ch09-7-ip-mac"></a>

## 三、组播 IP 与组播 MAC 的对应关系

### 1. 固定映射规则

| 项 | 值 |
|----|-----|
| **组播 IP** | **`224.0.0.0/4`** |
| **组播 MAC 前缀** | **`01:00:5E`**（IANA） |
| **规则** | MAC 前 24 bit 固定 `01:00:5E`；**后 23 bit = 组播 IP 的后 23 bit** |

**例**：组播 IP **`224.0.0.1`** → MAC **`01:00:5E:00:00:01`**

→ 详算、32:1 碰撞：[9.3 §映射](9.3-multicast-mac-mapping.md#ch09-3-mapping)

### 2. 完整转发流程

```text
① 发送方：目的 IP = 224.x.x.x；目的 MAC = 01:00:5E:xx:xx:xx（按规则计算）

② 交换机（看二层 MAC）：
   - 识别组播帧
   - 有 Snooping → 查组播表，只转对应端口
   - 无 Snooping → 当广播，全端口泛洪

③ 接收主机：
   - 网卡看目的 MAC = 组播 MAC
   - 已 Join 该组 → 上交协议栈
   - 未 Join → 网卡丢弃，系统无感知
```

### 3. 纠正误区

| 误区 | 正确 |
|------|------|
| 看到 224 IP 就变成广播 | **IP 是 L3 标识**；**MAC 是 L2 标识** — 交换机**只看 MAC** 决定洪泛/精准转发 |
| 组播在 LAN 里一定像广播 | **仅无 Snooping 的傻瓜交换机**才泛洪；**有 Snooping 则精准转发** |

<a id="ch09-7-summary"></a>

## 四、整体串讲总结

| # | 要点 |
|---|------|
| 1 | **同 LAN** → **交换机**（MAC）；**跨网段** → **路由器/网关**（IP） |
| 2 | **IGMP**：主机 ↔ 三层，记录谁订阅哪个组播 IP |
| 3 | **IGMP Snooping**：二层偷听 IGMP，**组播 → 端口** 精准转发 |
| 4 | **224/x** → **`01:00:5E` + IP 低 23 bit**；主机**加组才收** |
| 5 | 傻瓜交换机组播**表现像**广播；**协议与主机处理逻辑仍不同** |

<a id="ch09-7-cheat"></a>

## 考点速记

| 易错 | 正确 |
|------|------|
| 交换机认 IP 做组播转发 | 交换机认 **MAC**；组播精准靠 **IGMP Snooping** |
| IGMP 跑在交换机上 | **IGMP** = 主机↔**三层**；**Snooping** = **二层**侦听 |
| 组播 IP 直接当广播 MAC | IP **`224/4`** → MAC **`01:00:5E` + 映射** |
| 同网段要经过网关 | **同网段直连**，**不经网关** |

---

## 疑问与总结

**背：同网段交换机MAC转发；跨网段走路由；IGMP三层记订阅、Snooping二层定端口；224→01:00:5E；加组才收。**
