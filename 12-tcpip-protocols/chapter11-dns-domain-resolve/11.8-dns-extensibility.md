# 11.8 DNS 可扩展性

> 章级精读：[../study.md#ch11-6](../study.md#ch11-6)

## 本节核心目标

理解 DNS 协议的扩展机制：新 RR 类型、EDNS0、Class 命名空间。

---

## 扩展机制

| 维度 | 扩展方式 | 示例 |
|------|----------|------|
| **RR Type** | 新增记录类型 | SRV、NAPTR、URI、CAA、TLSA |
| **Class** | 理论可扩展 | 实际几乎仅 **IN**（Internet） |
| **EDNS0** | OPT 伪 RR 扩展 UDP 容量 | DNSSEC、Cookies、Padding |
| **扩展 RCODE** | EDNS0 扩展 | BADVERS/BADCOOKIE 等 |

---

## 现代 RR 类型

| 类型 | 用途 |
|------|------|
| **SRV** | 服务发现（`_service._proto.name`） |
| **NAPTR** | 号码映射（VoIP） |
| **CAA** | 证书授权（限制可发证书的 CA） |
| **TLSA** | DANE——绑定 TLS 证书到域名 |
| **SVCB/HTTPS** | 替代 CNAME + ALPN + IPv6 hints（HTTP/3 发现） |

---

## DNS over X

| 协议 | 端口 | 加密 | 特点 |
|------|------|------|------|
| 传统 DNS | 53/UDP | 无 | 快捷、可被劫持 |
| DoT (DNS over TLS) | 853/TCP | TLS | 加密、可被识别 |
| DoH (DNS over HTTPS) | 443/TCP | TLS | 穿防火墙、与 Web 流量混合 |
| DoQ (DNS over QUIC) | 443/UDP | QUIC | 低延迟 + 加密 |
