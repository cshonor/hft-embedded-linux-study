# 11.13 本章总结

> 章级精读：[../study.md#ch11-exam](../study.md#ch11-exam) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 主题 | 要点 |
|------|------|
| **分布式** | 分层命名空间 + 委派 + 缓存 |
| **名称空间** | 倒置树；FQDN ≤ 255B；标签 ≤ 63B |
| **服务器** | 权威（AA=1） vs 递归（跑腿） |
| **区域** | Primary/Secondary + AXFR/IXFR |
| **传输** | 默认 UDP/53；TC → TCP/53 |
| **EDNS0** | 突破 512B 限制 |
| **RR 类型** | A/AAAA/CNAME/MX/NS/SOA/PTR/SRV |
| **安全** | 缓存投毒、放大 DDoS、DNSSEC |

---

## 易混速记

| 问题 | 要点 |
|------|------|
| 递归 vs 迭代 | 客户端只看见**递归器**；递归器对上游**迭代** |
| 域 vs 区域 | **域**=树子树概念；**区域**=实际托管文件 |
| CNAME 与 A | CNAME **不能**与 NS 等记录同存于同名 |
| MX 优先级 | 数值**小**优先 |
| 端口 | DNS **53**；mDNS **5353** |

---

## HFT 核心关联

| DNS 特性 | HFT 策略 |
|----------|---------|
| 运行时查询延迟 | 预解析 + `/etc/hosts` 硬编码 |
| TTL 不即时生效 | 不依赖 DNS 做容灾切换——用 VIP/Anycast |
| 缓存投毒风险 | 专线/VPN + 不依赖公网 DNS |
| Happy Eyeballs 开销 | 固定 IPv4/IPv6，不做 fallback |
