# 14.3 设置重传超时 (RTO)

> 章级精读：[../study.md#ch14-3](../study.md#ch14-3) · 时间戳：[ch13 §13.3](../../chapter13-tcp-connection-manage/13.3-tcp-options.md)

## 本节核心目标

掌握 **RTT 估计 → RTO** 计算、**Jacobson/Karels** 算法、**Karn** 算法、**RTTM**。

---

## RTT 与 RTO

网络动态变化 → 持续测量 **RTT**，推导 **RTO**。RTO 不能是固定常数。

---

## 经典方法 (RFC 793)

```
SRTT ← α·SRTT + (1-α)·RTT_sample    （α 常 0.8~0.9）
RTO  ← f(SRTT)
```

**问题**：对方差/抖动不敏感 → 抖动网络易误重传。

---

## Jacobson / Karels（主流）

| 步骤 | 公式 |
|------|------|
| 误差 | `Err = M − SRTT`（M 为本次 RTT） |
| 平滑 RTT | `SRTT ← SRTT + g·Err`（g≈1/8） |
| 方差 | `RTTVAR ← RTTVAR + h·(|Err|−RTTVAR)`（h≈1/4） |
| **RTO** | **`RTO = SRTT + 4×RTTVAR`** |

**为何 ×4？** 工程上覆盖多数 RTT 波动；延迟升高时 RTO 快速抬高，减少伪重传。

---

## Karn 算法

**问题**：段重传后收到 ACK → 无法判断 ACK 对应原段还是重传段（歧义）。

**规则**：重传段的 RTT 样本**不**用于更新 SRTT/RTTVAR。

**代价**：重传后 RTO 无法自适应 → 下一次超时仍用旧 RTO。

---

## RTTM（时间戳选项）

时间戳选项（TSOPT）让每个段携带发送时间戳 → 重传时仍可测 RTT → **绕过 Karn 限制**。

```
段1 (TS=1000) → 丢失
重传段1 (TS=1000) → 到达 → ACK (TSecr=1000)
→ RTT = now - 1000（正确，不歧义）
```

兼 **PAWS** 防序号回绕 → [ch13](../../chapter13-tcp-connection-manage/13.3-tcp-options.md)

---

## Linux 实践

| 参数 | 典型值 |
|------|--------|
| 初始 RTO | **1s**（旧实现 3s） |
| 最小 RTO | **200ms** 下限 |
| 时钟粒度 | 可达 **1ms**（旧系统 500ms 级） |

```bash
# 查看 TCP 定时器信息
ss -ti
# 输出示例: rto:280 rtt:12.5/5 mss:1448
```

---

## HFT 关联

| RTO 特性 | HFT 影响 |
|----------|---------|
| 最小 RTO 200ms | 远超交易容忍——TCP 重传 = 灾难 |
| 时间戳 | 必须 enable（`tcp_timestamps=1`） |
| SRTT 自适应 | 反映网络延迟趋势，可用于监控 |
