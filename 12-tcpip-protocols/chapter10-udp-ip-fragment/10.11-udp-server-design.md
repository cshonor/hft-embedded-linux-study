# 10.11 UDP 服务器设计

> 章级精读：[../study.md#ch10-8](../study.md#ch10-8)

## 本节核心目标

掌握 UDP 服务器设计的关键问题：并发模型、缓冲区、多宿主、组播。

---

## 并发模型对比

| 模型 | 优点 | 缺点 |
|------|------|------|
| 单线程 + select/epoll | 简单，无锁 | 单核瓶颈 |
| 多线程 + SO_REUSEPORT | 内核级负载均衡 | 需处理线程间同步 |
| 单线程 + recvmmsg | 批量收包减少 syscall | Linux 专属 |
| io_uring | 零拷贝/异步 | 内核版本要求 |

---

## SO_REUSEPORT

```c
// 多进程/线程绑定同一端口
int val = 1;
setsockopt(fd, SOL_SOCKET, SO_REUSEPORT, &val, sizeof(val));
bind(fd, (struct sockaddr*)&addr, sizeof(addr));
// 内核将入站 UDP 包在多个 socket 间哈希分发
```

**优势**：内核做负载均衡，避免单进程收包瓶颈；相同五元组的包总是到同一 socket（保序）。

## 接收缓冲区

```c
// 增大接收缓冲区（防止高速收包时丢包）
int rcvbuf = 4 * 1024 * 1024;  // 4MB
setsockopt(fd, SOL_SOCKET, SO_RCVBUF, &rcvbuf, sizeof(rcvbuf));

// 查看实际值（内核会翻倍上报）
int actual;
socklen_t len = sizeof(actual);
getsockopt(fd, SOL_SOCKET, SO_RCVBUF, &actual, &len);
// actual ≈ 8MB（内核内部 4MB + 余量）
```

```bash
# 全局 UDP 缓冲区
sysctl net.core.rmem_max     # 最大接收缓冲
sysctl net.core.rmem_default # 默认接收缓冲
# UDP 统计
netstat -su                  # 查看 packet receive errors（缓冲满丢包）
```

## 多宿主问题

`bind(INADDR_ANY)` 的 UDP socket 收到包后，响应源 IP 可能与客户端看到的目的 IP 不一致（对称路由问题）：

```c
// 获取入站包的实际目的 IP
struct in_pktinfo pktinfo;
int val = 1;
setsockopt(fd, IPPROTO_IP, IP_PKTINFO, &val, sizeof(val));

// recvmsg 时通过 ancillary data 获取目的 IP
// 响应时用相同 IP 作为源
```

## HFT 关联

| 设计要点 | HFT 实践 |
|----------|---------|
| SO_REUSEPORT | 多进程行情接收，内核哈希分发 |
| recvmmsg / io_uring | 减少 syscall 开销，提高收包吞吐 |
| 大接收缓冲 | 防止行情突发时内核丢包 |
| 绑定特定网卡 | `SO_BINDTODEVICE` 避免跨网卡路由 |
| CPU 亲和性 | `pthread_setaffinity_np` 绑定收包线程到 NIC 对应核 |
