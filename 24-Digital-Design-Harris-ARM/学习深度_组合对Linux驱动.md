## 要什么 / 不要什么

| ✅ 要 | ❌ 不要 |
|------|--------|
| 输出 **只由当前输入** 决定（无记忆） | 手绘与非网、推气泡作业 |
| **延迟 (tp)**、可能有 **毛刺** | 卡诺化简考试技巧（除非你还想刷题） |
| 译码 / 位操作的 **逻辑语义** | 把译码器拆到每颗 MOS |

## 和你工作强相关的三例

### 1. 寄存器位掩码 = 软件里的组合语义

```
reg &= ~mask;   // 清位：与 + 非
reg |=  mask;   // 置位：或
```

| 记住 | |
|------|--|
| ✅ | 这就是与/或/非的 **布尔行为**；读写 MMIO 时一次操作对应硬件里一批组合逻辑 |
| ❌ | **不要**把「CMOS 里与非比与门少一级延迟」直接套到 C 语句上 —— CPU 执行的是 **ALU 指令**，不是在芯片里临时搭与非门 |
| ✅ | 「与非更原生、与/或多一级非」用在：读 **硬件手册 / 时序闭包 / ASIC 单元库** 时理解为何某路径紧；不是改驱动里 `&` 的写法 |

两层门用法 → [1.5](./ch01_binary/1.5_逻辑门.md)。

### 2. 引脚复用 / 设备树 pinctrl ≈ 译码思想

- 多位选择输入 → **往往唯一一路** 有效（或唯一配置）  
- 改一个 mux 寄存器字段，可能切换 **一整组** 外设连到该 ball  

你不用画 3–8 译码门级图，但要有：「地址/选择码 → 唯一选通」的直觉。  
模块黑盒 → [2.8.2 译码器](./ch02_combinational/2.8.2_译码器.md)。

### 3. 延迟与毛刺（高速外设调试的认知）

| 特性 | 含义 | 驱动侧直觉 |
|------|------|------------|
| **无状态** | 输入变，输出（经延迟后）跟到新值；**不记住**上一拍 | 「这段是纯组合」→ 不能指望它自己稳住 |
| **延迟 tp** | 不是数学上的立刻；路径越长越慢 | PCIe / 以太网等：时序裕量、手册 timing |
| **毛刺** | 多路径汇合可能闪一下错电平 | 别把毛刺当稳定采样；敏感信号要同步/寄存 |

细节 → [2.9](./ch02_combinational/2.9_时序.md)。  
和 Ch3 setup/hold 合看：组合算完要在边沿前稳住。
