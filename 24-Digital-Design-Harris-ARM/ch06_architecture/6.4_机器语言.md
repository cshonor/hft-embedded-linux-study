## 笔记

汇编 → 0/1，电路才能执行。经典 ARM：**固定 32 位指令字**（Thumb/Thumb-2 见 [6.7](./6.7_ARM体系结构的演变.md)）。

### 6.4.1–6.4.3 三大指令类

字段大致：`cond`、`op`、`funct`、`Rn`、`Rd`、立即/偏移等（位域以书图为准，不必默背每一位）。

| 大类 | 例子 | 编码要表达 |
|------|------|------------|
| **数据处理** | ADD、AND | 操作、寄存器、立即/移位 |
| **存储器** | LDR、STR | 基址、偏移、升降址、写回 |
| **分支** | B、BL | 相对偏移、是否写 LR |

**cond：** 几乎每条可带条件 → 条件执行（少分支；现代更多用条件分支）。

### 6.4.4 寻址直觉

| 模式 | 用途 |
|------|------|
| 寄存器 | 操作数在 Rn/Rm |
| 立即 | 小数在指令里 |
| 基址±偏移 | LDR/STR 算有效地址 |
| PC 相对 | 分支、文字池 LDR |

### 6.4.5 存储程序

```
Fetch（按 PC 取 32 位字）→ Decode（拆字段）→ Execute …
```

同一套硬件跑不同二进制 → 通用计算机。Ch7 把环路变成数据通路。

### 对嵌入式 Linux

| 用途 | |
|------|--|
| 读 `objdump -d` | 对照助记符与地址，查启动/驱动汇编 |
| 不必手写编码 | 知道「定长 32、三大类、译码吃字段」即可 |
| 安全/漏洞直觉 | 可执行页、指令与数据同存 → W^X、PXN 等保护（接 [8.4](../ch08_memory/8.4_虚拟存储器.md)） |
