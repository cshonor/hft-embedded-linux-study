## 笔记

```
源码 ──编译器──► 汇编
      ──汇编器──► .o（机器码 + 重定位 + 符号）
      ──链接器──► 可执行 / .ko / 镜像（定地址、拉库）
      ──加载──► 内存中跑（内核加载进程；bootloader 加载内核）
```

### 典型段（ELF 直觉）

| 区域 | 内容 |
|------|------|
| **.text** | 指令 |
| **.data** | 已初始化全局/静态 |
| **.bss** | 未初始化（加载时清零） |
| **堆** | `malloc` 等（向上） |
| **栈** | 调用帧（向下） |

### 对嵌入式 Linux

| 场景 | |
|------|--|
| `System.map` / `/proc/kallsyms` | 符号 ↔ 地址 |
| 内核模块 `.ko` | 加载时重定位到内核地址空间 |
| 裸机 / U-Boot | **链接脚本** 钉死各段物理/虚拟加载地址 |
| 调试「跑飞」 | 查 PC 是否仍在 .text；栈是否溢出 |

与 CSAPP 链接章同构；此处够用的是 **段 + 重定位 + 谁把映像放进内存**。
