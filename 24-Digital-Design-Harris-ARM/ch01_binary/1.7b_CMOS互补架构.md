# 1.7b CMOS 互补架构（钉死）

> 拆自 [1.7_CMOS晶体管.md](./1.7_CMOS晶体管.md) · 内容完整保留

### 1b. CMOS ≠ 新型单管，=「互补架构」（钉死）

**结论：** CMOS = **Complementary MOS 电路架构 / 布线规范**，不是「只要同时有一只 P 和一只 N」。

| 硬性规则（静态互补逻辑） | |
|--------------------------|--|
| **1. 互补配对** | 上拉 **PUN（PMOS→VDD）** + 下拉 **PDN（NMOS→GND）**；功能对偶 |
| **2. 互斥（稳态）** | 任意合法输入：PUN、PDN **恰一通**——通上则断下，通下则断上 |

→ 稳态无 VDD↔GND 直通 → **静态功耗≈0**（现代 CPU 用 CMOS 的原因之一）。

| ❌ | ✅ |
|----|-----|
| 1P+1N 随便摆 = CMOS | 接线须满足互补 + 稳态互斥，否则只是 MOS 混接 |
| CMOS = 专指反相器 | 反相器是最简例；NAND/NOR 等同架构扩展 |

**是 CMOS：** 反相器；2 输入 NAND（P 并 N 串）；2 输入 NOR（P 串 N 并）→ [1.5](./1.5_逻辑门.md)。  
**不是 CMOS：** 纯 NMOS+电阻上拉；PUN/PDN 非对偶导致稳态双通。  
**精度：** 翻转瞬间可有短暂双通（动态功耗）；三态故意双断出高阻 ≠ 稳态组合输出浮空。

| 词 | 是什么 |
|----|--------|
| **NMOS / PMOS** | **单个晶体管**；物理 4 极 G/S/D/B，数字单元对外常只见 G/S/D（B 内接轨） |
| **CMOS** | Complementary MOS：**架构**；按规则使用 PUN+PDN |

最基础单元：**CMOS 反相器（一对管子）**

```
        VDD（电源正极）
          │
          S （PMOS 源）
    G─────┼───── D（PMOS 漏）
          │
          ├──── 输出 OUT
          │
    D─────┼───── S（NMOS 源）
          │
         GND（0V）

输入 A 同时接两管栅极 G
```

| 输入 A | NMOS | PMOS | OUT |
|--------|------|------|-----|
| **高** | 栅＞源 → **通**，拉到 0 | 栅≈VDD → **断** | **低** |
| **低（0）** | 栅源无压差 → **断** | 源≫栅 → **通**，拉到 VDD | **高** |

永远一通一断 → VDD 不直通地 → **静态几乎不耗电**（CMOS 最大优势）。  
展开：各管独立 VDS、为何天然是非门 → 见下文「反相器里两个核心问题」。

#### 引脚数：器件电极 ≠ 对外引脚（别混）

两个维度：**晶体管内部电极** vs **电路对外引出端子**。  
不要把芯片内部独立电极，直接当成外部独立引脚。

**1. 两只管物理电极：4 + 4 = 8**

| | G | S | D | B |
|--|---|---|---|---|
| **NMOS** | 栅 | 源 | 漏 | **P-Sub** |
| **PMOS** | 栅 | 源 | 漏 | **N阱** |

**2. 标准 CMOS 反相器：内部短接合并（关键）**

| 合并规则 | 结果 |
|----------|------|
| NMOS.G ≡ PMOS.G | → 共用 **输入 A**（1 根） |
| NMOS.D ≡ PMOS.D | → 共用 **输出 OUT**（1 根） |
| PMOS.S ≡ PMOS.B(N阱) | → 统一接 **VDD**（1 根） |
| NMOS.S ≡ NMOS.B(P-Sub) | → 统一接 **GND**（1 根） |

合并后内部连接：

| 外端子 | 内部接到谁 |
|--------|------------|
| **VDD** | PMOS.S + N阱（PMOS.B） |
| **GND** | NMOS.S + P衬底（NMOS.B） |
| **A** | 两管 G 短接 |
| **OUT** | 两管 D 短接 |

**3. 对外只引出 4 脚**

① A　② OUT　③ VDD　④ GND  

为何不是 6/7/8？栅并、漏并、PMOS 的 S 与 N阱共 VDD、NMOS 的 S 与 P衬底共 GND。  
衬底/阱 **不会**单独再拉一根脚；标准数字 CMOS 单元内部就近与源极短接供电。

**4. 两种画法**

| 画法 | 看见什么 |
|------|----------|
| **原理图**（课本逻辑） | 只画 G/S/D，省略 Body → 每管看似 3 脚；反相器看不到阱/衬底 |
| **版图 / 剖面** | 完整看见 S、D、G、P-Sub、N阱 → 物理电极都在，只是内部已短接 |

**5. 极简**

物理独立电极共 **8** 处；内部短接后对外只 **4** 根：输入、输出、VDD、GND。

> **拓展：** 少数高压器件衬底不与源短接，会额外引出 Body；标准数字 CMOS 逻辑单元 → 衬底/阱全部内部接电源/地，不外引。
