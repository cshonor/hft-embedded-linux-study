### 5.3.0 补码：减法变加法（接 ALU）

有符号整数常用 **2 的补码**：

```
A − B = A + (~B) + 1
```

→ 硬件：**同一套加法器** + B 按位取反 + Cin=1（→ [5.2.2](./5.2_算术电路.md)）。  
理解 ARM 加减指令、条件标志时，根子在这。

### 5.3.0b 溢出（运算异常直觉）

| | 无符号 | 有符号（补码） |
|--|--------|----------------|
| 典型标志 | **C**（进位/借位） | **V**（oVerflow） |
| 含义 | 模 2^n 回绕 | 结果无法用同一位宽有符号表示 |

N/Z 看结果符号与是否为零。→ ALU Flags [5.2.4](./5.2_算术电路.md)。  
软件侧：检查标志、饱和运算、或用更宽类型——硬件先把异常「信号」给你。

### 5.3.1 定点数

- 二进制小数点位置**固定**（隐含）：前面若干位整数、后面若干位小数。  
- 加减像整数；乘除要盯对位与溢出。  
- **HFT / 金融：** 价格、数量常用定点（避免浮点舍入与非确定性）。

### 5.3.2 浮点数（IEEE 754）

科学计数法硬件化：

| 字段 | 作用 |
|------|------|
| 符号位 | 正负 |
| **阶码（指数）** | 常带 **偏置（bias）** 存储 |
| 尾数（有效数字） | 规格化表示 |

| 格式 | 位宽 |
|------|------|
| 单精度 | 32 |
| 双精度 | 64 |

特殊情况（硬件与软件都要认）：

| 编码 | 含义 |
|------|------|
| 全 0 等 | **±0** |
| 阶码全 1、尾数 0 | **±∞** |
| 阶码全 1、尾数非 0 | **NaN** |

ARM：整数流水线人人要懂；浮点常在 **VFP/NEON** 或软浮点库——格式与异常语义仍以 IEEE 为底。
