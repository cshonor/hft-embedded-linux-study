## 笔记

存大量数据的规整阵列；第7章寄存器堆、第8章层次存储的硬件底座。

**ARM 系统里怎么分工（先记这张表）：**

| 类型 | 典型角色 |
|------|----------|
| **SRAM** | 片上高速：Cache、紧耦合 TCM、**寄存器堆** 实现 |
| **DRAM** | 主存（容量大）；经总线/内存控制器访问 |
| **ROM / Flash** | 启动代码、固件、只读常量（现代多 Flash 可更新） |

→ 引出后文 **内存层次 / 管理**（Cache、页表、虚拟内存 —— Ch8 + CSAPP / 内核）。

### 5.5.1 基本结构

| 概念 | 作用 |
|------|------|
| **位单元阵列** | 每位一个存储单元排成矩阵 |
| **字线 wordline** | 选中某一行（读/写哪一行） |
| **位线 bitline** | 该行各位数据进出 |
| **多端口** | 多套字线/位线 → 并发读写（寄存器堆常用） |

### 5.5.2 DRAM（动态 RAM）

- 典型 **1T1C**（1 晶体管 + 1 电容）存 1 bit。  
- **密度高、成本低、较慢**；电容漏电 → 必须**定期刷新**。  
- 用途：主存、大容量缓冲。

### 5.5.3 SRAM（静态 RAM）

- 交叉耦合反相器，常见 **6T** 单元。  
- **快、不刷新**；面积大、贵。  
- 用途：Cache、片上缓冲、微处理器内 **寄存器文件（Register file）**。

| | DRAM | SRAM |
|--|------|------|
| 密度 | 高 | 低 |
| 速度 | 慢 | 快 |
| 刷新 | 要 | 不要 |
| 典型 | 主存 | 寄存器堆 / Cache |

### 5.5.6 ROM 与演进

- **非易失**：断电不丢。  
- 现代多可写：PROM → EEPROM → **Flash**（嵌入式固件、启动代码）。  

（书中中间小节若谈 CAM/多端口细节，按需补读；口述核心是 DRAM/SRAM/ROM 三分法。）

### 阵列 = 查找表（LUT）

存储器不只存「数据」：把地址当输入、读出当输出 → **任意组合逻辑**（FPGA LUT 思路）。

### 5.5.7 对嵌入式 Linux：地址空间怎么切

| 区域 | 典型实现 | 驱动怎么碰 |
|------|----------|------------|
| 代码/数据（主存） | DRAM + Cache | 普通指针 / `kmalloc` |
| 片上 SRAM / TCM | SRAM | 高速缓冲、DMA 描述符有时放这 |
| 外设寄存器 | 译码到总线从设备 | **`ioremap` + readl/writel** |
| 启动介质 | Flash/eMMC | MTD、块设备；早期 bootrom |

| ❌ | ✅ |
|----|-----|
| 把所有地址当「一样快的数组」 | DRAM ≠ SRAM ≠ MMIO 延迟与属性 |
| 对 MMIO 用缓存语义乱读 | Device 属性、volatile/访问宏 |
