# 坑点清单

1. **验证器看的是字节码**：源码改了没复现预期报错，先想编译器是不是把代码优化没了
2. `unknown func` 先查**程序类型**是否支持该 helper，别怀疑内核版本
3. 循环上界来自全局变量/map 值 = 验证器无法证明有界 = 拒绝；改成常量或用 `bpf_loop()`
4. `if (p != 0)` 检查必须在**解引用之前**；`bpf_map_lookup_elem` 返回值不判空直接用是最常见新手错误
5. 无 return 的函数：碰巧调过 helper 也能过验证，但返回值是 helper 的残留——语义错误验证器管不了
6. 非 root：4096 指令老限制仍在
7. 报错里的 "map value" 未必是你建的 map——全局变量也是 map
