# 5.11 bpftrace 的运算符

> 底本：《BPF之巅》第 5 章 bpftrace（印刷 p137–190），5.11 节（印刷 p164–165）

## 内容详解

布尔运算符（5.10 已列：`== != > < >= <= && ||`）之外，bpftrace 还支持：

| 类别 | 运算符 |
|------|--------|
| 赋值 | `=` |
| 算术 | `+` `-` `*` `/` `%` |
| 自增自减 | `++` `--` |
| 位运算 | `&`（按位与）、`|`（按位或）、`^`（按位异或）、`<<` `>>`（左右位移） |
| 逻辑 | `!`（逻辑非） |
| 复合赋值 | `+=` `-=` `*=` `/=` `%=` `&=` `^=` `<<=` `>>=` |

定义与 C 语言类似。

## HFT 关联

- 位运算常用于标志位解析：`args->flags & O_NONBLOCK`、`args->gfp_mask & __GFP_FS`；
- `++`/`+=` 配映射表做快速计数（注意 `@x++` 并发精度问题，见 5.7.11）。

## 陷阱

- ⚠️ 所有整数当前都是 **64 位无符号**（见 5.12.1）——`-` 结果的符号判断、`>>` 语义都按无符号处理；比较负错误码要用 `args->ret < 0` 这类写法时留意版本行为（可先转 str/强转）。
- ⚠️ 无浮点运算——比率计算在 print 时用除数参数（见 5.14.7 print 的 div）。
