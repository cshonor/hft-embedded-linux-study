# HFT 关联

- **选型决策树**：行情链路观测优先 fentry/fexit（新内核、开销最低、参数+返回值全拿）；syscall 级审计用 tp_btf（稳定接口 + 免手写结构）；热点函数计时用 kprobe+kretprobe 或 fentry+fexit 对（计算延迟分布进 histogram map）
- **fexit 拿全参+返回值**对测量"某内核路径耗时与返回原因"一步到位，避免 kprobe/kretprobe 两次挂载、跨事件配对的复杂度
- **XDP 单程序限制**：交易机网卡入口做过滤/early drop 时，所有逻辑（黑名单、速率限制、重定向到旁路采集）必须在一个 XDP 程序内组织好
- **uprobe 钩 SSL/加密库**思路同样适用于钩交易网关二进制的关键函数（下单路径计时），但注意静态链接与 Go 调用约定的坑
- LSM 返回码可阻断操作 → 可做交易进程的**内核级行为白名单**（如禁止非交易进程 connect 交易所网段），见第 9 章
