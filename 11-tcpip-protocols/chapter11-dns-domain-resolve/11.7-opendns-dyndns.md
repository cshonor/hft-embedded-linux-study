## 动态 DNS (DDNS)

动态 IP 环境（家庭宽带、移动网络）中，客户端 IP 会变化。DDNS 让域名自动跟踪 IP 变化：

```
1. 客户端检测公网 IP 变化
2. 向 DDNS 服务商发送更新请求
3. 服务商更新权威 DNS 记录
4. 外部用户通过域名连接到新 IP
```

常见 DDNS 服务：DynDNS、No-IP、DuckDNS。

---

## HFT 关联

HFT 系统一般不使用公共 DNS 或 DDNS——数据中心环境 IP 固定，DNS 仅用于初始发现。

但跨数据中心 WAN 连接可能涉及：
- 动态路由 + DNS fallback
- 公网 DNS 做健康检查探针
