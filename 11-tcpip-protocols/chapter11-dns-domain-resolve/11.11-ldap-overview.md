# 11.11 LDAP 概述

> 章级精读：[../study.md#ch11-10](study.md#ch11-10)

## 本节核心目标

理解 LDAP 与 DNS 的互补关系。

---

## DNS vs LDAP

| | DNS | LDAP |
|--|-----|------|
| 定位 | **名 → IP** 快速映射 | **复杂属性**查询 |
| 数据模型 | 扁平树 + 简单 RR | 层次目录 + 丰富属性 |
| 协议 | UDP/53 | TCP/389 (636 TLS) |
| 查询 | 名字精确匹配 | 过滤器 `(&`(cn=John)(ou=Sales))` |
| 典型 | 域名解析 | 用户认证/组织结构/权限 |

**互补非替代**：DNS 偏快速名→IP；LDAP 偏复杂属性查询。

---

## LDAP 在企业中的角色

```
[用户登录] → LDAP 查询 → 验证密码 + 获取组/权限
[邮件服务器] → LDAP 查询 → 获取邮件路由地址
[DNS] → 仍负责 IP 解析
```

---

## HFT 关联

LDAP 在 HFT 中不常见——交易系统一般用本地配置文件或配置中心（etcd/Consul），不依赖 LDAP 做运行时查询。
