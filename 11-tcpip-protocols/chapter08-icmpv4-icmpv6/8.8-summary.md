# 8.8 本章总结

> 章级精读：[../study.md](../study.md) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 主题 | 要点 |
|------|------|
| **角色** | IP 层控制与诊断协议 |
| **错误报告** | Type 3 (Unreachable)、Type 11 (Time Exceeded) |
| **诊断** | Type 8/0 (Echo = ping) |
| **PMTUD** | Type 3 Code 4 (Fragmentation Needed) |
| **IPv6 NDP** | ICMPv6 133-137 替代 ARP |
| **安全** | Smurf、Redirect 欺骗、ICMP 隧道 |

---

## HFT 核心关联

| ICMP 功能 | HFT 用途 |
|-----------|---------|
| ping | 延迟监控、链路健康检查 |
| PTB | PMTUD 核心——UDP 大包必备 |
| NDP | IPv6 邻居缓存预热 |
| Redirect | 数据中心路由优化（需禁用接受防攻击） |
