# 8.4 ICMP 查询消息与 Ping

> 章级精读：[../notes.md](../README.md)

## 本节核心目标

理解 Echo Request/Reply 和 ping 的工作原理。

---

## Echo 机制

```
发送方 → Echo Request (Type=8, ID=x, Seq=n)
接收方 → Echo Reply  (Type=0, ID=x, Seq=n)
```

| 字段 | 说明 |
|------|------|
| **Identifier** | 匹配请求与响应（同一 ping 会话） |
| **Sequence Number** | 递增，用于计算 RTT 和丢包率 |
| **Data** | 可选时间戳/自定义数据 |

---

## Ping 的功能

```bash
# 基本 ping
ping -c 4 8.8.8.8

# 输出:
# 64 bytes from 8.8.8.8: icmp_seq=1 ttl=117 time=12.3 ms
# 64 bytes from 8.8.8.8: icmp_seq=2 ttl=117 time=11.8 ms

# 指定包大小（测试 PMTUD）
ping -s 1472 -M do 8.8.8.8  # -M do = 设 DF 位

# 洪泛模式（HFT 延迟测试）
ping -f 8.8.8.8  # 需要 root
```

---

## RTT 计算

```
发送 Echo Request 时记录 t1
收到 Echo Reply 时记录 t2
RTT = t2 - t1
```

**注意**：ICMP 处理在内核中，RTT 包含内核处理延迟。HFT 延迟测试用 UDP/TCP 更真实。

---

## HFT 关联

| Ping 用途 | HFT 场景 |
|-----------|---------|
| 延迟监控 | 持续 ping 对端，监控 RTT 变化 |
| 链路健康 | 快速 ping 检测链路断开 |
| PMTUD | `ping -s N -M do` 探测路径 MTU |
| 路径诊断 | `ping -R` 记录路由（有限） |

**局限**：ICMP 优先级低，部分路由器限速/丢弃 ICMP → ping RTT 不代表真实延迟。
