# 8.7 ICMP 攻击

> 章级精读：[../study.md](../study.md) · 安全：[ch18](../../chapter18-network-security/study.md)

## 本节核心目标

理解利用 ICMP 的攻击及防御策略。

---

## 主要攻击

| 攻击 | 机制 | 防御 |
|------|------|------|
| **Smurf** | 伪造源 IP → ping 广播地址 → 放大 | 禁止广播 ICMP |
| **ICMP 隧道** | ICMP Data 字段封装数据 → 绕过防火墙 | 深度检测 ICMP |
| **Redirect 欺骗** | 伪造 ICMP Redirect → 劫持路由 | 忽略 Redirect 或验证 |
| **PTB 伪造** | 伪造 ICMP PTB → 强制降低 MTU → 性能攻击 | 验证 PTB 来源 |
| **Ping of Death** | 超大 ICMP 包 → 旧系统崩溃 | 现代内核已修复 |

---

## Smurf 攻击

```
攻击者 → 广播地址 (伪造源 IP = 受害者)
  ICMP Echo Request → 网络中所有主机回复 Echo Reply
  → 全部打向受害者
  放大率 = 网络中主机数
```

**防御**：路由器禁止向广播地址转发 ICMP（BCP 38/RFC 2827）。

---

## ICMP Redirect

路由器发 Redirect 告知主机"有更优路径" → 主机更新路由表。攻击者可伪造 Redirect 劫持流量。

```bash
# Linux: 禁用 ICMP Redirect 接受
sysctl net.ipv4.conf.all.accept_redirects=0
sysctl net.ipv4.conf.default.accept_redirects=0
sysctl net.ipv6.conf.all.accept_redirects=0
```

---

## HFT 关联

| 攻击 | HFT 影响 |
|------|---------|
| PTB 伪造 | MTU 被恶意降低 → 吞吐下降 |
| Redirect 欺骗 | 流量被劫持 → 信息泄露 |
| ICMP 隧道 | 隐蔽通道 → 数据泄露 |

**防御**：防火墙限制 ICMP 类型 + 加密 + 专线隔离。
