# 18.7 EAP 与 802.1X

> 章级精读：[../study.md](study.md)

## 本节核心目标

理解 802.1X 端口认证和 EAP 协议。

---

## 802.1X 架构

```
Supplicant (客户端) ←→ Authenticator (交换机) ←→ Authentication Server (RADIUS)
```

| 组件 | 作用 |
|------|------|
| **Supplicant** | 请求接入的设备 |
| **Authenticator** | 交换机/AP，控制端口 |
| **Auth Server** | RADIUS 服务器，验证凭据 |

---

## EAP 方法

| 方法 | 特点 |
|------|------|
| EAP-TLS | 证书双向认证（最安全） |
| EAP-PEAP | 服务器证书 + 客户端密码 |
| EAP-TTLS | 类似 PEAP |

---

## HFT 关联

数据中心网络可使用 802.1X 做端口级认证——防止未授权设备接入交易网络。
