# 18.13 本章总结

> 章级精读：[../study.md](../study.md) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 维度 | 要点 |
|------|------|
| **原则** | CIA + 纵深防御 + 最小权限 |
| **密码学** | 对称(AES) + 非对称(ECDH) + 哈希(SHA) + MAC(HMAC) |
| **PKI** | CA → 证书 → 信任链 |
| **分层** | 链路(MACSec) / 网络(IPSec) / 传输(TLS) / 应用 |
| **TLS 1.3** | 1-RTT / 0-RTT / AEAD / 证书加密 |
| **DNSSEC** | 签名链验证，不加密 |
| **攻击** | ARP/DNS/RST/ICMP/源伪造 |

---

## HFT 核心关联

| 安全维度 | HFT 策略 |
|----------|---------|
| 物理隔离 | 交易网络独立 VLAN/专线 |
| 加密 | TLS 1.3 (控制面) / IPSec (WAN) |
| 认证 | 802.1X 端口认证 + 证书 |
| 监控 | IDS/IPS + 流量异常检测 |
| DDoS 防护 | 专线 + QoS + 冗余 |

**核心**：HFT 安全是物理隔离为主、加密为辅——速度优先，安全不妥协。
