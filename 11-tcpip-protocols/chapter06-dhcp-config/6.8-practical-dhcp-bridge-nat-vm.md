# 6.8 实战：DHCP、桥接、NAT 与虚拟机网络

> 章级精读：[study.md#ch06-8](./study.md#ch06-8) · DHCP 通俗：[6.1 §DHCP 是什么](6.1-introduction.md#ch06-1-dhcp-plain) · 私网地址：[ch02 §2.5](../chapter02-ip-address-architecture/2.5-special-address.md) · NAT 原理：[ch07 §7.3](../chapter07-firewall-nat/7.3-nat-napt.md)

## 本节核心目标

结合**物理网络**与**虚拟机场景**，讲清 **NAT（网络地址转换）**、**桥接**、**DHCP** 三者分工 — 重点搞懂虚拟机 NAT 为何是**「套了两层 NAT」**。

<a id="ch06-8"></a>

> **术语**：**NAT** = Network Address Translation（**网络地址转换**），不是 NVP 等其他缩写。

**一句总览**：**NAT = 地址翻译官**；**DHCP = 自动发 IP 的服务**；**桥接/NAT = 虚拟机网络模式** — 模式决定通路，DHCP 决定参数怎么填。

---

<a id="ch06-8-nat-physical"></a>

## 一、标准 NAT 原本的作用（物理网络）

**NAT 核心 = 内网 IP ↔ 公网 IP 互相转换**

| 步骤 | 说明 |
|------|------|
| **① 内网私网** | 手机、电脑都是**私有内网 IP**（如 `192.168.x.x`）— 公网**不能直接路由** |
| **② 出站翻译** | 家用**路由器做 NAT**：内网 IP → 换成运营商分配的**唯一公网 IP** → 数据才能上互联网 |
| **③ 回包翻译** | 外网回包时，路由器再把公网 IP **转回**对应内网 IP，发给设备 |

**一句**：**NAT 是「翻译官」，负责内网和外网地址转换。**

→ 详：[ch07 §7.3 NAPT](../chapter07-firewall-nat/7.3-nat-napt.md)

<a id="ch06-8-nat-vm-layers"></a>

## 二、虚拟机 NAT 模式：套了「两层 NAT」（困惑关键点）

虚拟机软件（VMware / VirtualBox / libvirt）虚拟出一套**独立小局域网**，结构分**两层**：

### 第一层：虚拟机 ↔ 虚拟网卡（虚拟机内部子网）

| 组件 | 作用 |
|------|------|
| **虚拟 DHCP** | 给 VM 分配软件自定义私网 IP（如 `192.168.122.x`） |
| **虚拟 NAT 网关** | 在虚拟子网内做地址转换 |

- VM 拿到的是**虚拟私网 IP**
- 该网段与真机所在**家里局域网完全分开**

### 第二层：虚拟网关 ↔ 物理主机 ↔ 真实路由器

| 环节 | 翻译 |
|------|------|
| **虚拟 NAT** | VM `192.168.122.x` → **物理主机本机 IP**（如 `192.168.1.10`） |
| **物理 NAT** | 主机 IP → 家里路由器 → **公网 IP**（如 `110.xx.xx.xx`）→ 互联网 |

```text
虚拟机 → 虚拟子网(虚拟NAT) → 真机网卡 → 家里路由器(物理NAT) → 互联网
```

**一句总结**：虚拟机 NAT **只是把 NAT 机制嵌套了一层** — 原理与标准 NAT 相同，**多了一级虚拟网络**。

<a id="ch06-8-bridge"></a>

## 三、桥接模式：为什么没有这层嵌套？

**桥接 = 虚拟机直接「插队」进真实局域网**

| 项 | 桥接 | NAT |
|----|------|-----|
| 虚拟子网 | **无** | **有**（如 `192.168.122.0/24`） |
| 虚拟 NAT | **无** | **有** |
| IP 来源 | **家里路由器 DHCP** | **虚拟 DHCP** |
| 网段 | 与真机**同网段**（如 `192.168.1.x`） | **异网段** |
| 上网 NAT 层数 | **仅路由器一层 NAT** | **虚拟 NAT + 路由器 NAT** |

<a id="ch06-8-address-example"></a>

## 四、用地址举例，直观看懂区别

**假设**：

- 物理主机 IP：`192.168.1.10`（家里路由 DHCP）
- 家里路由公网 IP：`110.xx.xx.xx`

### 1）虚拟机 NAT 模式

| 项 | 值 |
|----|-----|
| VM IP | `192.168.122.20`（虚拟 DHCP，**独立网段**） |

**访问百度**：

```text
192.168.122.20 →【虚拟 NAT】→ 192.168.1.10 →【路由器 NAT】→ 110.xx.xx.xx → 互联网
```

**特点**：手机、另一台电脑**找不到** `192.168.122.x` 网段 → **无法主动访问 VM**

### 2）虚拟机桥接模式

| 项 | 值 |
|----|-----|
| VM IP | `192.168.1.11`（路由 DHCP，**与真机同网段**） |

**访问百度**：

```text
192.168.1.11 → 直接交路由器 →【路由器 NAT】→ 110.xx.xx.xx → 互联网
```

**特点**：同 Wi‑Fi 下设备**可直接访问 VM**

<a id="ch06-8-three"></a>

## 五、DHCP 与 NAT/桥接：三者分工（串起来）

| 概念 | 类型 | 干什么 |
|------|------|--------|
| **NAT** | **地址翻译机制** | 内网 IP ↔ 公网 IP；VM NAT = **多嵌一层虚拟 NAT** |
| **桥接 / NAT 模式** | **VM 网络拓扑** | 决定 VM **接哪张网、经几层 NAT** |
| **DHCP** | **配参服务** | 自动发 **IP、掩码、网关、DNS** — **与 NAT/桥接是两套东西** |

| # | 要点 |
|---|------|
| 1 | 桥接、NAT 两种模式**都可以开 DHCP**（也可手填静态 IP） |
| 2 | **NAT/桥接 = 网络通路规则** |
| 3 | **DHCP = IP 地址分配服务** |

```text
         ┌─ 桥接 → 路由 DHCP → 192.168.1.x → 一层物理 NAT 上网
VM 网络 ─┤
         └─ NAT   → 虚拟 DHCP → 192.168.122.x → 虚拟 NAT + 物理 NAT 上网
```

→ DHCP 协议：[6.2](6.2-dhcp-protocol.md)

<a id="ch06-8-subnet"></a>

## 六、内网 IP & 子网掩码（补充）

### 私网 IP

`192.168.x.x` / `10.x.x.x` / `172.16~31.x.x` — 仅局域网有效，公网不认。DHCP 下发的基本都是私网 IP。

### 子网掩码（判同网段）

家用常见 **`255.255.255.0`**：**IP ∧ 掩码 = 网络号** — 相同则同网段直连，不同则经网关。

| 设备 | IP | 网络号 |
|------|-----|--------|
| 宿主机 | `192.168.1.10/24` | `192.168.1.0` |
| 桥接 VM | `192.168.1.11/24` | `192.168.1.0` → **同网段** |
| NAT VM | `192.168.122.20/24` | `192.168.122.0` → **异网段** |

→ [ch02 §2.5](../chapter02-ip-address-architecture/2.5-special-address.md)

<a id="ch06-8-choice"></a>

## 七、快速选型

| 需求 | 选 |
|------|-----|
| 真机/局域网设备 ↔ VM **互访** | **桥接** |
| VM **能上网** + **外界不可主动连入** | **NAT** |
| IP 怎么填 | 默认 **DHCP**；固定地址改静态 |

---

<a id="ch06-8-cheat"></a>

## 极简记忆版 / 考点

| # | 要点 |
|---|------|
| 1 | **NAT**：地址翻译；VM NAT = **虚拟内网 + 虚拟翻译**，再叠**路由器 NAT** |
| 2 | **桥接**：VM 直连真实局域网，**无虚拟中间层**，仅**一层物理 NAT** 上网 |
| 3 | **DHCP**：自动发 IP；**两种模式都能用**，与 NAT/桥接**无关** |

| 易错 | 正确 |
|------|------|
| 写成 NVP | **NAT**（Network Address Translation） |
| VM NAT 只有一层 NAT | **虚拟 NAT + 路由器 NAT** 两层 |
| DHCP 是一种 VM 模式 | DHCP 是**服务**；桥接/NAT 才是**模式** |
| 桥接 VM 在 192.168.122.x | 桥接应与真机**同网段** `192.168.1.x` |

**背：物理 NAT=路由翻译私网↔公网；VM NAT=122.x→虚拟NAT→真机IP→路由NAT→公网；桥接无虚拟层；DHCP只管发IP。**
