# 13.9 本章总结

> 章级精读：[../study.md](study.md) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 主题 | 要点 |
|------|------|
| **握手** | 三次握手（SYN → SYN+ACK → ACK） |
| **关闭** | 四次挥手（FIN → ACK → FIN → ACK） |
| **选项** | MSS/WSCALE/SACK/Timestamps |
| **TIME_WAIT** | 2×MSL，防旧报文 + 确保关闭 |
| **RST** | 异常中断（端口未监听/崩溃/越界） |
| **Backlog** | SYN 队列 + Accept 队列 |

---

## HFT 核心关联

| 机制 | HFT 策略 |
|------|---------|
| 连接预热 | 提前握手，避免交易时延迟 |
| 长连接 | 避免 TIME_WAIT 堆积 |
| 所有选项启用 | MSS/WSCALE/SACK/TS 默认开 |
| SYN Cookies | 防御 SYN Flood |
| 加密 | 防 RST 注入/会话劫持 |
