# 13.6 TCP RST

> 章级精读：[../study.md](study.md)

## 本节核心目标

理解 TCP RST（重置）的触发条件和影响。

---

## RST 触发场景

| 场景 | 说明 |
|------|------|
| **端口未监听** | SYN 到未开放端口 → RST |
| **异常关闭** | 进程崩溃 → 内核发 RST |
| **序号越界** | 收到不在窗口内的段 → RST |
| **SO_LINGER=0** | close() 时立即发 RST（非优雅关闭） |
| **防火墙拦截** | 防火墙发 RST 中断连接 |

---

## RST vs FIN

| | FIN | RST |
|--|-----|-----|
| 语义 | 优雅关闭 | **异常中断** |
| 数据交付 | 缓冲区数据发完 | **直接丢弃** |
| 状态 | 四次挥手 | 立即 CLOSED |
| 应用感知 | EOF | `ECONNRESET` |

---

## 代码示例

```c
// SO_LINGER: close() 时发 RST
struct linger lg = { .l_onoff = 1, .l_linger = 0 };
setsockopt(fd, SOL_SOCKET, SO_LINGER, &lg, sizeof(lg));
close(fd);  // 不发 FIN，直接发 RST
```

---

## HFT 关联

| RST 场景 | HFT 影响 |
|----------|---------|
| 交易服务器崩溃 | RST → 客户端立即感知 |
| 防火墙拦截 | RST → 连接中断 |
| 序号异常 | RST → 可能是攻击 |

**排查**：Wireshark 过滤 `tcp.flags.reset == 1` 查看所有 RST。
