# 13.8 TCP 连接攻击

> 章级精读：[../study.md](study.md) · 安全：[ch18](../chapter18-network-security/study.md)

## 本节核心目标

理解针对 TCP 连接管理的攻击及防御。

---

## 主要攻击

| 攻击 | 机制 | 防御 |
|------|------|------|
| **SYN Flood** | 大量伪造 SYN → 半连接队列满 | SYN Cookies |
| **序号预测** | 猜测 ISN → 注入伪造段 | 随机化 ISN |
| **RST 注入** | 伪造 RST → 中断连接 | 序列号窗口验证 + 加密 |
| **会话劫持** | 猜测序号 → 接管连接 | TLS/加密 |
| **Land 攻击** | SYN 源=目的 → 自连接 | 现代内核已修复 |

---

## SYN Flood 详解

```
攻击者 → 大量 SYN (伪造源 IP) → 服务器
服务器 → SYN+ACK → 伪造 IP（无响应）→ 半连接队列满
正常客户端 → SYN → 被丢弃（队列满）
```

**SYN Cookies 防御**：不在半连接队列中保存状态，将状态编码在 SYN+ACK 的序号中 → 收到第三次 ACK 时验证。

---

## HFT 关联

| 攻击 | HFT 影响 |
|------|---------|
| SYN Flood | 交易服务器无法接受新连接 |
| RST 注入 | 交易连接中断 → 订单丢失 |
| 会话劫持 | 交易被篡改 |

**防御**：SYN Cookies + 加密 + 专线 + 端口白名单。
