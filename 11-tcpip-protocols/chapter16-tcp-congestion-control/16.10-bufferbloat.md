# 16.10 Bufferbloat

> 章级精读：[../study.md#ch16-10](../study.md#ch16-10)

## 本节核心目标

理解路由器过大缓冲导致的 Bufferbloat 问题。

---

## 问题

路由器**过大缓冲** → 排队时延秒级 → TCP 反馈**迟钝**。

```
传统: 路由器缓冲小 → 丢包快 → TCP 快速降速
Bufferbloat: 路由器缓冲大 → 排队不丢包 → RTT 暴涨 → TCP 不降速 → 延迟堆积
```

**影响**：
- 交互延迟（SSH/游戏/交易）可达秒级
- TCP 拥塞控制失效（丢包信号来得太晚）
- "网络感觉很慢"但带宽没用满

---

## AQM (Active Queue Management)

| 机制 | 作用 |
|------|------|
| **RED** | 队列介于 min_th–max_th 时**概率**丢/标；减**全局同步** |
| **CoDel** | 基于队列**停留时间**而非长度丢包 |
| **FQ-CoDel** | Flow Queue + CoDel → 公平 + 低延迟 |
| **fq** | Linux 默认 qdisc，配合 BBR |

---

## Linux QoS

```bash
# 查看 qdisc
tc qdisc show dev eth0

# 设置 fq-codel（推荐）
tc qdisc replace dev eth0 root fq_codel

# 设置 fq（配合 BBR）
tc qdisc replace dev eth0 root fq
```

---

## HFT 关联

Bufferbloat 对 HFT 致命——交换机/路由器大缓冲导致微秒级行情延迟变毫秒级。数据中心应：
- 配置交换机小缓冲 / AQM
- 使用 PFC（Priority Flow Control）而非大缓冲
- HFT 流量标记高优先级 DSCP
