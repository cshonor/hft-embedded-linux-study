# 16.12 拥塞相关攻击

> 章级精读：[../study.md#ch16-10](study.md#ch16-10) · 安全：[ch18](../chapter18-network-security/study.md)

## 本节核心目标

理解利用 TCP 拥塞控制机制的攻击及防御。

---

## 攻击类型

| 攻击 | 机制 | 防御 |
|------|------|------|
| **ACK 分割** | 拆 ACK 诱导按**个数**增 cwnd | 按 ACK 确认的**字节数**更新 cwnd |
| **Opt-ACK** | 数据未到先发 ACK → 发送方疯狂增 cwnd | 验证序号合理性 |
| **LDoS** | 周期性脉冲触发超时退避 | 加密 + 限速 |
| **ECN 伪造** | 伪造 CE 标记 → 发送方误降速 | 加密 (TLS/IPSec) |

---

## ACK 分割攻击

```
正常: 收到 1000B → 1 个 ACK → cwnd +1
攻击: 收到 1000B → 拆成 1000 个 1B ACK → cwnd +1000
→ 发送方 cwnd 暴涨 → 网络拥塞
```

**防御**：按 ACK 确认的**字节数**（而非 ACK 个数）更新 cwnd。现代 TCP 实现已修复。

---

## HFT 关联

| 攻击 | HFT 影响 |
|------|---------|
| LDoS | 交易连接周期性中断 |
| ECN 伪造 | 交易连接降速 |
| Opt-ACK | cwnd 暴涨导致突发 → 延迟波动 |

**防御**：加密 + 专线 + 监控 cwnd 异常变化。
