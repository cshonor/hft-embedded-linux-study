# 16.1 引言

> 章级精读：[../study.md#ch16-1](study.md#ch16-1) · 流控：[ch15](../chapter15-tcp-flow-window/study.md)

## 本节核心目标

理解**拥塞控制**与**流量控制**的区别，掌握 cwnd 的角色。

---

## 核心概念

| 术语 | 说明 |
|------|------|
| **拥塞** | 入网流量逼近/超过链路或缓冲能力 → 时延↑、丢包 |
| **cwnd** | 发送方据网络状况限制**在途数据** |
| **发送窗口 W** | **W = min(cwnd, awnd)**（awnd = 通告窗口） |

---

## 流控 vs 拥塞控制

| | 流量控制 | 拥塞控制 |
|--|----------|----------|
| 反馈 | **显式**（rwnd） | **隐式**（丢包、时延、ECN） |
| 范围 | 端到端接收能力 | **全网**路径 |
| 谁负责 | 接收方 | 发送方自行估算 |

---

## 工作点

```
吞吐
 ↑         ╱ ← 理想工作点（膝部 Knee）
 │       ╱
 │     ╱
 │   ╱
 │ ╱ ← 崖部 (Cliff) 拥塞崩溃
 └────────────→ 负载
```

**膝部**：高吞吐、低时延；**崖部**：拥塞崩溃。

---

## HFT 关联

| 拥塞控制 | HFT 影响 |
|----------|---------|
| cwnd 限制 | TCP 吞吐受限 → 大文件传输慢 |
| AIMD 降速 | 丢包后吞吐突降 → 延迟增加 |
| ECN | 可提前降速避免丢包 |

HFT 行情用 UDP 组播，不受 TCP AIMD 影响——这是选择 UDP 的关键原因之一。
