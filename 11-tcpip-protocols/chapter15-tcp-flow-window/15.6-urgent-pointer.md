# 15.6 紧急机制 (Urgent)

> 章级精读：[../study.md#ch15-6](study.md#ch15-6)

## 本节核心目标

理解 TCP 紧急数据机制的原理和现代使用状况。

---

## 机制

| 字段 | 说明 |
|------|------|
| **URG 标志** | 存在紧急数据 |
| **Urgent Pointer** | 指向紧急数据**末字节之后**的偏移（加在 SEQ 上） |

接收方可 **SIGURG** 等异步通知。

---

## 与带外数据的区别

TCP 的"紧急"并非真正的带外数据——紧急数据仍在正常数据流中，只是用 Urgent Pointer 标记位置。真正的带外数据需要不同的机制。

---

## 现代使用

| 场景 | 是否使用 |
|------|---------|
| Telnet 中断信号 | 历史用途 |
| 新设计 | **不推荐**——用独立连接或应用层信令 |
| 跨平台兼容性 | 差——OS 实现各异 |

```c
// 发送紧急数据（不推荐新设计使用）
send(fd, "X", 1, MSG_OOB);
// 接收方收到 SIGURG 信号
```

---

## HFT 关联

HFT 系统不使用 TCP 紧急机制——用独立 UDP 信令或专用控制连接更可靠。
