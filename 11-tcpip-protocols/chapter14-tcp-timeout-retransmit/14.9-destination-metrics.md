# 14.9 目的度量缓存

> 章级精读：[../study.md#ch14-9](study.md#ch14-9)

## 本节核心目标

理解 TCP 如何缓存目的地址的 RTT/cwnd 等指标，加速新连接收敛。

---

## 缓存内容

| 指标 | 用途 |
|------|------|
| **SRTT / RTTVAR** | 初始 RTO 估计 |
| **cwnd / ssthresh** | 初始拥塞窗口 |
| **MTU** | 避免重复 PMTUD |
| **TS Recent** | 时间戳时钟偏移 |

---

## 新连接继承

```
连接1 到 192.168.1.1: SRTT=12ms, cwnd=10
连接1 关闭
连接2 到 192.168.1.1: 继承 SRTT=12ms → 初始 RTO 合理
                       cwnd 可从较大值开始（跳过慢启动初期）
```

**Linux**：`tcp_no_metrics_save=0`（默认保存）→ 新连接继承缓存指标。

---

## HFT 关联

HFT 交易服务器通常连固定对端 → 目的度量缓存有效 → 新连接快速进入稳态。但如果对端 IP 变化（如负载均衡），缓存失效。
