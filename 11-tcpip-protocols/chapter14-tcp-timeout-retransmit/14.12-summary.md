# 14.12 本章总结

> 章级精读：[../study.md#ch14-exam](study.md#ch14-exam) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 支柱 | 内容 |
|------|------|
| **等多久** | SRTT → Jacobson **+4×RTTVAR**；Karn；时间戳 RTTM |
| **怎么补** | Timer → **3 dup ACK** → **SACK 精准补洞** |
| **误报** | DSACK / Eifel / F-RTO **撤销**误降 cwnd |

---

## 易混速记

| 问题 | 要点 |
|------|------|
| 超时 vs 快速重传 | 超时**重置** cwnd 更狠；快速恢复较温和 |
| Karn | 重传段 RTT **不采样**（无时间戳时） |
| 3 dup ACK | 丢包 vs **失序**的工程折中 |
| 伪超时 | 无线/移动网常见；需 DSACK/Eifel |
| SACK | 精确定位空洞，避免不必要重传 |

---

## HFT 核心关联

| 机制 | HFT 影响 |
|------|---------|
| RTO 最小 200ms | 远超交易容忍 |
| 指数退避 | 丢包后延迟雪崩 |
| 快速重传 ~1 RTT | 仍比 UDP + FEC 慢 |
| SACK | 高 BDP 链路必备 |

**结论**：TCP 重传机制不适合 HFT 热路径——用 UDP + 应用层可靠性。
