# 10.13 UDP 典型应用

> 章级精读：[../study.md#ch10-8](study.md#ch10-8)

## 本节核心目标

梳理 UDP 在现代网络中的典型应用场景及选择 UDP 的原因。

---

## 应用矩阵

| 应用 | 端口 | 选择 UDP 的原因 |
|------|------|----------------|
| **DNS** | 53 | 一问一答，握手开销不可接受 |
| **DHCP** | 67/68 | 无 IP 时无法建 TCP 连接 |
| **SNMP** | 161/162 | 网管流量，不能因网络拥塞阻塞 |
| **NTP** | 123 | 时间同步，UDP 无连接状态 |
| **TFTP** | 69 | 简单文件传输（应用层可靠性） |
| **RTP/RTCP** | 5004/5005 | 实时音视频，延迟敏感 |
| **VXLAN** | 4789 | 数据中心 overlay 封装 |
| **Geneve** | 6081 | 现代 overlay 封装 |
| **QUIC** | 443/UDP | HTTP/3，0-RTT + 多路复用 |
| **WebRTC** | 动态 | P2P 实时通信 |
| **mDNS** | 5353 | 局域网零配置发现 |

---

## 为什么选 UDP

```
需要低延迟 → UDP（无握手）
需要组播/广播 → UDP（TCP 只能单播）
需要无状态 → UDP（服务器无连接表）
需要自定义可靠性 → UDP（如 QUIC）
协议层太低无法用 TCP → UDP（如 DHCP）
```

---

## QUIC 特殊性

QUIC 在 UDP 上重建了 TCP 的可靠性 + 拥塞控制 + 加密：

- **0-RTT 连接**：首次 1-RTT，后续 0-RTT
- **多路复用**：单连接多流，无队头阻塞
- **连接迁移**：IP 变化不断连接（手机切换 WiFi/4G）
- **用户态实现**：绕过内核 TCP 栈迭代瓶颈

---

## HFT 关联

HFT 最常用的 UDP 应用是**组播行情分发**：
- 交易所用 UDP 组播发送 order book 增量
- 多个交易节点用 `SO_REUSEPORT` 同时接收
- 应用层用序号检测丢包 + FEC 恢复
