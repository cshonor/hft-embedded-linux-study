# 10.5 UDP 与 IPv6 (Teredo)

> 章级精读：[../study.md#ch10-3](study.md#ch10-3) · IPv6：[ch05](../chapter05-ip-protocol/study.md)

## 本节核心目标

理解 IPv6 对 UDP 的影响：**强制校验和**、Teredo 隧道、IPv6 组播。

---

## IPv6 下的 UDP 关键变化

| 项目 | IPv4 | IPv6 |
|------|------|------|
| 校验和 | 可选（可为 0） | **强制**（结果 0 时存 0xFFFF） |
| 分片 | 路由器可分片 | **仅源端分片**（扩展头） |
| 组播 | 可选 | 标配（ICMPv6 ND 依赖组播） |
| 伪首部 | 32-bit IP | **128-bit IP**（16 字节×2） |

---

## Teredo 隧道

Teredo（RFC 4380）通过 UDP 封装 IPv6 报文，使 IPv6 流量穿越 IPv4 NAT：

```
[IPv6 Host] → [Teredo Client] → UDP/IPv4 → [Teredo Server] → [IPv6 Network]
```

- 默认端口：UDP/3544
- 用途：IPv4-only 网络中的 IPv6 过渡
- 现代意义递减：原生 IPv6 普及后 Teredo 逐渐废弃

---

## IPv6 组播地址

```
FF02::1     所有节点（链路本地）
FF02::2     所有路由器
FF02::FB    mDNS
FF02::1:FF  被请求节点（Solicited-Node，用于 ND）
```

UDP 组播在 IPv6 中更核心——ICMPv6 邻居发现本身就依赖组播。

---

## HFT 关联

| IPv6 特性 | HFT 影响 |
|-----------|---------|
| 强制校验和 | NIC offload 仍可卸载，CPU 无感 |
| 源端分片 | 避免路由器分片 → 更可预测的延迟 |
| 组播 | IPv6 组播行情分发与 IPv4 一致 |
| 128-bit 地址 | 路由表/ACL 条目更宽，硬件匹配开销微增 |
