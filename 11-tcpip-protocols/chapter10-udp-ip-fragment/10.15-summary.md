# 10.15 本章总结

> 章级精读：[../study.md#ch10-exam](../study.md#ch10-exam) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 主题 | 要点 |
|------|------|
| **UDP 语义** | 无连接、不可靠、保留报文边界 |
| **首部** | 8 字节固定（src_port + dst_port + length + checksum） |
| **校验和** | 覆盖伪首部 + 首部 + 载荷；IPv6 强制 |
| **IP 分片** | 任一片丢失 → 整报文丢弃；偏移以 8B 为单位 |
| **PMTUD** | 设 DF + ICMP PTB → 探测路径 MTU |
| **服务器设计** | SO_REUSEPORT、recvmmsg、大接收缓冲 |
| **安全** | 反射放大、分片消耗、无认证 |

---

## 易混速记

| 问题 | Must Know |
|------|-----------|
| **UDP vs TCP 边界语义** | Datagram ↔ 字节流 |
| **IPv6 UDP checksum=0** | **非法**：必须存 0xFFFF |
| **IP 片中 UDP header 在哪** | **仅首片偏移 0** |
| **丢任意一片** | 整块上层 datagram 丢失 |
| **DF=1 oversized** | ICMP PTB → PMTUD |
| **推荐包大小** | 互联网 ≤1200B，数据中心 ≤1400B |

---

## HFT 核心关联

| UDP 特性 | HFT 价值 |
|----------|---------|
| 无连接 | 组播行情天然适合，无需维护连接状态 |
| 低开销 | 8B 头，带宽利用率高 |
| 无拥塞控制 | 行情分发不被 TCP AIMD 降速 |
| 保留边界 | 一次 recvfrom = 一个完整行情快照 |

**代价**：应用层自行处理可靠性（序号检测 + FEC + 重传请求）。

---

## 推荐包尺度

| 场景 | Payload 建议 |
|------|----------------|
| 互联网 UDP DNS/音视频 | **≤1200**（穿越 PPPoE、隧道） |
| Datacenter Overlay | **path MTU 探测** + DF |
| HFT 组播行情 | **≤1400**，设 DF 不分片 |
