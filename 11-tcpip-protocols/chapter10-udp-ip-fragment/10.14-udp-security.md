# 10.14 UDP 安全

> 章级精读：[../study.md#ch10-9](study.md#ch10-9) · 安全：[ch18](../chapter18-network-security/study.md)

## 本节核心目标

理解 UDP 无连接特性带来的安全风险及缓解策略。

---

## 主要攻击面

| 攻击 | 机制 | 缓解 |
|------|------|------|
| **反射/放大 DDoS** | 伪造受害者源 IP → 小查询换大应答 | BCP38 源校验、ACL、限速 |
| **分片重装消耗** | 大量分片占满重组缓冲 → OOM | 限制并发重组、`ipfrag_max_dist` |
| **Teardrop 变体** | 恶意偏移导致重组崩溃 | 现代内核已修复 |
| **UDP 端口扫描** | 无握手 → ICMP Port Unreachable 暴露端口 | 防火墙过滤 ICMP |
| **应用层伪造** | 无连接 → 任意源可发包 | 应用层认证/加密 |

---

## 反射放大攻击示例

```text
攻击者 → DNS 服务器 (伪造源 IP = 受害者)
  查询: "ANY example.com" (30B)
  响应: 3000B → 打向受害者

放大率: 3000/30 = 100x
历史上 Memcached 放大率曾达 51000x
```

**防御**：
- BCP38：ISP 验证源 IP 是否属于客户
- 服务器限速 + 大响应过滤
- 关闭不必要的 UDP 服务

## IP 分片安全

```bash
# Linux 分片相关参数
sysctl net.ipv4.ipfrag_high_thresh   # 重组缓冲上限
sysctl net.ipv4.ipfrag_max_dist      # 分片最大距离（防有序耗尽）
sysctl net.ipv4.ipfrag_time          # 重组超时（默认30s）
```

## HFT 关联

| 风险 | HFT 影响 |
|------|---------|
| 行情组播伪造 | 伪造行情 → 错误交易 → 巨额亏损 |
| UDP 风暴 | 网卡中断风暴 → 交易线程延迟 |
| 分片消耗 | 重组缓冲满 → 其他包丢弃 |

**防御**：
- 行情源 MAC/IP 白名单 + 交换机端口绑定
- IGMP snooping 限制组播范围
- NIC 硬件过滤（ethtool -N）
