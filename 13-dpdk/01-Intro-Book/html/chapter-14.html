section-2-传统OVS架构与瓶颈

一、架构划分

传统 Open vSwitch 分为 用户空间 与 内核空间 两部分：

                    ┌─────────────────────┐
   OpenFlow / 管理  │  ovs-vswitchd       │  用户态
   流表查询、下发   │  （慢速通路）        │
                    └──────────┬──────────┘
                               │ netlink
                    ┌──────────▼──────────┐
   首个包 / 未命中  │  openvswitch.ko     │  内核态
   快路径匹配转发   │  （快速通路）        │
                    └─────────────────────┘
组件 空间 职责
ovs-vswitchd 用户态 交换机核心逻辑、OpenFlow 流表 处理（慢速通路）
openvswitch.ko 内核态 流表 快速匹配与转发（快速通路）

→ OVS 是 NFV / OpenStack 等栈中 使用最广的开源虚拟交换机

二、典型处理流程

首个报文到达内核
    ↓
未命中内核流表（cache miss）
    ↓
netlink 上送 → ovs-vswitchd 查表、决策
    ↓
规则下发到内核 openvswitch.ko
    ↓
后续相同流 → 内核快路径直接转发（cache hit）
阶段 特点
首包 / miss 用户态参与 — 延迟高
稳态 / hit 内核转发 — 相对快
设计优点 控制逻辑灵活、与 OpenFlow/SDN 天然契合

三、NFV 场景下的性能瓶颈

瓶颈 说明
内核态转发 即使 hit，仍走内核协议栈路径 — 高并发下 吞吐与时延 受限
内核↔用户态切换 miss 路径 netlink 开销；频繁表项更新放大成本
商业 NFV 要求 高并发、高吞吐、低时延 — 传统架构 不够用

破局方向： 将 数据通路 移至用户态，用 DPDK 旁路内核 — 见 3. DPDK 加速通路

→ 与 Ch1 旁路内核 · Ch13 NFVI 一致

section-3-DPDK加速数据通路

OVS 2.4+ 引入 DPDK 支持 — 核心思想：数据通路完全用户态

一、旁路内核

DPDK 机制 在 OVS 中的作用
PMD 轮询 物理网口报文 不经 Linux 内核 直接进入用户态 OVS
向量指令 批量处理、提高每周期报文数
大页内存 减少 TLB miss，稳定转发延迟
绑核（isolcpus） 转发线程独占核，避免调度抖动 
物理网口 ──PMD──► 用户态 OVS（dpif-netdev）
                      │
                      ├──► 物理网口 / vhost / dpdkr
                      │
                      └── 不经过 openvswitch.ko 快路径

→ Ch7 PMD / burst · Ch2 大页

二、软件架构扩展

DPDK 加速 OVS 引入两个关键模块：

模块 角色
dpif-netdev 用户态 快速通路 实现 — 替代内核 openvswitch.ko 的数据面
netdev-dpdk 基于 DPDK 的 网络设备抽象 — 统一 PHY、vhost、IVSHMEM 等端口 
ovs-vswitchd
    ├── OpenFlow / 流表逻辑（仍可在用户态）
    └── dpif-netdev（用户态快路径）
            └── netdev-dpdk（DPDK 端口抽象）
                    ├── 物理 PMD 口
                    ├── vhost-user / vhost-cuse
                    └── dpdkr（IVSHMEM）

与 Ch13 呼应： OPNFV 栈中 OpenStack + KVM + OVS-DPDK 是常见 NFVI 组合。

三、慢路径 vs 快路径（DPDK 版）

路径 传统 OVS DPDK OVS
快路径 内核 openvswitch.ko 用户态 dpif-netdev
慢路径 netlink 上送 ovs-vswitchd 仍在用户态 — 减少跨空间切换
I/O 内核 netdevice DPDK PMD / vhost PMD

→ Ch4 无锁 ring — OVS 内部队列与 DPDK ring 思想相通

section-4-netdev-dpdk接口类型

netdev-dpdk 将多种 NFVI 连接方式 统一为 DPDK 端口，便于 OVS 转发面复用同一套快路径逻辑。

一、三类关键接口

接口类型 说明 典型场景
物理网口（PHY PMD） 高性能 向量化 PMD 驱动物理 NIC 南北向流量、PHY-PHY 转发
vhost-user / vhost-cuse 与 VM Virtio 前端 高速通信 PHY-VM-PHY、多 VM 互联
dpdkr（IVSHMEM） 共享内存 + 环形队列 VM 间或进程间低拷贝互通

二、与虚拟化篇对照

本书章节 与 netdev-dpdk 关系
Ch10 SR-IOV / 透传 PHY PMD 可配合 VF 透传 — 极致性能
Ch11 Virtio vhost 接口对接 Virtio-net 前端
Ch12 vhost-user OVS netdev-dpdk 直接使用 vhost-user 后端
Ch13 IVSHMEM dpdkr 即 IVSHMEM 路径在 OVS 中的封装 
         ┌────────── OVS (dpif-netdev) ──────────┐
         │                                        │
    PHY PMD                                  vhost-user
         │                                        │
    物理网卡                              VM Virtio 前端
         │                                        │
         └──────── dpdkr (IVSHMEM) ──────────────┘
                        VM / 进程

三、选型权衡（复习 Ch13）

接口 性能 热迁移 安全隔离
PHY PMD / SR-IOV 最高 差 依赖硬件
vhost-user 高 较好 软件隔离
dpdkr 高（同机） 受限 共享内存域

NFV 部署常 南北向 PHY PMD + 东西向 vhost-user 组合。

section-5-性能对比

本章引用 Intel 测试数据（256 字节小包）量化 DPDK 改造收益 — 具体数值随硬件/版本变化，量级与相对倍数 具有参考价值。

一、测试前提

项 说明
报文大小 256 字节
对比基线 传统内核快路径 OVS
加速版 OVS + DPDK（dpif-netdev / netdev-dpdk）

→ 小包场景对 PPS（包每秒） 压力最大 — 最能暴露内核与用户态切换开销。

二、PHY-PHY（物理网口 ↔ 物理网口）

NIC ──PMD──► OVS (用户态) ──PMD──► NIC
指标 结果
相对传统 OVS 11.4× 吞吐提升
原因 全程用户态 PMD — 无内核转发、无 netdevice 栈

→ 与 Ch7 burst / 向量 PMD 优化直接对应

三、PHY-VM-PHY（物理网口 ↔ VM ↔ 物理网口）

NIC ──► OVS ──vhost──► VM (Virtio PMD) ──► OVS ──► NIC
配置 相对传统 OVS
单核 处理 OVS 转发 7.1×
双核 处理 OVS 转发 12.9×
观察 含义
路径更复杂（含 VM 往返） 绝对倍数低于 PHY-PHY，但仍 数量级提升
双核 > 单核 且超过 PHY-PHY 单核倍数 多核并行扩展性 良好 — 与 Ch3 并行 设计一致

四、闭环调优提示（衔接 Ch13）

性能倍数 不是开箱即用 — 需配合：

维度 手段
硬件 多核、10G/25G NIC、NUMA 对齐
OS 大页、hugepages mount、isolcpus
OVS PMD 线程数、RX/TX 队列、流表 cache
VM Virtio 多队列、vhost-user 后端绑核

section-6-小结与索引

一、本章总结

虚拟交换机性能 = NFV 基础设施效率的关键一环。

传统 OVS DPDK OVS
内核 openvswitch.ko 快路径 dpif-netdev 用户态快路径
内核 netdevice I/O netdev-dpdk + PMD / vhost

融入的 DPDK 核心机制：

旁路内核 → PMD 轮询 → 大页 / 绑核 → 无锁队列 → 多核扩展
    ↑                                              ↑
 Ch1–7 裸金属基础                          Ch3/Ch4 并行与 ring
