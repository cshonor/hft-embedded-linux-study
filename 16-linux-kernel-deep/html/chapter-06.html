section-2-硬件时钟与定时器

80x86 上内核需与多种时钟/定时器交互

一、各硬件组件

组件 作用
RTC（实时钟） 跟踪 日历时间（年月日时分秒），掉电常由电池维持
TSC（时间戳计数器） CPU 内 高精度 计数器，适合短间隔测量
PIT（可编程间隔定时器） 以固定频率发 定时器中断；频率由 HZ 决定（2.6 常见 1000 Hz = 每 1 ms 一 tick）
HPET（高精度事件定时器） 较新芯片；多计数器/比较器，精度可达 10 MHz+
ACPI PM Timer CPU 降频/降压节能时频率 不变 — 可靠时间源

二、与内核的关系

硬件 tick（PIT/HPET/…）
    ↓ 定时器中断
内核 update_times / update_process_times
    ↓
jiffies++、系统时钟、调度 tick

→ 中断处理：Ch 4 · SMP APIC 局部 tick section-3

三、HFT 关联

  • TSC — 用户态/内核 rdtsc 测延迟（需 invariant TSC、频率校准）
  • HZ=1000 vs tickless/no_hz（modern）— 2.6 以固定 tick 为主
  • 设备驱动短延迟 → section-5 udelay

section-3-Linux计时架构

一、统一定时器源：timer_opts

内核用 timer_opts 描述符 统一管理不同硬件定时器源，主要能力：

  • 记录 中断发生的精确时刻
  • 时间插值 — 计算自上次中断以来实际流逝的时间（亚 tick 精度）

Modern 内核演进为 clocksource + clockevents 框架；ULK 2.6 概念仍适用。

二、jiffies 变量

要点 说明
含义 自启动以来 时钟 tick 计数
用途 内核时间基准、动态定时器、调度超时
启动技巧 不初始化为 0，而设为接近溢出的负值 — 尽早暴露 溢出处理 bug

三、单处理器 vs SMP

类型 来源 处理什么
全局定时器中断 PIT / HPET 等 与 特定 CPU 无关 的全局活动 — 更新 系统时间
局部定时器中断 CPU 本地 APIC 本 CPU 资源统计、本地 tick

SMP 下既要全局 wall clock，又要 per-CPU 统计 — 与 Ch 4 APIC 衔接。

section-4-更新时间与统计

定时器中断处理程序里的「每 tick 必做之事」

一、更新系统时间

  • update_times() — 在 tick 中断路径中更新 系统日期和时间
  • 与 RTC 校准、NTP（用户态）等配合（本章偏内核 tick 路径）

二、更新进程 CPU 时间

update_process_times()：

字段 含义
utime 用户态累计 CPU 时间
stime 内核态累计 CPU 时间

还检查进程是否 超出 CPU 时间限制 → 发送 SIGXCPU / SIGKILL。

→ task_struct：Ch 3 · 信号：Ch 11

三、NMI 看门狗 (NMI Watchdog)

SMP 系统中：

  • 利用 APIC 周期性产生 NMI（不可屏蔽中断）
  • 检测 CPU 是否 冻结（死锁、长时间关中断）
  • 若 CPU 无响应 → 记录错误、导出寄存器、杀死当前进程

生产环境 hang 排查时会见到 watchdog 相关日志。

section-5-软件定时器与延迟函数

一、动态定时器 (Dynamic Timers)

软件机制：内核函数在 未来某个 tick 被回调。

要点 说明
管理结构 5 个双向链表数组 tv1–tv5 — 分级超时队列（类似时间轮）
精度 以 jiffies 为单位 — 约 1 ms 量级（HZ=1000）
用途 内核协议超时、延迟工作、调度相关定时事件

Modern：hrtimer 提供纳秒级；2.6 动态定时器是理解「内核如何预约未来」的基础。

二、延迟函数：udelay() / ndelay()

当驱动需要 远小于一个 tick 的等待（微秒/纳秒）：

函数 行为
udelay() 忙等循环 — 微秒级
ndelay() 纳秒级忙等

不用 动态定时器 — 精度不够；不能睡眠 — 常用于初始化硬件时的短延时。

→ HFT：忙等 burn CPU；热路径应尽量避免，或用 TSC 校准的精确 spin。

三、与 Ch 4 下半部的区别

机制 粒度 上下文
softirq / tasklet 尽快、异步 中断上下文
动态定时器 jiffies 软中断处理
udelay μs/ns 当前路径忙等

section-6-定时相关系统调用

一、获取与设置时间

调用 说明
gettimeofday() 读当前 wall-clock 时间（2.6 经典）
settimeofday() 设置系统时间（需权限）
time() 秒级时间戳
stime() 已废弃的设时接口

→ 内核路径：Ch 10 · 用户态：08 TLPI

二、间隔定时器

调用 说明
setitimer() 设置 间隔定时器，到期发信号（如 SIGALRM）
alarm() 简化版 — N 秒后 SIGALRM

→ 信号：Ch 11

三、POSIX 定时器（更高级）

面向多线程 / 实时应用：

  • clock_gettime() — 指定时钟源（CLOCK_REALTIME / MONOTONIC 等）
  • timer_create() / timer_settime() — 线程级定时器

Modern 用户态代码应优先 POSIX API，而非仅 gettimeofday。
