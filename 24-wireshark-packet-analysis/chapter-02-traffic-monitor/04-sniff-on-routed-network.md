# 2.4 在路由网络环境中进行嗅探

> 本章：[chapter-summary.md](./chapter-summary.md) · 全书：[../README.md](../README.md)

**核心主旨**：多网段拓扑下，嗅探器**物理位置**决定你能看到什么；跨网段排障必须结合广播域边界与网络地图。

## 核心知识点

### 广播域边界

- 广播（含 ARP 泛洪）在 **路由器/三层边界** 处终止。
- 跨网段单播由路由器**按路由表转发**，不会出现在源网段交换机上（除非镜像了路由器端口）。

### 跨网段排障逻辑

```text
客户端（网段 D）→ 请求发出 → 在 D 段抓包：只见请求，不见应答？
```

| 错误结论 | 正确思路 |
|----------|----------|
| 「服务器坏了」 | 应答可能只在**上游网段 B** 或服务器所在网段出现 |
| 盲目改服务器 | 将嗅探器移到 **路由器上游/服务器侧** 交叉验证 |

| 上游也看不到该包 | 可能原因 |
|------------------|----------|
| 路由错误 | 静态路由/策略路由指错 |
| ACL / 防火墙 | 路由器丢弃 |
| NAT 改写 | 需在对称路径抓包 |

### 网络地图（拓扑图）

- 多网段嗅探前**必备**：网段、网关、关键服务器、镜像/TAP 点。
- 排障大量时间应用在：**对照拓扑选抓包点**，而非盲目加长捕获时间。

> **拓展**：动态路由（OSPF/BGP）可能导致**非对称路径**（去程≠回程网段）→ 需在多条路径或路由器接口分布式抓包后合并分析。

## 抓包/实操记录

| 步骤 | 操作 |
|------|------|
| 1 | 画/拿出拓扑：客户端网段、默认网关、服务器网段 |
| 2 | 在客户端侧抓：确认 SYN/请求是否发出 |
| 3 | 在网关 LAN 口或服务器侧抓：是否有 SYN-ACK/应答 |
| 4 | 对比 TTL、MAC、是否经 NAT 转换 |

**过滤器**：`ip.addr == 服务器IP` 在两侧同时用，比对「有去无回」停在哪一跳。

## 疑问与总结

- 路由器是**广播域分割点**；与 [§1.2 交换机 vs 路由器](../chapter-01-network-basics/02-network-communication-basics.md) 一致。
- 「看不见应答」≠ 应用层故障，先证伪**路径与路由**。
