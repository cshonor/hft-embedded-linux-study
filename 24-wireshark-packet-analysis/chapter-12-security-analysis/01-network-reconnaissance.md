# 12.1 网络侦察

> 本章：[chapter-summary.md](./chapter-summary.md) · 全书：[../README.md](../README.md) · TCP 握手：[§8.1](../chapter-08-transport-layer-tcp-udp/02-tcp-connection-management.md)

**核心主旨**：攻击前收集开放端口、服务与 OS 信息——在 pcap 里认 **SYN 扫描**与**被动/主动指纹**。

## 核心知识点

### 12.1.1 SYN 扫描（半开扫描）

| 项 | 说明 |
|----|------|
| 别名 | 隐秘扫描、半开扫描 |
| 特点 | 快、跨平台、常**无完整连接日志**（无最终 ACK） |

**开放端口**

```text
扫描方 SYN → 目标 SYN/ACK → 扫描方不发 ACK（放弃握手）
```

| Wireshark 线索 | 单端口会话常约 **5 包**（含扫描方对 SYN/ACK 的 **重传**，因无 ACK 完成） |
|----------------|------------------------------------------------------------------|

**关闭端口**

```text
扫描方 SYN → 目标 RST
```

| 线索 | 会话常仅 **2 包** |

**过滤器**

| 用途 | 表达式 |
|------|--------|
| 扫描 SYN | `tcp.flags.syn==1 && tcp.flags.ack==0` |
| 大量短会话 | Conversations → TCP，短流、多目的端口 |
| 对单受害者 | `ip.addr==<victim> && tcp.flags.syn==1` |

---

### 12.1.2 操作系统指纹

| 类型 | 机制 |
|------|------|
| **被动** | 只听受害者**自发**流量，不发探测包 |
| **主动** | 发特制包（Nmap `-O`），比响应指纹库 |

**被动常用字段**

| 字段 | 差异示例 |
|------|----------|
| **IP TTL 初值** | Windows 常 **128**；Linux/macOS 常 **64**（经跳数递减） |
| **DF 位** | 是否设 Don't Fragment |
| **TCP MSS** | 选项中最大段大小 |
| **TCP Window** | 初始窗口大小 |

> 标准未统一默认值 → 各 OS 栈实现不同 → 可推断。

| 工具拓展 | **p0f** 等对镜像流量实时被动指纹 |

## 抓包/实操记录

## 疑问与总结

- 防火墙可能 **DROP** SYN → 表现为超时重传，非 RST（与关闭端口不同）。
- 与 [§10.3.3](../chapter-10-basic-scenario/03-no-internet-access.md) SYN 黑洞区分：扫描是**多端口**模式。
