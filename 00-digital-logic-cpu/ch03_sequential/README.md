# 第3章 时序逻辑设计

> **定位：** Ch1–2 = **组合**（无记忆）；本章 = **时序**（有存储、有时钟、有状态）。  
> **根基：** CPU 寄存器 / 流水线锁存 / 外设 FSM / 同步约束 — 嵌入式 Linux 与 HFT 都用得到。

**一句话：** 锁存→D-FF→寄存器；同步范式；FSM；**setup/hold · 亚稳态 · 同步器**；拍内可控并行。

### 对你（Linux 驱动 / 系统 · 不上裸机门电路）

抓 **3 点** 即可，细节见 [学习深度_时序对Linux驱动.md](../学习深度_时序对Linux驱动.md)：

1. **Setup / Hold / Skew** → 高速外设、DDR 类采样问题的认知  
2. **寄存器 · FIFO · 计数器** → 知职责，不拆内部（FIFO→[5.4](../ch05_digital_blocks/5.4_时序电路模块.md)）  
3. **FSM 思想** → 写驱动状态/协议；**不必**门级搭状态机
