## 笔记

汇编 = 机器语言的人类可读形式。本书主线 **AArch32**（32 位 ARM 状态）。

### 6.2.1 指令长什么样

```
助记符   目的, 源…
例: ADD  R0, R1, R2     ; R0 = R1 + R2
    LDR  R0, [R1, #4]   ; R0 = Mem[R1+4]
    BL   foo            ; 调用，LR←返回地址
```

工具：`arm-linux-gnueabihf-objdump -d` / `aarch64-linux-gnu-objdump -d`。

### 6.2.2 操作数在哪

| 位置 | 说明 |
|------|------|
| **寄存器** | 16×32-bit：**R0–R15** |
| **存储器** | 只能经 LDR/STR（load/store 架构） |
| **立即数** | 嵌在指令里（大常数 → 文字池，见 [6.6](./6.6_其他主题.md)） |

### 6.2.3 寄存器银行（读反汇编必认）

| 编号 | 别名 | 角色（驱动/启动常见） |
|------|------|------------------------|
| R0–R3 | — | **参数 / 返回值**（AAPCS）；临时 |
| R4–R11 | — | 被调者常需保存 |
| R12 | IP | 过程内临时（约定相关） |
| R13 | **SP** | 栈指针（向下长） |
| R14 | **LR** | 返回地址（`BL` 写入） |
| R15 | **PC** | 程序计数器 |
| — | **CPSR** | 状态：NZCV、模式位等 |

> 异常时还有 **banked** 寄存器 / **SPSR**（→ [6.6](./6.6_其他主题.md)），读 IRQ/SVC 入口时会碰到。

### 6.2.4 对嵌入式 Linux

| 你在看 | 认什么 |
|--------|--------|
| `head.S` / 异常入口 | 谁被压栈、LR/SPSR 怎么存 |
| 内联汇编 | 约束里哪些是输入输出寄存器 |
| oops 里的 PC/LR | 崩溃点与返回链 |

对照：x86 见 [6.8](./6.8_另一个视角-x86体系结构.md)；AArch64（X0–X30、SP、PC）→ 19-ARM64。
