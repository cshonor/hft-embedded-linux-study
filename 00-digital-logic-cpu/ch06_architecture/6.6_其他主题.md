## 笔记

### 6.6.1 加载文字（Literal）

32 位指令塞不下任意大立即数 → **文字池**：附近内存放常数，**PC 相对 LDR** 装入寄存器。  
反汇编里常见 `ldr r0, [pc, #xx]` 指向池中立即数/地址。

### 6.6.2 NOP

空操作：对齐、延时占位、流水线填充。优化时可能被去掉；调试用「插 NOP」要小心。

### 6.6.3 异常与中断（嵌入式重点）

| 概念 | 直觉 |
|------|------|
| **异常 Exception** | 迫使 CPU 离开当前流：复位、未定义指令、SVC、数据/预取中止、IRQ、FIQ… |
| **中断** | 外设/定时器等异步请求（常归入异常一类处理） |
| **模式 / 权限** | User vs 特权；不同异常可进不同模式，部分寄存器 **banked** |
| **向量表** | 入口地址表：哪类异常 → 跳哪段入口代码 |
| **SPSR** | 进入异常前备份的程序状态；返回时恢复（和 LR_mode 等一起） |

简化时间线：

```
正在跑用户/内核代码
  → 异常发生（IRQ / 缺页 / SVC…）
  → 硬件切模式、存 SPSR/LR，PC ← 向量入口
  → 汇编入口保存通用寄存器
  → C 处理（Linux：IRQ handler / do_page_fault / syscall）
  → 恢复上下文，从 SPSR 返回
```

### 对嵌入式 Linux

| 你读的东西 | 对应本节 |
|------------|----------|
| `entry-armv.S` / `entry.S` | 向量入口、压栈、调 C |
| `request_irq` | 最终挂到某 IRQ 线 → 控制器（如 **GIC**）→ CPU |
| 系统调用 | SVC / `svc` → 内核入口 |
| 缺页 | 数据中止 → `do_page_fault`（接 VM） |
| 启动早期 | 复位向量、关 MMU 前的物理地址跑法 |

| ❌ | ✅ |
|----|-----|
| 在硬中断里随便睡眠、拿互斥锁 | 原子上下文规则 |
| 忽略「返回要用 SPSR」 | 入口汇编配对保存/恢复 |

> **一句话：** 向量表决定「谁来了去哪」；SPSR+入口汇编决定「怎么进怎么出」——驱动与启动汇编都围着它转。

（AArch64 用 Exception Level EL0–EL3、`VBAR_ELx` 等，名词不同、故事同构 → 19-ARM64。）
