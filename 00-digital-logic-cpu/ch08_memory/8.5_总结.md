## 笔记

### 本章带走

1. **鸿沟 + 局部性** → 必须有层次（[8.1](./8.1_引言.md)）  
2. **AMAT** = HitTime + MissRate×MissPenalty（[8.2](./8.2_存储器系统性能分析.md)）  
3. **Cache**：块、映射、写策略；驱动盯 **DMA 一致性**（[8.3](./8.3_高速缓存.md)）  
4. **VM**：VA→PA、TLB、保护、缺页；驱动盯 **ioremap / mmap / DMA / 用户指针**（[8.4](./8.4_虚拟存储器.md)）

### Linux 驱动一页纸

```
用户缓冲 (VA) --copy_*/DMA map--> 内核/总线可见缓冲
MMIO 物理 --> ioremap --> 内核 VA（Device 属性）
CPU 写 D-Cache  ←一致性→  DMA 引擎见的内存
缺页 / TLB miss = 看不见的「偶尔巨慢」
```
