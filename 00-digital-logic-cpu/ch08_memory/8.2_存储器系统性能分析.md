## 笔记

| 指标 | 含义 |
|------|------|
| **命中率 hit rate** | 在本级找到的比例 |
| **缺失率 miss rate** | 1 − hit rate |
| **AMAT** | 平均存储器访问时间 |

```
AMAT = HitTime + MissRate × MissPenalty
```

要点：即使 **MissRate 很小**，若 MissPenalty 极大（主存、磁盘），AMAT 仍可炸穿。

### 数量级直觉（示意，非某芯片标称）

| 层级 | 大约延迟量级 |
|------|----------------|
| L1 hit | 数拍 ~ 十来拍 |
| L2 hit | 十几 ~ 几十拍 |
| DRAM | 上百 ~ 数百拍 |
| 缺页进磁盘/Flash | **百万拍级**（数量级） |

例：HitTime=1，MissRate=2%，MissPenalty=100 → AMAT = 1 + 0.02×100 = **3**（平均已是 hit 的 3 倍）。  
MissRate=0.1% 但 MissPenalty=10⁶（缺页）→ 贡献仍巨大。

### 对嵌入式 Linux / 驱动

| 做法 | 为何 |
|------|------|
| 热路径少乱跳、少大范围扫冷内存 | 降 miss rate |
| DMA 缓冲对齐、连续物理页（若需要） | 降 TLB/Cache 压力 |
| 避免在中断里碰会缺页的用户缓冲 | MissPenalty 不可控 |
| 性能分析先看 **cache-miss / cycles** | 比只看「代码行数」更接近硬件 |

> **一句话：** 平均延迟由「偶尔一次的大罚」主导时，优化 miss 与缺页比抠几个 ALU 指令更值。
