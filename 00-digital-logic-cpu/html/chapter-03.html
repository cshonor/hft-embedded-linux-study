笔记

为何需要时序？

组合逻辑能算，但：

问题 后果
存不住 输入一撤，结果没了；无法「记住上次算到哪」
一直在变 毛刺、中间态乱飞；后级若当最终结果用会出错
无法对齐多块 多条路径延迟不同，没有统一节拍就无法可靠拼大系统

→ 引入 存储（锁存/触发器） + 工业上再用 统一时钟 把更新切成拍。

两大基础电路

组合逻辑 时序逻辑
存储 无 触发器/锁存器 有（记忆单元）
输出决定 仅当前输入 当前输入 + 过去保存的状态
并行 天然多路同时算 可在时钟节拍内多路同时算（受控）
缺陷 / 能力 有 tp、毛刺；存不住 能锁存稳定结果，可规模化搭系统

组合细节（延迟、毛刺）→ 2.9。
「立刻决定」是 逻辑关系；物理上仍要等传输延迟才稳定。

时序再分：

同步时序 异步时序
时钟 全体 FF 共用同一 CLK，边沿统一更新 无统一时钟，信号互相触发
分析 setup/hold 清晰 竞态难穷举
工业 CPU / MCU 主流 仅局部特殊；通用处理器不做大规模异步

3.2

锁存器和触发器

Core Concept: 正反馈存 1 bit；SR → D 锁存 → 主从 D-FF → 寄存器

状态

  • [x] 已读（口述巩固）

笔记

时序最基础的 1 bit / 多 bit 存储。

底层脉络： SR 锁存（最基础）→ D 锁存（电平）→ D 触发器（边沿）。
存储本质：正反馈环路 —— 两反相器首尾互锁电平。

3.2.0 记忆的物理根源：交叉耦合正反馈

零件： 与非门 Y=/(A·B)（全 1 出 0，否则出 1）。

什么叫「交叉耦合」

两个与非门：

门 输入 输出
门1 bar S、bar Q Q
门2 bar R、Q bar Q

连线：门1 的 Q → 门2 输入；门2 的 bar Q → 门1 输入。
→ 交叉耦合 = 互相把输出送给对方当输入；这两根线 = 反馈环路。

拆开两块（极易混）：

部分 是什么
① 内部闭环（记忆本体） Q↔bar Q 交叉耦合；无外部干预时 自锁
② 外部控制端子 bar S、bar R：外面电路 送来的驱动信号，用来 改写 记忆；不属于 环路内部 
   S̄（外部）          R̄（外部）
      ↓                  ↓
   与非门1 ──Q──► 与非门2 ──Q̄─┐
      ▲                      │
      └──────────Q̄───────────┘
         （内部反馈环）

什么是「正反馈」

信号绕环一圈后 强化原状态，把电平锁死。

保持模式 bar S=bar R=1，设 Q=1,bar Q=0：

  1. Q=1、bar R=1 进门2 → bar Q=0
  2. bar Q=0、bar S=1 进门1 → Q=1

闭环：Q=1 → bar Q=0 → Q=1 → 自我维持。
另一稳态 Q=0,bar Q=1 同理锁住。

为何能存 1 bit（双稳态 · 易失）

bar S=bar R=1（保持）时，电路退化成 两反相器首尾相连的正反馈闭环：只有两稳态 Q=1,bar Q=0 或 Q=0,bar Q=1。
进入某稳态后，反馈互相支撑电平，不需要外部持续输入维持。

❌ 别这样理解 ✅ 正确
「无限循环」= 电平来回 振荡 环路是 静态自洽稳态：电平稳定不动；「环路持续生效」≠ 翻转震荡
断电还记得住 易失：通电靠反馈保持；断电电平全消、记忆丢失（≠ Flash/ROM）

教材标准说法：锁存器有双稳态；无置位/复位激励时 长久维持现态，直到外控强制切换 —— 1 bit 存储最基础机理。

可背标准版：
与非 SR 靠交叉耦合正反馈形成双稳态。当 bar S=bar R=1 无有效改写时，内部反馈环路 持续维持当前稳定电平。通电下状态不自行改变；断电后状态消失。这是数字电路最原始的 1 bit 记忆。

对比组合电路：无反馈 → 输入撤掉输出立刻没了，不能保存。

怎么改写（Set / Reset）——外部打断、环再接管

阶段 bar S,bar R 谁在管
常态 都是 1 外部不起作用；只靠 Q↔bar Q 保持
置位 bar S=0,bar R=1 外部强行打破平衡 → Q=1；再把 bar S 回 1 → 环重新锁住 Q=1
复位 bar S=1,bar R=0 外部强制 Q=0；bar R 回 1 后环维持 Q=0

横线 = 低电平有效：bar S=0 才置位；bar S=1 不干预。或非版则是不带横线的 S、R，高有效。

考点：Q,bar Q = 内部反馈信号；bar S,bar R = 外部驱动信号。正因两路外输入有非法组合，才合并成一路 D → D 锁存。

非法坑

bar S=bar R=0 → Q=bar Q=1，互补破坏；同时回 1 时竞争，次态不定。

或非门版：同样交叉耦合正反馈、两稳态存 1 bit，只是 S/R 高有效。

一句话： 两门输出互为对方输入成环；环有两稳态，不靠外部就不会变 → 正反馈存 1 bit。
链路：交叉耦合 → SR 锁存 → +EN 得 D 锁存 → 主从串联得 D-FF。

3.2.1 SR 锁存器（一切触发器的源头）

定位： 时序电路最基础的 1 bit 存储；无时钟 → 异步时序。
结构：两与非（或两或非）交叉耦合正反馈。
相对组合逻辑（译码/MUX）：输出不只看当前输入，还依赖现态（有记忆）。

版本 1：与非门 SR（更常用，低电平有效）

输入 bar S（置位）、bar R（复位）；输出 Q,bar Q。图中 S'_D/R'_D 即 bar S/bar R。

bar S bar R 动作 Q（次态）
1 1 保持 不变（记忆）
0 1 Set 置位 强制 Q=1（与现态无关）
1 0 Reset 复位 强制 Q=0（与现态无关）
0 0 非法 Q=bar Q=1；同时回 1 时竞争，禁止

写完再松手： 置位/复位脉冲过后把对应脚抬回 1 → bar S=bar R=1 → 环路 保持 刚写入的值。

时序串一遍：

  1. bar S=0,bar R=1 → Q=1
  2. bar S 抬到 1 → 保持 Q=1
  3. bar R 拉到 0 → Q 强制变 0
  4. bar R 抬到 1 → 保持 Q=0

背诵四行： 11 保持 · 01 置 1 · 10 置 0 · 00 非法。
（或非版 S、R 不带横线、高有效，别和本表搞混 → 见下。）

版本 2：或非门 SR（高电平有效；教材常先讲）

      R ────>┌──────┐
             │ NOR  │──────> Q
      ┌──────┤      │
      │      └──────┘
      │             ↑ 交叉反馈
      │      ┌──────┐
      └──────┤ NOR  │──────> Q̄
             │      │
      S ────>└──────┘
脚 含义
S Set，高有效 → 强迫 Q=1
R Reset，高有效 → 强迫 Q=0
Q / /Q 主输出 / 反相输出；正常工作时互补（非法态除外）
S R Q /Q 模式
0 0 保持 保持 记忆（靠交叉反馈）
1 0 1 0 Set
0 1 0 1 Reset
1 1 0 0 非法（禁止）

危险： S=R=1 时两输出都为 0（暂时不互补）；再同时回到 00，谁先恢复不确定 → 竞争，次态不可预测。

有效电平 bar S/bar R 低有效 S/R 高有效
保持 11 00

CMOS 原生 NAND 原生 NOR

正反馈（同 3.2.0）

Q 送入另一门输入，另一门输出再送回；稳定在 0/1 后，无外部 S/R 则 永久锁住。

SR → D 锁存：为何要改

痛点：存在 非法输入（与非版 bar S=bar R=0；或非版 S=R=1）。
改造：加组合逻辑 S=D，R=/D（或等价），合并为单输入 D，消非法组合 → 再加 EN → D 锁存器。

链条（理顺）

器件 要点
SR 锁存 异步、无时钟、有非法态（教材常先讲 或非高有效版）
钟控 SR +CLK：仅 CLK=1 时响应 S/R（仍可能非法）→ 见下图
D 锁存 用 D 消非法 + EN/CP；电平触发
主从 D-FF 两级 D 锁存串联；边沿触发；CPU 寄存器单元

钟控 SR（Gated / Clocked SR）

  • 两 AND：R·Clk、S·Clk → 送到基本或非 SR
  • Clk=0：两 AND 输出恒 0 → 内层 SR 处于保持 → S/R 怎么变都不管
  • Clk=1：等价普通或非 SR（S=R=1 仍非法）

CLK 口误钉死：
CLK 不是「永远有效、永远为 1」。它是按周期在 0/1 之间跳的方波。
对本电路：「有效」= 处于高电平（Clk=1）那一段时间——此时才允许 S/R 改写；Clk=0 则保持。
一句：CLK=门控开关；=1 开门写，=0 关门冻。

→ 解决了「何时允许改写」，没解决非法态。下一步用 D 消非法。

易考点： 本质=交叉耦合正反馈；有非法态，实际少直接用；是 D 锁存/各类 FF 的底层原型；无时钟基本 SR=异步。

3.2.2 D 锁存器（电平敏感）

目标不是「让两个输入一样」。
核心输入：D（数据） + EN/CP（使能/门控）；输出 Q、bar Q。

图 (a)：D 与 /D 经两 NAND 与 CP 相与 → 交叉耦合与非 SR（保证内层不会 bar S=bar R=0 那种双有效）；(b) 符号里 1D / C1 = 数据受控于该控制端。

EN/CP 模式 行为
1（高） 透明 / 直通 Q=D，跟随变化；此时才「Q 与 D 相等」
0（低） 锁存 / 保持 切断输入；靠正反馈 冻结 关锁前那一刻的 Q；之后 D 怎么变都无关

纠误区：

❌ ✅
目的是保持「两个输入一样」 目的是：开则跟 D，关则冻住、隔绝 D 波动
D 与 Q 永远相等 仅透明时相等；关锁后可 D≠Q（这正是锁存意义）

例：CP=1、D=1 → Q=1；再 CP→0，D 改成 0 → D=0 而 Q 仍为 1。

一句话： CP 开 → 输出跟着 D 走；CP 关 → 冻结当前值。
缺陷：CP 持续高时 D 变 Q 就变，易捕获毛刺 → 要用边沿触发的 D-FF。

3.2.3 D 触发器（边沿敏感 · 主流：主从）

CPU 标准： 仅在时钟 上升/下降沿 采样并锁存；其余时间 Q 不变。

主从结构（Master-Slave）

D →【主 D 锁存】→【从 D 锁存】→ Q
      C = ~Clk         C = Clk
         （图：Clk→非门→主；再非一次→从）

口述大坑（必纠）： 不能写成「主接 Clk、从接 overlineClk」又同时说「Clk=0 时主透明」。
上升沿版正确配对： 主使能 = overlineClk（Clk 低时透明）；从使能 = Clk（Clk 高时透传）。接反则变成另一沿行为，和真值/波形对不上。

上升沿触发，分阶段：

阶段 主锁存（C=~Clk） 从锁存（C=Clk） 效果
Clk=低 透明，跟随 D 保持 主在采、从在守
Clk 上升沿 0→1 立刻关闭，锁死刚采到的值 打开，把主的值传到 Q 沿上完成采样+交接
Clk=高全程 持续关；外部 D 进不来 透传的是已冻结的主输出 隔绝外部抖动

关键结论：

  • D-FF 只在时钟沿附近把 D 交到 Q（本图为上升沿）
  • 采样后靠两级锁存内部 正反馈 维持
  • 之后外部 D 怎么变，无法改 Q（直到下一沿）

符号辨认： 锁存器时钟端无三角；触发器时钟端有 ▷ = 边沿。

形象总结

角色 比喻

3.2.5 带使能触发器

普通 D-FF：每拍都采 D。
使能 EN： 仅当 EN=1 时边沿才更新；EN=0 时保持原 Q（实现上常为「MUX：EN? D : Q」再进 FF，或时钟门控——后者要非常小心毛刺）。

用途
条件写 寄存器堆「本拍写不写」
流水线 stall 时冻结某级
外设 配置寄存器只在写选通时更新

3.2.6 带复位触发器

类型 行为
异步复位 reset 有效立刻清 Q（不等时钟）；释放时要注意同步，免亚稳态
同步复位 仅在时钟边沿采样 reset，再清 Q；更好分析

开机、看门狗、外设与 CPU 复位电路必备。上电后状态寄存器通常进 已知空闲态（接 FSM）。

锁存器 触发器

3.3.1 有问题的异步电路

无统一时钟时，一块电路的输出直接当另一块的「时钟」或异步置位：

风险 表现
竞态 谁先到决定行为，仿真与硅片可不一致
毛刺当时钟 组合毛刺 → 误触发 FF → 整系统乱
难分析 没有「一拍」概念，延迟约束无法用标准 STA 收敛
难调试 偶发、与温度/电压相关

芯片设计 禁止 大规模乱异步；允许的例外：复位释放后的同步、精心设计的异步 FIFO 指针、极少数低功耗异步岛——都不是「随便互触发」。

3.3.2 同步时序标准范式（工业 / CPU 全采用）

✅ 定义： 电路里 所有触发器共用同一个全局时钟 CLK。
所有触发器只在 同一个时钟边沿（全书默认常画 上升沿）统一更新状态。

时钟 = 统一的「发令枪」：

时钟边沿 N：全体 FF 同时锁住当前 D → 更新 Q
    ↓
两个边沿之间：中间组合逻辑对 Q 并行运算（算下一拍的 D）
    ↓
时钟边沿 N+1：全体 FF 再同时锁住已稳定的结果

标准骨架（务必能默画）

          ┌─────────────────────────────────────┐
          │           纯组合逻辑                 │
   Q ────►│  (ALU / 次态逻辑 / 译码 …)          │────► D
          └─────────────────────────────────────┘
            ▲                                   │
            │              CLK                  │
            │               │                   │
          ┌─┴───┐           ▼                 ┌─┴───┐
          │ FF  │◄──── 全体共此时钟 ──────────►│ FF  │ …
          │(现态)│                           │(次态采入)
          └─────┘                           └─────┘

三条铁律：

  1. 全局统一时钟 驱动所有（同步域内）触发器
  2. 触发器输出 → 纯组合逻辑 → 下一级触发器输入（组合里 不再塞异步反馈当时钟）
  3. 状态 仅在时钟边沿 更新；边沿之间组合可毛刺，只要在下一沿前稳定即可（→ 3.5）

ARM MCU、PC CPU 的通用设计标准（本书 HDL/FPGA 流程可跳，范式本身要）。

一拍里发生了什么（时间轴）

时刻 存储 组合
上升沿 采样 D→Q；开始新一拍 旧组合结果被锁进 FF
沿后不久 Q 已是新值 新 Q 灌进组合，输出可能乱跳（毛刺 OK）
沿前 setup 窗口 — D 必须已稳定
下一上升沿 再采样 循环

3.3.3 同步 vs 异步

同步 异步
时序分析 易（约束清晰） 极难收敛
稳定性 / 工具链 强 弱
用途 嵌入式 / PC CPU 主流 小众低功耗、局部特殊结构

❌ 异步：没有统一时钟，触发器靠信号互相触发 → 难分析、易不稳。
✅ 工业芯片统一走 同步时序。

3.3.4 常见「看起来同步、其实违规」

❌ 写法 为何坏 ✅ 改法
用组合输出当另一 FF 的时钟 毛刺 = 假边沿 全体共 CLK；用使能控制「本拍写不写」
异步反馈绕过时钟改状态 无法用一拍分析 次态只经组合算进 D，边沿才更新
两块各用各的晶振又直接连数据 跨时钟域 同步器 / 异步 FIFO（→ 3.5）
把锁存当 FF 用在同步通路 透明窗吃毛刺 同步通路用边沿 D-FF

3.3.5 和 FSM、流水线的关系

结构 同步骨架怎么套
FSM 状态寄存器 = FF；次态逻辑 + 输出逻辑 = 组合 → 3.4
单周期 CPU 一拍内组合算完整条指令；CLK 够慢盖住关键路径
流水线 每级之间插一排 FF；每段组合更短 → 可提高 f_max

一句话： 边沿之间交给组合并行算；边沿上全体一起存 —— 这就是同步。大规模数字系统几乎都长这样。

有限状态机

笔记

状态机 = 时序逻辑里最常用的 控制电路（UART、SPI、总线控制器、按键消抖、协议解析、CPU 控制器等）。

3.4.0 架构（钉死）

FSM = 时序部件（触发器）+ 组合逻辑，嵌在 3.3 的同步骨架里：

         外部输入 x
              │
              ▼
     ┌──────────────────┐
     │  次态组合逻辑     │────► 下一状态 D
     │  D = f(现态, x)  │
     └────────▲─────────┘
              │
         现态 Q │  CLK
              │   │
           ┌──┴───┴──┐
           │ 状态寄存器 │  （若干 D-FF）
           │  (现态)   │
           └────┬─────┘
                │
                ▼
     ┌──────────────────┐
     │  输出组合逻辑     │────► 输出 y
     │  y = g(...)     │
     └──────────────────┘
块 职责
状态寄存器 保存 当前状态（记忆）；仅时钟边沿更新
次态逻辑 根据 当前状态 + 外部输入 → 算出 下一状态
输出逻辑 算出对外控制信号 / 数据通路控制

特点：状态总数 有限，按规则在状态图上跳转。
「有限」= 可用有限位宽编码；不是无限历史。

3.4.1 设计流程（考试 / 实作同一套）

  1. 文字需求 → 列出要区分的「情况」（状态候选）
  2. 画状态图 / 表：圆圈=状态；箭头=转移（标注输入条件）；输出标在圈上或箭头上
  3. 状态编码：给每个状态分配二进制码
  4. 列真值表：现态 + 输入 → 次态；现态(+输入) → 输出
  5. 化简 → 次态方程、输出方程（卡诺 / 代数）
  6. 画电路：状态用 D-FF；方程用组合门实现
  7. 检查：每个状态+输入是否有唯一下一态；非法码是否要归位；复位进哪个态

3.4.2 小例：检测序列（直觉）

需求：输入串行 bit，检测到连续 08 时输出检测脉冲（示意）。

状态 含义
S0 还没看到 1
S1 刚看到一个 1
S2 已看到 11（可再定义是否停留）

转移直觉：S0 遇 1→S1，遇 0→S0；S1 遇 1→S2，遇 0→S0……
实现：2 个 FF 编码 3 态（或独热 3 个 FF）+ 若干组合门。

教材还有：计数器（状态=计数值）、交通灯、串口「空闲→起始位→数据位→停止位」等——结构相同，只是状态含义不同。

3.4.3 Moore / Mealy

Moore Mealy
输出取决于 仅当前状态 当前状态 + 输入
输出变时刻 通常随状态更新（对齐时钟） 输入一变输出就可能变（组合路径）
优点 时序更稳、好分析 往往更少状态、响应更快
风险 状态可能较多 输出易带 毛刺；异步后级危险
❌ ✅
Mealy 输出直接当别的模块时钟 控制信号进同步域或先寄存一拍
只背名字不画图 看输出标在 圈上（Moore） 还是 箭头上（Mealy）

嵌入式外设控制：两者都常见；对毛刺敏感的使能/写脉冲，优先 Moore 或 Mealy 后再打一拍寄存器。

3.4.4 状态编码

编码 做法 利弊
二进制 n 个状态用 ceil(log2 n) 个 FF 省触发器；次态逻辑可能复杂
独热 (one-hot) n 个状态用 n 个 FF，仅 1 位为 1 译码简单、次态常更简单；FF 多
格雷等 相邻状态只变 1 bit 减转移时的中间冒险（特定场合）

未用到的码字：要规定「落入非法态时回到空闲」，避免上电/单粒子后死锁。

3.4.5 状态机分解

复杂控制拆成 多个小 FSM（或 FSM + 数据通路计数器）：

  • 单机状态爆炸 → 时序难、易错
  • 分机：主控 FSM 调子 FSM；降低关键路径与认知负担

例：UART = 「帧级 FSM」+ 「位计数/波特计数」协作。

3.4.6 由电路图反推 FSM

调试技能：

  1. 找出哪些 FF 是状态寄存器
  2. 从次态组合反推转移条件
  3. 对照手册里「状态位」或波形

写 Linux 驱动时：外设「为什么卡在某状态位」= 往往卡在某个 FSM 态等条件。

3.4.7 和数据通路的分工（接 Ch5/Ch7）

控制（常 FSM） 数据通路
存什么 当前控制状态 数据、地址、GPR
算什么 次态、使能、选通 ALU、移位、访存
同步 同一 CLK 同一 CLK

CPU：译码/控制可用 FSM 或微码；执行级用 ALU——控制发使能，数据通路干活。

3.4.8 小结

要点
本质 有限个状态 + 同步跳转
硬件 FF 存现态；组合算次态与输出
选型 Moore 稳 / Mealy 省；编码看面积与逻辑复杂度
对你 外设与协议 = FSM；驱动要会读状态

一句话： FSM 就是「用时钟对齐的 if-else 状态图」的硬件版；看懂状态图就能看懂大半控制器。

3.5.1 两个黄金约束：Setup / Hold

约束 含义（钉死）
建立时间 Setup (tsu) 时钟边沿到来 之前，D 必须已经稳定，并维持至少 tsu
保持时间 Hold (th) 时钟边沿到来 之后，D 不能立刻变，还须再稳至少 th

通俗：

  • Setup：开枪前，人要提前站好
  • Hold：枪响瞬间，人不能马上乱跑
❌ ✅
「边沿一到马上改 D 也没事」 边沿后还要守 hold
「只要最终逻辑对就行」 采样瞬间 D 不稳 → 本拍就可能采错

和组合延迟的桥（→ 2.9）

上一级 FF 发出 Q（延迟 tpcq：时钟→Q）
  → 组合逻辑（延迟约在 tc … tp 之间）
  → 本级 FF 的 D
约束 直觉不等式（同频、忽略 skew）
Setup Tclk ≥ tpcq + tp_组合 + tsu
Hold tpcq + tc_组合 ≥ th
  • Setup 紧 → 时钟开不快（主频上限）；降频或缩短组合可救
  • Hold 紧 → 降频通常救不了；要加缓冲拉长最短路径、或改拓扑

3.5.2 建立 / 保持违反之后会发生什么？

情况 后果
D 在边沿附近仍在跳，最后碰巧落在合法 0/1 本拍采到错误逻辑值（静悄悄功能 bug）
D 落入触发器 孔径 / 分辨窗口 亚稳态：Q 长时间非 0 非 1，或随机落 0/1
下游当稳定电平用 后级乱判 → 整条链路错拍

Setup 违反 ≠「芯片烧掉」；= 这一拍采样不可信。高频、跨时钟、异步输入时概率陡增。

Hold 违反：边沿刚过后 D 已被新组合结果污染 → 同样可能采错 / 进亚稳态。

3.5.3 系统时序与最高频率

Tclk_min ≈ tpcq + tp_逻辑关键路径 + tsu   （再留裕量）
f_max = 1 / Tclk_min

流水线把长组合切开 → 每段 tp 变短 → 可抬 f_max（→ CSAPP Ch4 / 本书 Ch7）。

手算小例（假设数，练手感）

参数 值
tpcq 0.5 ns
tp_组合（关键路径） 3.0 ns
tsu 0.4 ns
tc_组合（最短） 0.3 ns
th 0.2 ns

Setup：Tclk ≥ 0.5+3.0+0.4 = 3.9 ns → f_max ≤ 1/3.9 ≈ 256 MHz（未留裕量）。
Hold：tpcq+tc = 0.5+0.3 = 0.8 ≥ 0.2 → 满足。

若把组合砍到 tp=1.5 ns → Tclk≥2.4 ns → f_max 升到约 416 MHz —— 这就是流水线/先行加法器要换的东西。

*3.5.3b 时钟偏移 Clock Skew（可选）

同一 CLK 到达不同 FF 的时间差 δ：

  • 发射 FF 晚到 / 接收 FF 早到 → 吃掉 setup 裕量
  • 反向 skew 可能 帮或害 hold（视方向）

高频、大芯片、板级时钟树时才痛；先知「skew 会偷裕量」。

3.5.4 亚稳态 Metastability

何时： 异步输入或跨时钟域，使 D 恰在采样边沿「中途」变化。
是何： Q 卡在中间电压；一段时间后随机落到 0 或 1。

要点
不能设计成概率为 0 只能把 传到下游的概率 压到极低（如 FIT 级）
多等一拍 给第一级更多分辨时间
场景 异步按键、UART RX、网卡与 CPU 不同源、中断线

Setup/Hold 窗口 = 「保证不进亚稳态」的契约；窗口外跳变 → 契约作废。

3.5.5 同步器

异步信号 → FF1 → FF2 → 同步域内使用
              ↑
         FF1 可能亚稳态；多等一拍衰减；
         FF2 再采，下游看到坏电平概率极低
注意
减的是 亚稳态传播概率 不保证「第一拍就采到正确新值」
可能多等 1～2 拍 协议/驱动要按延迟设计
多 bit 总线 不能每位各同步再拼（会撕裂）→ 用握手、异步 FIFO、或格雷码指针

*3.5.6 分辨时间推导（可选）

公式理论；时间紧可跳。

对接： Ch7 频率上限与「等一拍」；PREEMPT_RT / 网卡场景里「硬件何时算稳定」同根。

一句话： Setup 定能跑多快；Hold 定最短路径能不能活；亚稳态是异步世界的税；同步器是交税方式。

笔记

为何「并行」放在时序章讲？

教材把并行放在时序章，不是说组合不能并行，而是：没有时钟的并行无法规模化可靠使用。

  1. 组合本身天然并行
    多路信号可同时运算。
    但 无时钟管控：毛刺、竞态、结果无处稳定存放 → 大规模系统不可用。→ 2.9

  2. 时序框架下的可控并行
    多条独立组合通路放在 同一个时钟周期内同时运算，下一时钟边沿 统一采集 所有通路结果。

👉 并行不是「一直同时乱算」，而是被时钟切成一段一段、节拍可控的同时运算。

边沿：锁存各通路上一拍结果
  → 本拍内：ALU、地址计算、条件等组合块可同时算
  → 下一边沿：同时锁住各通路已稳定输出

和流水线、超标量的一层直觉

概念 和「拍内并行」关系
单周期 一拍内整条指令的组合都算完（并行度在空间，时间上串成一拍）
流水线 多条指令叠在不同级；每一级内部仍是拍内组合并行
超标量 同一拍发射多条 → 多套数据通路真正并排
❌ ✅
并行 = 不要时钟、越同时越好 并行 = 同一 CLK 拍内 多路算，边沿对齐存
组合并行已经够用 组合并行必须嵌进同步骨架才可规模化

HFT： 在满足 setup/hold 的前提下尽量并行、少串行等待；延迟下限仍受关键路径与时钟约束。
