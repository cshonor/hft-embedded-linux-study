a 单管：NMOS ↔ PMOS（四电极）

拆自 1.7_CMOS晶体管.md · 内容完整保留

1. 单管对比：NMOS ↔ PMOS（结构对称，掺杂与极性反过来）

物理上四电极： G 栅 | D 漏 | S 源 | B 衬底/阱（Bulk）。
原理图常只画 G/S/D（3 脚）：数字 CMOS 里 B 已在片内接到电源轨，不单独外引。

NMOS PMOS
体区 B 所在 P 衬底 N 阱（或 N 衬底）
S、D 掺杂 n+ p+
载流子 电子（S→D） 空穴（S→D）
传统电流方向 常 D→S（与电子反向） 常与空穴同向 S→D
导通（增强型，简化） (V_{GS}>V_{th})（栅相对源够高） (V_{SG}>
符号（数字教材常见） 栅无小圈；体端箭头 指向沟道 栅带小圈；体端箭头 离开沟道
B 硬性接法（标准数字 CMOS） B → GND（最低电位） B → VDD（最高电位）

导通口误纠： 「栅比源高」只是 NMOS 的粗记；正式是 V_GS = V_G − V_S 超过阈值 V_th（源不在 0 时不能只看 V_G 绝对值）。PMOS 对称看 V_SG 或「栅够低于源」。

1.1 电路符号怎么认（箭头 · 小圈 · 别和「朝栅极」搅在一起）

认管时看两件独立的事：① 体端（衬底）箭头方向；② 栅极旁有没有小圈。

① 四端符号：体端箭头 = 沟道类型

箭头画在 衬底/体 B 那条腿上，表示体与沟道之间的结类型：

箭头方向（钉死） 口误
NMOS 从衬底指向沟道（朝沟道「刺进去」） ✅
PMOS 从沟道指向衬底（离开沟道「拔出去」） ✅

画在纸上时：体端常在沟道下方 → NMOS 箭头往往 朝上指进沟道；PMOS 箭头往往 朝下离开沟道。
具体「朝上/朝下」取决于你怎么摆符号，以「进沟道 / 离沟道」为准，不要死记上下。

❌ 易混 ✅
把「指向沟道」说成「远离栅极」 体在下、箭头进沟道时，其实是 朝栅极那一侧 指；勿用「远不远离栅」当判据
用箭头朝上=一定是 PMOS 上下只是画法；看 进/离沟道

与本文件图注一致：朝沟道 = N 沟（NMOS）；离沟道 = P 沟（PMOS）。

② 数字 CMOS 简图：PMOS 栅极旁小圈

很多逻辑图里：

栅极
NMOS 无圈
PMOS 有小圆圈（表示反相/增强型 P 管「栅低才导通」的画法习惯）

小圈 不是 又一个物理电极，只是符号约定，用来和 NMOS 一眼区分。

③ 反相器里成对出现（接 CMOS）

标准静态 CMOS 反相器：

VDD ── PMOS（在上，S 接 VDD）──┐
                               ├── Out
GND ── NMOS（在下，S 接 GND）──┘
         两管栅极并接 = In
  • 总是成对：上拉用 P，下拉用 N（→ 1.7b）
  • 输入共栅 → 天然一开一关 → 电平翻转（非门）

一句话： 体箭头 进沟道=N、离沟道=P；数字图上 P 管栅带圈；反相器 P 上 N 下、共栅。

对照图（三端简图 · 只看箭头进/出）：

图中 箭头 记法
左 NMOS 朝里（指向沟道） N = in
右 PMOS 朝外（离开沟道） P = out

这张用箭头区分 N/P，栅极 都没画小圈——也常见。另一派数字简图会给 PMOS 栅加圈；两套都能认，别混成必须同时具备。

S/D 不固定左右： 载流子从哪边「出发」，哪边叫源。原理图勿死记「左 S 右 D」。
数字门里习惯：接 GND 的 N 管端、接 VDD 的 P 管端 称为源（标准反相器/NAND/NOR 如此）。

为何 B 必须接轨： 让源–衬底 / 阱–衬底等 PN 结保持反偏，减漏电、抑闩锁；乱接 B 会正偏或体偏置乱漂阈值。
（体效应 / 衬底偏置：B 与 S 电位差会改 V_th——知道有这事即可，公式体系结构向不背。）

细节机理 → 补充_PN结到MOS。同片剖面 → 下文「三、CMOS 芯片硅片横截面」。

教材剖面 + 符号（四极对照）：

图上标注 含义
(a) n-channel NMOS：体 p⁻，S/D n⁺，B 经 p⁺ body tie
(b) p-channel PMOS：体 n⁻，S/D p⁺，B 经 n⁺ body tie
metallurgical junction S/D 与体之间的 PN 结（要反偏）
body tie, not a junction p⁺–p⁻ 或 n⁺–n⁻：同型重掺接触，不是结
ohmic contact 金属与重掺区的欧姆接触
下方符号箭头 体端箭头：朝沟道 = N 沟（NMOS）；离沟道 = P 沟（PMOS）

→ 与上表「B→GND / B→VDD」同一套结构；看懂标注即可，不背工艺尺寸。

NMOS 立体示意（认四极 + 沟道，参数浅尝）：

看到 记什么 体系结构向要不要深挖
B / S / G / D 四电极；B 经 p⁺ 接 p⁻ 衬底 ✅ 要
n⁺ … n⁺ 之间 栅下形成 N 沟道 的地方 ✅ 要（通/断直觉）
poly + oxide 栅极 + 绝缘氧化层（t_ox） 知「栅与硅绝缘」即可
L_drawn、L_D、L_eff 版图栅长、侧扩、有效沟道长度（大致 L_eff ≈ L_drawn − 2L_D） ❌ 公式/工艺不背

→ 反相器下管就是这种 NMOS（S→GND）；上管是对偶的 PMOS。到此对「管长什么样」收束，回到门级 NAND/NOR。

再认一张：结构 ✅ / 图中偏置 ⚠️（勿当 CMOS 门标准接法）

看什么 结论
p-type Body、两 n⁺、Metal–SiO₂–沟道 L、t_ox 仍是 NMOS 结构，与上图同源
红虚线二极管 S/体、D/体的 寄生 PN 结；正常须 反偏
图中 S 与 Body 短接且标到 VDD，D 接电容 C_L 只是某一示例偏置（充电/开关示意）
CMOS 数字门里的下拉 NMOS S→GND，B→GND（不是 VDD！）；D 才接到输出

坑： 别把「这张图的 S/B 接 VDD」记成 NMOS 通用接法。标准逻辑：NMOS 的 B（及通常 S）接芯片最低电位 GND；PMOS 的 B（及通常 S）接 VDD。

笔记

应对大规模数字系统，本章给出关键方法论：

1.2.1 抽象 (Abstraction)

隐蔽当前层次不重要的物理细节。典型层次（由底向上）：

器件 → 模拟电路 → 数字电路 → 逻辑 → 微结构 → 体系结构 …

设计者可在某一层解题，而不必每次都沉到晶体管。

1.2.2 约束 (Discipline)

对设计选择做内在限制。例：数字电路把连续电压 约束 成离散区间 — 牺牲部分模拟灵活性，换来组合复杂度大降。

1.2.3 三大设计原则

原则 含义
层次化 Hierarchy 系统拆成更易理解的子模块
模块化 Modularity 明确功能与接口，连接时不产生意外副作用
规整化 Regularity 模块间求一致，便于复用同一类部件

HFT / 嵌入式直觉： 软件里的分层、API 边界、重复数据结构 — 同一套「管复杂度」思想。

档位: 浅读

状态

  • [x] 已读（口述巩固）
  • [x] 已写要点

笔记

逻辑门对二进制变量做最简单操作；符号、布尔式、真值表三位一体。

基础门

门 逻辑 作用
NOT 非门 取反 逻辑翻转
Buffer 缓冲 输出=输入 驱动放大 · 时序对齐（见下）
AND 与 全 1 才 1 合取
OR 或 有 1 则 1 析取

纸片逻辑（直觉）

约定：正面 = 1，反面 = 0。

门 纸片怎么玩
非门 一张纸片翻面：正进 → 反出（1→0）；反进 → 正出（0→1）
缓冲门 把薄纸加厚：正进仍正、反进仍反（1→1、0→0），只是更扎实、能传更远
与门 两张叠着：两张都正面才露出 1；任一张是反面就把输出挡成 0
或门 只要有一张正面朝上就是 1；两张都反面才是 0

为什么缓冲门要单列为基础门

真值表上看「进出一样」，容易误以为没用。工程上它是刚需：

用途 做什么
驱动能力放大 弱信号增强，去带更多负载（扇出、长线、重电容）
时序对齐 可控延迟，让各路信号同步到达，减时序偏差
隔离 / 整形 把前级与后级负载隔开，减轻信号衰减与畸变

→ 解决的是 信号衰减 与 时序偏差，不是改逻辑值。
→ 与 三态缓冲（可出 Z，见 2.6）不同：普通缓冲始终驱动 0/1；三态多一个使能，用于总线。

缓冲门真值表（多数教材表不画它，这里补上）：

A Out
0 0
1 1

符号与真值表速查

参考图（七种逻辑门；不含 Buffer）：

门 输出记法 一句话
AND AB 全 1 才 1
OR A+B 有 1 则 1
NOT A̅ 取反
NAND (AB)̅ AND 再非；万能门，芯片里极常见
NOR (A+B)̅ OR 再非；同样是 万能门
XOR A⊕B 相异为 1
XNOR (A⊕B)̅ 相同为 1（相等比较常用）

另有 多输入（≥3）与/或/与非等。

万能门 + CMOS 原生三件套（纠用词）

逻辑层： 只用 非门 拼不出全部逻辑。
NAND / NOR 各是一套 万能（功能完备）门：无数个同种门即可拼出非、与、或、异或……一切组合逻辑。

CMOS 硬件层（原生易做、功耗优）：

✅ 原生 ❌ 不直接原生
NOT 反相器 AND 与门
NAND 与非 OR 或门
NOR 或非

做法：AND = NAND+NOT；OR = NOR+NOT。晶体管细节 → 1.7 索引（分册 a–h）。

为何几乎不「原生与门」？
静态 CMOS 互补网络天然先做出带一次取反的门（NOT/NAND/NOR）。要 AND/OR 必须再加一级反相器 → 多一级延迟、多一对管子。故芯片里优先 NAND/NOR，需要与/或再局部加非。

嵌入式日常：两层需求（不必时刻全画与非）

层 做什么 用什么门
① 日常设计 / 可读性 画外设控制逻辑图、写驱动里的位判断、讲清功能 直接用 与 / 或 / 非 / 异或 —— 直观、协作不易错
② 底层认知 / 优化时 懂 CMOS 标准单元效率；压延迟、面积、功耗 记得 原生高效是与非、或非；与/或 = 与非/或非 再加一级非

口诀： 画图写逻辑用基础门保可读；要榨硬件效率时再 德摩根 / 推气泡 转成与非、或非网（→ 2.5）。

❌ ✅
日常原理图强制全改成与非，反而难读 功能层用 AND/OR；综合/手册/时序紧时才想 NAND/NOR
以为 C 驱动里的 \| & 也要「改成与非」 软件位运算在 CPU 指令上跑，不是在画 CMOS 门；② 针对 门级硬件 / ASIC 单元库
「FPGA 一定改成与非就省 LUT」 FPGA 映射到 LUT，不按晶体管串并联计费；极性变换有时有用，但 ≠ CMOS 那套「NAND 天生少一级」故事原样搬

对你路线：Linux/驱动 —— ① 为主、② 要懂；盯关键路径或读综合网表时才认真用 ②。

三门晶体管对照（已有图，并排看）： 反相器 · NAND · NOR —— 口诀仍是 NAND：P并N串；NOR：P串N并。

CMOS 门拓扑速记（2 输入，看懂即止）

反相器（看懂这张就够）：

PMOS（上） NMOS（下）
源 S → VDD → GND
漏 D 与下管漏相连 → Out 同上
栅 G 与下管栅并联 ← In（版图里常是一根多晶硅竖条） 同上

P 在 N-well；N 在 P 衬底。In=0→Out=1；In=1→Out=0 → 原生 NOT。

两层「非门」别混（必钉）：

CMOS 反相器 与非门两输入短接
层级 晶体管硬件 逻辑门拼装
做法 1P+1N，栅并、漏并 /(A·A)=/A
场景 芯片标准单元原生非 实验/只用 NAND 万能时

版图只认到「共栅多晶 + 共漏金属出 Out」即可，不背 lambda 设计规则。

门 Y 上拉 PMOS 下拉 NMOS 何时 Y=0
NAND /(A·B) 并联 串联 仅 A=B=1
NOR /(A+B) 串联 并联 A=1 或 B=1

口诀：NAND = P 并 N 串；NOR = P 串 N 并（与非/或非对偶）。
真值：NAND 仅 11→0，其余→1；NOR 仅 00→1，其余→0。

NAND（对照图）： Y=/AB

上 Q1/Q2（P）并联→VDD；下 Q3/Q4（N）串联→GND。仅 A=B=1 时下拉通路通 → Y=0；任一为 0 则有 P 通 → Y=1。

NOR（对照图）： Y=/(A+B)

上 Q1/Q2（P）串联→VDD；下 Q3/Q4（N）并联→GND。A 或 B 为 1 → 有 N 通 → Y=0；仅 A=B=0 时两 P 全通 → Y=1。

两图合看：拓扑对偶——NAND 的并/串，到 NOR 刚好对调。每门都是 4 管；A/B 各驱一对互补管（一上一下）。

同片上 N/P 管怎么长在硅里（P-sub + N-well 剖面）→ 1.7c 四图对照（看懂结构即可，不钻工艺）。

NAND / NOR 万能变换（保存）

方案 1 · NAND（CMOS 最常用）：

想要 接法
NOT A NAND(A, A)
A AND B NOT( NAND(A,B) )
A OR B NAND( NOT A, NOT B )
A XOR B NAND( NAND(A,T), NAND(B,T) )，其中 T=NAND(A,B)

即：A⊕ B=NAND(NAND(A,NAND(A,B)), NAND(B,NAND(A,B)))（标准 4×NAND 异或）。

四门钉死（N1–N4）：
T=/AB（N1）→ X=/(A·T)（N2）、Y=/(B·T)（N3）→ Out=/(X·Y)（N4）。

正确一行式（括号别丢）：

A⊕B = /[ /(A·T) · /(B·T) ] 其中 T=/AB

也就是 Out = NAND( NAND(A,T), NAND(B,T) )。

纠口述： 写成 /(A·T·B·T)（少了 A·T、B·T 各自外面的非）就错了。
另：若把「或再整体非」写成同或结构 → XNOR，不是 XOR。

例 A=1,B=0：T=1，X=0，Y=1，Out=1 ✔

全与非半加器（XOR + AND 全用 NAND）

半加：S=A⊕ B，C=AB。

输出 接法 门数
S 上节 4×NAND 异或 4
C T=/AB 再非：C=/T 可与 XOR 的 N1 共用 T，再 1 门：C=NAND(T,T) 
A ──┬──► N1 ── T=NAND(A,B)
B ──┘      │
           ├─► N2(A,T) ─┐
           ├─► N3(B,T) ─┴─► N4 ──► S = A⊕B
           └─► N5(T,T) ──────────► C = AB

共 5 个 2 输入与非（共享 T）。不共享则 AND 另用 2 门、XOR 4 门=6。
→ CMOS 里半加器底层就是这类 NAND 网；全加器再堆两套 + 进位或（或也拆成 NAND）。

图解（纯 NAND 万能）：

和组合模块的衔接

  • 工业优先 NAND/NOR：原生、管少；AND/OR = 再加一级非。
  • 74HC138 内部主要是与非阵列；MUX 常化为与或 / 与非等价网 → 2.8.3。

笔记

纯粹的「0 和 1」在现实里用 连续模拟电压 表示。

逻辑电平与噪声容限

  • 某电压范围识别为逻辑 0 (LOW) 或 1 (HIGH)
  • 驱动端与接收端识别区间之间留余量 → 噪声容限：允许一定干扰仍不判错

静态约束

每个电路元件在给定 有效 逻辑输入时，必须产出 有效 逻辑输出，避免电压落入无法预测的 禁止区域。

软件侧一句话： 「位」可靠，是因为硬件把模拟世界 约束 进了数字区间（呼应 1.2 Discipline）。
