笔记

课程核心目标： 学习基于 0 和 1 的数字系统设计，并最终结合汇编语言构造一个能执行程序的 微处理器。

笔记

应对大规模数字系统，本章给出关键方法论：

1.2.1 抽象 (Abstraction)

隐蔽当前层次不重要的物理细节。典型层次（由底向上）：

器件 → 模拟电路 → 数字电路 → 逻辑 → 微结构 → 体系结构 …

设计者可在某一层解题，而不必每次都沉到晶体管。

1.2.2 约束 (Discipline)

对设计选择做内在限制。例：数字电路把连续电压 约束 成离散区间 — 牺牲部分模拟灵活性，换来组合复杂度大降。

1.2.3 三大设计原则

原则 含义
层次化 Hierarchy 系统拆成更易理解的子模块
模块化 Modularity 明确功能与接口，连接时不产生意外副作用
规整化 Regularity 模块间求一致，便于复用同一类部件

HFT / 嵌入式直觉： 软件里的分层、API 边界、重复数据结构 — 同一套「管复杂度」思想。

状态

  • [x] 已读（口述巩固）
  • [x] 已写要点

笔记

逻辑门对二进制变量做最简单操作；符号、布尔式、真值表三位一体。

基础门

门 逻辑 作用
NOT 非门 取反 逻辑翻转
Buffer 缓冲 输出=输入 驱动放大 · 时序对齐（见下）
AND 与 全 1 才 1 合取
OR 或 有 1 则 1 析取

纸片逻辑（直觉）

约定：正面 = 1，反面 = 0。

门 纸片怎么玩
非门 一张纸片翻面：正进 → 反出（1→0）；反进 → 正出（0→1）
缓冲门 把薄纸加厚：正进仍正、反进仍反（1→1、0→0），只是更扎实、能传更远
与门 两张叠着：两张都正面才露出 1；任一张是反面就把输出挡成 0
或门 只要有一张正面朝上就是 1；两张都反面才是 0

为什么缓冲门要单列为基础门

真值表上看「进出一样」，容易误以为没用。工程上它是刚需：

用途 做什么
驱动能力放大 弱信号增强，去带更多负载（扇出、长线、重电容）
时序对齐 可控延迟，让各路信号同步到达，减时序偏差
隔离 / 整形 把前级与后级负载隔开，减轻信号衰减与畸变

→ 解决的是 信号衰减 与 时序偏差，不是改逻辑值。
→ 与 三态缓冲（可出 Z，见 2.6）不同：普通缓冲始终驱动 0/1；三态多一个使能，用于总线。

缓冲门真值表（多数教材表不画它，这里补上）：

A Out
0 0
1 1

符号与真值表速查

参考图（七种逻辑门；不含 Buffer）：

门 输出记法 一句话
AND AB 全 1 才 1
OR A+B 有 1 则 1
NOT A̅ 取反
NAND (AB)̅ AND 再非；万能门，芯片里极常见
NOR (A+B)̅ OR 再非；同样是 万能门
XOR A⊕B 相异为 1
XNOR (A⊕B)̅ 相同为 1（相等比较常用）

另有 多输入（≥3）与/或/与非等。

万能门 + CMOS 原生三件套（纠用词）

逻辑层： 只用 非门 拼不出全部逻辑。
NAND / NOR 各是一套 万能（功能完备）门：无数个同种门即可拼出非、与、或、异或……一切组合逻辑。

CMOS 硬件层（原生易做、功耗优）：

✅ 原生 ❌ 不直接原生
NOT 反相器 AND 与门
NAND 与非 OR 或门
NOR 或非

做法：AND = NAND+NOT；OR = NOR+NOT。晶体管细节 → 1.7 索引（分册 a–h）。

为何几乎不「原生与门」？
静态 CMOS 互补网络天然先做出带一次取反的门（NOT/NAND/NOR）。要 AND/OR 必须再加一级反相器 → 多一级延迟、多一对管子。故芯片里优先 NAND/NOR，需要与/或再局部加非。

嵌入式日常：两层需求（不必时刻全画与非）

层 做什么 用什么门
① 日常设计 / 可读性 画外设控制逻辑图、写驱动里的位判断、讲清功能 直接用 与 / 或 / 非 / 异或 —— 直观、协作不易错
② 底层认知 / 优化时 懂 CMOS 标准单元效率；压延迟、面积、功耗 记得 原生高效是与非、或非；与/或 = 与非/或非 再加一级非

口诀： 画图写逻辑用基础门保可读；要榨硬件效率时再 德摩根 / 推气泡 转成与非、或非网（→ 2.5）。

❌ ✅
日常原理图强制全改成与非，反而难读 功能层用 AND/OR；综合/手册/时序紧时才想 NAND/NOR
以为 C 驱动里的 \| & 也要「改成与非」 软件位运算在 CPU 指令上跑，不是在画 CMOS 门；② 针对 门级硬件 / ASIC 单元库
「FPGA 一定改成与非就省 LUT」 FPGA 映射到 LUT，不按晶体管串并联计费；极性变换有时有用，但 ≠ CMOS 那套「NAND 天生少一级」故事原样搬

对你路线：Linux/驱动 —— ① 为主、② 要懂；盯关键路径或读综合网表时才认真用 ②。

CMOS 门拓扑速记（2 输入，看懂即止）

反相器（看懂这张就够）：

PMOS（上） NMOS（下）
源 S → VDD → GND
漏 D 与下管漏相连 → Out 同上
栅 G 与下管栅并联 ← In（版图里常是一根多晶硅竖条） 同上

P 在 N-well；N 在 P 衬底。In=0→Out=1；In=1→Out=0 → 原生 NOT。

两层「非门」别混（必钉）：

CMOS 反相器 与非门两输入短接
层级 晶体管硬件 逻辑门拼装
做法 1P+1N，栅并、漏并 /(A·A)=/A
场景 芯片标准单元原生非 实验/只用 NAND 万能时

版图只认到「共栅多晶 + 共漏金属出 Out」即可，不背 lambda 设计规则。

门 Y 上拉 PMOS 下拉 NMOS 何时 Y=0
NAND /(A·B) 并联 串联 仅 A=B=1
NOR /(A+B) 串联 并联 A=1 或 B=1

口诀：NAND = P 并 N 串；NOR = P 串 N 并（与非/或非对偶）。
真值：NAND 仅 11→0，其余→1；NOR 仅 00→1，其余→0。

NAND（对照图）： Y=/AB

上 Q1/Q2（P）并联→VDD；下 Q3/Q4（N）串联→GND。仅 A=B=1 时下拉通路通 → Y=0；任一为 0 则有 P 通 → Y=1。

NOR（对照图）： Y=/(A+B)

上 Q1/Q2（P）串联→VDD；下 Q3/Q4（N）并联→GND。A 或 B 为 1 → 有 N 通 → Y=0；仅 A=B=0 时两 P 全通 → Y=1。

两图合看：拓扑对偶——NAND 的并/串，到 NOR 刚好对调。每门都是 4 管；A/B 各驱一对互补管（一上一下）。

同片上 N/P 管怎么长在硅里（P-sub + N-well 剖面）→ 1.7c 四图对照（看懂结构即可，不钻工艺）。

NAND / NOR 万能变换（保存）

方案 1 · NAND（CMOS 最常用）：

想要 接法
NOT A NAND(A, A)
A AND B NOT( NAND(A,B) )
A OR B NAND( NOT A, NOT B )
A XOR B NAND( NAND(A,T), NAND(B,T) )，其中 T=NAND(A,B)

即：A⊕ B=NAND(NAND(A,NAND(A,B)), NAND(B,NAND(A,B)))（标准 4×NAND 异或）。

四门钉死（N1–N4）：
T=/AB（N1）→ X=/(A·T)（N2）、Y=/(B·T)（N3）→ Out=/(X·Y)（N4）。

正确一行式（括号别丢）：

A⊕B = /[ /(A·T) · /(B·T) ] 其中 T=/AB

也就是 Out = NAND( NAND(A,T), NAND(B,T) )。

纠口述： 写成 /(A·T·B·T)（少了 A·T、B·T 各自外面的非）就错了。
另：若把「或再整体非」写成同或结构 → XNOR，不是 XOR。

例 A=1,B=0：T=1，X=0，Y=1，Out=1 ✔

全与非半加器（XOR + AND 全用 NAND）

半加：S=A⊕ B，C=AB。

输出 接法 门数
S 上节 4×NAND 异或 4
C T=/AB 再非：C=/T 可与 XOR 的 N1 共用 T，再 1 门：C=NAND(T,T) 
A ──┬──► N1 ── T=NAND(A,B)
B ──┘      │
           ├─► N2(A,T) ─┐
           ├─► N3(B,T) ─┴─► N4 ──► S = A⊕B
           └─► N5(T,T) ──────────► C = AB

共 5 个 2 输入与非（共享 T）。不共享则 AND 另用 2 门、XOR 4 门=6。
→ CMOS 里半加器底层就是这类 NAND 网；全加器再堆两套 + 进位或（或也拆成 NAND）。

图解（纯 NAND 万能）：

AND = NAND + 再非：F=AB=//AB

OR = 先各自非再 NAND（德摩根）：F=A+B=//A·/B

XOR = 4×NAND（与上表同一拓扑）：

Y=A⊕ B=//A·/AB·/B·/AB（图中公式；中间共享 T=/AB）。

方案 2 · NOR：

想要 接法
NOT A NOR(A, A)
A OR B NOT( NOR(A,B) )
A AND B NOR( NOT A, NOT B )

和组合模块的衔接

  • 工业优先 NAND/NOR：原生、管少；AND/OR = 再加一级非。
  • 74HC138 内部主要是与非阵列；MUX 常化为与或 / 与非等价网 → 2.8.3。
  • 异或是全加器核心；门级用上表即可，不必先背整份 CMOS 异或晶体管图（需要时再开 1.7e / 2.8.5 加法器）。

笔记

纯粹的「0 和 1」在现实里用 连续模拟电压 表示。

逻辑电平与噪声容限

  • 某电压范围识别为逻辑 0 (LOW) 或 1 (HIGH)
  • 驱动端与接收端识别区间之间留余量 → 噪声容限：允许一定干扰仍不判错

静态约束

每个电路元件在给定 有效 逻辑输入时，必须产出 有效 逻辑输出，避免电压落入无法预测的 禁止区域。

软件侧一句话： 「位」可靠，是因为硬件把模拟世界 约束 进了数字区间（呼应 1.2 Discipline）。

1b. CMOS ≠ 新型单管，=「互补架构」（钉死）

结论： CMOS = Complementary MOS 电路架构 / 布线规范，不是「只要同时有一只 P 和一只 N」。

硬性规则（静态互补逻辑）
1. 互补配对 上拉 PUN（PMOS→VDD） + 下拉 PDN（NMOS→GND）；功能对偶
2. 互斥（稳态） 任意合法输入：PUN、PDN 恰一通——通上则断下，通下则断上

→ 稳态无 VDD↔GND 直通 → 静态功耗≈0（现代 CPU 用 CMOS 的原因之一）。

❌ ✅
1P+1N 随便摆 = CMOS 接线须满足互补 + 稳态互斥，否则只是 MOS 混接
CMOS = 专指反相器 反相器是最简例；NAND/NOR 等同架构扩展

是 CMOS： 反相器；2 输入 NAND（P 并 N 串）；2 输入 NOR（P 串 N 并）→ 1.5。
不是 CMOS： 纯 NMOS+电阻上拉；PUN/PDN 非对偶导致稳态双通。
精度： 翻转瞬间可有短暂双通（动态功耗）；三态故意双断出高阻 ≠ 稳态组合输出浮空。

词 是什么
NMOS / PMOS 单个晶体管；物理 4 极 G/S/D/B，数字单元对外常只见 G/S/D（B 内接轨）
CMOS Complementary MOS：架构；按规则使用 PUN+PDN

2. 「互补」是什么意思？

同一输入下，两管永远 一个开、一个关，稳态不同时导通。

最简单单元：CMOS 反相器（非门）

        VDD
         │
       [PMOS]  ← 上管
         │
    ─────┼───── 输出
         │
       [NMOS]  ← 下管
         │
        GND

输入同时接两管栅极
输入 NMOS PMOS 输出
高 导通 截止 拉到 0（地）
低 截止 导通 拉到 1（VDD）

→ nMOS 擅长拉 0；pMOS 擅长拉 1 —— 和 1.5 的非门对应。

反相器里两个核心问题

问题 1：VDS 在哪里？（A=高 / A=低 细算）

标准结构：

        VDD
         │
      Sₚ PMOS Dₚ ──── OUT
    Gₚ ─┬
        │
    Gₙ ─┴
      Dₙ NMOS Sₙ
         │
        GND

输入 A 接 (G_p)、(G_n)。

PMOS（上） NMOS（下）
源极 Sₚ → VDD Sₙ → GND（0V）
漏极 Dₚ → Out Dₙ → Out
栅极 Gₚ ← A Gₙ ← A

每一只 MOS 各自有自己的 VDS；Out = 两漏公共点。统一：(V_{DS}=V_D-V_S)。

管子 VDS
NMOS (V_{DS(n)}=V_{Out}-0=\mathbf{V_{Out}})
PMOS (V_{DS(p)}=V_{Out}-V_{DD})（多为负；习惯也可看 (V_{SD})）

工况：A ≈ VDD（高）

电位 结论
NMOS (V_{Gn}=VDD)，(V_{Sn}=0) → (V_{GSn}=VDD>V_{th}) ✅ 导通
PMOS (V_{Gp}=VDD)，(V_{Sp}=VDD) → (V_{SGp}=0) ❌ 截止

状态演变（看 (V_{DS(n)})）：

时刻 OUT (V_{DS(n)}=V_{OUT})
刚切换瞬间 仍约 VDD (\approx VDD)
稳态（NMOS 拉低后） (\approx 0) (\boldsymbol{\approx 0})

此时截止的 PMOS：(V_{DS(p)}=V_{OUT}-V_{DD})，稳态 ≈ (-VDD)。

工况：A ≈ 0V（低）

电位 结论
NMOS (V_{GSn}=0-0=0<V_{th}) ❌ 截止
PMOS (S_p=VDD)，(G_p=0) → (V_{SGp}=VDD>|V_{thp}|) ✅ 导通

OUT 经导通的 PMOS 连通 VDD → 稳态 (\boldsymbol{OUT\approx VDD})。

管子 稳态 (V_{DS})
PMOS（通） (V_{DS(p)}=V_{OUT}-V_{Sp}=VDD-VDD\approx\mathbf{0})
NMOS（断） (V_{DS(n)}=V_{OUT}-0\approx\mathbf{VDD})

（翻转瞬态：OUT 仍低时 (V_{DS(p)}\approx -VDD)，随后被拉高到 0。）

口诀（非门）

输入 谁开 输出
低 PMOS 开、NMOS 关 拉高到 VDD
高 NMOS 开、PMOS 关 拉低到 GND

→ 这就是反相（非门）逻辑。

易混：

  1. 不要以为两管共用一套 VDS —— 必须分算 (V_{DS(n)})、(V_{DS(p)})
  2. 教材有时用 (V_{SD}) 说 PMOS；严格定义仍是 (V_{DS}=V_D-V_S)
  3. 导通管稳态 (V_{DS}\approx 0)（输出已被拉到源极电位）；大 (V_{DS}) 只在翻转瞬态

问题 2：输入 A 同时驱动两栅，为什么天然是「非」？

规则回顾：

管 导通直觉（增强型） 本反相器里
NMOS 栅比源够高（(V_{GS}>V_{thn})） Sₙ=0；A=高 → (V_{GSn}=A-0) 够大 → 开
PMOS 源比栅够高（(V_{SG}>|V_{thp}|)） Sₚ=VDD；A=高 → (V_{SG}=VDD-A≈0) → 关
输入 A NMOS PMOS Out
高（≈VDD） 导通 截止 经 NMOS 拉到 GND → 低
低（≈0） 截止（(V_{GSn}=0)） 导通（(V_{SG}=VDD)） 经 PMOS 拉到 VDD → 高

👉 输入高→输出低；输入低→输出高 = 非门。
不是外面又加了一级非门，是 NMOS/PMOS 导通特性天然互补 实现取反。

稳态永远一通一断 → 几乎没有 VDD 直通 GND 的电流 → CMOS 省电根源。
（翻转瞬间两管可能短暂同时通 → 贯通电流，需要时再开一小节。）

2b. 从非门到与/或：CMOS 天生是「反相逻辑」

根基（不能错）： 标准静态 CMOS 没有原生不带反相的与门、或门。
基础单元 = 反相器；多管串并联得到的是 与非 / 或非（输出已带一次非）；要与/或 = 再加一级反相器。

名词先拆开（卡住的根源）：
CMOS 不是零件名！ = Complementary MOS 架构：PUN(PMOS)+PDN(NMOS)，任意输入上下 互斥。
- 1N+1P 反相器 → CMOS 电路
- 2N+2P 与非 (\overline{AB}) → 同样是标准 CMOS 电路（同架构扩展，不是「模仿反相器」）

❌ CMOS ≠「特指 1N+1P 反相器」；其他多管门不是「只借鉴思路」。
✅ 反相器 = CMOS 最小特例；与非/或非/复杂组合门 = 同一大家族成员。
类比：矩形是四边形最简特例；不能说只有正方形才算四边形、长方形只是模仿。

才叫「借鉴但不算标准静态 CMOS」的： 伪 NMOS、动态逻辑（上拉不是对偶网络，如单只恒导通 P 负载）。
标准静态铁律：PDN 里每个 N，在 PUN 里有 同信号控制的配对 P（与非：A 驱 N(A)+P(A)，B 驱 N(B)+P(B)）。

逻辑功能对照 → 1.5 逻辑门。

−1. CMOS 通用范式：PUN + PDN（所有静态门共用）

铁律（固定不变）：

PDN（下拉） 全 NMOS GND ↔ 输出 拉到 0

硬约束（任意输入）： PUN 通 ⇔ PDN 断；PDN 通 ⇔ PUN 断。
→ 输出永不浮空、无静态直通。

纠死记误区： ❌「上拉一定串联、下拉一定并联」
✅ 串/并 按逻辑选，PUN 与 PDN 对偶；与非 / 或非 刚好相反。

根源德摩根：(\overline{AB}=\overline{A}+\overline{B})，(\overline{A+B}=\overline{A}\cdot\overline{B})。
PDN 实现「何时拉 0」，PUN 实现其对偶「何时拉 1」→ 天然互补、不同时通。

物理直觉：N 栅高才通 →「全高才通」用串、「有一高就通」用并；P 栅低才通 → 逻辑反过来。
PDN 通 → F=0；否则 PUN 通 → F=1；输出自带一次非 → 原生易做与非/或非。

反相器：PUN=1P，PDN=1N，输入 A 同控两管 → (F=\overline{A})。
与非门：仍是 一套 PUN+PDN（4 管），只是网络变复杂——不是两个 1N+1P 拼起来。

为何能从 2 管扩到 4 管？
CMOS 不是只能做非门。「1N+1P」= 最简实例；架构允许用串/并联自由搭 PUN/PDN，只要互斥对偶成立。

PDN 串联（与）→ 整体 (\overline{\text{与}}) = 与非；PDN 并联（或）→ 或非。
输出自带一次非（PDN 通就把节点拉到 0）。

别混：单门一套网 vs 多门多套网

例子 PUN/PDN
① 单一 CMOS 门（一个输出） (\overline{A+B+C})、(\overline{ABC}) 仅一组 PUN + 一组 PDN
② 多门拼接 (F=\overline{A+B}+\overline{C}) 不能一套搞定；每级独立门 各有 一套上下网（如或非、非、再或……）
③ 复合 CMOS 门（拓展） (F=\overline{AB+CD}) 仍 一个 输出、一套 PUN/PDN；网内更复杂（如 PDN：两组 N 串再并；PUN：对偶）

分层规则：

  1. 单输出静态 CMOS 单元 → 必有 P 上拉网 + N 下拉网
  2. 输入变多 → 只加管、改串并，框架不变
  3. 若式子整理不成单一 (\overline{(\dots)}) → 通常拆成多门，每门一套 PUN+PDN
  4. CMOS 天然适合「整体取反」函数（PDN 通 = 一次天然反相）

一句话： 标准静态 CMOS 单元永远有上下两套网；输入多只改网内拓扑；逻辑太复杂就拆门——每个门各自一套上拉/下拉。

门如何级联：前级输出 → 后级栅极

核心理解： 前一级的 输出节点，经金属线接到后一级 MOS 的 输入栅极。

  1. 前级 CMOS（自有 PUN+PDN）产生稳定 0/1
  2. 导线把该 电压 送到下一级栅极
  3. 下一级用栅压再控自己的 P/N 通断

例：与门 (AB=\overline{\overline{AB}})

[与非：Y=~(AB)] ──金属线──► [反相器栅极] → F=AB

两级 相互独立：各有一套 PUN+PDN；只有电压传递，不是两级源漏焊成一条通路。

为何能轻松级联？ 栅极下方有氧化层 → 绝缘、几乎不取电流。前级主要交电压电平，不必灌大电流驱动栅。
对比初高中：回路要持续电流；数字 CMOS 靠 电压电平 传信息，天然适于多级。

取反次数要数清： 每级 CMOS 门常自带一次反相潜力（与非/或非/非）。
(AB)：与非一次反相 + 反相器再反相 → 两次抵消得纯与。

多级例： (F=\overline{\overline{AB}\cdot\overline{CD}})
门1 出 (\overline{AB})、门2 出 (\overline{CD}) → 金属线分别进门3 两输入 → 出 F。各门独立，只靠导线传电平。

一句话： 各门独立（各一套上下网）；前门输出电压 → 后门栅极；栅极高阻 → 可多级组合。
考点： 不能无限制堆级——每级有负载与延时，须管 扇出、传输延迟（→ 2.9）。
逻辑跟踪： 全与非网里每级输出常带非；下一级以 线上真实式 为准 → 2.4.0b。

❌ 浮空 / 高阻 非法，既不是 0 也不是 1

推演：纯 PMOS「或」为什么假象能过、硬件不能用

两只 PMOS 并联、源接 VDD、漏共输出：
A=0 或 B=0 → 至少一管通 → 出 1；
A=B=1 → 两管全断 → 浮空。

若把浮空当 0，真值表「看起来」像 (\overline{A}+\overline{B})，但 硬件无法工作——下级认不出稳定 0。
布尔要求每组输入都有确定 0/1；纯 PMOS 做不到。
（若浮空真能当 0，全世界可只造 PMOS、不要 NMOS——现实没人这么做，原因就在此。）

伪 NMOS / 伪 PMOS 如何「补洞」

做法 代价
伪 PMOS P 做逻辑上拉网 + 1 个常导通 N 往 GND 拉 出 1 时仍有 VDD→地 直流电流
伪 NMOS N 做逻辑下拉网 + 1 个常导通 P 往 VDD 拉 出 0 时同样有直流功耗

→ 仍要 异类管子；不是纯单种 MOS；现代主流不用。

标准 CMOS 精妙处

网络 职责
PMOS 强拉 1
NMOS 强拉 0

任意输入：两套通路 互斥、恰一通 → 输出永远绑在 VDD 或 GND，永不浮空，无静态直通。
原生方便做 与非 / 或非 / 非；与/或 = 再加反相器。

通俗四条

  1. P 通 → 拉 1；P 断 → 只切断上拉，不创造 0
  2. N 通 → 拉 0；N 断 → 只切断下拉，不创造 1
  3. 要稳定 0 和 1 → 必须 上拉通路 + 下拉通路
  4. 只有单向通路 → 必现浮空 → 不能当正规逻辑门

一、基础功能：搭建全部数字逻辑

二、核心优势（相对老式纯 NMOS 等）

优势 含义
1. 静态功耗极低（最大亮点） 输入稳定时永远一管通、一管断；VDD→GND 无直流通路，几乎不耗电。老式纯 NMOS 静态持续耗电发热；CMOS 才能撑手机、手表等便携设备

4. 易大规模集成 同片做 N阱即可同时有 NMOS+PMOS，适合光刻批量、上亿晶体管处理器

（动态翻转仍有充放电与短暂贯通电流 → 1.8 功耗。）

4. 硅片上怎么做 CMOS：N阱工艺全流程

最重要一句： CMOS 不是一种晶体管，是「同一块硅片同时造出 NMOS + PMOS」；核心解法 = 在整块 P型衬底上局部改造出一块 N阱 放 PMOS。

收口定型（你现在理解正确）

  1. 基底原材料：整块 P-Sub（P型硅衬底）
  2. 离子注入+退火 → 局部一小块改造成 N型硅 = N阱（N-well）
  3. PMOS 制造在这块人工 N阱里面（N阱 = PMOS 需要的 N型衬底 / Body）

复习 PMOS 原生要求：Body=N；S/D=P+；P+↔N阱接触面 = PN结。

电位（防漏电）
外围原生 P衬底 → GND（给 NMOS）
内部人工 N阱 → VDD（给 PMOS）

→ 相关 PN结 永久反偏，不导通漏电。

┌────────────────────── 整片 P衬底 ──────────────────────┐
│  ← NMOS（直接长在 P 上）│ ████████ N阱（人工N硅）████ │
│  N+S        N+D         │ █ PMOS 做在阱内           █ │
│                         │ █ P+S          P+D       █ │
│                         │ ██████████████████████████ │
└────────────────────────────────────────────────────────┘

一句话： P衬底上造独立 N阱，N阱充当 PMOS 的 N型衬底；外面原生 P 做 NMOS → 同片两种基底 → 才能搭 CMOS。

易混补一句： N阱 只是一块 N型基底，N阱本身不是 PMOS。
还要在阱内注入 P+ 源漏 + 栅氧 + 多晶硅栅，才是完整 PMOS。
同理：外面 P衬底 ≠ NMOS，必须再注入 N+ 源漏才形成 NMOS。

N阱 vs 原生整片 N衬底（功能等价，物理不等同）

结论： 功能上 等价于 PMOS 需要的 N衬底；但 ≠「原生整块 N衬底晶圆」——是 局部人造、有限范围 的 N型区域。

相同（你最关心） 不同（不能划等号）
阱内晶格整体呈 N型（多子电子）→ 可当 PMOS 的 Body；满足 Body=N、S/D=P+ 原生 N晶圆：整片从头到尾全是 N；N阱：大 P衬底里 局部 改成 N，四周·底部被 P包围
阱 ↔ 外围 P → 天然一个 巨大 PN结

硬性规则（防这个大结正向漏电）：
✅ N阱 持续接芯片 最高电压 VDD
✅ 外层 P衬底 持续接 最低电压 GND

→ 阱–衬底 PN结始终 反偏，耗尽层隔离 → 电学上 N阱近似一块 独立 N衬底。

为何接 VDD/GND 就是反偏？（接 PN结零偏知识）
扩散后内建电场方向是 N→P（N正、P负）。N阱=高、P衬底=低 → 外加场与内建场 同向 → 反偏加宽耗尽层、隔离漏电。详见 补充_PN结 · 标准答案速记。

极简： 电学上充当 PMOS 的 N衬底；物理上只是被 P 包围的 局部 N型孤岛，不是独立整片 N晶圆。
外面大片 P = NMOS 天然 P衬底；内部孤岛 N阱 = PMOS 人造 N衬底 → 一块 P晶圆即可 CMOS。

同片无数管：反相器 vs 与非门，衬底规则一样

三句结论：

  1. 一块硅片上可做 无数 NMOS、PMOS。
  2. 标准 CMOS：N 与 P 不能共用同一导电类型衬底 —— N 在 P-sub，P 必须在 N阱。
  3. 反相器（1N+1P）、二输入与非（2N+2P）遵守 同一套版图规则；同门内多管共衬底/共阱，差别在数量与金属串并联。
谁 放哪 共享范围
NMOS 整片 P-sub 全芯片 N 都在这片基底上（有源区隔离，电气独立）
同门内 PMOS 一块 N阱 ✅ 同单元多只 P 共阱（省面积）
不同门的 PMOS 各自 N阱 ❌ 不把多门 P 塞进同一大阱（标准单元约定）
❌ PMOS 直接做在 P-sub 上 禁止

偏置： P-sub→GND；每一块 N阱→VDD。

门 P-sub 上 该门专属 N阱内 金属连线
反相器 1×NMOS 1×PMOS 两漏共输出、两栅共输入
2 输入与非 2×NMOS（串联） 2×PMOS（并联） 串/并路径不同，阱规则不变

门间：一单元一阱（版图铁律）

例 (F=\overline{\overline{AB}\cdot\overline{CD}}) → 3 个独立与非门：

单元 P-sub N阱
门1 (\overline{AB}) 2 N 阱①：2 P
门2 (\overline{CD}) 2 N 阱②：2 P（另一孤岛）
门3 (\overline{Y_1 Y_2}) 2 N 阱③：2 P

底层 P-sub 连通；三块 N阱是互相隔离的孤岛。
标准单元库： 一个标准单元 = 一个逻辑门 = 自带专属 N阱；单元间物理隔离，减串扰/噪声/时序偏差。

拓展：布局上偶见相关门合并阱，但 数字标准单元库不会这么做；基础学习记住 一单元一阱。

别混：

概念
硅衬底 / 晶圆 整片底层共用的 P-sub；所有 NMOS 建在其上
N阱 局部隔离区；一门一阱（同门多 P 共阱；异门分阱）

一句话： 同门所有 PMOS → 共一块 N阱；不同逻辑门 → 独立、隔离的不同 N阱；所有 NMOS 在同一 P-sub 上但有源区隔离。

架构 vs 工艺：别把两层焊死

但 CMOS ≠「全世界只有 P衬底+N阱」！

层 是什么 和工艺关系

❌ CMOS 架构 ≠ P-sub+N-well

  1. 硅片表面长一层 SiO₂
  2. 光刻+刻蚀，只打开要做 PMOS 的窗口
  3. 离子注入磷（N型杂质），高温退火向内扩散

步骤 2：器件隔离（场氧 / STI）

管与管之间隔开，防漏电、寄生管。
不做管的区域长厚 SiO₂（场氧）或挖沟槽填介质（STI），阻断寄生沟道；
只留 NMOS、PMOS 所在区域 = 有源区。

步骤 3：栅氧 + 多晶硅栅极 G

  1. 有源区高温生长极薄高质量 SiO₂（栅氧，绝缘，栅与硅隔开）
  2. 淀积多晶硅，光刻刻出栅线条 → 即 栅极 G

多晶硅栅充当 自对准掩膜：后面注源漏时，栅底下不被掺杂，自动留出沟道区。

① NMOS 区（P衬底上）
遮住 N阱，只开 NMOS 有源区；注入 砷（N型） → N+ 源、N+ 漏。
栅挡住离子 → 栅下仍是纯净 P（未来 N沟道）。

② PMOS 区（N阱内）
换掩膜遮住 NMOS；注入 硼（P型） → P+ 源、P+ 漏。
栅挡住离子 → 栅下仍是纯净 N（未来 P沟道）。

衬底 原生 P 人工 N阱
S/D N+ P+
栅 栅氧 + 多晶硅 同左

  1. 整片再覆绝缘 SiO₂
  2. 光刻接触孔，扎到 S/D、栅、衬底、N阱
  3. 淀积铝/铜，光刻出导线，按反相器接线：
连线
PMOS 源 → VDD NMOS 源 → GND
两漏短接 → OUT 两栅短接 → A
P衬底 → GND N阱 → VDD（防结正向漏电）

步骤 6：钝化保护

覆 SiO₂/氮化硅保护层，只露焊盘 → 晶圆完成，再切割封装。

NMOS 单管：N沟道，电子导电

CMOS 电路架构 / 体系：互补 MOS（PUN+PDN）；含反相器、与非、或非……不是「一种管子」也不是「专指非门」

C = Complementary；MOS = 金属氧化物半导体管；CMOS = 互补型 MOS 电路。

和单个 NMOS 笔记的衔接

单个管：VGS 造沟道、VDS 推电流、结锁反向、电流走表层。
CMOS：用 一对 管，同一栅信号下互补开关 → 组成非门/与非/或非 → 再堆成整个数字芯片。

和 Ch2 布尔设计的衔接： 纸上 A/B/C、F 是逻辑层；落到硅上时，输入布到各管 栅极，输出取自漏极 公共节点。完整「布尔→门→MOS」→ 2.4.6。

软件 / CSAPP / HFT 主线：记住 互补 + 低静态功耗 + 非门 +「P衬底放 N管 / N阱放 P管」+ 衬底接地、阱接 VDD；双阱/闩锁知概念即可。
