笔记

2.2.1 术语回顾

设 n 个变量 (A,B,C\cdots)：

最小项 (m_i) 最大项 (M_i)
形式 每个变量以原/反 恰好出现一次 的 与项 每个变量以原/反 恰好出现一次 的 或项
特点 只有一组 输入使它 = 1 只有一组 输入使它 = 0

另：变量的非；乘积项 / 蕴涵项（可少于全部变量）。

2.2.1b 为何已有最小项，还要发明最大项？

核心疑问：最小项已能挑出「令 F=1」的输入；为何还要最大项专门描述「令 F=0」？

最小项 (m_i) 最大项 (M_i)
本质 仅第 i 组输入令 (m_i=1)，其余全 0 仅第 i 组输入令 (M_i=0)，其余全 1
组函数 (F=\sum m_i)：挑出所有令 F=1 的项相加 (F=\prod M_i)：挑出所有令 F=0 的项相乘

理由 1：0 很少时，最大项写法极短

真值表 1 少、0 多 → 用 (\sum m) 舒服；
0 少、1 多 → 用 (\prod M) 更省事。

三变量，仅 110 使 F=0：

写法 式子
最小项 (F=\sum m(0,1,2,3,4,5,7))（7 项，啰嗦）
最大项 (F=\prod M(6))（一项）

再例：仅 ABC=111 使 F=0 → (\sum m(0..6)) vs (\prod M(7))，高下立判。

理由 2：直接通向「或与式」硬件

卡诺玩法 得到 电路骨架
圈 1（最小项） 最简 与或式 与门 → 或门
圈 0（最大项） 最简 或与式 或门 → 与门

两种结构门数、延时不一定一样；或门资源多 / 与门稀缺、或要 低电平有效 逻辑时，或与可能更合适。
→ 最大项体系 = 多一条硬件结构路径。

理由 3：取反 / 范式互转方便

(F=\sum m(S) \iff F=\prod M(\overline{S}))。
(\overline{F}) 的最小项集合 = F 的最大项下标集合 → 求反函数、SOP↔POS 切换快。

理由 4：低电平有效信号思维对齐

复位、片选等常 0=有效、1=无效；需求描述的是「哪些输入让输出变 0」。
用最大项建模，不必反复取反绕弯。

一句话对比

情况 优先
1 少 0 多 最小项 (\sum m)
0 少 1 多 最大项 (\prod M)

最小项主路径 → 与或电路；最大项另开路径 → 或与电路。

结构差异速记： 与或 = 先与后或（多条乘积项并起来）；或与 = 先或后与（多条和项叠与）。门型与级数不同，面积/延时/极性要选更省的那条。

2.2.2 最小项、最大项有什么用（核心）

一、标准表达式（范式）——最核心用途

任何逻辑函数都能写成：

范式 记法 结构
最小项之和（标准与或式 SOP） (F=\sum m(\dots)) 选中的最小项 相或
最大项之积（标准或与式 POS） (F=\prod M(\dots)) 选中的最大项 相与

作用：唯一表示一个逻辑函数。
普通与或式写法不唯一（可化简出多种形式）；范式唯一。
→ 判断两式是否相等：都展开成最小项列表，列表相同 = 同一函数。

例（二变量）：(F=A+B) → (\sum m(1,2,3))。
另一式若最小项集合也是 ({1,2,3})，功能完全相同。

二、真值表 ↔ 逻辑函数快速转换

真值表 写法
输出为 1 的输入组合 → 对应 最小项，相加得 (F=\sum m(\dots))
输出为 0 的输入组合 → 对应 最大项，相乘得 (F=\prod M(\dots))

做题最常用：给真值表，立刻写出标准逻辑式。

三、卡诺图化简的基础

卡诺图每个格子编号 = 最小项下标 i。
- 圈 1：合并最小项 → 最简 与或式
- 圈 0：合并最大项 → 最简 或与式

没有最小项编号体系，卡诺图无法规范使用。→ 2.7

四、互补关系（做题高频）

同一下标：(m_i=\overline{M_i})，(M_i=\overline{m_i})。

若 (F=\sum m(a,b,c))，则 (\overline{F}=\sum m(\text{其余项}))；
取反可得 (F=\prod M(\text{其余项}))。
→ 最小项和 ↔ 最大项积 快速互转。

五、工程意义

场景 作用
逻辑电路设计 标准式统一构造；最小项之和 ↔ 与门 + 或门
PLA / PROM / ROM ROM 译码产生全部 (m_i)，再选哪些相或 → 目标函数（输出 = 选中最小项之和）
多输出函数 用最小项清单找公共项，减门、共享逻辑

六、一句话

最小项、最大项 = 逻辑函数的「标准身份证」。
用途：真值表转式、判相等、卡诺化简、ROM/电路设计、SOP↔POS 互转。

2.2.3 与或式 (SOP) / 或与式 (POS)

  • SOP：真值表中为 1 的最小项 相或。
  • POS：真值表中为 0 的最大项 相与。

再交给 2.3 / 2.7 化简。

小例巩固（三变量）

真值表输出 1 出现在输入 001、011 → (F=\sum m(1,3))。

则 (\overline{F}=\sum m(0,2,4,5,6,7))，
且 (F=\prod M(0,2,4,5,6,7))。

2.2.4 对照例题：0 只一处时，最大项碾压

真值表（三变量）：仅 i=7（ABC=111） 时 F=0，其余全 1。

方式 写法 长短
最小项之和 (F=\sum m(0,1,2,3,4,5,6)) 7 项，很长
最大项之积 (F=\prod M(7)) 1 项

翻译 (M_7)： ABC=111；最大项规则 = 输入为 1 写反变量、为 0 写原变量
→ (M_7=\overline{A}+\overline{B}+\overline{C})，故 (F=\overline{A}+\overline{B}+\overline{C})。

验证：仅 A=B=C=1 时该或式 =0，其余 =1，与真值表一致。

硬件： (F=\overline{A}+\overline{B}+\overline{C}) 可用 一个三输入或门（或与特例）。
若硬写 7 个最小项 → 7 个三输入与门 + 大或门，成本天差地别。

反过来：1 只一处时，最小项更短

仅 i=2（ABC=010） 时 F=1，其余全 0：

方式 写法
最小项 (F=\sum m(2)=\overline{A}\,B\,\overline{C})（1 项）
最大项 (F=\prod M(0,1,3,4,5,6,7))（7 项）

⚠️ (m_2)：A=0,B=1,C=0 → (\overline{A}B\overline{C})，不是 (A\overline{B}C)（那是 (m_5)）。

核心再钉

真值表形态 优先
1 少、0 多 (\sum m)
0 少、1 多 (\prod M)

卡诺图 圈 0 走最大项 → 最简或与式，见 2.7 · 下文「最大项如何合并」。

2.2.5 最大项怎么合并？（与最小项对偶）

先钉定义（易错）

最小项 (m_i) 最大项 (M_i)
单独一项 仅一组输入使 (m_i=1) 仅一组输入使 (M_i=0)
组函数 (F=\sum m)：有一个 1 → 整体 1 (F=\prod M)：有一个 0 → 整体 0
❌ 不是「每个最大项都是 0」
✅ 任一 (M_i=0) → F=0；全部 (M_i=1) → F=1

最小项合并（对照）

相邻两项只差一个变量：(XY+X\overline{Y}=X)（因 (Y+\overline{Y}=1)）。
卡诺：圈 1。

例：(m_6=AB\overline{C})，(m_7=ABC) → (AB\overline{C}+ABC=AB)。

最大项合并（对偶）

最大项是 或项，整体 相与。依据：((X+Y)(X+\overline{Y})=X)。

相邻最大项只差一个变量 → 消去该变量。

标准字面量（A=MSB）： 输入为 1 写反、为 0 写原。

0 于 式子
(M_2) 010 (A+\overline{B}+C)
(M_3) 011 (A+\overline{B}+\overline{C})

$$ \begin{align} M_2\cdot M_3 &=(A+\overline{B}+C)(A+\overline{B}+\overline{C})\ &=(A+\overline{B})+(C\cdot\overline{C})\ &=A+\overline{B} \end{align} $$

⚠️ 若写成 (\overline{A}+B+\overline{C}) 当 (M_2)，在 010 上取值是 1 不是 0，编号就错了。

完整实例

仅 i=2、3 时 F=0 → (F=\prod M(2,3)=A+\overline{B})。

验证：(A+\overline{B}=0) ⟺ A=0 且 B=1 → 输入 010、011（与 C 无关），正好消去 C。

对偶对照表

项目 最小项（圈 1 → 与或） 最大项（圈 0 → 或与）
单元 与项 或项
运算 多项 相或 多项 相与
合并 (XY+X\overline{Y}=X) ((X+Y)(X+\overline{Y})=X)
卡诺 圈 1 圈 0
圈含义 圈内输入使 F=1 圈内输入使 F=0

思维方式 / 踩坑

  1. 圈 1：盯 F=1 → 合并最小项 → 最简 与或式
  2. 圈 0：盯 F=0 → 每块圈 = 一个合并后的 或项，块与块之间 相乘 → 最简 或与式

❌ 圈 0 得到的项 不能 直接相加
✅ 圈 0 每块是或项，块间是 与

极简： 最小项合并靠 (X+\overline{X}=1)；最大项合并靠 ((X+Y)(X+\overline{Y})=X) —— 对偶。
公式根源 = 2.3 布尔代数（分配 + 互补）；卡诺只是图形化同一套恒等变形。

布尔代数

Link Target: 2.2 最小项·最大项 · 2.7 卡诺图 · 德·摩根 → 2.5 推气泡
档位: 浅读

状态

  • [x] 已写要点
  • [x] 钉死：最小项/最大项/卡诺 = 布尔代数恒等变形

笔记

结论： 整套最小项、最大项、卡诺图化简，全部建立在布尔代数（逻辑代数）之上。

表达式常不是最简 → 用布尔代数化简，节省硬件成本。

2.3.0 知识链：布尔代数站在哪一层？

1. 布尔代数是什么

一套代数系统（课程里用 二值 版）：
取值 只有 0、1
基本运算 与(·)、或(+)、非
定律 交换、结合、分配、重叠、互补 (A+\overline{A}=1)、(A\cdot\overline{A}=0)、德摩根……

所有逻辑式运算、变换，遵守的规则 = 布尔代数公理。
广义布尔代数可不只两值；数电 / 数字逻辑全程只用二值。

2. 最小项 / 最大项的角色

它们是布尔代数里两种 特殊标准形式（不是另一套理论）：

形式 布尔运算
最小项 特殊与项 (F=\sum m_i) = 若干最小项 或（布尔加法）
最大项 特殊或项 (F=\prod M_i) = 若干最大项 与（布尔乘法）

细节 → 2.2。

3. 合并规则的根源 = 布尔代数

合并 公式 来源
最小项 (XY+X\overline{Y}=X) 分配律 + 互补律 (Y+\overline{Y}=1)
最大项 ((X+Y)(X+\overline{Y})=X) 分配律 + 互补律 (Y\cdot\overline{Y}=0)

不是凭空规定，是公理 直接推出。

4. 卡诺图本质

图形化工具，快速完成与代数化简 等价 的恒等变换；
圈 1 / 圈 0 底层仍是布尔代数。→ 2.7

5. 完整链路

真值表
  → 最小项之和 / 最大项之积（标准范式）
  → 布尔公式化简  或  卡诺图可视化化简（二者等价）
  → 最简布尔表达式
  → 画出逻辑门电路（SOP=与+或；POS=或+与）→ [2.4](./2.4_从逻辑到门.md)
  → 硬件实现（分立芯片 / FPGA）

6. 三者区分（别混）

概念 是什么
布尔代数 理论工具（公式、运算规则）
最小项 / 最大项 / 范式 布尔代数里的 标准表达形式
卡诺图 化简布尔式的 图形手段

一句话： 最小项、最大项互转、合并、卡诺化简，全部是在做 布尔代数的恒等变形。

2.3.1–2.3.3 公理与定理（要会用，不必全背）

单变量： 同一性、零元、重叠、回旋、互补等。

多变量： 交换律、结合律、分配律、吸收律、合并律；以及极重要的 德·摩根定理（推气泡 / NAND·NOR 实现的根基）。

2.3.4 统一证明：完全归纳法

用真值表 穷举 所有变量取值，证明布尔恒等式。

2.3.5 等式化简

逐步应用定理，压到 最少蕴涵项 的最小式（例题跟书走）。
与卡诺对照：同一函数，公式推一步 = 图上圈一步，结果应一致。

笔记

极简目标： 化简得到布尔式、画出逻辑图，最终是为了 构造数字硬件，严格实现想要的逻辑功能。

2.4.0 整条设计流水线（贴合 CMOS）

先钉两条化简路线（看你底层用什么门）：

路线 目标门阵列 化简到 再变换成
A（工业最常用） 与非门 最简 SOP（积之和） 德摩根 → 与非–与非
B 或非门 最简 POS（和之积） → 或非–或非

❌「和形式最好都转成乘积形式」——不准确。
✅ 优先最简 SOP，因大量用与非；若底层是或非阵列，则走最简 POS。
变换目的 = 匹配 CMOS 原生反相门，不是硬性规定和式必须变乘积式。

需求 → 真值表 / 原始布尔式
  → 卡诺/代数 → 最简 SOP 或 最简 POS（按路线选，勿盲目无限拆）
  → 德摩根适配 CMOS：原生只有 与非/或非/非（无原生与/或）
  → 门级网表（每门一套独立 CMOS：PUN+PDN）
  → 画逻辑图 → 版图·流片（连线固化）或 FPGA / 分立接线

例（路线 A）： F=AB+/A·C（SOP）
F=//(AB+/A·C)=/( /AB · /(/A·C) )
→ 与非–与非（可含反相得 /A）；每只与非/反相各一套 PUN+PDN，门间金属相连。

分支（进阶）： 若整理成单一 /(…)（如 /(AB+/A·C)），可用 单级复合 CMOS 门（一套 PUN+PDN）；课堂主学多门级联。→ 1.7

面包板可改线；普通 CMOS 芯片内部连线 出厂定死。对比 → 1.7 · 面包板 vs 硅片。

画图本质：把布尔表达式翻译成硬件电路。

2.4.1 两种表达式 → 两种电路（再接 CMOS）

路线 化简形态 纸上门骨架 CMOS 适配后
圈 1 最简 SOP 与门→或门 德摩根 → 与非阵列
圈 0 最简 POS 或门→与门 → 或非阵列

非门（反相器） 产生 /A 等；每个独立门 = 一套独立 CMOS（PUN+PDN）。

极简四步： ① 最简 SOP/POS → ② 按门库德摩根成单一类型级联 → ③ 每门一套 CMOS → ④ 原生带非，故必须做适配变换。

2.4.0b 全与非（或全或非）实现：必须逐级跟踪信号

采用 全与非门方案（工业主流） 时：
不能只盯原始式 F=AB+CD 直观脑补门；必须盯住每一级线上真实信号（带不带非），再决定下一级算什么。

例： F=AB+CD=/( /AB · /CD )

级 门 线上真实式 警示
1 与非 Y1=/AB，Y2=/CD 不是 AB、CD
2 与非 F=/(Y1·Y2) 输入是带非的 Y1、Y2

验算：/( /AB · /CD )=AB+CD ✓

工程思维：

  1. 整体转成与非–与非（或或非–或非）形式
  2. 从前往后标注每一根连线的布尔式
  3. 下一级输入 = 上一级输出式
  4. 用该输入式判断本级与非/或非最终逻辑

每级与非/或非都会 叠一次取反；取反是信号属性，不能视而不见。

❌ ✅
想要 AB+CD → 两与门进或门（CMOS 无原生与/或，须加反相） 先变全与非 → 跟踪 /AB、/CD → 再进下一级与非 → 还原目标

对偶（全或非）： F=(A+B)(C+D)=/( /(A+B) + /(C+D) )
第一级出 /(A+B)、/(C+D)，第二级再或非；不能把 /(A+B) 当 A+B 用。

一句话： 每根导线对应一条布尔项（常带非）；下一级输入 = 上一级 带非的输出，勿用原始无反式代替。

物理级联（输出→下一级栅）→ 1.7 · 门如何级联 · 2.5。

2.4.2 我们到底在设计什么？

现阶段主目标：组合逻辑

输出 仅由当前输入 决定（无记忆）。常见：

模块 用途
编码器 / 译码器 码制转换
多路选择器 MUX 选通一路
加法器（半加 / 全加） 算术核心

奇偶校验 检错
简单控制 报警、联锁等

通俗例：温度过高 或 门非法打开 → 报警响。
列真值表 → 布尔式 → 画逻辑门 → 可搭实物报警器。

进阶（Ch3 起）：时序逻辑

时序 = 组合逻辑 + 触发器（存储）。
触发器本身由门搭成；计数器、寄存器、CPU 运算单元底层大量仍靠组合块。→ Ch3

  • 输入在左/上，输出在右/下
  • 直线连接，避免乱线
  • 多输出： 真值表可共用；实现时 共享 公共门，少重复

2.4.6 再下一层：布尔变量 → 逻辑门 → MOS（物理实现）

✅ A、B、C = 输入信号，F = 输出信号（逻辑层没错）。
❌ 不能粗说「输入=栅极、输出=漏极」——要区分 单管 vs CMOS 门（N+P 成对）。

单管角色

极 作用
G 栅 控制端；布尔输入 最终接到各管栅极（栅几乎不流电流）
S / D 电流通路两端；通/断由栅电平决定

单独一只 MOS 不能稳定输出完整逻辑电平。 标准单元几乎都是 CMOS：PMOS + NMOS 配对。

例：CMOS 反相器 F=/A

管 S G D
PMOS VDD A 公共输出节点
NMOS GND A 公共输出节点
  • 输入 A → 两管栅极
  • 输出 F → 两管漏极短接的公共节点（不是「某一个管子单独的漏极」）

标准 CMOS 门（工业原生 NAND / NOR）

芯片里原生优先做 与非 / 或非（再加非得与/或）。拓扑 → 1.7 · 2b。

门 下 NMOS 上 PMOS
与非 /(A·B) 串联 并联
或非 /(A+B) 并联 串联

A、B 分接对应管栅；公共漏节点 = F。

标准静态 CMOS：某一个 k 输入门 → k 个 N + k 个 P；
❌ 不是「电路有几个全局输入就有几对管」。伪 NMOS / 动态例外 → 1.7 · §6。

两层翻译，禁止跳步

布尔式（A,B,C,D…）
  → 逻辑门网表（先化简；与/或 用德摩根 → 与非/或非/非）
  → 逐个门展开 CMOS 管（按该门的 k 计管子）
  → 外输入布线到各栅（可扇出）

例 F=AB+/C·D：外部仍 4 信号；转成若干 2 输入与非后，管子按 门的个数×每门 2N+2P 累加（可远多于 4 对），不是 4N+4P。

反例：名义 4 输入、电路只用 /(A+B) → 仅 2N+2P。

自上而下完整层级

  1. 功能需求
  2. 真值表 → 范式 → 布尔式 (A,B,C,F)
  3. 画逻辑门图（与/或/非）
  4. （可选）德摩根 → 与非/或非网表
  5. 每个门底层 = 若干 PMOS/NMOS
  6. 输入 A/B/C 布线到各管栅极 G（一输入可扇出到多管栅）
  7. 输出 F = 漏极互连节点

易踩误区

❌ ✅
输入 = 栅极 输入信号 被布线送到 各管栅极；一输入可接很多栅（扇出）
输出 = 某管漏极 输出 = 一组 MOS 漏极相连的公共节点
逻辑图 = 晶体管图 逻辑抽象层 ↔ 门电路翻译层 ↔ 晶体管物理层
全局 4 输入 ⇒ 4N+4P 管子数看 门清单；k 指 单门输入脚数

与布尔代数的接点

与/或/非运算 = 用 A/B/C 控制各管栅极通断，把节点 F 拉到 VDD(1) 或 GND(0)。

一句话： 逻辑输入驱动 MOS 栅极；逻辑输出取自漏极 互连节点；CMOS 是上下一对管协同，不是单管「栅入漏出」。

补钉： 不能只用 PMOS（或只用 NMOS）搭稳定与/或门——单一类型只能单向拉电平；关断后的浮空 ≠ 逻辑 0/1。必须 P 上拉网 + N 下拉网。→ 1.7 · §7

多级组合逻辑

Link Target: 2.3 德摩根 · 2.4 全与非跟踪 · 1.7 CMOS · 2.9 关键路径
档位: 浅读

  • [x] 推气泡步骤 + 全 NAND/NOR 落地
  • [x] 物理级联与线上带非跟踪

笔记

一句话： 最简 SOP/POS 常是 两级（与→或 / 或→与）；再 因式分解 / 共享中间项 可变成多级，门更少，但路径更长。CMOS 里再 推气泡 改成 NAND/NOR 网。

2.5.1 减少硬件：为何要多级？

两级（典型与或 / 或与） 多级
结构 一级与（或）+ 一级或（与） 中间再插门，可共享子式
优点 级数少 → 往往延迟可控 门数 / 输入脚总数 常更少
代价 大扇入或门、重复子式 级数↑ → 延迟↑（→ 2.9）

例：多输入异或

  • 硬做「纯两级」大 XOR：项爆炸、门极多
  • 工程：多个 2 输入 XOR 串联 / 树形 → 多级；硬件省，延迟 ≈ 树高 × 单级 tp

因式分解直觉（与代数同一套）：

两级 SOP（示意） 提出公因子后（多级）
F = A·B + A·C F = A·(B+C)
两与 + 一或；A 进两门 一或 + 一与；A 只进一门

圈出的最简 SOP 不等于 全局最少晶体管——还可再分解；但课堂/考试常先求最简两级，再问「能否多级优化」。

工程权衡：

面积（门数、布线）↓  ←多级→  延迟（级数、关键路径）↑

FPGA 里 LUT 深度、ASIC 里单元库选型，本质都在做这件事。
嵌入式日常：功能层仍可用与/或画图；转全与非/或非是优化层手段，不是写驱动时的强制画法 → 1.5 · 两层需求。

2.5.2 推气泡：把 AND/OR 网改成 NAND/NOR 网

CMOS 原生高效 的是 NAND / NOR / NOT（→ 1.5 · 1.7）。
纸上先画与/或再「推气泡」，比硬背德摩根公式更不容易画错。

气泡规则（德摩根的图形版）

操作 含义
门输出加气泡 该门变成「带非」版本（AND→NAND，OR→NOR）
气泡从输出推到所有输入 等价于把门类型 与↔或，气泡挪到输入脚
线上两气泡对消 //X = X，可擦掉一对

口诀：推过与/或门 → 门型翻转 + 气泡换边；同一根线两端各一气泡 → 消掉。

标准套路（SOP → 全与非）

目标：F = AB + CD（与或两级）

  1. 在 或门输出 加气泡又立刻再加一个（等价不变）：F = //(AB+CD)
  2. 把「外层非」推过或门 → 或变与、输入各带非：F = /( / (AB) · /(CD) )
  3. 内层的 /(AB)、/(CD) 正是 与非；外层又是与非 → 与非–与非

验算：/( /AB · /CD ) = AB + CD ✓（德摩根）

对偶（POS → 全或非）： F=(A+B)(C+D) → /( /(A+B) + /(C+D) )，两级或非。

必须逐级盯信号（别脑补）

全与非网里，第一级输出是 /AB、/CD，不是 AB、CD。
下一级输入 = 带非的线上式。细节钉死 → 2.4.0b。

❌ ✅
推完气泡仍按「AB、CD 进或门」想 每根线标真实式，再进下一级
以为多级 = 随便加门 每加一级都叠一次延迟 / 可能叠一次极性

与「多级少硬件」怎么叠

  1. 代数 / 卡诺 → 较简布尔式（可含因式分解）
  2. 画与/或逻辑图（可多级）
  3. 推气泡 → NAND/NOR（匹配 CMOS / 门库）
  4. 数级数、估关键路径 → 2.9

2.5.3 物理级联（CMOS）

前级门 输出节点 → 金属线 → 后级门 输入栅极；每级自有一套 PUN+PDN，只传 电压电平。
栅极绝缘、稳态几乎不取流 → 易级联；但：

因素 后果
级数↑ 延迟累加（tp 近似相加）
扇出↑ 后级栅电容↑ → 前级更慢
长线 额外 RC

细节 → 1.7 · 门如何级联。

逻辑级联 vs 物理级联：

层 盯什么
逻辑 每根线的布尔式（常带非）
物理 电压节点接到下一组栅；每门仍完整 CMOS

一句话： 多级 = 用级数换门数；推气泡 = 用德摩根把图改成 CMOS 爱用的 NAND/NOR；级联只传电压，但延迟跟级数和扇出走。

2.7.0 图为什么能化简？

合并律：只差一个变量的两项可并。

公式 图上
最小项 XY + X/Y = X 相邻两格 1 圈一起 → 消掉 Y
最大项 (X+Y)(X+/Y)=X 相邻两格 0 圈一起 → 消掉 Y

邻接条件： 两格对应输入码 恰好差 1 bit（汉明距离 1）。
所以行列标签用 格雷码（00-01-11-10），不是普通二进制 00-01-10-11——否则「几何相邻」≠「逻辑相邻」。

❌ ✅
行标写成 00,01,10,11 行/列用格雷：00,01,11,10
以为只有左右邻接 上下、左右、卷绕（首尾相接、四角）凡差 1 bit 都算邻

2.7.1 怎么填、怎么圈、怎么读

填图

  1. 真值表 → 每个输入组合进一格（编号 i = 二进制下标）
  2. 格内写 F 的值：1 / 0 / X（无关）
  3. 圈 1 路线： 盯所有 1（X 可当 1 用）
  4. 圈 0 路线： 盯所有 0（X 可当 0 用）

画圈规则

规则 说明
尺寸 1、2、4、8…（2 的整数次幂）个格
形状 矩形（含卷绕成的「环」）
越大越好 圈越大 → 消掉的变量越多 → 项越简
全覆盖 每个目标格（1 或 0）至少进一圈；可重叠
少圈 在覆盖前提下圈数尽量少（对应项数少）

读圈（圈 1 → 与项）

看圈内 哪些变量取值不变：

  • 某变量在圈内 始终为 1 → 与项里写原变量
  • 始终为 0 → 写反变量 /A
  • 有 0 有 1 → 该变量被消去，不出现

各与项再 相或 → 最简（或较简）SOP。

读圈（圈 0 → 或项）对偶

  • 圈内某变量 始终为 0 → 或项里写原变量（使该项在这些点上能为 0）
  • 始终为 1 → 写反变量
  • 有 0 有 1 → 消去

各或项再 相与 → 最简 POS。
合并细节、M2·M3 例 → 2.2.5。

2.7.2 变量数与图的样子（要会画）

二变量（2×2）

       B
     0   1

  1  m2  m3

（具体行列谁是 A/B 按教材习惯；关键是邻接 = 格雷。）

三变量（常用 2×4）

行：A = 0 / 1

四变量（4×4）

左右边、上下边、四角可卷绕邻接——四角四个 1 能圈成一项（消掉全部变量以外的……实际消掉两个变量，剩两变量与项，视具体哪四格而定）。

2.7.4 无关项 (Don't care) X

含义 用法
输入组合 永不出现 可当 0 或 1，任选有利者
出现了但输出 不关心 同上

圈图策略： 把 X 并进能 放大圈 的一侧；不需要覆盖的 X 可以不管（不必为 X 单独开圈）。

例：某格是 X，与两个 1 组成 4 格大圈 → 宁可把 X 当 1，换更简的与项。

2.7.5 和冒险 / 毛刺的接点（进阶一眼）

最简圈有时刚好停在「相邻 1 的边界」：输入跳变时，一圈刚灭、另一圈未亮 → 静态-1 冒险（输出该保持 1，却闪 0）。

消法之一：在卡诺图上 加冗余圈（多覆盖交界上的一对 1），用冗余与项搭桥。
细节 → 2.9 · 2.8.9。

化简追求最少门；消毛刺有时要 故意多一项——又是面积 vs 时序权衡。

2.7.6 小结清单

  1. 标签用格雷，邻接 = 差 1 bit（含卷绕）
  2. 圈尺寸 = 2 的幂；尽量大、尽量少、盖全
  3. 圈 1 → 与项相或；圈 0 → 或项相与
  4. X 用来撑大圈，不必强行覆盖
  5. 读完式 → 2.4 画门；要 NAND → 2.5 推气泡

一句话： 卡诺图 = 把「相邻合并」画出来；圈 1/圈 0 是两条对偶硬件路径，不是两种无关玩法。

2.9.1 传输延迟 tp 与污染延迟 tc

量 英文 含义 由什么决定
传输延迟 Propagation delay tp 输入变后，输出到达 最终正确稳定值 的最长时间 电路里 最长路径（关键路径）
污染/最小延迟 Contamination delay tc 输入变后，输出 开始离开旧值 的最短时间 电路里 最短路径

常记：

tc ≤ （实际延迟） ≤ tp
tp tc
关心谁 时钟能多快、组合块何时可信 保持时间 hold（后级寄存器别太早被污染）
估法 沿关键路径把门延迟 相加（再加线延迟） 沿最短路径相加
悲观/乐观 规格常给 最大 tp（保证最慢也够） 规格常给 最小 tc（保证最早也不会太早）

单门： 规格书里常见 tpLH / tpHL（升/降沿不同）；组合网表把各级叠起来。

多级： 级数↑、扇出↑、长线↑ → tp↑。面积换速度的反面 → 2.5。

2.9.2 关键路径 (Critical path)

定义： 从某输入（或寄存器输出）到某输出（或下一寄存器输入），延迟最大的那条组合路径。

直觉
决定什么 整块组合逻辑要等多久才「算完」
单周期 CPU 时钟周期 T ≥ tp_组合 + 寄存器开销（建立时间等）
CSAPP SEQ 「时钟迁就最慢那一级」= 盖住关键路径

找关键路径（纸上）：

  1. 从输出往回 / 从输入往前，枚举路径
  2. 每级门用其 tp（或单元库延迟）
  3. 和最大者 = 关键；和最小者 ≈ 污染路径

❌ 门数多 ≠ 一定是关键（可能有短路径旁路）
✅ 看 加权路径长度（延迟和），不是只数门个数

HFT： 「延迟」首先是硬件路径；软件侧少依赖链、少畸形访存，是更高抽象层在减「有效等待」。

2.9.3 竞争、冒险与毛刺

词 含义
竞争 同一变化经 多条路径，到达汇合门的时间有先后
冒险 竞争导致输出出现 不该有的瞬间错误
毛刺 (Glitch) 那一下错误脉冲（宽窄由路径差决定）

功能上最终值可能仍对（等够 tp 后稳定），但：

  • 若后级是 异步敏感（异步复位、锁存器使能、时钟误当数据）→ 毛刺可能被采进去
  • 同步系统里，组合毛刺通常在 下一拍采样前消失；仍可能增功耗、干扰模拟/IO

静态冒险（输出本该不变，却闪一下）

类型 现象 典型场景
静态-1 应保持 1，中间闪 0 与或式里两积项「交接」：一圈刚灭、另一圈未亮
静态-0 应保持 0，中间闪 1 或与式对偶情况

卡诺消静态-1： 在两圈交界再 加冗余圈（多一项搭桥）→ 2.7.5。
代价：多一门 / 多项，换无毛刺（或毛刺更窄到可忽略）。

动态冒险

输出本该 单调 0→1 或 1→0，却中间来回抖。多级、多路径时更易出现；消除比静态更绕，工程上常用：同步采样、选通、不把毛刺当时钟。

和其他手段

手段 作用
冗余项（卡诺加圈） 堵静态冒险
格雷码 相邻状态只变 1 bit → 少多路径同时抢 → 2.8.8
选通 / 同步 只在稳定窗口看输出
滤波 极窄毛刺滤掉（模拟/慢速场合）

简表 → 2.8.9。

2.9.4 和「带时钟的时序」怎么分界

本章 (2.9) Ch3 起
组合网的 tp / tc / 毛刺 触发器、寄存器、FSM
输出何时稳定、会否闪 setup / hold：数据相对时钟边沿何时必须稳
关键路径定「组合算多久」 时钟周期、偏移 skew、亚稳态

桥梁一句：

寄存器 → 组合逻辑(tp) → 下一寄存器
         ↑ 关键路径定最短时钟
         ↑ tc 太短可能撞 hold

细节进 Ch3 · 单周期/流水线 → CSAPP Ch4 / 本书 Ch7。

2.9.5 小结

  1. tp = 最晚稳定；tc = 最早开始变
  2. 关键路径 定能跑多快；单周期时钟必须盖住它
  3. 毛刺 = 多路径竞争的瞬态；静态-1 可用冗余圈消
  4. 功能正确 ≠ 时序干净；同步采样能吞很多组合毛刺，但不能当「没有延迟」

一句话： 先保证逻辑对，再用 tp/关键路径问速度，用冒险/毛刺问瞬态——三者都过，组合块才算能用。
