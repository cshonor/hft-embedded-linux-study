笔记

本章核心小节。 计算机运算模块；面积–速度–功耗在这里第一次系统出现。

5.2.1 加法器

基础积木：半加器 vs 全加器

半加器 Half Adder 全加器 Full Adder
输入 A、B（仅两个 1bit） A、B、Cin（低位进位）
输出 Sum、Carry Sum、Cout
限制 无 Cin → 不能直接串成完整多位链的「每一位」 ✅ N 位加法器的标准单元
用途 最低位可以只用半加（无来自更低位）；或教学引入 多位 CPA 逐位用全加器（或等价逻辑）

分界线：有没有 Cin。
多位加法器差异不在「换掉全加器」，而在 进位怎么在位与位之间传递。

CPA = Carry Propagate Adder（进位传播加法器）

一句话：把多个全加器（级）连起来，实现 N 位加减；ALU 内部核心运算块之一。

三类 CPA 对比

1）行波进位 RCA（Ripple Carry）

位0 Cout → 位1 Cin → 位2 Cin → … → 位N-1
（进位像波浪一样串行传）
优点 电路最简单、门最少；教材入门默认
缺点 延迟 ≈ O(N)；高位必须等低位 Cout
痛点 关键路径很长

HFT：若 32/64 位 ALU 纯靠行波，算术延迟巨大；现代高性能核 不会单独依赖纯 RCA。

2）先行进位 CLA（Carry-Lookahead）

进位：分组提前算，不全等低位 Sum 算完。

信号 含义（口诀）
G（Generate） 本位 一定 产生进位（与 A、B 有关）
P（Propagate） 低位进位 可以 传到更高位
优点 远快于行波
代价 硬件（逻辑门）明显增加
场景 教材标准「加速加法」；不少教学/中等设计用 CLA 或分组 CLA

纠一口误：CSAPP Y86 的 ALU 多为 抽象功能块，书中不强制画成 CLA；Harris/教学 CPU 常讲 CLA，真芯片 32/64 位更常上 前缀树。

3）前缀加法器（如 Kogge-Stone 等）

进位：树状并行前缀，尽量摆脱串行依赖。
性能 三者里 理论延迟最低量级
场景 32/64 位高性能 ALU（ARM/x86 应用核常见思路）
代价 门数多、布线复杂，面积/功耗贵

核心规律（空间换时间）

方案 硬件 进位延迟
行波 少 慢（串行拖关键路径）
CLA / 前缀 更多门 更快

👉 计算机硬件永恒权衡：用晶体管（空间）换延迟（时间）。

半加/全加（1bit）
  → CPA：RCA / CLA / 前缀（差在进位网络）
  → 嵌进 ALU（再加逻辑/移位/MUX）
  → C 的 a+b、汇编 ADD → 硬件走这条路径
你的路线 带走
嵌入式 Linux 知「加在 ALU 里做、有进位延迟」即可；不选手绘 CLA 逻辑
HFT 加法器在 关键路径 上 → 影响指令最小延迟与主频；前缀树为压算术时延

文字连线直觉（行波）：

FA0 → Cout0 ──► FA1 → Cout1 ──► FA2 → …

CLA 直觉：各位先出 P/G，再用超前进位逻辑算 Cin_i，再算 Sum（细节公式可跟书，驱动路线不必默写）。

5.2.2 减法器

补码：A − B = A + (~B) + 1 → 同一套加法器 + 取反 + Cin=1。

5.2.3 比较器

类型 做法
相等比较 逐位 XNOR，再 AND 聚合
数量比较 做减法，看符号位与溢出，判 < / >

5.2.4 ALU

1 位切片（组合）： 并行算出 AND、OR、全加结果；MUX 按 Operation 选一路作 Result。
减：B 取反 + 最低位 Cin=1。N 位：切片横拼，进位链串全加器。
→ 门级积木来自 2.8（HA/FA/MUX）。

ALU ≠ 加法器： 加法器 ⊂ ALU；ALU 另含位逻辑，靠 MUX 切换。

多路控制：加 / 减 / 与 / 或 / …；除结果外常输出 Flags（ARM 习惯）：

Flag 含义 用途
N Negative 有符号条件
Z Zero beq / 判零
C Carry 无符号进位/借位
V oVerflow 有符号溢出

对照 CSAPP/Y86：ZF / SF / OF（无统一的「C」命名习惯时别混）。条件跳转依赖这些标志。

5.2.5 移位器与循环移位

种类 空位怎么填
逻辑移位 补 0
算术移位 保留符号位（ASR）
循环移位 移出位绕回另一端

直觉：左移 N 位 ≈ ×2^N；算术右移 ≈ ÷2^N（有符号向 −∞ / 实现相关，先记硬件语义）。

5.2.6–5.2.7 乘法与除法

运算 硬件直觉 成本
乘法 AND 出部分积 → 加法树/阵列累加 面积、延迟都大
除法 阵列除法：反复减 + 移位 更贵；常多周期或不用组合阵列硬做

嵌入式：很多 MCU 可选硬件乘除；HFT 路径尽量避开慢除法、用移位/乘法近似。

5.3.0 补码：减法变加法（接 ALU）

有符号整数常用 2 的补码：

A − B = A + (~B) + 1

→ 硬件：同一套加法器 + B 按位取反 + Cin=1（→ 5.2.2）。
理解 ARM 加减指令、条件标志时，根子在这。

5.3.0b 溢出（运算异常直觉）

无符号 有符号（补码）
典型标志 C（进位/借位） V（oVerflow）
含义 模 2^n 回绕 结果无法用同一位宽有符号表示

N/Z 看结果符号与是否为零。→ ALU Flags 5.2.4。
软件侧：检查标志、饱和运算、或用更宽类型——硬件先把异常「信号」给你。

5.3.1 定点数

  • 二进制小数点位置固定（隐含）：前面若干位整数、后面若干位小数。
  • 加减像整数；乘除要盯对位与溢出。
  • HFT / 金融： 价格、数量常用定点（避免浮点舍入与非确定性）。

5.3.2 浮点数（IEEE 754）

科学计数法硬件化：

字段 作用
符号位 正负
阶码（指数） 常带 偏置（bias） 存储
尾数（有效数字） 规格化表示
格式 位宽
单精度 32
双精度 64

特殊情况（硬件与软件都要认）：

编码 含义
全 0 等 ±0
阶码全 1、尾数 0 ±∞
阶码全 1、尾数非 0 NaN

ARM：整数流水线人人要懂；浮点常在 VFP/NEON 或软浮点库——格式与异常语义仍以 IEEE 为底。

ARM 系统里怎么分工（先记这张表）：

类型 典型角色

5.5.1 基本结构

概念 作用
位单元阵列 每位一个存储单元排成矩阵
字线 wordline 选中某一行（读/写哪一行）
位线 bitline 该行各位数据进出
多端口 多套字线/位线 → 并发读写（寄存器堆常用）

5.5.2 DRAM（动态 RAM）

  • 典型 1T1C（1 晶体管 + 1 电容）存 1 bit。
  • 密度高、成本低、较慢；电容漏电 → 必须定期刷新。
  • 用途：主存、大容量缓冲。

5.5.3 SRAM（静态 RAM）

  • 交叉耦合反相器，常见 6T 单元。
  • 快、不刷新；面积大、贵。
  • 用途：Cache、片上缓冲、微处理器内 寄存器文件（Register file）。
DRAM SRAM
密度 高 低
速度 慢 快
刷新 要 不要
典型 主存 寄存器堆 / Cache

5.5.6 ROM 与演进

  • 非易失：断电不丢。
  • 现代多可写：PROM → EEPROM → Flash（嵌入式固件、启动代码）。

（书中中间小节若谈 CAM/多端口细节，按需补读；口述核心是 DRAM/SRAM/ROM 三分法。）

阵列 = 查找表（LUT）

存储器不只存「数据」：把地址当输入、读出当输出 → 任意组合逻辑（FPGA LUT 思路）。

5.5.7 对嵌入式 Linux：地址空间怎么切

区域 典型实现 驱动怎么碰

❌ ✅

代 是什么 直觉

5.6.1 PLA（可编程逻辑阵列）

  • 以 与–或两级 实现组合逻辑：AND 阵列 + OR 阵列。
  • 规整、适合固定 SOP；灵活度不如现代 FPGA。

5.6.2 FPGA（现场可编程门阵列）

积木 作用
LE / CLB 可配置逻辑元件
LUT 用小 SRAM 实现任意小组合函数（见 5.5 LUT 思路）
触发器 存状态、切流水
可编程布线 把 LE 连成大电路 
HDL/原理图 → 综合映射到 LUT/FF → 布局布线 → 比特流

和你的路线： 主攻 Linux/HFT 软件时，知「硬核 CPU + 可选可编程逻辑」即可；走 FPGA 加速卡再把本节升为精读。

一句话： PLA/PAL 是祖辈 SOP 阵列；FPGA 用 LUT+布线实现任意定制逻辑，补在 ARM 硬核旁边。
