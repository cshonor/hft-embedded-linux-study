# 12.4 本章总结

> 章级精读：[../study.md#ch12-1-4](../study.md#ch12-1-4) · QUICKREF：[../QUICKREF.md](../QUICKREF.md)

## 核心知识矩阵

| 主题 | 要点 |
|------|------|
| **服务模型** | 面向连接、可靠、有序、字节流、全双工 |
| **首部** | ≥20B + 选项（MSS/WSCALE/SACK/TS） |
| **序号** | 字节流位置标记（非段号） |
| **窗口** | rwnd（16-bit，可 WSCALE 扩展） |
| **Flags** | SYN/ACK/FIN/RST/PSH/URG |

---

## 易混速记

| 问题 | 要点 |
|------|------|
| TCP vs UDP 边界 | 字节流 ↔ 报文边界 |
| 序号含义 | 字节号，非段号 |
| 首部大小 | 最小 20B，最大 60B（含选项） |
| Window 16-bit | WSCALE 突破 64KB 限制 |

---

## HFT 核心关联

| TCP 特性 | HFT 评估 |
|----------|---------|
| 可靠+有序 | 代价是重传+队头阻塞 |
| 字节流 | 需应用层分帧 |
| 拥塞控制 | AIMD 不适合热路径 |
| 首部开销 | 20B+ vs UDP 8B |

**结论**：TCP 适合控制面，不适合 HFT 热路径。
