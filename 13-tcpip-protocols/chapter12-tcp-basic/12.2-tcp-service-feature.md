# 12.2 TCP 服务特性

> 章级精读：[../study.md#ch12-1-2](../study.md#ch12-1-2)

## 本节核心目标

深入理解 TCP 的六大服务特性。

---

## 六大特性

| 特性 | 说明 | 实现机制 |
|------|------|----------|
| **面向连接** | 通信前建立连接 | 三次握手 |
| **可靠传输** | 数据最终一定到达 | 序号 + ACK + 重传 |
| **有序交付** | 按发送顺序到达 | 序号重组 |
| **字节流** | 无报文边界 | 流式读写 |
| **全双工** | 双向同时传输 | 独立的发送/接收窗口 |
| **流控+拥塞** | 不压垮接收方和网络 | rwnd + cwnd |

---

## 可靠性如何实现

```
1. 发送方: 序号标记每个字节 → 发送 → 启动计时器
2. 接收方: 收到 → 回 ACK (确认序号)
3a. 正常: ACK 到达 → 推进窗口 → 发新数据
3b. 超时: RTO 溢出 → 重传
3c. dup ACK: 3次 → 快速重传
```

---

## 全双工

TCP 连接有**独立的双向数据流**：
- 每个方向有自己的序号、窗口、ACK
- 一方可以发送数据同时接收另一方的数据
- FIN 可以独立关闭一个方向（半关闭）

---

## HFT 关联

| 特性 | HFT 评估 |
|------|---------|
| 可靠传输 | 代价是重传延迟——HFT 更需要"最新值优先" |
| 有序 | 队头阻塞——丢失的段阻塞后续段 |
| 全双工 | 交易请求/响应可并行 |
| 流控 | rwnd 过小限制吞吐 |
