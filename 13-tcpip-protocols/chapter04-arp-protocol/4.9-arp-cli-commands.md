# 4.9 arp 命令

> 章级精读：[../study.md#ch04-9](../study.md#ch04-9)

## 本节核心目标

熟悉 **arp / ip neigh** 常用子命令。

---

## 常用操作

| 命令 | 作用 |
|------|------|
| `arp -a` | 查看缓存（Windows / 部分 Unix） |
| `arp -d <IP>` | 删除动态条目 |
| `arp -s <IP> <MAC>` | **静态绑定**（重启可能丢失，视 OS） |
| `ip neigh show` | Linux 邻居表（含状态） |
| `ip neigh flush` | 清空 |

---

## 静态 ARP 用途

- 关键服务器**防篡改**、无 ARP 响应的哑设备对接。
- 与 [4.10 嵌入式配置](4.10-embedded-arp-setup.md) 思路相关。

---

## Go / Rust 排障

- 容器/云主机：读宿主机或网络命名空间内的 `ip neigh`，勿假设与宿主机表一致。
