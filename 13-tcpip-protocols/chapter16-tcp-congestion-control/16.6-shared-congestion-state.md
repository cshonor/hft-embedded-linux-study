# 16.6 共享拥塞状态

> 章级精读：[../study.md#ch16-5](../study.md#ch16-5)

## 本节核心目标

理解同路径多连接共享拥塞信息的机制。

---

## 概念

同站点多图（多 IP/网卡到同一目标）时，新连接可**继承**已有连接的 cwnd/ssthresh/RTT 统计，减重复探测。

```
连接1 到 Server: cwnd=20, SRTT=12ms
连接2 到同 Server（新 IP）: 继承 cwnd=20 → 跳过慢启动
```

---

## Linux 实现

```bash
# tcp_congestion_window_validation
sysctl net.ipv4.tcp_cwnd_initialized
```

---

## HFT 关联

HFT 多连接到同一交易所时，共享拥塞状态可加速新连接收敛——减少慢启动阶段延迟。
