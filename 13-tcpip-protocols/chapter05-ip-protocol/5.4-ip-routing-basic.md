# 5.4 IP 转发与路由协议（ARP → IGP → BGP）

> 章级精读：[../study.md#ch05-4](../study.md#ch05-4) · ARP：[ch04 §4.2](../../chapter04-arp-protocol/4.2-arp-basic-operation.md) · 精编 LPM：[04 §4.3](../../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-lpm) · 控制平面：[§5](../../../top_down/05_network_layer_control_plane/study.md) · BGP 与 CIDR：[ch02 §2.4](../chapter02-ip-address-architecture/2.4-cidr-aggregation.md#ch02-4-bgp)

## 本节核心目标

掌握 **LPM 转发**、**直接/间接交付**；理清 **ARP（局域网）** 与 **IGP / EGP（BGP）** 分工；能串起 **主机 → 网关 → 公网** 完整路径。

---

<a id="ch05-4-two-segments"></a>

## 一、完整转发分两段（结合 ARP）

| 段 | 范围 | 靠什么 |
|----|------|--------|
| **① 局域网** | 同一广播域 | **ARP**：内网 IP ↔ 直连 **MAC**；广播**出不了**路由器 → [ch04 广播域](../../chapter04-arp-protocol/4.2-arp-basic-operation.md#ch04-2-broadcast-boundary) |
| **② 跨网段 / 公网** | 路由器之间 | **三层路由协议** 维护路由表，**逐跳**转发 |

**主机侧规则**：同网段用 ARP 找对方；**跨网段一律先发给网关（边缘路由器）**。

```text
[ 内网：ARP + 以太网 ] → 网关 → [ 运营商/公网：IGP + BGP 路由 ]
```

---

<a id="ch05-4-igp-egp"></a>

## 二、名词纠正 + 统一术语

| 纠正 | 正解 |
|------|------|
| ❌ **DGP** | 无此标准词 |
| ❌ **IGB** | 应为 **IGP**（Internal **G**ateway Protocol） |
| ✅ **AS** | **自治系统**（Autonomous System）：一家运营商或一个大型企业，在 BGP 里常作为一个整体编号（如 AS100） |
| ✅ **IGP** | **内部网关协议**（OSPF / IS-IS / RIP…） |
| ✅ **BGP** | **边界网关协议**，**不同 AS 之间**用（属于 **EGP** 这一类） |
| ✅ **EGP** | **外部网关协议**（**类别名**）；现网跨 AS 几乎全是 **BGP** |

**分工一句话**

| 类型 | 管什么 |
|------|--------|
| **IGP** | **同一个 AS 内部**的路由（企业内网、运营商骨干内网） |
| **BGP** | **AS 与 AS 之间**（不同运营商对接、公网前缀交换） |

---

<a id="ch05-4-as-boundary"></a>

## 二附、核心结论：AS ≠ 局域网；IGP 管内、BGP 站门口

### 1）一个 AS 内部 ≠ 局域网

| 易混 | 正解 |
|------|------|
| AS = 一个大局域网？ | **否**。AS 里是**大量路由器 + 多级网段**的**三层网络**，有无数**逐跳**转发 |
| 跨网段怎么转？ | **不靠 ARP 串完全网**；路由器之间靠 **IGP** 选下一跳；**每一跳**只在**当前直连广播域**里 ARP |

**结论**：**AS 内部**路由器之间的选路、跳转 → **全程 IGP（OSPF/IS-IS…）**。

### 2）BGP 只工作在「AS 与 AS 的边界」

- 包在本 AS **内部**爬升/横穿 → **只用 IGP**  
- 包到达**本 AS 边缘出口**，下一跳要进**另一个 AS**（别家运营商/外网）→ 才用 **BGP** 与邻居 AS **交换路由、定跨 AS 下一跳**

### 3）一句话区分边界（背）

> **AS 里面：IGP 当家**（内部路由器互访、一跳一跳）  
> **AS 门口：BGP 站岗**（不同 AS 对接、交换公网路由）

### 4）易错两点

| # | 易错 | 纠正 |
|---|------|------|
| 1 | 同一 AS 里也跑 BGP？ | **内部不用 BGP** 做域内选路；**跨 AS 主要靠 BGP** |
| 2 | 边缘路由器一张表？ | **IGP 条目**（内网前缀）+ **BGP 条目**（外网/其他 AS）**共存**；查表时 **LPM** 选最优，再 **ARP 下一跳 MAC** |

---

## 三、IGP（内部网关协议）

**适用范围**：一个机构、一家运营商**内部**。

| 常见 IGP | 备注 |
|----------|------|
| **OSPF** | 企业网、运营商内常用 |
| **IS-IS** | 运营商骨干常见 |
| **RIP** | 小规模、老环境 |
| **EIGRP** | Cisco 环境 |

**作用**

- 让内部**所有路由器互相学习**去往各内网前缀的路由  
- 路由信息**只在域内**传播，**不**用来和别的运营商直接交换全网表

**例子**：小区路由器 → 本地机房 → 省会骨干，这一段**运营商内部**跳数，靠 **OSPF / IS-IS（IGP）** 维护。

---

## 四、BGP（边界网关协议，属于 EGP）

**适用范围**：**不同 AS、不同运营商之间**（互联网「网间」路由）。

**作用**

- 各大网络之间**交换**可达的 IP 前缀（路径属性、策略）  
- 决定**跨运营商**流量从哪个出口走  
- **边缘路由器**上大量**公网 / 外网**路由，主要靠 **BGP** 学到

> **你的理解对**：边缘路由器去往**外网、跨运营商**的路由，**主要由 BGP 管理**。

→ 深入：[ch02 BGP 与 AS](../chapter02-ip-address-architecture/2.4-cidr-aggregation.md#ch02-4-bgp)

<a id="ch05-4-edge-table"></a>

## 五、边缘路由器：IGP + BGP 两张「地图」并存

一台企业/运营商**边缘路由器**的路由表里通常**同时**有：

| 条目来源 | 去往哪里 | 典型协议 |
|----------|----------|----------|
| **IGP** | 本企业 / 本运营商**内部**各网段 | OSPF、IS-IS… |
| **BGP（EGP）** | **互联网**、其他运营商、其他 AS 的前缀 | BGP |

**每一跳转发时**：仍遵循 **查路由表 → 得下一跳 IP → 本广播域内 ARP 下一跳 MAC**（与 [ch04](../../chapter04-arp-protocol/4.2-arp-basic-operation.md#ch04-2-route-arp) 相同）。

<a id="ch05-4-full-chain"></a>

## 六、串一遍：家宽 → AS100 → AS200 → 服务器

**路径**：家庭网 → **运营商 A（AS100）** → **运营商 B（AS200）** → 目标服务器

| 步 | 位置 | 协议/机制 |
|----|------|-----------|
| 1 | **终端 → 家里网关** | 局域网：**ARP** 解析网关 MAC |
| 2 | **进入 AS100 内部** | 各级路由器转发；选路、下一跳 → **IGP 全权**（OSPF/IS-IS） |
| 3 | **AS100 边缘出口** | 再往前要离开本 AS → **BGP** 与相邻 AS 交换路由，定**跨 AS** 下一跳 |
| 4 | **进入 AS200** | 内部 again → **IGP** 转发至目标网段 |
| 5 | **末端局域网** | **ARP** 交给目标主机 |

```text
PC --ARP--> 家网关 --IGP...IGP--> AS100边缘 --BGP--> AS200边缘 --IGP...IGP--> 目的网 --ARP--> 服务器
         └──── AS100 内 IGP ────┘              └──── AS200 内 IGP ────┘
```

**简化版**（单运营商外访）：PC **ARP 网关** → 边缘 **BGP 选外网** → 域内 **IGP** 跳 → 对端 **IGP/BGP** → 末端 **ARP**。

<a id="ch05-4-cheat"></a>

## 七、背诵（ARP / IGP / BGP）

1. **ARP**：只管**同广播域**；跨网段**找网关**；**不**用 ARP 串完整 AS。  
2. **AS 内**：**IGP 当家**（不是一个大局域网）。  
3. **AS 边界**：**BGP 站岗**（跨 AS / 运营商）；**AS 内不用 BGP**。  
4. **边缘路由表**：**IGP 条目 + BGP 条目** 共存；每跳仍 **路由 IP + ARP MAC**。

## 八、最长前缀匹配 (LPM)

- 目的 IP 与多条路由前缀匹配时，选**掩码最长（最具体）**的一条。  
- 查表五步、经典例题 → [04 §4.3 LPM](../../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-lpm)  
- 路由器查 **FIB** 转发；主机查 **路由表** 决定本机发出还是交网关。

## 九、交付方式（与 ARP 对照）

| 类型 | 条件 | 路由表下一跳 | L2（ARP） |
|------|------|--------------|-----------|
| **直接交付** | 目的与本机**同前缀** | 目的主机 IP | ARP **目的主机** MAC |
| **间接交付** | 目的在远端 | **网关 / 下一跳** IP | ARP **网关** MAC |
