# 13.4 TCP 的路径最大传输单元发现 (PMTUD)

> 章级精读：[../study.md#ch13-4](../study.md#ch13-4) · ICMP PTB：[ch08 §8.3](../../chapter08-icmpv4-icmpv6/8.3-icmp-error-messages.md)

## 本节核心目标

理解 TCP 用 **DF + ICMP** 探测路径 MTU 并调整 **MSS**。

---

## 机制

1. 发 IP 包 **DF=1**（不允许中间分片）
2. 某跳 MTU 不足 → **ICMP Fragmentation Needed** / v6 **Packet Too Big**
3. TCP 降低 **MSS**，后续段适配路径

---

## 黑洞

- 防火墙**丢弃 ICMP PTB** → MSS 不降 → 大包静默丢失。
- 缓解：MSS clamp、保守默认 MSS（如 536/1200）、TCP PLPMTUD（扩展）。

---

## 与 UDP 对比

- UDP 无 MSS；应用需自己控包大小 → [ch10 §10.8](../../chapter10-udp-ip-fragment/10.8-udp-pmtud.md)
