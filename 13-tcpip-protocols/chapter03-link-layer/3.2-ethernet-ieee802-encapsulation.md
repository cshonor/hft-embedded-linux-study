## 一、介质访问机制演进（大白话）

<a id="ch03-2-hub"></a>

### 1）经典共享式以太网（Hub 时代）

#### 集线器（Hub）基础属性

| 项 | 说明 |
|----|------|
| **工作层级** | **物理层**；只处理电/光信号，**不识别 MAC、不解析帧** |
| **本质** | 多端口中继器：**信号放大、整形、转发** |
| **拓扑** | 物理**星型**，逻辑**总线型**——所有端口共用一条总线 |
| **组网** | 总线型 / **集线器 Hub** 星型；**半双工** |

#### 转发与域

| 项 | 说明 |
|----|------|
| **转发规则** | 收到信号后**向除入端口外所有端口泛洪**，不区分目标 → 本网段主机都能收到（利于嗅探 → [混杂模式](../../../wireshark-packet-analysis/chapter-02-traffic-monitor/01-promiscuous-mode.md)） |
| **冲突域** | 整台 Hub **所有端口 = 1 个冲突域**；多机同时发 → 信号冲突 |
| **广播域** | 整台 Hub = **1 个广播域** |
| **双工 / 带宽** | **半双工**；**全体端口共享**带宽（如 10Mbps Hub 全员瓜分） |

#### CSMA/CD（考试简答 · 四步）

共享信道必须靠 **CSMA/CD** 规避冲突：

1. **先听后发（载波监听）**：发送前侦听信道是否空闲  
2. **边发边听（冲突检测）**：发送中持续检测是否冲突  
3. **冲突停发**：发现冲突立即停止，发**阻塞信号**通知全网  
4. **随机重传（退避）**：**二进制指数退避**后重试  

#### Hub 优缺点

| 优点 | 缺点 |
|------|------|
| 结构简单、价格低廉 | 冲突频发，主机越多效率越低 |
| 早期小型组网 | 流量**全网可见**，**安全性极差**，易嗅探 |
| | 半双工 + 共享带宽；**已被交换机全面替代**（MAC 泛洪可让交换机泛洪像 Hub → [3.10](./3.10-link-layer-security.md)） |

### 2）现代交换式以太网（Switch，当前主流）

| 项 | 说明 |
|----|------|
| **组网** | **交换机**星型；端口常 **全双工** |
| **机制** | 端口**点对点**；基于 **MAC 地址表** 转发，**不再靠 CSMA/CD 协调整网** |

1. 交换机查 **MAC 表**，只向目标端口转发（不是 Hub 那样所有端口都收到）  
2. 全双工时**收发物理分离**，可同时发+收，**无信号冲突**  

**冲突域**：**每个交换机端口 ≈ 独立冲突域**（常缩小到单个端点）；交换网内**基本无经典冲突**。

### 3）Hub 与交换机核心对比（直接背）

| 对比项 | 集线器（Hub） | 交换机（Switch） |
|--------|---------------|------------------|
| **工作层** | 物理层 | 数据链路层 |
| **转发方式** | 全网广播 | 基于 **MAC 表** 精准转发 |
| **冲突域** | 整设备 **1 个** | **每端口独立**（全双工下常无冲突） |
| **广播域** | 1 个 | 1 个（未划 VLAN）；VLAN 可再分 |
| **双工** | **半双工** | **全双工**（常见） |
| **带宽** | 所有端口**共享** | 单端口**独享** |
| **CSMA/CD** | **必须** | 基本**不需要** |

> **口诀**：Hub 半双工 CSMA/CD 一大域 · Switch 全双工 MAC 表 端口各一域

#### 现状：Hub 基本不用了

**现在几乎被交换机完全取代**——日常组网**直接选交换机，不用考虑集线器**。

| | **Hub（集线器）** | **Switch（交换机）** |
|---|-------------------|------------------------|
| **层级** | **一层**（物理层） | **二层** |
| **域 / 带宽** | 所有端口**同一冲突域、共享带宽** | **每端口独立带宽**，点对点转发 |
| **转发** | 一台发 → **所有端口广播** → 卡顿、冲突、不安全 | 查 MAC 表**只转目标口** → 快、少冲突、隐私好 |
| **速率** | 多为 **10/100M**，性能差 | 千兆/万兆常见 |
| **现状** | **早已淘汰**，买不到全新主流 Hub | **家用 / 企业标配** |

**Hub 还有场景吗？**

| 场景 | 说明 |
|------|------|
| **家用 / 办公** | **彻底不用** |
| **极特殊** | 老旧工业设备、**抓包**（Hub 全网广播便于监听 → [§2.3.2](../../../wireshark-packet-analysis/chapter-02-traffic-monitor/03-sniff-on-switched-network.md)）、古董机房调试 |
| **考试 / 原理** | 理解 CSMA/CD、冲突域、与交换机对比；**MAC 泛洪**可让交换机暂时「像 Hub」→ [3.10](./3.10-link-layer-security.md) |

**背一句**：Hub = 一层共享总线、泛洪、已淘汰；Switch = 二层 MAC 转发、现网标准（含 **802.3x PAUSE** 流控 → [3.3 §五](./3.3-full-duplex-autoneg.md#ch03-3-pause)，**Hub 不支持**）。

| 易混 | 纠正 |
|------|------|
| Hub vs 交换机 | Hub **不识 MAC**；交换机 **学 MAC、按端口转** |
| Hub vs 路由器 | Hub 在 **L1**；路由器在 **L3**，改 IP 路径 |
| 真 Hub vs 假 Hub | **真 Hub** 串线可见双向流量；**假 Hub**（实为交换机）无效 |

→ WiFi 用 **CSMA/CA**（避免冲突，不是 CD）→ [3.5 大白话](./3.5-wireless-80211.md#ch03-5-csma-ca) · [隐藏终端/RTS/CTS](./3.5-wireless-80211.md#ch03-5-rts-cts) · [自顶向下 §6.3](../../../top_down/06_link_layer_and_lan/6.3_mac_protocol/study.md#ch6-3-csma-local)

## 二、以太网帧（必背 · 考试精简）

### Ethernet II 帧结构（最常用）

| 字段 | 字节 | 核心作用 |
|------|------|----------|
| **目的 MAC** | 6B | 二层寻址，接收方物理地址 |
| **源 MAC** | 6B | 二层寻址，发送方物理地址 |
| **类型（EtherType）** | 2B | 上层协议分用（见下表） |
| **载荷（数据）** | **46–1500 B** | 上层 IP 数据报；**MTU = 1500 B**；不足 46 B **填充** |
| **FCS** | 4B | **CRC** 检错；以太网**只检错、不重传**，坏帧**直接丢弃** |

**常见 EtherType**

| 值 | 协议 |
|----|------|
| **0x0800** | **IPv4** |
| **0x0806** | **ARP** |
| **0x86DD** | **IPv6** |

<a id="ch03-2-ethertype-vs-protocol"></a>

**EtherType vs IP Protocol**：EtherType 是 **L2→L3** 路标（只定 IPv4/IPv6/ARP）；IP **Protocol** 是 **L3→内层** 路标（ICMP/TCP/UDP）— **口诀：二层定三层，三层定内层** → [ch01 §分用](../chapter01-overview/study.md#ch01-layering)

**整体格式**

```text
目的MAC(6B) | 源MAC(6B) | 类型(2B) | 数据(46–1500B) | FCS(4B)
```

- 帧总长：**64～1518 B**（**不含**前导码 7B + SFD 1B）

## 三、进阶 802.1 族（必背考点）

### 1）802.1Q VLAN（虚拟局域网）

- 在**源 MAC 与类型字段之间**插入 **4 B VLAN 标签（Tag）**
- **作用**：**隔离广播域**（交换机已隔离**冲突域**）→ [3.4](./3.4-bridge-switch-stp.md)
- 带 Tag 帧长：**68～1522 B**

<a id="ch03-2-vlan-tci"></a>

#### TCI 字段详解：PCP + DEI + VID

**4 B VLAN 标签** = **TPID（2B）** + **TCI（2B）**  
**TCI（16 bit）** = **PCP（3 bit）** + **DEI（1 bit）** + **VID（12 bit）**

```text
TPID(0x8100, 2B) | PCP(3b) | DEI(1b) | VID(12b)  ← 合在 TCI 里
```

| 字段 | 位数 | 要点 |
|------|------|------|
| **TPID** | 16 bit | 固定 **`0x8100`**，表示这是 VLAN 帧 |
| **PCP** | **3 bit** | **802.1p** 二层 QoS，**0–7**，**数字越大优先级越高** |
| **DEI** | **1 bit** | 可丢弃标识（旧称 CFI） |
| **VID** | **12 bit** | VLAN ID，**可用 1–4094** |

**PCP 常用等级（考点）**

| PCP | 典型业务 |
|-----|----------|
| **0** | 尽力而为（默认）— 普通网页、下载 |
| **1** | 背景 — 备份、日志 |
| **3** | 关键业务 — 视频会议 |
| **5** | 实时视频 — 流媒体 |
| **6** | **语音** — VoIP |
| **7** | **网络控制** — 路由协议、交换机管理 |

**DEI（Drop Eligible Indicator）**

| 值 | 含义 |
|----|------|
| **0** | 正常；拥塞时**优先保留** |
| **1** | 低优先级；拥塞时**优先丢弃** |

→ 配合 QoS：**流量监管、拥塞时保关键业务**

**VID（VLAN Identifier）**

| 值 | 说明 |
|----|------|
| **0** | 仅优先级标记，**不表示 VLAN** |
| **1** | 交换机**默认 VLAN**（端口出厂多在 VLAN 1） |
| **1–4094** | **可用** VLAN ID（考试常考） |
| **4095** | **保留**，不可用 |
| 范围 | 12 bit 共 4096 个编号（0–4095） |

**考试填空/简答精简版**

- 802.1Q Tag = **TPID `0x8100`** + TCI（**PCP 3b + DEI 1b + VID 12b**）  
- **PCP**：0–7，越大越优先；**6** 语音、**7** 网络控制  
- **DEI**：1 = 拥塞时**先丢**  
- **VID**：**1–4094** 可用；**0/4095** 不用；**1** 为默认 VLAN

### 2）802.1p 与 802.1q 的关系

| | 说明 |
|---|------|
| **802.1q** | **VID** → VLAN / **广播域**隔离 |
| **802.1p** | **PCP** → 二层 **QoS 优先级**（写在同一 Tag 的 TCI 里） |

### 3）802.1AX（原 802.3ad）链路聚合 LACP

- **多根物理链路捆绑成一条逻辑链路**
  1. **提升总带宽**
  2. **冗余**：一条断了自动切换
- 协商帧 EtherType：**`0x8809`**；常用**组播 MAC** 传 LACP

### 必背三句话

1. 以太网：**二层 MAC 寻址**、**MTU = 1500**、**CRC 检错不重传**  
2. **冲突域**：交换机端口隔离 · **广播域**：**VLAN（802.1Q）** 隔离  
3. **802.1p**：QoS 优先级 · **802.1AX**：链路聚合

## 四、30 秒写卷子 + 易混

**介质访问**：Hub · CSMA/CD · 一大冲突域 · Switch · 每端口一域  

**帧**：Ethernet II · `0x0800/0806/86DD` · 64–1518B · MTU 1500 · FCS 只检错  

**802.1Q**：TPID `0x8100` · TCI=**PCP(3)+DEI(1)+VID(12)** · VID **1–4094** · PCP **0–7**  

| 易混 | 纠正 |
|------|------|
| 帧 vs 分组 | **帧** = 链路层；**IP 分组** = 网络层 |
| CSMA/CD vs CA | **CD** = 有线以太网；**CA** = WiFi |
| 冲突域 vs 广播域 | 交换机拆**冲突域**；**802.1Q** 拆**广播域** |
| MTU vs 帧长 | **MTU 1500** = 载荷上限；最小帧 **64 B**（含填充） |

## 五、自测（6 题）

1. Hub 组网为何必须用 CSMA/CD？交换机为何可以取消？  
2. EtherType `0x0806` 表示什么？以太网收到坏帧会重传吗？  
3. 802.1Q 插在帧的什么位置？TPID 是多少？  
4. 交换机隔离的是冲突域还是广播域？VLAN 隔离哪个？  
5. VID 可用范围？PCP=6 通常对应什么业务？DEI=1 表示什么？  
6. CSMA/CD 四步各是什么？

<details>
<summary>答案</summary>

1. Hub **同一冲突域**，需 **CSMA/CD**；交换机**端口隔离** + 常全双工。  
2. **ARP**；**不重传**，**丢弃**坏帧（靠上层 TCP 等）。  
3. **源 MAC 与类型字段之间**；TPID **`0x8100`**。  
4. 交换机默认主要拆**冲突域**；**VLAN 拆广播域**。  
5. **1–4094**；**VoIP 语音**；拥塞时**优先丢弃**。  
6. 先听后发 → 边发边听 → 冲突停发 → 二进制指数退避重传。

</details>
