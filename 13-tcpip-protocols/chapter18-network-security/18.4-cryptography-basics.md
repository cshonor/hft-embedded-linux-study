# 18.4 密码学基础

> 章级精读：[../study.md](../study.md)

## 本节核心目标

掌握对称加密、非对称加密、哈希、MAC 的基本概念。

---

## 四大原语

| 原语 | 用途 | 示例 |
|------|------|------|
| **对称加密** | 加密大量数据 | AES-256 |
| **非对称加密** | 密钥交换/签名 | RSA, ECDH |
| **哈希** | 完整性验证 | SHA-256 |
| **MAC** | 认证+完整性 | HMAC-SHA256 |

---

## 对称 vs 非对称

| | 对称 | 非对称 |
|--|------|--------|
| 密钥 | 加解密同一密钥 | 公钥加密，私钥解密 |
| 速度 | **快**（硬件加速） | 慢 |
| 用途 | 数据加密 | 密钥交换/签名 |
| 问题 | 如何安全分享密钥？ | 速度慢 |

**TLS 的做法**：非对称交换密钥 → 对称加密数据。

---

## 哈希 vs MAC

| | 哈希 | MAC |
|--|------|-----|
| 输入 | 任意数据 | 数据 + 密钥 |
| 输出 | 固定长度摘要 | 固定长度认证码 |
| 验证完整性 | ✓ | ✓ |
| 验证身份 | ✗ | ✓（需要密钥） |

---

## HFT 关联

| 原语 | HFT 用途 |
|------|---------|
| AES | 交易数据加密（TLS 内部） |
| ECDH | TLS 1.3 密钥交换（0-RTT） |
| SHA-256 | 行情/订单完整性验证 |
| HMAC | 消息认证 |
