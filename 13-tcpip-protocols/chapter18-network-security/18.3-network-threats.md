# 18.3 威胁

> 章级精读：[../study.md#ch18-2](../study.md#ch18-2)

## 本节核心目标

归纳常见网络攻击，为后续协议铺垫。

---

## 典型威胁

| 威胁 | 说明 |
|------|------|
| **窃听** | 嗅探明文 |
| **篡改** | 改包再转发 |
| **欺骗 (Spoofing)** | 伪造 IP/身份 → [ch05](../../chapter05-ip-protocol/study.md) |
| **中间人 (MITM)** | 插入路径篡改握手/证书 |
| **DoS/DDoS** | 耗尽资源 → [ch13 SYN Flood](../../chapter13-tcp-connection-manage/13.8-tcp-connection-attacks.md) |

---

## 防御方向

- 加密、认证、访问控制、协议层安全（TLS/IPsec/DNSSEC）
