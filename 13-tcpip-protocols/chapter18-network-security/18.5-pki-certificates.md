# 18.5 PKI 与证书

> 章级精读：[../study.md](../study.md) · 密码学：[18.4](18.4-cryptography-basics.md)

## 本节核心目标

理解 PKI（公钥基础设施）和 X.509 证书的作用。

---

## PKI 组成

```
CA (证书颁发机构)
  ↓ 签发
证书 (绑定公钥与身份)
  ↓ 验证
依赖方 (验证证书链 → 信任公钥)
```

| 组件 | 作用 |
|------|------|
| **CA** | 受信任的第三方，签发证书 |
| **证书** | 绑定公钥与域名/组织 |
| **私钥** | 证书持有者保密 |
| **信任链** | 根 CA → 中间 CA → 终端证书 |

---

## 证书内容

```
X.509 Certificate:
  Subject: CN=example.com
  Public Key: RSA-2048 / ECDSA-P256
  Issuer: Let's Encrypt R3
  Validity: 2024-01-01 to 2024-04-01
  Signature: CA's signature on above
  Extensions: SAN (subjectAltName), KeyUsage, ...
```

---

## 证书验证

```
1. 收到证书 → 检查签名链 → 根 CA 在信任库中？
2. 检查有效期 → 未过期？
3. 检查吊销列表 (CRL/OCSP) → 未被吊销？
4. 检查域名匹配 (SAN) → 与连接目标一致？
```

---

## HFT 关联

HFT 交易系统可使用**自签 CA**（内部信任）或**硬件证书**（HSM 存储）。TLS 握手的证书验证增加延迟——TLS 1.3 通过预共享密钥（PSK）支持 0-RTT。
