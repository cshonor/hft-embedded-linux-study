# 18.12 协议攻击

> 章级精读：[../study.md](../study.md)

## 本节核心目标

了解跨层协议攻击的典型模式。

---

## 攻击矩阵

| 攻击 | 层 | 机制 | 防御 |
|------|-----|------|------|
| **ARP 欺骗** | 链路 | 伪造 ARP Reply | 动态 ARP 检测 |
| **DNS 投毒** | 应用 | 伪造 DNS 响应 | DNSSEC |
| **TCP RST 注入** | 传输 | 伪造 RST | 加密 (TLS) |
| **ICMP Redirect** | 网络 | 伪造重定向 | 禁用接受 |
| **VLAN 跳跃** | 链路 | 伪造 VLAN 标签 | 端口配置 |
| **BCP38 缺失** | 网络 | 源地址伪造 | 源地址验证 |

---

## 跨层攻击

攻击者可组合多层攻击：
1. ARP 欺骗 → 成为中间人
2. DNS 投毒 → 重定向流量
3. TLS 剥离 → 降级为明文

**防御**：每层都需独立防护 + 端到端加密。

---

## HFT 关联

| 攻击 | HFT 影响 |
|------|---------|
| ARP 欺骗 | 行情被劫持 |
| DNS 投毒 | 交易流量被重定向 |
| RST 注入 | 交易连接中断 |
| VLAN 跳跃 | 交易网络被渗透 |

**防御**：交换机端口绑定 + 专线 + 加密 + 监控。
