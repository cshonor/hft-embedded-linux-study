## 报文结构

```
┌─────────────────────────────┐
│ Header (12 bytes)            │
│   ID(2) + Flags(2)          │
│   QDCOUNT(2) + ANCOUNT(2)   │
│   NSCOUNT(2) + ARCOUNT(2)   │
├─────────────────────────────┤
│ Question Section             │
├─────────────────────────────┤
│ Answer Section               │
├─────────────────────────────┤
│ Authority Section            │
├─────────────────────────────┤
│ Additional Section           │
└─────────────────────────────┘
```

---

## 首部标志位

| 位 | 含义 |
|----|------|
| **QR** | 0=查询，1=响应 |
| **Opcode** | 0=标准 QUERY |
| **AA** | 权威回答 |
| **TC** | 截断（UDP>512 且无 EDNS0） |
| **RD** | 期望递归 |
| **RA** | 支持递归 |
| **RCODE** | 0 NoError，2 ServFail，3 **NXDOMAIN** |

---

## 传输选择

| 场景 | 协议 | 原因 |
|------|------|------|
| 常规查询 | **UDP/53** | 低延迟，一问一答 |
| 应答 **TC** 截断 | **TCP/53** | UDP 容纳不下 |
| 区域传输 AXFR/IXFR | **TCP/53** | 可靠传输大量数据 |
| DNS over TLS | **TCP/853** | 加密 |
| DNS over HTTPS | **TCP/443** | 加密 + 穿防火墙 |

---

## EDNS0

经典 UDP DNS 限制 **512B** 应答。EDNS0 通过 **OPT 伪 RR** 扩展：

- UDP 可 **>512B**（如 4096）
- 携带 DNSSEC 数据
- 扩展 RCODE 空间

```bash
# 查询时请求 EDNS0
dig @8.8.8.8 example.com +dnssec +bufsize=4096
```

---

## 核心 RR 类型

| 类型 | 用途 | 示例 |
|------|------|------|
| **A** | IPv4 | `example.com. A 93.184.216.34` |
| **AAAA** | IPv6 | `example.com. AAAA 2606:2800:220:1:...` |
| **CNAME** | 别名 → 规范名 | `www.example.com CNAME example.com` |
| **MX** | 邮件；含 **Preference** | `example.com MX 10 mail.example.com` |
| **NS** | 子区域委派 | `example.com NS ns1.example.com` |
| **SOA** | 区权威起点 | Serial/Refresh/Retry/Expire |
| **PTR** | 反向解析 | `34.216.184.93.in-addr.arpa PTR example.com` |
| **SRV** | 服务发现 | `_sip._tcp.example.com SRV 10 60 5060 sip.example.com` |
| **TXT** | 验证/SPF | `example.com TXT "v=spf1 -all"` |

## 代码示例

```python
# Python: 手动构造 DNS 查询
import socket, struct

def dns_query(domain, dns_server='8.8.8.8'):
    # DNS header: ID=0x1234, RD=1, QDCOUNT=1
    header = struct.pack('!HHHHHH', 0x1234, 0x0100, 1, 0, 0, 0)
    # Question: example.com type=A class=IN
    qname = b''.join(bytes([len(l)]) + l.encode() for l in domain.split('.')) + b'\x00'
    question = qname + struct.pack('!HH', 1, 1)  # type=A, class=IN

    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.sendto(header + question, (dns_server, 53))
    data, _ = sock.recvfrom(512)
    # 解析响应...
    return data
```
