## DNS 负载均衡

### Round Robin

```
;; 权威返回多条 A 记录，递归器轮转顺序
example.com.  A  1.2.3.4
example.com.  A  1.2.3.5
example.com.  A  1.2.3.6
```

客户端通常选第一个 → 不同客户端得到不同顺序 → 简单负载均衡。

### 基于地理/延迟的 DNS

- **GeoDNS**：根据客户端 IP 地理位置返回最近服务器
- **延迟路由**：探测 RTT 返回最低延迟节点
- **健康检查**：移除不可用节点的记录

## 动态更新（DDNS）

DHCP 分配 IP 后，客户端向权威服务器提交 RR 变更：

```bash
# nsupdate 命令
nsupdate <<EOF
server ns1.example.com
zone example.com
update delete host1.example.com. A
update add host1.example.com. 300 A 192.168.1.100
send
EOF
```

关联：[ch06 DHCP](../../chapter06-dhcp-config/6.4-dhcp-dns-ddns.md)

## 区域传输

| 类型 | 说明 |
|------|------|
| **AXFR** | 全量区域传输（整个 zone 文件） |
| **IXFR** | 增量区域传输（仅变更部分） |
| 传输协议 | **TCP/53** |
| 触发 | Secondary 检测 SOA Serial 增大 |

## Go/Rust 高并发 DNS

```go
// Go: 使用自定义解析器
resolver := &net.Resolver{
    PreferGo: true,
    Dial: func(ctx context.Context, network, address string) (net.Conn, error) {
        d := net.Dialer{Timeout: 2 * time.Second}
        return d.DialContext(ctx, "udp", "8.8.8.8:53")
    },
}
ips, err := resolver.LookupHost(ctx, "example.com")
```

- `getaddrinfo` **阻塞** → 高并发用 **miekg/dns** 或 **hickory-dns** 自实现 UDP 查询
- Go `net.Resolver` 支持 context 超时 + 自定义 Dial
