## IPv4：点分四组（极简）

**IPv4 地址 = 32 位二进制 = 4 字节 = 点分十进制（四段）**

| 要点 | 说明 |
|------|------|
| 总长度 | **32 bit** |
| 分组 | **4 段**，每段 **8 bit = 1 字节** |
| 写法 | 每段转**十进制 0–255**，用 **`.`** 隔开 |
| 例子 | `165.195.130.107` |

### 二进制 ↔ 点分（以 `192.168.1.1` 为例）

```text
32 位：11000000 10101000 00000001 00000001
4×8： 11000000 . 10101000 . 00000001 . 00000001
十进制：192 . 168 . 1 . 1
```

### 为什么每段是 0–255？

- 8 位最大 `11111111` → **255**；最小 `00000000` → **0**
- **任一段 > 255 的 IPv4 都非法**（如 `256.x.x.x`、`192.168.1.300`）

**一句话**：32 位分 4 段，每段 8 位 0–255，点分隔 → **点分十进制**。

→ 与 [自顶向下 §4.3](../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat/study.md) · [UNP 3.2 地址结构](../../UNP_Vol1/1_BasicFoundation/Chapter03_SocketProgramIntro/3.2_SocketAddressStructure.md)（`in_addr` 存这 32 位，**网络字节序**）

## 练习（先自己做，再对答案）

### 题 1 · 二进制 → 点分

把下面 32 位写成点分十进制：

`10101100 . 00011111 . 00111000 . 11000011`

<details>
<summary>答案</summary>

`172.31.56.195`

（`10101100`=172，`00011111`=31，`00111000`=56，`11000011`=195）

</details>

### 题 2 · 点分 → 二进制（写每段 8 位即可）

`10.0.0.1` 对应的 4 段二进制是？

<details>
<summary>答案</summary>

```text
00001010 . 00000000 . 00000000 . 00000001
```

</details>

### 题 3 · 判断合法 IPv4（对 / 错）

| 地址 | 合法？ |
|------|--------|
| `192.168.0.1` | |
| `300.1.1.1` | |
| `192.168.1` | |
| `0.0.0.0` | |

<details>
<summary>答案</summary>

| 地址 | 合法？ | 原因 |
|------|--------|------|
| `192.168.0.1` | ✅ | 四段，每段 ≤255 |
| `300.1.1.1` | ❌ | 300 > 255 |
| `192.168.1` | ❌ | 只有 3 段，缺一字节 |
| `0.0.0.0` | ✅ | 全 0 合法（常表示「本机/未指定」语义，见 [2.5](../2.5-special-address.md)） |

</details>

## IPv6：块/字段（极简）

| 要点 | 说明 |
|------|------|
| 总长 | **128 bit** |
| 分块 | **8 块（字段）× 16 bit** |
| 写法 | **8 组 4 位十六进制**，用 **`:`** 分隔 |
| 展开例 | `2001:0db8:0000:0000:0001:0000:0000:0001` |

### 规则表（可直接背）

| 规则 | 说明 | `::` 次数 |
|------|------|-----------|
| 基本格式 | 128 bit → 8 组 16 bit 十六进制，`:` 分隔 | — |
| 前导零 | 每组**开头**的 0 可省，至少留 1 个字符（`0db8`→`db8`，`0000`→`0`） | — |
| 零压缩 | 连续**一个或多个全 0 块**用 `::` 代替 | **≤ 1** |
| 内嵌 IPv4 | 末 **32 bit** 写成 IPv4 点分，双栈过渡 | — |

### 两种简化（必考）

**1）前导零省略（组内）**

```text
2001:0db8:0000:0000:0001:0000:0000:0001
→  2001:db8:0:0:1:0:0:1
```

**2）零压缩 `::`（整条地址只能用一次）**

```text
2001:db8:0:0:1:0:0:1
→  2001:db8::1:0:0:1
```

| 特殊地址 | 展开 | 压缩 |
|----------|------|------|
| 未指定 | `0:0:0:0:0:0:0:0` | **`::`** |
| 回环 | `0:0:0:0:0:0:0:1` | **`::1`** |

**为什么 `::` 只能一次？**  
`a::b::c` 无法确定每个 `::` 各补几个 0 块 → **歧义、非法**。

### 内嵌 IPv4（过渡）

末 **32 bit** 可写成 **IPv4 点分**。**最常见：IPv4-mapped**

| 项 | 内容 |
|----|------|
| 格式 | **`::ffff:IPv4`** |
| 结构 | 前 **80 bit** 为 0 + **16 bit `ffff`** + 后 **32 bit** IPv4 |
| 例 | `::ffff:192.0.2.1` ≡ `0000:…:0000:ffff:c000:0201`（展开） |

> **易混**：**IPv4 兼容** `::1.2.3.4` 已废弃（RFC 4291）→ 用 **映射** `::ffff:x.x.x.x`。

### 一句话背诵

**128 bit = 8×16 bit 十六进制块；前导零可省；全零块可压 `::` 且 ≤1 次；末尾可写 `::ffff:IPv4`。**

> **`/数字` = 前多少个二进制位**（不是几段）。例：`2000::/3` 只看最左 **3 bit** → [2.7 示意图](./2.7-unicast-allocation.md#ch02-7-ipv6-prefix)

## IPv6 练习（完整 ↔ 压缩 ↔ 内嵌 IPv4）

### 题 1 · 展开 → 最简压缩

把下面地址写成**最简合法**形式（前导零 + 一次 `::`）：

`2001:0db8:0000:0000:0000:0000:0000:0001`

<details>
<summary>答案</summary>

`2001:db8::1`

（中间连续 6 个全 0 块 → `::`）

</details>

### 题 2 · 判断合法写法

| 地址 | 合法？ |
|------|--------|
| `2001:db8::1` | |
| `2001::db8::1` | |
| `::1` | |
| `::ffff:192.0.2.1` | |

<details>
<summary>答案</summary>

| 地址 | 合法？ | 原因 |
|------|--------|------|
| `2001:db8::1` | ✅ | 仅一处 `::` |
| `2001::db8::1` | ❌ | **两处** `::` |
| `::1` | ✅ | 回环 |
| `::ffff:192.0.2.1` | ✅ | IPv4-mapped |

</details>

### 题 3 · 内嵌 IPv4 → 写出映射形式

主机 IPv4 为 `10.1.2.3`，写成 **IPv4-mapped** IPv6 字符串。

<details>
<summary>答案</summary>

`::ffff:10.1.2.3`

</details>

### 题 4 · 还原块数（进阶）

`fe80::1` 展开后一共是几个 **16 bit 块**？（数清楚 `::` 补了几个 0 块）

<details>
<summary>答案</summary>

**8 块**。`fe80` + `::` 补 6 个 0 块 + `1` → `fe80:0:0:0:0:0:0:1`。

</details>

---

## 易混考点

- 把 IPv6 当“更长 IPv4”背十进制 — 考试/抓包以 **十六进制块** 为准。
- `::` 用两次 → **非法** 表示。
