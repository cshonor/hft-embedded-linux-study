# 7.6 IPv4/IPv6 共存和过渡中的 NAT

> 章级精读：[study.md#ch07-6](./study.md#ch07-6) · NAPT/CGN 基础：[7.3](7.3-nat-napt.md) · DNS64 细节：[ch11 §11.9](../chapter11-dns-domain-resolve/11.9-dns-ipv6-transition.md)

## 本节核心目标

掌握 **DS-Lite**、**NAT64/DNS64** 两类 IPv6 演进中的 NAT 过渡技术 — 定位、原理与考点区分。

<a id="ch07-6"></a>

**定位**：二者均为**过渡技术**，最终目标是**全原生 IPv6 端到端**通信；NAT 在 v6 时代常作**协议桥梁**，而非仅省地址。

---

<a id="ch07-6-dslite"></a>

## 一、DS-Lite（Dual-Stack Lite）

### 原理

| 环节 | 说明 |
|------|------|
| **用户侧** | 内网仍跑 **IPv4 私网**；CPE **B4** 将 IPv4 报文封装进 **IPv6 隧道** |
| **传输** | 封装后的 **IPv4 over IPv6** 经运营商 IPv6 网络送达 |
| **运营商侧** | **AFTR**（CGN 设备）解封装，对 IPv4 做 **NAPT** 后上公网 |

```text
[内网 IPv4] → B4 封装 → IPv6 隧道 → AFTR 解封装 + NAPT → 公网 IPv4
```

### 作用

- **减少运营商对公网 IPv4 地址的消耗** — 家庭侧不再分配独立公网 v4
- **适配 IPv6 演进** — 承载层走 v6，业务层暂保留 v4

→ CGN / 大规 NAT：[7.3](7.3-nat-napt.md)

<a id="ch07-6-nat64"></a>

## 二、NAT64 + DNS64（纯 IPv6 终端访问 IPv4 服务）

**场景**：终端**仅有 IPv6**，需访问存量 **IPv4-only** 服务器（网站、API 等）。

### 1. DNS64

| 项 | 说明 |
|----|------|
| **触发** | 客户端查域名，权威 DNS **无 AAAA**、仅有 **A（IPv4）** |
| **合成** | DNS64 服务器将 IPv4 嵌入特殊前缀，返回合成 **AAAA** |
| **标准前缀** | **`64:ff9b::/96`**（Well-Known Prefix） |

例：IPv4 `203.0.113.1` → AAAA `64:ff9b::203.0.113.1`

### 2. NAT64

| 项 | 说明 |
|----|------|
| **方向** | **IPv6 ↔ IPv4** 双向协议翻译与转发 |
| **工作** | 识别目标地址中的嵌入 IPv4，改写首部（v6→v4 或 v4→v6），维护映射表 |
| **配合** | 必须与 **DNS64** 闭环 — 客户端拿到「伪 v6」地址后，NAT64 才能译回真实 v4 |

### 3. 适用场景

**仅拥有 IPv6 的终端** 访问 **存量 IPv4 业务** — 运营商/企业 v6-only 网络中的典型过渡方案。

→ DNS 流程：[ch11 §11.9](../chapter11-dns-domain-resolve/11.9-dns-ipv6-transition.md)

<a id="ch07-6-compare"></a>

## 补充区分：DS-Lite vs NAT64

| 维度 | **DS-Lite** | **NAT64 + DNS64** |
|------|-------------|-------------------|
| **用户协议栈** | 仍用 **IPv4**（私网） | 用户**只有 IPv6** |
| **核心机制** | **IPv4 over IPv6 隧道** + 运营商侧 CGN/NAPT | **协议层 v6↔v4 翻译** + DNS 合成 AAAA |
| **谁省 v4** | 运营商侧集中 NAPT，少发公网 v4 给家庭 | 终端侧无 v4；边缘 NAT64 对接 v4 互联网 |
| **典型部署** | 运营商宽带 CPE（B4/AFTR） | v6-only 移动/企业网访问 v4 网站 |

**一句**：DS-Lite 是「**用户仍 v4，靠 v6 隧道传**」；NAT64 是「**用户仅 v6，协议翻译对接 v4**」。

---

<a id="ch07-6-cheat"></a>

## 三、核心考点

| # | 要点 |
|---|------|
| 1 | **DS-Lite**：**IPv4 over IPv6 隧道** + **运营商侧 CGN/NAPT** → 节省公网 IPv4 |
| 2 | **NAT64/DNS64**：组合实现 **纯 IPv6 主机访问 IPv4 网络**（DNS64 合成 `64:ff9b::/96` AAAA → NAT64 双向翻译） |
| 3 | **定位**：均为**过渡技术**；长期目标是 **原生 IPv6 端到端** |

| 易错 | 正确 |
|------|------|
| DS-Lite 用户只有 v6 | 用户侧**仍跑 IPv4 私网** |
| NAT64 单独够用 | 需 **DNS64** 配合合成 AAAA |
| 过渡技术 = 永久方案 | **过渡** — 最终全 v6 端到端 |

---

## 疑问与总结

**背：DS-Lite = v4 封装进 v6 隧道 + AFTR 做 NAPT；NAT64/DNS64 = 纯 v6 访 v4（前缀 64:ff9b::/96）；二者都是过渡，不是终态。**
