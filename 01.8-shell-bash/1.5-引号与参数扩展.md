## ① 四种引号，一张总表（Ch6 精华）

bash 解析一行命令时，引号决定**后续哪些展开步骤被跳过**（流水线见 1.1 ③）：

| 形式 | 变量 `$x` | 命令 `$( )` | 通配 `*` | 分词 | 记忆 |
|---|---|---|---|---|---|
| `"双引号"` | ✅ 展开 | ✅ 展开 | ❌ | ❌ 保护 | **默认值**——不确定就用它 |
| `'单引号'` | ❌ | ❌ | ❌ | ❌ | 字面量保险箱，连 `\'` 都塞不进 |
| `无引号` | ✅ | ✅ | ✅ | ✅ 分词 | 坑的源泉（坑点 #7） |
| `\反斜杠` | 转义下一个字符 | | | | 只保一个字符 |

**实测对照**（`v="a b"`）：

```bash
echo "$v 原样 $v"     → a b 原样 a b      # 空格被保护
echo '$v 字面'        → $v 字面           # 什么都不发生
echo 前"$v"后          → 前a b后           # 引号可以只包一段
echo \$v               → $v               # 反斜杠只转义 $
```

**混合拼接**是日常最强技巧：`"前缀"'"$var"''后缀'` 三种引号可以无缝拼在同一个词里，
shell 按段处理再粘起来——写 `awk`/`sed` 内嵌变量时靠它活命：

```bash
awk -v th="$threshold" '$3 > th' data      # 正解：-v 传参
awk '$3 > '"$threshold"'' data             # 拼接法（能跑但脆，优先 -v）
```

## ② 命令替换：`$( )` 的三个要点

1. **别用反引号**——`` `cmd` `` 不能嵌套、引号里行为微妙，POSIX 保留它只为兼容老脚本
2. **可嵌套**：`echo $(echo $(echo 内层))` → `内层`（实测）
3. **剥掉全部尾部换行**（坑点 #10）：`x=$(printf "line\n\n"); echo "[$x]"` → `[line]`
   ——想保留精确字节流就重定向到文件，别过 `$()`

## ③ `$@` 与 `$*`：四种形态全实测（Ch12 最容易挂的部分）

`set -- "x y" z` 之后：

| 写法 | 实测结果 | 词数 | 语义 |
|---|---|---|---|
| `"$@"` | `x y` `z` | **2** | 参数各自独立——**转发参数唯一正确写法** |
| `$@`（裸写） | `x` `y` `z` | 3 | 先分词再传递，边界丢失 |
| `"$*"` | `x y-z`（`IFS=-` 时） | **1** | 全部参数用 IFS 首字符拼成**一个词** |
| `$*`（裸写） | `x` `y` `z` | 3 | 拼接完再分词，等于裸写 `$@`，一样糟 |

**经验法则**：写函数包装器（wrapper）转发参数只有两种合法姿势：

```bash
wrapper() { real_cmd "$@"; }              # 99% 的情况
log_and_run() { echo "运行: $*"; "$@"; }  # 打印用 $*（拼一起好看），执行用 "$@"
```

`$*` 裸写和 `$@` 裸写出现在任何代码里都是 bug 候选——review 时重点盯。

## ④ 参数扩展 `${...}` 八形态（Ch12 表格化）

`${var:-word}` 族里 **冒号的有无 = "空值算不算未设"**——实测（`v=""` vs `unset v`）：

| 写法 | `v=""` | `unset v` | 用途 |
|---|---|---|---|
| `${v:-默认}` | 默认 | 默认 | 空也算没给——可选参数默认值 |
| `${v-默认}` | （空） | 默认 | 只有完全未设才算——区分"空"与"没给" |
| `${v:=默认}` | 默认且赋值 | 默认且赋值 | 顺手把默认值写回变量 |
| `${v:?消息}` | 报错退出 | 报错退出 | 必填参数检查，比 `set -u` 报错友好 |
| `${v:+替代}` | （空） | （空） | 有才展开——构造可选 flag `${VERBOSE:+-v}` |

**场景速记**：

```bash
ENV=${1:-prod}                          # 可选参数带默认
: "${CONFIG:?必须设 CONFIG}"            # 必填检查（: 是空命令，只触发展开）
cmd ${VERBOSE:+-v} ${DRY:+--dry-run}    # flag 按需出现，不出现连空格都不留
```

## ⑤ 模式删除/替换（bash 扩展，POSIX 书没讲全的）

实测（`p=/a/b/c.tar.gz`）：

```bash
${p##*/}   → c.tar.gz      # 删最长前缀 = basename（## 贪婪）
${p#*/}    → a/b/c.tar.gz  # 删最短前缀
${p%.*}    → /a/b/c.tar    # 删最短后缀 = 去一层扩展名
${p%%.*}   → /a/b/c        # 删最长后缀（%% 贪婪）
```

批量改名实战：

```bash
for f in *.jpeg; do mv -- "$f" "${f%.jpeg}.jpg"; done    # 不起外部进程，bash 内建解决
```

## ⑥ 一个 Ch6 的经典陷阱：`ssh` / `su -c` 的引号层级

（坑点 #5 同款，书 Ch6 收尾案例）——变量在**哪一侧展开**取决于引号：

```bash
ssh host "ls '$dir'"      # $dir 本地展开，单引号保护到远端（值送过去）
ssh host 'ls "$dir"'      # $dir 远端展开（远端没这变量，大概率空）
ssh host bash -s <<'EOF'  # 复杂命令别拼引号：整段脚本喂远端，引号问题消失
cd /data && ./process.sh
EOF
```
