# 1.1 shell 一页速查

[← 模块首页](../README.md)

> 这里的"shell"= **bash**（`#!/usr/bin/env bash`），不追求 POSIX sh 兼容——你的脚本都在 Linux 上跑。
> ⚠ 版本基线先看 ⓪；另注意 **`/bin/sh` 不是 bash**（Ubuntu 上是指向 dash 的软链，坑点 #14，✅实测）。

## ⓪ 版本基线（本机实测：Ubuntu 24.04 / bash 5.2.21）

| 环境 | bash 版本 | 影响 |
|---|---|---|
| **本机（Lenovo，Ubuntu 24.04）** | **5.2.21**（2026-10 实测） | 全特性：关联数组、`\|&`、`mapfile`、coproc、`${var,,}` |
| Pi 5 / WSL Ubuntu 24.04 | 5.2.x | 同上 |
| ⚠ `/bin/sh`（Ubuntu） | **不是 bash，是 dash** | 无数组、`[[`、`<( )`、`source`——shebang 写错全炸（坑点 #14） |
| 跨 Mac 才看：macOS 自带 `/bin/bash` | 3.2.57（2007，GPLv2 末版） | 无关联数组等 4.x+ 特性（坑点 #6 备忘） |

**判断**：`echo $BASH_VERSION`（当前 shell）；`readlink -f /bin/sh`（看 sh 指向谁——本机实测 = dash）。
你的仓库脚本目标平台是 Linux，放心写 5.2 语法。

## ① 头部纪律（每个脚本前两行）

```bash
#!/usr/bin/env bash
set -euo pipefail
```

| 标志 | 作用 | 没有它会怎样 |
|---|---|---|
| `-e` | 任何命令失败立即退出 | 错误被吞，脚本带着坏状态继续跑 |
| `-u` | 引用未定义变量即报错 | 打错变量名 = 静默拿到空字符串 |
| `pipefail` | 管道中任一环节失败都算失败 | `cmd1 \| grep x` 里 cmd1 挂了脚本照样成功（坑点 #3） |

可选加强（按需要加，别默认全抄）：

```bash
shopt -s nullglob     # glob 无匹配时展开为空，而不是字面量 "*.log"（坑点 #8）
shopt -s failglob     # 更狠：无匹配直接报错（二选一）
IFS=$'\n\t'           # 分词只按换行/制表符——防御性写法，会改变 $* 等行为，谨慎
trap 'echo "失败于第 $LINENO 行" >&2' ERR   # -e 触发退出时带行号
```

## ② 变量与引号（90% 的 bug 在这）

| 写法 | 含义 | 记法 |
|---|---|---|
| `"$var"` | 引用变量（**永远加双引号**） | 不加引号 = 单词分割 + glob 展开，文件名带空格必碎（坑点 #7，✅实测） |
| `'$var'` | 字面量，不展开 | 单引号里什么都不会发生 |
| `$(cmd)` | 命令替换 | 别再用反引号 `` `cmd` ``，不能嵌套、可读性差；**$() 会剥掉全部尾部换行**（坑点 #10） |
| `"$@"` | 全部参数（保持各自边界） | 转发参数的**唯一**正确写法；`$*` 不加引号会拍平 |
| `$#` / `$1` / `shift` | 参数个数 / 第 N 个 / 左移 | — |
| `${var:-默认}` | 空/未设则用默认值 | 可选参数：`ENV=${1:-prod}` |
| `${var:=默认}` | 同上，且**顺手赋值** | 之后 `$var` 就是默认值了 |
| `${var:?消息}` | 空/未设则报错退出 | 必填参数检查，配 `set -u` 外的显式提示 |
| `${var:+替代}` | 非空才展开 | 构造可选 flag：`${VERBOSE:+-v}` |

## ③ 展开顺序（bash 处理一行的固定流水线）

```
大括号 {a,b} → 波浪号 ~ → 参数/变量 $x → 算术 $(( )) → 命令替换 $( )
→ 单词分割（按 IFS）→ 路径通配 glob（* ? [...]）→ 执行
```

为什么重要：**引号在解析阶段决定后面哪些步骤被跳过**——`"$var"` 展开后不再分词不再 glob；
不加引号则一路走到底。坑点 #2/#7/#8 全是这条流水线的不同切面。

大括号展开（生成序列，不是 glob）：

```bash
mkdir -p lab/{bin,src,build}     # 一次建三个目录
cp f.c{,.bak}                    # = cp f.c f.c.bak
echo {1..10}                     # 序列；{01..10} 保留前导零
```

## ④ 字符串操作（bash 内建，别为这点事起 sed）

| 写法 | 作用 | 例子（`f=dir/app.log`） |
|---|---|---|
| `${#f}` | 长度 | 11 |
| `${f#*/}` | 删**最短**前缀匹配 | `app.log` |
| `${f##*/}` | 删**最长**前缀匹配 | `app.log`（取 basename 标准写法） |
| `${f%.*}` | 删**最短**后缀匹配 | `dir/app`（去扩展名） |
| `${f%%.*}` | 删**最长**后缀匹配 | `dir/app` |
| `${f/log/txt}` | 替换第一个 | `dir/app.txt` |
| `${f//o/0}` | 替换全部 | `dir/app.l0g` |
| `${f:0:3}` | 子串（偏移:长度） | `dir` |
| `${f^^}` / `${f,,}` | 大小写（bash 4+） | `DIR/APP.LOG` |

## ⑤ 判断（`[` 是命令，`[[` 是关键字）

```bash
if cmd; then ... fi                    # 直接用退出码判断，不要 if [ $? -eq 0 ]
[[ -f "$f" ]]     # 普通文件存在    [[ -d "$d" ]]  # 目录存在
[[ -e "$p" ]]     # 存在（任意类型） [[ -r/-w/-x ]] # 可读/可写/可执行
[[ -s "$f" ]]     # 存在且非空       [[ -z "$s" ]]  # 字符串为空（-n 非空）
[[ "$a" = "$b" ]] # 字符串相等       [[ "$n" -gt 3 ]] # 数值比较用 -gt -ge -eq -ne -lt -le
[[ "$s" =~ ^[0-9]+$ ]]              # 正则（右侧不要加引号，加了变字面量）
[[ "$a" = "$b" && "$n" -gt 3 ]]     # 内部用 && ||，外部用 && 连接两个 [[ ]]
(( n > 3 ))                          # 纯数值比较的另一选择，支持 > < == C 风格
```

> 优先 `[[ ]]`：bash 关键字，**内部不做单词分割和 glob**，比 `[` 安全（坑点 #4）。
> 例外：`[[ $a = $b ]]` 右侧不加引号是 **glob 模式匹配**，纯比较写 `[[ $a = "$b" ]]`（坑点 #11，✅实测）。

## ⑥ 循环与读行

```bash
for f in *.log; do ... done            # glob 直接展开，每个文件名是一个词，空格安全（✅实测）
for i in {1..10}; do ... done          # 固定次数
for ((i=0; i<10; i++)); do ... done    # C 风格
while IFS= read -r line; do ... done < file     # 逐行读文件的唯一正确姿势
```

逐行读的三要素：`IFS=`（保留行首行尾空白）、`-r`（禁止反斜杠转义吃掉 `\`）、`< file` 重定向。
**陷阱**：`cmd | while read ...; done` 的 while 跑在**子 shell** 里，循环内改的变量外面看不见
（坑点 #9，✅实测）——解法用进程替换 `while ... done < <(cmd)`。

反模式：`for f in $(ls *.log)` —— 见坑点 #2。

## ⑦ 函数与参数

```bash
die() { echo "ERROR: $*" >&2; exit 1; }        # 统一的死法
need() { command -v "$1" >/dev/null || die "缺 $1"; }

myfunc() {
    local src=$1 dst=${2:-/tmp}      # local 必须！否则变量全局泄漏
    ...
    echo "$result"                   # 返回值用 echo 输出，调用方 $(myfunc a b) 接
    # return 只能返回 0-255 的退出码，不是返回值
}
myfunc "in.txt" || die "处理失败"     # 函数退出码照常走
```

命令行参数解析（轻量版，够 90% 脚本用）：

```bash
while getopts ":i:o:v" opt; do
  case $opt in
    i) in=$OPTARG ;; o) out=$OPTARG ;; v) verbose=1 ;;
    :) die "-$OPTARG 缺参数" ;; \?) die "未知选项 -$OPTARG" ;;
  esac
done
shift $((OPTIND-1))                  # 剩下的是位置参数 "$@"
```

## ⑧ 数组（bash 4+ 全可用；本机 5.2 已实测，dash 一律不支持）

```bash
files=(*.c)                    # glob 直接灌进数组
files+=("new.c")               # 追加
echo "${#files[@]}"            # 元素个数
for f in "${files[@]}"; do ... done    # 遍历的引用必须这么写
"${cmd[@]}"                    # 命令数组展开执行：cmd=(sudo perf stat -a); "${cmd[@]}"

declare -A last_seen           # 关联数组（bash 4+，坑点 #6）
last_seen[eth0]=$(date +%s)
```

## ⑨ 重定向与文件描述符

| 写法 | 作用 | 注意 |
|---|---|---|
| `cmd > out 2>&1` | stdout+stderr 都进文件 | **顺序不能反**：`2>&1 > out` 只把 stdout 送进文件 |
| `cmd &> out` | 同上，bash 简写 | 日志收集常用 |
| `cmd >> log 2>&1` | 追加 | triage 脚本落盘的标准形态 |
| `cmd 2>/dev/null` | 只丢错误输出 | 探测性命令 |
| `exec 3<> fifo` | 打开 fd 3 读写 | 需要双向通信时才用，日常见不到 |
| `cmd \| tee log` | 既看又存 | tee -a 追加 |
| `cmd1 \| grep pat \| awk '{print $2}'` | 三剑客最小集 | grep 挑行，awk 取列，sed 改写 |
| `sed -i 's/旧/新/g' file` | 就地替换（GNU 后缀可选） | Linux 直接这么写（✅本机实测）；跨 Mac 才要写 `-i.bak`（坑点 #12 备忘） |
| `<<< "$str"` | here-string | 把变量喂给读 stdin 的命令 |
| `<<'EOF'` | here-doc，引号阻止变量展开 | 写嵌入脚本/远端执行时用；不加引号则展开 |
| `<<-EOF` | here-doc，吃掉行首 TAB | 让 heredoc 能缩进对齐（只认 TAB 不认空格） |
| `< <(cmd)` | 进程替换：命令输出当文件 | 解子 shell 变量丢失（坑点 #9）；`diff <(ls a) <(ls b)` |

## ⑩ 退出码与错误处理

```bash
cmd || die "步骤 X 失败"                # 单行兜底最常用
cmd && echo ok                          # 成功才执行
if ! cmd; then ... fi                   # 显式取反
rc=$?                                   # 紧随命令之后取，隔一行就被别的命令覆盖
trap cleanup EXIT                       # 无论怎么退出都跑 cleanup——有副作用脚本必备（netem-lab 模式）
trap 'echo "Ctrl-C，清理中" >&2; exit 130' INT
```

退出码约定：0=成功，1=通用错误，2=误用，126=不可执行，127=命令不存在，128+N=被信号 N 杀死（130=Ctrl-C）。

## ⑪ 算术与数值

```bash
n=$((n+1))             # 整数算术，$ 可省：((n++))
(( n > 3 )) && ...     # C 风格比较
printf '%.2f\n' "$(echo "scale=2; 10/3" | bc)"     # 浮点 bash 不会，外包给 bc/awk
awk 'BEGIN{printf "%.2f\n", 10/3}'
```

## ⑫ 常用外部命令（脚本里反复出现的）

| 命令 | 场景 | 关键选项 |
|---|---|---|
| `printf` | 比 echo 可移植、可控 | `printf '%s\n' "$var"`；echo 的 `-e/-n` 各系统不一致 |
| `mktemp -d` | 临时目录 | 用完 `trap 'rm -rf "$tmp"' EXIT` |
| `xargs` | 参数太多/逐条喂 | 文件名安全版：`find . -print0 \| xargs -0 rm` |
| `find` | 找文件 | `-name/-mtime/-size/-exec ... +` |
| `date +%s` / `date -Iseconds` | 时间戳 | 日志命名、耗时统计（`$SECONDS` 也行） |
| `timeout 30 cmd` | 限时 | GNU coreutils 自带，Linux 直接用（✅本机实测）；macOS 没有（坑点 #1 备忘） |
| `nproc` | 核数 | coreutils 自带；macOS 对应物是 `sysctl -n hw.ncpu` |
| `command -v` | 探测命令存在 | 比 `which` 可靠（内建，不吃 PATH 别名干扰） |

## ⑬ 调试

```bash
bash -x script.sh     # 每条命令展开后打印再执行（首选）
bash -n script.sh     # 只查语法不执行（CI 里跑一遍很值）
set -x / set +x       # 脚本内局部开关
PS4='+${LINENO}: ' bash -x script.sh    # trace 带行号

```
