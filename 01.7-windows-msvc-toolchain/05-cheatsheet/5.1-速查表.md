## ① 三条工具链

| 角色 | MSVC (Windows) | macOS | Linux |
|------|----------------|-------|-------|
| 编译器 | `cl.exe` | `clang` | `gcc` / `clang` |
| 链接器 | `link.exe` | `ld64` | `ld` / `lld` |
| 构建系统 | MSBuild (`.vcxproj`) | CMake / make | CMake / make |
| 调试器 | VS 引擎 / WinDbg | `lldb` | `gdb` |
| 目标文件 | `.obj` (COFF) | `.o` (Mach-O) | `.o` (ELF) |
| 可执行文件 | `.exe` (PE) | 无后缀 (Mach-O) | 无后缀 (ELF) |
| 调试信息 | `.pdb` | DWARF（在 `.o` / `.dSYM`） | DWARF（嵌 ELF） |
| `_MSC_VER` 类比 | `1940+` | `clang --version` | `gcc --version` |

## ② 最常用的编译选项互译

| 目的 | MSVC | clang / gcc |
|------|------|-------------|
| 关优化 / 最大优化 | `/Od` / `/O2` | `-O0` / `-O2` |
| 调试信息 | `/Zi` | `-g` |
| 开警告 | `/W4` | `-Wall -Wextra` |
| 警告变错误 | `/WX` | `-Werror` |
| C 标准 | `/std:c17` | `-std=c17` |
| 只编译 | `/c` | `-c` |
| 指定可执行文件输出 | `/Fe:app.exe` | `-o app` |
| 头文件路径 | `/I<dir>` | `-I<dir>` |
| CRT 动态 / 静态 | `/MD` / `/MT` | （无对应概念） |
| 地址消毒剂 | — / 新版 `/fsanitize=address` | `-fsanitize=address` |
| UTF-8 源文件 | `/utf-8` | （默认就是） |
| LTO | `/GL` + `/LTCG` | `-flto` |

## ③ 调试器命令：VS ↔ lldb ↔ gdb

| 动作 | VS | lldb | gdb |
|------|----|----|-----|
| 下断点 | F9 | `b file.c:34` | `b file.c:34` |
| 条件断点 | 右键 → 条件 | `b file.c:34 -c 'n==8'` | `b file.c:34 if n==8` |
| 数据断点 | 右键 → 新建数据断点 | `watchpoint set variable x` | `watch x` |
| 开始 / 继续 | F5 | `run` / `continue` | `run` / `continue` |
| 单步跳过 | F10 | `next` | `next` |
| 单步进入 | F11 | `step` | `step` |
| 步出 | Shift+F11 | `finish` | `finish` |
| 局部变量 | 局部变量窗口 | `frame variable` | `info locals` |
| 打印一个值 | 悬停 / 快速监视 | `p n` | `p n` |
| 调用栈 | 调用堆栈窗口 | `bt` | `bt` |
| 切栈帧 | 双击 | `frame select 1` | `frame 1` |
| 读内存 | 内存窗口 | `x/12w &buf` | `x/12w buf` |
| 线程列表 | 线程窗口 | `thread list` | `info threads` |

> ⚠️ lldb 读数组**必须加 `&`**：`x/12w buf` 会报
> `value whose type can't be converted to an address: int[4]`。
> （[3.3 实测](./../03-debugger-mental-model/3.3-Mac实测lldb.md)）

## ④ MSVC 明确不支持的 C 特性

| 特性 | 检测宏（`__STDC_NO_*__`） | 替代 |
|------|--------------------------|------|
| VLA | `__STDC_NO_VLA__` | `malloc` / 固长数组 |
| `<threads.h>` | `__STDC_NO_THREADS__` | `_beginthreadex` / `std::thread` |
| `_Atomic` | `__STDC_NO_ATOMICS__` | `Interlocked*` / `std::atomic` |
| `_Complex` | `__STDC_NO_COMPLEX__` | 自建结构体 |
| `aligned_alloc` | —— | **`_aligned_malloc`** |

支持起点：VS 2019 16.8 起 `/std:c11` / `/std:c17`。

## ⑤ Windows ↔ POSIX 缺失对照

| POSIX | Windows |
|-------|---------|
| `fork()` | ❌ 无（`CreateProcess`） |
| `pthread_*` | ❌ 无（`CreateThread` / SRWLOCK） |
| `mmap()` | ❌ 无（`CreateFileMapping` + `MapViewOfFile`） |
| `<unistd.h>` | ❌ 无（`<io.h>` / `<process.h>` 部分） |
| `<sys/socket.h>` | `<winsock2.h>` + `WSAStartup()` 前置 |
| `read(fd)` on socket | `recv(s, ...)` |
| `close(fd)` | 文件 `CloseHandle` / socket `closesocket` |
| `fcntl(O_NONBLOCK)` | `ioctlsocket(FIONBIO)` |
| `errno` | `GetLastError()` / `WSAGetLastError()` |
| `sleep(sec)` | `Sleep(ms)` |
| `scanf` | MSVC 报 C4996 → 加 `_CRT_SECURE_NO_WARNINGS`；**别用 `scanf_s`**（非标准） |
