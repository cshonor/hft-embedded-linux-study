# CH2 · MSVC 编译器与选项：把另一套方言翻译成你会的

> **这一章解决什么困惑：** MSVC 的开关全是 `/` 开头，和我的 `-` 完全对不上号。
> 而且版本号有三个体系互相打架（VS 17.12 / MSVC 14.42 / v143），到底该看哪个。

---

## 本章的收获

1. `cl.exe` 的一条命令长什么样，和你熟悉的两件套命令差多少
2. 一张**能直接查」的编译选项三族对照表**（这也是本模块最常被回查的一节）
3. 版本号迷宫：VS 版本 / 工具集版本 / `_MSC_VER` 三者怎么互推，**以及为什么没有 v144**
4. CRT 选型：`/MD` vs `/MT` 的后果，以及"每个 DLL 有自己的堆"这个必踩的坑
5. 调试信息的**三种容器**：PDB / DWARF-in-ELF / DWARF+dSYM —— 这一段有本机实测

## 一句话结论

> MSVC 不是"换了拼写的 gcc"。它的默认行为（CRT、异常、预处理、 C 标准覆盖面）
> 都和 GNU/Clang 有**实质差异**。理解这些差异比记住选项拼写重要得多。
