# 1.0 先分清：Visual Studio / VS Code / Visual Studio for Mac

[← 模块首页](./../README.md) · 下一节：[1.1 IDE 不是编译器 →](./1.1-IDE不是编译器.md)

## 本节讲什么

三个都姓 "Visual Studio" 的东西，其实是**三个不同的产品**。混用名字会让你的所有搜索、
所有提问、所有安装决定全部走偏。先把名字弄清楚，后面三章才不会打架。

## 要点

| 产品 | 是什么 | 现在的可用性 |
|------|--------|--------------|
| **Visual Studio**（俗称 VS / massive IDE） | Windows 上的**完整 IDE**。自带 MSVC 编译器、MSBuild、调试器、设计器、性能分析器 | ✅ 仅 Windows（虚拟机 / Dev Box 也行） |
| **Visual Studio Code**（VS Code） | **跨平台编辑器**，本身不带任何编译器。装 C/C++ 扩展后调用你系统里已有的 clang/gcc/MSVC | ✅ Windows / macOS / Linux |
| **Visual Studio for Mac** | 曾经的 Mac 版 IDE（基于 Mono/Xamarin 血统） | ❌ **2024-08-31 退役** |

三个产品的**唯一共同点是品牌名**。VS Code 不是"VS 的精简版"，它们是两条独立的产品线，
连调试协议、工程文件格式都不共用。

### Visual Studio for Mac 的正式退役

微软 Modern Lifecycle 公告（中文版）原文：

> 自 2024 年 8 月 31 日起，Visual Studio for Mac 已根据 Microsoft 的新式生命周期策略停用。
> 不再支持 Visual Studio for Mac。不会有进一步的服务更新来解决来自 Apple 的安全问题或更新的平台。
> ……为了获得最安全且最新的体验，我们建议使用 **Visual Studio (Windows)** 或者
> **转移到 Mac 上使用 Visual Studio Code**。

出处：<https://learn.microsoft.com/lifecycle/announcements/visual-studio-mac-end-of-servicing>

> **对你的直接影响：** 你现在是 Apple Silicon Mac。**没有 Mac 版 VS 可以装。**
> 在 App Store 或搜索引擎里搜 "Visual Studio"，你装到的会是 VS Code。
> 而 VS Code **不自带编译器** —— 它需要一个你已经装好的 clang/gcc。

## 那在 Mac 上，C/C++ 到底怎么开发

三条路，按推荐度排：

| 方案 | 工具链来源 | 优点 | 代价 |
|------|-----------|------|------|
| **① Xcode 官方工具链**（你已经装了 Xcode 27.0） | Xcode.app + `xcrun`，Apple clang + Apple lldb | 免费、正版、与系统深度集成；Xcode IDE 自带**图形调试器**，和 VS 的调试体验最接近 | 需要执行 `sudo xcodebuild -license` 同意许可后才能用 `xcrun`（见下） |
| **② 现有 cdev 环境 + VS Code** | micromamba `cdev`：clang 23.1.0 / cmake 4.4.3 / make 4.4.1 / lldb 22.1.8 | 版本新（clang 23 vs Apple clang 17 系），已经是你的主力环境 | VS Code 需要另装；`cdev` 的 lldb **缺 debugserver**，见 [3.3 节实测](./../03-debugger-mental-model/3.3-Mac实测lldb.md) |
| **③ 虚拟机跑 Windows VS** | Parallels / Dev Box | 唯一能真正踩 MSVC 的路 | 付费 + 吃资源，只为偶尔对照一次不划算 |

### 本机现状（2026-09-26 实测定格）

```text
clang                     23.1.0      (cdev, Target: arm64-apple-darwin27.0.0)
Xcode.app                 27.0        Build 27A266a
xcode-select -p           /Applications/Xcode.app/Contents/Developer
xcrun --find clang        ❌ "You have not agreed to the Xcode license agreements."
Xcode 自带 lldb           lldb-2103.0.34.103（二进制可直接调用）
VS Code                   未安装
gdb                       未安装
```

⚠️ **一个卡住整条 Apple 工具链的坑**：Xcode.app 装着、`xcode-select` 也指对了，
但 `xcrun` 全部报错——因为**没同意许可协议**。这是安装完 Xcode 后的必经一步：

```bash
sudo xcodebuild -license        # 交互式阅读；或 sudo xcodebuild -license accept 直接接受
```

同意之后 `xcrun --find clang/lldb/make` 全部可用，Apple 官方工具链才算真正到手。

> 这一步我没有替你执行 —— 它需要 sudo，且是法律条款的确认，应该由你本人完成。
> 完整的 lldb 会话输出见 [3.3 Mac 实测](./../03-debugger-mental-model/3.3-Mac实测lldb.md)。
